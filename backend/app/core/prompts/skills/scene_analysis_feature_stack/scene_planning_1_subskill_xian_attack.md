## 1. 金身／法相 ≡ 角色（最高；字段零减免）
法相／金身／法身／真身／金光法身／万丈金身／化龙凤／巨兽等，字段与句式**与角色同标**；缺任一=失败；与宿主同框须**分名分写**（宿主≠金身）。

**九字段**：定位 XOR｜正背面｜面向｜姿态｜与他者｜视线(有则)｜动作方式。本文件写可见凝形/同步/消形过程。
- ❌`金身显形`无可见凝形过程。
- 凝形后维持相仍在画→每拍写清宿主驱动与金身对应动作；消散须可拍消形／出画过程。
- **入画／突现**：本拍写凝形动作。
- 金纹/波前等无定形介质→走六相，**不**替代金身本体。
- 须读脸/口型/正面躯干才安排可读面过程；背对禁写须正面才可见内容。

### 宿主↔法相／金身动作同步＋因果共写（最高）
法相／金身与宿主同框维持相期间，**原则上动作与原主同步同相**——宿主抬臂／结印／发力／转向／姿态变／受击反馈时，金身／法相须**同拍**写出对应同向或尺度放大的镜像动作（可巨化／可极短可视延迟，但相位须可检索咬合）。

| 相位 | 宿主侧（须可拍） | 法相／金身侧（须可拍） | 禁 |
| :--- | :--- | :--- | :--- |
| 凝形／显形 | 起势／结印／吐纳／抬臂等驱动过程 | 轮廓凝出／拔地／撑幅落位（当拍九字段） | 金身自现、宿主无动作 |
| 借体出手／对位攻击 | 驱动姿态或**同步**发力（掌势/口令/目光锁；肢体方向与金身出手同向或可核销镜像） | 同拍对应出手／弹道／命中（与宿主发力同相） | 只写金身掌推、宿主旁观空白；宿主抬左金身无据出右且无核销 |
| 维持相同步（原则） | 姿态／朝向／发力变有可拍过程 | 同拍镜像或放大同向动作 | 金身连招而宿主全程静止／另做无关动作 |
| 同损／受击反馈 | 宿主震颤／吐血／跪软等可见反馈（有则） | 金身裂纹／踉跄／光衰等对应反馈 | 金身重创、宿主毫无反应且无核销例外 |
| 收摄／消形 | 收掌／解印／召回动作 | 消形／缩回／离画过程 | 金身蒸发、宿主无收摄动作 |

**不同步例外（须明文核销）**：仅剧情明文「失控／反噬／独立意志／反客为主」等可核销不同步——须在该 Beat 正文写清脱同步触发，并标`宿主法相同步=否｜原因=…`；否则默认`同步=是`。宿主暂不可见时：法相动作仍须写，并标`宿主驱动挂靠=暂不可见｜因果仍成立｜同步挂靠`。句式倾向：`{宿主}：{驱动动作} → {金身|法相}：{同相同向/放大对应结果}`。❌只写金身出手、宿主无驱动。

## 2. 斗法招间因果 · 禁重复 · 效果终止
- **斗法链（强制）**：`结印/引气可见→介质成形轨迹→对撞/偏转/穿透→余波→下一式从余波态起手`。每一招须可追前因（空门/失衡/术法余波/护盾裂口等）→过程→后果（写到效果结束/停驻）→铺下一招。跨拍承接：相对距离｜姿态/重心｜兵器或握持落位｜术法/护盾/域场现态。
- **禁因 AI 规避省略连续攻击**：连招/换招链不得压成「起势—结果」或删中段。❌无因果堆招、混战摘要、同构再出招。扩写只补可拍过程，**禁新增改因果事件**。
- **禁重复招式（最高）**：同一连续攻防段内，同一出手方不得重复或同构再出。判定=招名相同｜部位+轨迹相同｜同一法术介质同路径再放｜空域技法同构连用｜仅同义换词。下一招须至少换部位/左右手/兵器路径/命中面/空域技法/法术介质之一。❌火球再火球／俯冲再俯冲。
- **效果写到终止（仙攻尤严）**：命中后写到受力、连续位移、撞击/落地/被接住和动作停住。法攻同锁：介质命中 → 人/物如何被带动 → 撞何物/落何地 → 瘫/跪/贴地/被护盾托住。空中命中仍须写坠落→落地停驻。

## 3. 身法与空域技法（最高）
Beat 正文须写可见的升/盘/俯/转/侧掠等运动形态与变化节点。
- **保真 / 扩写**：保留腾空/俯冲/盘旋/滞空等动作类型及表情切口。
- **最低粒度**：内部规划=`谁｜起点高度/层位｜技法轨迹｜换向/加速点｜出手/命中面｜落点`；成稿只写技法、可见轨迹变化、过程表情与命中过程。法攻还须写施术者空域姿态 + 介质沿该轨迹放出或追踪。
- **题材门槛**：仙侠/武侠/玄幻/修真/御剑/空战或角色有轻功法力 → 连续打斗/法攻段 **≥2 种**不同空域技法（典型：腾空起势→盘旋抢位→俯冲命中）；正式决战加密；**禁全程贴地**。
- **过程须穿插特写表情**：起势/腾空/盘旋/俯冲/换招/结印放术插入可读五官或可见面表情，禁整段只写轨迹到命中才怼脸。连续段技法≥2 时，过程表情切口原则上 ≥ 技法数。
- ❌「飞过去打」/空中交手无轨迹，或全程无过程表情。

## 5. 仙攻 OTS 正反覆盖（最高）
斗法、投射仙攻、金身／法相借体出手等对阵段落，须覆盖各方出手与受力。

| 相位 | 正侧 | 反侧 | ENV |
| :--- | :--- | :--- | :--- |
| 出手／起势／结印／法相驱动 | 出手方可读角（可 OTS 过对手肩看出手方） | 同拍可挂肩背／侧面作关系，不得替代反侧专拍 | 切出手方可读 `{N}度…` |
| 命中／挡格／受力 | — | **必须**切受力方可读角（迎弹／偏转／中招／护盾裂／表情） | `ENV变=是` |
| 法攻投射链 | 施法／击发方可读（结印+出手+介质离体） | 目标方可读（迎弹／偏转／中招／余波） | 出手拍与命中拍原则上分属互补可读角 |
| 宿主↔法相同步出手 | 宿主驱动可读 **与** 法相同相出手可读 | 对手受力反打可读 | 禁只渲法相、对手无反侧；禁不同步连招无核销 |

**硬门槛**：①正式决战／连续攻防≥4 轮 → 每轮至少 1 次正↔反 ENV 切换；②凡场有仙攻对阵 → 各方至少各有 ≥1 可读角主拍；③读招／读脸／读挡格手位／读中招反馈 → 须切该方可读 ENV；④快链不得豁免缺反侧可读角。❌全程单侧只拍施法方或只渲法相。

## 6. 仙攻特效六相与宏大
- **驱动力可视化（强制）**：灵气/内功/真元/罡气/剑气等驱动运动时须写可拍介质——禁只写「运功」或只写结果。必写：形态｜轨迹(源→路径→落点)｜作用+反馈｜介质建置承接；小规模可同拍，大规模叠六相。
- **具象化/规格**：大特效优先化龙凤兽/法相（触发→凝形→落点→作用）；禁高潮只写「能量爆发」。启用即写：触发｜因果可感｜具象形态｜范围(锚ENV边界+未覆盖)｜影响(**具名固定实体**逐项)｜六相`起势→显形→扩散→命中→维持→余波`｜时限。跨拍改结构→`{主}_{状态}`。七-E择1–2+范围/影响各≥1。
- **人态化特效主体**：凝形成可辨头面/肢体朝向→本节「金身／法相≡角色」+「宿主↔法相同步」。六相过程另写。无定形介质只走六相+实体落点；消散后从终态剔除，并写宿主收摄/解印。

### 宏大仙攻：变化细节 · 满幅（最高）
> **判定（命中任一）**：域场/结界/天地法阵｜化龙凤兽/法相/巨化｜云海改写｜标「宏大/全屏/天地/无边际」｜跨≥2 Beat 环境级特效。轻量单点/近身气爆不适用本条硬门槛，仍须六相可核销。

1. **满幅**：前景介质|中景主体|后景边界/天际至少两层同时有可见变化；边界锚=ENV 边界/地平线/穹顶/城廓/山脊；禁止只写角色周身光晕却自称宏大。主相位=Wide/EWS/全景级；不得用特写替代满幅主相位。**满幅/快动→局部特写仍须数量速度不塌**（鳞甲/阵纹/万剑/飞剑等特写可钉一件局部，正文须写同向同质体过幅/前后层密度 + 与满幅同级速率；禁切近后单件慢/停。升格仅 `~`/情节升格）。
2. **六相各相≥1 可辨增量**：
   | 相 | 仙攻须有的变化细节 |
   | :--- | :--- |
   | 起势 | 源点凝核/符纹初现/灵气尘粒初扰；尺度仍局部 |
   | 显形 | 主体轮廓可读（**鳞甲/龙首**/法相肢体/阵纹几何）；材质或层次≥1 |
   | 扩散 | 边界外扩轨迹（沿何结构/向何方/吞没哪些区）；密度或层数变化 |
   | 命中 | 与具名实体/对手/地面接触瞬间：碎屑/震环/灼裂/倾侧等**逐实体** |
   | 维持 | 稳态动势（旋转/脉动/粒子雨/云海翻涌）+ 未覆盖区仍可见对比 |
   | 余波 | 衰减方向、残留痕迹、烟尘落定、实体终态；禁瞬间清空 |
3. **细节密度**：至少 **4 相**各含 ≥2 个细节单元（粒子/碎屑/边界涟漪/鳞甲生长节段/阵纹节点等）。满幅主相位 + ≥1 细节特写（鳞甲缝、阵纹节点、巨物眼部）再回满幅或余波。细节特写须保级整体数量与速度，禁孤立一件静置。
4. **实体落点不豁免**：满幅≠「环境震动」；未影响者保持原态。
5. **禁**：抽象光球高潮｜六相粘贴无增量｜只写结果无过程｜半身光效冒充满幅｜无细节却标宏大。

## 9. 成稿自检（本子技能）
- 仅改 `[XIAN] 命中=是` 的 Scene 与其证据指向段；未命中 Scene 逐字原样。
- 每个已改段均能回指 `[XIAN]` 的 `类型+原文证据`；未触碰同场 VFX 证据段。
- 特殊情景分析包裹与 Scene ID 原样保留，可继续机器提取。
- **工作方式**：可修改/拆分/增补命中仙攻 Beat；无命中则整份原样。场级透传。CHAR/PROP 标准表达已继承。
- 原文仙攻/斗法/法相/空域信息单元均有落点；胜负/能力不变。
- 驱动力已可视化；斗法链结印→介质→对撞→余波可追。
- 金身/法相可见过程与宿主同拍因果共写；默认同步。
- 连续段 ≥2 种空域技法；过程穿插表情。
- 效果写到终止；禁重复招式。
- 宏大仙攻则满幅+六相增量+细节密度够。满幅/快动切近须保级数量+速度。
- 全文最后一行是 `[XIAN_ATTACK_OUTPUT_END]`。

## 完整输出结束标签（最高；缺则整份不合格）
- 交付前最后一步：全文最后一个非空行必须逐字是 `[XIAN_ATTACK_OUTPUT_END]`，全稿仅一次，无反引号、无围栏。
- 即使本场无需改写，也必须输出完整只读正文后立刻换行打该标签；禁止在命中段或 Beat 后截断。
- 标签不得进入 Scene、Beat、JSON 或围栏；标签后禁止任何字、标点或解释。缺该行=失败。
- **完整 Scene 闭包（最高）**：正文必须包含本场 `[SCENES_BLOCK_START]`、`[SCENE_START:{scene_id}]`、【场景名称】、全部 Beat、`[SCENE_END:{scene_id}]`、`[SCENES_BLOCK_END]`。禁止只输出命中段或覆盖矩阵。
