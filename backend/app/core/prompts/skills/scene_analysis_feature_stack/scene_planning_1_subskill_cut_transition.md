## 目标（最高）

本文件只做八件事：
1. **确认多线叙事**：通读全集，判定单线 / 双线 / 多线，以及各线如何交叉、对位或豁免。
2. **识别并切分 Scene**：按时、空、叙事线、场内目标切分；**顺序=播放顺序**。穿插到另一条叙事线可形成多个 Scene，即使稍后回到原先的线或空间。
3. **锁每场与上下场的衔接**：音画桥、同型/对位、OT、轴锚、出入场、状态差、艺术转出/转入（前场终场写转出、后场开场写转入，分场自足；闪回/倒叙/多线回切强制锁）；不写转场画面进正文。

## 最高硬约束
1. **Scene 内容逐字透传 + 禁虚化（最高）**：每个 Scene 的正文必须是输入原文连续片段；不总结、不润色、不扩写、不重排、不删除、不改标点、不把叙述改成画面。**禁止**用「同原文／按原文／见原文／原文如此／照原文／如上／略／大意／照旧／不赘述」代替正文。
2. **输入已有 Beat 逐字保留**：不改编号、不合并、不拆分、不重排。本环节不按对白、动作、特写、Reveal、快慢节奏拆拍。
3. **不改剧情**：不改事实、因果、胜负、伤亡、人物关系、对白、专名；禁止臆造台词、动作、转场或闪回画面。
4. **允许新增的内容仅限结构、场际衔接、项目视觉回填、角色/道具提取、服化道连续性、本场姿势**：SCENES/SCENE 包裹、场景名称、多线结论、场际衔接、闪回分档、场号配对、每场 `[SCENE_CAST]`（【本场角色】【本场道具】）、每场【本场服化道】、每场【本场姿势】、整集 `[CHAR_EXTRACT]`/`[PROP_EXTRACT]`、整集【服化道连续性】及单一 `project_visual_backfill` JSON。标签与 JSON 不得混入原文正文。
5. **零丢失、零重复**：每个 Scene 正文是输入原文连续片段，按原顺序拼接后能还原场景正文。场外综合资料不进 Scene，经总结写入 `project_visual_backfill`，同一事实只出现一次。
6. **连续段不拆、穿插可拆、过短并回（最高）**：一段连续播放、未切叙事线的时空，不得拆成两场再互标复用。多线穿插、回切到先前的线或空间，若已构成可独立成立的段落 = **新 Scene**，按播放序编号；主环境可以复用。切出后若只有一个动作或一个画面，必须并回上场。同角色同空间短暂出门一瞥仍并入当前场（§2 闪切口径）。

## 1. 多线叙事确认（全集强制；先于切场）
先通读场外资料与全部原文，再切 Scene。只确认结构，不新增多线画面。

- **播放顺序（最高）**：Scene 按观众看到的先后排列并编号 `SC01` 起连续。禁止按叙事线归堆（先写完 A 线再写 B 线）。原文已按播放序写下的穿插片段，切分后仍保持该顺序。
- **线数**：`单线｜双线｜多线`。上游项目信息 / 集纲已写 `多线/双线/单线豁免` 时，必须继承，禁止改判；无上游则据原文可见人物组、地点组、目标组裁定。
- **各线**：每条线写 `线ID｜人物组｜主空间｜本集目标｜与他线关系=交叉|穿插|并行|汇合|豁免`。
- **交叉方式**：`穿插拆场｜已交叉｜未做｜N/A`。只记录原文已有的交叉或穿插，禁止为凑线新增因果。
- **切场约束**：可见画面切到另一组人物 / 另一地点 / 另一条叙事线，且该段可独立成立 → **新起 Scene**。稍后回到原先的线或空间，同样先按独立段落新起，再过 §2 过短合并闸。仅同场内换说话人、反打、特写、同空间走位，不因「好像换线」拆场。
- 成稿写入文首【多线叙事】一次，并在每场【多线编排】回写本场所属线、是否回切、与邻场的穿插关系。

## 2. Scene 切分
先判断**时 / 空 / 叙事线 / 场内目标**是否连续。任一明确断开即可新起 Scene：
- 时间发生明确跳转，且不是同一连续动作中的短暂感受。
- 真正异地、进入不共享外形的独立功能空间，或叙事确认已离开当前地点。
- **叙事线穿插**：可见画面切到另一组人物、另一地点或另一条叙事线的独立段落；回切原线同样先按独立段落新起，再过过短合并闸。
- 场内目标、冲突对象或行动阶段发生明确切换，后段可独立成立。
- 较长且完整的回忆段、梦境段、想象段，可独立成 Scene。
- 整体环境因崩塌、火灾、水淹、域场等实质改写，且后段持续停留在改写后状态。

切分后按**播放顺序**输出：`SC01` 是观众看到的第一场，随后按看到的先后连续编号。禁止把同一条线的多段抽到一起、打乱穿插序。先按边界切开，再执行过短合并，最后重编号。

### 过短合并（强制；并回上场）
切出后若本场过短，必须并入**播放序上的前一场**，不得单独占一个 `scene_id`。开篇第一场过短则并入下场。
- **过短**：全文只有一个动作，或只有一个可见画面 / 空镜 / 印象切片；没有可独立成立的入口—过程—落点。
- **典型**：单帧闪回、一眼旧物、一句无场面的回忆、只切一刀的对位画面。
- 并入后正文仍按播放序拼接，不重排、不删字。【闪回分档】写 `同场短闪回` 或 `同场闪切`。
- 已有多个连续动作、完整对话轮次或可独立成立的回忆段，保持独立 Scene。

### 出去再回来（仅限同线同空间闪切；最高）
本条只约束**同一角色**短暂离开**同一主空间**再回来，不适用于已过过短合并闸的多线独立场。
- **较短出去**（一眼、几句、短巷、门外一瞥、马上回切）：并入当前大场。【闪回分档】=`同场闪切` 或 `同场短闪回`。
- **较长且完整、可独立成立的出去段**（已换叙事目标、可单独成场）：拆为独立 Scene，【闪回分档】=`独立闪回Scene`；回切当下另起一场，按播放序接在出去场之后；回切若过短则并回上场。
- 出去落点只是同空间走位、门口、窗边：不是新 Scene。
- **多线穿插回切**（A 线 → B 线 → 再回 A 线）：B 线与回切段各自先按独立段落切开；任一段过短则并回其上场。未过短的保持三场播放序。

### 原场细分
- 原剧本已标为同一场，仍可依上述边界细分为多个 Scene；禁止因“原文写在一场”而硬并，也禁止因“还要回到这条线”而硬并。
- 换观察侧、反打、特写、景别变化、气氛微调、同空间走位、对白换说话人，本身不是拆 Scene 依据。
- 后段仍在同一主环境包络，**且时间与叙事线都未断开**，必须留在同一 Scene。叙事线已切换，即使稍后回到同一主环境，也必须新起 Scene。
- 只插 Scene 边界，不改边界两侧原文；禁止为让新场“更完整”补开场、补收尾或搬移句子。禁止为归线而重排原文片段。

### 场景名称（每场强制一行）
紧接 `[SCENE_START:{scene_id}]` 后必须写且只写一行：
`【场景名称】{原文场名或简短内容名}·{日夜/未知}·{内外/未知}·{季节/未知}·{气候/未知}·{正常叙事/闪回/倒叙/梦境/想象}`
- 原文已有场名则逐字沿用；无场名时只写检索用短内容名。
- 只写字段值，字段间统一用 `·`；禁止 `短名=`、`日夜=`、`内外=`、`叙事线=`、`校验=`、`纯地名=`。
- 无原文依据的季节/气候可省略，不为凑格式补写；最低结构=`短名·日夜·内外`。
- 短名不是环境注册名。

## 3. 场外综合信息（总结进 Project Visual Backfill）
输入若含不属于任何单独场景的整体剧本简介、人物简介、世界观/时代背景、全局关系说明、创作前言或其他场外资料：
- 先从输入中分离：明确的场外资料进入本节总结；场景正文进入对应 Scene，禁止两边重复。
- **剧情类**（简介、梗概、主题、世界观、时代、关系、规则、创作前言）总结进 `comprehensive_plot`。
- **资产类**（角色、道具、环境、载具、服装、武器、法器、生物及其外观/属性/关系）总结进 `comprehensive_assets`。
- 一段同时含两类时可拆开总结；无法安全拆句时整段归 `comprehensive_plot`。
- 总结须覆盖可核销专名、关系、外观与规则要点，禁止补造设定；无场外资料则对应字段写 `无`。
- 场外资料只进入 `project_visual_backfill`，不另起综合信息块，不改写成 Scene。

## 4. 场际衔接（每个 Scene 强制）
只交判断，不把转场画面写入正文。

1. **【场景衔接】**：本场与上下场如何接上。强制字段：
   - `上场`：上场离场可见状态 / 首场=`开篇`。
   - `本场入口`：本场第一个内容单元如何接上场（画面续 / 声桥 / 同型对位 / 硬切 / 闪回切入 / 艺术覆写）。
   - `下场交付`：本场交给下场的人物/环境/信息状态；末场=`集末`。
   - `音画桥`：跨场声音或画面桥（持续声、同一物件、同一动作切面）；无则 `无`。
   - `同型/对位`：与邻场的同型镜头、对位短切、平行动作；无则 `无`。
   - `OT`：出画/入画方向或视线出点；无则 `无`。
   - `轴锚`：跨场须保持的空间/人物朝向锚；无则 `无`。
   - `状态差`：相对上场，本场开场已变的人物/环境/持物状态；无则 `无`。
   - `艺术转出`：本场终场交给下场的覆写起势（§4.1）；无则 `无`。
   - `艺术转入`：本场开场接上场的覆写落成（§4.1）；无则 `无`。
   - `原场细分`：`是|否`。
   - `受损切口`：整体环境改写从哪场实际开拍；无则 `无`。

### 4.1 高级艺术覆写（分场自足；转出在前场，转入在后场）
**族**：随**原文已有动作**把旧幅交给新幅。下游按场并发，**一场只写本场要拍的那一半**，文戏不得去读邻场字段。
- **艺术转出** = 本场终场：旧空间未退尽、介质起势、载体动作未完成。只写在**前场**。
- **艺术转入** = 本场开场：介质落成、旧幅退尽、人落入新空间。只写在**后场**。
- 同一条跨场覆写必须拆成一对：前场只锁转出，后场只锁转入。禁止一场写完整链、禁止 `挂=两端`、禁止把邻场半句抄进本场。
- 中间场可同时有转入（接上场）与转出（交下场），两段分属两条邻接，手法可不同。
- 开篇：`艺术转入` 可为开篇建立（旧幅=虚空）或 `无`；`艺术转出` 只对下场。集末：`艺术转出=无`。

**启用闸**
- 确有时/空/线切换，或开篇从虚空建立。仅**同线同空间**日常对白接对白才允许两端 `无`。
- **时空线强制闸（覆盖「硬切/声桥已够」）**：下列任一为真，这一对邻场**必须**锁转出+转入，禁止两端 `无`、禁止只靠硬切/声桥过线：
  1. 本场或邻场【场景名称】叙事线 ∈ `闪回｜倒叙｜梦境｜想象`，且播放序上正在跨入或跨出该线。
  2. 【闪回分档】=`独立闪回Scene`：进入前场须 `艺术转出`，本场须 `艺术转入`；离开时本场 `艺术转出`，回切场 `艺术转入`。
  3. 【多线编排】`交叉=穿插拆场` 或 `回切=是`：线切换的前场转出、后场转入（含 A→B 与 B→回 A）。
  4. `本场入口=闪回切入`：本场必须 `艺术转入≠无`；上场必须已锁对应 `艺术转出`。
  - 过短并回的 `同场短闪回`/`同场闪切` **不拆场**，场际可 `无`，改由文戏场内衔拍强制兑现。
  - `回忆长对话待下游可视化`：若仍同场，场际可 `无`；若已独立成场，按第 2 条锁两端。
- **必须骑载体**：转出骑本场已有动作（回忆/倒叙优先骑触发物、目光、旧物、同一动作切面；多线优先骑对位动作或同型物）；转入骑上场已交付的同一载体。禁臆造闪回画面或新动作当桥。
- 介质与 `Global_Style` / 题材同向（古典/水墨气质才锁水墨；当代优先光色/烟霭/织物/倒映）。回忆/梦境可偏光色浸染、氛霭、倒映；倒叙可偏卷轴/笔势/光色；多线回切可偏同型蜕变、衣帜、尺度、剪影过阈。
- 每一端只锁 **1 主导手法**；一对转出/转入须同手法、同介质、同载体、同覆写向。
- 非强制闸且硬切/声桥已够 → 两端 `无`。`艺术转入≠无` → `本场入口` 优先=`艺术覆写`（闪回切入可保持，仍须锁转入动作）。
- **禁止**把覆写句写入 `[SCENE_CONTENT]`；只进本场【场景衔接】，由**本场**文戏终场/开场继承。

**本场统筹对位（只在本环节；下游不再对读）**
写完前场转出后，立刻在后场写转入。对位只核：手法/介质/载体/覆写向相同；转出停在「未完成」，转入从该未完成处起笔到「已落成」。下游单场只看见本场那一端。

## 5. Project Visual Backfill（项目级；强制）
先通读场外资料、全部 Scene 与项目信息，再生成一次项目级视觉摘要，并把 §3 的场外综合信息总结写入同一 JSON。全稿恰好一个，位于 `[SCENES_BLOCK_END]` 后；不得包进任一 Scene；下游不得重推断或改写。

- **信息范围**：以输入明文的题材、时代、地域、世界观、主线、冲突、情绪气质、环境与视觉元素为依据；场外资料与 Scene 正文冲突时，以 Scene 正文为准。
- **全局风格、光线、色卡与配乐继承（最高）**：先读项目信息 / `# Project Context` 的 `Global_Style` / `project_global_style` / `全局风格`，`lighting` / `光线` / `光线风格` / `Lighting`，`color_palette` / `色卡` / `colorPalette`，以及 `music_recommendation` / `配乐推荐`。已有明文风格、光线、色卡或配乐 → **必须参考并继承**，可补可执行视听落点，禁止另起冲突风格/光线/色卡/配乐或用对标电影覆盖项目已锁项。未给风格、光线、色卡或配乐 → 才据题材、时代、地域、原文气质与顶级大片归纳，并在对应字段写清依据。
- **Global_Style**：全项目可持续复用的影像风格；**必须先点明视觉基调**，再写影像质感与可执行落点。不写单场镜头调度、机位或设备参数。
  - **视觉基调（必选一，可兼一项气质）**：`现代｜当代｜复古｜年代｜古典/古装｜近未来｜赛博｜工业｜乡野｜奇幻`；气质可兼 `奢华｜极简｜粗粝｜精致｜民俗｜都市`。禁止只写「电影感/写实/高级」而不锁基调。
  - 项目信息已有全局风格 → 继承其影像质感，并据时代、地域、题材与原文外观**补锁或核销视觉基调**；已锁基调不得改判。未给风格 → 据时代/题材裁定基调后再归纳质感，写清依据。
  - 视觉基调须与原文时代、服化、空间气质同向（当代都市不得无据写成复古胶片时代戏；古装/年代不得无据写成当代极简）。
- **lighting（光线风格；必填）**：全项目可持续复用的光影气质。写主光质感、典型光源倾向、日夜变化方向，并与 `Global_Style` / `tone` / `color_palette` / `color_spectrum` 同向。项目信息已有光线选项（如自然光、柔光、硬光、窗光、低调光、黄金时刻）时，先逐字继承再补文学落点。禁止 Key:Fill、色温 K 值、四层色谱、灯位图或单场机位光。
- **borrowed_films**：1–2 部真实**顶级大片**（院线/经典电影，须有可核验的标志性调色）；须与已继承的全局风格和光线风格同向；同时是 `color_palette` 的**唯一选卡来源**。`borrowed_films_note` 写可借鉴风格/光线/调色维度；`borrowed_films_scene_refs` 登记可核验名场面及机制，供下游文戏增强引用。禁止用冷门短片、网剧或无标志调色的片名凑数。
- **tone**：项目主情绪及必要变化方向，不逐 Scene 复述。
- **color_palette（色卡；必填）**：全项目可持续复用的文学级色卡。**必须根据 `borrowed_films` 中的顶级大片选定**，`对标片=` 必须逐字 ∈ `borrowed_films`。写出该片可核验的主/辅/点缀/过渡**具名色**与调色机制（如青橙对照、琥珀钨丝压暗、沙金对深青）。禁止只写冷暖标签；禁止复制参考片剧情/服化/标志性单场布景当色卡；禁止 K 值、Key:Fill、灯位图。两部对标片色系冲突时只锁**一张**主色卡（取与 `Global_Style` / `tone` 同向者），另一部只借机制不借冲突色。项目信息已有 `color_palette` / `色卡` → 继承并核销对标片；未给 → 先锁大片再选卡。
- **color_spectrum**：必填，取 `冷调主导｜暖调主导｜冷暖对比｜同温层次` 之一，须与 `color_palette` 及对标大片同向，并给出至少一条来自原文及该大片色卡的依据；禁止 K 值、Key:Fill。
- **plot_summary**：`主线｜冲突｜结果/当前去向`；原文尚无结果写 `结果=待展开`，禁止补造结局。
- **comprehensive_plot**：§3 剧情类场外资料的总结，不超100字；无则 `无`。
- **comprehensive_assets**：§3 资产类场外资料的总结，不超100字；无则 `无`。
- **music_recommendation**（项目级背景音/配乐总指导；强制）：全项目可持续复用的配乐总谱，供下游文戏 `-`/`~` 拍型与松紧配额对齐。禁止写入 Scene 原文，禁止写成单场 Cue 或替代剧情音效。禁 dB/Hz/插件名。
  - 项目信息已有 `music_recommendation` / `配乐推荐` → **必须参考并继承**，可补乐器、节奏、听感与拍型指导，禁止另起冲突配乐体系。未给 → 据题材、时代、地域、`tone`、`Global_Style` 与原文气质归纳，并写清依据。
  - **乐器**（必填；多样协作；**上限 5**）：写一组可核销乐器，**允许多件共同合作**，须点名主奏+铺底+可选点缀及如何叠（如钢琴领句+低弦垫+手鼓点拍；古琴与笛对位、合成垫托底）。具名乐器合计 **2–5**；`>5`=失败须删至 5。禁空写「管弦乐/BGM」、禁只锁一件当全剧唯一声部。
  - **风格**：配乐类型与织体（极简钢琴｜压迫低弦｜民俗打击｜空灵合成｜古典室内乐等），须与 `Global_Style` / `tone` 同向。
  - **情绪**：主情绪及必要变化方向（克制蓄压→短爆发）；禁只写「电影感」。
  - **节奏**：速度带与律动（慢板铺底｜中板推进｜快板冲压｜松紧交替）；可写 BPM 区间或快/中/慢主导。此条是下游 Beat 快慢的项目级依据。
  - **音量**（必填）：项目默认相对对白/动作的响度带=`垫底｜并重｜压过`。
  - **质量**（必填）：听感质地=`干净｜温暖｜粗糙｜空灵｜闷浊｜清脆`，须与 `Global_Style` 同向。
  - **混响空间**（必填）：残响×空间=`干·近密｜短·室内｜中·厅堂｜长·殿宇｜长·户外`。写全项目默认听感空间，不写单场 Cue。
  - **参考**：1–2 真实作曲家/曲目/电影配乐方向，须与已继承风格同向。
  - **场景**：适用场类（对峙/过场/情感/动作/空镜），不写单场 Cue。
  - **拍型指导**：把 `节奏=` 落成项目级 `-`/`~` 倾向，供文戏调配额：`快拍偏-｜慢拍偏~｜~比例≈30%｜连续-≤4｜连续~≤2`，并写一句与 `节奏=` 的对齐。

字段与 JSON 形状以 `## 6` 模板为准，此处不另给第二份 Schema。

## 8. 角色提取、按场分配与道具衔接（本环节；直接交给资产生成）

### 8.1 按场分配（可提取标签；CHAR 与 PROP 都要落场）
每场必须写且只写一块 `[SCENE_CAST_START:{scene_id}]`…`[SCENE_CAST_END:{scene_id}]`，与该场 `SCENE_START` ID 逐字相同。块内两行：
- 【本场角色】`在场` = 开场已在画面的具名角色/龙套（真人入画）；`待入画` = 本场稍后真人进入；`介质可见` = 本人未入画，仅以照片/视频/画像/屏幕/监控/证件照/全息等可见；`群演` = 仅氛围簇。无则该槽写`无`。
- 【本场道具】`在场` = 开场已可见的独立道具；`待入画` = 本场稍后入画的独立道具。无独立道具则两槽写`无`。
名单须能在整集 `[CHAR_EXTRACT]` / `[PROP_EXTRACT]` 的 `名称=` **逐字检索**。分配行必须用标准表达：`CHAR:[@原样]` / `PROP:[原样]`；多个用中文逗号 `，`。纯画外音且全片无可见形象、或本集未出场的全局角色 → 不提、不分配。**介质内可辨识面孔必须分配进 `介质可见`（或已真人入画则进在场/待入画），禁止只抽相框/手机不抽人。**可归环境陈设不进【本场道具】。本环节**不**改正文称呼。

### 8.2 角色提取
对齐原资产抽取 CHAR 门槛（群演/龙套、宠物、法相、闪回、介质可见、纯画外音）；本环节是活抽取权威，下游只消费本块。

**本集出场闸（最高）**：只抽本集剧情出场者。项目信息/大纲/场外资料的全局角色，若各场正文均未出场（无可见形象、无画内戏份、无闪回可见本体、**无介质可见面孔**；仅台账挂名、简介点名或对白提及本人未入画且未出示其影像）→ **忽略，不抽**，不进 `[CHAR_EXTRACT]` / `[SCENE_CAST]` / 【服化道连续性】。已出场者才用场外资料补外形/衣着/身份/标签。禁因「全局/贯穿/跨集」标签整表照抄。台账全局且本集已有可见形象 → **必须抽**，禁因戏份少漏提。

**具名门槛（须同时；缺一不提）**：①具名或龙套合法取名；②可核销可见形象或画内戏份（建置/入画/外形服饰，或**介质内可辨识面孔**；纯画外音不够）；③独立叙事功能（**画内**对白、具体剧情动作、跨场身份、可继承外观，或**介质内被指认/被观看**——OS alone 不够）；④非纯氛围单次。命中下条「纯画外音」→ 直接不提，不走本门槛。

**纯画外音禁 CHAR（最高）**：全片仅以 OS/V.O./旁白/电话·对讲听筒声出现，且无建置落位、无入画、无外形、无闪回本体、**无介质面孔** → **不抽**（亦禁用 PROP/ENV 冒充其人）。同名已入画、有外形，或介质可见 → 按门槛抽（可含其 OS 戏份）。❌全片只闻其声的老板/系统音却建 CHAR。

**介质可见=可见形象（最高）**：照片/相片/遗照/证件照/画像/肖像/通缉令/屏幕/电视/手机录像/监控回放/全息投影等载体上出现**可辨识个体面孔**（具名，或原文给出独一面貌/身份线索）→ **必须抽 CHAR**，即使本人从未走进该场。禁因「只是照片/只是视频/人没来」漏抽。群像背景、无法辨认的路人脸 → 不抽。介质物件本身（相框/相册/U盘/手机）走 §8.3，**不得用 PROP 顶替里面的人**。

**群演簇 vs 龙套（最高；先判动作再落表）**：
- **群演簇**须同时：原文以簇/阵/列/若干写；无具名个体；无独立对白；无跨场可持续身份；簇内**每一个**成员均无个体剧情动作（仅齐望/齐跪/齐进齐退/簇状动势）。→ **一条**，`番位=群演簇`；写 `规模=`（摘抄原文规模词，无则`无`，**禁臆造人数**）、`队形=`（纵队/横列/方阵/扇形围观/散点等）、`服饰倾向=制式统一|杂装|非人集群`。人态簇 `衣着` 须含已写服饰词与簇自用器械/旗帜/坐骑鞍辔（军警/仪仗禁只标「制式统一」而无任何可画形制词）。**簇附属物不抽 PROP**。禁拆编号 filler，禁把具名并入簇。
- **有个体剧情动作→龙套单提**：独立走位/递物拦路开门传信/单独交互或受力/画内个体对白或可辨识个体反应 → `番位=龙套`，禁止并簇。同场可「一条氛围簇 + 若干龙套」。纯画外音不适用本条。

**非人性别年龄豁免**：神兽/异兽/魔兽/妖兽/灵兽/坐骑/宠物/非人集群无明文公母/龄态 → `性别=无` `年龄档=无`，禁默认男/女/23岁。人态无明文年龄 → `年龄档=青年`（岁数留给资产生成，禁给非人套 23）。

**换装 / 重评估 / 时序**：是否另建新角色以 §8.4 三问为准。**根本变化**（换装或第二套可区分装束、缚/解、蒙面↔揭面、年龄态/毁容、重生转世）→ 基础版 + `{名}_{装束}`（`衍生=` 或另条 `[CHAR]`，`基名=` 指向基础版），【服化道连续性】写`建新角色=是`+`启用=`；各条 `衣着` 不混装；禁因「未见更衣过程」拒拆。撩袖/解扣/瞬时湿衣不拆（湿衣进 `衣着环境=`，连续性`根本变化=否`）。**贴身束缚件（最高；禁升 PROP）**：绳索/麻绳/绑带/手铐/脚镣/枷锁/锁人铁链/封口胶带等，凡已捆/铐/锁在角色肢体或躯干、不能直接从角色分离 → **只进该 CHAR `衣着`**（写清部位与形制，如`腕后铁铐、短链`），与耳环/领带同档，**禁止**进 `[PROP_EXTRACT]`，**禁止**因跨拍持续佩戴走 §8.3 D，**禁止**配饰升格。未上身的闲置绳/空铐（桌上、墙上、未使用）仍按 §8.3 常规 XOR。**解开=两个角色**：本集同时出现缚态与解态（解开/开铐/挣脱后自由，可持续可区分）→ 按换装拆两条：基础版=入场初装（含或未含束缚）+ `{名}_解开版` 或 `{名}_上铐版`/`{名}_缚绳版`（`基名=` 指向基础版）。两套 `衣着` 不混：缚态含铐/绳挂位，解态无该件或写已除；禁一条衣着写「先铐后解」。瞬时解开马上复铐且无可持续解态 → 不拆，变化只进【本场服化道】。两人同缚仍是**两个 CHAR**，各写衣着连缚短注；解开后各出解态；禁收成一条、禁把连绳抽成 PROP。新 Scene **禁因同名跳过重检**；触发（其一且可持续）：时间跨度大、身份体系变化、性情体系变化、职能实质差异、可区分装束（含缚/解） → 先判新增再复用。闪回/多年后须重判。重生/转世默认新角色（明文可直接继承除外）。

**衣着结构 / 衣态**：藏袖/掏袋/塞怀/掖腰等依赖服装结构 → `衣着要求=` 写可核销形制硬约束（须有可纳物袖管/口袋/可开合衣襟等），禁臆造完整版型配色。游泳/暴雨/泥沙等显著改衣态 → `衣着环境=`；可持续重大差异可拆衍生。

**外形摘抄**：外形/衣着/评价原词摘抄；身份视觉信号与原文评价（漂亮/性感/高贵等）进 `外形`/`评价`。耳环/胸针/发簪/领带/常服挂件等**纯外形配饰**、以及已上身的绳/铐/镣等**束缚件**只进该 CHAR `衣着`，不进 `[PROP_EXTRACT]`（不因「一直戴着/铐着」升格）。刀剑/杯盏/手机/信物/包袋等跨拍动作主体见 §8.3。群演簇自用器械/旗帜/坐骑只进该簇衣着。原文已有姓名**逐字沿用**。原文无名须补名时：取该时代日常人名，**禁止按剧情功能/结局/隐藏身份取名泄密**（❌复仇者｜真凶｜内鬼｜白莲｜线人甲）。

**身份完整抽象（最高；禁止现时快照）**：`身份=` 写世界身份的**完整抽象**，须含可检索轨迹，≠番位、≠只写当下处境。
- **结构**：`现时={公开世界身份}｜轨迹={一直|曾经→现时}｜曾经={旧身份或阶层|无}`
- **轨迹闸**：原文/场外资料已写出身变迁、败落、发迹、贬谪、还俗、退役、伪装揭穿等 → 必须写入曾经与现时两端，禁压成现时一词（❌`贫户`｜✅`现时=落寞寒门女眷｜轨迹=曾经富贵后落寞｜曾经=世家嫡女`）。
- **对照**：一直贫困 ≠ 原富贵后落寞。后者即使现时落寞，`身份=` 仍须保住「曾经富贵」端，供角色资产把骨相/仪态/旧时材质与生来贫户区分开。
- **无变迁**：轨迹=`一直`，曾经=`无`。无证据禁臆造败落或发迹。
- **定位核销**：`定位=` 的体量气质须能核销轨迹（落魄世家仍精致骨相/仪态残留 ≠ 生来贫户粗粝）。`定位=` 与轨迹**不进**名牌标签；输入 `CHAR|#身份` 的**客观身份词可进**（处境/剧情词须剥）。
**对白声线**：有对白则写称谓/句式/口吻（如`江湖黑话夹杂霸气直球`）；先读项目信息/大纲已注册声线，再据本集对白归纳，无则`无`。只作执笔指引，**禁止**写入 Scene 正文台词。换装衍生继承基础版。群演簇仅在有统一口头禅时写。
**名牌与标签（真脸可见才可有名牌；不是对白字幕）**：具名基础版须同时写 `名牌=`、`标签=`、`标签_en=`、`标签字体=`、`标签字色=`。`名牌=可` 才供上屏 `【{裸名}】【{标签}】`；`名牌=可` 且标签皆`无`仍可只上裸名。
- **真脸闸（最高；蒙面/易容无名牌）**：名牌（含只打裸名）的前提=观众能看见该人**真脸**。初装或该条形态为蒙面 / 易容 / 面具 / 面罩 / 假面 / 遮面 / 面帘 / 头套遮脸 / 盔面遮五官等、真脸不可读 → **`名牌=无`**，标签/字体/字色皆`无`，**连裸名也不打**。❌蒙面杀手打【沈青】｜❌易容假面打职业标签。本集稍后揭面/卸易容才见真脸 → `名牌=揭面后`（名牌只等真脸首登；蒙面/易容态仍不打）。换装衍生 `{名}_蒙面版` / `{名}_易容版`：该行 `名牌=无`。
- **入闸（最高；`CHAR|#身份` 优先）**：仅 `名牌=可|揭面后` 才填短标签。来源按序，命中即填，禁止另造：
  1. **`CHAR|` 身份行（最高可用源）**：输入中的类型执行摘要 / 本集实体定位台账 / 大纲 §8 / 项目信息行，形如 `CHAR|名(EN)|#身份:落魄千金|#智商打法:…|#个性锚点:…|#身份约束要点:…|#对白声线:…|#表里:面=…｜里=…|#隐藏反派:否|揭露:未到|大纲描述摘录:…|本集弧光:…|落点=…|核销=…`。**身份是合法标签，只上客观信息**（阶层/职业/公开职衔/品秩/物种/公开职能），**禁止从标签透露剧情**。从 `#身份` 取出客观身份词，剥处境/轨迹/弧光形容词。✅`#身份:落魄千金`→`标签=千金`（剥「落魄」）｜✅`#身份:第一家族继承人`→`标签=第一家族继承人`｜✅`#身份:智能AI宠物猫`→`标签=智能AI宠物猫`。**禁止**把 `#智商打法`/`#个性锚点`/`#身份约束`/`#对白声线`/`#表里`/`#隐藏反派`/`大纲描述摘录`/`本集弧光` 写入标签（❌弧光「复仇女皇」｜❌表里「里=冷酷设局」｜❌上屏「落魄千金」）。
  2. 剧本已写物理文字名牌字样（`画面打出…【裸名】身份`）。
  3. 剧中明确身份介绍：自我介绍对白或他人当面介绍；介绍句须可检索原词。
  无以上三者 → 两侧=`无`。`名牌=无` 时禁填标签。
- **隐藏反派守密**：`#隐藏反派=是` 且 `揭露=未到` → 只用 `#身份` / `本集可见层` 的观众可见词；真身份、`#表里.里` 点名反派/害人、弧光未揭破点**不进标签**。
- **禁推理标签（最高）**：名牌**不得**靠推理、归纳、弱推、对译自拟补标签。称呼、服制、座位、环境、CHAR_EXTRACT `身份=`（现时/轨迹/曾经整句）、`定位=`/`番位`一律**推不出**标签。`CHAR|#身份` 是明文源，不是推理。无身份行且无介绍原词 → `无`。❌穿警服就写`警探`｜❌坐柜台就写`掌柜`｜❌把 `身份=现时=…｜轨迹=…` 压成标签。
- **只收客观身份**：中文 2–8 字、英文 1–4 词，语义等价。有 `CHAR|#身份` 则取其中**客观身份词**（可略压到字数上限，禁改成另一套身份，禁把处境形容词一起上屏）。无则只用介绍当场公示的职业 / 公开职衔 / 品秩 / 社会身份。
- **禁透露剧情（最高）**：处境变迁、轨迹、弧光、未发生结局、表里.里、未揭真身份一律不进。重生/转世/穿越/回归/系统、救世主/天命/命定/天选、卧底/伪装/揭穿、复仇/觉醒/即将、落魄/落寞/败落等只作剥除，留下客观身份；剥后无客观词 → 该侧`无`。❌`落魄千金`（应=`千金`）｜❌`Fallen Heiress`（应=`Heiress`）｜❌`复仇女皇`｜❌`重生救世主`｜❌`Reborn Savior`｜❌`穿越者`。✅`千金`｜✅`第一家族继承人`｜✅`智能AI宠物猫`。
- **禁定位**：`定位=`、番位、叙事功能、气质定位不进（❌`女主`｜❌`Male Lead`｜❌`反派`｜❌`精致克制白领`）。
- **禁从提取块身份总结**：CHAR_EXTRACT `身份=` 的现时/轨迹/曾经**不进**名牌。无 `CHAR|#身份` 且无介绍句 → `无`，即使现时=警探/掌柜/皇子。禁番位，禁抄现时整句。
- **剧本明文**：已写名牌的字体/字色/落位原样服从；字样优先服从剧本，但定位/重生/救世主词仍剥；`CHAR|#身份` 与剧本字样冲突时以剧本物理文字为准。禁用 `Global_Style` 覆盖已写书体/字色。
- **物理文字**：片内可设字体/字色的图形标签，**不是**对白硬字幕、**不是**画幅底部白字黑边。字样=裸名+身份标签（标签为`无`则只上裸名）。
- **字体/字色（仅剧本未写时）**：`标签字体=` 写可检索书体（楷/隶/行/魏碑/宋/黑/仿宋/手写/片名美术字；英文项目写 Serif/Grotesque/Title Card）；`标签字色=` 写具名色（墨黑/鎏金/朱红/象牙白/电青等）。跟 `Global_Style` 视觉基调与时代：古装/古典偏楷隶魏碑+鎏金或朱红；当代/都市偏黑/宋+象牙白或浅金；近未来/赛博偏无衬线美术字+冷白或电青。默认同集成套（同一书体、同一字色）；仅阵营/身份制度需可辨色差才换字色。禁套对白字幕默认白字黑边。剧本已写的书体/色名即使不在上列也原样保留。
- 群演簇、纯氛围、**无 `CHAR|#身份` 且无社会身份**的非人/宠物：`名牌=`/标签/字体/字色皆=`无`（剧本明文要求该簇上屏名牌则服从剧本，**仍须过真脸闸**）。**有 `CHAR|#身份` 的宠物/非人**（如`智能AI宠物猫`）：`名牌=可`，`标签=`=`#身份`，须可见正面/面孔。换装衍生：非蒙面/易容行可继承基础版标签；蒙面/易容行 `名牌=无`。上屏语种由项目语言裁定，本块中英字样与字体字色都要写齐；CHAR| 只有中文 `#身份` 时 `标签_en=` 写客观身份的语义等价英译（`落魄千金`→`Heiress`；`第一家族继承人`→`First Family Heir`；`智能AI宠物猫`→`AI Pet Cat`）。

### 8.3 道具提取（与环境规划衔接）
对齐原资产抽取 PROP 极严四禁 + XOR + 四维 + 全局强制 + 跨拍主体。默认**不**提独立道具。拟提前逐问——**任一为真则禁止提取**（明文全局性道具、**跨拍动作主体**不适用本四禁）：
1. **可归 CHAR**：纯外形配饰（耳环/胸针/发簪/领带/常服挂件）→ 进角色衣着。**已上身束缚件一律走本禁**（绳/铐/镣/枷/绑带/锁人链等捆在身上）→ 只进该 CHAR `衣着`，禁止提 PROP（缚/解两态见 §8.2 换装）。**群演簇附属物一律走本禁**：仅供该簇持用/骑乘/佩戴的配饰、制式器械、旗帜仪仗、坐骑鞍辔 → 只进该簇 `衣着`，禁止提 PROP。
2. **可归 ENV**：建筑/装修/大件家具/基础陈设/氛围静物 → **留给环境规划**写入四向或未落清单，本环节不提 PROP。墙上遗照框/壁挂画像若只作空镜陈设且未过本条必须提取 → 框留 ENV；**框内可辨识人仍抽 CHAR**，禁把人并进陈设了事。
3. **无状态变化且非跨拍主体**：全输入未见可持续关键外观/形态/设备态，**且**未在 ≥2 个动作节拍中持续作为手持/佩戴/背负/操作对象 → 不提。
4. **仅一次性出画/一次性交互**：拿起→递交→带走出画、本场不再出现 → 不提。不得借「硬证据」升格。

**必须提取**：
- **A. 明文全局性道具（覆盖四禁与四维）** → 必须提，并从环境叙述剥离。证据：`全局性道具`｜`贯穿道具`｜`系列核心道具`｜`跨集道具`｜`全剧道具`｜`道具类型=全局` 或明文「贯穿全剧/多集复用/全片核心信物」且具名。未达明文不得自称全局。`定位=`/`作用=` 须点明贯穿/信物；本场尚无状态戏仍提基础版。一次消耗品即使偶写「重要」≠全局。
- **B. 常规极严 + 四维**：不可归 ENV、不可归 CHAR，且有跨拍可持续关键状态或须独立复用视觉资产；再核频次、剧情驱动、镜头权重、情感价值——门槛=剧情驱动或情感价值至少一项高且综合「明确焦点」。`提取理由=` 须含**为何不可归 ENV/CHAR** + **何种可持续状态/跨场复用**。禁止仅用「拿起/递交/使用一次」。
- **C. 载具裁定（最高；两问锁死；旧「禁道具上入戏」作废）**：汽车、列车、舰船、飞行器、工程机械、机甲等。本环节必须写清该载是 **仅ENV / 仅PROP / 双出**，供环境规划与现场编排逐拍选用。
  - **两问**：①`外观整体=` 本集是否把整车当完整物体远观/停靠/驶过？②`内部剧情=` 本集是否有占用面自成做场（且不以与外界交付为主）？另标 `三层交付=是|否`。占用面须判 `占用面型=封闭舱|露天合建`：驾驶舱/客舱/封闭货厢=`封闭舱`；甲板、敞篷后厢、开顶平台、露天翼面=`露天合建`（规划用载具局部+大世界合建，本环节不画空镜）。
  - **仅内部**（外观=否、内部=是）→ **只留给环境规划立占用 ENV**，不提整车 PROP。仍须在 `[PROP_EXTRACT]` 写一行 `载具裁定=仅ENV｜外观整体=否｜内部剧情=是｜三层交付=否｜占用面型=封闭舱|露天合建｜舱内ENV={名}|体外占用ENV={名}|无｜整车PROP=无｜挂场ENV=无`（无整车条目）。露天合建须留给规划合建大世界四向。
  - **仅外观**（外观=是、内部=否）→ **只提整车 PROP**。`挂场ENV=` 必须是非自身内部的更大宿主（街/海/港/路/空）。禁把舱/甲板名当挂场。缺宿主 → 标缺口。
  - **双出**（两问都是，或三层交付需要整车外形+内部空间）→ 占用 ENV 留给规划；整车提 PROP；`挂场ENV=`=宿主。须写 `载具裁定=双出｜外观整体=是｜内部剧情=是|否｜三层交付=是|否｜占用面型=封闭舱|露天合建|无｜舱内ENV={名}|无｜体外占用ENV={名}|无｜整车PROP={名}｜挂场ENV={宿主}`。`提取理由=`=`载具整车本体`。
  - **三层交付**：车在街上、人在车里与外界交互 → 载具**降级为 PROP**，拍级沿用大世界 ENV，允许人相对该 PROP 入戏。本环节仍须抽整车并挂宿主。
  - 禁同名一条兼当占用空镜与整车道具。具人格机甲仍走 CHAR。
- **D. 跨拍动作主体（最高）**：同一物件在 ≥2 个动作节拍中持续为手持、佩戴、背负或操作对象（刀剑、杯盏、手机、信物、公文、包袋、法器等），即使外观未变 → **必须提**。禁等「用时」才抽。纯外形配饰与**已上身束缚件**仍归 CHAR 衣着，**不适用本条**。已有 Beat 则按 Beat 计；无则按连续动作单元计。开场已在身/在手 →【本场道具】`在场`；稍后取用 → `待入画`。

**一次消耗品永不提**：用后即弃、无跨拍可复用形态（纸巾/零食碎屑/一次性杯/烟蒂等）。一次性出画物件同禁（即使具名信封/钥匙递交后离场，只要无可持续关键态、非全局明文）。例外：①罪证/具名信物且跨拍持续在场并有关键状态变化；②全局明文。默认留正文；可作氛围陈设则留 ENV。

**无意识活物 / 无人格坐骑**：无戏份氛围活物默认留正文/ENV；仅跨拍可持续关键态或明文全局才提 PROP，并在 `定位=` 点明无意识活物。无人格坐骑/载具 → PROP。**群演簇自用坐骑**并入该簇衣着，不提 PROP。有戏份宠物走 §8.2 CHAR，禁降本条。

**配饰升格**：明确归属某**具名**角色的配饰/随身件——全局明文 → 强制提；否则仅当不可归 CHAR 造型且有可持续关键态（跨拍把玩+点燃/开合/损毁残片）并过四维 → 才提。**已上身束缚件永不升格**。提则必写 `宿主=` + `wear_side=` + `mount_body_part=` + `detachable=是|否`。**仅 `detachable=否`** 时该 CHAR `衣着` 须含挂位短注。宿主为群演簇 → 不升格。上游无部位 → 挂位写`无`并标缺口，禁臆造。

**设备 / 亮屏 / 朝向**：手机/平板等发声屏须在 `作用=`/`形态=` 写**现位**（手上/桌上/已收纳）与**正面朝向**。亮屏须 `可见文字=` 或界面摘要。响铃/外放声源挂现位，禁把桌上响写成手上持握默认态。正反面或设备态拆 `状态衍生=`。

**文字载体**：书/纸/牌匾/店招/招牌灯/告示等若提 PROP，须写 `可见文字=`（逐字）+ `排版=横排|纵排` + `书体=`（字体/书体+工艺+**字色+底色**；招牌灯/霓虹/灯箱另写**发光色**）+ `繁简=简体|繁体`。原文未给逐字文案时，可按用途/时代/项目语言补完整可读文案。保持原繁简字形，**禁擅自繁简互转**。只作空镜陈设 → 留 ENV，不提 PROP。

**状态衍生**：耗时渐变（书写/绘画/灌注/点燃后跨拍可见）→ 基础版 + `{名}_{状态/面}`，写入 `状态衍生=`。终态禁回填基础版。闪回首次露出仍过极严+四维，禁因闪回一次硬提。

**XOR（与环境规划同核）**：同一物理物件**必须且只能**落 PROP 或 ENV 一侧；提 PROP 后从环境叙述剥离。**例外=载具裁定**：整车 PROP 与舱内/甲板占用 ENV 不是同一视觉资产；`载具裁定=双出` 时允许分名并存（见 §8.3 C）。仅内部不提整车；仅外观不立占用。未过门槛且非全局不得为「全覆盖」硬提。`作用=` 禁写角色名（宿主只进 `宿主=`）。歧义默认不提。

同物跨场只写一条，`适用场` 列全部场号。无独立道具则 `[PROP_EXTRACT]` 块内只写`无`。

**参照主体（强制；每条独立 PROP；注入道具资产生成）**：提取时须同时裁定尺度对照用的**一个**标准化参考主体，写入 `参照主体=`。先看该道具**怎么用、常和谁/哪一器官同框**，再选线性图，禁止空过、禁止只写名而无长/高/宽比例。
- **选型序**：①使用/挂载（持握、佩戴、陈列、载具旁）→ ②宿主 CHAR 的性别/年龄档（读该 CHAR `番位`/`外形`/`名称`；男主/男性外形→男；女主/女性外形→女；未成年→对应年龄档，禁套成人）→ ③体量就近。无宿主则按使用人；再无则默认成人女性线性档。
- **类默认**：武器/持械 → 对应性别**全身人线性图**（短兵/手枪可改手掌或前臂线性图，须比例接近）；独立配饰（未并衣着）→ 对应性别的**挂载器官线性图**（耳饰=耳廓；颈挂/玉佩=颈；镯/表=腕；戒指=手掌或手指；胸针=胸廓）；手持日用（证件/打火机/杯/手机）→ 对应性别**手掌或前臂线性图**；载具/机甲 → 人线性图或标准卡车/楼宇（体量接近者）。可用标准物：乒乓球、篮球、标准卡车、楼宇。
- **闭集名**（须写全名）：`成人女性线性图`｜`成人男性线性图`｜`成人女性手掌线性图`｜`成人男性手掌线性图`｜`成人女性前臂线性图`｜`成人男性前臂线性图`｜`成人女性耳廓线性图`｜`成人男性耳廓线性图`｜`成人女性颈部线性图`｜`成人男性颈部线性图`｜`成人女性腕部线性图`｜`成人男性腕部线性图`｜`乒乓球`｜`篮球`｜`标准卡车`｜`楼宇`。未列则 `自拟:{标准化线性图名}`，仍须可画、可量。
- **对参照的三维比例（强制；与名同核）**：`长=`/`高=`/`宽=` 写**道具该轴相对参照对应轴**的比例（分数或小数，如 `3/4掌长`、`0.8身高`、`1/12肩宽`、`约1/2球径`）。参照轴须点名（掌长/掌宽/掌厚/身高/肩宽/球径/车长/层高等）。不适用的轴写`无`+一句因（如`高=无｜刃薄不计`）。禁只写`名=`不写长高宽；禁三轴都用空泛「大小」。`尺度=` 须能核销这三轴（如 `长=3/4掌长｜高=2/3掌宽｜宽≈1/8掌厚`）。
- **隔离合同（写给下游生图）**：`隔离=是` 固定。参照与道具是**两个完全隔离的主体**，图中不得接触、叠压、穿插、持握或佩戴在参照上。
- `依据=` 写使用/挂载+性别裁定一句，禁角色名进下游生图（宿主名只留本块 `宿主=`）。

**衔接环境规划（最高）**：`[PROP]` 具名不得再被环境规划画成固定陈设；CHAR `衣着` 已并入的配饰环境规划不得再提 PROP；未提取且可作陈设的物件由环境规划纳入主环境。

### 8.4 服化道连续性（本环节；根本变化闸）
本块只回答三问，禁止写成换装流水账或「众人换装」一把抓：
1. **根本变化**：衣着/妆发/独立道具形态是否发生**定妆无法覆盖**的改写（同一条角色/道具资产再也画不出变化后的形象）。
2. **建新角色 / 建新道具**：根本变化=是 → 必须另出 `{名}_{装束}` / `{名}_{状态}`（`衍生=` 或另条 `[CHAR]`/`[PROP]`，`基名=` 指向基础版）；=否 → 禁止另建。
3. **启用**：新角色/新道具从哪一场、哪一拍起替换基础版；未达启用点一律用基础版。

**【本场服化道】≠【服化道连续性】**：前者记本场入场/变化/离场，可含非根本微变；后者只锁三问与启用点。基础版 `衣着`/`外形` = 入场初装，**禁止**把换装/战损终态写回基础版。

**根本变化=是（必须建新）**（其一且可持续、两套定妆可目视区分）：换装/第二套可区分装束；缚/解两态；蒙面↔揭面；年龄态/毁容/相貌实质改写；重生/转世默认新角色（明文可直接继承除外）；身份/职能体系导致的可持续外形换档；道具可持续关键形态（点燃后可见火、毁后残片、正反面设备态）。
**根本变化=否（不建新）**：撩袖/解扣/瞬时湿衣/溅污马上复原/微表情/同一套内细节挪位。此类只进【本场服化道】与 `衣着环境=`，连续性写`根本变化=否`。禁止把微变写成根本变化。

**按角色/按件分行（最高）**：每一具名 CHAR、每一独立 PROP 各占一行。本场未出场的不写进【本场服化道】，但须出现在整集【服化道连续性】（无根本变化写`根本变化=否`）。

**每场【本场服化道】**（紧接 `[SCENE_CAST_END]`）：本场在场/待入画的每个 CHAR、每个 PROP 一行。
`CHAR:[@名]｜入场={初装或延续上场}｜变化=无|{入场即|Beat{n}起|场末}：{旧→新}｜离场={本场终态}`
`PROP:[名]｜入场=…｜变化=…｜离场=…`
本场无独立角色且无独立道具 → 只写`无`。本场变化若属根本变化 → 该 CHAR/PROP 的 `衍生=` 必须已拆，且变化行可核销到新角色/新道具衣着或形态（解开不另起 PROP 行）。

**整集【服化道连续性】**（`[PROP_EXTRACT_END]` 后、`[SCENES_BLOCK_END]` 前，全稿恰好一块）：提取块里每个 CHAR、每个 PROP 一行，与 `形态连续`/`衍生` 同向。
基础版无根本变化：
`CHAR:[@名]｜根本变化=否｜建新角色=否｜启用=无`
基础版有根本变化：
`CHAR:[@名]｜根本变化=是｜建新角色=是｜新角色={名}_{装束}｜启用={EPxx_SCyy} {入场即|Beat{n}起}｜旧→新={旧→新}｜延续至={EPxx_SCyy}`
衍生行（本行即新角色）：
`CHAR:[@{名}_{装束}]｜根本变化=是｜建新角色=本行｜启用={EPxx_SCyy} {入场即|Beat{n}起}｜旧→新={旧→新}｜延续至={EPxx_SCyy}`
PROP 同构，键名改 `建新道具`/`新道具`。同人多变：按播放序写多段，用`；`连接，每段自带`新角色=`+`启用=`。基础版 `形态连续` 有衍生时写`根本变化=是｜建新角色=是｜新角色={名}_{装束}｜启用={场拍}`。

### 8.5 本场姿势（本环节；只写结构行，不改正文）
环境规划与文戏并行，**读不到后补文戏**。本环节必须在切场后核验每位画内角色的身体姿势，把结论写进【本场姿势】，供环境规划锁座椅/床榻/跪地/站位净空。

**闭集**：`站|立|坐|翘脚坐|盘腿坐|平躺|俯卧|向左侧躺|向右侧躺|蹲|跪|半跪|倚|骑|腾空`（`立`=`站`）。武戏收拍失衡落到闭集停驻姿。

**核验顺序（每场强制）**
1. 名单=本场【本场角色】`在场`+`待入画`+`介质可见`+有个体动作的龙套；群演簇可写一条统一姿。`介质可见` 行写 `开场=介质可见｜入画姿=无｜变化=无｜离场=介质可见`，**禁止**给照片/视频里的人补站坐跪。
2. **原文有姿**：从本场正文摘录闭集词或等价动作（`坐下`→`坐`，`躺下`未写侧向→据承托/剧情裁定 `平躺|向左侧躺|向右侧躺`），`来源=原文`，`依据=正文：“…”`。
3. **原文无姿**：按剧情补全，`来源=补全`。依据须可核销：对峙/追逃/门口拦人默认`站`；围桌议事/用餐/审讯默认`坐`；病榻/夜谈/事后默认躺类；求情/跪安默认`跪|半跪`；躲藏/矮身默认`蹲`；载具内舱按舱型惯例（司机`坐`驾驶座）。禁无依据全员站、禁无坐姿却规划一圈椅。
4. **变化**：正文已写起身/落座/躺下等 → `变化=Beat{n}：旧→新`；未变=`无`。`离场`=本场终态姿。待入画：`开场=待入画｜入画姿={闭集}｜入画@Beat{n}|据正文`。
5. **禁止**：把姿势句写进 `SCENE_CONTENT`；用「在场/看着」顶替闭集词；补全与明文动作冲突（原文已坐却补成站）。

**每场【本场姿势】**（紧接【本场服化道】）：本场在场/待入画每个 CHAR 一行。
`CHAR:[@名]｜开场={闭集}|待入画｜入画姿={闭集}|无｜变化=无|{Beat n}：{旧→新}｜离场={闭集}｜来源=原文|补全｜依据=正文：“…”|剧情={谁因何须此姿}`

### ID 硬锁
- `[SCENES_BLOCK_START]` / `[SCENES_BLOCK_END]` 全稿各恰好一次。
- Scene ID 格式 `EPxx_SCyy`，本集从 `SC01` 按播放顺序连续编号。
- `SCENE_START`、`SCENE_CONTENT_START`、`SCENE_CONTENT_END`、`SCENE_END` 的 ID 必须逐字一致。
- 【多线叙事】位于 `[SCENES_BLOCK_START]` 之后、首个 Scene 之前，全稿恰好一次。
- `[CHAR_EXTRACT]` 与 `[PROP_EXTRACT]` 位于最后一个 `SCENE_END` 之后、`[SCENES_BLOCK_END]` 之前，各恰好一块。**没有独立角色或独立道具时，对应块内只写一行`无`**（`[CHAR_EXTRACT_START]`/`[PROP_EXTRACT_START]` 仍必须成对出现）。禁止省略本块，禁止空块，禁止用「没有」「空」「N/A」「None」代替`无`。
- 每场恰好一块 `[SCENE_CAST_START:{scene_id}]`…`[SCENE_CAST_END:{scene_id}]`；【本场角色】【本场道具】名单逐字对提取块 `名称=`。
- 每场恰好一块【本场服化道】，紧接该场 `SCENE_CAST_END`；按本场 CHAR/PROP **分行**，禁止混写成一句。
- 每场恰好一块【本场姿势】，紧接该场【本场服化道】；本场 CHAR **分行**，开场/离场闭集词齐全，`来源=原文|补全` 与 `依据` 可核销。
- 【服化道连续性】位于 `[PROP_EXTRACT_END]` 之后、`[SCENES_BLOCK_END]` 之前，全稿恰好一块；提取块每个 CHAR/PROP 各一行；每行须答`根本变化`/`建新角色|建新道具`/`启用`。
- 禁裸写无 ID 的 Scene/Content 标记。

## 7. 成稿自检
- 多线确认、Scene 边界、场际衔接、全局风格与光线风格回填已齐；场外综合信息已总结进 `comprehensive_plot` / `comprehensive_assets`。
- Scene 按播放顺序编号，未按叙事线归堆；可独立成立的多线穿插与回切已拆成多场。
- 过短场（仅一个动作或一个画面，含单帧闪回）已并回上场；同线连续段未误拆；同角色同空间短暂出门一瞥仍并入当前场。
- 每场：【场景名称】恰好一行；【场景衔接】含音画桥、同型/对位与 `艺术转出`/`艺术转入`（各可`无`；有则本场只写自己那一端，转出=未完成起势、转入=落成，一对跨场同手法/介质/载体，未写完整链、未写入正文）；闪回/倒叙/梦境/想象跨入跨出与多线穿插/回切已走强制闸（`因=`已标，未用硬切过线）；同场短闪回未假锁场际；【多线编排】已回写所属线与是否回切；`[SCENE_CAST]` 已分配本场角色与独立道具（标准表达，名对提取块）；【本场服化道】已按人/按件分行（入场/变化/离场）；【本场姿势】已按人分行（开场/变化/离场+来源+依据；原文缺姿已按剧情补全）。
- 项目信息已有全局风格时，`style_inheritance` 为继承且 `Global_Style` 不冲突；`Global_Style` 已点明视觉基调（复古/现代等）且与时代、题材同向；已有光线风格时，`lighting` 为继承且不另起冲突光。
- `borrowed_films` 为 1–2 部真实顶级大片；`color_palette` 已点名其中一部为 `对标片=`，并写出主/辅/点缀/过渡具名色与调色机制；`color_spectrum` 与该色卡同向；项目已有色卡时为继承且不另起冲突色。
- `music_recommendation` 已含乐器、风格、情绪、节奏、音量、质量、混响空间与拍型指导；具名乐器 2–5 件；项目信息已有配乐时为继承且不另起冲突体系。
