1. **全量分析**：本环节已明确存在要优化的武戏点。禁止再做场景提取门闩，禁止只处理路由证据短引而漏读其余输入。通读场核、全部 Beat、对白、声画、环境块与路由行；路由行只作语境，**不作提取开关**。

3. **专名逐字 + 标准表达继承**：角色名/地名/招名/法器名/法相名与原文**逐字一致**；已有真名禁改。文戏已写的 `CHAR:[@]`/`PROP:[]` 原样继承；新写过程同此。禁拆前缀还原裸名。禁 `ENV:`。

10. **只执行已注入规约 + 禁跨体系发明**：按本场输入实际体系选用规格。原文无仙攻介质/空域/法相则不得改写成仙侠空战；原文有则必须按仙攻增量加密。禁止自行加入未写入的题材/地点/武器体系专规，禁止跨体系发明能力。

## 1. 动作规格与招间因果（打斗/法攻/仙攻）
- **动作规格（七项）**：①部位+幅度/速度/力度(止于手级)｜②动作始末与门开向｜③文戏低缓(武戏例外)｜④惯性过渡｜⑤操作链禁跳步｜⑥必要且日常的情绪外化｜⑦因果可感。写动作与经过的具名交互节点。
- **招招前后因果连续（最高）**：每一招须可追**前因**（承上招终态：空门/失衡/落空余势/挡格反弹/距离开合/护盾裂口/术法余波等）→**过程**（起势·轨迹·可见介质）→**后果**（命中/落空/挡格/打断+效果，**且写到效果结束/停驻**）→**铺下一招**。跨拍强制承接：相对距离｜姿态/重心｜兵器或握持落位｜术法/护盾/域场现态（有则）。攻防须双向咬合（甲招→乙因该招而应→甲因乙之应再出招）。
- **斗法链（仙攻段强制）**：`结印/引气可见→介质成形轨迹→对撞/偏转/穿透→余波→下一式从余波态起手`。
- **禁因 AI 规避省略连续攻击**：连招/换招链不得压成「起势—结果」或删中段；规避只砍不必要细节动作，不砍招招过程。❌无因果堆招、混战摘要、或同构再出招。
- **禁重复招式（最高）**：同一连续攻防段内，**同一出手方**不得重复或同构再出招式/法术。判定=招名相同｜部位+轨迹相同｜同一法术介质同路径再放｜空域技法同构连用｜仅同义换词。下一招须至少换部位/左右手/兵器路径/命中面/空域技法/法术介质之一。挡格/闪避可同类但须换方向或部位。明文连击须写出可辨变奏。❌直拳再直拳／火球再火球／俯冲再俯冲。
- **明确动作 + 效果写到终止态（最高）**
  - **禁混战摘要**：❌「混战在一起」/「激战一番」。群战=阵势质块 + 主角切口的明确 1v1/1v2 招式链。
  - **明确动作最低粒度**：每招可检索——谁｜部位/兵器/法器｜对谁｜起势→轨迹→命中面。
  - **效果写到终止**：命中/法攻/仙攻后写受力、连续位移、撞击/落地/被接住和动作停住。轻击写到局部运动停止。介质命中 → 人/物如何被带动 → 撞何物/落何地 → 瘫/跪/贴地/被护盾托住。空中命中仍须写坠落→落地停驻。
- **打击/投射**：近身=`起势→发力→命中→反馈→路径→终点/停驻`；投射=`出手→路径→命中→效果→停驻`；位移类效果须写到撞墙/落地/瘫地。反馈段须含受力方表情或可读局部特写，禁只写位移/光效或“混战”摘要。

## 2. 金身／法相 ≡ 角色（最高；仙攻增量；字段零减免）
输入出现法相／金身／法身／真身／金光法身／万丈金身／化龙凤／巨兽等时启用。字段与句式**与角色同标**；缺任一=失败；与宿主同框须**分名分写**（宿主≠金身）。

**九字段**：定位 XOR｜正背面｜面向｜姿态｜与他者｜视线(有则)｜动作方式。本文件写可见凝形/同步/消形过程。
- ❌`金身显形`无可见凝形过程。
- 凝形后维持相仍在画→每拍写清宿主驱动与金身对应动作；消散须可拍消形／出画过程。
- **入画／突现**：本拍写凝形动作。
- 金纹/波前等无定形介质→走六相，**不**替代金身本体。
- 须读脸/口型/正面躯干才安排可读面过程；背对禁写须正面才可见内容。

### 宿主↔法相／金身动作同步＋因果共写（最高）
法相／金身与宿主同框维持相期间，**原则上动作与原主同步同相**——宿主抬臂／结印／发力／转向／姿态变／受击反馈时，金身／法相须**同拍**写出对应同向或尺度放大的镜像动作（可巨化／可极短可视延迟，但相位须可检索咬合）。

| 相位 | 宿主侧（须可拍） | 法相／金身侧（须可拍） | 禁 |
| :--- | :--- | :--- | :--- |
| 凝形／显形 | 起势／结印／吐纳／抬臂等驱动过程 | 轮廓凝出／拔地／撑幅落位（当拍九字段） | 金身自现、宿主无动作 |
| 借体出手／对位攻击 | 驱动姿态或**同步**发力（掌势/口令/目光锁；肢体方向与金身出手同向或可核销镜像） | 同拍对应出手／弹道／命中（与宿主发力同相） | 只写金身掌推、宿主旁观空白；宿主抬左金身无据出右且无核销 |
| 维持相同步（原则） | 姿态／朝向／发力变有可拍过程 | 同拍镜像或放大同向动作 | 金身连招而宿主全程静止／另做无关动作 |
| 同损／受击反馈 | 宿主震颤／吐血／跪软等可见反馈（有则） | 金身裂纹／踉跄／光衰等对应反馈 | 金身重创、宿主毫无反应且无核销例外 |
| 收摄／消形 | 收掌／解印／召回动作 | 消形／缩回／离画过程 | 金身蒸发、宿主无收摄动作 |

**不同步例外（须明文核销）**：仅剧情明文「失控／反噬／独立意志／反客为主」等可核销不同步——须在该 Beat 正文写清脱同步触发，并标`宿主法相同步=否｜原因=…`；否则默认`同步=是`。宿主暂不可见时：法相动作仍须写，并标`宿主驱动挂靠=暂不可见｜因果仍成立｜同步挂靠`。句式倾向：`{宿主}：{驱动动作} → {金身|法相}：{同相同向/放大对应结果}`。❌只写金身出手、宿主无驱动。

## 3. 身法：地面与空域
Beat 正文须写可见运动形态与变化节点。
- **地面身法（无超能题材）**：都市/现实无超能 → 不强制腾空，仍须地面身法轨迹（闪绕/低扫/借墙）并穿插过程表情。
- **空域技法（仙攻增量；最高）**：保留腾空/俯冲/盘旋/滞空等动作类型及表情切口。内部规划=`谁｜起点高度/层位｜技法轨迹｜换向/加速点｜出手/命中面｜落点`；成稿只写技法、可见轨迹变化、过程表情与命中过程。法攻还须写施术者空域姿态 + 介质沿该轨迹放出或追踪。**高速飞翔特效（强制）**：腾空/盘旋飞翔/俯冲/侧掠/穿云等连续飞翔须叠 §7a 高速特效闸（粒子或流体体现高速），禁只写技法名或「飞过去」。
- **空中追逐（命中则叠 §7a；最高）**：连续腾空追逃须走空中追逐全槽+追杀链，不得只用空域技法名或「飞着追」交差。飞行器机体走飞行器追逐。蹬踏楼体起落走楼间穿梭（可与空中追逐分段叠用）。
- **题材门槛**：命中体系门槛的连续打斗/法攻段 **≥2 种**不同空域技法（典型：腾空起势→盘旋抢位→俯冲命中）；正式决战加密；**禁全程贴地**。
- **过程须穿插特写表情**：起势/腾空/盘旋/俯冲/换招/结印放术插入可读五官或可见面表情，禁整段只写轨迹到命中才怼脸。连续段技法≥2 时，过程表情切口原则上 ≥ 技法数。
- ❌「飞过去打」/空中交手无轨迹，或全程无过程表情。

## 4. 命中与过程特写
对话击中、近身/法攻/仙攻命中与挡格须以角色表情+特写级局部呈现；过程亦须穿插可读表情。

| 节点 | 特写最低要求（同拍或紧邻特写切口） |
| :--- | :--- |
| **对话击中** | 说话人开口≥1 面部微表情；**听者/被击中方**怼脸或局部反应过程链≥1 |
| **打斗命中/挡格** | **受力方**可读面表情或痛感/惊变微表演≥1 + 姿态/握持局部；关键招宜叠出手方眼神/咬牙 |
| **法攻/仙攻命中·对撞·挡格** | **目标方**中招/承压表情或可见面外化≥1 + 余波落在人/物上的局部；禁只写介质/爆炸无人脸上变化 |
| **过程穿插** | 每个过程位或每招中段：出手方**或**对手一方五官/可见面表情≥1。连续段技法≥2 时，过程表情切口原则上 ≥ 技法数。起势/结印｜腾空｜盘旋｜俯冲｜换招/半空急停｜介质离体均须穿插。**与命中效果脸并存，不得互相替代** |
| **宿主↔法相同步出手** | 宿主驱动可读 **与** 法相同相出手可读（可同拍分句）；对手受力反打可读 |

## 5. 打斗／法攻／仙攻 OTS 正反覆盖（最高）
连续打斗、近身缠斗、斗法、投射法攻/仙攻、金身／法相借体出手等**对阵段落**，覆盖语法必须参照对白 Shot-Reverse / OTS——对参战**各方**的主动作出手与受力／挡格反馈，均须有**可读角**与**反打可读角**；**禁止**全程单侧只拍甲方出手而乙方仅背影／远景糊弄。

| 相位 | 正侧（出手方） | 反侧（受力方） | ENV |
| :--- | :--- | :--- | :--- |
| 出手／起势／结印／法相驱动 | 出手方可读角（可 OTS 过对手肩） | 同拍可挂肩背／侧面作关系，但不得替代反侧专拍 | 切出手方可读 `{N}度…` |
| 命中／挡格／闪拆／受力 | — | **必须**切受力方可读角（迎弹／偏转／中招／护盾裂／表情） | `ENV变=是`；反打不换主环境名 |
| 反击／换手 | 新出手方可读角 | 原出手方转受力可读角 | 换手=新一轮正反 |
| 法攻/仙攻投射链 | 施法／击发方可读（出手/结印+介质离体） | 目标方可读（迎弹／偏转／中招／余波） | 出手拍与命中拍原则上分属互补可读角 |
| 宿主↔法相同步出手 | 宿主驱动可读 **与** 法相同相出手可读 | 对手受力反打可读 | 禁只渲法相、对手无反侧；禁不同步连招无核销 |

**硬门槛**：①正式决战／连续攻防≥4 轮 → **每轮**至少 1 次正↔反 ENV 切换；②凡场有打斗／法攻／仙攻对阵 → 各方至少各有 **≥1** 可读角主拍；③读招／读脸／读挡格手位／读中招反馈 → 须切该方可读 ENV；④快链可同拍合并动量，**不得**用快链豁免「缺反侧可读角」。❌全程单侧只拍一方出手或只渲法相。

## 6. 特效六相与驱动力
- **驱动力可视化（强制）**：气/内功/魔力/念力/力场/灵气/真元/罡气/剑气等驱动运动时须写可拍介质——禁只写「运功」或只写结果。必写：形态｜轨迹(源→路径→落点)｜作用+反馈｜介质建置承接；形态须落到**粒子**或**流体解算**之一（可叠用）；小规模可同拍，大规模叠六相。通用法攻写其实际介质；仙攻段写灵气/真元/罡气/剑气，禁止把仙攻介质改写成普通光效交差。
- **具象化/规格**：大特效禁高潮只写「能量爆发」。启用即写：触发｜因果可感｜具象形态｜范围(锚ENV边界+未覆盖)｜影响(**具名固定实体**逐项；禁「环境震动」无落点)｜六相`起势→显形→扩散→命中→维持→余波`｜时限。跨拍改结构/氛围→`{主}_{状态}`。**仙攻大招须环境改观**（扭曲｜变色｜粒子化，见下节）。七-E择1–2+范围/影响各≥1；点状离散介质须含粒子≥1，连续液/气/焰/雾/浆须含流体解算≥1。通用体系优先元素形体/冲击环/波前+粒子或流体；仙攻体系优先化龙凤兽/法相（触发→凝形→落点→作用），介质层仍须粒子或流体可核销。
- **粒子 / 流体解算（强制分型）**：点状离散（火星/尘埃/余烬/灵尘/光点/碎屑）走**粒子**——写出发射源、密度、速度方向、与具名实体碰撞后的碎裂/贴附、沉降消散。连续液/气/焰/雾/浆/能量流体走**流体解算**——写出体积、速度场、与具名实体碰撞后的翻卷/泼溅/浸润/回流、消散。可叠用（火=流体体+粒子火星；剑气=流体刃+拖尾粒子）。禁只写「光芒/气浪」而无粒子或流体形态。
- **仙攻粒子阵形秩序（最高；仙侠专属）**：仙攻段粒子**须有可读阵形秩序**——禁 random 无序光点雨、禁「灵尘/粒子飞溅」无数阵无几何。
  - **阵形类型（择≥1 写明；可叠化/旋转/扩散；六相至少一相须写阵形变化）**：
    - **阵图/符阵**：八卦图（双环/八门节点）、太极、九宫、星宿连线、天干地支环、天地法阵节点、符纹几何
    - **凶兽/灵兽形**：麒麟/饕餮/穷奇/梼杌/龙首/凤翼/虎扑/狼形/龟蛇等由粒子凝成的轮廓或剪影
    - **武器/器形**：剑阵/万剑扇形、刀轮、枪林、戟阵、鼎/钟/塔/印玺/莲台/光轮
    - **法相/金身缘**：粒子沿法相轮廓描边、金纹爬面、背光轮、莲座底盘
  - **写法最低**：须写 **阵形名** + **几何/轮廓可读**（例：「灵尘聚成八卦双环，八门节点依序亮灭」｜「真元粒子凝成饕餮巨口轮廓，向目标噬咬扩散」｜「万剑灵尘排成扇形剑阵，剑尖齐指 CHAR:[@乙]」）。起势/显形/扩散/维持至少一相写阵形**旋开/合拢/节段亮起/轮廓闭合/脉动旋转**；维持相保留阵形骨架（可脉动，禁瞬间散成雾）。轻量单点剑气/罡气也须 **≥1 条有序轨迹**（螺旋/扇形/直线阵列/环形），禁一团光。
  - 正文标 `粒子阵形={阵形名}｜类型=阵图|凶兽|武器|法相｜变化=旋开|合拢|脉动|扩散|闭合`（可检索）。❌乱粒子光雾｜❌只写「粒子雨/光点簇」无阵形｜❌五条同义光点。
- **粒子级衬托（全武戏最低门槛；按体系扩展；最高）**：凡本文件加密的打斗 / 兵器交击 / 法攻 / 仙攻 / 特效拍，**禁止干打**——每招、每击、每次命中或挡格须有可检索的**粒子级衬托**（源+方向+与具名面碰撞或沉降；可叠流体）。空标「粒子/气浪/特效」不算。按本场实际体系取档，**上层含下层、不得降级顶替**：
  | 体系 | 判定（内容复核，不另造） | 最低粒子衬托（每招≥1，可检索） | 扩展（叠加，不顶替下层） |
  | :--- | :--- | :--- | :--- |
  | **基本格斗** | 拳脚/近身/兵器互砍，无内力/轻功/仙攻明文 | 尘土、碎屑、踏地震尘、织物纤维、汗珠飞溅、拳风尘线、刃口火星、命中崩屑、衣袂扬尘 | 写出发射面（拳面/刃口/靴底/受击衣甲/地面）+飞散方向+落地或贴附 |
  | **武侠** | 轻功/内力/气劲/剑气/江湖兵器气劲 | 下层全开 | 再叠气劲拖尾粒子、剑光微粒、衣袂/披风过幅尘线、檐尘、轻功落点扬尘。禁只写「运气/内力一震」无粒子 |
  | **仙侠** | 本节体系门槛命中（灵气/真元/罡气/剑气/法相/御剑/域场） | 中下层全开 | 再叠灵尘、真元粒子雨、光电辉点、剑气拖尾、结印飞屑、法相边缘粒子化；**粒子须凝成可读阵形秩序**（八卦/符阵/凶兽/武器/法相轮廓，见上条）。禁把仙攻改成普通尘土交差；禁 random 无序光点；光电须有源+色相+消散+阵形 |
  同拍多击则每击各有衬托或写清连续扬尘未落。宏观/满幅另叠本节后条。法攻/仙攻另叠效果细节≥5（本条粒子可计入）。❌一拳无尘无屑｜❌武侠只扬土不写气劲粒子｜❌仙侠只用地面尘土顶替灵尘/光电。
- **人态化特效主体**：凝形成可辨头面/肢体朝向→本节「金身／法相≡角色」+「宿主↔法相同步」。六相过程另写。无定形介质只走六相+实体落点；消散后从终态剔除，并写宿主收摄/解印。通用体系可处理非仙的巨化/机甲展开/能量体，字段与角色同标（定位 XOR｜正背面｜面向｜姿态｜与他者｜视线(有则)｜动作方式），与驱动者同拍写清因果。
- **光效/特效边界**：画外光源可写其在画内的投影/受力/声音；禁写画外本体细节。特效命中陈设须可拍反馈。
- **高科技光电可拍（强制；最高）**：凡全息/立体投影/光幕/HUD立体/沙盘投影，以及激光/等离子/粒子束/离子束/EMP/能量盾/牵引束等科技光电，须同时写出**光源**与**占位空间**，缺一即不可拍。光源=具名发射源（枪口/炮塔/终端/投影台/护盾发生器/植入体/`PROP:[]`）+出光面或孔径+出光方向；画外源只写画内落光，禁写画外本体。占位空间分型：展现类=体积锚+边界（桌面上空柱体/两人之间/墙面投射区/房间中区）；束行类=源→空气柱/廊道/舱段→落点，束体厚度与经过空间可核销；波前类=源点外扩至具名边界的球/环/扇。影像/束体/波前只落在该体积内，并写环境受光（桌/脸/墙/尘柱被染或投影落点≥1）。禁「全息亮起/一道激光/护盾张开/EMP一闪」无源无体积。细槽见 §7a。

### 宏大特效：变化细节 · 满幅可渲染（最高）
> **判定（命中任一）**：域场/结界/天地法阵｜化龙凤兽/法相/巨化｜大招释放｜大范围元素爆发/对撞波前｜云海改写｜宏观灾难/奇观主相位｜标「宏大/全屏/天地/无边际」｜跨≥2 Beat 环境级特效。轻量单点/近身气爆不适用本条硬门槛，仍须六相可核销。
> **目标**：满幅可渲染 + 六相各有可辨变化细节；禁一句「能量爆发铺满天空」。

1. **满幅/全屏可渲染（强制）**：①覆盖层级=`前景介质|中景主体|后景边界/天际/地平` 至少两层同时有可见变化；②边界锚=`ENV 边界/地平线/穹顶/海面/城廓/山脊`（禁无边界「到处都是光」）；③规模词须可拍（无边际满幅｜自锚点向外吞没至边界｜对撞波前横贯画幅），**禁止**只写角色周身光晕却自称宏大。主相位景别意图=Wide/EWS/全景级；可穿插细节特写切口，但**不得用特写替代满幅主相位**。**满幅/快动→局部特写仍须数量速度不塌**（特写可钉一件局部，正文须写同向同质体过幅/前后层密度 + 与满幅同级速率；禁切近后单件慢/停。升格仅 `~`/情节升格）。**仙攻宏大/大招另叠本节后「满幅广角·震动·体量对比」。**
2. **分相变化细节（强制；六相各相≥1 可辨增量）**：禁六相复读同一句「光芒更盛」：
   | 相 | 须有的变化细节 |
   | :--- | :--- |
   | 起势 | 源点凝核/纹路或符纹初现/粒子初扰或流体微涌；**仙攻须初现阵形节点或轮廓骨架**；尺度仍局部 |
   | 显形 | 主体轮廓可读（元素形体/阵纹几何/冲击环/**鳞甲/龙首**/法相肢体/ **八卦/凶兽/武器阵形**）；粒子簇或流体体层次≥1 |
   | 扩散 | 边界外扩轨迹（沿何结构/向何方/吞没哪些区）；粒子密度场或流体速度场变化 |

## 8a. 命中段声画（强制；继承文戏标签）
先读场级【声画综合】与注入的 `Global_Style` / `music_recommendation`。拆/并拍后回填【声画综合】的 `起`/`变`/`落` B 号。未改写拍原样保留文戏【配乐】【音效】。
- **【配乐】**：格式同文戏 `【配乐】 | {听感} | 态=… | 乐器=… | 音量=… | 质量=… | 混响空间=… | 锚=…`。加密段按招相改 `态=`——起势/结印/引气加压=`变`，命中/介质对撞砸点=`变`，余波/收势=`收`，中间过程=`续`。`{…}`=本拍听感。`乐器=` 须与总谱同向，可多样共同合作（主奏+铺底+点缀齐奏/轮入；可加密打击/低弦/空灵垫/剑鸣点缀，**具名≤5**，禁另起冲突体系、禁只留一件、禁超编）。砸点 `音量=` 可升中/强，余波回弱/中；`质量=`/`混响空间=` 须与战场/域场/殿宇/空域同向。`锚=`=`CHAR:[@]`/`PROP:[]` + 本拍出手、结印、御剑或命中动作。听感只进本行 `{…}`，禁写入【音效】行。
- **【音效】**：每招/每式 ≥1 条；命中拍强制两条——出手/击发音 `配合={出手/施法方}{部位/兵器/结印/御剑/介质离体}` + 受击音 `配合={受力方}{受击部位}`。投射/介质另写路径声；法相出手另写金身动作声，`配合=` 挂法相名。**仙攻大招/满幅震动相**另写一条震声（地脉闷响/瓦裂/山石落渣），`配合=` 挂具名对比物或受力实体，不与出手/受击音互顶。载具追逐另写引擎/轮胎/气动路径声；空中追逐另写破风/衣袂猎猎/御剑啸或气动过障；现代武器击发+弹着；激光/等离子另写充能/束行/灼切，`配合=` 挂发射器 PROP；EMP另写放电噼啪，`配合=` 挂发生器；能量盾另写开闭嗡鸣或命中涟漪声；全息/光幕另写开闭蜂鸣或扫描声，`配合=` 挂发射源 PROP。**运动舱行驶段**每武戏拍另须一条舱体运动声（轮轨/引擎/风噪/浪拍/马蹄/轿厢导轨），`配合=舱体行进` 或 `PROP:[外部名]`，不与出手/受击音互相顶替。停靠段禁飞掠声。格式同文戏，须含 `音量`/`质量`/`混响空间`：`【音效】 | {可听内容+方位} | 配合=… | 方位=近|中|远 | 音量=… | 质量=… | 混响空间=…`。禁 BGM 进本行 `{…}`，禁空`{}`，禁 dB/Hz。

## 10. 成稿自检（本子技能）
- 已通读全部输入；未只凭路由短引漏改其它武戏段。
- 纯文戏 Beat、动作/表情/姿势、对白整行（八键+`{台词}`）、【配乐】【音效】、场级行、特殊路由包裹与 Scene ID 原样保留；未写成「语气层+台词」。
- **工作方式**：可修改/拆分/增补武戏 Beat；无任何可加密武戏过程则整份原样。场级透传。CHAR/PROP 标准表达已继承。
- 原文打斗/法攻/仙攻/特效/法相/空域信息单元均有落点；无新增胜负/能力；未改情绪弧。
- 招招因果闭合；禁重复招式；效果写到终止态。仙攻段斗法链结印→介质→对撞→余波可追。
- 法攻/仙攻有可见介质+轨迹+作用；点状走粒子、连续走流体解算，有发射源/碰撞/消散；六相无复读。体系门槛未命中则未改写成仙侠空战。
- **粒子级衬托**：每招/每击已有可检索粒子（基本格斗=尘土/碎屑/踏尘/织物/汗珠/刃火；武侠叠气劲/剑光微粒/轻功扬尘；仙侠再叠灵尘/真元/光电）；未干打；未用下层尘土顶替上层光电；未空标「粒子」。
- **仙攻粒子阵形**：仙侠段已写可读阵形秩序（八卦/符阵/凶兽/武器/法相轮廓择≥1）+ 六相至少一相阵形变化；未 random 无序光点雨。
- 金身/法相（有则）可见过程与宿主同拍因果共写；默认同步。
- 命中体系门槛的连续段 ≥2 种空域技法；过程穿插表情。
- 命中/过程有表情或可读局部。
- 宏大则满幅+分相增量+细节密度够。满幅/快动切近须保级数量+速度。
- **宏观全体**：主相位已布满全屏；多点承载≥5 且含尘土/云/震动/旗帜等非人承载（人/阵列只计 1 类）；已写广角可感+航拍建规模意图；未只写人头攒动或「大军压境」交差。
- **效果细节≥5**：每段法攻/仙攻/宏大特效已写出 ≥5 条互不复读的粒子或实体动作细节（可混计）；未用同义光效凑数。
- **仙攻宏大/大招**：主相位已写满幅广角（近大远小）+震动具名落点+体量对比（施法方巨大 / 对比物=被施法者或具名建筑/山 渺小）+效果细节≥5+**粒子阵形秩序可读**+**环境改观**（扭曲/变色/粒子化择≥2，前中后+边界具名落点；跨拍已标`环境改观={主}_{状态}`）；未用半身光晕、等大对打或「天地变色」无落点交差；未 random 无序粒子。
- 命中楼间穿梭/空中追逐/飞行器追逐/车辆追逐/机甲战斗/现代武器/激光武器/EMP脉冲/能量盾/全息展现时该行特征槽已全覆盖并写入正文（可检索 `特效类=`+全槽`落点=`+`表外=`）；楼间穿梭/飞翔已写高速特效（粒子或流体）体现高速；未把人飞改写成飞行器；未把现代/激光改写成仙攻。
- **高科技光电可拍**：全息/投影/激光/等离子/粒子束/EMP/能量盾已写光源（具名发射源+出光面+方向）与占位空间（展现体积 / 束行空气柱 / 波前外扩至具名边界）；已写环境受光；未「亮起/一道光/护盾张开」无源无体积。
