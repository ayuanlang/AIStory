## 通用硬约束（各子技能同锁；最高）

3. **专名逐字 + 标准表达继承**：角色名/地名/招名/法器名/法相名与原文**逐字一致**；已有真名禁改。文戏已写的 `CHAR:[@]`/`PROP:[]` 原样继承；新写过程同此。禁拆前缀还原裸名。禁 `ENV:`。
4. **对白整行继承（最高）**：上游开口行（`开口 |` 八键 `{台词}` `| 闭嘴 |`）整行原样写出；`{台词}` 必须带花括号。可按自然停顿拆句，词序与用词不改。**禁止臆造台词填洞**，禁止写成「语气层+台词」。无具体台词内容可省略该句对白，可见说话动作转动作/微表演。原文画外音/VO/旁白非空台词原样保留，可与动作同拍，禁遗漏。
5. **逻辑合理可拍**：过程须可拍。
6. **Beat 正文**：标题行 + 一段完整清晰过程。
7. **禁实拍执行语**：威亚/钢丝/替身/绿幕等；腾空/轻功/飞跃只写可见运动。
8. **禁意图词**：试图/想要/打算 → 具体动作链；失败也写可见受阻，不写「试图失败」。
9. **下游边界**：本阶段定「拍什么」；禁代写分镜处方（焦距/运镜处方归 `shot_generation`）。
10. **只执行已注入规约 + 禁跨体系发明**：按本场输入实际体系选用规格。原文无仙攻介质/空域/法相则不得改写成仙侠空战；原文有则必须按仙攻增量加密。禁止自行加入未写入的题材/地点/武器体系专规，禁止跨体系发明能力。

## 1. 动作规格与招间因果（打斗/法攻/仙攻）
- **动作规格（七项）**：①部位+幅度/速度/力度(止于手级)｜②动作始末与门开向｜③文戏低缓(武戏例外)｜④惯性过渡｜⑤操作链禁跳步｜⑥必要且日常的情绪外化｜⑦因果可感。写动作与经过的具名交互节点。
- **招招前后因果连续（最高）**：每一招须可追**前因**（承上招终态：空门/失衡/落空余势/挡格反弹/距离开合/护盾裂口/术法余波等）→**过程**（起势·轨迹·可见介质）→**后果**（命中/落空/挡格/打断+效果，**且写到效果结束/停驻**）→**铺下一招**。跨拍强制承接：相对距离｜姿态/重心｜兵器或握持落位｜术法/护盾/域场现态（有则）。攻防须双向咬合（甲招→乙因该招而应→甲因乙之应再出招）。
- **斗法链（仙攻段强制）**：`结印/引气可见→介质成形轨迹→对撞/偏转/穿透→余波→下一式从余波态起手`。
- **禁因 AI 规避省略连续攻击**：连招/换招链不得压成「起势—结果」或删中段；规避只砍不必要细节动作，不砍招招过程。❌无因果堆招、混战摘要、或同构再出招。
- **禁重复招式（最高）**：同一连续攻防段内，**同一出手方**不得重复或同构再出招式/法术。判定=招名相同｜部位+轨迹相同｜同一法术介质同路径再放｜空域技法同构连用｜仅同义换词。下一招须至少换部位/左右手/兵器路径/命中面/空域技法/法术介质之一。挡格/闪避可同类但须换方向或部位。明文连击须写出可辨变奏。❌直拳再直拳／火球再火球／俯冲再俯冲。
- **明确动作 + 效果写到终止态（最高）**
  - **禁混战摘要**：❌「混战在一起」/「激战一番」。群战=阵势质块 + 主角切口的明确 1v1/1v2 招式链。
  - **明确动作最低粒度**：每招可检索——谁｜部位/兵器/法器｜对谁｜起势→轨迹→命中面。
  - **效果写到终止**：命中/法攻/仙攻后写受力、连续位移、撞击/落地/被接住和动作停住。轻击写到局部运动停止。介质命中 → 人/物如何被带动 → 撞何物/落何地 → 瘫/跪/贴地/被护盾托住。空中命中仍须写坠落→落地停驻。
- **打击/投射**：近身=`起势→发力→命中→反馈→路径→终点/停驻`；投射=`出手→路径→命中→效果→停驻`；位移类效果须写到撞墙/落地/瘫地。反馈段须含受力方表情或可读局部特写，禁只写位移/光效或“混战”摘要。

## 2. 金身／法相 ≡ 角色（最高；仙攻增量；字段零减免）
输入出现法相／金身／法身／真身／金光法身／万丈金身／化龙凤／龙／巨兽等时启用。凡有正反面且有自身动作 → 须 `CHAR:[@{名}]`（与宿主分名；无专名=`{宿主}法相` 或原文称呼）。字段与句式**与角色同标**；缺任一=失败；与宿主同框须**分名分写**（宿主≠金身）。禁只当特效过程词无名体。

**九字段**：定位 XOR｜正背面｜面向｜姿态｜与他者｜视线(有则)｜动作方式。本文件写可见凝形/同步/消形过程。
- ❌`金身显形`无可见凝形过程。
- 凝形后维持相仍在画→每拍写清宿主驱动与金身对应动作；消散／被打碎／烟飞云散须走「收束/破灭过程」（分相细节+残留），禁一闪蒸发。

- 须读脸/口型/正面躯干才安排可读面过程；背对禁写须正面才可见内容。

### 宿主↔法相／金身动作同步＋因果共写（最高）
法相／金身与宿主同框维持相期间，**原则上动作与原主同步同相**——宿主抬臂／结印／发力／转向／姿态变／受击反馈时，金身／法相须**同拍**写出对应同向或尺度放大的镜像动作（可巨化／可极短可视延迟，但相位须可检索咬合）。

| 相位 | 宿主侧（须可拍） | 法相／金身侧（须可拍） | 禁 |
| :--- | :--- | :--- | :--- |
| 凝形／显形 | 起势／结印／吐纳／抬臂等驱动过程 | 轮廓凝出／拔地／撑幅落位（当拍九字段） | 金身自现、宿主无动作 |

| 同损／受击反馈 | 宿主震颤／吐血／跪软等可见反馈（有则） | 金身裂纹／踉跄／光衰等对应反馈 | 金身重创、宿主毫无反应且无核销例外 |
| 收摄／消形 | 收掌／解印／召回动作 | 消形／缩回／离画过程（须走「收束/破灭过程」，禁一闪蒸发） | 金身蒸发、宿主无收摄动作；「法相没了／烟散」无分相 |

**不同步例外（须明文核销）**：仅剧情明文「失控／反噬／独立意志／反客为主」等可核销不同步——须在该 Beat 正文写清脱同步触发，并标`宿主法相同步=否｜原因=…`；否则默认`同步=是`。宿主暂不可见时：法相动作仍须写，并标`宿主驱动挂靠=暂不可见｜因果仍成立｜同步挂靠`。句式倾向：`{宿主}：{驱动动作} → {金身|法相}：{同相同向/放大对应结果}`。❌只写金身出手、宿主无驱动。

**朝向同向＋同框面对镜头（最高；现场编排须执行）**：维持相同框期间，法相与发起者**世界朝向同向**（对同一目标，禁互为对打轴）。仙攻同框／巨化满幅主相位默认双方**同时面对镜头**（头面同朝近镜头半空间）。本层过程禁写法相转身与宿主反向、禁法相回头看宿主当正反。例外仅失控核销或对手反打分拍。选角落现场编排，本层只写不反向的可见过程。

## 3. 身法：地面与空域
Beat 正文须写可见运动形态与变化节点。
- **地面身法（无超能题材）**：都市/现实无超能 → 不强制腾空，仍须地面身法轨迹（闪绕/低扫/借墙）并穿插过程表情。
- **空域技法（仙攻增量；最高）**：保留腾空/俯冲/盘旋/滞空等动作类型及表情切口。内部规划=`谁｜起点高度/层位｜技法轨迹｜换向/加速点｜出手/命中面｜落点`；成稿只写技法、可见轨迹变化、过程表情与命中过程。法攻还须写施术者空域姿态 + 介质沿该轨迹放出或追踪。**高速飞翔特效（强制）**：腾空/盘旋飞翔/俯冲/侧掠/穿云等连续飞翔须叠 §7a 高速特效闸（粒子或流体体现高速）+ **主体/载具气流拖尾与强风拉扯**（发丝/衣物被风抽直拉丝，载具有则写扰流/喷流/饰带尾），并标 `motion_intensity=`，禁只写技法名或「飞过去」。
- **空中追逐（命中则叠 §7a；最高）**：连续腾空追逃须走空中追逐全槽+追杀链，不得只用空域技法名或「飞着追」交差。飞行器机体走飞行器追逐。蹬踏楼体起落走楼间穿梭（可与空中追逐分段叠用）。
- **题材门槛**：命中体系门槛的连续打斗/法攻段 **≥2 种**不同空域技法（典型：腾空起势→盘旋抢位→俯冲命中）；正式决战加密；**禁全程贴地**。
- **过程须穿插特写表情**：起势/腾空/盘旋/俯冲/换招/结印放术插入可读五官或可见面表情，禁整段只写轨迹到命中才怼脸。连续段技法≥2 时，过程表情切口原则上 ≥ 技法数。
- ❌「飞过去打」/空中交手无轨迹，或全程无过程表情。

## 4. 命中与过程特写
对话击中、近身/法攻/仙攻命中与挡格须以角色表情+特写级局部呈现；过程亦须穿插可读表情。

| 节点 | 特写最低要求（同拍或紧邻特写切口） |
| :--- | :--- |
| **对话击中** | 说话人开口≥1 面部微表情；**听者/被击中方**怼脸或局部反应过程链≥1 |
| **打斗命中/挡格** | **受力方**可读面表情或痛感/惊变微表演≥1 + 姿态/握持局部；关键招宜叠出手方眼神/咬牙 |
| **法攻/仙攻命中·对撞·挡格** | **目标方**中招/承压表情或可见面外化≥1 + 余波落在人/物上的局部；禁只写介质/爆炸无人脸上变化 |

## 5. 打斗／法攻／仙攻 OTS 正反覆盖（最高）
连续打斗、近身缠斗、斗法、投射法攻/仙攻、金身／法相借体出手等**对阵段落**，覆盖语法必须参照对白 Shot-Reverse / OTS——对参战**各方**的主动作出手与受力／挡格反馈，均须有**可读角**与**反打可读角**；**禁止**全程单侧只拍甲方出手而乙方仅背影／远景糊弄。

| :--- | :--- | :--- | :--- |

**硬门槛**：①正式决战／连续攻防≥4 轮 → **每轮**至少 1 次正↔反 ENV 切换；②凡场有打斗／法攻／仙攻对阵 → 各方至少各有 **≥1** 可读角主拍；③读招／读脸／读挡格手位／读中招反馈 → 须切该方可读 ENV；④快链可同拍合并动量，**不得**用快链豁免「缺反侧可读角」。❌全程单侧只拍一方出手或只渲法相。

**禁入戏假切（最高）**：本层只写可见过程（谁出手、谁接招、谁中招）。**禁止**写入戏「镜头切为…」「切到…视角」「【OTS正反覆盖】」而不拆拍。正反＝**另起 Beat**，各拍只写该角能看见的动作；选角与 `ENV变=` 归现场编排。❌同一 Beat 正文里假切两次机位。

## 6. 特效六相与驱动力
- **高科技 / 仙攻可拍性闸（强制；最高；宏观变化 + 具象内容）**：高科技光电与仙攻大招/域场/法相须**同时**写出①**宏观变化**（环境/边界/阵列/天际如何改观，规模可核销，禁只改角色周身）②**具象内容**（可读形体/束行体积/阵形/命中面/具名实体反馈）。高科技=光源+占位空间+环境受光；仙攻=六相+满幅/阵形+实体落点。禁抽象光晕、禁只写「能量爆发/系统启动」。下游分镜不得压成周身光晕。
- **驱动力可视化（强制）**：气/内功/魔力/念力/力场/灵气/真元/罡气/剑气等驱动运动时须写可拍介质——禁只写「运功」或只写结果。必写：形态｜轨迹(源→路径→落点)｜作用+反馈｜介质建置承接；形态须落到**粒子**或**流体解算**之一（可叠用）；小规模可同拍，大规模叠六相。通用法攻写其实际介质；仙攻段写灵气/真元/罡气/剑气，禁止把仙攻介质改写成普通光效交差。
- **具象化/规格**：大特效禁高潮只写「能量爆发」。启用即写：触发｜因果可感｜具象形态｜范围(锚ENV边界+未覆盖)｜影响(**具名固定实体**逐项；禁「环境震动」无落点)｜六相`起势→显形→扩散→命中→维持→余波`｜时限。跨拍改结构/氛围→`{主}_{状态}`。**仙攻大招须环境改观**（扭曲｜变色｜粒子化，见下节）。七-E择1–2+范围/影响各≥1；点状离散介质须含粒子≥1，连续液/气/焰/雾/浆须含流体解算≥1。通用体系优先元素形体/冲击环/波前+粒子或流体；仙攻体系优先化龙凤兽/法相（触发→凝形→落点→作用），介质层仍须粒子或流体可核销。

- **仙攻粒子阵形秩序（最高；仙侠专属）**：仙攻段粒子**须有可读阵形秩序**——禁 random 无序光点雨、禁「灵尘/粒子飞溅」无数阵无几何。

  | **武侠** | 轻功/内力/气劲/剑气/江湖兵器气劲 | 下层全开 | 再叠气劲拖尾粒子、剑光微粒、衣袂/披风过幅尘线、檐尘、轻功落点扬尘。禁只写「运气/内力一震」无粒子 |
  | **仙侠** | 本节体系门槛命中（灵气/真元/罡气/剑气/法相/御剑/域场） | 中下层全开 | 再叠灵尘、真元粒子雨、光电辉点、剑气拖尾、结印飞屑、法相边缘粒子化；**粒子须凝成可读阵形秩序**（八卦/符阵/凶兽/武器/法相轮廓，见上条）。禁把仙攻改成普通尘土交差；禁 random 无序光点；光电须有源+色相+消散+阵形 |
  同拍多击则每击各有衬托或写清连续扬尘未落。宏观/满幅另叠本节后条。法攻/仙攻另叠效果细节≥5（本条粒子可计入）。交火/扫射/掩体枪战另叠效果细节≥5。❌一拳无尘无屑｜❌武侠只扬土不写气劲粒子｜❌仙侠只用地面尘土顶替灵尘/光电｜❌枪战只写「开枪」无焰无弹道无崩屑。
- **人态化特效主体**：凝形成可辨头面/肢体朝向→本节「金身／法相≡角色」+「宿主↔法相同步」+**与发起者同向**（同框满幅默认同时面对镜头）。六相过程另写。无定形介质只走六相+实体落点；**消散／被打碎／烟飞云散须先写收束过程**（§6，禁一闪蒸发），过程完成后才从终态剔除，并写宿主收摄/解印。通用体系可处理非仙的巨化/机甲展开/能量体，字段与角色同标（定位 XOR｜正背面｜面向｜姿态｜与他者｜视线(有则)｜动作方式），与驱动者同拍写清因果。
- **光效/特效边界**：画外光源可写其在画内的投影/受力/声音；禁写画外本体细节。特效命中陈设须可拍反馈。
- **高科技光电可拍（强制；最高）**：凡全息/立体投影/光幕/HUD立体/沙盘投影，以及激光/等离子/粒子束/离子束/EMP/能量盾/牵引束等科技光电，须同时写出**光源**与**占位空间**，缺一即不可拍。光源=具名发射源（枪口/炮塔/终端/投影台/护盾发生器/植入体/`PROP:[]`）+出光面或孔径+出光方向；画外源只写画内落光，禁写画外本体。占位空间分型：展现类=体积锚+边界（桌面上空柱体/两人之间/墙面投射区/房间中区）；束行类=源→空气柱/廊道/舱段→落点，束体厚度与经过空间可核销；波前类=源点外扩至具名边界的球/环/扇。影像/束体/波前只落在该体积内，并写环境受光（桌/脸/墙/尘柱被染或投影落点≥1）。禁「全息亮起/一道激光/护盾张开/EMP一闪」无源无体积。细槽见 §7a。

### 宏大特效：变化细节 · 满幅可渲染（最高）
> **判定（命中任一）**：域场/结界/天地法阵｜化龙凤兽/法相/巨化｜大招释放｜大范围元素爆发/对撞波前｜云海改写｜宏观灾难/奇观主相位｜标「宏大/全屏/天地/无边际」｜跨≥2 Beat 环境级特效。轻量单点/近身气爆不适用本条硬门槛，仍须六相可核销。
> **目标**：满幅可渲染 + 六相各有可辨变化细节；禁一句「能量爆发铺满天空」。

1. **满幅/全屏可渲染（强制）**：①覆盖层级=`前景介质|中景主体|后景边界/天际/地平` 至少两层同时有可见变化；②边界锚=`ENV 边界/地平线/穹顶/海面/城廓/山脊`（禁无边界「到处都是光」）；③规模**只许对比或占屏**（见下条尺度闸），禁止只写角色周身光晕却自称宏大。主相位景别意图=Wide/EWS/全景级；可穿插细节特写切口，但**不得用特写替代满幅主相位**。**满幅/快动→局部特写仍须数量速度不塌**（特写可钉一件局部，正文须写同向同质体过幅/前后层密度 + 与满幅同级速率；禁切近后单件慢/停。升格仅 `~`/情节升格）。**仙攻宏大/大招另叠本节后「满幅广角·震动·体量对比」。**

**尺度只许对比或占屏（最高；凡宏大/仙攻大招/法相巨化/宏观全体）**：要展现宏大时，**禁止**把「万丈／千丈／百丈／几十米／几米／高达X米／无比巨大」当尺度真源。成稿必须二选一或叠用：
- **实体对比（优先）**：和同框**角色、主体、具名实体**比高比大——须写清对照件碰到巨大侧哪一部位。✅旁边的山只到法相膝部｜✅角色只到法相踝部｜✅殿脊不及膝｜✅人在掌心一线全身可辨。❌法相万丈金身｜❌高达百米｜❌山很大。
- **占满屏幕**：写清铺满画幅的可见后果。✅军队大全景遍布全屏至地平｜✅阵列铺满前景到后景边界｜✅波前横贯画幅吞没城廓。❌千军万马（无铺满、无对照）。
裸数字/文学丈尺可作内部换算，**不得单独成稿**。缺对比句且无占屏句 = 宏大失败。
2. **分相变化细节（强制；六相各相≥1 可辨增量）**：禁六相复读同一句「光芒更盛」：
   | 相 | 须有的变化细节 |
   | :--- | :--- |
   | 起势 | 源点凝核/纹路或符纹初现/粒子初扰或流体微涌；**仙攻须初现阵形节点或轮廓骨架**；尺度仍局部 |
   | 显形 | 主体轮廓可读（元素形体/阵纹几何/冲击环/**鳞甲/龙首**/法相肢体/ **八卦/凶兽/武器阵形**）；粒子簇或流体体层次≥1 |
   | 扩散 | 边界外扩轨迹（沿何结构/向何方/吞没哪些区）；粒子密度场或流体速度场变化 |
   | 命中 | 与具名实体/对手/地面的接触瞬间：粒子撞碎/流体泼溅/碎屑/震环/灼裂/倾侧等**逐实体** |
   | 维持 | 稳态动势（旋转/脉动/粒子雨/流体翻涌/云海）+ 未覆盖区仍可见对比 |
   | 余波 | 衰减方向、粒子沉降/流体回落、残留痕迹、实体终态；**收束/破灭须分相细节**（消散｜打碎｜烟飞云散），禁瞬间清空、禁一闪而过 |
3. **细节密度**：至少 **4 相**各含 ≥2 个可检索细节单元（粒子/流体泼溅/碎屑/边界涟漪/鳞甲生长节段/阵纹节点等）；满幅主相位 + ≥1 细节特写/Insert 再回满幅或余波。细节特写须保级整体数量与速度，禁孤立一件静置。**禁止**空标注凑过程。另叠「效果细节≥5」：该段特效（同一招/同一宏大主相位，可跨拍合计）须写出 **≥5 条**互不复读的可见效果细节，粒子与实体动作可混计（见下节）。
4. **实体落点不豁免**：须逐项写清哪些**具名固定实体**受何种可见作用，未影响者保持原态。满幅≠「环境震动」。
5. **禁**：抽象光球高潮｜六相粘贴无增量｜只写结果无过程｜满幅声称但只拍角色半身光效｜用特写冒充宏大主相位｜无细节却标宏大｜**消散/打碎/烟飞云散一闪清空**。
6. **仙攻收束／破灭过程（最高；消散·打碎·烟飞云散）**：凡仙攻介质、法相／金身／化龙凤、域场／阵形、剑气／万剑等**结束、被破、散尽**，须写成可拍特效过程，**禁止一闪而过、禁止只写结果词**。轻量单点亦须 ≥3 个可辨增量；宏大／法相／域场须 ≥4 增量且余波单独成相（可同拍分句，禁折叠成「没了」）。
   | 类型 | 须写出的过程（按序，各步有可见增量） | 细节最低 | 禁 |
   | :--- | :--- | :--- | :--- |
   | **消散／消形／收摄** | ①边缘失稳（金纹熄、轮廓毛边、阵形松）→ ②体量收缩／透明化／片状脱落 → ③介质离体飞散（灵尘向何方、密度降）→ ④残留（余烬落地、残光、烟缕未尽；有宿主则收掌／解印） | 粒子或流体≥1 + 残留≥1 | 「法相没了／金光一闪消失／蒸发」 |
   | **被打碎／崩裂／粉碎** | ①裂纹／裂口出现（部位+路径）→ ②块面分离崩飞（碎块大小层次+方向）→ ③碎屑粒子／流体溅散 → ④落地沉降或残留核 | 碎块层次≥2 + 粒子或流体≥1 + 落点 | 「碎了／爆开」无裂纹无飞散 |
   | **烟飞云散／气化／雾散／阵散** | ①形体先裂或失密（不是瞬间变烟）→ ②烟／云流体卷离（方向+层+速度场）→ ③疏密变化（近浓远淡、过幅）→ ④散尽残留（薄雾、余烬、空位） | 流体解算≥1 + 疏密变化 + 残留 | 「烟散／云散／一阵烟」无卷离过程 |
   正文标 `收束过程={消散|打碎|烟飞云散}｜增量=N≥3｜残留=…`（可检索）。❌一闪而过｜❌余波=瞬间清空｜❌只写「消散/打碎/烟飞云散」四字。

### 仙攻特效技法：满幅广角 · 震动 · 体量对比 · 环境改观（最高）
> **判定（仙攻段命中任一）**：大招释放｜法相/金身巨化｜化龙凤兽｜万剑/域场/天地法阵｜标「宏大/全屏/天地」的仙攻介质。轻量单点剑气/近身罡气不适用本条硬门槛，仍须六相。
> **目标**：效果布满广角全景 + 震动可感 + 大招须读出「施法方巨大 / 对比物渺小」+ **效果细节≥5** + **整场环境改观** + **粒子阵形秩序可读**。禁只写周身光晕或半身爆发；禁 random 无序粒子。

0. **粒子阵形秩序（仙侠全段；大招/域场/法阵强制）**：叠 §6「仙攻粒子阵形秩序」。大招/域场/天地法阵/万剑/法相巨化/化龙凤兽主相位须写出 **≥1 个满幅可读阵形**（八卦/符阵/凶兽/武器/法相轮廓择其大者），并在显形/扩散/维持相写阵形旋开/合拢/脉动/扩散变化；轻量剑气/罡气也须有序轨迹（螺旋/扇形/阵列）。禁乱粒子光雾。

1. **效果布满全景（强制）**：仙攻宏大/大招主相位=Wide/EWS/全景级，介质须铺满画幅——前景介质｜中景主体｜后景边界/天际/地平至少两层同时有可见变化，并锚 ENV 边界。禁止效果只停在角色周身或半身框。可穿插细节特写，但不得用特写替代满幅主相位。
2. **广角透视意图（拍什么；禁写焦距处方）**：主相位须写出**广角可感**的空间膨胀与近大远小——近层介质/肢体撑幅、远层对比物或边界被压小、纵深拉长。禁长焦平面压缩感（前后层挤成一层）。焦距/mm 归 `shot_generation`，本层只写可见透视后果。
3. **震动感（强制；须具名落点）**：扩散/命中/维持至少一相须有**可拍震动**，禁止空写「环境震动」。须逐项落到具名实体：地面裂纹跳尘｜瓦片错位｜柱础颤移｜山石落渣｜水面环纹｜尘粒离地｜衣袂发丝被震波抽直｜角色膝软/站桩不稳。震动=实体反馈链，不是抽象词。画面震感意图可写「全景随震波起伏」，禁代写 Handheld/焦距。
4. **效果细节≥5（强制；粒子+实体动作可混计）**：凡本文件加密的法攻/仙攻/宏大特效（同一招或同一宏大主相位，可跨拍合计）须写出 **≥5 条**互不复读的可见效果细节。两类可混、须可检索：
   - **粒子/流体**：发射源+形态可辨（灵尘簇/真元粒子雨/拖尾粒子/碎屑/火星/震环尘/流体翻涌/雾卷/光点簇等）；**仙侠须另写阵形名+几何轮廓**（八卦双环/饕餮巨口/万剑扇阵/法相金纹描边等）。
   - **实体动作**：具名人/物的可见反馈（结印抬臂/法相撑幅/膝软站桩/衣袂抽直/瓦片错位/柱础颤移/山石落渣/殿脊不及膝等）。
   同义复读不算（「光芒更盛」×5=失败）。空标「粒子特效/环境互动」无形态无落点不算。轻量单点也须 ≥5，但不叠满幅广角硬门槛。
5. **大招体量对比（强制；尺度走对比/占屏闸）**：大招/法相巨化/化龙凤主相位须同框或紧邻满幅拍写出。大小**必须**用对比句，禁止万丈/几米交差：
   - **巨大侧**=施法方本体或法相/化龙凤：撑满中后景或顶天立地；巨大只能靠对比物读出，不靠丈尺。
   - **渺小侧=对比物（择一入画，可叠）**：①被施法者（目标 CHAR）；②具名建筑/殿宇/城廓/塔刹；③具名山脊/峰峦/崖壁。无目标 CHAR 时必须用②或③。须写清对照件碰到巨大侧哪一部位——脚边/掌心/踝下/膝下/腰际/山腰一线/檐口不及膝；全身或全貌可辨但占比极小。
   - 禁只渲巨大侧而对比物出画或双方等大对打；禁只怼目标脸或只拍一座楼而读不出施法方巨大。宿主仍在画时，法相巨大 ≠ 宿主等大——宿主须作对比（人只到法相踝/膝）。建筑/山作对比物时须写「山只到膝／峰顶才到腰／殿脊不及踝」，禁「很大／万丈」。
   - 句式倾向：`{施法方/法相}：{巨大落位+撑幅} → {对比物=被施法者|建筑|山}：{只到踝/膝/腰等} → {介质}：{铺满画幅+震动落点} → {环境}：{扭曲/变色/粒子化落点}`。
6. **大招环境改观（强制；改展现方式，不换地）**：大招/法相巨化/化龙凤主相位须改写**整个可见环境的展现方式**。同一主环境、同一具名实体仍可辨认，禁止另起地名或换成另一空间。须从下列择 **≥2** 种，并落到前中后+边界具名实体（可计入效果细节≥5）：
   - **扭曲**：廊柱/殿脊/山脊/地平线弯折、热畸变、空间褶皱、叠影拉丝；须写哪件实体如何弯、弯向何方。
   - **变色**：天穹/石面/金属/云海色相或明度迁移（金赤/墨紫/死灰等）；须写从何色到何色、落在哪些具名面。
   - **粒子化**：檐口/城廓/山体/地面边缘溶解为灵尘或碎屑粒子，轮廓仍可辨；须写出发射源、剥落方向、未粒子化的残留核。
   可叠热雾/金纹爬面/负片闪，但不顶替上列三项门槛。跨拍仍维持改观→正文标`环境改观={主}_{状态}`（如`殿宇_域场扭曲`），供下游建状态衍生；余波须写回落或残留。禁只改角色周身光色而环境原样；禁空写「天地变色/空间扭曲」无实体落点；禁本层写 `ENV:`。
7. **法相↔发起者同向（最高；同框强制）**：同框须同向；满幅主相位默认同时面对镜头（头面同朝）。禁法相与宿主相向对视或一正一背。选角落现场编排。
8. **禁**：半身光晕当大招｜效果不铺全景｜无震动落点只写「天地震动」｜大招双方等大对打无尺度差｜只拍被施法者中招脸而无巨大侧｜对比物只用无名「远处山影」无具名锚｜**裸写万丈/几米/高达X米而无实体对比或占屏**｜效果细节<5 或五条同义｜环境不改观或只改角色周身｜**仙攻粒子 random 无序/无数阵**｜写 24mm/Handheld 处方｜**法相与发起者相向或一正一背**｜**消散/打碎/烟飞云散一闪清空**。

- **宏观群体**：`宏观群体=是`→≥6 Beat。三要素：无边际满幅｜阵势威武(前中后满编+真实参差，禁机械同步)｜压迫感。须写可拍规模 + 阵势排布；禁「大军压境」无人数感与队形。结构：全景→阵势→压迫→指挥→对冲→余波。输出【宏观 Beat 规划】。
  - **布满全屏 · 多点承载≥5（最高；军队/兽潮/机群/舰队/人海同核）**：宏观全体主相位特效须**布满全屏**——规模走「占满屏幕」：✅军队大全景遍布全屏至地平；❌「千军万马／数万人」无铺满句。禁只写人海/阵列而四周空、天净、地静。须同时写出 **≥5 点**互不复读的可见承载，且**不得全是人**：人/阵列只计 **1 类**；其余须从非人承载择满（尘土/扬尘浪｜云/烟/尘霾/旗云｜震动落点=地面跳尘/旗杆颤/甲叶振，须落到具名实体｜旗帜/旌旗猎猎过幅｜蹄尘/轮烟/羽矢幕｜甲光鳞浪｜鼓角烟尘｜海浪/沙暴/雪幕，题材有则）。覆盖层级=`前景介质（尘/旗/羽）|中景阵列|后景边界/天际/云海` **三层同时**有可见变化（严于普通满幅「至少两层」）。标 `宏观满幅承载=N≥5｜人=…｜尘=…｜云=…｜震=…｜旗=…｜其他=…`。有具名对照时叠实体对比（人在旗海中只及马胸／城楼只到阵列腰）。

  - **满幅/快动→局部特写（数量速度不塌）**：宏观整体或快速运动实体（冲锋/齐射/疾驰/穿梭/弹幕）切到盔甲/旌旗/马蹄/箭矢等局部特写时，特写正文仍须写清整体量级（同向同质体过幅/前后层密度）+ 与满幅同级速率；禁切近后变成单件慢/停。❌千骑→一马慢走｜❌万箭→单箭悬浮｜❌只写「千军万马」无尘无旗无云无震｜❌五点全是不同方阵人名。

### 枪战特效描写（最高；现代武器增量）
> **判定**：原文或文戏出现手枪/步枪/冲锋枪/机枪/狙击/霰弹/交火/点射/扫射/据枪开枪。激光/等离子走 §7a 激光行，不套本条弹道。无枪械依据不得加成枪战特效。
> **目标**：每发可追 `据枪→击发(焰+后坐+抛壳有则)→弹道→命中材质反馈→余波`；禁「开枪」交差，禁改写成剑气/灵尘。

0. **投射链（强制；叠 §7a 现代武器全槽）**：成稿须可检索 `特效类=现代武器` + 全槽落点 + `表外=`。点射可压成四相=`击发→弹道→命中→余波`；连发/交火/扫射须另写**维持相**（焰/壳连续、硝烟积、弹着点沿具名面位移）。同拍多发则每发有焰或写清连续焰未断+弹着点移动，禁合并成「连开几枪」。
1. **击发可见（强制）**：须同时写出——①**枪口焰**=形（锥/瓣/环）+色（橙黄/白芯/冷白）+瞬间照面（脸/墙/掩体被染，≥1）；②**后坐**=肩抵/腕/枪口上跳或回落；③**抛壳**（该枪有则：方向+旋转+落地弹跳停；转轮/无壳则写`抛壳=无`）。禁只写枪声或枪口一闪。
2. **弹道可读（强制）**：源=`PROP:[枪]`枪口 → 经过空间（空气柱/廊道/街面/舱段）→ 落点具名。可见介质择≥1：曳光｜尘线｜热畸变气纹｜近失热风抽衣。连发/扫射须写**弹着点位移轨迹**（沿柜台沿→柱础→墙面，禁「扫了一梭子」）。霰弹=锥形散布+多点命中。狙击=长弹道+热波+命中可略滞后仍须同链写完。跳弹=入射角+二次路径+二次命中面。近失=掠过部位+热风/衣洞/耳边粒子，禁当命中。
3. **命中按材质（强制；禁无反馈）**：命中面须具名，反馈跟材质，不得一律「打中溅血」：
   | 命中面 | 须写可见反馈（择够，须可检索） |
   | :--- | :--- |
   | 混凝土/砖石/地砖 | 弹孔+崩屑粒子+跳尘；连发则弹孔排列或位移 |
   | 玻璃/车窗 | 放射裂纹或穿孔+碎屑颗粒；有则写碎片下落 |
   | 金属/车门/护栏 | 凹陷或穿孔+火花粒子+漆皮卷起 |
   | 木器/柜台/门扇 | 木屑迸开+纤维毛边+弹孔 |
   | 人体（原文命中才写） | 受力位移/失衡/局部伤态；禁无据加血雾；禁只写「中弹」无部位无位移 |
   | 掩体沿 | 沿口崩缺+跳尘+探身者衣尘；弹着须落在具名掩体，禁空写「躲在掩体后」 |
4. **余波残留**：枪口残烟或室内硝烟层（疏密+方向）；弹壳落地停；弹孔/裂纹留在具名面上。禁命中后场面瞬间干净。
5. **交火／扫射／掩体战（效果细节≥5）**：连续对射、扫射、掩体探身枪战须写出 **≥5 条**互不复读的粒子或实体动作（焰/壳/弹道/崩屑/跳尘/后坐/探身可混计）。各方至少各有 **≥1** 可读击发角（叠 §5 OTS）。禁「双方对射」无各自焰与弹着。
6. **宏观弹幕**：机枪阵地/多点交火/街巷弹雨叠宏观全体——曳光或尘线须**布满纵深**（近层弹道+中景弹着+后景边界火花或跳尘），人/阵列只计 1 类，须另有弹道/烟尘/火花等非人承载。禁只写「枪声大作」。
7. **舱内／三层交付**：舱内开枪叠 §7b（舱外变化不顶替）；弹着写座椅/玻璃/仪表等舱内具名面。人在车里打街上（三层交付）须写出舱内枪口源→窗/门过阈→街上命中面，禁弹道凭空出舱。
8. **声画**：击发+弹着两条不互顶；弹道破空、弹壳落地、跳弹叮可另条，`配合=` 挂枪或命中面 PROP/CHAR。禁用枪声顶替画面焰/弹道/崩屑。
9. **禁**：开枪无焰无弹道｜命中无材质反馈｜扫射无弹着位移｜交火压成一句｜把子弹改成剑气/灵尘/光刃｜无据加血雾或爆炸｜用激光行顶替热武器弹道｜只写音效无画面特效。

### 7b. 运动舱内（强制；与文戏同核）
文戏已标或本场【主环境】/【场景名称】属交通工具内舱（汽车内、客舱、驾驶舱/操纵舱、轿子、马车厢、船舱、火车/地铁车厢、电梯轿厢等）→ 行驶段加密必须让观众读出**舱位在运动**，且**即使戏在舱内也须写出舱外变化**。文戏已写的舱体/窗外/随动/运动音整句只增不减；武戏过程段须再咬合惯性与舱外过幅，禁压成静止擂台或停泊厅堂。
- **舱态**：默认行驶。原文/场核明文停靠、停车、到站、熄火、停驶、停泊、停层开门 → 停靠（写停稳+窗外静止，禁飞掠）。禁无据改舱态、禁无据加急刹/脱轨改因果。
- **过程咬合（行驶段每武戏拍）**：①舱体动势可检索（`微颠|纵晃|侧倾|巡航微震|步态颠簸|浪摇|轿厢升降震`，按载具）｜②**舱外变化（强制，不与随动互顶）**=窗外/舷窗景物或光影沿前进向流过，且须写出变化增量（楼群更替/街景换段/层位升降/云海过幅）；无窗/帘闭仍须经缝隙/反光/仪表外景/蒙皮过幅交代舱外在变，禁整段只写舱内互殴而对舱外钉死｜③出手/挡格/落位写 `借晃|踩稳|扶{座/扶手}|被晃偏` 之一（不改胜负）｜④已有帘穗/吊环/杯水随动可叠写，**不顶替②**｜⑤【音效】一条舱体运动声（`配合=舱体行进` 或宿主外部 `PROP:[名]`；禁 `ENV:`）。外追逐另叠引擎/轮胎/气动，不顶替本条。
- **与 §7a**：外追逐槽归载具 `PROP:[]` 主语路线；舱内乘员段另写本条（含强制舱外变化）。楼间/空中/飞行器高速段另叠高速特效闸。同场可叠。投射可写舱摇微偏，命中/落空仍服从原文胜负。
- **仓外切入**：街上/站台等大背景进入本舱 → 先走 §7c，**落定舱内拍起**才用本条。
- ❌当静止房间互殴｜❌删文戏舱动句｜❌无据急刹改因果｜❌舱内拍无舱外变化｜❌`ENV:`

### 7c. 仓外大背景切舱内（强制；与文戏同核）
街上/站台/停靠点/广场等仓外大背景切入车厢/驾驶舱/客舱 → **必须写出切换**。文戏已写的切口/衔拍/开门落座/运镜句整句只增不减；禁把街景与舱内打成同一空间。
- **切法跟文戏**：`入舱过程`=仓外段加密到门扇/登乘（未完成）→ 另拍或衔拍落到舱内座位 → 落定后走 §7b。`过阈切`=街上满幅/宏观不得直接冒充舱内特写，须转出街上、转入舱内。`场际转入`已落到舱内 → 不重拍街上起势。`出舱反向`对称。追杀从街灌进车内不得压成 1 拍抓到。
- **运镜跟文戏（强制）**：文戏运镜档原样保留并咬合过程。默认：追杀/灌车=`跟随入舱`或`绕体外跟`（镜头跟人/车门过阈，禁街上满幅 Static 硬切进舱内特写）；过阈切=`过框推入`或`窗外窥入`；出舱=`跟随出舱`或`过框拉出`。禁焦距/机位处方。
- ❌街舱混空间互殴｜❌无门无座瞬移进车打｜❌删文戏入舱/运镜句｜❌只切空间不写镜头过阈

## 10. 成稿自检（本子技能）
