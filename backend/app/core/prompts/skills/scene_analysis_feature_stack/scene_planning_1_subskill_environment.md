## 目标（最高；本子技能工作方式）

本技能按**整集**调用。输入=全局统筹切分结果（含 `[CHAR_EXTRACT]` / `[PROP_EXTRACT]` / 各场 `[SCENE_CAST]`）+ 已注入的项目原有主环境（未删除）。只做**场景勘探与主环境规划**，确定本集需要的拍摄环境。
1. **按全局统筹做场景勘探**：通读各场正文、【场景衔接】、【闪回分档】、【场景名称】、**【本场时地】**、【本场姿势】与 `project_visual_backfill`，判断每场实际要拍的空间。**时地只抄统筹**：季节/时段/时辰/光变档/气候/气候可见/氛围/内外以【本场时地】为准，禁止另判、禁止改档、禁止用日/夜顶替时辰，禁止改气候或另造与统筹冲突的氛围。
2. **识别全部主环境需求（明示 + 隐藏）**：每个 Scene 至少一个主环境，可多个。必须找出场头/空境写明的空间，以及隐藏空间——同场短闪回/闪切落点、独立闪回 Scene、出入封闭舱（仓外+仓内）、二层内部不共享外形、整体环境实质改写后的新空间、载具内舱、**载具露天占用（甲板/敞篷后厢等，局部+大世界合建）**等。载具只立全局统筹 `载具裁定=` 需要的占用/宿主（整车走已抽 PROP，不并进占用空镜）。**占用/宿主注册名逐字抄统筹预留**（`舱内ENV=`/`体外占用ENV=`/`挂场ENV=`），**禁止**与 `整车PROP=` 同核、禁止另起近义。**`载具裁定=无` 的摩托/单兵飞行器/马匹等禁止另立占用/内舱/露天合建**。**马车≠马匹**：仅马车/马车厢可按裁定立厢内或敞篷占用；马匹只当已抽 PROP 挂宿主。拍级选 ENV 还是沿用宿主归现场编排。
3. **复用优先、继承原定义**：先对照 `[项目主环境名开始]…[项目主环境名结束]` 与 `[用户选定全局环境开始]…[用户选定全局环境结束]`。同空间必须 `复用=是`，名称逐字沿用；原项目主环境定义由程序按场回填，本文件不重写其骨架。写明 `可复用/可参考主环境=无` 或 `用户选定全局环境=无` 时不得臆造复用源。
4. **只输出每场主环境信息**：每个 `scene_id` 一个 `ENV_SCENE_PATCH`，内含 `SCENE_ENV_IDENT`（该场全部主环境 + **定位/目标/情绪表达**）以及 `复用=否` 者的【主环境】+【未落清单】（**剧本提及的全部非角色、非道具环境主体 + 所属向**一次写定）。角色与独立道具已由全局统筹提取；本环节只读衔接，**禁止**再输出 `[PROP_EXTRACT]` 或角色块。禁止输出场景分析、场级评估、SCENE 正文、对白、Beat、建置或完整 Scene。程序随后按场切分，注入对应场次的场景现场编排。下游继承主体名单与所属向、三属性；**精确定点（心点/距原点/占地/场径）由环境资产设计裁定，本环节禁止预写**。不重抽 CHAR/PROP。**禁止**借「只写基本描述」漏掉原文已点名的环境件。
5. **结束标签硬闸**：全部场补丁写完后，全文最后一行必须是 `[ENVIRONMENT_PLAN_OUTPUT_END]`。
6. **不拆场**：一次处理整集；同场多个主环境写在同一场补丁内。是否另起 Scene 服从输入已切场次。

## 通用硬约束（各子技能同锁；最高）
1. **忠于上游 + 未命中不输出**：不改事实/因果；禁新增改因果事件。非环境内容只读，禁止复制到补丁。
2. **原文信息零丢失 + 禁虚化（最高）**：环境文学/地名/固定实体须**原样写入**成稿可检索落点。**剧本点名、且不在禁入环境名集（已抽 CHAR/PROP/本场角色/本场道具/衣着配饰）的主体必须全入四向/中心/固定清单/未落**，不得只留门窗柜台等「主锚」。**禁止**用「同原文／按原文／见原文／原文如此／照原文／如上／略／大意／照旧／不赘述」等虚化代替原文环境句或专名。
3. **专名逐字**：环境注册名与原文或上游**逐字一致**；同环境名复用。
4. **对白保真**：本文件不改台词。
5. **逻辑合理可拍**：活动空间可站可动可出入；四向正交；椅面朝该椅功能面（主位朝门、驾驶座朝仪表）；禁把内舱并进仓外当衍生。
6. **禁实拍执行语**。
7. **下游边界**：禁代写分镜处方。
8. **只锁环境**：不得借「设计环境」改写对白/特效/建置几何。

## 术语

| :--- | :--- |
| **场景勘探** | 据全局统筹正文与场际标记，找出本集全部拍摄主环境（明示+隐藏）。只作内部判定，成稿不写勘探过程。 |
| **隐藏主环境** | 原文未单独标场、但必须另立拍摄空间者：闪回/回忆落点、同场闪切出去再回来、出入封闭舱、二层内部不共享外形、整体环境实质改写后的新空间、载具内舱等。 |
| **复用环境** | `SCENE_ENV_IDENT` 标 `复用=是` 的项目库/上集/本集同空间 → 程序按场回填并继承原项目主环境定义，本文件不重写骨架。 |
| **用户选定全局环境** | 剧本页「全局资产」勾选后注入的主环境清单（名称/原定义/已有衍生）。能对应则复用或参考，不能对应才新建。 |
| **新环境设计** | 识别为新建，且未匹配到项目主环境 / 用户选定全局环境 → 新立【主环境】+【未落清单】。 |
| **主环境** | 场级空间基准；**永不**作 Beat 当前环境。可拍当前环境由后续场景现场编排声明 `{N}度{主名}`。 |
| **环境骨架** | 【主环境】+【未落清单】两块。下游不得改名、不得把主体换到另一向、不得改 0°轴/注册名/已点名背景微动件。**精确定点归环境资产设计**，不叫改写骨架。 |
| **环境三属性** | 每条主环境在 `SCENE_ENV_IDENT` 内写：`定位`（空间是什么）+ `目标`（本场空镜须达成什么）+ `情绪表达`（本场空镜如何表达情绪）。复用场也写（定位可 `继承原定义`）；环境资产设计直接消费，资产清单不再转写 ENV 行。 |
| **本场时地** | 全局统筹【本场时地】的季节/时段/时辰/光变档/气候/气候可见/氛围/内外。IDENT 与【主环境】必须逐字抄入；复用锁名不锁光——同空间不同时段/气候/氛围仍用原名，但本场时地覆盖库内旧日夜。资产设计据此锁太阳方位、空气介质、湿迹与 `Key世界向`。 |
| **本场风格** | 全局统筹【本场风格】的闭集模式/视觉基调/气质/落点。IDENT `风格=` 必须逐字抄入；复用锁名不锁风格——同空间闪回/异世界可与库内初稿不同，以本场统筹为准。资产设计「风格定位」只消费本行，禁另起冲突世界视觉。 |
| **实体落点** | 剧本提及的全部非角色、非道具环境主体，用自然语言写入四向+中心+固定清单（哪面有什么、几件、原文开闭）。椅/沙发/驾驶座只写功能朝向（朝大门/朝桌心/朝挡风）。非正方凳/条案用自然语言写竖边走向（东西走向/南北走向）及在桌哪一侧。挂靠小件点名宿主即可。未升格/待入画物落【未落清单】。**禁止**写 `心点=`/`距原点=`/`占地=`/`占场≈`/`场径=`/`锚=`/`宫格=`/`F=`/`椅面朝向=`/`竖边=`/`在桌=` 及米/步/%。精确定点由环境资产设计规划。**已抽 CHAR/PROP 主体禁止进入任何环境描述**（§18）。 |
| **背景微动件** | 主环境可选点名的**一具**细小陈设，专供下游建置/入戏写 `ENV背景微动=`，配合镜头微动、避免空镜或对白镜死静不真实。**非必须**。须已入该主四向或固定清单；落点不占主舞台、不堵动线、不升格为走位/交互锚。禁桌/柜/门/柱/床/墙/柜台等大件；**禁已抽 CHAR/PROP 主体**。无合适件或不想加 → `背景微动件=无`。 |
| **整体环境锚点** | 本主环境的整体身份标签（场所类型+时代/地域气质），供衍生裁切与资产 `anchor_description` 检索。例：`古代中国客栈`、`1990s北美港口工业办公`、`现代都市开放式厨房`。**不是**家具名，**不是**注册名近义。一主环境只锁一枚。 |
| **主舞台区** | 本场主要表演落点（对峙/对白/入座/跪拜等发生在哪一块）。须写相对哪件、落在哪一区（中心净空/门前/窗前/案前），**禁止**只写「中区」而无挂靠。 |
| **挂靠锚点** | 主舞台区所挂的**一具**环境主体，供下游角色挂靠与四宫机位。优选剧本明确点名、且**本主环境内数量=1** 的件（唯一窗/唯一门/唯一桌/唯一柜台）。禁止已抽 CHAR/PROP。禁止写 `心点=`/`距原点=`/`宫格=`。 |
| **锚点落** | 挂靠主体在哪个方向的**正向**，或在**中部**。闭集 `北|东|南|西|中`。`北`=该件是北向正面主景（0°衍生正向可见）；`东`→90°；`南`→180°；`西`→270°；`中`=中部主体，四向衍生均可见。 |
| **逐场环境补丁** | 以输入 `scene_id` 包裹的主环境信息；程序拼回全局统筹后，再按场切分注入场景现场编排。 |

## 1. Scene 与环境（勘探 / 识别 / 复用 / 新设计）
> 完整口径 §9–§11、§16；下文流程速查。

### 1a. 场景勘探与复用（每个 Scene 强制；本环节产出）
执行前必须先读注入块 `[项目主环境名开始]…[项目主环境名结束]`（已删除环境不计入）及其**原定义**，再读 `[用户选定全局环境开始]…[用户选定全局环境结束]`。先读完全部已有主环境，再按全局统筹逐场勘探。若写明 `可复用/可参考主环境=无`，一律 `复用=否｜来源=新建｜匹配主环境=无`。禁止把未注入、已删除或自拟名当成复用源。

#### 场景勘探（明示 + 隐藏）
据全局统筹各场正文、【场景名称】、【闪回分档】、【场景衔接】与场外综合信息，列出本场全部拍摄主环境：
- **明示**：场头/空境/具名地点/场景名称中的空间。
- **隐藏（必须找）**：同场短闪回/闪切落点；独立闪回 Scene 的回忆空间；出入封闭舱的仓外+仓内；上楼后不共享外形的二层内部；整体环境实质改写（崩塌/火灾/水淹/域场）后持续停留的新空间；汽车/机舱/轿子/马车等载具内舱；蒙太奇各异地落点。
- 每个 Scene 至少 1 个主环境；上列隐藏空间与当下空间不共享外形时**必须另立**，写在同一场补丁内（输入已拆独立 Scene 则逐场各写）。
- 环境名用稳定空间注册名，不写日夜后缀，不写 `{N}度…` 衍生名。载具占用/宿主名须逐字等于统筹 `舱内ENV=`/`体外占用ENV=`/`挂场ENV=`，**禁止**抄 `整车PROP=` 名当 ENV。
- 日夜/时段/时辰/天气/气氛/季节不同不另起名（时地写在 IDENT/主环境字段，不进注册名）；换观察侧、反打、特写不是新环境。
- 勘探只作内部判定。成稿只交主环境信息，禁止输出勘探过程、场景分析或 SCENE 正文。

#### 复用判定（只对项目库与本集之前）
- `来源=项目库`：与注入清单同空间，名称须**逐字**等于清单已有名。
- `来源=上集`：与本集之前某集已锁定主环境同空间，名称逐字沿用。
- `来源=新建`：清单、上集与本集前文都没有可复用的同空间。同场闪切/短闪回的出去落点若为新空间，标新建并写在**同一场**第二行 `[ENV]`。
- `来源=本集`：本集前文某场已声明同空间，含多线穿插后回切到先前主环境。名称逐字沿用，`复用=是`。
- `复用=是` 用于 `项目库|上集|本集`。`新建` 必须 `复用=否`。
- 禁止把未切叙事线的连续同空间拆成两场再标复用。同线同空间短暂出门一瞥仍同场多主。多线穿插回切已是独立 Scene 时，锁本集已有主环境名即可。

#### 包裹格式（最高；程序只读此块做回填）
必须写在该场 `ENV_SCENE_PATCH` 内、【主环境】骨架之前，ID 与本场 `scene_id` 逐字一致：

```text
[SCENE_ENV_IDENT_START:EPxx_SCyy]
[ENV] 名称={主环境名}｜环境族=占用|宿主|普通｜占用面型=封闭舱|露天合建|无｜复用=是|否｜来源=项目库|上集|本集|新建｜匹配主环境={已有主环境名}|无｜依据=原文：“…”
定位={归属用番位禁姓名}，{体量档}，{气质/类型}
目标=本场空镜须={一句可核销目标}｜服务={场景名气质或无}｜可见落点={无人称空间语}
情绪表达=主情绪={抄统筹氛围.主情绪}｜空镜表达={一句无人气质}｜光色倾向={抄统筹氛围.光色倾向}｜构图倾向={纵深压迫|中心仪式|三分留白|负空间|对称|框中框|…}
时地=季节={春|夏|秋|冬}｜时段={清晨|白天|中午|黄昏|上半夜|下半夜}｜时辰={子|丑|寅|卯|辰|巳|午|未|申|酉|戌|亥}｜光变档={晨东|日南|午顶|午西南|夕西|上夜|下夜}｜内外={内|外}｜气候={晴|阴|雨|雪|雾|风|霾}｜气候可见={湿石|雨丝|雾霭|积雪|扬尘|阴云|无}｜氛围=主情绪={…}｜空气感={清透|薄雾|烟霭|尘土|雨幕|雪尘|闷湿|干冷}｜光色倾向={文学词}｜受光开口={东|东南|南|西南|西|无}｜继承={抄统筹}
风格=模式={抄统筹【本场风格】闭集标签}｜视觉基调={抄统筹}｜气质={抄统筹}｜落点={抄统筹}｜继承=抄统筹
[SCENE_ENV_IDENT_END:EPxx_SCyy]
```

换主环境名牌字样=本行 `名称=` 逐字（禁 `{N}度`、禁状态后缀）；时间标签仅原文明确时刻／故事日（早上9点、重生第一天），可空，禁从日夜内外推；落位顶部中央与成稿句由建置入戏落，本文件不写名牌句。

- 每场恰好一对包裹；有几个主环境就写几组：一行 `[ENV]` + 紧随五行 `定位`/`目标`/`情绪表达`/`时地`/`风格`。三属性、时地与风格跟在**该条** `[ENV]` 后，禁攒到块末或写进【主环境】重复。
- `复用=是` 时 `匹配主环境` 必须等于注入清单或本集前文已声明名，禁止近义改写；**仍须写本场 `目标`/`情绪表达`/`时地`**（场级空镜任务与本场光线可不同于库内初稿）；`定位` 写`继承原定义`或原句。
- `复用=否` 时 `匹配主环境=无`；`定位` 必须写满。
- 识别块之后：仅 `复用=否` 的环境续写【主环境】四向与【未落清单】落点；`复用=是` 不写骨架，但 IDENT `时地=` 仍为本场光线真源。

    - **新建环境（强制；据情节判定）**：凡情节确认**不在当前主环境**（时空/地点/回忆落点与当下包络不合——原文具名、场头/空境、或剧情可核销的异地意图均可；**含上楼进入不须与一层共享外形的二层内部**，§11⑦；**含进入汽车/机舱/轿子/马车等载具内舱**，舱内与车外道路不共享外形）→ **须新建【主环境】**（完整骨架：名称｜日夜内外｜活动空间｜俯视360｜四向+中心（输入该向内容=正面面对；各向正对边界正面，四方正交，禁偏斜）｜0°轴｜头尾双锚｜固定清单）。可据情节合理命名与建骨架；**禁止**因「原文未写全称地点」而硬挂当下主环境，**禁止**把二层内部并进一层通高主环境当「上层」，**禁止**把汽车/机舱内舱并进车外道路/停靠点。同环境复用优先（§10）：上游已有同空间名或已匹配用户选定全局环境→复用/参考注入信息，勿另起同义名。衍生族由后续现场编排按本场主环境声明。
    - **出入封闭环境（最高；仓外为主、场内切仓内；一般不分场）**：汽车/机舱/轿子/马车厢/电梯轿厢等封闭舱，凡本场含**出入过程**——
      1. **当场起始主环境通常=仓外**（道路/停靠点/站台/轿外街巷等已声明主环境）；仓内另立独立【主环境】（不并进仓外）。
      2. **仓外宿主环境须锁具名门扇**与停靠位/舷侧水面等落点；整车已抽 `[PROP]` 则**不进**仓外固定清单（由 PROP 入画）。仓内主环境按载具惯例写座舱（汽车等司机在前排驾驶座）。触发名与衍生白名单由后续现场编排声明。
      3. **换主名≠反打**。世界扇区按新主 0°轴重新锚定（异地/跨舱非反打）。
      4. **一般不另起 Scene**（出入=同场连贯戏，对齐 1f）。
      5. **例外**：①整场开场即在仓内、无出入过程 → 仓内可为当场唯一主环境；②入舱后仓内戏已与仓外时空断开且后续只在仓内（如长途车内对白另场）→ 可另场、该场仓内独主；③二层内部封闭房间仍按§11⑦通常拆 Scene（≠本条上车入舱）。
      ❌开场无出入却把仓外硬塞为本场主；❌把内舱并进仓外；❌仓外缺具名门扇；❌已抽整车仍写入仓外固定清单；❌把上车拆成仓外一场+仓内一场而无时空断开依据。
    - **快速闪回 / 蒙太奇 / 同场闪切（空间侧）**：若输入已判同场快闪、同场闪切或较短出去再回来，本文件在**当前 Scene** 声明多块【主环境】（当下 + 各快闪/闪切/出去落点）。蒙太奇每落点各一主环境，禁单主四向硬塞多地。输入已按播放序把多线穿插/回切拆成独立 Scene 时，逐场各自识别；回切场对先前主环境标 `复用=是｜来源=本集`。
    - **较长回忆片段（空间侧）**：若输入已拆独立闪回 Scene，本文件为该闪回场写自有【主环境】；禁把长回忆硬塞进当下 Scene 多主环境凑合。本文件不写 OT。
    - **标注**：每块主环境写`主环境角色=当下主线|仓外|仓内|闪回|蒙太奇片段{序号}|回切锚`（**禁**在角色/场注中自拟「三年前/童年/N年前」等字幕）；同场多主时在补丁中列主环境清单。
    - **切主环境（同场快闪/蒙太奇/出入封闭舱）**：本文件只声明多块主环境。触发名、衍生行、建置句由后续构图/站位节点执行。世界扇区 **按新主环境 0°轴重新锚定**（异地/跨舱非反打）。
    - **禁**：①用当下主环境冒充异地/舱内；②把异地或舱内写成当下的状态改写；③长回忆场缺独立【主环境】；④快闪/蒙太奇落点缺主环境块；⑤出入封闭舱误拆成仓外/仓内两场（无时空断开依据）——本文件不改判 Scene 切分；⑥仓外缺具名门扇（整车已抽 PROP 则不进固定清单）。无情节纯质感切片且情节未要求可读空间→可不另立主环境；一旦情节确认异地可读空间→须建（同场快闪块或长回忆 Scene）。
  - **剧本活动空间（最高；主环境强制）**：环境描述**须因剧情活动而生**——规划【主环境】前须通读本场情节需求与【本场姿势】（站位人数、对峙/围坐、追逐逃窜、跪拜、出入画、群演簇位、武戏位移等），使空间**可站、可动、可出入、可分组**；上游 ENV_BLOCK 已写活动空间要点时须继承并展开。须可检索 `围合=北=封|敞｜东=…｜南=…｜西=…` 与 `向距上限=北=窄|开|无限制｜东=…｜南=…｜西=…`（四向各评是否有封闭面、以及最大可见距档，**禁止**写米/步/%）。`围合=封`=该向有封闭面；`敞`=该向开口/无封闭面（院门洞、街口延续、野外）。巷/廊/夹道两侧常=`围合=封`+`向距=窄`；室外/野外开口向=`围合=敞`+`向距=无限制`；厅堂四向有墙=`围合=封`+`向距=开`。`封` 向须用自然语言点名封闭面（墙/板壁/石壁/舱壁），不能只写门柜桌；`敞` 向须点名远景（天/街/沙/海/山/云），不能只写开口。不写材质细参与米。两行是资产设计场径/机位距与现场机位距/衍生选择的上限，下游不得突破。规划只锁本场时地（季节/时段/时辰/光变档/气候/气候可见/氛围）与哪面开口受光（文学，抄 `受光开口=`）；不写米、`主光=`、`Key世界向=`、色温K、焦距。设计先写纯物理世界（含光源与光照方向），再反算机位/焦距/`可见面=`：原则上大角度见五面，服从窄/敞/小屋。广场/野外偏更广，仙境外景/美景再广一档（设计层写焦距，规划不写 mm）。禁只堆陈设导致无表演区。落位服从**分位从简**。空旷失败仅当本场硬核销动作无处落点（缺必须的门/桌/承托面）；表演中央无多余家具而留净空≠失败。多主环境时**逐主**通读其所属情节。
    - **姿势→承托面（强制；读【本场姿势】）**：开场/入画姿决定本场硬核销家具，禁与姿势对不上。`坐|翘脚坐|盘腿坐`→座次区+对应椅/凳/沙发（人数≥坐姿人数；**该椅当场按座椅惯例锁 `朝向=`**）；`平躺|俯卧|向左侧躺|向右侧躺`→床/榻/可躺承托；`跪|半跪|蹲`→跪地/蹲区净空，**禁止**无据加一圈椅；`站|立`→站位净空，无坐姿则表演中央不必摆椅；`倚`→可贴墙/柱/家具立面；`骑`→坐骑/鞍位不升格为厅堂座椅；内舱`坐`服从载具座向（驾驶座 `朝向=挡风/仪表盘`）。缺【本场姿势】则据正文/剧情自判并标 `upstream_missing_pose`，仍须写出承托，禁假装全员站。
    - **场头必要锁定（最高；写骨架时先锁定）**：先出**必要活动空间四项** + **必要环境陈设**（硬核销、且未进禁入环境名集的具名物入清单；已抽 CHAR/PROP 不入）+ **空间所属向**（哪面有什么；**有椅则当场写功能朝向，禁止预写锚/宫格/米数**）。**必要=剧本明确写出，或本场剧情硬核销必须用到的环境件**。落位服从**分位从简**。锁定后本场内**主体名单与所属向不得无因改写**——禁中途把门从南面挪到北面、禁桌与门对调、禁活动区换边、禁拍中凭空多门多桌。剧情打碎/挪动/携入须有可拍过程且只改该物；未受力实体相对保持场头锁定。上游已锁 → **原样继承**（禁把靠边常用件搬进表演中央）。整体环境状况改写：状态衍生/新主环境骨架走本文件；是否新起 Scene 服从输入已切场次，本文件不改判。
    - **角色与未落实体位置规划**：本文件只保证活动空间能容纳本场站位需求，**不写**【位置规划】块，不写初态/变化/终态落位。
    - **活动区禁布（分位从简之中间/靠边）**：表演中央禁无核销立体障碍；例外=贴地层｜硬核销表演锚｜靠边常用配置。其余实体落四面边缘。禁为「不空」把墙边件搬进中央。
    - **主环境须明文写【活动空间】**（紧接名称/日夜后，一段短句，禁省略）：①**整体环境锚点**（本场整体身份，须可检索 `整体环境锚点=`；例 `古代中国客栈`。禁止抄注册名、禁止写家具名）；①b **主舞台区**（本场主要表演落点：对峙/对白/入座/跪拜发生在哪一块；须写相对哪件，禁止只写「中区」）；①c **挂靠锚点**（主舞台区所挂的一具环境主体，供下游角色挂靠、四宫机位与衍生可见性。须可检索 `挂靠锚点=` + `锚点落=北|东|南|西|中`。`锚点落`=该件所在方向的**正向**或**中部**。衍生裁切：`北`→仅 `0度` 衍生正向可见；`东`→`90度`；`南`→`180度`；`西`→`270度`；`中`→四向衍生均可见。可见的那条衍生 `anchor_description`=`整体环境锚点={名}｜挂靠锚点={名}`；不可见的衍生只写 `整体环境锚点={名}`，禁把挂靠写成该角可见锚。**优选**：剧本明确点名、且本主环境内 `数量=1` 的件——唯一窗/唯一门/唯一桌/唯一柜台。多件同质不得当挂靠。无剧本点名则退到本环境内唯一功能件，logic 标 `挂靠锚点=无剧本点名取唯一件`。禁止已抽 CHAR/PROP。禁止写米数/`心点=`/`宫格=`）；②**动线**（走动/逃跑/追逐可通行，禁被固定实体堵死）；③**站位承载**（本场高峰同框人数与分区，须对齐【本场姿势】：坐→座次/椅、躺→榻、跪蹲→净空、站→站位；有桌则座次区；**交通工具内舱按载具惯例写同向座舱或对座排**，§12）；④**出入画口**（具名门/洞如何服务进出剧情）；⑤与⑦均衡咬合（活动区净空+禁无据家具障碍）。⑥**高速空间（命中强制）**：本场情节含楼间穿梭/空中追逐/飞行器追逐/车辆追逐/飙车/高速飞翔 → 【活动空间】另写 `高速空间=档=中|高|极高｜航线净空=｜过幅参照={具名柱列/灯列/楼缝/窗阵}｜光带锚={灯杆列/霓虹阵/窗格阵}｜借力结构={檐/窗框/管线/广告牌|无}｜层位={贴地|檐上|云腰|多层}`。过幅参照与光带锚须落入四向/固定清单（贴墙或贴边，禁入中区舞台；同质多件写整数，禁`成排`空数）；航线净空不得被家具堵死。供下游环境设计 §2.4.5 深化。禁只写「可以追」无具名参照。
    - **交通工具内舱=独立主环境（最高；按类型惯例，禁随意设计）**：汽车内、客舱、**任何驾驶舱/操纵舱**（飞机驾驶舱、轮船驾驶台/舰桥、列车司机室、工程机械/航天器驾驶舱等）、轿子、**马车厢**、船舱、火车车厢等一般为独立【主环境】，禁止并进舱外环境。出入封闭舱仍仓外起始、本场切仓内。**马车≠马匹**：仅马车厢/驾台可立内舱或敞篷占用；马匹/骑马只挂宿主 PROP。**前向驾驶舱**须先锁真实舱型、0°主要驾驶观察向、前向操纵位与后方槽位；固定清单驾驶座/副驾 `朝向=挡风/仪表盘`，**禁止背对仪表盘**、禁止套厅堂主位朝门；司机/飞行员/舵手/操纵员在前向操纵区，后方人员不得写到操纵员与前窗/驾驶台之间。开放式舰桥/多控制台按真实槽位逐人锁功能朝向，禁套汽车排座或无据全员同向。细则见§12「交通工具内舱」。
    - **载具裁定（最高；只立统筹已锁的一侧或两侧；旧「禁道具上入戏」作废）**：读全局统筹 `载具裁定=仅ENV|仅PROP|双出|无` 与 `外观整体=`/`内部剧情=`/`三层交付=`，以及【本场道具身份】。本环节不重抽、不改裁定、**不改预留名**。占用 IDENT `名称=` = 统筹 `舱内ENV=`/`体外占用ENV=`（`黑轿车车厢`）；宿主 `名称=` = `挂场ENV=`（`夜街`）；整车只认 `整车PROP=`（`黑轿车`）。**三名互异**。容器档场只立占用，不把整车名写成 ENV。主体档场不立占用冒充整车。**`=无`（摩托/单兵飞行器/马匹）→ 不立占用，已抽件挂宿主。马车/马车厢按已锁裁定立厢；拉车马匹不并进占用。**
      - **仅ENV**（仅内部剧情）→ 只立占用主环境，IDENT `环境族=占用`，名=统筹占用名。封闭舱不立宿主。露天合建把大世界写进该占用四向，仍不另立宿主，不把整车写进空镜。
      - **仅PROP**（仅外观整体）→ 只立或复用更大的宿主（街/海/港/路/空），IDENT `环境族=宿主`，名=统筹 `挂场ENV=`。已抽整车不进固定清单/四向。禁立自身舱/甲板占用。
      - **双出**（两问都是，或三层交付）→ 占用 + 宿主分名并存（占用名≠宿主名≠整车PROP名）。整车以已抽 `[PROP]` 为准；`挂场ENV=`=宿主，禁指向自身舱/甲板。漏抽或同核回流全局统筹。
      - **三层交付**：车在街上、人在车里与外界交互 → 规划层必须有宿主大世界；拍级沿用宿主、人可相对整车 PROP。另有内部自成做场才立占用。
      - **占用面型（最高；先判封闭或露天再写骨架）**：
        - **封闭舱**（驾驶舱/客舱/船舱/封闭货厢等）→ `占用面型=封闭舱`。独立主环境，四面是舱壁/窗；大世界只经窗/门看见。绑定：`内部主环境={舱名}｜host_exterior={整车名}|无`。
        - **露天合建**（甲板、敞篷后厢、开顶平台、露天翼面、无顶舰体表面等）→ `占用面型=露天合建`。**一块占用主环境须用载具局部 + 大世界合建**：【活动空间】主舞台/站位=载具局部活动面（甲板/厢底板/栏/厢壁）；四向远景与包络=宿主大世界（海/路/天/街）。禁把露天面写成四面围合房间。禁只写大世界、漏载具局部活动面。禁只写局部、漏大世界四向。仅ENV 露天也不另立宿主——大世界写进这同一块占用的四向。双出时宿主仍只服务整车远观，与合建占用分名。绑定：`体外占用主环境={名}｜host_exterior={整车名}|无｜合建大世界={海/路/街名}`。

      - **双出边界**：禁同名一条兼当占用空镜与整车。外壳/门窗/主色与整车绑定一致；舱内座椅不回填整车。拍级选档归现场编排，本环节不选 `{N}度`。❌`[ENV] 名称=黑轿车` 而整车已是 `PROP:[黑轿车]`｜❌占用另起「轿车内」「黑色轿车里」近义。

- **其余即环境全集（最高）**：未进名集的建筑/装修/大件家具/基础陈设，凡剧本点名或剧情硬核销 → **必须**纳入本场主环境四向/中心/固定清单/未落。不得留给资产设计补名单。

## 成稿自检（本子技能）
- 已按全局统筹做场景勘探；明示与隐藏主环境（闪回/闪切/舱内外/二层内部/环境实质改写/载具内舱/甲板等体外占用）均已入对应场的 `SCENE_ENV_IDENT`。载具已按 `载具裁定=` 只立需要的占用/宿主；仅内部未立宿主；仅外观未立占用；双出/三层未同名兼当；占用/宿主名已逐字抄统筹预留且 ≠ `整车PROP=`；`载具裁定=无` 的摩托/单兵飞行器/马匹未另立占用；马车未与马匹混判。每条 IDENT/【主环境】已写 `环境族=占用|宿主|普通` 与 `占用面型=封闭舱|露天合建|无`。露天合建已同时锁载具局部活动面+大世界四向，未写成封闭房间、未只写大世界。三层交付已立宿主大世界。
- 每条 `[ENV]` 后有可检索 `定位`/`目标`/`情绪表达`/`时地=`/`风格=`（复用场定位可`继承原定义`，目标、情绪、时地与风格仍为本场）。`时地=` 的季节/时段/时辰/光变档/气候/气候可见/氛围与本场【本场时地】逐字同核；`风格=` 与本场【本场风格】逐字同核；`情绪表达.主情绪`/`光色倾向` 与统筹氛围同核；【主环境】已写 `气候=`/`气候可见=`/`氛围=`；`日夜内外` 已写成 `{时段}·{内外}`，未停在日/夜。
- 输出覆盖全部输入 Scene 的 `ENV_SCENE_PATCH`；每场都有可提取的 `SCENE_ENV_IDENT`；补丁顺序与输入 Scene 一致。
- 补丁外未输出场景分析、SCENE 正文、综合信息或项目视觉回填。
- **复用已继承**：已读项目原有主环境（未删除）及其原定义；同空间已 `复用=是` 并逐字锁名；未重画复用骨架。输入写明 `可复用/可参考主环境=无` 时未臆造复用名。
- **全局资产已匹配**：需要的环境能对应注入项时，已复用锁名或参考其原定义写新建骨架，未另起同义空壳。
- 每场新建主环境【主环境】+【未落清单】闭合；四向/固定清单/未落项即实体落点真源；活动空间可站可动。命中穿梭/追逐/飞翔/飙车时【活动空间】可检索 `高速空间=`+具名过幅参照+航线净空，未只写「可以追」。
- **主舞台区+挂靠锚点已锁**：【活动空间】可检索 `整体环境锚点=` + `主舞台区=` + `挂靠锚点=` + `锚点落=北|东|南|西|中`。`整体环境锚点` 是场所身份（如 `古代中国客栈`），不是家具、不是注册名近义。挂靠件已入四向或中心，且本环境内数量=1。`锚点落` 已标明该件在哪一方向正向或中部。只写 `主舞台=` 无 `整体环境锚点=`/`主舞台区=`/`挂靠锚点=` = 失败。挂靠已抽 CHAR/PROP = 失败。同质多件当挂靠 = 失败。
- **世界方位已继承**：原文/场头/既有定义已点名北/东/南/西的主体，已落入对应 `正北=`/`正东=`/`正南=`/`正西=`，未为好看墙改挂。
- **五区主体已具名（地面场；禁止精确定点）**：俯视360可检索 `正北=0度=`/`正东=90度=`/`正南=180度=`/`正西=270度=` 与 `原点=中心`；各区有具名主体（或中心净空有据）。须可检索 `围合=北=`/`东=`/`南=`/`西=`（值∈`封|敞`）与 `向距上限=北=`/`东=`/`南=`/`西=`（值∈`窄|开|无限制`）。出现 `心点=`/`距原点=`/`占地=`/`占场≈`/`场径=`/`宫格=` 或米/步/% = 失败（精确定点是资产设计的活）。`整体环境锚点=`/`挂靠锚点=`/`锚点落=` 不是精确定点，必须写。只写 `0度=` 不写正北/正东/正南/正西=失败。舱轴场写 `舱轴前/后/左/右=`，未写东南西北。缺 `围合=` 或 `向距上限=` = 失败。四向 `围合=敞` 却写成四面房间 = 失败。`封` 向只写门柜桌、不点封闭面 = 失败。`敞` 向只写开口、不点远景 = 失败。
- **剧本环境主体零遗漏**：本场正文/场头/空境点名的非角色、非道具主体，均可在四向/中心/地面/空中屋顶/固定清单/未落检索到原词或逐字专名。只写门窗柜台等主锚、蒸发原文桌/椅/廊/梁/牌匾/灯笼/楼梯=失败。已抽 CHAR/PROP 误写入环境=失败。
- **姿势承托已对齐**【本场姿势】：坐有椅、躺有榻、跪蹲有净空、站有站位；未与姿势对不上的家具。
- **座椅功能朝向已锁**：凡清单有椅/沙发/轮椅/驾驶座，可检索功能朝向（朝大门/朝桌心/朝挡风）；书房/办公室主位朝大门且在大门对侧（自然语言即可）；客位/围桌朝桌心；驾驶座/副驾朝挡风/仪表盘，未写成背对仪表盘或套厅堂朝门。只写「案后椅/有驾驶座」无朝向=失败。出现 `锚=`/`宫格=`/`F=`/`椅面朝向=`/`竖边=`/`在桌=`/`心点=` = 失败。挂靠小件点名宿主即可。未把 CHAR 宠物/动物或已抽 PROP 写上台面。非正方凳/条案未用自然语言写竖边走向或在桌哪一侧=失败。
- **背景微动件已裁定**：每块新建【主环境】可检索 `背景微动件=`（具名或`无`）；有具名则已入四向/固定清单、落点不占舞台/动线、非大件。
- **门窗开闭**：原文有开闭则可检索（半开/全关/全开）。缺 `扇型=`/`门轴=`/`把手=` 不失败（归资产设计）。无据把场头写成大开=失败。
- **参照物未滥摊**：可固定参照物无剧情明文未摊多件；参考图/原定义已锁落位者未再写位置。
- 主环境永不作可拍当前环境。
