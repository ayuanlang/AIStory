## 目标（最高；本子技能工作方式）

本技能按**整集**调用。输入=全局统筹切分结果（含 `[CHAR_EXTRACT]` / `[PROP_EXTRACT]` / 各场 `[SCENE_CAST]`）+ 已注入的项目原有主环境（未删除）。只做**场景勘探与主环境规划**，确定本集需要的拍摄环境。
1. **按全局统筹做场景勘探**：通读各场正文、【场景衔接】、【闪回分档】、【场景名称】、【本场姿势】与 `project_visual_backfill`，判断每场实际要拍的空间。
2. **识别全部主环境需求（明示 + 隐藏）**：每个 Scene 至少一个主环境，可多个。必须找出场头/空境写明的空间，以及隐藏空间——同场短闪回/闪切落点、独立闪回 Scene、出入封闭舱（仓外+仓内）、二层内部不共享外形、整体环境实质改写后的新空间、载具内舱、**载具露天占用（甲板/敞篷后厢等，局部+大世界合建）**等。载具只立全局统筹 `载具裁定=` 需要的占用/宿主（整车走已抽 PROP，不并进占用空镜）。拍级选 ENV 还是沿用宿主归现场编排。
3. **复用优先、继承原定义**：先对照 `[项目主环境名开始]…[项目主环境名结束]` 与 `[用户选定全局环境开始]…[用户选定全局环境结束]`。同空间必须 `复用=是`，名称逐字沿用；原项目主环境定义由程序按场回填，本文件不重写其骨架。写明 `可复用/可参考主环境=无` 或 `用户选定全局环境=无` 时不得臆造复用源。
4. **只输出每场主环境信息**：每个 `scene_id` 一个 `ENV_SCENE_PATCH`，内含 `SCENE_ENV_IDENT`（该场全部主环境 + **定位/目标/情绪表达**）以及 `复用=否` 者的【主环境】+【未落清单】（**环境实体落点**一次写定）。角色与独立道具已由全局统筹提取；本环节只读衔接，**禁止**再输出 `[PROP_EXTRACT]` 或角色块。禁止输出场景分析、场级评估、SCENE 正文、对白、Beat、建置或完整 Scene。程序随后按场切分，注入对应场次的场景现场编排。下游只继承，不重做识别、不重落点、不重写三属性、不重抽 CHAR/PROP。
5. **结束标签硬闸**：全部场补丁写完后，全文最后一行必须是 `[ENVIRONMENT_PLAN_OUTPUT_END]`。
6. **不拆场**：一次处理整集；同场多个主环境写在同一场补丁内。是否另起 Scene 服从输入已切场次。

## 通用硬约束（各子技能同锁；最高）
1. **忠于上游 + 未命中不输出**：不改事实/因果；禁新增改因果事件。非环境内容只读，禁止复制到补丁。
2. **原文信息零丢失 + 禁虚化（最高）**：环境文学/地名/固定实体须**原样写入**成稿可检索落点。**禁止**用「同原文／按原文／见原文／原文如此／照原文／如上／略／大意／照旧／不赘述」等虚化代替原文环境句或专名。
3. **专名逐字**：环境注册名与原文或上游**逐字一致**；同环境名复用。
4. **对白保真**：本文件不改台词。
5. **逻辑合理可拍**：活动空间可站可动可出入；四向正交；椅面朝该椅功能面（主位朝门、驾驶座朝仪表）；禁把内舱并进仓外当衍生。
6. **禁实拍执行语**。
7. **下游边界**：禁代写分镜处方。
8. **只锁环境**：不得借「设计环境」改写对白/特效/建置几何。

## 1. Scene 与环境（勘探 / 识别 / 复用 / 新设计）
> 完整口径 §9–§11、§16；下文流程速查。

### 1a. 场景勘探与复用（每个 Scene 强制；本环节产出）
执行前必须先读注入块 `[项目主环境名开始]…[项目主环境名结束]`（已删除环境不计入）及其**原定义**，再读 `[用户选定全局环境开始]…[用户选定全局环境结束]`。先读完全部已有主环境，再按全局统筹逐场勘探。若写明 `可复用/可参考主环境=无`，一律 `复用=否｜来源=新建｜匹配主环境=无`。禁止把未注入、已删除或自拟名当成复用源。

#### 场景勘探（明示 + 隐藏）
据全局统筹各场正文、【场景名称】、【闪回分档】、【场景衔接】与场外综合信息，列出本场全部拍摄主环境：
- **明示**：场头/空境/具名地点/场景名称中的空间。
- **隐藏（必须找）**：同场短闪回/闪切落点；独立闪回 Scene 的回忆空间；出入封闭舱的仓外+仓内；上楼后不共享外形的二层内部；整体环境实质改写（崩塌/火灾/水淹/域场）后持续停留的新空间；汽车/机舱/轿子/马车等载具内舱；蒙太奇各异地落点。
- 每个 Scene 至少 1 个主环境；上列隐藏空间与当下空间不共享外形时**必须另立**，写在同一场补丁内（输入已拆独立 Scene 则逐场各写）。
- 环境名用稳定空间注册名，不写日夜后缀，不写 `{N}度…` 衍生名。
- 日夜/天气/气氛不同不另起名；换观察侧、反打、特写不是新环境。
- 勘探只作内部判定。成稿只交主环境信息，禁止输出勘探过程、场景分析或 SCENE 正文。

#### 复用判定（只对项目库与本集之前）
- `来源=项目库`：与注入清单同空间，名称须**逐字**等于清单已有名。
- `来源=上集`：与本集之前某集已锁定主环境同空间，名称逐字沿用。
- `来源=新建`：清单、上集与本集前文都没有可复用的同空间。同场闪切/短闪回的出去落点若为新空间，标新建并写在**同一场**第二行 `[ENV]`。
- `来源=本集`：本集前文某场已声明同空间，含多线穿插后回切到先前主环境。名称逐字沿用，`复用=是`。
- `复用=是` 用于 `项目库|上集|本集`。`新建` 必须 `复用=否`。
- 禁止把未切叙事线的连续同空间拆成两场再标复用。同线同空间短暂出门一瞥仍同场多主。多线穿插回切已是独立 Scene 时，锁本集已有主环境名即可。

#### 包裹格式（最高；程序只读此块做回填）
必须写在该场 `ENV_SCENE_PATCH` 内、【主环境】骨架之前，ID 与本场 `scene_id` 逐字一致：

```text
[SCENE_ENV_IDENT_START:EPxx_SCyy]
[ENV] 名称={主环境名}｜环境族=占用|宿主|普通｜占用面型=封闭舱|露天合建|无｜复用=是|否｜来源=项目库|上集|本集|新建｜匹配主环境={已有主环境名}|无｜依据=原文：“…”
定位={归属用番位禁姓名}，{体量档}，{气质/类型}
目标=本场空镜须={一句可核销目标}｜服务={场景名气质或无}｜可见落点={无人称空间语}
情绪表达=主情绪={压迫|肃杀|温煦|孤绝|蓄势|明媚|紧张|哀悯|决绝|温情|悬疑|空寂|…}｜空镜表达={一句无人气质}｜光色倾向={文学词}｜构图倾向={纵深压迫|中心仪式|三分留白|负空间|对称|框中框|…}
[SCENE_ENV_IDENT_END:EPxx_SCyy]
```

- 每场恰好一对包裹；有几个主环境就写几组：一行 `[ENV]` + 紧随三行 `定位`/`目标`/`情绪表达`。三属性跟在**该条** `[ENV]` 后，禁攒到块末或写进【主环境】重复。
- `复用=是` 时 `匹配主环境` 必须等于注入清单或本集前文已声明名，禁止近义改写；**仍须写本场 `目标`/`情绪表达`**（场级空镜任务可不同于库内初稿）；`定位` 写`继承原定义`或原句。
- `复用=否` 时 `匹配主环境=无`；`定位` 必须写满。
- 识别块之后：仅 `复用=否` 的环境续写【主环境】四向与【未落清单】落点；`复用=是` 不写骨架。
- **三属性口径（最高；文学级，禁 Key/Fill/色温K/焦距）**：扫描源只摘、禁臆造——场头/空境/【场景名称】、全局统筹情节与【场景衔接】、`project_visual_backfill` 气质、原文环境文学与评价词。`服务=`无卖点明文则写场景名气质或`无`。三键并存不互代：定位≠目标≠情绪；目标≠观察用途（Master/反打）。纯空镜：禁人名/人称。
- ❌只写 `[ENV]` 无三属性｜用四向拓扑顶替目标｜复用场漏本场情绪｜✅ 识别一行 + 定位/目标/情绪三行。

- **用户选定全局环境匹配（强制；写骨架前完成）**：
  1. **先读注入块**：`[用户选定全局环境开始]…[用户选定全局环境结束]`。写明 `用户选定全局环境=无` → 本集无用户指定全局环境，禁止把项目库未勾选项或自拟名当成「用户选定」。
  2. **列出需要的环境**：本场识别出的名称 + 情节确认的空间（异地/舱内/二层内部等）。这是待匹配的「需要侧」。
  3. **逐条对照注入清单**：对每一个需要的环境，在用户选定清单里找可对应项。命中任一即可：注册名逐字相同；同空间别称/地名/功能单元对应（如「客栈大堂」↔ 注入「客栈大堂」）；原定义所写空间类型与本场活动包络同一处（厅堂/街市/舱内等），且不与另一注入项抢占。
  4. **命中后必须用注入信息，禁止另起同义空壳**：
     - 该场已标 `复用=是` → **只锁资产注册名**，不输出其【主环境】骨架（程序继承原定义回填）。
     - 该场标 `复用=否｜来源=新建` → **仍须参考**注入的名称、原定义来写本场主环境骨架：主名优先用资产注册名（勿另起近义新名）；活动空间/固定实体/0°轴气质服从原定义。已有衍生名只作后续现场编排参考，本文件不写衍生行。
  5. **未命中才新建**：需要的环境在清单中找不到对应项 → 按新建写骨架。未用上的勾选资产**不要**硬塞进无关场。
  - ❌忽略已注入全局环境另起同义主名；❌未对照就按「感觉像」新建；❌把未对应资产摊进每场；❌`=无` 时臆造用户选定复用。
- **流程（先识别，再写新建骨架；整集一次）**：按输入 Scene 顺序完成本节识别，并完成本节「用户选定全局环境匹配」。每场先输出 `SCENE_ENV_IDENT`。`复用=是` → 只锁名称，不输出该主环境骨架。`复用=否` 且已匹配到全局资产 → 按注入信息写主环境骨架（参考，非另起空壳）。`复用=否` 且未匹配 → 定需求（须覆盖该场重点、空镜位、打斗/空域活动）→【主环境】新设计 →【未落清单】闭合。全复用场仍出识别补丁、不出骨架。本文件不写衍生行、角色建置朝向、建置句。**椅/沙发/轮椅/驾驶座等家具朝向与中区锚/宫格必须本环节按座椅惯例锁进固定清单**，下游只继承，不得留到环境设计再猜。
9. **空间闸（本文件）**：本文件**不裁定** Scene 切分（原场可否细分服从输入已切场次）。只锁主环境骨架：动作越四向包络、真正异地/进入不共享外形的功能单元 → 另立【主环境】；出入封闭舱一般仍同场多主；二层内部不共享外形 → 另立主环境。换观察侧、反打、特写、情绪/气氛微调、同空间走位 → **不另立主环境**（衍生/景别归后续现场编排）。景别/特写不是环境。
10. **环境定义（§11）**：空镜骨架+具名出入口；变化主体→环境、动作→后续 Beat。**同环境复用（最高）**：上游同空间名或已匹配的用户选定全局环境→主名**逐字复用**；日夜不同不另起名；仅无上游、未匹配全局资产且硬需才新建。因剧本而生；**先定本场活动空间再落实体**；**分位从简**见 §11 不变式（成稿禁写规则原句）。**交通工具内舱（汽车/机舱/轿子/马车等）一般为独立主环境，出入封闭以仓外为起始、场内切仓内，按载具类型惯例锁座向，汽车等司机在前排驾驶座，禁套厅堂围坐**（§11/§12）；禁装饰扩写；每场【主环境】+【未落清单】齐全（多主环境时每主各齐）；无人像；禁材质光色细参。**上下楼层先判是否须共享外形**（通高可互望→一块主环境并分层盘点；**二层内部等不共享外形→切成两块主环境，独立描述，可风格依赖**；§11 四向+中心⑦）。**主环境=原文初始建立态**（场头/空境/开场），禁用后文剧情终态改写基准（§7）。**环境描写：可简约、禁破旧倾向（强制）**——【主环境】/服化道「环境细节」/空镜建立句可写素净、少陈设、留白净空；**禁止**无原文/剧情硬核销时主动加破烂、破败、残墙剥落、霉渍油污、裂缝狼藉等破旧语汇；简单≠破旧；张力用光色/空寂/秩序，禁用脏乱破烂代替。**原文软性评价词保真**：精致/高贵/华贵/素净等须进【主环境】文学或固定清单定语，禁删或改成「好看」。
  - **上游/既有主环境注入→坐标锁（有则强制）**：既有主环境仅锁0°轴、世界拓扑、四向实体归属、固定清单与活动空间。禁止重映射/旋转坐标系。衍生行与选角不在本文件。

    3. **原则上不重复或不能完全重复（服从⑤唯一性）**：各向（含中心）主锚实体集**原则上互不重复**；确须同类多件时走⑤（总个数→逐具具名+区分特征+分边/各向个数），**禁止**四面抄同一套「门+窗+桌」完全同构；对向串写仍禁。四面可各加不同贴墙件以可辨；**禁止把四面件复制进中区凑互不重复。**
    4. **地面与空中/屋顶（有则强制）**：五区描述之外，按需另写——**地面/地板**（贴地层连续、中区净空可贴地；材质/分格/收边一句即可，禁活动区堆立体物）；**空中或屋顶/天花/天空**（室内=梁架/吊顶/主灯/天窗；外景=天空/天际/檐口/树冠上层等）。有航拍/空战/上段动作/可见天顶戏份时**必写**；无剧情亦不得五区只写立面、完全省略地面与上边界（至少各一句可核销）。
    5. **成稿口径**：俯视360写法须可检索 `0度=…｜90度=…｜180度=…｜270度=…｜中心=…`（**顺时针递增**；`0°=左上`、`90°=右上`、`180°=右下`、`270°=左下`；+可选 `地面=…｜空中/屋顶=…`；**通高须共享外形另须** `下层/一层=…｜上层/二层/回廊=…`，禁上层继承下层；**二层内部不共享外形则另块主环境，禁写入本块上层**）；中心服从【活动空间】净空（分位从简）。❌四向同句复制或四面空白；❌把沙发屏风摆进走位中央；❌按行优先写成 `0→90→270→180`。
    6. **中心≠某一向立面（最高；防茶几换角蒸发）**：沙发、茶几/矮几、中央桌、岛台等位于两边界之间或主家具前方的**地面家具只写入【中心】**，**禁止**记入 0°/90°/180°/270° 某一向立面主锚。沙发可靠近某向墙，该向仍只写墙面本身（沙发本体记【中心】）。屏风可贴墙记四面。❌`0度=沙发与矮几`。Stage 3 拼图跨格守恒继承本条。
    7. **上下楼层：先判是否须共享外形（最高）**：闸门=两层空镜是否必须画进**同一张**主环境四向拼图（同一视觉体量、可互望）。
       - **须共享外形 → 一块主环境 + 分层盘点**：仅当两层通高/可互望（客栈通高大堂+二楼回廊、Loft/夹层、中庭挑空——从一层能看见上层廊/栏，从廊能俯看一层）才共享一块【主环境】。此时须**分别**写清 `下层/一层=` 与 `上层/二层/回廊/夹层=` 具名实体（各层陈设+出入口/栏杆/楼板开口+该层活动区若有戏）；楼梯标 `下口在下层｜上口在上层`；跨层可见标 `所属楼层=`。禁 `二楼同楼下` / `上层继承一层` / 只写「空中=有回廊」无廊上实体；跨层同类件走⑤（总数→具名+所属楼层+区分特征）。有戏层各写活动区；无戏层仍须可辨结构，禁敷衍空廊。复用既有通高主环境须在该 Scene 补丁中原样继承两层清单；既有稿只有一层而本场确通高→回补，禁用「继承」跳过上层。
       - **不须共享外形 → 切成两块主环境（强制；典型=二层内部）**：上楼后进入**封闭房间内部**（二层客房/账房/闺房/办公室等——关上门即独立四向包络，镜头不必与一层大堂互望、不必共用一张四向拼图）→ **必须另立第二块【主环境】**，两块**独立描述**（各有名称、0°轴、四向+中心、固定清单），**禁止**并进一层当「上层/二层=…」。通常同时拆 Scene（§9 空断）；楼梯可留在一层作连接件，二层从房门起另立。❌把二层客房桌床写进一层大堂上层清单。
       - **风格依赖（允许；≠共享外形、≠简单继承）**：两块主环境空间骨架各自写满，但可声明 `风格依赖={另一主环境名}`——通常**二层内部挂一层/通高大堂**（同建筑气质）。只借风格（年代/材质族/色系/工艺/文学气质），**不借**四向拓扑、固定清单、0°轴、楼底、家具名。被依赖方（父）仍独立成稿、`风格依赖=无`。单向、禁环、禁互挂。无同建筑气质核销则 `风格依赖=无`。
       - **禁**：用共享主环境冒充二层内部；用「二层内部」逃避通高回廊的分层盘点；用风格依赖把两块压成一块。
  - **主环境必写**：名称｜日夜内外｜`主环境角色=…`（单主可写`当下主线`）｜**【活动空间】**｜俯视360｜**四向+中心（各区写实例化后的具体内容；禁敷衍空壳/禁完全同构；输入该向内容=正面面对；各向正对边界正面，四方正交，禁偏斜；扇区序=俯视顺时针 0左上→90右上→180右下→270左下）**｜**地面与空中/屋顶（有则写，常规至少各一句）**｜**通高须共享外形则下层+上层分列；二层内部不共享外形则另立主环境（可风格依赖另一主环境，仍独立描述）**｜0°轴（原点；后续角=`(0+90k)%360`）｜头尾双锚｜固定清单(含出入口；⑤全套；椅/沙发/轮椅/驾驶座须带 `朝向=`+`锚=`+`宫格=`；挂靠小件须带 `挂靠=`+眼高可读 `部位=`；只列最终实际存在的具名实体)｜**背景微动件={具名}\|无**（可选；见下条）；不写前中后景/人物/材质细参。分位从简为内部裁决词，禁入本块实例化字段。**主环境=基准定义，永不作可拍当前环境**——后续现场编排才声明 `{N}度{名}` 衍生。
  - **背景微动件（可选；非必须；有则供建置/入戏）**：每块【主环境】可点名**至多一具**细小实体，供下游建置看见、入戏写 `ENV背景微动=`，避免镜头死静、假静。
    1. **非必须**：空间确无合适细微件、或补一件会挡行动/破简约 → `背景微动件=无`。禁为凑行硬塞。
    2. **先点名已有、确无才补一件**：优先从该主四向/固定清单已有细微件点名（帘/穗/灯焰/烟气/水纹/叶/尘/旗角/窗纱/烛火/蒸汽/纸页边/香缕等）。清单全是大件且落点允许 → 可在**四面贴墙/窗沿/檐下/空中/地面贴边**补 **1** 具细小件，并同时写入该向与固定清单；**禁止**补进【中心】或动线。
    3. **不影响行动（最高）**：落点不占主舞台、不堵动线、不挡出入画口、不升格为相对锚/交互面；禁改【活动空间】净空。禁桌/柜/门/柱/床/墙/柜台等大件当微动件。
    4. **成稿**：`背景微动件={具名}｜落点={扇区或贴墙/空中/窗沿}｜可用动势={帘摆|灯焰颤|烟气丝|水纹|叶颤|尘浮|旗角|窗纱|烛火|蒸汽|纸页边|…}` 或 `背景微动件=无`。复用场不重写；原定义有则继承。
    ❌拿大门/八仙桌当微动件｜❌补件挡走位｜❌未入四向/固定清单却点名｜❌复用场另造新件｜❌已抽 CHAR/PROP 当微动件
  - **未落清单（未升格实体落点；最高）**：`{具名}｜依据｜开场在场|待入画｜归属主环境={名}`；多主时可按主环境分节。场头必要**环境陈设**须入清单或固定清单。开场能看见本体才`开场在场`；盒/匣内稍后取出的陈设件标`待入画`。已在全局统筹 `[CHAR_EXTRACT]` / `[PROP_EXTRACT]` / 【本场角色】【本场道具】或 CHAR `衣着` 的主体**禁止**再入未落/四向/中心/固定清单/微动件。清单外禁止中途凭空新增。不重抽 CHAR/PROP。
16. **三步开场（环境侧）**：空镜骨架/环境文学落点本文件锁进【主环境】。本文件不写吸睛→建置→入戏的画面句，不写服化道首落/静物预排布几何。
17. **实体覆盖（环境侧）**：全局场景/环境注册名进【主环境】（与上游逐字一致）。已抽全局道具**不写**（由道具资产入画）。本文件不写角色排期、开场在场几何或【实体覆盖】块（归站位）。
  - **上游全局实体→环境骨架明文（最高硬约束）**：输入（原剧本/分集正文/类型执行摘要/项目信息/Characters·Props·Environments/Applied Entities/Continuity·Carry/服化道等）**明文**将该环境定位为全局/贯穿/跨集/全剧级，且本 Scene **剧情涉及** → 必须在本场【主环境】**具名明文**写出（与注册名逐字一致）。已抽 `[CHAR]`/`[PROP]`（含全局道具）**禁止**写入环境骨架；漏抽回流全局统筹，本环节不补造、不改挂进环境。
    - **明文证据（任一即命中；禁臆造「感觉像全局」）**：`全局性道具`｜`全局道具`｜`贯穿道具`｜`跨集道具/环境`｜`全剧道具/场景`｜`系列核心道具`｜`主场景`/`#复用` 全局环境注册｜项目/集纲/台账等价标签（如`道具类型=全局`、`scope:global`、`global_prop`/`global_env`）；或明文「贯穿全剧/多集复用/全片核心」且具名该实体。未达明文 → 不得自称全局。
    - **落点分工（环境侧；本场涉及则缺一不可）**：
      | 实体类 | 本文件必写落点 | 禁 |
      | :--- | :--- | :--- |
      | **全局道具** | 不写。已抽 `[PROP]` 由道具资产承担 | 写入四向/中心/固定清单/未落清单/背景微动件/环境文学；另起同义陈设冒充 |
      | **全局场景/环境** | 【主环境】名称与上游注册名**逐字一致**；上游已有气质/活动空间/固定实体线索→进主环境骨架（空镜，无人名）；同环境复用§10 | 只换近义主环境名；ENV 空壳只挂地名；本场用全局环境却不写【主环境】块 |

- 其余建筑/装修/大件家具/基础陈设（未进名集）→ 纳入本场主环境。
- 禁止输出 `[PROP_EXTRACT]`、`[CHAR_EXTRACT]` 或角色块。漏抽回流全局统筹，本环节不补造、不改挂进环境。

## 成稿自检（本子技能）
- 已按全局统筹做场景勘探；明示与隐藏主环境（闪回/闪切/舱内外/二层内部/环境实质改写/载具内舱/甲板等体外占用）均已入对应场的 `SCENE_ENV_IDENT`。载具已按 `载具裁定=` 只立需要的占用/宿主；仅内部未立宿主；仅外观未立占用；双出/三层未同名兼当。每条 IDENT/【主环境】已写 `环境族=占用|宿主|普通` 与 `占用面型=封闭舱|露天合建|无`。露天合建已同时锁载具局部活动面+大世界四向，未写成封闭房间、未只写大世界。三层交付已立宿主大世界。
- 每条 `[ENV]` 后有可检索 `定位`/`目标`/`情绪表达`（复用场定位可`继承原定义`，目标与情绪仍为本场）。
- 输出覆盖全部输入 Scene 的 `ENV_SCENE_PATCH`；每场都有可提取的 `SCENE_ENV_IDENT`；补丁顺序与输入 Scene 一致。
- 补丁外未输出场景分析、SCENE 正文、综合信息或项目视觉回填。
