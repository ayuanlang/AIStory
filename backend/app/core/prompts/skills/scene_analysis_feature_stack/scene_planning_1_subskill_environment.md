## 目标（最高；本子技能工作方式）
读取场景拆分结果，对其中每个 Scene 做环境锁定；本技能只输出可由程序按 `scene_id` 回填的**逐场环境补丁**，不是完整剧本，不是建置加密，也不是文戏/特效改写。
1. **复用优先**：上游同空间名 → 主名/衍生主名段**逐字复用**；日夜不同不另起名。
2. **无则新设计**：情节确认异地/不共享外形的功能单元/载具内舱 → 新建【主环境】+衍生族。
3. **只产出环境骨架**：【主环境】【未落清单】【衍生】闭合即止。不写角色落位、不写【建置】画面句、不写入戏位移。
4. **禁止透传完整上游**：不得输出 `[SCENES_BLOCK_START/END]`、`COMPREHENSIVE_INFO`、`SPECIAL_SCENE_ANALYSIS`、`SCENE_START/END`、`SCENE_CONTENT`、原对白/场核/正文或 `project_visual_backfill`。这些内容由程序保留；本技能重复输出即失败。
5. **综合信息只读使用、不输出**：输入若含 `[COMPREHENSIVE_INFO_START]`…`[COMPREHENSIVE_INFO_END]`，可读取其世界观、整体简介、人物简介作为环境核销语境，但不得在结果中复制、移动或改写。
6. **项目级与路由元数据只读使用、不输出**：可读取 `SPECIAL_SCENE_ANALYSIS` 与 `project_visual_backfill` 作为环境承载依据，但输出中不得出现这两类包裹或 JSON。
7. **场级指导强制承载**：读取【卖点综合】`指导=`与【叙事综合】贯穿信息。凡 `细节特写参考` 或 `贯穿保护` 涉及环境、道具、文字/线索载体，必须进入主环境/未落清单及至少一个合法衍生的可见白名单；为 `反馈特写参考` 保留可同显的角色活动空间，为 `运镜参考` 保留可揭示、逼近、跟随、拉开或停留的连续可见空间。只提供环境承载条件，不在本文件写具体镜头执行。
8. **结束标签硬闸**：全部 Scene 补丁写完后，全文最后一行必须是 `[ENVIRONMENT_PLAN_OUTPUT_END]`，缺则失败。

## 通用硬约束（各子技能同锁；最高）
1. **忠于上游 + 未命中不输出**：不改事实/因果；禁新增改因果事件。非环境内容只读，禁止复制到补丁。
2. **原文信息零丢失 + 禁虚化（最高）**：环境文学/地名/固定实体须**原样写入**成稿可检索落点。**禁止**用「同原文／按原文／见原文／原文如此／照原文／如上／略／大意／照旧／不赘述」等虚化代替原文环境句或专名。
3. **专名逐字**：环境注册名与原文或上游**逐字一致**；同环境名复用。
4. **对白保真**：本文件不改台词。
5. **逻辑合理可拍**：活动空间可站可动可出入；四向正交；禁把内舱并进仓外当衍生。
6. **禁实拍执行语**。
7. **下游边界**：禁代写分镜处方。
8. **只锁环境**：不得借「设计环境」改写对白/特效/建置几何。

## 1. Scene 与环境（复用 / 新设计）
> 完整口径 §9–§11、§16；下文流程速查。
- **流程（止于环境骨架锁定）**：先读输入场核与已写入戏的对白/武戏需求。本文件只做到环境闭合：**核销上游同环境**（命中则锁定复用名；有上集/全局主环境注入→角度锁）→ 定需求（须覆盖本场重点、空镜位、打斗/空域活动）→【主环境】(复用既有骨架；无则**新设计**) →【未落清单】→【衍生】族闭合。本文件不写落位朝向、不补缺建置句。本文件只声明够用的 `{N}度…` 行。
9. **空间闸（本文件）**：本文件**不裁定** Scene 切分（原场可否细分服从输入已切场次）。只锁环境骨架：动作越四向包络、真正异地/进入不共享外形的功能单元 → 另立【主环境】；出入封闭舱一般仍同场多主；二层内部不共享外形 → 另立主环境。换观察侧、反打、特写、情绪/气氛微调、同空间走位 → **只切衍生，不另立主环境**。景别/特写不是环境，原文画面仍按 §1 核销。
10. **环境定义（§11）**：空镜骨架+具名出入口；变化主体→环境、动作→Beat。**同环境复用（最高）**：上游同空间名→主名/衍生主名段**逐字复用**；日夜不同不另起名；仅无上游且硬需才新建。因剧本而生；**先定本场活动空间再落实体**；**分位从简**见 §11 不变式（成稿禁写规则原句）。**交通工具内舱（汽车/机舱/轿子/马车等）一般为独立主环境，出入封闭以仓外为起始、场内切仓内，按载具类型惯例锁座向，汽车等司机在前排驾驶座，禁套厅堂围坐**（§11/§12）；禁装饰扩写/未用冗余衍生；每场三块齐全（多主环境时每主各齐）；无人像；禁材质光色细参。**上下楼层先判是否须共享外形**（通高可互望→一块主环境并分层盘点；**二层内部等不共享外形→切成两块主环境，独立描述，可风格依赖**；§11 四向+中心⑦）。**主环境=原文初始建立态**（场头/空境/开场），禁用后文剧情终态改写基准（§7）。**环境描写：可简约、禁破旧倾向（强制）**——【主环境】/服化道「环境细节」/空镜建立句可写素净、少陈设、留白净空；**禁止**无原文/剧情硬核销时主动加破烂、破败、残墙剥落、霉渍油污、裂缝狼藉等破旧语汇；简单≠破旧；张力用光色/空寂/秩序，禁用脏乱破烂代替。**原文软性评价词保真**：精致/高贵/华贵/素净等须进【主环境】文学或固定清单定语，禁删或改成「好看」。
  - **上游/既有主环境注入→角度锁（有则强制）**：既有主环境仅锁0°轴、世界拓扑、四向实体归属、固定清单与活动空间；每个 `{N}度…` 衍生必须与该坐标系同角一致，禁重映射/旋转坐标系。**但 Beat 选角与可见内容仍只读取该 `{N}度…` 衍生行自身的活动适配、可见内容白名单和边界**；既有主环境仅校验白名单没有越界或自创，禁止把其整套四向/固定实体直接套入 Beat。无衍生白名单覆盖需求时先补建衍生行，禁随机轮角或习惯性挂反打。
11. **主环境 / 未落清单 / 衍生（四向美术归 Stage 3）**
  > **不变式**：衍生对**所属**主环境固定实体不增/不减/不矛盾；仅可见性与方向性朝向可变。**主环境骨架与服化道「环境细节」锁定原文初始态**——剧情造成的破损/狼藉/域场改写/日夜突变等不得回填进【主环境】固定清单或初始摘要；须走 Beat 过程 / 状态衍生 / 新 Scene·新主环境（是否新起 Scene 服从输入已切场次，本文件不改判）。
  > **分位从简（最高；内部裁决；成稿禁写规则原句）**：①**四面允许加围合陈设**（贴墙柜/挂画/窗沿/靠边屏风；门窗默认各一、不另开侧室、不四面同构、加件不侵表演中央）；②**中间/舞台区按剧情需要**（表演中央只收剧本明确或硬核销锚+贴地层；无锚则留空≠失败）；③**靠边常用配置允许**（沙发/屏风/边柜及该类型配套须靠边/贴墙，前方留主舞台净空；无该类型依据不加）；④成稿只写实际采用的具名实体+具体扇区/靠向/净空，**禁止**把「分位从简/四面允许/中间按需/靠边配置允许」写入【主环境】/活动空间/固定清单。⑥管不漏；从简管落位。他处只写指针。
  > **⑤唯一性 + 数量闭合（最高）**：默认每功能实体**在所属主环境内**1具；**门/窗/楼梯默认唯一**；多件→总个数→逐具具名+区分特征。**通高两层**：一层件≠二层件，须标 `所属楼层` 并分列具名，禁「上层继承下层」。**桌形制须匹配名称**：有长轴（门↔梯/对坐长案）须写 `长方桌/条案` 并锁 `长轴 + 两端具名锚 + 长:宽`，禁用正方形桌名驱动长短换面。⑤-b同质≥2须分边/各向个数+朝向+同侧顺序。**固定实体清单与主环境中禁用 `若干|数把|多张|一些|成排|散座` 等模糊数量词**；须改写为 `总数 + 分桌/分边个数 + 逐具朝向 + 同侧顺序`，总数=分项之和。窗/窗棂除总扇数外，每扇须写所属扇区、开闭态、横×纵格阵与同墙顺序。上游未给数量时规划层须裁定**一个明确可拍数量**，不得下传不确定性。⑤-c配套：桌↔椅｜床↔被枕｜杯↔盏托。**配套只补已入清单主件的配件**；禁止为凑配套而新增主件。**方向性构筑**：门窗写开向/门轴；**楼梯须写上行朝向**（走上时面朝哪一扇区）+下口/上口，**所在扇区 ≠ 上行朝向**。完整门扇/贴墙整跑梯只登记在所属扇区；邻向禁再记为第二件。**歧义控制**：一名一物；坐标≠朝向；「朝门一侧」不另生一门。
  > **⑥全覆盖**：剧情实体全入**所属**主环境清单（剧本已写或剧情必要者零遗漏）；Stage2.1再XOR裁PROP；禁两侧双出或双消失。⑥管不漏；落位服从本节**分位从简**。⑦均衡：禁过挤（尤舞台区/动线阻塞）；四面偏空可加围合；表演中央偏空=无剧情锚时的正确默认。⑧出入口：具名门/洞/巷口；禁穿墙；默认单门。
  > **衍生最小化**：须切=任何真正反打/OTS读相向对手｜切镜头致正背面档位变化｜背对须读正面内容｜越轴｜>90°｜门窗内外/POV/状态｜**异排且异向**。前向驾驶舱“异排但同向”不属于本项，按驾驶舱槽位可见性选择0°/180°/90°/270°读角。反打却同父ENV、切镜头改档却同父ENV、当前ENV槽位许可与建置不匹配均失败。
  > **同场衍生ENV积极换角（强制；管选用节奏，≠另建行）**：同一 Scene 内，**切换合理**时须**积极**按剧情推进、对白轮次、角色情绪/表情/微反应、受者响应等表现需要，改挂**已声明**的不同 `{N}度…` 衍生（含合法侧向/反打/可读角），禁止长段粘同一角。**原则上同一衍生环境名连续使用不得超过 3 个 Beat**（计连续拍；可稍后切回，但每次连续段仍≤3）。第 4 拍起须换已声明合法角；满 3 且下一拍切换合理却仍同挂=失败。**合理=**候选角 `R−W=∅` + 对向零可见 + 守轴 + 逻辑可拍 + 径向/三联闭合，且非无动机越轴、非机械轮角。**≠衍生最小化冲突**：最小化=禁另建冗余行（Insert/CU/同侧过肩且档位/扇区不变→沿用父、禁新行）；本条=已有角须轮换使用。满 3 后优先切**已声明**他角；现有角皆不能覆盖才按剧情覆盖规则补合法侧向，不得为凑换角另建无 Beat 覆盖的冗余行。**例外（须写依据，否则连续>3=失败）**：①本场总拍数≤3；②转身过程拍且轴/背景半空间未变（可同父，**计入连续次数**）；③物理上仅一合法覆盖角（标`唯一覆盖角`+R−W；优先补合法侧向而非超限粘角）；④文戏连续载具/同行位移无停顿且切角破动量——最多再+1拍。武戏快链豁免连续≤3。❌连续4+同挂且下一拍切换合理。
  > **OTS读对手 vs 同侧过肩（强制判别；防误切/漏切）**：
  | 类型 | 判定 | ENV |
  | :--- | :--- | :--- |
  | **OTS读对手 / 反打** | 镜头越过近侧肩去看**对方脸/对手可读面**；或对白轮次需换可读方；背景半空间相对上拍翻转/对向 | **必须** `ENV变=是` + 新 `{N}度…`（常±180°；`PlannedReverse`） |
  | **同侧过肩（非反打）** | 仍看**同一观察半空间**；过肩只是构图框（近侧肩入画缘），**不**换对手可读面、**不**改背景扇区、正背面档不变 | **沿用父 ENV**；禁另建；禁标反打 |
  ❌OTS读对手却同父 ENV，或把同侧过肩标成反打。
  > **本阶段产出（轻量角度 + 可见性白名单；四向美术归 Stage 3）**：每衍生行必填名/`view_angle_from_main`/触发/`spatial_axis`/`lens_profile`/`axis_crossing`/`empty_view_delta`，**以及** `活动适配`/`可见内容白名单`/`可见边界`/`不可见内容`；**头尾双锚**在主环境声明。禁止写前中后景空镜层次、材质光色细参、四向拼图成稿。
  > **方位坐标约定（全链路最高；Stage 1→2.1→3 同核）**：一律**俯视鸟瞰顺时针**。以主环境 **0°轴**（首个非航拍全局建置视角的背景方位）为原点：`0° → 顺时针+90° → 90° → +90° → 180° → +90° → 270° → +90° → 0°`；正交四向闭集=`0/90/180/270`；下一正交角公式=`(N+90)%360`；对向=`(N+180)%360`。**禁止**逆时针编号、第一人称「向左/右转」推角、把 90° 写成 0° 左侧墙。画左=`(N+270)%360`、画右=`(N+90)%360` 亦按同一俯视顺时针推算。`view_angle_from_main` 与衍生名 `{N}度…` 的 N 必须服从本约定。
  - **情节异地→新建主环境 + 闪回 Scene 分档（最高）**：
    - **默认**：一 Scene 一块【主环境】+ 其【衍生】族。**例外同场多主**：快速闪回/蒙太奇；**出入封闭舱（仓外+仓内）**。
    - **新建环境（强制；据情节判定）**：凡情节确认**不在当前主环境**（时空/地点/回忆落点与当下包络不合——原文具名、场头/空境、或剧情可核销的异地意图均可；**含上楼进入不须与一层共享外形的二层内部**，§11⑦；**含进入汽车/机舱/轿子/马车等载具内舱**，舱内与车外道路不共享外形）→ **须新建【主环境】**（完整骨架：名称｜日夜内外｜活动空间｜俯视360｜四向+中心（输入该向内容=正面面对；各向正对边界正面，四方正交，禁偏斜）｜0°轴｜头尾双锚｜固定清单）+ **对应【衍生环境】族**（含强制 `0度{该主名}`；衍生角同锁四方正交）。可据情节合理命名与建骨架；**禁止**因「原文未写全称地点」而硬挂当下主环境衍生，**禁止**把二层内部并进一层通高主环境当「上层」，**禁止**把汽车/机舱内舱并进车外道路/停靠点当「车内衍生」。同环境复用优先（§10）：上游已有同空间名→复用，勿另起同义名。
    - **出入封闭环境（最高；仓外为主、场内切仓内；一般不分场）**：汽车/机舱/轿子/马车厢/电梯轿厢等封闭舱，凡本场含**出入过程**——
      1. **当场起始主环境通常=仓外**（道路/停靠点/站台/轿外街巷等已声明主环境）；仓内另立独立【主环境】（不并进仓外当衍生）。

      2b. **出舱落点承接（最高）**：仓内过程拍经具名门扇出舱落定 → **强制另起 Beat**，触发=`出舱切主环境|回切仓外主环境`，当前ENV=`{N}度{仓外主名}`。该拍【建置】=人站在**本拍所经那一扇门**的外侧旁（车边/舱门旁，一臂可及该门），**载具外部本体整体入画**（整车/整舱可见，非只门缝/半扇）。终态锚=`{外部本体}之{具名门位}外侧旁`。**下一 Beat**（无另写走位时）【建置】必须承接该门外落点与同一扇门，禁瞬移到另一扇门、车头、路对面或裸写「车边」。仓外衍生白名单须含该外部本体+该门扇。❌出舱后仍挂仓内ENV；❌下车落到未点名的「路边」。细则 §12 多门进出。
      3. **禁标反打**；换主名≠反打。世界扇区/F 按新主 0°轴重新锚定（异地/跨舱非反打）。

      ❌开场无出入却把仓外硬塞为本场主；❌入舱后仍挂仓外衍生当当前环境写座舱戏；❌把上车拆成仓外一场+仓内一场而无时空断开依据；❌出舱后落到未点名车边/另一扇门。

        - **先判“必须可见”，禁把剧情提及都算可见**：只有画面明写主体/动作/反应/交互/挂靠/可见细节的实体才进必见集；纯声音、对白提到、角色望向画外、因果来源可标D态，不要求其本体入镜。例：马蹄声由门外传来→`大门/门外=D`，除非本拍另写看见大门/残阳；不得因场景Master含大门就把大门强塞本拍。

      - **主环境对向位零可见（最高；固定环境实体专用）**：对当前衍生观察轴 N，主环境四向中精确位于 `(N+180)%360` 的**对向边界实体及其附着/承托物**全部在机位后方，必须列入`不可见内容`，与`可见内容白名单`交集必须为∅。禁止因“写背面/侧面”“在前景”“广角”“镜头稍带到”把对向位实体塞回画面。此锁针对门、柜台、酒架、楼梯、墙面等固定边界及其上的算盘/账册/酒盏等；可移动主体仍按 N 投影表判前中后景，不因本条自动消失。
        - N=0：180°位柜台、酒架及柜台承托物全不可见；`0度大门`白名单禁出现`柜台:背面`。
        - N=180：0°位大门及门外本体全不可见；`180度柜台`的不可见内容必须至少含`大门:全部面|大门外:全部`。
        - N=90：270°位楼梯/回廊全不可见；N=270：90°位桌区/左侧梁柱全不可见。相邻±90°内容仅在衍生`可见边界`明示贴边小部分时可入白名单，绝不能整面/完整实体入镜。
        - **舱内侧向例外（最高；仅交通工具内舱 90/270）**：狭小舱体横看≠厅堂对向抹墙。机位贴一侧窗/门看向对侧窗时，**近镜头侧仍在画内**——该侧门框/窗框+该侧全部座位侧面须进白名单与`活动适配`（近镜头层），中景写其余座位，后景写对侧窗；**全部座位都要描述**（驾驶座|副驾|后排各座，有则全写并标近镜头侧|远侧）。对向零可见只约束舱**外**对向街景，**禁止**把近侧半舱座位整排进`不可见内容`、禁止 90/270 只剩一扇侧窗。用法闸 §12。
      - **内容驱动建角（最高）**：先列每个 Beat 的标准化必见实体面集合R，再为能完整覆盖R的真实机位建立对应 `{N}度…`；**禁止默认0度/Master、按0→90→180→270轮角、或习惯先写180反打**。无Beat使用的冗余角不建。已声明角须按§11「同场积极换角」轮换使用（同一衍生连续≤3）。既有主环境注入只锁坐标系与资产归属；若现有角不能覆盖R，应在同坐标系内新增合法剧情覆盖衍生或拆Beat，禁篡改既有角白名单来迁就剧情。
      - **轴线与禁越轴（最高；设计衍生时强制）**：定 0° Master 后，声明本场 `spatial_axis`（对戏/站位动作轴线，常=双方连线或主舞台长轴）。后续衍生须守轴：
        | `axis_crossing` | 何时允许 | 要求 |
        | :--- | :--- | :--- |
        | `None` | 同侧微调、非反打 Insert/CU、沿用父观察侧 | 不跨 `spatial_axis` |
        | `PlannedReverse` | **正反打/OTS 读对手**（沿轴线对向，典型 ±180°） | 触发须含两步结论 `N_对手→(N±180)%360`；左右屏关系与轴线闭合；**≠随意跳角** |
        | `MotivatedCross` | **仅**剧情明文动机越轴（揭示、追视、被迫绕行等） | 须写动机一句；禁无动机为「换个角好看」而跨轴 |
      - **禁**：无动机在轴线两侧来回跳（如对戏轴为 0↔180，却无据插入破坏左右关系的 90/270 当反打）；把越轴标成普通反打；为填满清单而建跨轴角。
    - **核销**：任一 Beat 落位/运动终点在**当前所属主环境**四向包络内找不到对应表演区或动线锚→回改该主环境或拆 Scene（§9），禁硬塞；闪回异地缺主环境块=失败。
  - **0°轴序**：①上游继承→②该主环境首个非航拍全局Beat的背景方位→③特写/航拍开场可主门/中轴预声明。多主环境各自锚定。**交通工具内舱/驾驶舱（强制）**：无上游轴时0°=载具前进向或主要驾驶观察向主景正面（汽车=挡风/仪表；飞机驾驶舱=前窗/仪表主视面；轮船驾驶台/舰桥=舰艏观察窗/主操纵台；列车司机室=前窗/司机台；轿子=轿帘；马车=马头）。禁为好看锚到侧窗；开放式多控制台以主驾驶观察向为0°，各槽位F另记。
  - **四向包络**=法定边界；越界→新Scene或（闪回/蒙太奇）另立主环境。**严禁对向串写**（0↔180、90↔270）。
  - **四向正面边界锚定（最高；输入内容=正面面对；四方基准；禁偏斜）**：0/90/180/270 四向**各自正对四周边界立面的正面**，且以**四方正交**为唯一设计基准。
    1. **输入内容即本向正面面对（强制）**：原文/场头/空境/已规划写入某向（或将落入该向）的内容，**就是该向观察轴所正对、正面面对的背景主景**——规划 0°轴与四向落位时，该向主锚须以**正面/正立面**朝向该观察轴（门扇正面、窗框正面、柜体正面、街口开口面、主墙立面等）。禁止把输入该向内容放到斜侧、墙角或写成邻向贴边冒充主景。
    2. **正对边界**：如正对门、正对窗、正对主家具立面/端面、正对街口/巷口/廊口等具名边界或主景面；立面与坐标轴正交对齐。
    3. **禁止偏斜（最高）**：禁无剧情硬核销地把主锚门/窗/家具/街口等斜置、对角斜切、斜对观察轴当「好看构图」；禁 45°/墙角/荷兰角作为主环境或衍生空镜设计角。偏斜导致该向主景面不可读、邻向误成主景。例外仅限：①原文明文斜向/对角几何；②无可正对的边界面（开阔旷野无立面）时改以道路中轴/地标轴线**正对**（仍禁无据墙角构图）。头尾双锚优先选自可正对的边界主景面。Stage 3 四向拼图与衍生截取继承本条。
    4. **衍生可见半空间（Stage 1）**：每个 `{N}度…` 须正对输入该向主景（四方正交）。白名单须能解释画左=`(N+270)%360`、画右=`(N+90)%360` 的侧向实体是贴边可见还是对向不可见。焦段与四向拼图成稿归 Stage 3。
    5. **跨角实体守恒（Stage 1 规划）**：同一具名实体在各 `{N}度` 白名单中的可见面须几何自洽（对向位不可见；邻向可贴边）。四向美术层次与拼图格成稿归 Stage 3。
  - **四向+中心实体区分（最高；主环境俯视360强制）**：【主环境】**必须**对 **0° / 90° / 180° / 270° / 中心** 五区**分别**写明该区可辨内容——**不论该区当前是否有剧情戏份**。落位服从**分位从简**；四面加件不得侵入表演中央/动线；门窗默认各一、不另开侧室、不四面同构。
    1. **有剧情区·中间/舞台区**：实体落位须配合本场动作（动线可通、站位可落、交互锚可挂）；硬核销实体优先落该区或中心表演锚。无剧情锚则中央=净空+贴地。
    2. **四面（0/90/180/270）**：须写出可辨主锚/边界立面——可贴墙家具、挂画、窗、廊口陈设等使该向不空洞、与邻向可辨；不得写「空墙/无/略」或复制他向同名同功能实体集凑数。加件落该向围合立面/贴墙，**禁止写入【中心】或侵入舞台净空/动线**。
    3. **原则上不重复或不能完全重复（服从⑤唯一性）**：各向（含中心）主锚实体集**原则上互不重复**；确须同类多件时走⑤（总个数→逐具具名+区分特征+分边/各向个数），**禁止**四面抄同一套「门+窗+桌」完全同构；对向串写仍禁。四面可各加不同贴墙件以可辨；**禁止把四面件复制进中区凑互不重复。**
    4. **地面与空中/屋顶（有则强制）**：五区描述之外，按需另写——**地面/地板**（贴地层连续、中区净空可贴地；材质/分格/收边一句即可，禁活动区堆立体物）；**空中或屋顶/天花/天空**（室内=梁架/吊顶/主灯/天窗；外景=天空/天际/檐口/树冠上层等）。有航拍/空战/上段动作/可见天顶戏份时**必写**；无剧情亦不得五区只写立面、完全省略地面与上边界（至少各一句可核销）。
    5. **成稿口径**：俯视360写法须可检索 `0度=…｜90度=…｜180度=…｜270度=…｜中心=…`（+可选 `地面=…｜空中/屋顶=…`；**通高须共享外形另须** `下层/一层=…｜上层/二层/回廊=…`，禁上层继承下层；**二层内部不共享外形则另块主环境，禁写入本块上层**）；中心服从【活动空间】净空（分位从简）。❌四向同句复制或四面空白；❌把沙发屏风摆进走位中央。
    6. **中心≠某一向立面（最高；防茶几换角蒸发）**：沙发、茶几/矮几、中央桌、岛台等位于两边界之间或主家具前方的**地面家具只写入【中心】**，**禁止**记入 0°/90°/180°/270° 某一向立面主锚。沙发可靠近某向墙，该向仍只写墙面本身（沙发本体记【中心】）。屏风可贴墙记四面。❌`0度=沙发与矮几`。Stage 3 拼图跨格守恒继承本条。
    7. **上下楼层：先判是否须共享外形（最高）**：闸门=两层空镜是否必须画进**同一张**主环境四向拼图（同一视觉体量、可互望）。
       - **须共享外形 → 一块主环境 + 分层盘点**：仅当两层通高/可互望（客栈通高大堂+二楼回廊、Loft/夹层、中庭挑空——从一层能看见上层廊/栏，从廊能俯看一层）才共享一块【主环境】。此时须**分别**写清 `下层/一层=` 与 `上层/二层/回廊/夹层=` 具名实体（各层陈设+出入口/栏杆/楼板开口+该层活动区若有戏）；楼梯标 `下口在下层｜上口在上层`；跨层可见标 `所属楼层=`。禁 `二楼同楼下` / `上层继承一层` / 只写「空中=有回廊」无廊上实体；跨层同类件走⑤（总数→具名+所属楼层+区分特征）。有戏层各写活动区；无戏层仍须可辨结构，禁敷衍空廊。复用既有通高主环境须在该 Scene 补丁中原样继承两层清单；既有稿只有一层而本场确通高→回补，禁用「继承」跳过上层。
       - **不须共享外形 → 切成两块主环境（强制；典型=二层内部）**：上楼后进入**封闭房间内部**（二层客房/账房/闺房/办公室等——关上门即独立四向包络，镜头不必与一层大堂互望、不必共用一张四向拼图）→ **必须另立第二块【主环境】**，两块**独立描述**（各有名称、0°轴、四向+中心、固定清单、衍生族），**禁止**并进一层当「上层/二层=…」。通常同时拆 Scene（§9 空断）；楼梯可留在一层作连接件，二层从房门起另立。❌把二层客房桌床写进一层大堂上层清单。
       - **风格依赖（允许；≠共享外形、≠简单继承）**：两块主环境空间骨架各自写满，但可声明 `风格依赖={另一主环境名}`——通常**二层内部挂一层/通高大堂**（同建筑气质）。只借风格（年代/材质族/色系/工艺/文学气质），**不借**四向拓扑、固定清单、0°轴、楼底、家具名。被依赖方（父）仍独立成稿、`风格依赖=无`。单向、禁环、禁互挂、禁挂 `{N}度` 衍生。无同建筑气质核销则 `风格依赖=无`。
       - **禁**：用共享主环境冒充二层内部；用「二层内部」逃避通高回廊的分层盘点；用风格依赖把两块压成一块。
  - **主环境必写**：名称｜日夜内外｜`主环境角色=…`（单主可写`当下主线`）｜**【活动空间】**｜俯视360｜**四向+中心（各区写实例化后的具体内容；禁敷衍空壳/禁完全同构；输入该向内容=正面面对；各向正对边界正面，四方正交，禁偏斜；扇区序=俯视顺时针 0→90→180→270）**｜**地面与空中/屋顶（有则写，常规至少各一句）**｜**通高须共享外形则下层+上层分列；二层内部不共享外形则另立主环境（可风格依赖另一主环境，仍独立描述）**｜0°轴（原点；后续角=`(0+90k)%360`）｜头尾双锚｜固定清单(含出入口；⑤全套；只列最终实际存在的具名实体)；不写前中后景/人物/材质细参。分位从简为内部裁决词，禁入本块实例化字段。**主环境=基准定义，永不作可拍当前环境**——Beat「当前环境」**永远**只能挂 `{N}度{名}` 衍生（Master=`0度{名}`）；**禁止**写裸主环境名作当前环境。
  - **未落清单**：`{具名}｜依据｜开场在场|待入画｜归属主环境={名}`；多主时可按主环境分节；与开场在场性/交互点名交叉核销（Beat **不**为陈设写层位，§1 空镜重述）。**场头必要道具须全部入清单或固定清单**；清单外禁止中途凭空新增；落位服从分位从简（禁为填表演中央加无核销项）。各项的**初态/变化/终态**不在本清单写七要素落位。
  - **反打ENV**：先定本拍需要的背景内容/对手可读面，再算 `N_对手→(N±180)%360` 得角；`ENV变=是`+重建；新 ENV 必须由**该衍生行自身**的`活动适配+可见内容白名单+可见边界`确认能看见所需内容。禁止回主环境套内容、机械轮角、粘错角或挂裸主环境。`axis_crossing=PlannedReverse`；非反打Insert仅在父衍生ENV白名单仍覆盖所需内容时沿用。
  - **状态衍生**：`{主}_{状态}`；continue期间后续挂该状态；状态后缀挂**所属**主环境名。**衍生的衍生** `{N}度{主}_{状态}` 每行仍须写 `所属主环境={主}`（与主名逐字符一致）。

## 成稿模板（唯一输出；逐场环境补丁）
输入每个 `SCENE_START:{scene_id}` 必须对应且仅对应一个同 ID 补丁，按输入 Scene 顺序输出。补丁之外不得输出解释、完整 Scene 或上游原文。

**环境补丁**（快速闪回/蒙太奇同场异地时可重复【主环境】块；较长回忆则在独立闪回 Scene 内单块或多块；衍生须覆盖每一主环境族）：
> 规则见 §11。成稿只交实例化标签，禁把分位从简/四方正交/禁偏斜等裁决词写入成稿。

[ENV_BLOCK_START]

【活动空间】主舞台=…｜动线=…｜站位承载=…｜出入画口=…｜舱内座向=N/A|同向舱|相对座|轿子|马车:{车型}｜司机前座=是|N/A
0度轴=…｜四向+中心：0度=…｜90度=…｜180度=…｜270度=…｜中心=…
地面=…｜空中/屋顶=…｜通高=N/A|下层=…｜上层=…｜风格依赖=无|{主环境名}

## 成稿自检（本子技能）
- 输出只有逐场 `ENV_SCENE_PATCH`；补丁数、顺序和 ID 与输入 Scene 一一对应。
- 未输出或复述场景拆分结果、Scene 正文、综合信息、特殊路由或项目视觉回填。
- 未写【位置规划】【动作空间综合】【建置】落位句、未写入戏位移、未改对白/特效/场核。
- **复用/新建**：能复用则复用；新建须有情节异地/不共享外形/内舱依据。
- 每场（每主）【主环境】+【未落清单】+【衍生】闭合；活动空间可站可动，能承载本场重点与特殊场景。
- Beat 当前环境永不挂裸主名（建置选用本文件已声明 `{N}度…`）。
- 未命中内容不输出；由程序直接保留上游权威文本。

## 完整输出结束标签（最高；缺则整份不合格）
- 交付前最后一步：全文最后一个非空行必须逐字是 `[ENVIRONMENT_PLAN_OUTPUT_END]`，全稿仅一次，无反引号、无围栏。
- 写完最后一个 `ENV_SCENE_PATCH` 后立刻换行打该标签；禁止在补丁后截断。
- 该标签不得放入任何 `ENV_SCENE_PATCH`、`ENV_BLOCK` 或代码围栏；标签后禁止任何字、标点或解释。缺该行=失败。
