## 目标（最高；本子技能工作方式）
本技能按**整集**调用，一次读完全部分拆结果。职责仅一项：
**实体分流 + 主环境骨架**：把剧本提到的实体按规则写入【主环境】固定清单或【未落清单】（未落后续作道具），并写满主环境四向/活动空间/0°轴。
**不写衍生环境、不写景别、不写构图、不写 Beat 覆盖矩阵。** 这些在文戏（含仙攻/特效）完成后、由按场衍生构图子技能根据已注入主环境确认。
只为 `复用=否` 的新建主环境写骨架；复用环境由程序从项目库按场回填，不在本文件重设计。
1. **先读每场 `SCENE_ENV_IDENT`**：只为 `复用=否｜来源=新建` 的环境写【主环境】+【未落清单】。`复用=是` 的名称只作锁名，禁止输出其骨架。全复用场不要输出补丁。输入含「待复用主环境」时，只锁该清单已注入具体信息的主环境；若写明 `待复用主环境=无`，场景拆分未标复用。
2. **全局资产必须先匹配再写骨架（最高）**：写任何【主环境】之前，必须读 `[用户选定全局环境开始]…[用户选定全局环境结束]`，把本集**需要的环境**与注入清单**逐条对照**，找出可对应项后**复用或参考**其已注入信息。写明 `用户选定全局环境=无` 则不得臆造用户指定复用源。细则见下节。
3. **无则新设计**：情节确认异地/不共享外形的功能单元/载具内舱，识别标签为新建，**且未匹配到用户选定全局环境** → 新建【主环境】+【未落清单】。
4. **只产出主环境骨架**：【主环境】【未落清单】闭合即止。不写【衍生环境】行、不写覆盖矩阵、不写角色/道具落位、不写【建置】画面句、不写入戏位移、不写景别/构图。
5. **禁止透传完整上游**：不得输出 `[SCENES_BLOCK_START/END]`、`COMPREHENSIVE_INFO`、`SPECIAL_SCENE_ANALYSIS`、`SCENE_ENV_IDENT`、`SCENE_START/END`、`SCENE_CONTENT`、原对白/场核/正文或 `project_visual_backfill`。这些内容由程序保留；本技能重复输出即失败。
6. **综合信息只读使用、不输出**：输入若含 `[COMPREHENSIVE_INFO_START]`…`[COMPREHENSIVE_INFO_END]`，可读取其世界观、整体简介、人物简介作为环境核销语境，但不得在结果中复制、移动或改写。
7. **项目级与路由元数据只读使用、不输出**：可读取 `SPECIAL_SCENE_ANALYSIS`、`SCENE_ENV_IDENT` 与 `project_visual_backfill` 作为环境承载依据，但输出中不得出现这三类包裹或 JSON。
8. **场级指导强制承载**：读取【卖点综合】`指导=`与【叙事综合】贯穿信息。凡 `细节特写参考` 或 `贯穿保护` 涉及环境、道具、文字/线索载体，必须进入主环境固定清单或未落清单；为 `反馈特写参考` 保留可同显的角色活动空间，为 `运镜参考` 保留可揭示、逼近、跟随、拉开或停留的连续可见空间。只提供主环境承载条件，不在本文件写衍生白名单或镜头执行。
9. **结束标签硬闸**：全部须新建场的补丁写完后，全文最后一行必须是 `[ENVIRONMENT_PLAN_OUTPUT_END]`，缺则失败。
10. **不拆场**：本文件一次处理整集，禁止只交单场或要求程序再按场重调。同场闪切/短闪回的多个新建主环境写在同一场补丁内。

## 通用硬约束（各子技能同锁；最高）
1. **忠于上游 + 未命中不输出**：不改事实/因果；禁新增改因果事件。非环境内容只读，禁止复制到补丁。
2. **原文信息零丢失 + 禁虚化（最高）**：环境文学/地名/固定实体须**原样写入**成稿可检索落点。**禁止**用「同原文／按原文／见原文／原文如此／照原文／如上／略／大意／照旧／不赘述」等虚化代替原文环境句或专名。
3. **专名逐字**：环境注册名与原文或上游**逐字一致**；同环境名复用。
4. **对白保真**：本文件不改台词。
5. **逻辑合理可拍**：活动空间可站可动可出入；四向正交；禁把内舱并进仓外当衍生。
6. **禁实拍执行语**。
7. **下游边界**：禁代写分镜处方。
8. **只锁环境**：不得借「设计环境」改写对白/特效/建置几何。

## 1. Scene 与环境（复用 / 新设计）
> 完整口径 §9–§11、§16；下文流程速查。
- **用户选定全局环境匹配（强制；写骨架前完成）**：
  1. **先读注入块**：`[用户选定全局环境开始]…[用户选定全局环境结束]`。写明 `用户选定全局环境=无` → 本集无用户指定全局环境，禁止把项目库未勾选项或自拟名当成「用户选定」。
  2. **列出需要的环境**：每场 `SCENE_ENV_IDENT` 的名称 + 情节确认的空间（异地/舱内/二层内部等）。这是待匹配的「需要侧」。
  3. **逐条对照注入清单**：对每一个需要的环境，在用户选定清单里找可对应项。命中任一即可：注册名逐字相同；同空间别称/地名/功能单元对应（如「客栈大堂」↔ 注入「客栈大堂」）；摘要所写空间类型与本场活动包络同一处（厅堂/街市/舱内等），且不与另一注入项抢占。
  4. **命中后必须用注入信息，禁止另起同义空壳**：
     - 该场 `SCENE_ENV_IDENT` 已标 `复用=是` → **只锁资产注册名**，不输出其【主环境】骨架（程序回填）。
     - 该场标 `复用=否｜来源=新建` → **仍须参考**注入的名称、摘要来写本场主环境骨架：主名优先用资产注册名（勿另起近义新名）；活动空间/固定实体/0°轴气质服从摘要。已有衍生名只作后续构图节点参考，本文件不写衍生行。
  5. **未命中才新建**：需要的环境在清单中找不到对应项 → 按新建写骨架。未用上的勾选资产**不要**硬塞进无关场。
  - ❌忽略已注入全局环境另起同义主名；❌未对照就按「感觉像」新建；❌把未对应资产摊进每场；❌`=无` 时臆造用户选定复用。
- **流程（止于主环境骨架锁定；整集一次）**：按输入 Scene 顺序读每场 `SCENE_ENV_IDENT`，并完成本节「用户选定全局环境匹配」。`复用=是` → 只锁名称，不输出该主环境骨架。`复用=否` 且已匹配到全局资产 → 按注入信息写主环境骨架（参考，非另起空壳）。`复用=否` 且未匹配 → 定需求（须覆盖该场重点、空镜位、打斗/空域活动）→【主环境】新设计 →【未落清单】闭合。全复用场不出补丁。本文件不写衍生行、落位朝向、建置句。
9. **空间闸（本文件）**：本文件**不裁定** Scene 切分（原场可否细分服从输入已切场次）。只锁主环境骨架：动作越四向包络、真正异地/进入不共享外形的功能单元 → 另立【主环境】；出入封闭舱一般仍同场多主；二层内部不共享外形 → 另立主环境。换观察侧、反打、特写、情绪/气氛微调、同空间走位 → **不另立主环境**（衍生/景别归后续构图节点）。景别/特写不是环境。
10. **环境定义（§11）**：空镜骨架+具名出入口；变化主体→环境、动作→后续 Beat。**同环境复用（最高）**：上游同空间名或已匹配的用户选定全局环境→主名**逐字复用**；日夜不同不另起名；仅无上游、未匹配全局资产且硬需才新建。因剧本而生；**先定本场活动空间再落实体**；**分位从简**见 §11 不变式（成稿禁写规则原句）。**交通工具内舱（汽车/机舱/轿子/马车等）一般为独立主环境，出入封闭以仓外为起始、场内切仓内，按载具类型惯例锁座向，汽车等司机在前排驾驶座，禁套厅堂围坐**（§11/§12）；禁装饰扩写；每场【主环境】+【未落清单】齐全（多主环境时每主各齐）；无人像；禁材质光色细参。**上下楼层先判是否须共享外形**（通高可互望→一块主环境并分层盘点；**二层内部等不共享外形→切成两块主环境，独立描述，可风格依赖**；§11 四向+中心⑦）。**主环境=原文初始建立态**（场头/空境/开场），禁用后文剧情终态改写基准（§7）。**环境描写：可简约、禁破旧倾向（强制）**——【主环境】/服化道「环境细节」/空镜建立句可写素净、少陈设、留白净空；**禁止**无原文/剧情硬核销时主动加破烂、破败、残墙剥落、霉渍油污、裂缝狼藉等破旧语汇；简单≠破旧；张力用光色/空寂/秩序，禁用脏乱破烂代替。**原文软性评价词保真**：精致/高贵/华贵/素净等须进【主环境】文学或固定清单定语，禁删或改成「好看」。
  - **上游/既有主环境注入→坐标锁（有则强制）**：既有主环境仅锁0°轴、世界拓扑、四向实体归属、固定清单与活动空间。禁止重映射/旋转坐标系。衍生行与选角不在本文件。
11. **主环境 / 未落清单（四向美术归 Stage 3）**
  > **不变式**：**主环境骨架与服化道「环境细节」锁定原文初始态**——剧情造成的破损/狼藉/域场改写/日夜突变等不得回填进【主环境】固定清单或初始摘要；须走新主环境（过程改写归站位；是否新起 Scene 服从输入已切场次，本文件不改判）。
  > **分位从简（最高；内部裁决；成稿禁写规则原句）**：①**四面允许加围合陈设**（贴墙柜/挂画/窗沿/靠边屏风；门窗默认各一、不另开侧室、不四面同构、加件不侵表演中央）；②**中间/舞台区按剧情需要**（表演中央只收剧本明确或硬核销锚+贴地层；无锚则留空≠失败）；③**靠边常用配置允许**（沙发/屏风/边柜及该类型配套须靠边/贴墙，前方留主舞台净空；无该类型依据不加）；④成稿只写实际采用的具名实体+具体扇区/靠向/净空，**禁止**把「分位从简/四面允许/中间按需/靠边配置允许」写入【主环境】/活动空间/固定清单。⑥管不漏；从简管落位。他处只写指针。
  > **⑤唯一性 + 数量闭合（最高）**：默认每功能实体**在所属主环境内**1具；**门/窗/楼梯默认唯一**；多件→总个数→逐具具名+区分特征。**通高两层**：一层件≠二层件，须标 `所属楼层` 并分列具名，禁「上层继承下层」。**桌形制须匹配名称**：有长轴（门↔梯/对坐长案）须写 `长方桌/条案` 并锁 `长轴 + 两端具名锚 + 长:宽`，禁用正方形桌名驱动长短换面。⑤-b同质≥2须分边/各向个数+朝向+同侧顺序。**固定实体清单与主环境中禁用 `若干|数把|多张|一些|成排|散座` 等模糊数量词**；须改写为 `总数 + 分桌/分边个数 + 逐具朝向 + 同侧顺序`，总数=分项之和。窗/窗棂除总扇数外，每扇须写所属扇区、开闭态、横×纵格阵与同墙顺序。上游未给数量时规划层须裁定**一个明确可拍数量**，不得下传不确定性。⑤-c配套：桌↔椅｜床↔被枕｜杯↔盏托。**配套只补已入清单主件的配件**；禁止为凑配套而新增主件。**方向性构筑**：门窗写开向/门轴；**楼梯须写上行朝向**（走上时面朝哪一扇区）+下口/上口，**所在扇区 ≠ 上行朝向**。完整门扇/贴墙整跑梯只登记在所属扇区；邻向禁再记为第二件。**歧义控制**：一名一物；坐标≠朝向；「朝门一侧」不另生一门。
  > **⑥全覆盖**：剧情实体全入**所属**主环境清单（剧本已写或剧情必要者零遗漏）；Stage2.1再XOR裁PROP；禁两侧双出或双消失。⑥管不漏；落位服从本节**分位从简**。⑦均衡：禁过挤（尤舞台区/动线阻塞）；四面偏空可加围合；表演中央偏空=无剧情锚时的正确默认。⑧出入口：具名门/洞/巷口；禁穿墙；默认单门。
  > **方位坐标约定（全链路最高；Stage 1→2.1→3 同核）**：一律**俯视鸟瞰顺时针**。以主环境 **0°轴**（首个非航拍全局建置视角的背景方位）为原点：`0° → 顺时针+90° → 90° → +90° → 180° → +90° → 270° → +90° → 0°`；正交四向闭集=`0/90/180/270`；下一正交角公式=`(N+90)%360`；对向=`(N+180)%360`。**禁止**逆时针编号、第一人称「向左/右转」推角、把 90° 写成 0° 左侧墙。画左=`(N+270)%360`、画右=`(N+90)%360` 亦按同一俯视顺时针推算。后续衍生名 `{N}度…` 的 N 必须服从本约定；本文件只锁 0°轴与四向，不写衍生行。
  - **情节异地→新建主环境 + 闪回 Scene 分档（最高）**：
    - **默认**：一 Scene 一块【主环境】。**例外同场多主**：快速闪回/蒙太奇；**同场闪切/较短出去再回来**；**出入封闭舱（仓外+仓内）**。
    - **新建环境（强制；据情节判定）**：凡情节确认**不在当前主环境**（时空/地点/回忆落点与当下包络不合——原文具名、场头/空境、或剧情可核销的异地意图均可；**含上楼进入不须与一层共享外形的二层内部**，§11⑦；**含进入汽车/机舱/轿子/马车等载具内舱**，舱内与车外道路不共享外形）→ **须新建【主环境】**（完整骨架：名称｜日夜内外｜活动空间｜俯视360｜四向+中心（输入该向内容=正面面对；各向正对边界正面，四方正交，禁偏斜）｜0°轴｜头尾双锚｜固定清单）。可据情节合理命名与建骨架；**禁止**因「原文未写全称地点」而硬挂当下主环境，**禁止**把二层内部并进一层通高主环境当「上层」，**禁止**把汽车/机舱内舱并进车外道路/停靠点。同环境复用优先（§10）：上游已有同空间名或已匹配用户选定全局环境→复用/参考注入信息，勿另起同义名。衍生族由后续构图节点按本场主环境声明。
    - **出入封闭环境（最高；仓外为主、场内切仓内；一般不分场）**：汽车/机舱/轿子/马车厢/电梯轿厢等封闭舱，凡本场含**出入过程**——
      1. **当场起始主环境通常=仓外**（道路/停靠点/站台/轿外街巷等已声明主环境）；仓内另立独立【主环境】（不并进仓外）。
      2. **仓外主环境固定清单须含载具外部本体+各具名门扇**；仓内主环境按载具惯例写座舱（汽车等司机在前排驾驶座）。触发名与衍生白名单由后续构图节点声明。
      3. **换主名≠反打**。世界扇区按新主 0°轴重新锚定（异地/跨舱非反打）。
      4. **一般不另起 Scene**（出入=同场连贯戏，对齐 1f）。
      5. **例外**：①整场开场即在仓内、无出入过程 → 仓内可为当场唯一主环境；②入舱后仓内戏已与仓外时空断开且后续只在仓内（如长途车内对白另场）→ 可另场、该场仓内独主；③二层内部封闭房间仍按§11⑦通常拆 Scene（≠本条上车入舱）。
      ❌开场无出入却把仓外硬塞为本场主；❌把内舱并进仓外；❌仓外固定清单缺外部本体或门扇；❌把上车拆成仓外一场+仓内一场而无时空断开依据。
    - **快速闪回 / 蒙太奇 / 同场闪切（空间侧）**：若输入已判同场快闪、同场闪切或较短出去再回来，本文件在**当前 Scene** 声明多块【主环境】（当下 + 各快闪/闪切/出去落点）。蒙太奇每落点各一主环境，禁单主四向硬塞多地。较短出去段不得假设已被拆成独立 Scene。
    - **较长回忆片段（空间侧）**：若输入已拆独立闪回 Scene，本文件为该闪回场写自有【主环境】；禁把长回忆硬塞进当下 Scene 多主环境凑合。本文件不写 OT。
    - **标注**：每块主环境写`主环境角色=当下主线|仓外|仓内|闪回|蒙太奇片段{序号}|回切锚`（**禁**在角色/场注中自拟「三年前/童年/N年前」等字幕）；同场多主时在补丁中列主环境清单。
    - **切主环境（同场快闪/蒙太奇/出入封闭舱）**：本文件只声明多块主环境。触发名、衍生行、建置句由后续构图/站位节点执行。世界扇区 **按新主环境 0°轴重新锚定**（异地/跨舱非反打）。
    - **禁**：①用当下主环境冒充异地/舱内；②把异地或舱内写成当下的状态改写；③长回忆场缺独立【主环境】；④快闪/蒙太奇落点缺主环境块；⑤出入封闭舱误拆成仓外/仓内两场（无时空断开依据）——本文件不改判 Scene 切分；⑥仓外固定清单缺载具外部本体或具名门扇。无情节纯质感切片且情节未要求可读空间→可不另立主环境；一旦情节确认异地可读空间→须建（同场快闪块或长回忆 Scene）。
  - **剧本活动空间（最高；主环境强制）**：环境描述**须因剧情活动而生**——规划【主环境】前须通读本场情节需求（站位人数、对峙/围坐、追逐逃窜、跪拜、出入画、群演簇位、武戏位移等），使空间**可站、可动、可出入、可分组**；上游 ENV_BLOCK 已写活动空间要点时须继承并展开。禁只堆陈设导致无表演区。落位服从**分位从简**。空旷失败仅当本场硬核销动作无处落点（缺必须的门/桌/承托面）；表演中央无多余家具而留净空≠失败。多主环境时**逐主**通读其所属情节。
    - **场头必要锁定（最高；写骨架时先锁定）**：先出**必要活动空间四项** + **必要道具/陈设**（硬核销具名物入清单）+ **空间位置关系**（与四向归属一致）。**必要=剧本明确写出，或本场剧情硬核销必须用到**。落位服从**分位从简**。锁定后本场内**环境骨架与空间位置关系不得无因改写**——禁中途把门从 180° 挪到 0°、禁桌与门对调、禁活动区换边、禁拍中凭空多门多桌。剧情打碎/挪动/携入须有可拍过程且只改该物；未受力实体相对保持场头锁定。上游已锁 → **原样继承**（禁把靠边常用件搬进表演中央）。整体环境状况改写：状态衍生/新主环境骨架走本文件；是否新起 Scene 服从输入已切场次，本文件不改判。
    - **角色与未落实体位置规划**：本文件只保证活动空间能容纳本场站位需求，**不写**【位置规划】块，不写初态/变化/终态落位。
    - **活动区禁布（分位从简之中间/靠边）**：表演中央禁无核销立体障碍；例外=贴地层｜硬核销表演锚｜靠边常用配置。其余实体落四面边缘。禁为「不空」把墙边件搬进中央。
    - **主环境须明文写【活动空间】**（紧接名称/日夜后，一段短句，禁省略）：①**主舞台/表演区**（中区净空，可供对峙/对白/跪拜等，**区内无装饰性立体物件**）；②**动线**（走动/逃跑/追逐可通行，禁被固定实体堵死）；③**站位承载**（本场高峰同框人数与分区，如双人门前对峙+随从两侧跪地；有桌则座次区；**交通工具内舱按载具惯例写同向座舱或对座排**，§12）；④**出入画口**（具名门/洞如何服务进出剧情）；⑤与⑦均衡咬合（活动区净空+禁无据家具障碍）。
    - **交通工具内舱=独立主环境（最高；按类型惯例，禁随意设计）**：汽车内、客舱、**任何驾驶舱/操纵舱**（飞机驾驶舱、轮船驾驶台/舰桥、列车司机室、工程机械/航天器驾驶舱等）、轿子、马车厢、船舱、火车车厢等一般为独立【主环境】，禁止并进舱外环境。出入封闭舱仍仓外起始、本场切仓内。**前向驾驶舱**须先锁真实舱型、0°主要驾驶观察向、前向操纵位与后方槽位；司机/飞行员/舵手/操纵员在前向操纵区，后方人员不得写到操纵员与前窗/驾驶台之间。开放式舰桥/多控制台按真实槽位逐人锁F，禁套汽车排座或无据全员同向。细则见§12「交通工具内舱」。
    - **有内部环境的载具/机甲必须另登记外部本体（最高；内外双资产、非重复）**：凡汽车、列车、舰船、飞行器、工程机械、机甲、移动堡垒等已建立`驾驶舱/客舱/操纵舱/机甲驾驶室/内部空间`主环境，必须同时在场级清单中具名登记其**完整外部形象本体**，禁止只设计舱内而让整车/整机/整甲外观缺席。两者是绑定但不同的资产面：`内部主环境={舱内名}｜外部本体={外部名}｜host_exterior={外部名}｜interior_env={舱内名}`。
      - **外部本体→PROP（默认）**：整车/整机/整甲作为可移动、可驾驶、可交互的完整物体出现在道路、机库、战场、天空等另一主环境中；即使本场只拍舱内，只要上游已明确该载具/机甲存在，也须列为待提取外部本体。
      - **外部本体→ENV（仅场景尺度）**：甲板、舰体表面、机甲外壳平台、车顶/翼面等外部本体自身就是可站立、走位、战斗或建置镜头的场景空间，且须按环境四向/活动空间设计时，外部形象作为独立主环境或环境实体；禁同时再建同一外部本体 PROP。
      - **XOR边界**：`舱内ENV`与`外部本体PROP/ENV`不是同一视觉资产重复，可并存；但外部本体自身只能在 PROP/ENV 二选一。舱内固定座椅/仪表不回填到外部本体，外壳轮廓/车型/机型/甲型/舱门窗位/主色材质须内外绑定一致。若原文未给具体型号或外形，保留泛型与缺口，禁臆造品牌型号。
    - **动作空间与角色距离评估**：本文件只把净空写入【活动空间】；不写场级【动作空间综合】与 Beat 起止重评。
    - **核销**：情节落位/运动终点在所属主环境四向包络内找不到对应表演区或动线锚→回改该主环境（是否拆 Scene 服从输入已切场次）；闪回异地缺主环境块=失败。衍生白名单与选角不在本文件。
  - **0°轴序**：①上游继承→②该主环境首个非航拍全局Beat的背景方位→③特写/航拍开场可主门/中轴预声明。多主环境各自锚定。**交通工具内舱/驾驶舱（强制）**：无上游轴时0°=载具前进向或主要驾驶观察向主景正面（汽车=挡风/仪表；飞机驾驶舱=前窗/仪表主视面；轮船驾驶台/舰桥=舰艏观察窗/主操纵台；列车司机室=前窗/司机台；轿子=轿帘；马车=马头）。禁为好看锚到侧窗；开放式多控制台以主驾驶观察向为0°，各槽位F另记。
  - **四向包络**=法定边界；越界→新Scene或（闪回/蒙太奇）另立主环境。**严禁对向串写**（0↔180、90↔270）。
  - **四向正面边界锚定（最高；输入内容=正面面对；四方基准；禁偏斜）**：0/90/180/270 四向**各自正对四周边界立面的正面**，且以**四方正交**为唯一设计基准。
    1. **输入内容即本向正面面对（强制）**：原文/场头/空境/已规划写入某向（或将落入该向）的内容，**就是该向观察轴所正对、正面面对的背景主景**——规划 0°轴与四向落位时，该向主锚须以**正面/正立面**朝向该观察轴（门扇正面、窗框正面、柜体正面、街口开口面、主墙立面等）。禁止把输入该向内容放到斜侧、墙角或写成邻向贴边冒充主景。
    2. **正对边界**：如正对门、正对窗、正对主家具立面/端面、正对街口/巷口/廊口等具名边界或主景面；立面与坐标轴正交对齐。
    3. **禁止偏斜（最高）**：禁无剧情硬核销地把主锚门/窗/家具/街口等斜置、对角斜切、斜对观察轴当「好看构图」；禁 45°/墙角/荷兰角作为主环境或衍生空镜设计角。偏斜导致该向主景面不可读、邻向误成主景。例外仅限：①原文明文斜向/对角几何；②无可正对的边界面（开阔旷野无立面）时改以道路中轴/地标轴线**正对**（仍禁无据墙角构图）。头尾双锚优先选自可正对的边界主景面。Stage 3 四向拼图与衍生截取继承本条。
    4. **四方正交留给后续衍生**：后续 `{N}度…` 须正对输入该向主景。本文件只锁四向主锚正面，不写衍生白名单。焦段与四向拼图成稿归 Stage 3。
  - **四向+中心实体区分（最高；主环境俯视360强制）**：【主环境】**必须**对 **0° / 90° / 180° / 270° / 中心** 五区**分别**写明该区可辨内容——**不论该区当前是否有剧情戏份**。落位服从**分位从简**；四面加件不得侵入表演中央/动线；门窗默认各一、不另开侧室、不四面同构。
    1. **有剧情区·中间/舞台区**：实体落位须配合本场动作（动线可通、站位可落、交互锚可挂）；硬核销实体优先落该区或中心表演锚。无剧情锚则中央=净空+贴地。
    2. **四面（0/90/180/270）**：须写出可辨主锚/边界立面——可贴墙家具、挂画、窗、廊口陈设等使该向不空洞、与邻向可辨；不得写「空墙/无/略」或复制他向同名同功能实体集凑数。加件落该向围合立面/贴墙，**禁止写入【中心】或侵入舞台净空/动线**。
    3. **原则上不重复或不能完全重复（服从⑤唯一性）**：各向（含中心）主锚实体集**原则上互不重复**；确须同类多件时走⑤（总个数→逐具具名+区分特征+分边/各向个数），**禁止**四面抄同一套「门+窗+桌」完全同构；对向串写仍禁。四面可各加不同贴墙件以可辨；**禁止把四面件复制进中区凑互不重复。**
    4. **地面与空中/屋顶（有则强制）**：五区描述之外，按需另写——**地面/地板**（贴地层连续、中区净空可贴地；材质/分格/收边一句即可，禁活动区堆立体物）；**空中或屋顶/天花/天空**（室内=梁架/吊顶/主灯/天窗；外景=天空/天际/檐口/树冠上层等）。有航拍/空战/上段动作/可见天顶戏份时**必写**；无剧情亦不得五区只写立面、完全省略地面与上边界（至少各一句可核销）。
    5. **成稿口径**：俯视360写法须可检索 `0度=…｜90度=…｜180度=…｜270度=…｜中心=…`（+可选 `地面=…｜空中/屋顶=…`；**通高须共享外形另须** `下层/一层=…｜上层/二层/回廊=…`，禁上层继承下层；**二层内部不共享外形则另块主环境，禁写入本块上层**）；中心服从【活动空间】净空（分位从简）。❌四向同句复制或四面空白；❌把沙发屏风摆进走位中央。
    6. **中心≠某一向立面（最高；防茶几换角蒸发）**：沙发、茶几/矮几、中央桌、岛台等位于两边界之间或主家具前方的**地面家具只写入【中心】**，**禁止**记入 0°/90°/180°/270° 某一向立面主锚。沙发可靠近某向墙，该向仍只写墙面本身（沙发本体记【中心】）。屏风可贴墙记四面。❌`0度=沙发与矮几`。Stage 3 拼图跨格守恒继承本条。
    7. **上下楼层：先判是否须共享外形（最高）**：闸门=两层空镜是否必须画进**同一张**主环境四向拼图（同一视觉体量、可互望）。
       - **须共享外形 → 一块主环境 + 分层盘点**：仅当两层通高/可互望（客栈通高大堂+二楼回廊、Loft/夹层、中庭挑空——从一层能看见上层廊/栏，从廊能俯看一层）才共享一块【主环境】。此时须**分别**写清 `下层/一层=` 与 `上层/二层/回廊/夹层=` 具名实体（各层陈设+出入口/栏杆/楼板开口+该层活动区若有戏）；楼梯标 `下口在下层｜上口在上层`；跨层可见标 `所属楼层=`。禁 `二楼同楼下` / `上层继承一层` / 只写「空中=有回廊」无廊上实体；跨层同类件走⑤（总数→具名+所属楼层+区分特征）。有戏层各写活动区；无戏层仍须可辨结构，禁敷衍空廊。复用既有通高主环境须在该 Scene 补丁中原样继承两层清单；既有稿只有一层而本场确通高→回补，禁用「继承」跳过上层。
       - **不须共享外形 → 切成两块主环境（强制；典型=二层内部）**：上楼后进入**封闭房间内部**（二层客房/账房/闺房/办公室等——关上门即独立四向包络，镜头不必与一层大堂互望、不必共用一张四向拼图）→ **必须另立第二块【主环境】**，两块**独立描述**（各有名称、0°轴、四向+中心、固定清单），**禁止**并进一层当「上层/二层=…」。通常同时拆 Scene（§9 空断）；楼梯可留在一层作连接件，二层从房门起另立。❌把二层客房桌床写进一层大堂上层清单。
       - **风格依赖（允许；≠共享外形、≠简单继承）**：两块主环境空间骨架各自写满，但可声明 `风格依赖={另一主环境名}`——通常**二层内部挂一层/通高大堂**（同建筑气质）。只借风格（年代/材质族/色系/工艺/文学气质），**不借**四向拓扑、固定清单、0°轴、楼底、家具名。被依赖方（父）仍独立成稿、`风格依赖=无`。单向、禁环、禁互挂。无同建筑气质核销则 `风格依赖=无`。
       - **禁**：用共享主环境冒充二层内部；用「二层内部」逃避通高回廊的分层盘点；用风格依赖把两块压成一块。
  - **主环境必写**：名称｜日夜内外｜`主环境角色=…`（单主可写`当下主线`）｜**【活动空间】**｜俯视360｜**四向+中心（各区写实例化后的具体内容；禁敷衍空壳/禁完全同构；输入该向内容=正面面对；各向正对边界正面，四方正交，禁偏斜；扇区序=俯视顺时针 0→90→180→270）**｜**地面与空中/屋顶（有则写，常规至少各一句）**｜**通高须共享外形则下层+上层分列；二层内部不共享外形则另立主环境（可风格依赖另一主环境，仍独立描述）**｜0°轴（原点；后续角=`(0+90k)%360`）｜头尾双锚｜固定清单(含出入口；⑤全套；只列最终实际存在的具名实体)；不写前中后景/人物/材质细参。分位从简为内部裁决词，禁入本块实例化字段。**主环境=基准定义，永不作可拍当前环境**——后续构图节点才声明 `{N}度{名}` 衍生。
  - **未落清单**：`{具名}｜依据｜开场在场|待入画｜归属主环境={名}`；多主时可按主环境分节。**场头必要道具须全部入清单或固定清单**；清单外禁止中途凭空新增；落位服从分位从简（禁为填表演中央加无核销项）。各项的**初态/变化/终态**不在本清单写七要素落位。
16. **三步开场（环境侧）**：空镜骨架/环境文学落点本文件锁进【主环境】。本文件不写吸睛→建置→入戏的画面句，不写服化道首落/静物预排布几何。
17. **实体覆盖（环境侧）**：全局场景/环境注册名进【主环境】（与上游逐字一致）。全局道具进【未落清单】并标`全局性道具=是`。本文件不写角色排期、开场在场几何或【实体覆盖】块（归站位）。
  - **上游全局实体→环境骨架明文（最高硬约束）**：输入（原剧本/分集正文/类型执行摘要/项目信息/Characters·Props·Environments/Applied Entities/Continuity·Carry/服化道等）**明文**将该道具/环境定位为全局/贯穿/跨集/全剧级，且本 Scene **剧情涉及**（持用｜挂场｜Carry 触达｜Continuity 入→事→出）→ 必须在本场环境骨架中**具名明文**写出。下游 Stage 2.1 凭场级明文提取（尤其全局性道具强制提 PROP）。
    - **明文证据（任一即命中；禁臆造「感觉像全局」）**：`全局性道具`｜`全局道具`｜`贯穿道具`｜`跨集道具/环境`｜`全剧道具/场景`｜`系列核心道具`｜`主场景`/`#复用` 全局环境注册｜项目/集纲/台账等价标签（如`道具类型=全局`、`scope:global`、`global_prop`/`global_env`）；或明文「贯穿全剧/多集复用/全片核心」且具名该实体。未达明文 → 不得自称全局。
    - **落点分工（环境侧；本场涉及则缺一不可）**：
      | 实体类 | 本文件必写落点 | 禁 |
      | :--- | :--- | :--- |
      | **全局道具** | 【未落环境实体清单】具名+依据+开场在场\|待入画+`全局性道具=是` | 只进 Beat 交互句而无清单明文；埋进 ENV 陈设不标全局；因「本场戏少」省略 |
      | **全局场景/环境** | 【主环境】名称与上游注册名**逐字一致**；上游已有气质/活动空间/固定实体线索→进主环境骨架（空镜，无人名）；同环境复用§10 | 只换近义主环境名；ENV 空壳只挂地名；本场用全局环境却不写【主环境】块 |
      | **全局角色** | 本文件不写 | 不得借环境骨架排角色在场/待入画 |
    - **成稿自检**：本场涉及的全局道具可在【未落清单】逐字检索并标`全局性道具=是`；全局环境可在【主环境】名称逐字检索。角色排期由站位【实体覆盖】承接。

## 成稿模板（唯一输出；整集环境补丁）
按输入 Scene 顺序，只为含 `复用=否` 新建环境的场输出补丁；全复用场不输出。每个须输出的 `scene_id` 必须对应且仅对应一个同 ID 补丁。补丁之外不得输出解释、完整 Scene 或上游原文。

**环境补丁**（快速闪回/蒙太奇同场异地时可重复【主环境】块；较长回忆则在独立闪回 Scene 内单块或多块）：
> 规则见 §11。成稿只交实例化标签，禁把分位从简/四方正交/禁偏斜等裁决词写入成稿。禁写【衍生环境】与覆盖矩阵。

## 成稿自检（本子技能）
- 输出只有须新建场的 `ENV_SCENE_PATCH`；补丁顺序与输入 Scene 一致，未拆成多次调用。
- 未输出或复述场景拆分结果、Scene 正文、综合信息、`SCENE_ENV_IDENT`、特殊路由或项目视觉回填。
- 未写【衍生环境】【Beat→衍生ENV剧情覆盖矩阵】【位置规划】【动作空间综合】【实体覆盖】【建置】落位句、未写景别/构图、未改对白/特效/场核。
- **只设计新建**：未重画 `复用=是` 的项目库/上集主环境；全复用场未出补丁。输入写明 `待复用主环境=无` 时未臆造复用名。
- **全局资产已匹配**：已读用户选定全局环境块；需要的环境能对应注入项时，已复用锁名或参考其摘要写主环境骨架，未另起同义空壳。写明 `用户选定全局环境=无` 时未臆造用户选定源；未把无关勾选资产硬塞进不需要的场。
- 每场（每主）【主环境】+【未落清单】闭合；活动空间可站可动，能承载本场重点与特殊场景。
- 主环境永不作可拍当前环境。
- 未命中内容不输出；由程序直接保留上游权威文本。

## 完整输出结束标签（最高；缺则整份不合格）
- 交付前最后一步：全文最后一个非空行必须逐字是 `[ENVIRONMENT_PLAN_OUTPUT_END]`，全稿仅一次，无反引号、无围栏。
- 写完最后一个须新建场的 `ENV_SCENE_PATCH` 后立刻换行打该标签；禁止在补丁后截断。
- 该标签不得放入任何 `ENV_SCENE_PATCH`、`ENV_BLOCK` 或代码围栏；标签后禁止任何字、标点或解释。缺该行=失败。
