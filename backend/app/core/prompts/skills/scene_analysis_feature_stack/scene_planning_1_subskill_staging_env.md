## 目标

按**单场**调用。输入已含【主环境】【未落清单】【衍生环境】、【主体定位方案】【Beat主体定位】、各拍【取景锁定】（含拍摄键 + `选择证据=` + `[DERIVED_ENV:]`），以及文戏/武戏过程。
已锁拍摄与已锁起始帧是开拍条件。本文件把**拍摄键写入【建置】**，把朝向 / 走位 / 落点变化写入【入戏】，推导与连续性写入场级【场记分析】。场头只写短【实体覆盖】+ 场级【场记分析】。禁另起【位置规划综合】【角色位置】【未落实体位置】【观察视角与空间建置】【动作空间综合】【露脸冲突】；输入若仍有覆盖矩阵 / 【Beat景别构图方案】 / 拍内【场记分析】则透传或并入后删除，不新写。
1. **连续性（核心）**：动作链无跳步；**【建置】=动作前**（≡上拍终态/速查；本拍入戏才发生的转身/走位不进建置，新朝向只进本拍终态，**下拍建置才更新**）。开拍站位 ≡ 上拍速查（无走位则 `所在侧`/锚/姿态不变）。**建置名单 = 本拍【Beat主体定位】`可见性=V`**，对照上下拍已锁可见性：不缺 V、不多出未锁为 V 者、不得自造 `X`。ENV 变不瞬移：取上拍速查 `所在侧` 查 §7A（细则 §5 / §7A）。相对锚名+辅边位/面向/姿态/`所在侧` 不变，近/远对调，左右改查**新 ENV 画幅锚实体**，禁为查表改填前中后景；对向 180° 走换档表，邻档 90° 只换左右面。绝对重写层位+新 ENV 左右实体+高低；封闭**世界槽位守恒**（`排=第N排`/`座=`第K/`功能=`不改），只把「画左起」改查新 ENV 画幅锚。围桌抄上游 `辅=`+`座=该侧第K/M`。执行已锁 XOR，不改方式。角色组按上游 `序`/`朝向`/`距` 写组内相对。同锚/同格执行上游 `同簇相对=` 的**本拍投影**（画幅/高低/纵深），禁抄【主体定位方案】0° 锁的画左词到 180°/90° 建置。站位/走位守 `spatial_axis`。禁角度坐标（`所在侧=` 闭集除外）。
2. **走位核对与细化（核心）**：据已锁 ENV / 景别 / 活动空间 / 轴线，核本拍走位是否可拍且不越轴（净空、不穿障、步幅、门径向、触达一臂、终点仍被白名单覆盖、路径不跨轴线）。**先评直线开拍→终点有无障碍**（固定大件/柱/人/门扇）；有则 `经=` 须写绕过哪件、从该件`画左|画右|近镜头|远镜头`哪侧，直线穿障=失败。再把路径写清：`{名}:自{开拍}→经{路径/绕障/门/步数或臂距}→到{终态}`，并写停驻后与他者相对。无走位须明文 `走位=无`。
2A. **逐拍出入画（核心）**：谁在画、谁入、谁出、经哪口，必须在本文件写完。开拍在画 =【建置】具名主体；中途入画 =【入戏】写经{出入口}入画过程（建置不含，终态写入）；中途出画 = 建置含、入戏写出画过程、终态剔除。切角 ≠ 出入画。场头【实体覆盖】写在场 / 待入画 / 离场。
2B. **建置覆盖闸（核心；名单只在此条）**：本拍【Beat主体定位】`可见性=V` → **必须写入建置**。`可见性=暂不可见` → **不写建置**，速查留站位+`因=`（切角/特写 ≠ 出画）。组按 V 行 `序=`/`朝向=`/`距=`/`同簇相对=` 成稿。围桌/舱位抄该行 `辅=`/`排=`/`座=`/`功能=`，建置整句须能读出哪一侧第几个或第几排第几个；禁收成「靠桌/在车上/后排」。禁把暂不可见者补进建置，禁把 V 漏掉。上游闭集仅 `V|暂不可见|待入画|D`，不得自造 `X`。仅 `待入画` / 已离场 / `D` 不写本体。中途走位出画另写入戏过程。不改已锁 XOR。
3. **拍摄键写入建置**：该拍 `当前环境` / `景别` / `构图` / `可兼` / `主体落点` / `留白` / `纵深层` / `镜头角度` / `关系角` / `OTS类型` / `近侧框主` / `主拍对象` / `主观角色` = 输入已锁拍摄键。标题后**不保留**独立【取景锁定】行；拍摄键全部写入【建置】首句。入戏只写镜头实际看见的过程（对白/微表演/`{…}`），不写锁档键值、不写推导。上游【配乐】【音效】原样写入戏，不改 `态=`/`锚=`/`配合=`/`音量=`/`质量=`/`混响空间=`。
4. **两段式**：每个最终 Beat 只写 `────【建置】────` → `────【入戏】────`。Beat 内**禁**再写【场记分析】。
5. **推导写入场级场记分析**：从各拍【取景锁定】并入 `原文景别` / `原文角度` / `角度动机` / `上拍镜头角度` / `角度跨度` / `剧情匹配` / `上拍景别` / `跨度` / `选择证据` / `[DERIVED_ENV:…]`；再写走位终态 / 速查（**未出画全员**各一行：`所在侧=` + 锚侧或绝对层位或封闭排座 + 面向 + 镜头可见面 + 姿态 + `可见性=画内|暂不可见`）/ 差集 / 开拍评估。全部写入场级 `────【场记分析】────`…`────【场记分析结束】────`（`B{n}=` 一行一拍，位于场级综合项、`[BEAT_STREAM_START]` 前）。输入若仍有拍内【场记分析】并入对应 `B{n}=` 后删除。禁另起【Beat切换说明】。场记分析写站位时同样禁扇区 / `F≈` / `0°侧`（`所在侧=` 闭集与 §7A 表头除外）。
6. **入戏只写建置后变化（核心）**：【入戏】只描写开拍后相对本拍【建置】初态**新发生或推进**的部分（对白 / 语气 / 微表演 / 左右手脚 / 取用 / 朝向对象变化 / 门开闭（按环境合同匹配改写） / 走停转 / 出入画 / 武戏过程 / ENV 背景微动 / `{…}` / 【配乐】【音效】）。建置已写的位置 / 朝向 / 姿态 / 层位 / 距离 / 挂载 / 首登名牌一律不复述。无角色变化则只写对白（若有）+ ENV 背景微动。**开口/闭嘴仅有对白时必填**，无台词不写。变化结果只进场级场记分析 `B{n}` 终态。**上下拍衔接**：入戏须从上拍终态/未完成动作链接着写，并落到本拍终态，使下拍按该拍已锁 V 名单承接；禁跳步、禁蒸发受者响应、禁把下拍才发生的动作提前写完。禁缺 V、禁多出、禁与已锁可见性矛盾；不得自造 `X`。
7. **完整一场**：从 `[SCENES_BLOCK_START]` 起笔；末行 `[STAGING_ENV_OUTPUT_END]`。

## 硬约束
1. 不改事实 / 因果 / 对白词 / 场核 / `节拍=`。例外：门/窗/车门/舱门/厢门开关过程须按环境规划合同**匹配改写**（§6），不另造开向或门轴。
2. 成稿写出原文本身。
3. 专名与环境注册名逐字。继承现场编排后的 `CHAR:[@]` / `PROP:[]` / `ENV:[]`；新写建置/入戏同此。禁拆前缀还原裸名。衍生环境只认已声明 `ENV:[…]`。
4. 物理可拍优先；`正面/¾朝镜头` 与 `面向后景` 互斥。未锁越轴则走位 / 左右屏不得跨 `spatial_axis`。
5. **站位禁角度**：落位/朝向禁 `0°侧` / `90°侧` / `180°侧` / `270°侧` / `扇区=` / `F≈` / `面向N°` / `站在{N}度`。【建置】【入戏】同禁；场记分析除速查/差集 `所在侧=` 闭集外同禁。已锁 ENV 名 `{N}度…` 与 `镜头角度=` 可照抄。`所在侧=` 只许 `原后景侧|原前景侧|+90侧|-90侧|轴心`（✅`+90侧`｜❌`90°侧`｜❌建置抄 `所在侧=`）。
6. 仅因出入画改集合、转身改档、已锁 ENV 变、出入舱落定可另起 Beat。
7. 相对落位须带锚名；「画左/画右」已换成该拍 ENV 画幅锚实体。入戏只写建置后变化，与上下拍动作链衔接。
8. **自然语言整句**：【建置】键值行外须另写完整句：可见面（哪肩/哪颊/后脑）+ 已锁方式落位（§4）。【入戏】仅走位 / 转身 / 出入画时用同样整句写**新**可见面 + 新落点；无走位禁复述初态。缺**画内者**可见面句 = 失败。画内仅一人不强制凑第二人；禁为凑人数把不可见者写入建置。
9. **画幅锚替换（强制；切角左右会变）**：先读本拍 ENV【衍生环境画幅锚】`背景=`/`画左=`/`画右=`。建置**仍按相对/绝对/封闭**成稿（§4），**只把** XOR 键与落位句里的「画左」「画右」换成**本拍三键里实际在画的实体**（✅相对 `侧=楼梯口`｜✅绝对 `后景+{本拍背景实体}+平`｜✅封闭 `座=账房窗起第2/5个`｜❌`侧=画左`｜❌丢掉锚/层位/排座只写一个实体｜❌180° 后本拍三键无柜台仍写 `后景+柜台`）。上角锚未出现在本拍三键且非画内承托 → 禁写入建置/入戏，速查 `锚=` 原样继承。切角/反打须改查**新 ENV 行**（0°画左≠180°画左）。构图 `三分` 可留。场记分析内部可写画左↔画右对调。缺三键=失败。

| **在场主体** | 【实体覆盖】已入场且未离场者。本拍建置 = 本拍【Beat主体定位】`可见性=V`。 |
| **入戏** | 建置初态之后的可见变化 + ENV 背景微动（选件见 §1）。不复述初态位置 / 朝向 / 姿态 / 已写名牌；有走位 / 转身 / 出入画可写新可见面 + 落点。开口/闭嘴仅有对白时写。须承接上拍终态、交接下拍开拍。 |
| **场记分析** | 场级综合项。按 `B{n}=` 汇总推导与连续性（选择证据、跨度、终态、速查、差集）。不成画面句。不进 Beat。 |
| **XOR** | 同一主体定位只选相对 / 绝对 / 封闭一种（执行现场编排已锁方案）。三种都禁角度坐标。配饰按角色部位，不占这三种。 |

| **锚侧落位** | 相对：一个主环境固定大件锚 + 该锚的{本拍画左实体}/{本拍画右实体}/上/下/近远镜头侧 + 辅边位 + 细节椅号。 |

| **走位** | 可移动主体在已锁空间内的位移：开拍定位 → 路径 → 终态定位 + 与他者关系变化。本文件核对并写清。 |

## 1. 建置 / 入戏 / 场级场记分析
- **【建置】**：首句写满拍摄键（见目标 3）。名单见 2B（=本拍 `可见性=V`）。V 者各写 XOR + 可见面整句 + **动作前**朝向（=上拍终态；本拍转身/走位不写进建置）；组按上游序/朝向/距；同簇按本拍 `同簇相对=` 投影写清谁偏画左/居中/偏画右、谁上谁下、谁靠近镜头侧。运动后落点不进。禁工程句「不可见的{名}在机位后方」。禁把本拍白名单外的锚写成画内。**门槛起笔**：入戏含推门 / 入画行走且文戏未写人已在厅内 → 建置停门侧 / 门槛，入完只进终态；文戏已是厅内开口 → 跟文戏落点，禁倒逼拆拍。禁 `选择证据` / 扇区 / `F≈` / `0°侧` / `所在侧=`。画幅锚见硬约束 9。**首登名牌挂该人建置句**（见下条）：写完该人 XOR+可见面立刻写该人名牌，再写下一人；禁攒到建置段末或入戏。
- **【入戏】**：只写相对本拍【建置】初态的**变化**——动作 / 对白 / 表情 / 交互 / 动势推进 / ENV 背景微动 / `{…}` / 【配乐】【音效】原样。无变化时禁复述初态。有走位 / 转身 / 出入画时，变化句须用**同样完整的自然语言**写出新可见面与已锁方式落点（禁只写「走两步」「转过身」）；无走位则不复述位置 / 镜头可见面。亦不写锁档键值或选择证据。画内缺角色微动则只补不抢戏的微反应。ENV 背景微动**只在本段写**，不复述建置、不改已写动作 / 对白。**衔接**：起笔状态 ≡ 本拍建置（站位来自上拍速查，名单=本拍已锁 V）；入戏推进朝向/走位/落点后写入终态；下拍按该拍已锁可见性写建置，核不缺不矛盾不多出。建置已写的首登名牌禁再写入戏（中途入画落定见名牌条例外）。
  - ❌入戏写`跨度=越级` / 无变化却复述初态 / 无对白却写开口闭嘴 / 相对走位写成无锚画左
- **【场记分析】（场级综合项）**：写在 Beat 流之前，成对标记。`B{n}=` 一行一拍 = 输入【取景锁定】推导键 ⊕ 建置 ⊕ 入戏 → `变化过程` + `终态画面纵深` + `速查更新`。终态只写本拍画内；速查 / 差集覆盖未出画全员（`V`→`可见性=画内`；上游 `暂不可见` 留站位+因，不写画面句）。同 ENV 下拍从速查继承站位，建置只写该拍已锁 `V`。ENV 变取 `所在侧` 查 §7A 后重写 V 者画面词。无运动：V 者复述终态关系。Beat 内禁再出现该段。
- **集合**：`终态=(建置−出画)∪入画/突现`。中途入画者不进建置、不进差集，过程写入戏、终态写满字段；中途出画者建置含、入戏写过程、终态剔除、差集 `{名}|出画|经=…`。切角 ≠ 出入画。格式见 §7。
- **不可见**：执行上游 `暂不可见`（特写非主拍 / 锚不在本角 / 层位出画），不写建置、不写出画。`D` 只写入戏声音。`待入画`/已离场不写。上游已锁 `V` 却漏建置 = 失败。中途走位出画才改集合。
- **可移动主体**（角色 / 具名龙套 / 群演簇 / 动物 / 载具 / 法相金身 / 已入场独立可移动道具）：同等落位 + 朝向 + 进出场。配饰跟宿主；宿主暂不可见则配饰不进建置。群演簇**仅当簇仍在画**才写人数 / 队形 / 主导可见面；上游已拆簇主拍则具名对白/近景拍不把簇塞进近身。人—车 / 人—骑分行。**满幅→收紧**：CU 只建置上游 `V`（通常仅主拍）；其余按上游 `暂不可见` 留速查。
- **不提前入场**：剧情角色 / 独立道具首次剧情 Beat 前 = `待入画`。豁免 = 氛围龙套 / 群演簇（须依据）。待入画者禁塞进建置、终态、差集或速查。
- **出入画另起拍**：该拍只写出入画（入戏写经哪口、行进径向、落定/离场）；落定后下一拍才对白 / 主动作。切角 ≠ 出入画。禁只改集合不写过程。
- **动作覆盖**：【入戏】对建置内每人 / 每簇至少 1 个可见微动（计为变化，不是「无变化」）。剧情强制静止须写静止证据。受者响应须针对该动作，不能用旁观微动代替。
- **环境背景微动态（只写入戏）**：每拍【入戏】须有 `ENV背景微动=` 一行。**选件序**：①所属主环境已点名 `背景微动件=` 且本拍白名单或画幅锚可见 → **优先写该件**及其 `可用动势`（幅度 subtle，不改行动/走位/对白）；②该件不可见或 `背景微动件=无` → 再从当前环境已有细微件选（本拍 ENV `背景=`/`画左=`/`画右=`、固定清单/未落清单、本拍【建置】已点名的小件：帘/穗/灯焰/烟气/水纹/叶/尘/旗角/窗纱/烛火/蒸汽/纸页边等）；③仍无可选 → `ENV背景微动=无`（**宁愿空，禁凑件**）。**禁杜撰**原环境没有的物件（❌原无碗却写「碗沿轻晃」）；**禁**拿桌/柜/门/柱/床/墙/柜台等大件当微动锚来凑行。禁括号备注。光斑 / bokeh 不进。【建置】禁写本行。人群动势不替代本行。空镜拍建置=`空镜／无角色`，本行仍写（有则微动，无则`无`）。
- **开口｜闭嘴（仅有对白时；`|` 并排拉开）**：本拍有非空台词才写。按 drama 合同：`开口 | 说话人 |` 语气层 + `{台词}` `| 闭嘴 | 听者…`。开口/闭嘴与角色用 `|` 并排，中间夹完整对话。禁括号紧贴、禁闭嘴写在台词前。无对白、空镜、纯走位/空镜建立 **禁止**出现开口/闭嘴行。OS/旁白/自白仍算有台词，须写闭嘴、开口侧按 drama 合同。
- **本集首次正面出场物理文字名牌（强制 · 读【本场角色标签】 · 与该人建置同步）**：注入行 `CHAR:[@名]｜标签=…｜标签_en=…｜标签字体=…｜标签字色=…｜裸名=…｜裸名_en=…｜字幕=待落|已过|无`。`字幕=` 只是落态开关，**不是**对白硬字幕。名牌是该人开拍建置的一部分，**不是**入戏变化、**不是**段末清单。
  - **语种（最高）**：先读 `# Project Context` / `Language` / `project_language`。中文（`zh`/`cn`/`中文`/`Chinese`）→ 字样=`裸名`+`标签`。英文（`en`/`English`/`英文`）→ 字样=`裸名_en`+`标签_en`。未明确 → 跟剧本主语言（正文以汉字为主用中文侧，否则英文侧）。**禁**中英并列、**禁**用错语种上屏（英文项目打中文名/中文标签，或反向）。该侧标签为`无`或缺 `_en` → 不写名牌，场记分析标 `首登名牌缺口=缺{语种}标签`，禁拿另一语种顶上。
  - `字幕=待落` 且本拍【建置】该人镜头可见面 ∈ `正面/¾`（脸/双眼可读）→ **紧跟该人 XOR+可见面整句**写恰好一行：`画面打出物理文字标签：【{字样名}】{字样标签}】｜字体={标签字体}｜字色={标签字色}`。**禁**套 `CHAR:`。同人全场只写一次；写过后其余拍禁再写。注入已有字体/字色（非`无`/`待补`）→ **原样抄**，禁改书体或字色。仅`无`或`待补`才跟 `Global_Style` 时代/基调补一书体+具名色，禁套对白字幕白字黑边。
  - **一人一句同步（最高）**：写完 `CHAR:[@甲]` 落位/可见面 → 立刻写甲名牌 → 再写 `CHAR:[@乙]` 建置（乙合格则紧跟乙名牌）。**禁止**先写完全员建置再把多名牌攒到建置段末或【入戏】一起打出。
  - 本拍为背对/侧背面、空镜、主观且该人不可见 → 不写，等后拍该人首次正面/¾ 建置。
  - **中途入画例外**：该人不进本拍【建置】；入画落定后首次正面/¾ → 名牌紧跟该人入画落定句（=该人首次建置），不堆入戏段末、不与其他人名牌攒写。
  - 全场 `字幕=待落` 却从未正面/¾：在该人首次侧面仍可读半脸的拍，挂该人建置句补写；仍无则场记分析标 `首登名牌缺口={名}`，禁为名牌改朝向。
  - `字幕=已过|无`、群演簇 → **禁写**。
  - ✅中文项目 `CHAR:[@陈] …可见右肩与右颊… 画面打出物理文字标签：【陈】客栈掌柜】｜字体=魏碑｜字色=鎏金`｜✅英文项目同结构用 `【Chen】Innkeeper】｜字体=Title Card｜字色=Ivory`｜❌英文项目写`【陈】客栈掌柜】`｜❌`【Chen】客栈掌柜】`｜❌套 `CHAR:`｜❌写成画幅底部对白硬字幕｜❌全员建置后再一起打出多名牌

## 2. 连续性与走位
每拍先对上拍终态与本拍已锁取景做核对，再写建置 / 入戏 / 终态。

**动作连续**
- 上拍未完成的动作链本拍【入戏】承接，禁跳步、禁蒸发受者响应；本拍入戏未写完的链须留给下拍续，禁提前蒸发。
- 姿态 / 持物 / 朝向对象连续；变则须有本拍可拍过程（只写入戏）。姿态档（站坐跪蹲趴躺倚骑，含承托面）逐字继承；切角 ≠ 改姿势。入戏有过渡链才改终态姿态，建置仍写旧档。
- **朝向时序（最高）**：本拍建置 `面向=` + `镜头可见面` = 上拍终态（上拍若转身，新朝向从**本拍建置**才第一次落地）。本拍入戏若再转身：建置仍写动作前档；新朝向只进本拍终态/速查，**下拍建置**才改写。同 ENV 无转身则可见面不改档。❌把本拍转后朝向写入本拍建置。❌因换主拍/收景别重算可见面。仅 ENV 变且无转身才按 §5 / §7A 重写可见面（面向对象不改）。
- **随身件守恒**：本场已出现或原文点名的剧情随身件，**宿主本拍可见**时须可检索 `部位=` + `体侧=`。宿主本拍不在建置名单 → 不写建置，速查抄挂载。纯造型无戏件不写。无离身链 → 可见宿主建置抄上拍挂载。背对禁写胸前件正面。发声屏写现位 + 屏面朝向；无拿放翻面则抄上拍。离身只写入戏，新挂载进终态 / 速查。
- **入戏跨拍衔接**：入戏不得从与本拍建置矛盾的状态起笔（人已换位、手已换物、半句对白无据另起）；亦不得写到下拍无法承接的终态（半步悬空、物蒸发、动作无落点）。下拍从本拍速查继承站位，建置只写下拍仍可见者；下拍【入戏】再写新变化。

**位置连续**
- 真源=已锁方式（§4）+ 速查 `所在侧`。禁 `扇区+F`。
- 开拍站位 ≡ 上拍速查：同 ENV 不整句抄终态落位词（画幅锚可按本拍三键替换），但 **面向 + 镜头可见面档必须逐字抄上拍**。ENV 变写【上一ENV→触发→本ENV】后按 §5 / §7A 重写**本拍仍可见者**画面词，禁切角瞬移。上游 `暂不可见` 只进速查，不写建置。
- 反打 = 同主名对向已锁 ENV。换主名触发不标反打。来源 = 紧邻上拍终态，禁回取更早建置。

**关系连续**
- 仅本拍画内者互写前/后/左/右 + 尺度距离 + 面向。同锚或同绝对格须执行上游 `同簇相对=本拍投影`：整句交代**本拍三维**（偏画左/居中/偏画右、上/平/下、近镜头侧/同层/远镜头侧）。ENV 变用本拍投影，**禁**把 0°「甲偏画左」原样写进 180°/90° 建置。与画外者的关系只进速查，不写建置。走位后关系必须可从开拍关系 ⊕ 本拍路径推出，并更新投影。
- 正反打场：走位不得无过程把相向拆成同向，或把同向拧成相向。关系变须写在 `变化过程`。

**轴位连续（不越轴）**
- 轴线 = 本场已锁 `spatial_axis`。站位、走位路径、停驻点、左右屏必须落在轴线同一侧（左右屏=构图/轴线用语；**相对落位写「锚的画左/画右」，不是无锚的画面画左**）。
- 已锁 `axis_crossing=None`：禁跨轴；左右屏相对上拍保持同侧。
- 已锁 `PlannedReverse`：沿轴线对向，左右屏对调合法，仍算守轴，**不是**越轴。
- 已锁 `MotivatedCross`：允许跨轴，走位终点落到轴线另一侧，写 `越轴=是｜动机=` 该拍已锁动机。
- 失败：未锁越轴却因走位跨到轴线对面；无反打依据拧反左右屏；把越轴写成普通反打；改挂方案外角来圆越轴。回改走位。
  - ❌`守轴核销=通过`（无人名） / 未锁越轴却写`跨轴`

**走位核对**（相对已锁取景；不通过则回改落点或拆已锁空间硬锁拍，禁改挂方案外角）
1. 开拍落点 = 上拍终态，无瞬移。
2. 路径物理可拍：净空、步幅够、门径向闭合。**障物评估（有走位必写）**：直线开拍→终点扫本拍白名单与建置已写实体。无挡=`障=无`。有挡=`障={具名}`，路径须补 `绕={具名}之{画左|画右|近镜头|远镜头}`（承接文戏已写画侧；无则据已锁观察向裁定）；直线穿桌/柱/人/门扇=失败。绕障节点须仍在已锁活动空间且不越轴。
3. 终点仍在已锁活动空间；本拍必见项仍 ⊆ 已锁白名单。
4. 走位后距离档与已锁景别同向（贴身 ↔ MCU/CU；数步对峙 ↔ WS/FS）。
5. 触达对象开拍已在画且一臂可达；否则先切已锁可见该物的角。
6. 停驻后仍留后续动作净空（贴墙无退路、叠脚无步幅 = 失败）。
7. 路径与终点不越轴（上条）；`守轴核销=` 必填。

**走位细化**（写入 `变化过程` + `终态画面纵深`；【入戏】用自然语言同步写出）
- 有走位：`变化过程=`=`{名}:自{开拍}→经{路径/绕障/门/步数或臂距}→到{终态}｜障=无|{具名}｜绕=无|{具名}之{画左|画右|近镜头|远镜头}｜锚=…｜侧=…｜辅=…｜细节=… 距=…`。相对自/到禁无锚画左/前景。【入戏】须写路径（有障须写出绕过）+停驻后可见面+已锁方式落点。
- 停驻须落点可辨，不得与他人 / 锚混淆。
- 无走位：`走位=无`，场级场记分析 `B{n}` 复述**画内**终态关系，不可见者只在速查留站位；**入戏不复述**。
- 多门路径见 §6。

## 4. 定位成稿（执行已锁起始帧；不补锁）

## 5. 朝向与镜头可见面
档位：角色 = `正面/¾`｜`左侧面`｜`右侧面`｜`背对/侧背面`。载具 = `车头/车尾/左/右侧身朝镜头`｜`¾车头/¾车尾`。动物 = 身躯镜头可见面 + `头朝{对象|左|右}`。

**朝向禁角度**：只写 `面向{具名对象或锚}` + `镜头可见面` 档。禁 `面向N°` / `F≈` / `面向中心`。

**转身过程拍（建置=动作前；转肩只从建置判）**
入戏出现转身 / 转面 / 调头 → `拍型=转身过程`。禁同拍开口 / 走位 / 取物。轴未变可同父 ENV。禁写转了多少度。
时序：`上拍终态朝向 → 本拍建置（动作前） → 本拍入戏转身 → 本拍终态/速查（新朝向） → 下拍建置（才更新朝向）`。
- **建置**：只写动作前档 = 上拍终态 `面向=` + 本拍观察向下的 `镜头可见面`。禁写成转后面向。
- **入戏**：只写连续转体（可见面随转写出，不写 XOR）。五件套只进终态：`向{左|右}肩转 → 终态面向{对象} → 终态镜头可见面 → 终态姿态 → 终态落点`。
- **下拍建置**：才抄本拍终态新朝向。❌本拍建置与终态面向相同却写入戏「转身」。

**转肩判定（角色自身左/右，不是画面左/右）**
只以**本拍建置**为开拍态，禁止用终态回推。
1. 读建置 `面向=A`（具名对象或锚）。
2. 用**本拍** ENV `背景=`/`画左=`/`画右=`（及近镜头侧）把 A、B 各落入四向之一：`近镜头|远镜头|画左|画右`。B=入戏要转到的具名对象或锚。缺三锚=失败。
3. 按建置面向所定的角色左/右，取从 A 到 B 的较短转：

| 建置面向所在向 | 角色左 | 角色右 |
| :--- | :--- | :--- |
| **远镜头**（对背景） | 画左 | 画右 |
| **近镜头**（对机位） | 画右 | 画左 |
| **画左** | 近镜头 | 远镜头 |
| **画右** | 远镜头 | 近镜头 |

B 在角色左 → `向左肩转`；在角色右 → `向右肩转`。B 与 A 对向（约一转半）→ 拆成转身过程拍或先锁越轴，禁同拍硬拧 180° 还开口。
❌用画面左/右当角色左/右。❌用转后面向当建置再回推转肩。❌默认某类陈设（门/窗）在某一侧。

**切角只换观察向**：未走位未转身者，相对锚名 / 辅边位 / 面向对象 / 姿态 / `所在侧` / 世界槽位（`排=`/`辅=`/`功能=`/`K`）不变。用 `所在侧` 查 §7A 得画面位。相对只对调近镜头↔远镜头，左右改查**新 ENV 画幅锚**，禁为查表改填前中后景。绝对层位按对向对调（反打：前景↔后景）或按已锁取景重写，画位改写新 ENV 左右实体。同簇三维跟本拍 `同簇相对=本拍投影`（180°：画幅左右对调+纵深近远对调；90°/270°：原画幅轴与纵深轴互换后落入本拍词）。镜头可见面按新观察向重写：对向 180° 走下表；邻档 90° 侧切只换左右面，不换正背。禁经 `扇区=` / `F≈` 换算。

**朝向三联**：`面向=` 与 `镜头可见面` 必须和本拍 ENV 轴一致，**不按远近一刀切**。对象在近镜头半空间 → 可见面偏正面/¾；在远镜头半空间 → 偏背对/侧背面；在画左/画右半空间（侧墙窗、侧门）→ **侧面**（哪侧跟该半空间）。❌把「面向远处」一律写成背面。同层面向：相对角色写 `面向{具名}`，禁 `面向画左/画右`，禁 `面向N°`，禁 `面向中心`；仅绝对同层才写画左 / 画右或镜头向。

**落笔序**：定面向对象（具名） → 写镜头可见面档与自然语言 → 写已锁方式落位（锚侧 / 绝对层位 / 封闭排座） → 速查抄 `所在侧` + 面向 + 可见面 + 落位（不抄度数）。

**反打 ≠ 转身**：反打时未转身者面向对象 / 姿态 / `所在侧` 不变，镜头可见面随观察向对调。来源 = **紧邻上拍终态**（上拍是转身过程拍则取其终态新档，禁回取该拍建置旧档）。相对锚名与辅边位不改写，近/远镜头对调，左右改查新 ENV 画幅锚实体。

**180° 反打换档**（仅对向 180°，`N新=(N旧+180)%360`；邻档 90° 侧切只换左右面，不走本表）：

| :--- | :--- |
| 正面 / ¾ | 背对 / 侧背面 |
| 背对 / 侧背面 | 正面 / ¾ |
| 右侧面 | 左侧面 |

层位按对向对调（前景↔后景、画左↔画右）。`投影恒等` 仅轴心层位/中央，≠「可见面也没变」；正背面必须换。换档后该人锚已不在本拍画幅 → 执行上游 `暂不可见`，不写建置。禁复制上拍「正面朝镜头」；禁因「仍是说话人 / 要露脸」保持原档。若须反打后同一可见面，须先另起转身过程拍。

**朝向承接**：本拍建置面向对象 + 姿态 = 上拍终态（动作前）。同 ENV 无本拍转身 → 可见面也抄上拍终态。仅 ENV 变且无转身 → 面向不改，可见面按新观察向重写（180° 走换档表；90° 只换左右面）。本拍有转身 → 建置仍用上拍终态面向；新面向只进终态，下拍建置再抄。❌同 ENV 因换主拍/收景别重算可见面。❌建置写成转后面向。

**背对门禁**：背对禁写五官 / 口型 / 胸腹正面与 `对镜头`。须读脸 → 已锁可读角的下一拍再写。

**入画径向**：后景门入 → 朝镜头 → 终态正面（背对门）；近端门入 → 向纵深 → 终态背对。

**驾驶舱可见面**（无转身、全员面向驾驶台 / 前窗）：

## 6. 空间执行
- **出入舱**：入舱过程拍仍挂仓外衍生；落定后另起拍，触发 = `入舱切主环境`，ENV = `{N}度{仓内主名}`。出舱落定后另起拍，触发 = `出舱切主环境|回切仓外主环境`；建置 = 所经那扇门外侧旁，载具外部整体入画；下一拍抄同扇门旁落点。
- **多门路径**：入 = `门位→落点/座位`；出 = `舱内位→门位→门外落点={外部本体}之{门位}外侧旁`。
- **触达**：接触对象须在开拍可见集且一臂可达；否则先切已锁可见该物的角。
- **载具**：入戏只写运动 / 操作事件；途经、停靠、上下车起终点进建置 / 终态。
- **门窗开关（评估；有则强制；按环境合同匹配改写）**：凡入戏含开/关/推/拉/滑门窗（含车门/舱门/厢门/窗扇），**先读该口环境规划合同**（四向+固定清单；复用场读 `本场门窗初态`）：`扇型=单扇|双开` + `开闭=` + `开向=里|外|左滑|右滑` + `门轴=` + `把手=`（双开另读左右扇各份与`通行扇=`）。缺合同=失败，禁常识另造。文戏过程只作意图（谁开哪口、开或关）；**推|拉、接触点、开向词、人站侧、扇展侧、开哪一扇与合同冲突则改写**，左右手可承文戏，但触点不得落**该扇**门轴侧（冲突改到把手，必要时换手）。不改对白、不改门口注册名（裸「开门/开车门」须点名已锁口；双开再点左扇|右扇|双扇）。
  1. **建置开拍态**：该口入画则写开拍开闭（≡上拍终态；首拍=环境初态/`本场门窗初态`）。双开须分写左扇/右扇开闭，禁合成一句「对开门半开」。半开/全开须带该扇扇展占位核销 `开向`（里=占室内/舱内；外=占室外/车外）。门轴是世界属性，**不随本拍画左画右翻转**。
  2. **力向核销（铰链扇）**：`开向=里`＝扇面向室内/舱内展开；`开向=外`＝扇面向室外/车外展开。打开：人在门外/仓外 + 里 → **推向里**；人在门内/仓内 + 里 → **拉向里**；人在门外/仓外 + 外 → **拉向外**；人在门内/仓内 + 外 → **推向外**。关上=反向力，开向词不变。车门/舱门同表。双开**逐扇**套本表（左扇用左扇门轴/把手，右扇用右扇）。
  3. **推拉扇**：单扇 `开向=左滑|右滑`、`门轴=无` → 力=滑向已锁向。对开推拉：左扇滑左、右扇滑右，禁写成铰链推拉。
  4. **双开（一口两扇；强制点扇）**：只开通行扇 → 只写该扇触点+扇展，另一扇保持其开拍开闭。双扇同开 → 两触点（或双手各一扇），扇展对开（左扇往其门轴侧/左、右扇往右，占位仍同核一个开向）。通行只经已开扇缝，禁穿仍关的那扇。❌把整樘写成单扇一门轴｜❌只写「推开对开门」不分左右扇。
  5. **入戏句**：单扇=`在{门名}{把手左|右}{上|中|下}部{向里|向外|左滑|右滑}{推|拉|滑}{开|上}` + 人站={门内侧|门外侧|仓内|仓外} + 扇展。双开在门名后加 `{左扇|右扇}`，触点用该扇把手（中缝）。例：单扇 `开向=里｜门轴=门左｜把手=门右中`、人在门外 → `CHAR:[@甲]右手在大门右中部向里推开门，门扇往室内展开`；双开 `开向=里｜通行扇=右扇`、人在门外 → `CHAR:[@甲]右手在正门右扇左中部向里推开右扇，左扇仍关，右扇往室内展开`；双扇同开外开 → 左右手各在中缝把手向外拉开左右扇，两扇往室外对开。
  6. **态连续**：该扇开拍已全开 → 禁再写打开该扇，改写为经该扇缝通行。开拍全关 → 禁穿该扇、禁写门后可见。过程从建置初态推到终态；双开终态分写左右扇 `开闭=`。
  ❌照抄文戏「拉开」却与里开/外开冲突｜❌只写「开门/推门/开车门」无接触点无开向｜❌手摸该扇门轴侧｜❌切角后把门轴改到画面对侧｜❌半开却不写扇占里或外｜❌双开不分扇
- **已锁 OTS / 正反（建置写清）**：`关系角=` / `OTS类型=` / `近侧框主=` / `主拍对象=` 只执行已锁拍摄键，写入【建置】首句，禁改档。

| :--- | :--- | :--- |
| **读对手 / 反打** | 越过近侧肩/腰/身看对方脸；背景半空间对向 | 挂已锁对向 `{N}度…`；禁同父冒充 |
| **同侧过肩** | 近侧只作框，不换对手可读面、不改背景扇区 | 同父 ENV；禁标反打 |

`关系角=过肩|过腰|OPC` 时【建置】四要素缺一失败（肩主=`近侧框主`；主拍=`主拍对象`）：

- ❌`过肩看陈`（缺框主可见面 / 左右肩 / 主拍镜头可见面）
切角时未转身者面向对象与姿态不变，镜头可见面随观察向对调（§5 反打≠转身）。
**切主 ≠ 反打**：`闪回切主环境|蒙太奇切主环境|回切当下主环境|入舱切主环境|出舱切主环境|回切仓外主环境` 不标反打。前向驾驶舱 `0度↔180度` = `同向驾驶舱读角`，不得当厅堂反打（`180度` 不得保留前向操纵员在画）。出入舱后禁仍挂舱外 ENV 写舱内戏。
