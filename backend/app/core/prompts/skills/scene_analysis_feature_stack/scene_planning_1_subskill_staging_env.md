## 目标

按**单场**调用。输入已含【主环境】【未落清单】【衍生环境】、【主体定位方案】【Beat主体定位】、各拍【取景锁定】（含拍摄键 + `选择证据=` + `[DERIVED_ENV:]`），以及文戏/武戏过程。
已锁拍摄与已锁起始帧是开拍条件。本文件把**拍摄键写入【建置】**，把朝向 / 走位 / 落点变化写入【入戏】，推导与连续性写入**该拍**【场记分析】。成稿**只出节拍流**；场号 / 【场景名称】 / 环境块 / 定位方案 / 提取块由程序从上游拼回，本层不回写。开场全景写入 B1 场记 `开拍在场=`，不另起【实体覆盖】。禁另起【位置规划综合】【角色位置】【未落实体位置】【观察视角与空间建置】【动作空间综合】【露脸冲突】；输入若仍有覆盖矩阵 / 【Beat景别构图方案】 / 场级【场记分析】则拆入对应拍后删除，不新写场级块。
1. **连续性（核心）**：动作链无跳步；**【建置】=动作前**（时序 §2 / §5）。开拍站位 ≡ 上拍速查。名单只走 2B。ENV 变不瞬移：`所在侧` 查 §7A。**世界槽位守恒 ≠ 镜头纵深守恒**：世界键切角不改，近远/画幅按本拍 N 投影（细则 §5）。执行已锁 XOR。镜头关系只抄上游 `可见面推=`/`体侧=`。走位守 `spatial_axis`。禁角度坐标（`所在侧=` 闭集除外）。
2. **走位核对与细化（核心）**：据已锁 ENV / 景别 / 活动空间 / 轴线，核本拍走位是否可拍且不越轴（净空、不穿障、步幅、门径向、触达一臂、终点仍被白名单覆盖、路径不跨轴线）。**先评直线开拍→终点有无障碍**（固定大件/柱/人/门扇）；有则 `经=` 须写绕过哪件、从该件`画左|画右|近镜头|远镜头`哪侧，直线穿障=失败。再把路径写清：`{名}:自{开拍}→经{路径/绕障/门/步数或臂距}→到{终态}`，并写停驻后与他者相对。无走位须明文 `走位=无`。
2A. **逐拍出入画（核心）**：谁在画、谁入、谁出、经哪口，必须在本文件写完。**执行上游入场核销**：`入场=开场` → B1 必须安排到位（该拍 `V|部分可见` 写入【建置】，即使本拍无动作；`暂不可见` 写入场记/速查）；`入场=待入画` → 入画拍建置不含、【入戏】写经上游 `经=` 出入口的入画过程，终态写入；入画前禁写入建置。开拍在画 =【建置】具名主体；中途入画 =【入戏】写经{出入口}入画过程（建置不含，终态写入）；中途出画 = 建置含、入戏写出画过程、终态剔除。切角 ≠ 出入画。**禁鬼魅**：无开场行且无 `入画@`/`经=` 却写入建置或终态 = 失败。在场 / 待入画 / 离场与上游 `入场=`/`入画@`/`经=` 同核，写入 B1 `开拍在场=` 与各拍场记，不另起场头表。
2B. **建置覆盖闸（核心；名单只在此条）**：本拍【Beat主体定位】`可见性=V|部分可见` → **必须写入建置**（**无动作仍写**）。`可见性=暂不可见` → **不写建置**，速查留站位+朝向+`因=`（切角/特写 ≠ 出画）。**空镜分档**：上游 `剧情匹配=空镜` 且整车不是本拍主体 →【建置】只写拍摄键 + `空镜／无角色／无道具`，禁 CHAR/PROP 落位。**整车无人全景** → 拍摄键 + `空镜／无角色`，可点名 `PROP:[整车]` 停泊/行驶一句，**禁 CHAR**。已在场者速查 `暂不可见｜因=空镜无人`。档=`内部ENV` 禁写成空镜、禁改挂宿主。档=`道具沿用宿主` **允许** `位于 PROP:[整车]`。道具特写不是空镜。组按 V/部分可见行 `序=`/`朝向=`/`距=`/`同簇相对=`/`露=` 成稿。围桌/舱位抄该行 `辅=`/`排=`/`座=`/`功能=`，建置整句须能读出哪一侧第几个或第几排第几个 **+ 姿势闭集**；禁收成「靠桌/在车上/后排」、禁只写位于无姿。禁把暂不可见者补进建置，禁把 V/部分可见漏掉。上游闭集仅 `V|部分可见|暂不可见|待入画|D`，不得自造 `X`。仅 `待入画` / 已离场 / `D` 不写本体。中途走位出画另写入戏过程。不改已锁 XOR。**粒度=本拍 `当前环境=`**（硬约束 12）：禁把另一衍生/另一主环境里的人写进本段。
2C. **开场全景 + 无动作仍在场（最高）**：从 B1 起锁定本场**应存在的初始角色与可移动道具全景**，此后每拍跟踪进出与运动，核站位/朝向一致。本拍入戏无该人动作 ≠ 可从该拍删人/删道具。
   1. **开场全景集** = 上游 `入场=开场` 的 CHAR + 可移动 PROP（禁只列开口者/主拍）。B1 `开拍在场=` ≡ 该集，必须写全。
   2. **B1 安排到位**：开场者须在第一拍被核销。名单写法走 2B。❌B1 只建置有戏者，其余开场人到后拍才首次出现。
   3. **每拍跟踪**：开拍在场 ≡ 上拍收拍在场。入画/出场只写入戏过程。无动作且无出画 → 仍在 `开拍在场`/`收拍在场`/`本拍主体=`。可见性写法走 2B，禁从收拍剔除暂不可见者。
   4. **站位朝向一致**：无走位无转身者，本拍建置/速查的落点+面向+可见面 ≡ 上拍终态（ENV 变只投影，不改世界朝向对象）。禁因「本拍没戏」改朝向、重排站位或蒸发。道具同核：开场独立 PROP 进 B1 全景；无使用仍跟踪；随身件跟宿主。
3. **拍摄键写入建置**：该拍 `当前环境` / `景别` / `构图` / `可兼` / `主体落点` / `留白` / `纵深层` / `镜头角度` / `关系角` / `OTS类型` / `近侧框主` / `主拍对象` / `主观角色` = 输入已锁拍摄键。标题后**不保留**独立【取景锁定】行；拍摄键全部写入【建置】首句。入戏不写锁档键值或推导；走位/转身变化仍按目标 6 写新落点。上游【配乐】【音效】原样写入戏，不改 `态=`/`锚=`/`配合=`/`音量=`/`质量=`/`混响空间=`。
4. **三段式**：每个最终 Beat 写 `────【建置】────` → `────【入戏】────` → `────【场记分析】────`…`────【场记分析结束】────`。场头**禁**再写场级【场记分析】。
5. **推导写入该拍场记分析**：从本拍【取景锁定】并入 `原文景别` / `原文角度` / `角度动机` / `上拍镜头角度` / `角度跨度` / `剧情匹配` / `上拍景别` / `跨度` / `选择证据` / `朝向推` / `[DERIVED_ENV:…]`；再写走位终态 / 速查（**未出画全员**各一行：`所在侧=` + 锚侧或绝对层位或封闭排座 + 面向 + 镜头可见面 + 姿态 + `可见性=画内|暂不可见`）/ 差集 / 开拍评估。全部写入该拍 `────【场记分析】────`…`────【场记分析结束】────`（位于【入戏】后、`[BEAT_END]` 前）。**先写在场核销**（开拍人数 / 逐主体宫格与可见性及因 / 入画出场 / 收拍人数），再写推导与连续性。输入若仍有场级 `B{n}=` 拆入对应拍后删除。禁另起【Beat切换说明】。场记分析写站位时同样禁扇区 / `F≈` / `0°侧`（`所在侧=` 闭集与 §7A 表头除外）。`朝向推=` / 上游 `背对=` 只进本段，不进【建置】【入戏】。本段**不进分镜**（程序按成对标记剥离）。
6. **入戏只写建置后变化（核心）**：只写开拍后新发生或推进的部分。建置已写的位置 / 朝向 / 姿态 / 层位 / 距离 / 挂载不复述。有走位 / 转身 / 出入画 / 变姿须写新可见面 + 新落点 + 新姿势。上游本拍已有的动作 / 对白 / 声画必须写入戏（硬约束 0）。名牌不算动作。无角色变化则只写对白（若有）+ ENV 背景微动。变化结果进本拍终态。入戏须承接上拍未完成链、落到本拍终态。
7. **只出节拍流**：从 `[BEAT_STREAM_START]` 起笔，到 `[BEAT_STREAM_END]` 收束；末行 `[STAGING_ENV_OUTPUT_END]`。禁回写场头 / 环境块 / 定位方案 / 提取块 / `[SCENE_*]` / `[SCENES_BLOCK_*]`。

## 硬约束
0. **上游 Beat 只增不减（最高）**：本拍输入已有的动作、表情、姿势、对白整行（`开口 |` 八键 `{台词}` `| 闭嘴 |`）、VO、【配乐】【音效】必须全部落入【入戏】可检索。只允许加建置落位 / 走位 / 门合同改写 / ENV 微动。禁止删、漏、概括、用「同上/见上游」代替，禁止把合同骨架当成交稿。
1. 不改事实 / 因果 / 对白词 / 场核 / `节拍=`。例外：门/窗/车门/舱门/厢门开关过程须按环境规划合同**匹配改写**（§6），不另造开向或门轴。**对白例外仅限补花括号**：上游台词已是原文逐字但未包 `{}` → 只在原词外加 `{}`，八键与闭嘴侧原样；禁止改词、禁止改写成「语气层+台词」。
2. 成稿写出原文本身。
3. 专名与环境注册名逐字。继承现场编排后的 `CHAR:[@]` / `PROP:[]` / `ENV:[]`；新写建置/入戏同此。禁拆前缀还原裸名。衍生环境只认已声明 `ENV:[…]`。
4. 物理可拍优先；`正面可见` 与 `背朝镜头` 互斥。画内每人必写镜头关系闭集；成稿禁写 `180°`/`相对180度`/`面向N°`。建置只写正面朝向，禁重复写 `背对={实体}`。画外禁点名见硬约束 9。未锁越轴则走位 / 左右屏不得跨 `spatial_axis`。
5. **站位禁角度**：落位/朝向禁 `0°侧` / `90°侧` / `180°侧` / `270°侧` / `扇区=` / `F≈` / `面向N°` / `站在{N}度`。【建置】【入戏】同禁；场记分析除速查/差集 `所在侧=` 闭集外同禁。已锁 ENV 名 `{N}度…` 与 `镜头角度=` 可照抄。`所在侧=` 只许 `原后景侧|原前景侧|+90侧|-90侧|轴心`（✅`+90侧`｜❌`90°侧`｜❌建置抄 `所在侧=`）。
6. 仅因出入画改集合、转身改档、已锁 ENV 变、出入舱落定可另起 Beat。
7. 相对落位须核销到具名锚；成稿主语=该人，**禁过程词「相对{锚}」**。可见锚能区分该侧 → 只点该锚+世界侧名，禁叠 `靠近镜头|远离镜头`。宫格参照=画外 → 硬约束 10。无可见锚才写本拍投影的近/远。三维挂在侧名上。高低 `平`=齐站，成稿省略，禁「平的{侧}」。禁无主语句。
8. **自然语言整句**：【建置】键值行外须另写完整句：镜头关系（闭集；只抄上游 `体侧=`/`可见面推`）+ 姿势闭集（§2）+ 已锁方式落位（§4）+ 手持/佩戴（§1）+ 可见脸表情（§1）。【入戏】仅走位 / 转身 / 出入画 / 变姿时用同样整句写**新**镜头关系 + 新落点 + 新姿势。无走位禁复述初态。缺画内镜头关系、缺姿势、V 者缺 `手持=`/`佩戴=`、脸可读缺表情、脸不可见写五官、入戏有神色却 `背朝镜头`（§1）、`部分可见` 升全身或漏 `露=` = 失败。画内仅一人不强制凑第二人。成稿禁写相对180°。禁「面向{人}方向（即面向镜头）」。
9. **画幅锚替换（强制；切角左右会变）**：先读本拍 ENV【衍生环境画幅锚】`背景=`/`画左=`/`画右=`/`画外=`。建置**仍按相对/绝对/封闭**成稿（§4），**只把** XOR 键与落位句里的「画左」「画右」换成**本拍可见三键里实际在画的实体**（`背景=`/`画左=`/`画右=`；相对成稿须把画左/画右挂在该锚的某一侧上；✅绝对 `后景+{本拍背景实体}+平`｜✅封闭 `座={本拍画幅锚}起第K/M个`｜❌裸写「位于画左」｜❌丢掉锚/层位/排座只写一个实体｜❌切角后本拍三键已无该件仍写旧件）。**`画外=`=镜头后对向主体，明确不可见**——【建置】【入戏】**禁止点名**（禁「对着{画外件}」、禁当可见锚、禁写成后景/画左/画右）。宫格参照落画外时的成稿改挂见硬约束 10。上角锚未出现在本拍可见三键且非画内承托 → 禁写入建置/入戏，速查 `锚=` 原样继承。切角/反打须改查**新 ENV 行**（0°画左≠180°画左；0°画外≠180°画外）。构图 `三分` 可留。场记分析内部可写画左↔画右对调，**画外件只可标不可见、不得写入画面句**。缺可见三键=失败。
10. **宫格参照不可见→近镜头中区某侧旁（强制）**：读【宫格图】`四周=` 与本拍 `画外=`。定位行 `锚=` 或四周参照（`后|前|左|右`）等于本拍 `画外=`，或该参照本角不可见 →【建置】【入戏】落位**禁止点该参照名**。人仍 `可见性=V` 时，改写成**离镜头近处的中间主体**的某一侧旁：①优先 `四周=中:`（中心家具，且本拍可见）；②`中=无` 或该中区件本拍不可见 → 改用本拍离镜头最近的可见中景件（`画左=`/`画右=` 近端或白名单中景；**禁**远景 `背景=`、**禁** `画外=`）。句式=`位于{中间主体}{侧}旁`；侧=本拍投影的 `画左|画右|近镜头`，或未点名画外件的世界侧名（原 `辅=近门一侧` 而门已画外 → 改 `近镜头侧旁`，禁残留门名）。✅`位于八仙桌近镜头侧旁，站`｜✅`位于八仙桌画右侧旁，坐`｜❌`位于红木柜台客侧`（柜台=本拍画外）｜❌`位于大门近门一侧`（大门=画外）｜❌裸写「位于中间/靠近镜头」却不点中间主体。速查 `锚=` 仍继承原参照（世界槽位不改）。人已 `暂不可见` → 仍不写建置。
11. **建置不解释环境（最高）**：【建置】【入戏】**不解释**环境背景与内容——禁「远景是…」「画面左侧/右侧是…」、材质/陈设墙导游、四向复述、把 `背景=`/`画左=`/`画右=` 扩写成环境描写。环境已由该拍 `当前环境=ENV:[…]` 对应参考图承担，成稿只点名 ENV。本拍可见三锚与白名单具名主体**只作**角色/可移动道具的**定位锚**与**朝向对象**（`位于{可见锚}{侧}` / `面向={明示}`），点名即止：不写该件外观、不写其自身画面位、不把该件写成待生成环境内容。空镜拍=`空镜／无角色／无道具`+`当前环境=`，禁补环境导游，禁 CHAR/PROP 落位。载具只执行上游 `载具档=` 与已锁衍生，本层不改选。档=`内部ENV` 却挂宿主 = 失败回流。档=`道具沿用宿主`（含三层）**允许** CHAR 相对整车 PROP。档=`整车无人` 禁 CHAR。旧「禁道具上入戏」作废。【入戏】只在交互/微动时点名该件（推门、坐椅、`ENV背景微动=`），仍不解释环境。❌`远景是木质柜台和酒坛陈设墙，画面左侧是楼梯`｜❌建置另起「环境：大厅金碧辉煌」｜✅`CHAR:[@林] 位于八仙桌近镜头侧旁，站，面向镜头，正面可见，目光定，手持=无，佩戴=无`
12. **建置粒度=当前环境（最高）**：一份【建置】只服务本拍一个 `当前环境=`。只写本拍该 ENV 内 `V|部分可见` 者。环境切换=另起【建置】，禁止把不同衍生或不同主环境的角色落位写进同一段。他 ENV 的人只进该拍建置。❌同段并列两套环境里的人。❌先写甲环境远观主体、再写乙环境占用面上的人。

## 1. 建置 / 入戏 / 拍内场记分析
- **【建置】**：首句写满拍摄键（见目标 3）。名单见 2B（=本拍 `当前环境=` 内 `可见性=V|部分可见`，**含本拍无动作者**；粒度见硬约束 12）。V 者各写 **结果落位句**（§4；禁「相对{锚}」）+ **明示姿势**（闭集；抄上拍速查 `姿态=` / 文戏 / 【本场姿势】；切角 ≠ 改姿势；本拍入戏才变则建置仍写旧档；只写`位于…`无姿 = 失败）+ **镜头关系整句**（只抄上游 `体侧=`/`可见面推` 本拍 N，禁写相对180°）+ **动作前**正面朝向（=上拍终态；本拍转身/走位不写进建置；脸朝近镜头半空间 **只写** `面向镜头`，禁「面向{人}即面向镜头」；否则 `面向={明示}`；禁抄 `朝向推=` 的大门/对向件，**禁再写 `背对={实体}`**）+ **手持/佩戴**（见随身件条；无则`无`）+ **可见脸表情**（见表情条）；组按上游序/朝向/距；同簇按本拍 `同簇相对=` 投影写清谁偏哪一可见锚侧、谁上谁下；有可见锚则不写靠近镜头。运动后落点不进。禁工程句「不可见的{名}在机位后方」。画外 / 画幅锚 / 宫格参照不可见 / 不解释环境：硬约束 9–11。**门槛起笔**：入戏含推门 / 入画行走且文戏未写人已在厅内 → 建置停门侧 / 门槛，入完只进终态；文戏已是厅内开口 → 跟文戏落点，禁倒逼拆拍。禁 `选择证据` / 扇区 / `F≈` / `0°侧` / `所在侧=`。**建置禁写名牌**（见名牌条）。
- **手持/佩戴开拍必写（最高）**：画内每人必须在建置整句写清本拍开拍 `手持=` 与 `佩戴=`（无则写`无`）。已提取独立件用 `PROP:[名]` + 部位/体侧/握持态。**禁等入戏「用时」才第一次点名**——本场后续才用的刀/杯/手机，开拍已在身/在手则建置必须先写。尚未取用、物在桌上/架上 → 宿主写 `手持=无`，该 `PROP:` 另作可移动件建置（或待入画）；取用后下拍才改宿主 `手持=`。纯造型无戏耳钉/胸针不写。群演簇写簇持械（有则）。`背朝镜头` 禁写胸前件正面。
- **开拍表情（最高）**：画内每人开拍脸须可核销。`正面可见`/`正面¾可见` → 必写表情词（非「表情自然」空壳；中性须写可辨词如`下颌松、目光平`）。`左侧面可见`/`右侧面可见` 且该侧半脸可读 → 写该侧可见表情。`背朝镜头`、脸被遮、景别不及脸、`部分可见` 且 `露=` 不含脸、`CU|ECU` 主拍不是脸 → **仅当本拍入戏也不写该人五官/神色时豁免**（禁写眉眼口型，亦禁写`表情=不可见`）。入戏只写相对建置的表情变化。
- **同格挤身部分可见（最高；拥抱/押送/牵手）**：上游 `可见性=部分可见` → 建置**只写** `露=` 已锁部位 + 本拍 `画幅=偏画左|居中|偏画右` + 接触落点（按在谁的 `左肩|右肩` 等）。肢体左右=角色自身左/右，禁与画幅左右对调。姿势可写（站/按/搂），**禁**升成全身 `正面可见`/`面无表情`。`部分可见` 缺 `露=` 或部位无 `左|右` = 失败。接触带须能核销：押送两侧分写谁偏画左/画右、谁的哪只手按谁的哪侧肩；牵手双方写出牵住的那只手；拥抱写出谁的哪臂绕谁哪侧。
  - ✅`CHAR:[@甲] 位于{可见锚}偏画右，站，露=右手+右前臂（按在 CHAR:[@乙] 右肩），手持=无，佩戴=无`
  - ✅`CHAR:[@丙] 位于{可见锚}偏画左，站，露=左手+左前臂（按在 CHAR:[@乙] 左肩），手持=无，佩戴=无`
  - ❌全身 `正面可见` 顶替 `部分可见`+`露=`
  - ❌`露=手按肩`（无左右、无谁的手/谁的肩）
- **接触未结束须复述**：上游 `触≠无` 且本拍未松开 → 建置接触句与 `触=` 同核（见「接触关系守恒」），不得只写分立站位。
- **有表情禁背对（最高；改建置或衍生）**：本拍【入戏】或上游对该人写了五官/神色/脸色/眉眼/口型/苍白脸颊/得意/恐惧/冷酷等 → 该人写表情那一瞬**不得** `背朝镜头`。无转身 → 建置镜头关系必须 ∈ `正面可见|正面¾可见|左侧面可见|右侧面可见`（半脸可读）。有转身 → 建置可暂背对，表情只写在入戏转至可读面之后。**禁止**建置背对却入戏写神色；**禁止**删表情凑过。冲突则：改抄可读 `体侧=`（上游应已改挂其 `主拍ENV`/对打角）；或本拍入戏先转到可读面。上游已锁背面且本拍必须读脸 = 失败回流现场编排，改挂衍生。
  - ❌建置 `背朝镜头` + 入戏写神色/五官
  - ✅可读面 + 表情；或先转入戏转至可读面再写神色
- **【入戏】**：只写相对本拍【建置】初态的**变化**（目标 6）。无变化禁复述初态。上游本拍已有内容必须整段写入（硬约束 0）。有走位 / 转身 / 出入画 / 变姿 → 同样整句写新可见面 + 已锁方式落点 + 新姿势（禁只写「走两步」「转过身」「坐下」）。无走位且未变姿则不复述位置 / 可见面 / 姿势。不写锁档键值。ENV 背景微动只在本段。衔接：起笔 ≡ 本拍建置；变化进终态；下拍按已锁可见性承接。名牌见名牌条。
  - ❌入戏写`跨度=越级` / 无变化却复述初态 / 无对白却写开口闭嘴 / 相对走位写成无锚画左 / 把「语气层+台词」写进开口行
- **【场记分析】（拍内；【入戏】后）**：成对标记。**先写在场核销**（开拍人数 / 本拍逐主体宫格与可见性及因 / 入画出场 / 收拍人数），再写输入【取景锁定】推导键 ⊕ 建置 ⊕ 入戏 → `变化过程` + `终态画面纵深` + `速查更新`。终态只写本拍画内；速查 / 差集 / 收拍在场覆盖未出画全员（`V`→`可见性=画内`；上游 `暂不可见` 留站位+因，**仍计入收拍在场**，不写画面句）。同 ENV 下拍从速查与上拍收拍在场继承，建置只写该拍已锁 `V`。ENV 变取 `所在侧` 查 §7A 后重写 V 者画面词。无运动：V 者复述终态关系。场头禁再写该段。本段不进分镜。
- **集合**：`终态=(建置−出画)∪入画/突现`。中途入画者不进建置、不进差集，过程写入戏、终态写满字段；中途出画者建置含、入戏写过程、终态剔除、差集 `{名}|出画|经=…`。切角 ≠ 出入画。格式见 §7。
- **不可见**：执行上游 `暂不可见`（特写非主拍 / 锚不在本角 / 层位出画），不写建置、不写出画。`D` 只写入戏声音。`待入画`/已离场不写。上游已锁 `V|部分可见` 却漏建置 = 失败。中途走位出画才改集合。
- **可移动主体**（角色 / 具名龙套 / 群演簇 / 动物 / 载具 / 法相金身 / 已入场独立可移动道具）：同等落位 + 朝向 + 进出场。配饰跟宿主；宿主暂不可见则配饰不进建置。群演簇**仅当簇仍在画**才写人数 / 队形 / 主导可见面；上游已拆簇主拍则具名对白/近景拍不把簇塞进近身。人—车 / 人—骑分行。**满幅→收紧**：CU 只建置上游 `V`（通常仅主拍）；其余按上游 `暂不可见` 留速查。
- **不提前入场**：剧情角色 / 独立道具首次剧情 Beat 前 = `待入画`。豁免 = 氛围龙套 / 群演簇（须依据）。待入画者禁塞进建置、终态、差集或速查。
- **出入画另起拍**：该拍只写出入画（入戏写经哪口、行进径向、落定/离场）；落定后下一拍才对白 / 主动作。切角 ≠ 出入画。禁只改集合不写过程。
- **动作覆盖**：【入戏】对建置内每人 / 每簇至少 1 个可见微动（计为变化，不是「无变化」）。剧情强制静止须写静止证据。受者响应须针对该动作，不能用旁观微动代替。**打出角色名牌物理文字不算动作**，不得顶替本条微动。
- **环境背景微动态（只写入戏）**：每拍【入戏】须有 `ENV背景微动=` 一行。**选件序**：①所属主环境已点名 `背景微动件=` 且本拍白名单或**可见**画幅锚（`背景=`/`画左=`/`画右=`，**不含 `画外=`**）可见 → **优先写该件**及其 `可用动势`（幅度 subtle，不改行动/走位/对白）；②该件不可见、在 `画外=` 或 `背景微动件=无` → 再从当前环境已有细微件选（本拍 ENV `背景=`/`画左=`/`画右=`、固定清单/未落清单、本拍【建置】已点名的小件：帘/穗/灯焰/烟气/水纹/叶/尘/旗角/窗纱/烛火/蒸汽/纸页边等；**禁选 `画外=` 件**）；③仍无可选 → `ENV背景微动=无`（**宁愿空，禁凑件**）。**禁杜撰**原环境没有的物件（❌原无碗却写「碗沿轻晃」）；**禁**拿桌/柜/门/柱/床/墙/柜台等大件当微动锚来凑行。禁括号备注。光斑 / bokeh 不进。【建置】禁写本行。人群动势不替代本行。空镜拍建置=`空镜／无角色／无道具`，本行仍写（有则微动，无则`无`）。
- **开口｜闭嘴（最高；整行原样继承）**：上游本拍有开口行 → 【入戏】**整行原样抄入**：`开口 |` + 说话人 + 八键全文（`voice_type`｜`voice_identity`｜`tone`｜`speed`｜`volume`｜`rhythm`｜`stress`｜`pause`）+ `{台词原文逐字}` + `| 闭嘴 |` + 听者。`{台词}` **必须有花括号**；上游已是原文但未包 `{}` → 只补花括号，不改词。开口/闭嘴与角色用 `|` 并排，中间夹完整对话。禁括号紧贴、禁闭嘴写在台词前。无对白、空镜、纯走位 **禁止**出现开口/闭嘴行。OS/旁白/VO/自白仍算有台词，须整行抄入；**可与动作/画内对白同拍，禁漏 VO 行**。
  - ❌`开口 | CHAR:[@甲] | 语气层+台词 | 闭嘴 | CHAR:[@乙]`（把合同骨架当成交稿）
  - ❌`… | 台词原文。 | 闭嘴 | …`（台词未用 `{}` 包裹）
  - ✅`开口 | CHAR:[@甲] | voice_type=对白｜voice_identity=…｜tone=…｜speed=…｜volume=…｜rhythm=…｜stress=…｜pause=… | {台词原文逐字} | 闭嘴 | CHAR:[@乙], CHAR:[@丙]`
- **本集首次正面出场物理文字名牌（强制 · 读【本场角色标签】 · 不算动作 · 只跟该人主动作后）**：注入行 `CHAR:[@名]｜标签=…｜标签_en=…｜标签字体=…｜标签字色=…｜裸名=…｜裸名_en=…｜字幕=待落|已过|无`。`字幕=` 只是落态开关，**不是**对白硬字幕。**打出角色名牌物理文字不算动作**：不是角色行为、不占动作覆盖、不进动作链、禁写成「打出名牌」。名牌是片内图形叠字，**只能跟在该人本拍【入戏】主要动作后面**，**不是**建置的一部分、**不是**段末清单。
  - **语种（最高）**：先读 `# Project Context` / `Language` / `project_language`。中文（`zh`/`cn`/`中文`/`Chinese`）→ 字样=`裸名`+`标签`（标签为`无`则只打【裸名】）。英文（`en`/`English`/`英文`）→ 字样=`裸名_en`+`标签_en`（`标签_en`为`无`则只打【裸名_en】）。未明确 → 跟剧本主语言（正文以汉字为主用中文侧，否则英文侧）。**禁**中英并列、**禁**用错语种上屏（英文项目打中文名/中文标签，或反向）。该侧裸名为`无`或缺 `_en` 裸名 → 不写名牌，场记分析标 `首登名牌缺口=缺{语种}裸名`，禁拿另一语种顶上。标签为`无`**不是**缺口，禁臆造职业/定位凑牌，**禁推理标签**，**禁从身份、称呼、服制或叙述补标签**。注入标签若含剧情或角色定位词，当`无`处理，只打裸名。
  - **真脸闸（最高；蒙面/易容无名牌）**：本拍该人蒙面 / 易容 / 面具 / 面罩 / 假面 / 遮面 / 真脸不可读，或注入 `名牌条件=须真脸` 而本拍尚未见真脸 → **不写名牌**（连裸名也不打），即使 `字幕=待落`。等该人真脸 `正面可见`/`正面¾可见` 且已有主动作后再挂。全场真脸从未可读 → 不写、**不标** `首登名牌缺口`（不是缺口）。`字幕=无`（含上游 `名牌=无`）→ 禁写。
  - `字幕=待落` 且本拍该人镜头关系 ∈ `正面可见|正面¾可见`（脸/双眼可读）→ 先写该人【入戏】主要动作（走位/转身/入画落定/取用/开合/发力/接触/递交等体动），**紧跟该主动作句后**写恰好一行：`画面打出物理文字标签：【{字样名}】{字样标签}】｜字体={标签字体}｜字色={标签字色}`。**禁**套 `CHAR:`。同人全场只写一次；写过后其余拍禁再写。注入已有字体/字色（非`无`/`待补`）→ **原样抄**，禁改书体或字色。仅`无`或`待补`才跟 `Global_Style` 时代/基调补一书体+具名色，禁套对白字幕白字黑边。
  - **一人一挂（最高）**：写完甲的主动作 → 立刻甲名牌 → 再写乙的主动作（乙合格则紧跟乙名牌）。**禁止**挂建置句、**禁止**先于该人主动作、**禁止**把多名牌攒到入戏段末或建置段末。
  - 本拍为 `背朝镜头`、空镜、主观且该人不可见 → 不写，等后拍该人首次 `正面可见`/`正面¾可见` 且已有主动作（或开口）。
  - **中途入画**：该人不进本拍【建置】；入画落定=该人主动作 → 名牌紧跟该人入画落定句，不堆段末、不与其他人名牌攒写。
  - 本拍该人无主动作仅对白 → 跟在该人开口句后（开口不是动作，名牌仍不算动作）。本拍无主动作亦无开口 → 本拍不挂，等后拍。
  - 全场 `字幕=待落` 却从未 `正面可见`/`正面¾可见`：在该人首次 `左侧面可见`/`右侧面可见` 仍可读半脸的拍，挂该人主动作后补写；仍无则场记分析标 `首登名牌缺口={名}`，禁为名牌改朝向。
  - `字幕=已过|无`、群演簇 → **禁写**。
  - ✅中文项目 `CHAR:[@陈] 右手推开木门落入厅内。画面打出物理文字标签：【陈】客栈掌柜】｜字体=魏碑｜字色=鎏金`｜✅标签为`无`时 `【陈】｜字体=魏碑｜字色=鎏金`｜✅英文项目同结构用 `【Chen】Innkeeper】｜字体=Title Card｜字色=Ivory`｜❌`【陈】落魄千金】`（剧情泄露）｜❌`【陈】女主】`（角色定位）｜❌建置「可见右肩与右颊」后立刻打名牌｜❌`CHAR:[@陈] 打出物理文字标签`（当动作写）｜❌英文项目写`【陈】客栈掌柜】`｜❌`【Chen】客栈掌柜】`｜❌套 `CHAR:`｜❌写成画幅底部对白硬字幕｜❌全员动作后再一起打出多名牌

## 2. 连续性与走位
每拍先对上拍终态与本拍已锁取景做核对，再写建置 / 入戏 / 终态。

**动作连续**
- 上拍未完成的动作链本拍【入戏】承接，禁跳步、禁蒸发受者响应；本拍入戏未写完的链须留给下拍续，禁提前蒸发。
- 姿态 / 持物 / 朝向对象连续；变则须有本拍可拍过程（只写入戏）。**姿势闭集**（与【本场姿势】同核）=`站|立|坐|翘脚坐|盘腿坐|平躺|俯卧|向左侧躺|向右侧躺|蹲|跪|半跪|倚|骑|腾空`（`立`=`站`）。建置整句必须明示该词，禁只写`位于…`。抄上拍速查 `姿态=`；无则抄文戏 / 【本场姿势】。切角 ≠ 改姿势。入戏有过渡链才改终态姿态，建置仍写旧档。
- **朝向时序（最高）**：本拍建置 `面向=` + `镜头可见面` = 上拍终态（上拍若转身，新朝向从**本拍建置**才第一次落地）。本拍入戏若再转身：建置仍写动作前档；新朝向只进本拍终态/速查，**下拍建置**才改写。同 ENV 无转身则可见面不改档。❌把本拍转后朝向写入本拍建置。❌因换主拍/收景别重算可见面。仅 ENV 变且无转身才按 §5 / §7A 重写可见面（面向对象不改）。
- **随身件守恒**：开拍写法见 §1。无离身链 → 可见宿主抄上拍挂载；宿主不在建置名单 → 只进速查。离身只写入戏，新挂载进终态。发声屏写现位 + 屏面朝向。
- **接触关系守恒（最高；未结束则每拍建置复述）**：上拍终态 / 上游 `触≠无`（牵手/拥抱/押送/按肩/搂腰/接吻）且本拍入戏尚未松开 → 本拍【建置】**必须再次写明**该关系（谁的哪只手/哪臂接触谁的哪部位），即使本拍入戏不再写「牵着/抱着」。禁只靠速查暗示、禁下一拍两人各自独立站位。本拍入戏才松开 → 建置仍写动作前接触态，松开只写入戏，**下拍建置**才去掉。双方都 `V|部分可见` → 双方建置句都写（或一方写完整接触、另一方写被牵/被抱/被按）。一方本拍 `暂不可见` → 可见方仍写接触（手伸出画 / 仍被画外的手牵住），对方 `触=` 留速查。抄上游 `触=` 的式/己/对左右，禁改手、禁与画幅左右对调。
  - ✅上拍已牵手，本拍对白 MCU 建置仍写 `CHAR:[@甲] …右手牵 CHAR:[@乙] 左手`
  - ✅上拍拥抱未结束，切正面仍写 `CHAR:[@甲] 双臂环住 CHAR:[@乙] 左肩`
  - ❌上拍牵手，本拍只写两人分立「位于…站」无牵手
  - ❌建置写成已松开，入戏才写放开
- **入戏跨拍衔接**：入戏不得从与本拍建置矛盾的状态起笔（人已换位、手已换物、半句对白无据另起）；亦不得写到下拍无法承接的终态（半步悬空、物蒸发、动作无落点）。下拍从本拍速查继承站位，建置只写下拍仍可见者；下拍【入戏】再写新变化。

**位置连续**
- 真源=已锁方式（§4）+ 速查 `所在侧`。禁 `扇区+F`。
- 开拍站位 ≡ 上拍速查：同 ENV 不整句抄终态落位词（画幅锚可按本拍可见三键替换，禁换入 `画外=`），但 **面向 + 镜头可见面档必须逐字抄上拍**；`宫格=` 抄上拍终态格（上拍走位换格则本拍建置已是新格）。ENV 变写【上一ENV→触发→本ENV】后按 §5 / §7A / 上游 `换算=0→{N}` 做**宫格投影**（格名不改，体侧/近远/画幅词必改），禁切角瞬移、禁只换 ENV 名。上游 `暂不可见` 只进速查，不写建置。
- 反打 = 同主名对向已锁 ENV。换主名触发不标反打。来源 = 紧邻上拍终态，禁回取更早建置。

**关系连续**
- 仅本拍画内者互写前/后/左/右 + 尺度距离 + 面向。同锚或同绝对格须执行上游 `同簇相对=本拍投影`：整句交代**本拍三维**（偏画左/居中/偏画右、上/平/下、近镜头侧/同层/远镜头侧）。ENV 变用本拍投影，**禁**把 0°「甲偏画左」原样写进 180°/90° 建置。与画外者的关系只进速查，不写建置。走位后关系必须可从开拍关系 ⊕ 本拍路径推出，并更新投影。
- **身体接触未结束 ≠ 普通左右关系**：牵手/拥抱/押送等须按「接触关系守恒」在**每一拍建置复述**，不得只写「在其左侧」代替仍牵着/仍抱着。同 ENV「不整句抄终态落位」**不豁免**接触句。
- 正反打场：走位不得无过程把相向拆成同向，或把同向拧成相向。关系变须写在 `变化过程`。松开/改握只写入戏。

**轴位连续（不越轴）**
- 轴线 = 本场已锁 `spatial_axis`。站位、走位路径、停驻点、左右屏必须落在轴线同一侧（左右屏=构图/轴线用语；**相对落位写「锚的画左/画右」，不是无锚的画面画左**）。
- 已锁 `axis_crossing=None`：禁跨轴；左右屏相对上拍保持同侧。
- 已锁 `PlannedReverse`：沿轴线对向，左右屏对调合法，仍算守轴，**不是**越轴。
- 已锁 `MotivatedCross`：允许跨轴，走位终点落到轴线另一侧，写 `越轴=是｜动机=` 该拍已锁动机。
- 失败：未锁越轴却因走位跨到轴线对面；无反打依据拧反左右屏；把越轴写成普通反打；改挂方案外角来圆越轴。回改走位。
  - ❌`守轴核销=通过`（无人名） / 未锁越轴却写`跨轴`

**走位核对**（相对已锁取景；不通过则回改落点或拆已锁空间硬锁拍，禁改挂方案外角）
1. 开拍落点 = 上拍终态，无瞬移。
2. 路径物理可拍：净空、步幅够、门径向闭合。**障物评估（有走位必写）**：直线开拍→终点扫本拍白名单与建置已写实体。无挡=`障=无`。有挡=`障={具名}`，路径须补 `绕={具名}之{画左|画右|近镜头|远镜头}`（承接文戏已写画侧；无则据已锁观察向裁定）；直线穿桌/柱/人/门扇=失败。绕障节点须仍在已锁活动空间且不越轴。
3. 终点仍在已锁活动空间；本拍必见项仍 ⊆ 已锁白名单。
4. 走位后距离档与已锁景别同向（贴身 ↔ MCU/CU；数步对峙 ↔ WS/FS）。
5. 触达对象开拍已在画且一臂可达；否则先切已锁可见该物的角。
6. 停驻后仍留后续动作净空（贴墙无退路、叠脚无步幅 = 失败）。
7. 路径与终点不越轴（上条）；`守轴核销=` 必填。

**走位细化**（写入 `变化过程` + `终态画面纵深`；【入戏】用自然语言同步写出）
- 有走位：`变化过程=`=`{名}:自{开拍}→经{路径/绕障/门/步数或臂距}→到{终态}｜障=无|{具名}｜绕=无|{具名}之{画左|画右|近镜头|远镜头}｜锚=…｜侧=…｜辅=…｜宫格={终点0°格}｜细节=… 距=…`。相对自/到禁无锚画左/前景。【入戏】须写路径（有障须写出绕过）+停驻后可见面+已锁方式落点。**走位换格（最高）**：本拍建置/`宫格=`=开拍格（抄上游本拍定位）；终点格写入本拍终态+速查 `宫格=`；下拍建置必须用该终点格。换格则本拍终态 `宫格=` ≠ 开拍格。入画落定=入格写入终态；出画=速查剔除。同格内挪步可不改 `宫格=`，须改则先改 0° 相对再按本拍 N 投影。
- 停驻须落点可辨，不得与他人 / 锚混淆。
- 无走位：`走位=无`，本拍场记分析复述**画内**终态关系，不可见者只在速查留站位且**仍计入收拍在场**；**入戏不复述**。速查 `宫格=` 抄上游本拍开拍格。
- 多门路径见 §6。

## 3. 成稿范围
成稿**只出** `[BEAT_STREAM_START]`…`[BEAT_STREAM_END]`。禁回写场号、【场景名称】、环境块、【主体定位方案】【Beat主体定位】、提取块、【实体覆盖】、位置规划 / 角色位置 / 动作空间 / 露脸 / 场级【场记分析】。

**开场全景（写入 B1 场记，不另起场头表）**：对照上游【主体定位方案】`入场=`/`入画@`/`经=`。`入场=开场` 的 CHAR + 可移动 PROP = B1 `开拍在场=`（禁只列主拍/有戏者，禁漏无动作开场人/件）。待入画者不计入 B1 开拍人数，入画落定后计入该拍 `收拍在场`。

**【场记分析】** 每拍成对块，写在该拍【入戏】后、`[BEAT_END]` 前。须写满 §7 在场核销 + 0–8。输入若仍有场级 `B{n}=` 拆入对应拍后删除。

排位：地位 → 剧情 → 重要者 C 位。走位总账与初/变/终写入该拍场记 `变化过程` / `终态` / `速查`，不另起位置块。

## 4. 定位成稿（执行已锁起始帧；不补锁）
抄本拍【Beat主体定位】`可见性=V|部分可见` 各行的方式键，不改 XOR（**无动作的 V 者同样抄**）。角色组抄该行 `序=`/`朝向=`/`距=`。同簇抄该行 `同簇相对=本拍投影`（画幅/高低/纵深）写入建置整句；禁回抄【主体定位方案】的 `0度锁` 画幅词。`D`/`待入画` 不写建置。`暂不可见` 不写建置、必进速查。禁为凑人数补未入该拍定位表的人。入戏不写 XOR 键。缺项或度数/`F≈`=失败。
- **相对（约束）**：抄上游锚，优先本拍可见件。宫格参照=画外 → 硬约束 10。成稿须：①主语=该人；②位于可见锚的可区分一侧；③世界侧名切角不改（该侧名点到画外件则改中间主体的 `画左|画右|近镜头` 侧旁）；④可见锚已能区分该侧 → 禁写靠近/远离镜头。本拍未锁的轴不写。相对句禁写 `前景|中景|后景`，保留 `距锚=`。
  - 句式=`CHAR:[@名] 位于{可见锚}{世界侧名或本拍投影侧}，距锚={贴身|一臂|两步|三步|五步远|十步外|{N}步}，{姿势闭集}，面向{镜头|明示对象}，{正面可见|正面¾可见|左侧面可见|右侧面可见|背朝镜头}，{可见则写表情}，手持={PROP:[名] 左手|右手|双手|{握持态}|无}，佩戴={PROP:[名] {体侧}/{部位}|无}`。姿势闭集见 §2。失败项见硬约束 8。
  - **高低成稿（最高）**：键值 `高低=平` = **齐站**（脚在地面或与同桌/同簇同一站立高度），**不是**侧名形容词。成稿 **禁** `平的近门一侧` / `…侧，平，` / 孤字「平」。齐站默认**省略**高低。仅有高差才写可核销动作：`站在{凳/踏}上偏高`｜`俯身偏低`｜`跪/蹲偏低`｜`躺卧偏低`。高差词不顶替姿势闭集（仍须写`站`/`跪`/`蹲`/`平躺`等）。
  - ❌`相对主桌，位于该主桌靠近镜头、居中、平的近门一侧`（过程词+孤字「平」当侧名定语）
  - ❌`位于主桌近门一侧，面向镜头，正面可见`（有落点无姿势）
  - ❌`位于主桌近门一侧，坐，面向镜头，正面可见`（缺表情、缺手持/佩戴）
  - ✅`位于主桌近门一侧，坐，面向镜头，正面可见，下颌收、目光平，手持=PROP:[茶杯] 右手，佩戴=PROP:[玉牌] 正面/胸前`
  - ✅`位于主桌近门一侧，翘脚坐，面向镜头，正面可见，唇线绷，手持=无，佩戴=无`
  - ✅有高差：`位于主桌近门一侧，站，站在绣墩上偏高，面向镜头，正面可见，眉心微蹙，手持=无，佩戴=无`
  - ✅无可见锚：`位于{本拍画左实体}侧，站，背朝镜头，手持=PROP:[长剑] 左手，佩戴=无`（背朝镜头不写表情）
  - ✅宫格参照=画外、中区可见：`位于八仙桌近镜头侧旁，站，面向镜头，正面可见，目光定，手持=无，佩戴=无`
  - ❌宫格参照=画外仍写：`位于红木柜台客侧` / `位于大门近门一侧`
  - ✅躺：`位于榻近窗一侧，向左侧躺，右侧面可见`
  - **机位对齐**：切角后世界侧名不改；若仍须写近/远，按新机位重判，禁止沿用旧角。0° 靠近镜头的人，180° 必须写成远离镜头（或改用该拍可见锚，不再写近远）。
  - **围桌**抄 `辅=`+`座=该侧左起第K/M个`，写成 `位于{桌}{辅名}`；禁「相对{桌}」；禁只写「靠桌」。
- **绝对**：`前景|中景|后景` + `{本拍画左实体}|中央|{本拍画右实体}`，与本拍`主体落点`同向。后景主位优先写本拍 `背景=` 实体。高低：齐站省略；有高差写 `偏高|偏低`+承托（禁孤字「平」）。整句同样须明示姿势闭集。
- **封闭**：抄上游 `排=第N排` + `座=左起第K/M个` + `功能=驾驶座|副驾|后排左|后排中|后排右|操纵席|…`。建置整句须能读出第几排第几个+功能名+姿势（默认`坐`，除非文戏明文站/蹲于舱内）。反打只把「画左起」改查新 ENV 画幅锚，**不改**世界 `第N排`/`功能=`/`K`。禁收成「在车上/后排」。
- **配饰**：`挂靠={角色}`｜`部位=左肩|右肩|左腰|右腰|胸部上方|左手|右手`｜`体侧=正面|侧面|背面`。
同句禁叠无锚绝对 + 相对锚。相对/封闭禁写前中后景，保留 `距锚=`。画内者互写前后左右+距离；同簇点名各人落在可见锚哪一侧。锚=画外 → 硬约束 10。速查 `锚=` 仍继承。

**可见面整句**（键值可留场记；正文必写镜头关系词）：
| 档（成稿） | 须点名 |
| :--- | :--- |
| 正面可见 / 正面¾可见 | 哪侧脸、胸腹是否朝镜、双眼/口型是否可读；**必写开拍表情** |
| 左侧面可见 / 右侧面可见 | 哪一肩、哪一侧颊/鼻梁轮廓朝镜；半脸可读则写该侧表情，不可读则不写表情 |
| 背朝镜头 | 后脑 / 后颈 / 肩背；禁写五官与胸腹正面；**仅本拍入戏也不写该人神色时豁免**；入戏有表情 → 改建置可读面或改挂衍生 |

切角未转身者按新观察向重写可见面句，禁粘贴上拍「正面朝镜头」。

## 5. 朝向与镜头可见面
档位（成稿镜头关系；画内每人必写）：角色 = `正面可见`｜`正面¾可见`｜`左侧面可见`｜`右侧面可见`｜`背朝镜头`。载具 = `车头/车尾/左/右侧身朝镜头`｜`¾车头/¾车尾`。动物 = 身躯镜头关系 + `头朝{对象|左|右}`。
镜头关系只抄上游 `可见面推`/`体侧=`。场记可按对向换算；**成稿不明示** `180°` / `相对180度` / `面向N°` / `侧面90度`。

**朝向禁角度**：只写 `面向{明示对象}` 或脸朝近镜头半空间时 `面向镜头` + 镜头关系档。禁 `面向N°` / `F≈` / `面向中心`。
**朝向成稿闸（最高）**：【建置】【入戏】分写两件事——①**正面朝向** `面向=`：脸朝本拍近镜头半空间 → **只写** `面向镜头`（禁并列 `面向{明示人}`，禁「面向{人}方向（即面向镜头）」，禁把落点锚写进面向短语）；明示对象不在近镜头半空间 → 只写 `面向{明示}`。②**镜头关系**（必写）：`正面可见`｜`正面¾可见`｜`左侧面可见`｜`右侧面可见`｜`背朝镜头`——**只抄**上游【宫格图】`可见面推=` 本拍 N 或【Beat主体定位】`体侧=`。上游 `朝向推=` / `背对=` **只进场记分析**，禁写入建置/入戏整句。面向已写则**禁止再写 `背对={实体}`**。画外禁点名见硬约束 9。转肩可用场记四向，不得把锚名或 180° 写进画面句。
**落点画位 ≠ 可见面（最高）**：人所在画位 ≠ 镜头关系。侧面只由脸朝哪一半空间推出，不得用所在格猜。映射见朝向三联。

**转身过程拍（转肩只从建置判）**
时序走 §2。入戏出现转身 / 转面 / 调头 → `拍型=转身过程`。禁同拍开口 / 走位 / 取物。轴未变可同父 ENV。禁写转了多少度。
- **建置**：只写动作前档。禁写成转后面向。
- **入戏**：只写连续转体（可见面随转写出，不写 XOR）。五件套只进终态：`向{左|右}肩转 → 终态面向{对象} → 终态镜头可见面 → 终态姿态 → 终态落点`。
- **下拍建置**：才抄本拍终态新朝向。❌本拍建置与终态面向相同却写入戏「转身」。

**转肩判定（角色自身左/右，不是画面左/右）**
只以**本拍建置**为开拍态，禁止用终态回推。
1. 读建置 `面向=A`（明示对象或 `面向镜头`）。`面向镜头` 时 A 的几何锚取场记 `朝向推=`（无则取本拍近镜头/机位向），**不把该锚名写入建置**。
2. 用**本拍** ENV `背景=`/`画左=`/`画右=`（及近镜头侧）把 A、B 各落入四向之一：`近镜头|远镜头|画左|画右`。B=入戏要转到的明示对象；无明示则用 `朝向推=` 或三锚几何。缺三锚=失败。
3. 按建置面向所定的角色左/右，取从 A 到 B 的较短转：

| 建置面向所在向 | 角色左 | 角色右 |
| :--- | :--- | :--- |
| **远镜头**（对背景） | 画左 | 画右 |
| **近镜头**（对机位） | 画右 | 画左 |
| **画左** | 近镜头 | 远镜头 |
| **画右** | 远镜头 | 近镜头 |

B 在角色左 → `向左肩转`；在角色右 → `向右肩转`。B 与 A 对向（约一转半）→ 拆成转身过程拍或先锁越轴，禁同拍硬拧 180° 还开口。
❌用画面左/右当角色左/右。❌用转后面向当建置再回推转肩。❌默认某类陈设（门/窗）在某一侧。

**切角只换观察向**：未走位未转身者，相对锚名 / 辅边位 / 姿态 / `所在侧` / 世界槽位（`排=`/`辅=`/`功能=`/`K`）不变；**看谁**（世界对象）不改，成稿 `面向=` 按本拍半空间重判 XOR。用 `所在侧` 查 §7A 得画面位。相对近/远与画幅按本拍 N 投影（90/270：原画幅轴与纵深轴互换），左右改查**新 ENV 画幅锚**，禁为查表改填前中后景。绝对层位按投影重写，画位改写新 ENV 左右实体。同簇三维跟本拍 `同簇相对=本拍投影`。镜头可见面**四向都投影**：抄上游 `可见面推`/`体侧=` 该 N 档（下表覆盖 180；90/270 用 §0.2C 四向表，可换正背）。禁经 `扇区=` / `F≈` 换算。禁「90° 只换左右面、正背照抄」。

**朝向三联**：成稿闸见上。缺 `可见面推`/`体侧=` 时才用：脸朝近镜头 → 正面 + `面向镜头`；脸朝远镜头 → 背面；脸朝画左 → `右侧面可见`；脸朝画右 → `左侧面可见`。落点画位 ≠ 可见面。禁同句「面向{人}即面向镜头」，禁 `面向画左/画右` / `面向N°` / `面向中心`。

**落笔序**：查【宫格图】本拍 N 的 `可见面推`/`体侧=` → 定正面朝向（近镜头半空间=`面向镜头`，否则明示具名/`无`；禁「即」） → 写镜头关系档（抄表，禁写180°） → 写结果落位（可见锚+世界侧名；宫格参照=画外则 `位于{近镜头中区}{侧}旁`；无可见锚才写本拍近/远） → **写姿势闭集** → **写手持/佩戴（无则无）** → **脸可读则写表情，不可见则不写** → 速查抄 `所在侧` + 面向 + 镜头关系 + 落位 + `姿态=` + `手持=` + `佩戴=` +（脸可读才）`表情=`（不抄度数；`朝向推=`/`背对=` 可进速查/场记，不进建置句）。

**反打 ≠ 转身**：反打时未转身者面向对象 / 姿态 / `所在侧` 不变，镜头可见面随观察向对调。来源 = **紧邻上拍终态**（上拍是转身过程拍则取其终态新档，禁回取该拍建置旧档）。相对锚名与辅边位不改写，近/远镜头对调，左右改查新 ENV 画幅锚实体。

**180° 反打换档**（仅对向 180°，`N新=(N旧+180)%360`）。90/270 **不走「只换左右」捷径**，走上游 §0.2C 四向表（依 0° 面朝：正面可投成左/右侧面，侧面可投成正面或背面）。

| 紧邻上拍终态镜头关系 | 本拍开拍镜头关系 |
| :--- | :--- |
| 正面可见 / 正面¾可见 | 背朝镜头 |
| 背朝镜头 | 正面可见 / 正面¾可见 |
| 右侧面可见 | 左侧面可见 |
| 左侧面可见 | 右侧面可见 |

层位按对向对调（前景↔后景、画左↔画右）。**纵深词必须对调**：上拍「靠近镜头」→本拍「远离镜头」（或改用本拍可见锚、不再写近远）。世界槽位（`近门一侧`/`主位`/`辅=`）不随近远一起改口。`投影恒等` 仅轴心层位/中央，≠「可见面也没变」、≠「近远也没变」；正背面必须换。换档后该人锚已不在本拍画幅 → 执行上游 `暂不可见`，不写建置。禁复制上拍「正面朝镜头」；禁复制上拍「靠近镜头」；禁因「仍是说话人 / 要露脸」保持原档。若须反打后同一可见面，须先另起转身过程拍。

**朝向承接**：时序走 §2。同 ENV 无转身 → 可见面与 `面向=` 抄上拍终态。仅 ENV 变且无转身 → 世界对象不改；`面向=` 按本拍半空间重判 XOR；可见面抄 §0.2C 该 N 档（含 90/270）。❌同 ENV 因换主拍/收景别重算可见面。❌90°/270° 仍抄 0° 正面/`面向镜头`。

**背朝镜头门禁**：禁写五官 / 口型 / 胸腹正面。入戏有该人神色 → 走 §1「有表情禁背对」。

**入画径向**：后景门入 → 朝镜头 → 终态 `面向镜头` + `正面可见`（场记可留背对门，建置不写）；近端门入 → 向纵深 → 终态 `背朝镜头`（仍只写正面朝向，不写背对门）。

**驾驶舱可见面**（无转身、全员面向驾驶台 / 前窗）：

| 当前 ENV | 可见 | 后景 | 不可见 |
| :--- | :--- | :--- | :--- |
| `0度` 贴操纵员后脑 | 操纵员后脑 | 前窗 / 驾驶台 | 其身后人员 |
| `0度` 舱尾望前 | 全员后脑 | 前窗 | 任何人脸 |
| `180度` 拍后方人员 | 后方人员正面 | 后窗 | 操纵员；前窗 |
| `90/270` | 近侧门窗 + 全部座位侧面 | 对侧窗 | 半舱漏座 |

禁 `0/180` 标后排 + 司机 Two-Shot。`180度` 后方人员可写 `面向镜头正中`，面向仍是驾驶台 / 前窗，禁写 `F≈0`。

## 6. 空间执行
- **出入舱**：入舱过程拍仍挂仓外衍生；落定后另起拍，触发 = `入舱切主环境`，ENV = `{N}度{仓内主名}`。出舱落定后另起拍，触发 = `出舱切主环境|回切仓外主环境`；建置 = 所经那扇门外侧旁，载具外部整体入画；下一拍抄同扇门旁落点。入戏执行上游 `过阈运镜=`：外→内写连续推过具名门/窗/舱口，内→外写连续拉过同一口；禁改成硬切换空间。过程未完成拍不切 ENV，落幅拍才切。
- **多门路径**：入 = `门位→落点/座位`；出 = `舱内位→门位→门外落点={外部本体}之{门位}外侧旁`。
- **触达**：接触对象须在开拍可见集且一臂可达；否则先切已锁可见该物的角。
- **载具**：入戏只写运动 / 操作事件；途经、停靠、上下车起终点进建置 / 终态。
- **门窗开关（评估；有则强制；按环境合同匹配改写）**：凡入戏含开/关/推/拉/滑门窗（含车门/舱门/厢门/窗扇），**先读该口环境规划合同**（四向+固定清单；复用场读 `本场门窗初态`）：`扇型=单扇|双开` + `开闭=` + `开向=里|外|左滑|右滑` + `门轴=` + `把手=`（双开另读左右扇各份与`通行扇=`）。缺合同=失败，禁常识另造。文戏过程只作意图（谁开哪口、开或关）；**推|拉、接触点、开向词、人站侧、扇展侧、开哪一扇与合同冲突则改写**，左右手可承文戏，但触点不得落**该扇**门轴侧（冲突改到把手，必要时换手）。不改对白、不改门口注册名（裸「开门/开车门」须点名已锁口；双开再点左扇|右扇|双扇）。
  1. **建置开拍态**：该口入画则写开拍开闭（≡上拍终态；首拍=环境初态/`本场门窗初态`）。双开须分写左扇/右扇开闭，禁合成一句「对开门半开」。半开/全开须带该扇扇展占位核销 `开向`（里=占室内/舱内；外=占室外/车外）。门轴是世界属性，**不随本拍画左画右翻转**。
  2. **力向核销（铰链扇）**：`开向=里`＝扇面向室内/舱内展开；`开向=外`＝扇面向室外/车外展开。打开：人在门外/仓外 + 里 → **推向里**；人在门内/仓内 + 里 → **拉向里**；人在门外/仓外 + 外 → **拉向外**；人在门内/仓内 + 外 → **推向外**。关上=反向力，开向词不变。车门/舱门同表。双开**逐扇**套本表（左扇用左扇门轴/把手，右扇用右扇）。
  3. **推拉扇**：单扇 `开向=左滑|右滑`、`门轴=无` → 力=滑向已锁向。对开推拉：左扇滑左、右扇滑右，禁写成铰链推拉。
  4. **双开（一口两扇；强制点扇）**：只开通行扇 → 只写该扇触点+扇展，另一扇保持其开拍开闭。双扇同开 → 两触点（或双手各一扇），扇展对开（左扇往其门轴侧/左、右扇往右，占位仍同核一个开向）。通行只经已开扇缝，禁穿仍关的那扇。❌把整樘写成单扇一门轴｜❌只写「推开对开门」不分左右扇。
  5. **入戏句**：单扇=`在{门名}{把手左|右}{上|中|下}部{向里|向外|左滑|右滑}{推|拉|滑}{开|上}` + 人站={门内侧|门外侧|仓内|仓外} + 扇展。双开在门名后加 `{左扇|右扇}`，触点用该扇把手（中缝）。例：单扇 `开向=里｜门轴=门左｜把手=门右中`、人在门外 → `CHAR:[@甲]右手在大门右中部向里推开门，门扇往室内展开`；双开 `开向=里｜通行扇=右扇`、人在门外 → `CHAR:[@甲]右手在正门右扇左中部向里推开右扇，左扇仍关，右扇往室内展开`；双扇同开外开 → 左右手各在中缝把手向外拉开左右扇，两扇往室外对开。
  6. **态连续**：该扇开拍已全开 → 禁再写打开该扇，改写为经该扇缝通行。开拍全关 → 禁穿该扇、禁写门后可见。过程从建置初态推到终态；双开终态分写左右扇 `开闭=`。
  ❌照抄文戏「拉开」却与里开/外开冲突｜❌只写「开门/推门/开车门」无接触点无开向｜❌手摸该扇门轴侧｜❌切角后把门轴改到画面对侧｜❌半开却不写扇占里或外｜❌双开不分扇
