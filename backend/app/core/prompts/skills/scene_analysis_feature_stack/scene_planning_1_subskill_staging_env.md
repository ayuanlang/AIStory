## 目标

按**单场**调用。输入已含【主环境】【未落清单】【衍生环境】、【主体定位方案】【Beat主体定位】、各拍【取景锁定】（含拍摄键 + `选择证据=` + `[DERIVED_ENV:]`），以及文戏/武戏过程。
**本层只执行**已锁拍什么 + 怎么站，写成可独立生成的【建置】整句 +【入戏】变化 + 拍内【场记分析】。禁另选角／站位／可见档／机位。入场／可见性／`面向镜头` 镜后闸／人载／表情评／载具档／正反只抄上游；该见未见或已锁却拧人 → **回流现场编排**，本层不改锁。
成稿**只出节拍流**；场号／环境块／定位方案／提取块由程序拼回。开场全景写入 B1 `开拍在场=`，不另起【实体覆盖】。禁另起位置规划／角色位置／动作空间／露脸块；输入若仍有覆盖矩阵／【Beat景别构图方案】／场级【场记分析】则拆入对应拍后删除。
0. **单拍自足 + 跨拍连续**：每个 Beat 须能独立生成，同时守上下拍连续。
   1. **建置整句**（进分镜）：本拍 ENV 内每个 `可见性=V|部分可见` 的 CHAR + 每个本体可见独立 PROP（含无使用）各一条（姿势＋镜头关系＋面向＋手持／佩戴＋可见脸表情；部分可见抄 `露=`）。无动作 ≠ 可省。禁「同上／见上拍／略」。
   2. **复述 ≠ 重排**：世界键 ≡ 上拍终态；仅 ENV 变投影画面词。无走位无转身却换锚／换看谁 = 失败。
   3. **台账**：`暂不可见` 不进建置正文，场记整行复述（宫格＋锚侧／排座＋面向＋可见面＋姿态＋手持／佩戴＋`因=`）。待入画／盒内件不提前。
   4. **可见重评只执行上游**：上游已改回 `V|部分可见` → 建置整句（世界键抄上台账）。仍暂不可见 → 只更新 `因=`。该见未见 → 回流，不私自改档。切角 ≠ 出画。
   5. **入戏只写变化**，不补建置漏写的人／件。
1. **连续性**：【建置】=动作前。开拍站位 ≡ 上拍速查。换锚／换朝向对象须有走位或转身；`镜头推进` ≠ 换站。ENV 变：`所在侧` 查 §7A；世界槽不改，近远／画幅按本拍 N 投影。镜头关系只抄 `体侧=`／`可见面推`。走位守 `spatial_axis`。禁角度坐标（`所在侧=` 除外）。
2. **走位核对**：核可拍（净空、不穿障、步幅、门径向、触达一臂、终点仍在白名单、不越轴）。直线开拍→终点有障 → `经=` 须写绕过哪件、从该件哪侧；直线穿障=失败。路径=`{名}:自{开拍}→经{路径}→到{终态}`。无走位=`走位=无`。不另选角。
2A. **出入画（本层只写过程）**：档位只认上游 `入场=`／`入画@`／`经=`／可见性。`入场=开场` → B1 安排到位（`V|部分可见` 进建置，即使无动作；`暂不可见` 进台账）。`待入画` 入画前禁进建置。入画@B 且上游=`部分可见｜因=入画过程` → 建置只写经口身形（抄 `露=`），入戏写经口过程；上游仍=`待入画` → 建置不含。中途入画=入戏写过程、终态写入；中途出画=建置含、入戏写过程、终态剔除。切角 ≠ 出入画。盒内件开场禁进建置。**进出场衬托**（本层成句）：进出者过程（口沿→身形→落定，禁瞬现）+ **视线三拍**（预看→跟看→对视；抄文戏，禁自造）+ 在场者其余反应。禁只写进出者、禁人已站定无预看。无开场无 `入画@`／`经=` 却写入建置／终态 = 鬼魅。B1 `开拍在场=` ≡ 上游 `入场=开场` 全景（仅本体可见；禁只列有戏者；盒内件不进）。无动作仍跟踪，禁从收拍剔除 `暂不可见`。
2B. **建置覆盖（名单只在此条）**：本拍定位表 `V|部分可见` + 该 ENV 内本体可见独立 PROP → 必须整句（无动作／无使用仍写）。`暂不可见` 只进台账。空镜／整车无人／内部ENV 只执行上游 `剧情匹配=` 与 `载具档=`：空镜=拍摄键+`空镜／无角色／无道具`；整车无人可点名整车 PROP、禁 CHAR；内部ENV 禁改写成空镜、禁改挂宿主；道具沿用宿主允许 `位于 PROP:[整车]`。组／槽位／`触=`／`露=`／`同簇相对=` 抄上游写入整句；禁「靠桌／在车上」。`待入画`／已离场／`D` 不写本体。不得自造 `X`。粒度=本拍 `当前环境=`（硬约束 12）。
3. **拍摄键写入建置首句**：`当前环境`／景别／构图／可兼／主体落点／留白／纵深层／镜头角度／关系角／`OTS类型`／近侧框主／主拍对象／主观角色／机位锚／侧／距／变因／上机位／`AI位` = 已锁。删独立【取景锁定】行。入戏不写锁档。配乐音效原样写入戏。不另选机位。
4. **三段式**：【建置】→【入戏】→拍内【场记分析】…【场记分析结束】。场头禁场级场记。
5. **推导进该拍场记**：并入取景锁定推导键（`朝向推=`／`表情换环境评=`／`背对=` 只进本段）。再写走位终态／速查（未出画全员：`所在侧=`＋落位＋面向＋镜头可见面＋姿态＋`可见性=画内|暂不可见`）／`脸可见核销=`／差集。先在场核销再连续性。本段不进分镜。禁扇区／`F≈`／`0°侧`。
6. **入戏只写建置后变化**：不复述初态。有走位／转身／出入画／变姿须写新可见面＋新落点＋新姿势。上游本拍动作／对白／声画必须写入（硬约束 0）。名牌不算动作。无角色变化则只写对白（若有）＋ ENV 微动。承接上拍未完成链。
7. **只出节拍流**：`[BEAT_STREAM_START]`…`[BEAT_STREAM_END]`；末行 `[STAGING_ENV_OUTPUT_END]`。禁回写场头／环境块／定位／提取块／`[SCENE_*]`。

## 硬约束
0. **上游 Beat 只增不减（最高）**：本拍输入已有的动作、表情、姿势、对白整行（`开口 |` 八键 `{台词}` `| 闭嘴 |`）、VO、【配乐】【音效】必须全部落入【入戏】可检索。只允许加建置落位 / 走位 / 门合同改写 / ENV 微动。禁止删、漏、概括、用「同上/见上游」代替，禁止把合同骨架当成交稿。
1. 不改事实 / 因果 / 对白词 / 场核 / `节拍=`。例外：门/窗/车门/舱门/厢门开关过程须按环境规划合同**匹配改写**（§6），不另造开向或门轴。**对白例外仅限补花括号**：上游台词已是原文逐字但未包 `{}` → 只在原词外加 `{}`，八键与闭嘴侧原样；禁止改词、禁止改写成「语气层+台词」。
2. 成稿写出原文本身。
3. 专名与环境注册名逐字。继承现场编排后的 `CHAR:[@]` / `PROP:[]` / `ENV:[]`；新写建置/入戏同此。禁拆前缀还原裸名。衍生环境只认已声明 `ENV:[…]`。
4. 物理可拍优先；`正面可见` 与 `背朝镜头` 互斥。画内每人必写镜头关系闭集；成稿禁写 `180°`/`相对180度`/`面向N°`。建置只写正面朝向，禁重复写 `背对={实体}`。画外禁点名见硬约束 9。未锁越轴则走位 / 左右屏不得跨 `spatial_axis`。
5. **站位禁角度**：落位/朝向禁 `0°侧` / `90°侧` / `180°侧` / `270°侧` / `扇区=` / `F≈` / `面向N°` / `站在{N}度`。【建置】【入戏】同禁；场记分析除速查/差集 `所在侧=` 闭集外同禁。已锁 ENV 名 `{N}度…` 与 `镜头角度=` 可照抄。`所在侧=` 只许 `原后景侧|原前景侧|+90侧|-90侧|轴心`（✅`+90侧`｜❌`90°侧`｜❌建置抄 `所在侧=`）。
6. 仅因出入画改集合、转身改档、已锁 ENV 变、出入舱落定可另起 Beat。
7. 相对落位须核销到具名锚；成稿主语=该人，**禁过程词「相对{锚}」**。可见锚能区分该侧 → 只点该锚+世界侧名，禁叠 `靠近镜头|远离镜头`。宫格参照=画外 → 硬约束 10。无可见锚才写本拍投影的近/远。三维挂在侧名上。高低 `平`=齐站，成稿省略，禁「平的{侧}」。禁无主语句。
8. **自然语言整句**：【建置】键值行外须另写完整句：镜头关系（闭集；只抄上游 `体侧=`/`可见面推`）+ 姿势闭集（§2）+ 已锁方式落位（§4）+ 手持/佩戴（§1）+ 可见脸表情（§1）。【入戏】仅走位 / 转身 / 出入画 / 变姿时用同样整句写**新**镜头关系 + 新落点 + 新姿势。无走位禁复述初态。缺画内镜头关系、缺姿势、V 者缺 `手持=`/`佩戴=`、脸可读缺表情、脸不可见写五官、入戏有神色却 `背朝镜头`（§1）、`部分可见` 升全身或漏 `露=` = 失败。画内仅一人不强制凑第二人。成稿禁写相对180°。禁「面向{人}方向（即面向镜头）」。
9. **画幅锚替换（强制；切角左右会变）**：先读本拍 ENV【衍生环境画幅锚】`背景=`/`画左=`/`画右=`/`画外=`。建置**仍按相对/绝对/封闭**成稿（§4）。**绝对定位**：角色必须写清 `画左|画中|画右`（`画中`≡`中央`），再把该画位换成**本拍可见三键里实际在画的实体**（`背景=`/`画左=`/`画右=`；✅绝对 `后景+{本拍背景实体}+画中`）。**相对/封闭定位：角色落位禁止写画左/画右/画中**——只写锚的哪一头/哪一面/`近镜头侧|远镜头侧`/`辅=`/`排座`；环境键 `画左=`/`画右=` 只当具名锚点名，不写成该人画位。✅封闭 `座=左起第K/M个`｜❌相对「位于画左」｜❌丢掉锚/层位/排座只写一个实体｜❌切角后本拍三键已无该件仍写旧件。**`画外=`=镜头后对向主体，明确不可见**——【建置】【入戏】**禁止点名**（禁「对着{画外件}」、禁当可见锚、禁写成后景/画左/画右）。宫格参照落画外时的成稿改挂见硬约束 10。上角锚未出现在本拍可见三键且非画内承托 → 禁写入建置/入戏，速查 `锚=` 原样继承。切角/反打须改查**新 ENV 行**（0°画左≠180°画左；0°画外≠180°画外）。构图 `三分` 可留。场记分析内部可写画左↔画右对调，**画外件只可标不可见、不得写入画面句**。缺可见三键=失败。
10. **宫格参照不可见→近镜头中区某侧旁（强制）**：读【宫格图】`四周=` 与本拍 `画外=`。定位行 `锚=` 或四周参照（`后|前|左|右`）等于本拍 `画外=`，或该参照本角不可见 →【建置】【入戏】落位**禁止点该参照名**。人仍 `可见性=V` 时，改写成**离镜头近处的中间主体**的某一侧旁：①优先 `四周=中:`（中心家具，且本拍可见）；②`中=无` 或该中区件本拍不可见 → 改用本拍离镜头最近的可见中景件（`画左=`/`画右=` 近端或白名单中景；**禁**远景 `背景=`、**禁** `画外=`）。句式=`位于{中间主体}{侧}旁`；侧=世界侧名或本拍 `近镜头侧|远镜头侧`（原 `辅=近门一侧` 而门已画外 → 改 `近镜头侧旁`，禁残留门名）。**相对角色禁写画左/画右旁。**✅`位于八仙桌近镜头侧旁，站`｜✅`位于八仙桌客侧旁，坐`｜❌`位于八仙桌画右侧旁`（相对）｜❌`位于红木柜台客侧`（柜台=本拍画外）｜❌`位于大门近门一侧`（大门=画外）｜❌裸写「位于中间/靠近镜头」却不点中间主体。速查 `锚=` 仍继承原参照（世界槽位不改）。人已 `暂不可见` → 仍不写建置。
11. **建置不解释环境（最高）**：【建置】【入戏】**不解释**环境背景与内容——禁「远景是…」「画面左侧/右侧是…」、材质/陈设墙导游、四向复述、把 `背景=`/`画左=`/`画右=` 扩写成环境描写。环境已由该拍 `当前环境=ENV:[…]` 对应参考图承担，成稿只点名 ENV。本拍可见三锚与白名单具名主体**只作**角色/可移动道具的**定位锚**与**朝向对象**（`位于{可见锚}{侧}` / `面向={明示}`），点名即止：不写该件外观、不写其自身画面位、不把该件写成待生成环境内容。空镜拍=`空镜／无角色／无道具`+`当前环境=`，禁补环境导游，禁 CHAR/PROP 落位。载具只执行上游 `载具档=`，本层不改选；档与挂族冲突 → 回流。旧「禁道具上入戏」作废。【入戏】只在交互/微动时点名该件（推门、坐椅、`ENV背景微动=`），仍不解释环境。❌`远景是木质柜台和酒坛陈设墙，画面左侧是楼梯`｜❌建置另起「环境：大厅金碧辉煌」｜✅`CHAR:[@林] 位于八仙桌近镜头侧旁，站，面向镜头，正面可见，目光定，手持=无，佩戴=无`
12. **建置粒度=当前环境（最高）**：一份【建置】只服务本拍一个 `当前环境=`。只写本拍该 ENV 内 `V|部分可见` 者。环境切换=另起【建置】，禁止把不同衍生或不同主环境的角色落位写进同一段。他 ENV 的人只进该拍建置。❌同段并列两套环境里的人。❌先写甲环境远观主体、再写乙环境占用面上的人。

## 术语
| 术语 | 定义 |
| :--- | :--- |
| **建置** | **动作前**起始帧，且须**单拍自足**：拍摄键 + 本拍 `当前环境=` 内已锁 `可见性=V|部分可见` 者＋本体可见独立 PROP 的完整落位句（朝向 / 姿态 / 落点 / **手持与佩戴** / **可见脸表情**＝上拍终态；禁「同上」）。粒度=该 ENV，禁把另一环境的人写进本段（硬约束 12）。`部分可见` 只写 `露=` 部位+画幅左右。本拍入戏的转身/走位不写进建置。名单见 2B。固定陈设只作定位/朝向锚。不解释环境（硬约束 11）。ENV 背景微动写入戏。名牌不算动作，不进建置。 |
| **在场主体** | 上游已入场且未离场者（B1=`开拍在场=`；其后=上拍 `收拍在场`）。本拍建置 = 本拍【Beat主体定位】`可见性=V|部分可见`。 |

| **XOR** | 只执行上游已锁方式，本层不改选。该人相对/封闭后禁写 `前景|中景|后景`。三种都禁角度坐标。配饰跟宿主部位。 |
| **朝向三联** | 镜头关系（抄上游 `体侧=`／`可见面推` 本拍 N）+ `面向=`（只写对象／角色；镜后闸执行上游，本层不另推）。建置／入戏只写正面朝向，禁再写 `背对=`（只进场记）。`朝向推=` 只进场记。 |
| **锚侧落位** | 人落在一件**本拍可见**固定大件的某一侧。成稿写结果位（`位于{可见锚}{世界侧名}`）**并明示姿势**，禁「相对{锚}」推导。宫格参照=本拍 `画外=` → 改写 `位于{近镜头中区主体}{侧}旁`（硬约束 10）。有可见锚则不写靠近/远离镜头；无可见锚才用本拍投影的近/远。 |
| **入画径向三联** | 门层位 × 行进径向 / 镜头可见面 × `活动适配`。 |
| **走位** | 可移动主体在已锁空间内的位移：开拍定位 → 路径 → 终态定位 + 与他者关系变化。本文件核对并写清。 |
| **轴线 / 越轴** | 轴线 = 已锁 `spatial_axis`（对戏连线或人↔锚）。越轴 = 人走到轴线另一侧，或无反打依据地拧反左右屏。反打沿轴线对向 ≠ 越轴。 |
| **所在侧** | 只进速查/差集/台账的半空间记忆：`原后景侧`｜`原前景侧`｜`+90侧`｜`-90侧`｜`轴心`。切角查 §7A。禁写入【建置】【入戏】。 |

## 1. 建置 / 入戏 / 拍内场记分析
- **【建置】**：首句写满拍摄键（目标 3）。名单见 2B。每人／每件一条结果落位句（§4；禁「同上」「相对{锚}」）+ 姿势闭集（切角 ≠ 改姿势；本拍入戏才变则建置仍写旧档）+ 镜头关系（只抄 `体侧=`）+ 动作前 `面向=`（=上拍终态；镜后闸执行上游；禁抄 `朝向推=`、禁再写 `背对=`）+ 手持／佩戴 + 可见脸表情。组／同簇抄上游本拍投影。运动后落点不进。画外／宫格参照不可见／不解释环境：硬约束 9–11。**门槛**：入戏含推门／入画且文戏未写人已在厅内 → 建置停门槛，入完只进终态；文戏已是厅内开口 → 跟文戏。禁 `选择证据`／扇区／`所在侧=`。禁写名牌。
- **手持/佩戴开拍必写（最高；仅已可见件）**：画内每人必须在建置整句写清本拍开拍 `手持=` 与 `佩戴=`（无则写`无`）。已提取独立件用 `PROP:[名]` + 部位/体侧/握持态。开拍已在身/在手 → **禁等入戏「用时」才第一次点名**（后拍抚摸/发亮仍须开拍已写）。桌上/架上**本体可见** → 宿主写 `手持=无`，该 `PROP:` 另作可移动件建置。盒/匣/袋内**本体未露出** → 宿主 `手持=无`/`佩戴=无`，该件不进本拍建置（待入画）；【入戏】写开盒取出；取出后下拍才改宿主 `手持=`/`佩戴=`。纯造型无戏耳钉/胸针不写。群演簇写簇持械（有则）。`背朝镜头` 禁写胸前件正面。
- **开拍表情（最高）**：画内每人开拍脸须可核销。`正面可见`/`正面¾可见`/`左侧面可见`/`右侧面可见` **同等合法写表情**（侧面写该侧半脸：颊、眉尾、嘴角、目光；禁因「有表情」改成正面）。正面/¾ → 必写表情词（非「表情自然」空壳；中性须写可辨词如`下颌松、目光平`）。侧面且该侧半脸可读 → **同样必写**该侧可见表情。`背朝镜头`、脸被遮、景别不及脸、`部分可见` 且 `露=` 不含脸、`CU|ECU` 主拍不是脸 → **仅当本拍入戏也不写该人五官/神色时豁免**（禁写眉眼口型，亦禁写`表情=不可见`）。入戏只写相对建置的表情变化。
- **同格挤身部分可见（最高；拥抱/押送/牵手）**：上游 `可见性=部分可见` → 建置**只写** `露=` 已锁部位 + 本拍 `画幅=偏画左|居中|偏画右` + 接触落点（按在谁的 `左肩|右肩` 等）。肢体左右=角色自身左/右，禁与画幅左右对调。姿势可写（站/按/搂），**禁**升成全身 `正面可见`/`面无表情`。`部分可见` 缺 `露=` 或部位无 `左|右` = 失败。接触带须能核销：押送两侧分写谁偏画左/画右、谁的哪只手按谁的哪侧肩；牵手双方写出牵住的那只手；拥抱写出谁的哪臂绕谁哪侧。
  - ✅`CHAR:[@甲] 位于{可见锚}偏画右，站，露=右手+右前臂（按在 CHAR:[@乙] 右肩），手持=无，佩戴=无`
  - ✅`CHAR:[@丙] 位于{可见锚}偏画左，站，露=左手+左前臂（按在 CHAR:[@乙] 左肩），手持=无，佩戴=无`
  - ❌全身 `正面可见` 顶替 `部分可见`+`露=`
  - ❌`露=手按肩`（无左右、无谁的手/谁的肩）
- **接触未结束须复述**：上游 `触≠无` 且本拍未松开 → 建置接触句与 `触=` 同核（见「接触关系守恒」），不得只写分立站位。
- **有表情禁背对**：入戏／上游对该人写了神色 → 写表情那一瞬不得 `背朝镜头`。只执行上游 `表情换环境评=`（本层不改 ENV）。`保持`（含侧面半脸）→ 写该面表情。`本拍不写脸` → 入戏不写五官。`改挂:` 须已在上游落地，否则回流。禁止删表情；禁止同角无转身改 `面向镜头` 凑脸。侧面半脸与正面同等合法。名牌不进本条。
- **人载同向优先于凑脸**：只执行上游 `人载同向=`。`相对=后方` → 建置骑手必须 `背朝镜头`，禁 `面向镜头`／正面；要读脸须回流改挂人+车，或入戏只转头。名牌不是朝向／换环境依据。
  - ❌建置 `背朝镜头` + 入戏写五官
  - ❌无转身把「面向窗＋侧面」改成「面向镜头＋正面」
  - ✅侧面半脸写该侧神色；或入戏先转身再写神色
- **【入戏】**：只写相对本拍【建置】的变化（目标 6）。无变化禁复述初态。上游本拍已有内容必须整段写入（硬约束 0）。有走位／转身／出入画／变姿 → 整句写新可见面＋新落点＋新姿势（禁只写「走两步／转过身／坐下」）。出入画另须视线三拍＋在场者反应（2A）。不写锁档。ENV 微动只在本段。名牌见名牌条。
  - ❌入戏写`跨度=越级` / 无变化却复述初态 / 无对白却写开口闭嘴 / 相对走位写成画左画右 / 「语气层+台词」
- **【场记分析】**：成对标记。先在场核销，再推导键 ⊕ 建置 ⊕ 入戏 → `变化过程` + `终态画面纵深` + `速查更新`。终态只写画内；速查／差集／收拍覆盖未出画全员（`V`→`画内`；`暂不可见` 留站位+因，仍计入收拍）。ENV 变查 §7A。本段不进分镜。
- **集合**：`终态=(建置−出画)∪入画`。中途入画者不进建置，过程写入戏、终态写满；中途出画者建置含、入戏写过程、终态剔除。切角 ≠ 出入画。格式见 §7。
- **不可见**：只执行上游档。`暂不可见` 不写建置、不写出画。`D` 只写入戏声音。`待入画`／已离场不写。已锁 `V|部分可见` 却漏建置 = 失败。
- **可移动主体**：角色／簇／动物／载具／法相／已入场独立 PROP 同等落位。开场已佩戴配饰跟宿主；宿主暂不可见则配饰不进建置。盒内件取出前不进建置。簇仅当仍在画才写队形；上游已拆簇主拍则近景拍不塞簇。人—车分行。CU 只建置上游 `V`。
- **不提前入场**：执行上游 `待入画`。待入画者禁塞进建置／终态／差集／速查。对白点名／后拍将用 ≠ 开场建置依据。开场已佩戴必须写入开场建置。
- **出入画成句**：过程 + 视线三拍 + 在场者反应见 2A。落定后下一拍才对白／主动作。禁只改集合不写过程。
- **动作覆盖**：【入戏】对建置内每人 / 每簇至少 1 个可见微动（计为变化，不是「无变化」）。剧情强制静止须写静止证据。受者响应须针对该动作，不能用旁观微动代替。**打出角色名牌 / 环境名牌物理文字不算动作**，不得顶替本条微动。
- **环境背景微动态（只写入戏）**：每拍【入戏】须有 `ENV背景微动=` 一行。**选件序**：①所属主环境已点名 `背景微动件=` 且本拍白名单或**可见**画幅锚（`背景=`/`画左=`/`画右=`，**不含 `画外=`**）可见 → **优先写该件**及其 `可用动势`（幅度 subtle，不改行动/走位/对白）；②该件不可见、在 `画外=` 或 `背景微动件=无` → 再从当前环境已有细微件选（本拍 ENV `背景=`/`画左=`/`画右=`、固定清单/未落清单、本拍【建置】已点名的小件：帘/穗/灯焰/烟气/水纹/叶/尘/旗角/窗纱/烛火/蒸汽/纸页边等；**禁选 `画外=` 件**）；③仍无可选 → `ENV背景微动=无`（**宁愿空，禁凑件**）。**禁杜撰**原环境没有的物件（❌原无碗却写「碗沿轻晃」）；**禁**拿桌/柜/门/柱/床/墙/柜台等大件当微动锚来凑行。禁括号备注。光斑 / bokeh 不进。【建置】禁写本行。人群动势不替代本行。空镜拍建置=`空镜／无角色／无道具`，本行仍写（有则微动，无则`无`）。
- **开口｜闭嘴（最高；整行原样继承）**：上游本拍有开口行 → 【入戏】**整行原样抄入**：`开口 |` + 说话人 + 八键全文（`voice_type`｜`voice_identity`｜`tone`｜`speed`｜`volume`｜`rhythm`｜`stress`｜`pause`）+ `{台词原文逐字}` + `| 闭嘴 |` + 听者。`{台词}` **必须有花括号**；上游已是原文但未包 `{}` → 只补花括号，不改词。开口/闭嘴与角色用 `|` 并排，中间夹完整对话。禁括号紧贴、禁闭嘴写在台词前。无对白、空镜、纯走位 **禁止**出现开口/闭嘴行。OS/旁白/VO/自白仍算有台词，须整行抄入；**可与动作/画内对白同拍，禁漏 VO 行**。
  - ❌`开口 | CHAR:[@甲] | 语气层+台词 | 闭嘴 | CHAR:[@乙]`（把合同骨架当成交稿）
  - ❌`… | 台词原文。 | 闭嘴 | …`（台词未用 `{}` 包裹）
  - ✅`开口 | CHAR:[@甲] | voice_type=对白｜voice_identity=…｜tone=…｜speed=…｜volume=…｜rhythm=…｜stress=…｜pause=… | {台词原文逐字} | 闭嘴 | CHAR:[@乙], CHAR:[@丙]`

  - **名牌不判断朝向与背景（最高）**：朝向、`当前环境=`、可见面只执行现场编排。名牌只跟随**已锁合适时机**出现，**不必第一时间、不必卡在首次 `正面可见`**。本拍脸不可读、急飞/后方跟拍、人载背朝、主动作未落 → **推迟**到后拍，不本拍硬挂。**禁止**为挂牌改 `面向=` / `体侧=` / 换环境 / 改机位侧。全场始终不可读才标 `首登名牌缺口`，仍禁改朝向凑牌。

## 2. 连续性与走位
每拍先对上拍终态与本拍已锁取景做核对，再写建置 / 入戏 / 终态。

**动作连续**
- 上拍未完成的动作链本拍【入戏】承接，禁跳步、禁蒸发受者响应；本拍入戏未写完的链须留给下拍续，禁提前蒸发。
- 姿态 / 持物 / 朝向对象连续；变则须有本拍可拍过程（只写入戏）。**姿势闭集**（与【本场姿势】同核）=`站|立|坐|翘脚坐|盘腿坐|平躺|俯卧|向左侧躺|向右侧躺|蹲|跪|半跪|倚|骑|腾空`（`立`=`站`）。建置整句必须明示该词，禁只写`位于…`。抄上拍速查 `姿态=`；无则抄文戏 / 【本场姿势】。切角 ≠ 改姿势。入戏有过渡链才改终态姿态，建置仍写旧档。
- **朝向时序**：本拍建置 `面向=` + 镜头可见面 = 上拍终态（上拍转身 → 新朝向从**本拍建置**落地）。本拍入戏再转身 → 建置仍写动作前；新朝向进终态，**下拍建置**才改写。同 ENV 无转身不改档。ENV 变且无转身 → 世界对象不改，可见面抄上游本拍 `体侧=`，`面向=` 镜后闸执行上游。❌把本拍转后朝向写入本拍建置。❌因换主拍／收景别重算可见面。
- **随身件守恒**：开拍写法见 §1。无离身链 → 可见宿主抄上拍挂载；宿主不在建置名单 → 只进速查。离身只写入戏，新挂载进终态。发声屏写现位 + 屏面朝向。
- **接触关系守恒（最高；未结束则每拍建置复述）**：上拍终态 / 上游 `触≠无`（牵手/拥抱/押送/按肩/搂腰/接吻）且本拍入戏尚未松开 → 本拍【建置】**必须再次写明**该关系（谁的哪只手/哪臂接触谁的哪部位），即使本拍入戏不再写「牵着/抱着」。禁只靠速查暗示、禁下一拍两人各自独立站位。本拍入戏才松开 → 建置仍写动作前接触态，松开只写入戏，**下拍建置**才去掉。双方都 `V|部分可见` → 双方建置句都写（或一方写完整接触、另一方写被牵/被抱/被按）。一方本拍 `暂不可见` → 可见方仍写接触（手伸出画 / 仍被画外的手牵住），对方 `触=` 留速查。抄上游 `触=` 的式/己/对左右，禁改手、禁与画幅左右对调。
  - ✅上拍已牵手，本拍对白 MCU 建置仍写 `CHAR:[@甲] …右手牵 CHAR:[@乙] 左手`
  - ✅上拍拥抱未结束，切正面仍写 `CHAR:[@甲] 双臂环住 CHAR:[@乙] 左肩`
  - ❌上拍牵手，本拍只写两人分立「位于…站」无牵手
  - ❌建置写成已松开，入戏才写放开
- **入戏跨拍衔接**：入戏不得从与本拍建置矛盾的状态起笔（人已换位、手已换物、半句对白无据另起）；亦不得写到下拍无法承接的终态（半步悬空、物蒸发、动作无落点）。下拍从本拍速查继承站位，并**重评**上拍暂不可见者是否因视角／景别回画；回画则下拍【建置】**整句复述**（≡本拍终态世界键，不是重排）；仍暂不可见则只进下拍台账；下拍【入戏】再写新变化。

**位置连续**
- 真源=已锁方式（§4）+ 速查 `所在侧`。禁 `扇区+F`。
- 开拍站位 ≡ 上拍速查：同 ENV **必须整句复述**开拍落位（=上拍终态；画幅锚按本拍可见三键替换，禁换入 `画外=`），**面向 + 镜头可见面档逐字抄上拍**；`宫格=` 抄上拍终态格（上拍走位换格则本拍建置已是新格）。禁「同上／见上拍」省句。ENV 变写【上一ENV→触发→本ENV】后按 §5 / §7A / 上游 `换算=0→{N}` 做**宫格投影**（格名不改，体侧/近远/画幅词必改），禁切角瞬移、禁只换 ENV 名。上游 `暂不可见` 只进速查整行，不写建置画面句。
- **换锚核销**：建置 `位于{锚}`／`面向=` 世界对象与上拍终态不同 → 上拍或本拍入戏须有走位／转身路径；否则回抄上拍世界锚或回流。切角／收景别／`镜头推进` ≠ 换锚。`走位=无` 却换锚或换看谁 = 失败。
- **切角≠拧朝向**：无走位无转身 → `面向=` 只写对象／角色，镜后闸执行上游（对象仍可见则禁 `面向镜头`）。可见面只抄本拍 `体侧=`。要读脸却投影是背 → 回流改挂或入戏写转身，禁同角拧成正面。
  - ❌无转身、窗仍可见，却把「面向窗＋侧面」改成「面向镜头＋正面」
- **明示站位**：原文「窗前／门旁」→ 建置锚必须是该件。上游错挂中区桌 → 回流，禁照抄。
- 反打 = 同主名对向已锁 ENV。换主名触发不标反打。来源 = 紧邻上拍终态，禁回取更早建置。

**关系连续**
- 仅本拍画内者互写前/后/左/右 + 尺度距离 + 面向。同锚或同绝对格须执行上游 `同簇相对=本拍投影`：整句交代**本拍三维**（偏画左/居中/偏画右、上/平/下、近镜头侧/同层/远镜头侧）。ENV 变用本拍投影，**禁**把 0°「甲偏画左」原样写进 180°/90° 建置。与画外者的关系只进速查，不写建置。走位后关系必须可从开拍关系 ⊕ 本拍路径推出，并更新投影。
- **身体接触未结束 ≠ 普通左右关系**：牵手/拥抱/押送等须按「接触关系守恒」在**每一拍建置复述**，不得只写「在其左侧」代替仍牵着/仍抱着。同 ENV 整句复述**不豁免**接触句。
- 正反打场：走位不得无过程把相向拆成同向，或把同向拧成相向。关系变须写在 `变化过程`。松开/改握只写入戏。

**轴位连续（不越轴）**
- 轴线 = 本场已锁 `spatial_axis`。站位、走位路径、停驻点、左右屏必须落在轴线同一侧（左右屏=构图/轴线用语；**相对落位写「锚的哪一头/哪一面/近镜头侧」，禁止写该人画左/画右**）。
- 已锁 `axis_crossing=None`：禁跨轴；左右屏相对上拍保持同侧。
- 已锁 `PlannedReverse`：沿轴线对向，左右屏对调合法，仍算守轴，**不是**越轴。
- 已锁 `MotivatedCross`：允许跨轴，走位终点落到轴线另一侧，写 `越轴=是｜动机=` 该拍已锁动机。
- 失败：未锁越轴却因走位跨到轴线对面；无反打依据拧反左右屏；把越轴写成普通反打；改挂方案外角来圆越轴。回改走位。
  - ❌`守轴核销=通过`（无人名） / 未锁越轴却写`跨轴`

**走位核对**（相对已锁取景；不通过则回改落点或拆已锁空间硬锁拍，禁改挂方案外角）
1. 开拍落点 = 上拍终态，无瞬移。
2. 路径物理可拍：净空、步幅够、门径向闭合。**障物评估（有走位必写）**：直线开拍→终点扫本拍白名单与建置已写实体。无挡=`障=无`。有挡=`障={具名}`，路径须补 `绕={具名}之{画左|画右|近镜头|远镜头}`（承接文戏已写画侧；无则据已锁观察向裁定）；直线穿桌/柱/人/门扇=失败。绕障节点须仍在已锁活动空间且不越轴。
3. 终点仍在已锁活动空间；本拍必见项仍 ⊆ 已锁白名单。
4. 走位后距离档与已锁景别同向（贴身 ↔ MCU/CU；数步对峙 ↔ WS/FS）。
5. 触达对象开拍已在画且一臂可达；否则先切已锁可见该物的角。
6. 停驻后仍留后续动作净空（贴墙无退路、叠脚无步幅 = 失败）。
7. 路径与终点不越轴（上条）；`守轴核销=` 必填。

**走位细化**（写入 `变化过程` + `终态画面纵深`；【入戏】用自然语言同步写出）
- 有走位：`变化过程=`=`{名}:自{开拍}→经{路径/绕障/门/步数或臂距}→到{终态}｜障=无|{具名}｜绕=无|{具名}之{画左|画右|近镜头|远镜头}｜锚=…｜侧=…｜辅=…｜宫格={终点0°格}｜细节=… 距=…`。相对自/到禁画左/画右/前景。【入戏】须写路径（有障须写出绕过）+停驻后可见面+已锁方式落点。**走位换格（最高）**：本拍建置/`宫格=`=开拍格（抄上游本拍定位）；终点格写入本拍终态+速查 `宫格=`；下拍建置必须用该终点格。换格则本拍终态 `宫格=` ≠ 开拍格。入画落定=入格写入终态；出画=速查剔除。同格内挪步可不改 `宫格=`，须改则先改 0° 相对再按本拍 N 投影。
- 停驻须落点可辨，不得与他人 / 锚混淆。
- 无走位：`走位=无`，本拍场记分析复述**画内**终态关系，不可见者只在速查留站位且**仍计入收拍在场**；**入戏不复述**。速查 `宫格=` 抄上游本拍开拍格。
- 多门路径见 §6。

## 3. 成稿范围
成稿**只出** `[BEAT_STREAM_START]`…`[BEAT_STREAM_END]`。禁回写场号、【场景名称】、环境块、【主体定位方案】【Beat主体定位】、提取块、【实体覆盖】、位置规划 / 角色位置 / 动作空间 / 露脸 / 场级【场记分析】。

**开场全景**：写法见 2A。待入画者不计入 B1 开拍人数，入画落定后计入该拍 `收拍在场`。

**【场记分析】** 每拍成对块，写在该拍【入戏】后、`[BEAT_END]` 前。须写满 §7 在场核销 + 0–8。输入若仍有场级 `B{n}=` 拆入对应拍后删除。

排位：地位 → 剧情 → 重要者 C 位。走位总账与初/变/终写入该拍场记 `变化过程` / `终态` / `速查`，不另起位置块。

## 4. 定位成稿（执行已锁起始帧；不补锁）
抄本拍【Beat主体定位】`可见性=V|部分可见` 各行的方式键，不改 XOR（**无动作的 V 者同样抄**）。角色组抄该行 `序=`/`朝向=`/`距=`。同簇抄该行 `同簇相对=本拍投影`（画幅/高低/纵深）写入建置整句；禁回抄【主体定位方案】的 `0度锁` 画幅词。`D`/`待入画` 不写建置。`暂不可见` 不写建置、必进速查。禁为凑人数补未入该拍定位表的人。入戏不写 XOR 键。缺项或度数/`F≈`=失败。
- **相对（约束）**：抄上游锚，优先本拍可见件。宫格参照=画外 → 硬约束 10。成稿须：①主语=该人；②位于可见锚的可区分一侧（`四侧=`/`辅=`/`近镜头侧|远镜头侧`）；③世界侧名切角不改（该侧名点到画外件则改中间主体的 `近镜头侧|远镜头侧` 或客侧/里侧/哪一头，**禁**改成该人画左/画右）；④可见锚已能区分该侧 → 禁写靠近/远离镜头。本拍未锁的轴不写。相对句**禁止**写 `前景|中景|后景|画左|画中|画右|中央`，保留 `距锚=`。
  - 句式=`CHAR:[@名] 位于{可见锚}{世界侧名或本拍投影侧}，距锚={贴身|一臂|两步|三步|五步远|十步外|{N}步}，{姿势闭集}，面向{镜头|明示对象}，{正面可见|正面¾可见|左侧面可见|右侧面可见|背朝镜头}，{可见则写表情}，手持={PROP:[名] 左手|右手|双手|{握持态}|无}，佩戴={PROP:[名] {体侧}/{部位}|无}`。姿势闭集见 §2。失败项见硬约束 8。
  - **高低成稿（最高）**：键值 `高低=平` = **齐站**（脚在地面或与同桌/同簇同一站立高度），**不是**侧名形容词。成稿 **禁** `平的近门一侧` / `…侧，平，` / 孤字「平」。齐站默认**省略**高低。仅有高差才写可核销动作：`站在{凳/踏}上偏高`｜`俯身偏低`｜`跪/蹲偏低`｜`躺卧偏低`。高差词不顶替姿势闭集（仍须写`站`/`跪`/`蹲`/`平躺`等）。
  - ❌`相对主桌，位于该主桌靠近镜头、居中、平的近门一侧`（过程词+孤字「平」当侧名定语）
  - ❌`位于主桌近门一侧，面向镜头，正面可见`（有落点无姿势）
  - ❌`位于主桌近门一侧，坐，面向镜头，正面可见`（缺表情、缺手持/佩戴）
  - ✅`位于主桌近门一侧，坐，面向镜头，正面可见，下颌收、目光平，手持=PROP:[茶杯] 右手，佩戴=PROP:[玉牌] 正面/胸前`
  - ✅`位于主桌近门一侧，翘脚坐，面向镜头，正面可见，唇线绷，手持=无，佩戴=无`
  - ✅有高差：`位于主桌近门一侧，站，站在绣墩上偏高，面向镜头，正面可见，眉心微蹙，手持=无，佩戴=无`
  - ✅无可见锚、仍相对：`位于{本拍可见侧锚具名}近镜头侧，站，背朝镜头，手持=PROP:[长剑] 左手，佩戴=无`（背朝镜头不写表情；点名实体，不写该人画左）
  - ✅宫格参照=画外、中区可见：`位于八仙桌近镜头侧旁，站，面向镜头，正面可见，目光定，手持=无，佩戴=无`
  - ❌宫格参照=画外仍写：`位于红木柜台客侧` / `位于大门近门一侧`
  - ✅躺：`位于榻近窗一侧，向左侧躺，右侧面可见`
  - **机位对齐**：切角后世界侧名不改；若仍须写近/远，按新机位重判，禁止沿用旧角。0° 靠近镜头的人，180° 必须写成远离镜头（或改用该拍可见锚，不再写近远）。
  - **围桌**抄 `辅=`+`座=该侧左起第K/M个`，写成 `位于{桌}{辅名}`；禁「相对{桌}」；禁只写「靠桌」。
- **绝对**：必须按上游对照表抄 `层位×画位≡宫格`。成稿须写清该角色 `前景|中景|后景` + **`画左|画中|画右`**（`画中`≡`中央`；缺画位=失败），再把画位换成 `{本拍画左实体}|{本拍画中/背景实体}|{本拍画右实体}`，与本拍`主体落点`同向。本拍绝对人数＞2 → 每人必须写 `左起第K/M` + `近起第K/M`（从画左到画右、从近镜头到远镜头；K 不重复）。**朝向与面部可见必须明确**：整句须有 `面向=`（不得空）+ `正面可见|正面¾可见|左侧面可见|右侧面可见|背朝镜头` + 脸面（双眼口型可读 / 半脸可读 / 后脑不可读）。后景主位优先写本拍 `背景=` 实体。高低：齐站省略；有高差写 `偏高|偏低`+承托（禁孤字「平」）。整句同样须明示姿势闭集。
- **封闭**：抄上游 `排=第N排` + `座=左起第K/M个` + `功能=驾驶座|副驾|后排左|后排中|后排右|操纵席|…`。建置整句须能读出第几排第几个+功能名+姿势（默认`坐`，除非文戏明文站/蹲于舱内）。反打只把「画左起」改查新 ENV 画幅锚，**不改**世界 `第N排`/`功能=`/`K`。禁收成「在车上/后排」。
- **配饰**：`挂靠={角色}`｜`部位=左肩|右肩|左腰|右腰|胸部上方|左手|右手`｜`体侧=正面|侧面|背面`。
同句禁叠无锚绝对 + 相对锚。相对/封闭禁写前中后景与角色画左/画中/画右，保留 `距锚=`。画内者互写前后左右+距离；同簇点名各人落在可见锚哪一侧（相对簇写在其左/右，禁偏画左）。锚=画外 → 硬约束 10。速查 `锚=` 仍继承。

**可见面整句**（键值可留场记；正文必写镜头关系词）：
| 档（成稿） | 须点名 |
| :--- | :--- |
| 正面可见 / 正面¾可见 | 哪侧脸、胸腹是否朝镜、双眼/口型是否可读；**必写开拍表情** |
| 左侧面可见 / 右侧面可见 | 哪一肩、哪一侧颊/鼻梁轮廓朝镜；半脸可读则**必写**该侧表情（与正面同等合法，禁为表情改成正面）；不可读则不写表情 |
| 背朝镜头 | 后脑 / 后颈 / 肩背；禁写五官与胸腹正面；**仅本拍入戏也不写该人神色时豁免**；入戏有表情 → **只许**改挂可读环境或入戏先转身，禁同角拧成正面 |

切角未转身者按新观察向重写可见面句，禁粘贴上拍「正面朝镜头」。

## 5. 朝向与镜头可见面
档位（成稿镜头关系；画内每人必写）：角色 = `正面可见`｜`正面¾可见`｜`左侧面可见`｜`右侧面可见`｜`背朝镜头`。载具 = `车头/车尾/左/右侧身朝镜头`｜`¾车头/¾车尾`（飞行器=`机头朝镜`｜`机尾朝镜`｜`侧身朝镜`，语义同车头族）。动物 = 身躯镜头关系 + `头朝{对象|左|右}`。
镜头关系只抄上游 `可见面推`/`体侧=`。场记可按对向换算；**成稿不明示** `180°` / `相对180度` / `面向N°` / `侧面90度`。
**人↔载具同向**：只执行上游 `人载同向=`（§1）。漏锁或已锁后方却定位仍正面 → 回流，本层不改锁。回望只写入戏转头。

**朝向成稿闸**：【建置】【入戏】分写两件事——①`面向=` 只写对象／角色，镜后闸执行上游；禁「即面向镜头」、禁把落点锚写入面向短语。②镜头关系只抄本拍 `体侧=`。`朝向推=`／`背对=` 只进场记。禁 `面向N°`／`面向中心`。落点画位 ≠ 可见面：人所在格不推出左侧面。

**转身过程拍（转肩只从建置判）**
时序走 §2。入戏出现转身 / 转面 / 调头 → `拍型=转身过程`。禁同拍开口 / 走位 / 取物。轴未变可同父 ENV。禁写转了多少度。
- **建置**：只写动作前档。禁写成转后面向。
- **入戏**：只写连续转体（可见面随转写出，不写 XOR）。五件套只进终态：`向{左|右}肩转 → 终态面向{对象} → 终态镜头可见面 → 终态姿态 → 终态落点`。
- **下拍建置**：才抄本拍终态新朝向。❌本拍建置与终态面向相同却写入戏「转身」。

**转肩判定（角色自身左/右，不是画面左/右）**
只以**本拍建置**为开拍态，禁止用终态回推。
1. 读建置 `面向=A`（明示对象或 `面向镜头`）。`面向镜头` 时 A 的几何锚取场记 `朝向推=`（无则取本拍近镜头/机位向），**不把该锚名写入建置**。
2. 用**本拍** ENV `背景=`/`画左=`/`画右=`（及近镜头侧）把 A、B 各落入四向之一：`近镜头|远镜头|画左|画右`。B=入戏要转到的明示对象；无明示则用 `朝向推=` 或三锚几何。缺三锚=失败。
3. 按建置面向所定的角色左/右，取从 A 到 B 的较短转：

| 建置面向所在向 | 角色左 | 角色右 |
| :--- | :--- | :--- |
| **远镜头**（对背景） | 画左 | 画右 |
| **近镜头**（对机位） | 画右 | 画左 |
| **画左** | 近镜头 | 远镜头 |
| **画右** | 远镜头 | 近镜头 |

B 在角色左 → `向左肩转`；在角色右 → `向右肩转`。B 与 A 对向（约一转半）→ 拆成转身过程拍或先锁越轴，禁同拍硬拧 180° 还开口。
❌用画面左/右当角色左/右。❌用转后面向当建置再回推转肩。❌默认某类陈设（门/窗）在某一侧。

**切角只换观察向**：未走位未转身者，锚名／辅边位／姿态／`所在侧`／世界槽位不变；看谁不改。`所在侧` 查 §7A。近远／画幅抄上游本拍投影；左右改查新 ENV 画幅锚。镜头可见面只抄本拍 `体侧=`（90/270 禁正背照抄——上游已投影则照抄，未投影则回流）。禁扇区／`F≈`。

**朝向三联回退**（仅缺 `体侧=` 时）：脸朝近镜头 → 正面；朝远镜头 → 背面；朝画左 → `右侧面可见`；朝画右 → `左侧面可见`。`面向=` 仍写对象／角色。

**落笔序**：查【宫格图】本拍 N 的 `可见面推`/`体侧=` → 定正面朝向（只写对象/角色；该对象本拍 `画外=`/镜后才 `面向镜头`；禁「即」） → 写镜头关系档（抄表，禁写180°） → 写结果落位（可见锚+世界侧名；宫格参照=画外则 `位于{近镜头中区}{侧}旁`；无可见锚才写本拍近/远） → **写姿势闭集** → **写手持/佩戴（无则无）** → **脸可读则写表情，不可见则不写** → 速查抄 `所在侧` + 面向 + 镜头关系 + 落位 + `姿态=` + `手持=` + `佩戴=` +（脸可读才）`表情=`（不抄度数；`朝向推=`/`背对=` 可进速查/场记，不进建置句）。

**反打 ≠ 转身**：反打时未转身者面向对象 / 姿态 / `所在侧` 不变，镜头可见面随观察向对调。来源 = **紧邻上拍终态**（上拍是转身过程拍则取其终态新档，禁回取该拍建置旧档）。相对锚名与辅边位不改写，近/远镜头对调，左右改查新 ENV 画幅锚实体。

**180° 反打换档**（仅对向 180°，`N新=(N旧+180)%360`）。90/270 **不走「只换左右」捷径**，走上游 §0.2C 四向表（依 0° 面朝：正面可投成左/右侧面，侧面可投成正面或背面）。

| 紧邻上拍终态镜头关系 | 本拍开拍镜头关系 |
| :--- | :--- |
| 正面可见 / 正面¾可见 | 背朝镜头 |
| 背朝镜头 | 正面可见 / 正面¾可见 |
| 右侧面可见 | 左侧面可见 |
| 左侧面可见 | 右侧面可见 |

层位按对向对调（前景↔后景、画左↔画右）。**纵深词必须对调**：上拍「靠近镜头」→本拍「远离镜头」（或改用本拍可见锚、不再写近远）。世界槽位（`近门一侧`/`主位`/`辅=`）不随近远一起改口。`投影恒等` 仅轴心层位/中央，≠「可见面也没变」、≠「近远也没变」；正背面必须换。换档后该人锚已不在本拍画幅 → 执行上游 `暂不可见`，不写建置。禁复制上拍「正面朝镜头」；禁复制上拍「靠近镜头」；禁复制上拍「位于前景」到 180/0 对向拍。禁因「仍是来袭／要挡镜头」保持原层位。若须反打后同一可见面，须先另起转身过程拍。
❌`180度` 巨龙前景正面扑人 → 无走位切 `0度` 仍写巨龙前景背朝镜头（应为后景／远离镜头；人侧改近）。满幅法相／Crane Up 不得把该投影后的来袭体写成空气。

**朝向承接**：时序走 §2。同 ENV 无转身 → 抄上拍终态。ENV 变且无转身 → 世界对象不改，可见面抄本拍 `体侧=`，`面向=` 镜后闸执行上游。

**背朝镜头门禁**：禁写五官／胸腹正面。入戏有神色 → 走 §1。

**入画径向**：后景门入 → 朝镜头 → 终态 `面向镜头` + `正面可见`（场记可留背对门，建置不写）；近端门入 → 向纵深 → 终态 `背朝镜头`（仍只写正面朝向，不写背对门）。

**驾驶舱可见面**（无转身、全员面向驾驶台 / 前窗）：

| 当前 ENV | 可见 | 后景 | 不可见 |
| :--- | :--- | :--- | :--- |
| `0度` 贴操纵员后脑 | 操纵员后脑 | 前窗 / 驾驶台 | 其身后人员 |
| `0度` 舱尾望前 | 全员后脑 | 前窗 | 任何人脸 |
| `180度` 拍后方人员 | 后方人员正面 | 后窗 | 操纵员；前窗 |
| `90/270` | 近侧门窗 + 全部座位侧面 | 对侧窗 | 半舱漏座 |

禁 `0/180` 标后排 + 司机 Two-Shot。`180度` 后方人员可写 `面向镜头正中`，面向仍是驾驶台 / 前窗，禁写 `F≈0`。

## 6. 空间执行
- **出入舱**：入舱过程拍仍挂仓外衍生；落定后另起拍，触发 = `入舱切主环境`，ENV = `{N}度{仓内主名}`。出舱落定后另起拍，触发 = `出舱切主环境|回切仓外主环境`；建置 = 所经那扇门外侧旁，载具外部整体入画；下一拍抄同扇门旁落点。入戏执行上游 `过阈运镜=`：外→内写连续推过具名门/窗/舱口，内→外写连续拉过同一口；禁改成硬切换空间。过程未完成拍不切 ENV，落幅拍才切。
- **多门路径**：入 = `门位→落点/座位`；出 = `舱内位→门位→门外落点={外部本体}之{门位}外侧旁`。
- **触达**：接触对象须在开拍可见集且一臂可达；否则先切已锁可见该物的角。
- **载具**：入戏只写运动 / 操作事件；途经、停靠、上下车起终点进建置 / 终态。
- **门窗开关（评估；有则强制；按环境合同匹配改写）**：凡入戏含开/关/推/拉/滑门窗（含车门/舱门/厢门/窗扇），**先读该口环境规划合同**（四向+固定清单；复用场读 `本场门窗初态`）：`扇型=单扇|双开` + `开闭=` + `开向=里|外|左滑|右滑` + `门轴=` + `把手=`（双开另读左右扇各份与`通行扇=`）。缺合同=失败，禁常识另造。文戏过程只作意图（谁开哪口、开或关）；**推|拉、接触点、开向词、人站侧、扇展侧、开哪一扇与合同冲突则改写**，左右手可承文戏，但触点不得落**该扇**门轴侧（冲突改到把手，必要时换手）。不改对白、不改门口注册名（裸「开门/开车门」须点名已锁口；双开再点左扇|右扇|双扇）。
  1. **建置开拍态**：该口入画则写开拍开闭（≡上拍终态；首拍=环境初态/`本场门窗初态`）。双开须分写左扇/右扇开闭，禁合成一句「对开门半开」。半开/全开须带该扇扇展占位核销 `开向`（里=占室内/舱内；外=占室外/车外）。门轴是世界属性，**不随本拍画左画右翻转**。
  2. **力向核销（铰链扇）**：`开向=里`＝扇面向室内/舱内展开；`开向=外`＝扇面向室外/车外展开。打开：人在门外/仓外 + 里 → **推向里**；人在门内/仓内 + 里 → **拉向里**；人在门外/仓外 + 外 → **拉向外**；人在门内/仓内 + 外 → **推向外**。关上=反向力，开向词不变。车门/舱门同表。双开**逐扇**套本表（左扇用左扇门轴/把手，右扇用右扇）。
  3. **推拉扇**：单扇 `开向=左滑|右滑`、`门轴=无` → 力=滑向已锁向。对开推拉：左扇滑左、右扇滑右，禁写成铰链推拉。
  4. **双开（一口两扇；强制点扇）**：只开通行扇 → 只写该扇触点+扇展，另一扇保持其开拍开闭。双扇同开 → 两触点（或双手各一扇），扇展对开（左扇往其门轴侧/左、右扇往右，占位仍同核一个开向）。通行只经已开扇缝，禁穿仍关的那扇。❌把整樘写成单扇一门轴｜❌只写「推开对开门」不分左右扇。
  5. **入戏句**：单扇=`在{门名}{把手左|右}{上|中|下}部{向里|向外|左滑|右滑}{推|拉|滑}{开|上}` + 人站={门内侧|门外侧|仓内|仓外} + 扇展。双开在门名后加 `{左扇|右扇}`，触点用该扇把手（中缝）。例：单扇 `开向=里｜门轴=门左｜把手=门右中`、人在门外 → `CHAR:[@甲]右手在大门右中部向里推开门，门扇往室内展开`；双开 `开向=里｜通行扇=右扇`、人在门外 → `CHAR:[@甲]右手在正门右扇左中部向里推开右扇，左扇仍关，右扇往室内展开`；双扇同开外开 → 左右手各在中缝把手向外拉开左右扇，两扇往室外对开。
  6. **态连续**：该扇开拍已全开 → 禁再写打开该扇，改写为经该扇缝通行。开拍全关 → 禁穿该扇、禁写门后可见。过程从建置初态推到终态；双开终态分写左右扇 `开闭=`。
  ❌照抄文戏「拉开」却与里开/外开冲突｜❌只写「开门/推门/开车门」无接触点无开向｜❌手摸该扇门轴侧｜❌切角后把门轴改到画面对侧｜❌半开却不写扇占里或外｜❌双开不分扇
- **已锁 OTS / 正反**：拍摄键只执行、写入建置首句，禁改档。读对手／同侧过肩成句见下表；邻拍 180°／禁 ±90° 冒充由上游已锁，本层不重推。
