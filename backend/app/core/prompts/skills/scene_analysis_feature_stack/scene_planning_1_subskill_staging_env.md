上游档名 `贴身` 禁止裸字进入【建置】【入戏】的位置句和首句括注之外。位置句写成「大约一掌，中间有缝、不挨着」。它不是挨着，也不是一臂。挨着、触点共享边、不留缝，才写「挨着，不留缝」。一臂写成「大约一条手臂」。两步、三步、五步仍写步数。

**首句也不留罗盘字（最高）**

读**该拍**上游分布图 `机位=`＋`望=北|东|南|西`＋`景别=`＋`可见=`＋当前 `ENV:[{N}度…]`。已入场的每个角色、每个独立道具都要出结论；**只有进画者进【建置】**。换衍生环境必须整表重评，禁止沿用上一角的可见。覆盖 `可见=` 已列者禁无故裁掉，也禁把上游局部（`乙:右肩`）升成全身 `V`。禁另摆机、禁回抄 B1。密切关联体（接触／法相／载具／配饰）上游已同锚同可见 → 本层不得拆开。上游 `巨体尺=遮挡不可见` 或已忽略被挡者出 `可见=` → 本层不得补回可读全身；`肩前悬浮` → 建置须写「悬浮于…肩前」，禁普通前景。
**挂靠可见（最高；每拍、当前衍生环境）**：环境主体可见性只认现场编排提取块注入的【衍生环境画幅锚】。该行 `背景=`／`画左=`／`画右=`／`可见内容白名单=` 是本角可见环境主体；`画外=`／`不可见内容=` 是本角不可见环境主体。切角改查新 ENV 行。`方式=相对` 的角色与独立道具，就近参考物就是该行已选 `锚=`。锚名落在不可见环境主体上，而人／件贴着它（`距锚=` 为贴身或一臂）→ `暂不可见｜因=挂靠不可见`，不进建置，不改锚。两种例外必须在速查写明，并只把仍露出的部分写进建置：①离挂靠较远（`距锚=` 已到两步及以外），人／件自己的中心仍在镜前 → `V｜因=离挂靠较远仍可见`；②体量较大，中心随挂靠在镜后，但有一截伸进镜前 → `部分可见｜因=体量伸出仍可见`＋`露=`。不写明例外却把人留在建置 = 失败。原点档与封闭排座不走本闸，仍按镜前与景别评。手持、佩戴跟宿主：宿主本拍暂不可见，这些件也不进建置。
**朝向不可见译镜头（最高；只改建置句）**：进画角色的身体朝向（`面向=`，抄 `身朝=`／`朝向=`）或目光（`目光=`，抄 `眼神=`）所对的那一具，若是本角不可见主体，【建置】【入戏】把这一键写成 `面向镜头`。不可见主体=该行 `画外=`／`不可见内容=` 的环境主体，或本拍已评 `暂不可见` 的角色与独立道具。身体朝向落在不可见主体 → `面向=面向镜头`，镜头关系写 `正面可见`。目光落在不可见主体、身体仍朝可见主体 → `面向=` 仍写该可见主体，只把 `目光=` 写成 `面向镜头`。两者对同一不可见主体 → `面向=面向镜头`，`目光=同面向`。所对主体仍在本角可见（`背景=`／`画左=`／`画右=`／`可见内容白名单=`，或该人该件本拍 `V|部分可见`）→ 仍写该主体名，禁止改成 `面向镜头`。速查与分布图的世界朝向对象不改口。切到下一角该主体变为可见 → 建置改回写主体名。锚不因这句话改挂。`人载同向.相对=后方` 仍写 `背朝镜头`，不写成 `面向镜头`。
**上游局部可见（最高）**：`可见={名}:半身|:胸肩|:脸` → 主拍可 `V`（体量跟该档）。`可见={名}:左肩|右肩|…` → 该人必须 `部分可见`，`露=`≡上游部位（自身左右，禁改成画左肩）。过肩框主的 `露=` ≡ `可见=` 的左／右肩，并与 `机位侧=` 同核。
**可见性 ≠ 朝向**：背朝／侧面仍是 `V`（写投影可见面）。禁因「脸不可读／背对／不合理」标 `暂不可见`。
本拍 `剧情匹配=空镜` → 全员 `暂不可见｜因=空镜无人`（待入画仍=`待入画`），禁 `V`。

### 同锚挤身（拥抱/押送/牵手；本层评露）

上游只锁同锚 + `触=` + `在其{左|右}`。本层按景别裁定谁进画、露出哪块肉、画幅哪一侧。

**左右两套（禁混）**
1. **世界左右**：抄上游 `在其{左|右}`。切角不改口。
2. **画幅左右**：按本层同簇投影表得 `画幅=偏画左|居中|偏画右`。相对/封闭簇成稿仍写 `在其{左|右}`，禁造该人 `画幅=`。
3. **肢体左右**：角色**自身**左/右。`露=` 每一项必须带 `左|右`。❌「肩入画」「手按住」无左右｜❌用画面左写成「左手」。

`露=` 闭集=`左肩|右肩|左肩头|右肩头|左臂|右臂|左肘|右肘|左腕|右腕|左手|右手|左腰|右腰|左膝|右膝|左脚|右脚|左侧脸|右侧脸|后脑`。多项用 `+`。`V` 可写 `露=全身` 或省。`部分可见` 缺 `露=` 或部位无左右 = 失败。

| 本拍景别 | 主拍 | 同锚接触者（非主拍） | 同锚但未入接触带 |
| :--- | :--- | :--- | :--- |
| `EWS\|WS\|FS` | `V` | `V`（人可小，须可核销左右） | `V` 或被裁=`暂不可见` |
| `MS` | `V` | 半身可读=`V`；竖屏挤满/被挡=`部分可见`+`露=` | 被裁=`暂不可见` |
| `MCU` | `V`（胸肩以上） | **`部分可见`**；`露=`=入画接触部位 | `暂不可见｜因=景别不及` |
| `CU\|ECU` | `V`（脸或主物件） | 必须同框的接触肢=`部分可见`；否则 `暂不可见｜因=景别:CU仅主拍` | `暂不可见` |

**接触带核销（最高）**：押送/按肩 → 押者 `露=` 含按住的 `左手|右手`（可见则加前臂），被押者 `露=` 含被按的 `左肩|右肩`；两侧押者必须分写画幅左/右 + 各用哪只手按哪侧肩。牵手 → 双方各写牵住的那只手。拥抱 → 谁的 `左臂|右臂` 绕谁的哪侧肩/腰。过肩近侧框主已写左/右肩时，该框主若非全身入画 → `部分可见`，`露=` 与 `近侧框主=` 左右同核。
❌ MCU 押送把保镖写成全身 `正面可见`｜❌ CU 只留主拍、按肩的手蒸发｜❌ `露=肩` 无左右。

6. **本层不另起拍**：出入画改集合、转身改档、已锁 ENV 变、出入舱落定须上游已拆成独立拍。未拆或同拍混开口／走位／取物于转身过程 → **回流上游**。整机与舱内角色同拍 → **回流现场编排**补拆，本层不代划。本层只执行已拆拍。
7. 相对落位须核销到现场编排已选的那一具锚；成稿主语=该人，**禁过程词「相对{锚}」**。锚具名逐字继承，禁止另选。参考主体的位置句写成「位于{锚}的画面左或画面右，离镜头更靠近、更远离或同深」，并写离开多远。禁止保留东面、西面、南侧、北侧，禁止写 `离镜头=`。原点／开放不写离镜头，写成画面左或画面右，加上前景、中景或远景。禁止只用「靠近镜头」代替锚名。**依附类**还须画面大概位＋同宿主关系＋`落在=`／`离平地=`，宿主仍是已选那一具。锚落画外且人贴着它 → 暂不可见，不进建置；离挂靠较远或体量伸出才进建置，锚名不换（硬约束 10）。高低 `平`=齐站，成稿省略，禁「平的{侧}」。禁无主语句。参考主体与封闭禁把落位写成前景／中景／远景。
8. **自然语言整句（最高；建置落位用人话）**：【建置】首句保留拍摄键。下一行起，每个进画角色和道具各写一段普通中文，说法见「建置用标准自然语言」。句子里要能读出：在参照物的哪一边或哪一个点、离开多远、另一轴是一样远还是对齐、怎么站或怎么放、面朝着谁、眼睛看着谁、哪一面朝着镜头、两手和佩戴、已锁表情。用「面朝着」「眼睛看着」「两手空着」「右手拿着」，禁止写成 `面向=`、`目光=`、`手持=`、`佩戴=`。位置只写画布坐标，禁止东／南／西／北。参考主体写画面左边或右边，以及更靠近镜头、更远离镜头或离镜头一样远。原点／开放写画面左边或右边，加上前景、中景或远景。封闭保留第几排第几个，再写这一席在画面左边还是右边、比驾驶位更靠近还是更远离镜头。画左／画右／离镜头／前景／中景／远景只用于落位，禁止当作所看的对象。首句写 `景深=`。【入戏】有走位、转身、出入画、变姿、转视线时，用同样的人话写新的可见面、新落点和新姿势。无变化不把初态再说一遍。人话里读不出站哪、看谁、两手，或仍写 `位于`／`侧沿`／`同深`／`手持=`，或背面写五官，或 `部分可见` 升成全身，或依附类台上件没写离台面多高 = 失败。不因缺「脸可读」失败。画内仅一人不强制凑第二人。成稿禁写相对180°。禁「面向某人方向（即面向镜头）」。禁因神色把背面改成正面。
9. **画幅锚替换（强制；切角左右会变）**：先读本拍 ENV【衍生环境画幅锚】`背景=`/`画左=`/`画右=`/`画外=`。建置**仍按参考主体／原点／封闭**成稿（§4）。参考主体与封闭写成「位于锚的已译参照边或点，离开这一边或点写缝，另一轴对齐或同深」，禁止写 `离镜头=`，禁止 `离开{锚}贴身`。原点／开放写成画面左或画面右，加上前景、中景或远景。这是人与道具的落位，不是把环境再描写一遍。参考主体句必须还在锚的具名和已旋侧沿或触点，禁止只剩「位于画左」，也禁止在锚名后接东面、西面或东侧沿。封闭句必须还在排座与 `相对驾驶位=`。原点句不点名东南西北，也不写离镜头。环境键 `画左=`/`画右=` 只当具名锚点名，不扩写成「画面左侧是墙」或「远景是某墙」。✅`位于八仙桌靠近窗户的那一侧，离开这一侧大约一条手臂，离镜头同深`｜✅原点 `在画面右，远景`｜❌`离开桌子一臂，离镜头同深一臂`｜❌只写「位于画左」｜❌原点写成离镜头｜❌切角后把锚改成另一件。**`画外=`=镜头后对向主体，明确不可见**——【建置】【入戏】禁止把画外件写成环境导游，也禁止拿它替换已选锚。已选锚本身落在画外 → 落位仍写该锚名（硬约束 10）。切角/反打须改查**新 ENV 行**并重投（0°画左≠180°画左；0°远景≠180°远景；0°画外≠180°画外）。构图 `三分` 可留。场记分析内部可写画左↔画右对调。缺可见三键不构成换锚理由。
10. **画外不换锚（强制）**：定位行 `锚=` 等于本拍 `画外=`，或该锚本角不可见 → 贴身的人／件 `暂不可见｜因=挂靠不可见`，不进【建置】【入戏】。禁止改挂到中区另一件、近镜头可见件、地面或过道来保住可见。离挂靠较远或体量伸出仍可见时，落位锚具名仍是现场编排已选的那一具，并写明原因。✅贴着画外红木柜台：速查 `暂不可见｜因=挂靠不可见`，建置不写此人｜✅离该柜台五步、人在镜前：`位于红木柜台的画面左，离镜头更靠近五步，站｜因=离挂靠较远仍可见`｜❌同一行改写成 `位于八仙桌的画面左`。速查 `锚=` 与成稿锚名相同。
11. **建置不解释环境（最高）**：【建置】【入戏】**不解释**环境背景与内容——禁「远景是…」「画面左侧/右侧是…」、材质/陈设墙导游、四向复述、把 `背景=`/`画左=`/`画右=` 扩写成环境描写。环境已由该拍 `当前环境=ENV:[…]` 对应参考图承担，成稿只点名 ENV。现场编排已选的锚**只作**角色/可移动道具的**定位锚**与**朝向对象**（`位于{已选锚}` / `面向={明示}`），点名即止：不写该件外观、不写其自身画面位、不把该件写成待生成环境内容，也不换成可见三键里的另一件。空镜拍=`空镜／无角色／无道具`+`当前环境=`，禁补环境导游，禁 CHAR/PROP 落位。载具只执行上游 `载具档=`，本层不改选；档与挂族冲突 → 回流。【入戏】只在交互/微动时点名该件（推门、坐椅、`ENV背景微动=`），仍不解释环境。❌`远景是木质柜台和酒坛陈设墙，画面左侧是楼梯`｜❌建置另起「环境：大厅金碧辉煌」｜✅`CHAR:[@林] 位于八仙桌近镜头侧旁，站，面向 CHAR:[@对座]，正面可见，目光=CHAR:[@对座]，手持=无，佩戴=无`
12. **建置粒度=当前环境（最高）**：一份【建置】只服务本拍一个 `当前环境=`。只写本拍该 ENV 内本层评 `V|部分可见` 者。换 ENV = 下一拍另写【建置】。他 ENV 的人**不进**本拍建置。❌同段并列两套环境里的人。❌先写甲环境远观主体、再写乙环境占用面上的人。
13. **PROP 不替代 ENV（最高）**：`PROP:` 是当前 ENV 里的物件，不是环境本身。本拍出现独立 PROP → **必须**已有 `当前环境=ENV:[…]`（与该 PROP 分名）。`载具档=内部ENV`：落位写封闭槽（主驾驶座/第N排），**禁**`位于 PROP:[飞行器] 的主驾驶座`／`坐在 PROP:[…] 上` 把整车当房间。`载具档=道具沿用宿主|整车无人`：可写 `位于 PROP:[整车]`，当前环境必须是宿主大世界，**禁**驾驶舱 ENV 挂整车 PROP。缺 ENV 只写 PROP = 失败。
14. **整机与舱内角色禁同拍（最高；两套环境）**：一份【建置】只服务一套环境。舱内角色拍：`当前环境=ENV:[{N}度飞行器驾驶舱]`，写封闭驾驶座，**禁** `PROP:[飞行器] 作为舱体容器`／部分可见舱壁，禁挂 `霓虹摩天楼`。整机拍：`当前环境=ENV:[{N}度霓虹摩天楼]`，写整机 PROP，**禁**驾驶座 MCU／控制台机位锚，**禁** `ENV:[180度飞行器驾驶舱]`。环境名牌主段 ≡ 当前环境主名段。一眼整机（EWS/航拍/`主拍对象=PROP:[飞行器]`/机位锚=空域）+ 舱 ENV 或名牌【霓虹摩天楼】+ 舱 ENV → **回流现场编排**，本层不改选、不照抄。❌`ENV:[180度飞行器驾驶舱]` + `主拍对象=PROP:[飞行器]` + EWS 航拍 + 名牌【霓虹摩天楼】｜❌`ENV:[180度霓虹摩天楼]` + 驾驶座 MCU + `PROP:[飞行器] 作为舱体容器` + 名牌【飞行器驾驶舱】｜✅舱拍 `ENV:[180度飞行器驾驶舱]` + CHAR 驾驶座，无整机 PROP｜✅整机拍 `ENV:[180度霓虹摩天楼]` + `PROP:[飞行器]`，无舱内排座。

## 1. 建置 / 入戏 / 拍内场记分析
- **【建置】**：首句拍摄键（含 `当前环境=`）。名单=2B。整句配方=§4＋硬约束 8。切角 ≠ 改姿势；本拍入戏才变则建置仍写旧档。组／同簇世界锁抄该拍宫格，画幅／近远按本拍 `◎`＋N 投影。运动后落点不进。硬约束 9–11。**门槛**：入戏含推门／入画且文戏未写人已在厅内 → 建置停门槛；文戏已是厅内开口 → 跟文戏。禁 `选择证据`／扇区／`所在侧=`。禁写名牌。
- **手持/佩戴开拍必写（最高；仅已可见件）**：画内每人必须在建置整句写清本拍开拍 `手持=` 与 `佩戴=`（无则写`无`）。已提取独立件用 `PROP:[名]` + 部位/体侧/握持态。开拍已在身/在手 → **禁等入戏「用时」才第一次点名**（后拍抚摸/发亮仍须开拍已写）。桌上/架上**本体可见** → 宿主写 `手持=无`，该 `PROP:` 另作可移动件建置。盒/匣/袋内**本体未露出** → 宿主 `手持=无`/`佩戴=无`，该件不进本拍建置（待入画）；【入戏】写开盒取出；取出后下拍才改宿主 `手持=`/`佩戴=`。纯造型无戏耳钉/胸针不写。群演簇写簇持械（有则）。`背朝镜头` 禁写胸前件正面。
- **开拍表情**：不核脸可读。投影为正面／¾／侧面 → 按该面写上游已有表情词（侧面写该侧；禁改成正面）。投影为 `背朝镜头` 或 `露=` 不含脸 → 不写五官。`表情换环境评=` 原样并入场记，不据本评改挂。入戏只写相对建置的表情变化。
- **同锚挤身／接触未结束**：评 `露=` 与接触带见上文「同锚挤身」；未松开须每拍建置复述见 §2「接触关系守恒」。
- **朝向只投影**：所对主体本角可见 → `面向=` 抄 `身朝=`，`目光=` 抄 `眼神=`（同则 `目光=同面向`）。所对主体不可见 → 该键写成 `面向镜头`；身体朝向这一具时镜头关系写 `正面可见`，只转目光时镜头关系仍跟身体。`相对=后方` → 骑手写 `背朝镜头`，不写成 `面向镜头`。禁把仍可见的主体改成 `面向镜头`。禁把身朝／眼神改写成画左／近镜头。
  - ❌窗仍在画左，无转身把「面向窗＋侧面」改成「面向镜头＋正面」
  - ✅所朝的窗落在 `画外=`，建置写 `面向=面向镜头`，`正面可见`；速查仍写面向窗
  - ❌`目光=画右` ｜ ❌只写「目光定」无世界对象，也无 `面向镜头`
- **【入戏】**：只写相对本拍【建置】的变化（目标 6）。无变化禁复述初态。上游本拍已有内容必须整段写入（硬约束 0）。有走位／转身／出入画／变姿 → 整句写新可见面＋新落点＋新姿势（禁只写「走两步／转过身／坐下」）；新落点按本拍 N 再投一次，依附类须重写三层＋`落在=`／`离平地=`。**视线转移**：正文说到一半改看另一人／另一件 → 入戏写新目光。新对象本角可见则 `目光={对象}`；新对象不可见则 `目光=面向镜头`。仅转眼时身朝未变，`面向=` 仍=开拍（开拍所对不可见则开拍已是 `面向镜头`）。身亦转才写新 `面向=`，新身体所对不可见同样写成 `面向镜头`。建置仍写开拍。禁 `目光=画左`。出入画另须视线三拍＋在场者反应（2A）。不写锁档。ENV 微动只在本段。名牌见名牌条。
  - ❌入戏写`跨度=越级` / 无变化却复述初态 / 无对白却写开口闭嘴 / 相对走位写成该人画左画右 / 依附类新落点只写坐标不写大概位或同宿主关系 / 「语气层+台词」
- **【场记分析】**：成对标记。先在场核销，再推导键 ⊕ 建置 ⊕ 入戏 → `变化过程` + `终态画面纵深` + `速查更新`。终态只写画内；速查／差集／收拍覆盖未出画全员（`V`→`画内`；`暂不可见` 留站位+因，仍计入收拍）。ENV 变查 §7A。本段不进分镜。
- **集合**：`终态=(建置−出画)∪入画`。中途入画者不进建置，过程写入戏、终态写满；中途出画者建置含、入戏写过程、终态剔除。切角 ≠ 出入画。格式见 §7。
- **不可见**：裁定见「分镜可见裁定」。镜后、景别裁切、以及贴着本角不可见挂靠，都是暂不可见。背面不是不可见。`暂不可见` 不写建置、不写出画。已评 `V|部分可见` 却漏建置 = 失败。换衍生环境后才可见的，从该拍建置起整句写出。
- **可移动主体**：角色／簇／动物／载具／法相／已入场独立 PROP 同等落位。开场已佩戴配饰跟宿主；宿主暂不可见则配饰不进建置。盒内件取出前不进建置。簇仅当仍在画才写队形；上游已拆簇主拍则近景拍不塞簇。人—车分行。CU 只建置本层评 `V`（及接触肢 `部分可见`）。
- **不提前入场**：执行上游 `待入画`。待入画者禁塞进建置／终态／差集／速查。对白点名／后拍将用 ≠ 开场建置依据。开场已佩戴必须写入开场建置。
- **出入画成句**：过程 + 视线三拍 + 在场者反应见 2A。落定后下一拍才对白／主动作。禁只改集合不写过程。
- **动作覆盖**：【入戏】对建置内每人 / 每簇至少 1 个可见微动（计为变化，不是「无变化」）。剧情强制静止须写静止证据。受者响应须针对该动作，不能用旁观微动代替。**打出角色名牌 / 环境名牌物理文字不算动作**，不得顶替本条微动。

## 2. 连续性与走位
每拍先逐人逐件核对上游该拍分布图的 `在场=` 与 `站位变=`，再写建置 / 入戏 / 终态。在场名单不得偏离分布图。角色与道具的位置句只写画布坐标，不写东／南／西／北。画面词（画左画右、离镜头，或原点档的前景／中景／远景）只随本拍机位重投。

**在场与落点只抄分布图（最高）**
- 分布图 `在场=开场|仍在|入画落定` 且本层评进画 → 建置必须有该 CHAR 或 PROP，并把该行落点译成本拍画布坐标全文写入建置句。禁止只写「承上」，禁止在位置句里写东／南／西／北。`在场=本拍离场` → 建置仍写离开前的画布坐标全文，离开过程只写入戏，下拍不再出现。
- `站位变=否` → 人仍在同一世界点，建置只重投本拍画布坐标。禁止借切角、景别、景深把人挪到另一锚，或把道具换到另一头、另一只手。
- `站位变=是` → 建置仍写开拍位；新落点只出现在入戏，且必须能对上分布图的路径。下拍建置才用终点。
- 分布图未列的人／件，建置、入戏、终态都不得凭空加入。

**故意双生不补（最高）**
剧情已经写明同一人同时有第二具身体：灵魂出窍、元神离体、分身、残影，以及特效技术造出的另一具。第二具与本体分名分写，可以同时在不同位置、做不同动作。这种差不补走位，也不补成同一人的过渡。没有这个机制、只是同一人上下拍对不上，仍要补。切角、换景别不构成位置变化，不因此补走位。

**动作连续（主动补，不只核销）**
- 同一人、同一件：上拍终态的动作还没落到可承接的停点，本拍却已是下一步或另一动作 → 在本拍【入戏】该动作之前补上缺失的过渡（收势、换手、起身、放下、接上未完成的链、受者响应）。只增不删，不改对白。建置仍是动作前。
- 上拍未完成的动作链本拍【入戏】承接；本拍入戏未写完的链须留给下拍续。故意双生的两具各自接自己的链。
- 姿态 / 持物 / 朝向对象连续；变则须有本拍可拍过程（只写入戏）。**姿势闭集**（与【本场姿势】同核）=`站|立|坐|翘脚坐|盘腿坐|平躺|俯卧|向左侧躺|向右侧躺|蹲|跪|半跪|倚|骑|腾空`（`立`=`站`）。建置整句必须明示该词，禁只写`位于…`。抄上拍速查 `姿态=`；无则抄文戏 / 【本场姿势】。切角 ≠ 改姿势。入戏有过渡链才改终态姿态，建置仍写旧档。
- **朝向时序**：本拍建置 `面向=` + 镜头可见面 = 上拍终态（上拍转身 → 新朝向从**本拍建置**落地）。本拍入戏再转身 → 建置仍写动作前；新朝向进终态，**下拍建置**才改写。同 ENV 无转身不改对象。ENV 变且无转身 → 世界对象不改，可见面按本拍 N 重投影。❌把本拍转后朝向写入本拍建置。❌无转身却因换主拍／收景别改世界 `面向=`。
- **随身件与独立道具守恒（最高）**：开拍写法见 §1，名单与落点以该拍分布图为准。无离身链、无取出、无放下 → 手持、佩戴、桌上件、架上件的宿主与世界落点抄分布图；切角只重投画左画右和离镜头，原点档只重投前景／中景／远景。宿主不在建置名单 → 只进速查。离身、取出、放下只写入戏，且分布图须已写路径；新挂载进终态。发声屏写现位 + 屏面朝向。禁切角后茶杯换到桌的另一头，禁无过程让道具蒸发或跳到另一人手里，禁分布图没有的件突然在建置出现。
- **接触关系守恒（最高；未结束则每拍建置复述）**：上拍终态 / 上游 `触≠无`（牵手/拥抱/押送/按肩/搂腰/接吻）且本拍入戏尚未松开 → 本拍【建置】**必须再次写明**该关系（谁的哪只手/哪臂接触谁的哪部位），即使本拍入戏不再写「牵着/抱着」。禁只靠速查暗示、禁下一拍两人各自独立站位。本拍入戏才松开 → 建置仍写动作前接触态，松开只写入戏，**下拍建置**才去掉。双方都 `V|部分可见` → 双方建置句都写（或一方写完整接触、另一方写被牵/被抱/被按）。一方本拍 `暂不可见` → 可见方仍写接触（手伸出画 / 仍被画外的手牵住），对方 `触=` 留速查。抄上游 `触=` 的式/己/对左右，禁改手、禁与画幅左右对调。
  - ✅上拍已牵手，本拍对白 MCU 建置仍写 `CHAR:[@甲] …右手牵 CHAR:[@乙] 左手`
  - ✅上拍拥抱未结束，切正面仍写 `CHAR:[@甲] 双臂环住 CHAR:[@乙] 左肩`
  - ❌上拍牵手，本拍只写两人分立「位于…站」无牵手
  - ❌建置写成已松开，入戏才写放开
- **入戏跨拍衔接**：入戏不得从与本拍建置矛盾的状态起笔（人已换位、手已换物、半句对白无据另起）；亦不得写到下拍无法承接的终态（半步悬空、物蒸发、动作无落点）。下拍从本拍速查继承站位，并**重评**上拍暂不可见者是否因视角／景别回画；回画则下拍【建置】**整句复述**（≡本拍终态世界键，不是重排）；仍暂不可见则只进下拍台账；下拍【入戏】再写新变化。

**位置连续（主动补，不只核销）**
- 同一人、同一件：上拍终态世界位与本拍开拍对不上，且没有走位、离身、取出 → 建置仍写上拍终态译出的画布坐标；【入戏】在该拍动作之前补从上一落点走到本拍落点的移动；终态才是新落点。下拍建置用这个终态。只增不删，不改对白。道具无离手过程却换宿主或消失，同样在入戏补取出、放下或交接。故意双生的第二具不按这条把本体拉过去。
- 真源=已锁方式（§4）+ 速查 `所在侧`。禁 `扇区+F`。
- 开拍站位 ≡ 该拍分布图译出的画布坐标，必须整句写出，不得收成「承上」，位置句不写东／南／西／北。同 ENV：整句复述开拍画布落位（画幅锚换本拍可见三键，禁换入 `画外=`）；`面向=` 所对主体可见则抄分布图的对象名，所对主体不可见则写 `面向镜头`。ENV 变：写【上一ENV→触发→本ENV】后把同一世界点重投成新角度的画布坐标（人未走则不换锚，体侧／近远／画幅必改）。禁「同上」「承上」、禁切角瞬移。`暂不可见` 只进速查。
- **换锚核销**：建置 `位于{锚}` 与上拍终态不同 → 分布图须已写该角色移动离开上一具挂靠物的路径；否则回抄上拍世界锚或回流。切角／收景别／`镜头推进`／挂靠落到画外／读脸 ≠ 换锚。`走位=无` 却换锚 = 失败。世界 `面向=` 对象变仍只认转身路径。建置把不可见对象译成 `面向镜头` 不算朝向对象变。
- **切角≠拧朝向**：无走位无转身 → 世界朝向对象不改。所对主体本角可见则建置仍写该对象，投影是背就写背。所对主体不可见则建置写成 `面向镜头`，镜头关系写 `正面可见`。禁同角把仍可见的主体拧成正面，禁本层改挂。
- **明示站位**：抄上游锚／宫格。本层不重判「该不该挂这件」。
- 反打 = 同主名对向已锁 ENV。换主名触发不标反打。来源 = 紧邻上拍终态，禁回取更早建置。

**关系连续**
- 仅本拍画内者互写前/后/左/右 + 尺度距离 + 面向。**轴跟分布图世界位**：普通人同南北带只写左／右，同东西带才写前／后；无走位禁把上拍左右改成本拍前后。法相／坐骑／载具抄上游：未离开则同锚同朝向；锚内身后按上游身后投影（机在背侧：挂靠体近镜头、宿主其身前；机在面侧：挂靠体可更远）；离开则件留原地、人在新锚。禁无离开改成左右分锚，禁机在背侧写成宿主前景＋挂靠体后景／远镜头侧，禁人已走开却把车／马跟人写走。同锚或同绝对侧须抄上游世界 `同簇相对=0度锁｜在其{左|右|前|后}`，**本层**按同簇投影表投影本拍三维（偏画左/居中/偏画右、上/平/下、近镜头侧/同层/远镜头侧）。世界同南北带左右 → 建置禁拆成前景／后景。ENV 变用本层投影，**禁**把上拍画面「甲偏画左」原样写进 180°/90° 建置。与画外者的关系只进速查，不写建置。走位后关系必须可从开拍关系 ⊕ 本拍路径推出，并更新投影。
- **身体接触未结束 ≠ 普通左右关系**：牵手/拥抱/押送等须按「接触关系守恒」在**每一拍建置复述**，不得只写「在其左侧」代替仍牵着/仍抱着。同 ENV 整句复述**不豁免**接触句。
- 正反打场：走位不得无过程把相向拆成同向，或把同向拧成相向。关系变须写在 `变化过程`。松开/改握只写入戏。

**轴位连续（不越轴）**
- 轴线 = 本场已锁 `spatial_axis`。站位、走位路径、停驻点、左右屏必须落在轴线同一侧（左右屏=构图/轴线用语；**相对落位写「锚的哪一头/哪一面/近镜头侧」，禁止写该人画左/画右**）。
- 已锁 `axis_crossing=None`：禁跨轴；左右屏相对上拍保持同侧。
- 已锁 `PlannedReverse`：沿轴线对向，左右屏对调合法，仍算守轴，**不是**越轴。
- 已锁 `MotivatedCross`：允许跨轴，走位终点落到轴线另一侧，写 `越轴=是｜动机=` 该拍已锁动机。
- 失败：未锁越轴却因走位跨到轴线对面；无反打依据拧反左右屏；把越轴写成普通反打；改挂方案外角来圆越轴。回改走位。
  - ❌`守轴核销=通过`（无人名） / 未锁越轴却写`跨轴`

**走位核对**（相对已锁取景；不通过则回改落点或拆已锁空间硬锁拍，禁改挂方案外角）
1. 开拍落点 = 上拍终态，无瞬移。
2. 路径物理可拍：净空、步幅够、门径向闭合。**障物评估（有走位必写）**：直线开拍→终点扫本拍白名单与建置已写实体。无挡=`障=无`。有挡=`障={具名}`，路径须补 `绕={具名}之{左|右|近端|远端}`（对照该拍宫格；入戏可写成画左／近镜头）；直线穿桌/柱/人/门扇=失败。绕障节点须仍在已锁活动空间且不越轴。
3. 终点仍在已锁活动空间；本拍必见项仍 ⊆ 已锁白名单。
4. 走位后距离档与已锁景别同向（贴身 ↔ MCU/CU；数步对峙 ↔ WS/FS）。
5. 触达对象开拍已在画且一臂可达；否则先切已锁可见该物的角。
6. 停驻后仍留后续动作净空（贴墙无退路、叠脚无步幅 = 失败）。
7. 路径与终点不越轴（上条）；`守轴核销=` 必填。

**走位细化**（写入 `变化过程` + `终态画面纵深`；【入戏】用自然语言同步写出）
- 有走位：`变化过程=`=`{名}:自{开拍}→经{路径/绕障/门/步数或臂距}→到{终态}｜障=无|{具名}｜绕=无|{具名}之{左|右|近端|远端}｜锚=…｜侧=…｜辅=…｜细节=… 距=…`。相对自/到禁画左/画右/前景。禁写 `宫格=`。【入戏】须写路径（有障须写出绕过）+停驻后可见面+已锁方式落点。**走位换锚（最高）**：本拍建置世界位=开拍（抄上游本拍定位）；终点写入本拍终态+速查世界位；下拍建置必须用该终点。换锚则本拍终态世界位 ≠ 开拍。入画落定=入位写入终态；出画=速查剔除。同锚内挪步可不改世界键，须改则先改 0° 相对再按本拍 N 投影。
- 停驻须落点可辨，不得与他人 / 锚混淆。
- 无走位：`走位=无`，本拍场记分析复述**画内**终态关系，不可见者只在速查留站位且**仍计入收拍在场**；**入戏不复述**。速查世界位抄上游本拍开拍锚侧。
- 多门路径见 §6。

## 3. 成稿范围
成稿**只出** `[BEAT_STREAM_START]`…`[BEAT_STREAM_END]`。禁回写场号、【场景名称】、环境块、【角色道具世界分布图】／【角色道具宫格分布图】、【主体定位方案】【Beat主体定位】、提取块、【实体覆盖】、位置规划 / 角色位置 / 动作空间 / 露脸 / 场级【场记分析】。

**开场**：`开拍在场=` 见 2A（世界在场 ≠ 进画）。全员全景整句落在上游建置拍。待入画不计入 B1 开拍人数，入画落定后计入该拍 `收拍在场`。

**【场记分析】** 每拍成对块，写在该拍【入戏】后、`[BEAT_END]` 前。须写满 §7 在场核销 + 0–8。输入若仍有场级 `B{n}=` 拆入对应拍后删除。

排位：地位 → 剧情 → 重要者 C 位。走位总账与初/变/终写入该拍场记 `变化过程` / `终态` / `速查`，不另起位置块。

## 4. 定位成稿（执行已锁起始帧；不补锁）
只抄**该拍** `B{n}` 中本层已评 `V|部分可见` 各行的世界方式键，不改 XOR（**无动作的 V 者同样整句复述**）。角色组抄该行 `序=`/`朝向=`/`距=`。同簇抄上游世界 `同簇相对`，画幅／纵深按本拍 N＋`◎` 投影写入建置整句；禁回抄 B1。`D`/`待入画` 不写建置。镜后／`暂不可见` 不写建置、必进速查。禁为凑人数补未入该拍宫格的人。入戏不写 XOR 键。缺项或度数/`F≈`=失败。每条须能读出该人／件在本拍 `当前环境=` 内的落位。
- **相对（约束）**：锚具名逐字抄该行现场编排已选 `锚=`，禁止另选，画外也不换。成稿须：①主语=该人；②位于该锚的可区分一侧；③**固着侧不映射、方位侧与地理侧必投影**（统一投影 XOR 分闸）：`近窗/近门/主位/客侧` 原样；上游若写左长边或右长边，按本拍角度改写成「在桌子的画面左」或「在桌子靠近镜头的一侧」。建置句禁止再写左长边、右长边、左边长边。`西面/东面/偏=南` 同样改写成画面左、画面右、更靠近或更远离。固着侧不因画外改成另一件，也不改成该人画左/画右。④固着侧已能区分 → 禁叠靠近/远离镜头。相对句**禁止**把该人写成 `前景|中景|后景|画中|中央`。距离写成「离开这一侧沿大约一条手臂」或「离开这一侧沿大约一掌，中间有缝、不挨着」，必须带上已旋参照边或点，不写 `距锚=`，禁止裸写贴身，禁止「离开它一臂」。禁残留 `西面`／`东面`／`东侧沿`／`左边`。
  - 句式见「建置用标准自然语言」。例：`CHAR:[@名] 站在{锚}的画面右边，离{锚}的右边大约一掌宽，中间留着缝，没有挨上，和{锚}离镜头一样远。他面朝着{主体}，左侧朝着镜头。` 这一句的「一样远」和「左侧」必须是世界侧按本拍望向旋出来的，并且 `机位侧=左侧`。正后才写背对着镜头，正前才写正面朝着镜头。禁止为了背影把一样远改成更靠近。第二轴另有分量时才另说那一边，不把同一个距离再说一遍。贴身说成「大约一掌宽，中间留着缝，没有挨上」。一臂说成「大约一条手臂那么远」。禁止 `位于`、`侧沿`、`同深`、`面向=`、`目光=`、`手持=`、`佩戴=`、`贴身`。位置句与首句禁止东／南／西／北／东侧沿。姿势闭集见 §2。失败项见硬约束 8。所对主体可见则人话里点该主体名；所对主体不可见则写成「面朝着镜头」。禁把仍可见的主体改成面朝镜头，禁眼睛看着画面左边。**画布两点（最高）**：句子里必须同时有参照边旋出的那一边，以及另一边的对齐或一样远。只说「在旁边」、不说哪一边或哪一个点 = 失败。远近只认本拍机位。坐、倚、踏须写出碰到锚的哪一处。**依附类**：每人、每件自己一段人话，说出离开宿主的哪一边或哪一个点、离开多远；另一轴一样远或对齐，除非另有分量。不落地要说「放在{宿主}台面上，和台面一样高」。禁止「沿画面左右横行并排」。
  - **独立 PROP 句式（桌上／架上／台上；非手持）**：仅上游 `落在=` 或 `在桌=` 已有具名时使用。`PROP:[名] 落在{已选宿主}台面上，离台面同高，在{宿主}的画面左，离开桌心半掌，离镜头同深半掌，底贴台面`。画面右、更靠近、更远离按本拍改口。宿主名逐字抄该行 `落在=` 或 `锚=`，禁止另选。`落在=无` 则走同一套相对／绝对句，`位于{已选锚}`，不新造落在对象。同宿主第二件再写自己的一句。禁止写 `偏锚=`、`离镜头=`，禁止「两只沿画面左右齐平」。切角重写左右和远近，米数不改。禁止四拍都写成画面左和画面右、禁止合成一只。手持／佩戴不走本句，跟宿主手／部位。
  - **高低成稿（最高）**：键值 `高低=平` = **齐站**（脚在地面或与同桌/同簇同一站立高度），**不是**侧名形容词。成稿 **禁** `平的近门一侧` / `…侧，平，` / 孤字「平」。齐站默认**省略**高低。仅有高差才写可核销动作：`站在{凳/踏}上偏高`｜`俯身偏低`｜`跪/蹲偏低`｜`躺卧偏低`。高差词不顶替姿势闭集（仍须写`站`/`跪`/`蹲`/`平躺`等）。
  - ❌`相对主桌，位于该主桌靠近镜头、居中、平的近门一侧`（过程词+孤字「平」当侧名定语）

## 5. 朝向与镜头可见面
档位（成稿镜头关系；画内每人必写）：角色 = `正面可见`｜`正面¾可见`｜`左侧面可见`｜`右侧面可见`｜`背朝镜头`。载具 = `车头/车尾/左/右侧身朝镜头`｜`¾车头/¾车尾`（飞行器=`机头朝镜`｜`机尾朝镜`｜`侧身朝镜`，语义同车头族）。动物 = 身躯镜头关系 + `头朝{对象|左|右}`。
镜头关系按本层已算 `可见面推`＋本拍 N 投影（上游宫格／人行不供 `可见面推=`／`体侧=`）。场记可按对向换算；**成稿不明示** `180°` / `相对180度` / `面向N°` / `侧面90度`。
**人↔载具同向**：只执行上游 `人载同向=`（§1）。`相对=后方` 却写成骑手正面／`面向镜头` = 投影失败（不改挂）。

**朝向成稿闸**：所对主体可见 → `面向=` 写该对象／角色，镜头关系按 `可见面推`＋本拍 N。所对主体不可见 → `面向=` 或 `目光=` 写 `面向镜头`；身体朝向这一具时镜头关系写 `正面可见`。`朝向推=`／`背对=` 只进场记。禁 `面向N°`／「即面向镜头」。禁用 `面向镜头` 顶替仍可见的主体。落点画位 ≠ 可见面。

**转身过程拍（转肩只从建置判）**
时序走 §2。入戏出现转身 / 转面 / 调头 → `拍型=转身过程`。禁同拍开口 / 走位 / 取物。轴未变可同父 ENV。禁写转了多少度。
- **建置**：只写动作前档。禁写成转后面向。
- **入戏**：只写连续转体（可见面随转写出，不写 XOR）。五件套只进终态：`向{左|右}肩转 → 终态面向{对象} → 终态镜头可见面 → 终态姿态 → 终态落点`。
- **下拍建置**：才抄本拍终态新朝向。❌本拍建置与终态面向相同却写入戏「转身」。

**转肩判定（角色自身左/右，不是画面左/右）**
只以**本拍建置**为开拍态，禁止用终态回推。
1. 转肩读分布图世界对象 A，不读已译成 `面向镜头` 的建置句。几何锚取该对象在宫格上的格；无明示才用场记 `朝向推=`。
2. 用**本拍** ENV `背景=`/`画左=`/`画右=`（及近镜头侧）把 A、B 各落入四向之一：`近镜头|远镜头|画左|画右`。B=入戏要转到的明示对象；无明示则用 `朝向推=` 或三锚几何。缺三锚=失败。
3. 按建置面向所定的角色左/右，取从 A 到 B 的较短转：

| 建置面向所在向 | 角色左 | 角色右 |
| :--- | :--- | :--- |
| **远镜头**（对背景） | 画左 | 画右 |
| **近镜头**（对机位） | 画右 | 画左 |
| **画左** | 近镜头 | 远镜头 |
| **画右** | 远镜头 | 近镜头 |

B 在角色左 → `向左肩转`；在角色右 → `向右肩转`。B 与 A 对向 → 须上游已拆转身过程拍或已锁越轴，禁同拍硬拧 180° 还开口（未拆 → 回流）。
❌用画面左/右当角色左/右。❌用转后面向当建置再回推转肩。❌默认某类陈设（门/窗）在某一侧。

**切角只换观察向**：未走位未转身者，世界槽／看谁不改；近远／画幅／可见面按本拍 N 投影（90/270 禁正背照抄）。`所在侧` 查 §7A。

**落笔序**：决策链 2→4。句内序= `面向=` → 镜头关系 → 站位投影 → 姿势 → 手持／佩戴 → 投影面表情。速查另抄 `所在侧`；`朝向推=`／`背对=` 不进建置句。不写脸可读核销。

**反打 ≠ 转身**：反打时未转身者面向对象 / 姿态 / `所在侧` 不变，镜头可见面随观察向对调。来源 = **紧邻上拍终态**（上拍是转身过程拍则取其终态新档，禁回取该拍建置旧档）。相对锚名与辅边位不改写，近/远镜头对调，左右改查新 ENV 画幅锚实体。

层位按对向对调（前景↔后景、画左↔画右）。纵深词对调；世界槽（`近门一侧`/`主位`/`辅=`）不改口。`投影恒等` 仅轴心层位/中央，≠可见面／近远没变。落到 `◎` 背后 → `暂不可见`。禁照抄上拍正面／靠近镜头／前景。反打后仍要同一可见面 → 须上游已有转身过程拍，否则回流。

**背朝镜头门禁**：禁写五官／胸腹正面。神色上屏只抄上游评（§1）。

## 6. 空间执行
- **出入舱**：过程拍与落定拍须上游已拆（本层不另起）。入舱过程拍仍挂仓外衍生；落定拍触发 = `入舱切主环境`，ENV = `{N}度{仓内主名}`。出舱落定拍触发 = `出舱切主环境|回切仓外主环境`；建置 = 所经那扇门外侧旁，载具外部整体入画，**`当前环境`=宿主，禁仍写驾驶舱**；下一拍抄同扇门旁落点。入戏执行上游 `过阈运镜=`：外→内写连续推过具名门/窗/舱口，内→外写连续拉过同一口；禁改成硬切换空间。过程未完成且建置不见整机远观的那一拍不切 ENV。**本拍建置已是整机 EWS/航拍／机尾朝镜 → 按落幅执行，`当前环境` 必须已是宿主**；仍写驾驶舱 → 回流。入戏写「落幅在风雨大世界／整机入画／名牌【霓虹摩天楼】」而建置仍=`飞行器驾驶舱` = 失败。未拆 → 回流。
- **多门路径**：入 = `门位→落点/座位`；出 = `舱内位→门位→门外落点={外部本体}之{门位}外侧旁`。
- **触达**：接触对象须在开拍可见集且一臂可达；否则先切已锁可见该物的角。
- **载具**：入戏只写运动 / 操作事件；途经、停靠、上下车起终点进建置 / 终态。
- **门窗开关（评估；有则强制；按环境合同匹配改写）**：凡入戏含开/关/推/拉/滑门窗（含车门/舱门/厢门/窗扇），**先读该口环境规划合同**（四向+固定清单；复用场读 `本场门窗初态`）：`扇型=单扇|双开` + `开闭=` + `开向=里|外|左滑|右滑` + `门轴=` + `把手=`（双开另读左右扇各份与`通行扇=`）。缺合同=失败，禁常识另造。文戏过程只作意图（谁开哪口、开或关）；**推|拉、接触点、开向词、人站侧、扇展侧、开哪一扇与合同冲突则改写**，左右手可承文戏，但触点不得落**该扇**门轴侧（冲突改到把手，必要时换手）。不改对白、不改门口注册名（裸「开门/开车门」须点名已锁口；双开再点左扇|右扇|双扇）。
  1. **建置开拍态**：该口入画则写开拍开闭（≡上拍终态；首拍=环境初态/`本场门窗初态`）。双开须分写左扇/右扇开闭，禁合成一句「对开门半开」。半开/全开须带该扇扇展占位核销 `开向`（里=占室内/舱内；外=占室外/车外）。门轴是世界属性，**不随本拍画左画右翻转**。
  2. **力向核销（铰链扇）**：`开向=里`＝扇面向室内/舱内展开；`开向=外`＝扇面向室外/车外展开。打开：人在门外/仓外 + 里 → **推向里**；人在门内/仓内 + 里 → **拉向里**；人在门外/仓外 + 外 → **拉向外**；人在门内/仓内 + 外 → **推向外**。关上=反向力，开向词不变。车门/舱门同表。双开**逐扇**套本表（左扇用左扇门轴/把手，右扇用右扇）。
  3. **推拉扇**：单扇 `开向=左滑|右滑`、`门轴=无` → 力=滑向已锁向。对开推拉：左扇滑左、右扇滑右，禁写成铰链推拉。
  4. **双开（一口两扇；强制点扇）**：只开通行扇 → 只写该扇触点+扇展，另一扇保持其开拍开闭。双扇同开 → 两触点（或双手各一扇），扇展对开（左扇往其门轴侧/左、右扇往右，占位仍同核一个开向）。通行只经已开扇缝，禁穿仍关的那扇。❌把整樘写成单扇一门轴｜❌只写「推开对开门」不分左右扇。
  5. **入戏句**：单扇=`在{门名}{把手左|右}{上|中|下}部{向里|向外|左滑|右滑}{推|拉|滑}{开|上}` + 人站={门内侧|门外侧|仓内|仓外} + 扇展。双开在门名后加 `{左扇|右扇}`，触点用该扇把手（中缝）。例：单扇 `开向=里｜门轴=门左｜把手=门右中`、人在门外 → `CHAR:[@甲]右手在大门右中部向里推开门，门扇往室内展开`；双开 `开向=里｜通行扇=右扇`、人在门外 → `CHAR:[@甲]右手在正门右扇左中部向里推开右扇，左扇仍关，右扇往室内展开`；双扇同开外开 → 左右手各在中缝把手向外拉开左右扇，两扇往室外对开。
  6. **态连续**：该扇开拍已全开 → 禁再写打开该扇，改写为经该扇缝通行。开拍全关 → 禁穿该扇、禁写门后可见。过程从建置初态推到终态；双开终态分写左右扇 `开闭=`。
  ❌照抄文戏「拉开」却与里开/外开冲突｜❌只写「开门/推门/开车门」无接触点无开向｜❌手摸该扇门轴侧｜❌切角后把门轴改到画面对侧｜❌半开却不写扇占里或外｜❌双开不分扇
- **已锁 OTS / 正反**：拍摄键只执行、写入建置首句，禁改档。读对手／同侧过肩成句见下表；邻拍 180°／禁 ±90° 冒充由上游已锁，本层不重推。
- **禁入戏假切**：【入戏】禁止写「镜头切为／切到…视角／【OTS正反覆盖】」而 `当前环境=` 不变。上游把正反写进同一拍 → 回流拆拍。`OTS类型=读对手` 必须已 `ENV变=是`。
