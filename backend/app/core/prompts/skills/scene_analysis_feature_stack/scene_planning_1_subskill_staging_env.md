## 目标
按**单场**调用。输入已含【主环境】【未落清单】【衍生环境】、覆盖矩阵、【Beat景别构图方案】、各拍【取景锁定】与【场记分析】，以及文戏/特效/仙攻过程。
已锁拍摄是开拍条件。本文件把**拍摄键写入【建置】【入戏】**，把**推导与连续性写入【场记分析】**，并核对走位与逐拍出入画，保证动作、位置、人物/道具关系、**轴位**跨拍连续（默认不越轴）。场头写【实体覆盖】【位置规划】【观察视角与空间建置】。
1. **连续性（核心）**：动作链无跳步；开拍位置 ≡ 上拍终态（同 ENV 抄 `终态画面纵深`，ENV 变只按新 N 重投影、不瞬移）；每人与相关人的前/后/左/右/距离/面向关系可核销并跨拍承接；站位 / 走位停在已锁 `spatial_axis` 同一侧。
2. **走位核对与细化（核心）**：据已锁 ENV / 景别 / 活动空间 / 轴线，核本拍走位是否可拍且不越轴（净空、不穿障、步幅、门径向、触达一臂、终点仍被白名单覆盖、路径不跨轴线）；再把路径写清：`{名}:自{开拍定位}→经{路径/门/步数或臂距}→到{终态定位}`，并写停驻后与他者相对。无走位须明文 `走位=无`。
2A. **逐拍出入画（核心）**：谁在画、谁入、谁出、经哪口，必须在本文件写完。开拍在画 =【建置】具名主体；中途入画 =【入戏】写经{出入口}入画过程（建置不含，终态写入）；中途出画 = 建置含、入戏写出画过程、终态剔除。切角暂不可见 ≠ 出入画。场头【实体覆盖】写在场 / 待入画 / 出入口 / 离场。
3. **拍摄写入建置/入戏**：该拍 `当前环境` / `景别` / `构图` / `可兼` / `主体落点` / `留白` / `纵深层` / `镜头角度` / `关系角` / `OTS类型` / `近侧框主` / `主拍对象` / `主观角色` = 输入已锁拍摄键。标题后**不保留**独立【取景锁定】行；拍摄键全部写入【建置】首句。入戏只写镜头实际看见的过程（对白/微表演/`<…>`），不写锁档键值、不写推导。
4. **三段式**：每个最终 Beat 依次写 `────【建置】────` → `────【入戏】────` → `────【场记分析】────`…`────【场记分析结束】────`。
5. **推导写入场记分析**：`原文景别` / `原文角度` / `角度动机` / `上拍镜头角度` / `角度跨度` / `剧情匹配` / `上拍景别` / `跨度` / `选择证据` / `[DERIVED_ENV:…]`、世界度数（`F≈` / `0°侧`）、走位终态 / 速查 / 差集 / 开拍评估，全部写入【场记分析】。输入已有【场记分析】则并入本拍该段，禁另起【Beat切换说明】。
6. **入戏承过程**：对白、语气、微表演、左右手脚、取用、朝向对象、门开闭、特效/仙攻、`<…>` 写入【入戏】；位置 / 朝向 / 层位 / 距离 / 起终点只进【建置】或场记分析终态。入戏只写走位发生（走、停、转身），不写起终点坐标。
7. **完整一场**：从 `[SCENES_BLOCK_START]` 起笔；末行 `[STAGING_ENV_OUTPUT_END]`。

## 硬约束
1. 不改事实 / 因果 / 对白词 / 场核 / `节拍=`。
2. 成稿写出原文本身。
3. 专名与环境注册名逐字。
4. 物理可拍优先；`正面/¾朝镜头` 与 `面向后景` 互斥。未锁越轴则走位 / 左右屏不得跨 `spatial_axis`。
5. 【建置】【入戏】禁世界度数词（`F≈` / `0°侧`）；`速查更新` / `视角换算台账` 必须写扇区与 F，只进【场记分析】。
6. 仅因出入画改集合、转身改档、已锁 ENV 变、出入舱落定可另起 Beat。

| 术语 | 定义 |
| :--- | :--- |
| **建置** | 开口前可拍画面：拍摄键（ENV/景别/构图/机位/关系角）+ 可移动主体落位 / 朝向 / 姿态 + 可见 ENV 实体微动。固定陈设不写层位。 |
| **入戏** | 镜头看见的过程。不写位置、朝向、锁档键值或推导。 |
| **场记分析** | 推导与连续性：选择证据、跨度、原文映射、世界度数、走位终态、速查、差集。不成画面句。 |
| **XOR** | 同一主体定位只选绝对或相对一种。 |
| **朝向三联** | 正背面 + 面向对象层 + 层位词≡实层。 |
| **入画径向三联** | 门层位 × 行进径向 / 正背面 × `活动适配`。 |
| **走位** | 可移动主体在已锁空间内的位移：开拍定位 → 路径 → 终态定位 + 与他者关系变化。本文件核对并写清。 |

## 1. 三段
- **【建置】**：首句写满拍摄键（见目标 3）；其下仅开拍已在画、查表可见者。封闭 / 槽位空间用相对槽位；开放大空间才用前中后景 + 画左中右。写正背面、面向、姿态。运动后落点不进建置。`构图=` / `主体落点=` 只约束取景，不改世界落位。禁写 `选择证据` / `跨度` / `原文景别` / 世界度数。
- **【入戏】**：动作 / 对白 / 表情 / 交互 / 动势 / `<…>`。不写前中后景、画左中右、距离、槽位、起终点、F / 正背面变化、放置位置，也不写锁档键值或选择证据。画内缺角色微动则只补不抢戏的微反应；ENV 微动只延续建置已写项，不改已写动作 / 对白。
  - ✅建置已写`窗纱轻摆` → 入戏只写`窗纱续摆`
  - ❌入戏另起`旗帜猎猎`（建置未写） / 入戏写`陈走到画右` / 入戏写`跨度=越级`
- **【场记分析】**：拍摄推导（原文映射 / 跨度 / 角度动机 / 选择证据 / `[DERIVED_ENV:…]`）⊕ 建置 ⊕ 入戏 → `变化过程` + `终态画面纵深` + `速查更新`。同 ENV 下拍抄终态句；ENV 变取速查再按新 N 投影。无运动仍复述终态与周边相对。世界度数只写本段。
- **集合**：`终态=(建置−出画)∪入画/突现`。中途入画者不进建置，终态写满字段；中途出画者建置含、终态剔除。差集须写 `{名}|出画|经=…` 或 `{名}|入画|经=…`。
- **不可见**：机位后方 / 完全遮挡 → 禁入建置 / 入戏；必须进 `差集处置` + 速查 `暂不可见`。
- **可移动主体**（角色 / 具名龙套 / 群演簇 / 动物 / 载具 / 法相金身）：同等落位 + 朝向 + 进出场。群演簇写人数 / 队形 / 主导正背面。人—车 / 人—骑分行。
- **不提前入场**：剧情角色首次剧情 Beat 前 = `待入画`。豁免 = 氛围龙套 / 群演簇（须依据）。
- **出入画另起拍**：该拍只写出入画（入戏写经哪口、行进径向、落定/离场）；落定后下一拍才对白 / 主动作。切角暂不可见 ≠ 出入画。禁只改集合不写过程。
- **动作覆盖**：建置内每人 / 每簇至少 1 个可见微动。剧情强制静止须写静止证据。受者响应须针对该动作，不能用旁观微动代替。
- **环境背景微动态（强制）**：每拍【建置】可见 ENV **≥1** 项开口即在、可持续入戏的**实体物理微动**（禁静态空镜；无角色亦须）。点名陈设 ∈ 剧本 ∪ 本拍已写 ∪ Index ∪ 当前衍生 ENV；无可动锚则对已有结构写极轻态 1 句。选型 1–2 项（树冠轻晃 / 窗帘轻摆 / 远距车流 / 雨丝 / 旗帜等——实体须已出现）。幅度 subtle、不抢入戏主动作；宏观禁整齐机械同步。光斑 / bokeh 不进建置 / 入戏。
  - ✅`ENV背景微动=窗纱随穿堂风轻摆（开口即在，持续）`
  - ❌`大厅安静` / `氛围很好` / 只写人群晃动冒充 ENV / 光斑 bokeh
- **双层**：①ENV 实体物理微动（每拍必填，无人群亦须）→②有群演簇时追加簇内随机动势（禁用人群替代①）。入戏只延续已写微动。
  - ✅`ENV背景微动=窗纱轻摆` + `群演簇=后排3人｜簇内动势=肩线错落轻晃`（①②并存）
  - ❌只写`弟子列阵微晃`、建置无 ENV 实体微动
- **空镜拍**：建置 = `空镜／无角色`；固定陈设不写画面层位，仍须写 ENV 实体微动。
  - ✅`空镜／无角色｜ENV背景微动=檐下灯笼随气流轻晃`
  - ❌`空镜／无角色` 后无任何 ENV 微动

## 2. 连续性与走位
每拍先对上拍终态与本拍已锁取景做核对，再写建置 / 入戏 / 终态。

**动作连续**
- 上拍未完成的动作链本拍承接，禁跳步、禁蒸发受者响应。
- 姿态 / 持物 / 朝向对象连续；变则须有本拍可拍过程。姿态档（站坐跪蹲趴躺倚骑，含承托面）逐字继承；切角 ≠ 改姿势。入戏有过渡链才改终态姿态，建置仍写旧档。
- 正背面本拍内锁定。随身件无离身链则建置重复上拍挂载部位。

**位置连续**
- 世界真源 = `扇区+F+姿态+锚`；画面词 = 本拍 N 投影。
- 开拍位置 ≡ 上拍终态：同 ENV 一字不落抄 `终态画面纵深`；ENV 变写【上一ENV→触发→本ENV】，无走位 / 转身时世界扇区 / F / 姿态 / 锚不变，只按新 N 重算层位 / 左右 / 正背面。禁切角瞬移。
- 反打 = 同主名 + ±180°。换主名触发 = `闪回切主环境|蒙太奇切主环境|回切当下主环境|入舱切主环境|出舱切主环境|回切仓外主环境`，禁标反打。

**关系连续**
- 每人须写与相关人 / 锚的前/后/左/右 + 尺度距离 + 面向。走位后关系必须可从开拍关系 ⊕ 本拍路径推出。
- 正反打场：走位不得无过程把相向拆成同向，或把同向拧成相向。关系变须写在 `变化过程`。

**轴位连续（不越轴）**
- 轴线 = 本场已锁 `spatial_axis`。站位、走位路径、停驻点、画左/画右必须落在轴线同一侧。
- 已锁 `axis_crossing=None`：禁跨轴；左右屏相对上拍保持同侧。
- 已锁 `PlannedReverse`：沿轴线对向，左右屏对调合法，仍算守轴，**不是**越轴。
- 已锁 `MotivatedCross`：允许跨轴，走位终点落到轴线另一侧，写 `越轴=是｜动机=` 该拍已锁动机。
- 失败：未锁越轴却因走位跨到轴线对面；无反打依据拧反左右屏；把越轴写成普通反打；改挂方案外角来圆越轴。回改走位。
  - ✅`守轴核销=林|轴线侧=同侧｜陈|轴线侧=同侧`（`axis_crossing=None`）
  - ✅`守轴核销=林|轴线侧=对调(PlannedReverse)`（已锁反打，左右屏对调合法）
  - ❌`守轴核销=通过`（无人名、无轴线侧） / 未锁越轴却写`跨轴`

**走位核对**（相对已锁取景；不通过则回改落点或拆已锁空间硬锁拍，禁改挂方案外角）
1. 开拍落点 = 上拍终态，无瞬移。
2. 路径物理可拍：净空、不穿障、步幅够、门径向闭合。
3. 终点仍在已锁活动空间；本拍必见项仍 ⊆ 已锁白名单。
4. 走位后距离档与已锁景别同向（贴身 ↔ MCU/CU；数步对峙 ↔ WS/FS）。
5. 触达对象开拍已在画且一臂可达；否则先切已锁可见该物的角。
6. 停驻后仍留后续动作净空（贴墙无退路、叠脚无步幅 = 失败）。
7. 路径与终点不越轴（上条）；`守轴核销=` 必填。

**走位细化**（写入 `变化过程` + `终态画面纵深`）
- 有走位：`{名}:自{开拍定位}→经{路径/门/步数或臂距}→到{终态定位}｜相对={谁}之{前|后|左|右} 距=…`
  - ✅`陈:自柜台远镜头侧→经两步绕桌角→到八仙桌近门一侧｜相对=林之后 距=半臂`
  - ❌`陈走过去` / `陈来到那边`（无自/经/到）
- 停驻须落点可辨，不得与他人 / 锚混淆。
- 无走位：`走位=无`，仍复述终态关系。
- 多门：入=`门位→落点/座位`；出=`舱内位→门位→门外落点`。

## 3. 场头块
写在第一个 Beat 前。

**【实体覆盖】** 逐主体：`入场类别=剧情角色|氛围龙套|群演簇`｜`首次剧情Beat=`｜`开场在场依据=`｜在场 / 待入画｜出入口｜离场。本场涉及的全局角色 / 道具 / 环境具名入表。

**【位置规划综合】** 全场走位总账：主锚｜C位｜依据｜走位节点=B…｜轴线=`spatial_axis`｜守轴=是｜越轴拍=B…|无。**【角色位置】** / **【未落实体位置】**：初 / 变（哪一拍、自何到何、相对谁、是否跨轴） / 终。只写核对后的结果。站位不得布置在轴线对面。

**【观察视角与空间建置】** 附：
- 【动作空间综合】C位｜各人区域 / 动线 / 净空 / 前后左右 + 距离 / 后续型
- 【露脸冲突】需求｜冲突｜处理｜可拍

排位：地位 → 剧情 → 重要者 C 位。

## 4. 定位 XOR
只约束建置与终态。每人只选一种。
1. **封闭 / 槽位空间**（驾驶舱 / 车厢 / 轿厢 / 客舱 / 小房间 / 狭廊）：强制相对。槽位ID=`第N排-左起第K/M位-{功能名}`。排号以 0° 驾驶观察向最前排为第 1 排；横位 = 面朝 0° 时舱体左→右。相对角色不入实层表。
2. **室内有稳定锚**（桌 / 床 / 门 / 柜台）：相对槽位。桌椅床沙发须写哪一头 / 哪一侧 / 近镜头侧|远镜头侧。
3. **空旷无锚**：绝对 = `前景(离镜近处)|中景|后景` + `画左|中央|画右`。绝对角色入实层表。
4. 同句禁叠绝对 + 相对。面向层位 ≡ 对象实际纵深。人际「前 / 后」≡ 镜头近 / 远。
5. 每人须写与相关人的前 / 后 / 左 / 右 + 尺度距离。

## 5. 朝向与投影
档位：角色 = `正面/¾`｜`左侧面`｜`右侧面`｜`背对/侧背面`。载具 = `车头/车尾/左/右侧身朝镜头`｜`¾车头/¾车尾`。动物 = 身躯 F + `head_facing`。

**转身过程拍**：入戏出现转身 / 转面 / 调头 → `拍型=转身过程`。建置 = 旧档；入戏只写连续转体；终态 = 新档。禁同拍开口 / 走位 / 取物。五件套 = `旋转方向/幅度 → 终态面向 → 终态正背面 → 终态姿态 → 终态世界锚`。轴未变可同父 ENV。

**投影**（俯视顺时针；后景 = N°；前景 = `(N+180)%360`；画左 = `(N+270)%360`；画右 = `(N+90)%360`）：

| 世界扇区 | N=0 | N=90 | N=180 | N=270 |
| :--- | :--- | :--- | :--- | :--- |
| **0°侧** | 后景 | 画左 | 前景 | 画右 |
| **180°侧** | 前景 | 画右 | 后景 | 画左 |
| **90°侧** | 画右 | 后景 | 画左 | 前景 |
| **270°侧** | 画左 | 前景 | 画右 | 后景 |
| **轴心** | 中景中央 | 中景中央 | 中景中央 | 中景中央 |

**F↔正背面**：`F≈N` → 背对；`F≈N+180` → 正面 / ¾（禁面向后景）；`F≈N+90` → 右侧面须面向画右；`F≈N+270` → 左侧面须面向画左。

**朝向三联**：正面 / ¾ 若写 `面向{对象}`，对象须更近镜头；背对则对象须更远。同层只写画左 / 画右或镜头向。

**落笔序**：定面向世界目标 → 推 F → 查表得正背面 → 写建置画面句 → 速查抄 F。

**反打 ≠ 转身**：反打时未转身者 F 不变，正背面随 N 对调。180° 反打：正面↔背对、左侧面↔右侧面；层位前景↔后景、画左↔画右。轴心可仍中央。来源 = 上拍终态。

**F 承接**：无转身过程拍则开拍 F = 上拍速查 F。

**背对门禁**：背对禁写五官 / 口型 / 胸腹正面与 `对镜头`。须读脸 → 已锁可读角的下一拍再写。

**入画径向**：后景门入 → 朝镜头 → 终态正面（背对门）；近端门入 → 向纵深 → 终态背对。

**驾驶舱投影**（无转身、全员 `F≈0`）：

| 当前 ENV | 可见 | 后景 | 不可见 |
| :--- | :--- | :--- | :--- |
| `0度` 贴操纵员后脑 | 操纵员后脑 | 前窗 / 驾驶台 | 其身后人员 |
| `0度` 舱尾望前 | 全员后脑 | 前窗 | 任何人脸 |
| `180度` 拍后方人员 | 后方人员正面 | 后窗 | 操纵员；前窗 |
| `90/270` | 近侧门窗 + 全部座位侧面 | 对侧窗 | 半舱漏座 |

禁 `0/180` 标后排 + 司机 Two-Shot。`N=180` 后方人员可写 `面向镜头正中`，F 仍 ≈0。

## 6. 空间执行
- **出入舱**：入舱过程拍仍挂仓外衍生；落定后另起拍，触发 = `入舱切主环境`，ENV = `{N}度{仓内主名}`。出舱落定后另起拍，触发 = `出舱切主环境|回切仓外主环境`；建置 = 所经那扇门外侧旁，载具外部整体入画；下一拍抄同扇门旁落点。
- **多门路径**：入 = `门位→落点/座位`；出 = `舱内位→门位→门外落点={外部本体}之{门位}外侧旁`。
- **触达**：接触对象须在开拍可见集且一臂可达；否则先切已锁可见该物的角。
- **载具**：入戏只写运动 / 操作事件；途经、停靠、上下车起终点进建置 / 终态。
- **门**：开闭过程承输入；进出起终点进场记分析。紧闭禁写门后可见内容。
- **已锁 OTS / 正反（建置写清）**：`关系角=` / `OTS类型=` / `近侧框主=` / `主拍对象=` 只执行已锁拍摄键，写入【建置】首句，禁改档。

| 已锁类型 | 建置须成立 | ENV |
| :--- | :--- | :--- |
| **读对手 / 反打** | 越过近侧肩/腰/身看对方脸；背景半空间对向 | 挂已锁对向 `{N}度…`；禁同父冒充 |
| **同侧过肩** | 近侧只作框，不换对手可读面、不改背景扇区 | 同父 ENV；禁标反打 |

`关系角=过肩|过腰|OPC` 时【建置】四要素缺一失败（肩主=`近侧框主`；主拍=`主拍对象`）：
1. **过谁**：前景框主具名
2. **框主可见面**：左侧面｜右侧面｜正面｜背面
3. **左/右肩**（过腰=左/右腰侧）；与画左右、轴线留白自洽
4. **看谁**：主拍具名 + 其正/侧/背面

句式：`过 CHAR:[@甲] {可见面}{左|右}肩 → 看 CHAR:[@乙] {正/侧/背面}`。
- ✅`过 CHAR:[@林] 右侧面右肩 → 看 CHAR:[@陈] 正面`
- ❌`过肩看陈`（缺框主可见面 / 左右肩 / 主拍正背面）
切角时未转身者 F 不变，正背面随 N 对调（§5 反打≠转身）。
**切主 ≠ 反打**：`闪回切主环境|蒙太奇切主环境|回切当下主环境|入舱切主环境|出舱切主环境|回切仓外主环境` 不标反打。前向驾驶舱 `0°↔180°` = `同向驾驶舱读角`，不得当厅堂反打（`180度` 不得保留前向操纵员在画）。出入舱后禁仍挂舱外 ENV 写舱内戏。

可见三态：`V` 可写可见面；`D` 只写朝向 / 声音 / 画内受力；`X` 禁入建置 / 入戏，进差集。

## 7. 场记分析字段
标记成对。缺结束标记 = 不合格。先写拍摄推导，再写连续性。必含：
0. `原文景别=`｜`原文角度=`｜`角度动机=`｜`上拍镜头角度=`｜`角度跨度=`｜`剧情匹配=`｜`上拍景别=`｜`跨度=`｜`选择证据=`｜`[DERIVED_ENV:{已锁完整名}]`（从输入【取景锁定】/【场记分析】原样并入，禁改档）
1. `Beat开拍评估=`（走位核对 1–6 + 已锁白名单覆盖本拍必见项；须抽样）
2. `建置更新=`｜`ENV变=`｜`{Beat终态画内实体}`｜`角色分组`｜`上拍终态差集`｜`差集处置`
3. `变化过程=`（走位细化句或 `走位=无`）｜`终态画面纵深=`｜`空间重评=`（停驻后净空 + 关系是否连续）
4. `守轴核销={名}|轴线侧=同侧|对调(PlannedReverse)|跨轴(MotivatedCross)|失败`
5. `建置·朝向·视角自检=`（全量；反打另写档位承接）
6. `视角换算台账=`（ENV 变必填，否则 `N/A`）
7. `建置逻辑核销=通过|失败` + `N=?｜后景=?｜前景=?` 与必要抽样
8. `速查更新=`｜`F承接核销=`

终态格式：
- 绝对 = `{名}|{前景|中景|后景}|{画左|中央|画右}|正背面=…|面向=…|姿态=…|随身件=…|在{谁}之{前|后|左|右}|距{谁}=…|C位=`
- 相对 = `{名}|{主锚槽位+近|远镜头侧}|正背面=…|面向=…|姿态=…|随身件=…|在{谁}之…|距{谁}=…|C位=`

差集：`{名}|出画|经=…`｜`仍可见`｜`暂不可见|挂靠视角=…|扇区=…|姿态=…`｜`已转可见|带入建置=是`

## 成稿自检
- 完整一场 + 末行结束标签；环境块 / 覆盖矩阵 / 景别构图方案未改。各拍无独立【取景锁定】行。

- 动作 / 位置 / 关系 / 轴位跨拍连续：开拍 ≡ 上拍终态，无跳步、无瞬移、关系可从路径推出；未锁越轴则路径与左右屏未跨 `spatial_axis`。
- 走位已按已锁取景核对（净空 / 径向 / 白名单 / 景别距离同向 / 触达 / 不越轴），`变化过程` 已写清自→经→到或 `走位=无`，`守轴核销=` 已写。
- 【入戏】承过程且无位置 / 朝向 / 锁档 / 证据；同 ENV 下拍抄上拍终态，ENV 变则重投影。

- 【位置规划】已写全场走位总账。
- 定位 XOR、朝向三联、F 承接、反打 ≠ 转身闭合。过肩/过腰/OPC 四要素已写；读对手已挂对向、同侧过肩未标反打；切主未冒充反打。
