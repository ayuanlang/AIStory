6. **本层不另起拍**：出入画改集合、转身改档、已锁 ENV 变、出入舱落定须上游已拆成独立拍。未拆或同拍混开口／走位／取物于转身过程 → **回流上游**。本层只执行已拆拍。
7. 相对落位须核销到具名锚；成稿主语=该人，**禁过程词「相对{锚}」**。可见锚能区分该侧 → 只点该锚+世界侧名，禁叠 `靠近镜头|远离镜头`。宫格参照=画外 → 硬约束 10。无可见锚才写本拍投影的近/远。三维挂在侧名上。高低 `平`=齐站，成稿省略，禁「平的{侧}」。禁无主语句。
8. **自然语言整句**：【建置】键值行外须另写完整句：镜头关系（闭集；本层按可见面推表＋本拍 N 投影）+ 姿势闭集（§2）+ 已锁方式落位（§4；位置投影见同簇／位置投影表）+ `面向=`世界主体 + 手持/佩戴（§1）+ 投影面表情（§1）。【入戏】仅走位 / 转身 / 出入画 / 变姿 / **转视线**时用同样整句写**新**镜头关系 + 新落点 + 新姿势 / 新面向主体。无走位禁复述初态。缺画内镜头关系、缺姿势、V 者缺 `手持=`/`佩戴=`、背面写五官、`部分可见` 升全身或漏 `露=` = 失败。不因缺「脸可读」失败。画内仅一人不强制凑第二人。成稿禁写相对180°。禁「面向{人}方向（即面向镜头）」。禁因神色把投影背面改成正面。
9. **画幅锚替换（强制；切角左右会变）**：先读本拍 ENV【衍生环境画幅锚】`背景=`/`画左=`/`画右=`/`画外=`。建置**仍按相对/绝对/封闭**成稿（§4）。**绝对定位**：角色必须写清 `画左|画中|画右`（`画中`≡`中央`），再把该画位换成**本拍可见三键里实际在画的实体**（`背景=`/`画左=`/`画右=`；✅绝对 `后景+{本拍背景实体}+画中`）。**相对/封闭定位：角色落位禁止写画左/画右/画中**——只写锚的哪一头/哪一面/`近镜头侧|远镜头侧`/`辅=`/`排座`；环境键 `画左=`/`画右=` 只当具名锚点名，不写成该人画位。✅封闭 `座=左起第K/M个`｜❌相对「位于画左」｜❌丢掉锚/层位/排座只写一个实体｜❌切角后本拍三键已无该件仍写旧件。**`画外=`=镜头后对向主体，明确不可见**——【建置】【入戏】**禁止点名**（禁「对着{画外件}」、禁当可见锚、禁写成后景/画左/画右）。宫格参照落画外时的成稿改挂见硬约束 10。上角锚未出现在本拍可见三键且非画内承托 → 禁写入建置/入戏，速查 `锚=` 原样继承。切角/反打须改查**新 ENV 行**（0°画左≠180°画左；0°画外≠180°画外）。构图 `三分` 可留。场记分析内部可写画左↔画右对调，**画外件只可标不可见、不得写入画面句**。缺可见三键=失败。
10. **宫格参照不可见→近镜头中区某侧旁（强制）**：读【主环境】四向＋中心 与本拍 `画外=`。定位行 `锚=` 或四周参照（北｜南｜西｜东，旧称后｜前｜左｜右）等于本拍 `画外=`，或该参照本角不可见 →【建置】【入戏】落位**禁止点该参照名**。人仍 `可见性=V` 时，改写成**离镜头近处的中间主体**的某一侧旁：①优先主环境中心家具（且本拍可见）；②中心无或该中区件本拍不可见 → 改用本拍离镜头最近的可见中景件（`画左=`/`画右=` 近端或白名单中景；**禁**远景 `背景=`、**禁** `画外=`）。句式=`位于{中间主体}{侧}旁`；侧=世界侧名或本拍 `近镜头侧|远镜头侧`（原 `辅=近门一侧` 而门已画外 → 改 `近镜头侧旁`，禁残留门名）。**相对角色禁写画左/画右旁。**✅`位于八仙桌近镜头侧旁，站`｜✅`位于八仙桌客侧旁，坐`｜❌`位于八仙桌画右侧旁`（相对）｜❌`位于红木柜台客侧`（柜台=本拍画外）｜❌`位于大门近门一侧`（大门=画外）｜❌裸写「位于中间/靠近镜头」却不点中间主体。速查 `锚=` 仍继承原参照（世界槽位不改）。人已 `暂不可见` → 仍不写建置。
11. **建置不解释环境（最高）**：【建置】【入戏】**不解释**环境背景与内容——禁「远景是…」「画面左侧/右侧是…」、材质/陈设墙导游、四向复述、把 `背景=`/`画左=`/`画右=` 扩写成环境描写。环境已由该拍 `当前环境=ENV:[…]` 对应参考图承担，成稿只点名 ENV。本拍可见三锚与白名单具名主体**只作**角色/可移动道具的**定位锚**与**朝向对象**（`位于{可见锚}{侧}` / `面向={明示}`），点名即止：不写该件外观、不写其自身画面位、不把该件写成待生成环境内容。空镜拍=`空镜／无角色／无道具`+`当前环境=`，禁补环境导游，禁 CHAR/PROP 落位。载具只执行上游 `载具档=`，本层不改选；档与挂族冲突 → 回流。【入戏】只在交互/微动时点名该件（推门、坐椅、`ENV背景微动=`），仍不解释环境。❌`远景是木质柜台和酒坛陈设墙，画面左侧是楼梯`｜❌建置另起「环境：大厅金碧辉煌」｜✅`CHAR:[@林] 位于八仙桌近镜头侧旁，站，面向 CHAR:[@对座]，正面可见，目光定，手持=无，佩戴=无`
12. **建置粒度=当前环境（最高）**：一份【建置】只服务本拍一个 `当前环境=`。只写本拍该 ENV 内本层评 `V|部分可见` 者。换 ENV = 下一拍另写【建置】。他 ENV 的人**不进**本拍建置。❌同段并列两套环境里的人。❌先写甲环境远观主体、再写乙环境占用面上的人。

## 1. 建置 / 入戏 / 拍内场记分析
- **【建置】**：首句拍摄键（含 `当前环境=`）。名单=2B。整句配方=§4＋硬约束 8。切角 ≠ 改姿势；本拍入戏才变则建置仍写旧档。组／同簇世界锁抄该拍宫格，画幅／近远按本拍 `◎`＋N 投影。运动后落点不进。硬约束 9–11。**门槛**：入戏含推门／入画且文戏未写人已在厅内 → 建置停门槛；文戏已是厅内开口 → 跟文戏。禁 `选择证据`／扇区／`所在侧=`。禁写名牌。
- **手持/佩戴开拍必写（最高；仅已可见件）**：画内每人必须在建置整句写清本拍开拍 `手持=` 与 `佩戴=`（无则写`无`）。已提取独立件用 `PROP:[名]` + 部位/体侧/握持态。开拍已在身/在手 → **禁等入戏「用时」才第一次点名**（后拍抚摸/发亮仍须开拍已写）。桌上/架上**本体可见** → 宿主写 `手持=无`，该 `PROP:` 另作可移动件建置。盒/匣/袋内**本体未露出** → 宿主 `手持=无`/`佩戴=无`，该件不进本拍建置（待入画）；【入戏】写开盒取出；取出后下拍才改宿主 `手持=`/`佩戴=`。纯造型无戏耳钉/胸针不写。群演簇写簇持械（有则）。`背朝镜头` 禁写胸前件正面。
- **开拍表情**：不核脸可读。投影为正面／¾／侧面 → 按该面写上游已有表情词（侧面写该侧；禁改成正面）。投影为 `背朝镜头` 或 `露=` 不含脸 → 不写五官。`表情换环境评=` 原样并入场记，不据本评改挂。入戏只写相对建置的表情变化。
- **同格挤身／接触未结束**：评 `露=` 与接触带见上文「同格挤身」；未松开须每拍建置复述见 §2「接触关系守恒」。
- **朝向只投影**：`面向=` 抄上游世界对象；镜头关系按可见面推表。`相对=后方` → 骑手写 `背朝镜头`。禁同角无转身改 `面向镜头`。
  - ❌无转身把「面向窗＋侧面」改成「面向镜头＋正面」
- **【入戏】**：只写相对本拍【建置】的变化（目标 6）。无变化禁复述初态。上游本拍已有内容必须整段写入（硬约束 0）。有走位／转身／出入画／变姿 → 整句写新可见面＋新落点＋新姿势（禁只写「走两步／转过身／坐下」）。**视线转移**：正文说到一半改看另一人／另一件 → 入戏写新 `面向={对象}[之左|…]`（所看面，≠站位），建置仍写开拍朝向；禁改成 `面向镜头`。出入画另须视线三拍＋在场者反应（2A）。不写锁档。ENV 微动只在本段。名牌见名牌条。
  - ❌入戏写`跨度=越级` / 无变化却复述初态 / 无对白却写开口闭嘴 / 相对走位写成画左画右 / 「语气层+台词」
- **【场记分析】**：成对标记。先在场核销，再推导键 ⊕ 建置 ⊕ 入戏 → `变化过程` + `终态画面纵深` + `速查更新`。终态只写画内；速查／差集／收拍覆盖未出画全员（`V`→`画内`；`暂不可见` 留站位+因，仍计入收拍）。ENV 变查 §7A。本段不进分镜。
- **集合**：`终态=(建置−出画)∪入画`。中途入画者不进建置，过程写入戏、终态写满；中途出画者建置含、入戏写过程、终态剔除。切角 ≠ 出入画。格式见 §7。
- **不可见**：裁定见「分镜可见裁定」。只认镜后／景别裁切。背面不是不可见。`暂不可见` 不写建置、不写出画。已评 `V|部分可见` 却漏建置 = 失败。
- **可移动主体**：角色／簇／动物／载具／法相／已入场独立 PROP 同等落位。开场已佩戴配饰跟宿主；宿主暂不可见则配饰不进建置。盒内件取出前不进建置。簇仅当仍在画才写队形；上游已拆簇主拍则近景拍不塞簇。人—车分行。CU 只建置本层评 `V`（及接触肢 `部分可见`）。
- **不提前入场**：执行上游 `待入画`。待入画者禁塞进建置／终态／差集／速查。对白点名／后拍将用 ≠ 开场建置依据。开场已佩戴必须写入开场建置。
- **出入画成句**：过程 + 视线三拍 + 在场者反应见 2A。落定后下一拍才对白／主动作。禁只改集合不写过程。
- **动作覆盖**：【入戏】对建置内每人 / 每簇至少 1 个可见微动（计为变化，不是「无变化」）。剧情强制静止须写静止证据。受者响应须针对该动作，不能用旁观微动代替。**打出角色名牌 / 环境名牌物理文字不算动作**，不得顶替本条微动。
- **环境背景微动态（只写入戏）**：每拍【入戏】须有 `ENV背景微动=` 一行。**选件序**：①所属主环境已点名 `背景微动件=` 且本拍白名单或**可见**画幅锚（`背景=`/`画左=`/`画右=`，**不含 `画外=`**）可见 → **优先写该件**及其 `可用动势`（幅度 subtle，不改行动/走位/对白）；②该件不可见、在 `画外=` 或 `背景微动件=无` → 再从当前环境已有细微件选（本拍 ENV `背景=`/`画左=`/`画右=`、固定清单/未落清单、本拍【建置】已点名的小件：帘/穗/灯焰/烟气/水纹/叶/尘/旗角/窗纱/烛火/蒸汽/纸页边等；**禁选 `画外=` 件**）；③仍无可选 → `ENV背景微动=无`（**宁愿空，禁凑件**）。**禁杜撰**原环境没有的物件（❌原无碗却写「碗沿轻晃」）；**禁**拿桌/柜/门/柱/床/墙/柜台等大件当微动锚来凑行。禁括号备注。光斑 / bokeh 不进。【建置】禁写本行。人群动势不替代本行。空镜拍建置=`空镜／无角色／无道具`，本行仍写（有则微动，无则`无`）。
- **开口｜闭嘴（最高；整行原样继承）**：上游本拍有开口行 → 【入戏】**整行原样抄入**：`开口 |` + 说话人 + 八键全文（`voice_type`｜`voice_identity`｜`tone`｜`speed`｜`volume`｜`rhythm`｜`stress`｜`pause`）+ `{台词原文逐字}` + `| 闭嘴 |` + 听者。`{台词}` **必须有花括号**；上游已是原文但未包 `{}` → 只补花括号，不改词。开口/闭嘴与角色用 `|` 并排，中间夹完整对话。禁括号紧贴、禁闭嘴写在台词前。无对白、空镜、纯走位 **禁止**出现开口/闭嘴行。OS/旁白/VO/自白仍算有台词，须整行抄入；**可与动作/画内对白同拍，禁漏 VO 行**。
  - ❌`开口 | CHAR:[@甲] | 语气层+台词 | 闭嘴 | CHAR:[@乙]`（把合同骨架当成交稿）
  - ❌`… | 台词原文。 | 闭嘴 | …`（台词未用 `{}` 包裹）

  - `字幕=已过|无`、群演簇 → **禁写**。

- **换主环境物理文字名牌（强制 · 类似角色名牌 · 落位顶部中央 · 不算动作）**：主环境一换，须像角色名牌一样打出**环境名牌**，叠在画幅**顶部中央**。此为片内图形叠字，不是对白硬字幕、不是画幅底部白字黑边、不是角色行为。

  - **字样（最高；第二段仅明确时间，可空）**：主段=一对角括号 `【{所属主环境注册名}】`。有【本场环境名牌】→ 抄 `字样=`（注册名）+ `时间=`。`时间=`∈原文已写的明确时刻／故事日（`早上9点`／`上午九点`／`重生第一天`／`第三日`），**可空=`无`**。时间为无 → 只打 `【{注册名}】`，后面立刻接 `｜落位=顶部中央`。时间非无 → `【{注册名}】{时间}】｜落位=顶部中央`（结构同角色名牌，第二段只能是该时间）。无注入则注册名用所属主环境，时间从本场原文／场头／衔接摘，摘不到=`无`。**禁**从【场景名称】`·日·外` 推日夜当时间；**禁**上屏日/夜/晨/昏/内/外/季节/气候；**禁**自拟「三年前／童年」。字样主段=注册名**逐字**，禁套 `ENV:`，禁带 `{N}度`，禁带状态后缀。若误写成 `【客栈】日】` / `【客栈】外】` / `【客栈】日·外】` → **剥掉伪时间**，只留 `【客栈】`。

## 2. 连续性与走位
每拍先对上拍终态与本拍已锁取景做核对，再写建置 / 入戏 / 终态。

**动作连续**
- 上拍未完成的动作链本拍【入戏】承接，禁跳步、禁蒸发受者响应；本拍入戏未写完的链须留给下拍续，禁提前蒸发。
- 姿态 / 持物 / 朝向对象连续；变则须有本拍可拍过程（只写入戏）。**姿势闭集**（与【本场姿势】同核）=`站|立|坐|翘脚坐|盘腿坐|平躺|俯卧|向左侧躺|向右侧躺|蹲|跪|半跪|倚|骑|腾空`（`立`=`站`）。建置整句必须明示该词，禁只写`位于…`。抄上拍速查 `姿态=`；无则抄文戏 / 【本场姿势】。切角 ≠ 改姿势。入戏有过渡链才改终态姿态，建置仍写旧档。
- **朝向时序**：本拍建置 `面向=` + 镜头可见面 = 上拍终态（上拍转身 → 新朝向从**本拍建置**落地）。本拍入戏再转身 → 建置仍写动作前；新朝向进终态，**下拍建置**才改写。同 ENV 无转身不改对象。ENV 变且无转身 → 世界对象不改，可见面按本拍 N 重投影。❌把本拍转后朝向写入本拍建置。❌无转身却因换主拍／收景别改世界 `面向=`。
- **随身件守恒**：开拍写法见 §1。无离身链 → 可见宿主抄上拍挂载；宿主不在建置名单 → 只进速查。离身只写入戏，新挂载进终态。发声屏写现位 + 屏面朝向。
- **接触关系守恒（最高；未结束则每拍建置复述）**：上拍终态 / 上游 `触≠无`（牵手/拥抱/押送/按肩/搂腰/接吻）且本拍入戏尚未松开 → 本拍【建置】**必须再次写明**该关系（谁的哪只手/哪臂接触谁的哪部位），即使本拍入戏不再写「牵着/抱着」。禁只靠速查暗示、禁下一拍两人各自独立站位。本拍入戏才松开 → 建置仍写动作前接触态，松开只写入戏，**下拍建置**才去掉。双方都 `V|部分可见` → 双方建置句都写（或一方写完整接触、另一方写被牵/被抱/被按）。一方本拍 `暂不可见` → 可见方仍写接触（手伸出画 / 仍被画外的手牵住），对方 `触=` 留速查。抄上游 `触=` 的式/己/对左右，禁改手、禁与画幅左右对调。
  - ✅上拍已牵手，本拍对白 MCU 建置仍写 `CHAR:[@甲] …右手牵 CHAR:[@乙] 左手`
  - ✅上拍拥抱未结束，切正面仍写 `CHAR:[@甲] 双臂环住 CHAR:[@乙] 左肩`
  - ❌上拍牵手，本拍只写两人分立「位于…站」无牵手
  - ❌建置写成已松开，入戏才写放开
- **入戏跨拍衔接**：入戏不得从与本拍建置矛盾的状态起笔（人已换位、手已换物、半句对白无据另起）；亦不得写到下拍无法承接的终态（半步悬空、物蒸发、动作无落点）。下拍从本拍速查继承站位，并**重评**上拍暂不可见者是否因视角／景别回画；回画则下拍【建置】**整句复述**（≡本拍终态世界键，不是重排）；仍暂不可见则只进下拍台账；下拍【入戏】再写新变化。

**位置连续**
- 真源=已锁方式（§4）+ 速查 `所在侧`。禁 `扇区+F`。
- 开拍站位 ≡ 上拍速查。同 ENV：整句复述开拍落位（画幅锚换本拍可见三键，禁换入 `画外=`）；`面向=`＋可见面档逐字抄上拍；`宫格=`=上拍终态格。ENV 变：写【上一ENV→触发→本ENV】后走宫格转换（格名不改，体侧／近远／画幅必改）。禁「同上」、禁切角瞬移。`暂不可见` 只进速查。
- **换锚核销**：建置 `位于{锚}`／`面向=` 世界对象与上拍终态不同 → 上拍或本拍入戏须有走位／转身路径；否则回抄上拍世界锚或回流。切角／收景别／`镜头推进` ≠ 换锚。`走位=无` 却换锚或换看谁 = 失败。
- **切角≠拧朝向**：无走位无转身 → `面向=` 仍写对象（对象镜后仍写该对象）；可见面与位置按本拍 N 投影。投影是背就写背，禁同角拧成正面、禁本层改挂。
- **明示站位**：抄上游锚／宫格。本层不重判「该不该挂这件」。
- 反打 = 同主名对向已锁 ENV。换主名触发不标反打。来源 = 紧邻上拍终态，禁回取更早建置。

**关系连续**
- 仅本拍画内者互写前/后/左/右 + 尺度距离 + 面向。**轴跟分布图中心格**：普通人同行只写左／右，同列才写前／后；无走位禁把上拍左右改成本拍前后。法相／坐骑／载具抄上游：未离开则同格同朝向；格内身后按上游身后投影（机在背侧：挂靠体近镜头、宿主其身前；机在面侧：挂靠体可更远）；离开则件留原地格、人在新格。禁无离开改成左右分格，禁机在背侧写成宿主前景＋挂靠体后景／远镜头侧，禁人已走开却把车／马跟人写走。同锚或同绝对格须抄上游世界 `同簇相对=0度锁｜在其{左|右|前|后}`，**本层**按同簇投影表投影本拍三维（偏画左/居中/偏画右、上/平/下、近镜头侧/同层/远镜头侧）。世界同行左右 → 建置禁拆成前景／后景。ENV 变用本层投影，**禁**把上拍画面「甲偏画左」原样写进 180°/90° 建置。与画外者的关系只进速查，不写建置。走位后关系必须可从开拍关系 ⊕ 本拍路径推出，并更新投影。
- **身体接触未结束 ≠ 普通左右关系**：牵手/拥抱/押送等须按「接触关系守恒」在**每一拍建置复述**，不得只写「在其左侧」代替仍牵着/仍抱着。同 ENV 整句复述**不豁免**接触句。
- 正反打场：走位不得无过程把相向拆成同向，或把同向拧成相向。关系变须写在 `变化过程`。松开/改握只写入戏。

**轴位连续（不越轴）**
- 轴线 = 本场已锁 `spatial_axis`。站位、走位路径、停驻点、左右屏必须落在轴线同一侧（左右屏=构图/轴线用语；**相对落位写「锚的哪一头/哪一面/近镜头侧」，禁止写该人画左/画右**）。
- 已锁 `axis_crossing=None`：禁跨轴；左右屏相对上拍保持同侧。
- 已锁 `PlannedReverse`：沿轴线对向，左右屏对调合法，仍算守轴，**不是**越轴。
- 已锁 `MotivatedCross`：允许跨轴，走位终点落到轴线另一侧，写 `越轴=是｜动机=` 该拍已锁动机。

  - ❌`守轴核销=通过`（无人名） / 未锁越轴却写`跨轴`

**走位核对**（相对已锁取景；不通过则回改落点或拆已锁空间硬锁拍，禁改挂方案外角）

2. 路径物理可拍：净空、步幅够、门径向闭合。**障物评估（有走位必写）**：直线开拍→终点扫本拍白名单与建置已写实体。无挡=`障=无`。有挡=`障={具名}`，路径须补 `绕={具名}之{左|右|近端|远端}`（对照该拍宫格；入戏可写成画左／近镜头）；直线穿桌/柱/人/门扇=失败。绕障节点须仍在已锁活动空间且不越轴。
3. 终点仍在已锁活动空间；本拍必见项仍 ⊆ 已锁白名单。
4. 走位后距离档与已锁景别同向（贴身 ↔ MCU/CU；数步对峙 ↔ WS/FS）。
5. 触达对象开拍已在画且一臂可达；否则先切已锁可见该物的角。
6. 停驻后仍留后续动作净空（贴墙无退路、叠脚无步幅 = 失败）。

## 5. 朝向与镜头可见面
档位（成稿镜头关系；画内每人必写）：角色 = `正面可见`｜`正面¾可见`｜`左侧面可见`｜`右侧面可见`｜`背朝镜头`。载具 = `车头/车尾/左/右侧身朝镜头`｜`¾车头/¾车尾`（飞行器=`机头朝镜`｜`机尾朝镜`｜`侧身朝镜`，语义同车头族）。动物 = 身躯镜头关系 + `头朝{对象|左|右}`。
镜头关系按本层已算 `可见面推`＋本拍 N 投影（上游宫格／人行不供 `可见面推=`／`体侧=`）。场记可按对向换算；**成稿不明示** `180°` / `相对180度` / `面向N°` / `侧面90度`。

**朝向成稿闸**：`面向=` 只写对象／角色（对象镜后仍写该对象）；镜头关系按 `可见面推`＋本拍 N。`朝向推=`／`背对=` 只进场记。禁 `面向镜头`／`面向N°`／「即面向镜头」。落点画位 ≠ 可见面。

**转身过程拍（转肩只从建置判）**

**转肩判定（角色自身左/右，不是画面左/右）**

2. 用**本拍** ENV `背景=`/`画左=`/`画右=`（及近镜头侧）把 A、B 各落入四向之一：`近镜头|远镜头|画左|画右`。B=入戏要转到的明示对象；无明示则用 `朝向推=` 或三锚几何。缺三锚=失败。

| **画左** | 近镜头 | 远镜头 |

## 6. 空间执行
- **出入舱**：过程拍与落定拍须上游已拆（本层不另起）。入舱过程拍仍挂仓外衍生；落定拍触发 = `入舱切主环境`，ENV = `{N}度{仓内主名}`。出舱落定拍触发 = `出舱切主环境|回切仓外主环境`；建置 = 所经那扇门外侧旁，载具外部整体入画；下一拍抄同扇门旁落点。入戏执行上游 `过阈运镜=`：外→内写连续推过具名门/窗/舱口，内→外写连续拉过同一口；禁改成硬切换空间。过程未完成拍不切 ENV，落幅拍才切。未拆 → 回流。
- **多门路径**：入 = `门位→落点/座位`；出 = `舱内位→门位→门外落点={外部本体}之{门位}外侧旁`。
- **触达**：接触对象须在开拍可见集且一臂可达；否则先切已锁可见该物的角。
- **载具**：入戏只写运动 / 操作事件；途经、停靠、上下车起终点进建置 / 终态。
- **门窗开关（评估；有则强制；按环境合同匹配改写）**：凡入戏含开/关/推/拉/滑门窗（含车门/舱门/厢门/窗扇），**先读该口环境规划合同**（四向+固定清单；复用场读 `本场门窗初态`）：`扇型=单扇|双开` + `开闭=` + `开向=里|外|左滑|右滑` + `门轴=` + `把手=`（双开另读左右扇各份与`通行扇=`）。缺合同=失败，禁常识另造。文戏过程只作意图（谁开哪口、开或关）；**推|拉、接触点、开向词、人站侧、扇展侧、开哪一扇与合同冲突则改写**，左右手可承文戏，但触点不得落**该扇**门轴侧（冲突改到把手，必要时换手）。不改对白、不改门口注册名（裸「开门/开车门」须点名已锁口；双开再点左扇|右扇|双扇）。
  1. **建置开拍态**：该口入画则写开拍开闭（≡上拍终态；首拍=环境初态/`本场门窗初态`）。双开须分写左扇/右扇开闭，禁合成一句「对开门半开」。半开/全开须带该扇扇展占位核销 `开向`（里=占室内/舱内；外=占室外/车外）。门轴是世界属性，**不随本拍画左画右翻转**。
  2. **力向核销（铰链扇）**：`开向=里`＝扇面向室内/舱内展开；`开向=外`＝扇面向室外/车外展开。打开：人在门外/仓外 + 里 → **推向里**；人在门内/仓内 + 里 → **拉向里**；人在门外/仓外 + 外 → **拉向外**；人在门内/仓内 + 外 → **推向外**。关上=反向力，开向词不变。车门/舱门同表。双开**逐扇**套本表（左扇用左扇门轴/把手，右扇用右扇）。
  3. **推拉扇**：单扇 `开向=左滑|右滑`、`门轴=无` → 力=滑向已锁向。对开推拉：左扇滑左、右扇滑右，禁写成铰链推拉。
  4. **双开（一口两扇；强制点扇）**：只开通行扇 → 只写该扇触点+扇展，另一扇保持其开拍开闭。双扇同开 → 两触点（或双手各一扇），扇展对开（左扇往其门轴侧/左、右扇往右，占位仍同核一个开向）。通行只经已开扇缝，禁穿仍关的那扇。❌把整樘写成单扇一门轴｜❌只写「推开对开门」不分左右扇。
  5. **入戏句**：单扇=`在{门名}{把手左|右}{上|中|下}部{向里|向外|左滑|右滑}{推|拉|滑}{开|上}` + 人站={门内侧|门外侧|仓内|仓外} + 扇展。双开在门名后加 `{左扇|右扇}`，触点用该扇把手（中缝）。例：单扇 `开向=里｜门轴=门左｜把手=门右中`、人在门外 → `CHAR:[@甲]右手在大门右中部向里推开门，门扇往室内展开`；双开 `开向=里｜通行扇=右扇`、人在门外 → `CHAR:[@甲]右手在正门右扇左中部向里推开右扇，左扇仍关，右扇往室内展开`；双扇同开外开 → 左右手各在中缝把手向外拉开左右扇，两扇往室外对开。
  6. **态连续**：该扇开拍已全开 → 禁再写打开该扇，改写为经该扇缝通行。开拍全关 → 禁穿该扇、禁写门后可见。过程从建置初态推到终态；双开终态分写左右扇 `开闭=`。
