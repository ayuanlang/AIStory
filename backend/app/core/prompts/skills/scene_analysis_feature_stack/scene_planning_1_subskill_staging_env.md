## 进画测算（最高）

建置最优先的任务：用该拍世界物理坐标，加上本拍机位、望向、景别，逐个测算角色和独立道具留不留在画面里。机位、望向或景别一变就整表重算，禁止沿用上一拍的进画结论。

留在画面的，写进【建置】【入戏】。不留在画面的，这两段不描述，只登记台账（速查保留世界位，`可见=暂不可见`）。名字不进这两段。

用作参照的环境主体同样测算。本角不可见的环境主体，禁止再拿来描述角色或道具站在它的哪一边。原锚名留在台账。

参照不可见、但该角色仍须留在画面（过肩的近侧框主、主拍、景别盖到且人在镜前）→ 这一拍的建置句子可以用临时锚：另一件本角可见的环境主体，或正面可见的主拍主体。临时锚只写在这一拍的描述里。`锚=`、世界位、台账仍是现场编排已选的那一具，不换锚。下一拍原锚重新可见，描述回到原锚，不把临时锚留成新锚。禁止继续写成站在那件不可见的主体旁边。人在镜后或景别盖不到 → 仍只登记台账，不为了有句子把人写进建置。参照本角可见时，沿用原锚，不为构图另选。

## 依赖参考图的不写外形（最高）

只对依赖参考图的主体禁写外形：角色、道具、环境内的主体，以及同类已有参考图的具名物。建置和入戏里这些只写名字、画布位置、姿态、朝向、手持和镜头，不写颜色、形状、大小、材质、纹样，也不展开成红木、圆形、三米。不依赖参考图的，包括特效，可以写颜色、形状、大小和纹样；入戏照抄上游已写的特效形色。

## 成稿口径（最高）

【建置】【入戏】用普通中文。禁止 `位于`、`侧沿`、`同深`、`面向=`、`目光=`、`手持=`、`佩戴=`、`离镜头=`，禁止贴身裸字。贴身写成「大约一掌，中间有缝、不挨着」。开放环境的深度只写前景、中景、远景。`面向=`、`手持=` 这类键只进【场记分析】。所对的人不可见时，【建置】【入戏】不写面对镜头、不写看向镜头。场记 `面向=`／`目光=` 写 `面向镜头`。

**坐标闭集（最高）**：与现场编排相反。现场编排的位置和距离是主环境的东南西北；本层按本拍衍生环境的视角，把它们全部转换成左右和远近。左=画面左，右=画面右，近=靠近镜头，远=远离镜头。开放环境的远近写成前景、中景、远景，左右仍是画面左、画面右。封闭舱的排座照抄，座与驾驶位的罗盘关系改写成这一席在画面左或画面右、靠近镜头或远离镜头。【建置】【入戏】里不得留下东、南、西、北、东面、西侧、朝东、北侧。上游分布图的罗盘字只用于换算，不进成稿，也不进首句 `上机位=`／`机位侧=`／`机位=`。分镜生成只继承这里已经写成的左右远近，不再改回东南西北。
**远近左右（最高）**：每个 Beat 的画面左右和离镜头远近，由两份材料一起确定。一份是该拍现场编排结果：人相对这一个参照主体在哪一边、离开多远、在体外还是在面上或底下。另一份是本拍衍生环境的描述：按 `当前环境=`／`望=` 的 N 只打开对应一格，`0`→`[0度格-左上·北]`，`90`→`[90度格-右上·东]`，`180`→`[180度格-左下·南]`，`270`→`[270度格-右下·西]`。该格的 `正面：`、`左侧面：`、`右侧面：`、`中部：` 写出这一具在本拍衍生环境里的画面位置。`左侧面`＝画面左，`右侧面`＝画面右，`正面`＝远离镜头的那一面，`中部`＝舞台中部。人在这一具的哪一侧，就落在这一格已经写成的那一侧；走位的落点同样落在这一格里这一具的旁边，并带上体外／面上／底下。换衍生环境就换格，再按新的现场编排结果重定远近左右。禁止用邻格。禁止把格内环境句子、材质、墙面导游抄进【建置】【入戏】。建置仍只写角色和道具。

**按角度建置（最高；只译角色与道具）**：与环境资产四宫同一套旋转，但对象只有本拍进画的 CHAR 与独立 PROP。远近左右以「现场编排结果 + 本拍衍生环境描述」为准：先读上游相对那一个参照主体的世界位，再用本拍 `望=`／N（0望北、90望东、180望南、270望西）旋到该格已经写出的画面侧上。旋出的左右远近必须和该格里这一具的位置一致。参考主体与封闭舱的成稿落位写成「在画面左，离镜头更靠近」或「在画面右，离镜头更远离」或「左右对齐，和它离镜头一样远」，再跟距离档。禁止写 `离镜头=`。**世界原点档，尤其开放环境（最高）**：`锚=原点` 的人与独立道具，左右仍写 `画左|画右|对齐`，深度不写离镜头，改写成 `前景|中景|远景`。世界原点那一条深度=中景；旋到靠近镜头一侧=前景；旋到远离镜头一侧=远景。景别决定入画体量（全身／半身／脸／局部），不因人在画里变大就把远景改叫前景。景深不改层位：`CU|ECU|MCU`=`景深=浅`（主拍所在层写清楚，更远的层仍写远景或中景并标 `焦外`）；`MS`=`景深=中`；`FS|WS|EWS`=`景深=深`（进画者不标焦外）。禁止用景深把人挪到另一侧，禁止把环境再写成一套四宫。禁止把人的层位写成「远景是某墙」。

**建置与入戏时序（最高）**：【建置】只写本 Beat 开拍时的初始位置、姿态、朝向和手持，等于动作发生之前的画面。本拍走位、转身、出入画、变姿、取放之后的结果不写进本拍【建置】。本拍才入画的人，开拍还不在画面里，本拍【建置】先不写这个人。**【入戏】**只用动作写出相对这份初始建置发生了什么：走到、转身、坐下、起身、取出、放下、出入画、转视线、对白。入画必须写明从哪里入画，以及停在哪个参照位置。入戏不必把【建置】里已经写过的开拍落位整段再抄一遍。无变化不复述初态。动作要能读出变化落到哪、变成哪一面、改成什么姿势、手持交给谁，禁止只写「走两步／转过身」却读不出结果。本拍【建置】加上本拍【入戏】的变化，等于下一拍的初始【建置】。下一拍按自己的机位角度把这个结果重投成画布全文；无变化则世界点不变，只重投。切角只改画布词，不把上拍入戏的终态提前写进上拍建置。

**每拍【建置】（最高）**：本拍进画的每一 CHAR／可见独立 PROP 各一条整句（含无动作），写的是开拍初始态。位置只写本拍画布坐标全文，禁止写入东／南／西／北、东面／西面／南侧／北侧、东侧沿、`北=`／`东=`。首句 `上机位=`／`机位侧=`／`机位=` 同样先旋掉罗盘字。参考主体的落位写成普通中文，说法见「建置用标准自然语言」。远近只按本拍 `望=` 旋转上游世界侧，可见面只按面半空间和 `望=` 的夹角，并且必须和上游 `机位侧=` 一致。正前写正面，正后写背影，左侧或右侧写侧面。对不上就回流现场编排，本层不把人挪近或挪远。禁止 `位于`、`侧沿`、`同深`、`离开{锚}贴身`。贴身说成「大约一掌，中间有缝、不挨着」。原点／开放：`画左|画右|对齐`＋`前景|中景|远景`。封闭：排座与`相对驾驶位=`照抄，再加该席的画左画右与离镜头。另写朝向对象、姿态、手持。这些画布词每拍按本拍角度重投并全文写出。细则见「距种先分再量」。所对主体本角可见时，人话写「面朝着」该主体，不写键 `面向=`；所对主体不可见时，建置不写面朝着谁，也不写面对镜头。场记 `面向=` 写 `面向镜头`。哪一面朝着镜头仍按 `机位侧=`。参照本角不可见时按「进画测算」：不用它描述；人须留在画面则这一拍用临时锚，`锚=` 不换；人也不在画面则只登记台账。不解释环境，不重做四宫（硬约束 11–12）。

**锚只继承（最高）**：【建置】【入戏】里每个人／件的锚，逐字等于该拍现场编排已经选定的 `锚=`。`落在=` 与 `触点=` 的宿主名同此，逐字等于该行已经写上的那一具。本层只把这一具上的世界侧，按本拍角度译成画左／画右／离镜头。该锚本角可见时，禁止另选，禁止为构图改挂。该锚是环境主体且本角不可见时，按「进画测算」：人也不在画面则只登记台账；人仍须留在画面则这一拍描述用临时锚，`锚=` 仍是原具。分布图写明的走动换锚仍照分布图。上游 `落在=无` 则不得新造一个落在对象。上游 `方式=相对` 只有锚名、没有世界侧也没有 `触点=` 部位 → 回流现场编排，本层不代选边或点。建置位置句必须把已锁的那一边或那一点译出来，禁止收成只剩锚名。

成稿只出节拍流。`开拍在场=`=世界在场（B1=上游 `入场=开场` 全员，待入画除外），**≠**本拍进画名单。全员全景建置句落在上游 `剧情匹配=建置` 的那一拍。禁另起位置规划／覆盖矩阵／场级场记。

0. **读该拍上游**：该拍原文 ＋【角色道具世界分布图】（旧稿【角色道具宫格分布图】仍可读）＋注入四宫格里与本拍 N 相同的那一格。核 `望=`／`景别=`／`当前环境=`／`[DERIVED_ENV:]` 同核，`景别=`≡`机位距=`。无独立【取景锁定】。人行=世界锁；机位行=本拍观察锁；画面侧以该格环境描述为准。`当前环境=`／`[DERIVED_ENV:]` **逐字抄该拍机位行**，禁用场头第一【主环境】或上拍占用名改挂（`霓虹摩天楼` ≠ `飞行器驾驶舱`）。缺对应格 → 停写。
1. **抄机站**：场记复述分布图 `机位=`（`场内|{锚}{侧}` 或 `场外:`）＋`望=`＋`景别=`＋`针对=`＋`可见=`＋`覆盖=`。禁另摆机。`当前环境=` 已由上游望向推出，本层不另选角、不重写主名段。**一眼整机主拍**（`主拍对象=PROP:[飞行器]`／`PROP:[飞行器残骸]`／EWS 航拍整机／机位锚=云雾空域或楼群／名牌主段=霓虹摩天楼）**却** `当前环境` 主名=驾驶舱 → **回流现场编排**，禁照抄舱 ENV、禁自行改回舱名。
2. **世界→画面（三投影；先可见性，再站位，再朝向）**：自算 `换算=`／`背景衍生=`（跟本拍 ENV 画幅锚）／**分镜可见**／**位置投影**／**可见面推**。世界锚侧、`身朝=`／`眼神=` 对象不改，仍留速查；本层只把落位与镜头关系转成画布（画左画右／前景、中景、远景／近远／正面可见…）。所对主体本角不可见时，建置不写面对镜头，也不写那个名字。场记 `面向=`／`目光=` 写 `面向镜头`。**依附类**（桌上碗盏、台上座、围桌人／件）每人、每件写成在宿主的画面左或右、或比宿主更靠近或更远离，并写离开多远。禁止用横行并排或纵向同列顶替第二人。不落地另写落在哪张台面、离台面多高。**换衍生 ENV 只换观察轴（最高）**：开篇主光心点+高度不改。角色受光半与影子跟本拍 N 宫格已旋 `源体画布位=`（含 `高度带=`）同核，禁止本层另起主光或把邻角金盘抄进本拍。
3. **分镜可见**：只按「分镜可见裁定」——世界侧相对分布图 `望=` ＋景别档；覆盖 `可见=` 已列者禁无故裁。朝向／背面不进本步。已入场全员出结论。
4. **写【建置】**：首句拍摄键＋本拍 `当前环境=`。进画（`V|部分可见`）全员各一条完整句（含 PROP、含无动作），写开拍初始态，XOR 分闸成稿。本拍动作之后的落点不进本段。镜后／景别不及只台账。不因主拍镜后改机或回流。
5. **写【入戏】**：只写相对本拍建置的动作变化；可转视线。不必把建置开拍落位整段再抄一遍。走位／转身／出入画／变姿用动作写出新可见面、新落点和新姿势（世界终点仍认上游路径）。这些结果的完整初始建置写在下一拍。不补建置漏写的人／件。
6. **写【场记分析】**：在场核销＋转换台账＋速查（未出画全员，含镜后）。下拍开拍在场≡本拍收拍。

## 硬闸（决策链之上）

0. **单拍自足 + 严格沿上游连续（最高）**：每拍独立出图。在场名单与开拍世界位只认该拍【角色道具世界分布图】。建置位置句必须把该行落点按本拍角度译成画布坐标全文写出，禁止把东／南／西／北写进句子，也禁止收成「承上」「同上」「见上拍」。`在场=仍在` 或 `站位变=否` → 人仍在同一世界点，本拍只重投画布坐标；排座、朝向对象、手持宿主与分布图同核。`站位变=是` 时建置仍先写开拍画布坐标全文；入戏用动作写出走到新落点，不必把开拍建置整段再抄一遍，路径必须已在分布图。新落点的完整初始建置写在下一拍。分布图没有的角色或道具禁止补进建置。分布图有且本层评进画的，禁止漏写。同一人、同一件无路径却换锚、换手或消失：本层在【入戏】补上从上一落点走到本拍落点的移动或离手动作，建置仍写上拍终态，下一拍建置才是新落点。故意双生不按断续补。补完仍对不上剧情的，再回流现场编排。
1. **连续性**：【建置】=该 Beat 开始的初始建置，等于动作前，等于该拍分布图开拍态。本拍【建置】加上本拍【入戏】的变化，等于下一拍的初始建置。`镜头推进`／切角／收景别 ≠ 换站、≠ 换件。人际轴只读该拍世界轴＋本拍投影。挂靠／法相／走位见 §2。漏评或无离开却分锚 → 回流。
2. **走位核对**：净空、不穿障、步幅、门径向、触达一臂、终点仍在白名单、不越轴。有障须写绕过哪件哪侧。无走位=`走位=无`。细则 §2。
2A. **出入画／开场**：档只认上游 `入场=`／`入画@`／`经=`。进画本层按 `◎`＋景别评。待入画入画前禁进建置。本拍才入画的人，本拍【建置】先不写，也不写经口 `露=`。入戏写明从哪个口入画，以及停在哪个参照位置（锚的哪一边或哪个点，并写清体外还是体内）。下一拍建置才把这个停留位置写成完整开拍句。切角 ≠ 出入画。进出须过程＋视线三拍（抄文戏）。B1 `开拍在场=` ≡ 上游 `入场=开场` 全员（世界在场）。全员全景整句落在上游建置拍（默认同 B1；先吸睛则紧邻下一拍——吸睛拍按景别评可见，禁把特写非主拍／镜后升全身）。禁从收拍剔除镜后者。本层不另起拍。
2B. **建置覆盖**：本拍 `V|部分可见` 的 CHAR + 该 ENV 内本体可见独立 PROP → 各一条整句。空镜=拍摄键+`空镜／无角色／无道具`；整车无人可点名整车、禁 CHAR；内部ENV 禁改空镜。组／槽位／`触=`／`同簇相对=`／`落在=`／`离平地=`／`在桌=`／`台面心点=` 抄上游；`露=` 本层按景别评。依附类整句须含三层（同宿主关系从坐标比出，不抄 `同排=`）。`待入画`／已离场／`D` 不写本体。粒度=本拍 `当前环境=`。
3. **拍摄键入建置首句**：从该拍分布图写入 `当前环境`／景别／构图／`机高=`／`镜头角度=`／`机运=`／关系角／`OTS类型`／近侧框主／主拍对象／`机位锚=`（环境主体）／相对该锚的侧／`机位距=`／变因／`AI位`，并写 `景深=浅|中|深`（由景别推出，见按角度建置）。`上机位=`／`机位侧=`／`机位=` 里的东／南／西／北先按本拍 `望=` 旋成画面左边、画面右边、靠近镜头的这一边或远离镜头的那一边，再写入。`机位距=贴身` 必须括注「镜头离开{机位锚}的{已译边或点}大约一掌，中间有缝、不挨着」。每拍重写。首句不得留下东、南、西、北。无剧情改机则与上拍机位、机高、俯仰相同，角色相对参考图的边或点仍照分布图，边或点同样先旋再写。禁另起【取景锁定】。不另选机位。缺 `机高=` 或只写俯仰不写高低 → 回流现场编排。
4. **三段式**：【建置】→【入戏】→拍内【场记分析】…【场记分析结束】。
5. **场记**：并入 `朝向推=`／`表情换环境评=`／`背对=`。速查未出画全员。本段不进分镜。
6. **入戏只写变化**：用动作写出相对本拍建置的变化，不必把建置整段再抄一遍。有走位／转身／出入画／变姿时，动作里写出新可见面、新落点和新姿势，供下一拍建成初始建置。转视线写进动作。依附类换层（坐下、端起、放回）写在动作里；完整三层落位由下一拍建置写出。上游动作／对白／声画必须写入。名牌不算动作。
7. **只出节拍流**：`[BEAT_STREAM_START]`…`[BEAT_STREAM_END]`；末行 `[STAGING_ENV_OUTPUT_END]`。

8. **自然语言整句（最高；建置落位用人话）**：【建置】首句保留拍摄键。下一行起，每个进画角色和道具各写一段普通中文，说法见「建置用标准自然语言」。句子里要能读出：在整个主体外面、在面上、还是在底下，再读出在参照物的哪一边或哪一个点、离开多远、另一轴是一样远还是对齐、怎么站或怎么放、面朝着谁（所对的人不可见则不写这句，也不写面对镜头）、眼睛看着谁（落点不可见则不写这句，也不写看向镜头）、哪一面朝着镜头、两手和佩戴、已锁表情。只写「离床右侧」分不清体外和体内 = 失败。用「面朝着」「眼睛看着」「两手空着」「右手拿着」，禁止写成 `面向=`、`目光=`、`手持=`、`佩戴=`。位置只写画布坐标，禁止东／南／西／北。参考主体写画面左边或右边，以及更靠近镜头、更远离镜头或离镜头一样远。原点／开放写画面左边或右边，加上前景、中景或远景。封闭保留第几排第几个，再写这一席在画面左边还是右边、比驾驶位更靠近还是更远离镜头。画左／画右／离镜头／前景／中景／远景只用于落位，禁止当作所看的对象。首句写 `景深=`。【入戏】有走位、转身、出入画、变姿、转视线时，用动作写出新的可见面、新落点和新姿势，不必把开拍建置整段再说一遍。无变化不把初态再说一遍。建置人话里读不出开拍站哪、两手。所对者可见却读不出看谁，或仍写 `位于`／`侧沿`／`同深`／`手持=`，或背面写五官，或 `部分可见` 升成全身，或依附类台上件没写离台面多高 = 失败。入戏有变化却只写「走两步／转过身」，读不出落到哪、变成哪一面、什么姿势 = 失败。不因缺「脸可读」失败。画内仅一人不强制凑第二人。成稿禁写相对180°。所对的人仍可见时，禁止写成「面向某人（即面向镜头）」。所对的人不可见时，建置不写面朝着谁，也不写面对镜头。场记 `面向=` 写 `面向镜头`。禁止「面朝着不可见的人」。禁因神色把背面改成正面。
9. **画幅锚替换（强制；切角左右会变）**：先读本拍 ENV【衍生环境画幅锚】`背景=`/`画左=`/`画右=`/`画外=`。建置**仍按参考主体／原点／封闭**成稿（§4）。参考主体与封闭用人话写出在锚的哪一边、离开多远，另一轴对齐或一样远。禁止 `位于`、`离镜头=`、`离开{锚}贴身`。原点／开放写成画面左或画面右，加上前景、中景或远景。这是人与道具的落位，不是把环境再描写一遍。参考主体句必须还在锚的具名和已旋的那一边或触点，禁止只剩「位于画左」，也禁止在锚名后接东面、西面或东侧沿。封闭句必须还在排座与 `相对驾驶位=`。原点句不点名东南西北，也不写离镜头。环境键 `画左=`/`画右=` 只当具名锚点名，不扩写成「画面左侧是墙」或「远景是某墙」。✅`坐在八仙桌靠近窗户的那一边，离开这一边大约一条手臂，和这张桌子离镜头一样远`｜✅原点 `在画面右，远景`｜❌`离开桌子一臂，离镜头同深一臂`｜❌只写「位于画左」｜❌原点写成离镜头｜❌切角后把锚改成另一件。**`画外=`=镜头后对向主体，明确不可见**——【建置】【入戏】禁止把画外件写成环境导游，也禁止拿不可见的那一具来描述站位。人须留在画面时按「进画测算」用临时锚描述，不换锚。人也不在画面则只登记台账。切角/反打须改查**新 ENV 行**并重投（0°画左≠180°画左；0°远景≠180°远景；0°画外≠180°画外）。构图 `三分` 可留。场记分析内部可写画左↔画右对调。缺可见三键不构成换锚理由。
10. **参照不可见（强制；不换锚）**：定位行 `锚=` 等于本拍 `画外=`，或该锚本角不可见 → 建置禁止用这具描述位置。`锚=` 不改。人按世界位＋机位也不在画面 → `暂不可见｜因=挂靠不可见`，只登记台账，不进【建置】【入戏】。人仍须留在画面（过肩近侧框主、主拍、景别盖到且人在镜前）→ 这一拍的描述用临时锚：另一件本角可见的环境主体，或正面可见的主拍主体。临时锚不写回 `锚=`，不进入下一拍。原锚重新可见，描述回到原锚。离挂靠较远或体量伸出仍可见时，可以仍写原锚，并写明原因。✅人在镜后、柜台也在画外：速查 `暂不可见｜因=挂靠不可见`，建置不写此人，`锚=` 仍是柜台｜✅过肩、人须留在画面、柜台在画外：这一拍写成相对正面可见的主拍主体，台账 `锚=` 仍是红木柜台｜❌把临时锚写回 `锚=`｜❌继续写成站在画外红木柜台的画面左边。参照可见时，成稿参照名与 `锚=` 相同。
11. **建置不解释环境（最高）**：【建置】【入戏】**不解释**环境背景与内容——禁「远景是…」「画面左侧/右侧是…」、材质/陈设墙导游、四向复述、把 `背景=`/`画左=`/`画右=` 扩写成环境描写。环境已由该拍 `当前环境=ENV:[…]` 对应参考图承担，成稿只点名 ENV。对照宫格只用来对齐角色和道具落在该格已经写好的哪一侧，格内 `正面：`／`左侧面：` 句子本身不进成稿。现场编排已选的锚**只作**角色/可移动道具的**定位锚**与**朝向对象**，人话点名即可：不写该件外观、不写其自身画面位、不把该件写成待生成环境内容，也不换成可见三键里的另一件。空镜拍=`空镜／无角色／无道具`+`当前环境=`，禁补环境导游，禁 CHAR/PROP 落位。载具只执行上游 `载具档=`，本层不改选；档与挂族冲突 → 回流。【入戏】只在交互/微动时点名该件（推门、坐椅、`ENV背景微动=`），仍不解释环境。❌`远景是木质柜台和酒坛陈设墙，画面左侧是楼梯`｜❌建置另起「环境：大厅金碧辉煌」｜✅所对的人可见：`CHAR:[@林] 站在八仙桌靠近镜头的这一边，和这张桌子离镜头一样远。他面朝着 CHAR:[@对座]，正面朝着镜头，眼睛看着 CHAR:[@对座]，两手空着，身上没有佩戴`。所对的人不可见时不写面朝着谁，也不写面对镜头，不出现那个人的名字。场记 `面向=` 写 `面向镜头`。
12. **建置粒度=当前环境（最高）**：一份【建置】只服务本拍一个 `当前环境=`。只写本拍该 ENV 内本层评 `V|部分可见` 者。换 ENV = 下一拍另写【建置】。他 ENV 的人**不进**本拍建置。❌同段并列两套环境里的人。❌先写甲环境远观主体、再写乙环境占用面上的人。
13. **PROP 不替代 ENV（最高）**：`PROP:` 是当前 ENV 里的物件，不是环境本身。本拍出现独立 PROP → **必须**已有 `当前环境=ENV:[…]`（与该 PROP 分名）。`载具档=内部ENV`：落位写封闭槽（主驾驶座/第N排），**禁**`位于 PROP:[飞行器] 的主驾驶座`／`坐在 PROP:[…] 上` 把整车当房间。`载具档=道具沿用宿主|整车无人`：可写 `位于 PROP:[整车]`，当前环境必须是宿主大世界，**禁**驾驶舱 ENV 挂整车 PROP。缺 ENV 只写 PROP = 失败。
14. **整机与舱内角色禁同拍（最高；两套环境）**：一份【建置】只服务一套环境。舱内角色拍：`当前环境=ENV:[{N}度飞行器驾驶舱]`，写封闭驾驶座，**禁** `PROP:[飞行器] 作为舱体容器`／部分可见舱壁，禁挂 `霓虹摩天楼`。整机拍：`当前环境=ENV:[{N}度霓虹摩天楼]`，写整机 PROP，**禁**驾驶座 MCU／控制台机位锚，**禁** `ENV:[180度飞行器驾驶舱]`。环境名牌主段 ≡ 当前环境主名段。一眼整机（EWS/航拍/`主拍对象=PROP:[飞行器]`/机位锚=空域）+ 舱 ENV 或名牌【霓虹摩天楼】+ 舱 ENV → **回流现场编排**，本层不改选、不照抄。❌`ENV:[180度飞行器驾驶舱]` + `主拍对象=PROP:[飞行器]` + EWS 航拍 + 名牌【霓虹摩天楼】｜❌`ENV:[180度霓虹摩天楼]` + 驾驶座 MCU + `PROP:[飞行器] 作为舱体容器` + 名牌【飞行器驾驶舱】｜✅舱拍 `ENV:[180度飞行器驾驶舱]` + CHAR 驾驶座，无整机 PROP｜✅整机拍 `ENV:[180度霓虹摩天楼]` + `PROP:[飞行器]`，无舱内排座。

## 1. 建置 / 入戏 / 拍内场记分析
- **【建置】**：首句拍摄键（含 `当前环境=`）。名单=2B。整句配方=§4＋硬约束 8。切角 ≠ 改姿势；本拍入戏才变则建置仍写旧档。组／同簇世界锁抄该拍宫格，画幅／近远按本拍 `◎`＋N 投影。运动后落点不进。硬约束 9–11。**门槛**：入戏含推门／入画且文戏未写人已在厅内 → 入画者本拍建置不写；入戏写从哪个口入画、停在哪个参照位置。已在场的人建置仍写开拍。文戏已是厅内开口 → 跟文戏，此人已在建置里。禁 `选择证据`／扇区／`所在侧=`。禁写名牌。
- **手持/佩戴开拍必写（最高；仅已可见件）**：画内每人必须在建置整句写清本拍开拍 `手持=` 与 `佩戴=`（无则写`无`）。已提取独立件用 `PROP:[名]` + 部位/体侧/握持态。开拍已在身/在手 → **禁等入戏「用时」才第一次点名**（后拍抚摸/发亮仍须开拍已写）。桌上/架上**本体可见** → 宿主写 `手持=无`，该 `PROP:` 另作可移动件建置。盒/匣/袋内**本体未露出** → 宿主 `手持=无`/`佩戴=无`，该件不进本拍建置（待入画）；【入戏】写开盒取出；取出后下拍才改宿主 `手持=`/`佩戴=`。纯造型无戏耳钉/胸针不写。群演簇写簇持械（有则）。`背朝镜头` 禁写胸前件正面。
- **开拍表情**：不核脸可读。投影为正面／¾／侧面 → 按该面写上游已有表情词（侧面写该侧；禁改成正面）。投影为 `背朝镜头` 或 `露=` 不含脸 → 不写五官。`表情换环境评=` 原样并入场记，不据本评改挂。入戏只写相对建置的表情变化。
- **同锚挤身／接触未结束**：评 `露=` 与接触带见上文「同锚挤身」；未松开须每拍建置复述见 §2「接触关系守恒」。

  - **字体字色**：跟 `Global_Style` 时代/基调补一书体+具名色（古装偏楷隶魏碑+鎏金/朱红；当代偏黑/宋+象牙白；近未来偏无衬线+冷白/电青）。本场角色标签已有非`无`字体字色 → **同集成套**。禁套对白字幕白字黑边。

## 2. 连续性与走位
每拍先逐人逐件核对上游该拍分布图的 `在场=` 与 `站位变=`，再写建置 / 入戏 / 终态。在场名单不得偏离分布图。角色与道具的位置句只写画布坐标，不写东／南／西／北。画面词（画左画右、离镜头，或原点档的前景／中景／远景）只随本拍机位重投。

**在场与落点只抄分布图（最高）**
- 分布图 `在场=开场|仍在|入画落定` 且本层评进画 → 建置必须有该 CHAR 或 PROP，并把该行落点译成本拍画布坐标全文写入建置句。禁止只写「承上」，禁止在位置句里写东／南／西／北。`在场=本拍离场` → 建置仍写离开前的画布坐标全文，离开过程只写入戏，下拍不再出现。
- `站位变=否` → 人仍在同一世界点，建置只重投本拍画布坐标。禁止借切角、景别、景深把人挪到另一锚，或把道具换到另一头、另一只手。
- `站位变=是` → 建置仍写开拍位。入戏用动作写出走到终点，不必把开拍建置整段再抄一遍，且必须能对上分布图的路径。下一拍建置才把终点写成完整初始建置。
- 分布图未列的人／件，建置、入戏、终态都不得凭空加入。

**故意双生不补（最高）**
剧情已经写明同一人同时有第二具身体：灵魂出窍、元神离体、分身、残影，以及特效技术造出的另一具。第二具与本体分名分写，可以同时在不同位置、做不同动作。这种差不补走位，也不补成同一人的过渡。没有这个机制、只是同一人上下拍对不上，仍要补。切角、换景别不构成位置变化，不因此补走位。

**动作连续（主动补，不只核销）**
- 同一人、同一件：上拍终态的动作还没落到可承接的停点，本拍却已是下一步或另一动作 → 在本拍【入戏】该动作之前补上缺失的过渡（收势、换手、起身、放下、接上未完成的链、受者响应）。只增不删，不改对白。建置仍是动作前。
- 上拍未完成的动作链本拍【入戏】承接；本拍入戏未写完的链须留给下拍续。故意双生的两具各自接自己的链。
- 姿态 / 持物 / 朝向对象连续；变则须有本拍可拍过程（只写入戏）。**姿势闭集**（与【本场姿势】同核）=`站|立|坐|翘脚坐|盘腿坐|平躺|俯卧|向左侧躺|向右侧躺|蹲|跪|半跪|倚|骑|腾空`（`立`=`站`）。建置整句必须明示该词，禁只写`位于…`。抄上拍速查 `姿态=`；无则抄文戏 / 【本场姿势】。切角 ≠ 改姿势。入戏有过渡链才改终态姿态，建置仍写旧档。
- **朝向时序**：本拍建置 `面向=` + 镜头可见面 = 上拍终态（上拍转身 → 新朝向从**本拍建置**落地）。本拍入戏再转身 → 建置仍写动作前；新朝向进终态，**下拍建置**才改写。同 ENV 无转身不改对象。ENV 变且无转身 → 世界对象不改，可见面按本拍 N 重投影。❌把本拍转后朝向写入本拍建置。❌无转身却因换主拍／收景别改世界 `面向=`。
- **随身件与独立道具守恒（最高）**：开拍写法见 §1，名单与落点以该拍分布图为准。无离身链、无取出、无放下 → 手持、佩戴、桌上件、架上件的宿主与世界落点抄分布图；切角只重投画左画右和离镜头，原点档只重投前景／中景／远景。宿主不在建置名单 → 只进速查。离身、取出、放下只写入戏，且分布图须已写路径；新挂载进终态。发声屏写现位 + 屏面朝向。禁切角后茶杯换到桌的另一头，禁无过程让道具蒸发或跳到另一人手里，禁分布图没有的件突然在建置出现。
- **接触关系守恒（最高；未结束则每拍建置复述）**：上拍终态 / 上游 `触≠无`（牵手/拥抱/押送/按肩/搂腰/接吻）且本拍入戏尚未松开 → 本拍【建置】**必须再次写明**该关系（谁的哪只手/哪臂接触谁的哪部位），即使本拍入戏不再写「牵着/抱着」。禁只靠速查暗示、禁下一拍两人各自独立站位。本拍入戏才松开 → 建置仍写动作前接触态，松开只写入戏，**下拍建置**才去掉。双方都 `V|部分可见` → 双方建置句都写（或一方写完整接触、另一方写被牵/被抱/被按）。一方本拍 `暂不可见` → 可见方仍写接触，但不写对方名字（右手仍被画外的一只手牵住）。对方 `触=` 留速查。双方都可见才点名。抄上游 `触=` 的式/己/对左右，禁改手、禁与画幅左右对调。
  - ✅上拍已牵手，本拍对白 MCU 建置仍写 `CHAR:[@甲] …右手牵 CHAR:[@乙] 左手`
  - ✅上拍拥抱未结束，切正面仍写 `CHAR:[@甲] 双臂环住 CHAR:[@乙] 左肩`
  - ❌上拍牵手，本拍只写两人分立「位于…站」无牵手
  - ❌建置写成已松开，入戏才写放开
- **入戏跨拍衔接**：入戏不得从与本拍建置矛盾的状态起笔（人已换位、手已换物、半句对白无据另起）；亦不得写到下拍无法承接的终态（半步悬空、物蒸发、动作无落点）。下拍从本拍速查继承站位，并**重评**上拍暂不可见者是否因视角／景别回画；回画则下拍【建置】**整句复述**（≡本拍终态世界键，不是重排）；仍暂不可见则只进下拍台账；下拍【入戏】再写新变化。

**位置连续（主动补，不只核销）**
- 同一人、同一件：上拍终态世界位与本拍开拍对不上，且没有走位、离身、取出 → 建置仍写上拍终态译出的画布坐标；【入戏】在该拍动作之前补从上一落点走到本拍落点的移动，不必把开拍建置整段再抄一遍。下一拍建置才把新落点写成完整初始建置。只增不删，不改对白。道具无离手过程却换宿主或消失，同样在入戏补取出、放下或交接。故意双生的第二具不按这条把本体拉过去。
- 真源=已锁方式（§4）+ 速查 `所在侧`。禁 `扇区+F`。
- 开拍站位 ≡ 该拍分布图译出的画布坐标，必须整句写出，不得收成「承上」，位置句不写东／南／西／北。同 ENV：整句复述开拍画布落位（画幅锚换本拍可见三键，禁换入 `画外=`）；所对主体可见则建置人话点该主体名，所对主体不可见则建置不写面对镜头，也不写那个名字。场记 `面向=` 可见时抄对象名，不可见时写 `面向镜头`。ENV 变：写【上一ENV→触发→本ENV】后把同一世界点重投成新角度的画布坐标（人未走则不换锚，体侧／近远／画幅必改）。禁「同上」「承上」、禁切角瞬移。`暂不可见` 只进速查。
- **换锚核销**：建置 `位于{锚}` 与上拍终态不同 → 分布图须已写该角色移动离开上一具挂靠物的路径；否则回抄上拍世界锚或回流。切角／收景别／`镜头推进`／挂靠落到画外／读脸 ≠ 换锚。`走位=无` 却换锚 = 失败。世界 `面向=` 对象变仍只认转身路径。建置删掉不可见对象的朝向句、场记写成 `面向镜头`，不算朝向对象变。
- **切角≠拧朝向**：无走位无转身 → 世界朝向对象不改。所对主体本角可见则建置仍写该对象，投影是背就写背。所对主体不可见则建置不写面对镜头，场记 `面向=` 写 `面向镜头`，镜头关系写 `正面可见`。禁同角把仍可见的主体拧成正面，禁本层改挂。
- **明示站位**：抄上游锚／宫格。本层不重判「该不该挂这件」。
- 反打 = 同主名对向已锁 ENV。换主名触发不标反打。来源 = 紧邻上拍终态，禁回取更早建置。

**关系连续**
- 仅本拍画内者互写前/后/左/右 + 尺度距离 + 面向。**轴跟分布图世界位**：普通人同南北带只写左／右，同东西带才写前／后；无走位禁把上拍左右改成本拍前后。法相／坐骑／载具抄上游：未离开则同锚同朝向；锚内身后按上游身后投影（机在背侧：挂靠体近镜头、宿主其身前；机在面侧：挂靠体可更远）；离开则件留原地、人在新锚。禁无离开改成左右分锚，禁机在背侧写成宿主前景＋挂靠体后景／远镜头侧，禁人已走开却把车／马跟人写走。同锚或同绝对侧须抄上游世界 `同簇相对=0度锁｜在其{左|右|前|后}`，**本层**按同簇投影表投影本拍三维（偏画左/居中/偏画右、上/平/下、近镜头侧/同层/远镜头侧）。世界同南北带左右 → 建置禁拆成前景／远景。ENV 变用本层投影，**禁**把上拍画面「甲偏画左」原样写进 180°/90° 建置。与画外者的关系只进速查，不写建置。走位后关系必须可从开拍关系 ⊕ 本拍路径推出，并更新投影。
- **身体接触未结束 ≠ 普通左右关系**：牵手/拥抱/押送等须按「接触关系守恒」在**每一拍建置复述**，不得只写「在其左侧」代替仍牵着/仍抱着。同 ENV 整句复述**不豁免**接触句。
- 正反打场：走位不得无过程把相向拆成同向，或把同向拧成相向。关系变须写在 `变化过程`。松开/改握只写入戏。

**轴位连续（不越轴）**
- 轴线 = 本场已锁 `spatial_axis`。站位、走位路径、停驻点、左右屏必须落在轴线同一侧（左右屏=构图/轴线用语；**相对落位写「锚的哪一头/哪一面/近镜头侧」，禁止写该人画左/画右**）。
- 已锁 `axis_crossing=None`：禁跨轴；左右屏相对上拍保持同侧。
- 已锁 `PlannedReverse`：沿轴线对向，左右屏对调合法，仍算守轴，**不是**越轴。
- 已锁 `MotivatedCross`：允许跨轴，走位终点落到轴线另一侧，写 `越轴=是｜动机=` 该拍已锁动机。
- 失败：未锁越轴却因走位跨到轴线对面；无反打依据拧反左右屏；把越轴写成普通反打；改挂方案外角来圆越轴。回改走位。
  - ❌`守轴核销=通过`（无人名） / 未锁越轴却写`跨轴`

**走位核对**（相对已锁取景；不通过则回改落点或拆已锁空间硬锁拍，禁改挂方案外角）
1. 开拍落点 = 上拍终态，无瞬移。
2. 路径物理可拍：净空、步幅够、门径向闭合。**障物评估（有走位必写）**：直线开拍→终点扫本拍白名单与建置已写实体。无挡=`障=无`。有挡=`障={具名}`，路径须补 `绕={具名}之{左|右|近端|远端}`（对照该拍宫格；入戏可写成画左／近镜头）；直线穿桌/柱/人/门扇=失败。绕障节点须仍在已锁活动空间且不越轴。
3. 终点仍在已锁活动空间；本拍必见项仍 ⊆ 已锁白名单。
4. 走位后距离档与已锁景别同向（贴身 ↔ MCU/CU；数步对峙 ↔ WS/FS）。
5. 触达对象开拍已在画且一臂可达；否则先切已锁可见该物的角。
6. 停驻后仍留后续动作净空（贴墙无退路、叠脚无步幅 = 失败）。
7. 路径与终点不越轴（上条）；`守轴核销=` 必填。

**走位细化**（写入 `变化过程` + `终态画面纵深`；【入戏】用自然语言同步写出）
- 有走位：`变化过程=`=`{名}:自{开拍}→经{路径/绕障/门/步数或臂距}→到{终态}｜障=无|{具名}｜绕=无|{具名}之{左|右|近端|远端}｜锚=…｜侧=…｜辅=…｜细节=… 距=…`。相对自/到禁画左/画右/前景。禁写 `宫格=`。【入戏】用动作写出路径（有障须写出绕过）和停下来时的可见面与姿势，不必把开拍建置整段再抄一遍。**走位换锚（最高）**：本拍建置世界位=开拍（抄上游本拍定位）；终点写入本拍终态+速查世界位；下拍建置必须把该终点写成完整初始建置。换锚则本拍终态世界位 ≠ 开拍。入画落定=入位写入终态；出画=速查剔除。同锚内挪步可不改世界键，须改则先改 0° 相对再按本拍 N 投影。
- 停驻须落点可辨，不得与他人 / 锚混淆。
- 无走位：`走位=无`，本拍场记分析复述**画内**终态关系，不可见者只在速查留站位且**仍计入收拍在场**；**入戏不复述**。速查世界位抄上游本拍开拍锚侧。
- 多门路径见 §6。

## 3. 成稿范围
成稿**只出** `[BEAT_STREAM_START]`…`[BEAT_STREAM_END]`。禁回写场号、【场景名称】、环境块、【角色道具世界分布图】／【角色道具宫格分布图】、【主体定位方案】【Beat主体定位】、提取块、【实体覆盖】、位置规划 / 角色位置 / 动作空间 / 露脸 / 场级【场记分析】。

**开场**：`开拍在场=` 见 2A（世界在场 ≠ 进画）。全员全景整句落在上游建置拍。待入画不计入 B1 开拍人数，入画落定后计入该拍 `收拍在场`。

**【场记分析】** 每拍成对块，写在该拍【入戏】后、`[BEAT_END]` 前。须写满 §7 在场核销 + 0–8。输入若仍有场级 `B{n}=` 拆入对应拍后删除。

排位：地位 → 剧情 → 重要者 C 位。走位总账与初/变/终写入该拍场记 `变化过程` / `终态` / `速查`，不另起位置块。

## 4. 定位成稿（执行已锁起始帧；不补锁）
只抄**该拍** `B{n}` 中本层已评 `V|部分可见` 各行的世界方式键，不改 XOR（**无动作的 V 者同样整句复述**）。角色组抄该行 `序=`/`朝向=`/`距=`。同簇抄上游世界 `同簇相对`，画幅／纵深按本拍 N＋`◎` 投影写入建置整句；禁回抄 B1。`D`/`待入画` 不写建置。镜后／`暂不可见` 不写建置、必进速查。禁为凑人数补未入该拍宫格的人。入戏不写 XOR 键。缺项或度数/`F≈`=失败。每条须能读出该人／件在本拍 `当前环境=` 内的落位。
- **相对（约束）**：锚具名逐字抄该行现场编排已选 `锚=`，禁止另选，画外也不换。成稿须：①主语=该人；②人话能读出在该锚的哪一边或哪个点；③**固着侧功能名不改口，方位侧与地理侧必投影**：`近窗/近门/主位/客侧` 原样，同时仍写本拍的画面左或靠近镜头。上游若写左长边或右长边，按本拍角度改写成「在桌子的画面左」或「在桌子靠近镜头的一侧」。建置句禁止再写左长边、右长边。`西面/东面/偏=南` 同样改写成画面左、画面右、更靠近或更远离。固着侧不因画外改成另一件。相对句**禁止**把该人写成 `前景|中景|远景|画中|中央`。距离写成「离开这一边大约一条手臂」或「离开这一边大约一掌，中间有缝、不挨着」，必须带上已旋参照边或点，不写 `距锚=`，禁止裸写贴身，禁止「离开它一臂」。禁残留 `西面`／`东面`／`东侧沿`／`左边`。
  - 句式见「建置用标准自然语言」。例：`CHAR:[@名] 站在{锚}的画面右边，离{锚}的右边大约一掌，中间有缝、不挨着，和{锚}离镜头一样远。他面朝着{主体}，左侧朝着镜头。` 这一句的「一样远」和「左侧」必须是世界侧按本拍望向旋出来的，并且 `机位侧=左侧`。正后才写背对着镜头，正前才写正面朝着镜头。禁止为了背影把一样远改成更靠近。第二轴另有分量时才另说那一边，不把同一个距离再说一遍。贴身说成「大约一掌，中间有缝、不挨着」。一臂说成「大约一条手臂那么远」。禁止 `位于`、`侧沿`、`同深`、`面向=`、`目光=`、`手持=`、`佩戴=`、`贴身`。姿势闭集见 §2。失败项见硬约束 8。所对主体可见则人话里点该主体名；所对主体不可见则建置不写面朝着谁，也不写面对镜头。场记写 `面向镜头`。禁把仍可见的主体改成面朝镜头，禁眼睛看着画面左边。**画布两点（最高）**：句子里必须同时有参照边旋出的那一边，以及另一边的对齐或一样远。只说「在旁边」、不说哪一边或哪一个点 = 失败。远近只认本拍机位。坐、倚、踏须写出碰到锚的哪一处。**依附类**：每人、每件自己一段人话，说出离开宿主的哪一边或哪一个点、离开多远；另一轴一样远或对齐，除非另有分量。不落地要说「放在{宿主}台面上，和台面一样高」。禁止「沿画面左右横行并排」。

## 5. 朝向与镜头可见面
档位（成稿镜头关系；画内每人必写）：角色 = `正面可见`｜`正面¾可见`｜`左侧面可见`｜`右侧面可见`｜`背朝镜头`。载具 = `车头/车尾/左/右侧身朝镜头`｜`¾车头/¾车尾`（飞行器=`机头朝镜`｜`机尾朝镜`｜`侧身朝镜`，语义同车头族）。动物 = 身躯镜头关系 + `头朝{对象|左|右}`。
镜头关系按本层已算 `可见面推`＋本拍 N 投影（上游宫格／人行不供 `可见面推=`／`体侧=`）。场记可按对向换算；**成稿不明示** `180°` / `相对180度` / `面向N°` / `侧面90度`。
**人↔载具同向**：只执行上游 `人载同向=`（§1）。`相对=后方` 却写成骑手正面／`面向镜头` = 投影失败（不改挂）。

**朝向成稿闸**：所对主体可见 → `面向=` 写该对象／角色，镜头关系按 `可见面推`＋本拍 N。所对主体不可见 → `面向=` 或 `目光=` 写 `面向镜头`；身体朝向这一具时镜头关系写 `正面可见`。`朝向推=`／`背对=` 只进场记。禁 `面向N°`／「即面向镜头」。禁用 `面向镜头` 顶替仍可见的主体。落点画位 ≠ 可见面。

**转身过程拍（转肩只从建置判）**
时序走 §2。入戏出现转身 / 转面 / 调头 → `拍型=转身过程`。禁同拍开口 / 走位 / 取物。轴未变可同父 ENV。禁写转了多少度。
- **建置**：只写动作前档。禁写成转后面向。
- **入戏**：只写连续转体（可见面随转写出，不写 XOR）。五件套只进终态：`向{左|右}肩转 → 终态面向{对象} → 终态镜头可见面 → 终态姿态 → 终态落点`。
- **下拍建置**：才抄本拍终态新朝向。❌本拍建置与终态面向相同却写入戏「转身」。

**转肩判定（角色自身左/右，不是画面左/右）**
只以**本拍建置**为开拍态，禁止用终态回推。
1. 转肩读分布图世界对象 A，不从建置人话反推朝向。建置不写面对镜头。几何锚取该对象在宫格上的格；无明示才用场记 `朝向推=`。
2. 用**本拍** ENV `背景=`/`画左=`/`画右=`（及近镜头侧）把 A、B 各落入四向之一：`近镜头|远镜头|画左|画右`。B=入戏要转到的明示对象；无明示则用 `朝向推=` 或三锚几何。缺三锚=失败。
3. 按建置面向所定的角色左/右，取从 A 到 B 的较短转：

| 建置面向所在向 | 角色左 | 角色右 |
| :--- | :--- | :--- |
| **远镜头**（对背景） | 画左 | 画右 |
| **近镜头**（对机位） | 画右 | 画左 |
| **画左** | 近镜头 | 远镜头 |
| **画右** | 远镜头 | 近镜头 |

B 在角色左 → `向左肩转`；在角色右 → `向右肩转`。B 与 A 对向 → 须上游已拆转身过程拍或已锁越轴，禁同拍硬拧 180° 还开口（未拆 → 回流）。
❌用画面左/右当角色左/右。❌用转后面向当建置再回推转肩。❌默认某类陈设（门/窗）在某一侧。

**切角只换观察向**：未走位未转身者，世界槽／看谁不改；近远／画幅／可见面按本拍 N 投影（90/270 禁正背照抄）。`所在侧` 查 §7A。

**落笔序**：决策链 2→4。句内序= `面向=` → 镜头关系 → 站位投影 → 姿势 → 手持／佩戴 → 投影面表情。速查另抄 `所在侧`；`朝向推=`／`背对=` 不进建置句。不写脸可读核销。

**反打 ≠ 转身**：反打时未转身者面向对象 / 姿态 / `所在侧` 不变，镜头可见面随观察向对调。来源 = **紧邻上拍终态**（上拍是转身过程拍则取其终态新档，禁回取该拍建置旧档）。相对锚名与辅边位不改写，近/远镜头对调，左右改查新 ENV 画幅锚实体。

| 紧邻上拍终态镜头关系 | 本拍开拍镜头关系 |
| :--- | :--- |
| 正面可见 / 正面¾可见 | 背朝镜头 |

| 右侧面可见 | 左侧面可见 |
| 左侧面可见 | 右侧面可见 |

层位按对向对调（前景↔远景、画左↔画右）。纵深词对调；世界槽（`近门一侧`/`主位`/`辅=`）不改口。`投影恒等` 仅轴心层位/中央，≠可见面／近远没变。落到 `◎` 背后 → `暂不可见`。禁照抄上拍正面／靠近镜头／前景。反打后仍要同一可见面 → 须上游已有转身过程拍，否则回流。
❌`180度` 巨龙前景正面扑人 → 无走位切 `0度` 仍写巨龙前景背朝镜头（应为远景／远离镜头）。满幅法相不得写成空气。
