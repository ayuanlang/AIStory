## 目标（最高；本子技能工作方式）
对**输入剧本**做建置与入戏空间补缺：在已声明环境里把缺口的建置与入戏空间过程写完整。
1. **当前 ENV 必须 ∈ 输入已声明衍生名**（Master=`0度{主}`）；禁裸主环境名；禁把仓内戏挂仓外衍生。
2. **只补缺**：输入已有合格建置/入戏空间句 → 原样透传；仅当缺落位、缺朝向、缺出入画过程、缺终态承接时按本文件补。
3. **不改环境骨架**：不写/不改【主环境】【衍生】行；不裁定复用或新建。
4. **其余原样输出**：对白词、微表演、场核、特效过程、环境块正文。
本文件只补空间容器与位移过程；入戏氛围句若输入已有则原样透传。
5. **综合信息块只读透传**：输入若含 `[COMPREHENSIVE_INFO_START]`…`[COMPREHENSIVE_INFO_END]`，可读取其整体简介、人物简介、世界观作为全局语境，但不得据此直接新增本场站位/动作，不得改写、移动、拆散或复制；整块及 `INFO_ITEM` 子包裹逐字原位保留，供下游提取。
6. **特殊路由包裹只读透传**：位于 `SCENE_START` 前的 `SPECIAL_SCENE_ANALYSIS` 包裹及 VFX/XIAN 两行必须逐字原位保留，START/END 与对应 Scene ID 不得改动；不得移入 Scene、Beat、【建置】或【入戏】。
7. **场级指导强制落地**：读取【场景综合】【卖点综合】`指导=`、【情绪峰谷综合】和【叙事综合】。建置与选角必须让 `细节特写参考` 的对象处于当前衍生白名单且可读，让 `反馈特写参考` 的人物可见面与重点对象同拍或紧邻切角可读，并为 `运镜参考` 保留无穿障的揭示/逼近/跟随/拉开/停留空间。`贯穿保护` 的道具、信息载体、伤态、持物和人物状态必须在速查与终态中连续。

## 通用硬约束（各子技能同锁；最高）
> 抽自父提示词文首总闸 / 【边界】 / §1 原文核销 / 成稿口径。本子技能写环境/建置/入戏空间时**不得**借「加密站位」违反下列任一条。

1. **忠于上游原文 + 未命中原样输出**：不改事实/因果/胜负/伤亡/角色关系；**禁新增改因果事件**；扩写只补**命中本规则段落**的可拍空间与可见过程。上游已写则**保真不得压扁**；上游空泛则仅对该段加密。**未命中段落禁止改写。**
2. **原文信息零丢失**：原剧本**每一处文字 / 每一信息单元**必须落入成稿可检索落点；**禁删/漏**原剧本任一文字单元。未优化段须能与输入逐字对上。
3. **专名逐字**：角色名/地名/环境注册名与原文**逐字一致**；已有真名禁改；同环境名复用。
4. **对白保真**：项目语言侧台词逐字保留；**禁止臆造台词填洞**。本文件不拆句、不改台词用词。
5. **逻辑合理可拍**：凡建置/朝向/层位/运动/ENV 选择——第一原则=物理世界 + 镜头投影下可成立、可拍摄。公式/硬锁/模板与可拍冲突时**以逻辑合理为准重写**。**废除正面优先**；仅当本拍须读脸/口型/正面躯干才安排正面/¾。**绝对禁**：`正面/¾朝镜头可读`又`面向后景…`。
6. **三段职责**：【建置】=开口前画面初始态；【入戏】=纯过程；【Beat切换说明】=变化过程 + 终态。**位置与朝向只写建置及切换说明终态**；入戏禁止描述角色/道具的位置、朝向、层位、左右、距离、起终点或槽位。
7. **禁实拍执行语**：威亚/钢丝/替身/绿幕等；腾空/轻功只写可见运动。
8. **禁意图词**：试图/想要/打算 → 具体动作链；失败也写可见受阻。
9. **下游边界**：本阶段定「拍什么」；禁代写分镜处方（焦距/运镜处方归 `shot_generation`）。
10. **只执行已注入规约**：不得把文戏改写成武戏/仙攻；武戏/仙攻空间过程若输入已写则原样透传。

## 术语
| 术语 | 定义 |
| :--- | :--- |
| **主环境** | 场级空间基准（名称/0°轴/四向+中心/活动空间/固定清单）；**永不**作 Beat 当前环境。 |
| **衍生环境** | `{N}度{主名}` 可拍当前环境；可见性只查该行白名单+活动适配+边界。 |
| **建置** | 开口前画面初始态：可移动主体落位/朝向/姿态；固定陈设只点名不写其位。 |
| **入戏** | 纯过程：动作/对白/表情/交互/动势/音效；**不写**位置与朝向。 |
| **XOR** | 同一主体定位只选绝对或相对一种；入戏不写定位。 |
| **朝向三联** | 正背面 + 面向对象层 + 层位词≡实层。 |
| **入画径向三联** | 门层位 × 行进径向/正背面 × `活动适配`。 |
| **运动三要素** | 起点/路径/终点（内部规划；成稿入戏不写起终位）。 |
| **对向零可见** | 当前 N 的 `(N+180)%360` 对向固定实体不得进白名单。 |
| **连续≤3** | 同一衍生环境名连续使用不得超过 3 个 Beat。 |
| **核销** | 原文信息单元在成稿有且仅有可检索落点。 |
| **原样输出** | 未命中本规则的输入文本逐字透传，禁止润色/重排/顺带改写。 |

## 1. Quick Start — Beat 完整逻辑（强制）
**每个 Beat 均须按下列逻辑完整执行**；**前置 + 六环节**彼此咬合、缺任一即 Beat 不合格。

| 块 | 内容 | 细则落点 |
| :--- | :--- | :--- |
| **前置（环节 0）** | 承接上拍终态/差集；核进出画、姿态、正背面、骑乘与随身物守恒。中途入画/突现者不进本拍建置，过程写入戏，**当拍终态登记完整字段**；集合变化后续戏另起 Beat。**法相与宿主同拍因果若输入已写则原样透传。** | §1 三段时序/集合锁；§12；§15；§17 |
| **① 观察视角—实体落位** | 当前可拍 ENV 名 + 观察视角 + **可移动主体**落位/朝向/身体姿态；**正背面本拍内锁定**；相对上拍有变→已另起拍（切镜头则先切 ENV）｜环境固定陈设（桌椅床等）**只点名不写其位**（§1 空镜重述）｜**当前 ENV=衍生行（Master=`0度…`，禁裸主环境）=本视角直接可见背景半空间** | §13；速查表 §12 |
| **② 景深层次** | 前景=最近、后景=最远；扇区≠景深；遮挡/层间距离 | §14（公约摘要见下） |
| **③ 运动方向与朝向** | **运动三要素**（起点/路径/终点；非建置三轴）；朝向跟剧情与后续动作方向；**运动终点须具体**（具名地点/人旁/出画外等，禁只写「跑向某处」）；**停驻须交代落点+与他者相对关系**（纵深/左右/距离；按后续是正反打还是同向选型，§12）；**多门进出须双向具体**——入=`从{门位}→到{座位/落点}`｜出=`从{座位/舱内位}→经{门位}→到{门外落点}`（禁裸「上车/下车/进门/出门」）；**禁意图词**（试图/想要→具体动作，§6） | §12；§6 |
| **④ 对白咬合** | **对谁/朝哪方向说（强制）**；说话人/主听众面向；**他人目光默认朝向说话人**；**受者响应**（应答/可见反应/明文未听见；禁只写说话人）；角色粒度；异排异向切 ENV；**语言须符合身份/地位/明文性格** | §12「对白咬合」+ 章节5；§6 上游 1g |
| **⑤ 微表情+微动作** | 动态过程链；肢体到位+程度量化（交互止于手级，防穿模）；情绪具象外化须**仍像该身份/地位/明文性格**（豪门内敛失态≠农家直顶；复合过程脸优先：欲言又止/气得说不出话/话到嘴边又咽回/强忍不哭/似笑非笑，禁「眉头一皱/一愣」交差）；**细微动作仅剧情必要体现具体情绪才设计**，且须**日常常见**、**禁细微动作创新**；口型对白开口须≥1 面部微表情（**须正面/¾可读**）；OS/V.O./旁白/自白等须明文闭嘴+非口型外化；**背对/侧背面禁正面才可见内容**（含五官微表情**与**胸膛/肚子等正面躯干；改后脑肩背等；**须读脸/正面躯干→强制新可读角衍生 ENV + 新 Beat**）；**禁「试图/想要」类意图句** | 章节5 §6；§12；动作规格 §6 |
| **⑥ 表演连贯** | 跨 Beat 表演落点承接；**对白/动作跨拍连贯衔接**；动作惯性衔接；**操作链无跳步**；**受者响应闭环**（对白主听众+交互被作用对象；禁受者僵立）；过程须可拍具体动作非意图概括 | 章节5 §7；§6；对齐上游 1g |

**Beat 成稿叙述原则（强制）**
- **逻辑合理可拍**：见文首总闸。建置/入戏失败闭集=`正面/¾可读+面向后景`｜物理不可拍｜公式倒逼。
- **禁「同上」（最高）**：每拍独立可读。**同 ENV**：【建置】=上一拍【Beat切换说明】之`终态画面纵深`（或等价：上拍`速查更新`经**同一 N** 投影后的完整画面句）——**一字不落抄写纵深+正背面+姿态**（禁顺带微调；仅本拍明文移动/出入画/持握/姿态变更可在入戏改、终态写入本拍切换说明——**正背面档位本拍内禁变**；转身/转面致档位变须另起拍）。**ENV 变**（另起新拍，§4）：写【上一→触发→本 ENV】；**世界扇区/F/姿态 承接不变**（无明文走位/起跪坐时；转身改 F 亦须另起拍后在新拍建置落新档），画面句按新 N **整句重写层位与正背面**（禁粘贴上拍任一「画左/画右/前景/后景/正面/背对」短语），**身体姿态档须逐字继承**（见下）。违径向/三联/姿态继承须回改。
- **世界态为投影真源（手段；服从总闸）**：真源=`世界扇区+F+姿态+具名锚`；画面相对词=观察轴 N 投影。落笔：承`速查更新`→定 F→按 N 投影→把**开拍位置/朝向写入【建置】**；动作造成的世界态变化只写入【Beat切换说明】终态/速查，**不得回写进【入戏】**。
- **姿态跨拍严格继承（最高；外置+姿势）**：承接上拍时，角色除世界扇区/锚/可见性（外置）外，**身体姿态档必须严格继承**——站｜坐｜跪｜蹲｜趴｜躺｜倚靠｜骑乘 等（座/躺/倚须连同具名承托面一并继承）。**切角/反打/景别收紧≠改姿势**：`ENV变=是` 只重投影层位/左右/正背面，**不得**把上拍终态「跪」改写成「站」、把「坐」改成「立」。本拍【建置】起始姿态 ≡ 上拍`速查更新`之`姿态=`（可见带回者同）；仅当本拍【入戏】有可拍过渡链（跪下/起立/入座/起身/下马等）方可在**速查终态**改姿态，建置仍写旧姿态。❌切角后无过渡把跪写成站。
- **建置防错乱五锁（最高；每拍落笔序，缺锁=失败）**：错乱根因=用画面词当记忆、把度数写进建置、速查与画面不对账、反打乱换空间名、自检空话盖章。强制：
  1. **时序锁**：【建置】=开口前**画面初始态**（含上拍终态姿态档+**初始纵深**：前景/中景/后景须带括注）；【入戏】=过程（运动/对白）；【Beat切换说明】=`初始建置 + 入戏运动` 的**变化过程摘要 + 画面终态**（含**终态纵深**；供下拍【建置】承接）。`速查更新`∈切换说明，=场内世界态终态。禁把终态 F/新姿态/转身结果/**运动后纵深**写进建置；禁建置残留 `F≈`/`0°侧`。❌建置含`F≈`。**入戏含推门入内/入画行走时**：建置不得已是「大厅深处前景站定」的入完态——起始须在门侧/门外/刚跨过门槛，入完落点+终态纵深只进切换说明。**入戏含起立/跪下/入座时**：建置须仍为旧姿态，新姿态只进切换说明/速查。
  2. **投影锁（算术硬核；禁直觉）**：速查扇区+本拍 N → **先算**`后景=N°｜前景=(N+180)%360`再查§12 表 → 层位/左右**必须≡**建置≡台账`→画面`。❌N=180 却把 0°侧写成后景（应为前景）。ENV 变后未走位者画面三项相对上拍必变。
  3. **朝向锁**：F/正背面/面向目标只进【建置】与切换说明终态；入戏仅据建置可见面裁定可写的表情、口型和动作，不得输出朝向词、画幅方向或新 F。对白只写`对{听众名}`，不写`对画左/画右/对镜头/望向某方位`。转身只写动作发生，新朝向只进终态。OS/V.O./旁白/自白仍按可见面判定闭嘴与非口型。
  4. **ENV 名锁**：`ENV变` 触发类型与新 ENV **主名段**闭合——同场反打=`{N}度{同一主环境名}`（❌`0度主大门`→反打却写`180度王座区`）；**默认**换主空间名=转场/新 Scene，禁标「反打」。**特例（同场多主，§11）**：同 Scene 已声明的另一【主环境】族之间切换时，主名段**必须**变为目标主环境名（`ENV变=是`），触发=`闪回切主环境|蒙太奇切主环境|回切当下主环境|入舱切主环境|出舱切主环境|回切仓外主环境`，**禁止**标「反打」，亦禁止用当下主环境的视角衍生冒充异地/舱内。较长回忆若输入已拆独立闪回 Scene 则按该场已声明主环境族切 ENV；**出入封闭舱一般不分场**（仓外起始、场内切仓内，§11）。**标签判别**：同主名+±180°可读对手=`反打`；换主名=闪回/蒙太奇/入出舱/转场（**非反打**）——禁混标。
  5. **集合锁（开拍集≠收拍集；最高）**：
     - **开拍可见集**≡【建置】具名集合（开口前已在画——含角色/动物/载具/法相/金身等）。
     - **收拍可见集**≡`{Beat终态画内实体}`≡`终态画面纵深`具名集合。
     - **公式（强制）**：`终态=(建置−本拍明文出画)∪本拍入画/突现落定`。**禁止**无条件写「终态≡建置」——中途入画（门入/驶入/金身凝形等）→建置可不含其名、终态必须含且字段齐全；中途出画→建置含、终态剔除。
     - **≠纵深等同**：落位/朝向终态进切换说明`终态画面纵深`（可与建置层位不同）。
     - 速查覆盖画内+暂不可见（未出画）；上拍差集处置本拍重析——出画｜仍画内｜暂不可见续挂｜已转可见则**必须**带入建置；**新人/群演/动物/载具/法相/金身不得凭空入画**（上拍终态∪差集∪速查皆无其名时，本拍须经具名出入口或可核销驶入/凝形链）；禁带病标「①–⑧全过」。
- **三段时序（最高；建置≠终态）**：
  1. **【建置】=画面初始态（仅可见）**：开口前静止画面——仅写开拍已在画、查表可见的可移动主体/可见物件。定位按空间类型先分流：①**封闭/紧凑/槽位明确空间**（驾驶舱、车厢、轿厢、客舱、小房间、狭廊等）一律以座位/操纵位/舱门/过道/床位/桌位等**环境槽位相对定位为主**，禁再叠前中后景+画左画右；②只有空旷大厅、广场、旷野等无稳定近身槽位的开放大空间，才用镜头绝对前中后景/左右。每名另写正背面、面向、姿态；禁止把本拍运动后的落点写进建置。
  2. **【入戏】=纯过程**：只写动作、对白、表情/可见面反应、交互事件、环境动势、音效`<…>`。角色/道具可作动作主语或对象，但**禁止写其位置与朝向**：前中后景、画左/中/右、距离、槽位、起点/终点、停驻落点、移动方向、F/正背面变化、道具放置/收纳位置均不写。移动/转身/移交/放置只写发生了什么；结果统一写【Beat切换说明】`变化过程/终态画面纵深/速查更新`。

    - **可见面与朝向同锁**：正面/¾可写眼神/表情；侧面仅写该侧半脸；背对/侧背面禁眉眼口型，只能写肩背、后脑≤30°微偏、手部、重心等可见动作。`看向{名/方向}`必须与建置身体朝向、头眼偏转档位及目标可见性V/D闭合；动物须分别核`body_facing/head_facing`，禁身躯背对却写正面眼神。
    - **群演簇/氛围龙套**：群演簇可用1条簇级同步/错落微动覆盖（如`靠门食客簇随马蹄声同时停箸，前排两人侧头`），无需逐人；单独具名龙套仍逐名。已建置的具名龙套不得因“非焦点”省略。
    - **剧情强制完全静止例外**：仅原文明文死亡、昏迷、冻结、屏息伪装等必须不动时，可用`静止核销=剧情强制`，但仍须写可见的静止证据/被动反馈（无胸腹起伏、衣角受风而身体不动、受冲击仍僵直）；禁无依据用“静止”逃避动作覆盖。
    - **与受者响应分工（对齐上游 1g）**：覆盖率管「画内每人至少 1 个可拍微动」；**受者响应**管「这一句对白 / 这一手交互的被作用对象必须有针对该动作的接收」。覆盖率微反应**不能替代**受者响应（例：旁观龙套肩颤 ≠ 乙接过甲递出的信）。受者开口仍另起拍。
    - ❌建置多人、入戏只写主动作主体。
  - **无当前剧情的角色禁止提前入场（最高；氛围龙套/群演簇除外）**：
    - 【Scene实体覆盖】须给每个主体标`入场类别=剧情角色|氛围龙套|群演簇`、`首次剧情Beat=…|N/A`（对剧情角色即**剧情触发/入画过程拍本身**，不是后续对白拍）、`开场在场依据=原文明文|氛围建置|无`。剧情角色若原文未明文其开场已在场，则首次剧情Beat前必须=`待入画`：不得塞进开场【建置】、实层表、终态名单、差集池或速查，也不得为“后面要用”提前站在背景。
    - **不得提前一拍“预备入场”**：角色必须在其剧情第一次实际发生的**同一叙事节点**才入画；把该节点拆为相邻两拍时，第一拍就是`剧情触发/入画过程拍`（开拍不含该角色→入戏经具名出入口/Reveal→终态含该角色），紧邻下一拍才承载其对白/后续主动作。禁止在更早、无关的 Beat 先让角色进来站着等剧情。首次仅为**画外声**时仍不算入画，保持`待入画|声源=画外`，直到剧情要求其本体出现的当拍才入画。
    - **仅有两类豁免**：①氛围龙套；②群演簇。它们可因原文/场景氛围建置在开场已在画，但须写`氛围在场依据`，不得抢占剧情动作或被伪装成具名剧情角色；一旦已在画仍服从后续守恒。某氛围龙套后来被剧情单独点名/交互，须从既有氛围位置连续承接，禁止同一人再次凭空入场。
    - ❌剧情未到却提前入画，或放进差集伪装暂不可见。
  - **出入画改集合→强制另起 Beat（最高；与转身另起同级）**：可移动主体（角色/群演/动物/载具/法相/金身等）**明文入画或出画**，致本拍**开拍可见集≠收拍可见集**（建置集合变）时——该拍**只承载出入画过程**，落定/出画完成即切拍；**后续对白轮次、新主动作、新表演单元必须新起 Beat**，以新集合为【建置】开拍态承接。

    | :--- | :--- | :--- | :--- |
    | **Beat N（出入画过程拍）** | =开拍可见集（入画者可尚未在建置；出画者须在） | 经具名出入口的入画/出画链（可含同拍因果必需的极短反应，**禁**新对白轮次/新主动作） | =收拍可见集；入画/突现者当拍写满字段 |
    | **Beat N+1 起** | =上拍`终态画面纵深`（新集合） | 后续对白/主动作/表演 | 按本拍运动更新 |
    ❌出入画落定后同拍继续对白/主动作。须拆两拍。**切角暂不可见≠出入画**（差集续挂，不触发本条）；同拍多名一并入/出且同属一次出入画事件可同过程拍，仍须在落定后切拍再开后续戏。
  - ❌无落位朝向的「跟着/现身」；上拍在画下拍蒸发；金身有动作却建置/终态无名。
  - **边界**：①无定形介质/仙攻凝形过程→原样透传，本文件不加密凝形六相；输入已凝成形体可读且入画→当拍按可移动主体建置承接。②开场静物→预排布；一旦本拍位移/携出画→升格可移动主体，进出场+朝向全开。
- **空镜重述限定（Beat【建置】【入戏】；强制）**：空镜骨架与固定陈设的世界落位只在 Scene 级【主环境】/【衍生】定义；Beat **不负责**再描写环境美术，**亦不负责**复述环境内固定实体在画面中的位置。**例外**：原文具体环境文学须进**独立空镜拍【入戏】**作可感信息+动势核销（§1），仍禁为陈设写画面层位；禁借本条把文学只塞进【主环境】后跳过 Beat。
  - **环境固定实体只点名、不写其位**：建置可写角色相对固定实体的槽位；入戏只把固定实体作为动作对象点名，禁止附带实体或角色槽位。
    - **例外（须特指哪一件）**：同类多件且剧情须区分时，才用清单已具名区分特征点名（`坐在靠窗那把椅`｜`掀开左侧床帷`）——仍**禁止**借机重写该椅/床在画面中的层位/左右；只消歧实体身份。
    - **角色位≠实体位**：可移动主体按定位 XOR 写自己的位置；挂靠固定实体时只写角色相对该**名+槽位**的关系（坐哪把椅/靠桌哪一头/头朝床头），**不要**把「桌子在前景画左」写进建置。
    - **定位 XOR（最高；角色与可移动道具同锁）**：只约束【建置】与【Beat切换说明】终态；每个主体只选绝对或相对一种定位。**【入戏】不写任何定位字段，因此不参与 XOR 成稿。**
    - **空间类型优先级（最高；覆盖“无剧情交互才绝对”旧口径）**：
      1. **封闭/紧凑/槽位明确空间 → 强制相对定位**：驾驶舱/操纵舱、汽车/车厢/客舱/轿厢、电梯、轿子、马车厢、小房间、病房、牢房、狭廊等，角色即使未与固定实体交互，也天然受舱体/房间槽位约束。须写 `坐在驾驶座|副驾|后排右座|飞行员左操纵席|舵手位|后方观察员位|靠舱门过道侧|床尾侧` 等具名槽位，并补与相关人员的前/后/左/右关系；**禁止**写成`前景画左/中景画右`。
      1-a. **槽位坐标必须完整（最高；禁裸“后排/右座”）**：
        - **排号**：以0°主要驾驶观察向的**最前一排/前向操纵排为第1排**，沿舱尾方向依次第2、3…排。须写`第N排`；可同时附功能别名`前排|后排|操纵排|观察员排`，但别名不得代替排号。无排式开放舰桥则写`操纵区第N列/控制台编号`，禁伪造座排。
        - **横位**：以人员**面朝0°主要驾驶观察向时的舱体左→右**计数（世界/舱体左右，**不是画面左右**）。须写`本排共M位｜从左到右第K位`，并可附`靠左|居中|靠右|靠舷窗|靠过道`；强制`1≤K≤M`。左右驾只改变驾驶席K，不改变计数方向。
        - **唯一槽位ID**：格式=`第N排-左起第K/M位-{功能名}`，如`第2排-左起第3/3位-后排右座`、`第1排-左起第1/2位-左驾驶座`、`第1排-左起第2/2位-副驾`。飞机/轮船/列车同义替换功能名。
        - **人际相对**：槽位后再写`在{人}后方第几排｜位于其左后/正后/右后`；距离优先以`相隔N排|相邻排`表达，狭舱禁无据写“一臂”冒充排距。
        - **建置/终态同串继承**：同一主体全拍使用完全相同槽位ID；无入戏换座过程不得改N/K/M。多人同槽位、K重复或总位数不闭合=失败。槽位相对定位角色不纳入实层表。
      2. **普通室内有稳定锚 → 优先相对定位**：桌、床、柜台、门、窗、沙发、讲台等任一可核销锚存在且能定义站坐关系时，用其槽位。
      3. **仅空旷大厅/广场/旷野等无稳定槽位锚 → 允许绝对定位**：才可写前/中/后景+画左/中/右。
      4. **相对定位角色不入实层表（最高）**：凡角色位置以完整槽位ID、桌/床/门/柜等具名锚槽位或人际前后左右关系表达，**该角色不得写入`实层表`**；其位置只在建置、终态与速查中以相对关系闭合。若本拍全部角色均为相对定位，整行`实层表`省略。只有采用镜头绝对`前景|中景|后景`定位的角色才纳入实层表。内部构图可计算纵深，但不得把计算结果回填为该相对角色的实层表项。
      5. **构图≠定位**：可保留`构图=纵深/主体落点=画右三分`作为摄影排布，但角色建置句不得因此追加画左/前景等绝对位置。
      - **判定（逐主体、本拍；剧本明文即相对）**：原文或本场剧情出现该人在`桌旁|桌子旁|案旁|凳上|凳子上|椅上|椅子上|床上|榻上|柜台后|靠桌|入座|躺床|墙前|碑前|桥前|栏前|门前`等挂靠环境实体的位置或动作 → **必须相对定位**，主参考点=该实体（多件时取剧情相关最大者）。其余可核销接触（触碰/取物/绕过/推门/站在旁边）同走相对。仅当该人与环境实体无上述挂靠（广场、空大厅独立站立对峙等）才走绝对。同拍不同人可各选各的。
      - **方式A · 视角绝对定位**：较空旷舞台（广场、空大厅等）或本拍无挂靠/接触 → 用镜头坐标系：前景(离镜近处)/中景/后景(远处)+画左|中央|画右+上下。禁把桌/床等当位置锚。

        2. **面向层位≡对象实际纵深**：`面向后景{名}` ⇒ 该名必须比面向者更远镜头；该名已是前景/更近=失败。`面向前景{名}` ⇒ 该名必须更近。未核实对象纵深，**禁止**套正反打套话填「面向后景对手」。

      - **`面向{层位词}(的){名|锚}`≡对象实层（最高）**：层位词须≡该对象本拍实际位置；禁为凑公式篡改。**绝对定位角色**出现纵深落位或`面向前景/中景/后景`时，须在【建置】首行实层表中填该角色/对象的`前景|中景|后景`，面向层位词只许抄表。**相对定位角色一律不纳入实层表**：其`面向近镜头侧/远镜头侧的{名}`或面向具名锚，直接按建置中的槽位/锚近远侧关系核销；不得为核朝向另补该角色的实层表项。混合定位拍的实层表只列绝对定位角色；全员相对定位则省略整行。交叉核销：①定露脸需求→②绝对者填表、相对者锁槽位关系→③仅当剧情确须朝向他者且该他者确在相应方向才写`面向{名}`→④核己方正背面是否允许→⑤否则省略或写镜头向。**字面与对应定位真源不一致=整拍失败**（含`正面+面向后景`、同层互称前/后景）。ENV变/回挂靠后须重核三联；只对绝对定位角色重核实层表。
