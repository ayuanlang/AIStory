## 目标

按**单场**调用。输入已含【主环境】【未落清单】【衍生环境】、覆盖矩阵、【主体定位方案】【Beat主体定位】、【Beat景别构图方案】、各拍【取景锁定】与【场记分析】，以及文戏/特效/仙攻过程。
已锁拍摄是开拍条件。本文件把**拍摄键写入【建置】【入戏】**，把**推导与连续性写入场级【场记分析】**，并核对走位与逐拍出入画，保证动作、位置、人物/道具关系、**轴位**跨拍连续（默认不越轴）。场头写【实体覆盖】【位置规划】【观察视角与空间建置】【场记分析】。
1. **连续性（核心）**：动作链无跳步；开拍 ≡ 上拍终态。同 ENV 抄 `终态画面纵深`。ENV 变不瞬移：相对锚名+辅边位/面向/姿态不变，画左↔画右与近/远镜头对调，只重写镜头可见面；绝对重写层位+画左右+高低；封闭重写排+画左起第K。执行已锁【主体定位方案】/【Beat主体定位】，不改方式。站位/走位守已锁 `spatial_axis` 同一侧。禁角度坐标。
2. **走位核对与细化（核心）**：据已锁 ENV / 景别 / 活动空间 / 轴线，核本拍走位是否可拍且不越轴（净空、不穿障、步幅、门径向、触达一臂、终点仍被白名单覆盖、路径不跨轴线）。**先评直线开拍→终点有无障碍**（固定大件/柱/人/门扇）；有则 `经=` 须写绕过哪件、从该件`画左|画右|近镜头|远镜头`哪侧，直线穿障=失败。再把路径写清：`{名}:自{开拍}→经{路径/绕障/门/步数或臂距}→到{终态}`，并写停驻后与他者相对。无走位须明文 `走位=无`。
2A. **逐拍出入画（核心）**：谁在画、谁入、谁出、经哪口，必须在本文件写完。开拍在画 =【建置】具名主体；中途入画 =【入戏】写经{出入口}入画过程（建置不含，终态写入）；中途出画 = 建置含、入戏写出画过程、终态剔除。切角暂不可见 ≠ 出入画。场头【实体覆盖】写在场 / 待入画 / 出入口 / 离场。
3. **拍摄写入建置/入戏**：该拍 `当前环境` / `景别` / `构图` / `可兼` / `主体落点` / `留白` / `纵深层` / `镜头角度` / `关系角` / `OTS类型` / `近侧框主` / `主拍对象` / `主观角色` = 输入已锁拍摄键。标题后**不保留**独立【取景锁定】行；拍摄键全部写入【建置】首句。入戏只写镜头实际看见的过程（对白/微表演/`<…>`），不写锁档键值、不写推导。上游【配乐】【音效】原样写入戏，不改 `态=`/`锚=`/`配合=`/`音量=`/`质量=`/`混响空间=`。
4. **两段式**：每个最终 Beat 只写 `────【建置】────` → `────【入戏】────`。Beat 内**禁**再写【场记分析】。

6. **入戏只写建置后变化（核心）**：【入戏】只描写开拍后相对本拍【建置】初态**新发生或推进**的部分（对白 / 语气 / 微表演 / 左右手脚 / 取用 / 朝向对象变化 / 门开闭 / 走停转 / 出入画 / 特效仙攻 / ENV 背景微动 / `<…>` / 【配乐】【音效】 / 本集首次正面出场字幕）。建置已写的位置 / 朝向 / 姿态 / 层位 / 距离 / 挂载一律不复述。无角色变化则只写对白（若有）+ ENV 背景微动。**开口/闭嘴仅有对白时必填**，无台词不写。变化结果只进场级场记分析 `B{n}` 终态。**上下拍衔接**：入戏须从上拍终态/未完成动作链接着写，并落到本拍终态，使下拍建置能直接承接；禁跳步、禁蒸发受者响应、禁把下拍才发生的动作提前写完。
7. **完整一场**：从 `[SCENES_BLOCK_START]` 起笔；末行 `[STAGING_ENV_OUTPUT_END]`。

## 1. 建置 / 入戏 / 场级场记分析
- **【建置】**：首句写满拍摄键（见目标 3）；其下仅开拍已在画、查表可见者。初始位置 / 朝向 / 姿态由此段一次写清，按已锁方式成稿（§4）。键值行后须跟自然语言句。运动后落点不进建置。禁写 `选择证据` / `跨度` / `原文景别` / 扇区 / `F≈` / `0°侧`。
- **【入戏】**：只写相对本拍【建置】初态的**变化**——动作 / 对白 / 表情 / 交互 / 动势推进 / ENV 背景微动 / `<…>` / 【配乐】【音效】原样 / 本集首次正面出场字幕。无变化时禁复述初态。有走位 / 转身 / 出入画时，变化句须用**同样完整的自然语言**写出新可见面与已锁方式落点（禁只写「走两步」「转过身」）；无走位则不复述位置 / 镜头可见面。亦不写锁档键值或选择证据。画内缺角色微动则只补不抢戏的微反应。ENV 背景微动**只在本段写**，不复述建置、不改已写动作 / 对白。**衔接**：起笔状态 ≡ 本拍建置 ≡ 上拍终态；入戏推进后的可见结果须能被本拍终态收下、下拍建置抄走。
  - ❌入戏写`跨度=越级` / 无变化却复述初态 / 无对白却写开口闭嘴 / 相对走位写成无锚画左
- **【场记分析】（场级综合项）**：写在 Beat 流之前，成对标记。`B{n}=` 一行一拍 = 输入推导键 ⊕ 建置 ⊕ 入戏 → `变化过程` + `终态画面纵深` + `速查更新`。同 ENV 下拍【建置】抄上拍 `B{n}` 终态句；ENV 变取速查的锚名 / 辅边位 / 面向 / 姿态，相对只对调画左↔画右与近/远镜头并重写镜头可见面，绝对只重写层位与画左右+高低。无运动仍复述终态与周边相对。站位禁写扇区 / `F≈` / `0°侧`。Beat 内禁再出现该段。
- **集合**：`终态=(建置−出画)∪入画/突现`。中途入画者不进建置，终态写满字段；中途出画者建置含、终态剔除。差集须写 `{名}|出画|经=…` 或 `{名}|入画|经=…`。
- **不可见**：机位后方 / 完全遮挡 → 禁入建置 / 入戏；必须进 `差集处置` + 速查 `暂不可见`。
- **可移动主体**（角色 / 具名龙套 / 群演簇 / 动物 / 载具 / 法相金身）：同等落位 + 朝向 + 进出场。群演簇写人数 / 队形 / 主导镜头可见面。人—车 / 人—骑分行。**满幅/快动→局部特写**：上拍为宏观整体或快速运动、本拍已锁 `CU|ECU` 时，【建置】仍抄上拍规模 / 队形；簇内动势须含速率词（冲 / 疾 / 掠 / 过幅）。禁因景别收紧写成一人静立。入戏过幅体密度与速率须与上拍满幅同级。
- **不提前入场**：剧情角色首次剧情 Beat 前 = `待入画`。豁免 = 氛围龙套 / 群演簇（须依据）。
- **出入画另起拍**：该拍只写出入画（入戏写经哪口、行进径向、落定/离场）；落定后下一拍才对白 / 主动作。切角暂不可见 ≠ 出入画。禁只改集合不写过程。
- **动作覆盖**：建置内每人 / 每簇至少 1 个可见微动。剧情强制静止须写静止证据。受者响应须针对该动作，不能用旁观微动代替。
- **环境背景微动态（强制 · 只写入戏）**：每拍【入戏】`ENV背景微动={具名陈设}{物理微动}` ≥1，禁括号备注。禁静态空镜。陈设 ∈ 剧本 ∪ 本拍已写 ∪ Index ∪ 当前衍生 ENV；无可动锚则对已有结构写极轻态 1 句。幅度 subtle。光斑 / bokeh 不进。【建置】禁写本行。人群动势不替代 ENV 微动。空镜拍建置=`空镜／无角色`，微动仍写入戏。
- **开口｜闭嘴（仅有对白时）**：本拍有非空台词才写 `开口（说话人）｜闭嘴（听者…）`。无对白、空镜、纯走位/空镜建立 **禁止**出现开口/闭嘴行。OS/旁白/自白仍算有台词，须写闭嘴、开口侧按 drama 合同。
- **本集首次正面出场字幕（强制 · 读【本场角色标签】）**：注入行 `CHAR:[@名]｜标签=…｜标签_en=…｜裸名=…｜裸名_en=…｜字幕=待落|已过|无`。
  - **语种（最高）**：先读 `# Project Context` / `Language` / `project_language`。中文（`zh`/`cn`/`中文`/`Chinese`）→ 字样=`裸名`+`标签`。英文（`en`/`English`/`英文`）→ 字样=`裸名_en`+`标签_en`。未明确 → 跟剧本主语言（正文以汉字为主用中文侧，否则英文侧）。**禁**中英并列、**禁**用错语种上屏（英文项目打中文名/中文标签，或反向）。该侧标签为`无`或缺 `_en` → 不写字幕，场记分析标 `首登字幕缺口=缺{语种}标签`，禁拿另一语种顶上。
  - `字幕=待落` 且本拍【建置】该人镜头可见面 ∈ `正面/¾`（脸/双眼可读）→ 入戏**恰好一行**：`画面打出字幕：【{字样名}】{字样标签}】`。**禁**套 `CHAR:`。同人全场只写一次；写过后其余拍禁再写。
  - 本拍为背对/侧背面、空镜、主观且该人不可见 → 不写，等后拍首次正面/¾。
  - 全场 `字幕=待落` 却从未正面/¾：在该人首次侧面仍可读半脸的拍补写；仍无则场记分析标 `首登字幕缺口={名}`，禁为字幕改朝向。
  - `字幕=已过|无`、群演簇 → **禁写**。多人同拍各写一行，按入画/主拍次序。
  - ✅中文项目 `画面打出字幕：【陈】客栈掌柜】`｜✅英文项目 `画面打出字幕：【Chen】Innkeeper】`｜❌英文项目写`【陈】客栈掌柜】`｜❌`【Chen】客栈掌柜】`｜❌套 `CHAR:`

## 2. 连续性与走位
每拍先对上拍终态与本拍已锁取景做核对，再写建置 / 入戏 / 终态。

**动作连续**
- 上拍未完成的动作链本拍【入戏】承接，禁跳步、禁蒸发受者响应；本拍入戏未写完的链须留给下拍续，禁提前蒸发。
- 姿态 / 持物 / 朝向对象连续；变则须有本拍可拍过程（只写入戏）。姿态档（站坐跪蹲趴躺倚骑，含承托面）逐字继承；切角 ≠ 改姿势。入戏有过渡链才改终态姿态，建置仍写旧档。
- 镜头可见面本拍内锁定。随身件无离身链则建置重复上拍挂载部位。
- **入戏跨拍衔接**：入戏不得从与本拍建置矛盾的状态起笔（人已换位、手已换物、半句对白无据另起）；亦不得写到下拍建置无法承接的终态（半步悬空、物蒸发、动作无落点）。下拍【建置】抄本拍终态，下拍【入戏】再写新变化。

**位置连续**
- 真源=已锁方式（§4）。禁 `扇区+F`。
- 开拍 ≡ 上拍终态：同 ENV 抄 `终态画面纵深`。ENV 变写【上一ENV→触发→本ENV】；无走位/转身时锚名/辅边位/面向/姿态不变。相对：画左↔画右、近镜头↔远镜头对调，只重写可见面。绝对：层位/画左右/高低按对向对调。封闭：排与画左起第K随观察向重写。禁切角瞬移。
- 反打 = 同主名对向已锁 ENV。换主名触发不标反打。

**关系连续**
- 每人须写与相关人 / 锚的前/后/左/右 + 尺度距离 + 面向。走位后关系必须可从开拍关系 ⊕ 本拍路径推出。
- 正反打场：走位不得无过程把相向拆成同向，或把同向拧成相向。关系变须写在 `变化过程`。

**轴位连续（不越轴）**
- 轴线 = 本场已锁 `spatial_axis`。站位、走位路径、停驻点、左右屏必须落在轴线同一侧（左右屏=构图/轴线用语；**相对落位写「锚的画左/画右」，不是无锚的画面画左**）。
- 已锁 `axis_crossing=None`：禁跨轴；左右屏相对上拍保持同侧。
- 已锁 `PlannedReverse`：沿轴线对向，左右屏对调合法，仍算守轴，**不是**越轴。
- 已锁 `MotivatedCross`：允许跨轴，走位终点落到轴线另一侧，写 `越轴=是｜动机=` 该拍已锁动机。
- 失败：未锁越轴却因走位跨到轴线对面；无反打依据拧反左右屏；把越轴写成普通反打；改挂方案外角来圆越轴。回改走位。
  - ❌`守轴核销=通过`（无人名） / 未锁越轴却写`跨轴`

**走位核对**（相对已锁取景；不通过则回改落点或拆已锁空间硬锁拍，禁改挂方案外角）
1. 开拍落点 = 上拍终态，无瞬移。
2. 路径物理可拍：净空、步幅够、门径向闭合。**障物评估（有走位必写）**：直线开拍→终点扫本拍白名单与建置已写实体。无挡=`障=无`。有挡=`障={具名}`，路径须补 `绕={具名}之{画左|画右|近镜头|远镜头}`（承接文戏已写画侧；无则据已锁观察向裁定）；直线穿桌/柱/人/门扇=失败。绕障节点须仍在已锁活动空间且不越轴。
3. 终点仍在已锁活动空间；本拍必见项仍 ⊆ 已锁白名单。
4. 走位后距离档与已锁景别同向（贴身 ↔ MCU/CU；数步对峙 ↔ WS/FS）。
5. 触达对象开拍已在画且一臂可达；否则先切已锁可见该物的角。
6. 停驻后仍留后续动作净空（贴墙无退路、叠脚无步幅 = 失败）。
7. 路径与终点不越轴（上条）；`守轴核销=` 必填。

**走位细化**（写入 `变化过程` + `终态画面纵深`；【入戏】用自然语言同步写出）
- 有走位：`变化过程=`=`{名}:自{开拍}→经{路径/绕障/门/步数或臂距}→到{终态}｜障=无|{具名}｜绕=无|{具名}之{画左|画右|近镜头|远镜头}｜锚=…｜侧=…｜辅=…｜细节=… 距=…`。相对自/到禁无锚画左/前景。【入戏】须写路径（有障须写出绕过）+停驻后可见面+已锁方式落点。
- 停驻须落点可辨，不得与他人 / 锚混淆。
- 无走位：`走位=无`，场级场记分析 `B{n}` 仍复述终态关系；**入戏不复述**。
- 多门：入=`门位→落点/座位`；出=`舱内位→门位→门外落点`。

## 4. 定位成稿（执行已锁方案）
抄【主体定位方案】/本拍【Beat主体定位】。不改方式。入戏不写 XOR 键。缺项或度数/`F≈`=失败。
- **相对**：选锚优先唯一件（该功能全场仅 1 具的门/桌/柜/沙发）。唯一 ENV 参照物已由参考图/主环境定位 → **只写锚名，禁复述其扇区/中心/前后左右**。同质多件须**先建置该参照物** `远镜头第N排｜画左起第K/M个`，再写角色相对该具名锚。`锚=`具名大件｜`侧=画左|画右|上|下+近|远镜头`（须带锚名）｜`辅=主位|客位|左长边|右长边|近门一侧|床头|床尾`｜`细节=`第K/M把椅旁|上 / 离镜几步。禁只写「靠桌」。多人同桌 K 不重复、`1≤K≤M`。
- **绝对**：`前景|中景|后景` + `画左|中央|画右` + `高|平|低`，与本拍`主体落点`同向。
- **封闭**：`排=近镜头第N排|第N排椅背朝镜头|第N排面朝镜头` + `座=画左起第K/M个`（可兼功能名）。反打重写排与 K。
- **配饰**：`挂靠={角色}`｜`部位=左肩|右肩|左腰|右腰|胸部上方|左手|右手`｜`体侧=正面|侧面|背面`。
同句禁叠无锚绝对 + 相对锚。每人另写与相关人前后左右+距离。

**可见面整句**（键值可留场记；正文必写）：
| 档 | 须点名 |
| :--- | :--- |
| 正面 / ¾ | 哪侧脸、胸腹是否朝镜、双眼/口型是否可读 |
| 左侧面 / 右侧面 | 哪一肩、哪一侧颊/鼻梁轮廓朝镜 |

## 5. 朝向与镜头可见面
档位：角色 = `正面/¾`｜`左侧面`｜`右侧面`｜`背对/侧背面`。载具 = `车头/车尾/左/右侧身朝镜头`｜`¾车头/¾车尾`。动物 = 身躯镜头可见面 + `头朝{对象|左|右}`。

**朝向禁角度**：只写 `面向{具名对象或锚}` + `镜头可见面` 档。禁 `面向N°` / `F≈`。

**转身过程拍**：入戏出现转身 / 转面 / 调头 → `拍型=转身过程`。建置 = 旧档；入戏只写连续转体；终态 = 新档。禁同拍开口 / 走位 / 取物。五件套 = `向{左|右}肩转 → 终态面向{对象} → 终态镜头可见面 → 终态姿态 → 终态锚侧或绝对层位或封闭排座`。禁写转了多少度。轴未变可同父 ENV。

**切角只换观察向**：未走位未转身者，相对锚名 / 辅边位 / 面向对象 / 姿态不变（画左↔画右、近镜头↔远镜头随观察向对调）；绝对层位与画左右按对向对调（反打：前景↔后景、画左↔画右）或按已锁取景重写。镜头可见面必须按新观察向重写（正面↔背对、左侧面↔右侧面）。禁经世界扇区 / `F≈` 换算。

**朝向三联**：正面 / ¾ 若写 `面向{对象}`，对象须更近镜头；背对则对象须更远。同层面向：相对角色写 `面向{具名}`，禁 `面向画左/画右`，禁 `面向N°`；仅绝对同层才写画左 / 画右或镜头向。

**落笔序**：定面向对象（具名） → 写镜头可见面档与自然语言 → 写已锁方式落位（锚侧 / 绝对层位 / 封闭排座） → 速查抄面向 + 可见面 + 落位（不抄度数）。

**反打 ≠ 转身**：反打时未转身者面向对象与姿态不变，镜头可见面随观察向对调。对向反打：正面↔背对、左侧面↔右侧面；绝对层位前景↔后景、画左↔画右。轴心可仍中央。来源 = 上拍终态。相对锚名与辅边位不改写，只对调画左/画右与近/远镜头。

**朝向承接**：无转身过程拍则开拍面向对象 + 姿态 = 上拍终态；镜头可见面可随已锁观察向重写。

**背对门禁**：背对禁写五官 / 口型 / 胸腹正面与 `对镜头`。须读脸 → 已锁可读角的下一拍再写。

**入画径向**：后景门入 → 朝镜头 → 终态正面（背对门）；近端门入 → 向纵深 → 终态背对。

**驾驶舱可见面**（无转身、全员面向驾驶台 / 前窗）：

| 当前 ENV | 可见 | 后景 | 不可见 |
| :--- | :--- | :--- | :--- |
| `0度` 贴操纵员后脑 | 操纵员后脑 | 前窗 / 驾驶台 | 其身后人员 |
| `0度` 舱尾望前 | 全员后脑 | 前窗 | 任何人脸 |
| `180度` 拍后方人员 | 后方人员正面 | 后窗 | 操纵员；前窗 |
| `90/270` | 近侧门窗 + 全部座位侧面 | 对侧窗 | 半舱漏座 |

禁 `0/180` 标后排 + 司机 Two-Shot。`180度` 后方人员可写 `面向镜头正中`，面向仍是驾驶台 / 前窗，禁写 `F≈0`。

## 6. 空间执行
- **出入舱**：入舱过程拍仍挂仓外衍生；落定后另起拍，触发 = `入舱切主环境`，ENV = `{N}度{仓内主名}`。出舱落定后另起拍，触发 = `出舱切主环境|回切仓外主环境`；建置 = 所经那扇门外侧旁，载具外部整体入画；下一拍抄同扇门旁落点。
- **多门路径**：入 = `门位→落点/座位`；出 = `舱内位→门位→门外落点={外部本体}之{门位}外侧旁`。
- **触达**：接触对象须在开拍可见集且一臂可达；否则先切已锁可见该物的角。
- **载具**：入戏只写运动 / 操作事件；途经、停靠、上下车起终点进建置 / 终态。
- **门窗开关（评估；有则强制）**：先读环境规划已锁的该扇 `开闭/开向/门轴/把手` 与文戏开闭过程。建置写出该扇**开拍开闭态**（≡上拍终态或环境初始）。本拍入戏有开/关/推/拉 → 须写清接触点+开向+结果，句式=`在{门名}{左|右}{上|中|下}部{向内|向外}{打开|关上}`（把手抄环境锁；开向抄环境锁；手/推拉承接文戏，不改写）。例：`CHAR:[@甲]右手在大门左中部向内推开门`；`CHAR:[@乙]左手在窗右下部向外推开窗扇`。开拍已全开禁再写打开；开拍全关禁写门后可见内容；过程须从建置初态推进到终态开闭。进出起终点进场记分析，终态须更新该扇开闭态。❌只写「开门/推门」无接触点无开向｜❌手摸到门轴侧｜❌向内锁却写成向外开。
- **已锁 OTS / 正反（建置写清）**：`关系角=` / `OTS类型=` / `近侧框主=` / `主拍对象=` 只执行已锁拍摄键，写入【建置】首句，禁改档。

| 已锁类型 | 建置须成立 | ENV |
| :--- | :--- | :--- |
| **读对手 / 反打** | 越过近侧肩/腰/身看对方脸；背景半空间对向 | 挂已锁对向 `{N}度…`；禁同父冒充 |
| **同侧过肩** | 近侧只作框，不换对手可读面、不改背景扇区 | 同父 ENV；禁标反打 |

`关系角=过肩|过腰|OPC` 时【建置】四要素缺一失败（肩主=`近侧框主`；主拍=`主拍对象`）：
1. **过谁**：前景框主具名
2. **框主可见面**：左侧面｜右侧面｜正面｜背面
3. **左/右肩**（过腰=左/右腰侧）；与画左右、轴线留白自洽
4. **看谁**：主拍具名 + 其正/侧/背面

句式：`过 CHAR:[@甲] {可见面}{左|右}肩 → 看 CHAR:[@乙] {正/侧/背面}`。
- ✅`过 CHAR:[@林] 右侧面右肩 → 看 CHAR:[@陈] 正面`
- ❌`过肩看陈`（缺框主可见面 / 左右肩 / 主拍镜头可见面）
切角时未转身者面向对象与姿态不变，镜头可见面随观察向对调（§5 反打≠转身）。
**切主 ≠ 反打**：`闪回切主环境|蒙太奇切主环境|回切当下主环境|入舱切主环境|出舱切主环境|回切仓外主环境` 不标反打。前向驾驶舱 `0度↔180度` = `同向驾驶舱读角`，不得当厅堂反打（`180度` 不得保留前向操纵员在画）。出入舱后禁仍挂舱外 ENV 写舱内戏。

可见三态：`V` 可写可见面；`D` 只写朝向 / 声音 / 画内受力；`X` 禁入建置 / 入戏，进差集。
