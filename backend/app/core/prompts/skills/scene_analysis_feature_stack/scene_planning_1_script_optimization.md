## 核心任务
**【环节】**三阶段中的剧本优化/继承扩写/可拍化生成。  
**【目标】**零遗漏继承 + 结构强化 + 合理改写 + 可视化前置 + **补全微表情与微动作**（让剧本与主动作更有表现力，让对白—反应—动作链更具连贯性）+ **剧情叙事连贯**（用对白、反应、OS/V.O.、道具与转场情节桥梁完整表达因果与信息，禁断层与脑补）。  
**【覆盖】**剧情结构、**叙事因果与信息承接**、站位调度、**微表情/微动作/微反应补全与动态过程链**、**对白—反应—动作连贯衔接**、每场细节特写、对白情绪标点与节奏、题材适配表情（喜剧夸张/情感细腻）、心理外化、风格视觉化、动作细分、**AI视觉特效强化**、**武打/特效/正式决战/宏观群体场面规划**、对白与 `OS/V.O.`、环境补充、节奏转场、全员反馈闭环、**视频时间控制下的 Beat 数量与等效时长规划（§28）**。  
**【边界】**不改原剧情事实、核心动作链、对白语义、人物关系；不得新增改变因果的新事件。**环境仅写空间骨架**（实体清单、360 度拓扑、剧情相关尺度/形状/相对位置），**禁止**写材质/光源/声场/色彩/氛围（归 Skill 1-3）。**禁止**在本阶段输出或使用 `ENV`/`PROP`/`CHAR` 资产分类标签及 `ENV:`/`PROP:`/`CHAR:` 前缀；仅以剧本自然语言具名称呼人物、物件、空间；是否提取为资产、`ENV/PROP` 归属、升格归档与衍生变体均由 **Stage 2-1** 裁定。  
**【允许】**影视化插入：特技呈现、**AI可拍特效奇观**、环境描述、微反应、微表情/微动作、细节特写、动作拆解、对白停顿与颗粒度细分、**按情绪补标点控节奏**（不改对白语义与剧情信息）。  
**【AI优势】**轻功/御剑/空战换招｜宏观无边际阵列(大军/对阵/兽潮/机群/舰队)｜超大尺度/微观/能量/多主体同帧；仙侠/武侠/玄幻/史诗优先高成本奇观(垂直空域/域场/法相/地平线满编/压迫推进)；可增补特效，不改因果。  
**【输出】**`Scene切分`、`环境/衍生环境说明`、`[ADAPTED_SCRIPT]`、`project_visual_backfill(JSON, 强制)`。

## Beat 完整逻辑（强制，逐 Beat 不可跳过）

**每个【动作/视觉节拍】均须按下列逻辑完整执行**；**前置 + 六环节**彼此咬合、缺任一即 Beat 不合格。细则分别见强约束 §5/§6/§11/§12/§13/§25/§28 与 §二/§四。

| 顺序 | 环节 | 强制内容 |
| :--- | :--- | :--- |
| **0（前置）** | **参考前一 Beat 全体站位** | **Beat 2 起**：动笔前先读取**上一 Beat 终态**——全体在场人物/关键道具/群演簇的 FG/MG/BG 逐实体落位（七要素）、持握/佩戴、环境名与观察视角；本 Beat 环节 1–3 须在此基准上演化，位移/入出画/环境切换须写清变化依据；禁止无承接瞬移或全员复位。**Scene 首 Beat**：读 Scene 开场建置或**上场承接**（§一-B Step1）；**转场专拍 Beat**：读前后咬合 Beat 的终态/起势。 |
| **1** | **观察视角—环境—建置** | 先写观察视角（环境+观察起点+角度+目标+可见边界），再写当前环境；**落笔当前环境前须完成环境—视角匹配自检（§12）**——OTS/正反/POV/门窗内外等须切至匹配衍生环境，禁止主环境错配；视角变化须触发建置重评估（§12、§14）。**无对白武戏/决斗/术法/追逐 Beat 与对白 Beat 同等强制**：逐 Beat 须写清**背景（FG/MG/BG）变化、各参战者朝向四要素、观察侧切换、双人/多人入境与环境切换**（细则 §二「武戏视角—环境—朝向」、§12）；禁止只写招式名/特效名而省略视角—环境—建置三联。 |
| **2** | **FG/MG/BG 三层 + 逐实体落位** | **先**写 FG→MG→BG 框架（结构+层间关系），**再**每层内对**每一个可见实体逐个、具名**写清落位；**人物建置须同步写清位置 + 身体朝向 + 相对当前 Observer View 的正/侧/背面 + 与他者/物件的朝向关系**（§11「角色建置朝向四要素」）；禁止跳过三层或合并为「两人/若干道具」（§11、§13、§16）。 |
| **3** | **立体三轴 + 运动方向与朝向 + 动作方式** | 每个实体须写：**立体三轴位置**（层位 FG/MG/BG + 左/中/右 + 距参照物 + 必要时垂直上/中/下即高/中/低）；**运动方向与朝向**（静止：身体/物件/载具面向；移动：行进/飞行/车体轴向 + 轨迹节点，每节点 FG/MG/BG+左中右+必要时上中下）；**视角正背面**（人物/载具/正方向物件相对当前 Observer View 哪一面朝向镜头——正面/背面/左侧面/右侧面/四分之三面，及该面是否可读）；**与他者/物件朝向关系**（面向/背对/侧对/同向/相向/对峙/跟随/隔障相对等，须锚定具名他者或 ENV 结构）；**视线/传感落点**（七要素分列，看谁/看哪）；**动作方式**（姿态/接触/发力/力度/速度/节奏/变向/受力或静止）。均须符合 §11 立体三轴口径。 |
| **4** | **对白咬合 + 情绪层** | 每句画内对白/OS/V.O./独白/自白须写：**说话人**三轴落位 + 面向与视线指向**主听众或被点名对象**（自白/独白见 §四「自白/独白全员闭嘴」）；**情绪层**（voice_type/tone/speed/volume + 情绪标点，§四）；**主听众/听者**面向+视线（看谁/回避/侧听/群听）及闭口/微反应；**自白/独白 Beat 强制**：除发言人外，画内**每一个可见角色/群演簇**均须写**闭嘴**（双唇紧闭/口型静止/未张嘴/唇线抿合），【全员反馈】逐人/逐簇核销，禁止遗漏或他人同步张嘴；Walk-and-Talk 逐句同步三轴+运动方向与朝向（§11 对白咬合）。**有动作+对白角色**：建置时须为该角色确认与落位/面向/视线一致的**当前环境**（主或衍生）；主动作起势、位移、递交/接触及每句对白落点若改变观察侧或可读性，须**同步环境切换**并重写三层，使站位与剧情要求一致（§12「有动作+对白角色环境绑定」）。 |
| **5** | **微动作 + 微表情（动作/对白配套）** | **每个主动作、每句对白、每个听者/触发者反应**均须各含 ≥1 **微动作** + ≥1 **微表情**，按 `部位 → 起始态 → 变化方向/幅度/节奏 → 落点/余韵` 动态过程链书写；视线/头颈/肩线/肢体位移的变化方向须写清立体三轴（§5）。长对白每 2–3 句至少 1 处组合切口；禁止只写对白/动作而无配套表演层。 |
| **6** | **表演连贯 + 全员反馈** | 承接上一 Beat **表演**落点/余韵（环节 0 已承接空间站位）；状态跳变须有触发；对白后必有听者动态反应再入下一句或主动作（§6）。画内可见角色对发言/动作/环境刺激须有动态反馈；群演簇写统一/随机反馈。**自白/独白 Beat**：【全员反馈】须逐人/逐簇写除发言人外的**全员闭嘴**（§四）。 |

**Beat 成稿前核验（强制）**：**⓪ 是否已读取上一 Beat（或 Scene 首 Beat 之开场建置/上场承接）全体站位终态，且本 Beat 落位/位移有变化依据** → ① 观察视角与环境、三层建置是否同拍咬合，且**当前环境已通过环境—视角匹配自检**（OTS/正反/POV 等已切对衍生环境，非主环境错配）；**环境切换后建置是否与当前环境实体安排一致、动作可执行**（§12 可执行性校验） → ①-b **有动作+对白角色**是否已在建置时为该角色配置匹配环境，且主动作/各句对白落点已按需切换 ENV、落位与面向/视线仍符合站位与剧情（§12「有动作+对白角色环境绑定」） → ①-c **武戏/决斗/术法 Beat（默认，与对白同等粒度）**：是否已**逐 Beat**写清**背景层（FG/MG/BG）相对上一 Beat 的变化**、**各参战者角色建置朝向四要素**（含相对 Observer View 正/侧/背面及可读性）、**OTS/正反/POV/Two Shot/Insert 等观察侧**及切换触发；双人/多人场是否已写**双人入境/出画**（径向、落位、面向、ENV）；各参战角色相对上一 Beat 终态是否均有**可核销的三轴落位变化**（跨 FG/MG/BG、绕障/换侧、逼近/退离、腾空/落地、越轴换位等）；位移/观察侧/可读性/域场态变化是否已写清切换触发→衍生/状态环境名→空镜差异→**建置重建**（§12、§14）并通过可执行性校验；**禁止**多 Beat 复用同一固定站位+同一观察侧+同一 BG 硬写换招/格挡/闪避/术法而无位移、朝向更新与建置更新（§二「武戏视角—环境—朝向」） → ② FG/MG/BG 各层内是否**每个实体**均已逐个写清三轴位置 → ②-b **每个画内人物**是否均已写清**角色建置朝向四要素**（位置｜身体朝向｜相对 Observer View 正/侧/背面及可读性｜与他者/物件朝向关系）→ ③ 每个实体是否均已写**运动方向与朝向**及**动作方式**（含力度/速度等，移动者含轨迹节点），且**每个角色前后位置已标明参照系（相对镜头 / 相对 ENV / 相对实体）** → ③-b **正方向物件**（手机/平板/相框/证件/屏幕等）是否已写清**位置依附 + 正面（屏幕/封面/图文面）相对谁/镜头/ENV 的朝向 + 当前视角哪一面可见/是否可读**（§二「正方向物件」） → ③-c **景深遮挡与层间距离**：MG 遮挡体是否阻断 BG 可见性（闭合门/实墙等占满视轴时 BG 是否误写不可见实体）；FG↔MG↔BG 较远跨度是否已写清层间距离；景别/景深是否与各层可读性一致（§14） → ③-d **门窗 Beat（错误高发区）**：凡涉及门/窗/门槛/门柱/窗框/百叶/推拉门等，是否已**动笔前**完成 §二「门窗 Beat 专项评估」五维核验（开向方向｜内外侧 ENV｜遮挡不可见｜通行阻碍｜视轴读写）；门扇开闭态变化是否跨 Beat 承接 → ③-e **跨 Beat 角色可见性与面部可读性过渡（§11）**：逐具名角色对比上一 Beat 与当前 Beat——**画内可见状态**（可见↔不可见）与**面部可读状态**（口型/眼神/微表情可读↔背对/遮挡/虚焦不可读）是否发生变化；任一维度变化是否已在两 Beat 间写清**出画/入画/转身别脸/低头抬脸/遮挡/视角切换/切 ENV 反打**等过渡动作，且 `[Beat切换说明]` 已核销；禁止同视角同站位下角色凭空消失/出现，或面部可读性无动作跳变 → ④ 有对白时**对白咬合**是否成立 → ④-b **自白/独白 Beat**是否已在【语言】标注类型，且画内**除发言人外全员闭嘴**已在【全员反馈】逐人/逐簇写清（§四「自白/独白全员闭嘴」）→ ⑤ **每个动作与每句对白**是否均有配套微动作+微表情 → ⑥ 表演连贯与全员反馈是否闭环。

| **门窗 Beat 五维评估** | 环节 1–2 / §二 | **错误高发区**：涉及门/窗/门槛等 Beat **动笔建置前**须完成开向方向｜内外侧 ENV｜遮挡不可见｜通行阻碍｜视轴读写五维评估；见 §二「门窗 Beat 专项评估」 |

| **自白/独白全员闭嘴** | 环节 4 / §四 / 【全员反馈】 | **自白**（面向自我/镜头/空位的画内或 OS 独白）与**独白**（内心 OS/V.O./画外心理旁白）Beat：**除当前发言人外**，画内每一个可见具名角色与群演簇均须写**闭嘴**——双唇紧闭/口型静止/未张嘴/唇线抿合；禁止他人写口型变化、接话、同步张嘴；OS/V.O. 类发言人亦**无画内口型** |
| **有动作+对白角色环境绑定** | 环节 1–4 / §12 | 同时承担具名主动作与画内对白/OS 的角色：建置时确认匹配 ENV；动作/各句对白落点随观察侧与站位变化**同步切换** ENV 并重写三层 |
| **武戏/攻防视角咬合** | 环节 1–3 / §二 | 无对白决斗/术法/追逐 Beat：**观察侧+当前 ENV+FG/MG/BG 背景+各参战者朝向四要素**须与同拍主动作/攻防关系咬合——读招/读势/读术法须 OTS 或正反切至可读侧；主动作发起方与受击/格挡/闪避方须写清**与他者朝向关系**（相向/侧对/背向威胁等）；切视角后须重判视角正背面与 BG 可见半空间 |
| **环境切换建置可执行性** | 环节 1–2 / §12、§14 | 切换 ENV 后建置须符合当前环境实体安排；落位/动作须可拍可行；冲突则修正动作→落位→环境设置 |
| **跨 Beat 角色可见性过渡** | 环节 0–3 / §11 | 相邻 Beat 间具名角色**画内可见↔画外/遮挡不可见**，或**面部/口型/眼神可读↔不可读**（含背对、别脸、低头、肩/手/发丝遮挡、虚焦等）变化时，**必须**写可拍过渡动作；`[Beat切换说明]` 须核销；禁止同视角下凭空消失/出现，或同站位下面部可读性无过渡跳变 |

## 强约束
1. **零遗漏继承**：逐句核销；动作/暗示/过渡台词/背景设定不得跳过。  
2. **剧情叙事连贯（强制）**：每场/每 Beat 须可回答「谁—欲何—阻何—已知—将变」；跨 Beat/Scene 动机、筹码、关系、前情与后果须通过对白承接、听者反应、OS/V.O.、道具状态、转场**情节桥梁**显性传递，禁只写表演/空镜而无剧情信息落点。  
   - **对白承载剧情**：台词须推进立场/筹码/关系/前因/后果；>20 字拆句时插入听者反应或说话者动作切口，使信息递进可读；禁装饰性流水账与旁白硬灌。  
   - **省略/跳转补偿**：时空省略或跳转时，须写 `情节桥梁` 与（若需）`信息补偿`；新信息须有铺垫或当场交代来源；关键转折禁只靠动作不写台词。  
   - **场间接续**：Scene 首 Beat 须回扣上场退出状态（对白/反应/OS 均可）；Scene 末 Beat 须写清本场剧情推进与角色立场/关系变化落点。  
3. **心理可视化**：心理必须转译为微动作、微表情、道具接触、空间反馈。  
4. **创作**：结构、站位、微表情/微动作/微反应、每场细节特写、风格视觉化、**主动作归属主动施力方（被动物件轨迹与纯粹受力位移写入同 Beat，禁止客体/纯粹受力独立成 Beat）**均在本阶段完成；**每个 Beat 须完整执行「Beat 完整逻辑」前置 + 六环节**；Beat 2 起须先完成环节 0「参考前一 Beat 全体站位」，即使原剧本已有场景分镜等的划分，也要遵守以下规则进行创作。  
5. **每场细节特写（强制）**：每个 Scene **至少 1 处**；须写清特写对象、可见部位、**变化过程**、叙事功能、承接 Beat；禁止整场无特写切口。落点优先：情绪转折/信息落点、长对白停顿与听者反应、道具线索/环境纹理、武戏接触受力瞬间。  
6. **微表情+微动作双轨（强制）**：= Beat 完整逻辑环节 5；下列为动态过程链写法与密度补充。每个【动作/视觉节拍】除主节拍外须各含至少一项微表情与微动作；**每个主动作、每句对白、每个听者/触发者反应均须配套**。均按**动态过程链**书写：`部位 → 起始态 → 变化方向/幅度/节奏 → 落点/余韵`；涉及视线/头颈/肩线/肢体位移者，**变化方向须写清立体三轴（横向左中右 + 纵深 FG/MG/BG + 必要时垂直上中下/高中低）**；禁止静态定格式。长对白/停顿处优先插入组合切口；**原文未写但情绪/信息/动作链需要处须主动补全**，不得留表演真空。  
7. **表演连贯性（强制）**：= Beat 完整逻辑环节 6；**空间站位承接**见环节 0。下列为表演层补充：相邻 Beat、台词轮次与主动作须**承接上一表演落点/余韵**；对白后必有听者/触发者动态反应，反应后再入下一台词或主动作，禁止对白—反应—动作链断层。跨 Beat 持续情绪须写渐变或保持态；状态跳变须有触发交代。主动作起势须呼应前一 Beat 身体姿态与视线；武戏形体链与微表情/微动作同链咬合，禁止 Beat 间表演层断裂或情绪复位无依据。  
8. **原文点出表演层（特别提醒）**：原文明确写出或强暗示的表情、神态、视线、呼吸、手部/肩颈/喉结细部、停顿反应，须**逐项核销并可视化动态改写**进【动作/视觉节拍】/【语言】/【全员反馈】；禁止遗漏、合并吞掉、仅留对白删表演层，或压成静态形容词。改编前先建**核销清单**（原文表述 → Beat 落点 → 动态改写）。  
9. **Scene切分**：按连续时空+同叙事目标划分；**以原文/上游 Scene 切分为首要依据**，不得为闪回/蒙太奇/补足视觉而自创 Scene（见§三「闪回三档判定」）。时间跳跃/空间跨越/闪回蒙太奇/目标切换/行动线切换**且原文或上游已切分或具独立场次结构**时方可新 Scene；**完整闪回/回忆段落不必然拆独立 Scene**——原文嵌于单场、无独立时空切换、或叙事目标仍锚定当下场时，优先 Scene 内**转场专拍 Beat**/**快速闪回**承载。**快速闪回**（短促回忆对话/有情节画面切片，叙事目标仍锚定当下场；**仅当待呈现回忆对白合计 >30 字**，见§三）不新建 Scene；**无情节回忆切片**（仅印象/情绪/物象触发、无具体对白链与动作情节，见§三）不新建 Scene，**并入相邻 Beat 转场链**或短转场专拍，**不受 >30 字门槛约束**；仅视角/构图/特写/正反/节拍变化不新建 Scene。  
10. **环境定义**：环境=可复用拍摄空间的**空间骨架**，按空镜写：边界、内外/日夜、空间基准点、**应存在的固定实体清单**、与剧情相关的**尺度/形状/开合/相对位置**、阻隔、通行路径、景深层次（FG/MG/BG 空间层）。**禁止自创环境（强制）**：主环境命名、360 度拓扑与固定实体清单须以原文明示/强暗示或可核销的上游信息为依据；**禁止**为闪回/回忆/蒙太奇/补足视觉而新增原文未出现、无强暗示支撑的地点、房间或独立空间实体；回忆时空若原文未具名空间，不得虚构完整 ENV，改用质感区分+印象级落点（见§三无情节切片/快速闪回），或复用 Index/上游已有环境条目，不得 Stage 1 凭空命名新地点。**本阶段环境描述边界（强制）**：只明确**该有的实体**及**剧情需要的尺寸、形状、开合状态、相对方位**；**禁止**写材质、纹理、工艺、配色、光源/灯光设计、声场/声源设计、氛围形容词、色调/色温/明暗美学、生图级光学与色彩参数。**门窗等可开合构件（强制）**：凡清单、360 度拓扑或实体关系中出现**门/窗/柜门/推拉门/百叶/阳台门/窗洞/玻璃幕墙开口**等，**必须写明开闭状态**（紧闭/半开约几度/全开/合拢/开启等），禁止只写「有门/有窗/门口/窗边」而不交代是否闭合。**有正反面/使用面的实体（强制）**：门扇/窗扇/柜门/屏风/柜台/祭案/讲台/招牌/长桌/床/沙发/椅子等具**正面/背面/内外侧/显示面/座次面**差异者，**必须写清哪一面为正面、哪一面为背面/背板/室内侧/室外侧/椅背/椅面/桌头/桌尾/主位/客位**，及相对空间基准或另一具名实体的朝向；禁止只列物件名而不交代正反与开合。**❌「旧木会议桌、黄铜台灯、冷蓝雨夜映亮百叶窗」**｜**❌「BG 有木门和窗户」**｜**✅「MG 会议桌居中（长边约 2.4m）；两把转椅分列桌左右；BG 文件柜贴 180 度墙段；BG 半开内开木门（180 度墙段中央，门轴右侧，门扇向室内开启）；BG 紧闭百叶窗（270 度墙段）；0 度为桌长边侧面 Two Shot」**。内外/日夜仅写时空调度所需（内/外、日/夜/晨/昏），不写光照氛围。**材质/光源/声场/色彩/生图提示词的技术化设计**由 Stage 2-1 写入**文学氛围**、由 **Skill 1-3 `entity_design_environment_and_poster.md`** 转译为技术参数，本阶段不得越权代写。主环境 360 度拓扑的 **0 度正面** 须与 Scene **开场建置/首 Beat Master 视角** 同轴对齐，不得按建筑方位、默认进门方向或随意选墙当 0 度。须先判定本场开场人物关系与核心舞台（桌面对坐、并排同向、门内外对峙、舞台面对观众、床侧陪护、柜台内外服务等），再据此确定 0 度观察基点与空间基准实体。**典型**：开场两人在桌前对坐/对谈 → 0 度须取**桌子长边侧面视角**（Two Shot 轴线：左右分置两人、桌面作中轴），禁止把桌头/桌尾单人正面或背墙当 0 度；并排同向看窗/银幕 → 0 度取共同正面或侧面 Master；门内外首镜 → 0 度取门槛轴向或首 Beat 实际 Master 侧。**360 度坐标系定义（强制，先于拓扑书写）**：
  - **0 度是什么**：0 度 = **摄影机观察方向（Viewing Direction）**，不是建筑真北、默认进门方向或随意选墙。**0 度观察基点** = 本 Scene 开场建置/首 Beat Master 视角的机位落点 + 朝向；须显式写清「观察起点（站在/位于空间哪一侧/哪段）→ 朝向（看向哪一侧/哪段）」。
  - **角度递增方向**：90°、180°、270°、315° 等均为**顺时针**递增——**站在空间内俯视**，从 0 度正面沿顺时针扫视各方位；**禁止**混用逆时针标注或左右与顺逆不一致。
  - **各向可见/不可见对照（强制）**：360 度拓扑**每个方位**除写该方向存在的固定结构/景物/出入口外，须标注相对**主环境 0 度**的可见性关系——**0 度可见 / 0 度不可见（位于机位后方或被遮挡）**。**180 度方位须特别写明**：此为 0 度**对侧半空间/背面**；若切至 180 度衍生视角，其 BG 通常应呈现 0 度时位于机位后方、被主体遮挡或不在画内的背景内容（如 0 度 BG 的百叶窗墙，在 180 度视角可能变为机位后方不可作当前 BG，而 0 度不可见的入口/对侧墙段变为 180 度 BG）。
  - **方向性物体朝向随视角调整（强制）**：椅子、沙发、床、长桌/会议桌/餐桌、门/窗/柜门、屏风、柜台、祭案、讲台、台阶、主位/客位/上首/下首等具有正面/背面/开合/使用朝向/座次指向的固定物，在 360 度拓扑与各 Beat 建置中须**具名 + 写清朝向 + 写清开闭态（门窗等）+ 写清正反面/内外侧/使用面**；切至衍生视角（尤其 180 度/越轴）时须**按当前 Viewing Direction 重判**可见面（椅背/椅面、门扇开向与铰链侧、窗扇/百叶开闭与可见侧、桌头/桌尾/主客位、床头/床尾、柜台内外/正背、屏风正背面、牌匾文字面），禁止沿用 0 度朝向描述导致左右/前后/可见面自相矛盾；**禁止**只写「有门/有窗/有屏风」而不写紧闭/半开/全开及正反面。
**主环境须写清 360 度方位拓扑（强制）**：以已锚定的 **0 度观察基点与 Viewing Direction** 为原点、**顺时针**标注各方向存在的固定结构/景物/出入口及**相对 0 度的可见/不可见标注**——至少写清 0/90/180/270 四向，复杂或需 45 度倍数切镜的空间须补全 0/45/90/135/180/225/270/315；该拓扑为全场视角衍生之唯一空间坐标源，禁止各 Beat/各衍生视角出现拓扑矛盾。**剧情相关固定实体须写清 FG/MG/BG 及实体间前后左右关系（强制）**：凡与剧情交互、站位、动线、视线、攻防、遮挡、对峙/座次直接相关的固定结构/家具/陈设（如桌、椅、床、柜台、门扇、屏风、祭案、栏杆、台阶、文件柜、白板等），除各自所属前/中/后景层次外，须**依据剧情**写清相对另一具名环境实体的方位——如椅子在桌子哪一侧/哪一头、门在墙的左段还是右段、屏风相对主舞台的左右与前后面；禁止只列物件名而不交代相互空间关系。**方向性实体具名+朝向+开闭态（强制）**：椅子、门/窗/柜门、长桌/会议桌/餐桌、主位/客位/上首/下首、沙发、床、屏风、柜台、祭案、讲台、台阶等具有正面/背面/开合/使用朝向/座次指向的固定物，清单与 360 度拓扑中须**具名并同步写朝向、开闭态与正反面**——门/窗/柜门/百叶等须写**紧闭|半开|全开**及**内开|外开、门轴侧**；具正反面的须写**正面/背面/内外侧/椅背/椅面/桌头/桌尾/主客位/文字面**相对谁或朝哪；禁止只列「椅子/门/窗户/桌子」。❌「办公室有桌子和两把椅子」｜❌「BG 有木门和百叶窗」｜✅「MG 会议桌居中（长边沿 0 度 Two Shot 轴，桌头朝 90 度）；主位转椅（MG 桌左，椅背朝桌心、椅面背对 270 度墙）；客位转椅（MG 桌右，椅背朝桌心）；BG 半开内开木门（180 度墙段中央，门轴右侧，门扇向室内开启）；BG 紧闭百叶窗（270 度墙段，叶片合拢）」。纯装饰性、无剧情交互的远景点缀可只写层位与分布区段。思考时可先用“主锚点”定空间原点，成稿须写为具体空间结构具名部位（如「会议桌右前角」「文件柜门扇」）。人物与可交互物件以剧名/物件名书写，**不预做资产分类**；会被拿起/递交/移出/破坏/独立展示或跨 Beat 承接状态的物件须写清可拍动作证据；**正方向物件（手机/平板/相框/证件/屏幕等）须同步写清手持或静置时的正面朝向与当前视角可读面**，归属由 Stage 2-1 裁定。  
11. **主/衍生环境**：每个 Scene 1 个主环境（**0 度须对齐开场建置 Master 视角**，见 §9；**须含完整 360 度方位拓扑**）。定主环境前须先完成 **Scene 开场人物建置预判**（§15 三步之建置段、§16 实体覆盖）：主环境 0 度 = 首 Beat 0 度 Master/Two Shot 观察轴，而非事后硬套。**❌ 开场桌面对坐，却把 0 度定为从文件柜墙正面看、只看见单人椅背**｜**✅ 开场桌面对坐，0 度取桌子长边侧面 Two Shot，0 度左/右为桌两侧就座区，90/270 为桌头/桌尾，180 度为对面背景墙/窗**。衍生环境分两类，须分别扫描，不得互相替代：
  - **视角衍生**：依据剧情/观察视角，判定相对主环境 0 度的**顺时针转角度数** `N`（通常取 45 度倍数：`OTS`、门窗内外、屏幕内、镜中、遮挡后、画外声源等触发）；命名 `{N}度{主环境名}`，冲突时追加 `_{衍生类型/观察区域/可见方向}`。**转角对照（强制）**：`N` 度衍生环境的 **0 度正面** 必须严格采用主环境 **360 度拓扑中 N 度方位** 的描述作为该衍生环境的正面基准；衍生环境 90/180/270 度依次对应主环境 `(N+90)%360`、`(N+180)%360`、`(N+270)%360` 方位描述，禁止脱离主环境拓扑另造空间或只改方位词而不做转角映射。**OTS/反打环境角判定（强制，禁止盲套主环境+180°）**：OTS/正反/反打衍生角 **不得** 不经判定一律取主环境 0 度 + 180 度。须先依据**被拍对象/对手**在本 Beat 的落位、面向、与说话人/听者的轴线关系，对照主环境 360 度拓扑，判定使该对象面部/手势/武器**可读**的观察角 **N_对手**（相对主 0 度顺时针）；本镜 OTS/反打 ENV 角 = **`(N_对手 + 180) % 360`**。例：对手可读角 90° → 反打 ENV 270°；对手可读角 0° → 反打 ENV 180°；对手可读角 45° → 反打 ENV 225°。上一镜已在衍生角 M 时，切至对手 OTS/反打仍须以**对手可读角**推导目标 ENV，而非「从上一镜 M 再转 180」或回溯盲套主环境 180°；同 Scene 内 A↔B 各 OTS/反打须分别判定并声明对应 ENV，禁止所有反打共用一个 180 度 ENV。**可见性 Delta（强制）**：`empty_view_delta` 须列明相对主环境 0 度**新进入可见**的实体/半空间 + **退出可见**的实体/半空间；**180 度衍生须显式写**：BG 呈现 0 度不可见/被遮挡的对侧内容，0 度 BG 中位于机位后方的结构在本视角转为不可见或仅边缘可见（**N≠180 的 OTS/反打 ENV 同理**：BG 须呈现该角位下相对主 0 度新进入可见/退出可见的半空间，按 `(N_对手+180)%360` 实际角位写 Delta，禁照搬 180 度模板）。**方向性物体（强制）**：衍生视角须按当前 Viewing Direction 重写椅背/椅面、门扇开向、桌头/桌尾、床头/床尾、主客位等朝向，禁止照抄 0 度描述。  
  - **状态/特效衍生**：AI 特效/域场/环境级冲击导致**固定结构、边界或可拍空镜基准**发生**剧烈且可持续**的形态/布局变化，且须**延续至下一 Beat 及后续 Beat**（非纯瞬时光效/粒子/拖尾）时，必须另建状态衍生环境；命名 `{主环境名}_{状态/域场标识}`，如 `侯府正厅_符阵覆盖态`、`实验室_磁暴电离域`；`empty_view_delta` 只写**结构/布局/边界**差异（如地面符纹覆盖范围、柜体倾覆、墙段崩裂），不写光色/材质/声场；状态衍生继承主环境 360 度拓扑与转角映射。  
  - **扫描默认“有”**：每 Scene 必扫 `0/45/90/135/180/225/270/315` 视角衍生；**凡 Scene 含环境级特效/域场/结构破坏再生且余波或后果跨 Beat**，必扫状态衍生。仅“5秒内、极简单轴、少/无对白、无多角度触发、无跨 Beat 环境态变化、无后续切换需求”可写无，须附 `无：否决证据`。  
12. **站位与空间建置（强制）**：= Beat 完整逻辑环节 2–4 的展开细则；**Beat 2 起动笔前须先完成环节 0**（读取上一 Beat 全体站位终态）。文首总纲表为唯一基准，本节为执行层。  
  - **核心定义（先三层，再层内逐个）**：建置与站位须按**固定书写顺序**展开：**① 先建 FG/MG/BG 三层框架**（每层写清结构/边界/框景阻隔与层间关系、**遮挡阻断关系**、**层间距离/空间跨度**；无有效前景须说明原因）；**② 再在每个层位内，对该层**当前视角实际可见**的每一个人物与物体逐个、具名**写清落位。禁止跳过三层直接按人名罗列；禁止只写环境氛围或「两人在桌边对峙」等笼统句；**画内可见主体清单（§16）中的已入场者，须在本 Beat 三层内全部落位**（**§15 远距离/受限 POV 例外**：`全局建置=延迟` 时，首 Beat 仅落位当前 POV 可见/可读者，其余标注待补全 Beat）。群演簇可按簇描述，但须写清簇内人数、分布区段与**运动方向与朝向**（含视线落点）。
  - **立体三轴落位（强制，与原有口径融合）**：每个实体**只做一次**三轴描述——`FG/MG/BG`（纵深，相对镜头）+ `左/中/右`（横向，相对当前观察视角）+ 距参照物（标明相对镜头/ENV/具名实体）+ 必要时 `上/中/下`（高/中/低，垂直高度差）；**禁止**只写 FG/MG/BG 而省略左中右；有站/坐/蹲、台阶/地面/腾空等高度差时须写垂直区段；**禁止**在 FG/MG/BG 三层框架与各层内同一主体落位中重复堆叠同一坐标。

  - **层内逐主体七要素（强制，该层内每个人物/物体各写一遍）**：`[具名主体] + [所属层位 FG/MG/BG（=相对镜头纵深，必填）] + [横向序位（左/中/右）] + [距参照物距离（须标明参照系：相对当前环境结构部位 / 相对镜头 / 相对具名实体）] + [运动方向与朝向] + [视角正背面（相对当前 Observer View：正面/背面/左侧面/右侧面/四分之三面 + 该面可读性）] + [与他者/物件朝向关系（面向/背对/侧对/同向/相向/对峙/跟随/隔障相对等，锚定具名他者或 ENV 结构）] + [面部/视线/传感落点] + [动作方式] + [与他者/环境的空间相对关系（前/后/左右/隔障须写清参照环境结构、镜头纵深或具名实体，禁止裸写「在前/在后」）]`；有高度差时七要素「位置」须同步含垂直上/中/下；**画内人物**须完整覆盖**角色建置朝向四要素**（位置｜身体朝向｜视角正背面｜与他者/物件朝向关系）；有对白时另须核验**对白咬合**（环节 4）；层内缺任一要素即该主体建置不完整。

    - **④ 与他者/物件朝向关系**：相对**具名他者人物、道具、载具或 ENV 结构**的朝向语义——如「面向陈医生」「背对文件柜」「与陈医生相向对坐」「与林医生同向并排看窗」「侧对门扇、背向走廊威胁侧」「隔桌与客位相对」；须锚定参照对象，禁止只写坐标不写相对朝向。

  - **成稿示例（先三层，再层内逐个）**：0 度观察（**桌子长边侧面 Two Shot，对齐开场对坐建置**），办公室会客区。**FG**：无有效近距遮挡。**MG**：**林医生**（MG 相对镜头；相对会议桌左就座区前侧约 0.8 米）：坐姿前倾，**面朝右、四分之三右侧面朝向镜头**，**与陈医生隔桌相向对坐**，视线锁定陈医生，**当前视角可读右侧面与口型**；**陈医生**（MG 相对镜头；相对会议桌右就座区约 0.5 米）：坐姿后仰，**面朝左回视、四分之三左侧面朝向镜头**，**与林医生隔桌相对**，相距约 1.2 米（桌沿隔障），**当前视角可读左侧面与口型**；会议桌长边侧面横贯 MG 作中轴；**MG 与 BG 相距约 3m**（人物—桌—后墙纵深）。**BG**：0 度正面后方为文件柜与白板所在墙面（主环境 180 度方向）；2–3 名办公人员位于文件柜与百叶之间（相对环境），**侧对双人区、同向朝 MG 双人区**，目光朝 MG 双人区。**遮挡阻断示例（对照）**：若本 Beat 为**门内 POV、MG 紧闭木门扇占满视轴**，则 ❌ 仍写 BG「走廊尽头文件柜与办公人员」｜✅ **FG** 内开门框边缘；**MG** 紧闭木门扇占满画面；**BG** 被门扇完全遮挡不可见（门后为走廊+文件柜，本视角不可读，待开门或切至门外衍生环境后可见）。
13. **观察视角—环境—建置三位一体（强制，Beat 粒度）**：= Beat 完整逻辑环节 1；与 §11 建置、§14 重评估配套。每个 Beat **必须先写清观察视角**，再写环境与 FG/MG/BG 建置；三者同拍咬合，禁止只写动作/表情而隐去观察侧。  
  - **Beat 视角必填项**：当前环境名（主或衍生）、观察起点、观察角度（0/45/90…度或 OTS/正反/POV/插入特写等）、观察目标、可见范围边界（画内可见 vs 画外/遮挡）。  
  - **环境—视角匹配自检（强制，写清「当前环境」前必做）**：  
    1. **判观察角度**：本 Beat 是 0 度 Master / OTS·过肩 / 正反打 / POV / 门窗内外 / 镜中·屏幕内 / 插入特写 / 状态域场等？  
    2. **判环境是否匹配**：当前应写**主环境（0 度基准）**还是**视角衍生** / **状态·特效衍生**？  
    3. **不匹配则须切换**：写环境切换（触发 → 角度/域场 → 切至/返回环境名 → 空镜差异 → 下一节拍承接），`建置更新=是`，并触发 §14。  
    - **典型须切换（禁止仍用主环境硬写）**：**OTS/过肩**（如林医生右后侧 OTS 看陈医生正面；**决斗中甲肩后 OTS 看乙读招/乙肩后 OTS 看甲受击**）→ 须切对应角度衍生环境，**先判对手可读角 N_对手，再取 `(N_对手+180)%360` 为 ENV 角**（如 0 度 Two Shot 下陈医生正面可读角 180° → `180度办公室会客区_桌后反打`；若对手可读角 90° → `270度…_反打`，**禁止**不经判定一律写 180 度）；再写被看者面部/手势/武器/术法可读细节；**正反打对白/正反打攻防**→ 各说话 Beat 或各攻防焦点 Beat 用各自匹配衍生环境（各轮次分别判 N_对手，不得共用错角 ENV）；**POV**→ POV 衍生（**术法瞄准/御剑俯冲/受击者主观**等）；**双人入境建置**→ 首见双人时用 Two Shot/Master 或航拍全局建置，后续 Beat 再 OTS/正反/Insert 切分；**远距离/受限 POV**（瞄准镜/望远镜/监控变焦/航拍远距等）→ POV 或 `{观察介质}度{主环境名}` 衍生，**仅建置镜内/屏内/远距可见范围**，不要求同 Beat 补齐全场全实体（§15）；**门窗内外（错误高发区，强制）**→ **须切门内/门外衍生环境**，动笔建置前完成 §二「门窗 Beat 专项评估」五维核验；禁止门内视角硬写门外 BG、禁止闭合门扇仍写门后实体、禁止内外侧混用主环境；**跨 Beat 状态/特效/域场**→ 状态衍生。  
    - **可沿用主环境**：0 度 Master/Two Shot 且观察侧与空镜轴未实质变化；`建置更新=否` 且仅层内微动。  
    - ❌ Beat 标 OTS 却写「当前环境：办公室会客区（0度）」并建置陈医生正面口型｜✅ 「视线 Match → 切至桌后反打衍生环境 → 建置重建 → 写陈医生口型」  
  - **视角—环境/建置匹配**：FG/MG/BG 须按**当前 Beat 已自检确认的环境与观察视角**展开；切衍生环境后观察视角、空间轴、空镜差异须同步切换；写眼神/口型/局部特写前须先完成环境—视角匹配自检并交代观察侧。  
  - **环境切换建置可执行性校验（强制，与视角切换/§14 配套）**：切换主环境或衍生环境（含 OTS/正反/POV/门窗内外/状态·特效衍生）后，重建 FG/MG/BG 前须对照**当前环境**已写明的固定结构/家具/陈设布局（§9）、阻隔、通行路径、可见边界与空镜差异，核验人物/道具/群演落位及本 Beat 动作、走位、接触、视线、对白咬合是否**合理、可拍、可执行**。  
    - **建置须服从环境实体安排**：落位与层位不得与当前环境固定布局、空镜轴、剧情相关实体前后左右关系（§9）矛盾；衍生环境须按**转角对照**（N 度衍生 0 度=主环境 N 度拓扑）重建该视角可见半空间，共同锚点与上一 Beat 一致，仅可见面/左右/前后按轴线更新。  
    - **动作须在空间约束内可行**：距参照、隔障、通廊净空、可见性、通行路径须与当前环境一致；禁止「人已在桌后却从 0 度主环境硬写正面口型」「门为实体墙却仍将门外景作 FG 框景」等不可执行建置。  
    - **冲突须当场修正（禁止带病输出）**：发现建置与动作不可执行时，按优先序调整——① 微调动作/走位/接触方式/观察目标/对白落点 → ② 调整实体落位与 FG/MG/BG 层位 → ③ 修正环境切换选择、衍生环境或【主环境】固定布局/空镜差异说明；**不得**保留无法执行的建置或动作链。  
    - ❌ 切至桌后反打衍生环境，却把本应在桌前的角色仍建置在「桌后读稿」且无越桌/换位交代｜✅ 切反打后按该视角可见半空间重建三层，桌面/门槛等共同锚点与上一 Beat 一致，椅背/文件柜等左右关系按 180 度翻转更新，后续「递文件」动作仍可从桌沿完成。  
  - **视角变化 → 建置重评估（强制）**：观察视角实质变化时**必须**触发 §14，成稿须说明「观察视角已变 → 当前环境 → 是否重建三层及原因」；**重建后须通过可执行性校验**。典型触发：OTS/正反/POV 切换、越轴、全景→插入特写、镜中/屏幕内/门窗内外等。  
  - **示例**：Beat 2：视线 Match 后，观察视角由林医生右后侧 OTS 切至陈医生正面 45 度近景（衍生环境：办公室桌后反打），建置重建——**FG** 无有效遮挡；**MG** 陈医生面部占画面左三分之二；**BG** 文件柜虚焦；后写眼神由平渐锐、眼尾轻颤。  
  - **武戏/决斗示例**：Beat 1 0 度 Master Two Shot 建置双人练武场对峙（**MG** 甲乙相向、**BG** 兵器架墙）；Beat 2 甲出掌——观察视角切至**甲右后侧 OTS**（衍生：练武场_甲侧过肩）看乙正面格挡，**BG** 转为乙身后对侧拱门；Beat 3 动势 Match 切**乙正面近景反打**（衍生：练武场_乙侧反打），**FG** 甲出掌手臂占画左缘，**MG** 乙四分之三左侧面朝向镜头、举臂格挡；Beat 4 乙反击腾挪——观察视角切 90 度侧移（衍生：练武场_侧轴跟拍），**BG** 变为侧墙与兵器架纵深，二人间距与朝向同步更新。  
14. **景深层次建置（强制）**：= Beat 完整逻辑环节 2 的空间层写法；与 §11 核心定义同义，本节为**可拍性/景深/遮挡**执行细则。每个 Beat 按**已声明观察视角与景别**，**先** FG→MG→BG 框架（结构/边界/框景+层间关系+**遮挡阻断**+**层间距离**），**再**各层内逐实体落位（七要素见 §11）；不得合并为「中景两人」；无有效前景须说明原因。
  - **遮挡阻断（强制）**：三层框架须先建立**视轴遮挡链**——从镜头/观察点沿 Viewing Direction 逐层判断 MG 是否被 FG 框景、BG 是否被 MG 遮挡体阻断。**完全遮挡**（闭合门扇/实墙/不透光屏风/幕布/柜体正面占满视轴）→ **BG 禁止写入不可见实体**；须明确「BG：被 {MG 遮挡体} 完全遮挡，当前视角不可见」，门后/墙后/对侧空间内容标注待可见 Beat 或待切换衍生环境。**半遮挡**（半开门/窗洞/镂空屏风/人物肩背框景）→ BG 仅写**经开口/框景实际可见**的区段，标注清晰/虚焦/剪影/仅轮廓。
  - **层间距离（强制）**：FG↔MG、MG↔BG 若非紧邻（跨门槛一步以上、跨房间、跨街道、深景窗景、长走廊/大厅纵深等），三层框架**须写清层间空间跨度**——格式：`{近层实体/结构} 与 {远层实体/结构} 相距约 {距离/步数/深景描述}`，锚定 ENV 具名部位或具名实体；禁止只写各层落位而无纵深关系（如 MG 人物与 BG 窗景/街景/远墙相距 10m+ 却未交代）。
  - **景别与景深可读性（强制）**：观察视角须体现景别对层间可读性的约束——**特写/CU/近景/MCU + 浅景深/长焦**时，非焦点层可标「虚焦不可辨」或省略不可读 BG 细节；**中景/MS、全景/LS、大景深/EWS/深焦**时，各层可见实体须按距离写清可读程度。**禁止**景别为特写/近景却在 BG 写清晰可辨的远距细节；**禁止**大景深/EWS 却省略远距 BG 应有的空间交代。
  - **与全局可见性联动**：§11「全局可见性」遮挡判定为本节执行口径；**涉及门/窗/门槛的 Beat 须叠加 §二「门窗 Beat 专项评估」**（错误高发区）；Beat 成稿前须核验三层无「被遮挡仍写 BG」矛盾。
  - ❌ **FG** 内开门框；**MG** 紧闭木门占满视轴；**BG** 走廊尽头文件柜与办公人员（门后不可见仍硬写）｜✅ **FG** 内开门框边缘；**MG** 紧闭木门扇占满画面；**BG** 被门扇完全遮挡不可见。
  - ❌ **MG** 林医生站门口；**BG** 窗外街景（未写 MG—窗约 8m 深景）｜✅ **MG** 林医生站 **FG 门框内侧**（距 FG 门槛约 0.5m）；**BG** 窗外街景位于 MG 身后约 **8m 深景**，虚焦成色块与车灯轨迹。  
15. **Beat 建置重评估（强制）**：= 环节 1→2 的重建触发器；与 §12 视角变化规则配套。每 Beat 对比上一 Beat 的**观察视角**与 FG/MG/BG。须完整重写三层：Scene/Beat 首幅、**观察视角实质变化**、切至/返回衍生环境、越轴、主体跨层位移/换层、出入画、**具名角色画内可见性或面部可读性变化（须含 §11 过渡动作，禁止同视角同站位跳变）**、**新主体首次入画/首次交互**。**环境变化原则上须重建建置**（建置更新=是），且重建后须通过 **§12 环境切换建置可执行性校验**（落位/动作与当前环境实体安排一致、可拍可行；冲突则修正动作或环境设置）。可只列变更项：仅层内微动且观察视角与三层构成均不变。成稿须说明「观察视角 + 环境 + 是否重建三层及变更项」；**第二部分禁止**仅写 `建置更新=是|否` 而不展开。  
16. **每个新 Scene 三步开场（强制）**：新 Scene 首【动作/视觉节拍】按 **先吸睛（前3秒）→ 再建置（观察视角+当前环境+空间基准实体+空间轴+先 FG/MG/BG 三层框架、再每层内逐个写清人物与物体落位）→ 再入戏** 展开；全剧第一场与场间切换同等适用；**场间切换须先完成 §一-B 转场逻辑链 Step1–3，再执行三步**。**远距离/受限 POV 开场例外**：首 Beat 若以**远距离 POV、瞄准镜/望远镜/监控变焦/航拍远距/单向受限传感视角**等开场，且当前视角**无法可读地看见**本场多数主体的全身、相互关系或完整空间（如远程瞄准只见靶区剪影、镜内十字线压点、远距监控只见局部），则**不要求**首 Beat 完成全场**全局全实体建置**；首 Beat **仅建置当前 POV 可见范围内**的观察视角+环境（或 POV 衍生环境）+ FG/MG/BG 内**确属该视角可见/可读**的主体；其余已入场主体标注「待全局建置 Beat + 触发条件」，在后续合适 Beat 补全全场三层落位。**补全全局建置须优先采用航拍/高位俯瞰类手段**（Drone / Crane / 建置航拍景观 / Bird's-Eye / Top Shot / 地图缩放式揭示等，OT-LS/OT-MAP/OT-AE 等），自远及近或高位俯看一次性交代空间关系与全员落位；Pullback 至 0 度 Master/Two Shot、观察侧后拉、目标近距入画、镜筒·屏幕移开等可作为切入/收束，**但不得**用地面级近距 Master 替代本应航拍完成的远距全局建置。**须在【Scene实体覆盖】与首 Beat 成稿写明** `全局建置=延迟`、计划补全 Beat 及**补全手段（须含航拍/高位类）**；Scene 结束前须完成全部已入场者落位闭环。
17. **Scene 实体覆盖评估（强制）**：每个 Scene 开场建置前，先盘点本场全部可见主体（**具名**人物、物件，及后续 Beat 才入画/才被交互/才成为感知焦点者；**含完整闪回 Scene 全量具名主体、Scene 内快速闪回/回忆切片 Beat 中出现的具名可见主体**）。**群演/龙套/匿名背景簇（强制）**：「村民」「路人」「士兵群」「办公人员簇」「龙套甲/乙/丙」等无具名、无独立对白的背景人群，须在 Beat/【全员反馈】中以**簇描述**（数量+分布+统一/随机反馈）书写，**列入 Scene 空间调度但不列入资产提取清单**；Stage 2-1 **禁止**为其建 CHAR；下游 Shot/文生视频按自然语言随机生成。**默认**：已入场**具名**者须在开场建置 Beat **先建 FG/MG/BG 三层，再在各层内逐个**给出落位与初始状态（七要素，见 §11）。**远距离/受限 POV 例外（§15）**：首 Beat 为远距离/受限 POV 且触发 `全局建置=延迟` 时，**当前 POV 不可见或不可读**的已入场者首 Beat **不必落位**，须标注「待全局建置 Beat + 触发条件 + **补全手段（航拍/高位类优先）**」；**当前 POV 可见/可读**者（含观察侧 POV 主体、镜内/屏内压点目标、远距可辨剪影等）仍须在首 Beat 落位。未入场者须标注「待入画 Beat + 触发条件/出入画方向」；**快速闪回切片内首次出现、仅存在于回忆时空的主体同样须列入本场【Scene实体覆盖】并具名**。任一 Beat 新出现的主体若前序 Beat 无落位或出入画交代，该 Beat 必须触发 §14 建置重评估并补全三层；`全局建置=延迟` 场须在标注 Beat **补齐全场已入场者**三层落位。本项只负责**空间可见性与落位闭环**及**可拍交互证据**（拿起、递交、移出、破坏、跨 Beat 状态承接等）；**禁止**预列资产表或使用 `ENV/PROP/CHAR` 标签；主体分类、升格归档、衍生变体、环境补建、`ENV/PROP` 归属等归 Stage 2-1。  
18. **锚点实体化与自然语言具名（强制）**：`主锚点`、`辅助锚定`、`原始锚点` 等仅为内部推演辅助，**禁止**原样输出。成稿须替换为具体人物名、物件名、空间结构部位等自然语言具名；**禁止**使用 `ENV/PROP/CHAR` 分类标签或 `ENV:`/`PROP:`/`CHAR:` 前缀。  
19. **角色占位名替换（强制）**：原文若用职能/番位/泛指称呼**具名叙事角色**（如「男主」「女主」「男一/男二」「女二」「主角」「反派」「配角」「Boss」「CP 男/女」等），**须主动替换为具体姓名**；原文已有真实姓名者**逐字保留**，不得改写。**群演/龙套/匿名背景例外（强制）**：「村民」「路人」「士兵群」「群众」「背景人群」「办公人员簇」「龙套甲/乙/丙」等**无具名、无独立画内对白/OS、无跨 Beat 可持续身份**的匿名泛指，**禁止**为资产提取目的替换为具体姓名或拆为个体；Beat/【Scene实体覆盖】/【全员反馈】中仅以簇描述（数量+分布区段+统一/随机反馈）书写，标注「非资产提取·留Beat/ENV氛围」；下游视频模型按文生视频随机生成匿名背景人物。无姓名且属**须提取的具名叙事角色**时，须结合项目语言、时代/地理/族群/题材/阶层/职业语境**新取姓名**（中文项目优先中文名，英文项目优先英文名；古装/民国/都市/西幻等须服题材），同一人物全剧称呼一致；对白直呼、旁白、Scene 实体覆盖、Beat 落位、全员反馈等**禁止**再出现占位称谓（**龙套/群演簇除外**）。成稿前须建**占位名→具名对照表**（原文称呼 → 新取/保留姓名/匿名簇保留 → 依据），写入 Part 1【角色命名】；下游 Stage 2-1 以本阶段**具名叙事角色**为唯一 CHAR 原名权威。  
20. **自然语言成稿（强制）**：模板、键值串、思考模板仅为覆盖校验与内部推演；第一、二部分须改写为连贯自然语言，逐项覆盖硬约束，禁止照搬 `字段=值` 或裸标签堆砌。第三部分 JSON 除外。  
21. **AI特效强化（强制）**：凡原文明示/强暗示、题材需要或情绪/信息可视化可受益处，须主动规划可拍特效。单段须覆盖**六相链**（触发源→显形起势→扩散传播→命中作用→维持碰撞→余波残留）及受影响人物/物件/空间结构在 FG/MG/BG 的落点。分配方式见§三-B。  
22. **资产分类禁令（强制）**：全文禁止 `ENV/PROP/CHAR` 分类术语、`ENV:`/`PROP:`/`CHAR:` 前缀及资产表式枚举；仅以自然语言具名书写，并为 Stage 2-1 保留归类证据（固定陈设 vs 可移动交互、跨 Beat 状态变化、拿起/递交/破坏等）。  
23. **输出边界**：不得输出 `Scenes Table` 或 `Shot List`；“首镜/补镜头”仅指视觉节拍。  
24. **Backfill强制校验**：第三部分只能有一个 JSON 代码块，顶层 `project_visual_backfill`；`Global_Style`、`borrowed_films`、`borrowed_films_note`、`tone`、`lighting`、`plot_summary`、`music_recommendation` 必填非空，`borrowed_films>=1`；`plot_summary` 须为 **80–120 字中文**百字剧情总结（概括核心剧情、人物关系与情感走向，禁止剧透终局细节）；`music_recommendation` 须写明配乐风格、情绪基调、参考曲目/作曲家/影视配乐及主要使用场景（开场/高潮/情感转折等）；禁止 `null`/空串/`[]`/`{}`/`TBD`/`N/A`/`待补`。  
25. **每场对白拆句判定（强制）**：每个 Scene **必须**单独输出【对白拆句判定】，明确本场是否进行了拆句处理；禁止省略、默认不写或仅在 Part 1 汇总而不逐场声明。  
  - **判定值**：`已拆句` | `未拆句` | `无对白`（三选一，不得留空）。  
  - **已拆句**：逐条列出被拆原句/原段（说话人+原文或核销源对应句）→ 拆句后各子句（含情绪标点）→ 落点 Beat → 配套说话动作切口或听者微反应。>20 字单句或同一角色连续说话 >20 字**必须**拆句并标 `已拆句`。  
  - **未拆句**：须写**未拆原因**（如：全场最长台词≤20 字且节奏无需断句；纯 OS/V.O. 画外无口型；武戏无画内对白；单句短促爆发且≤20 字等）。禁止对 >20 字应拆句台词标 `未拆句`。  
  - **无对白**：本场无任何对白/OS/V.O./旁白/独白，写 `无对白：原因`（如纯动作场、纯环境转场、纯特效专拍等）。  
  - **与成稿一致**：【对白拆句判定】须与【语言】各 Beat 成稿台词、拆句结果一一可核销；拆句不改词义与剧情信息，仅断句+标点+节奏。
26. **纯粹受力/客体运动禁止独立 Beat（强制）**：**纯粹受力的动作不得单独建 Beat**，必须与**主动作（发力方）**合成同一 Beat 的因果链延续；被动物件飞行/滚动/落点、受力方纯粹被动位移（被推动、被击倒、被抛出而无格挡/闪避/承接等主动意图）均须写入**施力方 Beat**内连贯描述，**禁止**升格为下一 Beat 的「主节拍」。**唯一例外**：受力方产生**新的主动作**（接球、格挡、闪避、拦截、反击、主动后撤收势等）时，方可新开 Beat，且**主节拍归该新的主动施力方**，不得把「球飞了」「人被推倒」本身当作 Beat 主节拍。写法见§二「主动作主体示例」。  
27. **正式决战（§27，仙侠/武侠/武打/玄幻）**：`正式决战=是` → Scene **≥10 Beat**，禁概括合并。**判定**：生死决斗/终极一战/核心飞剑术法对决/高潮武力战；**不含**宏观对阵(§27)、日常比划、≤3招。**结构**（全覆盖）：对峙→试探→攻防≥4轮(换招/格挡/闪避/反击各≥1)→术法域场→逆转受伤→决胜→收势。**高成本**：≥3 Beat 轻功/飞翔/空域/域场(§三-B/§七-C)，禁全地面平拍。**输出**：【决战 Beat 规划】+高成本清单；<10或奇观<3→「决战 Beat 缺口」。  
28. **宏观群体（§28）**：`宏观群体=是` → Scene **≥6 Beat**，禁「大军开到/一触即发」。**判定**：大军/两阵对冲/兽潮/机群/舰队/人海/阅兵/遮天蔽日/无边无际等；**不含**2–3人背景簇。**三要素**：①无边无际(FG→BG地平线满幅) ②细节整齐(同步阵列/FG-MG-BG满编+**剧本威武细节**，见下) ③压迫感(体量逼近/尘浪声浪压境)；高潮三项齐，余Beat≥2项。**威武描绘双轨（强制）**：除全景/远距建置（Drone/EWS/地平线满幅）外，须在 Beat 成稿中用**剧本可拍细节**写出军威——盔甲、武器、旌旗、盾墙、马具/载具军械、阵列同步动作等；**整齐细节 Beat** 与 **高潮 Beat** 各须 ≥2 项具体装备/军械/同步细节（锚定 FG/MG/BG+左中右，必要时上中下），禁仅写「大军威武/铁流滚滚」而无可见物件。**结构**：无边际建置→整齐细节(含剧本军械描绘)→压迫推进→指挥焦点→高潮对冲→余波。**禁**：稀疏小簇/「远处若干士兵」；须FG/MG/BG满编。**输出**：【宏观 Beat 规划】；<6或三要素缺→「宏观 Beat 缺口」。
29. **视频时间控制与 Beat 数量规划（§29，强制）**：下游单镜视频生成强制 **4–15s**；本阶段 Beat 切分须**预先匹配**输入中的视频时间控制要求，使 Beat 数量、粒度与等效时长可落入下游可拍区间。**输入来源（须优先读取）**：`Project Context` 中的 `Shot / Lens Preference`（镜头偏好）、`Episode Duration`（每集时长）、`Project Notes`；原文/用户提示中的显式时限（如「前 3 秒吸睛」「闪回 ≤8s」「整段 ≤30s」「慢节奏长镜头」等）。**规划原则**：① **有明确时间要求时 Beat 数须与之匹配**——先估算本场/本段目标总时长 T，再按镜头偏好与单镜 4–15s 上限反推 Beat 数区间：`目标 Beat 数 ≈ ceil(T / 单镜目标秒)`，并在【节拍时间规划】写明依据；② **长镜头 / Long Take 偏好** → **减少 Beat 数**（合并相邻对白轮次、正反打可并入同 Beat 的运镜/反应相位，目标单 Beat 等效 **10–15s**）；禁为快切而过度拆 Beat；③ **短镜头 / 特写 / 快切偏好** → **增加 Beat 数**（正反打、听者反应、Insert、Walk-and-Talk 逐句、武戏换招/格挡/闪避/反击各独立 Beat，目标单 Beat 等效 **4–8s**）；④ **均衡默认** → 单 Beat 等效 **6–12s**，对白场按拆句+反应自然切分；⑤ **硬性下限不受时长压缩**：`正式决战=是` 仍 **≥10 Beat**；`宏观群体=是` 仍 **≥6 Beat**；快速闪回 ≤8s、首节拍前 3 秒吸睛、六相链维持/余波时长等 Stage 1 已写时间上限**不得**为凑 Beat 数而删减；⑥ **每 Scene 必输出**【Duration Estimate Basis】：对白（字数/4）、动作层级、建置/转场留白、奇观补偿的加法算式 + 本场 Beat 总数与单 Beat 预估区间；⑦ **集级校验**：各 Scene `Equivalent Duration` 之和须与 `Episode Duration` 可 reconcile（偏差过大须在 Part 1【节拍时间规划】说明压缩/扩写策略）。**禁止**：无视输入时间要求而按默认粒度随意拆 Beat；为压 Beat 数合并本应独立的正反打/拆句/决战阶段；为拉 Beat 数把客体轨迹或纯粹受力升格为独立 Beat（§25 仍适用）。

## Scene/环境识别
- **流程**：先判 Scene → 再判**开场建置与 Master 观察轴**（据此锚定主环境 0 度，见 §9）→ 再写主环境 360 度拓扑 → 再判衍生环境。  
- **Scene四问**：时间连续？空间连续？行动线连续？叙事目标连续？任一断裂即新 Scene。  
- **环境六要素**：环境名、内/外、日/夜、空间基准实体、空间边界、固定结构。  
- **0 度锚定（强制）**：主环境 0 度 = 开场首 Beat Master/Two Shot 视角，须服 §9 开场建置要求；360 度拓扑各向描述均相对此 0 度展开。  
- **环境描述边界**：仅写**实体清单 + 剧情相关尺度/形状/开合/相对位置 + 交互/站位/通行/遮挡/攻防/视线**所需的空间约束；**禁止**材质、纹理、工艺、配色、光源/灯光、声场/声源、氛围词、色调/色温/明暗美学及一切生图级视觉细化（归 **Skill 1-3 资产设计**）。
- **剧情相关实体空间关系（强制）**：影响交互/站位/通行/遮挡/视线/攻防的固定实体，须同时写 **FG/MG/BG 层次**、**实体间前后左右关系**及**剧情需要的尺度/形状**（锚定空间基准实体或其他固定结构具名部位，如「两把转椅分列会议桌左右两侧，椅背朝向桌心」「半开内开木门位于 180 度墙段中央，门轴在画面右侧、门扇向室内开启」）；禁止只写「有桌椅/有门/有窗」而不说明相对位置；禁止写材质/光源/色彩修饰。
- **门窗开闭态（强制）**：环境描述中凡出现门/窗/柜门/推拉门/百叶/阳台门/窗洞等可开合或可调光构件，**必须写明开闭状态**（紧闭/半开约几度/全开/合拢/叶片开启等）；未闭合时须同步写**内开|外开、门轴/铰链侧、门扇/窗扇占视轴比例**；禁止只写「门口/窗边/有门/有窗」而不交代是否闭合。
- **方向性实体具名+朝向+正反面（强制）**：椅子、沙发、床、门/窗/柜门、屏风、柜台、祭案、讲台、台阶、长桌/会议桌/餐桌及**主位/客位/上首/下首**等礼制座次相关固定物，凡具有正面/背面/开合方向/使用朝向/座次指向/内外侧差异，在固定实体清单、360 度拓扑与实体间关系描述中须**具名并同步写朝向与正反面**——格式：`{实体名}（{层位/相对方位}，{开闭态}，{正面/背面/内外侧/座次/文字面}）`，如「主位转椅（MG 桌左，椅背朝桌心、椅面背对 270 度墙）」「客位转椅（MG 桌右，椅背朝桌心）」「半开内开木门（180 度墙段中央，门轴右侧，门扇向室内开启，室外侧为正面）」「紧闭百叶窗（270 度墙段，叶片合拢）」「会议桌（MG 居中，长边沿 0 度 Two Shot 轴，桌头朝 90 度、桌尾朝 270 度）」「山水屏风（90 度墙段，正面绘山水朝 0 度、背面素绢朝 180 度）」；禁止只列「椅子/门/窗户/桌子/屏风」而不写椅背/椅面、门轴/开向/开闭态、桌头/桌尾/主客位、屏风正背面、牌匾文字面等方向与正反信息。

- **切换句式（强制）**：视角衍生写 `触发 -> 顺时针转角 N（相对主环境 0 度）-> 切至/返回 环境名 -> 空镜差异（须符合 N 度→衍生 0 度对照；仅写可见实体/布局 Delta）-> 下一节拍承接`；状态/特效衍生写 `特效触发/六相链落点 -> 环境剧变完成（通常在维持/余波相）-> 切至/返回 状态衍生环境名 -> 空镜差异（固定结构/边界/布局变化，不写光色材质）-> 下一 Beat 起沿用直至恢复触发`。**切换后须重建建置并通过可执行性校验**（§12）：三层落位与动作须符合目标环境的实体安排，冲突则修正动作或环境设置。  
- **禁令**：氛围/情绪/景别/特写不是环境；停顿/表情变化/正反打不是新 Scene。

### 一-A、视频时间控制与 Beat 数量规划（§28）
- **先读输入再拆 Beat**：动笔每个 Scene 前，先汇总本场适用的视频时间控制（镜头偏好、集时长、原文时限、Project Notes），写入 Part 1【节拍时间规划】并据此定 Beat 目标数。
- **反推公式（内部推演，成稿写自然语言）**：`本场目标秒 T` → `Beat 数下限 = max(题材硬性下限, ceil(T / 单镜上限15s))`；`Beat 数上限 = floor(T / 单镜下限4s)`；在区间内按镜头偏好取目标 Beat 数（长镜头偏下限、短镜头偏上限）。
- **长镜头合并策略**：多轮对白可合并为更少 Beat，在同 Beat 内用运镜/反打/反应相位串联；正反打若可在单镜 4–15s 内完成则**优先不拆 Beat**；通过扩展微表演、环境微变、Walk-and-Talk 同拍填充至 10–15s 等效。
- **短镜头拆分策略**：正反打各 Beat、每句拆句独立 Beat、武戏每换招/格挡/闪避/反击独立 Beat、Insert/反应镜独立 Beat；单 Beat 等效控制在 4–8s。
- **显式时限落点**：`前 3 秒吸睛` → 【场景切换与首节拍转场】首节拍三步；`快速闪回 ≤8s` → 转场专拍/快速闪回 Beat；特效/域场 `维持 N 秒` → 六相链维持相或专拍 Beat；须在对应字段**写明秒数**，不得只写「短暂」「一会儿」。
- **等效时长复核算术（每场必填）**：对白约 4 字/秒（极短句 1.5s 保底）；日常微交互 1–2s；正常大动作/格挡/躲闪 3–5s；奇观/域场/宏观场面单独 +3–6s 或 ×1.3；建置/转场留白 1–3s；写入【Duration Estimate Basis】。

### 一-B、场景切换与首节拍转场（合并说明，强制）
本小节统摄 **Beat 间过渡、Scene 内快速闪回、Scene 间切换、每场首节拍**；与 §二「转场专拍 Beat」「转场手段参考库」配套使用。Part 1 / Part 2 **禁止**将切换判定、首节拍技巧、出场转场拆成三处各写一半，须合并写入 **【场景切换与首节拍转场】**。

- **转场逻辑链（强制顺序，逐 Scene 走完）**：  
  1. **上场承接**：读取上一场【视觉落点】为本场入点锚；写明「上场落点 → 本场如何接住」（动作余势/视线/声音/物体/色调/构图之一或多）；全剧第一场写「无上场：开场特例」。  
  2. **切换判定（四项必填）**：`时空关系`（连续/省略/跳转）｜`桥接依据`（动作/视线/声音/特写/色调/光影/遮挡/图形 Match/运镜/声画对位等，至少一项）｜`轴线状态`（同侧/已交代过轴）｜`跨幅级别`（小跨幅/已说明跨环境）。禁止无依据硬切。  
  3. **手法选定**：从 §二「首节拍 OT 标签」+「转场手段参考库」各选 **≥1 项**；场间切换与每场首节拍**须标 OT 简称** + 自然语言可拍描述；Beat 间小过渡可只写手段名称。  
  4. **首节拍三步咬合**（强约束§15）：**吸睛（前 3 秒）→ 建置（观察视角+环境+先 FG/MG/BG 三层、再每层内逐个实体落位）→ 入戏**；吸睛手段须与 Step2 桥接依据、Step3 OT/转场手法**同链**，局部特写吸睛后须后拉/摇移或紧接全局建置。**远距离/受限 POV 例外**：首 Beat 为瞄准镜/望远镜/远距监控等 POV 时，建置步**仅覆盖 POV 可见范围**，可标注 `全局建置=延迟`，不必同 Beat 后拉全场；补全 Beat **优先 OT-LS/OT-MAP/OT-AE 等航拍/高位俯瞰建置**，再写 `{下一节拍起幅}` 或专拍 Beat。  
  5. **下场预埋**：本场末 Beat 或【视觉落点】须写明可供下一场 Step1 承接的锚点（落点画面/动作态/声源/物件状态）。

- **三层切换粒度**：  
  | 层级 | 典型场景 | 写法要点 |  
  |---|---|---|  
  | **Beat 间** | 正反打、视线 Match、无情节回忆切片 | 同 Scene；无情节切片可并入转场链，不必独立 Beat |  
  | **Scene 内插入** | 快速闪回（回忆对白 >30 字）/ 无情节回忆切片 | 不拆 Scene；快速闪回主节拍=快速闪回桥接；无情节切片主节拍仍归当下场，切片写入转场链（§三） |  
  | **Scene 间** | 时空跳跃、空间跨越、原文/上游已切分的独立场次 | 新 Scene 首节拍走完全链；上场末+本场首须双端桥接；**完整闪回不必然另拆 Scene**，以原文/上游切分为准 |

- **首节拍技巧 = 场间转场技巧**：每场第一个【动作/视觉节拍】的 OT/转场手法，即本场**入画方式**；须同时回答——**从哪来（上场承接）→ 怎么切进来（桥接+OT）→ 第一眼看什么（吸睛）→ 空间怎么建立（建置）→ 戏从哪入（入戏）**。  
- **参考片对标（强制）**：每场至少写 1 部 `borrowed_films` 中对标片 + 具体手法（如「《xxx》走廊跟拍入画，OT-TR 横移穿越」），不得只写片名或只写 OT 代号。  
- **与转场专拍 Beat 分工**：需独立展开的桥接情节（场间省略、蒙太奇、声画对位、快速闪回等）→ 上场末 Beat 或本场首 Beat 建**转场专拍 Beat**（主节拍=转场/快速闪回桥接），其前后 Beat 仍须写切换判定与承接；简单连续时空且桥接可在首节拍三步内完成 → 不必另建专拍 Beat。  
- **示例**：【场景切换与首节拍转场】上场林医生推门落点 → 切换判定：连续省略｜声画对位+色调渐变｜同侧｜小跨幅 → OT-LG 走廊灯光由暖渐冷+OT-TR 横移穿越（对标《xxx》）→ 首节拍：门缝光带收窄吸睛 → Pullback 建置走廊 FG/MG/BG → 陈医生脚步声入戏。  
- **远距离 POV 延迟建置示例**：【Scene实体覆盖】`全局建置=延迟`；已入场：狙击手李、目标王、观察员张——Beat 1 仅落位李（POV 观察侧）+ 镜内王剪影压点；张与王全场关系标注「待全局建置 Beat 3，触发：镜筒移开；补全手段：OT-LS Drone 高位俯拍 rooftop 建置航拍景观」。Beat 1 首节拍：瞄准镜十字线压王胸口吸睛 → POV 衍生环境建置镜框/靶区 FG/MG/BG → 李扣机指渐紧入戏；Beat 3 Drone 自 BG 高位俯拍缓缓下降，一次性建置 rooftop 三人 FG/MG/BG 全局落位与相对距离，再切近景入戏。

### 二、空间位移与动作微观化
- **主节拍/主动作（强制）**：每 Beat 标明**唯一**主节拍/主动作，且**必须归属主动施力方**（**例外**：转场专拍 Beat 主节拍=转场桥接，见下条）；被动物件的运动、落点、碰撞及**纯粹受力位移**仅为该 Beat 因果链的延续描述，**不得升格为独立 Beat**（执行见强约束§25）。微动作不得替代主动作，但须在全员反馈与对白停顿中持续落地。  
- **纯粹受力/客体运动禁令（强制，§25 展开）**：  
  - **同 Beat 必写**：施力主动作 → 接触/命中（**写清命中部位/落点**）→ **命中效果/受力反馈** → 客体轨迹或受力方被动位移（**需要时写移动路径**：沿结构滑行/弧线/反弹/滚转等，锚定 ENV 具名部位）→ 落点/碰撞/静止，全链写在**发力方同一 Beat**（或发力方动作延续的下一 Beat，主节拍仍归同一施力方）。投射攻击（子弹/飞镖/箭矢/暗器等）同样适用，禁只写射出/飞出而无路径（需要时）、命中与效果。  
  - **禁止独立 Beat**：以被动物件为主语的单 Beat（「球飞向…」「杯摔碎」「纸张飘落」）、以纯粹受力为主语的单 Beat（「他被推倒」「她被撞飞」且不含主动格挡/闪避/承接）——均须**并入上一施力方 Beat**。  
  - **可新开 Beat 的条件**：仅当**新的主动施力方**接续并承担主节拍——如对方接球、门将扑救、格挡反击、主动闪避后还击、主动后撤收势等；此时主节拍归该人物，不得仅写「受力结果」而无其主动意图。  
  - **链过长拆分**：**施力起势 Beat** → **同一施力方动作延续 Beat**（含客体全程轨迹至静止/命中，或受力方纯粹被动位移至落点）；**禁止**拆出「客体独立 Beat」或「纯粹受力独立 Beat」。  
- **形体动作因果链（强制）**：施力-受力、接触-运动等同链，须先写完整主动作与受力反馈，再写结果轨迹/落点；禁止只写结果而跳过施力主动作。**主节拍必须归属主动施力方**（人物、有自主意识的活物、或术法/机关的明确触发者）；客体轨迹、旋转、飞行、落点、碰撞须写入施力方同一 Beat 的因果链内连贯描述。仅当**新的主动施力方**接续（对方接球、门将扑救、第二人拦截等）时，方可新开 Beat，主节拍归新施力方。  
- **主动作主体示例**：  
  - Beat 1 主角立于球场 **MG 左区**，右脚由 **BG 右下**发力踢球→球沿低平弧线由 **MG 左前** 飞向 **FG 门口**、在门槛 **FG 前侧** 反弹后滚入走廊 **BG 中纵深**（施力主动作与客体轨迹同 Beat）。  
  - Beat 1 甲挥拳击中乙胸口→乙上身受力后倾、脚跟离地半步后坐倒在地（施力、命中、受力反馈、落点全链同 Beat）。  
  - Beat 1 甲 **MG 右区**抬枪击发→子弹自 **FG 右前**低平射出，途经 **MG 中线** 命中乙 **MG 左肩**→乙肩线后挫、身体顺时针半旋后坐倒地（出手、弹道、命中部位、效果同 Beat）。  
  - Beat 1 丙 **MG 左前**甩腕掷出飞镖→飞镖沿弧线自 **MG 左** 飞向 **FG 右** 丁喉前→丁 **FG** 侧身闪避，飞镖擦耳钉 **FG 右后** 木质屏风，镖尾颤振嵌于屏心（出手、弹道、预期命中、实际落点、效果同 Beat）。  
  - Beat 1 林医生 **MG 左区**推桌→桌上文件夹沿 **MG 桌面**滑向桌沿（施力主动作与客体轨迹同 Beat）。  
  - Beat 1 主角踢球→球飞向 **FG 门口**；Beat 2 门将 **FG 中区**跃起扑救（主节拍归门将，新主动施力方）。  
  - Beat 1 黑色轿车自 **BG 左深区** 沿 **MG 左车道** 加速驶向 **FG 中偏右区**（车头朝右前，途经 **MG 中线** 后变道至 **FG 右车道**），在斑马线 **FG 右前区** 急刹停稳（施力主动作=加速驶近与制动，轨迹与终落同 Beat）。  
- **特效拆 Beat（例外）**：术法/域场/奇观六相链过长时，可 **起势 Beat → 特效专拍 Beat → 落位 Beat**（细则见§三-B）；不得替代形体动作链，不得跳过触发源。  
- **转场/过渡专拍 Beat（例外）**：凡 Beat 间、Scene 间或时空/情绪/信息需桥接的转场，本阶段为连贯性**优化补写的过渡情节**（蒙太奇切片、空镜桥接、声画对位、匹配切、走位穿越、环境异象铺垫、情绪余韵承接、**快速闪回**、**无情节回忆切片**等）**可单独建 Beat**；**主节拍=转场桥接**（**快速闪回**时主节拍=快速闪回桥接，**须满足回忆对白 >30 字**，见§三；**无情节回忆切片**可并入相邻 Beat 转场链而不必独立建 Beat，见§三）；须写清：切换判定（时空关系/桥接依据/轴线状态/跨幅级别）、前后承接落点、OT 或转场手段名称、可视过程链；**快速闪回**另须标明进入锚点、回忆切片内容（对白/动作要点）、回切锚点与质感处理（见§三）；**无情节回忆切片**写清触发→切片画面要点（≤2s）→回切锚点与质感即可，**不要求**完整对白链/动作链/三层建置。此类 Beat 服务于叙事连贯与转场可读，**不**视为客体独立主动作；**禁止**无桥接依据的硬切占位。  
- **转场专拍示例**：Beat 3 对白落点，林医生视线定格门外→ Beat 4【转场桥接】走廊灯光由暖渐冷、脚步声叠化、门缝光带收窄（桥接依据：声画对位+色调渐变；时空关系：连续省略）→ Beat 5 陈医生推门入画。  
- 路径、开关方向、进出径向、绕障路线须写清；凡方向变化须按**立体三轴**落点，且**前/后须标明相对镜头或相对 ENV/实体**（见 §11 前后位置双轨）。  
- 高动量段落须写速度状态（起速/加速/急停/失速）+ **方向变化节点**（每个变向须写清沿哪一轴、从 FG/MG/BG 哪区段切至哪区段、左中右哪区段切至哪区段，必要时上中下）。  
- 位移动作五元组：`起始实体落位（含层位 FG/MG/BG + 左中右 + 必要时上中下） → 发力（发力部位+立体方向） → 路径/方向（**移动路径**（需要时：相对 ENV 结构的路径形态）+ 沿三轴的变化节点，每节点须 FG/MG/BG + 左中右） → 终点实体落位（含层位 FG/MG/BG + 左中右） → 静止/受力结果`（成稿写具体人物/物件/载具/空间结构部位）。**移动链须同步写行进/飞行/车体朝向与轨迹路径**；客体/受力体轨迹**需要时须同步写移动路径**，执行细则见强约束§11「运动方向与朝向」。  
- **打斗场景站位默认（强制）**：凡近身肉搏/追逐缠斗/正式决战/武打换招段，**默认每个 Beat 各参战角色均须相对上一 Beat 终态发生可核销的三轴落位变化**（跨层、绕障换侧、逼近/退离、腾空/落地、借物换位、越轴等）；**禁止**多 Beat 固定同一 FG/MG/BG+左中右 硬写「出拳/格挡/闪避」而无位移链。**环境切换与建置重建（打斗专项，强制）**：位移导致观察侧变化、OTS/正反/POV 可读性变化、绕至桌后/门内外/檐上檐下/域场态跨 Beat、或固定布局相对关系翻转时，须**同步**写环境切换（主→衍生或状态衍生）并触发 §14 三层重建 + §12 可执行性校验；成稿须可核对「上一 Beat 终态落位 → 本 Beat 起点落位 → 轨迹节点 → 终态落位」与「是否切换 ENV / 建置更新=是|否及原因」。
- **武戏/决斗/术法 Beat 视角—环境—朝向（与对白同等粒度，强制）**：凡**无对白或对白为辅**的近身决斗、远程投射、术法/域场、轻功空战 Beat，**须与对白 Beat 一样逐 Beat 完整执行环节 1–3**，不得因「纯动作」而省略观察视角、背景层或朝向分析。每个 Beat 动笔前须完成下列**动作视角咬合**核验（与 §12 环境—视角匹配、§11 朝向四要素同拍）：
  1. **观察侧声明（必填）**：写清本 Beat **Observer View**——0 度 Master/Two Shot、OTS 过肩（谁的肩后看谁）、正反打（攻方/守方/施术者/受击者各 Beat 切换）、POV（施术者/受击者/弹道/瞄准）、Insert 特写（拳/剑/符/法器/命中部位）、全景建置（双人/多人对峙或空域换位）等；**相对上一 Beat 观察侧是否变化**及触发（动作 Match、视线 Match、动势切、越轴、入画等）。
  2. **背景层变化（必填）**：按当前观察侧重写 **FG/MG/BG**——须写清相对上一 Beat **BG 可见半空间是否变化**（如 0 度 BG 文件柜墙 → 180 度反打 BG 变为入口/对侧墙；檐上 Beat BG 变为地面纵深/天际线；域场态 BG 结构/layout Delta）；**禁止**多 Beat 沿用同一主环境 0 度 BG 硬写正反/OTS/越轴而不切衍生环境、不重写三层。
  3. **朝向四要素（必填，逐参战者）**：每个画内人物均须写**角色建置朝向四要素**——位置｜身体朝向｜相对 Observer View 正/侧/背面及可读性｜与他者/物件朝向关系（相向对峙/侧对格挡/背向威胁/同向追击/隔障相对等）；主动作发起时须写**发力侧/武器轴向/术法手势朝向**相对镜头与他者的可读面。
  4. **OTS/正反/双人镜（强制，双人及以上决斗）**：与对白正反打同等规则——**读招/读势/读表情/读术法手势/读受击反馈**时，须切至匹配衍生环境后再写可读细节；典型：**甲出拳 Beat** 可用甲侧 OTS 或 Master 看乙；**乙格挡/受击 Beat** 须切乙正面/侧脸或乙侧 OTS 反打（衍生环境），并重判乙视角正背面与 BG；**术法 Beat** 施术者结印/引气可读时切施术者近景或 POV，命中/域场展开时切受击者 OTS 或状态衍生 ENV 重写 BG。**禁止**标 OTS/反打却仍在主环境 0 度写对方面部/手势/术法细节可读。
  5. **双人/多人入境与出画（强制）**：第二人/第三人**首次入画或重新入画** Beat 须写：出入画径向（左/右/上/下/纵深 FG→MG）、触发（被追击入画/援兵赶到/术法召唤/空域降落）、**入境后 FG/MG/BG 落位+朝向四要素**、与已在场者**与他者朝向关系**；若入境改变观察侧或轴线，须同步 ENV 切换与建置重建。**Scene 开场双人决斗**首 Beat 须完成双人 Two Shot 或等效全局建置（§15/§16），再进入逐 Beat OTS/正反/POV 切分。
  6. **术法/域场/空战环境切换（强制）**：结印/引气/域场展开/轻功腾空/御剑换层等导致**观察高度、可读侧、固定结构可见性、域场 layout**变化时，须写 `触发 → 视角/状态衍生 ENV 名 → 空镜差异 → 建置重建`；跨 Beat 域场/结构破坏用**状态衍生**；空战 Beat 须写垂直层位（上/中/下）+ FG/MG/BG 在纵深与高度双轴的落位变化。
  7. **成稿最低覆盖（每个武戏 Beat 须可检索）**：`观察视角（含相对上一 Beat 变化）→ 当前环境名 → [环境切换声明/None] → FG/MG/BG 框架与各层逐实体落位 → 各参战者朝向四要素 → 主动作/轨迹/命中链 → 终态落位与 ENV/视角承接`。
  - ❌ Beat 3「甲挥剑劈向乙，乙格挡」（无观察侧、无 ENV、无 BG 变化、无朝向、多 Beat 同站位同 0 度主环境）｜✅ Beat 3 动势 Match 后观察视角切至**乙正面 45 度近景**（衍生环境：练武场_乙侧反打），**BG** 由 0 度兵器架墙变为**180 度对侧拱门与天际线**；**MG** 乙**四分之三左侧面朝向镜头、与甲相向对峙**，举剑格挡、**剑刃轴向朝左上迎击**；**FG** 甲挥剑手臂占画左缘 OTS 框景（肩背剪影）；甲**MG 右区**、**侧对乙、背向镜头**，终态二人间距由 2m 缩至 0.8m。
  - ❌ Beat 5「陈医生结印，符阵炸开」（无 POV/OTS、无状态 ENV）｜✅ Beat 5 观察视角切至**陈医生 POV 衍生**读结印手势 → Beat 6 动势切/特效专拍切**状态衍生「会客区_符阵覆盖态」**，**BG** 地面符纹覆盖范围与文件柜倾角变化，**MG** 林医生**背对镜头、肩线后撤**，**与陈医生隔桌相向**；Beat 7 切**林医生 OTS 反打**读受击微表情。
- **打击与投射攻击链（强制，打斗/远程攻击统一口径）**：近身打击与远程投射均须写完整因果链，禁只写动作名或只写「打出/射出/飞出」而无命中与效果。  
  - **近身打击链**：施力方(FG/MG/BG+左中右)→发力方向→**接触/命中部位**→**受力反馈**（位移/失衡/伤态/格挡硬抗等）→**移动路径**（需要时：受力方被动位移沿哪结构/弧线/滚转）→终点落位。
  - **投射攻击链**（子弹/飞镖/箭矢/暗器/投掷物/法术弹道等）：`出手/击发锚点 → **移动路径**（需要时：低平/弧线/绕障等路径形态，锚定 ENV 结构）→ 弹道轨迹（途经 FG/MG/BG+左中右 节点）→ **命中部位/落点**（写具体：左肩/门柱/地面哪一区段等）→ **命中效果**（贯穿/嵌入/反弹/碎裂/阻停/擦过/打偏入障/受击者生理或物理反馈/环境痕迹）→ 静止/余势`。闪避/格挡/打偏时须写预期弹道/路径与实际落点及效果。
- **门窗 Beat 专项评估（错误高发区，强制）**：凡 Beat 涉及**门/窗/门槛/门柱/窗框/门楣/百叶/推拉门/玻璃幕墙开口/窗洞/阳台门**等（含推门/拉门/窥视/门内外对峙/窗内外对话/经门洞射击/撞门/隔门喊话/门缝透光/窗外框景），**动笔写建置前须认真完成下列五维评估**，缺任一维即 Beat 不合格；本类为 Stage 1 **错误高发区**，禁止凭直觉堆坐标。
  - **① 开向与方向（必填）**：从【主环境】360 度拓扑读取并写清——**内开|外开**（或推拉/折叠/旋转轴向）、**门轴/铰链侧**（左/右）、**开闭状态**（紧闭/半开约几度/全开）、**门扇/窗扇占视轴比例**（占满 MG / 仅 FG 框缘 / 经门洞可见）；切衍生视角时须**按当前 Viewing Direction 重判**门扇可见面（室外侧/室内侧/铰链侧/把手侧），禁止照抄 0 度描述。
  - **② 内外侧与衍生 ENV（必填）**：判明本 Beat 观察侧在**门内|门外|窗内|窗外|经窗洞框景**哪一侧；**须切换**对应 `{N}度{主环境名}_门内|门外|窗内|窗外` 或等价衍生环境，**禁止**门内 POV 仍用主环境硬写门外 BG、禁止门外 POV 硬写门内陈设。**empty_view_delta** 须列门内/外切换时**新可见/退出可见**实体。

### 三、内容增强与文化纵深
- 改写前先核对项目时代/地理/族群阶层/制度/题材；缺失写“缺失：按原文与题材常识保守处理”。  
- 结构按“建置->发展->转折->高潮->尾钩”推演；明确发展重点段与高潮重点段。  
- 闪回仅可视觉化原文明示/强暗示信息，不得新增因果事件；**禁止自创 Scene/环境**（执行见强约束§8–§9）。  
- **闪回三档判定（强制先判，以上游为准）**：  
  - **完整闪回**：时间层切换、人物/环境/道具状态态与当下形成**可识别差异**、或回忆段落须独立承载对白链/动作链/信息 Reveal → **不必然拆独立 Scene**；**以原文/上游 Scene 切分为准**——原文已切独立场次/具明确时空跳跃且叙事目标切换时方可拆 Scene；原文嵌于单场、无独立时空切换、或叙事目标仍锚定当下场时，**优先** Scene 内**转场专拍 Beat**/**快速闪回**承载，**禁止**仅为满足「完整闪回」条件而自创 Scene 或虚构回忆地点 ENV；前后 Scene 间仍须保留桥接关系。  
  - **快速闪回（有情节）**：服务于当下场情绪/信息落点的**短促回忆对话或具名动作情节切片**（通常 1–3 Beat、单段 ≤8s 体感）；**启用门槛（强制）**：待视觉化呈现的**回忆对白原文合计须 >30 字**（含画外/OS/V.O. 闪切台词；不含仅触发回忆的当下台词如「你还记得吗」）；**≤30 字且含具体情节/对白**时**禁止**建快速闪回 Beat，改以当下场微表情/微动作、听者反应、口述转述或 `OS/V.O.` 承接。人物年龄态/妆发/服装、环境状态、道具状态与当下**无实质差异**，或差异仅通过质感处理（去色、虚化、噪点衰减、柔焦、慢速等）即可区分；回忆内容**补充印证**当前对白/反应，不独立承担新叙事目标。**不拆 Scene**，在当前 Scene 内以**转场专拍 Beat**（主节拍=快速闪回桥接）或插入节拍承载；须写清进入锚点（视线/物体/台词关键词/声音桥）与回切锚点（动作余势/声残响/构图呼应），手法优先：感官冲击闪切、定格闪帧、回忆质感衰减、闪回梦境叠化、跳切、声画对位。  
  - **无情节回忆切片（转场式）**：原文或强暗示仅有**印象/情绪/物象触发**，**无具体对白链、无完整动作情节、无独立信息 Reveal**（如「想起父亲的脸」「雨夜的车灯」「爆炸一闪」「童年走廊剪影」）；**不受 >30 字门槛约束**，**禁止**升格为完整闪回 Scene 或扩写为快速闪回 Beat。**处理方式**：按**转场手段**写入相邻 Beat 的转场链——触发（视线/物件/声/触觉）→ **≤2s 单幅或 1–2 帧印象切片**（写清可见物象/人物剪影/环境色块，**不要求**完整 FG/MG/BG 建置与对白咬合）→ 质感处理（去色/虚化/噪点/柔焦/慢速等）→ 回切当下（动作余势/微反应/声残响）；可并入上一 Beat 末、下一 Beat 初或短转场专拍，**主节拍仍归当下场**。**禁止**为无情节切片单独扩写对白链或完整动作链；切片内具名主体须列入【Scene实体覆盖】，但可仅写剪影/局部/impression 级落点。  
  - **回忆对话处理原则**：原文或强暗示的「想起/记得/当年/那时说过」类回忆——**无具体情节**→ **无情节回忆切片（转场式）**；**≤30 字且有具体情节/对白**→ 当下场口述/反应/OS，不闪回；**>30 字且未达完整闪回升格条件**→ **优先快速闪回**；**构成独立戏剧段落**（多轮对话、完整动作链、状态态大变）→ 若原文/上游已切独立场次则拆 Scene，**否则仍优先 Scene 内转场专拍/快速闪回**，不得自创 Scene 或回忆 ENV。  
  - **示例（快速闪回）**：回忆对白「爸，你别走，我会乖乖听话的，以后都听你的话，求你别丢下我一个人，我真的好怕」>30 字 → 转场专拍 Beat：银打火机特写 Match 切至回忆质感画面，幼年林医生对父亲上述对白闪切（≤8s）→ 声残响回切，陈医生面部微反应承接。  
  - **示例（无情节切片）**：林医生视线落向窗外雨痕 → 去色+柔焦 1 帧「童年走廊尽头父亲背影剪影」感官冲击闪切 → 回切当下，林医生喉结滚动、呼吸一滞；不建独立闪回 Beat，不拆 Scene，不写回忆对白链。  
- 古装/豪门必须体现礼法座次与高低站位。  
- **角色占位名→具名（强制，§18）**：改编前先扫描原文人物称呼；凡「男主/女主/主角/反派/男二/女二/龙套甲/路人甲/Boss/CP 男/女」等职能或番位词，须在本阶段统一替换为具体姓名；已有真实姓名者保留；新取名须服项目语言与时代/地理/题材/阶层/职业，全剧一致。Part 2 成稿、Scene 实体覆盖、Beat 落位、对白与全员反馈中**不得**残留占位称谓；Part 1 须输出完整对照表。
- `UI`/旁白/对白最终统一到剧本指定语种。

### 三-B、AI特效（§20）
- **定位**：前置规划可拍特效。
- **高成本优先(仙侠/武侠/玄幻/史诗)**：轻功/御剑/空战/域场/法相/巨物/多主体/尺度反差(§七-C)；同拍|专拍六相链；写实/职场不适用。
- **触发**：原文暗示｜仙侠/玄幻/科幻/奇幻/恐怖/超自然/史诗｜情绪转折/Reveal｜信息可视化｜域场建置。
- **分配**：同拍=短特效+形体绑定｜专拍=六相链分帧/域场/奇观；专拍前后咬合起势/落位。
- **状态衍生**：跨Beat改写结构/边界/布局 → `{主环境}_{状态}`(§10)+建置重建(§14)；瞬时光效/粒子不建衍生；光色材质由 Skill 1-3 细化。
- **方法库**：能量术法｜形体变身｜时空维度｜环境域场｜微观宏观｜光影质感｜情绪外化｜冲击破坏｜生物诡异｜科技赛博｜轻功飞翔空域(§七-C)。
- **禁**：装饰堆砌/无触发光效/纯特效替动作/改因果。

### 三-D、宏观群体 AI 高成本（§27）
- **适用**：大军/对阵/兽潮/机群/舰队/人海主节拍；同帧海量/极端密度/地平线铺满；禁稀疏小簇。
- **三要素**：`无边无际` FG→BG满幅｜`细节整齐` 同步阵列/三层满编+**剧本威武细节**｜`压迫感` 体量逼近/尘浪声浪/低角或俯瞰；高潮三项齐。
- **威武描绘双轨**：**全景层**（Drone/Crane/EWS/地平线铁流/满幅阵列）+ **剧本层**（Beat 成稿写盔甲、武器、旌旗、盾墙、戟林/枪阵、马具/舰炮/机甲轮廓、同步出鞘/举旗/踏步等可拍细节）；整齐细节 Beat 与高潮 Beat 各 ≥2 项装备/军械描写。
- **Beat链(≥6)**：①无边际 Drone/Crane/EWS ②整齐细节(Insert/Wide+**剧本军械描绘**) ③压迫 Tracking/低角尘浪 ④指挥 Scale Contrast ⑤高潮对冲 ⑥余波。
- **群演**：簇/阵/列写密度队形，不逐人具名；指挥/旗舰=体量锚。
- **区分**：背景2–3人小簇(§16) ≠ 宏观主节拍(本条)。

### 四、对白/旁白/心理外化
- **继承边界**：改标点控节奏，不改意图、词义、事实与因果。  
- **剧情承载（强制）**：每句对白/OS/V.O. 须推进立场/筹码/关系/前因/后果之一；跨 Beat 信息须靠对白承接、听者反应或当场交代来源，禁装饰性流水账；>20 字拆句时插入反应/动作切口使信息递进可读。  
- **每场拆句声明（强制）**：每个 Scene 在【对白拆句判定】中明确 `已拆句|未拆句|无对白`；已拆句须列原句→子句→Beat→切口对照；未拆句/无对白须附原因。Part 1【对白拆句自检】须逐 Scene 复核判定与【语言】成稿一致。  
- **情绪标点（强制）**：先判情绪阶段，再选标点；与 `tone`/`speed`/`volume` 一致；服务口型与微表情切口。可用：`，` `。` `……` `——` `！` `？` `、` `「」/""`；策略类型：压抑型、爆发型、试探型、喜剧型、治愈型、紧张型；>20字拆句时每子句自带标点。  
- **禁止**：滥用标点；标点与 `tone`/`speed` 冲突；改数字/**已确立真实姓名**/关键事实词（占位称谓→具名替换见强约束§18，不属于「改人名」）。  
- **OS/V.O./旁白**：明确归属与听者；适用情绪标点与同场反馈规则。  
- **自白/独白全员闭嘴（强制）**：凡 Beat 含**自白**或**独白**，执行下列规则，缺任一项即 Beat 不合格：  
  - **类型判定**：**自白**=面向自我/镜头/空位/无在场听众的独白式陈述（可画内可 OS）；**独白**=内心 OS/V.O./心理旁白/画外心声（通常 OS/V.O.，听众不在场或不可闻）。原文「独白」「自白」「内心」「心声」「OS」「V.O.」「旁白（角色心理）」等须归入本类并标注 `voice_type`。  
  - **全员闭嘴（强制）**：**除当前发言人外**，画内每一个可见具名角色与群演簇，均须在【全员反馈】写**闭嘴**（双唇紧闭/口型静止/未张嘴/唇线抿合）；可写眼神/呼吸/肢体微反应，**禁止**写口型变化、接话、同步张嘴。  
  - **发言人口型**：**画内自白**→仅发言人可写口型；**OS/V.O. 独白/自白**→发言人画内落位亦写**口型静止/未张嘴**（声画分离，画外声）。  
  - **核销位置**：【语言】标注 `voice_type=自白|独白`；【全员反馈】逐人/逐簇写闭嘴，禁止用「众人沉默」概括而不逐主体核销。  
  - ❌ 林医生独白 OS「我……没病。」｜全员反馈只写陈医生反应、未写闭嘴｜✅ 【语言】林医生（voice_type=独白，OS，画外声）「我……没病。」｜【全员反馈】林医生 **双唇紧闭、口型静止**；陈医生 **双唇紧闭**，眉弓渐蹙；办公人员簇 **全员双唇紧闭、口型静止**。  
- **主听众（强制）**：每轮标最主要听众及依据（`叙事目标相关度 > 视线直指 > 空间距离 > 因果承接`）；默认禁止并列，证据等强才写“并列：原因”。听众反应含动态微表情+微动作各≥1。  
- **心理外化**：转译为可拍微表情+微动作+道具接触+空间反馈；禁抽象情绪词（执行见强约束§5/§7）。  
- **环境补充**：仅服务剧情与动作逻辑；禁新增改变因果的实体/事件。  
- **输出**：【语言】直接写成稿台词；第一部分写【对白节奏标点】策略与典型落点。

### 五、角色表情与题材适配
- **先判表情强度**：`夸张型`（喜剧/轻喜剧/日常搞笑/闹剧/反差萌）| `细腻型`（情感/爱情/治愈/亲情/现实主义细腻/文艺）| `标准型`（悬疑/剧情/职场/犯罪等）；混合段按节拍切换。  
- **微表情选材**：优先从 §一「微表情常见项」择项组合；喜剧/夸张型场叠加 §一「喜剧类微表情常见项」；须写清部位与动态过程链，禁抽象情绪词。  
- **夸张型**：眉眼幅度大、嘴型明确、多肌肉组联动；反应可适度漫画感但真人可拍；肢体与表情同步夸张；包袱/误会/反转须补夸张表情切口，**优先用喜剧类微表情常见项**（挑眉飞挑、瞪眼、瘪嘴、憋笑抽搐、O 型嘴、斜眼睨视等）并写多部位联动过程链。  
- **细腻型**：写具体微动与渐变链（`前置克制 → 中段裂缝 → 落点余韵`）；强情绪也克制幅度。  
- **标准型**：清晰可读，在夸张与细腻间取中值。  
- **文戏特写增量**：每文戏 Scene 主角局部特写≥3（含强约束§4 的每场至少 1 处细节特写）；长对白每 2-3 句至少 1 处微表情+微动作组合。

### 六、影视化手法
- 可选标签：`MONTAGE`、`AV_CONTRAST`、`PROP_SYMBOL`、`MACRO_INTRO`、`CROSS_CUT`、`MATCH_CUT`、`POV`、`OFFSCREEN`、`JUMP_CUT`、`DOLLY_ZOOM`、`EMPTY_SHOT`。  
- 原则：只服务剧情推进/情绪外化/转场连贯，禁装饰性滥用。

### 七、文戏/武戏差异化
- 先判类型：对白情绪主导=文戏；打斗追逐术法主导=武戏；混合段按节拍切换。  
- **正式决战(§26)**：`正式决战=是` → ≥10 Beat → 【决战 Beat 规划】  
- **宏观群体(§27)**：`宏观群体=是` → ≥6 Beat → 【宏观 Beat 规划】；高潮三要素齐  
- **文戏模板**：`触发（台词/动作/停顿） → **观察视角（谁从哪看、看哪）** → 主角局部特写（部位+动态变化，须与当前视角/环境一致） → 下一承接`。  
- **武戏强制**：方向链+美感动作；**近身打击与投射攻击（子弹/飞镖/箭矢/暗器/投掷物/法术弹道等）均须写完整攻击链（出手→弹道/接触→命中部位→命中效果）**；术法/异能→六相链(§三-B)。**打斗默认每 Beat 有位移（强制）**：各参战角色须相对上一 Beat 终态写清三轴落位变化与轨迹节点，禁多 Beat 同站位硬写换招。**武戏视角—环境—朝向（与对白同等粒度，强制，§二）**：**逐 Beat**须写观察侧（OTS/正反/POV/Two Shot/Insert）、**FG/MG/BG 背景变化**、各参战者**朝向四要素**、双人/多人**入境出画**、ENV 切换与建置重建；读招/读势/读术法/读受击须 OTS 或正反切至可读衍生环境，禁止主环境错配。**环境切换与建置重建（打斗专项核验）**：观察视角/可读侧/绕障换区/域场态变化时须切换衍生或状态环境并重写 FG/MG/BG，通过 §12 可执行性校验；Part 1【Beat 完整逻辑自检】武戏场须逐 Beat 核「**视角/背景/朝向 + 位移闭环 + ENV 切换 + 建置重建**」。
- **武戏模板**：**观察视角声明**→ **环境/ENV 切换**→ **FG/MG/BG 背景层**→ **双人/多人落位与朝向四要素**→ 起势→**位移/换侧**→发力→换招/腾空→接触反馈→**终态落位**→特效→收势（三轴+FG/MG/BG；每段须可核对相对上一 Beat 的**视角/背景/朝向/落位 Delta**）。
- **正式决战模板（≥10 Beat，§26）**：对峙(1–2)｜试探(1–2)｜攻防≥4(换招/格挡/闪避/反击,含≥1轻功/空域)｜术法域场(1–2)｜逆转受伤(1–2)｜决胜(1–2)｜收势(1)；禁概括，须扩写≥10 Beat。
- **宏观群体模板（≥6 Beat，§27）**：建置(1–2,Drone/EWS,无边+整齐)｜细节(1,Insert+Wide+**剧本盔甲/武器/旌旗等威武描绘**)｜推进(1–2,Tracking/低角)｜焦点(1,Scale Contrast)｜高潮(1,对冲,三要素齐+军械细节)｜余波(1)；禁「大军开到/一触即发」。

### 七-B、武术/法术动作库（§26）
**武术**：起势｜试探｜拳/腿/格挡/闪避｜剑/刀/枪/双刀｜擒拿/摔投｜气劲  
**法术**：结印/引气｜五行｜御剑/剑阵｜符/阵｜护盾｜对撞/反制｜禁术｜域场｜法宝/法相｜收功  
**原则**：Beat择1–2项+三轴+轨迹+**命中部位与效果**；正式决战全覆盖。

### 七-C、轻功/飞翔/高成本奇观（§26/§三-B）
**轻功**：踏空｜檐上｜竹冠｜飞瀑｜凌波｜壁跑  
**御剑/飞**：冲天｜竞逐｜元气托身｜法相｜灵禽  
**空战**：换招｜俯冲｜对掌｜穿云｜托剑  
**域场**：云海｜法阵｜巨物  
**原则**：正式决战≥3 Beat；三轴轨迹+反馈；禁全场地面平拍。

### 七-D、宏观群体动作联想库（§27/§三-D）
**军**：地平线铁流｜同步踏步｜旌旗蔽日｜尘浪推进｜梯队纵深  
**对阵**：峡谷对垒｜阵线齐推｜冲锋对撞｜箭阵遮天｜鼓声压境  
**兽潮/人海**：兽潮满幅｜浪潮翻涌｜合围压迫  
**空/海**：天空遮满｜舰队铺满｜俯冲掠阵  
**阅兵**：方阵如棋｜整齐变换  
**剧本威武细节（整齐细节/高潮 Beat 择项，≥2/Beat）**：盔甲（鳞甲/札甲/明光/肩吞/护心镜/蹭痕与反光）｜武器（枪尖/戟刃/刀鞘/剑穗/弓弩/盾面/炮口/剑阵同高）｜旌旗（旗面边穗/旗杆林立/同色阵列）｜马具/载具（马铠/辔头/战车栏板/履带/舰桥/机甲轮廓）｜同步动作（同时出鞘/举盾/枪立/踏步步频一致/金属铿锵）  
**原则**：≥6 Beat六阶段各择1+；FG/MG/BG满编+队形+推进；**全景+剧本双轨**；高潮三要素齐；主将/旗舰=Scale Contrast。

## 输出模板与格式

### 第一部分：剧本改编补充说明
极简标签输出，只写结论；**用自然语言短句**覆盖各检查项，禁止粘贴键值模板；无改动项写“无：原因”。
- **【继承】**：剧情/动作/对白/OS/V.O./心理/环境/原文点出表演层：继承|扩写|改写|细分；未下放。  
- **【剧情叙事连贯】（强制，§2）**：逐 Scene 列「谁—欲何—阻何—已知—将变」落点；跨 Beat/Scene 情节桥梁与（若需）信息补偿是否完整；首/末 Beat 是否回扣上场、写清本场推进。
- **【角色命名】（强制，§19）**：占位名→具名对照表（原文称呼 → 保留/新取姓名 → 依据）；成稿是否已无「男主/女主/反派/龙套甲」等泛指；主要角色全剧称呼一致。
- **【项目考据】**：时代/地理/历史/文化/人文/民俗/礼仪：已核对|缺失；本次约束及影响项。
