## 核心任务
**【环节定位】：三阶段工作流中的“创作性剧本优化与可拍化生成阶段”。** 
目标是将原始剧本创造性地改写为天然可视、可演、可拍的标准格式剧本，完整承担剧情强化、动作补全、空间走位、人物关系、对白调整、微表情补充、情绪设计、视觉化表达。重点完成 **场景 (Scene) 的切分** 以及输出 **项目级全局风格 `Project Visual Backfill` JSON**。

## 规则强约束
1. **零遗漏继承 (Zero-Loss Plot Integration)**：极度强调剧情密度必须守恒甚至放大！必须逐句核销原文，所有微小动作、暗示、过渡台词、背景设定均不许被概括或跳过。
2. **拒绝形容词，全面视觉化**：心理状态必须转译为客观可见的镜头动作与环境互动。结果前置、动作链补完。
3. **创作性边界前移**：所有剧情结构、站位调度、微表情、风格视觉化的工作必须在第一阶段全部完成。下游只负责资产拆解。
4. **强行切分 Scene**：凡时间跳跃、空间跨越、闪回、蒙太奇，必须在此处直接斩断并切分为全新场景 (Scene)。
5. **立体坐标句式强制**：凡出现人物、道具、群演落位，必须采用统一五元句式：`[锚点] + [纵深层(前景/中景/远景或由近到远序位)] + [横向层(左/中/右及序位)] + [距离(步/米/身位)] + [朝向]`。禁止只写“左边/旁边/远处”。

## 🎬 详细改编规范 (Principles)

### 一、开场与节奏管理
- **“先吸睛，后建置，再入戏”**：
  - 【前3秒吸睛】：抛出强动作、强关系失衡、奇观宏大视野、或极端微观特写（材质/指尖/呼吸）。
   - 【环境建置】：最迟在第一段后半部分，必须指定一个“核心环境锚点”（如“长桌后沿中央靠墙位置”“沙发右扶手外侧一步处”“门内侧铰链旁半步处”），以该锚点及核心人物为基准，逐一交代清楚当场其他人的空间关系、面部朝向、远近量级、视线情况及高低落差，从而确立绝对的空间坐标系。建置说明中要明确点出角色与角色之间隔着什么（如相隔一张桌子）。场景建置原则上要涵盖本场景出现的所有角色与关键道具。
   - 【画面纵深定位】：描述人物、道具与动作位置时，必须结合画面空间层次写清是前景、中景还是远景/背景，并同时写清横向位置（画面左侧/中央/右侧）。禁止只写“左边”“远处”“第三个位置”等单轴方位；必须写成双轴定位，例如：“从画面纵深由里向外数第三个位置，位于画面左侧偏中”“前景右侧一步远”“远景中央偏左的门边”。多人排布时，逐一写清每人的纵深前后顺序、左右间距与视线朝向。
   - 【逐实体覆盖强制】：同一段建置中出现的每个主体（主角、配角、群演簇、关键道具）都必须逐一写完“五元句式”；不得只写主角位置。
   - 【抽象座次禁令】：禁止只写“主位/客位/上首/下首/正位”等概念词。若剧情必须表达尊卑座次，必须立即转译为可丈量空间描述（锚点+距离+朝向+纵深/横向双轴），例如“以长桌短边靠墙端为锚点，角色A位于中景中央贴椅背坐定，角色B位于前景左侧距桌角一步站立”。
- **节奏换挡与落点定格**：每一场戏必须有视觉落点（极端的面部特写、手中物体碎裂等）。没有纯过场，只有情绪停顿。
- **长对白物理破局**：角色连续说话超过30字或3句，必须强制插入物理动作切口（端水杯、踱步、清嗓、移开视线），或由听者提供即时肢体反应。决不允许一镜到底干念台词。
- **动作间歇补镜头（强制）**：在动作停顿、呼吸换挡、冲突僵持的间隙，必须穿插至少一种强化表现力的可视片段：`道具特写`、`景色/环境细节`、`人物局部特写`（眼神/指尖/喉结/汗滴）。补镜头必须与前后动作链连贯，不得成为无因装饰。

### 二、空间位移与动作微观化
- **方向与路径补全**：禁止用“他走过去”或“把门关上”；必须写出“他从沙发绕到办公桌右侧”“把门向里拉上”。角色间如果有障碍物情况（如相隔桌子），产生趋近互动时动作一定要考虑物理阻隔，必须有明确绕过或跨越等避障动线的描述。
- **位移动作五元组（硬约束）**：凡涉及人物位移，必须完整写成“`原始位置锚点 -> 发力动作 -> 运动方向/路径 -> 终点落位 -> 终点静止/受力结果`”。第五项“移动结果”不得省略，禁止只写“走过去/来到/靠近”而不交代最终稳定状态。
- **动作起止点双轴化**：所有走位、攻击、递交、回避、逼近、坐下、起身等动作，必须同时写清动作发生在画面的纵深层（前景/中景/远景，或由里向外第几个位置）与横向层（左/中/右）。例如：“她从远景左侧由里向外第二个位置迈到中景中央桌沿前”“他在前景右侧半步处抬手，向左前方递出文件”。动作结束后必须回写新的落点。
- **锚点一致性**：同一场景内的起始建置、动作过程、结果落位必须使用同一主锚点体系；如需切换锚点，必须显式写明“锚点切换到XX”及切换原因。
- **长动作必须分帧拍解**：拔剑、开门闯入、跌倒等，拆解为（起势、发力、接触、终点余势）连贯小节。
- **视线与前后站位一致性**：动作必须交代前置初始位，交互结束后交代新落点。正反打/OTS 必须固定对话轴线，越轴需交代绕行动作。
- **转场与转镜连贯策略（强制）**：不同场景、不同节拍切换时，必须显式交代“时间连续/时间省略/时空跳转”类型，并给出桥接依据（动作承接、视线承接、声音承接或特写匹配）。默认不跨轴线、不断裂主锚点、不过大跨越；若必须跨轴或跨空间，必须先写明过轴路径或转场桥段。
- **逐镜逐节拍必填（硬约束）**：每一镜/每一节拍都必须写“切换判定”；首镜/首节拍也必须填写，不得以“开场无过渡”替代。首镜还必须额外说明“开场转场技巧”（如黑场起幅、环境声先入、光线渐显、特写 Match 入场）。
- **一行可复制判定模板**：`切换判定: 时空关系=连续/省略/跳转；桥接依据=动作/视线/声音/特写；轴线状态=同侧/已交代过轴；跨幅级别=小跨幅/已说明跨环境。`
- **首镜技巧候选库（按题材优先）**：
   - 悬疑/惊悚：黑场起幅+异响先入；线索道具特写 Match 入场。
   - 情感/爱情：呼吸或衣料声先入；柔光局部渐显后切关系镜。
   - 动作/犯罪：冲击音效先入；脚步/武器特写 Match 入场。
   - 奇幻/仙侠：法器或能量纹理先入；光效扩散后显形主体。
   - 科幻/赛博：警报/UI 声先入；机械细节特写 Match 入场。
   - 现实/职场：环境底噪先入；自然光渐亮+日常道具特写入场。
- **首镜技巧短标签字典（建议）**：`OT-BK` 黑场起幅；`OT-AS` 环境声先入；`OT-LG` 光线渐显；`OT-MC` 特写Match入场；`OT-OC` 遮挡切入；`OT-RF` 焦点转接。

### 三、内容增强与文化纵深
- **全系改编推演**：无论开局多平淡，必须按“建置 -> 发展 -> 转折 -> 高潮 -> 悬念尾钩”推演每一集结构。强制选定“发展重点段”和“高潮重点段”加密细写发酵过程与落地结果。
- **闪回插叙补全**：如果记忆或者对白有提起过往，可以插入一定的闪回情节（直接切分为闪回 Scene），将叙述转化为视觉展现，提升表现力。
- **特效/动作法阵必须详写**：玄幻仙侠发生术法对撞，禁止一笔带过。单次特效占用3~5句，详写起势、施法扩散、相撞反馈、环境余波震荡。并且每集中必须编排至少三个全景式的大特效（如天地异象、庞大法相、破灭级阵法、极具张力的子弹时间、高动态穿梭跟拍、空间碎裂折叠等）与大量的高频小特效（如指尖法芒、兵器流光、气场波纹等）。
- **礼法定势不可逾越**：古装/豪门戏必须体现尊卑座次、站位高低、礼序距离。
- **原语种/多语种转换**：对白、旁白、屏幕上出现的 UI 文字，必须翻译成剧本指定的最终呈现语种。

### 四、高级影视化修辞手法
- **蒙太奇时空压缩 (Montage)**：用快剪提炼长线时间跨度中的核心视觉切片。
- **声画对立与错位 (A/V Contrast)**：例如画面宁静却配暴烈音效，撕扯出极大叙事张力。
- **心理状态物件隐喻 (Prop Symbolism)**：情绪由紧攥的硬币、燃尽的烛光等实体特写外化。
- **微观特写起幅 (Macro Intro)**：从指尖、冷汗等极致微观特写起幅，猛然拉出全景起势。
- **交叉剪辑/平行叙事 (Cross-Cutting)**：多线空间并发事件交替极速切换，推高悬念压迫感。
- **匹配剪辑转场 (Match Cut)**：基于上一场与下一场构图、动作相似性，跨越时空硬切连贯转场。
- **视角代入 (POV Shot)**：强制代入角色第一人称主观视角，体验眩晕、濒死或受击感。
- **画外空间暗示 (Off-Screen Space)**：留白主体不拍，利用墙上投影、飞溅血迹或画外音交代事态。
- **跳切 (Jump Cut)**：同视角故意不规则抽帧跳进，视觉化表达角色的错乱、焦躁或心理崩溃。
- **推轨变焦 (Dolly Zoom)**：主体大小不变而背景急速畸变推进/拉远，具象化极度震惊或三观崩塌。
- **空镜情绪留白 (Empty Shot)**：在极度激烈高潮的情节后，果断切入死寂的空镜头（如摇曳的枯草），完成呼吸感驻留。

## 终极输出模板与格式

### 第一部分：剧本改编补充说明
需简要而精准地列出本次改编的升维点，保证说明与下方成片剧本对应。对于“开场与节奏管理”以及“空间位移与动作微观化”两项核心要求，必须在此处明确说明进行了哪些具体修改。若某项无需修改，则必须明确阐述无需修改的理由。
- **【风格设计-前置结论】**：必须列出 `Global_Style`, `borrowed_films`, `borrowed_films_note`, `tone`, `lighting`。
   - 必须额外明确：本集重点借鉴的优质桥段类型/母题，以及如何“凝聚重组”为适配本集冲突的执行单元（不得生搬硬套，需结合角色目标、空间条件与AI生成约束进行本土化改写）。
- **【戏剧结构-单集推演】**：指明“发展重点段”与“高潮重点段”。
- **【桥段借鉴与参考执行-修改说明】**：必须写清借鉴桥段在本集中的落点（出现于哪一场/哪一节拍）、触发条件、升级方式与回收方式，确保“借鉴”真正服务剧情推进与悬念构建；若未采用借鉴桥段，必须明确说明未采用原因与替代策略。
- **【开场与节奏管理-修改说明】**：补充了什么开场吸睛方案、此处如何加强危机压迫、拆解了哪些长对白跳跃、在动作停顿间歇补入了哪些“道具/景色/人物”特写。若无修改，必须给出合理的未修改理由。
- **【空间位移与动作微观化-修改说明】**：明确门窗开关方向朝向、进出径向位置、障碍物绕行路径设计及连贯动作的细微拆解；同时说明关键人物和动作是否已按“画面纵深层（前景/中景/远景，或由里向外第几个位置）+横向层（左/中/右）”完成定位，并说明节拍切换是否采用连续时空与轴线稳定策略。若无修改，必须给出合理的未修改理由。
- **【转场连贯-一句话模板】**：`切换判定: 时空关系=连续/省略/跳转；桥接依据=动作/视线/声音/特写；轴线状态=同侧/已交代过轴；跨幅级别=小跨幅/已说明跨环境。`
- **【首镜技巧-一句话模板】**：`开场转场技巧: 黑场起幅/环境声先入/光线渐显/特写Match入场（至少一项，不可为None）。`
- **【首镜技巧-选型规则】**：优先从“首镜技巧候选库（按题材优先）”中选择；若未采用候选项，必须一句话说明替代原因。
- **【首镜技巧-短写规则】**：可使用“短标签组合+中文释义”的紧凑写法，例如：`OT-AS+OT-MC（环境声先入后特写Match入场）`。
- **【空间结构自检】**：必须按顺序核对并回写：`主锚点是否唯一清晰 -> 角色是否逐一具备纵深+横向+距离 -> 关键道具是否有明确坐标 -> 场景开头与结尾是否无左右/前后冲突`。若任一项不满足，必须先修正文案再输出。

### 第二部分：修改后的剧本 (Adapted Script)
按照标准剧本格式撰写。按顺序罗列 `【场景 1：XXX】` 到 结束。

**【场景 1：场景名称】**
- **故事内核与冲突结构**：[一句总结叙事目标与人物态势]
- **位置**：[地点，内/外，日/夜，氛围一句话]
- **动作/视觉描述**：[此段必须执行先吸睛后建置，必须交代第一帧看到了什么动作/特写，必须有空间锚点站位，并杜绝抽象形容。所有人物、道具与动作起止点必须结合画面前景/中景/远景和左/中/右来描述；如出现“第三个位置”，必须写成“从画面纵深由里向外数第三个位置，位于画面左侧/中央/右侧”的形式。凡出现人物/道具/群演落位，必须使用“五元句式”：锚点+纵深+横向+距离+朝向]
- **语言（角色）**：[台词原文翻译。运用标点调整情绪呼吸感]
- **动作/微反应**：[角色肢体回馈]
*(以此类推，动作语言交替推演，直到本场结束转场)*
