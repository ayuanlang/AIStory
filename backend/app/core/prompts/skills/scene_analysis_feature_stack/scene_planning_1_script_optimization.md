## 核心任务
**【环节】**三阶段中的剧本优化/继承扩写/可拍化生成。  
**【目标】**零遗漏继承 + 结构强化 + 合理改写 + 可视化前置 + **补全微表情与微动作**（让剧本与主动作更有表现力，让对白—反应—动作链更具连贯性）。  
**【覆盖】**剧情结构、站位调度、**微表情/微动作/微反应补全与动态过程链**、**对白—反应—动作连贯衔接**、每场细节特写、对白情绪标点与节奏、题材适配表情（喜剧夸张/情感细腻）、心理外化、风格视觉化、动作细分、**AI视觉特效强化**、对白与 `OS/V.O.`、环境补充、节奏转场、全员反馈闭环。  
**【边界】**不改原剧情事实、核心动作链、对白语义、人物关系；不得新增改变因果的新事件。**禁止**在本阶段输出或使用 `ENV`/`PROP`/`CHAR` 资产分类标签及 `ENV:`/`PROP:`/`CHAR:` 前缀；仅以剧本自然语言具名称呼人物、物件、空间；是否提取为资产、`ENV/PROP` 归属、升格归档与衍生变体均由 **Stage 2-1** 裁定。  
**【允许】**影视化插入：特技呈现、**AI可拍特效奇观**、环境描述、微反应、微表情/微动作、细节特写、动作拆解、对白停顿与颗粒度细分、**按情绪补标点控节奏**（不改对白语义与剧情信息）。  
**【AI优势】**主动运用生成式视觉能力：超大尺度、微观细节、能量物理、时空扭曲、风格化质感、多主体同帧奇观；原文未明示但题材/情绪/信息可视化需要时，可合理增补特效，不得改变因果。  
**【输出】**`Scene切分`、`环境/衍生环境说明`、`[ADAPTED_SCRIPT]`、`project_visual_backfill(JSON, 强制)`。

## 强约束
1. **零遗漏继承**：逐句核销；动作/暗示/过渡台词/背景设定不得跳过。  
2. **心理可视化**：心理必须转译为微动作、微表情、道具接触、空间反馈。  
3. **创作**：结构、站位、微表情/微动作/微反应、每场细节特写、风格视觉化、**主动作归属主动施力方（被动物件轨迹写入同 Beat，禁止客体独立成 Beat）**均在本阶段完成；即使原剧本已有场景分镜等的划分，也要遵守以下的规则进行创作。  
4. **每场细节特写（强制）**：每个 Scene **至少 1 处**；须写清特写对象、可见部位、**变化过程**、叙事功能、承接 Beat；禁止整场无特写切口。落点优先：情绪转折/信息落点、长对白停顿与听者反应、道具线索/环境纹理、武戏接触受力瞬间。  
5. **微表情+微动作双轨（强制）**：每个【动作/视觉节拍】除主节拍外，须各含至少一项微表情与微动作；均按**动态过程链**书写：`部位 → 起始态 → 变化方向/幅度/节奏 → 落点/余韵`；禁止静态定格式（如只写“皱眉/紧张/手抖”）。长对白/停顿处优先插入组合切口；**原文未写但情绪/信息/动作链需要处须主动补全**，不得留表演真空。  
6. **表演连贯性（强制）**：相邻 Beat、台词轮次与主动作须**承接上一落点/余韵**；对白后必有听者/触发者动态反应，反应后再入下一台词或主动作，禁止对白—反应—动作链断层。跨 Beat 持续情绪须写渐变或保持态；情绪、视线、重心、握物等状态跳变须有触发交代（台词/动作/环境刺激）。主动作起势须呼应前一 Beat 身体姿态与视线；武戏形体链与微表情/微动作同链咬合，禁止 Beat 间表演层断裂或情绪复位无依据。  
7. **原文点出表演层（特别提醒）**：原文明确写出或强暗示的表情、神态、视线、呼吸、手部/肩颈/喉结细部、停顿反应，须**逐项核销并可视化动态改写**进【动作/视觉节拍】/【语言】/【全员反馈】；禁止遗漏、合并吞掉、仅留对白删表演层，或压成静态形容词。改编前先建**核销清单**（原文表述 → Beat 落点 → 动态改写）。  
8. **Scene切分**：按连续时空+同叙事目标划分；时间跳跃/空间跨越/**完整闪回/回忆段落**（见§三「快速闪回 vs 完整闪回」）/闪回蒙太奇/目标切换/行动线切换即新 Scene；**快速闪回**（短促回忆对话/画面切片，叙事目标仍锚定当下场；**仅当待呈现回忆对白合计 >30 字**，见§三）不新建 Scene，以**转场专拍 Beat** 或同场插入节拍承载；仅视角/构图/特写/正反/节拍变化不新建 Scene。  
9. **环境定义**：环境=可复用拍摄空间，按空镜写：边界、内外/日夜、空间基准点、固定结构、固定家具/基础陈设、光源、声源、阻隔、尺度、景深层次。思考时可先用“主锚点”定空间原点，成稿须写为具体空间结构具名部位（如「会议桌右前角」「文件柜玻璃门」）。人物与可交互物件以剧名/物件名书写，**不预做资产分类**；会被拿起/递交/移出/破坏/独立展示或跨 Beat 承接状态的物件须写清可拍动作证据，归属由 Stage 2-1 裁定。  
10. **主/衍生环境**：每个 Scene 1 个主环境（0度正面建置）。衍生环境分两类，须分别扫描，不得互相替代：  
  - **视角衍生**：主环境顺时针 45 度倍数切换（`OTS`、门窗内外、屏幕内、镜中、遮挡后、画外声源等触发）；命名 `{观察角度}度{主环境名}`，冲突时追加 `_{衍生类型/观察区域/可见方向}`。  
  - **状态/特效衍生**：AI 特效/域场/环境级冲击导致**固定结构、光源、边界或可拍空镜基准**发生**剧烈且可持续**变化，且须**延续至下一 Beat 及后续 Beat**（非纯瞬时光效/粒子/拖尾）时，必须另建状态衍生环境；命名 `{主环境名}_{状态/域场标识}`，如 `侯府正厅_符阵覆盖态`、`实验室_磁暴电离域`。  
  - **扫描默认“有”**：每 Scene 必扫 `0/45/90/135/180/225/270/315` 视角衍生；**凡 Scene 含环境级特效/域场/结构破坏再生且余波或后果跨 Beat**，必扫状态衍生。仅“5秒内、极简单轴、少/无对白、无多角度触发、无跨 Beat 环境态变化、无后续切换需求”可写无，须附 `无：否决证据`。  
11. **站位与空间建置（强制）**：  
  - **核心定义（先三层，再层内逐个）**：建置与站位须按**固定书写顺序**展开：**① 先建 FG/MG/BG 三层框架**（每层写清结构/边界/框景阻隔与层间关系；无有效前景须说明原因）；**② 再在每个层位内，对该层出现的每一个人物与物体逐个、具名**写清站位（横向序位、距参照物距离、朝向/视线、姿态/动作/接触状态、与他者的相对距离与隔障）。禁止跳过三层直接按人名罗列；禁止只写环境氛围或「两人在桌边对峙」等笼统句；**画内可见主体清单（§16）中的已入场者，须在本 Beat 三层内全部落位**，未写到的视为建置缺口。群演簇可按簇描述，但须写清簇内人数、分布区段与朝向。
  - **书写顺序（强制）**：`观察视角+环境 → FG（结构+层间关系 → 本层每个主体逐个落位）→ MG（结构+层间关系 → 本层每个主体逐个落位）→ BG（结构+层间关系 → 本层每个主体逐个落位）`。成稿须按 **FG → MG → BG** 分段叙述，不得打乱层序。
  - **层内逐主体五要素（强制，该层内每个人物/物体各写一遍）**：`[具名主体] + [横向序位] + [距参照物距离] + [身体朝向] + [面部/视线落点（看谁/回避/画外）] + [姿态/动作/接触状态] + [与他者/环境的相对关系（距离/隔障/高低差）]`；有对白时另须核验**说话人/听者/主听众**朝向是否与该句咬合；主体所属 FG/MG/BG 由所在层段隐含，层内缺任一要素即该主体建置不完整。
  - **思考模板（内部推演，不得原样输出）**：`[环境/主锚点逻辑] + [视角角度] + [FG/MG/BG 各层结构] + [各层内主体逐个落位] + [空间约束] + [环境切换]`
  - **成稿覆盖项**：当前环境名与观察基点、视角角度、**FG/MG/BG 三层框架（结构+层间关系）**、**每层内每个可见人物/物件的独立落位**、距具体参照物距离、阻隔/高低差/行动余量、人物朝向视线、相对实体定位、环境切换。全部内容不得留空或"-"等符号替代；**禁止**用「全员/两人/若干道具已就位」概括替代层内逐个主体描述。
  - **关系驱动站位（强制）**：建置须**先判本场已入场/待入画人物之间的戏剧关系**（尊卑/职级、亲疏/同盟/对立、主客/攻守、保护-被保护、监视-被监视、情感张力等），再据此决定**相互距离、左右/前后序位、高低差、是否隔障、视线是否交汇或回避**；禁止只按几何坐标排人而不体现关系语义。典型：对立/审讯→拉大距离或隔桌/隔障；亲密/同盟→缩短距离或同侧并列；尊卑/主客→尊位/高位/内侧优先，卑位/低位/外侧或下首；护卫→贴近被护者侧后、面向威胁侧；新入画者落位须与已在场者关系一致，并触发 §14 建置重评估。  
  - **建置逻辑核验（强制，认真分析非机械填坐标）**：落位前须完成**全局可见 + 空间逻辑 + 朝向/视线 + 对白咬合**四步核验；禁止不经分析直接堆坐标。  
    - **全局可见性**：在**当前 Beat `Observer View` 所声明的观察视角**下，FG/MG/BG 各层内写出的每个主体须**确属该视角可实际看见**（含被虚焦/半遮挡但仍可读的情况须说明）；画外/完全遮挡/背对不可读者不得写入该层「可见落位」而不交代；若主体暂不可见，须标注「画外/待入画 Beat+方向」或切至可读视角后再写口型/眼神。  
    - **空间逻辑一致**：距离、隔障、高低差、通行路径须与三层结构、动作链、道具交互一致；禁止同一 Beat 内前后矛盾（如 MG 写「距桌沿一步」、同段又写「已退至门边」而无位移交代）。  
    - **朝向/视线逐项分析（强制）**：每个画内人物须分别写清**身体朝向**（躯干/肩线/座姿/站姿面向）、**面部/视线落点**（看谁/看哪/回避/游移/定格）、**是否可读**（口型/眼神/微表情在该视角下是否可拍）；禁止只写「面朝左/朝窗/朝门」而不写**看谁**；道具/物件须写**相对使用者的朝向与接触面**（如文件封面朝向林医生、杯口朝上等）。  
    - **对白—朝向—听者咬合（强制）**：本 Beat 含**画内对白/OS/V.O./独白**时，站位须与说话—聆听关系同拍咬合：  
      - **说话人**：身体/面部/视线须指向本 Beat **主听众**（或明确声源对象）；台词含**第二人称/直呼其名/「你」「您」/指向性称谓**时，朝向须与**被点名的具名人物**一致，禁止说话人背对或侧背主听众却标「正在对白」。  
      - **主听众**：须面朝说话人、侧耳倾听、或写清**有意回避/偷听/分心/群听**等例外及视线落点；闭口/微反应须在可读角度内。  
      - **多人场**：逐轮对白须标注**该句主听众**；轮次切换时朝向/视线可随主听众变更，但须写清变化触发（谁开口、谁接话、谁转看）。  
      - **画外 V.O./OS/旁白**：画内角色不对不存在声源主体 Push In 或张嘴；听者看**声源方向/物件/空位**，而非虚构画内说话人。  
      - **Walk-and-Talk / 边走边谈**：朝向可随路径微变，但每句 `(Pn)` 仍须写清该句说话人面部是否可读、听者是否在侧前方/后方可反应位。  
    - **正反例**：❌ 林医生对陈医生说「把文件给我」，林医生却写「背对陈医生面朝窗」。✅ 林医生坐姿前倾，**面朝右、视线锁定陈医生**，桌沿隔障；陈医生**面朝左回视**，闭口倾听。❌ OTS 过肩镜只写陈医生背影，同 Beat 却要求读陈医生口型。✅ 切至陈医生正面近景（衍生环境反打）后再写对白与口型。  
  - **成稿示例（先三层，再层内逐个）**：0 度观察，办公室正面会客区。**FG**：无有效近距遮挡（桌面以上无框景），不干扰中景主体。**MG**：结构为会议桌桌面与桌沿，层间关系为承载主关系层——**林医生**：偏左三分之一，距桌沿右前角约 0.8 米，坐姿前倾，面朝右看向陈医生，身体介于本人与文件夹之间；**陈医生**：偏右三分之一，距桌后缘约 0.5 米，坐姿后仰，面朝左回视林医生，与林医生相距约 1.2 米（桌沿隔障）；**桌上文件夹**：居中偏右，距林医生指尖约 0.3 米，平放桌面。**BG**：结构为后墙文件柜与百叶，层间关系为虚焦纵深——文件柜前左后 2–3 名办公人员停谈转头，目光朝中景双人区。❌ 跳过 FG/MG/BG 直接写「林医生在中景、陈医生在中景」；❌ 只写「两人在桌边对峙」。  
12. **观察视角—环境—建置三位一体（强制，Beat 粒度）**：每个 Beat **必须先写清观察视角**，再写环境与 FG/MG/BG 建置；三者必须互相匹配、同拍咬合，禁止只写动作/表情而隐去观察侧。  
  - **Beat 视角必填项**：当前环境名（主或衍生）、观察起点（谁在何位/何结构旁/何机位逻辑观察）、观察角度（0/45/90…度或 OTS/正反/POV/插入特写等）、观察目标（看谁/看什么部位/什么物件）、可见范围边界（画内可见 vs 画外/遮挡）。  
  - **视角—环境匹配**：FG/MG/BG 必须按**当前 Beat 的观察视角**展开；切至衍生环境后，观察视角、空间轴、空镜差异须同步切换，不得沿用主环境 0 度视角写层位。  
  - **视角—建置匹配**：同一 Beat 内，观察视角决定三层可见内容；**须先写 FG/MG/BG 框架，再各层内逐个主体落位**；写眼神/口型/局部特写前，须先交代该特写所对应的观察侧与环境（如正面近景、OTS 过肩、镜中反视等）。  
  - **视角变化即建置重评估（强制）**：观察视角发生实质变化时，**必须**触发 §14 建置重评估，成稿须**显式说明**「观察视角已变 → 当前环境（主/衍生）→ 建置是否重建及原因」。典型触发：背部/背影观察 → 正面/眼部/口型特写；全景建置 → 插入局部特写；OTS/正反打切换；越轴；POV/主观镜；镜中/屏幕内/门窗内外视角切换。  
  - **正反例**：❌ Beat 2 只写“陈医生眼神由平渐锐，眼尾轻颤”，未说明已从背部观察切至正面眼部近景、环境是否仍为办公室正面或已切衍生反打环境。✅ Beat 2：视线 Match 后，观察视角由林医生右后侧 OTS 切至陈医生正面 45 度近景（衍生环境：办公室桌后反打），建置重建——前景无有效遮挡；中景为陈医生面部占画面左三分之二；背景为文件柜虚焦；在此视角下写眼神由平渐锐、眼尾轻颤。  
13. **景深层次建置（强制）**：每个 Beat 按**当前 Beat 已声明的观察视角**，**先**写清 **FG → MG → BG** 三层框架（每层：结构/边界/框景阻隔 + 层间关系），**再**在**每一层内**对该层每一个人物/物件/群演簇**逐个**写清落位（横向序位、距参照物距离、朝向/视线、姿态/接触状态；不得合并为「中景两人」）。禁止只写“纵深/远近”不拆层；无有效前景时说明原因。  
14. **Beat 建置重评估（强制）**：每 Beat 对比上一 Beat 的**观察视角**与 FG/MG/BG。须完整重写三层：Scene/Beat 首幅、**观察视角实质变化**、切至/返回衍生环境、越轴或观察角度变化、主体跨层位移、物体换层、群演换层、出入画、**新主体首次入画/首次交互**。**环境变化原则上须重建建置**（建置更新=是）。可只列变更项：仅层内微动、观察视角与三层构成均不变。成稿用自然语言说明「观察视角 + 环境 + 是否重建三层及变更项」；**第二部分禁止**仅写 `建置更新=是|否` 而不展开。  
15. **每个新 Scene 三步开场（强制）**：新 Scene 首【动作/视觉节拍】按 **先吸睛（前3秒）→ 再建置（观察视角+当前环境+空间基准实体+空间轴+先 FG/MG/BG 三层框架、再每层内逐个写清人物与物体落位）→ 再入戏** 展开；全剧第一场与场间切换同等适用；**场间切换须先完成 §一-B 转场逻辑链 Step1–3，再执行三步**。
16. **Scene 实体覆盖评估（强制）**：每个 Scene 开场建置前，先盘点本场全部可见主体（人物、物件、群演及后续 Beat 才入画/才被交互/才成为感知焦点者；**含完整闪回 Scene 全量主体、Scene 内快速闪回/回忆切片 Beat 中出现的可见主体**）。已入场者须在开场建置 Beat **先建 FG/MG/BG 三层，再在各层内逐个**给出落位与初始状态（位置、距离、朝向、姿态等，见§11）；未入场者须标注「待入画 Beat + 触发条件/出入画方向」；**快速闪回切片内首次出现、仅存在于回忆时空的主体同样须列入本场【Scene实体覆盖】并具名**。任一 Beat 新出现的主体若前序 Beat 无落位或出入画交代，该 Beat 必须触发 §14 建置重评估并补全三层。本项只负责**空间可见性与落位闭环**及**可拍交互证据**（拿起、递交、移出、破坏、跨 Beat 状态承接等）；**禁止**预列资产表或使用 `ENV/PROP/CHAR` 标签；主体分类、升格归档、衍生变体、环境补建、`ENV/PROP` 归属等归 Stage 2-1。

18. **自然语言成稿（强制）**：模板、键值串、思考模板仅为覆盖校验与内部推演；第一、二部分须改写为连贯自然语言，逐项覆盖硬约束，禁止照搬 `字段=值` 或裸标签堆砌。第三部分 JSON 除外。

23. **每场对白拆句判定（强制）**：每个 Scene **必须**单独输出【对白拆句判定】，明确本场是否进行了拆句处理；禁止省略、默认不写或仅在 Part 1 汇总而不逐场声明。

  - **与成稿一致**：【对白拆句判定】须与【语言】各 Beat 成稿台词、拆句结果一一可核销；拆句不改词义与剧情信息，仅断句+标点+节奏。

## Scene/环境识别
- **流程**：先判 Scene，再判主环境，再判衍生环境。  
- **Scene四问**：时间连续？空间连续？行动线连续？叙事目标连续？任一断裂即新 Scene。  
- **环境六要素**：环境名、内/外、日/夜、空间基准实体、空间边界、固定结构。  
- **环境描述边界**：仅写影响交互/站位/通行/遮挡/攻防/视线/声音定位的空间约束；不写材质纹理工艺配色等美术细节。  
- **命名**：主环境=“功能/地点+关键特征”（0 度基准，不加角度前缀）。**视角衍生**=`{观察角度}度{主环境名}`，同角度多区域冲突时追加 `_{衍生类型/观察区域/可见方向}`，如 `45度办公室会客区`、`180度办公室会客区_桌后反打`。**状态/特效衍生**=`{主环境名}_{状态/域场标识}`，如 `办公室会客区_符阵覆盖态`、`侯府正厅_墙体崩塌态`；与视角衍生可同时存在、分别切换。  
- **切换句式（强制）**：视角衍生写 `触发 -> 顺时针角度 -> 切至/返回 环境名 -> 空镜差异 -> 下一节拍承接`；状态/特效衍生写 `特效触发/六相链落点 -> 环境剧变完成（通常在维持/余波相）-> 切至/返回 状态衍生环境名 -> 空镜差异（固定结构/光源/边界变化）-> 下一 Beat 起沿用直至恢复触发`。  
- **禁令**：氛围/情绪/景别/特写不是环境；停顿/表情变化/正反打不是新 Scene。

### 一-B、场景切换与首节拍转场（合并说明，强制）
本小节统摄 **Beat 间过渡、Scene 内快速闪回、Scene 间切换、每场首节拍**；与 §二「转场专拍 Beat」「转场手段参考库」配套使用。Part 1 / Part 2 **禁止**将切换判定、首节拍技巧、出场转场拆成三处各写一半，须合并写入 **【场景切换与首节拍转场】**。

- **转场逻辑链（强制顺序，逐 Scene 走完）**：  
  1. **上场承接**：读取上一场【视觉落点】为本场入点锚；写明「上场落点 → 本场如何接住」（动作余势/视线/声音/物体/色调/构图之一或多）；全剧第一场写「无上场：开场特例」。  
  2. **切换判定（四项必填）**：`时空关系`（连续/省略/跳转）｜`桥接依据`（动作/视线/声音/特写/色调/光影/遮挡/图形 Match/运镜/声画对位等，至少一项）｜`轴线状态`（同侧/已交代过轴）｜`跨幅级别`（小跨幅/已说明跨环境）。禁止无依据硬切。  
  3. **手法选定**：从 §二「首节拍 OT 标签」+「转场手段参考库」各选 **≥1 项**；场间切换与每场首节拍**须标 OT 简称** + 自然语言可拍描述；Beat 间小过渡可只写手段名称。  
  4. **首节拍三步咬合**（强约束§15）：**吸睛（前 3 秒）→ 建置（观察视角+环境+先 FG/MG/BG 三层、再每层内逐个实体落位）→ 入戏**；吸睛手段须与 Step2 桥接依据、Step3 OT/转场手法**同链**，局部特写吸睛后须后拉/摇移或紧接全局建置。  
  5. **下场预埋**：本场末 Beat 或【视觉落点】须写明可供下一场 Step1 承接的锚点（落点画面/动作态/声源/物件状态）。

- **三层切换粒度**：  
  | 层级 | 典型场景 | 写法要点 |  
  |---|---|---|  
  | **Beat 间** | 正反打、视线 Match、快速闪回 | 同 Scene；可建转场专拍 Beat；切换判定四项简写即可 |  
  | **Scene 内插入** | 快速闪回（回忆对白 >30 字） | 不拆 Scene；主节拍=快速闪回桥接；须进入/回切锚点（§三） |  
  | **Scene 间** | 时空跳跃、空间跨越、完整闪回 | 新 Scene 首节拍走完全链；上场末+本场首须双端桥接；完整闪回另拆独立 Scene |

- **首节拍技巧 = 场间转场技巧**：每场第一个【动作/视觉节拍】的 OT/转场手法，即本场**入画方式**；须同时回答——**从哪来（上场承接）→ 怎么切进来（桥接+OT）→ 第一眼看什么（吸睛）→ 空间怎么建立（建置）→ 戏从哪入（入戏）**。  
- **参考片对标（强制）**：每场至少写 1 部 `borrowed_films` 中对标片 + 具体手法（如「《xxx》走廊跟拍入画，OT-TR 横移穿越」），不得只写片名或只写 OT 代号。  
- **与转场专拍 Beat 分工**：需独立展开的桥接情节（场间省略、蒙太奇、声画对位、快速闪回等）→ 上场末 Beat 或本场首 Beat 建**转场专拍 Beat**（主节拍=转场/快速闪回桥接），其前后 Beat 仍须写切换判定与承接；简单连续时空且桥接可在首节拍三步内完成 → 不必另建专拍 Beat。  
- **正反例**：❌ 【切换判定】写「跳转+硬切」；【Scene 首节拍技巧】另写「特写吸睛」；【视觉落点】写「结束」——三处互不承接。✅ 【场景切换与首节拍转场】上场林医生推门落点 → 切换判定：连续省略｜声画对位+色调渐变｜同侧｜小跨幅 → OT-LG 走廊灯光由暖渐冷+OT-TR 横移穿越（对标《xxx》）→ 首节拍：门缝光带收窄吸睛 → Pullback 建置走廊 FG/MG/BG → 陈医生脚步声入戏。

### 二、空间位移与动作微观化
- **主节拍/主动作（强制）**：每 Beat 标明**唯一**主节拍/主动作，且**必须归属主动施力方**（**例外**：转场专拍 Beat 主节拍=转场桥接，见下条）；被动物件的运动、落点、碰撞仅为该 Beat 因果链的延续描述，不得升格为独立 Beat。微动作不得替代主动作，但须在全员反馈与对白停顿中持续落地。  
- **形体动作因果链（强制）**：施力-受力、接触-运动等同链，须先写完整主动作与受力反馈，再写结果轨迹/落点；禁止只写结果（反例：只写“球滚向门口”）。**主节拍必须归属主动施力方**（人物、有自主意识的活物、或术法/机关的明确触发者）；**禁止**将被动物件/受力客体（球、杯、纸张、飞出的道具等）拆为独立 Beat 的「自主运动」——客体轨迹、旋转、飞行、落点、碰撞须写入施力方同一 Beat 的因果链内连贯描述。链过长可拆 Beat：**施力起势 Beat** → **同一施力方动作延续 Beat**（含客体全程轨迹至静止/命中）；或 **接续受力方反应 Beat**（新的主动施力/拦截/承接方入画）；**禁止**拆出「客体独立主动作 Beat」。仅当**新的主动施力方**接续（对方接球、门将扑救、第二人拦截等）时，方可新开 Beat，主节拍归新施力方。  
- **主动作主体示例**：❌ Beat 1 主角踢球；Beat 2 球飞向门口。✅ Beat 1 主角右脚发力踢球→球沿低平弧线飞向门口、在门槛反弹后滚入走廊。  
- **特效拆 Beat（例外）**：术法/域场/奇观六相链过长时，可 **起势 Beat → 特效专拍 Beat → 落位 Beat**（细则见§三-B）；不得替代形体动作链，不得跳过触发源。  
- **转场/过渡专拍 Beat（例外）**：凡 Beat 间、Scene 间或时空/情绪/信息需桥接的转场，本阶段为连贯性**优化补写的过渡情节**（蒙太奇切片、空镜桥接、声画对位、匹配切、走位穿越、环境异象铺垫、情绪余韵承接、**快速闪回**等）**可单独建 Beat**；**主节拍=转场桥接**（快速闪回时主节拍=快速闪回桥接，**须满足回忆对白 >30 字**，见§三）；须写清：切换判定（时空关系/桥接依据/轴线状态/跨幅级别）、前后承接落点、OT 或转场手段名称、可视过程链；**快速闪回**另须标明进入锚点、回忆切片内容（对白/动作要点）、回切锚点与质感处理（见§三）。此类 Beat 服务于叙事连贯与转场可读，**不**视为客体独立主动作；**禁止**无桥接依据的硬切占位。  
- **转场专拍示例**：Beat 3 对白落点，林医生视线定格门外→ Beat 4【转场桥接】走廊灯光由暖渐冷、脚步声叠化、门缝光带收窄（桥接依据：声画对位+色调渐变；时空关系：连续省略）→ Beat 5 陈医生推门入画。  
- 路径、开关方向、进出径向、绕障路线须写清。  
- 高动量段落须写速度状态（起速/加速/急停/失速）+ 方向变化节点。

### 三、内容增强与文化纵深
- 改写前先核对项目时代/地理/族群阶层/制度/题材；缺失写“缺失：按原文与题材常识保守处理”。  
- 结构按“建置->发展->转折->高潮->尾钩”推演；明确发展重点段与高潮重点段。  
- 闪回仅可视觉化原文明示/强暗示信息，不得新增因果事件。  
- **快速闪回 vs 完整闪回（强制先判）**：  
  - **快速闪回**：服务于当下场情绪/信息落点的**短促回忆对话或画面切片**（通常 1–3 Beat、单段 ≤8s 体感）；**启用门槛（强制）**：待视觉化呈现的**回忆对白原文合计须 >30 字**（含画外/OS/V.O. 闪切台词；不含仅触发回忆的当下台词如「你还记得吗」）；≤30 字回忆内容**禁止**建快速闪回 Beat，改以当下场微表情/微动作、听者反应、口述转述或 `OS/V.O.` 承接，不得为短句单独闪切。人物年龄态/妆发/服装、环境状态、道具状态与当下**无实质差异**，或差异仅通过质感处理（去色、虚化、噪点衰减、柔焦、慢速等）即可区分；回忆内容**补充印证**当前对白/反应，不独立承担新叙事目标。**不拆 Scene**，在当前 Scene 内以**转场专拍 Beat**（主节拍=快速闪回桥接）或插入节拍承载；须写清进入锚点（视线/物体/台词关键词/声音桥）与回切锚点（动作余势/声残响/构图呼应），手法优先：感官冲击闪切、定格闪帧、回忆质感衰减、闪回梦境叠化、跳切、声画对位。  
  - **完整闪回**：时间层切换、人物/环境/道具状态态与当下形成**可识别差异**、或回忆段落须独立承载对白链/动作链/信息 Reveal → **必须拆独立 Scene**（执行见强约束§8）；前后 Scene 间仍须保留桥接关系。  
  - **回忆对话处理原则**：原文或强暗示的「想起/记得/当年/那时说过」类回忆对白——**≤30 字**：当下场口述/反应/OS 即可，不闪回；**>30 字且未达完整闪回升格条件**：**优先快速闪回**而非扩写为完整回忆场；**构成独立戏剧段落**（多轮对话、完整动作链、状态态大变）→ 升格为完整闪回 Scene。  
  - **正反例**：❌ 当下对谈中一句「你还记得那天吗」→ 拆出完整童年 Scene 三场对谈。❌ 回忆仅「别怕」2 字 → 建快速闪回 Beat 闪切。✅ 回忆对白「爸，你别走，我会乖乖听话的，以后都听你的话，求你别丢下我一个人，我真的好怕」>30 字 → 转场专拍 Beat：银打火机特写 Match 切至回忆质感画面，幼年林医生对父亲上述对白闪切（≤8s）→ 声残响回切，陈医生面部微反应承接。  
- 古装/豪门必须体现礼法座次与高低站位。  
- `UI`/旁白/对白最终统一到剧本指定语种。

### 三-B、AI视觉特效强化（细则，强约束§18之展开）
- **定位**：本阶段须**前置规划**可拍特效，不得留给下游即兴补。  
- **触发判定（满足任一即须考虑）**：原文明示/强暗示术法异能科技奇观；题材属仙侠/玄幻/科幻/奇幻/恐怖/悬疑超自然/史诗战争；情绪高潮/转折/Reveal 需视觉外化；信息可视化；空间建置需天地异象或环境域场。  
- **Beat 分配**：  
  - **同拍咬合**：特效较短、与单一形体动作强绑定 → 写入同一 Beat，与角色主动作同框。  
  - **特效专拍 Beat**：六相链须分帧、域场/对抗/宏观微观奇观、或单 Beat 塞不下完整链 → 单独 Beat，**主节拍=六相链**；前 Beat 写触发/起势，后 Beat 写命中后果/落位/收势；专拍内锚定角色具名与微动作/微表情。  
- **特效环境衍生（强制，跨 Beat 承接）**：当特效/域场/环境级冲击改写**固定结构、光源、边界或可拍空镜基准**，且变化须**延续至下一 Beat 及后续 Beat**时：  
  - **升格门槛（须同时满足）**：① 六相链「命中/维持/余波」已改写 FG/MG/BG 内空间结构或空镜基准（如墙体崩裂、地面陷落/符纹定帧、寒潮域场、黑雾半室、建筑再生完成态等）；② 已写明变化**至少延续到下一 Beat**；③ 非仅观察角度切换。  
  - **专拍/同拍分工**：环境剧变可在**特效专拍 Beat 的维持/余波相**完成，或**同拍六相链**内完成；**下一 Beat 起 `当前环境` 必须切换为状态衍生环境**（强约束§10 命名），并触发 §14 建置重评估——FG/MG/BG 须按**新空镜约束**重写，不得沿用破坏/域场前的主环境建置。  
  - **返回主环境**：术法消散、域场解除、时间跳转、Scene 切换等恢复基准态时，须写清触发与 `返回 {主环境名}`；纯 Beat 内瞬时光效/粒子/拖尾**不**建状态衍生环境。  
  - **正反例**：❌ Beat 5 符阵炸开席卷整室，Beat 6 仍写「当前环境：办公室正面」且三层按破坏前描述。✅ Beat 5 专拍符阵炸开，地面符纹定帧、文件柜半倾、冷蓝域光压顶（余波相完成）；Beat 6 起切换至「办公室会客区_符阵覆盖态」，建置重建——MG 桌面被光幕覆盖、BG 文件柜倾斜虚焦，人物落位按新空镜重写。  
- **写法**：自然语言；写清作用范围与 FG/MG/BG 内受影响人物/物件/空间结构；追逐/对抗类须写速度+方向变化并回写新落位。

  - **时空/维度类**：时间冻结变速、空间折叠扭曲、门扉传送、平行叠影、记忆闪回实体化、预知幻象、因果回溯残像、次元裂缝、时空涟漪、画中界出入。  
  - **环境/气象域场类**：局部天气改写、地貌瞬时变化、建筑崩塌再生、水面倒流、火焰寒潮域场、磁暴电离、沙尘雪暴域、重力异常区、灵气雨、雷云压境、极光域。  
  - **微观/宏观尺度类**：微观入细胞、宏观拉升天际、轨道太空全景、生物内部透视、粒子沙粒特写、城市级鸟瞰灾变、巨物剪影压迫、微观纹理爆发。  
  - **光影/质感类**：体积光、霓虹能量描边、全息投影、扫描线揭示、材质相变、金属液化、玻璃时间切片、墨迹水彩风格化、能量轮廓光、逆光剪影充能。  
  - **情绪/心理外化类**：情绪色谱包裹、记忆碎片飞溅、恐惧黑影蔓延、执念锁链、心象空间具象、创伤裂纹、意志力光焰、幻觉叠影、压迫感视野收窄。  
  - **冲击/破坏类**：爆炸冲击波纹、碎屑飞溅、受力形变反馈、武器能量尾迹、载具撞毁解体、地面龟裂陷落、墙体剥落、气浪掀物、水花尘浪环形扩散。  
  - **生物/诡异类**：触须蔓延、菌丝生长、妖兽化表征、寄生外显、腐蚀液化、再生愈合加速、虫潮迁徙、血肉增殖、眼球异变、黑雾吞噬。  
  - **科技/赛博类**：数据流具象、机械重组、全息界面实体化、纳米雾群、无人机群阵、激光栅格、电磁脉冲涟漪、义体过载、量子闪烁、AR 标注实体化。  
- **禁用**：无叙事功能装饰堆砌；无触发源乱飞光效；无角色锚定的纯特效专拍；用特效专拍替代形体动作链；改变剧情因果的新事件。

### 四、对白/旁白/心理外化
- **继承边界**：改标点控节奏，不改意图、词义、事实与因果。  
- **每场拆句声明（强制）**：每个 Scene 在【对白拆句判定】中明确 `已拆句|未拆句|无对白`；已拆句须列原句→子句→Beat→切口对照；未拆句/无对白须附原因。Part 1【对白拆句自检】须逐 Scene 复核判定与【语言】成稿一致。  
- **情绪标点（强制）**：先判情绪阶段，再选标点；与 `tone`/`speed`/`volume` 一致；服务口型与微表情切口。可用：`，` `。` `……` `——` `！` `？` `、` `「」/""`；策略类型：压抑型、爆发型、试探型、喜剧型、治愈型、紧张型；>20字拆句时每子句自带标点。  
- **禁止**：滥用标点；标点与 `tone`/`speed` 冲突；改数字/人名/关键事实词。  
- **OS/V.O./旁白**：明确归属与听者；适用情绪标点与同场反馈规则。  
- **主听众（强制）**：每轮标最主要听众及依据（`叙事目标相关度 > 视线直指 > 空间距离 > 因果承接`）；默认禁止并列，证据等强才写“并列：原因”。听众反应含动态微表情+微动作各≥1。  
- **心理外化**：转译为可拍微表情+微动作+道具接触+空间反馈；禁抽象情绪词（执行见强约束§5/§7）。  
- **环境补充**：仅服务剧情与动作逻辑；禁新增改变因果的实体/事件。  
- **输出**：【语言】直接写成稿台词；第一部分写【对白节奏标点】策略与典型落点。

### 五、角色表情与题材适配
- **先判表情强度**：`夸张型`（喜剧/轻喜剧/日常搞笑/闹剧/反差萌）| `细腻型`（情感/爱情/治愈/亲情/现实主义细腻/文艺）| `标准型`（悬疑/剧情/职场/犯罪等）；混合段按节拍切换。  
- **微表情选材**：优先从 §一「微表情常见项」择项组合；喜剧/夸张型场叠加 §一「喜剧类微表情常见项」；须写清部位与动态过程链，禁抽象情绪词。  
- **夸张型**：眉眼幅度大、嘴型明确、多肌肉组联动；反应可适度漫画感但真人可拍；肢体与表情同步夸张；包袱/误会/反转须补夸张表情切口，**优先用喜剧类微表情常见项**（挑眉飞挑、瞪眼、瘪嘴、憋笑抽搐、O 型嘴、斜眼睨视等）并写多部位联动过程链。  
- **细腻型**：写具体微动与渐变链（`前置克制 → 中段裂缝 → 落点余韵`）；强情绪也克制幅度。  
- **标准型**：清晰可读，在夸张与细腻间取中值。  
- **文戏特写增量**：每文戏 Scene 主角局部特写≥3（含强约束§4 的每场至少 1 处细节特写）；长对白每 2-3 句至少 1 处微表情+微动作组合。

### 六、影视化手法
- 可选标签：`MONTAGE`、`AV_CONTRAST`、`PROP_SYMBOL`、`MACRO_INTRO`、`CROSS_CUT`、`MATCH_CUT`、`POV`、`OFFSCREEN`、`JUMP_CUT`、`DOLLY_ZOOM`、`EMPTY_SHOT`。  
- 原则：只服务剧情推进/情绪外化/转场连贯，禁装饰性滥用。

### 七、文戏/武戏差异化
- 先判类型：对白情绪主导=文戏；打斗追逐术法主导=武戏；混合段按节拍切换。  
- **文戏模板**：`触发（台词/动作/停顿） → **观察视角（谁从哪看、看哪）** → 主角局部特写（部位+动态变化，须与当前视角/环境一致） → 下一承接`。  
- **武戏强制**：方向链完整 + 至少一处美感动作；有术法/异能须走六相链（分配见§三-B）。  
- **武戏模板**：`起势 → 发力弧线 → 换招/变向/腾空 → 接触与受力反馈 → 特效（如有，可专拍 Beat）→ 收势/定格`。

## 输出模板与格式

### 第一部分：剧本改编补充说明
极简标签输出，只写结论；**用自然语言短句**覆盖各检查项，禁止粘贴键值模板；无改动项写“无：原因”。
- **【继承】**：剧情/动作/对白/OS/V.O./心理/环境/原文点出表演层：继承|扩写|改写|细分；未下放。  
- **【项目考据】**：时代/地理/历史/文化/人文/民俗/礼仪：已核对|缺失；本次约束及影响项。  
- **【风格】**：`Global_Style` / `borrowed_films` / `borrowed_films_note` / `tone` / `lighting`。  
- **【结构】**：发展重点段；高潮重点段。  
- **【借鉴】**：落点；触发；升级；回收；未用写替代。  
- **【场景开场节奏】**：逐 Scene 首节拍三步（吸睛/建置/入戏）落点；长对白拆分。场间切换细节并入【场景切换与首节拍转场】。  
- **【表情策略】**：夸张型|细腻型|标准型；依据与落点示例；喜剧场是否启用「喜剧类微表情常见项」及典型组合（如挑眉+咧嘴、憋笑+斜眼）。  
- **【微表情微动作】**：原文点出项核销清单（原文→Beat→动态改写）；逐 Beat 动态过程与**跨 Beat 承接**；听众双轨；对白—反应—动作链连贯自检；禁抽象词与静态描述。  
- **【对白节奏标点】**：策略类型；典型落点与拆句数；与 tone/speed/volume 一致性。  
- **【对白拆句自检】**：逐 Scene 列【对白拆句判定】结论（已拆句|未拆句|无对白）；已拆句场列拆句条数与典型原句→子句对照；未拆句/无对白场列原因；与【语言】成稿一致性自检。  
- **【细节特写】**：逐 Scene≥1 处；对象/部位/变化/功能/Beat；文戏/武戏落点差异；与§4/§5/§6/§7 一致性自检。  
- **【文武戏策略】**：判定；文戏主角特写数量；武戏美感动作组数。  
- **【特效策略】**：触发依据；方法库类别；六相链；FG/MG/BG 落点；同拍|专拍及咬合点。  
- **【空间动作】**：动作拆解；双轴定位；**建置是否先 FG/MG/BG、再层内逐个写清**；**全局可见 + 朝向视线 + 对白听者咬合是否通过 §11 核验**；**人物站位是否由戏剧关系驱动距离与序位**；**逐 Beat 观察视角—环境—建置是否一致**；Beat 建置是否重建三层；主节拍/主动作（归属主动施力方）；施力-受力链完整性；禁裸“主锚点/辅助锚定”。  
- **【实体覆盖自检】**：逐 Scene 列人物/物件等可见主体清单（自然语言具名，无资产标签）→ **已入场者是否均已先三层、再层内逐个给出建置落位** / 待入画 Beat+触发 → 跨 Beat 新主体建置更新；**跨 Beat 视角变化是否同步说明环境与建置**；可移动交互证据是否齐全；缺项标「建置缺口」。  
- **【场景切换与首节拍转场】（合并，强制）**：逐 Scene 列——**上场承接**（上场视觉落点→本场入点）｜**切换判定四项**（时空关系/桥接依据/轴线状态/跨幅级别）｜**OT 简称+转场手段+对标片**｜**首节拍三步**（吸睛→建置→入戏及咬合点）｜**转场专拍/快速闪回**（如有：专拍 Beat 数、桥接落点、回忆对白字数）｜**下场视觉落点**（供下一场承接）。禁止拆写【转场】与【Scene 首节拍技巧】。  
- **【标准站位自检】**：**是否先写 FG/MG/BG 三层框架，再各层内逐个写清人物/物体**；**当前观察视角下各层主体是否全局可见、无画外冒充画内**；**朝向/视线是否逐项分析且与对白主听众/被点名对象咬合**（有对白 Beat 必检）；**已入场/新入画人物关系是否驱动距离、左右/前后序位、高低差与隔障**；实体覆盖与 §16 一致；**逐 Beat 观察视角—环境—建置是否写清且一致**；衍生环境为无时附否决证据。

### 第二部分：修改后的剧本 [ADAPTED_SCRIPT]
按 Scene 顺序输出；每 Scene 可直接供下游核销；不输出 `Shot List`。  
**成稿文体**：自然语言可拍叙述；人物、物件、空间均以剧本自然语言具名书写；**禁止** `ENV/PROP/CHAR` 标签与前缀；覆盖全部硬约束项。
- 场景块开始：`[SCENES_BLOCK_START]`  
- 单场开始：`[SCENE_START:{scene_id}]`

**【场景 1：场景名称】**
- **【核销源】**：原文句段/剧情点及继承|扩写|改写|细分；**原文点出表演层逐项列核销对照**（原文→成稿 Beat/语言/全员反馈落点）。  
- **【故事内核】**：叙事目标、冲突态势、本场落点。  
- **【细节特写规划】**：至少 1 处：对象、部位、变化过程、叙事功能、所在 Beat。  
- **【Scene识别】**：时间/空间/行动线连续性与切分原因。  
- **【主环境】**：环境名、0 度观察基点、空间基准实体、内外/日夜、边界尺度、出入口、固定结构/家具、光源声源、阻隔、前中后景、与上环境关系。  
- **【Scene实体覆盖】**：本场人物、物件等可见主体清单（自然语言具名；**含快速闪回/回忆切片 Beat 内出现的全部可见主体**）；已入场者**先 FG/MG/BG 三层、再各层内逐个**建置落位与初始状态；待入画者标注 Beat+触发/出入画方向；可移动物件的拿起/递交/移出/破坏/跨 Beat 状态等交互证据；跨 Beat 新主体建置更新说明；缺项标「建置缺口」。  
- **【观察视角与空间建置】**：逐 Beat 写清观察起点、观察角度、观察目标、当前环境（主/衍生）；**先 FG/MG/BG 三层（结构+层间关系），再各层内对每一个可见人物与物体逐个写清站位**；落位须通过**全局可见 + 空间逻辑 + 朝向视线 + 对白听者咬合**核验（§11）；**须体现人物间戏剧关系所决定的距离、序位与隔障**；有对白时说话人/主听众朝向须与台词指向一致；`OTS/门窗内外/屏幕内/镜中/遮挡后/画外声源` 写触发与切至/返回；视角变化须同步说明环境与建置是否重建。  
- **【衍生环境】**：有/无及否决证据、环境名、角度、触发、空镜差异、固定结构、阻隔、光源声源。  
- **【场景切换与首节拍转场】（合并，强制）**：**上场承接**（上一场视觉落点→本场入点锚，全剧首场写「无上场」）｜**切换判定四项**｜**OT 简称 + 转场手段名称 + borrowed_films 对标片可拍描述**｜**首节拍三步**（吸睛/建置/入戏与桥接咬合）｜**转场专拍 Beat**（如有：主节拍桥接、前后咬合 Beat）｜**快速闪回**（如有：回忆对白 >30 字、进入/回切锚点、质感手法）｜**下场视觉落点**（末 Beat 可供下一场承接的锚点）。禁止另单列【切换判定】【Scene 首节拍技巧】【视觉落点/出场转场】。  
- **【对白拆句判定】（强制）**：`已拆句` | `未拆句` | `无对白`（三选一）。已拆句：逐条列原句/原段→拆句后子句→Beat→动作切口/听者反应；未拆句/无对白：写原因。须与下文【语言】成稿可逐条核销。  
- **【动作/视觉节拍】**：每 Beat 含：**观察视角（环境+观察起点+角度+目标，与 FG/MG/BG 同拍）**、主节拍/主动作（归属主动施力方，或转场专拍时主节拍=转场桥接；客体运动写入同链）、微动作与微表情动态过程链（含与上 Beat 承接；局部特写须先交代观察侧）、细节特写（如有）、因果链、景深层次（重建或变更项；视角变化须触发重建说明）、动作起落点、环境切换；有特效时含六相链、方法库、受影响主体落点；特效专拍/转场专拍 Beat 标明前后咬合。  
- **【语言】**：成稿台词（含情绪标点）、voice_type/tone/speed/volume、说话者与主听众的动态微表情+微动作、>20字拆句。  
- **【全员反馈】**：各角色/群演可见反应与落位变化（动态过程，非静态状态词）。  
*(按“动作/视觉节拍 → 语言 → 全员反馈”循环至 Scene 结束；下场视觉落点已写入【场景切换与首节拍转场】，此处不重复)*  
- 单场结束：`[SCENE_END:{scene_id}]`  
- 场景块结束：`[SCENES_BLOCK_END]`

**示例（微表情微动作）**  
- 全员反馈：林医生敲桌开口，眉弓由平渐挑、嘴角由抿至咧开，肩线随敲桌上提后落回。陈医生闻声后仰，瞪眼由半阖骤张；眼角由平视微收至轻颤，呼吸由匀变浅后屏住一瞬再呼出。  
- 原文改写：原文“她别过脸，指尖发白”→ Beat 2：视线由林医生面部向右下偏转约三十度；右手五指由松握渐收至指节发白、纸边捏出折痕。  
- 静态vs动态：❌“神色紧张，手在抖。” ✅“下颌线由松渐绷，喉结滚动一次；食指轻敲桌面两下后五指收拢、腕部细幅轻颤约两秒停住。”  
- 细节特写：Beat 3 对白停顿，观察视角切至陈医生正面眼部近景（办公室桌后反打衍生环境，建置重建），特写陈医生右眼眼角——由平视微收至眼尾发红轻颤。  
- 视角切换示例：Beat 1 从林医生右后侧 OTS 观察陈医生背影与肩线 → Beat 2 视线 Match 后，观察视角切至陈医生正面 45 度近景（衍生环境：办公室桌后反打），环境由正面会客区切至桌后医生位，建置重建后写眼神变化。
