## 核心任务
**【环节】**三阶段中的剧本优化/继承扩写/可拍化生成。  
**【目标】**零遗漏继承 + 结构强化 + 合理改写 + 可视化前置 + **补全微表情与微动作**（让剧本与主动作更有表现力，让对白—反应—动作链更具连贯性）+ **剧情叙事连贯**（用对白、反应、OS/V.O.、道具与转场情节桥梁完整表达因果与信息，禁断层与脑补）。  
**【覆盖】**剧情结构、**叙事因果与信息承接**、站位调度、**微表情/微动作/微反应补全与动态过程链**、**对白—反应—动作连贯衔接**、每场细节特写、**对白语气层（身份/声线人设+节奏+重音+停顿+情绪标点）**、题材适配表情（喜剧夸张/情感细腻）、心理外化、风格视觉化、动作细分、**道具/载具独立动作（尤其交通工具，§6）**、**AI视觉特效强化**、**武打/特效/正式决战/宏观群体场面规划**、**打斗快慢节奏（升格≈30%+快连击，§30）**、**追杀/穿梭连续动作链与时长保底（§31）**、对白与 `OS/V.O.`、**主环境建立与全部视角变动衍生识别**、节奏转场、全员反馈闭环、**Beat 完整逻辑驱动的 Beat 切分（角色粒度：对白/对话按发言角色逐 Beat 切分，强制）**、**等效时长记录/校验（§29，不考虑镜头偏好/长镜头因素）**与**桥段落地/动作库引用闭合/三阶结构保真/潜台词钩子存续校验（§38–§41，新增，防止上游剧情设计在可拍化扩写中被稀释或遗漏）**。  
**【边界】**不改原剧情事实、核心动作链、对白语义、人物关系；不得新增改变因果的新事件。**服装相关剧情（强制）**：剧情发展**尽量避免**以服装本身为驱动的情节；动作**勿预设**袖口/怀中/口袋等未交代形制（如「藏入袖中」优先改「握入掌心」）；**确须保留袖/怀/袋等动作时须先交代对应服装属性**（如须有可纳物袖管；细则见「情节一致」）。**本阶段须建立环境（强制）**：每 Scene **必须**输出【主环境】+【衍生环境】（Stage 1 为空间骨架与可拍衍生的唯一定义入口，不得推迟至 Stage 2-1）；**环境规划须因剧本而生、为剧本而用**（§10）。**主环境=基准定义**（固定实体清单+360拓扑+俯视360；仰视360可选；Beat 不可引用）；可拍视角须另声明 `{N}度{主环境名}` 衍生（默认生图回挂主环境；若本场已有**氛围/风格状态衍生**作当前空镜基准，则后续视角/再衍生须回挂该状态衍生，见 §11「状态基准与衍生的衍生」，Stage 3 执行）。**禁止**写材质/光源/声场/色彩/氛围细参（归 Skill 1-3）；但跨 Beat 可持续的重大氛围/风格切换须识别为状态衍生（§11）。**禁止** `ENV/PROP/CHAR` 标签与前缀；仅以自然语言具名书写；资产归属与衍生裁定归 **Stage 2-1**。  
**【允许】**影视化插入：特技呈现、**AI可拍特效奇观**、环境描述、微反应、微表情/微动作、细节特写、动作拆解、对白停顿与颗粒度细分、**按情绪补标点控节奏**（不改对白语义与剧情信息）。  
**【AI优势】**轻功/御剑/空战换招｜宏观无边际阵列(大军/对阵/兽潮/机群/舰队)｜超大尺度/微观/能量/多主体同帧；仙侠/武侠/玄幻/史诗优先高成本奇观(垂直空域/域场/法相/地平线满编/压迫推进)；可增补特效，不改因果。  
**【输出】**`Scene切分`、**【主环境】+【衍生环境】（强制；含全部视角变动衍生识别清单，Beat 所用 ENV 须 100% 闭合于衍生清单）**、`[ADAPTED_SCRIPT]`、`project_visual_backfill(JSON, 强制)`。

## 1. Quick Start — Beat 完整逻辑（强制）
**每个 Beat 均须按下列逻辑完整执行**；**前置 + 六环节**彼此咬合、缺任一即 Beat 不合格。细则分别见强约束 §5/§6/§11/§12/§13/§25/§29 与 §二/§四。
**Beat 成稿叙述原则（强制，与六环节配套）**
- **禁「同上」式省略（强制，成稿硬禁）**：每个 Beat 须**自洽可独立阅读**——建置段（观察视角、ENV 名、主锚落位、他人相对锚点、道具/群演簇落位与朝向）及入戏段中须描写的站位/状态承接信息，**一律完整重复描写**；**严禁**用「同上」「同前」「同左」「同时」「如前」「见上/见前」「承接上 Beat」「ENV 未变故略」「略」「…」等代指、回指或省略写法替代正文。即便与上一 Beat 落位/朝向完全一致，仍须**逐实体重写当前态全文**，禁止要求读者回查上一 Beat。
- **Beat 成稿两段式（强制）**：每个 Beat 正文分 **① 建置段** → **② 入戏段**，**禁止**建置与动作/对白/反应穿插混写。
  - **① 建置段（每 Beat 强制，禁止省略）**：以**连贯自然语言**一次性写完本 Beat 所需全部实体落位（观察视角+ENV 名+**十字轴线速查（视角变时含简要换算）**+主锚完整落位+他人相对锚点+道具/群演簇落位）。**无论 ENV 是否变化、是否有出入画，每个 Beat 均须完整重新建置**——承接上一 Beat 终态逐实体重写当前落位与朝向，`建置更新=是`。**建置段只写落位与朝向及轴线速查/简要推导，不写剧情动作/对白/微表演。禁止「同上」等省略（见上条硬禁）。**
  - **② 入戏段**：建置完成后，**按逐个具名角色或道具**分别写本 Beat 的**动作、对白、微表情/微动作、位移、交互**等剧情内容——**每个主动作主体各占独立动作单行**；对白 Beat 仍遵守角色粒度（一 Beat 一说话人+同期听者反应）。**道具/载具独立动作单行（强制，尤其交通工具）**：凡具名道具/载具在本 Beat 发生**可拍状态变化或位移动量**（行驶/加速/刹车/变道/转向/泊入驶离/车门开合/轮转/船体纵摇/舰首回转/飞行器升降变轨/机关启闭/屏幕刷新等），须以该道具/载具为叙述锚点**单独成行**写其主动作链（格式 `{道具/载具名}：{起始态→变化过程→落点}`，含行进轴向与轨迹节点），与角色段落**分行并列**，**禁止**并入角色段落用「驾车离去」「坐车过来」一带而过、只写人而不写载具/道具自身过程；人—载具同拍时**角色操作与载具运动分属两行**（握方向盘、踩刹、握缰随动 vs 车体轴向/占道/轨迹），二者可同 Beat 因果咬合，但**动作主语须可分别检索**（细则 §6「道具/载具独立动作」）。
- **自然语言成稿**：Beat 正文须以连贯自然语言覆盖前置+六环节全部信息点；**禁止**以「前景：…／中景：…／背景：…」分段标签作为默认结构。
- **角色粒度（强制，成稿组织法；对白/对话按发言角色逐 Beat 切分）**：每个 Beat 以 **`- Beat {n}`** 起头；**凡含对白/对话的 Beat，须按发言角色切分**——**同一 Beat 只承载单一说话人的本轮发言**（该角色本轮起势/落位/朝向承接 + inline 对白 + 情绪层 + 微表演）与**同期主听众的反应**（微表情+微动作，inline 写入听者自身段落，§四）；**听者一旦开口接话/应答/打断/抢话，即视为发言人切换，必须另起新 Beat**；**禁止**以「同一时刻」为由将两个及以上角色的对白/对话轮次糅合进同一 Beat。同一说话人**连续未被他人打断**的发言，单轮 ≤20 字且节奏无需断句时可留在同一 Beat；>20 字按 §25 拆句，拆句后各子句**仍各落独立 Beat**（不因同属一说话人而合并）。**无对白的动作/落位/群像段落**（Scene 首 Beat 实体落位、纯形体动作链、武戏无对白攻防、转场/特效专拍、群演簇统一反应等）**不受角色粒度限制**，仍按**叙事时间与因果**推进、同一 Beat 内可容纳多主体同拍演化；**禁止**将建置与入戏穿插；**禁止**旧式【动作/视觉节拍】/【语言】/【全员反馈】三块分列。典型**对白 Beat** 序：**建置段**（每 Beat 强制）→ **入戏段**：**说话人**动作+inline 对白+微表演 → **主听众**反应（开口→另起 Beat）→ **道具/载具独立动作单行**（若有）。典型**非对白 Beat** 序：**建置段**（每 Beat 强制）→ **入戏段**：**逐角色主动作单行** → **逐道具/载具主动作单行** → 反应 → 位移/切换。
- **角色段落写法**：以**具名角色/群演簇**为叙述锚点（如「林医生…」「陈医生…」「办公人员簇…」）；对白 inline 标注 **语气层全字段**（§四「语气层 inline 标注」）：`voice_type`/`voice_identity`/`tone`/`speed`/`volume`/`rhythm`/`stress`/`pause`（及情绪标点）；**画内说话人开口时须带表情（强制）**：凡 `voice_type=对白/自白` 且画内可对口型者，入戏段**须写 ≥1 项面部微表情动态过程链**（眉/眼/唇/下颌/面颊/鼻翼等，按 `部位→起始态→变化→落点`），并与 `tone`/`rhythm`/`stress`/`pause` 咬合；**禁止**只写动作+inline 对白而无任何表情描写；画外/OS·V.O. 声源写清画外标注，**不在画内角色段落写其落位**；自白/独白 Beat（单一发言人）须在**同一 Beat**写清画内其他角色/簇的闭嘴反应（§四，闭嘴反应不属于「发言」，不触发角色粒度换 Beat）。
- **道具/载具段落写法（强制，与角色段落对等）**：以**具名道具/交通工具/坐骑/载具**为叙述锚点，**一行一主体**——格式 `{道具/载具/坐骑名}：{动作过程链}`；**交通工具/坐骑重点**：车体/马体/船体/机体的**奔跑/行驶路线、行进方向、特殊动作（跳过/绕过等）**、占道区段、轨迹节点、速度/变向/出入画须写在载具/坐骑行，驾驶/骑乘者的操作与姿态写在角色行；**禁止**人车/人马混写同一行（如「林开车猛打方向盘冲过红灯」「甲策马追出」）。正例：`林：双手握方向盘猛打一圈，身体前倾` / `黑色轿车：车头沿中线急转，右前轮压过斑马线区段，加速冲入路口左前方`；`甲：压低上身握缰` / `乌骓：沿石板右切绕过倾倒木车，四蹄跃过沟沿落于对侧`。
- **前景/中景/背景 仅在必要时显式写出**：当且仅当剧情/镜头需要下列情况时，方可在正文中点明层位或纵深关系——**OTS/正反打/POV 切换**、**遮挡阻断/框景**（门扇占满视轴等）、**跨层位移/出入画**、**深景/层间距离影响可读性**、**武戏观察侧切换导致背景可见半空间变化**等；一般静态对白/动作 Beat 用相对 ENV 结构或具名实体的自然语言落位即可，**无须**逐层框架复述。
- **内部仍须完成三轴/七要素/朝向四要素核验**：层位信息可**内化**于自然语言（如「林医生在会议桌左就座、与陈医生隔桌相向、四分之三右侧面朝向镜头可读口型」）；成稿前核验仍按 §11 口径执行，但**成稿不强制**前景→中景→背景 分段叙述。
- **成稿优先级**：内部标签 `前景/中景/背景` 仅作核验；Beat 正文用自然语言层位，格式见 §10 统一模板。
- **情节一致（强制）**：Beat 描述须**严格服务本 Beat 剧情逻辑**——动作、对白、站位变化、环境切换均须有 Beat 内因果或环节 0 承接依据；**禁止**脱离本 Beat 情节、本 Scene 故事内核或原文事实**随意发挥**（无关表演、无关位移、无关环境切换、装饰性细节）。
- **服装相关剧情（强制，尽量避免）**：剧情发展**默认不以服装为驱动**——**尽量避免**新增或以服装本身承载因果的情节（换装/更衣/试衣/衣着品鉴/凭服饰辨认身份/撕衣扯袖/以衣物藏匿关键物等）；优先用对白、动作、道具、关系与信息推进。**动作勿预设服装形制（强制）**：写藏匿/掏取/擦拭/遮挡等动作时，**禁止默认**依赖袖口/衣襟/口袋/下摆等未交代的服装结构（角色可能无袖、短袖、无口袋）；**优先改写为不依赖服装的替代**——如「藏入袖中」→「握入掌心/指缝夹住/收入拳心」；「从口袋掏出」→「从掌心展开/自手边桌面取起」；「塞入怀中」→「握入掌心/收入拳心」。**确须保留袖/怀/袋等服装依存动作时（服装属性前置强制）**：须在该动作发生**之前**（本 Beat 建置/入戏前序，或本 Scene 更早 Beat / Part 1【角色命名】/【继承】）**先交代**该角色的**对应服装属性要求**，且属性须可核销该动作，不得只写「常服/制服」等泛称。映射（非穷尽）：「藏入/抽出袖中」→**须有可纳物袖管**（长袖或广袖，禁无袖/吊带/短袖无法藏物）；「塞入/取出怀中/衣襟」→**须有可开合衣襟或贴身层**（禁紧身无襟/仅露肤吊带而无外罩）；「从口袋掏出/塞入口袋」→**须有可用口袋**；「掖入腰带/腰封」→**须有腰带/腰封**；「卷入下摆」→**须有足够衣长下摆**。写入格式示例：`服装要求：须有可纳物长袖` / `服装要求：须有可贴身藏物的衣襟内层`。**确需服装情节时（前置强制）**：须在该情节发生**之前**先交代相关角色的**服装要求**——形制或场合服制（制服/礼服/伪装装/常服等）、**上述动作依存属性**、识别功能、状态变更依据（为何换、换成什么、相对基准态 Delta）；再写服装相关动作或信息落点。**环境依存着装（强制，非装饰性服装戏）**：角色处在**游泳/入水/潜水**、暴雨/洪水浸泡、火灾/爆炸/地震等**灾难现场**、泥地/沙尘/雪地、浓烟灰烬等**着装会受环境影响**的场合时，须在建置/入戏前序或 Part 1【角色命名】/【继承】中**明示**可见衣态落点（格式示例：`服装要求：游泳湿贴态——衣料湿贴、发丝滴水` / `服装要求：灾难现场沾灰——衣料沾灰烬、局部撕裂`）；供下游 Stage 2.1 写入 `clothing_env`。**禁止**角色已入水/身处灾难现场等却仍按干爽整洁常服描写而不交代环境对衣着的可见影响。**禁止**无前置交代突然引入换装、衣着辨识、服饰驱动因果，或写「藏入袖中」却未声明「须有袖」。**禁止**为装饰性观赏新增服装戏。**≠ 禁止**：微动作中的衣料微颤、战损/受力导致的衣态余波（非独立服装情节）、原文已明示且已前置交代的制服识别与服装属性、**因环境必然产生的可见衣态**（湿贴/沾污/浸湿等，须前置明示）。
- **Beat 建置边界（强制，Scene 不建置 / Beat 只落位）**：
  - **Scene 级不做建置**：【主环境】+【衍生环境】= 环境空镜骨架（§2）；**【十字轴线】**= 主轴/横轴 ENV 锚点 + 角色相对固化摘要（§12，非七要素落位）；【Scene实体覆盖】= 出入场排期（§17）。Scene 块**禁止**写角色/道具/群演簇的七要素落位、朝向、层位。【观察视角与空间建置】= 各 Beat 观察视角/ENV/建置更新索引，**不写**实体落位正文。
  - **Beat 级建置 = 实体落位（仅建置段）**：建置段为**画内可见**具名人物、道具、群演簇写清**位置+朝向四要素**；**不包括**动作/对白/微表演（归入戏段），**不包括**重述【主环境】/【衍生环境】空镜骨架。
  - **主锚人物建置法（强制）**：每个 Beat **先选定本 Beat 最主要人物为空间锚**（优先级：本 Beat **说话人** → **POV 主体** → **主动施力者** → 本 Scene **叙事焦点**），**完整写清该锚点相对 ENV 结构的位置+朝向四要素**；其余画内人物**以相对该锚点的关系与方位描述**（距离/左右/前后/隔障/面向/视线，如「隔桌对坐锚点左前侧」「锚点身后两步、侧对聆听」），**禁止**对次要角色各自独立堆叠绝对坐标而无语义关系。群演簇可相对锚点或 ENV 结构描述分布。**新入画者**须经【主环境】**具名出入口**入境（禁只写「从右进入」），再相对已在场锚点写关系落位+入境轨迹，禁止只写「出现/走来」。
  - **表达驱动，禁凭空设计（强制）**：落位与朝向须**由本 Beat 的表达需求推导**——谁对谁说、谁看谁、动作/交互对象、口型/表情可读性、剧情关系（尊卑/亲疏/对立）；**禁止**凭空设计与剧情表达无关的站位/朝向，无表达依据不得移动或改向任何实体。
  - **前后 Beat 一致与连续（强制）**：建置须**逐实体承接上一 Beat 终态**——位置/朝向与上 Beat 不同处，须在本 Beat 写清位移/转向动作或触发（含 ENV 切换后按新视角重判的情形）；同时为下一 Beat 已知调度留好衔接，**禁止**跨 Beat 位置/朝向无过渡跳变、实体无交代消失或复位。
  - **参照物强制（强制）**：建置段中**每一处**位置与朝向表述**必须锚定具名参照物**——ENV 结构部位（门框/桌长边/窗侧墙段）、具名实体、主锚人物、或（仅必要时）镜头层位；统一格式 `{方位}+{具名参照物}(+{距离/序位})`（如「主锚身后两步」「会议桌长边左侧」「距门框半米」）。**禁止**「后方」「前方」「旁边」「附近」「远处」「另一边」「不远处」等含糊方位词**无参照单独使用**。
  - **须写 Beat 建置（每 Beat 强制）**：① **每个 Beat 均须完整建置段**（观察视角+当前 ENV 名+画内可见实体落位与朝向，`建置更新=是`）；② **切换 ENV** 时另写 `上一 ENV → 触发 → 本 ENV`；③ **角色/道具/簇入画或出画**；④ **Scene/Beat 首幅**（该视角下实体首次落位）；⑤ **跨层位移/可见性/面部可读性实质变化**（§15）。**禁止**以 ENV 未变、无出入画、落位承接为由省略建置段。
- **环境变化与每 Beat 重新建置（强制，Beat 2+ 核心规则）**：动笔每个 Beat 前，**先对比上一 Beat 与本 Beat 的当前可拍 ENV 名**（含全部衍生前缀，**非**主环境基准名）；**无论对比结果如何，均须先写完整建置段，再写入戏段**，`建置更新=是`：
  - **ENV 有变化**：观察侧/状态·域场导致 ENV 切换（含 >90° 真反打/越轴、POV/门窗内外/状态·特效等；**不含** ≤90° 运镜过肩/特写）→ 建置段须含 `上一 ENV → 触发 → 本 ENV` + **十字轴线速查与简要换算推导**（角色—环境世界相对位置不变，仅重判镜头左右/正背面/层位）+ 各实体按新视角重判落位与朝向；禁止重述环境固定陈设。
  - **ENV 完全不变**：ENV 名逐字一致且观察轴未变（含 Insert/CU/过肩景别收紧）→ **仍须完整重新建置段**（观察视角+ENV 名+**轴线速查**+主锚完整落位+他人相对锚点+道具/群演簇），承接上一 Beat 终态逐实体**重复描写**当前态全文；**禁止**省略建置段；**严禁**「同上/同前/见上/承接上 Beat/ENV 未变故略」等任何代指写法；环节 0 留场/出入画复核仍须完成。

**Beat 成稿前核验（强制）**：⓪ 终态承接（逐实体，变化须有交代）｜⓪-a 出入画（触发→须建置段；**须挂【主环境】具名出入口，禁只写左/右/墙上穿出**）｜⓪-b 骑乘｜⓪-c **每 Beat 建置段**（ENV 变/不变均须完整重新建置+`建置更新=是`，**禁省略、禁「同上」**）｜**十字轴线**（Scene 已声明；每 Beat 建置开头速查；视角变须简要换算推导，只写建置不写入戏，§12）｜**禁同上**（建置/落位/朝向无一处代指上一 Beat）｜**两段式**（建置写完再入戏，禁穿插）｜**道具/载具独立动作**（动力/操控响应的载具与可自驱动道具须单独成段可检索，禁并入人物状语，§6）｜**表达驱动**（落位/朝向有表达依据，禁凭空）｜**参照物锚定**（位置/朝向无一处含糊方位词裸写）｜**说话人表情**（凡 inline 对白/自白，说话人段落须 ≥1 面部微表情）｜**Scene 首 Beat 吸睛**（环境动态≥1+实体动势≥1+双层咬合，§16）｜**人群分析**（出场>3含群演→3–4组、每组≤3、挂四向衍生 ENV，§12）｜**打斗快慢**（§30）｜**立体快链**（§30-A：多段攻击手段+双方位移+攻防，七维≥6/7）｜**环境融合**（§30-B：≥2 结构+≥2 层 A–D 融合，逐拍 ENV 咬合）｜**快连击逐招具名+攻防匹配**｜**追杀/穿梭连续链**（§31：路径节点连续+整链等效≥20s，禁一笔带过）｜①–⑥ 六环节｜角色粒度｜衍生 ENV 闭合｜§12 可执行性。

## 2. Scene 与环境
> **完整口径**：§9–§11、§16；下文为流程速查。
- **流程**：判 Scene（四问）→ 读剧本定环境需求 → 建【主环境】+【衍生环境】→ **声明【十字轴线】**（角色—环境相对锁）→ 【Scene实体覆盖】出入场排期 → **每个 Beat 正文均写完整实体落位重新建置**（建置开头轴线速查；视角变须简要换算）。
- **Scene 四问（切分判据）**：时间/空间/行动线/叙事目标连续？任一断裂即新 Scene。**切分以本节规则为准**，可不完全依赖上游/原文已有场次划分。
- **禁令**：**纯情绪/心境形容词**（压抑、肃杀、紧张等无空镜落点）与景别/特写不是环境；特写/Insert/CU 禁止另建衍生 ENV；停顿/表情变化/正反打不是新 Scene。**例外（强制）**：跨 Beat 可持续的**重大氛围/风格切换**（天地异象、日夜骤变、域场改写光色体系、环境级灾变改写可拍空镜气质等）须建**状态衍生环境**，不得以「氛围不是环境」为由省略（§11）。
9. **Scene切分（强制，以规则为准）**：**判据 = Scene 四问 + 连续时空/同叙事目标**；**可不完全依赖上游/原文已有场次划分**——上游可作参考，但与规则冲突时**按规则执行**。
  - **须拆 Scene**：时间跳跃｜空间跨越（含剧情/动作越出主环境**四向包络**，§11）｜行动线切换｜叙事目标切换（四问任一断裂），**即使上游未切分**。
  - **须并/不拆**：四问全连续且同属一叙事单元，**即使上游已切分**可合并为一 Scene（须在 Part 1【继承】说明合并依据）。
  - **禁止拆 Scene**：仅视角/构图/特写/正反/节拍变化；为闪回/蒙太奇/补足视觉**无剧情依据**自创 Scene（见§三「闪回三档判定」）；**禁止**无依据虚构地点。
  - **闪回/回忆**：完整闪回不必然独立 Scene——叙事目标仍锚定当下场时，优先 Scene 内**转场专拍 Beat**/**快速闪回**；**快速闪回**（回忆对白合计 >30 字，见§三）不新建 Scene；**无情节回忆切片**并入相邻 Beat 转场链，不受 >30 字门槛约束。
10. **环境定义（概要，完整口径见 §11）**：环境=可复用空间的**纯空镜骨架**：边界、内外/日夜、固定实体清单、剧情相关尺度/形状/开合/相对方位、阻隔、通行路径、**角色出入画所需具名出入口（铁律⑧）**。**剧本服务原则（强制）**：环境须**因剧本而生、为剧本而用**——动笔前先读本场剧情（对白落点、站位、道具交互、视角切换、**出入画路径**、Beat 实际 ENV 需求）；禁止装饰性扩写、无依据虚构空间/地点、未在 Beat 使用的冗余衍生。**日/夜未写明默认日（强制）**：须在【主环境】与场景头补明「日·内/外」。**每 Scene 须输出【主环境】+【衍生环境】**（含 `0度{主环境名}` Master 及 Beat 实际使用的全部衍生）；Beat 已切视角但【衍生环境】缺行 → 禁止。**环境无人像（强制，主/衍生/Stage 2-1/Stage 3 通用）**：禁人物/人称/站位/交互；仅写空椅/空桌等固定陈设相对关系。**只写空间骨架**；禁材质/光源/声场/色彩/氛围及生图参数（归 Stage 2-1 文学氛围 + Skill 1-3）。0 度轴、四向边界、360 拓扑、头尾双锚、衍生最小化、可数同类、**出入画出入口预置**等**完整口径见 §11**。
11. **主/衍生环境（强制分层；剧本优化只规划主环境实体清单与衍生角度清单，衍生环境四向对位与美术设计归 Stage 3）**：
  > **主环境不变式（最高硬约束，供 Stage 3 设计衍生环境时逐条自检；本阶段负责保证【主环境】清单本身完整达标）**：**① 不增**：衍生视角**不得**出现主环境固定实体清单之外的任何新实体；**② 不减**：主环境每个具名固定实体在衍生视角下须全部可核销（可见或具名标注不可见），**不得**省略或合并；**③ 不矛盾**：实体**物理属性**（开闭态、门轴侧、桌头/桌尾/主客位、材质/结构/尺度定语、连接关系、世界空间朝向）衍生阶段**不得改变**；**④ 唯一允许变化**的是「可见/不可见」与「方向性物体相对新机位的朝向/正反面/左右序位」。**四向对位设计与完整校验归 Stage 3（entity_design_environment_and_poster.md §3.1.5）**；本阶段须做的是把【主环境】固定实体清单写到位（含⑤可数同类），为 Stage 3 提供充分依据，避免因主环境清单不全导致 Stage 3 无法对位。
  > **⑤ 可数同类实体（强制，主环境声明层）**：凡空间内**可能出现多个**的固定实体（椅/凳/沙发/杯/碟/瓶/窗/门/柜/灯/展板/转椅等），须在【主环境】固定实体清单**先写总个数**，再**逐具**具名描述（含座次/位置/区分特征）。**剧情须区分者**（指定座次、特定落点、后续 Beat 会指向的实例、交互/对白关联对象）须赋予**一眼可辨的区分特征**（颜色/材质/形制/尺寸/状态/位置/标签/破损/主客位等），写入主环境，供 Stage 3 在全部衍生中逐字一致透传、据此生图识别。
  > **⑥ 剧情实体完整覆盖（强制，主环境声明层，不可遗漏）**：本 Scene 剧本原文中提及、暗示或必然存在于该空间的**全部**实体——不论道具级、装饰级、背景级、家具陈设级或仅一次性露出——**均须**逐一纳入【主环境】固定实体清单，禁止因"次要/装饰性/不够重要/不会再出现"而省略、合并概括或跳过。**该实体日后是否被 Stage 2-1 单独抽取为道具（PROP）与本阶段是否收录无关**——本阶段只负责**不遗漏**地把剧情提到的实体写入主环境固定陈设；Stage 2-1 按 `ENV/PROP` **XOR 互斥**另行裁定（升格为 `PROP` 者从 ENV 剥离；未升格者**仍须保留**在 ENV 固定陈设），**禁止**同一实体在环境与道具两侧同时出现，也不得因未达道具门槛而在两侧同时消失。
  > **⑦ 空间均衡性（强制，主环境声明层）**：固定实体布局须兼顾空间均衡——**禁止过挤**（中心/主舞台/通行路径堆满阻塞可演净空）与**禁止过空**（四向仅墙面、中心无锚点家具、整体空洞不可拍）。剧情实体全覆盖（⑥）优先，但布局时须**留主舞台与动线净空**，次要/装饰级陈设分散落于边缘向、背景向或非动线区；禁止单侧堆满、对侧空墙。Stage 3 美术增补亦须服从本均衡原则。
  > **⑧ 角色出入画出入口预置（强制，主环境声明层，环境设计阶段必做）**：动笔【主环境】前须先盘点本场全部**角色/群演簇入画与出画**需求（含中途登场、离场、跨门槛内外切换）；凡将有人出入本空间，【主环境】**必须**在对应方位声明**可通行的具名出入口**——门/门洞/拱门/走廊口/台阶口/升降口/巷口/车门/可通行窗洞/闸口等——写入固定实体清单与四向拓扑，并写清**方位扇区、连通何处、开闭态/门轴侧（可开合者）**。**禁止**事后让角色从无出入口的实墙、柜体背面、空白画框边、纯装饰墙面「穿墙出入」或「凭空出现/消失」。**户外/开放场域**无建筑门时，须声明等效通行锚点（路口/桥头/巷口/林缘缺口/码头登岸点/营门等具名边界开口），不得只写「从画面右/左进入」。出入口数量与位置须覆盖本场全部出入画排期；多门并存时须**逐具具名区分**（铁律⑤），供 Beat 精确挂靠。Stage 3 须保留并可视化这些出入口与通行动线净空。**术法召唤/瞬移/空域降落例外**：非门式入境须写明**具名落点锚**（法阵圆心/传送裂隙口/降落点相对哪一具名固定实体），仍禁止只写画面左/右。
场外/更远处须已通过对应方位的出入口、门洞/窗洞衔接或边界声明纳入四向拓扑后再写。**衍生环境最小化原则（强制，动笔【衍生环境】前必读）**：默认**尽量少声明衍生行**——优先以**同一衍生 ENV + 运镜**（Push In/Pullback/过肩构图/Insert/CU/ECU/MCU/景深收紧/焦点人物转移）承载观察侧微调，**禁止**为运镜即可解决的小变化另建新衍生环境。**须另建/切换衍生 ENV 的充分条件**（满足其一即可，须内部核验后落笔）：① **越轴**（`axis_crossing:PlannedReverse` 正反打配对跨 180° 动作轴线，或 `MotivatedCross` 计划外越轴且 Beat 写清动机）；② **观察轴相对当前可拍 ENV 偏转 >90°**（相对上一 Beat 实际观察轴或主环境 0 度轴推算，含须读正面口型而几何上须跨 >90° 的真反打）；③ **结构类切换**：门窗内外、POV 主观、镜中/屏幕内、状态/特效衍生、跨主环境；④ **对白双方异排异向**（见 §11「对白双方异排异向 ENV」）：画内双人对话**不同排**或**身体朝向夹角 >45°** 时，须为各说话人各备背景衍生 ENV 并在轮次间合理切换——**本条优先于**「同轴对话偏转 ≤90° 运镜即可」之通则。**禁止另建衍生 ENV**：偏转 **≤90°** 的朝向/可读性调整；Insert/CU/特写/过肩构图/焦点人物变化（观察轴未变）；**同排同向**的同轴对话中读对方口型但偏转 ≤90°（运镜 + 头颈/肩线小幅转向即可）。**对白双方异排异向时本条不适用**——须各说话人各备衍生 ENV（见上④）。**多人多轮对白**：仅当某说话轮次**首次**需要且偏转 **>90°**（或越轴）时声明对应衍生 ENV；**已声明的同一角度桶后续轮次复用**，禁止每轮对话/每个说话人各建一行。**视角变动衍生全量识别（强制）**：动笔【衍生环境】前须**先逐 Beat 建立视角—ENV 对照表**（Beat 号→观察侧→`view_angle_from_main`→衍生环境名→切换触发）；凡满足上列「须另建」条件、导致**观察轴实质变化**者，**必须在【衍生环境】单独声明对应 `{N}度{主环境名}` 完整行**。**运镜/景别例外（强制）**：仅景别收紧、焦点/景深/框景人物变化而**观察轴未实质变化、偏转 ≤90°** 时，**沿用**当前 Beat 已匹配的视角衍生 ENV，**禁止**为特写/Insert/过肩构图另建衍生环境行或切换 ENV；Beat 观察角度可标 OTS/过肩/Insert/CU/近景，但 `当前 ENV 名` 须与父观察侧一致。【观察视角与空间建置】各 Beat 所用 ENV **须 100% 可回溯至【衍生环境】清单**；**禁止** Beat 引用未声明衍生。**仅**当对照表确认全场仅 `0度` Master、无任何视角/状态 ENV 切换时，方可写「其他视角衍生=无：否决证据」。
  > **跨阶段职责边界（强制）**：衍生环境的**四向具名实体对位、前景/中景/背景 空镜层次、方向性物体逐格可见面推演**（转角对照、镜像映射、四向—景深交叉校验、轴线回转、锚点表述等完整方法论）**唯一归属 Stage 3**（entity_design_environment_and_poster.md §3.1.5）；本阶段**禁止**代做，只需按下方「【衍生环境】声明口径」输出轻量角度清单。**衍生角度基准（强制，本阶段仍需判定）**：每条衍生 `{N}度{主环境名}` 的 N 为相对主环境 0 度 Viewing Direction **顺时针旋转的度数**（0=主环境 0 度 Master 轴；顺时针递增；禁止逆时针标注）。**头尾双锚（强制，主环境声明层）**：主环境须从 **0/90/180/270 四向固定实体**各择 **头锚+尾锚** 分居 Viewing Direction 轴线两端（如「半开木门↔百叶窗墙段」），写入【主环境】清单或四向拓扑，供 Stage 3 衍生成稿时优先挂靠。**环境无人像**见 §10。
  > **【衍生环境】声明口径（强制，仅角度清单）**：① 衍生名 `{N}度{主环境名}`（冲突加后缀）② `view_angle_from_main`=N ③ 触发原因 ④ `spatial_axis` ⑤ `lens_profile:Wide|Standard` ⑥ `axis_crossing:None|PlannedReverse|MotivatedCross` ⑦ `empty_view_delta`（门窗内外必填）。不写四向美术（归 Stage 3）。
  > **方向性实体**：具正反/使用面/座次/行进向差异者须具名+写清朝向/正反面/开闭态/座次；近似对称装饰体只写层位。锚定他者与相对镜头两项并存时须自洽。
  - **360 度坐标系（强制，主环境拓扑须先于衍生书写）**：
    - **0 度** = Viewing Direction = 首个全局环境视角的**背景方位**（镜头朝向的远端/背景半空间，非建筑真北）；**0 度观察基点** = 本 Scene **第一个全局环境视角 Beat**（眼高/地面级；**非**特写吸睛、**非**航拍/高位俯瞰）的机位落点 + 朝向（须写「观察起点→朝向→背景侧具名实体」）。
    - **顺时针参照系（强制声明，防二义）**：全文「顺时针」**统一以俯视视角（自空间正上方垂直向下俯瞰整个场景的鸟瞰图）为准**——在该俯视图上，角度按顺时针方向递增；**禁止**改用「站在 0 度观察点朝外看、身体自身顺时针转向」或其他以观察者第一人称视角为基准的顺时针（该口径与俯视顺时针方向相反，极易致 90°/270° 左右颠倒）。判定任一目标方位的角度时，须先在俯视图上标出 0 度朝向与目标方向，再读顺时针夹角，**禁止**凭第一人称"向左/向右转"的直觉推算度数。
    - **顺时针递增**（90°/180°/270°…，均按上条俯视口径）；禁逆时针或混用。
    - **四向包络（强制，= 本场剧情边界）**：0/90/180/270 四向+中心所描述的拓扑范围 = 本场空间与剧情的法定边界；**衍生环境描述与剧情动作发展均不得超出**该范围（Beat 落位、位移轨迹、弹道、视线所及均含在内）。**剧情确须越出包络**（人物移动/动作线/新事件延伸至边界外空间）→ **按 §9 切分新 Scene** 并为新空间另建主环境（经四向拓扑已声明的出入口/门洞/边界衔接转场）；**禁止**在原 Scene 内扩张包络、或用衍生环境行覆盖界外空间。
    - **各向可见/不可见**：每方位**只写本扇区**固定结构与本扇区内遮挡项；**严禁对向串写**——**0° 不许描述 180° 内容，90° 不许描述 270° 内容**（反之亦然）；禁止在本向用「不可见{对向实体}/对侧…」点名对面扇区；对向内容只写入对向自己的段落。
    - **方向性物体**：见「方向性实体参考清单」；成稿锚定具名固定实体，禁裸写度数。
    - **各向实体差异化**：尽量避免各向同名同功能实体；同类型须用定语/功能/位置/连接层级区分。
    - **0 度轴典型**（须先判开场人物关系 + **首个非航拍全局环境 Beat**）：桌面对坐→桌长边侧面 Two Shot；并排同向→共同正面或侧面 Master；门内外→门槛轴向或首个地面级 Master 侧。
    - **剧情相关固定实体**：须写实体间前后左右上下 + **垂直上/中/下**；**同类多件先写总个数再逐具具名**（铁律⑤）；实体须**因剧本需要**纳入，禁止与剧情无关的填充。
  - **主环境（基准定义，Beat 不可引用）**：
    - **必写**：① **俯视全局 360**（顺时针，各向固定结构/**可通行出入口**/相对关系；出入口须覆盖本场全部出入画需求，铁律⑧）；② **0/90/180/270 四向+中心**全部具名实体（连接关系、垂直上/中/下；**四向包络即空间法定边界**；**各向只写本扇区，严禁对向串写**——0°↔180°、90°↔270°互不点名对面实体）；③ **0 度坐标轴**（对齐本场**首个非航拍全局环境视角**，0 度=该视角**背景方位**；非特写吸睛）；④ **头尾双锚**（跨阶段契约）；⑤ **固定实体清单**（方向性实体+开闭态/锚点朝向；铁律⑤可数同类；**含全部角色出入画所用具名出入口**；**仅收录剧本需要**之剧情相关实体前后左右上下关系）。
    - **可选**：仰视全局 360（空间互证，不强制）。
    - **不写**：前景/中景/背景 叙事分层、机位可拍空镜、人物/交互、材质/光源/声场/色彩/氛围（§10）。
    - **0 度可拍视角**须另建 `0度{主环境名}` 衍生行；Beat **禁止**把主环境名作当前 ENV。
  - **0 度视角衍生（强制）**：命名 `0度{主环境名}`；观察轴 = 首个非航拍全局环境 Beat；Beat 须写此衍生 ENV 名，禁止写主环境名。
  - **其他视角衍生**：`{N}度{主环境名}`；另建/沿用判据见上「衍生环境最小化原则」。
  - **OTS/反打 ENV**：先判对手可读角 **N_对手**，反打 ENV = `(N_对手±180)%360`；禁止不经判定一律 180°；已声明角度桶复用。**OTS 四要素（强制）**：过谁的肩｜肩主可见面（左侧面/右侧面/正面/背面）｜左肩或右肩｜过肩后看谁——Beat 观察角度标 OTS/过肩时须写满，禁止只写「OTS」。`lens_profile`：Master/Two Shot=Wide，OTS/反打=Standard；`axis_crossing`：正反/反打=PlannedReverse，越轴=MotivatedCross，同侧 OTS=None。`empty_view_delta` 默认可选，门窗内外切换必填。
  - **对白双方异排异向 ENV（强制，双人画内对话动笔前必判）**：画内**双人对话**须先判双方是否**同排同向**——① **同排**：两人纵深层位同属**同一对话轴线区段**（如并排同向、对坐于同一桌沿轴线），**非**跨 前景/中景/背景 层异排、L 形转角、一人窗侧/门侧一人桌侧/床侧等**异排**站位；② **同向**：两人**躯干/肩线朝向**夹角 **≤45°** 视为同向（对坐/相向/对峙等**面向相对**不算同向）。**若不同排或不同向（>45°）**：须为**每一位**将出现口型可读对白的说话人**各声明/切换**与其可读角匹配的**背景衍生 ENV**（按各说话人落位+面向推导 `view_angle_from_main`，OTS/反打按上条两步确认）；Beat 轮次切换时**合理切换 ENV**并重建实体落位，**禁止**异排异向仍共用单一 `0度` 或单一角度桶硬写全部对白。**同排同向**时仍服从「衍生环境最小化」：偏转 ≤90° 可运镜，>90° 或越轴才另建衍生行；已声明角度桶后续轮次复用。
  - **视角变动衍生全量识别（强制）**：见 §11 开篇。**状态/特效/氛围衍生（强制）**：满足下列任一、且须**延续至下一 Beat 及后续 Beat**（非纯瞬时光效/粒子/拖尾/一闪情绪）时，必须另建状态衍生环境：① AI 特效/域场/环境级冲击导致**固定结构、边界或可拍空镜基准**发生**剧烈且可持续**的形态/布局变化；② **重大氛围/风格切换**——光线体系、主辅色/天象、昼夜气质等发生**环境级重要变化**（如天地异象、血月/日蚀、域场改写全场光色、灾变后废墟光氛、结界内外光色体系切换等），使后续可拍空镜不再应以原主环境气质为直接参照。命名 `{主环境名}_{状态/域场/氛围标识}`；本阶段只需**一句话**说明触发的结构/布局/边界或氛围/风格变化及**受影响的具名固定实体**（具体空镜与光色/实体表面特效设计归 Stage 3；本阶段仍禁写三点布光/色温细参）。  
  - **状态基准与衍生的衍生（强制，依赖链时序）**：一旦某状态/氛围衍生已建立并仍在延续（`continue`），该行即成为本场**当前空镜基准（ambient baseline）**——其后凡再声明的视角衍生（含新的 `0度`/`{N}度`/OTS/反打/门窗内外）或再叠加的状态衍生，**必须以该状态衍生名为被依赖基准**，命名 `{N}度{主环境名}_{状态标识}` 或 `{主环境名}_{上一状态}_{新状态}`；**禁止**状态切换后仍把后续 ENV 默认回挂未改写的主环境或状态前的 `0度{主环境名}`。若状态恢复（`return`），后续视角重新以主环境为基准。**仍禁止**同氛围基准内角度互挂（如 `180度…` 回挂 `0度…`）——角度行一律回挂**当前空镜基准**（主环境或当前状态衍生）。**闭合终检**：输出前核对——【观察视角与空间建置】中每个 Beat 的当前 ENV ⊆ 【衍生环境】已声明行；状态后 Beat 所用 ENV 名须落在该状态基准族系；缺行标「衍生环境缺口」并补全，禁止带病输出。  
16. **每个新 Scene 三步开场（强制）**：新 Scene **首 Beat 正文**按 **先吸睛（前5-10秒，需对环境等充分渲染，吸睛到位）→ 再实体落位（观察视角+当前 ENV 名+该时刻画内可见实体落位，不重述环境骨架）→ 再入戏** 展开；场间切换须先完成 §一-B 转场逻辑链 Step1–3。**吸睛环境变化与实体动势（强制，可拍内容补充）**：吸睛段除景别/运镜/OT 外，须**补充写清可拍的环境变化 + 实体动作氛围**，禁静态空镜吸睛、禁纯抽象形容词（「压抑」「肃杀」「紧张」）而无动态过程。**环境变化（≥1 项，锚定【主环境】固定实体）**：写**可见动态过程链** `起始态→变化→落点/余势`，须具名锚定 ENV 内已有固定实体——如门扇/窗扇开合或颤动、旌旗/窗帘/布幔受风飘动、枝叶/树冠轻晃、尘浪/雾粒/雨丝/水面涟漪推进、远距人流/车流/兽潮涌动、域场余波/结构轻震、挂钟秒针/屏光节律闪动、烟柱/火光蔓延方向等；**禁**脱离主环境清单臆造新实体；**禁**写 Stage 3 专责的材质/光源/声场/色彩/整体氛围定调（§10 边界仍适用）。**实体动作氛围（≥1 项）**：写画内**具名角色/群演簇/道具**的可拍动势链 `实体→起始态→变化→落点`——如甲士抬枪/盾墙前推、马蹄溅尘节奏、武器出鞘/交击、指挥挥旗、人群推涌/回头、角色慢步踏入/停顿扫视、手指扣扳机/翻页/指尖轻敲、群演簇错位微动等；须服务本场剧情与吸睛，**禁止**只写「众人威武」而无具体动作节点。**双层咬合（强制）**：至少 1 项环境动态与 1 项实体动势**同链呼应**（例：风动旌旗+阵线推进；门缝光带渐宽+门内脚步声逼近；雨丝加密+路人收伞快步）。**宏观吸睛→入戏特写过渡（强制）**：当开场吸睛采用**宏观/全景/EWS/Drone/大军阵势/灾难规模/环境级奇观**等大尺度画面时，**进入正常建置/入戏前须安排 ≥1 项特写陪衬过渡**——如盔甲/武器/旌旗/马蹄溅尘/指挥眼神/主要角色面部或局部、关键道具细节、阵线局部纹理等；写法须形成 **Wide/EWS → Insert/CU/Scale Contrast → 建置/入戏** 的可拍链（Push In/Rack Focus/Match Cut/Scale Contrast/OT-LS→OT-MC 等），**禁止**宏观吸睛后直接硬切进入对白/走位/正常入戏而无特写缓冲。**0 度轴锚定**见 §11；首 Beat 若为特写/航拍，须在【场景切换与首节拍转场】标明「0度轴锚定 Beat」及「0 度背景侧」，并写明**宏观→特写→入戏**过渡手段。POV/延迟全局落位例外（§16 原口径）：首 Beat 仅落位 POV 可见范围内实体；其余标「待全局建置 Beat + 触发」于【Scene实体覆盖】，补全 Beat 再落位。**分组/分批出场**：首 Beat 只落位该时刻确已同框者；后续 Beat 按 §17 待入画标注补建。
17. **Scene 实体覆盖评估（强制）**：Scene 开场**先盘点**本场全部主体（具名人物、物件、群演簇、后续入画者；含闪回切片主体）。**群演簇**（村民/路人/士兵群等）落位写在 **Beat 正文**，Stage 2-1 按簇提取。**Scene 级只排期、不建置（强制）**：【Scene实体覆盖】只需列本场**全部**主体的**出入场排期**——已在场者标「开场即在场」；**画外/待入画者**标注「待入画 Beat + 触发 + **具名出入口**（须逐字对应【主环境】已声明的门/门洞/走廊口/巷口等可通行结构；画面左/右/纵深仅可作相对镜头补充，**禁止**单独写「从右边进入/从左出画」而无具名出入口）」；**中途离场者**标注「离场 Beat + 触发 + **具名出入口**」。**不要求、不代做**具体落位、身体朝向、视角正背面、前景/中景/背景 层位、初始状态等任何建置内容——**这些均属该主体实际入画/在场 Beat 的职责**，须由该 Beat 依据其**实际 Observer View** 写**实体落位**（§12/§16），**禁止**在【Scene实体覆盖】里预写位置/朝向/角度。**远距离/受限 POV 例外（§16）**：首 Beat 为远距离/受限 POV 时，触发 `全局建置=延迟`（当前 POV 不可见/不可读的已入场者）或 `全局建置=即时`（当前 POV 可见/可读者，由首 Beat 自行落位）；`全局建置=延迟` 须标注「待全局建置 Beat + 触发条件 + **补全手段（航拍/高位类优先）**」——此处仅为**排期标注**，具体落位仍由该补全 Beat 自行完成，不在【Scene实体覆盖】中预写。**分组/分批出场例外（§16）**：若本场存在**两拨及以上人群/主体本就分属不同 Beat 先后登场、不同框**（非 POV 限制导致，而是剧情/空间/节奏本身设计如此），**禁止**为求开场「全体亮相」而把后到场的一拨人群标为「开场即在场」并强行并入首 Beat 建置；须如实按各自实际登场 Beat 分别标注「开场即在场」或「待入画 Beat + 触发 + **具名出入口**」，首 Beat 建置**只覆盖**确与其他在场主体同框的一拨。**快速闪回切片内首次出现、仅存在于回忆时空的主体同样须列入本场【Scene实体覆盖】并具名**，标注其所在切片 Beat。任一 Beat **新变为画内可见**的主体若前序 Beat 无出入画交代，该 Beat **必须**按 §11「新出场角色完整建置」触发 §14 建置重评估并补全三层（与 Scene 开场同等粒度，**须写清经哪个具名出入口、怎么进入**）。本项只负责**出入场排期与可核销闭环**及**可拍交互证据线索**（拿起、递交、移出、破坏、跨 Beat 状态承接等——仅标注发生所在 Beat，具体交互细节由该 Beat 描述）；**禁止**预列资产表或使用 `ENV/PROP/CHAR` 标签；主体分类、升格归档、衍生变体、环境补建、`ENV/PROP` 归属等归 Stage 2-1。  
## 3. Beat 建置与空间（§12–§15）
12. **站位与空间建置（强制）**：= Beat **建置段**细则（两段式与主锚人物建置法的定义见 §1，本节只补细则）。
  - **核心定义**：建置段以自然语言写清**观察视角 + 当前 ENV 名 + 画内可见实体落位/朝向**（七要素+朝向四要素）；书写顺序 `观察视角+ENV 名 → **十字轴线速查（简要）** → 主锚完整落位 → 他人相对锚点 → 道具/群演簇落位`；**位置与朝向逐处锚定具名参照物**（§1「参照物强制」），禁无参照的「后方/旁边/附近」等含糊方位词；落位**由表达需求推导并承接上一 Beat 终态**（§1「表达驱动」「前后连续」），禁凭空设计、禁无过渡跳变；**禁止**写动作/对白/微表演、重述环境空镜骨架、与入戏段穿插。
  - **场景十字轴线（强制，每 Scene 建立；角色—环境相对位置固化）**：每个 Scene **必须**建立一条**十字轴线**，把画内角色与【主环境】具名固定实体的**相对位置关系固化**为全场连续性基准，供视角切换时重推落位。
    - **定义**：十字 = **主轴**（对戏/动作轴线，通常沿主客位、对坐连线、对峙双方或主叙事对戏轴）+ **横轴**（与主轴正交，锚定左右扇区）。两轴交点优先落在主舞台中心或主对戏区；**两端须挂靠【主环境】具名固定实体**（如「主轴：半开木门↔百叶窗墙段；横轴：会议桌头椅↔文件柜」），并写清当前在场角色/簇相对两轴与实体的固化关系（例：「甲居会议桌左侧横轴负向、乙居桌右侧横轴正向，相对主轴同排对坐」）。**与 0 度 Viewing Direction 的关系**：0 度轴是环境观察基准；十字轴线是**角色—环境相对锁**；二者可共线或成角，但**禁止**用镜头左右替代十字轴固化（镜头左右随视角变，十字轴世界关系不变）。
    - **Scene 级声明（强制）**：在 Scene 块输出 **【十字轴线】**（置于【主环境】/【衍生环境】之后、【观察视角与空间建置】之前）——只写主轴/横轴 ENV 锚点 + 角色相对固化摘要 + 与 0 度轴夹角关系（一句话）；**不写**七要素完整落位、不写镜头层位、不写动作。全局建置延迟场可先写「轴线待全局建置 Beat 固化」，该补全 Beat 起必须落定。角色入画/出画/明文位移后，下一 Beat 起按新终态**更新轴线固化关系**（可在【十字轴线】末注「更新 Beat={n}」或仅在后续建置速查中体现最新态）。
    - **每个 Beat 起笔速查（强制）**：动笔建置段前**必须**对照本场【十字轴线】做速查——当前在场角色相对主轴/横轴/具名实体的世界关系是否与上一 Beat 终态一致；再写本 Beat 观察视角下的落位。建置段开头用**一两句**写明速查结论（例：「轴线速查：甲仍桌左、乙仍桌右；本拍切 180°，镜头左右对调，世界关系不变」）。**ENV/观察轴未变**时也须速查，可更短（「轴线速查：关系未变」）。
    - **视角转变时按轴线重推（强制，推导过程）**：凡观察侧/ENV 切换（正反/OTS/越轴/>90°/门窗内外等），须**依据十字轴线**将角色与环境实体的相对关系换算到新 Viewing Direction 下重写落位与朝向四要素——**保持角色之间、角色与 ENV 具名实体的世界相对位置一致**（未发生明文位移/出入画前，禁止因换镜而改写谁在桌左/谁在门侧）；仅允许变化的是相对镜头的左右、正背面、前景/中景/背景 层位。建置段用**简要推导句**交代换算（例：「由 0°→180°：主轴两端对调入画；甲仍相对会议桌左侧，镜头下改居画右」），**禁止**省略推导直接凭感觉重摆。
    - **成稿边界（强制）**：十字轴线的速查与视角换算**只写在建置段**；**禁止**写入戏段当作动作/走位/表演过程（入戏只写本 Beat 真实发生的位移、对白、微表演）。推导是建置准确性工具，不是剧情动作。
    - **禁止**：无十字轴线即写多视角对白/正反；换镜后角色相对桌/门/窗跳边而无位移交代；把「镜头左/右」当成世界固化关系；在入戏段铺陈轴线公式或冗长推演。 
  - **逐主体七要素（强制，每个人物/物体各写一遍，内化于自然语言）**：`[具名主体] + [位置（纵深可内化；横向左/中/右 + 距参照物，须标明参照系：相对 ENV 结构部位 / 相对具名实体 / 必要时相对镜头层位）] + [运动方向与朝向] + [视角正背面（相对当前 Observer View：正面/背面/左侧面/右侧面/四分之三面 + 该面可读性）] + [与他者/物件朝向关系] + [面部/视线/传感落点] + [动作方式] + [与他者/环境的空间相对关系（前/后/左右/隔障须写清参照 ENV 结构或具名实体，禁止裸写「在前/在后」）]`；有高度差时须含垂直上/中/下；**画内人物**须完整覆盖**角色建置朝向四要素**；有对白时另须核验**对白咬合**（环节 4）；缺任一要素即该主体建置不完整。
  - **角色建置朝向四要素（强制，画内人物逐项同写）**：建置**不仅**写位置，**还须**同步写清下列四项，缺任一项即人物建置不完整：  
    - **① 位置**：前景/中景/背景 + 左/中/右 + 距参照物（标明相对镜头/ENV/具名实体参照系）+ 必要时上/中/下（高/中/低）；  
    - **② 身体朝向**：躯干/肩线/座姿/站姿在立体三轴中的面向（归入「运动方向与朝向」）；  
    - **③ 视角正背面**：相对**当前 Observer View**，人物**哪一面朝向镜头**（正面/背面/左侧面/右侧面/四分之三面），及该面**口型/眼神/微表情是否可读**；OTS/正反/POV/越轴切换后须**按新 Viewing Direction 重判**，禁止沿用上一视角正背面。  
    - **④ 与他者/物件朝向关系**：相对**具名他者人物、道具、载具或 ENV 结构**的朝向语义——须锚定参照对象，禁止只写坐标不写相对朝向；**锚点—镜头传递自洽**见「方向性实体参考清单」。成稿格式见 §10 统一模板。
  - **正面露出保底（强制，Scene 级规划）**：每个具名画内角色在本 Scene 内须**至少一次**以正面或四分之三面朝向镜头、面部可读。凡因**正反打/OTS、参拜/仪式/跪拜、背对威胁、背身入画**等设定为背对/侧背视角的角色，须**提前规划转正时机**——在该背对 Beat 写明「正面露出 Beat={n}」或等效说明（经何动作/视角切换面向镜头）；不得整场只给背影/侧背而无正面 Beat。**唯一例外**：剧情需要的**秘密角色/悬念遮面**（蒙面人、暗中窥视者、Reveal 前反派等）——须写明保密依据；若本剧后续揭示，须标注揭示 Beat 或「本 Scene 不揭示：原因」。
  - **前后位置双轨（强制，逐角色，优先 ENV/实体参照）**：**主锚人物**优先写**相对 ENV 结构**的绝对落位；**其他人物**优先写**相对主锚人物**的距离/左右/前后/隔障/面向/视线，必要时补相对 ENV 结构。**相对镜头层位**仅在 OTS/正反打/遮挡/跨层位移等必要时点明。
  - **混合参照系换算一致（强制，同一 Beat 内两套前后参照系并存时必须执行）**：部分实体用相对 ENV/实体、部分用相对镜头层位描述时，须在内部换算到**同一条纵深轴**核对相对远近，冲突须回改。
  - **思考模板（内部推演，不得原样输出）**：`[十字轴线速查] + [环境/主锚点逻辑] + [视角角度换算] + [各实体三轴落位] + [空间约束] + [环境切换]`；视角变时内部完成轴线换算，建置段只留简要推导句，禁止把完整推演写入戏。
  - **成稿覆盖项**：当前环境名与观察基点、视角角度、**每个可见人物/物件的相对落位与朝向**、距具体参照物距离、阻隔/高低差/行动余量、**运动方向与朝向（含视线/传感落点）**、相对实体定位、环境切换；**须与本 Beat 剧情逻辑一致，禁止脱离情节随意发挥**。全部内容不得留空或"-"等符号替代；**禁止**用「全员/两人/若干道具已就位」概括替代逐个主体描述。

- **Beat 切分先于时长验算**：动笔每个 Scene 前，**先按 Beat 完整逻辑规则**（拆句、正反打/观察侧切换、听者反应、叙事转折、§26–§28、快链合并等）确定 Beat 数与粒度；**不考虑** `Shot / Lens Preference`（镜头偏好/长镜头因素）。再汇总集时长、原文显式时限、Project Notes，写入 Part 1【节拍时间规划】并验算等效时长。
- **Beat 生成规则速查（切分依据，非镜头偏好）**：
  - **强制另起 Beat**：**角色粒度**——对白/对话逐说话人轮次（说话人变更即另起 Beat，无论观察侧/ENV 是否切换，文首「角色粒度」）｜**>20 字对白拆句**各子句各 Beat（§25）｜**当前可拍 ENV 名变化**（§12，含 >90° 真反打/越轴/POV/门窗内外/状态·特效）｜听者**开口应答/接话**（反应留本 Beat、开口另起，§四）｜叙事节拍/信息 Reveal 转折｜域场态变化｜**正式决战/宏观群体阶段节点**（§27/§28）｜**新主动施力方且非同一节奏单元快链**（§26；快链合并优先，见下条）｜转场专拍/快速闪回等专拍 Beat。
  - **不强制另起 Beat**（同 ENV、观察轴未变）：≤90° **过肩/Insert/CU/ECU/MCU** 景深或框景收紧（**禁止**另建衍生 ENV；句中 Insert/眼部特写等**可并入**当前说话人 Beat 正文）｜同一说话人连续发言 **≤20 字**且未被打断（可留同一 Beat）｜快链内攻防换手（格挡→闪避→反击，§二，满足合并条件时）。**注**：不另起 Beat ≠ 可省略建置；若仍为同一 Beat 内多相位，建置段写在 Beat 起势一次即可；**凡另起的每个 Beat 均须完整重新建置。**
  - **快链可合并**（§二）：同一节奏单元内、连续动量、无叙事停顿的无对白/武戏动作链。
  - 决战≥10、宏观≥6 为硬下限（§27/§28）。
- **等效时长验算（内部推演，成稿写自然语言）**：Beat 数由规则自然产出后，`本场等效秒 ≈ 对白+动作+建置/转场+奇观补偿`；单 Beat 等效宜落 4–15s 下游区间，**但不得**为此回头合并/拆分 Beat。
- **显式时限落点**：`前 5 秒吸睛` → 【场景切换与首节拍转场】首节拍三步；`快速闪回 ≤8s` → 转场专拍/快速闪回 Beat；特效/域场 `维持 N 秒` → 六相链维持相或专拍 Beat；须在对应字段**写明秒数**，不得只写「短暂」「一会儿」。
- **等效时长复核算术（每场必填）**：对白约 4 字/秒（极短句 1.5s 保底）；日常微交互 1–2s；正常大动作/格挡/躲闪 3–5s；**快链合并 Beat** 内每招约 1–3s 累加；**追杀/穿梭路径节点**每节点约 2–4s 累加（§31，整链等效 **≥20s**）；奇观/域场/宏观场面单独 +3–6s 或 ×1.3；建置/转场留白 1–3s；写入【Duration Estimate Basis】。
- **与 §27/§28 优先级**：决战 ≥10、宏观 ≥6 为硬下限（**继承剧本生成规划，本阶段不得压缩**）；时间压缩**不得**突破；时间扩写**不得**违反 §26 客体独立 Beat 禁令。
25. **每场对白拆句判定（强制）**：每个 Scene **必须**单独输出【对白拆句判定】，明确本场是否进行了拆句处理；禁止省略、默认不写或仅在 Part 1 汇总而不逐场声明。  
  - **判定值**：`已拆句`|`未拆句`|`无对白`
  - **已拆句**：逐条列出被拆原句/原段（说话人+原文或核销源对应句）→ 拆句后各子句（含情绪标点 + **各子句 rhythm/stress/pause 微调**）→ 落点 Beat → 配套说话动作切口或听者微反应。>20 字单句或同一角色连续说话 >20 字**必须**拆句并标 `已拆句`。  
  - **未拆句**：须写**未拆原因**（如：全场最长台词≤20 字且节奏无需断句；纯 OS/V.O. 画外无口型；武戏无画内对白；单句短促爆发且≤20 字等）。禁止对 >20 字应拆句台词标 `未拆句`。  
  - **无对白**：本场无任何对白/OS/V.O./旁白/独白，写 `无对白：原因`（如纯动作场、纯环境转场、纯特效专拍等）。  
  - **与成稿一致**：【对白拆句判定】须与 Beat 正文 inline 对白、拆句结果一一可核销；拆句不改词义与剧情信息，仅断句+标点+节奏。
26. **纯粹受力/客体运动禁止独立 Beat（强制）**：**纯粹受力的动作不得单独建 Beat**，必须与**主动作（发力方）**合成同一 Beat 的因果链延续；被动物件飞行/滚动/落点、受力方纯粹被动位移（被推动、被击倒、被抛出而无格挡/闪避/承接等主动意图）均须写入**施力方 Beat**内连贯描述，**禁止**升格为下一 Beat 的「主节拍」。**唯一例外**：受力方产生**新的主动作**（接球、格挡、闪避、拦截、反击、主动后撤收势等）时，方可新开 Beat，且**主节拍归该新的主动施力方**，不得把「球飞了」「人被推倒」本身当作 Beat 主节拍。**不含**：动力行驶/操控响应中的**载具与可自驱动道具**（其动作按 §6「道具/载具独立动作」单独成段书写，可作主节拍归属；≠ 本条禁止的「球飞了」类客体）。**优先级（强制）**：**同一节奏单元快链合并**（§二「快速系列动作同 Beat 合并」，含格挡→闪避→反击等攻防换手）**优先于**一般「新主动施力方须拆 Beat」规则——快链满足 §二合并条件时，**不必**因施力方切换机械拆 Beat。  
27. **正式决战（§27，仙侠/武侠/武打/技击/玄幻）**：`正式决战=是` → Scene **≥10 Beat**，**Scene 级**禁概括合并（对峙/试探/攻防轮/术法域场/逆转受伤/决胜/收势各阶段须分 Beat 覆盖）。**判定**：生死决斗/终极一战/核心飞剑术法对决/高潮武力战；**不含**宏观对阵(§28)、日常比划、≤3招。**结构**（全覆盖）：对峙→试探→攻防≥4轮(换招/格挡/闪避/反击各≥1)→术法域场→逆转受伤→决胜→收势。**阶段内**快速连招/连续攻防**可同 Beat 合并**（§二「快速系列动作同 Beat 合并」），但 Scene 总 Beat 数仍 **≥10**；**快慢节奏**须服从 §30（升格≈30%、≥1 快连击链、常速≥50%）。**高成本**：≥3 Beat 轻功/飞翔/空域/域场(§三-B/§七-C)，禁全地面平拍。**输出**：【决战 Beat 规划】+【打斗快慢规划】（§30）+高成本清单；<10或奇观<3→「决战 Beat 缺口」；打斗节奏不合规→「打斗节奏缺口」。  
28. **宏观群体（§28）**：`宏观群体=是` → Scene **≥6 Beat**，禁「大军开到/一触即发」。**判定**：大军/两阵对冲/兽潮/机群/舰队/人海/阅兵/遮天蔽日/无边无际等；**不含**2–3人背景簇。**三要素**：①无边无际(前景→背景地平线满幅) ②阵势威武(前景-中景-背景满编+**剧本威武/宏大/雄壮细节**+有组织感阵线/推进；**须真实自然**——允许 terrain、疲态、个体号召/呼喊错落、队形弹性等合理参差，**禁**整齐划一/机械同步——如全员绝对同高同姿、完全同一节拍踏步、复制人阵列) ③压迫感(体量逼近/尘浪声浪压境)；高潮三项齐，余Beat≥2项。**主要角色贯穿（强制）**：宏观场须同步跟踪本场**具名主要角色**（不限于指挥/主将）——各 Beat **正文**须写明其在阵线/队形中的相对位置、叙事功能或体量锚；**景别/观察视角切换**（全景↔特写、Drone→人物 CU、Scale Contrast、Match/Cut 等）须写清主要角色**过渡**（骑乘/旗从众/随从簇锚、位移、视线或动作 Match），禁止切换后主角落位断裂或凭空出现；Beat 2+ 遵循 §11 跨 Beat 可见性过渡。**全景+特写增强震撼（强制，§三-D/§七-D）**：宏观场**须全景与特写交替或同链组合**，用尺度反差强化压迫与军威——**全景**交代体量/阵线/地平线/推进浪潮（**含主要角色在阵中的可读锚点**）；**特写**钉住盔甲磨损、武器阵列举起、旌旗猎猎、盾墙推进、马蹄溅尘、戟林前指、舰炮开火、兽瞳/甲胄反光、指挥/主角眼神、金属撞击瞬间等（**优选有叙事功能的自然瞬间**，非机械同步）；**阵势细节 Beat** 与 **高潮 Beat** 各须 **≥1 全景 + ≥1 特写**（或同 Beat 内 Wide→Insert/Rack Focus/Scale Contrast 链）；禁整场仅全景空镜或仅抽象「大军威武」而无特写切口。**结构**：无边际全景建置→阵势细节(全景+特写交替+军械描绘+主要角色锚)→压迫推进(低角/Tracking+局部特写)→指挥/主角焦点(Scale Contrast+面部/旗令/主角特写，含切换过渡)→高潮对冲(全景对撞+命中/冲击特写)→余波。**禁**：稀疏小簇/「远处若干士兵」/整场无特写/整场只见群演不见主要角色；须前景/中景/背景满编。**输出**：【宏观 Beat 规划】须标注各 Beat 景别（全景/特写）+ 主要角色锚点。
29. **等效时长规划与 Beat 切分边界（§29，强制）**：下游单镜视频生成强制 **4–15s**。**Beat 切分与合并的唯一依据为「Beat 完整逻辑」**（文首总纲表前置+六环节、**角色粒度—对白/对话逐说话人轮次切分**、§25 对白拆句、§26 客体禁令、§27 决战≥10、§28 宏观≥6、§30 打斗快慢、**§31 追杀/穿梭连续链**、观察侧/ENV 实质切换、叙事节拍转折、域场态变化、§二「快速系列动作同 Beat 合并」等）；**角色粒度为对白/对话场景的默认强制切分依据**——同一场对话中不同角色的发言轮次，即便观察侧/ENV 未变化，也**必须**各自独立成 Beat，不得以「无视角切换」为由合并；**禁止**因 `Shot / Lens Preference`（镜头偏好/长镜头/特写/快切）而增减 Beat 数，或为迎合单镜时长而合并/拆分本应独立的正反打、拆句、听者反应、**决战阶段节点**、**追杀/穿梭路径节点**。**输入来源（仅用于等效时长估算与校验，非 Beat 切分依据）**：`Episode Duration`（每集时长）、`Project Notes`；原文/用户提示中的**显式时限**（如「前 3 秒吸睛」「闪回 ≤8s」「整段 ≤30s」等）。**规划原则**：① **先按 Beat 生成规则产出 Beat 数与粒度**，再验算等效时长是否可落入下游可拍区间，并在【节拍时间规划】写明依据；② **显式时限**须写入对应 Beat/转场字段（前 3 秒吸睛、闪回上限、维持时长等），**不得**为凑 Beat 数而删减；③ **硬性下限**：`正式决战=是` 仍 **≥10 Beat**；`宏观群体=是` 仍 **≥6 Beat**；**追杀/穿梭链整链等效仍 ≥20s 且路径节点 ≥3**（§31）；④ **每 Scene 必输出**【Duration Estimate Basis】：对白（字数/4）、动作层级、**打斗场另分项：常速快相位/升格慢相位**（§30）、**追杀/穿梭场另分项：路径节点累加**（§31）、建置/转场留白、奇观补偿的加法算式 + 本场 Beat 总数与单 Beat 预估区间；⑤ **集级校验**：各 Scene `Equivalent Duration` 之和须与 `Episode Duration` 可 reconcile（偏差过大须在 Part 1【节拍时间规划】说明，**不得**为此违反 Beat 规则压缩/扩写 Beat）。**禁止**：镜头偏好驱动 Beat 切分；无视显式时限；为压 Beat 数合并本应独立的正反打/拆句/**决战阶段节点**/删减追杀路径节点；为拉 Beat 数把客体轨迹或纯粹受力升格为独立 Beat（§26 仍适用）；**禁止**为机械拆招把同一节奏单元内可完成的快链硬拆多 Beat；**禁止**追杀/穿梭一笔带过压时长（§31）。  
30. **打斗快慢节奏规划（§30，强制）**：凡 Scene 含**近身打斗/追逐缠斗/正式决战/武打换招/术法对撞/投射攻防**等打斗过程（不含纯对峙静止、纯建置、纯收势余韵段），须在剧本层规划**常速快相位与升格慢相位**配比，供下游分镜继承。**升格占比控制（Mandatory）**：统计范围为本场打斗连续链（从首击/首招至收势前全部打斗 Beat）；**升格慢相位**= Beat 内标注 `{升格}`/`{慢镜}`/`Bullet Time`/`定格读命中`/`Time Slice` 等慢速可读节点（**不含** Speed Ramp 入出过渡）；累计等效时长须控制在打斗过程总时长的 **≈30% 左右**（建议 **25%–35%**）；**>40% 视为升格滥用**，须削减升格改写为常速；**<15% 且无快连击**视为节奏失败。**快连击设计（Mandatory）**：每个打斗 Scene 须 **≥1 段快速连招/快攻链**——优先用 §二「快速系列动作同 Beat 合并」+ **§30-A 立体快链模式**写 **≥3 击/≥3 招** 常速衔接，**连续快击可同 Beat 合并**；链内逐招写轨迹节点与命中/格挡效果；**禁止**只写「一套连招」而无各招过程；**禁止**把多击全拆成升格慢镜。**快连击逐招具名与攻防匹配（Mandatory）**：链内**每一击/每一招/每一防须写具体招式或动作名称**；**攻防匹配**见 §30 与 §30-A。**常速快相位合计须 ≥50%** 打斗总时长（建议 50%–70%）。**升格落点**、**Beat 写法**、**输出**同前；缺 **§30-A 立体快链**（多段攻击手段+双方位移）或 **§30-B 环境融合**（≥2 结构+≥2 层融合）或快链缺招名/缺攻防匹配 → 「打斗节奏缺口」/「环境融合缺口」。

**§30-A 立体快链打斗描述模式（Strike-Move-Environment 三位一体，Mandatory）**

**定位**：连续快攻/快连击 Beat（含 §二 同 Beat 合并链）的**标准成稿模式**——把**多段攻击手段**（拳/掌/肘/膝/腿足/抓摔等）、**双方位置移动**、攻防对位、立体层次、环境融合写进**同一条可读快链**，供下游分镜直接摄影转译。**凡 Scene ≥1 段快连击，须至少 1 Beat 完整采用本模式**；**动笔前先读【主环境】固定实体清单**，从中择 **≥2 个具名结构/陈设**作为本链 ENV 参与物。

**七维合成（每条快链须全覆盖）**

| 维度 | 写什么 | 最低要求 |
| :--- | :--- | :--- |
| **① 多段攻击手段** | 链内逐招须**具名**，且覆盖 **≥2 种**不同攻击部位/手段——**拳/掌/指**、**肘击**、**膝撞/飞膝**、**腿/足**（正踢/侧踢/鞭腿/扫堂/铲/绊/踩）、**抓/拧/推/架**、**肩/髋撞**（题材适配）；每段写发力侧 + 命中/格挡部位 + 上/中/下段 | 链内 **≥2 种手段** + **≥3 击**；**禁**全程单一手段（如只连拳或只连腿） |
| **② 双方位移** | **攻守双方**每拍均须写**可见位置变化**——逼近/后撤/绕侧/换轴/跨层/借物跃起/贴结构滑步/失位退至 ENV 锚点；相对距离、区段、轴线须可读 | 链内 **≥3 次**落位变化，且**双方各 ≥1 次**；**禁**同点站桩互殴 |

| **⑥ 环境融合** | 打斗与 ENV **材质/光影/动态/受力反馈**同场发生——见 §30-B | 链内 **≥2 层**环境融合（结构+材质/动态/光影 任二） |

**§30-B 打斗环境融合专规（Mandatory，与 §30-A 同 Beat 执行）**

打斗**不是**在空白场地上互殴——须与当前 `ENV:[...]` **主环境/衍生环境**的固定实体、材质、光源、可动元素**同场咬合**。

**动笔前 ENV 提取（Mandatory）**
1. 从【主环境】固定实体清单择 **≥2 个**本链参与结构（桌/柱/门/窗/椅/台阶/栏杆/柜/墙段等），写入 Beat 起点；
2. 读取 ENV **地面/墙面材质**（木地板/瓷砖/地毯/湿石/沙地等）→ 影响滑步/阻脚/尘起；
3. 读取 ENV **动机光源**（窗光/Practical/霓虹/天光）→ 影响走位明暗区与剪影；
4. 读取 ENV **可动/易扰元素**（杯碟/纸张/帘/门扇/悬挂物/植被）→ 受力/擦过时可触发微动。

**连续动作描述（Mandatory）**：
1. **禁止一笔带过**：禁「追过去」「穿过走廊」「一路狂奔」「穿梭其间」等结果动词概括整段；须写**连续子动作链**。
2. **路径节点链（强制）**：整链须含 **≥3 个可核销路径节点**（相对 ENV 具名结构/固定实体），成稿格式：`起点落位 → 节点1（动作名+发力/路径+途经参照物+速度态）→ 节点2 → … → 终点落位/抓捕·逃脱·转入缠斗`；每个节点写清**追者与被追**相对距离/序位变化（逼近/拉开/并排/错肩），禁只写一方。

   - **具体奔跑/行驶路线**：相对 ENV 具名结构的路径形态——如沿中线→贴右障→斜切过桥→折入窄巷；须写**途经参照物序列**（门洞/立柱/壕沟/落石/摊位/树丛等），禁「一路狂奔」「飞驰而去」。

   - **特殊动作（择 ≥1，障碍场景强制）**：写清**跳过/跃过**（跃壕沟、越断桥、腾空过落石）、**绕过/绕障**（绕立柱、贴墙擦过、绕摊位外弧）、**钻过/穿过**（钻门洞、穿拱廊、过树冠间隙）、**急转/侧身擦过/急刹避障/超车并排/错肩换侧**等具名动作 + 相对障碍物的接触关系（擦过/跃过无接触/擦碰）。
   - **双方载具/坐骑相对态**：追者与被追各自路线是否同道/分道、相对距离弧（逼近/拉开/并排/错肩），禁只写一方载具。
4. **载具追逐节点（强制）**：凡节点涉及车/船/飞行器/坐骑等，须以**载具/坐骑为动作主语**写加速/变道/占道/轴向变化 + 上条四维，禁只写人物「追」「逃」而无车体/马体过程。
5. **穿梭专项**：经门洞/窗洞/转角/楼梯/窄巷/立柱间隙时，须写**门槛/转角/层间**过渡（进→经→出），含开闭门态服从 §二门窗五维；**禁止**无视阻隔瞬移到下一空间。坐骑/载具穿梭同理——写载具/坐骑如何进→经→出该结构。

- **剧情承载（强制）**：每句对白/OS/V.O. 须推进立场/筹码/关系/前因/后果之一；跨 Beat 信息须靠对白承接、听者反应或当场交代来源，禁装饰性流水账；>20 字拆句时插入反应/动作切口使信息递进可读。

- **语气层 inline 标注（强制，每条对白/OS/V.O./自白/独白）**：Beat 正文开口写台词前，须 inline 标注下列字段（括号内自然语言，**禁止**只写「开口说」而不写语气层）；字段须与 Part 1【角色命名】该角色 `voice_identity` **一致或 shorthand 引用**，并与本句**面部微表情+微动作**咬合。  
  - **`voice_type`**：对白｜OS｜V.O.｜自白｜独白  
  - **`voice_identity`（强制）**：说话人**身份/声线人设**——取自【角色命名】，Beat 内可 shorthand（如「林医生·领导型主治医师音」「村妇·农家妇女音」「少女·萝莉音」）；须让配音/TTS 可检索音色类型，**禁止**省略或仅写姓名  
  - **`tone`**：情绪气质（冷峻、试探、讥讽、温存、压抑、爆发、嬉皮、威严…）  
  - **`speed`**：慢｜中速｜快｜渐快｜渐慢｜先慢后快…  
  - **`volume`**：低语｜正常｜略高｜厉声｜压抑声｜气声…  
  - **`rhythm`（节奏型，强制）**：本句**整体节奏走势**——如「一字一顿」「短促连珠」「先缓后催」「抑扬顿挫」「平铺直叙」「句尾下沉」「问句尾音上扬」等；须与 `speed`/标点一致  
  - **`stress`（重音，强制）**：标出**须重读的关键词/字**（2–5 处为宜，与剧情信息点一致）——如「重读：确定、签字」「重读：条件、一个字」；重音须落在立场/筹码/关系/事实词，禁随机强调  
  - **`pause`（停顿，强制）**：标出**有意停顿位置与类型**——如「句首蓄力半拍」「报告——你确定」「条件后长停」「换气后再开口」「吞咽后挤出」「破折号截断」「省略号拖长」；停顿须服务节奏与情绪，并与 `……`/`——`/`,` 等标点一致  
- **情绪标点（强制）**：先判情绪阶段与 `rhythm`/`pause`，再选标点；与 `tone`/`speed`/`volume`/`stress` 一致；服务口型与微表情切口。可用：`，` `。` `……` `——` `！` `？` `、` `「」/""`；策略类型：压抑型、爆发型、试探型、喜剧型、治愈型、紧张型；>20字拆句时每子句自带标点 + **各子句独立 `rhythm`/`stress`/`pause` 可微调**。  
- **声线人设参考（`voice_identity` 选型，须结合题材具体化，非穷举）**：
  | 类型 | 典型适用 | 节奏/重音/停顿倾向 |
  | :--- | :--- | :--- |
  | **领导/上位者** | 领导、上司、君王、将帅、严师 | 语速稳偏慢；重音落命令词/结论词；停顿短而有权威；句尾少上扬 |
  | **御姐音** | 成熟女性、姐姐型、冷艳御姐 | 中低音域感；从容不迫；重音克制；词间停顿干净；尾音略沉 |
  | **萝莉音/少女音** | 幼女、少女、软萌角色 | 偏高；字句短；重音轻；停顿短；语气软、尾音可上扬 |
  | **农家妇女/村妇** | 农妇、大妈、市井妇人 | 朴实口语；语速参差；生活词重读；停顿随呼吸自然 |
  | **老者/长者** | 老人、祖母、前辈 | 气声略重；慢；顿挫分明；重音落经验/回忆词 |
  | **军人/警探** | 警察、士兵、硬汉 | 短句；硬朗；重音落动词/编号/事实；停顿如报告 |
  | **书生/学者** | 文人、教师、医生（文气型） | 吐字清；句读工整；偏慢；重音落术语/逻辑词 |
  | **反派/阴狠** | 反派、审讯者、阴柔权谋者 | 低缓；词间长停；关键词阴读；句尾拖或截 |
  | **市井/商贩** | 小贩、伙计、滑头 | 快；节奏灵活；重音落价格/数量；停顿少 |
  - **同一角色跨 Beat**：`voice_identity` 全剧稳定，仅 `tone`/`speed`/`rhythm`/`stress`/`pause` 随情绪与节拍变化；身份体系变化（换装/年龄态/受伤嘶哑等）须在【角色命名】或 Beat 内注明变体。  
- **禁止**：滥用标点；标点与 `tone`/`speed`/`rhythm`/`pause` 冲突；只写 `tone=冷峻` 而省略 `voice_identity`/`rhythm`/`stress`/`pause`；改数字/**已确立真实姓名**/关键事实词（占位称谓→具名替换见强约束§19，不属于「改人名」）。  
- **OS/V.O./旁白**：明确归属与听者；适用语气层全字段与同场反馈规则；OS/V.O. 亦须写 `voice_identity`。  
- **自白/独白全员闭嘴（强制）**：凡 Beat 含**自白**或**独白**，执行下列规则，缺任一项即 Beat 不合格：  
  - **类型判定**：**自白**=面向自我/镜头/空位/无在场听众的独白式陈述（可画内可 OS）；**独白**=内心 OS/V.O./心理旁白/画外心声（通常 OS/V.O.，听众不在场或不可闻）。原文「独白」「自白」「内心」「心声」「OS」「V.O.」「旁白（角色心理）」等须归入本类并标注 `voice_type`。  
  - **全员闭嘴（强制）**：Beat 正文**仅列画内可见**具名角色与群演簇；**画外/OS·V.O. 声源不在画内时，发言人不在画内角色段落列名**。画内每一个可见具名角色与群演簇均须写**闭嘴**（双唇紧闭/口型静止/未张嘴/唇线抿合），**画内自白**发言人除外；可写眼神/呼吸/肢体微反应，**禁止**画内他人写口型变化、接话、同步张嘴。  
  - **发言人口型**：**画内自白**→发言人可写口型，**写入同期角色段落**；**OS/V.O./画外声**→发言人**不在画内角色段落列名**，声源与台词 inline 标注画外。  
  - **核销位置**：Beat 正文 inline 标注 `voice_type=自白/独白`；画内逐人/逐簇写闭嘴（画内自白发言人除外），禁止用「众人沉默」概括而不逐主体核销；**禁止**在画内角色段落写画外人物。
- **主听众（强制）**：每轮标最主要听众及依据（`叙事目标相关度 > 视线直指 > 空间距离 > 因果承接`）；默认禁止并列，证据等强才写“并列：原因”。听众反应含动态微表情+微动作各≥1。  
- **心理外化**：转译为可拍微表情+微动作+道具接触+空间反馈；禁抽象情绪词（执行见强约束§5/§7）。  
- **环境补充**：须**因剧本而生、为剧本而用**（§10）；仅服务剧情与动作逻辑；禁脱离剧本的装饰性环境扩写；禁在四向拓扑包络外扩张空间（§11）；禁新增改变因果的实体/事件。  
- **输出**：Beat 正文 inline 写成稿台词 + **语气层全字段**；第一部分写【对白语气与节奏】策略、典型 `voice_identity`/`rhythm`/`stress`/`pause` 落点。
- **先判表情强度**：`夸张型`（喜剧/轻喜剧/日常搞笑/闹剧/反差萌）
- **微表情选材**：优先从 §一「微表情常见项」择项组合；喜剧/夸张型场叠加 §一「喜剧类微表情常见项」；须写清部位与动态过程链，禁抽象情绪词。  
- **夸张型**：眉眼幅度大、嘴型明确、多肌肉组联动；反应可适度漫画感但真人可拍；肢体与表情同步夸张；包袱/误会/反转须补夸张表情切口，**优先用喜剧类微表情常见项**（挑眉飞挑、瞪眼、瘪嘴、憋笑抽搐、O 型嘴、斜眼睨视等）并写多部位联动过程链。  
- **细腻型**：写具体微动与渐变链（`前置克制 → 中段裂缝 → 落点余韵`）；强情绪也克制幅度。  
- **标准型**：清晰可读，在夸张与细腻间取中值。  
- **文戏特写增量**：**§5 底线**——每 Scene **至少 1 处**细节特写（任意对象/叙事功能均可）；**§五增量**——文戏 Scene 另须主角**局部特写累计 ≥3**（情绪/信息/道具/局部部位等，可与 §5 那 1 处重叠计数）；长对白每 2–3 句至少 1 处微表情+微动作组合。
### 影视化手法（§六）
- 可选标签：`MONTAGE`、`AV_CONTRAST`、`PROP_SYMBOL`、`MACRO_INTRO`、`CROSS_CUT`、`MATCH_CUT`、`POV`、`OFFSCREEN`、`JUMP_CUT`、`DOLLY_ZOOM`、`EMPTY_SHOT`。  
- 原则：只服务剧情推进/情绪外化/转场连贯，禁装饰性滥用。
## 6. 动作与武戏（§二、§27–§28、§七）
- **主节拍/主动作（强制）**：每 Beat 标明**唯一**主节拍/主动作（或**快速系列动作链**之主节拍名，见下条「快速系列动作同 Beat 合并」），且**必须归属主动施力方**（**例外**：转场专拍 Beat 主节拍=转场桥接，见下条）；被动物件的运动、落点、碰撞及**纯粹受力位移**仅为该 Beat 因果链的延续描述，**不得升格为独立 Beat**（执行见强约束§26）。微动作不得替代主动作，但须在全员反馈与对白停顿中持续落地。  
- **道具/载具独立动作（强制，≠ §26 客体禁令）**：具名道具——**尤其交通工具、坐骑与可自驱动机械体**（车/摩托/自行车/马车/船/舰/飞行器/列车/轮椅动力态/马/灵兽座骑/御剑座骑等）——凡发生**动力驱动、操控响应、奔行或机构自运动**，其动作须视为**单独的主动作主体**，入戏段须以**独立动作单行**书写（`{载具/坐骑/道具名}：…`），成稿须可检索该主体自己的动作链，**不得**折叠进人物动作当状语或并入角色段落同一行。  
  - **须独立动作单行写的载具/坐骑/道具动作（示例，非穷举）**：起步/加速/匀速巡航/急刹/点刹/滑行余势｜变道/超车/汇入/驶离/掉头/倒车入库｜车头/舰首/机头/马首朝向变化｜**追逐路线节点**（途经参照物序列+行进方向+跳过/绕过/钻过等特殊动作，§31）｜四蹄奔行/扬蹄/后蹬｜车门/舱门/厢门开合｜轮转/履带推进/螺旋桨或喷流可见态｜船体纵摇/横摇｜飞行器爬升/俯冲/悬停变轨｜列车进站出站｜机关闸门启闭、屏幕/仪表可读刷新、可动道具的开合翻转等。  
  - **人—载具/坐骑同拍写法（强制）**：同一 Beat 内可写「驾驶员/骑手操作 → 载具/坐骑响应 → 乘客/骑乘姿态随动」，但**必须分行、主语分离**——**载具/坐骑独立动作单行**写车体/马体/船体/机体过程（**奔跑/行驶路线、行进方向、特殊动作、占道、速度态、轨迹节点**）；**人物角色段落**写操作与身体反应（踩油门/打方向/握缰轻磕催促/身体随惯性前倾后仰）；**禁止**只写「甲开车离开」「乙策马追赶」「乘船靠岸」而无载具/坐骑自身过程节点；**禁止**人车/人马混写同一行。  
  - **追逐场面载具/坐骑（强制，与 §31 咬合）**：载具/坐骑追逐的每一路径节点须在载具/坐骑行写清：`途经参照物 → 行进方向（含转向） → 特殊动作名（跳过/绕过/钻过/急转/超车等） → 速度态 → 与对方载具/坐骑相对距离`。正例：`乌骓：沿石板中线加速，马首右切绕过倾倒木车，四蹄跃过沟沿落于对侧蹄道，与前方白马距离由三身位收至一身位`。  
  - **可作主节拍归属**：当叙事焦点落在载具/坐骑/道具运动本身（空镜跟车、载具追逐节点、坐骑跃障、船靠码头、飞行器掠过等），**主节拍可归属该载具/坐骑/道具**（主动施力方=动力源/奔行体/操控响应体）；乘客/驾驶员/骑手反应写入同 Beat 或下一 Beat 的**各自独立单行**，**不**把载具/坐骑运动降级为人物动作的附属描述。  
  - **与 §26 边界（强制）**：§26 禁止的是**纯粹受力客体**（被踢飞的球、被推倒的人、被抛出的杯）**单独建 Beat**；本条管的是**同一 Beat 入戏段内的独立动作单行**——**动力行驶/奔行中的载具与坐骑、正在响应操控的机械体、有机构自运动的道具 ≠ 纯粹受力客体**，须按本条独立单行写动作。被撞失控滑行至静止若无新操控输入，可并入碰撞施力链同 Beat，但仍须给该载具/坐骑/道具**独立动作单行**写轨迹至静止；一旦出现**新的操控/动力响应**（重新加速、急刹避障、转向脱困、扬蹄再跃），即视为载具/坐骑/操控方新主动作，可同 Beat 快链或另起 Beat。  
  - **反例（禁止）**：❌「甲驾车离去」无车体起步/轴向/轨迹｜❌「马车驶过」无马/车体过程节点、只写人物表情｜❌「林开车猛打方向盘冲过红灯」人车混写一行｜❌「策马追出」无路线/方向/跳过·绕过｜❌ 载具/坐骑追逐只写双方人物「追」「逃」而无车体/马体变道/加速/占道/特殊动作节点（§31 仍须写载具/坐骑主语独立单行）。  
- **快速系列动作同 Beat 合并（强制选项，打斗/追逐/术法/日常快链通用）**：**同一节奏单元内、连续动量、无叙事停顿**的系列动作**可合并为单 Beat**，不必每招/每格/每闪独立拆 Beat。典型：**打斗连招**（直拳→鞭腿→扫堂腿）、**连续攻防**（格挡→闪避→反击）、**追杀/穿梭短链**（起跑→绕障→跃槛→贴墙错肩，§31）、**术法连击**（结印→引气→连发）、**日常快链**（拾物→转身→递交）等。**合并条件（须全部满足）**：  
  1. **单镜可拍体感**：合并链等效 **4–15s**，属同一观察节奏单元（One-Shot/跟拍/动作 Match 连贯，或观察侧无需切 ENV 即可读完全链）；  
  2. **Beat 内写完整子动作链**：`起点建置 → 子动作1（**具名招式/动作**+发力/接触/效果）→ 子动作2 → … → 终态落位`；每一子动作须写**具体招式或动作名称**（禁「连招」「连打数拳/数招」泛化）、**关键轨迹节点**（相对 ENV/实体的位置+左中右区段）、**命中/格挡/闪避效果**、**朝向变化**；**双人对战**须写**双方对应攻防链**（攻方招名↔守方格挡/闪避/拆招/反击，或命中/破防/擦过/打空），禁单方无反应堆招；**追杀/穿梭**须写**双方相对距离变化 + 路径节点**（§31），禁止合并后只写「一路追」；禁止合并后只写「一套连招」而无各招过程；  
  3. **位移在链内闭环**：各参战者相对链**起点**须有可核销的三轴位移与终态落位；**Beat 间**仍须相对上一 Beat 终态有落位变化（链内微动不算 Beat 间重复）；  
  4. **主节拍命名**：标合并链整体名（如「甲三连击压制」「乙格挡闪避反刺」「甲追杀乙走廊穿梭三节点」），非仅第一招；  
  5. **【Duration Estimate Basis】**：合并 Beat 按链内子动作数累加时长（每招约 1–3s 快链 / 3–5s 大动作 / **追杀节点 2–4s**），总时长仍须落入 4–15s；**整场追杀/穿梭链仍须满足 §31 ≥20s**。  
  **须拆为独立 Beat（禁止强行合并）**：① 观察侧/ENV 须切换才能读招/读表情/读术法（OTS/正反/POV/状态衍生）；② **新主动施力方**接续（§26，**快链合并满足 §二条件时除外**）；③ 叙事节拍/情绪/信息 Reveal 转折；④ 域场态/结构/layout 跨 Beat 变化；⑤ **武戏/术法**升格慢镜/定格/Insert 须独立可读且**仅作关键节点短插**（§30，**Insert Beat 仍沿用父观察侧 ENV**，禁止另建特写衍生环境；**禁止**为读招把整段快连击拆成多 Beat 升格；**文戏句中 Insert/CU 可并入当前 Beat**，见 §一-A 速查表）；⑥ `正式决战=是` 的**阶段节点**（对峙/试探/术法域场/逆转/决胜/收势）仍须分 Beat 覆盖，**阶段内**快链可合并；⑦ **追杀/穿梭跨主环境或整链将超 15s**（§31，按节点拆 Beat，禁删节点）。**≠** 允许：合并后省略位移/朝向/命中链；把本应分 Beat 的正反/OTS 硬塞一 Beat；追杀一笔带过。  
- **纯粹受力/客体运动禁令（强制，§26 展开）**：  
  - **同 Beat 必写**：施力主动作 → 接触/命中（**写清命中部位/落点**）→ **命中效果/受力反馈** → 客体轨迹或受力方被动位移（**需要时写移动路径**：沿结构滑行/弧线/反弹/滚转等，锚定 ENV 具名部位）→ 落点/碰撞/静止，全链写在**发力方同一 Beat**（或发力方动作延续的下一 Beat，主节拍仍归同一施力方）。投射攻击（子弹/飞镖/箭矢/暗器等）同样适用，禁只写射出/飞出而无路径（需要时）、命中与效果。  
  - **禁止独立 Beat**：以被动物件为主语的单 Beat（「球飞向…」「杯摔碎」「纸张飘落」）、以纯粹受力为主语的单 Beat（「他被推倒」「她被撞飞」且不含主动格挡/闪避/承接）——均须**并入上一施力方 Beat**。  
  - **可新开 Beat 的条件**：仅当**新的主动施力方**接续并承担主节拍——如对方接球、门将扑救、格挡反击、主动闪避后还击、主动后撤收势等；此时主节拍归该人物，不得仅写「受力结果」而无其主动意图。**例外**：**同一节奏单元快链**（格挡→闪避→反击等，§二「快速系列动作同 Beat 合并」）**优先合并同 Beat**，不必因施力方切换机械拆 Beat。  
  - **链过长拆分**：**施力起势 Beat** → **同一施力方动作延续 Beat**（含客体全程轨迹至静止/命中，或受力方纯粹被动位移至落点）；**禁止**拆出「客体独立 Beat」或「纯粹受力独立 Beat」。  
- **形体动作因果链（强制）**：施力-受力、接触-运动同链——先写完整主动作与受力反馈，再写结果轨迹/落点，禁只写结果跳过施力主动作；**主节拍必须归属主动施力方**（人物、有自主意识的活物、**动力/操控响应中的载具与可自驱动道具**、或术法/机关的明确触发者），其余口径同上条「纯粹受力/客体运动禁令」与「道具/载具独立动作」。示例：`甲挥拳击中乙胸口→乙上身受力后倾、脚跟离地半步后坐倒在地`（全链同 Beat）；`Beat 1 主角踢球→球飞向门口；Beat 2 门将跃起扑救`（新主动施力方新 Beat）；`黑色轿车自左车道加速变道切入中线→甲握方向盘侧身回正，车体沿中线驶向路口`（载具主动作单独成段，人的操作/随动另段同 Beat）。  
- **特效拆 Beat（例外）**：术法/域场/奇观六相链过长时，可 **起势 Beat → 特效专拍 Beat → 落位 Beat**（细则见§三-B）；不得替代形体动作链，不得跳过触发源。  
- **转场/过渡专拍 Beat（例外）**：凡 Beat 间、Scene 间或时空/情绪/信息需桥接的转场，本阶段为连贯性**优化补写的过渡情节**（蒙太奇切片、空镜桥接、声画对位、匹配切、走位穿越、环境异象铺垫、情绪余韵承接、**快速闪回**、**无情节回忆切片**等）**可单独建 Beat**；**主节拍=转场桥接**（**快速闪回**时主节拍=快速闪回桥接，**须满足回忆对白 >30 字**，见§三；**无情节回忆切片**可并入相邻 Beat 转场链而不必独立建 Beat，见§三）；须写清：切换判定（时空关系/桥接依据/轴线状态/跨幅级别）、前后承接落点、OT 或转场手段名称、可视过程链；**快速闪回**另须标明进入锚点、回忆切片内容（对白/动作要点）、回切锚点与质感处理（见§三）；**无情节回忆切片**写清触发→切片画面要点（≤2s）→回切锚点与质感即可，**不要求**完整对白链/动作链/三层建置。此类 Beat 服务于叙事连贯与转场可读，**不**视为客体独立主动作；**禁止**无桥接依据的硬切占位。  
- 路径、开关方向、进出径向、绕障路线须写清；凡方向变化须按**立体三轴**落点，且**前/后须标明相对镜头或相对 ENV/实体**（见 §11 前后位置双轨）。  
- 高动量段落须写速度状态（起速/加速/急停/失速）+ **方向变化节点**（每个变向须写清沿哪一轴、从 前景/中景/背景 哪区段切至哪区段、左中右哪区段切至哪区段，必要时上中下）。  
- 位移动作五元组：`起始实体落位（含层位 前景/中景/背景 + 左中右 + 必要时上中下） → 发力（发力部位+立体方向） → 路径/方向（**移动路径**（需要时：相对 ENV 结构的路径形态）+ 沿三轴的变化节点，每节点须 前景/中景/背景 + 左中右） → 终点实体落位（含层位 前景/中景/背景 + 左中右） → 静止/受力结果`（成稿写具体人物/物件/载具/空间结构部位）。**移动链须同步写行进/飞行/车体朝向与轨迹路径**；客体/受力体轨迹**需要时须同步写移动路径**，执行细则见强约束§11「运动方向与朝向」。  
- **打斗场景站位默认（强制）**：凡近身肉搏/追逐缠斗/正式决战/武打换招段，**Beat 间**各参战角色须相对**上一 Beat 终态**发生可核销的三轴落位变化（跨层、绕障换侧、逼近/退离、腾空/落地、借物换位、越轴等）；**Beat 内**快速系列动作链（§二「快速系列动作同 Beat 合并」）位移在链内写清各招节点即可，**不要求**每招拆 Beat。**禁止**多 Beat 固定同一 前景/中景/背景+左中右 硬写换招/格挡/闪避而无位移链；**禁止**为机械拆招把本应合并的快链硬拆多 Beat 却省略链内轨迹。**环境切换与建置重建（打斗专项，强制）**：**每个打斗 Beat 均须完整重新建置**（§15）+ §12 可执行性校验；**ENV 名有变**（观察侧/OTS/正反/POV/门内外/域场态等导致衍生或状态 ENV 切换）→ 须**同步**写环境切换 + 完整重新建置说明；**ENV 名不变** → **仍须**完整重新建置段（承接上一 Beat 终态重写落位/朝向），再写入戏段链内位移/攻防变化，**禁止**省略建置。成稿须可核对「上一 Beat 终态 → 本 Beat 建置 → 本 Beat 变化 → 终态」与「ENV 名=变/未变、建置更新=是」。
- **武戏/决斗/术法 Beat 视角—环境—朝向（与对白同等粒度，强制）**：凡**无对白或对白为辅**的近身决斗、远程投射、术法/域场、轻功空战 Beat，**须与对白 Beat 一样逐 Beat 完整执行环节 1–3**，不得因「纯动作」而省略观察视角、背景层或朝向分析。每个 Beat 动笔前须完成下列**动作视角咬合**核验（与 §12 环境—视角匹配、§11 朝向四要素同拍）：
  1. **观察侧声明（必填）**：写清本 Beat **Observer View**——0 度 Master/Two Shot、OTS 过肩（**四要素**：过谁的肩｜肩主可见面=左侧面/右侧面/正面/背面｜左肩或右肩｜过肩后看谁）、正反打（攻方/守方/施术者/受击者各 Beat 切换）、POV（施术者/受击者/弹道/瞄准）、Insert 特写（拳/剑/符/法器/命中部位）、全景建置（双人/多人对峙或空域换位）等；**相对上一 Beat 观察侧是否变化**及触发（动作 Match、视线 Match、动势切、越轴、入画等）。
  2. **背景层变化（必填）**：按当前观察侧重写 **前景/中景/背景**——须写清相对上一 Beat **背景 可见半空间是否变化**（如 0 度 背景 文件柜墙 → 180 度反打 背景 变为入口/对侧墙；檐上 Beat 背景 变为地面纵深/天际线；域场态 背景 结构/layout Delta）；**禁止**多 Beat 沿用同一主环境 0 度 背景 硬写正反/OTS/越轴而不切衍生环境、不重写三层。
  3. **朝向四要素（必填，逐参战者）**：每个画内人物均须写**角色建置朝向四要素**——位置｜身体朝向｜相对 Observer View 正/侧/背面及可读性｜与他者/物件朝向关系（相向对峙/侧对格挡/背向威胁/同向追击/隔障相对等）；主动作发起时须写**发力侧/武器轴向/术法手势朝向**相对镜头与他者的可读面。
  4. **OTS/正反/双人镜（强制，双人及以上决斗）**：与对白正反打同等规则——**读招/读势/读表情/读术法手势/读受击反馈**时，须切至匹配衍生环境后再写可读细节；典型：**甲出拳 Beat** 可用甲侧 OTS 或 Master 看乙；**乙格挡/受击 Beat** 须切乙正面/侧脸或乙侧 OTS 反打（衍生环境），并重判乙视角正背面与 背景；**术法 Beat** 施术者结印/引气可读时切施术者近景或 POV，命中/域场展开时切受击者 OTS 或状态衍生 ENV 重写 背景。**禁止**标 OTS/反打却仍在主环境 0 度写对方面部/手势/术法细节可读。
  5. **双人/多人入境与出画（强制）**：第二人/第三人**首次入画或重新入画** Beat 须写：**经哪个具名出入口**（与【主环境】逐字一致；禁只写左/右）、相对镜头径向（左/右/上/下/纵深可作补充）、触发（被追击入画/援兵赶到/术法召唤/空域降落）、**入境后 前景/中景/背景 落位+朝向四要素**、与已在场者**与他者朝向关系**；**须与 §11「新出场角色完整建置」同等粒度**——禁止只写「出现/登场/入画/从右边进来」而无具名出入口、位置、身体朝向、视角正背面及关系站位；若入境改变观察侧或轴线，须同步 ENV 切换与建置重建。**Scene 开场双人决斗**首 Beat 须完成双人 Two Shot 或等效全局建置（§16/§17），再进入逐 Beat OTS/正反/POV 切分。
  6. **术法/域场/空战环境切换（强制）**：结印/引气/域场展开/轻功腾空/御剑换层等导致**观察高度、可读侧、固定结构可见性、域场 layout**变化时，须写 `触发 → 视角/状态衍生 ENV 名 → 空镜差异 → 建置重建`；跨 Beat 域场/结构破坏用**状态衍生**；空战 Beat 须写垂直层位（上/中/下）+ 前景/中景/背景 在纵深与高度双轴的落位变化。
  7. **成稿最低覆盖（每个武戏 Beat 须可检索）**：`观察视角（含相对上一 Beat 变化）→ 当前环境名 → [环境切换声明/None] → 前景/中景/背景 框架与各层逐实体落位 → 各参战者朝向四要素 → 主动作/轨迹/命中链 → 终态落位与 ENV/视角承接`。
- **打击与投射攻击链（强制，打斗/远程攻击统一口径）**：近身打击与远程投射均须写完整因果链，禁只写动作名或只写「打出/射出/飞出」而无命中与效果。  
  - **近身打击链**：施力方起势位置（相对 ENV/实体+左中右）→发力方向→**接触/命中部位**→**受力反馈**（位移/失衡/伤态/格挡硬抗等）→**移动路径**（需要时：受力方被动位移沿哪结构/弧线/滚转）→终点落位。
  - **投射攻击链**（子弹/飞镖/箭矢/暗器/投掷物/法术弹道等）：`出手/击发锚点 → **移动路径**（需要时：低平/弧线/绕障等路径形态，锚定 ENV 结构）→ 弹道轨迹（途经节点相对 ENV/实体+左中右）→ **命中部位/落点**（写具体：左肩/门柱/地面哪一区段等）→ **命中效果**（贯穿/嵌入/反弹/碎裂/阻停/擦过/打偏入障/受击者生理或物理反馈/环境痕迹）→ 静止/余势`。闪避/格挡/打偏时须写预期弹道/路径与实际落点及效果。
- **门窗 Beat 专项评估（错误高发区，强制）**：凡 Beat 涉及**门/窗/门槛/门柱/窗框/门楣/百叶/推拉门/玻璃幕墙开口/窗洞/阳台门**等（含推门/拉门/窥视/门内外对峙/窗内外对话/经门洞射击/撞门/隔门喊话/门缝透光/窗外框景），**动笔写建置前须认真完成下列五维评估**，缺任一维即 Beat 不合格；本类为 Stage 1 **错误高发区**，禁止凭直觉堆坐标。
  - **① 开向与方向（必填）**：从【主环境】360 度拓扑读取并写清——**内开式/外开式**（或推拉/折叠/旋转轴向）、**门轴/铰链侧**（左/右）、**开闭状态**（紧闭/半开约几度/全开）、**门扇/窗扇占视轴比例**（占满近处画面 / 仅框缘可见 / 经门洞可见）；切衍生视角时须**按当前 Viewing Direction 重判**门扇可见面（室外侧/室内侧/铰链侧/把手侧），禁止照抄 0 度描述。
  - **② 内外侧与衍生 ENV（必填）**：判明本 Beat 观察侧在**门内/门外/窗内/窗外/经窗洞框景**哪一侧；**须切换**对应 `{N}度{主环境名}_门内|门外|窗内|窗外` 或等价衍生环境，**禁止**门内 POV 仍用主环境硬写门外景象、禁止门外 POV 硬写门内陈设。**empty_view_delta** 须列门内/外切换时**新可见/退出可见**实体。
  - **③ 遮挡·阻断·不可见（必填，与 §14 联动）**：沿视轴判**哪部分被门扇/窗扇/墙段完全遮挡**——**紧闭门扇占满近处画面** → **禁止写门后/对侧不可见实体**；**半开门** → 仅写**经门洞/门缝实际可见**区段（清晰/虚焦/剪影/仅光带）；**关闭窗扇/合拢百叶/厚窗帘** → 窗外景象不可见或仅写光形/轮廓；须显式写「被门扇/窗扇遮挡不可见」或标注待开门/开窗/切视角 Beat。
  - **④ 通行阻碍（必填）**：关闭门扇=**实体阻隔**，人物/物件/弹道/被击飞体**禁止穿模**；须写**开门/破门/经门洞/绕障/隔门喊话（声源在画外）**之一；半开时须写**可通行净空宽度**是否够人/物通过；跨 Beat 门态变化（关→半开→全开）须写**触发+承接**。
  - **⑤ 视轴与读写（必填）**：门内外对视、隔门对白、经窗对话时，须判**口型/眼神/手势在当前视角是否可读**——不可读则切衍生 ENV 或标注画外声源/待切换 Beat；POV 过门框/窗框时须写**框景边界**及近处/远处层位；门缝/窗缝透光时须写**光带方向**与对侧空间是否可读。
  - **成稿前门窗 Beat 快检（强制，内部推演）**：`开向+门轴+开闭态` → `观察侧门内/外+衍生ENV名` → `近处遮挡体→远处何者不可见` → `动作/弹道/位移是否穿模` → `口型视线是否可读`；五项全过再落笔成稿（成稿用自然语言，不写 前景/中景/背景 标签）。
  - **门窗受力与开向（强制，本专项之动作/弹道子项）**：近身打击、投射弹道、被击飞/踹门/撞门时，施力方向、命中面、反弹与终点落位须与 **① 开向与方向** 几何一致。
    - **内开门**：门扇向室内旋开。室外侧施力/射击命中关闭或半关门扇 → 常推开门扇向内或阻停嵌入，非向外弹出；室内侧撞击/被击飞撞门 → 门扇趋向关合/压向门框，不可无依据向室外甩开。
    - **外开门**：向室外旋开；逻辑与内开**镜像**（室内推/射常向外开，室外撞常趋向关合）。
    - **投射穿门/窗**：关闭时须写清命中门扇/窗扇/框体哪一面哪一区段及贯穿/碎裂/阻停/擦框；**禁止**关闭门扇仍直线命中门后目标；半开/全开时弹道须经门洞/窗洞通道，交代是否擦扇/擦框变向。
    - **被击飞/撞门**：位移与反弹须服从门轴侧与当前开向；禁止穿门而无破门/开门/经门洞过程。
- **正方向物件（手机等）手持与静置朝向（强制）**：凡 Beat 涉及手机、平板、笔记本电脑、相框/画框、证件/工牌/卡片、书本/杂志、屏幕/显示器、照片、地图、遥控器等具**正反面或显示面差异**的可移动物件，**须写清位置依附 + 正面朝向 + 当前视角可读性**；原文简略时须主动补全，禁止物件悬浮无依附或只写物件名不写朝向。
  - **位置依附（必填）**：明确物件在哪里——**握于哪只手/哪一高度区段**、**平放/斜靠于哪张桌面/哪一环境结构部位**、递交/展示中相对接收者方位、**仅当剧本明确直播/开播/固定机位直播**时方可写支架固定，非直播禁止默认加支架。

  - **显示/开合态（适用时必填）**：屏幕类写**亮屏/黑屏/来电/锁屏/具体界面可读性**；相框/证件/书本写**图文面是否朝向可读侧**；开合类（笔记本/翻盖手机）写**开角与可见面**。
  - **视角匹配（强制）**：正面朝向须与**当前 Beat Observer View** 一致——若本镜须读屏幕/证件/封面内容，正面须朝向镜头或 POV 主体；若本镜只见背板/侧缘，须写明**内容不可读**并标注后续可读 Beat/视角切换；切至 **POV/屏幕内衍生视角**时须**按新 Viewing Direction 重判**哪一面可见。**同轴 Insert/CU/ECU/MCU**（非 POV、非门窗内外）仅景别收紧，**沿用当前衍生 ENV**，禁止按插入特写另建衍生环境。
  - **跨 Beat 承接**：正方向物件位移/递交/翻转/息屏亮屏时，须写清**正面朝向变化**及与上一 Beat 终态的承接依据。

## 7. 转场与开场（§一、§一-B、§三）
- **三步执行细则**：= 新 Scene 首 Beat 的环节 1–2 入场写法 + §16；吸睛后须后拉/摇移或紧接全局建置，并写清吸睛所用观察视角；**吸睛须写环境动态+实体动势**（各≥1、双层咬合，§16）；**宏观吸睛→入戏须特写陪衬过渡**（Wide/EWS 吸睛后 ≥1 Insert/CU/Scale Contrast 再建置/入戏，见 §16）；**主环境与 0 度衍生锚定于首个非航拍全局环境 Beat，0 度=该视角背景方位，非吸睛特写、非航拍**（§11「0 度轴锚定」）；建置前须完成 §17 实体覆盖盘点；**先固化【十字轴线】**（§12），人物落位须先据戏剧关系定距离/序位/隔障（§11「关系驱动站位」），并相对十字轴线挂靠 ENV 实体。**无剧情冲突时**角色原则按主环境 0/90/180/270 四向均匀分布，**礼仪/尊卑优先**（§12「主环境四向均匀分布」）。**多人开场建置**：三人及以上具名角色同场时，优先短 Master/关系骨架 + 各侧衍生 ENV 分批建置（§12「多人建置分散方向」），勿默认全员同镜；分散所用角度须已入【衍生环境】。**出场超过三人（含群演）**：须先按剧情关系+礼法关系做人群分析，分成 3–4 组、每组≤3，各组分布到主环境四向衍生 ENV（§12「人群分析与四向分组」）。**远距离/受限 POV 开场**（§16 例外）：首 Beat 可只做 POV 范围内局部建置，**不必**强行后拉完成全场全实体建置；全局建置可推迟至后续合适 Beat（可用航拍/高位揭示），**但 0 度轴须锚定于其后首个非航拍全局环境 Beat**，并在【Scene实体覆盖】标注 `全局建置=延迟`、补全 Beat 与 **0度轴锚定 Beat**。**分组/分批出场**（§16 例外）：若两拨人群/主体本就分属不同 Beat 先后登场、不适合同一开场画面出现，**不得**为凑「全体亮相」强行把尚未到场者拼进开场同框；只建置该时刻确已同框在场者，其余按 §17 标注待入画，到其登场 Beat 再完整建置。  
- **建置归属**：空间/关系/物体说明并入可拍节拍，不得留“下游补建置”；**画外/待入画者**仅在【Scene实体覆盖】标注 Beat+触发+**具名出入口**，**非入画 Beat 不写其建置**；`全局建置=延迟` 场须标注补全 Beat+触发+**航拍/高位建置手段**，Scene 结束前闭环。  
- **实体入画承接（= 新出场角色完整建置，强制）**：凡 Scene 内**首次入画、重新入画、跨 Beat 新变为画内可见**的具名角色，该 Beat **须与 Scene 开场建置同等粒度**——**先**观察视角+当前环境，**再**以自然语言写清七要素 + **角色建置朝向四要素**（内部三轴核验，见文首「Beat 成稿叙述原则」）；须写**经【主环境】哪个具名出入口进入**（门/门洞/走廊口/巷口等，名称逐字一致；开闭态须允许通行）、触发、相对镜头径向、入境轨迹（位移动作五元组）与终态落位；落位须先据**与已在场者的戏剧关系**（§11「关系驱动站位」）定距离/序位/隔障/相对朝向，并触发 §15。**禁止**只写「出现/登场/从右边进来/走到某处」而无具名出入口；**禁止**从实墙/无开口墙面凭空出入；**禁止**新出场 Beat 直接写对白/主动作而跳过完整建置。**画外角色**：尚未入画者**不在非入画 Beat** 描述。**跨 Beat 可见性/面部可读性变化**：须写 §12 过渡动作并在 `[Beat切换说明]` 核销。
- **立体三轴建置**：执行见 Beat 完整逻辑环节 2–3、§11、§14；纵深统一用 前景/中景/背景（=**相对镜头**）；横向用左/中/右；有高度差时用上/中/下（高/中/低）；**每个实体只做一次三轴落位描述**（见 §11「立体三轴落位」）；环境内前/后/内/外须锚定 ENV 结构或具名实体（=**相对环境**）；禁止无参照系混用「前/中/后」。**人物建置须同步写清角色建置朝向四要素**（位置｜身体朝向｜视角正背面及可读性｜与他者/物件朝向关系），禁止只写坐标不写朝向。**建置时须同步考虑景深遮挡与层间距离**（§14）：中景 完全遮挡时 背景 不可见则禁止硬写；层间较远须写清 前景↔中景↔背景 空间跨度。

  5. **下场预埋**：本场末 Beat 或【视觉落点】须写明可供下一场 Step1 承接的锚点（落点画面/动作态/声源/物件状态）。

  |---|---|---|  
  | **Beat 间** | 正反打、视线 Match、无情节回忆切片 | 同 Scene；无情节切片可并入转场链，不必独立 Beat |  
  | **Scene 内插入** | 快速闪回（回忆对白 >30 字）/ 无情节回忆切片 | 不拆 Scene；快速闪回主节拍=快速闪回桥接；无情节切片主节拍仍归当下场，切片写入转场链（§三） |  
  | **Scene 间** | 时空跳跃、空间跨越、按 §9 四问判定须拆的场次 | 新 Scene 首节拍走完全链；上场末+本场首须双端桥接；**完整闪回不必然另拆 Scene**，按 §9 四问判定 |
- **首节拍技巧 = 场间转场技巧**：每场**首 Beat 正文**的 OT/转场手法，即本场**入画方式**；须同时回答——**从哪来（上场承接）→ 怎么切进来（桥接+OT）→ 第一眼看什么（吸睛：含环境动态+实体动势）→ 空间怎么建立（建置）→ 戏从哪入（入戏）**。  
- **参考片对标（强制）**：每场至少写 1 部 `borrowed_films` 中对标片 + 具体手法（如「《xxx》走廊跟拍入画，OT-TR 横移穿越」），不得只写片名或只写 OT 代号。  
- **与转场专拍 Beat 分工**：需独立展开的桥接情节（场间省略、蒙太奇、声画对位、快速闪回等）→ 上场末 Beat 或本场首 Beat 建**转场专拍 Beat**（主节拍=转场/快速闪回桥接），其前后 Beat 仍须写切换判定与承接；简单连续时空且桥接可在首节拍三步内完成 → 不必另建专拍 Beat。  
- 改写前先核对项目时代/地理/族群阶层/制度/题材；缺失写“缺失：按原文与题材常识保守处理”。  
- 结构按“建置->发展->转折->高潮->尾钩”推演；明确发展重点段与高潮重点段。**发展段优先非服装驱动**（见文首「服装相关剧情」）；确需服装情节须先交代角色服装要求。  
  
- 闪回仅可视觉化原文明示/强暗示信息，不得新增因果事件；**禁止无依据虚构 Scene/地点**（执行见强约束§8–§10）；Stage 1 **仍须**为闪回/回忆场建立或复用主环境与 Beat 实际使用的视角衍生。  
- **闪回三档判定（强制先判，服从 Scene 切分规则 §9）**：  
  - **完整闪回**：时间层切换、状态态与当下**可识别差异**、或须独立承载对白链/动作链/信息 Reveal → **按 §9 四问判定是否拆 Scene**（时空/叙事目标独立 → 可拆；仍锚定当下场 → 不拆，用转场专拍/快速闪回）；**禁止**无依据自创 Scene 或虚构回忆地点 ENV。  
  - **快速闪回（有情节）**：服务于当下场情绪/信息落点的**短促回忆对话或具名动作情节切片**（通常 1–3 Beat、单段 ≤8s 体感）；**启用门槛（强制）**：待视觉化呈现的**回忆对白原文合计须 >30 字**（含画外/OS/V.O. 闪切台词；不含仅触发回忆的当下台词如「你还记得吗」）；**≤30 字且含具体情节/对白**时**禁止**建快速闪回 Beat，改以当下场微表情/微动作、听者反应、口述转述或 `OS/V.O.` 承接。人物年龄态/妆发/服装、环境状态、道具状态与当下**无实质差异**，或差异仅通过质感处理（去色、虚化、噪点衰减、柔焦、慢速等）即可区分；回忆内容**补充印证**当前对白/反应，不独立承担新叙事目标。**不拆 Scene**，在当前 Scene 内以**转场专拍 Beat**（主节拍=快速闪回桥接）或插入节拍承载；须写清进入锚点（视线/物体/台词关键词/声音桥）与回切锚点（动作余势/声残响/构图呼应），手法优先：感官冲击闪切、定格闪帧、回忆质感衰减、闪回梦境叠化、跳切、声画对位。  
  - **无情节回忆切片（转场式）**：原文或强暗示仅有**印象/情绪/物象触发**，**无具体对白链、无完整动作情节、无独立信息 Reveal**（如「想起父亲的脸」「雨夜的车灯」「爆炸一闪」「童年走廊剪影」）；**不受 >30 字门槛约束**，**禁止**升格为完整闪回 Scene 或扩写为快速闪回 Beat。**处理方式**：按**转场手段**写入相邻 Beat 的转场链——触发（视线/物件/声/触觉）→ **≤2s 单幅或 1–2 帧印象切片**（写清可见物象/人物剪影/环境色块，**不要求**完整 前景/中景/背景 建置与对白咬合）→ 质感处理（去色/虚化/噪点/柔焦/慢速等）→ 回切当下（动作余势/微反应/声残响）；可并入上一 Beat 末、下一 Beat 初或短转场专拍，**主节拍仍归当下场**。**禁止**为无情节切片单独扩写对白链或完整动作链；切片内具名主体须列入【Scene实体覆盖】，但可仅写剪影/局部/impression 级落点。  
  - **回忆对话处理原则**：「想起/记得/当年/时说」类回忆——**无具体情节**→ 无情节回忆切片；**≤30 字有情节**→ 当下口述/反应/OS；**>30 字未达完整闪回**→ 优先快速闪回；**构成独立戏剧段落**→ **按 §9 四问判定**拆 Scene 或 Scene 内转场专拍/快速闪回；禁止无依据自创 Scene 或回忆 ENV。
- **礼法/民俗站位（强制，不限古装/豪门）**：凡涉及明确文化礼制、宗教仪轨、组织位序或民俗传统的场景（古装宫廷/庙堂、豪门家族、军队仪典、宗教场所、传统节庆礼俗、职场会议室主次座位等）均须体现相应**礼法座次与高低站位**；**明确上下级/尊卑关系人物同框时的站位、朝向与文化考据细则见 §12「关系驱动站位」「文化/文明/民俗敏感站位」「明确上下级关系群体站位」**；**有桌有凳时剧情与礼仪允许则优先各向有序坐定并写清桌向/具名椅/位序，见 §12「有桌有凳（椅）时的站坐安排」**；**无剧情冲突时原则上按主环境 0/90/180/270 四向均匀分布，但礼仪/尊卑优先于均匀，见 §12「主环境四向均匀分布」**；**三人及以上建置优先分散方向、降低多人同镜，并配套衍生环境，见 §12「多人建置分散方向」**；**出场超过三人（含群演）须先人群分析分成 3–4 组（每组≤3）并分布到四向衍生 ENV，见 §12「人群分析与四向分组」**。  
- **角色占位名→具名（强制，§19）**：改编前先扫描原文人物称呼；凡「男主/女主/主角/反派/男二/女二/Boss/CP 男/女」等**具名叙事角色**的职能或番位词，须在本阶段统一替换为具体姓名；**群演/龙套/匿名背景簇**（如「村民」「路人」「士兵群」「办公人员簇」「龙套甲/乙/丙」）**禁止**替换为具体姓名，仅以簇描述书写（见 §19 群演例外）；已有真实姓名者保留；新取名须服项目语言与时代/地理/题材/阶层/职业，全剧一致。Part 2 成稿、Scene 实体覆盖、Beat 落位、对白与全员反馈中**不得**残留占位称谓（**龙套/群演簇除外**）；Part 1 须输出完整对照表。
- `UI`/旁白/对白最终统一到剧本指定语种。
## 8. 特效与宏观（§三-B、§三-D、§21）
- **定位**：前置规划可拍特效。
- **具象化优先（强制，仙侠/武侠/玄幻/奇幻/科幻高潮）**：大特效/决战术法**优先写成可辨认的具象形体或物态**——如**化龙/化凤/化兽**、法相具身、冰龙凝结砸落、雷兽显形扑击、剑化万刃、符纸化甲、血雾化刃、纳米重组机甲等；须写清「触发源 → 凝形/化形过程 → 具名形体落点 → 作用」。**禁止**高潮特效只写「能量爆发/光芒四射/金光冲天/气浪弥漫/域场展开」而无具体化形或具名物态。光效/粒子仅作具象形体的**辅料**（鳞甲辉光、龙息焰尾、法相轮廓光），不得单独充当大特效主体。小特效（指尖法芒、兵器流光）可保留抽象光效层。
- **高成本优先(仙侠/武侠/玄幻/史诗)**：轻功/御剑/空战/域场/法相/**具象化形(化龙等)**/巨物/多主体/尺度反差(§七-C)；同拍/专拍六相链；写实/职场不适用。
- **触发**：原文暗示｜仙侠/玄幻/科幻/奇幻/恐怖/超自然/史诗｜情绪转折/Reveal｜信息可视化｜域场建置。
- **分配**：同拍=短特效+形体绑定｜专拍=六相链分帧/域场/奇观/**具象化形**；专拍前后咬合起势/落位。
- **特效可拍规格（强制，凡启用特效/术法/域场/奇观须写清）**：禁止只写「放特效/能量爆发/光芒四射/域场展开」而无范围、影响与**具象落点**。每个特效在 Beat 入戏段（及 Part 1【特效策略】摘要）须覆盖下列维度：
  - **触发源**：谁/何物/何动作触发（结印、击发、撞击、情绪外化、道具启动等）；须可核销至具名角色或道具。
  - **具象形态（Mandatory，大特效/决战术法）**：写清特效**凝成/化成什么可辨认形体或物态**（龙/凤/兽/法相/冰柱巨物/符甲/万剑体等）+ 尺度/材质线索（鳞甲/骨角/焰息/冰晶等）；禁只写「一团能量/一道金光」。
  - **作用范围（Mandatory）**：写清特效覆盖的**空间边界**——相对 ENV 具名结构的半径/扇形/纵深/层位（前景/中景/背景 哪一区段）、波前推进方向、**未覆盖区**；域场/结界须写清包络是否改写四向拓扑边界。禁止只写「大范围/全场」而无锚点边界。
  - **影响对象与效果（Mandatory）**：逐项写清受影响的具名角色/道具/ENV 固定实体——位移、失衡、伤态、材质/形态变化、结构破坏、可见光效/粒子/余波；群演簇可写统一反馈但须点明簇名与效果类型。**特效须落到环境实体上（强制）**：凡特效覆盖空间，须写清**哪些具名固定实体**进入作用范围、各实体上发生何种可见作用（灼裂/冰结/倾侧/符纹覆盖/辉光染色/震裂/余烬附着等），以及哪些实体未受影响仍保持原态；禁止只写「环境震动/能量弥漫」而无具名实体落点。禁止只写「众人受冲击」「环境震动」而无具名对象与具体效果。
  - **六相链**：`触发/起势 → 显形/蓄能 → 扩散/轨迹 → 命中/作用 → 维持/碰撞 → 余波/残留`；**具象化形**时「显形」相须写出凝形节点（鳞片覆体/骨角顶出/龙首成型等），不得跳到抽象光球；各相须可核销范围与影响是否变化。过长可拆 **起势 Beat → 特效专拍 Beat → 落位 Beat**。
  - **时限与跨 Beat**：维持/消散写明秒数（见 §29 显式时限）；瞬时光效/粒子（本 Beat 内消散、无跨 Beat 空镜承接）不建状态衍生；跨 Beat 改写结构/边界/布局 → 状态衍生（下条）。
- **状态衍生**：跨 Beat 改写结构/边界/布局，**或**跨 Beat 可持续的重大氛围/风格切换（光线/色彩/天地异象等环境级变化）→ `{主环境}_{状态}`(§11)+建置重建(§14)；瞬时光效/粒子/纯情绪形容词不建衍生；光色材质细参由 Skill 1-3 细化。状态衍生声明须一句话点明**结构/布局/边界或氛围/风格变化范围**及**受影响的具名固定实体**；该状态确立后，**后续视角/再状态衍生须以它为被依赖基准**（§11「状态基准与衍生的衍生」），具体空镜与实体表面特效设计归 Stage 3。
- **方法库**：能量术法｜**形体变身（化龙等具象优先）**｜时空维度｜环境域场｜微观宏观｜光影质感｜情绪外化｜冲击破坏｜生物诡异｜科技赛博｜轻功飞翔空域(§七-C)；**描述手法择项见附录 B 七-E**（范围/影响/六相各择 ≥1；大特效优先从**形体变身**择项）。
- **禁**：装饰堆砌/无触发光效/纯特效替动作/改因果；**禁**无作用范围、无影响对象的空泛特效描写；**禁**高潮大特效仅抽象光效而无具象化形。
- **适用**：大军/对阵/兽潮/机群/舰队/人海主节拍；同帧海量/极端密度/地平线铺满；禁稀疏小簇。**三要素、主要角色贯穿、全景+特写组合、六阶段结构与输出**：完整口径见 **§28**（§6 有宏观群体模板，联想库见附录 B 七-D）；OT 优先：OT-LS/OT-MAP/OT-AE（全景）+ Insert/Scale Contrast/Rack Focus（特写）。
- **群演**：簇/阵/列写密度队形，不逐人具名；指挥/旗舰/主要角色=体量与叙事锚。
- **区分**：背景2–3人小簇(§16) ≠ 宏观主节拍(本条)。
- **联想库选用**：启用特效时，从 **附录 B 七-E** 按方法类择 1–2 项手法名写入 Beat（大特效优先**形体变身**），并强制补齐 §8 具象形态+作用范围+影响对象；输出只写手法名称+可拍规格，禁止粘贴整库。

## 9. 剧情保真与桥段校验（§38–§41，新增，强制）
> **定位**：分集执笔（Stage 0.5）现以纯自然语言产出剧情、桥段、三阶定位、潜台词与钩子，不做任何可拍化处理。本节校验这些叙事设计在 Stage 1 扩写为 Beat 后是否**保真存续**，防止"可拍化"过程稀释、遗漏或走样原有戏剧设计。缺任一即该 Scene 不合格，须回改，不得带病输出。

38. **桥段落地校验（强制）**：若来源剧本（Stage 0 或原文）标注/可识别桥段母题或创新设计点，本阶段扩写为多 Beat 后必须**保真可核销**，不得被扩写稀释成流水账。逐场输出【桥段落地校验】：`桥段母题/创新点 → 触发 Beat 号 → 升级 Beat 号 → 回收 Beat 号`；任一环节缺失或无法对应具体 Beat 号，标「桥段缺口」并回改补全。
39. **动作库/表情库引用闭合（强制）**：若来源剧本以自然语言引用武术/法术/轻功/空战/宏观群体动作库或微表情/微动作库项（如「剑刺→回旋斩→下劈」「喜剧类微表情」），本阶段翻译为完整 Beat 级动作链（三轴+命中/效果）或表情动态过程链时，**成稿动作/表情项集合须与引用项集合逐项可核销**：不得遗漏引用项（禁止简化为「打斗一番」「表情丰富」），也不得无依据在引用范围外新增招式/表情花活。逐场输出【动作库引用闭合】：`引用项 → 落点 Beat 号 → 完整翻译|遗漏|越界新增`。
40. **三阶结构保真校验（强制）**：来源剧本已给出本场「立矛盾/推矛盾/弧光反击解决」定位；本阶段拆分为多 Beat 后，须核对该定位对应的升级/转折节点是否仍在扩写后的 Beat 序列中**清晰可辨**，未被建置/表演层细节稀释为无升级的平铺 Beat。逐场输出【三阶保真自检】：`本场定位（立/推/反击） → 承担该定位的关键 Beat 号 → 保真|已稀释（稀释时说明原因与回改建议）`。
41. **潜台词/钩子存续校验（强制）**：来源剧本设计的潜台词（不明说欲望，靠动作/表情/欲言又止承载）与钩子（场景切换抛问号、集末悬念）在本阶段补充建置、语气层、微表演细节后，须仍然**含蓄可读、未被写成直白对白**，钩子须**未被提前解答**。逐场输出【潜台词/钩子存续自检】：`潜台词/钩子内容 → 承载 Beat 号/落点 → 仍含蓄未提前解答|已泄露/已提前解答（说明与回改建议）`。

## 10. 输出模板与格式
### 第一部分：剧本改编补充说明
极简标签输出，只写结论；**用自然语言短句**覆盖各检查项，禁止粘贴键值模板；无改动项写“无：原因”。
- **【继承】**：继承|扩写|改写|细分。
- **【角色命名】（§19）**：占位名（根据角色状态变化，可能有多个，要单列一条）→具名 + voice_identity。
