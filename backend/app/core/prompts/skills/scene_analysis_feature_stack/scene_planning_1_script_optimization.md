**Beat 成稿叙述原则（强制）**
- **禁「同上」（最高）**：每拍独立可读。**同 ENV**：【建置】=上一拍【Beat切换说明】之`终态画面纵深`（或等价：上拍`速查更新`经**同一 N** 投影后的完整画面句）——**一字不落抄写纵深+正背面+姿态**（禁顺带微调；仅本拍明文移动/出入画/持握/姿态变更可在入戏改、终态写入本拍切换说明——**正背面档位本拍内禁变**；转身/转面致档位变须另起拍）。**ENV 变**（另起新拍，§4）：写【上一→触发→本 ENV】；**世界扇区/F/姿态 承接不变**（无明文走位/起跪坐时；转身改 F 亦须另起拍后在新拍建置落新档），画面句按新 N **整句重写层位与正背面**（禁粘贴上拍任一「画左/画右/前景/后景/正面/背对」短语），**身体姿态档须逐字继承**（见下）。违径向/三联/姿态继承须回改。
- **世界态优先（最高；切视角根治）**：画面相对词（画左/前景/正面…）**不是**站位真源，只是观察轴 N 下的投影。真源=每人`世界扇区 + 世界朝向F + 姿态 + 具名锚`。落笔序强制：**①写/承上拍`速查更新`世界态（含姿态档） → ②按本拍 ENV 之 N 查表得画面落位/正背面 → ③才写【建置】【入戏】**。禁先写画面句再倒推世界态；禁把上拍画面词当「人还在那儿」。
- **姿态跨拍严格继承（最高；外置+姿势）**：承接上拍时，角色除世界扇区/锚/可见性（外置）外，**身体姿态档必须严格继承**——站｜坐｜跪｜蹲｜趴｜躺｜倚靠｜骑乘 等（座/躺/倚须连同具名承托面一并继承）。**切角/反打/景别收紧≠改姿势**：`ENV变=是` 只重投影层位/左右/正背面，**不得**把上拍终态「跪」改写成「站」、把「坐」改成「立」。本拍【建置】起始姿态 ≡ 上拍`速查更新`之`姿态=`（可见带回者同）；仅当本拍【入戏】有可拍过渡链（跪下/起立/入座/起身/下马等）方可在**速查终态**改姿态，建置仍写旧姿态。❌上拍`Kneeling`→下拍建置无过渡写成`Standing`｜❌反打后随从无「起身」却改站立。✅上拍跪→本拍建置仍跪；入戏「起立」后速查=`Standing`。
- **建置防错乱五锁（最高；每拍落笔序，缺锁=失败）**：错乱根因=用画面词当记忆、把度数写进建置、速查与画面不对账、反打乱换空间名、自检空话盖章。强制：
  1. **时序锁**：【建置】=开口前**画面初始态**（含上拍终态姿态档+**初始纵深**：前景/中景/后景须带括注）；【入戏】=过程（运动/对白）；【Beat切换说明】=`初始建置 + 入戏运动` 的**变化过程摘要 + 画面终态**（含**终态纵深**；供下拍【建置】承接）。`速查更新`∈切换说明，=场内世界态终态。禁把终态 F/新姿态/转身结果/**运动后纵深**写进建置；禁建置残留 `F≈`/`0°侧`。❌`跪伏在地（F≈180…）`｜✅建置只写「前景中央正面朝镜头，双膝跪地」；F 与终态层位只进切换说明。**入戏含推门入内/入画行走时**：建置不得已是「大厅深处前景站定」的入完态——起始须在门侧/门外/刚跨过门槛，入完落点+终态纵深只进切换说明。❌用户案：建置`Foreground…standing` + 入戏`Pushes doors…walks inside`。**入戏含起立/跪下/入座时**：建置须仍为旧姿态，新姿态只进切换说明/速查。
  2. **投影锁（算术硬核；禁直觉）**：速查扇区+本拍 N → **先算**`后景=N°｜前景=(N+180)%360`再查§12 表 → 层位/左右**必须≡**建置≡台账`→画面`。❌速查`轴心`却建置「前景中央」（N=0 时前景=180°侧，轴心=中景中央）。❌**用户案（反打算反）**：N=180 时 `0°侧=前景`、`180°侧=后景`——却写`Serena|扇区=0°|→后景` + `Rupert|扇区=180°|→前景`，或建置把 0°人放后景、180°人放前景 = **投影锁失败**，**禁止**标`投影锁=扇区≡层位`/`①–⑧全过`。ENV 变后未走位者画面三项相对上拍必变。
  3. **朝向锁**：F↔正背面 + 侧面↔面向同侧画幅 + 三联句 + 对白向；**主要动作者（含金身/法相）原则上正面/¾朝镜头**（见§1）；**背对/侧背面朝镜头 → 禁止写「对镜头」**（口型对白与 OS/自白方向锚均不可）；要对镜头须**另起拍**切可读角或完成转身且新拍建置已是正面/¾（禁同拍转正后对镜头）。**背对/侧背面 → 禁止描写须正面才可见的内容**（五官/口型/泪线**与**胸膛/肚子/正面躯干等；仅可写后脑肩背等可见面，见§12）。`voice_type=画外音/OS/V.O./旁白` → OS 只挂声（声源人或在画外），禁对镜头口型开口；画内可见角色须**明文闭嘴**；背对时 OS/内心方向写`对{后景人}|内心|望天`等，**禁**「对镜头」。`voice_type=自白/独白/内心` → 发言人与画内他人均须**明文闭嘴**，禁按 lip-sync 写「开口」。❌N=180 且`F≈90`却写`right profile facing Frame Right`（F≈90=(N+270)→须**左侧面+面向画左**；右侧面+画右须`F≈270`）。
  4. **ENV 名锁**：`ENV变` 触发类型与新 ENV **主名段**闭合——同场反打=`{N}度{同一主环境名}`（❌`0度主大门`→反打却写`180度王座区`）；**默认**换主空间名=转场/新 Scene，禁标「反打」。**特例（快速闪回/蒙太奇同场多主，§7/§11）**：同 Scene 已声明的另一【主环境】族之间切换时，主名段**必须**变为目标主环境名（`ENV变=是`，触发=`闪回切主环境|蒙太奇切主环境|回切当下主环境`），**禁止**标「反打」，亦禁止用当下主环境的视角衍生冒充异地。较长回忆→应已拆为独立闪回 Scene，不在同场用多主凑合。
  5. **集合锁（开拍集≠收拍集；最高）**：
     - **开拍可见集**≡【建置】具名集合（开口前已在画——含角色/动物/载具/法相/金身等）。
     - **收拍可见集**≡`{Beat终态画内实体}`≡`终态画面纵深`具名集合。
     - **公式（强制）**：`终态=(建置−本拍明文出画)∪本拍入画/突现落定`。**禁止**无条件写「终态≡建置」——中途入画（门入/驶入/金身凝形等）→建置可不含其名、终态必须含且字段齐全；中途出画→建置含、终态剔除。
     - **≠纵深等同**：落位/朝向终态进切换说明`终态画面纵深`（可与建置层位不同）。
     - 速查覆盖画内+暂不可见（未出画）；上拍差集处置本拍重析——出画｜仍画内｜暂不可见续挂｜已转可见则**必须**带入建置；**新人/群演/动物/载具/法相/金身不得凭空入画**（上拍终态∪差集∪速查皆无其名时，本拍须经具名出入口或可核销驶入/凝形链）；禁带病标「①–⑧全过」。
- **三段时序（最高；建置≠终态）**：
  1. **【建置】=画面初始态**：开口前静止画面——每名可移动主体须写清**纵深**（前景(离镜近处)/中景/后景(远处)+画左|中央|画右）+正背面（或载具前进向）+面向+姿态；**禁止**把本拍入戏走位/转身后的落点写进建置。
  2. **【入戏】=过程**：动作/对白/位移链；禁混入建置句。
  3. **【Beat切换说明】=初始建置 ⊕ 入戏运动 → 终态**：必须可核销为「在【建置】基础上施加【入戏】运动后的结果」；须记录**变化过程**（谁自何层位→何层位/何姿态/何正背面/出画或入画）+ **终态画面纵深**（与建置同粒度的镜头相对词），供**下一 Beat【建置】**直接承接（同 ENV 抄写终态画面句；ENV 变则世界态取`速查更新`再按新 N 重投影）。无运动时：终态纵深≡建置纵深，切换说明仍须明文复述终态纵深（禁省略「无变化」而不写层位）。
  - 【建置】【入戏】=查表后的镜头相对词（禁度数推演句）；世界态度数**只**进`速查更新`与 ENV 变时的`视角换算台账`（§15）。`建置更新=是`；一拍禁切ENV。**应可见**必建。**进出场守恒**（群演/**动物/载具/法相**等可移动主体**不豁免**；切角暂不可见须差集续挂，转可见必带入，§15）。**静物道具禁凭空消失**（≠可移动主体豁免进出画）。**开场预排布**。**入戏**分行；载具独立行（§6）。**流畅**叙事散文，禁电报体。**入戏禁意图词**：禁止「试图/想要/打算/试图去…」等未落地动作表述——须写成可拍具体动作链，并服从朝向/正背面/运动终点/三联句等规则（§6「意图→具体动作」）。
  - **纵深双落（强制；按开拍/收拍切片）**：
     - **开拍已在画**者：①【建置】写初始纵深+左右 ②`终态画面纵深`写终态纵深（同粒度；有走位可≠建置层位）。

## 2. Scene 与环境
> 完整口径 §9–§11、§16；下文流程速查。
- **流程**：四问判 Scene → **核销上游同环境**（命中则锁定复用名）→【场景名称】(剧情+复用主名) → 定需求 →【主环境】(继承上游骨架；无则新立；**情节确认异地→可新建**；快速闪回/蒙太奇可同场多主，§7/§11) →【未落清单】→【衍生】(须覆盖每一主环境族) →【观察视角与空间建置】(速查表+Beat索引) →【Scene实体覆盖】→ 每 Beat 完整重写建置（内部速查+查表；成稿首句当前ENV+视角落位）。
- **四问**：时/空/线/目标连续？任一断→新 Scene。另核**内容是否适配当前主环境**——不适配则拆（§9）；闪回切分见§7（快闪/蒙太奇不新起 Scene；较长回忆须新起）。切分以本节为准，可不依赖上游场次。
- **禁令**：纯情绪词/景别/特写≠环境（**≠可删该行画面**——原文`△近景`/`【特写：…】`须入戏核销，§1）；Insert/CU禁另建衍生；停顿/表情/正反≠新 Scene。**例外**：跨拍可持续重大氛围/风格切换→须建状态衍生（§11）；情节确认不在当前环境→另立主环境（非状态衍生）；**环境/服化道剧变且停留较长→新 Scene 或另立主环境**（§7 初始态锁定+§9）。
9. **Scene切分**：四问+适配。**须拆**：时/空(越四向包络)/线/目标断；多线各地点各场再穿插（§7）；**较长回忆片段**（§7）；**原文初始环境被剧情大幅改写且后段仍长时间停留于改写后空间**（§7 服化道/环境初始态锁定——禁把改写结果回填原主环境；停留长→新 Scene，短时可持续→状态衍生）。**不适配**：①动作越出本场｜②对白异地异线｜③须换主环境→后段新场+转场四步（**例外**：快速闪回/蒙太奇异地快切→同 Scene 多主环境，§7/§11，不新起 Scene；较长回忆→须新起闪回 Scene）。禁删剧情、禁电话消解真空间切换。**可并**：四问连续且适配。**禁拆 Scene**：仅视角/特写/正反（特写仍须成 Beat 入戏，禁整行删除）；假多线。闪回§7。**场景名**：`【场景名称】{短名}｜日夜·内外｜季节｜气候｜叙事线`。**场景描述融入Beat**（禁只挂场头；首落优先切场+首拍，§7）：场头文学/氛围/`△俯拍·航拍`/`【空境/空镜：…】`建立句，以及原文`△近景·特写`/`【特写/近景：…】`景别行，均须进首拍/独立建立拍/特写切口拍入戏（§1），禁只留【主环境】或场注，禁因「景别≠环境」丢特写画面。
10. **环境定义（§11）**：空镜骨架+具名出入口；变化主体→环境、动作→Beat。**同环境复用（最高）**：上游同空间名→主名/衍生主名段**逐字复用**；日夜不同不另起名；仅无上游且硬需才新建。因剧本而生；**先定本场活动空间再落实体**；禁装饰扩写/未用冗余衍生；每场三块齐全（多主环境时每主各齐）；无人像；禁材质光色细参。**主环境=原文初始建立态**（场头/空境/开场），禁用后文剧情终态改写基准（§7）。
11. **主环境 / 未落清单 / 衍生（四向美术归 Stage 3）**
  > **不变式**：衍生对**所属**主环境固定实体不增/不减/不矛盾；仅可见性与方向性朝向可变。**主环境骨架与服化道「环境细节」锁定原文初始态**——剧情造成的破损/狼藉/域场改写/日夜突变等不得回填进【主环境】固定清单或初始摘要；须走 Beat 过程 / 状态衍生 / 新 Scene·新主环境（§7）。
  > **⑤唯一性**：默认每功能实体**在所属主环境内**1具；**门/窗默认唯一**；多件→总个数→逐具具名+区分特征。⑤-b同质≥2须分边/各向个数+朝向+同侧顺序。⑤-c配套：桌↔椅｜床↔被枕｜杯↔盏托。
  > **⑥全覆盖**：剧情实体全入**所属**主环境清单；Stage2.1再XOR裁PROP；禁两侧双出或双消失。⑦均衡：禁过挤/过空；**活动区净空**——主舞台/表演区/动线/站位承载区**禁止**布置无剧情硬核销的立体实体物件（家具障碍等）；仅贴地层或剧情必需锚（对白桌/座次椅等）可占；其余陈设落边缘/背景向。⑧出入口：具名门/洞/巷口；禁穿墙；默认单门。
  > **衍生最小化**：须切=任何反打/OTS看对手(不论≤90°)｜**切镜头致正背面档位变化**（正面/¾↔侧面↔背对/侧背面；含左↔右侧面）｜**背对/侧背面须写正面才可见内容**（五官/口型**或**胸膛/肚子等正面躯干 → 须切可读角衍生 ENV）｜越轴｜>90°｜门窗内外/POV/状态｜异排异向。禁另建=非反打Insert/CU/同侧过肩**且正背面档位不变且非须读脸/正面躯干**。反打却同父ENV=失败；**切镜头改正背面却同父ENV=失败**；**背对拍写抬眼/眉尾或胸腹正面却未切可读角 ENV=失败**。**角色自身转身/转面致档位变→强制另起 Beat**（单拍禁正+背双态；观察轴未变且背景半空间仍匹配时可同父 ENV，标`触发=转身/转面`；**但须读脸/正面躯干时仍须切可读角衍生 ENV**，§12）。
  > **本阶段只出角度清单**：名/`view_angle_from_main`/触发/`spatial_axis`/`lens_profile`/`axis_crossing`/`empty_view_delta`；**头尾双锚**必声明；四向对位归Stage3。顺时针=俯视。
  - **情节异地→新建主环境 + 闪回 Scene 分档（最高）**：
    - **默认**：一 Scene 一块【主环境】+ 其【衍生】族。
    - **新建环境（强制；据情节判定）**：凡情节确认**不在当前主环境**（时空/地点/回忆落点与当下包络不合——原文具名、场头/空境、或剧情可核销的异地意图均可）→ **须新建【主环境】**（完整骨架：名称｜日夜内外｜活动空间｜俯视360｜四向+中心（各向正对边界正面，禁斜对）｜0°轴｜头尾双锚｜固定清单）+ **对应【衍生环境】族**（含强制 `0度{该主名}`）。可据情节合理命名与建骨架；**禁止**因「原文未写全称地点」而硬挂当下主环境衍生。同环境复用优先（§10）：上游已有同空间名→复用，勿另起同义名。
    - **快速闪回 / 蒙太奇（不新起 Scene）**：短切、印象链、多地快切、嵌入当下的短暂回忆 → **留在当前 Scene**，同场声明多块【主环境】（当下 + 各快闪/蒙太奇落点），各挂各衍生族；Beat `ENV变=是`，触发=`闪回切主环境|蒙太奇切主环境|回切当下主环境`。蒙太奇每落点各一主环境，禁单主四向硬塞多地。
    - **较长回忆片段（须新起 Scene）**：可持续回忆戏——完整对白链、多 Beat 叙事推进、可独立成场的时空块、或连续回忆明显长于快闪（典型多轮对白/完整事件/等效≫快闪专拍）→ **拆为独立闪回 Scene**（场景头叙事线=`闪回`），该场自有【主环境】+衍生；回切当下另场或经转场四步咬合。禁把长回忆硬塞进当下 Scene 多主环境凑合。
    - **标注**：每块主环境写`主环境角色=当下主线|闪回|蒙太奇片段{序号}|回切锚`（**禁**在角色/场注中自拟「N年前」时长）；同场多主时【观察视角与空间建置】列主环境清单与 Beat↔主环境映射。闪回感用§7 **转场光学+运镜技巧**体现，不靠臆造时间标签。
    - **切主环境（同场快闪/蒙太奇）**：建置写【上一ENV→触发→本ENV】；世界扇区/F **按新主环境 0°轴重新锚定**（异地非反打）。
    - **禁**：①用当下主环境视角衍生冒充异地；②把异地写成当下的状态衍生；③标「反打」却换主名段；④长回忆不拆场；⑤快闪/蒙太奇误拆多余 Scene。无情节≤2s 纯质感切片且情节未要求可读空间→可不另立主环境；一旦情节确认异地可读空间→须建（同场快闪块或长回忆 Scene）。
  - **剧本活动空间（最高；主环境与衍生共同强制）**：环境描述**须因剧情活动而生**——规划【主环境】/【衍生】前须通读本场全部 Beat 需求（站位人数、对峙/围坐、追逐逃窜、跪拜、出入画、群演簇位、武戏位移等），使空间**可站、可动、可出入、可分组**；上游 ENV_BLOCK 已写活动空间要点时须继承并展开。禁只堆陈设导致无表演区，亦禁空旷无锚无法落位。多主环境时**逐主**通读其所属 Beat。
    - **活动区禁布实体物件（最高）**：【活动空间】划定的主舞台/表演区、动线、站位承载区为表演净空——**禁止**在该区内规划/落位无剧情硬核销的立体固定实体（家具/陈设/立柱/屏风/箱柜等）；固定清单其余实体须落**边缘/四向背景侧/非动线区**。例外仅限：①贴地层（地毯等不影响行动）；②本场戏硬核销的表演锚（对白桌、座次椅、跪拜承托面等）且不得再向净空加装饰件。先定活动空间再落实体时，实体落点须服从本条。
    - **主环境须明文写【活动空间】**（紧接名称/日夜后，一段短句，禁省略）：①**主舞台/表演区**（中区净空，可供对峙/对白/跪拜等，**区内无装饰性立体物件**）；②**动线**（走动/逃跑/追逐可通行，禁被固定实体堵死）；③**站位承载**（本场高峰同框人数与分区，如双人门前对峙+随从两侧跪地；有桌则座次区）；④**出入画口**（具名门/洞如何服务进出剧情）；⑤与⑦均衡咬合（活动区净空+禁无据家具障碍）。
    - **衍生环境（按内容建、禁机械轮角、禁无动机越轴）**：每个视角/状态衍生须服务其触发动作与**该角应看见的背景内容**——反打/OTS 保留对戏双方可读站位纵深；逃窜/出门向须见目标出入口与通向画外动线；门内外切换须两侧皆有落位空间。衍生行除角度元数据外，加一句`活动适配=…`（写明本角后景可见何具名实体，非四向美术描写）。**衍生主名段必须=所属主环境名**。
      - **内容驱动建角（最高）**：先列本场 Beat 实际需要看见的背景（大门侧｜王座侧｜窗墙｜对戏可读半空间等），再为每一需求建对应 `{N}度…`；**禁止**按 0→90→180→270 机械凑齐四角，或「习惯先写 180 反打」而无背景内容依据。无 Beat 使用的冗余角不建。
      - **轴线与禁越轴（最高；设计衍生时强制）**：定 0° Master 后，声明本场 `spatial_axis`（对戏/站位动作轴线，常=双方连线或主舞台长轴）。后续衍生须守轴：
        | `axis_crossing` | 何时允许 | 要求 |
        | :--- | :--- | :--- |
        | `None` | 同侧微调、非反打 Insert/CU、沿用父观察侧 | 不跨 `spatial_axis` |
        | `PlannedReverse` | **正反打/OTS 读对手**（沿轴线对向，典型 ±180°） | 触发须含两步结论 `N_对手→(N±180)%360`；左右屏关系与轴线闭合；**≠随意跳角** |
        | `MotivatedCross` | **仅**剧情明文动机越轴（揭示、追视、被迫绕行等） | 须写动机一句；禁无动机为「换个角好看」而跨轴 |
      - **禁**：无动机在轴线两侧来回跳（如对戏轴为 0↔180，却无据插入破坏左右关系的 90/270 当反打）；把越轴标成普通反打；为填满清单而建跨轴角。
    - **核销**：任一 Beat 落位/运动终点在**当前所属主环境**四向包络内找不到对应表演区或动线锚→回改该主环境或拆 Scene（§9），禁硬塞；闪回异地缺主环境块=失败。
  - **0°轴序**：①上游继承→②该主环境首个非航拍全局Beat的**背景方位**→③特写/航拍开场可主门/中轴预声明。多主环境时**各主各自锚定**，互不共用 0°轴。
  - **四向包络**=法定边界；越界→新Scene或（闪回/蒙太奇）另立主环境。**严禁对向串写**（0↔180、90↔270）。
  - **四向正面边界锚定（最高；禁斜对）**：0/90/180/270 四向**原则上各自正对四周边界立面的正面**——如正对门、正对窗、正对主家具立面/端面、正对街口/巷口/廊口等具名边界或主景面；规划 0°轴与四向落位时，优先让各向背景半空间的主锚实体以**正面/正立面**朝向该观察轴（门扇正面、窗框正面、柜体正面、街口开口面等）。**禁止**无剧情硬核销地把主锚门/窗/家具/街口等斜置、对角斜切、斜对观察轴当「好看构图」——斜对导致四向拼图与衍生截取背景主景面不可读、邻向误成主景。例外仅限：①原文明文斜向/对角几何；②无可正对的边界面（开阔旷野无立面）时改以道路中轴/地标轴线正对。头尾双锚优先选自可正对的边界主景面。
  - **主环境必写**：名称｜日夜内外｜`主环境角色=…`（单主可写`当下主线`）｜**【活动空间】**｜俯视360｜四向+中心（**各向正对边界正面，禁斜对**）｜0°轴｜头尾双锚｜固定清单(含出入口；⑤全套)；不写前中后景/人物/材质细参。**主环境=基准定义，永不作可拍当前环境**——Beat「当前环境」**永远**只能挂 `{N}度{名}` 衍生（Master=`0度{名}`；其他角=`90/180/270度…`）；**禁止**写裸主环境名作当前环境。
  - **未落清单**：`{具名}｜依据｜开场在场|待入画｜归属主环境={名}`；多主时可按主环境分节；与建置交叉核销。
  - **反打ENV**：先定本拍需要的**背景内容/对手可读面**，再算 `N_对手→(N±180)%360` 得角；`ENV变=是`+重建；新 ENV 背景半空间须对应该可读角（据【主环境】描述与`活动适配`选 `{N}度…`）。`axis_crossing=PlannedReverse`。**禁止**机械轮换下一角度数、禁粘错角、禁挂裸主环境。非反打Insert沿用父衍生ENV**且背景扇区未变**。异排/异向各备可读角。**反打不得跨主环境名**；无动机越轴≠反打。
  - **状态衍生**：`{主}_{状态}`；continue期间后续挂该状态；状态后缀挂**所属**主环境名。
16. **三步开场**：吸睛(前5s；宏观8–10s；环境动态+实体动势各≥1；宏观须特写过渡)→建置→入戏；服化道首落；静物预排布；POV可延迟。**原文有建立空镜时**（`△俯拍/航拍…` 或 `【空境/空镜：…】` 或场头环境文学）：首拍（或紧接转场后的第一拍）**必须**以该建立画面作吸睛——入戏写出原文规模/氛围信息+≥1环境动势（`△`俯拍类观察角=航拍/俯拍/EWS；`【空境】`类按描写选 Wide/EWS/环境建立角）；再过渡到本场角色入戏/首个非航拍全局建置（0°轴锚定）；禁开场直接对白而跳过该建立句。
17. **实体覆盖**：只排期(在场/待入画+出入口/离场)；静物默认开场在场；群演可延迟但入画后守恒。

## 3. Beat 建置与空间（§12–§15）
12. **站位与空间建置（强制）**：建置段细则（三段时序/主锚/三轴/世界态优先/空镜重述限定见 §1）。**落笔序（强制）**：⓪**正背面档位开拍必检**→⓪-b**当前 ENV↔背景半空间匹配（静止亦检）**（见下）→①承上拍终态（同ENV抄`终态画面纵深`；ENV变承`速查更新`世界态）→②查表→③【建置】**初始**画面句（含纵深）→④【入戏】运动过程→⑤【Beat切换说明】=初态⊕运动→变化过程+`终态画面纵深`+`速查更新`(+ENV变台账)。禁：用上拍画面词当站位（须用上拍终态）；度数入【建置】【入戏】；同上；漏应可见；静物中途出现；动作对白混建置；**把运动后纵深写进建置**；**切换说明缺终态纵深**；**无功能空镜观光句**（§1 空镜重述限定；**原文`△`/`【空境】`建立句例外，须进入戏核销**）。**三轴须同拍闭合**，冲突口径见 §1/§15。
  - **可移动主体—镜头正背面／可见面：单拍单档 + 转身／调头另起拍（最高硬约束；开拍必检；含动物／载具）**：
    - **档位闭集（角色／动物／法相／巨兽等）**：`正面/¾`｜`左侧面`｜`右侧面`｜`背对/侧背面`（`侧正面`归正面/¾族；左/右分档，互变亦算变化；法相／巨兽以主头面／龙头兽首为准）。**载具可见面闭集**：`车头(船首)朝镜头`｜`车尾(船尾)朝镜头`｜`左侧身朝镜头`｜`右侧身朝镜头`｜`¾车头/¾车尾`（§1「动物／载具／法相·巨兽朝向说明」；车头↔车尾互变=档位变）。
    - **单拍单档位（最高；废止「同拍入戏转身」例外）**：同一 Beat 内每名可移动主体【建置】【入戏】`终态画面纵深`正背面／可见面**必须同一档**——**禁止**同拍既有正面／车头又有背面／车尾描述。转身/转面/回头转正/转体/**动物转身／载具调头／法相转面／巨兽扭身**致档位变 → **强制另起 Beat**（§4）；旧拍终态仍旧档，新拍建置=新档。
    - **开拍必检（环节0；写【建置】前强制）**：对每个仍在画可移动主体（角色+动物+载具+法相+巨兽等），比对上拍终态正背面／可见面档位 vs 本拍拟写【建置】档位。任一档位变化时：
      1. **切镜头/反打/OTS/可读角**（世界 F 不变、观察轴 N 变）→ **必须** `ENV变=是`，切换对应衍生 ENV，写【上一 ENV → 触发=正背面档位变化|可读角 → 本 ENV】，按新 N 重投影（动物／载具／法相／巨兽可见面同须重投影）。
      2. **自身转身/转面/调头**（世界 F 变；上拍入戏已写转身／调头／转面过程且上拍终态仍旧档）→ **必须已另起本拍**；观察轴未变且背景半空间仍匹配时**可同父 ENV**（`ENV变=否`，写【触发=转身/转面/调头|同ENV】）；若同时须换背景半空间/反打可读角则仍 `ENV变=是`。
    - **禁止**：同拍内建置旧档+入戏/终态新档；未另起拍却写转身后正面表情/对镜头／车头已调转／法相已转面；切镜头改正背面／可见面却同父 ENV；动物／车／法相／巨兽只写落位或「现身」不写可见面+面向／车头向。
    - **咬合**：反打/OTS/异排异向/背对突切脸/**须表情读脸** ⊆ 切镜头支路（**须表情→新可读角衍生 ENV + 新 Beat**，§12）；因切 ENV 导致的档位变化须与查表一致（ENV变画面必变）。
  - **当前 ENV↔背景环境匹配（最高硬约束；开拍必检；选 ENV 铁律）**：
    - **定义**：本拍「当前环境」**永远**只能是 `{N}度…` **衍生行**（含强制 Master=`0度{主}`）= **本观察视角直接看见的背景半空间**（后景=N°侧）。机位在 `(N+180)%360` 侧看向 N°；画内背景/后景具名实体须∈【主环境】**N°扇区**（及该衍生 `活动适配`/`empty_view_delta`/触发声明的可见半空间）。
    - **永远不用主环境作可拍 ENV（最高）**：【主环境】名只作基准定义/所属主名段；Beat「当前环境」**禁止**挂裸主环境名（❌`当前环境 办公室会客区`｜✅`当前环境 0度办公室会客区` 或 `180度…`）。需要 Master/0° 轴观察侧时，**必须**写 `0度{主}`，**不是**主环境本体。
    - **按背景内容选角（最高；禁机械按序）**：选当前 ENV **唯一依据**=本拍需要出现在画面深处/后景的内容是否匹配该衍生的【主环境】N°扇区描述 + `活动适配`可见面。`0度{主}` **仅**当本镜背景确为 0°轴锚定扇区时选用。**禁止**：①无据粘 `0度`/裸主环境名；②按 0→90→180→270 或「上拍用了 X 这拍就轮下一个角」机械选角；③背景内容不对却因「度数顺手」硬挂。反打/OTS/可读角/正背面变化 → 先问「后景应看见谁/何物」，再挂对应衍生，**不是**先假定一定是 180。
    - **活动适配=背景可见面（最高；Beat↔衍生必对齐；静止亦检）**：衍生行 `活动适配`/`empty_view_delta` 写明的「可见{具名}」= **本拍画面深处/后景应出现的实体**，不是「本场有这扇门」的泛指。**凡有角色落位的 Beat——含完全静止对白/站立/跪坐、无走位、无出入画——开拍仍必须核销后景适配**；禁因「人没动/ENV变=否/同上」跳过。选当前 ENV 前先读该行活动适配，再核建置（静止拍重点核：角色背后/画面深处可见何物 vs 活动适配）：
      | Beat 画面事实 | 应挂的衍生（据活动适配） | 禁挂 |
      | :--- | :--- | :--- |
      | **静止**站/坐/跪：背对镜头、面向后景（后景应是内侧/王座等） | `活动适配`含「可见王座/内侧纵深」的角 | 「可见大门」的 `0度…`（大门不应在其背后后景） |
      | **静止**正面朝镜头：其身后/后景应见大门侧 | `活动适配`含「可见大门」的角（常=`0度…`） | 「可见王座」的对向角 |
      | 后景/背景可见 **Main Door/大门**；角色自背景门朝镜头入画（终态正面） | `活动适配`含「可见大门」的角（常=`0度…`） | 「可见王座/内侧」的对向角 |
      | 角色**背对镜头向内走**、推门入殿、面向后景深处（门在近端/身后） | `活动适配`含「可见王座/内侧纵深」的角（常=`180度…`） | 「可见大门」的 `0度…` |
      | 外景航拍/山巅城堡建立（非厅内半空间） | 外景专用主环境族之 `{N}度…`；禁拿厅内衍生冒充 | 厅内 `0度…`（活动适配=可见大门） |
    - **选 ENV 五步（每拍强制；内容优先；禁机械轮角）**：
      1. 定本拍**背景内容需求**（后景应见何门/墙/人或半空间；读谁脸/对白向/出入画等）——**先内容、后度数**；
      2. 在【主环境】四向描述中定位该内容所属 **N°**（及头尾锚）；核对相对上拍是否守 `spatial_axis`（反打=PlannedReverse；无动机禁跨轴乱跳）；
      3. 在【衍生环境】取 `view_angle_from_main=N` 且 `活动适配`「可见X」=本拍后景 X 的行（N=0→`0度{主}`；禁裸主环境名；禁因顺序顺手换行）；缺行→先按内容补衍生再落 Beat；
      4. 核销：建置/入戏背景锚∈该 N° 半空间；机位后方实体禁作本镜背景；入画径向与活动适配同拍闭合；
      5. 与正背面/反打/OTS/轴线交叉：新 ENV 背景半空间与描述一致，且未无动机越轴。
    - **入画径向×ENV 活动适配三联锁（最高；防「视角与环境视角不一致」）**：经具名门入画时，须同时满足——①门相对本镜层位；②行进径向与正背面；③当前 ENV 的 `活动适配` 可见面。三者任一互斥=整拍失败：
      - ❌典型病（用户案）：衍生 `0度…` 活动适配=可见大门 + Beat 写「前景背对镜头、推开大门向内走」——背对向内 ⇒ 后景应是内侧/王座，门应在近端 ⇒ 应挂 `180度…`（可见王座），**不得**挂可见大门的 `0度…`；若坚持挂 `0度…`（门在后景），则入画须自背景门朝镜头逼近、终态正面背对门——不得背对镜头面向深处。
      - ✅背影进厅内深处：门放前景/近端 + 当前 ENV=`活动适配`可见内侧/王座的衍生 + 建置背对镜头面向后景。
      - ✅迎面见入门者：门在后景 + 当前 ENV=`活动适配`可见大门的衍生 + 终态正面朝镜头。
    - **失败例**：❌挂裸主环境名｜❌`0度`（可见大门）+「背对镜头推门向内」｜❌外景航拍挂厅内 `0度`（可见大门）｜❌门在180°扇区却挂 `0度` 写背景门｜❌反打仍同父 ENV。✅背对入殿→`180度…`（可见王座）+门近端；✅背景门迎入→`0度…`（可见大门）+终态正面。
    - **规则一致性总核**：同一拍内不得出现——「须切 ENV」却仍挂旧 ENV；「已换 ENV」背景锚仍写旧半空间；「景别收紧沿用父 ENV」却写对向扇区实体；裸主环境名冒充可拍 ENV；**Beat 正背面/入画径向/静止站位朝向与当前衍生 `活动适配` 可见面矛盾**；**静止拍跳过后景适配核销**；**机械轮角/背景内容不匹配仍挂该 ENV**；**无动机越轴当反打**。
  - **角色环境速查（并入【观察视角与空间建置】；跨 Beat 真源）**：
    - **目标**：每人主场衍生ENV+**世界扇区**+**F**+姿态+具名锚；不符→入戏补动作再改表（禁无动作改表）。首句单一当前ENV（有变含切换链）；一拍禁切ENV；**当前ENV须通过背景半空间匹配**。
    - **落位两层（强制分立）**：
      1. **世界层（真源）**：扇区∈`0°/90°/180°/270°侧|轴心`+锚+F+**姿态**——写入每拍末`速查更新`；无明文走位/转身/**起跪坐躺**时跨 ENV **扇区+F+姿态原样继承**（姿态档与承托面逐字，不因切角改站坐跪）。
      2. **画面层（投影）**：由本拍 N 查下表得到——只写入【建置】【入戏】（层位/左右/正背面可变；**姿态词照抄世界层，不投影改档**）。ENV 名中的 N=观察轴；禁 ENV=`180度…`却按 0° 轴写左右。
    - **ENV 变画面必变（最高；无走位亦然）**：仅切观察轴、无人走动时——世界扇区/F/**姿态** **不变**，但每人画面层位/左右/正背面**几乎必变**（180° 反打→前景↔后景且正背面对调；90° 切→原前后变左右等）。若 `ENV变=是` 且未动者画面句与上拍**同侧同层同正背面** → **生成失败**（典型病：换了 ENV 名，人仍写在「前景中央正面」）。若 `ENV变=是` 却把未动者姿态档改掉（跪→站等）→ **同样失败**。
    - **视角换算速查表（强制；切角必查；禁凭直觉）**：观察轴=主环境 **N°**（ENV=`{N}度…`；**N 以 ENV 名为准**）。无走位时世界扇区不变，仅按下表重判（俯视顺时针；机位在`(N+180)%360`看向N；**画左=`(N+270)%360`，画右=`(N+90)%360`，后景=N°，前景=`(N+180)%360`**）：
      | 世界扇区（相对主环境 0° 轴） | N=0° | N=90° | N=180° | N=270° |
      | :--- | :--- | :--- | :--- | :--- |
      | **0°侧**（纵轴+ / 原后景侧） | 后景/远端 | **画面左** | **前景/近端** | **画面右** |
      | **180°侧**（纵轴− / 原前景侧） | 前景/近端 | **画面右** | **后景/远端** | **画面左** |
      | **90°侧**（横轴+） | **画面右** | 后景/远端 | **画面左** | 前景/近端 |
      | **270°侧**（横轴−） | **画面左** | 前景/近端 | **画面右** | 后景/远端 |
      | **轴心** | 中景中央 | 中景中央 | 中景中央 | 中景中央 |
      **算术闸（最高；每拍写台账/建置前默念）**：`后景扇区 ≡ N`；`前景扇区 ≡ (N+180)%360`。N=0→后景0°/前景180°；**N=180→后景180°/前景0°**（**最易写反**）。口诀：**后景永远吃 ENV 名上的度数**；反打后原前景人（常在180°侧）落到后景，原后景人（常在0°侧）落到前景——**不是**「0°永远是后景」。
      **❌用户案（Hotel Lobby 反打算反；须标失败）**：`ENV:[180度Hotel Lobby]` + 台账`Serena|扇区=0°|→后景/背对` + `Rupert|扇区=180°|建置前景正面` = **整拍失败**（正确：0°侧→**前景**；180°侧→**后景**）。同错亦见于 N=0 却写`扇区=0°|Foreground`（N=0 时 0°=后景）。
      **落笔**：①世界态→`速查更新`；②**先写算术**`N=?｜后景=?｜前景=?`再查表→画面（ENV变须填`视角换算台账`）；③【建置】【入戏】只写画面词。禁跳过查表；禁把查表句写进【建置】正文；**台账→画面与算术不符却写「查表=是/投影锁通过」=无效盖章，整拍失败**。
    - **F↔正背面（最高；内部F°/N°，成稿禁度数）**：用世界朝向F与观察轴N核销——**禁**凭主角身份另写正面。ENV=`{N}度…`→后景=N°侧，前景=`(N+180)%360`侧：
      | 世界朝向 F 相对观察轴 N（**仅内部**） | 相对镜头正背面（默认） | **成稿可用表述（禁写 F°/N°/°侧）** |
      | :--- | :--- | :--- |
      | **F ≈ N**（与镜头同向看向后景） | **背对镜头**（背面/侧背面为主） | `背对镜头` / `背面朝镜头` / `侧背面朝镜头`；口型**不可读**；**禁「对镜头」**（含OS）；**禁正面才可见内容**（脸部五官/口型**与**胸膛/肚子/正面躯干等；仅可写后脑/肩背/后腰等可见面）；可补 `面向{后景具名对象}`（禁裸「面向…深处」） |
      | **F ≈ (N+180)%360**（朝向机位/对向观察轴） | **正面或¾面朝镜头** | `正面朝向镜头可读` / `侧正面朝镜头`；可补 `面向前景` / `面向{前景具名对象|入画者}`；**禁**写侧背面/背对 |
      | **F ≈ (N+90)%360** | **右侧面朝镜头** | 鼻尖朝**画右**（见下硬锁） |
      | **F ≈ (N+270)%360**（≡N−90） | **左侧面朝镜头** | 鼻尖朝**画左**（见下硬锁） |
      **侧面↔面向硬锁（最高；角色自身左/右）**：`右侧面`=右颊对镜⇒鼻尖朝**画右**；`左侧面`=左颊对镜⇒鼻尖朝**画左**。口诀：**见哪侧颊，鼻尖朝同侧画幅**。成稿**只许**：
      | 正背面 | 面向 | 对应内部 F（相对本拍 N） |
      | :--- | :--- | :--- |
      | `左侧面朝镜头` | **必须** `面向画左`… | F≈(N+270)%360 |
      | `右侧面朝镜头` | **必须** `面向画右`… | F≈(N+90)%360 |
      ❌`右侧面+面向画左`｜`F≈0`却写侧背面（N=180 时 F≈0=正面）｜`F≈(N+180)`却写背对。❌**用户案**：N=180 + 速查`F≈90` + 建置`right profile facing Frame Right`——F≈90=(N+270)⇒须`左侧面+面向画左`；要右侧面+画右须改`F≈270`。面对面：看画左=`左侧面`；看画右=`右侧面`。
      ¾面须与朝机/背机侧一致。**侧背面仅属 F≈N 族**，禁用于 F≈(N+180)。相向默认：前景背对↔后景正面。**三联句（最高；对象=人／簇／环境锚／天穹／裂口／门／台等凡「面向」所指，不限角色名）**：层位+正背面+面向对象层闭合——
      | 正背面 | 面向对象所在层 | 判定 |
      | :--- | :--- | :--- |
      | **正面/¾朝镜头** | 对象须在**前景(离镜近处)**侧（或同层偏镜头侧），且**比面向者更近镜头** | ✅；❌ `正面朝镜头 + 面向后景的{人\|天穹\|裂口\|门\|锚}` = **成稿失败**（脸朝镜头=看向机位/前景侧，物理上背对后景，无法「面向后景」） |
      | **背对镜头** | 对象须在**后景/背景(远处)**侧，且**比面向者更远镜头** | ✅；❌ `背对镜头 + 面向前景的{人\|锚}` 且该对象更近镜头 = 失败（除非侧身回望等例外且写清） |
      | **相向对峙/俯冲默认配对** | 近镜侧（前景/偏前景）=`背对镜头 + 面向后景对手`；远镜侧（后景/偏后景）=`正面朝镜头 + 面向前景对手` | 反打 180° 后**两人层位对调、正背面对调**，配对式不变 |
      - **❌用户案（云渊仙境；整拍失败）**：`ENV:[0度云渊仙境]` + 建置`CHAR:[@沈渊]在中景中央，正面朝镜头，面向后景的裂云天穹` = **三联句互斥**。若要仰望/对向后景裂云（及随后自裂口俯冲的渊龙群）→须`背对镜头，面向后景的裂云天穹`（读脸/对白另起拍切正面可读角）；若须保留正面朝镜→面向只能是前景侧对象／镜头，**禁**写面向后景天穹。
      - **`面向{层位词}的{名|锚}` 层位词≡对象实层（最高；禁套话造假）**：凡写`面向前景的{名|锚}`／`面向后景的{名|锚}`／`面向中景的{名|锚}`，该**层位词必须与本拍【建置】中该对象的纵深层位一致**（后景天穹/裂口不得称「前景」；后景人不得称「前景的{名}」）。**禁止**为凑三联公式而篡改层位词。核销序：①读对象建置层位（环境锚取其画面层） → ②再选`面向前景/后景/中景的…` → ③再核己方正背面是否允许该层（上表）。
      - ❌**用户案（整拍失败）**：`N=0` 建置`沈渊在后景中央，背对镜头` + `渊龙群在中景半空，正面朝镜头，面向前景的沈渊`——①沈渊实在**后景**却称「前景的沈渊」=**层位词造假**；②渊龙群`正面朝镜头`却看向比自己更远的后景沈渊=**正背面×对象层互斥**；③俯冲/视线追踪正确纵深应为：**沈渊偏前景背对 + 渊龙群偏后景正面朝镜头、面向前景的沈渊**（或同扇区时龙更远、人更近），禁龙在人前、人在龙后却写龙「面向前景人」。
      - **ENV变/回挂靠后强制重核三联（最高）**：切角、反打、差集`已转可见`带回后，须按**本拍新 N**重投影层位与正背面，再重写`面向…`；**禁止**粘贴上拍或差集备注里的「正面朝镜头｜相对=某人」套话而不核二人相对远近。差集`正背面若可见`只作提示，**不得**直接粘进建置当已闭合三联。
    - **速记**：180°反打无人转身→层位与正背面对调，须`ENV变=是`。左右口诀：0°→90°原前景→**画右**、原后景→**画左**。主场ENV可≠镜头ENV，成稿仍先写当前ENV。字段：角色｜主场ENV｜扇区｜位置｜朝向｜与他者｜末次更新。【观察视角与空间建置】=速查+Beat索引。无转身禁改世界向；无动作禁改表/改正面。
    - **七要素/露出/特写**：位置｜姿态｜身体朝向｜正背面(F≈N→背对)｜与他者(面对面)｜视线｜动作方式。**适用范围=全部可移动主体**（画内角色 + 动物/宠物/坐骑 + 车辆等载具 + **法相/金身/法身/真身/化龙/化凤/巨兽/巨化体/半人半兽/拟人灵体**等）——**金身／法相／巨兽与角色字段零减免**；**主要动作者（尤金身/法相）原则上正面/¾朝镜头**（§1）。金身／法相／巨兽背对时禁写正面才可读的头面**与**胸腹正面细节（同角色背对门禁）。场内每具名角色≥1次正面/¾。特写预标`角色→可读脸Beat→ENV→转正`：已正面｜**另起拍后**建置为正面/¾｜切可读角+重建。**背对禁突切脸/突切胸腹正面**/Push In；**档位须变→先另起拍**（开拍必检，见上）。
  - **站位**：主锚优先相对ENV；他人优先相对主锚。阵列≥3标左中右/前中后。**同层多人分位（强制）**：≥2人同处前景/中景/后景时须分`画左|中央|画右`（或相对主锚左右），禁两人同写「前景中央」。速规：礼法｜尊者居中前｜有桌凳优先坐下(椅名位序；>4人两区)｜>3人分组挂四向ENV｜群演拉开可延迟(入画后守恒)。移动规划=`起点→意图核对→朝向→节点→速度→具体终点`；**成稿入戏禁写「意图/试图/想要」**，须落具体动作+朝向（§6）；**动物／载具位移同须写清可见面+前进向+具体终点**。
        - **入画径向↔正背面硬锁（最高；经门必核）**：先判出入口相对本镜层位，再锁径向与终态正背面——禁三者各写各的。无明文转身按下表：

    - **对白咬合（最高；建置↔入戏方位必须同拍闭合）**：每句`对{具名}|对镜头|望天/空位|内心|画外声源`；称呼锁定。他人目光默认朝说话人。轮次=新Beat；异排异向各切可读ENV。口型不可读先切ENV；反打必切。

          1. **先**在【衍生环境】插入（或选用已有）该主体**正面/¾可读角**衍生 ENV（按背景内容选角；典型反打/OTS/`(N±180)%360`；禁机械轮角）；

    **适用范围**：【建置】【入戏】道具行、配饰注、特写切口、服化道首落可见态。❌背对+胸前玉牌亮起｜❌写机位后方落地窗铭文｜❌桌面信正面字却信已扣合背面朝上｜✅先核①–④再写细节；须读不可见面→另拍/翻面/切角。

13. **观察视角—实体落位**：每拍必写。填：衍生ENV（Master=`0度…`；**禁裸主环境**）｜观察角(含OTS四要素)｜目标｜可见边界。写前核：∈清单｜须切则切（含**正背面档位变化**）｜**背景半空间匹配（§12；按描述选角）**｜非反打Insert沿用**且正背面档位不变且背景扇区未变**。航拍不作0°轴。
14. **景深公约（最高）**：相对镜头。前景=最近、背景=最远。朝向≠人所在层。扇区≠景深：N°=后景；N+180=机位后方不可见。**背景层具名实体须∈当前 ENV 之 N° 可见半空间**（据【主环境】描述核销）。浅景深可虚焦，在场道具不得删终态。**纵深双落（强制；开拍/收拍切片）**：开拍已在画→①【建置】初始纵深+左右 ②`终态画面纵深`终态纵深；中途入画/突现→仅强制终态（+入戏落定句）；中途出画→建置有、终态无。禁无括注裸「中景/前景」。有走位时终态层位须反映运动结果且可由入戏核销；无走位且全程在画则终态≡建置。
15. **建置重评估 + Beat切换说明自检（强制）**：每拍完整建置（`建置更新=是`；同ENV抄写上拍`终态画面纵深`/ENV变**画面重投影**见§1/§12）。**切换说明=初始建置⊕入戏运动（最高）**：【Beat切换说明】记录变化过程 + 画面终态，**不是**再建一遍与建置相同的初始句；有运动则终态纵深/姿态/正背面须反映运动结果；无运动则终态=初始并仍须写出纵深。**名单闭合（最高；开拍集≠收拍集）**：【建置】≡**开拍可见集**；`{Beat终态画内实体}`≡**收拍可见集**≡`终态画面纵深`具名；**`终态=(建置−本拍出画)∪本拍入画/突现落定`**——禁无条件「终态≡建置」。出画者自终态剔除；中途入画/金身凝形者建置可不含、终态必须含且≡角色全字段。**纵深/落位闭合**：终态层位∈`终态画面纵深`（≠强制≡建置层位）。**切角/反打/景别收紧≠清场/≠出画**。`角色分组=`禁「同上」。
  - **差集跨拍重析（最高；每拍落笔前强制；含静止/同ENV；可移动主体全覆盖）**：
    - **输入池（并集，禁漏）**：①上一拍 `{Beat终态画内实体}`；②上一拍 `差集处置` 中全部 `暂不可见` 行（未明文出画者）；③上一拍 `速查更新` 场内未出画全员——**含动物/载具/法相/坐骑，禁只扫角色**。本拍须对输入池**逐名重新分析**，不得照抄上拍「通过」完事。
    - **三态判定（每名恰好一态；先查表再定性）**：对输入池每名可移动主体用本拍 N + 其世界扇区查§12 换算表，得 `投影层位`∈`前景|中景|后景|画左|画右|中央` **或** `机位后方/画外`：
      1. **仍可见/已转可见（强制带入）**：`投影层位`∈前景/中景/后景（任一层，含后景虚焦）→ **必须**写入本拍【建置】+`{Beat终态画内实体}`+`速查更新`（可见性=画内；`ENV变=是` 时重投影）。禁因「不是对白焦点」「Medium/CU」「群演」「只是动物/车/法相」省略。曾为暂不可见、本拍查表可见 → 差集写`已转可见|带入建置=是`，**漏带=整拍失败**。
      2. **合法离场（唯一可清场路径）**：本拍【入戏】明文可拍出画（经具名出入口/退画外/驶离飞离/消形至可核销终态）→ 该名**不得**再入本拍终态/建置；速查可标`已出画`或删除；差集处置写`出画|经…`。
      3. **暂不可见（仅当查表=机位后方/画外）**：`投影层位`=机位后方/画外，且无出画——**≠出画**。方可不上建置；须（a）速查保留世界态可见性=暂不可见；（b）差集续挂全字段；（c）之后任一拍查表变可见或回挂靠视角 → 态1强制带入。
    - **回挂靠视角必恢复（最高；防随从/动物/载具蒸发）**：若上拍/历拍 `差集处置` 写明 `挂靠视角={X}`，且本拍当前环境 **=`{X}`（同角衍生，含同主名段+同 N）** → 该名**默认已转可见，必须带入建置**，禁止再标暂不可见。带回后须按本拍 N **重投影层位+正背面+`面向{层位}的{相对锚}`**，并过§12三联（层位词≡对象实层；正面⇒对象更近；背对⇒对象更远）——**禁**只恢复名单、却写`中景龙正面+面向前景的后景人`这类造假三联。❌用户案：`Entourage|暂不可见|挂靠视角=180度酒店大堂` → 本拍切到 `180度酒店大堂` 却仍写暂不可见/原因=景别收紧、终态只有 Serena+Rupert = **失败**。❌`渊龙群|挂靠视角=0度…|正背面若可见=正面朝镜头|相对=沈渊` → 切回`0度…`后建置`沈渊后景 + 渊龙群中景正面、面向前景的沈渊` = **三联失败**（应人近龙远，或改正面向层位词与正背面）。✅同拍须：建置写入（按新 N 重投影层位/正背面/面向且三联闭合）+ 终态含该名 + 差集`已转可见|带入建置=是`。同理：上拍在画的犬/马/车/法相回挂靠视角后不得蒸发。
    - **景别收紧不得否决查表可见**：仅当查表已为机位后方/画外时，方可因景别维持暂不可见。若查表得前景/中景/**后景**（含 `画面应位=后景/中央`），**禁止**用「Medium/景别收紧」继续挂暂不可见——后景仍属画内，须写入建置（可写虚焦/远处）。挂靠视角已回到当前 ENV 时，**一律禁止**再用景别收紧挡恢复。
    - **`差集处置` 格式（强制可检索；禁只写「通过」）**：
      - 出画：`{名}|出画|经={出入口/画外/驶离路径}|相对上拍=…`
      - 仍可见：`{名}|仍可见|重投影=是|否`
      - 暂不可见（**每名必填全字段**；且本拍查表须=机位后方/画外）：`{名}|暂不可见|挂靠视角={N}度{主}|世界扇区={0°侧|…}|画面应位={若可见则前景|中景|后景}/{画左|中央|画右}|相对={具名角色或锚}|姿态={…}|正背面若可见={…}|本拍投影=机位后方|原因={切角机位后方|…}`（原因禁单独写「景别收紧」而无本拍投影=机位后方）

    - **续挂与带回**：上拍暂不可见且本拍查表仍=机位后方 → 刷新暂不可见行；查表可见 **或** 当前ENV=挂靠视角 → **禁止续挂**，须态1带入。后续 Beat 以上拍 `差集处置`+`速查更新` 为真源；`ENV变=是` 时视角换算台账**必须含**输入池每一名（含暂不可见→可见的转换行；含动物/载具/法相）。

## 4. Beat 切分与时长（§25–§29、§31；角色粒度见 §1）
> 切分以本节为准；**先定 Beat 粒，再验时长**；**禁** `Shot/Lens Preference` 驱动切分。
- **强制另起**：说话人轮次变更（角色粒度）｜>20字拆句各拍（§25）｜**可拍 ENV 名变**（含任何反打、**切镜头致正背面档位变化**、>90°/越轴/POV/门窗内外/状态）｜**转身/转面/回头转正/转体致正背面档位变化**（单拍禁正+背双态；旧拍终态仍旧档，新拍建置=新档）｜**背对/侧背面须写五官微表情或口型面部微表情**（§12：须表情→**新可读角衍生 ENV + 新 Beat + `ENV变=是`**；禁同拍背对写抬眼/眉尾/挑眉等）｜听者开口应答｜Reveal/域场变｜决战·宏观阶段节点（§27/28）｜新主动施力且非快链｜转场/闪回专拍｜**原文建立空镜**（`△俯拍/航拍…`｜`【空境/空镜：…】`｜场头环境文学；可与首节拍吸睛合并为独立建立拍；禁并进对白拍而删画面信息；无人戏时仍须独立拍）｜**原文独立景别/特写行**（`△近景/特写/…：…`｜`【特写/近景/大特写：…】`——承载与邻行不同信息单元时须独立拍或紧邻特写切口拍入戏；禁整行删除；轴未变则沿用父 ENV，禁另建特写 ENV）。
- **不强制另起**（同 ENV、轴未变、**正背面档位不变**）：≤90°**非反打** Insert/CU/同侧过肩（禁另建衍生；**模型自增**的景别收紧可并入说话人正文；**原文已单列的`△近景`/`【特写：…】`不得用本条豁免删除**——见上「强制另起」与§1；**反打/转身转面/正背面档位变/须表情读脸切角不得归本条**）｜同人连续≤20字未打断｜快链攻防换手。不另起≠省建置；一拍内禁中途切 ENV；凡新拍/ENV变须完整重写建置。
- **快链可合并**（§二）：同节奏单元、连续动量、无停顿的无对白/武戏链。硬下限：决战≥10｜宏观≥6。
- **时长**：等效≈对白+动作+留白+奇观，宜 4–15s；中文≈字/4、英文≈词/2.5；追杀节点 2–4s（整链≥20s）；**禁**为凑时长改切分。
25. **对白拆句**：【对白拆句判定】=`已拆句|未拆句|无对白`；>20字必拆并落独立 Beat；**不改词、不删字、不换序**（仅允许在原句边界或自然停顿切开）；拆后各拍`{台词}`拼接=原文全句（项目语言侧）。
26. **客体禁独立拍**：受力/飞物并施力同拍；新主动作才可新拍；载具≠客体（§6）；快链优先合并。
27. **正式决战**：≥10 Beat；对峙→试探→攻防≥4轮→术法域场→逆转→决胜→收势；阶段内可快链；高成本≥3；输出【决战 Beat 规划】+【打斗快慢规划】。
28. **宏观群体**：`宏观群体=是`→≥6 Beat。判定：大军/对冲/兽潮/机群/舰队/人海等（≠2–3人簇）。三要素：无边际满幅｜阵势威武(前中后满编+真实参差，禁机械同步)｜压迫感；高潮三项齐。主角每拍可追踪；阵势/高潮各≥1全景+≥1特写（七-D）。结构：全景→阵势→压迫→指挥→对冲→余波。输出【宏观 Beat 规划】。
29. **等效时长**：下游单镜 4–15s。切分只服从完整逻辑（粒度/拆句/ENV变/§26–31/快链）；先产出再验算。硬下限：决战≥10｜宏观≥6｜追杀≥20s且节点≥3。【Duration Estimate Basis】=对白+动作+快慢分项+追杀+留白+奇观；集级 reconcile 不得违规压/扩 Beat。
30. **打斗快慢**：升格≈30%(25–35%；>40%滥用；<15%且无快连击=失败)；常速≥50%；每场≥1快连击(≥3招具名+攻防，可同拍，禁全升格)；须穿插特写；缺 30-A/B→缺口。
**§30-A 立体快链**：凡场≥1快连击须≥1 Beat 本模式；动笔前自【主环境】择≥2具名结构。七维最低：①≥2部位+≥3击具名｜②位移≥3次攻守各≥1｜③每招↔挡/闪/拆/反击｜④≥1上下段｜⑤≥2 ENV结构｜⑥融合≥2层(30-B)｜⑦常速≥50%本链升格≤1。提交≥6/7通过。
**§30-B 环境融合**（同拍）：起点≥2结构锚+材质/光区一句；每拍≥1 ENV信息；命中有陈设反馈。四层 A结构｜B材质｜C光影｜D动态。禁抠图空白互殴。
**句式骨架**：`{常速} 起点：{ENV}+双方落位+材质光区。拍n 甲【招】→乙【应】+位移/陈设反馈…；{升格}读命中。终态换区。` ❌无招名｜站桩｜中段无ENV｜全升格。输出【打斗快慢规划】标30-A+七维+A–D层。
31. **追杀/穿梭**：连续位移动量（禁结果概括）。节点≥3（相对距离可核销）；载具主语写路线+方向+特殊动作+相对态（§6）；门洞进→经→出（六维）；跨拍动量承接；可快链仍≥3节点。整链≥20s、≥2 Beat（或单拍≥12s且≥3节点）。入缠斗写撞停/下马；须特写。❌一路狂奔｜1拍抓到｜无路线。输出【追杀/穿梭链规划】。
## 5. 对白与表演
5a. **母语地道**：按项目语言×地理×时代原生写；禁翻译腔；方言用`用{语种}说道{}`。
  - **中英同义去重（最高；服从项目语言）**：权威源=`project_language` / `Language` / `Project Context.Language`（项目信息明确的语言）；未明确时跟随剧本主语言。输入剧本中**同一语义**的中英并列——括号对译、斜线双语、中英各写一遍、字幕式双语对白、叙述层双语重复等——成稿**只保留项目语言侧**，删除另一语种同义表述。❌`{Leave me alone! / 别烦我！}`（项目中文）→✅`{别烦我！}`；❌建置「大门 main gate 清晰可见」→✅只留项目语言一侧。适用范围：对白/OS、建置/入戏叙述、场景名附属说明、角色设定外形性情、环境块文学描述、服化道摘要具体词。
  - **例外（不删）**：①专有名词/人名原文（如 Serena）；②剧情有动机的异语片段（须`用{语种}说道{}`或明文外语动机，非同义翻译堆叠）；③多语言项目设定下的有动机语码切换（非同句双语复述）。禁输出中英同义双语堆叠。
5b. **场面丰满**：禁只堆动作对白；每场≥1背景锚（对白/互动/环境/`<>`声）；场景描述融入 Beat（§9）；服化道首落（§7）。
5. **细节特写 + 高潮/核心情绪点咬合（最高；每 Scene 强制）**
  > **目标**：每场先标定情绪弧，再核销「有无对应特写放大该点」；**缺则主动增拍/特写切口**——不得只写情绪词却全程中远景平推。
  - **① 每场必析（写进 Scene 头【高潮与核心情绪点】）**：通读本场全部 Beat 后，明文标定：
    1. **本场高潮**（1 个主高潮；可附 0–2 个次高潮）：落点剧情（谁/何事件）｜强度档=`压抑蓄力|加压|爆发/高潮|崩塌/余波|温情峰值|悬念落点|反转冲击`｜落点 Beat（或拟增 Beat 号）｜承载主体=`角色|环境|角色+环境`。
    2. **核心情绪点**（≥1；通常 1–3）：每点写`情绪名（压抑/恐惧/决绝/狂喜/羞耻/杀意/孤绝/压迫…）｜触发因果｜落点 Beat｜需放大方式=角色特写|环境特写|双特写`。
    3. **情绪弧摘要**（一句）：如`蓄压→对峙加压→爆发→余波`；禁空话「情绪饱满」。
  - **② 特写咬合检查（成稿前强制；缺=失败须回补）**：对①中**每一个**高潮与核心情绪点，逐项核销是否已有**可检索**的放大特写：
    | 类型 | 合格落点 | 常见用途 |
    | :--- | :--- | :--- |
    | **角色特写** | 独立拍或紧邻切口拍入戏：脸/眼/唇/手/肩颈/胸腹局部等 CU/ECU；须服从§12（**背对禁写正面五官与胸腹正面**；须转正或切可读角 ENV 后再写） | 可读脸时：压抑=眼睑/下颌绷/握拳白指；爆发=瞳孔/唇颤/泪线；决绝=视线定死；恐惧=骤张眼+后倾。背对未转正时改肩背握拳等可见面 |
    | **环境特写** | 独立拍或切口：空镜细节/象征陈设/压迫性空间构件/氛围动势 Insert（门缝光、钟摆、雨痕窗、空椅、摇晃灯罩、裂缝、远景孤灯等）；**轴未变且非反打、正背面档位不变→沿用父观察侧衍生 ENV**，禁另建特写专属 ENV | 压抑=窄门缝/高窗小光/空旷回响物；高潮=结构震动落点/旗帜猛摆/灯爆闪；孤绝=空椅/无人长廊尽头 |
    - **双特写优先**：主高潮与「爆发/崩塌/反转冲击」级情绪点，**原则上**须同时有角色特写 **与** 环境特写（可同拍内先后切口，或紧邻两拍）；仅一方有、另一方缺=须主动增补。
    - **压抑蓄力例外**：若场核为长压抑、高潮在后，蓄压段至少 **环境特写≥1 或 角色局部特写≥1**（手/呼吸/物件），不可全程无放大。
  - **③ 缺则主动增加（强制；不改因果）**：核销发现缺口时，**必须**在情绪落点 Beat 内增特写切口，或**紧邻另起**特写拍（文戏链=`触发→视角→特写→承接`）：
    - 增补只加可拍微表演/景别收紧/环境象征细节，**禁止**新增改因果事件、改对白事实、改站位世界态（无走位时扇区/F/姿态继承不变）。
    - 脸部特写服从§12：已正面｜切可读角衍生 ENV（**另起拍 + `ENV变=是`**）+重建落位｜转身另起拍且新拍建置已正面/¾（读脸致背景半空间变时仍须新 ENV）；禁同拍转正写脸；禁同 ENV Push In 硬露背对脸；**背对拍禁夹带抬眼/眉尾微挑等五官链**。
    - 环境特写须挂**本场已有**固定实体/未落清单实体/原文氛围动势；禁凭空新造改因果的奇观物件；可对已有陈设做「景别收紧+动势一句」。
    - **原文已写`△特写/近景`或`【特写：…】`时**：该行即强制核销切口（§1），计入②咬合；不得因「另凑情绪特写」而替换或省略原文特写内容。
  - **④ 底线数量**：每场细节特写合计≥1（含原文核销与主动增补）；**文戏**在满足②双特写/蓄压例外后，局部特写通常≥3（与下「强度」一致）。脸部服从§12；原文细写道具须有特写切口。
6. **微表演**：过程链；**口型对白**开口≥1面部微表情（**须该说话人正面/¾可读**；背对/侧背面→**禁止**同拍写面部微表情/抬眼/眉尾微挑；须表情时**强制**另起拍+插入/切可读角衍生 ENV（`ENV变=是`，§12），新拍建置已正面/¾ 后再写；若本拍坚持背影则只许肩背握拳等可见面外化且**不得**夹带五官链）；**OS/V.O./旁白/自白/独白/内心**改为明文闭嘴+≥1非口型外化——正面/¾可读时可用眉眼/呼吸/视线；**背对/侧背面时禁眉眼/泪线等正面五官链**，改肩绷/背影微颤/握拳等可见面；听者微反应同服从正背面可见面；禁抽象情绪词（见下表）。
7–8. **表演连贯**：承接上拍落点；操作链无跳步；原文表演层逐项核销（服从§1 原文逐字核销）。
- **格式**：音效`<…>`｜台词`{…}`｜方言前置标注。
- **语气层（每条必填）**：`voice_type`｜`voice_identity`(禁省略)｜`tone`｜`speed`｜`volume`｜`rhythm`｜`stress`｜`pause` + `{台词}`；与微表情咬合。声线选型：领导/御姐/萝莉/村妇/老者/军人/书生/反派/市井（具体化）。禁只写 tone。
- **OS/V.O./旁白/自白闭嘴（强制）**：凡 `voice_type∈{画外音,OS,V.O.,旁白,自白,独白,内心}`——建置或入戏须**逐人写明闭嘴/闭口**（可写「闭口倾听」「闭口内心状」）；禁省略、禁写「开口」、禁对镜头口型 lip-sync。分型：①OS/V.O./旁白/画外音→画内可见全员闭嘴（含群演）；声源人若在画外则不写其画内落位。②自白/独白/内心→须方向锚；**发言人本人亦闭嘴**（内心状，不张嘴对口型）+画内他人逐人闭嘴；画外声源不列入画内段落。**闭嘴≠可写对镜头**：发言人建置若为背对/侧背面，OS/自白方向锚仍禁`对镜头`（改`内心`或`对{其面向的后景人}`）。
- **思想转自白**：心知/暗想→自白或短OS；禁作者旁白；转写后仍须服从上条明文闭嘴。
- **情绪外化**：≥2项过程链。悲=低头塌肩｜怒=下颌绷+握拳｜惧=眼骤张+后倾｜紧=手敲/游移｜羞=视线躲开+唇咬｜犹豫=抬手中停｜决心=视线定｜温=轻抬手｜冷=斜睨｜喜=唇角扬｜愧=回避｜杀意=视线定死。**正背面门禁**：背对/侧背面时上表含五官项（下颌/眼/唇/斜睨/视线定/抬眼/眉尾等）**不得选用**，改塌肩/握拳/手敲/抬手中停/背影微颤等可见面项；**须用五官项时强制另起拍+新可读角衍生 ENV**（§12）。**情绪外化须落在§5②已标定的情绪点附近**，并尽量与角色/环境特写同拍或紧邻咬合。
- **强度**：夸张/细腻/标准；文戏局部特写≥3（含情绪咬合主动增补）。影视标签仅服务剧情。
## 6. 动作与武戏（§二、§27–§28、§七）
- **动作规格（七项织入流畅句）**：①部位+幅度/速度/力度(止于手级)｜②始→终位；门开向内/外；**禁指节贴触**｜③文戏低缓(武戏例外)｜④惯性过渡｜⑤操作链禁跳步｜⑥情绪外化｜⑦因果可感。❌跳结果｜无幅度「抬手」。
- **意图→具体动作（最高；【建置】【入戏】强制）**：**禁止**用「试图 / 想要 / 打算 / 企图 / 准备去 / 想干 / 想做 / trying to / wants to / attempts to」等表述代替可拍动作。镜头只能拍到身体与物件的可见过程，拍不到「想」本身——须把意图**转译为具体动作链**，并**同时闭合**朝向/正背面/运动终点/对白向等规则（§1 朝向锁、§12）。
  - **转译要求**：谁｜哪一部位｜幅度/速度｜自何始位→至何终位｜相对镜头与画幅朝向（背对/正面/侧面+面向画左/画右/对{具名}）｜具体终点或交互对象｜结果反馈（若被拦/失手则写可见受阻过程，非「试图失败」四字）。
  - **失败改写例**：❌`试图推开门` → ✅`右手掌心抵住大门门扇中部，向前用力推，门扇向内开至半开`（开向/门轴服从门窗六维；入画径向↔正背面硬锁）｜❌`想要抓住他的手腕` → ✅`右手自腰侧向前伸出，五指扣向画右近前{名}的右腕`（面向与抓取方向同侧闭合）｜❌`打算转身逃走`（且同拍写完转身+背影逃）→ ✅拆两拍：Beat N 建置正面，入戏`以左脚为轴开始转身`（终态仍正面档）｜Beat N+1 建置背对镜头，入戏`沿动线冲向背景大门，经大门出画外`（正背面变=另起拍；终点具体）｜❌`试图扑向王座` → ✅`自前景中央向前扑出，双手前伸，落点扑向后景王座台阶前`。
  - **与「犹豫/决心」微表演区分**：情绪外化可用「抬手中停」「视线定」等**可见停顿/微动作**（§5）；**不得**用「想要/试图」概括未发生的大动作。未执行的意图若剧情只需心理→走思想转自白/OS（须明文闭嘴），**不得**在入戏写空意图句冒充动作。
  - **内部规划词≠成稿**：位移规划中的「意图」节点仅作内部核对；写入【入戏】时必须已换成上列具体动作句。成稿出现意图词=整拍失败，须回改。
- **主节拍/客体**：每拍唯一主动施力方；客体禁独立拍（§26）；施力→命中→反馈同拍。
- **载具独立行**：`{载具名}：…`；人操作与车体分行；追逐=`途经→方向→特殊动作→速度→相对距离`（§31）。载具属§1**可移动主体**——须写入【建置】**可见面档位（车头/车尾/左/右侧身朝镜头）+车头前进向/停靠向**+落位，并入进出场三态与差集（禁只在入戏出现、建置无名、无朝向或跨拍蒸发）。
- **快链合并**：同节奏4–15s连续动量可合并；须拆=切ENV/读脸｜Reveal｜域场变｜决战节点｜追杀跨环境/将超15s。
- **位移五元组**：起点→发力→节点→**具体终点**→静止（规划可含意图核对；**成稿禁残留「意图/试图/想要」词**，须落为具体发力与路径句）。
- **武戏站位/视角**：Beat间须有可核销三轴落位变化；禁多拍同层位硬换招。每拍环节1–3可检索：观察侧→ENV/[切换]→层位重写→朝向四要素→命中链→终态。读招/读脸须切可读ENV；域场/空战写状态衍生+垂直层位。
- **打击/投射**：近身=`起势→发力→命中→反馈→路径→终点`；投射=`出手→路径→命中→效果`。
- **门窗六维**：①开向+门轴+开闭态+占视轴(切角重判)｜②门内/外POV切对应ENV｜③紧闭禁写门后｜④关闭=阻隔，须开门/破门/经洞等｜⑤口型不可读→切ENV｜⑥`门态→开→通行→带上→关闭终态(默认紧闭)`。禁穿关闭门扇。
- **正方向物件**：屏/证件等=依附位+正面朝向+可读性；亮屏写屏面内容；背板朝镜=不可读。
- **要点**：美感≥1/段；§30升格≈30%+快连击≥1；§31≥3节点/≥20s；决战≥10；宏观≥6。文戏=`触发→视角→特写→承接`；武戏=`视角→ENV→层位→朝向→常速快链→升格短插→终态`。
## 7. 转场与开场
- **开场**：§16三步+服化道首落；入画经具名口+完整建置。微表演：呼吸/手敲/视线/肩线｜眉眼唇｜喜剧大眉眼(禁脸红)；禁指节贴触。
- **转场总则**：Beat间/场内闪回/场间/首节拍——判定+OT+首节拍**合并写入**【场景切换与首节拍转场】。闪回/回切须带可拍光学手段（色调变化等，见下「闪回禁臆想多久前」），禁仅靠字幕报时。
- **场间四步（禁硬切）**：动机→桥接(≥1可感)→入场现态(+服化道)→情节咬合。
- **转场服化道**：切场/换主环境/首节拍首落环境细节、服饰(**换装必交**)、道具；**Part1 与 Scene 内【场景切换与首节拍转场】均须**写标准行`服化道核销摘要：环境细节=…｜服饰/换装=…｜道具细节=…`（无则对应项写「无」）+首Beat落点闭环。**换装明文（强制）**：角色改穿/入场新装/与上场不同装束体系时，「服饰/换装」须写清`{具名}+旧装要点→新装要点`（或「入场即{新装}」；例：`Serena｜员工便服→绝美裙子`），建置/入戏须可见新装落点；禁只写「换好衣服」/「服饰换装」无具名无新旧装束差异——下游 Stage 2.1 据此强制拆新角色行。❌原文礼服+吊灯→首拍直接对白｜摘要换装无具名｜Scene 内省略三项摘要只写散文。
- **服化道/环境初始态锁定（最高硬约束；严格按原文）**：
  1. **权威源**：服化道三项与【主环境】固定清单/文学氛围 = 原剧本对该空间的**初始建立描述**（场头、`△`/`【空境/空镜】`、开场首落、入场现态）——**逐字/逐信息单元**摘抄核销；禁概括改写、禁意译美化、禁下游「为好看」增补回填摘要。
  2. **禁剧情发展回填基准**：禁止把**后文剧情推进后的结果态**写入本场服化道摘要、【主环境】基准、【角色设定】初始外形——如打斗后狼藉、爆炸废墟、火烧烟熏、域场改写后陈设、湿透/血污/战损衣态、道具被毁后残片等。此类变化只进：①Beat【入戏】过程链；②跨拍可持续结构/氛围改写→`{主}_{状态}` 状态衍生（§11）；③明文换装→服饰项旧装→新装 + 衍生行。
  3. **剧变分档（视在该环境停留时长）**：情节对环境/服化道改动过大时，**禁止**用改写后的终态覆盖初始基准，须按下表拆：
     | 判定 | 处置 |
     | :--- | :--- |
     | 短时过程（单拍/短链；可读空间仍是原主环境，未形成可持续新基准） | 只写 Beat 入戏过程；必要时瞬态留 Beat，不改建【主环境】 |
     | 跨拍可持续的结构/重大氛围改写，但仍在同一主空间包络内 | 建状态衍生 `{主}_{状态}`；服化道「环境细节」仍写**改写前初始态**；状态差异进衍生/`empty_view_delta` |
     | 改写后空间已实质异质，且角色**长时间停留**（多 Beat 叙事推进/完整事件/等效≫快闪） | **新起 Scene**（或另立新【主环境】+衍生族）；新场服化道与主环境按**该段起始建立态**重新摘抄原文；经转场四步咬合 |
     | 情节确认已不在当前主环境（异地） | 按§11 新建主环境/闪回分档，不把异地描写并进原主环境 |
  4. **服饰/道具同锁**：摘要与【角色设定】初始着装/道具态 = 该场**入场或开场初态**；中途换装/损毁/拾取→过程进 Beat，结果进换装衍生或 PROP 状态衍生，**禁**把终态衣/物写回基础版唯一描述。**剧情配饰**：摘要「道具细节」与角色外形中凡佩戴/挂戴件，须写清挂载体侧（正面/背面/左侧面/右侧面）+具体部位（§12），供 Stage 2.1 继承。
  5. ❌`环境细节=废墟狼藉`却场头原文是完好王宫｜主环境清单写入后文倒塌柱｜角色设定直接写「血污战损装」却开场是整装｜✅初始=原文开场完好/整装；狼藉/战损=状态衍生或新 Scene/换装衍生 + Beat 过程。
- **逻辑链**：①上场承接｜②四项(时空/桥接/轴线/跨幅)｜③附C OT+手段各≥1｜④首节拍吸睛(环境动态+实体动势各≥1；宏观须特写过渡)→建置→入戏｜⑤下场预埋。每场≥1 `borrowed_films` 对标。
- **粒度/多线/闪回**：Beat间Match｜场内快闪｜场间(四问+多线)。并行线禁整段连排，先拆再交叉；异地异线禁硬并。闪回分档+环境（§11）：
  - **较长回忆片段（须新起 Scene）**：可持续回忆戏（完整对白链/多 Beat 推进/独立时空块）→独立闪回 Scene + 自有主环境族；场景头叙事线=`闪回`（**仅此档，禁自拟「三年前」等**）；回切当下走场间转场。
  - **快速闪回（有情节；不新起 Scene）**：嵌入当下的短暂回忆（对白>30字或具名动作、典型≤8s专拍）→**同 Scene**；情节确认异地→新建闪回【主环境】+衍生；回切=`回切当下主环境`。
  - **无情节切片（不新起 Scene）**：≤2s 印象/质感；情节未要求可读空间→可不另立主环境；确认异地可读→同场最小主环境块。
  - **蒙太奇多地点快切（不新起 Scene）**：每落点各一【主环境】+`0度{名}`及所需衍生；Beat 逐点`ENV变=是`（触发=`蒙太奇切主环境`）；禁单主硬塞多地、禁误拆为多 Scene。
  - **新建环境依据**：情节确认不在当前环境即可立新主环境（原文具名或剧情可核销异地意图）；优先§10复用上游同空间名。
  - **闪回禁臆想多久前 + 禁自加时间标注（最高）**：原文未写具体回溯时长/纪年时，**禁止**臆造或输出「三年前」「童年」「十年前」「某年某月」「FLASHBACK - 5 YEARS AGO」等字幕/场注/Beat 标题/场景名附加。场景头叙事线只用闭集`正常叙事|闪回|倒叙|梦境|想象`等（与 Stage 2.1 `plot_stage` 同）；**不得**另起时长标签。时间距离感**只用转场手段**表达——在【场景切换与首节拍转场】须同时写清 **光学≥1 + 运镜≥1**（附C；缺任一=失败）：
