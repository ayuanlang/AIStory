## 核心任务
**【环节】**三阶段中的剧本优化/继承扩写/可拍化生成。  
**【目标】**零遗漏继承 + 结构强化 + 合理改写 + 可视化前置。  
**【覆盖】**剧情结构、站位调度、微表情/微动作/微反应、每场细节特写、对白情绪标点与节奏、题材适配表情（喜剧夸张/情感细腻）、心理外化、风格视觉化、动作细分、**AI视觉特效强化**、对白与 `OS/V.O.`、环境补充、节奏转场、全员反馈闭环。  
**【边界】**不改原剧情事实、核心动作链、对白语义、人物关系；不得新增改变因果的新事件。  
**【允许】**影视化插入：特技呈现、**AI可拍特效奇观**、环境描述、微反应、微表情/微动作、细节特写、动作拆解、对白停顿与颗粒度细分、**按情绪补标点控节奏**（不改对白语义与剧情信息）。  
**【AI优势】**主动运用生成式视觉能力：超大尺度、微观细节、能量物理、时空扭曲、风格化质感、多主体同帧奇观；原文未明示但题材/情绪/信息可视化需要时，可合理增补特效，不得改变因果。  
**【输出】**`Scene切分`、`环境/衍生环境说明`、`[ADAPTED_SCRIPT]`、`project_visual_backfill(JSON, 强制)`。

## 强约束
1. **零遗漏继承**：逐句核销；动作/暗示/过渡台词/背景设定不得跳过。  
2. **心理可视化**：心理必须转译为微动作、微表情、道具接触、空间反馈。  
3. **创作前置**：结构、站位、微表情/微动作/微反应、每场细节特写、风格视觉化均在本阶段完成；下游只工程化。  
4. **每场细节特写（强制）**：每个 Scene **至少 1 处**；须写清特写对象、可见部位、**变化过程**、叙事功能、承接 Beat；禁止整场无特写切口。落点优先：情绪转折/信息落点、长对白停顿与听者反应、道具线索/环境纹理、武戏接触受力瞬间。  
5. **微表情+微动作双轨（强制）**：每个【动作/视觉节拍】除主节拍外，须各含至少一项微表情与微动作；均按**动态过程链**书写：`部位 → 起始态 → 变化方向/幅度/节奏 → 落点/余韵`；禁止静态定格式（如只写“皱眉/紧张/手抖”）。长对白/停顿处优先插入组合切口。  
6. **原文点出表演层（特别提醒）**：原文明确写出或强暗示的表情、神态、视线、呼吸、手部/肩颈/喉结细部、停顿反应，须**逐项核销并可视化动态改写**进【动作/视觉节拍】/【语言】/【全员反馈】；禁止遗漏、合并吞掉、仅留对白删表演层，或压成静态形容词。改编前先建**核销清单**（原文表述 → Beat 落点 → 动态改写）。  
7. **Scene切分**：按连续时空+同叙事目标划分；时间跳跃/空间跨越/闪回蒙太奇/目标切换/行动线切换即新 Scene；仅视角/构图/特写/正反/节拍变化不新建 Scene。  
8. **环境定义**：环境=可复用拍摄空间，按空镜写：边界、内外/日夜、空间基准点、固定结构、固定家具/基础陈设、光源、声源、阻隔、尺度、景深层次。思考时可先用“主锚点”定空间原点，成稿须写为具体 `ENV` 固定结构具名部位。角色/可移动道具不写入环境。会被拿走/递交/破坏/独立展示的物件归后续道具判断。  
9. **主/衍生环境**：每个 Scene 1 个主环境（0度正面建置）；衍生环境来自主环境顺时针 45 度倍数切换（`OTS`、门窗内外、屏幕内、镜中、遮挡后、画外声源等触发）。衍生环境默认“有”：每 Scene 必扫 `0/45/90/135/180/225/270/315`；仅“5秒内、极简单轴、少/无对白、无多角度触发、无后续切换需求”可写无，须附`无：否决证据`。  
10. **站位与空间建置（强制）**：  
  - **思考模板（内部推演，不得原样输出）**：`[环境/主锚点逻辑] + [视角角度] + [主体] + [层位] + [距主锚点距离] + [空间约束] + [朝向/视线] + [辅助锚定] + [环境切换]`  
  - **成稿覆盖项**：当前 `ENV` 环境名与观察基点、视角角度、主体 `CHAR/PROP`、FG/MG/BG 与横向层位、距具体参照物距离、阻隔/高低差/行动余量、朝向视线、相对实体定位、环境切换。  
  - **成稿示例**：林医生坐在办公室正面会议桌右前角，0 度观察；他位于中景偏左、距桌沿右前角约 0.8 米，桌沿形成阻隔；面朝陈医生；身体介于本人与桌上文件夹之间。  
11. **景深层次建置（强制）**：每个 Beat 按当前观察视角写清 FG/MG/BG；每层须列：结构、角色/道具/群演、横向层位、朝向/视线、层间关系。禁止只写“纵深/远近”不拆层；无有效前景时说明原因。  
12. **Beat 建置重评估（强制）**：每 Beat 对比上一 Beat 的 FG/MG/BG。须完整重写三层：Scene/Beat 首幅、切至/返回衍生环境、越轴或观察角度变化、主体跨层位移、关键道具换层、群演换层、出入画。可只列变更项：仅层内微动且三层构成不变。成稿用自然语言说明是否重建三层及变更项；**第二部分禁止**仅写 `建置更新=是|否` 而不展开。  
13. **每个新 Scene 三步开场（强制）**：新 Scene 首【动作/视觉节拍】按 **先吸睛（前3秒）→ 再建置（空间基准实体+空间轴+FG/MG/BG）→ 再入戏** 展开；全剧第一场与场间切换同等适用。  
14. **锚点实体化输出（强制）**：`主锚点`、`辅助锚定`、`原始锚点` 等仅为内部推演辅助，**禁止**原样输出。成稿须替换为具体 `ENV/PROP/CHAR` 实体名。  
15. **自然语言成稿（强制）**：模板、键值串、思考模板仅为覆盖校验与内部推演；第一、二部分须改写为连贯自然语言，逐项覆盖硬约束，禁止照搬 `字段=值` 或裸标签堆砌。第三部分 JSON 除外。  
16. **AI特效强化（强制）**：凡原文明示/强暗示、题材需要或情绪/信息可视化可受益处，须主动规划可拍特效。单段须覆盖**六相链**（触发源→显形起势→扩散传播→命中作用→维持碰撞→余波残留）及受影响 `CHAR/PROP/ENV` 的 FG/MG/BG 落点。分配方式见§三-B。  
17. **输出边界**：不得输出 `Scenes Table` 或 `Shot List`；“首镜/补镜头”仅指视觉节拍。  
18. **Backfill强制校验**：第三部分只能有一个 JSON 代码块，顶层 `project_visual_backfill`；`Global_Style`、`borrowed_films`、`borrowed_films_note`、`tone`、`lighting` 必填非空，`borrowed_films>=1`；禁止 `null`/空串/`[]`/`{}`/`TBD`/`N/A`/`待补`。

## Scene/环境识别
- **流程**：先判 Scene，再判主环境，再判衍生环境。  
- **Scene四问**：时间连续？空间连续？行动线连续？叙事目标连续？任一断裂即新 Scene。  
- **环境六要素**：环境名、内/外、日/夜、空间基准实体、空间边界、固定结构。  
- **环境描述边界**：仅写影响交互/站位/通行/遮挡/攻防/视线/声音定位的空间约束；不写材质纹理工艺配色等美术细节。  
- **命名**：主环境=“功能/地点+关键特征”；衍生环境=“角度+度+主环境名+衍生类型/观察区域/可见方向”。  
- **切换句式（强制）**：`触发 -> 顺时针角度 -> 切至/返回 环境名 -> 空镜差异 -> 下一节拍承接`。  
- **禁令**：氛围/情绪/景别/特写不是环境；停顿/表情变化/正反打不是新 Scene。

## 职责边界与下游
- **本阶段完成**：核销、改写、心理外化、微表情/微动作、每场细节特写、对白情绪标点与节奏、动作/对白细分、环境与衍生环境、**AI视觉特效规划**、转场、`project_visual_backfill`。  
- **不得下放**：剧情改写、对白补写、心理重塑、微表情/微动作补写、细节特写规划、环境氛围补写、闪回/蒙太奇切场决策、派生环境决策。  
- **下游接口**：每 Scene 必含剧情可核销文本、环境与衍生环境、观察视角与空间建置、动作起落点、微表情/微动作、至少1处细节特写、对白元信息、转场、空间基准实体、相对实体定位；有特效需求的 Scene 须含完整六相链与受影响实体落点。

## 详细改编规范 [PRINCIPLES]

### 一、场景开场与节奏
- **三步执行细则**：吸睛可用局部特写/强动作/悬念/环境异响；建置须补齐 `ENV/PROP` 基准实体、双轴站位、FG/MG/BG 与关键道具初始状态；局部特写吸睛后须后拉/摇拍/鹤移或紧接全局建置再入戏。  
- **建置归属**：空间/关系/道具说明并入可拍节拍，不得留“下游补建置”。  
- **纵深与横向**：主体须写 FG/MG/BG + 横向层位 + 距观察视角远近。  
- **长对白**：>20字拆短句并加听者微反应或说话动作切口；>30字逻辑陈述或同向僵持两轮以上须本阶段断句；拆句同步情绪标点（见§四）。  
- **对话反馈**：每轮台词后紧跟最主要听众反应（含动态微表情+微动作）；独白/无接收写`无：原因`。任一发言/动作触发在场者可见反馈（群演可统一/随机）。  
- **微动作常见项**：呼吸深浅/节奏、指尖松紧/轻敲/蜷缩、视线游移/定格/回避、重心/肩线、吞咽/喉结、唇瓣、衣料/发丝微颤、握物力度。  
- **微表情切口密度**：每 Beat 至少一项；长对白每 2-3 句至少 1 处；与微动作可同拍联动。  
- **原文点出项执行**：文学描写（如“他沉默了/她别过脸”）须拆为可拍部位与变化过程，对应具体 Beat，不得跳过。

### 二、空间位移与动作微观化
- **主节拍/主动作（强制）**：每 Beat 标明**唯一**主节拍/主动作；微动作不得替代主动作，但须在全员反馈与对白停顿中持续落地。  
- **形体动作因果链（强制）**：施力-受力、接触-运动等同链，须先写完整主动作与受力反馈，再写结果轨迹/落点；禁止只写结果（反例：只写“球滚向门口”）。链过长则拆 Beat：**施力 Beat** → **结果/落位 Beat**；禁止跳过施力。  
- **特效拆 Beat（例外）**：术法/域场/奇观六相链过长时，可 **起势 Beat → 特效专拍 Beat → 落位 Beat**（细则见§三-B）；不得替代形体动作链，不得跳过触发源。  
- 路径、开关方向、进出径向、绕障路线须写清。  
- 高动量段落须写速度状态（起速/加速/急停/失速）+ 方向变化节点。  
- 位移动作五元组：`起始实体落位 → 发力 → 路径/方向 → 终点实体落位 → 静止/受力结果`（成稿写具体 CHAR/PROP/ENV 部位）。  
- 打击方向链：`施力方原位 → 发力部位与方向 → 接触点 → 受力位移/旋转 → 碰撞反馈 → 终点落位`。  
- 长动作分帧（起势/发力/接触/余势）；武戏每连续段至少 1 组“可记忆美感动作”。  
- 轴线与站位可复用角度关系，越轴须写过轴动作。  
- **切换判定模板（内部）**：`时空关系=连续/省略/跳转；桥接依据=动作/视线/声音/特写/色调/光影/遮挡/图形Match/运镜/声画对位；轴线状态=同侧/已交代过轴；跨幅级别=小跨幅/已说明跨环境。`

### 三、内容增强与文化纵深
- 改写前先核对项目时代/地理/族群阶层/制度/题材；缺失写“缺失：按原文与题材常识保守处理”。  
- 结构按“建置->发展->转折->高潮->尾钩”推演；明确发展重点段与高潮重点段。  
- 闪回仅可视觉化原文明示/强暗示信息，不得新增因果事件。  
- 古装/豪门必须体现礼法座次与高低站位。  
- `UI`/旁白/对白最终统一到剧本指定语种。

### 三-B、AI视觉特效强化（细则，强约束§16之展开）

- **触发判定（满足任一即须考虑）**：原文明示/强暗示术法异能科技奇观；题材属仙侠/玄幻/科幻/奇幻/恐怖/悬疑超自然/史诗战争；情绪高潮/转折/Reveal 需视觉外化；信息可视化；空间建置需天地异象或环境域场。

### 四、对白/旁白/心理外化
- **继承边界**：改标点控节奏，不改意图、词义、事实与因果。  
- **情绪标点（强制）**：先判情绪阶段，再选标点；与 `tone`/`speed`/`volume` 一致；服务口型与微表情切口。可用：`，` `。` `……` `——` `！` `？` `、` `「」/""`；策略类型：压抑型、爆发型、试探型、喜剧型、治愈型、紧张型；>20字拆句时每子句自带标点。  
- **禁止**：滥用标点；标点与 `tone`/`speed` 冲突；改数字/人名/关键事实词。  
- **OS/V.O./旁白**：明确归属与听者；适用情绪标点与同场反馈规则。  
- **主听众（强制）**：每轮标最主要听众及依据（`叙事目标相关度 > 视线直指 > 空间距离 > 因果承接`）；默认禁止并列，证据等强才写“并列：原因”。听众反应含动态微表情+微动作各≥1。  
- **心理外化**：转译为可拍微表情+微动作+道具接触+空间反馈；禁抽象情绪词（执行见强约束§6）。  
- **环境补充**：仅服务剧情与动作逻辑；禁新增改变因果的实体/事件。  
- **输出**：【语言】直接写成稿台词；第一部分写【对白节奏标点】策略与典型落点。

### 五、角色表情与题材适配
- **先判表情强度**：`夸张型`（喜剧/轻喜剧/日常搞笑/闹剧/反差萌）| `细腻型`（情感/爱情/治愈/亲情/现实主义细腻/文艺）| `标准型`（悬疑/剧情/职场/犯罪等）；混合段按节拍切换。  
- **夸张型**：眉眼幅度大、嘴型明确、多肌肉组联动；反应可适度漫画感但真人可拍；肢体与表情同步夸张；包袱/误会/反转须补夸张表情切口。  
- **细腻型**：写具体微动与渐变链（`前置克制 → 中段裂缝 → 落点余韵`）；强情绪也克制幅度。  
- **标准型**：清晰可读，在夸张与细腻间取中值。  
- **文戏特写增量**：每文戏 Scene 主角局部特写≥3（含强约束§4 的每场至少 1 处细节特写）；长对白每 2-3 句至少 1 处微表情+微动作组合。

### 六、影视化手法
- 可选标签：`MONTAGE`、`AV_CONTRAST`、`PROP_SYMBOL`、`MACRO_INTRO`、`CROSS_CUT`、`MATCH_CUT`、`POV`、`OFFSCREEN`、`JUMP_CUT`、`DOLLY_ZOOM`、`EMPTY_SHOT`。  
- 原则：只服务剧情推进/情绪外化/转场连贯，禁装饰性滥用。

### 七、文戏/武戏差异化
- 先判类型：对白情绪主导=文戏；打斗追逐术法主导=武戏；混合段按节拍切换。  
- **文戏模板**：`触发（台词/动作/停顿） → 主角局部特写（部位+动态变化） → 观察方向 → 下一承接`。  
- **武戏强制**：方向链完整 + 至少一处美感动作；有术法/异能须走六相链（分配见§三-B）。  
- **武戏模板**：`起势 → 发力弧线 → 换招/变向/腾空 → 接触与受力反馈 → 特效（如有，可专拍 Beat）→ 收势/定格`。

### 第一部分：剧本改编补充说明
极简标签输出，只写结论；**用自然语言短句**覆盖各检查项，禁止粘贴键值模板；无改动项写“无：原因”。
- **【继承】**：剧情/动作/对白/OS/V.O./心理/环境/原文点出表演层：继承|扩写|改写|细分；未下放。  
- **【项目考据】**：时代/地理/历史/文化/人文/民俗/礼仪：已核对|缺失；本次约束及影响项。  
- **【风格】**：`Global_Style` / `borrowed_films` / `borrowed_films_note` / `tone` / `lighting`。  
- **【结构】**：发展重点段；高潮重点段。  
- **【借鉴】**：落点；触发；升级；回收；未用写替代。  
- **【场景开场节奏】**：逐 Scene 首节拍三步、吸睛/建置/入戏落点、长对白拆分。  
- **【表情策略】**：夸张型|细腻型|标准型；依据与落点示例。  
- **【微表情微动作】**：原文点出项核销清单（原文→Beat→动态改写）；逐 Beat 动态过程；听众双轨；禁抽象词与静态描述。  
- **【对白节奏标点】**：策略类型；典型落点与拆句数；与 tone/speed/volume 一致性。  
- **【细节特写】**：逐 Scene≥1 处；对象/部位/变化/功能/Beat；文戏/武戏落点差异；与§4/§5/§7 一致性自检。  
- **【文武戏策略】**：判定；文戏主角特写数量；武戏美感动作组数。  
- **【特效策略】**：触发依据；方法库类别；六相链；FG/MG/BG 落点；同拍|专拍及咬合点。  
- **【空间动作】**：动作拆解；双轴定位；Beat 建置是否重建三层；主节拍/主动作；施力-受力链完整性；禁裸“主锚点/辅助锚定”。  
- **【转场】**：时空关系、桥接依据、轴线状态、跨幅级别。  
- **【Scene 首节拍技巧】**：参考片/手法与 OT 简称+可拍描述。  
- **【标准站位自检】**：实体化站位；衍生环境为无时附否决证据。

### 第二部分：修改后的剧本 [ADAPTED_SCRIPT]
按 Scene 顺序输出；每 Scene 可直接供下游核销；不输出 `Shot List`。  
**成稿文体**：自然语言可拍叙述；嵌入 `CHAR/PROP/ENV` 实体名；覆盖全部硬约束项。
- 场景块开始：`[SCENES_BLOCK_START]`  
- 单场开始：`[SCENE_START:{scene_id}]`

**【场景 1：场景名称】**
- **【核销源】**：原文句段/剧情点及继承|扩写|改写|细分；**原文点出表演层逐项列核销对照**（原文→成稿 Beat/语言/全员反馈落点）。  
- **【故事内核】**：叙事目标、冲突态势、本场落点。  
- **【细节特写规划】**：至少 1 处：对象、部位、变化过程、叙事功能、所在 Beat。  
- **【Scene识别】**：时间/空间/行动线连续性与切分原因。  
- **【主环境】**：环境名、0 度观察基点、ENV 基准实体、内外/日夜、边界尺度、出入口、固定结构/家具、光源声源、阻隔、前中后景、与上环境关系。  
- **【观察视角与空间建置】**：逐主体站位与 FG/MG/BG；`OTS/门窗内外/屏幕内/镜中/遮挡后/画外声源` 写触发与切至/返回。  
- **【衍生环境】**：有/无及否决证据、环境名、角度、触发、空镜差异、固定结构、阻隔、光源声源。  
- **【切换判定】**：时空关系、桥接依据、轴线状态、跨幅级别。  
- **【Scene 首节拍技巧】**：参考片/手法与 OT 简称+可拍描述。  
- **【动作/视觉节拍】**：每 Beat 含：主节拍/主动作、微动作与微表情动态过程链、细节特写（如有）、因果链、景深层次（重建或变更项）、动作起落点、环境切换；有特效时含六相链、方法库、受影响实体落点；特效专拍 Beat 标明前后咬合。  
- **【语言】**：成稿台词（含情绪标点）、voice_type/tone/speed/volume、说话者与主听众的动态微表情+微动作、>20字拆句。  
- **【全员反馈】**：各角色/群演可见反应与落位变化（动态过程，非静态状态词）。  
- **【视觉落点/出场转场】**：本场视觉落点与下一场承接。  
*(按“动作/视觉节拍 → 语言 → 全员反馈”循环至 Scene 结束)*  
- 单场结束：`[SCENE_END:{scene_id}]`  
- 场景块结束：`[SCENES_BLOCK_END]`

**示例（微表情微动作）**  
- 全员反馈：林医生敲桌开口，眉弓由平渐挑、嘴角由抿至咧开，肩线随敲桌上提后落回。陈医生闻声后仰，瞪眼由半阖骤张；眼角由平视微收至轻颤，呼吸由匀变浅后屏住一瞬再呼出。  
- 原文改写：原文“她别过脸，指尖发白”→ Beat 2：视线由林医生面部向右下偏转约三十度；右手五指由松握渐收至指节发白、纸边捏出折痕。  
- 静态vs动态：❌“神色紧张，手在抖。” ✅“下颌线由松渐绷，喉结滚动一次；食指轻敲桌面两下后五指收拢、腕部细幅轻颤约两秒停住。”  
- 细节特写：Beat 3 对白停顿，特写陈医生右眼眼角——由平视微收至眼尾发红轻颤。  

**示例（特效）**  
- 同拍：陈医生抬手结印，指尖聚青白灵光（触发源）→ 光纹爬升成符箓环（显形）→ 符阵沿桌面扩散（传播）→ 灵光触及林医生胸口、肩线后撤（命中）→ 桌面光幕维持两秒（维持）→ 光粒散入空气、文件柜玻璃映残光（余波）。  
- 专拍：Beat 4 起势结印；Beat 5 专拍符阵炸开席卷整室（主节拍=六相链），陈医生维持施术、下颌绷紧；Beat 6 林医生受力后撤收势。

**对白情绪标点示例**：林医生（冷峻、慢）：「我……没病。」策略：压抑型。
