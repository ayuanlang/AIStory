## 核心任务
**【环节】**三阶段中的剧本优化/继承扩写/可拍化生成。  
**【目标】**零遗漏继承 + 结构强化 + 合理改写 + 可视化前置 + **补全微表情与微动作**（让剧本与主动作更有表现力，让对白—反应—动作链更具连贯性）+ **剧情叙事连贯**（用对白、反应、OS/V.O.、道具与转场情节桥梁完整表达因果与信息，禁断层与脑补）。  
**【覆盖】**剧情结构、**叙事因果与信息承接**、站位调度、**微表情/微动作/微反应补全与动态过程链**、**对白—反应—动作连贯衔接**、每场细节特写、**对白语气层（身份/声线人设+节奏+重音+停顿+情绪标点）**、题材适配表情（喜剧夸张/情感细腻）、心理外化、风格视觉化、动作细分、**AI视觉特效强化**、**武打/特效/正式决战/宏观群体场面规划**、对白与 `OS/V.O.`、**主环境建立与全部视角变动衍生识别**、节奏转场、全员反馈闭环、**Beat 完整逻辑驱动的 Beat 切分（角色粒度：对白/对话按发言角色逐 Beat 切分，强制）**与**等效时长记录/校验（§29，不考虑镜头偏好/长镜头因素）**。  
**【边界】**不改原剧情事实、核心动作链、对白语义、人物关系；不得新增改变因果的新事件。**本阶段须建立环境（强制）**：每 Scene **必须**输出【主环境】+【衍生环境】（Stage 1 为空间骨架与可拍衍生的唯一定义入口，不得推迟至 Stage 2-1）；**环境规划须因剧本而生、为剧本而用**（§10）。**主环境=基准定义**（固定实体清单+360拓扑+俯视360；仰视360可选；Beat 不可引用）；可拍视角须另声明 `{N}度{主环境名}` 衍生（生图回挂主环境，Stage 3 执行）。**禁止**写材质/光源/声场/色彩/氛围（归 Skill 1-3）。**禁止** `ENV/PROP/CHAR` 标签与前缀；仅以自然语言具名书写；资产归属与衍生裁定归 **Stage 2-1**。  
**【允许】**影视化插入：特技呈现、**AI可拍特效奇观**、环境描述、微反应、微表情/微动作、细节特写、动作拆解、对白停顿与颗粒度细分、**按情绪补标点控节奏**（不改对白语义与剧情信息）。  
**【AI优势】**轻功/御剑/空战换招｜宏观无边际阵列(大军/对阵/兽潮/机群/舰队)｜超大尺度/微观/能量/多主体同帧；仙侠/武侠/玄幻/史诗优先高成本奇观(垂直空域/域场/法相/地平线满编/压迫推进)；可增补特效，不改因果。  
**【输出】**`Scene切分`、**【主环境】+【衍生环境】（强制；含全部视角变动衍生识别清单，Beat 所用 ENV 须 100% 闭合于衍生清单）**、`[ADAPTED_SCRIPT]`、`project_visual_backfill(JSON, 强制)`。

## Beat 完整逻辑（强制，逐 Beat 不可跳过）

**每个 Beat 均须按下列逻辑完整执行**；**前置 + 六环节**彼此咬合、缺任一即 Beat 不合格。细则分别见强约束 §5/§6/§11/§12/§13/§25/§29 与 §二/§四。

**Beat 成稿叙述原则（强制，与六环节配套）**
- **自然语言成稿**：Beat 正文须以**连贯自然语言**写清本 Beat 内各时刻、各角色的**动作、朝向、对白、表情/微表演、位移、观察视角与环境切换**等（覆盖前置 + 六环节全部信息点）；**禁止**以「前景：…／中景：…／背景：…」分段标签作为默认成稿结构。
- **角色粒度（强制，成稿组织法；对白/对话按发言角色逐 Beat 切分）**：每个 Beat 以 **`- Beat {n}`** 起头；**凡含对白/对话的 Beat，须按发言角色切分**——**同一 Beat 只承载单一说话人的本轮发言**（该角色本轮起势/落位/朝向承接 + inline 对白 + 情绪层 + 微表演）与**同期主听众的反应**（微表情+微动作，inline 写入听者自身段落，§四）；**听者一旦开口接话/应答/打断/抢话，即视为发言人切换，必须另起新 Beat**；**禁止**以「同一时刻」为由将两个及以上角色的对白/对话轮次糅合进同一 Beat。同一说话人**连续未被他人打断**的发言，单轮 ≤20 字且节奏无需断句时可留在同一 Beat；>20 字按 §25 拆句，拆句后各子句**仍各落独立 Beat**（不因同属一说话人而合并）。**无对白的动作/建置/群像段落**（Scene 首 Beat 开场三层建置、纯形体动作链、武戏无对白攻防、转场/特效专拍、群演簇统一反应等）**不受角色粒度限制**，仍按**叙事时间与因果**推进、同一 Beat 内可容纳多主体同拍演化；**禁止**将建置、对白、听众反馈拆成【动作/视觉节拍】/【语言】/【全员反馈】三块分列输出。典型**对白/对话 Beat** 序：**说话人起势/落位/朝向承接** → **inline 对白+情绪层+微表演** → **主听众同期反应（微表情+微动作）**（听者接续开口 → 另起新 Beat，不得延续本 Beat）；典型**非对白/建置 Beat** 时间序不变：**起幅/观察视角—环境建置** → **主动作落点** → **触发者反应** → **位移/环境切换/终态落位**（武戏/特效/转场专拍按实际链序，可含多个时间小段）。
- **角色段落写法**：以**具名角色/群演簇**为叙述锚点（如「林医生…」「陈医生…」「办公人员簇…」）；对白 inline 标注 **语气层全字段**（§四「语气层 inline 标注」）：`voice_type`/`voice_identity`/`tone`/`speed`/`volume`/`rhythm`/`stress`/`pause`（及情绪标点）；画外/OS·V.O. 声源写清画外标注，**不在画内角色段落写其落位**；自白/独白 Beat（单一发言人）须在**同一 Beat**写清画内其他角色/簇的闭嘴反应（§四，闭嘴反应不属于「发言」，不触发角色粒度换 Beat）。
- **前景/中景/背景 仅在必要时显式写出**：当且仅当剧情/镜头需要下列情况时，方可在正文中点明层位或纵深关系——**OTS/正反打/POV 切换**、**遮挡阻断/框景**（门扇占满视轴等）、**跨层位移/出入画**、**深景/层间距离影响可读性**、**武戏观察侧切换导致背景可见半空间变化**等；一般静态对白/动作 Beat 用相对 ENV 结构或具名实体的自然语言落位即可，**无须**逐层框架复述。
- **内部仍须完成三轴/七要素/朝向四要素核验**：层位信息可**内化**于自然语言（如「林医生在会议桌左就座、与陈医生隔桌相向、四分之三右侧面朝向镜头可读口型」）；成稿前核验仍按 §11 口径执行，但**成稿不强制**前景→中景→背景 分段叙述。
- **全文优先级声明（强制，防止误仿）**：本文档 §一–§29、§一/§二/§三/§四 等细则中出现的 `前景`/`中景`/`背景`/`FG`/`MG`/`BG` 字样，**均为内部空间核验与规则命名的概念标签**（用于校验三轴、遮挡、层间距离等逻辑是否自洽），**不代表** Beat 正文应以此类词汇literal 写入成稿；凡本文档其余位置出现的「✅ 正确」「示例」句子中若仍带有 `前景/中景/背景` 字面词，**均以本节「角色粒度」与文末「Beat 正文：角色粒度，自然语言层位」示例为最终成稿标准**，直接替换为「近处/后方/身后/远处/画面左缘」等自然语言表达或 ENV/实体相对位置；如两处示例写法冲突，**以本节与文末示例为准**。
- **情节一致（强制）**：Beat 描述须**严格服务本 Beat 剧情逻辑**——动作、对白、站位变化、环境切换均须有 Beat 内因果或环节 0 承接依据；**禁止**脱离本 Beat 情节、本 Scene 故事内核或原文事实**随意发挥**（无关表演、无关位移、无关环境切换、装饰性细节）。
- **环境变化建置触发（强制，Beat 2+ 核心规则）**：动笔每个 Beat 前，**先对比上一 Beat 与本 Beat 的当前可拍 ENV 名**（含全部衍生前缀，如 `0度{主环境名}` / `{N}度{主环境名}_反打` / 状态·特效衍生等，**非**主环境基准名）：
  - **ENV 有变化 → 必须重新建置说明（强制）**：凡当前可拍 ENV 名与上一 Beat **不完全一致**，或观察侧/空镜基准/状态·域场导致 ENV 切换（含偏转 >90° 的真反打/越轴、POV/门窗内外/状态·特效衍生/跨主环境等；**不含** ≤90° 运镜过肩/特写/焦点变化）→ **须**在 Beat 正文写完整**观察视角—当前环境（含衍生环境名）—建置**三联：观察视角 + **当前环境名** + 当前视角下画内各实体落位与朝向（§11 七要素+朝向四要素）；`[Beat切换说明]` 标 `建置更新=是` + 切换触发。**禁止**只写「切至反打」而不写新 ENV 下的空间建置。
  - **ENV 完全不变 → 可省略建置说明（允许）**：本 Beat 与上一 Beat **当前可拍 ENV 名逐字一致**，且观察轴/空镜基准未变（含 Insert/CU/ECU/MCU 景别收紧仍沿用父衍生 ENV）→ **可省略**重复的环境—观察视角—三层建置段落；**仍须**完成环节 0 留场/出入画复核，正文**直接承接**上一 Beat 终态写动作/对白/位移/微表演等**变化项**；`[Beat切换说明]` 标 `建置更新=否` + 依据=ENV未变。**禁止** ENV 未变却每 Beat 复述全场建置；**禁止** ENV 已变却省略建置硬写对白/动作。

## 强约束
1. **零遗漏继承**：逐句核销；动作/暗示/过渡台词/背景设定不得跳过。  
2. **剧情叙事连贯（强制）**：每场/每 Beat 须可回答「谁—欲何—阻何—已知—将变」；跨 Beat/Scene 动机、筹码、关系、前情与后果须通过对白承接、听者反应、OS/V.O.、道具状态、转场**情节桥梁**显性传递，禁只写表演/空镜而无剧情信息落点。  
   - **对白承载剧情**：台词须推进立场/筹码/关系/前因/后果；>20 字拆句时插入听者反应或说话者动作切口，使信息递进可读；禁装饰性流水账与旁白硬灌。  
   - **省略/跳转补偿**：时空省略或跳转时，须写 `情节桥梁` 与（若需）`信息补偿`；新信息须有铺垫或当场交代来源；关键转折禁只靠动作不写台词。  
   - **场间接续**：Scene 首 Beat 须回扣上场退出状态（对白/反应/OS 均可）；Scene 末 Beat 须写清本场剧情推进与角色立场/关系变化落点。  
3. **心理可视化**：心理必须转译为微动作、微表情、道具接触、空间反馈。  
4. **创作**：结构、站位、微表情/微动作/微反应、每场细节特写、风格视觉化、**主动作归属主动施力方（被动物件轨迹与纯粹受力位移写入同 Beat，禁止客体/纯粹受力独立成 Beat）**均在本阶段完成；**每个 Beat 须完整执行「Beat 完整逻辑」前置 + 六环节**；Beat 2 起须先完成环节 0「参考前一 Beat **画内**站位」，即使原剧本已有场景分镜等的划分，也要遵守以下规则进行创作。  
5. **每场细节特写（强制）**：每个 Scene **至少 1 处**；须写清特写对象、可见部位、**变化过程**、叙事功能、承接 Beat；禁止整场无特写切口。落点优先：情绪转折/信息落点、长对白停顿与听者反应、**剧本原文对道具的特别描述**（材质/工艺/磨损/颜色/形态/铭文/显示内容/状态变化/线索强调等，须标注对象=该道具、可见部位=原文强调细节）、道具线索/环境纹理、武戏接触受力瞬间。  
   - **道具特别描述→特写（强制）**：原文/Adapted Script 对某道具写出超越泛称的**特别描述**时，须在对应 Beat 或【细节特写规划】中标注 `{细节特写}` / `细节特写`，写明特写对象、可见部位（逐字对应原文强调点）、变化过程与叙事功能；**禁止**原文已细写道具细节却在 Beat 中仅全景/中景一带而过、无特写切口。  
6. **微表情+微动作双轨（强制）**：= Beat 完整逻辑环节 5；下列为动态过程链写法与密度补充。每个 Beat 除主节拍外须各含至少一项微表情与微动作；**每个主动作、每句对白、每个听者/触发者反应均须配套**。均按**动态过程链**书写：`部位 → 起始态 → 变化方向/幅度/节奏 → 落点/余韵`；涉及视线/头颈/肩线/肢体位移者，**变化方向须写清立体三轴（横向左中右 + 纵深 前景/中景/背景 + 必要时垂直上中下/高中低）**；禁止静态定格式。长对白/停顿处优先插入组合切口；**原文未写但情绪/信息/动作链需要处须主动补全**，不得留表演真空。  
7. **表演连贯性（强制）**：= Beat 完整逻辑环节 6；**空间站位承接**见环节 0。下列为表演层补充：相邻 Beat、台词轮次与主动作须**承接上一表演落点/余韵**；对白后必有听者/触发者动态反应，反应后再入下一台词或主动作，禁止对白—反应—动作链断层。跨 Beat 持续情绪须写渐变或保持态；状态跳变须有触发交代。主动作起势须呼应前一 Beat 身体姿态与视线；武戏形体链与微表情/微动作同链咬合，禁止 Beat 间表演层断裂或情绪复位无依据。  
8. **原文点出表演层（特别提醒）**：原文明确写出或强暗示的表情、神态、视线、呼吸、手部/肩颈/喉结细部、停顿反应，须**逐项核销并可视化动态改写**进 Beat 正文**对应时刻/角色段落**；禁止遗漏、合并吞掉、仅留对白删表演层，或压成静态形容词。改编前先建**核销清单**（原文表述 → Beat 落点 → 动态改写）。  
9. **Scene切分**：按连续时空+同叙事目标划分；**以原文/上游 Scene 切分为首要依据**，不得为闪回/蒙太奇/补足视觉而自创 Scene（见§三「闪回三档判定」）。时间跳跃/空间跨越/闪回蒙太奇/目标切换/行动线切换**且原文或上游已切分或具独立场次结构**时方可新 Scene；**完整闪回/回忆段落不必然拆独立 Scene**——原文嵌于单场、无独立时空切换、或叙事目标仍锚定当下场时，优先 Scene 内**转场专拍 Beat**/**快速闪回**承载。**快速闪回**（短促回忆对话/有情节画面切片，叙事目标仍锚定当下场；**仅当待呈现回忆对白合计 >30 字**，见§三）不新建 Scene；**无情节回忆切片**（仅印象/情绪/物象触发、无具体对白链与动作情节，见§三）不新建 Scene，**并入相邻 Beat 转场链**或短转场专拍，**不受 >30 字门槛约束**；仅视角/构图/特写/正反/节拍变化不新建 Scene。  
10. **环境定义（概要，完整口径见 §11）**：环境=可复用空间的**纯空镜骨架**：边界、内外/日夜、固定实体清单、剧情相关尺度/形状/开合/相对方位、阻隔、通行路径。**剧本服务原则（强制）**：所有环境设置须**因剧本而生、为剧本而用**——动笔【主环境】/【衍生环境】前须先读本场剧情（对白落点、站位关系、道具交互、视角切换、转场因果、Beat 实际 ENV 需求），环境规划**只服务**可拍化与剧情表达；禁止脱离剧本的装饰性扩写、无剧情依据虚构空间、或未在 Beat 中使用的冗余衍生角度；**服从衍生环境最小化**（§11）——运镜可解决的 ≤90° 变化不另建衍生行。**日/夜未写明默认白天（强制）**：须在【主环境】与场景头补明「日·内/外」。**每 Scene 须输出【主环境】+【衍生环境】**（含 `0度{主环境名}` Master 及 Beat 实际使用的全部衍生）；Beat 已切视角但【衍生环境】缺行 → 禁止。**环境无人像（强制）**：禁人物/人称/站位/交互；仅写空椅/空桌等固定陈设相对关系。**禁止无依据虚构地点**（见§三）。**只写空间骨架**；禁材质/光源/声场/色彩/氛围及生图参数（归 Stage 2-1 文学氛围 + Skill 1-3）。**0 度轴**锚定本 Scene **第一个全局环境视角**（Wide/Full/EWS/Establishing/Master/Two Shot/LS 等眼高/地面级全局建置；**排除** Insert/CU/ECU/MCU/特写吸睛**与**航拍/高位俯瞰，§11、§16）；**0 度方向 = 该视角的背景方位**。**四向空间边界**：0/90/180/270 四向拓扑所描述范围为剧情与环境描述的法定边界，不得向外扩张（§11）。**360拓扑、头尾双锚、主/衍生分层、可数同类、跨阶段契约等完整口径见 §11**。
11. **主/衍生环境（强制分层；剧本优化只规划主环境实体清单与衍生角度清单，衍生环境四向对位与美术设计归 Stage 3）**：
  > **主环境不变式（最高硬约束，供 Stage 3 设计衍生环境时逐条自检；本阶段负责保证【主环境】清单本身完整达标）**：**① 不增**：衍生视角**不得**出现主环境固定实体清单之外的任何新实体；**② 不减**：主环境每个具名固定实体在衍生视角下须全部可核销（可见或具名标注不可见），**不得**省略或合并；**③ 不矛盾**：实体**物理属性**（开闭态、门轴侧、桌头/桌尾/主客位、材质/结构/尺度定语、连接关系、世界空间朝向）衍生阶段**不得改变**；**④ 唯一允许变化**的是「可见/不可见」与「方向性物体相对新机位的朝向/正反面/左右序位」。**四向对位设计与完整校验归 Stage 3（entity_design_environment_and_poster.md §3.1.5）**；本阶段须做的是把【主环境】固定实体清单写到位（含⑤可数同类），为 Stage 3 提供充分依据，避免因主环境清单不全导致 Stage 3 无法对位。
  > **⑤ 可数同类实体（强制，主环境声明层）**：凡空间内**可能出现多个**的固定实体（椅/凳/沙发/杯/碟/瓶/窗/门/柜/灯/展板/转椅等），须在【主环境】固定实体清单**先写总个数**，再**逐具**具名描述（含座次/位置/区分特征）。**剧情须区分者**（指定座次、特定落点、后续 Beat 会指向的实例、交互/对白关联对象）须赋予**一眼可辨的区分特征**（颜色/材质/形制/尺寸/状态/位置/标签/破损/主客位等），写入主环境，供 Stage 3 在全部衍生中逐字一致透传、据此生图识别。❌「中景 有椅子和杯子」｜✅「中景 **两把**空转椅：主位深棕皮革转椅（桌左，椅背朝桌心）、客位浅木靠背椅（桌右，椅背朝桌心）；中景 桌面**三只**白瓷杯：主位侧带金边马克杯、客位侧素白小杯、桌角备用空杯」
  > **⑥ 剧情实体完整覆盖（强制，主环境声明层，不可遗漏）**：本 Scene 剧本原文中提及、暗示或必然存在于该空间的**全部**实体——不论道具级、装饰级、背景级、家具陈设级或仅一次性露出——**均须**逐一纳入【主环境】固定实体清单，禁止因"次要/装饰性/不够重要/不会再出现"而省略、合并概括或跳过。**该实体日后是否被 Stage 2-1 单独抽取为道具（PROP）与本阶段是否收录无关**——本阶段只负责**不遗漏**地把剧情提到的实体写入主环境固定陈设，是否升格为独立 `PROP` 由 Stage 2-1 按 `ENV/PROP` 互斥规则另行裁定；未被抽取为道具的实体**仍须保留**在主环境固定陈设描述中，不得因未达道具门槛而在环境与道具两侧同时消失。❌ 原文写「桌上放着一份文件和一支钢笔」，主环境固定实体清单只字未提｜✅ 主环境固定实体清单写入「桌面**一份**文件（合拢，封面朝上）、**一支**钢笔（搁于文件旁，笔尖朝右）」，后续 Stage 2-1 判定是否升格为独立道具。

  > **锚点—镜头传递自洽（强制，凡同一实体的朝向表述同时出现"锚定具名他者/固定物"与"相对镜头可见面"两项时必须执行）**：写出「{实体}正面/背面朝向 {锚点}（相对镜头为 {正面|背面|侧面}）」前，须先核对本 Beat 已建立的**镜头—锚点—该实体三者相对位置关系**，"相对镜头可见面"**必须**由"该实体朝向锚点的方位"与"锚点相对镜头的位置"共同推导，**禁止**两项独立声明、互不校验。**推导口径**：锚点与镜头处于**同侧**（即锚点夹在该实体与镜头之间，或锚点与镜头大致共享同一条观察轴延长线）时，该实体朝向锚点的面**同时朝向镜头一侧**——镜头可见面与"朝向锚点的面"**相同**；锚点与镜头处于**异侧**（该实体夹在锚点与镜头之间，或二者位于观察轴相反延长线）时，镜头可见面与"朝向锚点的面"**相反**。结论不一致时须回改朝向声明或补写镜头位置关系，**禁止**两句并列却互相矛盾。❌「CHAR完全背对镜头（镜头在CHAR身后，即CHAR夹在PROP与镜头之间、二者同侧）+ PROP正面朝向CHAR（相对镜头为背面）」（错误：锚点CHAR与镜头同侧，PROP朝CHAR即同时朝镜头一侧，应推导为相对镜头**正面**，与括注矛盾）｜✅「CHAR完全背对镜头，PROP正面朝向CHAR（相对镜头亦为正面，因CHAR与镜头同侧、PROP朝CHAR即朝镜头方向）」。

  - **视角变化 → 建置重评估（强制）**：**判定口径统一为「ENV 名是否变化」**（见文首「环境变化建置触发」）：当前可拍 ENV 名相对上一 Beat **有变** → **必须**写完整重新建置说明（观察视角 + 当前环境含衍生名 + 各实体落位/朝向），`建置更新=是`，并通过 §12 可执行性校验；**ENV 名完全不变** → **可省略**重复建置，`建置更新=否`。典型 **ENV 有变** 触发：偏转 >90° 的真反打/越轴、POV 切换、镜中/屏幕内/门窗内外、状态·特效衍生、**面部可读性翻转导致 ENV 切换**等。**角度阈值**：偏转 **>90°** 且导致 ENV 名变化 → 强制完整建置；偏转 **≤90°** 且 ENV 名不变 → 建置可省略。**运镜/Insert/CU 例外**：仅景别收紧、过肩构图、焦点人物变化而观察轴与 ENV 名不变 → 沿用当前衍生 ENV，建置可省略，**禁止**为特写/过肩另建衍生环境。

15. **Beat 建置重评估（强制）**：= 环节 1→2 的重建触发器；与 §12、文首「环境变化建置触发」配套。**核心判据（强制）**：对比上一 Beat 与本 Beat 的**当前可拍 ENV 名**（含全部衍生/状态前缀）——  
  - **ENV 有变化 → 必须重新建置说明（强制）**：ENV 名不完全一致，或切至/返回/切换衍生环境、状态·特效衍生、跨主环境、观察侧切换导致 ENV 名变化 → **须**在 Beat 正文写完整**观察视角—当前环境（含衍生环境名）—建置**（当前视角下画内各实体落位+朝向四要素+七要素）；`建置更新=是`；并通过 **§12 环境切换建置可执行性校验**。另须完整建置的情形（即使 ENV 名判定已覆盖）：Scene/Beat 首幅、主体跨层位移/换层、出入画、**新主体首次入画/重新入画**（§11 完整建置，禁止只写「出现」）、**具名角色画内可见性或面部可读性变化**（须含 §11 过渡动作）。  
  - **ENV 完全不变 → 可省略建置说明（允许）**：ENV 名逐字一致且观察轴/空镜基准未变 → **可省略**重复的环境—观察视角—建置段落；正文只写环节 0 留场复核后的**变化项**（动作/对白/位移/微表演）；`建置更新=否`。**仍须**完成实体出入画核销，禁止画内实体无依据消失。

16. **每个新 Scene 三步开场（强制）**：新 Scene **首 Beat 正文**按 **先吸睛（前3秒）→ 再建置（观察视角+当前环境+空间基准实体+空间轴+先 前景/中景/背景 三层框架、再每层内逐个写清人物与物体落位）→ 再入戏** 展开；全剧第一场与场间切换同等适用；**场间切换须先完成 §一-B 转场逻辑链 Step1–3，再执行三步**。**0 度轴与主环境锚定（强制）**：主环境与 `0度{主环境名}` 衍生的观察轴锚定于本场**第一个全局环境视角**（Wide/Full/Master/Two Shot/LS 等眼高/地面级全局建置）；**排除** Insert/CU/ECU/MCU/特写吸睛**与**航拍/高位俯瞰；**0 度方向 = 该视角的背景方位**；**非**吸睛特写 Beat、**非**航拍 Beat；首 Beat 若为特写或航拍，须在【场景切换与首节拍转场】标明「0度轴锚定 Beat = {首个非航拍全局环境 Beat 号}」及「0 度背景侧 = {具名实体/墙段}」，建置步的观察轴以该 Beat 为准。**远距离/受限 POV 开场例外**：首 Beat 若以**远距离 POV、瞄准镜/望远镜/监控变焦/航拍远距/单向受限传感视角**等开场，且当前视角**无法可读地看见**本场多数主体的全身、相互关系或完整空间（如远程瞄准只见靶区剪影、镜内十字线压点、远距监控只见局部），则**不要求**首 Beat 完成全场**全局全实体建置**；首 Beat **仅建置当前 POV 可见范围内**的观察视角+环境（或 POV 衍生环境）+ 前景/中景/背景 内**确属该视角可见/可读**的主体；其余已入场主体标注「待全局建置 Beat + 触发条件」，在后续合适 Beat 补全全场三层落位。**补全全局建置可采用航拍/高位俯瞰类手段**（Drone / Crane / 建置航拍景观 / Bird's-Eye / Top Shot / 地图缩放式揭示等，OT-LS/OT-MAP/OT-AE 等）自远及近或高位俯看一次性交代空间关系与全员落位——**但航拍/高位 Beat 不得作为 0 度轴锚定依据**；须在其后（或同期收束至）**首个非航拍全局环境 Beat**（如 Pullback Two Shot/Master 地面级建置）锁定 0 度轴与主环境，Pullback/观察侧后拉/目标近距入画/镜筒·屏幕移开等可作为切入/收束。**须在【Scene实体覆盖】与首 Beat 成稿写明** `全局建置=延迟`、计划补全 Beat、**0度轴锚定 Beat**（须为非航拍全局环境 Beat）及补全手段；Scene 结束前须完成全部已入场者落位闭环。**分组/分批出场例外（强制，不限于 POV 场景）**：若剧情本身将本 Scene 内的人物/群演簇设计为**并非同一时刻同框**——如两拨人群分属不同 Beat 依次登场/互动、彼此错峰到场、或各自锚定不同区域与叙事节点，明显不适合在开场时刻硬凑一框——**首 Beat 建置不得为凑齐「全体亮相」而强行把剧情上本不与当前主体同框、或尚未到场的人群拼合进同一开场画面**；首 Beat **只需**完整建置**该时刻确已同框在场、且叙事需要**的人物/群演簇；剧情安排在后续 Beat 才登场、才同框的人群，按 §17 标注「待入画 Beat + 触发 + 出入画方向」，待其实际登场 Beat 再按 §11「新出场角色完整建置」同等粒度补建，**不得**提前建置。**禁止**倒果为因——因「Scene 须一次性全局建置」而无依据把后续 Beat 才出场的人群提前塞入开场同框，或让本应先后到场、分属不同 Beat 的两拨人群在开场画面强行凑在一起。

22. **资产分类禁令（强制）**：全文禁止 `ENV/PROP/CHAR` 分类术语、`ENV:`/`PROP:`/`CHAR:` 前缀及资产表式枚举；仅以自然语言具名书写，并为 Stage 2-1 保留归类证据（固定陈设 vs 可移动交互、跨 Beat 状态变化、拿起/递交/破坏等）。  
23. **输出边界**：不得输出 `Scenes Table` 或 `Shot List`；“首镜/补镜头”仅指视觉节拍。  
24. **Backfill强制校验**：第三部分只能有一个 JSON 代码块，顶层 `project_visual_backfill`；`Global_Style`、`borrowed_films`、`borrowed_films_note`、`tone`、`lighting`、`color_spectrum`、`plot_summary`、`music_recommendation` 必填非空，`borrowed_films>=1`；`plot_summary` 须为 **80–120 字中文**百字剧情总结（概括核心剧情、人物关系与情感走向，禁止剧透终局细节）；`music_recommendation` 须写明配乐风格、情绪基调、参考曲目/作曲家/影视配乐及主要使用场景（开场/高潮/情感转折等）；**`lighting` 仅写文学级光影气质/方向（如 low-key noir、温润窗光），禁止 Key:Fill、色温 K 值、大光比、四层色谱等 Stage 3 技术参数**；**`color_spectrum` 须基于 `borrowed_films` 推导全片主冷暖色谱方向（四选一：`冷调主导`｜`暖调主导`｜`冷暖对比`｜`同温层次`），句首或句中显式写出所选方向，并点名 ≥1 部参考片及其典型色谱做法（如《银翼杀手2049》冷蓝雨夜+暖 Practical 对照），可写 1–2 组文学级主辅色倾向（如煤灰蓝/旧木褐/琥珀台灯光），禁止 Key:Fill、色温数值、四层色谱技术细则**；禁止 `null`/空串/`[]`/`{}`/`TBD`/`N/A`/`待补`。  
25. **每场对白拆句判定（强制）**：每个 Scene **必须**单独输出【对白拆句判定】，明确本场是否进行了拆句处理；禁止省略、默认不写或仅在 Part 1 汇总而不逐场声明。  
  - **判定值**：`已拆句` | `未拆句` | `无对白`（三选一，不得留空）。  
  - **已拆句**：逐条列出被拆原句/原段（说话人+原文或核销源对应句）→ 拆句后各子句（含情绪标点 + **各子句 rhythm/stress/pause 微调**）→ 落点 Beat → 配套说话动作切口或听者微反应。>20 字单句或同一角色连续说话 >20 字**必须**拆句并标 `已拆句`。  
  - **未拆句**：须写**未拆原因**（如：全场最长台词≤20 字且节奏无需断句；纯 OS/V.O. 画外无口型；武戏无画内对白；单句短促爆发且≤20 字等）。禁止对 >20 字应拆句台词标 `未拆句`。  
  - **无对白**：本场无任何对白/OS/V.O./旁白/独白，写 `无对白：原因`（如纯动作场、纯环境转场、纯特效专拍等）。  
  - **与成稿一致**：【对白拆句判定】须与 Beat 正文 inline 对白、拆句结果一一可核销；拆句不改词义与剧情信息，仅断句+标点+节奏。
26. **纯粹受力/客体运动禁止独立 Beat（强制）**：**纯粹受力的动作不得单独建 Beat**，必须与**主动作（发力方）**合成同一 Beat 的因果链延续；被动物件飞行/滚动/落点、受力方纯粹被动位移（被推动、被击倒、被抛出而无格挡/闪避/承接等主动意图）均须写入**施力方 Beat**内连贯描述，**禁止**升格为下一 Beat 的「主节拍」。**唯一例外**：受力方产生**新的主动作**（接球、格挡、闪避、拦截、反击、主动后撤收势等）时，方可新开 Beat，且**主节拍归该新的主动施力方**，不得把「球飞了」「人被推倒」本身当作 Beat 主节拍。**同节奏快链内**攻防换手（如格挡→闪避→反击）**优先合并同 Beat**（§二「快速系列动作同 Beat 合并」），不必因施力方切换机械拆 Beat。写法见§二「主动作主体示例」。  
27. **正式决战（§27，仙侠/武侠/武打/玄幻）**：`正式决战=是` → Scene **≥10 Beat**，**Scene 级**禁概括合并（对峙/试探/攻防轮/术法域场/逆转受伤/决胜/收势各阶段须分 Beat 覆盖）。**判定**：生死决斗/终极一战/核心飞剑术法对决/高潮武力战；**不含**宏观对阵(§28)、日常比划、≤3招。**结构**（全覆盖）：对峙→试探→攻防≥4轮(换招/格挡/闪避/反击各≥1)→术法域场→逆转受伤→决胜→收势。**阶段内**快速连招/连续攻防**可同 Beat 合并**（§二「快速系列动作同 Beat 合并」），但 Scene 总 Beat 数仍 **≥10**。**高成本**：≥3 Beat 轻功/飞翔/空域/域场(§三-B/§七-C)，禁全地面平拍。**输出**：【决战 Beat 规划】+高成本清单；<10或奇观<3→「决战 Beat 缺口」。  
28. **宏观群体（§28）**：`宏观群体=是` → Scene **≥6 Beat**，禁「大军开到/一触即发」。**判定**：大军/两阵对冲/兽潮/机群/舰队/人海/阅兵/遮天蔽日/无边无际等；**不含**2–3人背景簇。**三要素**：①无边无际(前景→背景地平线满幅) ②阵势威武(前景-中景-背景满编+**剧本威武细节**+有组织感阵线/推进；**允许合理自然参差**——terrain、疲态、个体号召/呼喊错落、队形弹性等，**禁**为机械整齐写违背常理的同步——如全员绝对同高同姿、完全同一节拍踏步) ③压迫感(体量逼近/尘浪声浪压境)；高潮三项齐，余Beat≥2项。**主要角色贯穿（强制）**：宏观场须同步跟踪本场**具名主要角色**（不限于指挥/主将）——各 Beat **正文**须写明其在阵线/队形中的相对位置、叙事功能或体量锚；**景别/观察视角切换**（全景↔特写、Drone→人物 CU、Scale Contrast、Match/Cut 等）须写清主要角色**过渡**（骑乘/旗从众/随从簇锚、位移、视线或动作 Match），禁止切换后主角落位断裂或凭空出现；Beat 2+ 遵循 §11 跨 Beat 可见性过渡。**全景+特写增强震撼（强制，§三-D/§七-D）**：宏观场**须全景与特写交替或同链组合**，用尺度反差强化压迫与军威——**全景**交代体量/阵线/地平线/推进浪潮（**含主要角色在阵中的可读锚点**）；**特写**钉住盔甲磨损、武器阵列举起、旌旗猎猎、盾墙推进、马蹄溅尘、戟林前指、舰炮开火、兽瞳/甲胄反光、指挥/主角眼神、金属撞击瞬间等（**优选有叙事功能的自然瞬间**，非机械同步）；**阵势细节 Beat** 与 **高潮 Beat** 各须 **≥1 全景 + ≥1 特写**（或同 Beat 内 Wide→Insert/Rack Focus/Scale Contrast 链）；禁整场仅全景空镜或仅抽象「大军威武」而无特写切口。**结构**：无边际全景建置→阵势细节(全景+特写交替+军械描绘+主要角色锚)→压迫推进(低角/Tracking+局部特写)→指挥/主角焦点(Scale Contrast+面部/旗令/主角特写，含切换过渡)→高潮对冲(全景对撞+命中/冲击特写)→余波。**禁**：稀疏小簇/「远处若干士兵」/整场无特写/整场只见群演不见主要角色；须前景/中景/背景满编。**输出**：【宏观 Beat 规划】须标注各 Beat 景别（全景|特写|全景+特写链）、OT 手法及**主要角色落位与切换过渡**；<6或三要素缺→「宏观 Beat 缺口」。
29. **等效时长规划与 Beat 切分边界（§29，强制）**：下游单镜视频生成强制 **4–15s**。**Beat 切分与合并的唯一依据为「Beat 完整逻辑」**（文首总纲表前置+六环节、**角色粒度—对白/对话逐说话人轮次切分**、§25 对白拆句、§26 客体禁令、§27 决战≥10、§28 宏观≥6、观察侧/ENV 实质切换、叙事节拍转折、域场态变化、§二「快速系列动作同 Beat 合并」等）；**角色粒度为对白/对话场景的默认强制切分依据**——同一场对话中不同角色的发言轮次，即便观察侧/ENV 未变化，也**必须**各自独立成 Beat，不得以「无视角切换」为由合并；**禁止**因 `Shot / Lens Preference`（镜头偏好/长镜头/特写/快切）而增减 Beat 数，或为迎合单镜时长而合并/拆分本应独立的正反打、拆句、听者反应、**决战阶段节点**。**输入来源（仅用于等效时长估算与校验，非 Beat 切分依据）**：`Episode Duration`（每集时长）、`Project Notes`；原文/用户提示中的**显式时限**（如「前 3 秒吸睛」「闪回 ≤8s」「整段 ≤30s」等）。**规划原则**：① **先按 Beat 生成规则产出 Beat 数与粒度**，再验算等效时长是否可落入下游可拍区间，并在【节拍时间规划】写明依据；② **显式时限**须写入对应 Beat/转场字段（前 3 秒吸睛、闪回上限、维持时长等），**不得**为凑 Beat 数而删减；③ **硬性下限**：`正式决战=是` 仍 **≥10 Beat**；`宏观群体=是` 仍 **≥6 Beat**；④ **每 Scene 必输出**【Duration Estimate Basis】：对白（字数/4）、动作层级、建置/转场留白、奇观补偿的加法算式 + 本场 Beat 总数与单 Beat 预估区间；⑤ **集级校验**：各 Scene `Equivalent Duration` 之和须与 `Episode Duration` 可 reconcile（偏差过大须在 Part 1【节拍时间规划】说明，**不得**为此违反 Beat 规则压缩/扩写 Beat）。**禁止**：镜头偏好驱动 Beat 切分；无视显式时限；为压 Beat 数合并本应独立的正反打/拆句/**决战阶段节点**；为拉 Beat 数把客体轨迹或纯粹受力升格为独立 Beat（§26 仍适用）；**禁止**为机械拆招把同一节奏单元内可完成的快链硬拆多 Beat。

## Scene/环境识别
- **流程**：先判 Scene → **先读剧本定环境需求（§10 剧本服务原则）** → **锁定首个非航拍全局环境 Beat 并锚定主环境 0 度轴**（§11、§16；0 度=该视角**背景方位**；排除特写吸睛与航拍）→ **建立主环境**（§11：360拓扑+头尾双锚+俯视360；**四向包络=空间法定边界**）→ **识别全部视角衍生写入【衍生环境】**（Beat ENV ⊆ 衍生清单）→ 写 Beat 建置。  
- **Scene四问**：时间/空间/行动线/叙事目标连续？任一断裂即新 Scene。  
- **环境六要素**：环境名、内/外、日/夜、空间基准实体、边界、固定结构。  
- **日/夜默认**：未写明则默认**日**，须在成稿明文标注。  
- **0 度锚定**：主环境 0 度 = 本场**第一个非航拍全局环境 Beat** 的 Master/Two Shot/地面级全局建置观察轴，**0 度方向 = 该视角背景方位**（§11、§16；**排除**特写吸睛与航拍；`全局建置=延迟` 时 0 度轴仍锚定**首个非航拍**全局环境 Beat，航拍补全 Beat 不得作为 0 度依据）；360 拓扑相对此 0 度展开（§11）。  
- **四向空间边界**：0/90/180/270 四向拓扑 = 剧情与环境描述法定范围，不得向外扩张（§11）。  
- **环境描述边界、门窗/方向性实体、命名与切换**：见 §9–11；**禁**材质/光源/声场/色彩/氛围。  
- **剧情相关实体空间关系**：固定实体须写清前后左右上下及尺度/形状/开合（主环境可不写 前景/中景/背景；衍生与 Beat 建置须写，§11–14）。  
- **禁令**：氛围/情绪/景别/特写不是环境；**特写/Insert/CU/ECU/MCU 禁止另建衍生环境**（沿用父观察侧 ENV）；停顿/表情变化/正反打不是新 Scene。

- **不得下放**：剧情改写、对白补写、心理重塑、微表情/微动作补写、细节特写规划、**主环境 360 度拓扑与 Beat 级视角衍生识别决策**、闪回/蒙太奇切场决策。

## 详细改编规范 [PRINCIPLES]

### 一-A、等效时长规划与 Beat 切分边界（§29）
- **Beat 切分先于时长验算**：动笔每个 Scene 前，**先按 Beat 完整逻辑规则**（拆句、正反打/观察侧切换、听者反应、叙事转折、§26–§28、快链合并等）确定 Beat 数与粒度；**不考虑** `Shot / Lens Preference`（镜头偏好/长镜头因素）。再汇总集时长、原文显式时限、Project Notes，写入 Part 1【节拍时间规划】并验算等效时长。
- **Beat 生成规则速查（切分依据，非镜头偏好）**：**角色粒度——对白/对话逐说话人轮次切分各 Beat（强制默认依据，文首「角色粒度」；说话人变更即另起 Beat，无论观察侧/ENV 是否切换）**；>20 字对白拆句各 Beat（§25，拆句后仍各落独立 Beat）；观察侧/ENV 实质切换各 Beat（§12）；正反打/OTS/POV 切换各 Beat；听者反应与对白咬合（§四，反应留本 Beat、应答另起新 Beat）；叙事节拍转折、新主动施力方、域场态变化各 Beat（§26）；**同一节奏单元内**快链可合并（§二，限无对白动作链）；决战≥10、宏观≥6 为硬下限（§27/§28）。
- **等效时长验算（内部推演，成稿写自然语言）**：Beat 数由规则自然产出后，`本场等效秒 ≈ 对白+动作+建置/转场+奇观补偿`；单 Beat 等效宜落 4–15s 下游区间，**但不得**为此回头合并/拆分 Beat。
- **显式时限落点**：`前 3 秒吸睛` → 【场景切换与首节拍转场】首节拍三步；`快速闪回 ≤8s` → 转场专拍/快速闪回 Beat；特效/域场 `维持 N 秒` → 六相链维持相或专拍 Beat；须在对应字段**写明秒数**，不得只写「短暂」「一会儿」。
- **等效时长复核算术（每场必填）**：对白约 4 字/秒（极短句 1.5s 保底）；日常微交互 1–2s；正常大动作/格挡/躲闪 3–5s；**快链合并 Beat** 内每招约 1–3s 累加；奇观/域场/宏观场面单独 +3–6s 或 ×1.3；建置/转场留白 1–3s；写入【Duration Estimate Basis】。
- **与 §27/§28 优先级**：决战 ≥10、宏观 ≥6 为硬下限（**继承剧本生成规划，本阶段不得压缩**）；时间压缩**不得**突破；时间扩写**不得**违反 §26 客体独立 Beat 禁令。

### 一、场景开场与节奏
- **三步执行细则**：= 新 Scene 首 Beat 的环节 1–2 入场写法 + §16；吸睛后须后拉/摇移或紧接全局建置，并写清吸睛所用观察视角；**主环境与 0 度衍生锚定于首个非航拍全局环境 Beat，0 度=该视角背景方位，非吸睛特写、非航拍**（§11「0 度轴锚定」）；建置前须完成 §17 实体覆盖盘点；人物落位须先据戏剧关系定距离/序位/隔障（§11「关系驱动站位」）。**远距离/受限 POV 开场**（§16 例外）：首 Beat 可只做 POV 范围内局部建置，**不必**强行后拉完成全场全实体建置；全局建置可推迟至后续合适 Beat（可用航拍/高位揭示），**但 0 度轴须锚定于其后首个非航拍全局环境 Beat**，并在【Scene实体覆盖】标注 `全局建置=延迟`、补全 Beat 与 **0度轴锚定 Beat**。**分组/分批出场**（§16 例外）：若两拨人群/主体本就分属不同 Beat 先后登场、不适合同一开场画面出现，**不得**为凑「全体亮相」强行把尚未到场者拼进开场同框；只建置该时刻确已同框在场者，其余按 §17 标注待入画，到其登场 Beat 再完整建置。  
- **建置归属**：空间/关系/物体说明并入可拍节拍，不得留“下游补建置”；**画外/待入画者**仅在【Scene实体覆盖】标注 Beat+触发+出入画方向，**非入画 Beat 不写其建置**；`全局建置=延迟` 场须标注补全 Beat+触发+**航拍/高位建置手段**，Scene 结束前闭环。  
- **实体入画承接（= 新出场角色完整建置，强制）**：凡 Scene 内**首次入画、重新入画、跨 Beat 新变为画内可见**的具名角色，该 Beat **须与 Scene 开场建置同等粒度**——**先**观察视角+当前环境，**再** 前景/中景/背景 三层框架，**再**对该角色层内逐个写清七要素 + **角色建置朝向四要素**（位置｜身体朝向｜视角正背面及可读性｜与他者/物件朝向关系）；须写**从哪一侧/哪个位置进入**、触发、出入画径向、入境轨迹（位移动作五元组）与终态落位；落位须先据**与已在场者的戏剧关系**（§11「关系驱动站位」）定距离/序位/隔障/相对朝向，并触发 §14。**禁止**只写「出现/登场/推门进来/走到某处」而不写**进入位置、进入方式、身体朝向、相对镜头正/侧/背面及与他者朝向关系**；**禁止**新出场 Beat 直接写对白/主动作而跳过该角色完整建置。**画外角色（强制）**：尚未入画的具名角色**不在非入画 Beat 的建置/对白落位/全员反馈中描述**。**跨 Beat 可见性与面部可读性变化**：凡相邻 Beat 间具名角色画内可见状态或**面部/口型/眼神可读状态**发生变化，须写 §11 过渡动作，并在 `[Beat切换说明]` 核销；禁止同视角同站位下无过渡即删列/新增角色，或面部可读性无动作跳变。  
- **立体三轴建置**：执行见 Beat 完整逻辑环节 2–3、§11、§14；纵深统一用 前景/中景/背景（=**相对镜头**）；横向用左/中/右；有高度差时用上/中/下（高/中/低）；**每个实体只做一次三轴落位描述**（见 §11「立体三轴落位」）；环境内前/后/内/外须锚定 ENV 结构或具名实体（=**相对环境**）；禁止无参照系混用「前/中/后」。**人物建置须同步写清角色建置朝向四要素**（位置｜身体朝向｜视角正背面及可读性｜与他者/物件朝向关系），禁止只写坐标不写朝向。**建置时须同步考虑景深遮挡与层间距离**（§14）：中景 完全遮挡时 背景 不可见则禁止硬写；层间较远须写清 前景↔中景↔背景 空间跨度。
- **视角切换书写**：**ENV 名有变** → 成稿须写清 `上一 ENV → 触发 → 本 ENV（含衍生名）→ 完整重新建置说明`（§12、§15）；**ENV 名不变** → 可省略建置，只写变化项，`建置更新=否`。  
- **长对白**：>20字拆短句并加听者微反应；拆句同步情绪标点（§四）；结果写入【对白拆句判定】。  
- **对话反馈**：执行见 Beat 完整逻辑环节 4–6；每轮台词后紧跟主听众反应（微表情+微动作各≥1）。  
- **微动作/微表情常见项**：见下列清单；均须动态过程链书写，视线/肢体变化须写立体三轴；切口密度：每 Beat 至少一项，长对白每 2–3 句至少 1 处。  
- **微动作常见项**：呼吸深浅/节奏、指尖松紧/轻敲/蜷缩、视线游移/定格/回避、重心/肩线、吞咽/喉结、唇瓣、衣料/发丝微颤、握物力度。  
- **微表情常见项**：眉弓平蹙/轻挑、眼角半阖/骤张/轻颤/发红、瞳孔视线定格/游移/回避、鼻翼翕动/收紧、唇角抿紧/微扬/下撇/轻颤、下颌绷紧/咬紧、面颊抽动/血色上浮、泪膜蓄溢/滑落、口型微启/紧封/欲言又止、法令纹加深。  
- **喜剧类微表情**（夸张型场叠加）：挑眉飞挑、瞪眼/眼珠上翻、瘪嘴/撇嘴、咧嘴大笑、憋笑抽搐、白眼、O 型嘴、斜眼睨视、装无辜睁大眼等；包袱落点优先眉眼+嘴型组合。  
- **表演连贯性/原文点出项**：执行见 Beat 完整逻辑环节 6、强约束§6–§7；文学描写须拆为可拍部位与变化过程，对应具体 Beat。  

### 一-B、场景切换与首节拍转场（合并说明，强制）
本小节统摄 **Beat 间过渡、Scene 内快速闪回、Scene 间切换、每场首节拍**；与 §二「转场专拍 Beat」「转场手段参考库」配套使用。Part 1 / Part 2 **禁止**将切换判定、首节拍技巧、出场转场拆成三处各写一半，须合并写入 **【场景切换与首节拍转场】**。

- **转场逻辑链（强制顺序，逐 Scene 走完）**：  
  1. **上场承接**：读取上一场【视觉落点】为本场入点锚；写明「上场落点 → 本场如何接住」（动作余势/视线/声音/物体/色调/构图之一或多）；全剧第一场写「无上场：开场特例」。  
  2. **切换判定（四项必填）**：`时空关系`（连续/省略/跳转）｜`桥接依据`（动作/视线/声音/特写/色调/光影/遮挡/图形 Match/运镜/声画对位等，至少一项）｜`轴线状态`（同侧/已交代过轴）｜`跨幅级别`（小跨幅/已说明跨环境）。禁止无依据硬切。  
  3. **手法选定**：从 §二「首节拍 OT 标签」+「转场手段参考库」各选 **≥1 项**；场间切换与每场首节拍**须标 OT 简称** + 自然语言可拍描述；Beat 间小过渡可只写手段名称。  
  4. **首节拍三步咬合**（强约束§16）：**吸睛（前 3 秒）→ 建置（观察视角+环境+先 前景/中景/背景 三层、再每层内逐个实体落位）→ 入戏**；吸睛手段须与 Step2 桥接依据、Step3 OT/转场手法**同链**，局部特写吸睛后须后拉/摇移或紧接全局建置。**远距离/受限 POV 例外**：首 Beat 为瞄准镜/望远镜/远距监控等 POV 时，建置步**仅覆盖 POV 可见范围**，可标注 `全局建置=延迟`，不必同 Beat 后拉全场；补全 Beat **优先 OT-LS/OT-MAP/OT-AE 等航拍/高位俯瞰建置**，再写 `{下一节拍起幅}` 或专拍 Beat。  
  5. **下场预埋**：本场末 Beat 或【视觉落点】须写明可供下一场 Step1 承接的锚点（落点画面/动作态/声源/物件状态）。

- **三层切换粒度**：  
  | 层级 | 典型场景 | 写法要点 |  
  |---|---|---|  
  | **Beat 间** | 正反打、视线 Match、无情节回忆切片 | 同 Scene；无情节切片可并入转场链，不必独立 Beat |  
  | **Scene 内插入** | 快速闪回（回忆对白 >30 字）/ 无情节回忆切片 | 不拆 Scene；快速闪回主节拍=快速闪回桥接；无情节切片主节拍仍归当下场，切片写入转场链（§三） |  
  | **Scene 间** | 时空跳跃、空间跨越、原文/上游已切分的独立场次 | 新 Scene 首节拍走完全链；上场末+本场首须双端桥接；**完整闪回不必然另拆 Scene**，以原文/上游切分为准 |

- **首节拍技巧 = 场间转场技巧**：每场**首 Beat 正文**的 OT/转场手法，即本场**入画方式**；须同时回答——**从哪来（上场承接）→ 怎么切进来（桥接+OT）→ 第一眼看什么（吸睛）→ 空间怎么建立（建置）→ 戏从哪入（入戏）**。  
- **参考片对标（强制）**：每场至少写 1 部 `borrowed_films` 中对标片 + 具体手法（如「《xxx》走廊跟拍入画，OT-TR 横移穿越」），不得只写片名或只写 OT 代号。  
- **与转场专拍 Beat 分工**：需独立展开的桥接情节（场间省略、蒙太奇、声画对位、快速闪回等）→ 上场末 Beat 或本场首 Beat 建**转场专拍 Beat**（主节拍=转场/快速闪回桥接），其前后 Beat 仍须写切换判定与承接；简单连续时空且桥接可在首节拍三步内完成 → 不必另建专拍 Beat。  
- **示例**：【场景切换与首节拍转场】上场林医生推门落点 → 切换判定：连续省略｜声画对位+色调渐变｜同侧｜小跨幅 → OT-LG 走廊灯光由暖渐冷+OT-TR 横移穿越（对标《xxx》）→ 首节拍：门缝光带收窄吸睛 → Pullback 建置走廊，近处门框、地面、远处走廊尽头依次入画 → 陈医生脚步声入戏。  
- **远距离 POV 延迟建置示例**：【Scene实体覆盖】`全局建置=延迟`；已入场：狙击手李、目标王、观察员张——Beat 1 仅落位李（POV 观察侧）+ 镜内王剪影压点；张与王全场关系标注「待全局建置 Beat 3，触发：镜筒移开；补全手段：OT-LS Drone 高位俯拍 rooftop 建置航拍景观」。Beat 1 首节拍：瞄准镜十字线压王胸口吸睛 → POV 衍生环境建置镜框与靶区范围 → 李扣机指渐紧入戏；Beat 3 Drone 自高位俯拍缓缓下降，一次性建置 rooftop 三人全局落位与相对距离，再切近景入戏。
- **分组/分批出场示例（禁止强行全体建置）**：剧情设计为码头一侧工人簇先行装卸作业，另一侧接头人一行三人稍后才从仓库侧门登场会面——【Scene实体覆盖】：工人簇标「开场即在场」；接头人甲/乙/丙标「待入画 Beat 3，触发：仓库侧门开启脚步声，出入画方向：画面右侧仓库侧门」。Beat 1 首 Beat **只需**建置码头与工人簇作业（该时刻确已同框在场者），**不得**为求「全体亮相」而把尚未登场的接头人一行提前塞入 Beat 1 同框；Beat 3 接头人甲/乙/丙自仓库侧门登场时，再按 §11「新出场角色完整建置」同等粒度补建三人入画位置、朝向与和工人簇的关系站位。❌ Beat 1 强行写「工人簇在码头作业，接头人一行三人已候在仓库侧门旁」（两拨人群本不同框却硬凑一景）。

### 二、空间位移与动作微观化
- **主节拍/主动作（强制）**：每 Beat 标明**唯一**主节拍/主动作（或**快速系列动作链**之主节拍名，见下条「快速系列动作同 Beat 合并」），且**必须归属主动施力方**（**例外**：转场专拍 Beat 主节拍=转场桥接，见下条）；被动物件的运动、落点、碰撞及**纯粹受力位移**仅为该 Beat 因果链的延续描述，**不得升格为独立 Beat**（执行见强约束§26）。微动作不得替代主动作，但须在全员反馈与对白停顿中持续落地。  
- **快速系列动作同 Beat 合并（强制选项，打斗/追逐/术法/日常快链通用）**：**同一节奏单元内、连续动量、无叙事停顿**的系列动作**可合并为单 Beat**，不必每招/每格/每闪独立拆 Beat。典型：**打斗连招**（直拳→鞭腿→扫堂腿）、**连续攻防**（格挡→闪避→反击）、**追逐短链**（起跑→绕障→跃过）、**术法连击**（结印→引气→连发）、**日常快链**（拾物→转身→递交）等。**合并条件（须全部满足）**：  
  1. **单镜可拍体感**：合并链等效 **4–15s**，属同一观察节奏单元（One-Shot/跟拍/动作 Match 连贯，或观察侧无需切 ENV 即可读完全链）；  
  2. **Beat 内写完整子动作链**：`起点建置 → 子动作1（发力/接触/效果）→ 子动作2 → … → 终态落位`；每一子动作须写**关键轨迹节点**（相对 ENV/实体的位置+左中右区段）、**命中/格挡/闪避效果**、**朝向变化**；禁止合并后只写「一套连招」而无各招过程；  
  3. **位移在链内闭环**：各参战者相对链**起点**须有可核销的三轴位移与终态落位；**Beat 间**仍须相对上一 Beat 终态有落位变化（链内微动不算 Beat 间重复）；  
  4. **主节拍命名**：标合并链整体名（如「甲三连击压制」「乙格挡闪避反刺」），非仅第一招；  
  5. **【Duration Estimate Basis】**：合并 Beat 按链内子动作数累加时长（每招约 1–3s 快链 / 3–5s 大动作），总时长仍须落入 4–15s。  
  **须拆为独立 Beat（禁止强行合并）**：① 观察侧/ENV 须切换才能读招/读表情/读术法（OTS/正反/POV/状态衍生）；② **新主动施力方**接续（§26）；③ 叙事节拍/情绪/信息 Reveal 转折；④ 域场态/结构/layout 跨 Beat 变化；⑤ 慢镜/定格/Insert 须独立可读（**Insert Beat 仍沿用父观察侧 ENV，禁止另建特写衍生环境**）；⑥ `正式决战=是` 的**阶段节点**（对峙/试探/术法域场/逆转/决胜/收势）仍须分 Beat 覆盖，**阶段内**快链可合并。**≠** 允许：合并后省略位移/朝向/命中链；把本应分 Beat 的正反/OTS 硬塞一 Beat。**示例**：Beat 3 甲在场地右区起势→直拳击乙左肩（乙肩线后挫）→甲移至中线鞭腿扫乙左膝（乙向左后半步闪避）→甲逼近左前扫堂腿（乙跃起避过、退至右区）→终态甲落场地左前、乙落右区，间距 1.2m（三连击同 Beat，主节拍=甲三连击压制）。  
- **纯粹受力/客体运动禁令（强制，§26 展开）**：  
  - **同 Beat 必写**：施力主动作 → 接触/命中（**写清命中部位/落点**）→ **命中效果/受力反馈** → 客体轨迹或受力方被动位移（**需要时写移动路径**：沿结构滑行/弧线/反弹/滚转等，锚定 ENV 具名部位）→ 落点/碰撞/静止，全链写在**发力方同一 Beat**（或发力方动作延续的下一 Beat，主节拍仍归同一施力方）。投射攻击（子弹/飞镖/箭矢/暗器等）同样适用，禁只写射出/飞出而无路径（需要时）、命中与效果。  
  - **禁止独立 Beat**：以被动物件为主语的单 Beat（「球飞向…」「杯摔碎」「纸张飘落」）、以纯粹受力为主语的单 Beat（「他被推倒」「她被撞飞」且不含主动格挡/闪避/承接）——均须**并入上一施力方 Beat**。  
  - **可新开 Beat 的条件**：仅当**新的主动施力方**接续并承担主节拍——如对方接球、门将扑救、格挡反击、主动闪避后还击、主动后撤收势等；此时主节拍归该人物，不得仅写「受力结果」而无其主动意图。**同施力方快速系列动作链**（连招/连击/连续格挡闪避）**优先合并同 Beat**（见上条），不必因「每招一招」机械拆 Beat。  
  - **链过长拆分**：**施力起势 Beat** → **同一施力方动作延续 Beat**（含客体全程轨迹至静止/命中，或受力方纯粹被动位移至落点）；**禁止**拆出「客体独立 Beat」或「纯粹受力独立 Beat」。  
- **形体动作因果链（强制）**：施力-受力、接触-运动等同链，须先写完整主动作与受力反馈，再写结果轨迹/落点；禁止只写结果而跳过施力主动作。**主节拍必须归属主动施力方**（人物、有自主意识的活物、或术法/机关的明确触发者）；客体轨迹、旋转、飞行、落点、碰撞须写入施力方同一 Beat 的因果链内连贯描述。仅当**新的主动施力方**接续（对方接球、门将扑救、第二人拦截等）时，方可新开 Beat，主节拍归新施力方。  
- **主动作主体示例**：  
  - Beat 1 主角立于球场左区，右脚发力踢球→球沿低平弧线飞向门口、在门槛前侧反弹后滚入走廊深处（施力主动作与客体轨迹同 Beat）。  
  - Beat 1 甲挥拳击中乙胸口→乙上身受力后倾、脚跟离地半步后坐倒在地（施力、命中、受力反馈、落点全链同 Beat）。  
  - Beat 1 甲在右区抬枪击发→子弹自枪口低平射出，途经中线命中乙左肩→乙肩线后挫、身体顺时针半旋后坐倒地（出手、弹道、命中部位、效果同 Beat）。  
  - Beat 1 丙在左前甩腕掷出飞镖→飞镖沿弧线飞向丁喉前→丁侧身闪避，飞镖擦耳钉嵌入身后木质屏风，镖尾颤振（出手、弹道、预期命中、实际落点、效果同 Beat）。  
  - Beat 1 林医生在左区推桌→桌上文件夹沿桌面滑向桌沿（施力主动作与客体轨迹同 Beat）。  
  - Beat 1 主角踢球→球飞向门口；Beat 2 门将在门前跃起扑救（主节拍归门将，新主动施力方）。  
  - Beat 1 黑色轿车自远处左侧车道加速驶向中偏右区（车头朝右前，途经中线后变道至近处右车道），在斑马线附近急刹停稳（施力主动作=加速驶近与制动，轨迹与终落同 Beat）。  
- **特效拆 Beat（例外）**：术法/域场/奇观六相链过长时，可 **起势 Beat → 特效专拍 Beat → 落位 Beat**（细则见§三-B）；不得替代形体动作链，不得跳过触发源。  
- **转场/过渡专拍 Beat（例外）**：凡 Beat 间、Scene 间或时空/情绪/信息需桥接的转场，本阶段为连贯性**优化补写的过渡情节**（蒙太奇切片、空镜桥接、声画对位、匹配切、走位穿越、环境异象铺垫、情绪余韵承接、**快速闪回**、**无情节回忆切片**等）**可单独建 Beat**；**主节拍=转场桥接**（**快速闪回**时主节拍=快速闪回桥接，**须满足回忆对白 >30 字**，见§三；**无情节回忆切片**可并入相邻 Beat 转场链而不必独立建 Beat，见§三）；须写清：切换判定（时空关系/桥接依据/轴线状态/跨幅级别）、前后承接落点、OT 或转场手段名称、可视过程链；**快速闪回**另须标明进入锚点、回忆切片内容（对白/动作要点）、回切锚点与质感处理（见§三）；**无情节回忆切片**写清触发→切片画面要点（≤2s）→回切锚点与质感即可，**不要求**完整对白链/动作链/三层建置。此类 Beat 服务于叙事连贯与转场可读，**不**视为客体独立主动作；**禁止**无桥接依据的硬切占位。  
- **转场专拍示例**：Beat 3 对白落点，林医生视线定格门外→ Beat 4【转场桥接】走廊灯光由暖渐冷、脚步声叠化、门缝光带收窄（桥接依据：声画对位+色调渐变；时空关系：连续省略）→ Beat 5 陈医生推门入画。  
- 路径、开关方向、进出径向、绕障路线须写清；凡方向变化须按**立体三轴**落点，且**前/后须标明相对镜头或相对 ENV/实体**（见 §11 前后位置双轨）。  
- 高动量段落须写速度状态（起速/加速/急停/失速）+ **方向变化节点**（每个变向须写清沿哪一轴、从 前景/中景/背景 哪区段切至哪区段、左中右哪区段切至哪区段，必要时上中下）。  
- 位移动作五元组：`起始实体落位（含层位 前景/中景/背景 + 左中右 + 必要时上中下） → 发力（发力部位+立体方向） → 路径/方向（**移动路径**（需要时：相对 ENV 结构的路径形态）+ 沿三轴的变化节点，每节点须 前景/中景/背景 + 左中右） → 终点实体落位（含层位 前景/中景/背景 + 左中右） → 静止/受力结果`（成稿写具体人物/物件/载具/空间结构部位）。**移动链须同步写行进/飞行/车体朝向与轨迹路径**；客体/受力体轨迹**需要时须同步写移动路径**，执行细则见强约束§11「运动方向与朝向」。  
- **打斗场景站位默认（强制）**：凡近身肉搏/追逐缠斗/正式决战/武打换招段，**Beat 间**各参战角色须相对**上一 Beat 终态**发生可核销的三轴落位变化（跨层、绕障换侧、逼近/退离、腾空/落地、借物换位、越轴等）；**Beat 内**快速系列动作链（§二「快速系列动作同 Beat 合并」）位移在链内写清各招节点即可，**不要求**每招拆 Beat。**禁止**多 Beat 固定同一 前景/中景/背景+左中右 硬写换招/格挡/闪避而无位移链；**禁止**为机械拆招把本应合并的快链硬拆多 Beat 却省略链内轨迹。**环境切换与建置重建（打斗专项，强制）**：**ENV 名有变**（观察侧/OTS/正反/POV/门内外/域场态等导致衍生或状态 ENV 切换）→ 须**同步**写环境切换 + **完整重新建置说明**（§15）+ §12 可执行性校验；**ENV 名不变** → 建置可省略，只写链内位移/攻防变化。成稿须可核对「上一 Beat 终态 → 本 Beat 变化 → 终态」与「ENV 名=变|未变 / 建置更新=是|否」。
- **武戏/决斗/术法 Beat 视角—环境—朝向（与对白同等粒度，强制）**：凡**无对白或对白为辅**的近身决斗、远程投射、术法/域场、轻功空战 Beat，**须与对白 Beat 一样逐 Beat 完整执行环节 1–3**，不得因「纯动作」而省略观察视角、背景层或朝向分析。每个 Beat 动笔前须完成下列**动作视角咬合**核验（与 §12 环境—视角匹配、§11 朝向四要素同拍）：
  1. **观察侧声明（必填）**：写清本 Beat **Observer View**——0 度 Master/Two Shot、OTS 过肩（谁的肩后看谁）、正反打（攻方/守方/施术者/受击者各 Beat 切换）、POV（施术者/受击者/弹道/瞄准）、Insert 特写（拳/剑/符/法器/命中部位）、全景建置（双人/多人对峙或空域换位）等；**相对上一 Beat 观察侧是否变化**及触发（动作 Match、视线 Match、动势切、越轴、入画等）。
  2. **背景层变化（必填）**：按当前观察侧重写 **前景/中景/背景**——须写清相对上一 Beat **背景 可见半空间是否变化**（如 0 度 背景 文件柜墙 → 180 度反打 背景 变为入口/对侧墙；檐上 Beat 背景 变为地面纵深/天际线；域场态 背景 结构/layout Delta）；**禁止**多 Beat 沿用同一主环境 0 度 背景 硬写正反/OTS/越轴而不切衍生环境、不重写三层。
  3. **朝向四要素（必填，逐参战者）**：每个画内人物均须写**角色建置朝向四要素**——位置｜身体朝向｜相对 Observer View 正/侧/背面及可读性｜与他者/物件朝向关系（相向对峙/侧对格挡/背向威胁/同向追击/隔障相对等）；主动作发起时须写**发力侧/武器轴向/术法手势朝向**相对镜头与他者的可读面。
  4. **OTS/正反/双人镜（强制，双人及以上决斗）**：与对白正反打同等规则——**读招/读势/读表情/读术法手势/读受击反馈**时，须切至匹配衍生环境后再写可读细节；典型：**甲出拳 Beat** 可用甲侧 OTS 或 Master 看乙；**乙格挡/受击 Beat** 须切乙正面/侧脸或乙侧 OTS 反打（衍生环境），并重判乙视角正背面与 背景；**术法 Beat** 施术者结印/引气可读时切施术者近景或 POV，命中/域场展开时切受击者 OTS 或状态衍生 ENV 重写 背景。**禁止**标 OTS/反打却仍在主环境 0 度写对方面部/手势/术法细节可读。
  5. **双人/多人入境与出画（强制）**：第二人/第三人**首次入画或重新入画** Beat 须写：出入画径向（左/右/上/下/纵深 前景→中景）、触发（被追击入画/援兵赶到/术法召唤/空域降落）、**入境后 前景/中景/背景 落位+朝向四要素**、与已在场者**与他者朝向关系**；**须与 §11「新出场角色完整建置」同等粒度**——禁止只写「出现/登场/入画」而无位置、身体朝向、视角正背面及关系站位；若入境改变观察侧或轴线，须同步 ENV 切换与建置重建。**Scene 开场双人决斗**首 Beat 须完成双人 Two Shot 或等效全局建置（§16/§17），再进入逐 Beat OTS/正反/POV 切分。
  6. **术法/域场/空战环境切换（强制）**：结印/引气/域场展开/轻功腾空/御剑换层等导致**观察高度、可读侧、固定结构可见性、域场 layout**变化时，须写 `触发 → 视角/状态衍生 ENV 名 → 空镜差异 → 建置重建`；跨 Beat 域场/结构破坏用**状态衍生**；空战 Beat 须写垂直层位（上/中/下）+ 前景/中景/背景 在纵深与高度双轴的落位变化。
  7. **成稿最低覆盖（每个武戏 Beat 须可检索）**：`观察视角（含相对上一 Beat 变化）→ 当前环境名 → [环境切换声明/None] → 前景/中景/背景 框架与各层逐实体落位 → 各参战者朝向四要素 → 主动作/轨迹/命中链 → 终态落位与 ENV/视角承接`。
  - ❌ Beat 3「甲挥剑劈向乙，乙格挡」（无观察侧、无 ENV、无背景变化、无朝向、多 Beat 同站位同 0 度主环境）｜✅ Beat 3 动势 Match 后观察视角切至**乙正面 45 度近景**（衍生环境：练武场_乙侧反打），乙身后由兵器架墙变为**对侧拱门与天际线**；乙**四分之三左侧面朝向镜头、与甲相向对峙**，举剑格挡、**剑刃轴向朝左上迎击**；甲挥剑手臂占画面左缘近处作 OTS 框景（肩背剪影）；甲位于场地右区、**侧对乙、背向镜头**，终态二人间距由 2m 缩至 0.8m。
  - ❌ Beat 5「陈医生结印，符阵炸开」（无 POV/OTS、无状态 ENV）｜✅ Beat 5 观察视角切至**陈医生 POV 衍生**读结印手势 → Beat 6 动势切/特效专拍切**状态衍生「会客区_符阵覆盖态」**，地面符纹覆盖范围与文件柜倾角变化；林医生**背对镜头、肩线后撤**，**与陈医生隔桌相向**；Beat 7 切**林医生 OTS 反打**读受击微表情。
- **打击与投射攻击链（强制，打斗/远程攻击统一口径）**：近身打击与远程投射均须写完整因果链，禁只写动作名或只写「打出/射出/飞出」而无命中与效果。  
  - **近身打击链**：施力方起势位置（相对 ENV/实体+左中右）→发力方向→**接触/命中部位**→**受力反馈**（位移/失衡/伤态/格挡硬抗等）→**移动路径**（需要时：受力方被动位移沿哪结构/弧线/滚转）→终点落位。

  - **快速闪回（有情节）**：服务于当下场情绪/信息落点的**短促回忆对话或具名动作情节切片**（通常 1–3 Beat、单段 ≤8s 体感）；**启用门槛（强制）**：待视觉化呈现的**回忆对白原文合计须 >30 字**（含画外/OS/V.O. 闪切台词；不含仅触发回忆的当下台词如「你还记得吗」）；**≤30 字且含具体情节/对白**时**禁止**建快速闪回 Beat，改以当下场微表情/微动作、听者反应、口述转述或 `OS/V.O.` 承接。人物年龄态/妆发/服装、环境状态、道具状态与当下**无实质差异**，或差异仅通过质感处理（去色、虚化、噪点衰减、柔焦、慢速等）即可区分；回忆内容**补充印证**当前对白/反应，不独立承担新叙事目标。**不拆 Scene**，在当前 Scene 内以**转场专拍 Beat**（主节拍=快速闪回桥接）或插入节拍承载；须写清进入锚点（视线/物体/台词关键词/声音桥）与回切锚点（动作余势/声残响/构图呼应），手法优先：感官冲击闪切、定格闪帧、回忆质感衰减、闪回梦境叠化、跳切、声画对位。  
  - **无情节回忆切片（转场式）**：原文或强暗示仅有**印象/情绪/物象触发**，**无具体对白链、无完整动作情节、无独立信息 Reveal**（如「想起父亲的脸」「雨夜的车灯」「爆炸一闪」「童年走廊剪影」）；**不受 >30 字门槛约束**，**禁止**升格为完整闪回 Scene 或扩写为快速闪回 Beat。**处理方式**：按**转场手段**写入相邻 Beat 的转场链——触发（视线/物件/声/触觉）→ **≤2s 单幅或 1–2 帧印象切片**（写清可见物象/人物剪影/环境色块，**不要求**完整 前景/中景/背景 建置与对白咬合）→ 质感处理（去色/虚化/噪点/柔焦/慢速等）→ 回切当下（动作余势/微反应/声残响）；可并入上一 Beat 末、下一 Beat 初或短转场专拍，**主节拍仍归当下场**。**禁止**为无情节切片单独扩写对白链或完整动作链；切片内具名主体须列入【Scene实体覆盖】，但可仅写剪影/局部/impression 级落点。  
  - **回忆对话处理原则**：原文或强暗示的「想起/记得/当年/那时说过」类回忆——**无具体情节**→ **无情节回忆切片（转场式）**；**≤30 字且有具体情节/对白**→ 当下场口述/反应/OS，不闪回；**>30 字且未达完整闪回升格条件**→ **优先快速闪回**；**构成独立戏剧段落**（多轮对话、完整动作链、状态态大变）→ 若原文/上游已切独立场次则拆 Scene，**否则仍优先 Scene 内转场专拍/快速闪回**，不得自创 Scene 或回忆 ENV。  
  - **示例（快速闪回）**：回忆对白「爸，你别走，我会乖乖听话的，以后都听你的话，求你别丢下我一个人，我真的好怕」>30 字 → 转场专拍 Beat：银打火机特写 Match 切至回忆质感画面，幼年林医生对父亲上述对白闪切（≤8s）→ 声残响回切，陈医生面部微反应承接。  
  - **示例（无情节切片）**：林医生视线落向窗外雨痕 → 去色+柔焦 1 帧「童年走廊尽头父亲背影剪影」感官冲击闪切 → 回切当下，林医生喉结滚动、呼吸一滞；不建独立闪回 Beat，不拆 Scene，不写回忆对白链。  
- **礼法/民俗站位（强制，不限古装/豪门）**：凡涉及明确文化礼制、宗教仪轨、组织位序或民俗传统的场景（古装宫廷/庙堂、豪门家族、军队仪典、宗教场所、传统节庆礼俗、职场会议室主次座位等）均须体现相应**礼法座次与高低站位**；**明确上下级/尊卑关系人物同框时的站位、朝向与文化考据细则见 §11「关系驱动站位」「文化/文明/民俗敏感站位」「明确上下级关系群体站位」**。  
- **角色占位名→具名（强制，§19）**：改编前先扫描原文人物称呼；凡「男主/女主/主角/反派/男二/女二/Boss/CP 男/女」等**具名叙事角色**的职能或番位词，须在本阶段统一替换为具体姓名；**群演/龙套/匿名背景簇**（如「村民」「路人」「士兵群」「办公人员簇」「龙套甲/乙/丙」）**禁止**替换为具体姓名，仅以簇描述书写（见 §19 群演例外）；已有真实姓名者保留；新取名须服项目语言与时代/地理/题材/阶层/职业，全剧一致。Part 2 成稿、Scene 实体覆盖、Beat 落位、对白与全员反馈中**不得**残留占位称谓（**龙套/群演簇除外**）；Part 1 须输出完整对照表。
- `UI`/旁白/对白最终统一到剧本指定语种。

### 三-B、AI特效（§21）
- **定位**：前置规划可拍特效。
- **高成本优先(仙侠/武侠/玄幻/史诗)**：轻功/御剑/空战/域场/法相/巨物/多主体/尺度反差(§七-C)；同拍|专拍六相链；写实/职场不适用。
- **触发**：原文暗示｜仙侠/玄幻/科幻/奇幻/恐怖/超自然/史诗｜情绪转折/Reveal｜信息可视化｜域场建置。
- **分配**：同拍=短特效+形体绑定｜专拍=六相链分帧/域场/奇观；专拍前后咬合起势/落位。
- **状态衍生**：跨Beat改写结构/边界/布局 → `{主环境}_{状态}`(§10)+建置重建(§14)；瞬时光效/粒子不建衍生；光色材质由 Skill 1-3 细化。
- **方法库**：能量术法｜形体变身｜时空维度｜环境域场｜微观宏观｜光影质感｜情绪外化｜冲击破坏｜生物诡异｜科技赛博｜轻功飞翔空域(§七-C)。
- **禁**：装饰堆砌/无触发光效/纯特效替动作/改因果。

### 三-D、宏观群体 AI 高成本（§28）
- **适用**：大军/对阵/兽潮/机群/舰队/人海主节拍；同帧海量/极端密度/地平线铺满；禁稀疏小簇。
- **三要素**：`无边无际` 前景→背景满幅｜`阵势威武` 三层满编+**剧本威武细节**+有组织感阵线/推进（**允许自然参差**，禁机械同步）｜`压迫感` 体量逼近/尘浪声浪/低角或俯瞰；高潮三项齐。
- **主要角色（强制）**：具名主角/关键人物须在各 Beat 可追踪；全景须标其在阵中的相对位置或叙事锚；景别/视角切换须写**过渡**（Match/Cut、骑乘/旗从众锚、位移/视线引导），禁切换后落位断裂。
- **动作自然性（强制）**：阵势须有组织感与威武细节，但**动作须自然合理**——允许 terrain、疲态、队形弹性、呼喊/踏点错落等参差；**禁**为追求整齐划一而写违背常理的机械同步（全员绝对同高同姿、完全同一节拍等）。
- **全景+特写增强震撼（强制）**：宏观场须**全景与特写组合**写军威与压迫——**全景层**（Drone/Crane/EWS/LS/地平线铁流/满幅阵列/对冲宽画幅）交代体量与阵线（**含主要角色锚点**）；**特写层**（CU/Insert/MCU/低角局部/Scale Contrast 后切特写）钉住盔甲、武器阵列、旌旗、盾墙推进、马蹄溅尘、戟林前指、出鞘瞬间、金属撞击、指挥/主角眼神/旗令、舰炮开火、兽瞳/甲胄反光、冲撞瞬间等（**自然瞬间优先**，非机械同步）；**阵势细节 Beat** 与 **高潮 Beat** 各须 **≥1 全景 + ≥1 特写**（或同 Beat Wide→Insert/Match/Scale Contrast 链）；OT 优先：OT-LS/OT-MAP/OT-AE（全景）+ Insert/特写 Match/Scale Contrast/Rack Focus（特写）。
- **Beat链(≥6)**：①无边际全景 Drone/Crane/EWS（**含主要角色阵中锚**）②阵势细节(**全景+特写交替**+军械描绘+主角/指挥可读落位) ③压迫 Tracking/低角尘浪+局部特写 ④指挥/主角 Scale Contrast+面部/旗令/主角特写（**含全景→特写过渡**）⑤高潮全景对冲+冲击/命中特写 ⑥余波(全景收束或特写余韵)。
- **群演**：簇/阵/列写密度队形，不逐人具名；指挥/旗舰/主要角色=体量与叙事锚。
- **区分**：背景2–3人小簇(§16) ≠ 宏观主节拍(本条)。

### 四、对白/旁白/心理外化
- **继承边界**：改标点控节奏，不改意图、词义、事实与因果。  
- **剧情承载（强制）**：每句对白/OS/V.O. 须推进立场/筹码/关系/前因/后果之一；跨 Beat 信息须靠对白承接、听者反应或当场交代来源，禁装饰性流水账；>20 字拆句时插入反应/动作切口使信息递进可读。  
- **每场拆句声明（强制）**：每个 Scene 在【对白拆句判定】中明确 `已拆句|未拆句|无对白`；已拆句须列原句→子句→Beat→切口对照；未拆句/无对白须附原因。Part 1【对白拆句自检】须逐 Scene 复核判定与 Beat 正文 inline 对白一致。  
- **语气层 inline 标注（强制，每条对白/OS/V.O./自白/独白）**：Beat 正文开口写台词前，须 inline 标注下列字段（括号内自然语言，**禁止**只写「开口说」而不写语气层）；字段须与 Part 1【角色命名】该角色 `voice_identity` **一致或 shorthand 引用**，并与本句情绪标点、微表演咬合。  
  - **`voice_type`**：对白｜OS｜V.O.｜自白｜独白  
  - **`voice_identity`（强制）**：说话人**身份/声线人设**——取自【角色命名】，Beat 内可 shorthand（如「林医生·领导型主治医师音」「村妇·农家妇女音」「少女·萝莉音」）；须让配音/TTS 可检索音色类型，**禁止**省略或仅写姓名  
  - **`tone`**：情绪气质（冷峻、试探、讥讽、温存、压抑、爆发、嬉皮、威严…）  
  - **`speed`**：慢｜中速｜快｜渐快｜渐慢｜先慢后快…  
  - **`volume`**：低语｜正常｜略高｜厉声｜压抑声｜气声…  
  - **`rhythm`（节奏型，强制）**：本句**整体节奏走势**——如「一字一顿」「短促连珠」「先缓后催」「抑扬顿挫」「平铺直叙」「句尾下沉」「问句尾音上扬」等；须与 `speed`/标点一致  
  - **`stress`（重音，强制）**：标出**须重读的关键词/字**（2–5 处为宜，与剧情信息点一致）——如「重读：确定、签字」「重读：条件、一个字」；重音须落在立场/筹码/关系/事实词，禁随机强调  
  - **`pause`（停顿，强制）**：标出**有意停顿位置与类型**——如「句首蓄力半拍」「报告—略停—你确定」「条件后长停」「换气后再开口」「吞咽后挤出」「破折号截断」「省略号拖长」；停顿须服务节奏与情绪，并与 `……`/`——`/`,` 等标点一致  
  - **成稿写法（inline 示例）**：`开口（voice_identity=领导型主治医师音，tone=冷峻，speed=慢，volume=压抑，rhythm=一字一顿、句尾下沉，stress=重读「报告」「确定」「签字」，pause=「……」前长停、逗号处略停，voice_type=对白）「……这份报告，你确定要签字？」`  
- **情绪标点（强制）**：先判情绪阶段与 `rhythm`/`pause`，再选标点；与 `tone`/`speed`/`volume`/`stress` 一致；服务口型与微表情切口。可用：`，` `。` `……` `——` `！` `？` `、` `「」/""`；策略类型：压抑型、爆发型、试探型、喜剧型、治愈型、紧张型；>20字拆句时每子句自带标点 + **各子句独立 `rhythm`/`stress`/`pause` 可微调**。  
- **声线人设参考（`voice_identity` 选型，须结合题材具体化，非穷举）**：
  | 类型 | 典型适用 | 节奏/重音/停顿倾向 |
  | :--- | :--- | :--- |
  | **领导/上位者** | 领导、上司、君王、将帅、严师 | 语速稳偏慢；重音落命令词/结论词；停顿短而有权威；句尾少上扬 |
  | **御姐音** | 成熟女性、姐姐型、冷艳御姐 | 中低音域感；从容不迫；重音克制；词间停顿干净；尾音略沉 |
  | **萝莉音/少女音** | 幼女、少女、软萌角色 | 偏高；字句短；重音轻；停顿短；语气软、尾音可上扬 |
  | **农家妇女/村妇** | 农妇、大妈、市井妇人 | 朴实口语；语速参差；生活词重读（「地里的」「娃」）；停顿随呼吸自然 |
  | **老者/长者** | 老人、祖母、前辈 | 气声略重；慢；顿挫分明；重音落经验/回忆词 |
  | **军人/警探** | 警察、士兵、硬汉 | 短句；硬朗；重音落动词/编号/事实；停顿如报告 |
  | **书生/学者** | 文人、教师、医生（文气型） | 吐字清；句读工整；偏慢；重音落术语/逻辑词 |
  | **反派/阴狠** | 反派、审讯者、阴柔权谋者 | 低缓；词间长停；关键词阴读；句尾拖或截 |
  | **市井/商贩** | 小贩、伙计、滑头 | 快；节奏灵活；重音落价格/数量；停顿少 |
  - **同一角色跨 Beat**：`voice_identity` 全剧稳定，仅 `tone`/`speed`/`rhythm`/`stress`/`pause` 随情绪与节拍变化；身份体系变化（换装/年龄态/受伤嘶哑等）须在【角色命名】或 Beat 内注明变体。  
- **禁止**：滥用标点；标点与 `tone`/`speed`/`rhythm`/`pause` 冲突；只写 `tone=冷峻` 而省略 `voice_identity`/`rhythm`/`stress`/`pause`；改数字/**已确立真实姓名**/关键事实词（占位称谓→具名替换见强约束§19，不属于「改人名」）。  
- **OS/V.O./旁白**：明确归属与听者；适用语气层全字段与同场反馈规则；OS/V.O. 亦须写 `voice_identity`。  
- **自白/独白全员闭嘴（强制）**：凡 Beat 含**自白**或**独白**，执行下列规则，缺任一项即 Beat 不合格：  
  - **类型判定**：**自白**=面向自我/镜头/空位/无在场听众的独白式陈述（可画内可 OS）；**独白**=内心 OS/V.O./心理旁白/画外心声（通常 OS/V.O.，听众不在场或不可闻）。原文「独白」「自白」「内心」「心声」「OS」「V.O.」「旁白（角色心理）」等须归入本类并标注 `voice_type`。  
  - **全员闭嘴（强制）**：Beat 正文**仅列画内可见**具名角色与群演簇；**画外/OS·V.O. 声源不在画内时，发言人不在画内角色段落列名**。画内每一个可见具名角色与群演簇均须写**闭嘴**（双唇紧闭/口型静止/未张嘴/唇线抿合），**画内自白**发言人除外；可写眼神/呼吸/肢体微反应，**禁止**画内他人写口型变化、接话、同步张嘴。  
  - **发言人口型**：**画内自白**→发言人可写口型，**写入同期角色段落**；**OS/V.O./画外声**→发言人**不在画内角色段落列名**，声源与台词 inline 标注画外。  
  - **核销位置**：Beat 正文 inline 标注 `voice_type=自白|独白`；画内逐人/逐簇写闭嘴（画内自白发言人除外），禁止用「众人沉默」概括而不逐主体核销；**禁止**在画内角色段落写画外人物。  
  - ❌ 林医生独白 OS「我……没病。」｜Beat 正文写林医生闭嘴、或只写陈医生反应未写闭嘴｜✅ **Beat 3**：林医生（voice_type=独白，OS，画外声）「我……没病。」——同期**陈医生** **双唇紧闭**，眉弓渐蹙；**办公人员簇** **全员双唇紧闭、口型静止**（**不含画外林医生**）。  
- **主听众（强制）**：每轮标最主要听众及依据（`叙事目标相关度 > 视线直指 > 空间距离 > 因果承接`）；默认禁止并列，证据等强才写“并列：原因”。听众反应含动态微表情+微动作各≥1。  
- **心理外化**：转译为可拍微表情+微动作+道具接触+空间反馈；禁抽象情绪词（执行见强约束§5/§7）。  
- **环境补充**：须**因剧本而生、为剧本而用**（§10）；仅服务剧情与动作逻辑；禁脱离剧本的装饰性环境扩写；禁在四向拓扑包络外扩张空间（§11）；禁新增改变因果的实体/事件。  
- **输出**：Beat 正文 inline 写成稿台词 + **语气层全字段**；第一部分写【对白语气与节奏】策略、典型 `voice_identity`/`rhythm`/`stress`/`pause` 落点。

### 五、角色表情与题材适配
- **先判表情强度**：`夸张型`（喜剧/轻喜剧/日常搞笑/闹剧/反差萌）| `细腻型`（情感/爱情/治愈/亲情/现实主义细腻/文艺）| `标准型`（悬疑/剧情/职场/犯罪等）；混合段按节拍切换。  
- **微表情选材**：优先从 §一「微表情常见项」择项组合；喜剧/夸张型场叠加 §一「喜剧类微表情常见项」；须写清部位与动态过程链，禁抽象情绪词。  
- **夸张型**：眉眼幅度大、嘴型明确、多肌肉组联动；反应可适度漫画感但真人可拍；肢体与表情同步夸张；包袱/误会/反转须补夸张表情切口，**优先用喜剧类微表情常见项**（挑眉飞挑、瞪眼、瘪嘴、憋笑抽搐、O 型嘴、斜眼睨视等）并写多部位联动过程链。  
- **细腻型**：写具体微动与渐变链（`前置克制 → 中段裂缝 → 落点余韵`）；强情绪也克制幅度。  
- **标准型**：清晰可读，在夸张与细腻间取中值。  
- **文戏特写增量**：每文戏 Scene 主角局部特写≥3（含强约束§5 的每场至少 1 处细节特写）；长对白每 2-3 句至少 1 处微表情+微动作组合。

### 六、影视化手法
- 可选标签：`MONTAGE`、`AV_CONTRAST`、`PROP_SYMBOL`、`MACRO_INTRO`、`CROSS_CUT`、`MATCH_CUT`、`POV`、`OFFSCREEN`、`JUMP_CUT`、`DOLLY_ZOOM`、`EMPTY_SHOT`。  
- 原则：只服务剧情推进/情绪外化/转场连贯，禁装饰性滥用。

### 七、文戏/武戏差异化
- 先判类型：对白情绪主导=文戏；打斗追逐术法主导=武戏；混合段按节拍切换。  
- **正式决战(§27)**：`正式决战=是` → ≥10 Beat → 【决战 Beat 规划】  
- **宏观群体(§28)**：`宏观群体=是` → ≥6 Beat → 【宏观 Beat 规划】；高潮三要素齐  
- **文戏模板**：`触发（台词/动作/停顿） → **观察视角（谁从哪看、看哪）** → 主角局部特写（部位+动态变化，须与当前视角/环境一致） → 下一承接`。  
- **武戏强制（细则 §二「武戏视角—环境—朝向」+ 文首 Beat 核验①-c）**：方向链+美感动作；近身/投射均须完整攻击链（§二）；术法→六相链(§三-B)；快链合并见 §二；Beat 间位移闭环；**逐 Beat** 观察侧+背景 变化+朝向四要素+入境出画+ENV 切换/建置重建，禁止主环境错配。
- **武戏模板**：**观察视角声明**→ **环境/ENV 切换**→ **前景/中景/背景 背景层**→ **双人/多人落位与朝向四要素**→ 起势→**（快链：子动作1→子动作2→…）**→**位移/换侧**→发力→换招/腾空→接触反馈→**终态落位**→特效→收势（三轴+前景/中景/背景；每段须可核对相对上一 Beat 的**视角/背景/朝向/落位 Delta**；快链合并时链内各招仍须分节点）。
- **正式决战模板（≥10 Beat，§27）**：对峙(1–2)｜试探(1–2)｜攻防≥4(换招/格挡/闪避/反击,含≥1轻功/空域；**阶段内快链可合并**)｜术法域场(1–2)｜逆转受伤(1–2)｜决胜(1–2)｜收势(1)；**Scene 级**禁概括，须扩写≥10 Beat。
- **宏观群体模板（≥6 Beat，§28）**：建置(1–2,**全景** Drone/EWS,无边+阵势+**主要角色阵中锚**)｜细节(1,**全景+特写交替**+军械描绘+自然参差)｜推进(1–2,Tracking/低角**全景**+马蹄/尘浪/盾墙**特写**)｜焦点(1,Scale Contrast+指挥/主角**特写**,**含切换过渡**)｜高潮(1,**全景**对冲+冲击/命中**特写**,三要素齐)｜余波(1)；禁「大军开到/一触即发」/整场无特写/整场只见群演不见主要角色。

## 输出模板与格式

### 第一部分：剧本改编补充说明
极简标签输出，只写结论；**用自然语言短句**覆盖各检查项，禁止粘贴键值模板；无改动项写“无：原因”。
- **【继承】**：剧情/动作/对白/OS/V.O./心理/环境/原文点出表演层：继承|扩写|改写|细分；未下放。  
- **【剧情叙事连贯】（强制，§2）**：逐 Scene 列「谁—欲何—阻何—已知—将变」落点；跨 Beat/Scene 情节桥梁与（若需）信息补偿是否完整；首/末 Beat 是否回扣上场、写清本场推进。
- **【角色命名】（强制，§19）**：占位名→具名对照表（原文称呼 → 保留/新取姓名 → 依据 → **身份角色说明**：基础身份 + **`voice_identity` 声线人设** + 默认语气倾向，供下游配音/TTS）；成稿是否已无「男主/女主/反派/龙套甲」等泛指；主要角色全剧称呼与 `voice_identity` 一致、跨场不矛盾。
- **【项目考据】**：时代/地理/历史/文化/人文/民俗/礼仪：已核对|缺失；本次约束及影响项。  
- **【风格】**：`Global_Style` / `borrowed_films` / `borrowed_films_note` / `tone` / `lighting` / `color_spectrum`（文学级光影与**参考片推导的冷暖色谱方向**；大光比/四层色谱/色温 K 值归 Stage 3）。  
- **【结构】**：发展重点段；高潮重点段。  
- **【借鉴】**：落点；触发；升级；回收；未用写替代。  
- **【场景开场节奏】**：逐 Scene 首节拍三步（吸睛/建置/入戏）落点；长对白拆分。场间切换细节并入【场景切换与首节拍转场】。  
- **【表情策略】**：夸张型|细腻型|标准型；依据与落点示例；喜剧场是否启用「喜剧类微表情常见项」及典型组合（如挑眉+咧嘴、憋笑+斜眼）。  
- **【微表情微动作】**：原文点出项核销清单（原文→Beat→动态改写）；逐 Beat 动态过程与**跨 Beat 承接**；**每个主动作/每句对白/每个听者反应是否均有配套微动作+微表情**（Beat 完整逻辑环节 5）；听众双轨；对白—反应—动作链连贯自检；禁抽象词与静态描述。  
- **【对白语气与节奏】（强制，§四）**：逐 Scene/典型 Beat 列 `voice_identity` 运用、策略类型（压抑/爆发/试探等）；**每条对白是否含 rhythm/stress/pause**；典型重音落点与停顿设计示例；与 tone/speed/volume/情绪标点一致性自检。  
- **【对白拆句自检】**：逐 Scene 列【对白拆句判定】结论（已拆句|未拆句|无对白）；已拆句场列拆句条数与典型原句→子句对照；未拆句/无对白场列原因；与 Beat 正文 inline 对白一致性自检。  
- **【细节特写】**：逐 Scene≥1 处；对象/部位/变化/功能/Beat；**原文对道具的特别描述是否均已映射为道具特写落点**（材质/工艺/磨损/铭文/显示内容/状态变化等）；文戏/武戏落点差异；与§5/§6/§7 一致性自检。  
- **【文武戏策略】**：文/武判定；决战场列表(≥10 Beat+阶段)｜宏观场列表(≥6 Beat+三要素+**全景特写组合**)｜§七-B/C/D选用；缺口标「决战/宏观 Beat 缺口」。

### 第三部分：Project Visual Backfill
放在最终输出末尾；仅输出一个独立 JSON 代码块；不得附加解释文本。除既有视觉字段外，须额外输出：

**Stage 1 边界**：`project_visual_backfill` **须含** `color_spectrum`（基于 `borrowed_films` 的文学级主冷暖方向四选一 + 参考片色谱依据 + 可选 1–2 组主辅色倾向）；**不含** `color_palette`、Key:Fill、色温 K 值、四层色谱、大光比技术细则——上述均在 **Stage 3**（`entity_design_common.md` §1.5）由资产设计环节根据 `Global_Style` / `tone` / `lighting` / **`color_spectrum`** / `Genre` / `Base Positioning` **本阶段推导并落实**。

**`color_spectrum` 推导规则（Mandatory）**：
1. **先读 `borrowed_films`**：从每部参考片提取其典型色谱气质（如《小森林》暖蜜自然光、《真探》S1 冷青褐 noir、《银翼杀手2049》冷蓝+暖橙 Practical、《海街日记》同温低饱和治愈）。
2. **四选一主方向**（句首或句中须显式写出）：`冷调主导`｜`暖调主导`｜`冷暖对比`｜`同温层次`；须与 `tone`、`lighting`、`Global_Style` 同体系，不得冲突。
3. **参考片绑定（强制）**：须点名 ≥1 部 `borrowed_films` 条目并写清「借什么色谱做法」；与 `borrowed_films_note` 分工——note 写综合视听对标，spectrum 专写冷暖色谱方向。
