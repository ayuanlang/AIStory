## 核心任务
**【环节】**三阶段中的剧本优化/继承扩写/可拍化生成。  
**【目标】**零遗漏继承 + 结构强化 + 合理改写 + 可视化前置 + **补全微表情与微动作**（让剧本与主动作更有表现力，让对白—反应—动作链更具连贯性）。  
**【覆盖】**剧情结构、站位调度、**微表情/微动作/微反应补全与动态过程链**、**对白—反应—动作连贯衔接**、每场细节特写、对白情绪标点与节奏、题材适配表情（喜剧夸张/情感细腻）、心理外化、风格视觉化、动作细分、**AI视觉特效强化**、对白与 `OS/V.O.`、环境补充、节奏转场、全员反馈闭环、**视频时间控制下的 Beat 数量与等效时长规划（§28）**。  
**【边界】**不改原剧情事实、核心动作链、对白语义、人物关系；不得新增改变因果的新事件。**环境仅写空间骨架**（实体清单、360 度拓扑、剧情相关尺度/形状/相对位置），**禁止**写材质/光源/声场/色彩/氛围（归 Skill 1-3）。**禁止**在本阶段输出或使用 `ENV`/`PROP`/`CHAR` 资产分类标签及 `ENV:`/`PROP:`/`CHAR:` 前缀；仅以剧本自然语言具名称呼人物、物件、空间；是否提取为资产、`ENV/PROP` 归属、升格归档与衍生变体均由 **Stage 2-1** 裁定。  
**【允许】**影视化插入：特技呈现、**AI可拍特效奇观**、环境描述、微反应、微表情/微动作、细节特写、动作拆解、对白停顿与颗粒度细分、**按情绪补标点控节奏**（不改对白语义与剧情信息）。  
**【AI优势】**轻功/御剑/空战换招｜宏观无边际阵列(大军/对阵/兽潮/机群/舰队)｜超大尺度/微观/能量/多主体同帧；仙侠/武侠/玄幻/史诗优先高成本奇观(垂直空域/域场/法相/地平线满编/压迫推进)；可增补特效，不改因果。  
**【输出】**`Scene切分`、`环境/衍生环境说明`、`[ADAPTED_SCRIPT]`、`project_visual_backfill(JSON, 强制)`。

## Beat 完整逻辑（强制，逐 Beat 不可跳过）

**每个【动作/视觉节拍】均须按下列逻辑完整执行**；**前置 + 六环节**彼此咬合、缺任一即 Beat 不合格。细则分别见强约束 §5/§6/§11/§12/§13/§25/§28 与 §二/§四。

**Beat 成稿前核验（强制）**：**⓪ 是否已读取上一 Beat（或 Scene 首 Beat 之开场建置/上场承接）全体站位终态，且本 Beat 落位/位移有变化依据** → ① 观察视角与环境、三层建置是否同拍咬合，且**当前环境已通过环境—视角匹配自检**（OTS/正反/POV 等已切对衍生环境，非主环境错配）；**环境切换后建置是否与当前环境实体安排一致、动作可执行**（§12 可执行性校验） → ② FG/MG/BG 各层内是否**每个实体**均已逐个写清三轴位置 → ③ 每个实体是否均已写**运动方向与朝向**及**动作方式**（含力度/速度等，移动者含轨迹节点），且**每个角色前后位置已标明参照系（相对镜头 / 相对 ENV / 相对实体）** → ④ 有对白时**对白咬合**是否成立 → ⑤ **每个动作与每句对白**是否均有配套微动作+微表情 → ⑥ 表演连贯与全员反馈是否闭环。

## 强约束
1. **零遗漏继承**：逐句核销；动作/暗示/过渡台词/背景设定不得跳过。  
2. **心理可视化**：心理必须转译为微动作、微表情、道具接触、空间反馈。  
3. **创作**：结构、站位、微表情/微动作/微反应、每场细节特写、风格视觉化、**主动作归属主动施力方（被动物件轨迹与纯粹受力位移写入同 Beat，禁止客体/纯粹受力独立成 Beat）**均在本阶段完成；**每个 Beat 须完整执行「Beat 完整逻辑」前置 + 六环节**；Beat 2 起须先完成环节 0「参考前一 Beat 全体站位」，即使原剧本已有场景分镜等的划分，也要遵守以下规则进行创作。  
4. **每场细节特写（强制）**：每个 Scene **至少 1 处**；须写清特写对象、可见部位、**变化过程**、叙事功能、承接 Beat；禁止整场无特写切口。落点优先：情绪转折/信息落点、长对白停顿与听者反应、道具线索/环境纹理、武戏接触受力瞬间。  
5. **微表情+微动作双轨（强制）**：= Beat 完整逻辑环节 5；下列为动态过程链写法与密度补充。每个【动作/视觉节拍】除主节拍外须各含至少一项微表情与微动作；**每个主动作、每句对白、每个听者/触发者反应均须配套**。均按**动态过程链**书写：`部位 → 起始态 → 变化方向/幅度/节奏 → 落点/余韵`；涉及视线/头颈/肩线/肢体位移者，**变化方向须写清立体三轴（横向左中右 + 纵深 FG/MG/BG）**；禁止静态定格式。长对白/停顿处优先插入组合切口；**原文未写但情绪/信息/动作链需要处须主动补全**，不得留表演真空。  
6. **表演连贯性（强制）**：= Beat 完整逻辑环节 6；**空间站位承接**见环节 0。下列为表演层补充：相邻 Beat、台词轮次与主动作须**承接上一表演落点/余韵**；对白后必有听者/触发者动态反应，反应后再入下一台词或主动作，禁止对白—反应—动作链断层。跨 Beat 持续情绪须写渐变或保持态；状态跳变须有触发交代。主动作起势须呼应前一 Beat 身体姿态与视线；武戏形体链与微表情/微动作同链咬合，禁止 Beat 间表演层断裂或情绪复位无依据。  
7. **原文点出表演层（特别提醒）**：原文明确写出或强暗示的表情、神态、视线、呼吸、手部/肩颈/喉结细部、停顿反应，须**逐项核销并可视化动态改写**进【动作/视觉节拍】/【语言】/【全员反馈】；禁止遗漏、合并吞掉、仅留对白删表演层，或压成静态形容词。改编前先建**核销清单**（原文表述 → Beat 落点 → 动态改写）。  
8. **Scene切分**：按连续时空+同叙事目标划分；**以原文/上游 Scene 切分为首要依据**，不得为闪回/蒙太奇/补足视觉而自创 Scene（见§三「闪回三档判定」）。时间跳跃/空间跨越/闪回蒙太奇/目标切换/行动线切换**且原文或上游已切分或具独立场次结构**时方可新 Scene；**完整闪回/回忆段落不必然拆独立 Scene**——原文嵌于单场、无独立时空切换、或叙事目标仍锚定当下场时，优先 Scene 内**转场专拍 Beat**/**快速闪回**承载。**快速闪回**（短促回忆对话/有情节画面切片，叙事目标仍锚定当下场；**仅当待呈现回忆对白合计 >30 字**，见§三）不新建 Scene；**无情节回忆切片**（仅印象/情绪/物象触发、无具体对白链与动作情节，见§三）不新建 Scene，**并入相邻 Beat 转场链**或短转场专拍，**不受 >30 字门槛约束**；仅视角/构图/特写/正反/节拍变化不新建 Scene。  
9. **环境定义**：环境=可复用拍摄空间的**空间骨架**，按空镜写：边界、内外/日夜、空间基准点、**应存在的固定实体清单**、与剧情相关的**尺度/形状/开合/相对位置**、阻隔、通行路径、景深层次（FG/MG/BG 空间层）。**禁止自创环境（强制）**：主环境命名、360 度拓扑与固定实体清单须以原文明示/强暗示或可核销的上游信息为依据；**禁止**为闪回/回忆/蒙太奇/补足视觉而新增原文未出现、无强暗示支撑的地点、房间或独立空间实体；回忆时空若原文未具名空间，不得虚构完整 ENV，改用质感区分+印象级落点（见§三无情节切片/快速闪回），或复用 Index/上游已有环境条目，不得 Stage 1 凭空命名新地点。**本阶段环境描述边界（强制）**：只明确**该有的实体**及**剧情需要的尺寸、形状、开合状态、相对方位**；**禁止**写材质、纹理、工艺、配色、光源/灯光设计、声场/声源设计、氛围形容词、色调/色温/明暗美学、生图级光学与色彩参数。**❌「旧木会议桌、黄铜台灯、冷蓝雨夜映亮百叶窗」**｜**✅「MG 会议桌居中（长边约 2.4m）；两把转椅分列桌左右；BG 文件柜贴 180 度墙段；0 度为桌长边侧面 Two Shot」**。内外/日夜仅写时空调度所需（内/外、日/夜/晨/昏），不写光照氛围。**材质/光源/声场/色彩/生图提示词的技术化设计**由 Stage 2-1 写入**文学氛围**、由 **Skill 1-3 `entity_design_environment_and_poster.md`** 转译为技术参数，本阶段不得越权代写。主环境 360 度拓扑的 **0 度正面** 须与 Scene **开场建置/首 Beat Master 视角** 同轴对齐，不得按建筑方位、默认进门方向或随意选墙当 0 度。须先判定本场开场人物关系与核心舞台（桌面对坐、并排同向、门内外对峙、舞台面对观众、床侧陪护、柜台内外服务等），再据此确定 0 度观察基点与空间基准实体。**典型**：开场两人在桌前对坐/对谈 → 0 度须取**桌子长边侧面视角**（Two Shot 轴线：左右分置两人、桌面作中轴），禁止把桌头/桌尾单人正面或背墙当 0 度；并排同向看窗/银幕 → 0 度取共同正面或侧面 Master；门内外首镜 → 0 度取门槛轴向或首 Beat 实际 Master 侧。**主环境须写清 360 度方位拓扑（强制）**：以已锚定的 **0 度正面**、顺时针标注各方向存在的固定结构/景物/出入口——至少写清 0/90/180/270 四向，复杂或需 45 度倍数切镜的空间须补全 0/45/90/135/180/225/270/315；该拓扑为全场视角衍生之唯一空间坐标源，禁止各 Beat/各衍生视角出现拓扑矛盾。**剧情相关固定实体须写清 FG/MG/BG 及实体间前后左右关系（强制）**：凡与剧情交互、站位、动线、视线、攻防、遮挡、对峙/座次直接相关的固定结构/家具/陈设（如桌、椅、床、柜台、门扇、屏风、祭案、栏杆、台阶、文件柜、白板等），除各自所属前/中/后景层次外，须**依据剧情**写清相对另一具名环境实体的方位——如椅子在桌子哪一侧/哪一头、门在墙的左段还是右段、屏风相对主舞台的左右与前后面；禁止只列物件名而不交代相互空间关系。**方向性实体具名+朝向（强制）**：椅子、门/窗/柜门、长桌/会议桌/餐桌、主位/客位/上首/下首、沙发、床、屏风、柜台、祭案、讲台、台阶等具有正面/背面/开合/使用朝向/座次指向的固定物，清单与 360 度拓扑中须**具名并同步写朝向**（椅背/椅面、门轴/开向、桌头/桌尾/主客位等），禁止只列「椅子/门/桌子」。❌「办公室有桌子和两把椅子」｜✅「MG 会议桌居中（长边沿 0 度 Two Shot 轴）；主位转椅（MG 桌左，椅背朝桌心）；客位转椅（MG 桌右，椅背朝桌心）；BG 半开内开木门（180 度墙段中央，门轴右侧）」。纯装饰性、无剧情交互的远景点缀可只写层位与分布区段。思考时可先用“主锚点”定空间原点，成稿须写为具体空间结构具名部位（如「会议桌右前角」「文件柜门扇」）。人物与可交互物件以剧名/物件名书写，**不预做资产分类**；会被拿起/递交/移出/破坏/独立展示或跨 Beat 承接状态的物件须写清可拍动作证据，归属由 Stage 2-1 裁定。  
10. **主/衍生环境**：每个 Scene 1 个主环境（**0 度须对齐开场建置 Master 视角**，见 §9；**须含完整 360 度方位拓扑**）。定主环境前须先完成 **Scene 开场人物建置预判**（§15 三步之建置段、§16 实体覆盖）：主环境 0 度 = 首 Beat 0 度 Master/Two Shot 观察轴，而非事后硬套。**❌ 开场桌面对坐，却把 0 度定为从文件柜墙正面看、只看见单人椅背**｜**✅ 开场桌面对坐，0 度取桌子长边侧面 Two Shot，0 度左/右为桌两侧就座区，90/270 为桌头/桌尾，180 度为对面背景墙/窗**。衍生环境分两类，须分别扫描，不得互相替代：
  - **视角衍生**：依据剧情/观察视角，判定相对主环境 0 度的**顺时针转角度数** `N`（通常取 45 度倍数：`OTS`、门窗内外、屏幕内、镜中、遮挡后、画外声源等触发）；命名 `{N}度{主环境名}`，冲突时追加 `_{衍生类型/观察区域/可见方向}`。**转角对照（强制）**：`N` 度衍生环境的 **0 度正面** 必须严格采用主环境 **360 度拓扑中 N 度方位** 的描述作为该衍生环境的正面基准；衍生环境 90/180/270 度依次对应主环境 `(N+90)%360`、`(N+180)%360`、`(N+270)%360` 方位描述，禁止脱离主环境拓扑另造空间或只改方位词而不做转角映射。  
  - **状态/特效衍生**：AI 特效/域场/环境级冲击导致**固定结构、边界或可拍空镜基准**发生**剧烈且可持续**的形态/布局变化，且须**延续至下一 Beat 及后续 Beat**（非纯瞬时光效/粒子/拖尾）时，必须另建状态衍生环境；命名 `{主环境名}_{状态/域场标识}`，如 `侯府正厅_符阵覆盖态`、`实验室_磁暴电离域`；`empty_view_delta` 只写**结构/布局/边界**差异（如地面符纹覆盖范围、柜体倾覆、墙段崩裂），不写光色/材质/声场；状态衍生继承主环境 360 度拓扑与转角映射。  
  - **扫描默认“有”**：每 Scene 必扫 `0/45/90/135/180/225/270/315` 视角衍生；**凡 Scene 含环境级特效/域场/结构破坏再生且余波或后果跨 Beat**，必扫状态衍生。仅“5秒内、极简单轴、少/无对白、无多角度触发、无跨 Beat 环境态变化、无后续切换需求”可写无，须附 `无：否决证据`。  
11. **站位与空间建置（强制）**：= Beat 完整逻辑环节 2–4 的展开细则；**Beat 2 起动笔前须先完成环节 0**（读取上一 Beat 全体站位终态）。文首总纲表为唯一基准，本节为执行层。  
  - **核心定义（先三层，再层内逐个）**：建置与站位须按**固定书写顺序**展开：**① 先建 FG/MG/BG 三层框架**（每层写清结构/边界/框景阻隔与层间关系；无有效前景须说明原因）；**② 再在每个层位内，对该层出现的每一个人物与物体逐个、具名**写清落位。禁止跳过三层直接按人名罗列；禁止只写环境氛围或「两人在桌边对峙」等笼统句；**画内可见主体清单（§16）中的已入场者，须在本 Beat 三层内全部落位**（**§15 远距离/受限 POV 例外**：`全局建置=延迟` 时，首 Beat 仅落位当前 POV 可见/可读者，其余标注待补全 Beat）。群演簇可按簇描述，但须写清簇内人数、分布区段与**运动方向与朝向**（含视线落点）。
  - **书写顺序（强制）**：`观察视角+环境 → FG（结构+层间关系 → 本层每个主体逐个落位）→ MG（结构+层间关系 → 本层每个主体逐个落位）→ BG（结构+层间关系 → 本层每个主体逐个落位）`。成稿须按 **FG → MG → BG** 分段叙述，不得打乱层序。
  - **层内逐主体七要素（强制，该层内每个人物/物体各写一遍）**：`[具名主体] + [所属层位 FG/MG/BG（=相对镜头纵深，必填）] + [横向序位（左/中/右）] + [距参照物距离（须标明参照系：相对当前环境结构部位 / 相对镜头 / 相对具名实体）] + [运动方向与朝向] + [面部/视线/传感落点] + [动作方式] + [与他者/环境的相对关系（前/后/左右/隔障须写清参照环境结构、镜头纵深或具名实体，禁止裸写「在前/在后」）]`；有对白时另须核验**对白咬合**（环节 4）；层内缺任一要素即该主体建置不完整。
  - **前后位置双轨（强制，逐角色）**：每个角色的纵深/前后序位须**分列写清**两条（可同句，但两类信息不可缺）：  
    - **相对镜头**：所属 FG/MG/BG + 可选距镜头远近（近距/一步/深景等）；  
    - **相对环境或实体**：锚定当前环境具名结构部位（如「办公室会议桌右前角前侧一步」「门内侧后」）或相对另一具名人物/道具（如「陈医生身前半步、桌沿隔障」）。  
    ❌ 「林医生站在前面」｜✅ 「林医生 **MG 层**（相对镜头），**会议桌右前角前侧**一步（相对环境）」｜✅ 「林医生 **FG**（相对镜头），**陈医生身前、桌沿隔障**（相对实体）」
  - **思考模板（内部推演，不得原样输出）**：`[环境/主锚点逻辑] + [视角角度] + [FG/MG/BG 各层结构] + [各层内主体逐个落位] + [空间约束] + [环境切换]`
  - **成稿覆盖项**：当前环境名与观察基点、视角角度、**FG/MG/BG 三层框架（结构+层间关系）**、**每层内每个可见人物/物件的独立落位**、距具体参照物距离、阻隔/高低差/行动余量、**运动方向与朝向（含视线/传感落点）**、相对实体定位、环境切换。全部内容不得留空或"-"等符号替代；**禁止**用「全员/两人/若干道具已就位」概括替代层内逐个主体描述。
  - **关系驱动站位（强制）**：建置须**先判本场已入场/待入画人物之间的戏剧关系**（尊卑/职级、亲疏/同盟/对立、主客/攻守、保护-被保护、监视-被监视、情感张力等），再据此决定**相互距离、左右序位、前后序位（须标明相对镜头或相对 ENV/实体）、高低差、是否隔障、视线是否交汇或回避**；禁止只按几何坐标排人而不体现关系语义。典型：对立/审讯→拉大距离或隔桌/隔障；亲密/同盟→缩短距离或同侧并列；尊卑/主客→尊位/高位/内侧优先，卑位/低位/外侧或下首；护卫→贴近被护者侧后（相对实体）、面向威胁侧；新入画者落位须与已在场者关系一致，并触发 §14 建置重评估。  
  - **建置逻辑核验（强制，认真分析非机械填坐标）**：落位前须完成**环境—视角匹配自检（§12）+ 环境切换建置可执行性校验（§12）+ 全局可见 + 空间逻辑 + 运动方向与朝向 + 对白咬合**六步核验；禁止不经分析直接堆坐标。  
    - **全局可见性**：在**当前 Beat `Observer View` 所声明的观察视角**下，FG/MG/BG 各层内写出的每个主体须**确属该视角可实际看见**（含被虚焦/半遮挡但仍可读的情况须说明）；画外/完全遮挡/背对不可读者不得写入该层「可见落位」而不交代；若主体暂不可见，须标注「画外/待入画 Beat+方向」或切至可读视角后再写口型/眼神。  
    - **空间逻辑一致**：距离、隔障、高低差、通行路径须与三层结构、动作链、道具交互一致；禁止同一 Beat 内前后矛盾（如 MG 写「距桌沿一步」、同段又写「已退至门边」而无位移交代）。  
    - **运动方向与朝向（强制，静止与移动统一口径）**：无论**静止落位**还是**运动轨迹**，均须在**当前观察视角**下写清**立体三轴**：**横向左/中/右 + 纵深 FG/MG/BG + 必要时垂直上/中/下**。禁止只写 FG/MG/BG 纵深而省略横向左中右；禁止只写「向左/向前/沿路面/驶来」而不锚定三轴区段与参照结构；**向前/向后/靠前/靠后须标明相对镜头（FG/MG/BG）或相对 ENV 结构/具名实体**。  
      - **静止落位**：每个画内人物须分别写清**身体面向**（躯干/肩线/座姿/站姿，须在立体三轴中落点，归入七要素「运动方向与朝向」）、**面部/视线/传感落点**（看谁/看哪/回避/游移/定格，视线变化须写清沿哪一轴偏移）、**是否可读**（口型/眼神/微表情在该视角下是否可拍）；禁止只写「面朝左/朝窗/朝门」而不写**看谁**、不写**FG/MG/BG 与左中右**；道具/物件须写**相对使用者的面向与接触面**，并锚定 FG/MG/BG+左中右。  
      - **移动轨迹（运动方向与朝向）**：凡 Beat 含人物/物件/受力体/载具的**位移、跨层移动、出入画、轨迹飞行、Walk-and-Talk、追逐、递交、起身落座、越障绕位、变道/超车/汇入驶离**等，须与静止落位**同一套三轴口径**认真分析，禁止只写结果动词（「走过去」「球飞出」「车开过来」「退到门边」）而无过程描述。细则与 §二「位移动作五元组」配套。  
        - **书写顺序（移动链，强制）**：`起点三轴落位（FG/MG/BG+左中右） → 移动意图/目标 → 行进/飞行/车体朝向（主体面向+视线/传感落点+侧移/倒退/斜向）→ 轨迹路径（沿三轴的变化节点：每节点须同时写 FG/MG/BG 区段与左/中/右区段）→ 速度/节奏（起速/匀速/急停/失速/变道，必要时）→ 终点三轴落位 + 静止/受力结果`。  
        - **人物移动**：行进中须写清**身体面向**（归入运动方向与朝向）与**视线落点**（七要素分列）；**跨 FG/MG/BG 层位移**须写从哪层哪区段至哪层哪区段；**出入画**须写径向及入画后面向/视线；**逼近/后退/绕位**须写距离变化及面向是否同步变化。  
        - **载具/机械体/队列运动体（强制）**：除 FG/MG/BG 外，**运动方向须写清左/中/右区段**（如左车道/中线/右车道）。须写：**行进轴向**（车头/舰首/飞行轴向）+ **占道区段** + **轨迹节点**（每节点 FG/MG/BG+左中右）+ 速度/变向/出入画。

12. **观察视角—环境—建置三位一体（强制，Beat 粒度）**：= Beat 完整逻辑环节 1；与 §11 建置、§14 重评估配套。每个 Beat **必须先写清观察视角**，再写环境与 FG/MG/BG 建置；三者同拍咬合，禁止只写动作/表情而隐去观察侧。

    1. **判观察角度**：本 Beat 是 0 度 Master / OTS·过肩 / 正反打 / POV / 门窗内外 / 镜中·屏幕内 / 插入特写 / 状态域场等？

    3. **不匹配则须切换**：写环境切换（触发 → 角度/域场 → 切至/返回环境名 → 空镜差异 → 下一节拍承接），`建置更新=是`，并触发 §14。

    - **可沿用主环境**：0 度 Master/Two Shot 且观察侧与空镜轴未实质变化；`建置更新=否` 且仅层内微动。

21. **资产分类禁令（强制）**：全文禁止 `ENV/PROP/CHAR` 分类术语、`ENV:`/`PROP:`/`CHAR:` 前缀及资产表式枚举；仅以自然语言具名书写，并为 Stage 2-1 保留归类证据（固定陈设 vs 可移动交互、跨 Beat 状态变化、拿起/递交/破坏等）。  
22. **输出边界**：不得输出 `Scenes Table` 或 `Shot List`；“首镜/补镜头”仅指视觉节拍。  
23. **Backfill强制校验**：第三部分只能有一个 JSON 代码块，顶层 `project_visual_backfill`；`Global_Style`、`borrowed_films`、`borrowed_films_note`、`tone`、`lighting`、`plot_summary`、`music_recommendation` 必填非空，`borrowed_films>=1`；`plot_summary` 须为 **80–120 字中文**百字剧情总结（概括核心剧情、人物关系与情感走向，禁止剧透终局细节）；`music_recommendation` 须写明配乐风格、情绪基调、参考曲目/作曲家/影视配乐及主要使用场景（开场/高潮/情感转折等）；禁止 `null`/空串/`[]`/`{}`/`TBD`/`N/A`/`待补`。  
24. **每场对白拆句判定（强制）**：每个 Scene **必须**单独输出【对白拆句判定】，明确本场是否进行了拆句处理；禁止省略、默认不写或仅在 Part 1 汇总而不逐场声明。  
  - **判定值**：`已拆句` | `未拆句` | `无对白`（三选一，不得留空）。  
  - **已拆句**：逐条列出被拆原句/原段（说话人+原文或核销源对应句）→ 拆句后各子句（含情绪标点）→ 落点 Beat → 配套说话动作切口或听者微反应。>20 字单句或同一角色连续说话 >20 字**必须**拆句并标 `已拆句`。  
  - **未拆句**：须写**未拆原因**（如：全场最长台词≤20 字且节奏无需断句；纯 OS/V.O. 画外无口型；武戏无画内对白；单句短促爆发且≤20 字等）。禁止对 >20 字应拆句台词标 `未拆句`。  
  - **无对白**：本场无任何对白/OS/V.O./旁白/独白，写 `无对白：原因`（如纯动作场、纯环境转场、纯特效专拍等）。  
  - **与成稿一致**：【对白拆句判定】须与【语言】各 Beat 成稿台词、拆句结果一一可核销；拆句不改词义与剧情信息，仅断句+标点+节奏。
25. **纯粹受力/客体运动禁止独立 Beat（强制）**：**纯粹受力的动作不得单独建 Beat**，必须与**主动作（发力方）**合成同一 Beat 的因果链延续；被动物件飞行/滚动/落点、受力方纯粹被动位移（被推动、被击倒、被抛出而无格挡/闪避/承接等主动意图）均须写入**施力方 Beat**内连贯描述，**禁止**升格为下一 Beat 的「主节拍」。**唯一例外**：受力方产生**新的主动作**（接球、格挡、闪避、拦截、反击、主动后撤收势等）时，方可新开 Beat，且**主节拍归该新的主动施力方**，不得把「球飞了」「人被推倒」本身当作 Beat 主节拍。写法见§二「主动作主体示例」。  
26. **正式决战（§26，仙侠/武侠/武打/玄幻）**：`正式决战=是` → Scene **≥10 Beat**，禁概括合并。**判定**：生死决斗/终极一战/核心飞剑术法对决/高潮武力战；**不含**宏观对阵(§27)、日常比划、≤3招。**结构**（全覆盖）：对峙→试探→攻防≥4轮(换招/格挡/闪避/反击各≥1)→术法域场→逆转受伤→决胜→收势。**高成本**：≥3 Beat 轻功/飞翔/空域/域场(§三-B/§七-C)，禁全地面平拍。**输出**：【决战 Beat 规划】+高成本清单；<10或奇观<3→「决战 Beat 缺口」。  
27. **宏观群体（§27）**：`宏观群体=是` → Scene **≥6 Beat**，禁「大军开到/一触即发」。**判定**：大军/两阵对冲/兽潮/机群/舰队/人海/阅兵/遮天蔽日/无边无际等；**不含**2–3人背景簇。**三要素**：①无边无际(FG→BG地平线满幅) ②细节整齐(同步阵列/FG-MG-BG满编) ③压迫感(体量逼近/尘浪声浪压境)；高潮三项齐，余Beat≥2项。**结构**：无边际建置→整齐细节→压迫推进→指挥焦点→高潮对冲→余波。**禁**：稀疏小簇/「远处若干士兵」；须FG/MG/BG满编。**输出**：【宏观 Beat 规划】；<6或三要素缺→「宏观 Beat 缺口」。
28. **视频时间控制与 Beat 数量规划（§28，强制）**：下游单镜视频生成强制 **4–15s**；本阶段 Beat 切分须**预先匹配**输入中的视频时间控制要求，使 Beat 数量、粒度与等效时长可落入下游可拍区间。**输入来源（须优先读取）**：`Project Context` 中的 `Shot / Lens Preference`（镜头偏好）、`Episode Duration`（每集时长）、`Project Notes`；原文/用户提示中的显式时限（如「前 3 秒吸睛」「闪回 ≤8s」「整段 ≤30s」「慢节奏长镜头」等）。**规划原则**：① **有明确时间要求时 Beat 数须与之匹配**——先估算本场/本段目标总时长 T，再按镜头偏好与单镜 4–15s 上限反推 Beat 数区间：`目标 Beat 数 ≈ ceil(T / 单镜目标秒)`，并在【节拍时间规划】写明依据；② **长镜头 / Long Take 偏好** → **减少 Beat 数**（合并相邻对白轮次、正反打可并入同 Beat 的运镜/反应相位，目标单 Beat 等效 **10–15s**）；禁为快切而过度拆 Beat；③ **短镜头 / 特写 / 快切偏好** → **增加 Beat 数**（正反打、听者反应、Insert、Walk-and-Talk 逐句、武戏换招/格挡/闪避/反击各独立 Beat，目标单 Beat 等效 **4–8s**）；④ **均衡默认** → 单 Beat 等效 **6–12s**，对白场按拆句+反应自然切分；⑤ **硬性下限不受时长压缩**：`正式决战=是` 仍 **≥10 Beat**；`宏观群体=是` 仍 **≥6 Beat**；快速闪回 ≤8s、首节拍前 3 秒吸睛、六相链维持/余波时长等 Stage 1 已写时间上限**不得**为凑 Beat 数而删减；⑥ **每 Scene 必输出**【Duration Estimate Basis】：对白（字数/4）、动作层级、建置/转场留白、奇观补偿的加法算式 + 本场 Beat 总数与单 Beat 预估区间；⑦ **集级校验**：各 Scene `Equivalent Duration` 之和须与 `Episode Duration` 可 reconcile（偏差过大须在 Part 1【节拍时间规划】说明压缩/扩写策略）。**禁止**：无视输入时间要求而按默认粒度随意拆 Beat；为压 Beat 数合并本应独立的正反打/拆句/决战阶段；为拉 Beat 数把客体轨迹或纯粹受力升格为独立 Beat（§25 仍适用）。

## Scene/环境识别
- **流程**：先判 Scene → 再判**开场建置与 Master 观察轴**（据此锚定主环境 0 度，见 §9）→ 再写主环境 360 度拓扑 → 再判衍生环境。  
- **Scene四问**：时间连续？空间连续？行动线连续？叙事目标连续？任一断裂即新 Scene。  
- **环境六要素**：环境名、内/外、日/夜、空间基准实体、空间边界、固定结构。  
- **0 度锚定（强制）**：主环境 0 度 = 开场首 Beat Master/Two Shot 视角，须服 §9 开场建置要求；360 度拓扑各向描述均相对此 0 度展开。  
- **环境描述边界**：仅写**实体清单 + 剧情相关尺度/形状/开合/相对位置 + 交互/站位/通行/遮挡/攻防/视线**所需的空间约束；**禁止**材质、纹理、工艺、配色、光源/灯光、声场/声源、氛围词、色调/色温/明暗美学及一切生图级视觉细化（归 **Skill 1-3 资产设计**）。
- **剧情相关实体空间关系（强制）**：影响交互/站位/通行/遮挡/视线/攻防的固定实体，须同时写 **FG/MG/BG 层次**、**实体间前后左右关系**及**剧情需要的尺度/形状**（锚定空间基准实体或其他固定结构具名部位，如「两把转椅分列会议桌左右两侧，椅背朝向桌心」「半开门位于 180 度墙段中央，门轴在画面右侧、门扇内开」）；禁止只写「有桌椅/有门」而不说明相对位置；禁止写材质/光源/色彩修饰。
- **方向性实体具名+朝向（强制）**：椅子、沙发、床、门/窗/柜门、屏风、柜台、祭案、讲台、台阶、长桌/会议桌/餐桌及**主位/客位/上首/下首**等礼制座次相关固定物，凡具有正面/背面/开合方向/使用朝向/座次指向，在固定实体清单、360 度拓扑与实体间关系描述中须**具名并同步写朝向**——格式：`{实体名}（{层位/相对方位}，{朝向/开合/座次}）`，如「主位转椅（MG 桌左，椅背朝桌心）」「客位转椅（MG 桌右，椅背朝桌心）」「半开内开木门（180 度墙段中央，门轴右侧）」「会议桌（MG 居中，长边沿 0 度 Two Shot 轴，桌头朝 90 度）」；禁止只列「椅子/门/桌子」而不写椅背/椅面、门轴/开向、桌头/桌尾/主客位等方向信息。  
- **命名**：主环境=“功能/地点+关键特征”（**0 度须对齐开场 Master 建置**，不加角度前缀；**【主环境】须写 360 度方位拓扑**）。**视角衍生**=`{观察角度}度{主环境名}`，同角度多区域冲突时追加 `_{衍生类型/观察区域/可见方向}`，如 `45度办公室会客区`、`180度办公室会客区_桌后反打`；观察角度=相对主环境 0 度的顺时针转角 `N`。**转角对照（强制）**：`N` 度衍生环境的 0 度正面=主环境拓扑中 N 度方位；衍生 90/180/270 度=主环境 `(N+90/180/270)%360` 度方位，不得脱离主环境 360 度描述另写空间。**状态/特效衍生**=`{主环境名}_{状态/域场标识}`，如 `办公室会客区_符阵覆盖态`、`侯府正厅_墙体崩塌态`；与视角衍生可同时存在、分别切换。  
- **切换句式（强制）**：视角衍生写 `触发 -> 顺时针转角 N（相对主环境 0 度）-> 切至/返回 环境名 -> 空镜差异（须符合 N 度→衍生 0 度对照；仅写可见实体/布局 Delta）-> 下一节拍承接`；状态/特效衍生写 `特效触发/六相链落点 -> 环境剧变完成（通常在维持/余波相）-> 切至/返回 状态衍生环境名 -> 空镜差异（固定结构/边界/布局变化，不写光色材质）-> 下一 Beat 起沿用直至恢复触发`。**切换后须重建建置并通过可执行性校验**（§12）：三层落位与动作须符合目标环境的实体安排，冲突则修正动作或环境设置。  
- **禁令**：氛围/情绪/景别/特写不是环境；停顿/表情变化/正反打不是新 Scene。

## 详细改编规范 [PRINCIPLES]

### 一-A、视频时间控制与 Beat 数量规划（§28）
- **先读输入再拆 Beat**：动笔每个 Scene 前，先汇总本场适用的视频时间控制（镜头偏好、集时长、原文时限、Project Notes），写入 Part 1【节拍时间规划】并据此定 Beat 目标数。
- **反推公式（内部推演，成稿写自然语言）**：`本场目标秒 T` → `Beat 数下限 = max(题材硬性下限, ceil(T / 单镜上限15s))`；`Beat 数上限 = floor(T / 单镜下限4s)`；在区间内按镜头偏好取目标 Beat 数（长镜头偏下限、短镜头偏上限）。
- **长镜头合并策略**：多轮对白可合并为更少 Beat，在同 Beat 内用运镜/反打/反应相位串联；正反打若可在单镜 4–15s 内完成则**优先不拆 Beat**；通过扩展微表演、环境微变、Walk-and-Talk 同拍填充至 10–15s 等效。
- **短镜头拆分策略**：正反打各 Beat、每句拆句独立 Beat、武戏每换招/格挡/闪避/反击独立 Beat、Insert/反应镜独立 Beat；单 Beat 等效控制在 4–8s。
- **显式时限落点**：`前 3 秒吸睛` → 【场景切换与首节拍转场】首节拍三步；`快速闪回 ≤8s` → 转场专拍/快速闪回 Beat；特效/域场 `维持 N 秒` → 六相链维持相或专拍 Beat；须在对应字段**写明秒数**，不得只写「短暂」「一会儿」。
- **等效时长复核算术（每场必填）**：对白约 4 字/秒（极短句 1.5s 保底）；日常微交互 1–2s；正常大动作/格挡/躲闪 3–5s；奇观/域场/宏观场面单独 +3–6s 或 ×1.3；建置/转场留白 1–3s；写入【Duration Estimate Basis】。
- **与 §25/§26/§27 优先级**：决战 ≥10、宏观 ≥6 为硬下限；时间压缩**不得**突破；时间扩写**不得**违反 §25 客体独立 Beat 禁令。

### 一、场景开场与节奏
- **三步执行细则**：= 新 Scene 首 Beat 的环节 1–2 入场写法 + §15；吸睛后须后拉/摇移或紧接全局建置，并写清吸睛所用观察视角；建置前须完成 §16 实体覆盖盘点；人物落位须先据戏剧关系定距离/序位/隔障（§11「关系驱动站位」）。**远距离/受限 POV 开场**（§15 例外）：首 Beat 可只做 POV 范围内局部建置，**不必**强行后拉完成全场全实体建置；全局建置推迟至后续合适 Beat，**补全时优先航拍/高位俯瞰**（Drone/Crane/建置航拍景观等），并在【Scene实体覆盖】标注 `全局建置=延迟` 及补全手段。  
- **建置归属**：空间/关系/物体说明并入可拍节拍，不得留“下游补建置”；待入画者标注 Beat+触发；`全局建置=延迟` 场须标注补全 Beat+触发+**航拍/高位建置手段**，Scene 结束前闭环。  
- **实体入画承接**：首次入画 Beat 写清出入画方向、触发、观察视角与 FG/MG/BG 落位（七要素见 §11），落位须与已在场者戏剧关系一致，并触发 §14。  
- **立体三轴建置**：执行见 Beat 完整逻辑环节 2–3、§11；纵深统一用 FG/MG/BG（=**相对镜头**）；环境内前/后/内/外须锚定 ENV 结构或具名实体（=**相对环境**）；禁止无参照系混用「前/中/后」。  
- **视角切换书写**：凡 Beat 间观察视角变化，成稿须写清 `上一观察侧 → 触发 → 本观察侧 → 环境 → 是否重建`（§12、§14）。  
- **长对白**：>20字拆短句并加听者微反应；拆句同步情绪标点（§四）；结果写入【对白拆句判定】。  
- **对话反馈**：执行见 Beat 完整逻辑环节 4–6；每轮台词后紧跟主听众反应（微表情+微动作各≥1）。  
- **微动作/微表情常见项**：见下列清单；均须动态过程链书写，视线/肢体变化须写立体三轴；切口密度：每 Beat 至少一项，长对白每 2–3 句至少 1 处。  
- **微动作常见项**：呼吸深浅/节奏、指尖松紧/轻敲/蜷缩、视线游移/定格/回避、重心/肩线、吞咽/喉结、唇瓣、衣料/发丝微颤、握物力度。  
- **微表情常见项**：眉弓平蹙/轻挑、眼角半阖/骤张/轻颤/发红、瞳孔视线定格/游移/回避、鼻翼翕动/收紧、唇角抿紧/微扬/下撇/轻颤、下颌绷紧/咬紧、面颊抽动/血色上浮、泪膜蓄溢/滑落、口型微启/紧封/欲言又止、法令纹加深。  
- **喜剧类微表情**（夸张型场叠加）：挑眉飞挑、瞪眼/眼珠上翻、瘪嘴/撇嘴、咧嘴大笑、憋笑抽搐、白眼、O 型嘴、斜眼睨视、装无辜睁大眼等；包袱落点优先眉眼+嘴型组合。  
- **表演连贯性/原文点出项**：执行见 Beat 完整逻辑环节 6、强约束§6–§7；文学描写须拆为可拍部位与变化过程，对应具体 Beat。  

### 一-B、场景切换与首节拍转场（合并说明，强制）
本小节统摄 **Beat 间过渡、Scene 内快速闪回、Scene 间切换、每场首节拍**；与 §二「转场专拍 Beat」「转场手段参考库」配套使用。Part 1 / Part 2 **禁止**将切换判定、首节拍技巧、出场转场拆成三处各写一半，须合并写入 **【场景切换与首节拍转场】**。

- **转场逻辑链（强制顺序，逐 Scene 走完）**：  
  1. **上场承接**：读取上一场【视觉落点】为本场入点锚；写明「上场落点 → 本场如何接住」（动作余势/视线/声音/物体/色调/构图之一或多）；全剧第一场写「无上场：开场特例」。  
  2. **切换判定（四项必填）**：`时空关系`（连续/省略/跳转）｜`桥接依据`（动作/视线/声音/特写/色调/光影/遮挡/图形 Match/运镜/声画对位等，至少一项）｜`轴线状态`（同侧/已交代过轴）｜`跨幅级别`（小跨幅/已说明跨环境）。禁止无依据硬切。  
  3. **手法选定**：从 §二「首节拍 OT 标签」+「转场手段参考库」各选 **≥1 项**；场间切换与每场首节拍**须标 OT 简称** + 自然语言可拍描述；Beat 间小过渡可只写手段名称。  
  4. **首节拍三步咬合**（强约束§15）：**吸睛（前 3 秒）→ 建置（观察视角+环境+先 FG/MG/BG 三层、再每层内逐个实体落位）→ 入戏**；吸睛手段须与 Step2 桥接依据、Step3 OT/转场手法**同链**，局部特写吸睛后须后拉/摇移或紧接全局建置。**远距离/受限 POV 例外**：首 Beat 为瞄准镜/望远镜/远距监控等 POV 时，建置步**仅覆盖 POV 可见范围**，可标注 `全局建置=延迟`，不必同 Beat 后拉全场；补全 Beat **优先 OT-LS/OT-MAP/OT-AE 等航拍/高位俯瞰建置**，再写 `{下一节拍起幅}` 或专拍 Beat。  
  5. **下场预埋**：本场末 Beat 或【视觉落点】须写明可供下一场 Step1 承接的锚点（落点画面/动作态/声源/物件状态）。

- **三层切换粒度**：  
  | 层级 | 典型场景 | 写法要点 |  
  |---|---|---|  
  | **Beat 间** | 正反打、视线 Match、无情节回忆切片 | 同 Scene；无情节切片可并入转场链，不必独立 Beat |  
  | **Scene 内插入** | 快速闪回（回忆对白 >30 字）/ 无情节回忆切片 | 不拆 Scene；快速闪回主节拍=快速闪回桥接；无情节切片主节拍仍归当下场，切片写入转场链（§三） |  
  | **Scene 间** | 时空跳跃、空间跨越、原文/上游已切分的独立场次 | 新 Scene 首节拍走完全链；上场末+本场首须双端桥接；**完整闪回不必然另拆 Scene**，以原文/上游切分为准 |

- **首节拍技巧 = 场间转场技巧**：每场第一个【动作/视觉节拍】的 OT/转场手法，即本场**入画方式**；须同时回答——**从哪来（上场承接）→ 怎么切进来（桥接+OT）→ 第一眼看什么（吸睛）→ 空间怎么建立（建置）→ 戏从哪入（入戏）**。  
- **参考片对标（强制）**：每场至少写 1 部 `borrowed_films` 中对标片 + 具体手法（如「《xxx》走廊跟拍入画，OT-TR 横移穿越」），不得只写片名或只写 OT 代号。  
- **与转场专拍 Beat 分工**：需独立展开的桥接情节（场间省略、蒙太奇、声画对位、快速闪回等）→ 上场末 Beat 或本场首 Beat 建**转场专拍 Beat**（主节拍=转场/快速闪回桥接），其前后 Beat 仍须写切换判定与承接；简单连续时空且桥接可在首节拍三步内完成 → 不必另建专拍 Beat。  
- **示例**：【场景切换与首节拍转场】上场林医生推门落点 → 切换判定：连续省略｜声画对位+色调渐变｜同侧｜小跨幅 → OT-LG 走廊灯光由暖渐冷+OT-TR 横移穿越（对标《xxx》）→ 首节拍：门缝光带收窄吸睛 → Pullback 建置走廊 FG/MG/BG → 陈医生脚步声入戏。  
- **远距离 POV 延迟建置示例**：【Scene实体覆盖】`全局建置=延迟`；已入场：狙击手李、目标王、观察员张——Beat 1 仅落位李（POV 观察侧）+ 镜内王剪影压点；张与王全场关系标注「待全局建置 Beat 3，触发：镜筒移开；补全手段：OT-LS Drone 高位俯拍 rooftop 建置航拍景观」。Beat 1 首节拍：瞄准镜十字线压王胸口吸睛 → POV 衍生环境建置镜框/靶区 FG/MG/BG → 李扣机指渐紧入戏；Beat 3 Drone 自 BG 高位俯拍缓缓下降，一次性建置 rooftop 三人 FG/MG/BG 全局落位与相对距离，再切近景入戏。

### 二、空间位移与动作微观化
- **主节拍/主动作（强制）**：每 Beat 标明**唯一**主节拍/主动作，且**必须归属主动施力方**（**例外**：转场专拍 Beat 主节拍=转场桥接，见下条）；被动物件的运动、落点、碰撞及**纯粹受力位移**仅为该 Beat 因果链的延续描述，**不得升格为独立 Beat**（执行见强约束§25）。微动作不得替代主动作，但须在全员反馈与对白停顿中持续落地。  
- **纯粹受力/客体运动禁令（强制，§25 展开）**：  
  - **同 Beat 必写**：施力主动作 → 接触/命中（**写清命中部位/落点**）→ **命中效果/受力反馈** → 客体轨迹或受力方被动位移（**需要时写移动路径**：沿结构滑行/弧线/反弹/滚转等，锚定 ENV 具名部位）→ 落点/碰撞/静止，全链写在**发力方同一 Beat**（或发力方动作延续的下一 Beat，主节拍仍归同一施力方）。投射攻击（子弹/飞镖/箭矢/暗器等）同样适用，禁只写射出/飞出而无路径（需要时）、命中与效果。  
  - **禁止独立 Beat**：以被动物件为主语的单 Beat（「球飞向…」「杯摔碎」「纸张飘落」）、以纯粹受力为主语的单 Beat（「他被推倒」「她被撞飞」且不含主动格挡/闪避/承接）——均须**并入上一施力方 Beat**。  
  - **可新开 Beat 的条件**：仅当**新的主动施力方**接续并承担主节拍——如对方接球、门将扑救、格挡反击、主动闪避后还击、主动后撤收势等；此时主节拍归该人物，不得仅写「受力结果」而无其主动意图。  
  - **链过长拆分**：**施力起势 Beat** → **同一施力方动作延续 Beat**（含客体全程轨迹至静止/命中，或受力方纯粹被动位移至落点）；**禁止**拆出「客体独立 Beat」或「纯粹受力独立 Beat」。  
- **形体动作因果链（强制）**：施力-受力、接触-运动等同链，须先写完整主动作与受力反馈，再写结果轨迹/落点；禁止只写结果而跳过施力主动作。**主节拍必须归属主动施力方**（人物、有自主意识的活物、或术法/机关的明确触发者）；客体轨迹、旋转、飞行、落点、碰撞须写入施力方同一 Beat 的因果链内连贯描述。仅当**新的主动施力方**接续（对方接球、门将扑救、第二人拦截等）时，方可新开 Beat，主节拍归新施力方。  
- **主动作主体示例**：  
  - Beat 1 主角立于球场 **MG 左区**，右脚由 **BG 右下**发力踢球→球沿低平弧线由 **MG 左前** 飞向 **FG 门口**、在门槛 **FG 前侧** 反弹后滚入走廊 **BG 中纵深**（施力主动作与客体轨迹同 Beat）。  
  - Beat 1 甲挥拳击中乙胸口→乙上身受力后倾、脚跟离地半步后坐倒在地（施力、命中、受力反馈、落点全链同 Beat）。  
  - Beat 1 甲 **MG 右区**抬枪击发→子弹自 **FG 右前**低平射出，途经 **MG 中线** 命中乙 **MG 左肩**→乙肩线后挫、身体顺时针半旋后坐倒地（出手、弹道、命中部位、效果同 Beat）。  
  - Beat 1 丙 **MG 左前**甩腕掷出飞镖→飞镖沿弧线自 **MG 左** 飞向 **FG 右** 丁喉前→丁 **FG** 侧身闪避，飞镖擦耳钉 **FG 右后** 木质屏风，镖尾颤振嵌于屏心（出手、弹道、预期命中、实际落点、效果同 Beat）。  
  - Beat 1 林医生 **MG 左区**推桌→桌上文件夹沿 **MG 桌面**滑向桌沿（施力主动作与客体轨迹同 Beat）。  
  - Beat 1 主角踢球→球飞向 **FG 门口**；Beat 2 门将 **FG 中区**跃起扑救（主节拍归门将，新主动施力方）。  
  - Beat 1 黑色轿车自 **BG 左深区** 沿 **MG 左车道** 加速驶向 **FG 中偏右区**（车头朝右前，途经 **MG 中线** 后变道至 **FG 右车道**），在斑马线 **FG 右前区** 急刹停稳（施力主动作=加速驶近与制动，轨迹与终落同 Beat）。  
- **特效拆 Beat（例外）**：术法/域场/奇观六相链过长时，可 **起势 Beat → 特效专拍 Beat → 落位 Beat**（细则见§三-B）；不得替代形体动作链，不得跳过触发源。  
- **转场/过渡专拍 Beat（例外）**：凡 Beat 间、Scene 间或时空/情绪/信息需桥接的转场，本阶段为连贯性**优化补写的过渡情节**（蒙太奇切片、空镜桥接、声画对位、匹配切、走位穿越、环境异象铺垫、情绪余韵承接、**快速闪回**、**无情节回忆切片**等）**可单独建 Beat**；**主节拍=转场桥接**（**快速闪回**时主节拍=快速闪回桥接，**须满足回忆对白 >30 字**，见§三；**无情节回忆切片**可并入相邻 Beat 转场链而不必独立建 Beat，见§三）；须写清：切换判定（时空关系/桥接依据/轴线状态/跨幅级别）、前后承接落点、OT 或转场手段名称、可视过程链；**快速闪回**另须标明进入锚点、回忆切片内容（对白/动作要点）、回切锚点与质感处理（见§三）；**无情节回忆切片**写清触发→切片画面要点（≤2s）→回切锚点与质感即可，**不要求**完整对白链/动作链/三层建置。此类 Beat 服务于叙事连贯与转场可读，**不**视为客体独立主动作；**禁止**无桥接依据的硬切占位。  
- **转场专拍示例**：Beat 3 对白落点，林医生视线定格门外→ Beat 4【转场桥接】走廊灯光由暖渐冷、脚步声叠化、门缝光带收窄（桥接依据：声画对位+色调渐变；时空关系：连续省略）→ Beat 5 陈医生推门入画。  
- 路径、开关方向、进出径向、绕障路线须写清；凡方向变化须按**立体三轴**落点，且**前/后须标明相对镜头或相对 ENV/实体**（见 §11 前后位置双轨）。  
- 高动量段落须写速度状态（起速/加速/急停/失速）+ **方向变化节点**（每个变向须写清沿哪一轴、从 FG/MG/BG 哪区段切至哪区段、左中右哪区段切至哪区段）。  
- 位移动作五元组：`起始实体落位（含层位 FG/MG/BG + 左中右） → 发力（发力部位+立体方向） → 路径/方向（**移动路径**（需要时：相对 ENV 结构的路径形态）+ 沿三轴的变化节点，每节点须 FG/MG/BG + 左中右） → 终点实体落位（含层位 FG/MG/BG + 左中右） → 静止/受力结果`（成稿写具体人物/物件/载具/空间结构部位）。**移动链须同步写行进/飞行/车体朝向与轨迹路径**；客体/受力体轨迹**需要时须同步写移动路径**，执行细则见强约束§11「运动方向与朝向」。  
- **打击与投射攻击链（强制，打斗/远程攻击统一口径）**：近身打击与远程投射均须写完整因果链，禁只写动作名或只写「打出/射出/飞出」而无命中与效果。  
  - **近身打击链**：施力方(FG/MG/BG+左中右)→发力方向→**接触/命中部位**→**受力反馈**（位移/失衡/伤态/格挡硬抗等）→**移动路径**（需要时：受力方被动位移沿哪结构/弧线/滚转）→终点落位。
  - **投射攻击链**（子弹/飞镖/箭矢/暗器/投掷物/法术弹道等）：`出手/击发锚点 → **移动路径**（需要时：低平/弧线/绕障等路径形态，锚定 ENV 结构）→ 弹道轨迹（途经 FG/MG/BG+左中右 节点）→ **命中部位/落点**（写具体：左肩/门柱/地面哪一区段等）→ **命中效果**（贯穿/嵌入/反弹/碎裂/阻停/擦过/打偏入障/受击者生理或物理反馈/环境痕迹）→ 静止/余势`。闪避/格挡/打偏时须写预期弹道/路径与实际落点及效果。
  ❌「甲开枪，乙倒地」｜✅ 见上条「抬枪击发→子弹…命中左肩→后坐倒地」示例。  
  ❌「飞镖飞出」｜✅ 见上条「甩腕掷出→弧线飞向喉前→闪避擦耳→嵌入屏风」示例。

- **闪回三档判定（强制先判，以上游为准）**：  
  - **完整闪回**：时间层切换、人物/环境/道具状态态与当下形成**可识别差异**、或回忆段落须独立承载对白链/动作链/信息 Reveal → **不必然拆独立 Scene**；**以原文/上游 Scene 切分为准**——原文已切独立场次/具明确时空跳跃且叙事目标切换时方可拆 Scene；原文嵌于单场、无独立时空切换、或叙事目标仍锚定当下场时，**优先** Scene 内**转场专拍 Beat**/**快速闪回**承载，**禁止**仅为满足「完整闪回」条件而自创 Scene 或虚构回忆地点 ENV；前后 Scene 间仍须保留桥接关系。  
  - **快速闪回（有情节）**：服务于当下场情绪/信息落点的**短促回忆对话或具名动作情节切片**（通常 1–3 Beat、单段 ≤8s 体感）；**启用门槛（强制）**：待视觉化呈现的**回忆对白原文合计须 >30 字**（含画外/OS/V.O. 闪切台词；不含仅触发回忆的当下台词如「你还记得吗」）；**≤30 字且含具体情节/对白**时**禁止**建快速闪回 Beat，改以当下场微表情/微动作、听者反应、口述转述或 `OS/V.O.` 承接。人物年龄态/妆发/服装、环境状态、道具状态与当下**无实质差异**，或差异仅通过质感处理（去色、虚化、噪点衰减、柔焦、慢速等）即可区分；回忆内容**补充印证**当前对白/反应，不独立承担新叙事目标。**不拆 Scene**，在当前 Scene 内以**转场专拍 Beat**（主节拍=快速闪回桥接）或插入节拍承载；须写清进入锚点（视线/物体/台词关键词/声音桥）与回切锚点（动作余势/声残响/构图呼应），手法优先：感官冲击闪切、定格闪帧、回忆质感衰减、闪回梦境叠化、跳切、声画对位。  
  - **无情节回忆切片（转场式）**：原文或强暗示仅有**印象/情绪/物象触发**，**无具体对白链、无完整动作情节、无独立信息 Reveal**（如「想起父亲的脸」「雨夜的车灯」「爆炸一闪」「童年走廊剪影」）；**不受 >30 字门槛约束**，**禁止**升格为完整闪回 Scene 或扩写为快速闪回 Beat。**处理方式**：按**转场手段**写入相邻 Beat 的转场链——触发（视线/物件/声/触觉）→ **≤2s 单幅或 1–2 帧印象切片**（写清可见物象/人物剪影/环境色块，**不要求**完整 FG/MG/BG 建置与对白咬合）→ 质感处理（去色/虚化/噪点/柔焦/慢速等）→ 回切当下（动作余势/微反应/声残响）；可并入上一 Beat 末、下一 Beat 初或短转场专拍，**主节拍仍归当下场**。**禁止**为无情节切片单独扩写对白链或完整动作链；切片内具名主体须列入【Scene实体覆盖】，但可仅写剪影/局部/impression 级落点。

### 四、对白/旁白/心理外化
- **继承边界**：改标点控节奏，不改意图、词义、事实与因果。  
- **每场拆句声明（强制）**：每个 Scene 在【对白拆句判定】中明确 `已拆句|未拆句|无对白`；已拆句须列原句→子句→Beat→切口对照；未拆句/无对白须附原因。Part 1【对白拆句自检】须逐 Scene 复核判定与【语言】成稿一致。  
- **情绪标点（强制）**：先判情绪阶段，再选标点；与 `tone`/`speed`/`volume` 一致；服务口型与微表情切口。可用：`，` `。` `……` `——` `！` `？` `、` `「」/""`；策略类型：压抑型、爆发型、试探型、喜剧型、治愈型、紧张型；>20字拆句时每子句自带标点。  
- **禁止**：滥用标点；标点与 `tone`/`speed` 冲突；改数字/**已确立真实姓名**/关键事实词（占位称谓→具名替换见强约束§18，不属于「改人名」）。  
- **OS/V.O./旁白**：明确归属与听者；适用情绪标点与同场反馈规则。  
- **主听众（强制）**：每轮标最主要听众及依据（`叙事目标相关度 > 视线直指 > 空间距离 > 因果承接`）；默认禁止并列，证据等强才写“并列：原因”。听众反应含动态微表情+微动作各≥1。  
- **心理外化**：转译为可拍微表情+微动作+道具接触+空间反馈；禁抽象情绪词（执行见强约束§5/§7）。  
- **环境补充**：仅服务剧情与动作逻辑；禁新增改变因果的实体/事件。  
- **输出**：【语言】直接写成稿台词；第一部分写【对白节奏标点】策略与典型落点。

### 五、角色表情与题材适配
- **先判表情强度**：`夸张型`（喜剧/轻喜剧/日常搞笑/闹剧/反差萌）| `细腻型`（情感/爱情/治愈/亲情/现实主义细腻/文艺）| `标准型`（悬疑/剧情/职场/犯罪等）；混合段按节拍切换。  
- **微表情选材**：优先从 §一「微表情常见项」择项组合；喜剧/夸张型场叠加 §一「喜剧类微表情常见项」；须写清部位与动态过程链，禁抽象情绪词。  
- **夸张型**：眉眼幅度大、嘴型明确、多肌肉组联动；反应可适度漫画感但真人可拍；肢体与表情同步夸张；包袱/误会/反转须补夸张表情切口，**优先用喜剧类微表情常见项**（挑眉飞挑、瞪眼、瘪嘴、憋笑抽搐、O 型嘴、斜眼睨视等）并写多部位联动过程链。  
- **细腻型**：写具体微动与渐变链（`前置克制 → 中段裂缝 → 落点余韵`）；强情绪也克制幅度。  
- **标准型**：清晰可读，在夸张与细腻间取中值。  
- **文戏特写增量**：每文戏 Scene 主角局部特写≥3（含强约束§4 的每场至少 1 处细节特写）；长对白每 2-3 句至少 1 处微表情+微动作组合。

### 七、文戏/武戏差异化
- 先判类型：对白情绪主导=文戏；打斗追逐术法主导=武戏；混合段按节拍切换。  
- **正式决战(§26)**：`正式决战=是` → ≥10 Beat → 【决战 Beat 规划】  
- **宏观群体(§27)**：`宏观群体=是` → ≥6 Beat → 【宏观 Beat 规划】；高潮三要素齐  
- **文戏模板**：`触发（台词/动作/停顿） → **观察视角（谁从哪看、看哪）** → 主角局部特写（部位+动态变化，须与当前视角/环境一致） → 下一承接`。  
- **武戏强制**：方向链+美感动作；**近身打击与投射攻击（子弹/飞镖/箭矢/暗器/投掷物/法术弹道等）均须写完整攻击链（出手→弹道/接触→命中部位→命中效果）**；术法/异能→六相链(§三-B)。
