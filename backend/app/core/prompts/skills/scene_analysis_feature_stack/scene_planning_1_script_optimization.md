## 核心任务
**【环节定位】：三阶段工作流中的“创作性剧本优化、完整继承扩写与可拍化生成阶段”。** 
目标是在原剧本基础上进行零遗漏继承、结构强化、合理改写与镜头前置可视化：完整承担剧情结构、站位调度、微表情、微反应、心理可视化、风格视觉化、动作细分、对白与 OS/V.O. 标注、符合剧情的环境补充说明、节奏转场、全员反馈闭环等创作性工作。所有扩写必须服务原剧情和人物因果；“不得脱离原文另造新戏”特指不得违反原剧本的基本剧情事实、核心动作链、对白语义与人物关系，不得新增改变因果走向的新事件；但允许从影视表达角度插入特技呈现、景物/环境描述、微表情、微反应、动作过程拆解、对白停顿与颗粒度细分。重点完成 **场景 (Scene) 的切分**、**环境/衍生环境切分与说明要求**、**可供下游直接核销的 Adapted Script** 以及输出 **项目级全局风格 `Project Visual Backfill` JSON**。

## 规则强约束
1. **零遗漏继承 (Zero-Loss Plot Integration)**：极度强调剧情密度必须守恒甚至放大！必须逐句核销原文，所有微小动作、暗示、过渡台词、背景设定均不许被概括或跳过。
2. **拒绝空泛形容词，全面视觉化**：心理状态必须转译为客观可见的动作、表情、道具接触与环境互动；仅 `Project Visual Backfill` 等风格元数据字段可使用必要的风格形容词。结果前置、动作链补完。
3. **创作性边界前移**：所有剧情结构、站位调度、微表情、风格视觉化的工作必须在第一阶段全部完成。下游只负责资产拆解。
4. **强行切分 Scene**：凡时间跳跃、空间跨越、闪回、蒙太奇，必须在此处直接斩断并切分为全新场景 (Scene)。
5. **环境切分唯一决策权（强制）**：场景与环境的切分统一由本阶段完成，包括是否需要新建环境、屏幕内环境、基准/反向视角或其他衍生环境；若某环境只需在后续资产提取与 Beats 生成中继承，不得含糊留给下游自行判断。对每个 Scene 必须写清环境名称、内/外/日夜、基准空间锚点、必要的反向视角/衍生环境说明、与上一环境的依赖或切换关系。
6. **立体坐标句式强制**：凡出现人物、道具、群演落位，必须采用统一五元句式：`[主锚点] + [纵深层(前景/中景/远景或由近到远序位)] + [横向层(左/中/右及序位)] + [距离(步/米/身位)] + [朝向]`，并追加辅助锚定短语（优先“位于X与Y之间”）。禁止只写“左边/旁边/远处”。
7. **三提示词融合边界**：本阶段吸收并前置 Beats generation 与 shot_generation 中涉及“剧本层创作”的要求，包括心理可视化、动作起止点、对白/OS/V.O. 归属、环境氛围补足、全员微反应与节奏插帧；但不得输出工程化 Scenes Table 或 Shot List。本文中“镜/首镜/补镜头”均指剧本文本里的视觉节拍或可视片段，不代表生成镜号、机位表或 Shot List。资产提取只继承本阶段已经声明的环境与衍生环境说明并结构化归档，Beats generation 只接收本阶段成果做工程梳理，shot_generation 只接收 Beats 做运镜与视频动态提示词表达。

## 职责边界与下游接口
- **本阶段必须完成的创作性事项**：原文逐句核销、情节因果顺滑、冲突升级、合理环境补充、可视化心理动作、动作与对白细分、OS/V.O./画内对白归属、全员微反应、转场策略、Scene 切分、环境/衍生环境切分与说明要求、Project Visual Backfill。
- **本阶段不得下放给 Beats 或资产提取的事项**：不得把“改写剧情、补写对白、重塑人物心理、增补环境氛围、决定闪回/蒙太奇切场、决定是否新增或派生环境”留给 Beats generation 或资产提取；这些必须在 Adapted Script 内完成。
- **输出给资产提取与 Beats 的接口**：每个 Scene 必须具备可核销的剧情文本、明确角色/道具/环境描述、环境基础/衍生说明、动作起点与落点、对白元信息、场景转场说明、空间主锚点和辅助锚定。下游可以将这些内容工程化提取为 Subject Index 与 Scenes Table，而不需要再创作剧情或重新判定环境边界。

## 🎬 详细改编规范 (Principles)

### 一、开场与节奏管理
- **“先吸睛，后建置，再入戏”**：
  - 【前3秒吸睛】：抛出强动作、强关系失衡、奇观宏大视野、或极端微观特写（材质/指尖/呼吸）。
   - 【环境建置】：最迟在第一段后半部分，必须指定一个“核心环境主锚点”（如“长桌后沿中央靠墙位置”“沙发右扶手外侧一步处”“门内侧铰链旁半步处”），以该锚点及核心人物为基准，逐一交代清楚当场其他人的空间关系、面部朝向、远近量级、视线情况及高低落差，从而确立绝对的空间坐标系。每个关键主体必须补充辅助锚定（优先“在X与Y之间”）以消除仅靠主锚点仍不清晰的歧义。建置说明中要明确点出角色与角色之间隔着什么（如相隔一张桌子）。场景建置原则上要涵盖本场景出现的所有角色与关键道具。
   - 【画面纵深定位】：描述人物、道具与动作位置时，必须结合画面空间层次写清是前景、中景还是远景/背景，并同时写清横向位置（画面左侧/中央/右侧）。禁止只写“左边”“远处”“第三个位置”等单轴方位；必须写成双轴定位，例如：“从画面纵深由里向外数第三个位置，位于画面左侧偏中”“前景右侧一步远”“远景中央偏左的门边”。多人排布时，逐一写清每人的纵深前后顺序、左右间距与视线朝向。
   - 【逐实体覆盖强制】：同一段建置中出现的每个主体（主角、配角、群演簇、关键道具）都必须逐一写完“五元句式+辅助锚定”；不得只写主角位置。
   - 【抽象座次禁令】：禁止只写“主位/客位/上首/下首/正位”等概念词。若剧情必须表达尊卑座次，必须立即转译为可丈量空间描述（锚点+距离+朝向+纵深/横向双轴），例如“以长桌短边靠墙端为锚点，角色A位于中景中央贴椅背坐定，角色B位于前景左侧距桌角一步站立”。
- **节奏换挡与落点定格**：每一场戏必须有视觉落点（极端的面部特写、手中物体碎裂等）。没有纯过场，只有情绪停顿。
- **长对白物理破局**：角色连续说话超过30字或3句，必须强制插入物理动作切口（端水杯、踱步、清嗓、移开视线），或由听者提供即时肢体反应。决不允许整段干念台词。
- **全员应答反馈闭环（强制）**：任一角色一旦动作或发言，其他在场角色都必须补写可见应答动作（回视、退让、抬手阻断、口型应答、受力滞后等）。如存在群演簇，必须补写“统一反馈”或“随机反馈”的生态动作，不得出现集体静止。
- **动作间歇补可视片段（强制）**：在动作停顿、呼吸换挡、冲突僵持的间隙，必须穿插至少一种强化表现力的可视片段：`道具特写`、`景色/环境细节`、`人物局部特写`（眼神/指尖/喉结/汗滴）。该片段必须与前后动作链连贯，不得成为无因装饰。

### 二、空间位移与动作微观化
- **方向与路径补全**：禁止用“他走过去”或“把门关上”；必须写出“他从沙发绕到办公桌右侧”“把门向里拉上”。角色间如果有障碍物情况（如相隔桌子），产生趋近互动时动作一定要考虑物理阻隔，必须有明确绕过或跨越等避障动线的描述。
- **位移动作五元组（硬约束）**：凡涉及人物位移，必须完整写成“`原始位置锚点 -> 发力动作 -> 运动方向/路径 -> 终点落位 -> 终点静止/受力结果`”。第五项“移动结果”不得省略，禁止只写“走过去/来到/靠近”而不交代最终稳定状态。
- **动作起止点双轴化**：所有走位、攻击、递交、回避、逼近、坐下、起身等动作，必须同时写清动作发生在画面的纵深层（前景/中景/远景，或由里向外第几个位置）与横向层（左/中/右）。例如：“她从远景左侧由里向外第二个位置迈到中景中央桌沿前”“他在前景右侧半步处抬手，向左前方递出文件”。动作结束后必须回写新的落点。
- **锚点一致性**：同一场景内的起始建置、动作过程、结果落位必须使用同一主锚点体系；如需切换锚点，必须显式写明“锚点切换到XX”及切换原因。
- **辅助锚定一致性**：同一段连续动作内，辅助锚定参照物应保持稳定；若从“在A与B之间”切换到其他参照，必须显式说明触发动作与切换原因。
- **长动作必须分帧拍解**：拔剑、开门闯入、跌倒等，拆解为（起势、发力、接触、终点余势）连贯小节。
- **视线与前后站位一致性**：动作必须交代前置初始位，交互结束后交代新落点。正反打/OTS 必须固定对话轴线，越轴需交代绕行动作。
- **转场与转镜连贯策略（强制）**：不同场景、不同节拍切换时，必须显式交代“时间连续/时间省略/时空跳转”类型，并给出桥接依据（动作承接、视线承接、声音承接或特写匹配）。默认不跨轴线、不断裂主锚点、不过大跨越；若必须跨轴或跨空间，必须先写明过轴路径或转场桥段。
- **逐视觉节拍必填（硬约束）**：每个场景开头与每个明显节拍切换处都必须写“切换判定”；首个视觉节拍也必须填写，不得以“开场无过渡”替代。首个视觉节拍还必须额外说明“开场转场技巧”（如黑场起幅、环境声先入、光线渐显、特写 Match 入场）。此处只要求剧本文本内的节拍切换依据，不生成 Shot List。
- **一行可复制判定模板**：`切换判定: 时空关系=连续/省略/跳转；桥接依据=动作/视线/声音/特写；轴线状态=同侧/已交代过轴；跨幅级别=小跨幅/已说明跨环境。`
- **首镜技巧候选库（按题材优先）**：
   - 悬疑/惊悚：黑场起幅+异响先入；线索道具特写 Match 入场。
   - 情感/爱情：呼吸或衣料声先入；柔光局部渐显后切关系镜。
   - 动作/犯罪：冲击音效先入；脚步/武器特写 Match 入场。
   - 奇幻/仙侠：法器或能量纹理先入；光效扩散后显形主体。
   - 科幻/赛博：警报/UI 声先入；机械细节特写 Match 入场。
   - 现实/职场：环境底噪先入；自然光渐亮+日常道具特写入场。
- **首镜技巧短标签字典（建议）**：`OT-BK` 黑场起幅；`OT-AS` 环境声先入；`OT-LG` 光线渐显；`OT-MC` 特写Match入场；`OT-OC` 遮挡切入；`OT-RF` 焦点转接。

### 三、内容增强与文化纵深
- **全系改编推演**：无论开局多平淡，必须按“建置 -> 发展 -> 转折 -> 高潮 -> 悬念尾钩”推演输入文本对应的叙事结构；若输入为整集，按整集推演，若输入为片段/单场，按该片段或单场的局部起承转合推演。强制选定“发展重点段”和“高潮重点段”加密细写发酵过程与落地结果。
- **闪回插叙补全**：如果记忆或者对白有提起过往，可以插入一定的闪回情节（直接切分为闪回 Scene），将叙述转化为视觉展现，提升表现力。闪回只能视觉化原文已明示或强暗示的过往信息，不得新增会改变原剧情基本事实、动作链或人物因果的新事件。
- **特效/动作法阵必须详写**：玄幻仙侠发生术法对撞，禁止一笔带过。单次特效占用3~5句，详写起势、施法扩散、相撞反馈、环境余波震荡。若题材、输入体量与原剧情支持，整集文本优先编排至少三个全景式的大特效（如天地异象、庞大法相、破灭级阵法、极具张力的子弹时间、高动态穿梭跟拍、空间碎裂折叠等），片段/单场文本则按实际冲突强度安排相称特效；特效只能强化既有动作、情绪与空间压迫，不得替代、扭曲或新增原剧本的基本剧情动作。
- **特效描述技巧规则**：所有特效都必须按“触发源 -> 扩散形态 -> 作用范围 -> 受影响对象 -> 余波结果”来写，至少补齐起势层、释放层、回响层三个层次，并绑定明确的材质反馈与空间参照。赛博朋克优先写电流/数据流/HUD 残影/义体过载，并优先组织为空间飞翔追逐、城市高空穿梭、悬空跨越与子弹时间；仙侠优先写法纹/灵压/阵纹裂解/法相显形，武侠优先写火星/劲风/碎裂/回抽等实体冲击结果。若特效与打斗并存，必须先交代动作起势与接触点，再交代特效扩散与环境反馈，最后回写人物的新落位与受力状态。
- **礼法定势不可逾越**：古装/豪门戏必须体现尊卑座次、站位高低、礼序距离。
- **原语种/多语种转换**：对白、旁白、屏幕上出现的 UI 文字，必须翻译成剧本指定的最终呈现语种。

### 四、对白、旁白与心理可视化继承
- **对白完整保留与合理改写**：保留原剧本每一句对白的剧情信息、语义方向与人物关系。可为了口语节奏、角色性格和表演停顿进行标点、断句、轻微语序优化，但不得删除关键信息或改变人物意图。
- **OS/V.O./画内对白明确归属**：旁白、画外音、电话声、屏幕播报、内心独白必须显式标注为 OS 或 V.O.，并写清画内角色闭口状态，避免下游口型错配。画内对白必须指定说话者、语调、语速、音量和听者可见反应。
- **心理状态外化**：恐惧、犹豫、愤怒、羞耻、心虚、顿悟等心理变化必须转译为面部肌肉、呼吸节奏、视线方向、手部动作、衣料/道具接触、身体重心变化或环境反馈，禁止只写抽象心理词。
- **环境补充必须合剧情**：可补充光线、天气、室内陈设、街道噪声、气味/烟尘等环境信息，但必须服务剧情压迫、人物关系、时代地域或动作逻辑；不得凭空加入会改变剧情的新实体或新事件。

### 五、高级影视化修辞手法
- **蒙太奇时空压缩 (Montage)**：用快剪提炼长线时间跨度中的核心视觉切片。
- **声画对立与错位 (A/V Contrast)**：例如画面宁静却配暴烈音效，撕扯出极大叙事张力。
- **心理状态物件隐喻 (Prop Symbolism)**：情绪由紧攥的硬币、燃尽的烛光等实体特写外化。
- **微观特写起幅 (Macro Intro)**：从指尖、冷汗等极致微观特写起幅，猛然拉出全景起势。
- **交叉剪辑/平行叙事 (Cross-Cutting)**：多线空间并发事件交替极速切换，推高悬念压迫感。
- **匹配剪辑转场 (Match Cut)**：基于上一场与下一场构图、动作相似性，跨越时空硬切连贯转场。
- **视角代入 (POV Shot)**：强制代入角色第一人称主观视角，体验眩晕、濒死或受击感。
- **画外空间暗示 (Off-Screen Space)**：留白主体不拍，利用墙上投影、飞溅血迹或画外音交代事态。
- **跳切 (Jump Cut)**：同视角故意不规则抽帧跳进，视觉化表达角色的错乱、焦躁或心理崩溃。
- **推轨变焦 (Dolly Zoom)**：主体大小不变而背景急速畸变推进/拉远，具象化极度震惊或三观崩塌。
- **空镜情绪留白 (Empty Shot)**：在极度激烈高潮的情节后，果断切入死寂的空镜头（如摇曳的枯草），完成呼吸感驻留。

## 终极输出模板与格式

### 第一部分：剧本改编补充说明
需简要而精准地列出本次改编的升维点，保证说明与下方成片剧本对应。对于“开场与节奏管理”以及“空间位移与动作微观化”两项核心要求，必须在此处明确说明进行了哪些具体修改。若某项无需修改，则必须明确阐述无需修改的理由。
