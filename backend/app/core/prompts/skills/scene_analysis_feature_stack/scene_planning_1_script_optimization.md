**每个 Beat 均须按下列逻辑完整执行**；**前置 + 六环节**彼此咬合、缺任一即 Beat 不合格。

**Beat 成稿叙述原则（强制）**
- **禁「同上」（最高）**：每拍独立可读。**同 ENV**：【建置】=上一拍`速查更新`终态经**同一 N** 投影后的完整画面句（禁顺带微调；仅明文移动/转向/出入画/持握/姿态变更可调）。**ENV 变**（另起新拍，§4）：写【上一→触发→本 ENV】；**世界扇区/F 承接不变**（无明文走位/转身时），画面句按新 N **整句重写**（禁粘贴上拍任一「画左/画右/前景/后景/正面/背对」短语）。违径向/三联须回改。
- **世界态优先（最高；切视角根治）**：画面相对词（画左/前景/正面…）**不是**站位真源，只是观察轴 N 下的投影。真源=每人`世界扇区 + 世界朝向F + 姿态 + 具名锚`。落笔序强制：**①写/承上拍`速查更新`世界态 → ②按本拍 ENV 之 N 查表得画面落位/正背面 → ③才写【建置】【入戏】**。禁先写画面句再倒推世界态；禁把上拍画面词当「人还在那儿」。
- **建置防错乱五锁（最高；每拍落笔序，缺锁=失败）**：错乱根因=用画面词当记忆、把度数写进建置、速查与画面不对账、反打乱换空间名、自检空话盖章。强制：
  1. **时序锁**：【建置】=开口前起始态；【入戏】=过程；`速查更新`=本拍终态。禁把终态 F/姿态写进建置；禁建置残留 `F≈`/`0°侧`。❌`跪伏在地（F≈180…）`｜✅建置只写「前景中央正面朝镜头，双膝跪地」；F 只进速查。
  2. **投影锁**：速查扇区+本拍 N → 查表得层位/左右，**必须≡**建置画面句。❌速查`轴心`却建置「前景中央」（N=0 时前景=180°侧，轴心=中景中央）。ENV 变后未走位者画面三项相对上拍必变。
  3. **朝向锁**：F↔正背面 + 侧面↔面向同侧画幅 + 三联句 + 对白向；`voice_type=画外音/OS/V.O./旁白` → OS 只挂声（声源人或在画外），禁对镜头口型开口；画内可见角色须**明文闭嘴**。`voice_type=自白/独白/内心` → 发言人与画内他人均须**明文闭嘴**（闭口/内心状），禁按 lip-sync 写「开口」。
  4. **ENV 名锁**：`ENV变` 触发类型与新 ENV **主名段**闭合——同场反打=`{N}度{同一主环境名}`（❌`0度主大门`→反打却写`180度王座区`）；**默认**换主空间名=转场/新 Scene，禁标「反打」。**特例（快速闪回/蒙太奇同场多主，§7/§11）**：同 Scene 已声明的另一【主环境】族之间切换时，主名段**必须**变为目标主环境名（`ENV变=是`，触发=`闪回切主环境|蒙太奇切主环境|回切当下主环境`），**禁止**标「反打」，亦禁止用当下主环境的视角衍生冒充异地。较长回忆→应已拆为独立闪回 Scene，不在同场用多主凑合。
  5. **集合锁**：画内终态≡建置；速查覆盖画内+暂不可见（未出画）；上拍差集处置本拍重析——出画｜仍画内｜暂不可见续挂｜已转可见则**必须**带入建置；禁带病标「①–⑧全过」。
- **两段式**：建置→入戏，禁混写。【建置】【入戏】=查表后的镜头相对词（禁度数推演句）；世界态度数**只**进`速查更新`与 ENV 变时的`视角换算台账`（§15）。`建置更新=是`；一拍禁切ENV。**应可见**必建。**进出场守恒**（群演不豁免；切角暂不可见须差集续挂，转可见必带入，§15）。**道具禁凭空消失**。**开场预排布**。**入戏**分行；载具独立行（§6）。**流畅**叙事散文，禁电报体。
- **原文逐字核销（最高硬约束；原剧本→优化稿）**：原剧本**每一处文字 / 每一信息单元**必须落入优化稿可检索落点；**禁止**概括吞并、跳场省略、只留「大意」、因「不知归哪类」而静默丢弃。
  - **入戏兜底（最高；总闸）**：成稿前对原文逐行/逐信息单元扫一遍——凡**尚未**在【对白】/【建置】/ENV 块/角色设定/服化道摘要/未落清单/切换说明等处完整落地的原文内容，**一律写入对应 Beat【入戏】**（可独立拍或并入因果相邻拍，但须可检索原文关键信息）。**兜底优先于分类**：不认识格式、不在下例子清单、被误判为「备注/景别标签/可忽略镜头提示」——只要原文存在且别处未处理，就进【入戏】。ENV/场头/摘要可**同步**继承结构线索，但**不能替代**入戏落点。仅§5a 中英同义去重删除的另一语种侧免核销。
  - **对白/OS/屏幕可见字**：项目语言侧台词 **逐字保留**（标点可按拆句§25切开，但词序与用词不改；禁意译替换、禁删半句）。拆拍后各拍拼接须能还原原文全句。
  - **专有名词/角色名/地名**：与原文 **逐字一致**（§19 仅处理番位占位→具名；已有真名禁改）。
  - **叙述/动作/场景描写**：逐**信息单元**核销（谁做了什么、何处、何物、何结果）；可改编为可拍建置+入戏，但**信息零丢失**；场景文学描写须融入 Beat（§9），禁只挂场头；未归建置则入戏兜底。
  - **建立空镜 / 环境建立描述（入戏兜底下的常漏例；须作 Beat）**：下列原文**每一行/每一段都是独立核销单元**，须落入**可拍 Beat【入戏】**（优先独立首拍/吸睛拍；可与§16首节拍合并为专段）——**ENV 块不能替代 Beat 落点**：
    1. **`△`环境建立类镜头提示**：`△俯拍/航拍/…` 及同型「俯拍/航拍/鸟瞰/大远景/远景/全景：…」（例：`△俯拍：昏暗的欧式王宫城堡伫立在山巅`）。
    2. **`【空境：…】` / `【空镜：…】`（及无括号同型「空境/空镜：…」）**：纯环境/氛围建立描写——须独立建立拍或首拍入戏写出可拍画面；**无人戏时建置写空镜/无角色即可**；实体线索同时进【主环境】固定清单/未落清单。
    3. **场头长段环境文学**（非对白、非动作，专写地点外观/氛围/规模）：同第2条，禁只挂场注。
    **禁止**：仅写入【主环境】后跳过；因「空镜重述限定」删除。航拍/俯拍**不作**本场 0°轴（§11）。
  - **原文景别/特写镜头提示（入戏兜底下的常漏例；≠可删）**：`景别≠环境`/Insert·CU 禁另建衍生 **≠** 可忽略画面。`△近景/特写/中景/…：…`、`【特写/近景/大特写：…】` 等——须入戏保留景别意图+全部信息单元；轴未变且非反打、正背面档位不变时**沿用父观察侧衍生 ENV**。例：`△近景：…Larissa…推开王宫的大门` 与 `【特写：Larissa光脚…血脚印】` 各须有入戏落点；禁整行当备注删除。
  - **与中英去重关系**：§5a 删除的同义另一语种**不算**遗漏；去重后保留侧仍须按上列+入戏兜底落地。
  - **增补边界**：可增可拍微表演/站位/ENV 工程句，**不得挤掉、改写或替代**原文单元；禁新增改因果事件。
  - **交付**：Part1 必填【原文逐字核销】（声明已做入戏兜底扫尾；抽检须覆盖建立空镜、景别/特写行，**及任一未归他处的原文句**）；任一侧原文无落点=整 Scene 失败，须回补【入戏】后输出。
- **自然语言**：覆盖前置+六环节；禁「前景：/中景：/背景：」标签骨架。
- **角色粒度**：首行`Beat {n}:`；分段建置/入戏/切换。对白拍=一说话人+同期听者反应；听者开口→另拍；同人连续未打断且≤20字可同拍，>20字按§25拆后仍各拍。无对白武戏不受此限。序：建置→说话人/主动作→听者→道具/载具行。
- **段落**：角色=具名+语气层全字段（§四）+对谁/朝哪说；**口型对白**才写「开口」+≥1微表情；**OS/V.O./旁白/自白/独白/内心**须在建置或入戏**明文写闭嘴/闭口**（禁只标 voice_type 却写张嘴对口型）——OS/旁白：画内全员闭嘴；自白/独白/内心：发言人+他人均闭嘴。画外/OS 不写画内落位、不对镜头开口。道具/载具=`{名}：{过程}`；人车分行。
- **成稿分区（最高）**：【建置】【入戏】**禁**世界度数词（`F≈`/`0°侧`/`面向N°`/`躯干面向…`；ENV名除外）——只留镜头相对词。`速查更新`/`视角换算台账`**必须**写扇区与 F（否则切角无法核销）。裸「…深处」见§12。
- **情节一致**：动作/对白/站位/ENV切换须本拍因果；扩写可核销；钩子保留未决；特效须保留解释对白/反应。一致≠可删原文；**删原文=核销失败**。
- **服装剧情（尽量避免）**：禁默认未交代袖/袋藏物——优先握掌/自桌取。确须→动作前`服装要求：…`；环境湿污明示衣态。禁无前置「藏入袖中」。
- **建置边界**：Scene=空镜+未落清单+速查/索引+覆盖排期（不写七要素落位）。Beat=当前衍生ENV下落位+朝向四要素+姿态。姿态必填（座/躺挂承托）；主锚=说话人→POV→施力→焦点；朝向=主动作→对白对象→终态→礼仪；**交付面对面**；阵列中间位标左中右/前中后；参照=`{方位}+{具名}`。
- **空镜重述限定（Beat【建置】；强制）**：空镜骨架只在 Scene 级【主环境】/【衍生】定义；Beat 建置**不负责**再描写环境美术。
  - **禁止**：模型自造的四向/材质/光色/氛围长句；无站位功能的观光句（如「大门与休息区清晰可见」「大厅金碧辉煌」）；把 Observer View 写成 ENV 名重复（❌`0度大门，当前环境 0度大门`→✅`Wide，当前环境 0度大门`）。
  - **允许（须挂角色/动作/出入画功能）**：①具名出入口/固定实体作**落位锚或运动终点**（`经大门出画外`｜`背靠主柱`）；②入画径向所需门态一句（开/闭）；③特效/武戏命中陈设的可拍反馈（§8/§30）；④首节拍吸睛所需≥1 环境动态（§16，一句且含动势）。
  - **原文建立空镜例外（最高；覆盖本条「禁止」）**：原文已写的 `△俯拍/航拍…`、`【空境/空镜：…】`、场头环境文学建立句**不是**违规观光句——须在对应 Beat【入戏】（或独立建立拍）写出可拍画面，保留原文关键信息单元（如「昏暗/山巅城堡」「高耸烟筒/浓郁黄烟/隐绰实验室」）；须含≥1环境动势（烟缕、雾涌、旗动等）。该例外**仅限原文核销**，禁借此在对白拍建置段堆砌自造氛围。
  - **判定**：①属原文`△`/`【空境】`/建立空镜核销→保留入戏；②否则：删掉该环境短语后，角色落位/朝向/运动终点是否仍完整——仍完整则属违规重述，须删；不完整则保留为功能锚。
- **建置·朝向·视角三轴（最高硬约束；须彼此一致）**：
  1. **视角轴**：当前可拍 ENV=`{N}度…` 唯一决定观察轴 N；一拍一 ENV；反打/异排异向/**角色相对镜头正背面档位变化**须 `ENV变=是` 并另起拍；**当前 ENV 的可见半空间须=本镜背景所挂【主环境】N°扇区描述**（禁默认粘 `0度`）；成稿禁泄漏世界度数推演句。
  2. **朝向轴**：世界朝向 F（内部）↔成稿正背面服从 **F≈N→背对**；无明文转身禁因换镜改正面；**无明文转身禁同父 ENV 改正背面档位**；对白「对谁说」须与正背面/层位闭合（三联句）。
  3. **建置轴**：落位=查表后的本镜左右/前后+姿态+参照；同 ENV 抄写上拍终态画面句；ENV 变则世界态承接、画面句按新 N **重写**（禁粘贴上拍相对句）。
  **冲突即失败**：任两轴矛盾或五锁任一破（如建置含`F≈`；速查扇区投影≠建置层位；F≈0却写侧背面；反打却换主环境名；闪回/蒙太奇异地却仍挂当下主环境衍生；OS/V.O./旁白/自白却对镜头口型开口或漏写闭嘴；正面朝镜却面向后景人；ENV名变却`ENV变=否`；反打仍同父ENV；**正背面档位变却同父ENV（无明文转身）**；**当前环境挂裸主环境名（须用 `0度…`/`{N}度…`）**；**背景锚具名却不在当前 ENV 可见半空间**；**无据默认 `0度` 而背景实体属其他扇区**；**左侧面+面向画右/右侧面+面向画左**；终态/差集静默缺人；**暂不可见无挂靠视角/相对锚**；**已转可见却未带入建置**；**回挂靠视角仍标暂不可见**；**查表后景却可见性=暂不可见**等）→ **整拍重写**；**禁止**带病标通过。自检见§15。

**成稿前核验（指针）**：⓪**原文逐字核销+入戏兜底**（对白逐字｜叙述逐项｜建立空镜/景别特写→Beat入戏｜**凡原文存在且他处未落地→【入戏】**｜无落点=失败）｜**五锁**｜**正背面档位开拍检**｜**背景ENV匹配（静止亦检）**｜世界态→查表→建置｜**差集重析（暂不可见续挂/已转可见必带入）**｜建置禁度数｜投影锁｜ENV名↔触发｜OS/自白等明文闭嘴｜三联+侧面硬锁｜终态≡建置｜速查含暂不可见｜§15①–⑧｜§30/31｜§8。任一项冲突→整拍/整场重写。

## 2. Scene 与环境
> 完整口径 §9–§11、§16；下文流程速查。
- **流程**：四问判 Scene → **核销上游同环境**（命中则锁定复用名）→【场景名称】(剧情+复用主名) → 定需求 →【主环境】(继承上游骨架；无则新立；**情节确认异地→可新建**；快速闪回/蒙太奇可同场多主，§7/§11) →【未落清单】→【衍生】(须覆盖每一主环境族) →【观察视角与空间建置】(速查表+Beat索引) →【Scene实体覆盖】→ 每 Beat 完整重写建置（内部速查+查表；成稿首句当前ENV+视角落位）。
- **四问**：时/空/线/目标连续？任一断→新 Scene。另核**内容是否适配当前主环境**——不适配则拆（§9）；闪回切分见§7（快闪/蒙太奇不新起 Scene；较长回忆须新起）。切分以本节为准，可不依赖上游场次。
- **禁令**：纯情绪词/景别/特写≠环境（**≠可删该行画面**——原文`△近景`/`【特写：…】`须入戏核销，§1）；Insert/CU禁另建衍生；停顿/表情/正反≠新 Scene。**例外**：跨拍可持续重大氛围/风格切换→须建状态衍生（§11）；情节确认不在当前环境→另立主环境（非状态衍生）；**环境/服化道剧变且停留较长→新 Scene 或另立主环境**（§7 初始态锁定+§9）。
9. **Scene切分**：四问+适配。**须拆**：时/空(越四向包络)/线/目标断；多线各地点各场再穿插（§7）；**较长回忆片段**（§7）；**原文初始环境被剧情大幅改写且后段仍长时间停留于改写后空间**（§7 服化道/环境初始态锁定——禁把改写结果回填原主环境；停留长→新 Scene，短时可持续→状态衍生）。**不适配**：①动作越出本场｜②对白异地异线｜③须换主环境→后段新场+转场四步（**例外**：快速闪回/蒙太奇异地快切→同 Scene 多主环境，§7/§11，不新起 Scene；较长回忆→须新起闪回 Scene）。禁删剧情、禁电话消解真空间切换。**可并**：四问连续且适配。**禁拆 Scene**：仅视角/特写/正反（特写仍须成 Beat 入戏，禁整行删除）；假多线。闪回§7。**场景名**：`【场景名称】{短名}｜日夜·内外｜季节｜气候｜叙事线`。**场景描述融入Beat**（禁只挂场头；首落优先切场+首拍，§7）：场头文学/氛围/`△俯拍·航拍`/`【空境/空镜：…】`建立句，以及原文`△近景·特写`/`【特写/近景：…】`景别行，均须进首拍/独立建立拍/特写切口拍入戏（§1），禁只留【主环境】或场注，禁因「景别≠环境」丢特写画面。
10. **环境定义（§11）**：空镜骨架+具名出入口；变化主体→环境、动作→Beat。**同环境复用（最高）**：上游同空间名→主名/衍生主名段**逐字复用**；日夜不同不另起名；仅无上游且硬需才新建。因剧本而生；**先定本场活动空间再落实体**；禁装饰扩写/未用冗余衍生；每场三块齐全（多主环境时每主各齐）；无人像；禁材质光色细参。**主环境=原文初始建立态**（场头/空境/开场），禁用后文剧情终态改写基准（§7）。
11. **主环境 / 未落清单 / 衍生（四向美术归 Stage 3）**
  > **不变式**：衍生对**所属**主环境固定实体不增/不减/不矛盾；仅可见性与方向性朝向可变。**主环境骨架与服化道「环境细节」锁定原文初始态**——剧情造成的破损/狼藉/域场改写/日夜突变等不得回填进【主环境】固定清单或初始摘要；须走 Beat 过程 / 状态衍生 / 新 Scene·新主环境（§7）。
  > **⑤唯一性**：默认每功能实体**在所属主环境内**1具；**门/窗默认唯一**；多件→总个数→逐具具名+区分特征。⑤-b同质≥2须分边/各向个数+朝向+同侧顺序。⑤-c配套：桌↔椅｜床↔被枕｜杯↔盏托。
  > **⑥全覆盖**：剧情实体全入**所属**主环境清单；Stage2.1再XOR裁PROP；禁两侧双出或双消失。⑦均衡：禁过挤/过空；**活动区净空**——主舞台/表演区/动线/站位承载区**禁止**布置无剧情硬核销的立体实体物件（家具障碍等）；仅贴地层或剧情必需锚（对白桌/座次椅等）可占；其余陈设落边缘/背景向。⑧出入口：具名门/洞/巷口；禁穿墙；默认单门。
  > **衍生最小化**：须切=任何反打/OTS看对手(不论≤90°)｜**角色相对镜头正背面档位变化**（正面/¾↔侧面↔背对/侧背面；含左↔右侧面）｜越轴｜>90°｜门窗内外/POV/状态｜异排异向。禁另建=非反打Insert/CU/同侧过肩**且正背面档位不变**。反打却同父ENV=失败；**正背面档位变却同父ENV（无明文转身）=失败**。
  > **本阶段只出角度清单**：名/`view_angle_from_main`/触发/`spatial_axis`/`lens_profile`/`axis_crossing`/`empty_view_delta`；**头尾双锚**必声明；四向对位归Stage3。顺时针=俯视。
  - **情节异地→新建主环境 + 闪回 Scene 分档（最高）**：
    - **默认**：一 Scene 一块【主环境】+ 其【衍生】族。
    - **新建环境（强制；据情节判定）**：凡情节确认**不在当前主环境**（时空/地点/回忆落点与当下包络不合——原文具名、场头/空境、或剧情可核销的异地意图均可）→ **须新建【主环境】**（完整骨架：名称｜日夜内外｜活动空间｜俯视360｜四向+中心｜0°轴｜头尾双锚｜固定清单）+ **对应【衍生环境】族**（含强制 `0度{该主名}`）。可据情节合理命名与建骨架；**禁止**因「原文未写全称地点」而硬挂当下主环境衍生。同环境复用优先（§10）：上游已有同空间名→复用，勿另起同义名。
    - **快速闪回 / 蒙太奇（不新起 Scene）**：短切、印象链、多地快切、嵌入当下的短暂回忆 → **留在当前 Scene**，同场声明多块【主环境】（当下 + 各快闪/蒙太奇落点），各挂各衍生族；Beat `ENV变=是`，触发=`闪回切主环境|蒙太奇切主环境|回切当下主环境`。蒙太奇每落点各一主环境，禁单主四向硬塞多地。
    - **较长回忆片段（须新起 Scene）**：可持续回忆戏——完整对白链、多 Beat 叙事推进、可独立成场的时空块、或连续回忆明显长于快闪（典型多轮对白/完整事件/等效≫快闪专拍）→ **拆为独立闪回 Scene**（场景头叙事线=`闪回`），该场自有【主环境】+衍生；回切当下另场或经转场四步咬合。禁把长回忆硬塞进当下 Scene 多主环境凑合。
    - **标注**：每块主环境写`主环境角色=当下主线|闪回|蒙太奇片段{序号}|回切锚`；同场多主时【观察视角与空间建置】列主环境清单与 Beat↔主环境映射。
    - **切主环境（同场快闪/蒙太奇）**：建置写【上一ENV→触发→本ENV】；世界扇区/F **按新主环境 0°轴重新锚定**（异地非反打）。
    - **禁**：①用当下主环境视角衍生冒充异地；②把异地写成当下的状态衍生；③标「反打」却换主名段；④长回忆不拆场；⑤快闪/蒙太奇误拆多余 Scene。无情节≤2s 纯质感切片且情节未要求可读空间→可不另立主环境；一旦情节确认异地可读空间→须建（同场快闪块或长回忆 Scene）。
  - **剧本活动空间（最高；主环境与衍生共同强制）**：规划【主环境】/【衍生】前须通读本场全部 Beat 需求（站位人数、对峙/围坐、追逐逃窜、跪拜、出入画、群演簇位、武戏位移等），使空间**可站、可动、可出入、可分组**——禁只堆陈设导致无表演区，亦禁空旷无锚无法落位。多主环境时**逐主**通读其所属 Beat。
    - **活动区禁布实体物件（最高）**：【活动空间】划定的主舞台/表演区、动线、站位承载区为表演净空——**禁止**在该区内规划/落位无剧情硬核销的立体固定实体（家具/陈设/立柱/屏风/箱柜等）；固定清单其余实体须落**边缘/四向背景侧/非动线区**。例外仅限：①贴地层（地毯等不影响行动）；②本场戏硬核销的表演锚（对白桌、座次椅、跪拜承托面等）且不得再向净空加装饰件。先定活动空间再落实体时，实体落点须服从本条。
    - **主环境须明文写【活动空间】**（紧接名称/日夜后，一段短句，禁省略）：①**主舞台/表演区**（中区净空，可供对峙/对白/跪拜等，**区内无装饰性立体物件**）；②**动线**（走动/逃跑/追逐可通行，禁被固定实体堵死）；③**站位承载**（本场高峰同框人数与分区，如双人门前对峙+随从两侧跪地；有桌则座次区）；④**出入画口**（具名门/洞如何服务进出剧情）；⑤与⑦均衡咬合（活动区净空+禁无据家具障碍）。
    - **衍生环境**：每个视角/状态衍生须服务其触发动作——反打/OTS 保留对戏双方可读站位纵深；逃窜/出门向须见目标出入口与通向画外动线；门内外切换须两侧皆有落位空间。衍生行除角度元数据外，加一句`活动适配=…`（非四向美术描写）。**衍生主名段必须=所属主环境名**。
    - **核销**：任一 Beat 落位/运动终点在**当前所属主环境**四向包络内找不到对应表演区或动线锚→回改该主环境或拆 Scene（§9），禁硬塞；闪回异地缺主环境块=失败。
  - **0°轴序**：①上游继承→②该主环境首个非航拍全局Beat的**背景方位**→③特写/航拍开场可主门/中轴预声明。多主环境时**各主各自锚定**，互不共用 0°轴。
  - **四向包络**=法定边界；越界→新Scene或（闪回/蒙太奇）另立主环境。**严禁对向串写**（0↔180、90↔270）。
  - **主环境必写**：名称｜日夜内外｜`主环境角色=…`（单主可写`当下主线`）｜**【活动空间】**｜俯视360｜四向+中心｜0°轴｜头尾双锚｜固定清单(含出入口；⑤全套)；不写前中后景/人物/材质细参。**主环境=基准定义，永不作可拍当前环境**——Beat「当前环境」**永远**只能挂 `{N}度{名}` 衍生（Master=`0度{名}`；其他角=`90/180/270度…`）；**禁止**写裸主环境名作当前环境。
  - **未落清单**：`{具名}｜依据｜开场在场|待入画｜归属主环境={名}`；多主时可按主环境分节；与建置交叉核销。
  - **反打ENV**：`N_对手`→`(N±180)%360`；`ENV变=是`+重建；新 ENV 背景半空间须对应该可读角（据【主环境】描述选 `{N}度…`，禁粘错角、禁挂裸主环境）。非反打Insert沿用父衍生ENV**且背景扇区未变**。异排/异向各备可读角。**反打不得跨主环境名**。
  - **状态衍生**：`{主}_{状态}`；continue期间后续挂该状态；状态后缀挂**所属**主环境名。
16. **三步开场**：吸睛(前5s；宏观8–10s；环境动态+实体动势各≥1；宏观须特写过渡)→建置→入戏；服化道首落；静物预排布；POV可延迟。**原文有建立空镜时**（`△俯拍/航拍…` 或 `【空境/空镜：…】` 或场头环境文学）：首拍（或紧接转场后的第一拍）**必须**以该建立画面作吸睛——入戏写出原文规模/氛围信息+≥1环境动势（`△`俯拍类观察角=航拍/俯拍/EWS；`【空境】`类按描写选 Wide/EWS/环境建立角）；再过渡到本场角色入戏/首个非航拍全局建置（0°轴锚定）；禁开场直接对白而跳过该建立句。
17. **实体覆盖**：只排期(在场/待入画+出入口/离场)；静物默认开场在场；群演可延迟但入画后守恒。

## 3. Beat 建置与空间（§12–§15）
12. **站位与空间建置（强制）**：建置段细则（两段式/主锚/三轴/世界态优先/空镜重述限定见 §1）。**落笔序（强制）**：⓪**正背面档位开拍必检**→⓪-b**当前 ENV↔背景半空间匹配（静止亦检）**（见下）→①承/写世界态(`速查更新`)→②查表→③【建置】画面句→④【入戏】→⑤切换说明(+ENV变台账)。禁：用上拍画面词当站位；度数入【建置】【入戏】；同上；漏应可见；静物中途出现；动作对白混建置；**无功能空镜观光句**（§1 空镜重述限定；**原文`△`/`【空境】`建立句例外，须进入戏核销**）。**三轴须同拍闭合**，冲突口径见 §1/§15。
  - **角色—镜头正背面档位变化必切 ENV（最高硬约束；开拍必检）**：
    - **档位闭集**：`正面/¾`｜`左侧面`｜`右侧面`｜`背对/侧背面`（`侧正面`归正面/¾族；左/右分档，互变亦算变化）。
    - **开拍必检（环节0；写【建置】前强制）**：对每个仍在画角色，比对上拍终态正背面档位 vs 本拍拟写【建置】档位。任一角色档位变化（如原来正面、后来变成侧面或背对；侧面→正面；左侧面↔右侧面等）→ **必须** `ENV变=是`，切换对应可读角衍生 ENV，写【上一 ENV → 触发=正背面档位变化|可读角 → 本 ENV】，按新 N 重投影；**禁止**同父 ENV 下直接改写该角色正背面档位。
    - **唯一例外**：本拍【入戏】有该角色**明文转身/转体过程链**——建置写起始档位、速查写终态 F；同 ENV 合法。下一拍开拍再检时以本拍终态档位为基准。
    - **咬合**：反打/OTS/异排异向/背对突切脸 ⊆ 本条；无明文转身却同 ENV 改正背面=**失败**；因切 ENV 导致的档位变化须与查表一致（ENV变画面必变）。
  - **当前 ENV↔背景环境匹配（最高硬约束；开拍必检；选 ENV 铁律）**：
    - **定义**：本拍「当前环境」**永远**只能是 `{N}度…` **衍生行**（含强制 Master=`0度{主}`）= **本观察视角直接看见的背景半空间**（后景=N°侧）。机位在 `(N+180)%360` 侧看向 N°；画内背景/后景具名实体须∈【主环境】**N°扇区**（及该衍生 `活动适配`/`empty_view_delta`/触发声明的可见半空间）。
    - **永远不用主环境作可拍 ENV（最高）**：【主环境】名只作基准定义/所属主名段；Beat「当前环境」**禁止**挂裸主环境名（❌`当前环境 办公室会客区`｜✅`当前环境 0度办公室会客区` 或 `180度…`）。需要 Master/0° 轴观察侧时，**必须**写 `0度{主}`，**不是**主环境本体。
    - **按描述选角、非无据粘 0°**：`0度{主}` **仅**当本镜背景确为 0°轴锚定扇区时选用；其他背景扇区挂对应 `{N}度…`。**禁止**因「Master 熟悉」而无据粘 `0度`，亦**禁止**用裸主环境名代替 `0度`。反打/OTS/可读角/正背面档位变化后往往是 90/180/270——须据【主环境】四向+中心/固定清单/头尾双锚**按描述裁定**该挂哪条衍生。
    - **活动适配=背景可见面（最高；Beat↔衍生必对齐；静止亦检）**：衍生行 `活动适配`/`empty_view_delta` 写明的「可见{具名}」= **本拍画面深处/后景应出现的实体**，不是「本场有这扇门」的泛指。**凡有角色落位的 Beat——含完全静止对白/站立/跪坐、无走位、无出入画——开拍仍必须核销后景适配**；禁因「人没动/ENV变=否/同上」跳过。选当前 ENV 前先读该行活动适配，再核建置（静止拍重点核：角色背后/画面深处可见何物 vs 活动适配）：
      | Beat 画面事实 | 应挂的衍生（据活动适配） | 禁挂 |
      | :--- | :--- | :--- |
      | **静止**站/坐/跪：背对镜头、面向后景（后景应是内侧/王座等） | `活动适配`含「可见王座/内侧纵深」的角 | 「可见大门」的 `0度…`（大门不应在其背后后景） |
      | **静止**正面朝镜头：其身后/后景应见大门侧 | `活动适配`含「可见大门」的角（常=`0度…`） | 「可见王座」的对向角 |
      | 后景/背景可见 **Main Door/大门**；角色自背景门朝镜头入画（终态正面） | `活动适配`含「可见大门」的角（常=`0度…`） | 「可见王座/内侧」的对向角 |
      | 角色**背对镜头向内走**、推门入殿、面向后景深处（门在近端/身后） | `活动适配`含「可见王座/内侧纵深」的角（常=`180度…`） | 「可见大门」的 `0度…` |
      | 外景航拍/山巅城堡建立（非厅内半空间） | 外景专用主环境族之 `{N}度…`；禁拿厅内衍生冒充 | 厅内 `0度…`（活动适配=可见大门） |
    - **选 ENV 五步（每拍强制；禁跳步）**：
      1. 定本拍观察意图（读谁脸/对白向/出入画门侧/吸睛建立角等）→ 推出所需**背景扇区**（哪一墙/门/窗/景应在画面深处）；
      2. 在【主环境】四向描述中定位该扇区所属 **N°**（及头尾锚归属）；
      3. 在【衍生环境】取 `view_angle_from_main=N` 的行（N=0→`0度{主}`；禁用裸主环境名顶替）；读该行 `活动适配` 确认「可见X」=本拍后景 X；缺行→先补衍生再落 Beat，禁硬挂错误角；
      4. 核销：建置/入戏凡写背景锚、经门出入、面向后景对象，其具名须落在该 N° 可见半空间；机位后方扇区实体**禁**写进本镜背景；**入画径向须与活动适配同拍闭合**（见下条与§12 径向表）；
      5. 与正背面/反打/OTS 规则交叉：切可读角后的新 ENV 仍须通过本条——可读角的背景半空间也须与描述一致。
    - **入画径向×ENV 活动适配三联锁（最高；防「视角与环境视角不一致」）**：经具名门入画时，须同时满足——①门相对本镜层位；②行进径向与正背面；③当前 ENV 的 `活动适配` 可见面。三者任一互斥=整拍失败：
      - ❌典型病（用户案）：衍生 `0度…` 活动适配=可见大门 + Beat 写「前景背对镜头、推开大门向内走」——背对向内 ⇒ 后景应是内侧/王座，门应在近端 ⇒ 应挂 `180度…`（可见王座），**不得**挂可见大门的 `0度…`；若坚持挂 `0度…`（门在后景），则入画须自背景门朝镜头逼近、终态正面背对门——不得背对镜头面向深处。
      - ✅背影进厅内深处：门放前景/近端 + 当前 ENV=`活动适配`可见内侧/王座的衍生 + 建置背对镜头面向后景。
      - ✅迎面见入门者：门在后景 + 当前 ENV=`活动适配`可见大门的衍生 + 终态正面朝镜头。
    - **失败例**：❌挂裸主环境名｜❌`0度`（可见大门）+「背对镜头推门向内」｜❌外景航拍挂厅内 `0度`（可见大门）｜❌门在180°扇区却挂 `0度` 写背景门｜❌反打仍同父 ENV。✅背对入殿→`180度…`（可见王座）+门近端；✅背景门迎入→`0度…`（可见大门）+终态正面。
    - **规则一致性总核**：同一拍内不得出现——「须切 ENV」却仍挂旧 ENV；「已换 ENV」背景锚仍写旧半空间；「景别收紧沿用父 ENV」却写对向扇区实体；裸主环境名冒充可拍 ENV；**Beat 正背面/入画径向/静止站位朝向与当前衍生 `活动适配` 可见面矛盾**；**静止拍跳过后景适配核销**。
  - **角色环境速查（并入【观察视角与空间建置】；跨 Beat 真源）**：
    - **目标**：每人主场衍生ENV+**世界扇区**+**F**+姿态+具名锚；不符→入戏补动作再改表（禁无动作改表）。首句单一当前ENV（有变含切换链）；一拍禁切ENV；**当前ENV须通过背景半空间匹配**。
    - **落位两层（强制分立）**：
      1. **世界层（真源）**：扇区∈`0°/90°/180°/270°侧|轴心`+锚+F+姿态——写入每拍末`速查更新`；无明文走位/转身时跨 ENV **原样继承**。
      2. **画面层（投影）**：由本拍 N 查下表得到——只写入【建置】【入戏】。ENV 名中的 N=观察轴；禁 ENV=`180度…`却按 0° 轴写左右。
    - **ENV 变画面必变（最高；无走位亦然）**：仅切观察轴、无人走动时——世界扇区/F **不变**，但每人画面层位/左右/正背面**几乎必变**（180° 反打→前景↔后景且正背面对调；90° 切→原前后变左右等）。若 `ENV变=是` 且未动者画面句与上拍**同侧同层同正背面** → **生成失败**（典型病：换了 ENV 名，人仍写在「前景中央正面」）。
    - **视角换算速查表（强制；切角必查；禁凭直觉）**：观察轴=主环境 **N°**（ENV=`{N}度…`；**N 以 ENV 名为准**）。无走位时世界扇区不变，仅按下表重判（俯视顺时针；机位在`(N+180)%360`看向N；**画左=`(N+270)%360`，画右=`(N+90)%360`，后景=N°，前景=`(N+180)%360`**）：
      | 世界扇区（相对主环境 0° 轴） | N=0° | N=90° | N=180° | N=270° |
      | :--- | :--- | :--- | :--- | :--- |
      | **0°侧**（纵轴+ / 原后景侧） | 后景/远端 | **画面左** | 前景/近端 | **画面右** |
      | **180°侧**（纵轴− / 原前景侧） | 前景/近端 | **画面右** | 后景/远端 | **画面左** |
      | **90°侧**（横轴+） | **画面右** | 后景/远端 | **画面左** | 前景/近端 |
      | **270°侧**（横轴−） | **画面左** | 前景/近端 | **画面右** | 后景/远端 |
      | **轴心** | 中景中央 | 中景中央 | 中景中央 | 中景中央 |
      **落笔**：①世界态→`速查更新`；②查表→画面（ENV变须填`视角换算台账`）；③【建置】【入戏】只写画面词。禁跳过查表；禁把查表句写进【建置】正文。
    - **F↔正背面（最高；内部F°/N°，成稿禁度数）**：用世界朝向F与观察轴N核销——**禁**凭主角身份另写正面。ENV=`{N}度…`→后景=N°侧，前景=`(N+180)%360`侧：
      | 世界朝向 F 相对观察轴 N（**仅内部**） | 相对镜头正背面（默认） | **成稿可用表述（禁写 F°/N°/°侧）** |
      | :--- | :--- | :--- |
      | **F ≈ N**（与镜头同向看向后景） | **背对镜头**（背面/侧背面为主） | `背对镜头` / `背面朝镜头` / `侧背面朝镜头`；口型**不可读**；可补 `面向{后景具名对象}`（禁裸「面向…深处」） |
      | **F ≈ (N+180)%360**（朝向机位/对向观察轴） | **正面或¾面朝镜头** | `正面朝向镜头可读` / `侧正面朝镜头`；可补 `面向前景` / `面向{前景具名对象|入画者}`；**禁**写侧背面/背对 |
      | **F ≈ (N+90)%360** | **右侧面朝镜头** | 鼻尖朝**画右**（见下硬锁） |
      | **F ≈ (N+270)%360**（≡N−90） | **左侧面朝镜头** | 鼻尖朝**画左**（见下硬锁） |
      **侧面↔面向硬锁（最高；角色自身左/右）**：`右侧面`=右颊对镜⇒鼻尖朝**画右**；`左侧面`=左颊对镜⇒鼻尖朝**画左**。口诀：**见哪侧颊，鼻尖朝同侧画幅**。成稿**只许**：
      | 正背面 | 面向 | 对应内部 F（相对本拍 N） |
      | :--- | :--- | :--- |
      | `左侧面朝镜头` | **必须** `面向画左`… | F≈(N+270)%360 |
      | `右侧面朝镜头` | **必须** `面向画右`… | F≈(N+90)%360 |
      ❌`右侧面+面向画左`｜`F≈0`却写侧背面（N=180 时 F≈0=正面）｜`F≈(N+180)`却写背对。面对面：看画左=`左侧面`；看画右=`右侧面`。
      ¾面须与朝机/背机侧一致。**侧背面仅属 F≈N 族**，禁用于 F≈(N+180)。相向默认：前景背对↔后景正面。**三联句（最高）**：层位+正背面+面向对象层闭合——
      | 正背面 | 面向对象所在层 | 判定 |
      | :--- | :--- | :--- |
      | **正面/¾朝镜头** | 对象须在**前景(离镜近处)**侧（或同层偏镜头侧） | ✅；❌ `正面朝镜头 + 面向后景的{人}` = **成稿失败**（脸朝镜头却看向背景，物理矛盾） |

  - **七要素/露出/特写**：位置｜姿态｜身体朝向｜正背面(F≈N→背对)｜与他者(面对面)｜视线｜动作方式。场内每具名≥1次正面/¾。特写预标`角色→可读脸Beat→ENV→转正`：已正面｜入戏转正｜切可读角+重建。**背对禁突切脸**/Push In；**凡正背面档位须变（无明文转身）一律先切衍生 ENV**（开拍必检，见上）。
  - **站位**：主锚优先相对ENV；他人优先相对主锚。阵列≥3标左中右/前中后。**同层多人分位（强制）**：≥2人同处前景/中景/后景时须分`画左|中央|画右`（或相对主锚左右），禁两人同写「前景中央」。速规：礼法｜尊者居中前｜有桌凳优先坐下(椅名位序；>4人两区)｜>3人分组挂四向ENV｜群演拉开可延迟(入画后守恒)。移动=`起点→意图→朝向→节点→速度→具体终点`。
        - **入画径向↔正背面硬锁（最高；经门必核）**：先判出入口相对本镜层位，再锁径向与终态正背面——禁三者各写各的。无明文转身按下表：
          | 出入口相对本镜层位 | 入画行进径向（无转身） | 入画终态默认正背面 | 出入口相对入画者 |
          | :--- | :--- | :--- | :--- |
          | **背景(远处)/后景** | 自背景门洞 **→ 朝镜头**（向前景逼近） | **正面/¾朝镜头**；须锚「面向{内侧空间}（**背对{门名}**）」 | **身后**（门可仍写在背景） |

          | **画左/画右侧缘** | 自该侧入画后沿横/斜轴 | 侧/¾面为主；终态面向须与入室/入殿意图一致 | 按轨迹核销 |

        - **载具/骑乘**：载具写轴向+占道+节点（§31）；弹道=`出手→路径→命中→效果`同施力拍。骑乘每拍保留坐骑+骑姿+落位至下马；终态含人+载具。
    - **对白咬合（最高；建置↔入戏方位必须同拍闭合）**：每句`对{具名}|对镜头|望天/空位|画外声源`；称呼锁定。他人目光默认朝说话人。轮次=新Beat；异排异向各切可读ENV。口型不可读先切ENV；反打必切。
      - **方位词核销（强制）**：入戏若写`对画左/画右的{名}`／`望向画左/画右`／`朝画左/画右退去`等，该方位**必须**与本拍【建置】中该角色（或路径终点）的画面左右**一致**；对象在「中景/前景中央」则禁写「对画左/画右的{名}」（应写`对身后/对面/近前的{名}`或先改建置落位）。
      - **对白向↔身体朝向**：默认说话人面向/目光落在对白对象所在侧；若剧情刻意避开（侧身、背对、慌乱退开），须同时写清①身体朝向②目光/喊话方向③例外情绪——**禁止**建置写「面向画右（避开X）」而入戏写「对画左的X」却无「回首/侧喊/目光甩向画左」等可拍过渡。
      - ❌失败例：建置「Rupert 中景中央 + Serena 前景中央面向画右」↔入戏「对画左的Rupert」= **方位互斥，整拍失败**。

13. **观察视角—实体落位**：每拍必写。填：衍生ENV（Master=`0度…`；**禁裸主环境**）｜观察角(含OTS四要素)｜目标｜可见边界。写前核：∈清单｜须切则切（含**正背面档位变化**）｜**背景半空间匹配（§12；按描述选角）**｜非反打Insert沿用**且正背面档位不变且背景扇区未变**。航拍不作0°轴。
14. **景深公约（最高）**：相对镜头。前景=最近、背景=最远。朝向≠人所在层。扇区≠景深：N°=后景；N+180=机位后方不可见。**背景层具名实体须∈当前 ENV 之 N° 可见半空间**（据【主环境】描述核销）。浅景深可虚焦，在场道具不得删终态。
15. **建置重评估 + Beat切换说明自检（强制）**：每拍完整建置（`建置更新=是`；同ENV抄写/ENV变**画面重投影**见§1/§12）。**终态↔建置双向闭合（最高）**：建置具名集合 **≡** `{Beat终态画内实体}`（=本镜**可见**名单）；**切角/反打/景别收紧≠清场/≠出画**。`角色分组=`禁「同上」。
  - **差集跨拍重析（最高；每拍落笔前强制；含静止/同ENV）**：
    - **输入池（并集，禁漏）**：①上一拍 `{Beat终态画内实体}`；②上一拍 `差集处置` 中全部 `暂不可见` 行（未明文出画者）；③上一拍 `速查更新` 场内未出画全员。本拍须对输入池**逐名重新分析**，不得照抄上拍「通过」完事。
    - **三态判定（每名恰好一态；先查表再定性）**：对输入池每人用本拍 N + 其世界扇区查§12 换算表，得 `投影层位`∈`前景|中景|后景|画左|画右|中央` **或** `机位后方/画外`：
      1. **仍可见/已转可见（强制带入）**：`投影层位`∈前景/中景/后景（任一层，含后景虚焦）→ **必须**写入本拍【建置】+`{Beat终态画内实体}`+`速查更新`（可见性=画内；`ENV变=是` 时重投影）。禁因「不是对白焦点」「Medium/CU」「群演」省略。曾为暂不可见、本拍查表可见 → 差集写`已转可见|带入建置=是`，**漏带=整拍失败**。
      2. **合法离场（唯一可清场路径）**：本拍【入戏】明文可拍出画（经具名出入口/退画外至可核销终态）→ 该名**不得**再入本拍终态/建置；速查可标`已出画`或删除；差集处置写`出画|经…`。
      3. **暂不可见（仅当查表=机位后方/画外）**：`投影层位`=机位后方/画外，且无出画——**≠出画**。方可不上建置；须（a）速查保留世界态可见性=暂不可见；（b）差集续挂全字段；（c）之后任一拍查表变可见或回挂靠视角 → 态1强制带入。
    - **回挂靠视角必恢复（最高；防随从蒸发）**：若上拍/历拍 `差集处置` 写明 `挂靠视角={X}`，且本拍当前环境 **=`{X}`（同角衍生，含同主名段+同 N）** → 该人**默认已转可见，必须带入建置**，禁止再标暂不可见。❌用户案：`Entourage|暂不可见|挂靠视角=180度酒店大堂` → 本拍切到 `180度酒店大堂` 却仍写暂不可见/原因=景别收紧、终态只有 Serena+Rupert = **失败**。✅同拍须：建置写入 Entourage（按 N=180 重投影层位/正背面）+ 终态含 Entourage + 差集`已转可见|带入建置=是`。
    - **景别收紧不得否决查表可见**：仅当查表已为机位后方/画外时，方可因景别维持暂不可见。若查表得前景/中景/**后景**（含 `画面应位=后景/中央`），**禁止**用「Medium/景别收紧」继续挂暂不可见——后景仍属画内，须写入建置（可写虚焦/远处）。挂靠视角已回到当前 ENV 时，**一律禁止**再用景别收紧挡恢复。
    - **`差集处置` 格式（强制可检索；禁只写「通过」）**：
      - 出画：`{名}|出画|经={出入口/画外}|相对上拍=…`
      - 仍可见：`{名}|仍可见|重投影=是|否`
      - 暂不可见（**每名必填全字段**；且本拍查表须=机位后方/画外）：`{名}|暂不可见|挂靠视角={N}度{主}|世界扇区={0°侧|…}|画面应位={若可见则前景|中景|后景}/{画左|中央|画右}|相对={具名角色或锚}|姿态={…}|正背面若可见={…}|本拍投影=机位后方|原因={切角机位后方|…}`（原因禁单独写「景别收紧」而无本拍投影=机位后方）
      - 已转可见：`{名}|已转可见|带入建置=是|自挂靠视角={…}|本拍投影={层位/左右}`
    - **续挂与带回**：上拍暂不可见且本拍查表仍=机位后方 → 刷新暂不可见行；查表可见 **或** 当前ENV=挂靠视角 → **禁止续挂**，须态1带入。后续 Beat 以上拍 `差集处置`+`速查更新` 为真源；`ENV变=是` 时视角换算台账**必须含**输入池每一名（含暂不可见→可见的转换行）。
    - **禁止**：静默删名；回挂靠视角不恢复；查表后景/前景却标暂不可见；用「景别收紧」否决挂靠视角恢复；已转可见却不带入。❌`挂靠=180度…` + 本拍`180度…` + 终态无 Entourage。❌扇区=180°侧、N=180（后景）却可见性=暂不可见。
  - **`速查更新`（每拍必填；=场内世界态，含暂不可见）**：`{名}|扇区=…|锚=…|F≈…|姿态=…|主场ENV=…|可见性={画内|暂不可见}`。覆盖**所有未出画**角色（画内+暂不可见）。画内者：扇区→层位须与【建置】一致（有走位则建置=起始、速查=终态，由入戏闭合）。暂不可见者：扇区/F/锚继承上拍，可见性=暂不可见。无走位/转身：扇区与 F 逐字承上拍。❌`轴心`+建置「前景中央」。缺速查/未出画却从速查蒸发=失败。
  - **`视角换算台账`（`ENV变=是` 必填；否则`N/A`）**：**输入池全员逐行**（含上拍暂不可见的随从/群演，禁只写对白二人）：`{名}|扇区=…|F≈…|N={本拍}|→画面={前景|中景|后景|机位后方}/{画左|中央|画右|N/A}|正背面={…|N/A}`。`→画面`∈前景/中景/后景 → 该名**必须**在建置+终态；`→画面=机位后方` → 方可暂不可见。可见者→画面/正背面≡建置；未走位可见者画面三项≠上拍全同。台账缺随从/差集池任一名=失败。
  - **【Beat切换说明】必含字段**（缺任一项=不合格；不可只写「通过」）：
    1. `建置更新=是`｜`ENV变=是|否`｜`{Beat终态画内实体}=…`｜`角色分组=…`｜`上拍终态差集=…`｜`差集处置=…`（含暂不可见续挂/已转可见带入；须重析上拍差集）
    2. **`建置·朝向·视角自检:`**（须可核销，禁空话）——
       - **视角**：当前ENV=衍生行（禁裸主环境；Master=`0度…`）｜轴一致｜ENV变触发（反打/正背面档位变化须主名段不变）｜查表=是|N/A｜**正背面档位开拍检=通过**｜**背景ENV匹配=通过（静止亦检；活动适配≡后景）**｜**径向×活动适配=通过|N/A**
       - **朝向**：F↔正背面｜侧面硬锁｜三联｜对白向↔落位｜径向/反打对调|N/A｜OS/自白等明文闭嘴｜**档位变↔ENV变闭合**
       - **建置**：五锁=通过｜承接｜同ENV抄写或重投影｜建置无F≈｜投影锁=扇区≡层位｜姿态/同层分位｜终态≡建置｜差集重析=通过｜**回挂靠必带入=通过|N/A**
    3. `视角换算台账=…`（或 `N/A`）
    4. `建置逻辑核销=通过`｜`摘要=①–⑧全过`（未过→`失败｜冲突=…`，整拍重写）
    5. `速查更新=…`（场内世界态：画内+暂不可见）

## 4. Beat 切分与时长（§25–§29、§31；角色粒度见 §1）
> 切分以本节为准；**先定 Beat 粒，再验时长**；**禁** `Shot/Lens Preference` 驱动切分。
- **强制另起**：说话人轮次变更（角色粒度）｜>20字拆句各拍（§25）｜**可拍 ENV 名变**（含任何反打、**角色正背面档位变化**、>90°/越轴/POV/门窗内外/状态）｜听者开口应答｜Reveal/域场变｜决战·宏观阶段节点（§27/28）｜新主动施力且非快链｜转场/闪回专拍｜**原文建立空镜**（`△俯拍/航拍…`｜`【空境/空镜：…】`｜场头环境文学；可与首节拍吸睛合并为独立建立拍；禁并进对白拍而删画面信息；无人戏时仍须独立拍）｜**原文独立景别/特写行**（`△近景/特写/…：…`｜`【特写/近景/大特写：…】`——承载与邻行不同信息单元时须独立拍或紧邻特写切口拍入戏；禁整行删除；轴未变则沿用父 ENV，禁另建特写 ENV）。
- **不强制另起**（同 ENV、轴未变、**正背面档位不变**）：≤90°**非反打** Insert/CU/同侧过肩（禁另建衍生；**模型自增**的景别收紧可并入说话人正文；**原文已单列的`△近景`/`【特写：…】`不得用本条豁免删除**——见上「强制另起」与§1；**反打/正背面档位变不得归本条**）｜同人连续≤20字未打断｜快链攻防换手。不另起≠省建置；一拍内禁中途切 ENV；凡新拍/ENV变须完整重写建置。
- **快链可合并**（§二）：同节奏单元、连续动量、无停顿的无对白/武戏链。硬下限：决战≥10｜宏观≥6。
- **时长**：等效≈对白+动作+留白+奇观，宜 4–15s；中文≈字/4、英文≈词/2.5；追杀节点 2–4s（整链≥20s）；**禁**为凑时长改切分。
25. **对白拆句**：【对白拆句判定】=`已拆句|未拆句|无对白`；>20字必拆并落独立 Beat；**不改词、不删字、不换序**（仅允许在原句边界或自然停顿切开）；拆后各拍`{台词}`拼接=原文全句（项目语言侧）。
26. **客体禁独立拍**：受力/飞物并施力同拍；新主动作才可新拍；载具≠客体（§6）；快链优先合并。
27. **正式决战**：≥10 Beat；对峙→试探→攻防≥4轮→术法域场→逆转→决胜→收势；阶段内可快链；高成本≥3；输出【决战 Beat 规划】+【打斗快慢规划】。
28. **宏观群体**：`宏观群体=是`→≥6 Beat。判定：大军/对冲/兽潮/机群/舰队/人海等（≠2–3人簇）。三要素：无边际满幅｜阵势威武(前中后满编+真实参差，禁机械同步)｜压迫感；高潮三项齐。主角每拍可追踪；阵势/高潮各≥1全景+≥1特写（七-D）。结构：全景→阵势→压迫→指挥→对冲→余波。输出【宏观 Beat 规划】。
29. **等效时长**：下游单镜 4–15s。切分只服从完整逻辑（粒度/拆句/ENV变/§26–31/快链）；先产出再验算。硬下限：决战≥10｜宏观≥6｜追杀≥20s且节点≥3。【Duration Estimate Basis】=对白+动作+快慢分项+追杀+留白+奇观；集级 reconcile 不得违规压/扩 Beat。
30. **打斗快慢**：升格≈30%(25–35%；>40%滥用；<15%且无快连击=失败)；常速≥50%；每场≥1快连击(≥3招具名+攻防，可同拍，禁全升格)；须穿插特写；缺 30-A/B→缺口。
**§30-A 立体快链**：凡场≥1快连击须≥1 Beat 本模式；动笔前自【主环境】择≥2具名结构。七维最低：①≥2部位+≥3击具名｜②位移≥3次攻守各≥1｜③每招↔挡/闪/拆/反击｜④≥1上下段｜⑤≥2 ENV结构｜⑥融合≥2层(30-B)｜⑦常速≥50%本链升格≤1。提交≥6/7通过。
**§30-B 环境融合**（同拍）：起点≥2结构锚+材质/光区一句；每拍≥1 ENV信息；命中有陈设反馈。四层 A结构｜B材质｜C光影｜D动态。禁抠图空白互殴。
**句式骨架**：`{常速} 起点：{ENV}+双方落位+材质光区。拍n 甲【招】→乙【应】+位移/陈设反馈…；{升格}读命中。终态换区。` ❌无招名｜站桩｜中段无ENV｜全升格。输出【打斗快慢规划】标30-A+七维+A–D层。
31. **追杀/穿梭**：连续位移动量（禁结果概括）。节点≥3（相对距离可核销）；载具主语写路线+方向+特殊动作+相对态（§6）；门洞进→经→出（六维）；跨拍动量承接；可快链仍≥3节点。整链≥20s、≥2 Beat（或单拍≥12s且≥3节点）。入缠斗写撞停/下马；须特写。❌一路狂奔｜1拍抓到｜无路线。输出【追杀/穿梭链规划】。
## 5. 对白与表演
5a. **母语地道**：按项目语言×地理×时代原生写；禁翻译腔；方言用`用{语种}说道{}`。
  - **中英同义去重（最高；服从项目语言）**：权威源=`project_language` / `Language` / `Project Context.Language`（项目信息明确的语言）；未明确时跟随剧本主语言。输入剧本中**同一语义**的中英并列——括号对译、斜线双语、中英各写一遍、字幕式双语对白、叙述层双语重复等——成稿**只保留项目语言侧**，删除另一语种同义表述。❌`{Leave me alone! / 别烦我！}`（项目中文）→✅`{别烦我！}`；❌建置「大门 main gate 清晰可见」→✅只留项目语言一侧。适用范围：对白/OS、建置/入戏叙述、场景名附属说明、角色设定外形性情、环境块文学描述、服化道摘要具体词。
  - **例外（不删）**：①专有名词/人名原文（如 Serena）；②剧情有动机的异语片段（须`用{语种}说道{}`或明文外语动机，非同义翻译堆叠）；③多语言项目设定下的有动机语码切换（非同句双语复述）。禁输出中英同义双语堆叠。
5b. **场面丰满**：禁只堆动作对白；每场≥1背景锚（对白/互动/环境/`<>`声）；场景描述融入 Beat（§9）；服化道首落（§7）。
5. **细节特写**：每场≥1；脸部服从§12可读性；原文细写道具须有特写切口。**原文已写`△特写/近景`或`【特写：…】`时**，该行即强制核销切口（§1），不得因「每场另凑一条」而替换或省略原文特写内容。
6. **微表演**：过程链；**口型对白**开口≥1面部微表情；**OS/V.O./旁白/自白/独白/内心**改为明文闭嘴+≥1非口型微表情（眉眼/呼吸/视线等）；听者微反应；禁抽象情绪词（见下表）。
7–8. **表演连贯**：承接上拍落点；操作链无跳步；原文表演层逐项核销（服从§1 原文逐字核销）。
- **格式**：音效`<…>`｜台词`{…}`｜方言前置标注。
- **语气层（每条必填）**：`voice_type`｜`voice_identity`(禁省略)｜`tone`｜`speed`｜`volume`｜`rhythm`｜`stress`｜`pause` + `{台词}`；与微表情咬合。声线选型：领导/御姐/萝莉/村妇/老者/军人/书生/反派/市井（具体化）。禁只写 tone。
- **OS/V.O./旁白/自白闭嘴（强制）**：凡 `voice_type∈{画外音,OS,V.O.,旁白,自白,独白,内心}`——建置或入戏须**逐人写明闭嘴/闭口**（可写「闭口倾听」「闭口内心状」）；禁省略、禁写「开口」、禁对镜头口型 lip-sync。分型：①OS/V.O./旁白/画外音→画内可见全员闭嘴（含群演）；声源人若在画外则不写其画内落位。②自白/独白/内心→须方向锚；**发言人本人亦闭嘴**（内心状，不张嘴对口型）+画内他人逐人闭嘴；画外声源不列入画内段落。
- **思想转自白**：心知/暗想→自白或短OS；禁作者旁白；转写后仍须服从上条明文闭嘴。
- **情绪外化**：≥2项过程链。悲=低头塌肩｜怒=下颌绷+握拳｜惧=眼骤张+后倾｜紧=手敲/游移｜羞=视线躲开+唇咬｜犹豫=抬手中停｜决心=视线定｜温=轻抬手｜冷=斜睨｜喜=唇角扬｜愧=回避｜杀意=视线定死。
- **强度**：夸张/细腻/标准；文戏局部特写≥3。影视标签仅服务剧情。
## 6. 动作与武戏（§二、§27–§28、§七）
- **动作规格（七项织入流畅句）**：①部位+幅度/速度/力度(止于手级)｜②始→终位；门开向内/外；**禁指节贴触**｜③文戏低缓(武戏例外)｜④惯性过渡｜⑤操作链禁跳步｜⑥情绪外化｜⑦因果可感。❌跳结果｜无幅度「抬手」。
- **主节拍/客体**：每拍唯一主动施力方；客体禁独立拍（§26）；施力→命中→反馈同拍。
- **载具独立行**：`{载具名}：…`；人操作与车体分行；追逐=`途经→方向→特殊动作→速度→相对距离`（§31）。
- **快链合并**：同节奏4–15s连续动量可合并；须拆=切ENV/读脸｜Reveal｜域场变｜决战节点｜追杀跨环境/将超15s。
- **位移五元组**：起点→发力→节点→**具体终点**→静止。
- **武戏站位/视角**：Beat间须有可核销三轴落位变化；禁多拍同层位硬换招。每拍环节1–3可检索：观察侧→ENV/[切换]→层位重写→朝向四要素→命中链→终态。读招/读脸须切可读ENV；域场/空战写状态衍生+垂直层位。
- **打击/投射**：近身=`起势→发力→命中→反馈→路径→终点`；投射=`出手→路径→命中→效果`。
- **门窗六维**：①开向+门轴+开闭态+占视轴(切角重判)｜②门内/外POV切对应ENV｜③紧闭禁写门后｜④关闭=阻隔，须开门/破门/经洞等｜⑤口型不可读→切ENV｜⑥`门态→开→通行→带上→关闭终态(默认紧闭)`。禁穿关闭门扇。
- **正方向物件**：屏/证件等=依附位+正面朝向+可读性；亮屏写屏面内容；背板朝镜=不可读。
- **要点**：美感≥1/段；§30升格≈30%+快连击≥1；§31≥3节点/≥20s；决战≥10；宏观≥6。文戏=`触发→视角→特写→承接`；武戏=`视角→ENV→层位→朝向→常速快链→升格短插→终态`。

- **开场**：§16三步+服化道首落；入画经具名口+完整建置。微表演：呼吸/手敲/视线/肩线｜眉眼唇｜喜剧大眉眼(禁脸红)；禁指节贴触。
- **转场总则**：Beat间/场内闪回/场间/首节拍——判定+OT+首节拍**合并写入**【场景切换与首节拍转场】。

- **转场服化道**：切场/换主环境/首节拍首落环境细节、服饰(**换装必交**)、道具；**Part1 与 Scene 内【场景切换与首节拍转场】均须**写标准行`服化道核销摘要：环境细节=…｜服饰/换装=…｜道具细节=…`（无则对应项写「无」）+首Beat落点闭环。**换装明文（强制）**：角色改穿/入场新装/与上场不同装束体系时，「服饰/换装」须写清`{具名}+旧装要点→新装要点`（或「入场即{新装}」；例：`Serena｜员工便服→绝美裙子`），建置/入戏须可见新装落点；禁只写「换好衣服」/「服饰换装」无具名无新旧装束差异——下游 Stage 2.1 据此强制拆新角色行。❌原文礼服+吊灯→首拍直接对白｜摘要换装无具名｜Scene 内省略三项摘要只写散文。
- **服化道/环境初始态锁定（最高硬约束；严格按原文）**：
  1. **权威源**：服化道三项与【主环境】固定清单/文学氛围 = 原剧本对该空间的**初始建立描述**（场头、`△`/`【空境/空镜】`、开场首落、入场现态）——**逐字/逐信息单元**摘抄核销；禁概括改写、禁意译美化、禁下游「为好看」增补回填摘要。
  2. **禁剧情发展回填基准**：禁止把**后文剧情推进后的结果态**写入本场服化道摘要、【主环境】基准、【角色设定】初始外形——如打斗后狼藉、爆炸废墟、火烧烟熏、域场改写后陈设、湿透/血污/战损衣态、道具被毁后残片等。此类变化只进：①Beat【入戏】过程链；②跨拍可持续结构/氛围改写→`{主}_{状态}` 状态衍生（§11）；③明文换装→服饰项旧装→新装 + 衍生行。
  3. **剧变分档（视在该环境停留时长）**：情节对环境/服化道改动过大时，**禁止**用改写后的终态覆盖初始基准，须按下表拆：
     | 判定 | 处置 |
     | :--- | :--- |
     | 短时过程（单拍/短链；可读空间仍是原主环境，未形成可持续新基准） | 只写 Beat 入戏过程；必要时瞬态留 Beat，不改建【主环境】 |
     | 跨拍可持续的结构/重大氛围改写，但仍在同一主空间包络内 | 建状态衍生 `{主}_{状态}`；服化道「环境细节」仍写**改写前初始态**；状态差异进衍生/`empty_view_delta` |
     | 改写后空间已实质异质，且角色**长时间停留**（多 Beat 叙事推进/完整事件/等效≫快闪） | **新起 Scene**（或另立新【主环境】+衍生族）；新场服化道与主环境按**该段起始建立态**重新摘抄原文；经转场四步咬合 |
     | 情节确认已不在当前主环境（异地） | 按§11 新建主环境/闪回分档，不把异地描写并进原主环境 |
  4. **服饰/道具同锁**：摘要与【角色设定】初始着装/道具态 = 该场**入场或开场初态**；中途换装/损毁/拾取→过程进 Beat，结果进换装衍生或 PROP 状态衍生，**禁**把终态衣/物写回基础版唯一描述。
  5. ❌`环境细节=废墟狼藉`却场头原文是完好王宫｜主环境清单写入后文倒塌柱｜角色设定直接写「血污战损装」却开场是整装｜✅初始=原文开场完好/整装；狼藉/战损=状态衍生或新 Scene/换装衍生 + Beat 过程。

- **粒度/多线/闪回**：Beat间Match｜场内快闪｜场间(四问+多线)。并行线禁整段连排，先拆再交叉；异地异线禁硬并。闪回分档+环境（§11）：
  - **较长回忆片段（须新起 Scene）**：可持续回忆戏（完整对白链/多 Beat 推进/独立时空块）→独立闪回 Scene + 自有主环境族；场景头=`闪回`；回切当下走场间转场。
  - **快速闪回（有情节；不新起 Scene）**：嵌入当下的短暂回忆（对白>30字或具名动作、典型≤8s专拍）→**同 Scene**；情节确认异地→新建闪回【主环境】+衍生；回切=`回切当下主环境`。
  - **无情节切片（不新起 Scene）**：≤2s 印象/质感；情节未要求可读空间→可不另立主环境；确认异地可读→同场最小主环境块。
  - **蒙太奇多地点快切（不新起 Scene）**：每落点各一【主环境】+`0度{名}`及所需衍生；Beat 逐点`ENV变=是`（触发=`蒙太奇切主环境`）；禁单主硬塞多地、禁误拆为多 Scene。
  - **新建环境依据**：情节确认不在当前环境即可立新主环境（原文具名或剧情可核销异地意图）；优先§10复用上游同空间名。
- **§19具名**：禁番位当姓名；有真名保留否则合法取名；姓名≠剧情地位；群演簇不具名；宠物按角色。Part1对照表含地位闭集。
- **§19a【角色设定】**：Part2首段；只摘原文已写外形/性情/特定动作；禁发散。语种统一；方言标语种。
## 8. 特效与宏观（六相；库见附录B；宏观§28）
- **驱动力可视化（强制）**：气/灵气/内功/真元/罡气/魔力/念力/力场/剑气等驱动运动时须写可拍介质——禁只写「运功」或只写结果。必写：形态｜轨迹(源→路径→落点)｜作用+反馈｜介质建置承接；小规模可同拍，大规模叠六相。
- **具象化/规格**：大特效优先化龙凤兽/法相（触发→凝形→落点→作用）；禁高潮只写「能量爆发」。启用即写：触发｜因果可感｜具象形态｜范围(锚ENV边界+未覆盖)｜影响(**具名固定实体**逐项；禁「环境震动」无落点)｜六相`起势→显形→扩散→命中→维持→余波`｜时限。跨拍改结构→`{主}_{状态}`（§11）。七-E择1–2+范围/影响各≥1。宏观见§28；群演写簇；小簇≠宏观。
