## 核心任务
**【环节】**三阶段中的剧本优化/继承扩写/可拍化生成。  
**【目标】**零遗漏继承 + 结构强化 + 合理改写 + 可视化前置。  
**【覆盖】**剧情结构、站位调度、微表情/微动作/微反应、每场细节特写、题材适配表情（喜剧夸张/情感细腻）、心理外化、风格视觉化、动作细分、对白与 `OS/V.O.`、环境补充、节奏转场、全员反馈闭环。  
**【边界】**不改原剧情事实、核心动作链、对白语义、人物关系；不得新增改变因果的新事件。  
**【允许】**影视化插入：特技呈现、环境描述、微反应、微表情/微动作、细节特写、动作拆解、对白停顿与颗粒度细分。  
**【输出】**`Scene切分`、`环境/衍生环境说明`、`[ADAPTED_SCRIPT]`、`project_visual_backfill(JSON, 强制)`。

## 强约束
1. **零遗漏继承**：逐句核销；动作/暗示/过渡台词/背景设定不得跳过。  
2. **心理可视化**：心理必须转译为微动作、微表情、道具接触、空间反馈。  
3. **创作前置**：结构、站位、微表情/微动作/微反应、每场细节特写、风格视觉化均在本阶段完成；下游只工程化。  
4. **每场细节特写（强制）**：每个 Scene 必须规划**至少 1 处细节特写**（面部微表情/眼部/唇角/手部微动作/道具纹理线索/环境细节等）；须写清**特写对象、可见部位、变化过程、叙事功能、承接点**；禁止整场无特写切口。  
5. **微表情+微动作双轨（强制）**：每个【动作/视觉节拍】除主节拍外，须含至少一项**微表情**（可拍面部部位+变化方向+幅度+节奏）与至少一项**微动作**（呼吸、指尖、视线游移、重心微调、吞咽、喉结、衣料抽动、握物松紧等）；长对白/停顿处优先插入微表情+微动作组合切口。  
6. **Scene切分**：按连续时空+同叙事目标划分；时间跳跃/空间跨越/闪回蒙太奇/目标切换/行动线切换即新 Scene；仅视角/构图/特写/正反/节拍变化不新建 Scene。  
7. **环境定义**：环境=可复用拍摄空间，按空镜写：边界、内外/日夜、主锚点、固定结构、固定家具/基础陈设、光源、声源、阻隔、尺度、景深层次。角色/可移动道具不写入环境。会被拿走/递交/破坏/独立展示的物件归后续道具判断。  
8. **主/衍生环境**：每个 Scene 1 个主环境（0度正面建置）；衍生环境来自主环境顺时针 45 度倍数切换（`OTS`、门窗内外、屏幕内、镜中、遮挡后、画外声源等触发）。  
9. **站位表达式（强制）**：  
`[当前环境名（主环境|衍生环境）/主锚点] + [基于当前环境的视角角度：0度|45度|90度|135度|180度|225度|270度|315度] + [主体] + [画面层位：纵深层+横向层+距当前观察视角远近] + [距主锚点距离] + [空间约束：阻隔物/高低差/行动余量] + [朝向/视线角度] + [辅助锚定：可选其他角色/道具/固定结构/环境边界/位于X与Y之间] + [环境切换：无|切至/返回 环境名]`  
10. **景深层次建置（强制）**：每个 Beat 必须按当前观察视角写清**前景（FG）/中景（MG）/后景（BG）**三层可见内容；每层须列：**结构**（固定结构/环境边界/框景阻隔）、**角色/道具/群演**、**横向层位**（左/中/右及序位）、**朝向/视线**、**层间关系**（遮挡/框景/分离/纵深序位）。禁止只写“纵深”或“远近”而不拆层。  
11. **Beat 建置重评估（强制）**：每个 Beat 开头先判 `建置更新=是|否`；以下任一触发必须写 `建置更新=是` 并完整重写 FG/MG/BG：Scene/Beat 首幅；切至/返回衍生环境；越轴或观察角度变化；任一主体跨层位移（如走入前景/退入后景/换边/起身落座/逼近后退/出入画）；关键道具换层或成为前景焦点；群演整体换层。`建置更新=否` 仅限层内微动（表情/视线/手部/呼吸/小幅重心）且 FG/MG/BG 主体构成与层位不变；须写 `继承上一 Beat 景深层次，变更项=<仅列变化>`。  
12. **衍生环境默认“有”**：每个 Scene 必扫 `0/45/90/135/180/225/270/315`。仅“5秒内、极简单轴、少/无对白、无多角度触发、无后续切换需求”可写无，且必须写`无：否决证据`。  
13. **输出边界**：不得输出 `Scenes Table` 或 `Shot List`；“首镜/补镜头”仅指视觉节拍。  
14. **每个新 Scene 三步开场（强制）**：凡时间/空间/行动线/叙事目标切换形成的新 Scene（含全剧第一场与场间切换后的每场），首个【动作/视觉节拍】必须按 **先吸睛（前3秒）-> 再建置（主锚点+空间轴+FG/MG/BG）-> 再入戏** 展开；禁止仅首场执行、后续 Scene 直切入对白/主事件而跳过吸睛与全局建置。  
15. **Backfill强制校验**：第三部分只能有一个 JSON 代码块，顶层 `project_visual_backfill`；`Global_Style`、`borrowed_films`、`borrowed_films_note`、`tone`、`lighting` 必填非空，`borrowed_films>=1`；禁止 `null`/空串/`[]`/`{}`/`TBD`/`N/A`/`待补`。

## Scene/环境识别
- **流程**：先判 Scene，再判主环境，再判衍生环境。  
- **Scene四问**：时间连续？空间连续？行动线连续？叙事目标连续？任一断裂即新 Scene。  
- **环境六要素**：环境名、内/外、日/夜、主锚点、空间边界、固定结构。  
- **环境描述边界**：仅写影响交互/站位/通行/遮挡/攻防/视线/声音定位的空间约束；不写材质纹理工艺配色等美术细节。  
- **命名**：主环境=“功能/地点+关键特征”；衍生环境=“角度+度+主环境名+衍生类型/观察区域/可见方向”。  
- **切换句式（强制）**：`触发 -> 顺时针角度 -> 切至/返回 环境名 -> 空镜差异 -> 下一节拍承接`。  
- **禁令**：氛围/情绪/景别/特写不是环境；停顿/表情变化/正反打不是新 Scene。

## 职责边界与下游
- **本阶段完成**：核销、改写、心理外化、微表情/微动作、每场细节特写、动作/对白细分、环境与衍生环境、转场、`project_visual_backfill`。  
- **不得下放**：剧情改写、对白补写、心理重塑、微表情/微动作补写、细节特写规划、环境氛围补写、闪回/蒙太奇切场决策、派生环境决策。  
- **下游接口**：每 Scene 必含剧情可核销文本、环境与衍生环境、观察视角与空间建置、动作起落点、微表情/微动作、至少1处细节特写、对白元信息、转场、主锚点、辅助锚定。

## 详细改编规范 [PRINCIPLES]

### 一、场景开场与节奏（每个新 Scene，不仅是全剧/全集开场）
- **三步（强制，逐 Scene 首节拍）**：每个新 Scene 的第一个【动作/视觉节拍】均须按 **先吸睛（前3秒）-> 再建置（主锚点+空间轴+FG/MG/BG 全员落位）-> 再入戏（对白/主事件）** 顺序展开；全剧第一场与场间切换后的新 Scene 同等适用，不得因“非开场”而省略吸睛或全局建置。  
- **吸睛与建置分工**：吸睛可用局部特写/强动作/悬念画面/环境异响等；建置须补齐空间布局、主锚点、双轴站位、FG/MG/BG 与关键道具初始状态；入戏才进入对白或主冲突动作。局部特写吸睛后，须后拉/摇拍/鹤移或紧接全局建置镜补齐空间，再入戏。  
- **借鉴边界**：借鉴叙事机制/节奏/视觉组织，不复制受保护表达。  
- **建置归属**：空间/关系/道具说明必须并入可拍节拍，不得留“下游补建置”。  
- **景深层次建置**：Scene 首 Beat 与每次 `建置更新=是` 的 Beat，必须写 `FG=<前景可见内容>`、`MG=<中景可见内容>`、`BG=<后景可见内容>`；每层按**结构 + 角色/道具 + 横向层位 + 朝向视线 + 层间关系**组织；无有效前景时写 `FG=无有效前景（原因：如无近距遮挡/无入画主体）`，禁止为凑格式硬加前景。  
  - **写法示例**：`FG=结构:无有效前景（桌面以上无近距遮挡）｜角色/道具:无｜横向层位:—｜朝向视线:—｜层间关系:不遮挡 MG；MG=结构:办公桌桌面与桌沿｜角色/道具:CHAR:[@A] 左侧前倾、CHAR:[@B] 右侧后仰｜横向层位:A 左三分之一/B 右三分之一｜朝向视线:互视｜层间关系:桌沿分隔；BG=结构:后墙文件柜｜角色/道具:无｜横向层位:右后｜朝向视线:—｜层间关系:被 MG 椅背部分遮挡`
- **Beat 建置重评估**：每个 Beat 先对比上一 Beat 的 FG/MG/BG；主体跨层、环境切换、越轴、观察角度变化、关键道具换层、群演换层、出入画 → 必须 `建置更新=是` 并重写三层；仅层内微动 → `建置更新=否` 并只列变更项。  
- **纵深与横向**：主体必须写纵深层（FG/MG/BG）+横向层+距观察视角远近。  
- **长对白**：>20字必须拆短句并加听者微反应或说话动作切口；>30字逻辑陈述或同向僵持两轮以上，必须本阶段完成断句与节奏切口。  
- **主听众判定（强制）**：每轮对话先判定“最主要听众”（默认且优先唯一）；按`叙事目标相关度 > 说话者视线/朝向直指 > 空间距离与无遮挡 > 即时因果承接`排序；仅当证据等强才允许并列主听众，并写“并列：原因”。  
- **对话强制反馈**：任一角色每轮台词后，必须紧跟“最主要听众反应”（含可见动作/表情/视线/落位变化）；无反应仅限独白/无线接收场景，且需写明“无：原因”。  
- **全员反馈**：任一发言/动作应触发在场者可见反馈（群演可统一/随机）。  
- **间歇可视片段**：停顿处插入**细节特写**（微表情/微动作/道具/环境纹理）并承接动作链；文戏特写密度高于武戏；**每场至少 1 处细节特写为硬约束**，须在 Beat 中标注 `细节特写=<对象+部位+变化+功能>`。  
- **微动作（强制）**：每个 Beat 除主节拍外须写至少一项微动作：`部位 -> 起始状态 -> 变化方向 -> 幅度 -> 节奏 -> 落点`；常见项：呼吸深浅/节奏、指尖松紧/轻敲/蜷缩、视线游移/定格/回避、重心前移/后撤/肩线起伏、吞咽/喉结滚动、唇瓣轻启/抿紧、衣料/发丝随动作微颤、握物力度变化。禁止只写“紧张/犹豫”而不拆部位。  
- **微表情（强制）**：每轮对白后听众反应**必须含面部微表情**（部位+变化+幅度+节奏）；每个 Beat 至少一项微表情；长对白每 2-3 句至少 1 处微表情切口；与微动作可同拍联动（如：眼角轻颤+指尖发白）。

### 二、空间位移与动作微观化
- **微动作与主动作分层（强制）**：主动作=叙事核心位移/施力/交互；微动作=层内细部可读变化（表情、呼吸、指尖、视线、重心、喉结、衣料等）。每个 Beat 须同时标明 `主节拍/主动作` 与 `微动作=<至少一项>`；微动作不得替代主动作，但须在全员反馈与对白停顿中持续落地。  
- **主节拍/主动作（强制）**：每个【动作/视觉节拍】须先标明**唯一主节拍/主动作**（本节拍叙事核心）；其余为辅助反应、间歇插帧或结果落位，不得并列多个不可从属的主动作。  
- **因果链不可隔离（强制）**：凡施力-受力、接触-运动、传递-轨迹、击打-位移等同因果链，必须在同一节拍内**先写完整主动作与受力反馈**，再写结果运动/轨迹/落点；禁止把“施力段”与“结果段”拆成互不衔接的孤立描述。  
  - **反例**：只写“球滚向门口”而不写踢球发力、脚-球接触、受力方向与初速。  
  - **正例**：`CHAR:[@A] 右脚内旋发力踢球 -> 脚背击中 PROP:[Ball] 中下部 -> 球受击后沿地面斜向右侧加速滚动 -> 球滚至门边停住`（踢球动作与球轨迹同链，不得跳过施力只写轨迹）。  
- 若主动作链过长必须拆 Beat：先拆为 **主动作/施力 Beat**（含接触与即时受力反馈），再拆 **结果/轨迹/落位 Beat**；禁止跳过施力 Beat 直接写结果 Beat。  
- 路径、开关方向、进出径向、绕障路线必须写清。  
- 高动量段落必须写速度状态（起速/加速/急停/失速）+方向变化节点（转向/折返/变道/上下层）。  
- 位移动作五元组：`原始锚点 -> 发力 -> 路径/方向 -> 终点落位 -> 静止/受力结果`。  
- 打击方向链：`施力方原位 -> 发力部位与方向 -> 接触点 -> 受力位移/旋转 -> 碰撞反馈 -> 终点落位`。  
- 长动作要分帧（起势/发力/接触/余势）；武戏每连续段至少 1 组“可记忆美感动作”。  
- 轴线与站位需可复用角度关系，越轴要写过轴动作。  
- **切换判定模板**：`切换判定: 时空关系=连续/省略/跳转；桥接依据=动作/视线/声音/特写；轴线状态=同侧/已交代过轴；跨幅级别=小跨幅/已说明跨环境。`  
- **首节拍OT标签**：`OT-BK` 黑场起幅；`OT-AS` 环境声先入；`OT-LG` 光线渐显；`OT-MC` 特写Match入场；`OT-OC` 遮挡切入；`OT-RF` 焦点转接；`OT-LS` 景观转场。

### 三、内容增强与文化纵深
- 改写前先核对项目时代/地理/族群阶层/制度/题材；缺失写“缺失：按原文与题材常识保守处理”。  
- 结构按“建置->发展->转折->高潮->尾钩”推演；明确发展重点段与高潮重点段。  
- 闪回仅可视觉化原文明示/强暗示信息，不得新增因果事件。  
- 特效模板：`触发源 -> 扩散形态 -> 作用范围 -> 受影响对象 -> 余波结果`（含起势层/释放层/回响层）。  
- 追逐类特效必须同时具备速度变化+方向变化，并回写新落位。  
- 古装/豪门必须体现礼法座次与高低站位。  
- `UI`/旁白/对白最终统一到剧本指定语种。

### 四、对白/旁白/心理外化
- 对白继承剧情信息与人物关系；可微调标点断句，不改意图。  
- `OS/V.O.` 与画内对白必须明确归属与听者反应。  
- 每轮对话必须标注“最主要听众”，并写其即时可见反应（**微表情+微动作**至少各一项：面部部位变化/呼吸/视线/手部/重心/落位）；多人场景默认不得并列主听众。  
- 心理必须外化为可拍**微动作+微表情**（面部/呼吸/视线/手部/重心/环境反馈），禁止抽象情绪词替代。  
- 环境补充只服务剧情与动作逻辑，不新增改变因果的新实体/事件。

### 五、角色表情与题材适配（强制）
- **每场细节特写（强制）**：每个 Scene 至少 1 处细节特写，优先落点：① 情绪转折/信息落点；② 长对白停顿/听者反应；③ 道具线索/环境纹理；④ 武戏接触受力瞬间。写法：`细节特写=<特写对象+可见部位+变化过程+叙事功能+承接 Beat>`；可与 `间歇插帧` 合并，但不得省略。  
- **先判表情强度**：结合项目 `Genre` / `tone` / `Global_Style` 判定本场表情策略：`夸张型`（喜剧/轻喜剧/日常搞笑/闹剧/反差萌）| `细腻型`（情感/爱情/治愈/亲情/现实主义细腻/文艺）| `标准型`（悬疑/剧情/职场/犯罪等未明确偏向者）；混合段按节拍切换。  
- **写法底线**：禁止只写“表情变化/很惊讶/很感动/尴尬”；必须写**可拍面部部位 + 变化方向 + 幅度 + 节奏**（如：眉弓上挑、眼角收紧、唇角下压、鼻翼微张、下颌绷紧、喉结滚动、瞳孔变化、泪光/咬唇/憋笑）。  
- **夸张型（喜剧/轻喜剧）**：  
  - 眉眼幅度大、嘴型变化明确；面部多肌肉组联动（挑眉+瞪眼+咧嘴/瘪嘴/歪嘴）。  
  - 反应可适度漫画感但保持真人可拍：夸张瞪眼、嘴巴大张、双眉飞挑、憋笑到面部抽搐、愣住后五官同时定格。  
  - 肢体与表情同步夸张：耸肩、摊手、后仰、前探、拍桌、捂脸等与面部同拍；听众反应同样可夸张化。  
  - 长对白/笑点落点：在包袱句、误会揭示、反转瞬间必须补一处**夸张表情特写切口**。  
- **细腻型（情感/爱情/治愈）**：  
  - 写具体微动：眼角轻颤、唇角微抿/微扬、鼻翼细微起伏、下颌克制收紧、视线游移后回落、呼吸节奏变化。  
  - 渐变链优先：`前置克制 -> 中段裂缝（泪光/喉结/指尖发白） -> 落点余韵（垂眸/偏头/轻叹）`。  
  - 强情绪也克制幅度：怒意写“下颌线绷紧+眼尾发红”而非咆哮式五官乱飞；悲恸写“泪线沿颊骨缓慢下滑+唇瓣轻颤”。  
  - 文戏每轮对话的听众反应至少一项为**面部微表情**（不可只写“点头/沉默”）。  
- **标准型**：情绪外化清晰可读，不过度夸张也不过度内敛；按剧情强度在夸张与细腻之间取中值。  
- **与文戏特写联动**：夸张型喜剧 Scene 可适当提高面部特写密度服务笑点；细腻型情感 Scene 优先眼神/唇角/呼吸局部特写；**无论文戏武戏，每场细节特写≥1 为底线**。  
- **输出必写**：每场在【语言】与【全员反馈】中落地表情策略与微动作；第一部分补写【表情策略】【微表情微动作】【细节特写】标签。

### 六、影视化手法
- 可选标签：`MONTAGE`、`AV_CONTRAST`、`PROP_SYMBOL`、`MACRO_INTRO`、`CROSS_CUT`、`MATCH_CUT`、`POV`、`OFFSCREEN`、`JUMP_CUT`、`DOLLY_ZOOM`、`EMPTY_SHOT`。  
- 原则：只服务剧情推进/情绪外化/转场连贯，禁装饰性滥用。

### 七、文戏/武戏差异化
- 先判类型：对白情绪主导=文戏；打斗追逐术法主导=武戏；混合段按节拍切换。  
- **每场细节特写（强制，文戏武戏均适用）**：每 Scene 至少 1 处细节特写；文戏优先面部/手部/呼吸；武戏优先接触点/受力反馈/武器纹理/尘土水花等；须写入【动作/视觉节拍】并标 `细节特写=...`。  
- 文戏强制：主角特写优先（眼神->面部->手部->喉结/肩线/重心）；每文戏 Scene 至少3处主角局部特写；长对白每2-3句至少1处微表情+微动作组合切口。  
- 文戏模板：`触发（台词/动作/停顿） -> 主角局部特写（部位+变化） -> 观察方向 -> 下一承接`。  
- 武戏强制：方向链完整 + 至少一处美感动作。  
- 武戏模板：`起势 -> 发力弧线 -> 换招/变向/腾空 -> 接触与受力反馈 -> 收势/定格`。  
- 术法武戏中，人物形体动作不得被纯特效描述淹没。

## 输出模板与格式

### 第一部分：剧本改编补充说明
极简标签输出，只写结论；无改动项写“无：原因”。
- **【继承】**：剧情/动作/对白/OS/V.O./心理/环境：继承|扩写|改写|细分；未下放。  
- **【项目考据】**：时代/地理/历史/文化/人文/民俗/礼仪：已核对|缺失；本次约束及影响项。  
- **【风格】**：`Global_Style` / `borrowed_films` / `borrowed_films_note` / `tone` / `lighting`。  
- **【结构】**：发展重点段；高潮重点段。  
- **【借鉴】**：落点；触发；升级；回收；未用写替代。  
- **【场景开场节奏（每个新 Scene）】**：逐 Scene 首节拍是否执行三步；前3秒吸睛落点；建置是否含主锚点+空间轴+FG/MG/BG；是否先建置再入戏；长对白拆分与微反应；间歇可视片段；**每场细节特写落点**。  
- **【表情策略】**：本场/全片判定（夸张型|细腻型|标准型）；依据题材与 tone；夸张/细腻落点示例；与文戏特写联动。  
- **【微表情微动作】**：逐 Scene 微表情切口数与落点；逐 Beat 微动作项（部位+变化+节奏）；对白听众反应是否含微表情+微动作双轨；禁止抽象情绪词。  
- **【细节特写】**：逐 Scene 至少 1 处；列 `对象+部位+变化+叙事功能+所在 Beat`；文戏/武戏落点差异。  
- **【文武戏策略】**：判定；文戏主角特写数量与落点；武戏美感动作组数与要素；武戏细节特写落点。  
- **【空间动作】**：门窗方向；进出径向；避障；动作拆解；双轴定位；辅助锚定；节拍切换；各 Beat 建置更新判定与 FG/MG/BG 重写落点；逐 Beat 是否标明主节拍/主动作；施力-受力/接触-运动链是否写完整（禁只写结果轨迹）。  
- **【转场】**：`切换判定: 时空关系=连续/省略/跳转；桥接依据=动作/视线/声音/特写；轴线状态=同侧/已交代过轴；跨幅级别=小跨幅/已说明跨环境。`  
- **【Scene 首节拍技巧（每个新 Scene 必填）】**：参考片/手法；`开场转场技巧: OT标签+中文释义`；至少一项；禁止写无/None（全剧首场与后续每个新 Scene 均须填写）。
- **【标准站位自检】**：按统一表达式逐 Scene 核对；若衍生环境为无，必须写“无：否决证据”。  
- **【景深层次自检】**：逐 Beat 核对是否写 `建置更新=是|否`；`建置更新=是` 的 Beat 是否完整写 FG/MG/BG 三层，且每层含结构、角色/道具、横向层位、朝向视线、层间关系；跨层位移 Beat 是否触发重写；`建置更新=否` 是否只列变更项且不遗漏层位变化。  
- **【细节特写自检】**：逐 Scene 是否≥1 处细节特写；是否写清对象/部位/变化/功能/Beat；是否含微表情与微动作可拍描述。

### 第二部分：修改后的剧本 [ADAPTED_SCRIPT]
按 Scene 顺序输出；每 Scene 可直接供下游核销；不输出 `Shot List`。
- 场景块开始：`[SCENES_BLOCK_START]`  
- 单场开始：`[SCENE_START:{scene_id}]`

**【场景 1：场景名称】**
- **【核销源】**：原文句段/剧情点：已继承|扩写|改写|细分。  
- **【故事内核】**：叙事目标；冲突态势；本场落点。  
- **【细节特写规划（强制）】**：本场至少 1 处；`细节特写=<对象+部位+变化过程+叙事功能+所在Beat>`；可与吸睛/间歇插帧/听者反应合并。  
- **【Scene识别】**：时间连续性；空间连续性；行动线连续性；与上一场切分原因。  
- **【主环境】**：`环境名；0度正面观察基点；主锚点；内/外；日/夜；空间边界与尺度；入口/出口；固定结构；固定家具/基础陈设；光源；声源；阻隔物；前中后景层次；与上一环境关系`。  
- **【观察视角与空间建置】**：逐主体使用标准站位表达式；涉及 `OTS/门窗内外/屏幕内/镜中/遮挡后/画外声源` 必写触发与切至/返回。  
- **【衍生环境】**：`是否有（有/无：否决证据）；环境名；依赖主环境；顺时针角度（45度倍数）；触发类型；空镜边界与尺度；固定结构；阻隔层；光源；声源；是否独立行动空间`。  
- **【切换判定】**：时空关系；桥接依据；轴线状态；跨幅级别。  
- **【Scene 首节拍技巧（每个新 Scene 必填）】**：参考片/手法；`开场转场技巧: OT标签+中文释义`；至少一项；禁止无/None。  
- **【动作/视觉节拍】**：须先写 `主节拍/主动作=<唯一核心动作>`；`微动作=<至少一项，部位+变化+节奏>`；含细节特写时写 `细节特写=<对象+部位+变化+功能>`；首个节拍须落实三步（先吸睛 -> 再建置 -> 再入戏）；因果链动作（踢/推/打/抛/递交/撞击等）须在同一节拍内写清 **施力/接触/受力反馈 -> 结果运动/轨迹/落点**，禁只写结果轨迹而跳过施力；过长则拆为施力 Beat + 结果 Beat，禁跳施力；`建置更新=是|否`；`建置更新=是` 时写 `FG/MG/BG=...`；`建置更新=否` 时写 `继承上一 Beat 景深层次，变更项=<...>`；再写 `动作起点 -> 发力 -> 路径/方向 -> 终点落位 -> 静止/受力结果`；跨层位移标注起止层位；打击类补方向链；环境切换按强制句式写。  
- **【语言】**：角色|OS|V.O.；台词；`voice_type`；`tone`；`speed`；`volume`；说话者表情（部位+变化+幅度+节奏，按题材夸张/细腻策略）+说话者微动作（至少一项）；最主要听众（默认唯一）；主听众判定依据；最主要听众反应（强制，含**面部微表情+微动作**各至少一项）；>20字必须拆分。  
- **【全员反馈】**：触发后在场角色与群演逐一可见应答并更新落位；反应须按题材表情策略写面部微表情细节+肢体微动作（喜剧可夸张、情感须细腻）。  
- **【视觉落点/出场转场】**：本场视觉落点；下一场承接。  
*(按“动作/视觉节拍 -> 语言 -> 全员反馈”循环至 Scene 结束)*  
- 单场结束：`[SCENE_END:{scene_id}]`  
- 场景块结束：`[SCENES_BLOCK_END]`

**全员反馈示例**：`【@A】动作/台词（说话者表情：眉弓上挑+嘴角咧开；微动作：肩线上提+指尖敲桌） -> 【@B】反应+落位变化（喜剧：瞪眼+嘴巴微张定格；微动作：后仰僵住；情感：眼角轻颤+唇角微抿；微动作：呼吸变浅+指尖蜷缩） -> 【@C】反应+落位变化 -> 【群演簇】统一/随机反馈+落位变化。`  
**细节特写示例**：`细节特写=CHAR:[@B] 右眼眼角｜由平视微收至眼尾发红轻颤｜揭示被戳中痛处｜承接 Beat 3 对白停顿`
