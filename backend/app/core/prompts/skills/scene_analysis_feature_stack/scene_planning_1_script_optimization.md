**Beat 成稿叙述原则（强制）**
- **逻辑合理优先（最高总闸；压过偏好）**：成稿任一画面句须在物理世界+镜头投影下可成立——谁在哪一层、脸朝哪、面向谁、门在哪侧、运动往哪去，须同一拍内自洽。**优先级**：①逻辑合理（物理/镜头可拍）→②硬锁闭合（三联/投影/时序/名单/原文核销）→③偏好优化（正面优先、场内≥1次正面、景别好看等）。偏好与①冲突时**弃偏好、保逻辑**；硬锁是逻辑的形式化，不是用来制造不可能句的借口。**先定露脸（对话/动作）再写朝向**；正面可读**绝对禁**再朝后景；面向他者⇒对方须在前景更近，否则省略或写镜头向；**禁**套模板随便点朝向。❌为「主角要正面」写`正面朝镜头+面向后景渊龙`｜❌为凑公式把后景天穹改称「前景」｜❌正面可读却随便挂门/路人当朝向｜✅近侧背对+面向后景，或反打远侧正面+面向前景，或正面朝镜写`面向镜头正中`。
- **禁「同上」（最高）**：每拍独立可读。**同 ENV**：【建置】=上一拍【Beat切换说明】之`终态画面纵深`（或等价：上拍`速查更新`经**同一 N** 投影后的完整画面句）——**一字不落抄写纵深+正背面+姿态**（禁顺带微调；仅本拍明文移动/出入画/持握/姿态变更可在入戏改、终态写入本拍切换说明——**正背面档位本拍内禁变**；转身/转面致档位变须另起拍）。**ENV 变**（另起新拍，§4）：写【上一→触发→本 ENV】；**世界扇区/F/姿态 承接不变**（无明文走位/起跪坐时；转身改 F 亦须另起拍后在新拍建置落新档），画面句按新 N **整句重写层位与正背面**（禁粘贴上拍任一「画左/画右/前景/后景/正面/背对」短语），**身体姿态档须逐字继承**（见下）。违径向/三联/姿态继承须回改。
- **世界态优先（最高）**：真源=`世界扇区+F+姿态+具名锚`；画面相对词=观察轴 N 投影。落笔：**①承`速查更新` → ②按本拍 N 查表 → ③写【建置】【入戏】**。禁先写画面句倒推世界态；禁把上拍画面词当站位。
- **姿态跨拍严格继承（最高；外置+姿势）**：承接上拍时，角色除世界扇区/锚/可见性（外置）外，**身体姿态档必须严格继承**——站｜坐｜跪｜蹲｜趴｜躺｜倚靠｜骑乘 等（座/躺/倚须连同具名承托面一并继承）。**切角/反打/景别收紧≠改姿势**：`ENV变=是` 只重投影层位/左右/正背面，**不得**把上拍终态「跪」改写成「站」、把「坐」改成「立」。本拍【建置】起始姿态 ≡ 上拍`速查更新`之`姿态=`（可见带回者同）；仅当本拍【入戏】有可拍过渡链（跪下/起立/入座/起身/下马等）方可在**速查终态**改姿态，建置仍写旧姿态。❌上拍`Kneeling`→下拍建置无过渡写成`Standing`｜❌反打后随从无「起身」却改站立。✅上拍跪→本拍建置仍跪；入戏「起立」后速查=`Standing`。
- **建置防错乱五锁（最高；每拍落笔序，缺锁=失败）**：错乱根因=用画面词当记忆、把度数写进建置、速查与画面不对账、反打乱换空间名、自检空话盖章。强制：
  1. **时序锁**：【建置】=开口前**画面初始态**（含上拍终态姿态档+**初始纵深**：前景/中景/后景须带括注）；【入戏】=过程（运动/对白）；【Beat切换说明】=`初始建置 + 入戏运动` 的**变化过程摘要 + 画面终态**（含**终态纵深**；供下拍【建置】承接）。`速查更新`∈切换说明，=场内世界态终态。禁把终态 F/新姿态/转身结果/**运动后纵深**写进建置；禁建置残留 `F≈`/`0°侧`。❌`跪伏在地（F≈180…）`｜✅建置只写「前景中央正面朝镜头，双膝跪地」；F 与终态层位只进切换说明。**入戏含推门入内/入画行走时**：建置不得已是「大厅深处前景站定」的入完态——起始须在门侧/门外/刚跨过门槛，入完落点+终态纵深只进切换说明。❌用户案：建置`Foreground…standing` + 入戏`Pushes doors…walks inside`。**入戏含起立/跪下/入座时**：建置须仍为旧姿态，新姿态只进切换说明/速查。
  2. **投影锁（算术硬核；禁直觉）**：速查扇区+本拍 N → **先算**`后景=N°｜前景=(N+180)%360`再查§12 表 → 层位/左右**必须≡**建置≡台账`→画面`。❌速查`轴心`却建置「前景中央」（N=0 时前景=180°侧，轴心=中景中央）。❌**用户案（反打算反）**：N=180 时 `0°侧=前景`、`180°侧=后景`——却写`Serena|扇区=0°|→后景` + `Rupert|扇区=180°|→前景`，或建置把 0°人放后景、180°人放前景 = **投影锁失败**，**禁止**标`投影锁=扇区≡层位`/`①–⑧全过`。ENV 变后未走位者画面三项相对上拍必变。
  3. **朝向锁**：F↔正背面 + 侧面↔面向同侧画幅 + 三联句 + 对白向；**逻辑合理优先于偏好**；**主要动作者（含金身/法相）原则上正面/¾朝镜头**（见§1；偏好——**禁**`正面朝镜头+面向后景{对象}`）；**背对/侧背面朝镜头 → 禁止写「对镜头」**（口型对白与 OS/自白方向锚均不可）；要对镜头须**另起拍**切可读角或完成转身且新拍建置已是正面/¾（禁同拍转正后对镜头）。**背对/侧背面 → 禁止描写须正面才可见的内容**（五官/口型/泪线**与**胸膛/肚子/正面躯干等；仅可写后脑肩背等可见面，见§12）。`voice_type=画外音/OS/V.O./旁白` → OS 只挂声（声源人或在画外），禁对镜头口型开口；画内可见角色须**明文闭嘴**；背对时 OS/内心方向写`对{后景人}|内心|望天`等，**禁**「对镜头」。`voice_type=自白/独白/内心` → 发言人与画内他人均须**明文闭嘴**，禁按 lip-sync 写「开口」。❌N=180 且`F≈90`却写`right profile facing Frame Right`（F≈90=(N+270)→须**左侧面+面向画左**；右侧面+画右须`F≈270`）。
  4. **ENV 名锁**：`ENV变` 触发类型与新 ENV **主名段**闭合——同场反打=`{N}度{同一主环境名}`（❌`0度主大门`→反打却写`180度王座区`）；**默认**换主空间名=转场/新 Scene，禁标「反打」。**特例（快速闪回/蒙太奇同场多主，§7/§11）**：同 Scene 已声明的另一【主环境】族之间切换时，主名段**必须**变为目标主环境名（`ENV变=是`，触发=`闪回切主环境|蒙太奇切主环境|回切当下主环境`），**禁止**标「反打」，亦禁止用当下主环境的视角衍生冒充异地。较长回忆→应已拆为独立闪回 Scene，不在同场用多主凑合。
  5. **集合锁（开拍集≠收拍集；最高）**：
     - **开拍可见集**≡【建置】具名集合（开口前已在画——含角色/动物/载具/法相/金身等）。
     - **收拍可见集**≡`{Beat终态画内实体}`≡`终态画面纵深`具名集合。
     - **公式（强制）**：`终态=(建置−本拍明文出画)∪本拍入画/突现落定`。**禁止**无条件写「终态≡建置」——中途入画（门入/驶入/金身凝形等）→建置可不含其名、终态必须含且字段齐全；中途出画→建置含、终态剔除。
     - **≠纵深等同**：落位/朝向终态进切换说明`终态画面纵深`（可与建置层位不同）。
     - 速查覆盖画内+暂不可见（未出画）；上拍差集处置本拍重析——出画｜仍画内｜暂不可见续挂｜已转可见则**必须**带入建置；**新人/群演/动物/载具/法相/金身不得凭空入画**（上拍终态∪差集∪速查皆无其名时，本拍须经具名出入口或可核销驶入/凝形链）；禁带病标「①–⑧全过」。
- **三段时序（最高；建置≠终态）**：
  1. **【建置】=画面初始态（仅可见）**：开口前静止画面——**仅**开拍已在画、查表可见的可移动主体/可见物件；每名须写清**纵深**（前景(离镜近处)/中景/后景(远处)+画左|中央|画右）+正背面（或载具前进向）+面向+姿态；**禁止**把本拍入戏走位/转身后的落点写进建置。
  2. **【入戏】=过程**：动作/对白/位移链/**音效`<…>`**（每拍≥1，§5）；禁混入建置句；**禁**把机位后方/画外/暂不可见实体写成画面可见落位。
  3. **【Beat切换说明】=初始建置 ⊕ 入戏运动 → 终态**：必须可核销为「在【建置】基础上施加【入戏】运动后的结果」；须记录**变化过程**（谁自何层位→何层位/何姿态/何正背面/出画或入画）+ **终态画面纵深**（与建置同粒度的镜头相对词），供**下一 Beat【建置】**直接承接（同 ENV 抄写终态画面句；ENV 变则世界态取`速查更新`再按新 N 重投影）。无运动时：终态纵深≡建置纵深，切换说明仍须明文复述终态纵深（禁省略「无变化」而不写层位）。
  - **不可见实体分区（最高硬约束）**：本拍查表=机位后方/画外、或完全遮挡导致**不可见/暂不可见**的实体（角色/群演/动物/载具/法相/金身/道具等）——
    | 段落 | 可否写该实体 | 写什么 |
    | :--- | :--- | :--- |
    | **【建置】** | **禁止** | 不得出现其画面落位/朝向/姿态句，亦禁「不可见的{名}在机位后方…」工程说明句冒充建置 |
    | **【入戏】** | **禁止**当可见事实 | 不得写其可见动作/细节；出画过程仅在其仍曾可见时段写 |

- **原文逐字核销（最高硬约束；原剧本→优化稿）**：原剧本**每一处文字 / 每一信息单元**必须落入优化稿可检索落点；**禁止**概括吞并、跳场省略、只留「大意」、因「不知归哪类」而静默丢弃。

  - **对白/OS/屏幕可见字**：项目语言侧台词 **逐字保留**（标点可按拆句§25切开，但词序与用词不改；禁意译替换、禁删半句）。拆拍后各拍拼接须能还原原文全句。原文已写明的环境/道具可见字（牌匾题字、书名、纸笺正文、店招等）同锁——**逐字保留原字形体系（繁/简不得擅自互转）**；写入【主环境】固定实体或 Beat 时可附字体/书体线索（有则写）；无字样的裸载体名可保留，逐字文案/字体/繁简裁定由 Stage 2.1/3 补全。

  - **叙述/动作/场景描写**：逐**信息单元**核销（谁做了什么、何处、何物、何结果）；可改编为可拍建置+入戏，但**信息零丢失**；场景文学描写须融入 Beat（§9），禁只挂场头；未归建置则入戏兜底。原文声音/音效/背景声→【入戏】尖括号`<…>`（§5），禁只留画面删声。
  - **建立空镜 / 环境建立描述（入戏兜底下的常漏例；须作 Beat）**：下列原文**每一行/每一段都是独立核销单元**，须落入**可拍 Beat【入戏】**（优先独立首拍/吸睛拍；可与§16首节拍合并为专段）——**ENV 块不能替代 Beat 落点**：

    2. **`【空境：…】` / `【空镜：…】`（及无括号同型「空境/空镜：…」）**：纯环境/氛围建立描写——须独立建立拍或首拍入戏写出可拍画面；**无人戏时建置写空镜/无角色即可**；实体线索同时进【主环境】固定清单/未落清单。

- **服装剧情（尽量避免）**：禁默认未交代袖/袋藏物——优先握掌/自桌取。确须→动作前`服装要求：…`；环境湿污明示衣态。禁无前置「藏入袖中」。
- **建置边界**：Scene=空镜+未落清单+速查/索引+覆盖排期（不写七要素落位）。Beat=当前衍生ENV下**可移动主体**落位+朝向四要素+姿态；环境固定实体只作名引用锚（不写其画面位，§1 空镜重述）。姿态必填（座/躺挂承托**名**）；主锚=说话人→POV→施力→焦点；朝向=主动作→对白对象→终态→礼仪；**交付面对面**；阵列中间位标左中右/前中后；参照=`{方位}+{具名}`（具名可为人或固定实体名，后者不附层位）。
- **可移动主体建置等同角色（最高硬约束；覆盖进出场+朝向）**：【建置】**不仅**人物角色——凡画内可见、**有移动可能**（自主走跑飞游／被驾驶行驶／被骑乘／可入画出画／可改朝向或可见面）的具名实体，**一律按角色同等守则**建置，并服从同一套**进出场三态守恒**（§15）与**朝向／正背面（可见面）说明**（§12 F↔正背面表同锁），**禁止**仅当道具一行或特效落点糊弄、禁止因「不是人」而省略落位/**朝向**/跨拍承接。
  - **闭集（含但不限于）**：①角色／**具名龙套**／**群演簇**／具名手下；②**动物／宠物／坐骑**；③**车辆／舰船／飞行器等载具**；④**法相／金身／法身／真身／金光法身／万丈金身**、化龙／化凤／巨兽／巨化体、半人半兽、拟人灵体／化身等（**凡入戏作主语施力／受击的具名形体，不论是否挂「法相」二字，一律入本闭集**）；⑤其他本场可位移的具名可交互体（机甲、可自驱动装置等）。
  - **群演／龙套建置零豁免（最高；所有建置要求同等生效）**：本文全部建置硬约束——五锁／三段时序／朝向四件套／正背面单档／姿态继承／出入场三态／不可见禁建置必进切换说明／纵深双落／名单闭合／查表重投影／三联句／入画当拍建置等——对**具名龙套**与**群演簇**与主配角**同等强制**。**禁止**因「只是群演／龙套／气氛／远景虚化／不是对白焦点」省略落位、朝向、姿态、差集或终态；**禁止**只写「背景有随从／龙套在场／众人围观」而无镜头相对定位。
    | 对象 | 建置粒度（强制） | 禁 |
    | :--- | :--- | :--- |
    | **具名龙套** | **≡角色全字段**：纵深+画左\|中央\|画右+正背面+面向+姿态+锚/与他者；入速查/终态/差集 | 并入群演簇糊弄；只写名字无朝向 |
    | **群演簇**（匿名氛围集合） | **簇级≡角色字段集合**：簇名+**人数/规模**+**位置排列/队形**+纵深带+画左\|中央\|画右（或扇区带）+**主导正背面/面向倾向**（如多背对镜头朝后景主台／多¾朝画左）+姿态档（站立簇/跪拜簇等）+相对主锚；入速查/终态/差集 | 只写「人群在背景」／「有军队」无人数与队形；ENV变后粘贴上拍画面句；因 Wide 省略 |
    已入画后守恒、切角重投影、回挂靠必带入——**群演/龙套不豁免**。可延迟开场入画（§17），但一旦入画即开本条全套。
  - **群演簇人数与排列（最高；凡写群演簇强制）**：成稿【建置】【入戏】`速查更新`/`终态画面纵深`凡出现群演簇，**必须**同时写清——①**人数/规模**（可核销：确切人数如`约12人`/`两排各6人`，或可拍规模词如`百人方阵`/`数十骑`/`满编一连`；禁裸写「众人/一批/若干」）；②**位置排列/队形**（镜头相对落位带 + 内部排布：整齐纵队／横列／方阵／扇形围观／散点簇／前后梯次等；军警/仪仗/甲士等制式簇须写**整齐度与行列**——如`三列纵队齐肩`/`方阵前排跪后排立`）；③与主人物/主锚的相对距离与扇区（服从群演拉开）。宏观大军另叠§28 满幅阵势。❌`后景有士兵`｜`军队在场`｜`一群随从`｜✅`约四十名甲士兵簇在后景画右，三列整齐纵队面向画左主台，前排齐膝、后两排齐肩`。
  - **须逐具／逐簇写清（适配形体）**：纵深层位+`画左|中央|画右`｜**群演簇另须人数/规模+位置排列/队形**｜姿态／停驻态｜**朝向四件套（强制）**｜正背面或等效可见面档位｜与他者／锚关系｜视线（有则）｜动作方式；并入`速查更新`｜`终态画面纵深`｜`{Beat终态画内实体}`｜正背面开拍检｜**进出场守恒**（已入画→后 Beat 须承接；离场须经具名出入口或可核销驶离／飞离／消形出画；切角暂不可见≠出画；差集续挂与回挂靠必带入——**群演／龙套／动物／载具／法相／金身／巨兽一律不豁免**）。载具／坐骑另须人—车（人—骑）分行且终态含双方（§6）。法相／金身／巨兽凝形后维持相仍在画→每拍完整建置含朝向；消散须可拍消形／出画过程。**角色与其金身／法相同时画内可见时须分名分写建置**（不可用角色落位替代金身落位）。
  - **金身／法相／巨兽 ≡ 角色（最高；字段零减免；§8 只指针）**：法相／金身／法身／真身／金光法身／万丈金身／化龙凤／巨兽等，字段与句式**与角色同标**；缺任一=失败；与宿主同框须**分名分写**（沈渊≠金身）。九字段：纵深｜左右｜具名锚｜正背面｜面向｜姿态｜与他者｜视线(有则)｜动作方式。
    句式：`{金身|…}在{前景|中景|后景}(括注){画左|中央|画右}，{正背面}，面向{画左/画右|{具名}}，姿态{…}，{锚/与他者}`；终态/速查同角色行格式。
    ✅`万丈金身在中景中央，正面朝镜头，面向前景的渊龙群，姿态站立，立于玉台之上`｜❌`金身显形`／`撑满天地`／`右掌推出`无位置朝向｜❌建置只有宿主、金身仅入戏「显形」。
    ❌**用户案（三联破）**：`沈渊…正面朝镜头可读，面向后景渊龙` + `渊龙群在后景上空…`——正面=看向机位/前景侧，物理上背对后景龙群，无法「面向后景」；须改近侧背对+面向后景龙，或反打远侧正面+面向前景龙（龙群层位与面向词同步）。
    ❌**用户案（同层互称前/后景）**：`沈渊在中景中央，背对镜头，面向后景的朱七` + `朱七在中景画右，正面朝镜头，面向前景的沈渊`——同层却互称前/后景（层位词≠实层）；须一近一远，或同层改`面向画左/画右`。
    ❌**用户案（层位词造假+正面朝远人）**：`李玄在后景中央，背对镜头，面向后景大门` + `燕三娘在前景画右，正面朝镜头可读，面向前景的李玄`——①李玄实层=**后景**，却被写成「前景的李玄」；②燕三娘正面朝镜头=看向机位/近端，物理上**背对**后景李玄，不可能「面向李玄」。改法择一：近侧`背对+面向后景的李玄`；或反打远侧读脸时李玄改到更近层且写`面向前景的{近侧人}`；或燕三娘只读镜头/柜台、**不写**面向李玄（李玄另戏看门）。
  - **宿主↔法相／金身动作同步＋因果共写（最高；原则同步）**：法相／金身／法身／真身／化龙凤／巨兽等与宿主角色同框维持相期间，**原则上动作与原主同步同相**——宿主抬臂／结印／发力／转向／姿态变／受击反馈时，金身／法相须**同拍**写出对应同向或尺度放大的镜像动作（可巨化／可极短可视延迟，但相位须可检索咬合）。存在**直接因果**（施法驱动、凝形显形、借体出手、同损同伤、收摄消形、操控对位等）时，【入戏】**必须同拍同时写清双方动作**并显式咬合因果链——**禁只写法相出手而宿主静止无驱动**，**禁只写宿主结印/运功而法相无对应可见相变或出手**，**禁双方各写一套互不相关／不同步动作**（金身独立乱打、宿主另做无关事）。
    | 相位 | 宿主侧（须可拍） | 法相／金身侧（须可拍） | 禁 |
    | :--- | :--- | :--- | :--- |
    | 凝形／显形 | 起势／结印／吐纳／抬臂等驱动过程 | 轮廓凝出／拔地／撑幅落位（当拍九字段） | 金身自现、宿主无动作 |
    | 借体出手／对位攻击 | 驱动姿态或**同步**发力（掌势/口令/目光锁；肢体方向与金身出手同向或可核销镜像） | 同拍对应出手／弹道／命中（与宿主发力同相） | 只写金身掌推、宿主旁观空白；宿主抬左金身无据出右且无核销 |
    | 维持相同步（原则） | 姿态／朝向／发力变有可拍过程 | 同拍镜像或放大同向动作 | 金身连招而宿主全程静止／另做无关动作 |
    | 同损／受击反馈 | 宿主震颤／吐血／跪软等可见反馈（有则） | 金身裂纹／踉跄／光衰等对应反馈 | 金身重创、宿主毫无反应且无核销例外 |
    | 收摄／消形 | 收掌／解印／召回动作 | 消形／缩回／离画过程 | 金身蒸发、宿主无收摄动作 |
    **不同步例外（须明文核销）**：仅剧情明文「失控／反噬／独立意志／反客为主」等可核销不同步——须在入戏写清脱同步触发，并在切换说明标`宿主法相同步=否｜原因=…`；否则默认`同步=是`。宿主暂不可见（差集）时：法相动作仍须写，并在差集/切换说明标`宿主驱动挂靠=暂不可见｜因果仍成立｜同步挂靠`；**禁止**借差集省略因果另一侧的可见结果。句式倾向：`{宿主}：{驱动动作} → {金身|法相}：{同相同向/放大对应结果}`（可分行，须同拍可检索因果箭头或等效顺序）。✅`沈渊抬臂结印发力 → 万丈金身同拍右掌推出，掌风命中前景渊龙`｜❌`金身：右掌推出`（宿主无驱动）｜❌`沈渊运功` + 金身另拍才出手且无承接｜❌宿主结印静立、金身独自连打三招且无失控核销。
  - **主要动作者面向镜头优先（金身／法相尤严；服从逻辑合理）**：本拍主出手/对白主拍/凝形主体原则上`正面/¾朝镜头`；禁无核销默认背对「撑满天地」。本条=**偏好**，位阶低于**逻辑合理优先**与三联硬锁。若对手/仰望对象实层在**后景(更远)**，**禁止**为凑正面优先而写`正面朝镜头 + 面向后景{对象}`——按剧情可核销择一：①反打/OTS/Two-Shot 重组把主行动者放到远侧且对手更近（`正面朝镜头 + 面向前景{对手}`）；②近侧主行动者写`背对镜头 + 面向后景{对手}`（本拍禁正面才可见内容，须读脸另起拍切可读角）；③主行动者正面朝镜、对象仍在后景时——**省略**「面向{对象}」，改写`面向镜头正中/上/下/画左/画右`（禁随便另挂门/天穹凑朝向）；④**仅当**剧情/布局允许对象比己更近镜头时，才改对象层位并同步面向词（禁为凑公式把后景天穹/后景龙群无据前挪）。**「背影离镜／仰望后景」=对本条正面优先的豁免（须背对或侧背面+面向后景），绝非允许`正面+面向后景`**。须读脸/胸腹→另起拍切可读角 ENV。
  - **动物／载具朝向（闭集；金身等走上表九字段）**：
    | 主体 | 可见面档位 | 面向／前进向 | 例 |
    | :--- | :--- | :--- | :--- |
    | **动物／坐骑** | 同角色闭集；头面优先，身躯≠头面时两者都写 | `面向画左/画右|{具名}|前景/后景` | ✅`犬背对镜头，身躯面向后景大门，头扭向画左的{名}`｜❌`狗在旁边` |
    | **载具** | `车头/车尾/左/右侧身朝镜头`｜`¾车头/¾车尾`（单拍锁定） | `车头朝画左/画右/后景/前景`；静止写停靠向 | ✅`轿车右侧身朝镜头，车头朝画左`｜❌`车开过`无车头车尾 |

  - **入画／突现当拍建置（禁拖下拍）**：可移动主体首次入画或突现（经门/驶入/**凝形·显形·降临·拔地**等）→**出入画过程拍内**写满朝向四件套并入终态+速查；禁本拍只写过程、更后拍才首次建置。
    | 时序 | 本拍必须 | 禁止 |
    | :--- | :--- | :--- |
    | 开拍已在画 | 【建置】含完整朝向四件套 | 入戏才补朝向 |
    | 入戏中入画 | 落定句或`终态画面纵深`含建置粒度朝向；**下一 Beat【建置】抄终态** | 终态仅「已入画」；更后拍才首次落位 |
    | 突现/凝形 | 轮廓可读起当拍写满九字段（开拍凝形→建置；入戏凝形→落定句+终态/速查） | 入戏`金身：显形出手`而终态无名/无朝向 |
    **入戏主语扫描**：入戏具名施力/受击/显形者须在建置或`终态画面纵深`可检索九字段；金纹/波前等无定形介质→§8，**不**替代金身本体。下拍只承接终态，非首次建置窗口。
  - **新入画定位特写（一般强制；角色/实体首次入画）**：具名角色、具名龙套、重要可移动实体（动物/载具/法相/金身等）或关键道具**首次入画/突现**时，**一般须**在入画过程拍或紧随其后的定位拍给予**入画定位性特写/近景描述**（Insert/CU/MCU 可；轴未变且非反打、正背面未变时沿用父 ENV，禁另建特写专属衍生），使观众完成「谁/何物刚入画」的可拍锚定。须写清：①**位置**（层位+画左|中央|画右+出入口/具名锚+与他者相对，服从停驻相对与戏份选型）；②**朝向**（正背面+面向）；③**姿态**；④**表情或可见面微表演**（角色/有脸实体：≥1 可检索微表情或非口型外化；须正面/¾ 可读——背对入画则另起拍切可读角再写脸，§12）；⑤关键实体另写可见面/挂载/状态一句。群演簇可簇级定位（**人数/规模+位置排列/队形**+主导正背面+姿态+落位带），免逐人脸部特写。❌只写「推门进来/现身」无位置朝向表情｜❌背对入画同拍写眉眼特写却未切可读角｜✅入画落定句含定位特写，或 N=入画过程 → N+1=入画者近景定位（位置+朝向+表情）再开对白。
  - **出入画改集合→强制另起 Beat（最高；与转身另起同级）**：可移动主体（角色/群演/动物/载具/法相/金身等）**明文入画或出画**，致本拍**开拍可见集≠收拍可见集**（建置集合变）时——该拍**只承载出入画过程**，落定/出画完成即切拍；**后续对白轮次、新主动作、新表演单元必须新起 Beat**，以新集合为【建置】开拍态承接。

## 2. Scene 与环境
> 完整口径 §9–§11、§16；下文流程速查。
- **流程**：四问判 Scene → **核销上游同环境**（命中则锁定复用名；有上集/全局主环境注入→§10 角度锁）→【场景名称】(剧情+复用主名) → 定需求 →【主环境】(继承上游/既有骨架；无则新立；**情节确认异地→可新建**；快速闪回/蒙太奇可同场多主，§7/§11) →【未落清单】→【衍生】(须覆盖每一主环境族；复用主环境时衍生角与原角一致、按设置选角) →【观察视角与空间建置】(速查表+Beat索引) →【Scene实体覆盖】→ 每 Beat 完整重写建置（内部速查+查表；成稿首句当前ENV+视角落位）。
- **四问**：时/空/线/目标连续？任一断→新 Scene。另核**内容是否适配当前主环境**——不适配则拆（§9）；闪回切分见§7（快闪/蒙太奇不新起 Scene；较长回忆须新起）。切分以本节为准，可不依赖上游场次。
- **禁令**：纯情绪词/景别/特写≠环境（**≠可删该行画面**——原文`△近景`/`【特写：…】`须入戏核销，§1）；Insert/CU禁另建衍生；停顿/表情/正反≠新 Scene。**例外**：跨拍可持续重大氛围/风格切换→须建状态衍生（§11）；情节确认不在当前环境→另立主环境（非状态衍生）；**环境/服化道剧变且停留较长→新 Scene 或另立主环境**（§7 初始态锁定+§9）。
9. **Scene切分**：四问+适配。**须拆**：时/空(越四向包络)/线/目标断；多线各地点各场再穿插（§7）；**较长回忆片段 / 回忆性长对话**（§7——长段往事口述须闪回可视化，完整往事→独立闪回 Scene）；**原文初始环境被剧情大幅改写且后段仍长时间停留于改写后空间**（§7 服化道/环境初始态锁定——禁把改写结果回填原主环境；停留长→新 Scene，短时可持续→状态衍生）。**不适配**：①动作越出本场｜②对白异地异线｜③须换主环境→后段新场+转场四步（**例外**：快速闪回/蒙太奇异地快切→同 Scene 多主环境，§7/§11，不新起 Scene；较长回忆/回忆性长对话→须新起闪回 Scene 或同场快闪，禁当下坐聊消化）。禁删剧情、禁电话消解真空间切换。**可并**：四问连续且适配。**禁拆 Scene**：仅视角/特写/正反（特写仍须成 Beat 入戏，禁整行删除）；假多线。闪回§7。**场景名**：`【场景名称】{短名}｜日夜·内外｜季节｜气候｜叙事线`。**场景描述融入Beat**（禁只挂场头；首落优先切场+首拍，§7）：场头文学/氛围/`△俯拍·航拍`/`【空境/空镜：…】`建立句，以及原文`△近景·特写`/`【特写/近景：…】`景别行，均须进首拍/独立建立拍/特写切口拍入戏（§1），禁只留【主环境】或场注，禁因「景别≠环境」丢特写画面。
10. **环境定义（§11）**：空镜骨架+具名出入口；变化主体→环境、动作→Beat。**同环境复用（最高）**：上游同空间名→主名/衍生主名段**逐字复用**；日夜不同不另起名；仅无上游且硬需才新建。因剧本而生；**先定本场活动空间再落实体**；禁装饰扩写/未用冗余衍生；每场三块齐全（多主环境时每主各齐）；无人像；禁材质光色细参。**主环境=原文初始建立态**（场头/空境/开场），禁用后文剧情终态改写基准（§7）。**环境描写：可简约、禁破旧倾向（强制）**——【主环境】/服化道「环境细节」/空镜建立句可写素净、少陈设、留白净空；**禁止**无原文/剧情硬核销时主动加破烂、破败、残墙剥落、霉渍油污、裂缝狼藉等破旧语汇；简单≠破旧；张力用光色/空寂/秩序，禁用脏乱破烂代替。
  - **上集/既有主环境注入→角度锁+按设置选角（最高；有则强制）**：输入含 `[已存在的全局主环境约束]` / 上集或跨集须复用的主环境既有提示词时——①**主环境骨架锁**：0°轴、四向扇区实体归属、头尾双锚、固定清单、活动空间须与既有提示词**同核延续**（可补本场活动适配句，禁重定 0°、禁对调四向、禁另起同义主名）；②**衍生角度锁**：本场声明的每一 `{N}度…` 衍生，其 `view_angle_from_main=N` 与该角后景半空间**必须与既有主环境同角完全一致**（`0度`=`原0°`、`180度`=`原180°`…）；**禁止**为「本场好看」重映射度数、旋转坐标系、或另起与原角扇区不符的同名角；③**选 ENV 按该环境设置**：Beat 挂靠衍生时**唯一依据**=该既有主环境四向/活动适配所定义的「后景应见何物」→匹配对应 `{N}度…`；**禁止**随机选角、按 0→90→180→270「轮下一角」、或无背景内容依据习惯先挂反打。无注入/非复用主环境→仍走内容驱动建角（§11），本条不适用。
11. **主环境 / 未落清单 / 衍生（四向美术归 Stage 3）**
  > **不变式**：衍生对**所属**主环境固定实体不增/不减/不矛盾；仅可见性与方向性朝向可变。**主环境骨架与服化道「环境细节」锁定原文初始态**——剧情造成的破损/狼藉/域场改写/日夜突变等不得回填进【主环境】固定清单或初始摘要；须走 Beat 过程 / 状态衍生 / 新 Scene·新主环境（§7）。
  > **⑤唯一性**：默认每功能实体**在所属主环境内**1具；**门/窗默认唯一**；多件→总个数→逐具具名+区分特征。⑤-b同质≥2须分边/各向个数+朝向+同侧顺序。⑤-c配套：桌↔椅｜床↔被枕｜杯↔盏托。
  > **⑥全覆盖**：剧情实体全入**所属**主环境清单；Stage2.1再XOR裁PROP；禁两侧双出或双消失。⑦均衡：禁过挤/过空；**活动区净空**——主舞台/表演区/动线/站位承载区**禁止**布置无剧情硬核销的立体实体物件（家具障碍等）；仅贴地层或剧情必需锚（对白桌/座次椅等）可占；其余陈设落边缘/背景向。⑧出入口：具名门/洞/巷口；禁穿墙；默认单门。

    2. **无剧情区**：**禁止敷衍**——仍须写出可辨主锚/边界立面/陈设或结构实体（如对向墙段、侧廊、窗墙、街口剪影、次要家具立面等），不得写「空墙/无/略」或复制他向同名同功能实体凑数；可简约，但须有区分信息。
    3. **原则上不重复或不能完全重复（服从⑤唯一性）**：各向（含中心）主锚实体集**原则上互不重复**；确须同类多件时走⑤（总个数→逐具具名+区分特征+分边/各向个数），**禁止**四面抄同一套「门+窗+桌」完全同构；对向串写仍禁。
    4. **地面与空中/屋顶（有则强制）**：五区描述之外，按需另写——**地面/地板**（贴地层连续、中区净空可贴地；材质/分格/收边一句即可，禁活动区堆立体物）；**空中或屋顶/天花/天空**（室内=梁架/吊顶/主灯/天窗；外景=天空/天际/檐口/树冠上层等）。有航拍/空战/上段动作/可见天顶戏份时**必写**；无剧情亦不得五区只写立面、完全省略地面与上边界（至少各一句可核销）。

## 3. Beat 建置与空间（§12–§15）
12. **站位与空间建置（强制）**：建置段细则（三段时序/主锚/三轴/世界态优先/空镜重述限定见 §1）。**落笔序（强制）**：⓪**正背面档位开拍必检**→⓪-b**当前 ENV↔背景半空间匹配（静止亦检）**→⓪-c**Beat开拍评估（运动合理性 + 衍生ENV四周/舞台中间↔角色建置匹配；结论写入切换说明）**（见下）→①承上拍终态（同ENV抄`终态画面纵深`；ENV变承`速查更新`世界态）→②查表→③【建置】**初始**画面句（含**可移动主体**纵深；环境固定实体只点名）→④【入戏】运动过程→⑤【Beat切换说明】=开拍评估结论+初态⊕运动→变化过程+`终态画面纵深`+`速查更新`(+ENV变台账)。禁：用上拍画面词当站位（须用上拍终态）；度数入【建置】【入戏】；同上；漏应可见可移动主体；静物中途凭空出现；动作对白混建置；**把运动后纵深写进建置**；**切换说明缺终态纵深/缺开拍评估**；**无功能空镜观光句**；**为陈设写前景/画左等层位**（§1 空镜重述——只点名，多件才特指哪一件；**原文`△`/`【空境】`建立句例外，须进入戏核销**）。**三轴须同拍闭合**，冲突口径见 §1/§15。
  - **可移动主体—镜头正背面／可见面：单拍单档 + 转身／调头另起拍（最高硬约束；开拍必检；含动物／载具）**：
    - **档位闭集**：角色/动物/法相=`正面/¾`｜`左侧面`｜`右侧面`｜`背对/侧背面`；载具=`车头/车尾/左/右侧身朝镜头`｜`¾车头/¾车尾`（§1 动物/载具朝向；车头↔车尾=档位变）。
    - **单拍单档 + 开拍必检**：建置≡入戏≡终态同一档；档位变→另起拍。切镜头/反打致变→`ENV变=是`+重投影；自身转身/调头→已另起拍，轴未变可同父 ENV（标`触发=转身/转面/调头`）。禁同拍旧档建置+新档入戏；禁切角改档却同父 ENV；须读脸→新可读角 ENV+新 Beat。
  - **当前 ENV↔背景匹配（最高；开拍必检；静止亦检）**：
    - 可拍 ENV **永远**=`{N}度…` 衍生（Master=`0度{主}`）；=本视角直接可见背景半空间（后景=N°侧）。禁裸主环境名。
    - **按背景内容选角**：唯一依据=后景应见内容 ↔【主环境】N°扇区 + `活动适配`可见面。禁无据粘`0度`、禁 0→90→180→270 机械轮角、禁随机挑角。`0度`仅当背景确属 0°扇区。**复用既有主环境时**：后景内容须对照注入的既有四向/提示词扇区映射，不得另立度数表。
    - **活动适配（静止亦检）**：`活动适配`「可见X」=本拍后景 X，非「本场有这扇门」。禁因「人没动/ENV变=否」跳过。
      | 画面事实 | 应挂 | 禁挂 |
      | :--- | :--- | :--- |
      | 背对/面向后景（内侧/王座） | 可见王座/内侧的角（常`180度…`） | 可见大门的`0度…` |
      | 正面朝镜、身后/后景应见大门；或自背景门迎入（终态正面） | 可见大门的角（常`0度…`） | 可见王座的对向角 |
      | 背对向内走、门近端/身后 | 可见内侧/王座（常`180度…`） | 可见大门的`0度…` |
      | 外景航拍/山巅建立 | 外景族`{N}度…` | 厅内`0度…`（可见大门） |
    - **选 ENV**：①定后景内容 → ②定位 N°+守轴 → ③取`活动适配`匹配行（禁裸主名）→ ④背景锚∈半空间；径向闭合 → ⑤与正背面/反打交叉。
    - **入画径向×活动适配三联**：门层位 × 行进径向/正背面 × `活动适配`可见面同拍闭合。❌`0度`(可见大门)+背对推门向内→应`180度…`或改自背景门迎入终态正面。✅背影进深处=门近端+可见内侧 ENV；✅迎面入门=门后景+可见大门 ENV。禁外景挂厅内；禁反打仍同父 ENV。
  - **Beat开拍评估（最高；每 Beat 强制；结论写入【Beat切换说明】）**：写本拍【建置】【入戏】**之前**必须完成，结果写入切换说明字段`Beat开拍评估=`（缺=失败；禁空话「通过」无抽样）。含两轴，缺一不可：
    1. **本拍运动合理性**：本拍拟发生的位移/姿态变/出入画/对峙逼近等是否物理可拍——起动净空、步幅/挥打半径、终点可落、门径向闭合、不穿墙不穿桌、不穿越活动区立体障碍、意图已转具体动作链（§6）。无运动写`运动=静止|N/A`仍须明示。
    2. **当前衍生 ENV 四周与舞台中间 ↔ 角色建置匹配**：对照本拍当前 `{N}度…` 的 `活动适配`/主环境该 N° 扇区四周实体 + 中心/舞台净空——①后景四周主锚是否与建置「身后/后景应见」一致（背景匹配，静止亦检）；②角色落点是否落在舞台中间净空或合理边缘/座次锚，禁踩死四周立面或堵死动线；③建置挂靠的桌/椅/门等**名**是否属于本角可见半空间或中心表演锚（禁挂机位后方才有的实体当可见交互）；④群演/可移动主体分布是否与四周/中区分工不冲突。不匹配→先改 ENV 角或改建置/动作，禁带病开拍。
    - **成稿字段（切换说明强制）**：`Beat开拍评估=通过|失败｜运动=合理|静止|失败：…｜ENV匹配=四周=…｜舞台中间=…｜角色建置抽样=…｜不匹配项=无|…`。失败须回改后重写，禁标通过。
  - **动作空间与角色距离（最高；场级专评 + Beat 起止重评）**：
    - **场级（每 Scene 强制；写入【观察视角与空间建置】）**：开场规划时**专门评估**每个具名角色（及同框关键可移动实体）的——①**动作空间**：本场其戏份所需净空/动线/转身半径/对峙区是否落在【活动空间】主舞台或动线内，禁落点贴死墙角无后续步幅；②**角色距离**：与相关角色的身体尺度距离档（下表）；③与**后续正反打|同向**选型咬合（§12 前瞻）。缺场级评估块=失败。
    - **Beat 起止重评（强制；承接开拍评估）**：开拍评估已核运动合理性后——**动作结束后（停驻/落定）**再评终态是否留出**后续动作**所需空间：若下拍/后续仍有走位、对峙、正反打、打斗换位等，终态不得把人挤死在无净空位（贴墙无退路、叠脚无步幅、两人贴死却下拍要拉开数步等）；无后续动作则可写清静止距离。结论写入切换说明`空间重评=通过｜后续动作=有|无｜净空=…`（与`Beat开拍评估`并存，不互相替代）。
    - **身体尺度距离词（强制；禁只写「靠近/远处」）**：成稿描述角色间距须用可拍身体尺度，优先闭集（可组合）：`贴身/贴肩`｜`肩并肩`｜`一臂之距`｜`半臂`｜`一步`｜`两三步`｜`数步`｜`约十步/远距对峙`｜`隔桌/隔案`｜`门内门外分置`。建置/入戏/停驻相对句须可检索该档；可辅以画幅层位（前景/中景/后景）。
    - **构图术语 + 景别咬合（强制）**：用专业构图词标明人物关系可读性，并配**合适景别**使距离可感——景别与距离须同向匹配，禁 Wide 却写贴身无依据、或 ECU 却写数步外对峙同框无交代。常用：
      | 距离档（例） | 宜用景别（意图） | 构图术语（例） |
      | :--- | :--- | :--- |
      | 贴身/肩并肩/一臂内 | MCU/CU/近景；双人紧凑 | Two-Shot｜Dirty Single｜OTS 近肩｜并肩双人 |
      | 两三步/社交距 | MS/Medium Two-Shot｜Cowboy | Two-Shot｜OTS｜单人 Medium + 对方入画缘 |
      | 数步/远距对峙 | Wide/Full/LS｜EWS（环境压迫时） | Wide Two-Shot｜对峙全景｜单人 Full 含对方远景剪影 |
      | 隔桌/分区 | MS–Wide 视桌长 | 过桌 Two-Shot｜对称分坐构图 |
      景别写在建置首句景别位（`Wide|Full|MS|MCU|CU|…`）；构图关系可写在建置/入戏一句（如`Medium Two-Shot，二人相距一臂`）。**非反打**景别收紧沿用父 ENV；须读脸/OTS 反打仍切可读角 ENV。
    - ❌`走近他`无步数/臂距｜❌场级无逐角色动作空间评估｜❌动作结束贴墙却下拍要冲刺数步无重评｜❌CU 写「相距十步」同框无切镜交代｜✅`MS Two-Shot：沈渊与朱七相距两三步；动作结束后空间重评=通过｜后续正反打有净空`。
  - **角色环境速查（并入【观察视角与空间建置】；跨 Beat 真源）**：
    - **目标**：每人主场衍生ENV+**世界扇区**+**F**+姿态+具名锚；不符→入戏补动作再改表（禁无动作改表）。首句单一当前ENV（有变含切换链）；一拍禁切ENV；**当前ENV须通过背景半空间匹配**。
    - **落位两层（强制分立）**：
      1. **世界层（真源）**：扇区∈`0°/90°/180°/270°侧|轴心`+锚+F+**姿态**——写入每拍末`速查更新`；无明文走位/转身/**起跪坐躺**时跨 ENV **扇区+F+姿态原样继承**（姿态档与承托面逐字，不因切角改站坐跪）。
      2. **画面层（投影）**：由本拍 N 查下表得到——只写入【建置】【入戏】（层位/左右/正背面可变；**姿态词照抄世界层，不投影改档**）。ENV 名中的 N=观察轴；禁 ENV=`180度…`却按 0° 轴写左右。
    - **ENV 变画面必变（最高；无走位亦然）**：仅切观察轴、无人走动时——世界扇区/F/**姿态** **不变**，但每人画面层位/左右/正背面**几乎必变**（180° 反打→前景↔后景且正背面对调；90° 切→原前后变左右等）。若 `ENV变=是` 且未动者画面句与上拍**同侧同层同正背面** → **生成失败**（典型病：换了 ENV 名，人仍写在「前景中央正面」）。若 `ENV变=是` 却把未动者姿态档改掉（跪→站等）→ **同样失败**。
    - **视角换算速查表（强制；切角必查；禁凭直觉）**：观察轴=主环境 **N°**（ENV=`{N}度…`；**N 以 ENV 名为准**）。无走位时世界扇区不变，仅按下表重判（俯视顺时针；机位在`(N+180)%360`看向N；**画左=`(N+270)%360`，画右=`(N+90)%360`，后景=N°，前景=`(N+180)%360`**）：
      | 世界扇区（相对主环境 0° 轴） | N=0° | N=90° | N=180° | N=270° |
      | :--- | :--- | :--- | :--- | :--- |
      | **0°侧**（纵轴+ / 原后景侧） | 后景/远端 | **画面左** | **前景/近端** | **画面右** |
      | **180°侧**（纵轴− / 原前景侧） | 前景/近端 | **画面右** | **后景/远端** | **画面左** |
      | **90°侧**（横轴+） | **画面右** | 后景/远端 | **画面左** | 前景/近端 |
      | **270°侧**（横轴−） | **画面左** | 前景/近端 | **画面右** | 后景/远端 |
      | **轴心** | 中景中央 | 中景中央 | 中景中央 | 中景中央 |
      **算术闸**：`后景≡N`；`前景≡(N+180)%360`。**N=180→后景180°/前景0°**（禁把 0°当永远后景）。❌`ENV:[180度…]`+`扇区=0°|→后景` =失败（0°侧应为前景）。落笔：①速查世界态→②先写`N=?｜后景=?｜前景=?`再查表→③建置/入戏只写画面词。台账与算术不符却标通过=失败。
    - **F↔正背面（最高；内部F°/N°，成稿禁度数）**：用世界朝向F与观察轴N核销——**禁**凭主角身份另写正面。ENV=`{N}度…`→后景=N°侧，前景=`(N+180)%360`侧：
      | 世界朝向 F 相对观察轴 N（**仅内部**） | 相对镜头正背面（默认） | **成稿可用表述（禁写 F°/N°/°侧）** |
      | :--- | :--- | :--- |
      | **F ≈ N**（与镜头同向看向后景） | **背对镜头**（背面/侧背面为主） | `背对镜头` / `背面朝镜头` / `侧背面朝镜头`；口型**不可读**；**禁「对镜头」**（含OS）；**禁正面才可见内容**（脸部五官/口型**与**胸膛/肚子/正面躯干等；仅可写后脑/肩背/后腰等可见面）；可补 `面向{后景具名对象}`（禁裸「面向…深处」） |
      | **F ≈ (N+180)%360**（朝向机位/对向观察轴） | **正面或¾面朝镜头** | `正面朝向镜头可读` / `侧正面朝镜头`；**绝对禁**再写「面向后景…」。可补面向**仅当**对象比己更近镜头：`面向{前景具名对象|入画者}` / `面向前景`；**否则省略「面向{角色/实体}」**，改为明确镜头向：`面向镜头正中`｜`面向镜头上/下`｜`面向画左`｜`面向画右`（可重复写清）。**禁**为套模板随便点个后景人/门/天穹当朝向；**禁**写侧背面/背对 |
      | **F ≈ (N+90)%360** | **右侧面朝镜头** | 鼻尖朝**画右**（见下硬锁） |
      | **F ≈ (N+270)%360**（≡N−90） | **左侧面朝镜头** | 鼻尖朝**画左**（见下硬锁） |
      **侧面↔面向硬锁（最高；角色自身左/右）**：`右侧面`=右颊对镜⇒鼻尖朝**画右**；`左侧面`=左颊对镜⇒鼻尖朝**画左**。口诀：**见哪侧颊，鼻尖朝同侧画幅**。成稿**只许**：
      | 正背面 | 面向 | 对应内部 F（相对本拍 N） |
      | :--- | :--- | :--- |
      | `左侧面朝镜头` | **必须** `面向画左`… | F≈(N+270)%360 |
      | `右侧面朝镜头` | **必须** `面向画右`… | F≈(N+90)%360 |
      ❌`右侧面+面向画左`｜`F≈0`却写侧背面（N=180 时 F≈0=正面）｜`F≈(N+180)`却写背对。❌**用户案**：N=180 + 速查`F≈90` + 建置`right profile facing Frame Right`——F≈90=(N+270)⇒须`左侧面+面向画左`；要右侧面+画右须改`F≈270`。面对面：看画左=`左侧面`；看画右=`右侧面`。
      ¾面须与朝机/背机侧一致。**侧背面仅属 F≈N 族**，禁用于 F≈(N+180)。相向默认：前景背对↔后景正面。**绝对禁：既面向镜头可读又朝向后景（最高；零例外）**——`正面/¾朝镜头可读` 与 `面向后景…` / `面向更远对象` **同拍同人互斥**；出现即整拍失败，不得用「对白在看他」「仰望」等借口并存。**三联句（最高；对象=人／簇／环境锚／天穹／裂口／门／台等凡「面向」所指，不限角色名）**：层位+正背面+面向对象层闭合——
      | 正背面 | 面向对象所在层 | 判定 |
      | :--- | :--- | :--- |
      | **正面/¾朝镜头** | **若写「面向{角色/实体}」**：该对象**必须**在**前景(离镜近处)**侧（或同层偏镜头侧），且**比面向者更近镜头**。对象不在前景 → **禁止**写面向该角色/实体，改为省略或写镜头向（见下「露脸朝向写法」） | ✅；❌ `正面朝镜头 + 面向后景(的){人\|龙\|天穹\|裂口\|门\|锚}`（**有无「的」同罪**）= **成稿失败**；❌ 为套模板随便点后景人/门/天穹当朝向 |
      | **背对镜头** | 对象须在**后景/背景(远处)**侧，且**比面向者更远镜头** | ✅；❌ `背对镜头 + 面向前景的{人\|锚}` 且该对象更近镜头 = 失败（除非侧身回望等例外且写清） |
      | **相向对峙/俯冲默认配对** | 近镜侧（前景/偏前景）=`背对镜头 + 面向后景对手`；远镜侧（后景/偏后景）=`正面朝镜头 + 面向前景对手`（对手实层须更近） | 反打 180° 后**两人层位对调、正背面对调**，配对式不变；远侧正面**不得**再写面向后景 |
      - **露脸对象优先 + 朝向写法（最高；按剧情定，禁套模板）**：写建置前先据本拍**对话中 / 动作中**剧情判定**谁须露脸可读**（对白口型、情绪卖点、出手读脸、凝形主体等），再安排他人层位与朝向——**不是**先填「面向{随便一个名}」再凑正背面。
        1. **定露脸对象**：标明`露脸={名}|依据=对白|动作|读脸|Two-Shot…`（同拍可多人可读，但每人各自闭合三联；默认仍先定唯一正面点）。
        2. **要朝向另一角色**：该角色**必须**落在露脸者**更近镜头侧（前景侧）**；否则改站位/反打，或本拍**不写**「面向{该角色}」。
        3. **正面镜头且对象不在前景时**：可**省略**「面向{角色/实体}」，或明确写镜头向——`面向镜头正中`｜`面向镜头上`｜`面向镜头下`｜`面向画左`｜`面向画右`（须与侧面硬锁一致；可重复说明，禁含糊）。
        4. **禁模板填空**：禁止因句式习惯随便找个实体或角色当朝向（后景龙群/天穹/裂口/门/路人等）——面向目标须有本拍剧情核销（对话对象、动作注视、运动终点锚）；无核销则用镜头向或省略。
        5. **Two-Shot 露脸**：可用 Medium/Close Two-Shot 等同框露脸——须**逐人**写清正背面+面向（面向他者则对方须更近；否则各自写镜头向/画左画右）；禁「两人正面相对」却层位/面向互斥。✅`双人中景：甲画左正面朝镜头、面向镜头正中；乙画右¾朝镜头、面向画左的甲（甲比乙近或同层偏近）`｜❌`两人正面朝镜头，互面向后景对方`。
      - **角色位置关系前瞻（最高；按后续戏份选型）**：落笔前须**预测角色间位置关系**——通读本场后续对白/对峙/同行/打斗，先判定该角色对后续主要是 **①正反打戏份** 还是 **②同向剧情**，再设计站位（**不是**一律预埋正反打）：
        | 后续戏份判定 | 站位设计 | 禁 |
        | :--- | :--- | :--- |
        | **正反打 / OTS / Shot-Reverse**（对白轮次读对方、异排异向、攻防正反覆盖等） | 自首次同框对峙起分属**不同纵深层**，相差**≥1 档**（优先`前景↔后景`；可用`前景↔中景`/`中景↔后景`）；相向用近背对+远正面 | 同层并排却互称前/后景；无走位突改层位硬切反打 |
        | **同向剧情**（并肩/同向行进/同向注视/并排旁白/无需读对方反打等） | 可同层分`画左|中央|画右`；面向用`画左/画右`或镜头向；**不必**强行拆前景/后景 | 无正反打需求却硬套相向层位词凑「正反打感」 |
        ❌后续是正反打却双人同中景互称前/后景｜❌后续是同向并肩却强行甲前景乙后景只为套相向公式｜✅先判戏份类型再落位。
      - **开场冲突预评 + 正面基准点 / 露脸对象（最高；逻辑可拍第一）**：写 Scene/Beat 建置**之前**，须先评估本场易优先冲突项（不得边写边撞）：①**谁须露脸**（对话口型/动作读脸——正面/¾；含 Two-Shot）②谁须看谁/看何锚（面向——须剧情核销，禁模板填空）③正反打|同向④纵深差与实层表⑤动作空间/停驻距离。**第一原则=逻辑可拍**：任一「正面朝镜头」与「面向更远对象/后景」等物理不可能组合，在落笔前即判冲突并改方案，禁成稿带病。**选定露脸对象 / 唯一正面点（按剧情）**：在同拍/同对峙单元中，先据**对话中、动作中**指定当前须露脸可读者——优先本拍对白主说者/主行动者/须读脸卖点角色（或反打后轮到的可读方；Two-Shot 可同框多人可读）；标明`正面点/露脸={名}|Beat={n}|依据=对白主拍|读脸|出手|Two-Shot…`。**其余一律以该露脸安排为基准依次调整**：同拍他人层位/正背面/面向须服务露脸可读且三联闭合（典型：露脸点在远侧→近侧背对+面向后景的露脸点；露脸点正面朝镜且对话对象不在前景→**省略面向该对象**或写`面向镜头正中/画左/画右`，**禁止**写面向后景该对象）。**可用动作配合**：他人要改朝向面对露脸点/镜头可读 → 用**转身/转面另起拍**（旧档终态→新拍新档）；要换可读方 → **反打/OTS/Two-Shot 重组 + `ENV变=是`（切角时）**；禁止同拍无过渡硬改正背面，亦禁止人人同时正面却互称面向对方/后景。场级写入【观察视角与空间建置】（可短表）；每拍自检含`正面点/露脸=…｜冲突预评=通过｜朝向核销=剧情|镜头向|省略`。❌未定露脸就多人同时「正面+面向对方」｜❌为凑全员正面破坏层位｜❌正面可读却随便挂后景门/龙群当朝向｜✅先定露脸李玄（远侧可读）→燕三娘近侧背对看他；燕三娘要读脸时另起反打拍改她为露脸点；✅李玄正面对白且燕三娘在后景→李玄`正面朝镜头，面向镜头正中`（不写面向燕三娘），或改站位让燕三娘入前景后再写面向她。
      - **停驻落点与他者相对（最高；运动终态）**：任一角色/可移动主体**运动后停下**时，入戏终点 +【Beat切换说明】`终态画面纵深`/`速查更新` **必须**同时交代：①停驻绝对落位（前景/中景/后景 + 画左|中央|画右 + 具名锚/ENV 结构）；②与场内相关角色的**相对关系**——须含**身体尺度距离**（肩并肩/一臂/两三步等，§12 距离词）+ 画左/画右/层位差；③停驻几何按**后续戏份选型**+**空间重评**——后续正反打→纵深差≥1 档且留对峙净空；后续同向→可同层并排；**尤须评估后续是否还有动作**，终态留够下一步幅/退路。辅以构图术语+景别（如`MS，相距一臂`）。禁只写「跑过去停下」「走到他面前」而无层位/左右/尺度距离。✅正反打向：`冲至后景画右朱七身前一步停下（终态：相距一步；MS OTS 可读；空间重评=后续正反打有净空）`｜✅同向：`跑至中景画左与朱七肩并肩停下（Medium Two-Shot）`｜❌`跑向朱七后停下`。
      - **`面向{层位词}(的){名|锚}`≡对象实层（最高）**：层位词须≡该对象本拍建置实层；禁为凑公式篡改；**「面向后景渊龙」「面向后景的渊龙」同检**。**同拍实层表（强制；【建置】首行）**：凡本拍【建置】出现纵深落位或`面向前景/中景/后景`，**必须先**独占一行写出`实层表：{名}=前景|中景|后景｜…`（可含 ENV 锚），**然后**才写景别/当前环境/画面初始态；面向层位词**只许抄自该表**，禁止边写画面句边猜。交叉核销：①定露脸对象（对话/动作）→②填实层表 →③**仅当**剧情确须朝向他者且该他者比己更近才写`面向{名}` →④选层位词 →⑤核己方正背面是否允许该层 →⑥否则省略或写`面向镜头正中/上/下/画左/画右` →⑦**不得**先写正面优先/相向套话再硬填后景对象。`面向前景的{名}` ⇒ 表内该名=前景（或比面向者更近）；`面向后景的{名}` ⇒ =后景（或更远）且面向者须背对/侧背面。**字面与表不一致=整拍失败**。❌`正面朝镜头+面向后景的裂云天穹`｜❌**用户案**`沈渊…正面+面向后景渊龙`｜❌**用户案**`燕三娘前景正面朝镜头，面向前景的李玄`+`李玄在后景…`｜❌无实层表直接写画面句｜❌**同层互称前/后景**｜❌正面可读却随便挂门/天穹/路人当朝向凑句。ENV变/回挂靠后须按新 N 重核三联+实层表。
    - **速记**：180°反打无人转身→层位与正背面对调，须`ENV变=是`。左右口诀：0°→90°原前景→**画右**、原后景→**画左**。主场ENV可≠镜头ENV，成稿仍先写当前ENV。字段：角色｜主场ENV｜扇区｜位置｜朝向｜与他者｜末次更新。【观察视角与空间建置】=速查+Beat索引。无转身禁改世界向；无动作禁改表/改正面。
    - **七要素/露出/特写**：位置｜姿态｜身体朝向｜正背面｜与他者｜视线｜动作方式——覆盖全部可移动主体（金身≡角色，§1）；背对门禁§12。**新入画**一般须定位特写（位置+朝向+表情等，§1）。每具名角色场内累计≥1次正面/¾（**跨拍满足即可**——近侧对后景对手时可先背对，再以反打/OTS 远侧正面兑现；**禁**为凑本条在同一背对需求拍强写`正面+面向后景`）。特写预标`角色→可读脸Beat→ENV→转正`；背对禁突切脸/胸腹；档位变→另起拍。
  - **站位**：主锚优先相对ENV；他人优先相对主锚。阵列≥3标左中右/前中后。**同层多人分位（强制）**：≥2人同处前景/中景/后景时须分`画左|中央|画右`（或相对主锚左右），禁两人同写「前景中央」。**角色位置关系前瞻**+**动作空间与角色距离**+**停驻落点**见上——场级专评动作空间/距离；动作起止重评；距离用步/臂/肩并肩+构图词+景别。速规：礼法｜尊者居中前｜有桌凳优先坐下(椅名位序；>4人两区)｜>3人分组挂四向ENV｜群演拉开可延迟(入画后守恒)。移动规划=`起点→意图核对→朝向→节点→速度→具体终点(+停驻相对+尺度距离+空间重评)`；**成稿入戏禁写「意图/试图/想要」**，须落具体动作+朝向（§6）；**动物／载具位移同须写清可见面+前进向+具体终点+停驻相对**。
        - **入画径向↔正背面硬锁（最高；经门必核）**：先判出入口相对本镜层位，再锁径向与终态正背面——禁三者各写各的。无明文转身按下表：
          | 出入口相对本镜层位 | 入画行进径向（无转身） | 入画终态默认正背面 | 出入口相对入画者 |
          | :--- | :--- | :--- | :--- |
          | **背景(远处)/后景** | 自背景门洞 **→ 朝镜头**（向前景逼近） | **正面/¾朝镜头**；须锚「面向{内侧空间}（**背对{门名}**）」 | **身后**（门可仍写在背景） |
          | **前景(离镜近处)/画缘近端** | 自近端 **→ 远离镜头**（向背景纵深） | **背对镜头**；须锚「面向{远端具名|内侧}」或「面向背景深处（背对{近端门名}）」 | **身前近侧或画外** |
          | **画左/画右侧缘** | 自该侧入画后沿横/斜轴 | 侧/¾面为主；终态面向须与入室/入殿意图一致 | 按轨迹核销 |
          禁裸「…深处」；须「面向{内侧}（背对{门名}）」。径向表须与「入画径向×活动适配」同拍过关。门终态默认紧闭。动物/载具经门同表（背景驶近→车头朝镜；近端进纵深→车尾朝镜）。
        - **载具/骑乘（含朝向强制）**：载具写**可见面档位+车头前进向**+轴向+占道+节点（§1朝向表+§31）；弹道=`出手→路径→命中→效果`同施力拍。骑乘每拍保留坐骑+骑姿+**人／骑各自朝向**（默认同向；回望分写）+落位至下马；终态含人+载具且双方朝向可检索。
        - **多门空间进出（最高；上车/下车/进门/出门等同锁）**：目标空间有≥2个可通行门/门位时（轿车四门、厢车侧滑门、火车多车门、多门厅堂、电梯轿厢门等），**进入与离开同等强制**——禁止只写「上车」「下车」「进门」「出门」「离开」「出来」。须同拍写清双向路径（服从门窗六维与入画径向）：
          - **进入／登乘**：`从{具名门位/侧} → 到{具名落位点/座位}`
          - **离开／下车**：`从{座位/舱内位/室内锚} → 经{具名门位/侧} → 到{门外/车外具名落点}`（须点明离座起点+出门扇+落地终点三环；缺任一=失败）
          | 场景 | ❌禁 | ✅须 |
          | :--- | :--- | :--- |
          | 轿车/厢车上车 | `上车`／`拉开车门上车`（无哪扇门、无哪座） | `拉开右侧后车门，跨入后排右侧座坐下`（门态→通行→落座） |
          | 轿车/厢车下车 | `下车`／`推门下车`（无哪座、无哪扇门、无落点） | `自后排右侧座起身，经右侧后车门下车，落点站到车右后侧近端` |
          | 多门建筑入 | `进门`／`推门进去`（未点哪扇） | `经东侧侧门入内，落点走到前景中央对白桌前`（挂§11⑧具名出入口） |
          | 多门建筑出 | `出门`／`离开大厅`／`走出来`（无起点位、无哪扇门、无门外落点） | `自对白桌前起身，经东侧侧门出厅外，落点站到门外台阶右侧` |
          | 多人同进/同出 | `众人上车`／`一起下车`／`一起出门` | 逐人各自入=`门位→座位`｜出=`座位→门位→落点`（可同拍分行） |
          座位闭集优先：`驾驶座|副驾|后排左|后排中|后排右`（或原文具名座/铺位）。上车后终态／下拍建置须写清每人舱内座位；下车后终态须写清每人车外/门外落点（相对载具或出入口可核销）；禁「已上车」无座号、禁「已下车/已出门」无门位与落点。骑乘同理：上=`自{侧}上马 → 骑姿落点`｜下=`自骑姿 → 经{侧}下马 → 立地点`。
    - **对白咬合（最高；建置↔入戏方位必须同拍闭合）**：每句`对{具名}|对镜头|望天/空位|内心|画外声源`；称呼锁定。他人目光默认朝说话人。轮次=新Beat；异排异向各切可读ENV。口型不可读先切ENV；反打必切。
      - **背对门禁（最高；canonical）**：
        | 档位 | 方向锚 | 可写 | 禁写 |
        | :--- | :--- | :--- | :--- |
        | 正面/¾ | `对镜头`/`对{前景人}` | 五官/口型/胸腹正面 | — |
        | 背对/侧背面 | `对{后景人}`/`内心`/`望天` | 后脑肩背/握拳等背面外化 | **`对镜头`**；五官/口型/泪线；胸膛/肚子/正面躯干/胸前纹饰 |
        | 左/右侧面 | `对画左/画右的{名}`（同侧硬锁） | 该侧半脸/体侧 | 对侧不可见面；无转正却`对镜头` |
        **须读脸/胸腹正面**→①插/选可读角衍生 ENV（内容选角）②另起拍+`ENV变=是`③新拍建置已正面/¾后再写。转身支路同：新拍建置须已是正面/¾。❌背对+抬眼/眉尾/胸膛金纹｜❌背对+「对镜头」OS。
      - **方位/对白向**：入戏`对画左/画右的{名}`须≡建置左右；对象居中禁写画左/画右。避开对象须写清身体朝向+目光/喊话+例外情绪，禁方位互斥。
  - **剧情随身物件建置守恒（最高；配饰/包/武器等；跨拍强制承接）**：凡角色**身上佩戴、随身携带、手持/背负**且在本场**已出现或原文直接提到、有剧情作用**的物件——含配饰、挂坠、包袋、武器、信物、公文、法器、可交互随身件等（非纯造型无戏耳钉类）——**一律服从建置全套要求**（挂载/持握部位、可视性同锁、名单闭合、禁凭空消失），**不得**因「次要道具/本拍未再交互」省略。

    | :--- | :--- | :--- |
    | **挂载/持握部位** | 佩戴：`正面\|背面\|左侧面\|右侧面`+具体部位；持握：哪只手/哪侧肩背+握持态；背负：哪侧肩/背带位置——禁只写「带着/有刀」 | 玉牌=`正面/胸前`；挎包=`右侧面/右肩斜挎`；长剑=`左侧面/左手持握`或`背面/背负` |

13. **观察视角—实体落位**：每拍必写。填：衍生ENV（Master=`0度…`；**禁裸主环境**）｜观察角(含OTS四要素)｜目标｜可见边界。写前核：∈清单｜须切则切（含**正背面档位变化**）｜**背景半空间匹配（§12；按描述选角）**｜非反打Insert沿用**且正背面档位不变且背景扇区未变**。航拍不作0°轴。
14. **景深公约（最高）**：相对镜头。前景=最近、背景=最远。朝向≠人所在层。扇区≠景深：N°=后景；N+180=机位后方不可见。**背景层具名实体须∈当前 ENV 之 N° 可见半空间**（据【主环境】描述核销）。浅景深可虚焦，在场道具不得删终态。**纵深双落（强制；开拍/收拍切片）**：开拍已在画→①【建置】初始纵深+左右 ②`终态画面纵深`终态纵深；中途入画/突现→仅强制终态（+入戏落定句）；中途出画→建置有、终态无。禁无括注裸「中景/前景」。有走位时终态层位须反映运动结果且可由入戏核销；无走位且全程在画则终态≡建置。
15. **建置重评估 + Beat切换说明自检（强制）**：每拍完整建置（`建置更新=是`；同ENV抄写上拍`终态画面纵深`/ENV变**画面重投影**见§1/§12）。**切换说明=初始建置⊕入戏运动（最高）**：【Beat切换说明】记录变化过程 + 画面终态，**不是**再建一遍与建置相同的初始句；有运动则终态纵深/姿态/正背面须反映运动结果；无运动则终态=初始并仍须写出纵深。**名单闭合（最高；开拍集≠收拍集）**：【建置】≡**开拍可见集**；`{Beat终态画内实体}`≡**收拍可见集**≡`终态画面纵深`具名；**`终态=(建置−本拍出画)∪本拍入画/突现落定`**——禁无条件「终态≡建置」。出画者自终态剔除；中途入画/金身凝形者建置可不含、终态必须含且≡角色全字段。**开拍集≠收拍集（出入画）→过程拍落定后强制另起 Beat**（§1/§4；后续对白/主动作不得同拍续堆）。**纵深/落位闭合**：终态层位∈`终态画面纵深`（≠强制≡建置层位）。**切角/反打/景别收紧≠清场/≠出画**。`角色分组=`禁「同上」。

## 4. Beat 切分与时长（§25–§29、§31；角色粒度见 §1）
> 切分以本节为准；**先定 Beat 粒，再验时长**；**禁** `Shot/Lens Preference` 驱动切分。
- **强制另起**：说话人轮次变更（角色粒度）｜>20字拆句各拍（§25）｜**可拍 ENV 名变**（含任何反打、**切镜头致正背面档位变化**、>90°/越轴/POV/门窗内外/状态）｜**转身/转面/回头转正/转体致正背面档位变化**（单拍禁正+背双态；旧拍终态仍旧档，新拍建置=新档）｜**出入画致建置集合变化**（开拍可见集≠收拍可见集：明文入画/出画/突现/消形出画等——过程拍落定后**强制新起 Beat** 承接后续对白/主动作；切角暂不可见≠本条，§1）｜**背对/侧背面须写五官微表情或口型面部微表情**（§12：须表情→**新可读角衍生 ENV + 新 Beat + `ENV变=是`**；禁同拍背对写抬眼/眉尾/挑眉等）｜听者开口应答｜Reveal/域场变｜决战·宏观阶段节点（§27/28）｜新主动施力且非快链｜转场/闪回专拍｜**原文建立空镜**（`△俯拍/航拍…`｜`【空境/空镜：…】`｜场头环境文学；可与首节拍吸睛合并为独立建立拍；禁并进对白拍而删画面信息；无人戏时仍须独立拍）｜**原文独立景别/特写行**（`△近景/特写/…：…`｜`【特写/近景/大特写：…】`——承载与邻行不同信息单元时须独立拍或紧邻特写切口拍入戏；禁整行删除；轴未变则沿用父 ENV，禁另建特写 ENV）。
- **不强制另起**（同 ENV、轴未变、**正背面档位不变**、**画内集合不变**）：≤90°**非反打** Insert/CU/同侧过肩（禁另建衍生；**模型自增**的景别收紧可并入说话人正文；**原文已单列的`△近景`/`【特写：…】`不得用本条豁免删除**——见上「强制另起」与§1；**反打/转身转面/正背面档位变/出入画改集合/须表情读脸切角不得归本条**）｜同人连续≤20字未打断｜快链攻防换手。不另起≠省建置；一拍内禁中途切 ENV；凡新拍/ENV变须完整重写建置。
- **快链可合并**（§二）：同节奏单元、连续动量、无停顿的无对白/武戏链。硬下限：决战≥10｜宏观≥6。
- **时长**：等效≈对白+动作+留白+奇观，宜 4–15s；中文≈字/4、英文≈词/2.5；追杀节点 2–4s（整链≥20s）；**禁**为凑时长改切分。
25. **对白拆句**：【对白拆句判定】=`已拆句|未拆句|无对白`；>20字必拆并落独立 Beat；**不改词、不删字、不换序**（仅允许在原句边界或自然停顿切开）；拆后各拍`{台词}`拼接=原文全句（项目语言侧）。
26. **客体禁独立拍**：受力/飞物并施力同拍；新主动作才可新拍；载具≠客体（§6）；快链优先合并。
27. **正式决战**：≥10 Beat；对峙→试探→攻防≥4轮→术法域场→逆转→决胜→收势；阶段内可快链；高成本≥3；**各轮招式须前后因果连续**（上轮终态=下轮前因；禁无因换招/空降域场）；**各轮须 OTS／正反覆盖**（攻侧可读↔守侧可读至少切换 1 次，§6）；输出【决战 Beat 规划】+【打斗快慢规划】。
28. **宏观群体**：`宏观群体=是`→≥6 Beat。判定：大军/对冲/兽潮/机群/舰队/人海等（≠2–3人簇）。三要素：无边际满幅｜阵势威武(前中后满编+真实参差，禁机械同步)｜压迫感；高潮三项齐。**规模与排列强制**（叠§1「群演簇人数与排列」）：须写可拍规模（如`千人方阵`/`两翼各数百骑`）+ 阵势排布（整齐纵队/方阵/楔形突击/前中后梯次等）；禁「大军压境」无人数感与队形。主角每拍可追踪；阵势/高潮各≥1全景+≥1特写（七-D）。结构：全景→阵势→压迫→指挥→对冲→余波。输出【宏观 Beat 规划】。
29. **等效时长**：下游单镜 4–15s。切分只服从完整逻辑（粒度/拆句/ENV变/§26–31/快链）；先产出再验算。硬下限：决战≥10｜宏观≥6｜追杀≥20s且节点≥3。【Duration Estimate Basis】=对白+动作+快慢分项+追杀+留白+奇观；集级 reconcile 不得违规压/扩 Beat。
30. **打斗快慢**：升格≈30%(25–35%；>40%滥用；<15%且无快连击=失败)；常速≥50%；每场≥1快连击(≥3招具名+攻防，可同拍，禁全升格)；须穿插特写；缺 30-A/B→缺口。
**§30-A 立体快链**：凡场≥1快连击须≥1 Beat 本模式；动笔前自【主环境】择≥2具名结构。七维最低：①≥2部位+≥3击具名｜②位移≥3次攻守各≥1｜③每招↔挡/闪/拆/反击且**招间前因→后果可追**（上招终态喂下招）｜④≥1上下段｜⑤≥2 ENV结构｜⑥融合≥2层(30-B)｜⑦常速≥50%本链升格≤1。提交≥6/7通过。
**§30-B 环境融合**（同拍）：起点≥2结构锚+材质/光区一句；每拍≥1 ENV信息；命中有陈设反馈。四层 A结构｜B材质｜C光影｜D动态。禁抠图空白互殴。
**句式骨架**：`{常速} 起点：{ENV}+双方落位+材质光区。拍n 甲【招】(攻侧可读ENV/OTS)→拍n+1 乙【应】（守侧反打可读ENV/OTS，因该招）+位移/陈设反馈→终态铺下一招…；{升格}读命中。终态换区（距离/姿态/兵器·术法态可核销承接）。` ❌无招名｜站桩｜中段无ENV｜全升格｜招招无前后因果｜终态不承接｜全程单侧无正反。输出【打斗快慢规划】标30-A+七维+A–D层+招间因果+**OTS正反覆盖**。
31. **追杀/穿梭**：连续位移动量（禁结果概括）。节点≥3（相对距离可核销）；载具主语写路线+方向+特殊动作+相对态（§6）；门洞进→经→出（六维）；跨拍动量承接；可快链仍≥3节点。整链≥20s、≥2 Beat（或单拍≥12s且≥3节点）。入缠斗写撞停/下马；须特写。❌一路狂奔｜1拍抓到｜无路线。输出【追杀/穿梭链规划】。
## 5. 对白与表演
5a. **母语地道**：按项目语言×地理×时代原生写；禁翻译腔；方言用`用{语种}说道{}`。
  - **中英同义去重（最高；服从项目语言）**：权威源=`project_language` / `Language` / `Project Context.Language`（项目信息明确的语言）；未明确时跟随剧本主语言。输入剧本中**同一语义**的中英并列——括号对译、斜线双语、中英各写一遍、字幕式双语对白、叙述层双语重复等——成稿**只保留项目语言侧**，删除另一语种同义表述。❌`{Leave me alone! / 别烦我！}`（项目中文）→✅`{别烦我！}`；❌建置「大门 main gate 清晰可见」→✅只留项目语言一侧。适用范围：对白/OS、建置/入戏叙述、场景名附属说明、角色设定外形性情、环境块文学描述、服化道摘要具体词。
  - **例外（不删）**：①专有名词/人名原文（如 Serena）；②剧情有动机的异语片段（须`用{语种}说道{}`或明文外语动机，非同义翻译堆叠）；③多语言项目设定下的有动机语码切换（非同句双语复述）。禁输出中英同义双语堆叠。
5b. **场面丰满**：禁只堆动作对白；每场≥1背景锚（对白/互动/环境/`<>`声）；**另：每一 Beat【入戏】须含音效`<…>`**（见下「音效描述」）；场景描述融入 Beat（§9）；服化道首落（§7）。
5-0. **核心卖点（按场）+ 集级高低点总析 → 特别描写强化（最高；写 Scene/Beat 前强制）**
  > **目标**：先**逐场**标清本场卖什么（制作向类型闭集），再汇总集级冲顶/落底；对应落点用特别描写强化——禁只堆情节骨架、禁「卖点只在集级摘要、场头/画面无落点」、禁漏场。
  - **⓪ 制作向卖点类型闭集（每场选用；可+连接）**：`动作｜宏观场面｜精彩对白｜打斗美学·飘逸｜打斗美学·暴力｜四美·美食｜四美·美景｜四美·美物｜四美·美人｜蒙太奇技巧`；可兼叙事标签`冲突/人物弧/世界观奇观/情感核/悬念钩/类型爽点`。禁空话「好看/刺激」。
  - **① 必析（写进 Part1；场级优先）**：
    1. **逐场核心卖点（最高；每一 Scene 一行，禁漏）**：`场=EPxx_SCyy｜本场卖点=名（1–2；无则无·过场承接）｜类型=闭集|N/A｜落点Beat=…｜依据=一句｜制作指导=改编:…；资产:…；分镜:…｜强化=特别描写类型｜集级挂靠=卖点k|无`。过场仍须出行。制作指导供下游资产/分镜消费，三环有卖点时非空。
    2. **集级主卖点汇总**（1–3 条，从场级上卷，**不替代①**）：`集级卖点k｜类型=…｜名=…｜主承载场=SCxx@Beat｜强化=…`。
    3. **高潮点**（主高潮 1；次高潮 0–2）：落点=`EPxx_SCyy@Beat n`（或拟增）｜事件摘要｜强度档=`加压|爆发/高潮|反转冲击|温情峰值|悬念落点|崩塌/余波`｜与卖点关系=`兑现本场/集级卖点k|抬升`。
    4. **低点/谷底**（主低点 1；可附 0–2 次低点；**强制标定，不得省略**）：落点=`EPxx_SCyy@Beat n`｜事件摘要｜低点类型=`希望粉碎|关系谷底|孤立无援|道德两难|蓄压谷底|失败余烬|温情被抽空`｜与主高潮关系=`前蓄|后余波|对照反差`。低点≠可跳过过场——须让观众感到「沉下去」再冲高或余烬。
    5. **集级情绪弧**（一句可检索骨架）：如`建置好奇→低点压迫→卖点兑现加压→主高潮爆发→余波钩子`；须能对上场级卖点/高潮/低点；禁「情绪饱满/跌宕起伏」空话。
  - **② 特别描写强化（强制；服务①；不改因果）**：对**每一场有卖点行**、**每一个**主/次高潮、**每一个**主/次低点，须在对应 Beat【入戏】（或紧邻特写拍）落入≥1 种可检索特别描写；缺=失败须回补：
    | 类型 | 合格落点（可拍） | 优先用于 |
    | :--- | :--- | :--- |
    | **角色特写** | 脸/眼/手/肩颈等 CU/ECU（§12 正背面门禁） | 高潮爆发；低点崩溃/隐忍；人物弧/美人卖点 |
    | **环境特写** | 象征陈设/空间压迫/氛围动势 Insert（沿用父 ENV） | 低点孤绝/蓄压；美景/宏观卖点；高潮空间反馈 |
    | **感官/氛围特写** | 可拍光态、声`<…>`、温度触感外化、雨尘烟等介质一句（禁抽象「氛围很好」） | 低点沉底；奇观前蓄；美食/美物质感 |
    | **微表演加密** | 同拍≥2 项情绪外化过程链（§5 表）或听者反应闭环加厚 | 精彩对白/情感核；低点无对白段 |
    | **节奏留白** | 关键拍后独立静默/余烬拍（动作停、呼吸/物件余动、环境余响）；禁空拍无画面信息 | 主高潮后余波；主低点沉底 |
    | **对照强化** | 高低点前后同一锚（物件/空间位/姿态）可检索对照（前热后冷或前满后空） | 卖点对照；低点↔高潮反差 |
    | **动作/武戏过程加密** | 起势→节点→命中/效果可检索（§6） | 动作｜打斗美学·飘逸/暴力 |
    | **蒙太奇锚点** | 进入/回切锚（物件/声/视线）+切片可感 | 蒙太奇技巧 |
    - **双特写优先**：主高潮与「爆发/反转冲击」→角色+环境特写原则上双备（同§5②）。
    - **低点强化优先**：主低点至少 **环境特写或感官/氛围特写 ≥1** + **角色特写或微表演加密 ≥1**（可分拍）；禁只写「他很难过」无放大。
    - **卖点承载**：每一场「有卖点」行须在本场有≥1 特别描写落点可检索；奇观/宏观另服从§8 满幅/分相（若适用）。
  - **③ 与场级咬合**：每 Scene 头须复述本场卖点块（见下§5①）；【高潮与核心情绪点】另勾选集级身份（`集级=主高潮|次高潮|主低点|次低点|集级卖点挂靠`）。Part1 逐场行与 Scene 头、Beat 入戏三者须同号可核销。
  - **④ 禁**：只写集级不写场级｜漏场｜只在 Part1 写卖点/高低点却 Beat 无特别描写｜臆造改因果的「假高潮/假卖点」｜把过场误标主高潮｜省略主低点｜用作者旁白代替可拍描写｜有卖点却制作指导三环空。
5. **细节特写 + 本场卖点/高潮/低点（人物弧光）/核心情绪点咬合（最高；每 Scene 强制 · 写 Beat 前）**
  > **目标**：**开始写本场 Beat 前**先标定**本场核心卖点**（制作向类型+制作指导）、高潮、低谷（人物弧光）与情绪弧（并挂靠§5-0），再核销「有无对应特写/特别描写放大该点」；**缺则主动增拍/特写切口**——不得只写情绪词却全程中远景平推。下游分镜（`shot_generation` §二.0）与资产生成将按本场类型与制作指导分配支撑。
  - **① 每场必析（写进 Scene 头【高潮与核心情绪点】；动笔 Beat 前完成）**：通读本场剧情后，明文标定：
    1. **本场核心卖点（强制）**：`本场卖点=名|无·过场承接｜类型=§5-0⓪闭集|N/A｜落点Beat=…｜制作指导=改编:…；资产:…；分镜:…｜特别描写落点=Beat…｜集级挂靠=卖点k|无`。
    2. **本场高潮**（1 个主高潮；可附 0–2 个次高潮）：落点剧情（谁/何事件）｜强度档=`压抑蓄力|加压|爆发/高潮|崩塌/余波|温情峰值|悬念落点|反转冲击`｜落点 Beat（或拟增 Beat 号）｜承载主体=`角色|环境|角色+环境`｜集级挂靠=`主高潮|次高潮|无`。
    3. **本场低点 / 人物弧光**（有则必写；无则`无：本场非谷底`）：低点类型（同§5-0）｜落点 Beat｜**弧光角色**（具名）｜弧光态=`希望粉碎|关系谷底|孤立无援|道德两难|蓄压谷底|失败余烬|温情被抽空|决意拐点`｜集级挂靠=`主低点|次低点|场内谷底|无`。低谷=本场可见的人物弧沉底或翻转拐点，禁省略。
    4. **核心情绪点**（≥1；通常 1–3）：每点写`情绪名（压抑/恐惧/决绝/狂喜/羞耻/杀意/孤绝/压迫…）｜触发因果｜落点 Beat｜需放大方式=角色特写|环境特写|双特写|感官氛围|微表演加密`。
    5. **情绪弧摘要**（一句）：如`蓄压→低点→对峙加压→爆发→余波`；禁空话「情绪饱满」。
  - **② 特写/特别描写咬合检查（成稿前强制；缺=失败须回补）**：对①中**每一个**高潮、低点与核心情绪点，逐项核销是否已有**可检索**的放大描写（类型表见§5-0②；下表为特写主口径）：
    | 类型 | 合格落点 | 常见用途 |
    | :--- | :--- | :--- |
    | **角色特写** | 独立拍或紧邻切口拍入戏：脸/眼/唇/手/肩颈/胸腹局部等 CU/ECU；须服从§12（**背对禁写正面五官与胸腹正面**；须转正或切可读角 ENV 后再写） | 可读脸时：压抑/低点=眼睑/下颌绷/握拳白指；爆发=瞳孔/唇颤/泪线；决绝=视线定死；恐惧=骤张眼+后倾。背对未转正时改肩背握拳等可见面 |
    | **环境特写** | 独立拍或切口：空镜细节/象征陈设/压迫性空间构件/氛围动势 Insert（门缝光、钟摆、雨痕窗、空椅、摇晃灯罩、裂缝、远景孤灯等）；**轴未变且非反打、正背面档位不变→沿用父观察侧衍生 ENV**，禁另建特写专属 ENV | 压抑/低点=窄门缝/高窗小光/空旷回响物；高潮=结构震动落点/旗帜猛摆/灯爆闪；孤绝=空椅/无人长廊尽头 |
    | **高潮空镜（可增；对齐上游）** | 高潮/重要情节落点可另起或紧邻**空镜描写**（建置可写「空镜／无角色」+ENV；入戏=本场已有实体/光色/天气 ≥1 动势或象征增量）；**优先本场景内**，禁另换无关外景凑气氛；轴未变沿用父 ENV | 爆发余波=烛火跳灭/空椅余摆；反转=窗外雷光；决绝前=长廊孤灯 |
    - **双特写优先**：主高潮与「爆发/崩塌/反转冲击」级情绪点，**原则上**须同时有角色特写 **与** 环境特写（可同拍内先后切口，或紧邻两拍）；仅一方有、另一方缺=须主动增补。
    - **高潮/重要情节→空镜可增（优先本场景）**：集级/场级高潮及揭破/决裂/命中/反转/生死抉择等重要情节，在角色特写与效果反馈外**宜增空镜描写**托气氛/余波；挂本场固定清单或未落清单实体，须有可见增量，禁无动机观光；场外对位空镜仅双线加压需要时用之。
    - **低点咬合**：本场低点（含集级主/次低点）须满足§5-0「低点强化优先」；仅台词说惨而无特写/氛围=失败。
    - **压抑蓄力例外**：若场核为长压抑、高潮在后，蓄压段至少 **环境特写≥1 或 角色局部特写≥1**（手/呼吸/物件），不可全程无放大。
  - **③ 缺则主动增加（强制；不改因果）**：核销发现缺口时，**必须**在情绪落点 Beat 内增特写/特别描写切口，或**紧邻另起**特写拍（文戏链=`触发→视角→特写→承接`）：
    - 增补只加可拍微表演/景别收紧/环境象征细节/**本场景空镜**/感官氛围/节奏留白，**禁止**新增改因果事件、改对白事实、改站位世界态（无走位时扇区/F/姿态继承不变）。

    - **原文已写`△特写/近景`或`【特写：…】`时**：该行即强制核销切口（§1），计入②咬合；不得因「另凑情绪特写」而替换或省略原文特写内容。
  - **④ 底线数量**：每场细节特写合计≥1（含原文核销与主动增补）；**文戏**在满足②双特写/低点/蓄压例外后，局部特写通常≥3（与下「强度」一致）。脸部服从§12；原文细写道具须有特写切口。
  - **⑤ 对话·打斗·法攻效果→表情/特写突出桥段（强制；对齐上游主笔 15c；不改因果）**：**对话击中、近身命中、法攻/术法命中与挡格**的效果须在【入戏】用**角色表情 + 特写级局部**写出，使桥段触发｜升级｜回收可从脸上读到——禁只写台词接力或招式/光效轨迹而无脸部与局部反馈。

    | :--- | :--- |

    | **法攻命中·对撞·挡格** | **目标方**中招/承压表情或可见面外化≥1 + 余波落在人/物上的局部；禁只写介质/爆炸无人脸上变化 |

7–8. **表演连贯**：承接上拍落点；操作链无跳步；原文表演层逐项核销（服从§1 原文逐字核销）。
- **格式**：音效`<…>`｜台词`{…}`｜方言前置标注。
- **音效描述（最高；每 Beat【入戏】强制）**：每一 Beat 的【入戏】**必须**含 ≥1 条可听剧情音效，格式一律尖括号 `<{音效描述}>`（例：`<门轴吱呀一声>`｜`<远处传来狗叫声>`｜`<剑刃相击金属脆响>`｜`<雨点砸在窗棂上>`｜`<靴跟踏在石板地上的短促回声>`）。

  2. **落位**：写在【入戏】与触发动作/对白/环境事件的**时序对应处**（可与动作同行，或紧邻独立行）；同拍多事件可多条 `<…>`。静默对白拍仍须有环境/器物/呼吸可听锚（如雨声、钟摆、远处车流），**禁止**整拍无尖括号。
  3. **原文核销**：原文已写声音/音效/背景声/可听线索 → 须落入尖括号（逐字或等义可检索）；禁删声只留画面。
  4. **禁止**：省略音效；把音效写进【建置】代替入戏；写 **BGM/配乐/主题曲**（剧情音效≠配乐）；升级为混响/频段/分贝等后期细参；无剧情依据堆砌装饰声；空尖括号 `<>` / `<无>` / `<气氛>`。
  5. **下游**：Stage 2.2 **原样透传**尖括号全文（禁译抹/删改）；`shot_generation` §六.2 按尖括号继承落镜。缺尖括号=该 Beat 不合格，须回补后输出。
- **禁无内容语言描述（最高硬约束）**：【入戏】**禁止**出现没有具体台词内容的语言/语气壳。判定=本行在 `开口｜闭嘴（…）` 之后**无非空 `{台词}`**（花括号内至少一字；空白/`…`/`无`/仅标点=空）。❌`闭嘴（对空位，voice_identity=皇子·冷峻青年音，tone=压抑，…，voice_type=内心）`后无`{…}`｜❌纯动作行挂 `voice_type=OS/内心` 空壳｜❌听者反应行套语气层却无台词。✅有内心/OS 时：`闭嘴（对空位，voice_identity=…，tone=…，…，voice_type=内心）{……}`｜✅纯动作：`皇子：右手握粗布擦拭剑刃；眼睑低垂。`（**不**写开口/闭嘴/voice_*）。目光/对谁可写在动作句内，**≠**可借此挂空语气层。
- **语气层（有台词才必填）**：仅当本行有非空 `{台词}` 时强制全字段——`voice_type`｜`voice_identity`(禁省略)｜`tone`｜`speed`｜`volume`｜`rhythm`｜`stress`｜`pause` + `{台词}`；与微表情咬合。禁只写 tone。**无台词行禁止出现任一 voice_* 字段或「开口｜闭嘴（…）」括号块**。
- **`voice_identity` 填写说明（强制；TTS/配音锚；仅有台词行）**：=该说话人**稳定声线身份标签**（谁在用什么嗓/气口说话），**≠** `tone`（当句情绪）**≠** `voice_type`（对白/OS/旁白通道）。每条**有具体台词**的对白/OS/V.O./旁白/自白均须明文填写，**禁省略、禁空、禁「默认/同上」**。
  1. **格式（推荐）**：`{具名}·{声线类型+身份/年龄气质}音`——前段=说话人具名（与入戏主语/`【角色命名】`一致）；中段=声线选型+职业/阶层/年龄气质具体化；尾缀`音`。旁白无具名角色时可写`旁白·{气质}音`。✅`林医生·领导型主治医师音`｜`阿强·市井青年音`｜`沈渊·冷峻青年音`｜`Serena·优雅女继承人音`。可接受短写（仍须可辨身份）：`冷峻青年`｜`Elegant Heiress`——但**同人全稿须统一一种写法**，优先推荐格式。
  2. **声线选型闭集（须具体化，禁裸标签）**：`领导｜御姐｜萝莉｜村妇｜老者｜军人｜书生｜反派｜市井`（可+年龄/职业词：青年/中年/主治医师/管家等）。选型须匹配角色年龄/性别气质/身份阶层（上游 `#身份`/`#对白声线`/【角色设定】/Part1【角色命名】地位）；❌只写`领导`无职业｜❌少女写`老者`无剧情依据｜❌全员同用`市井`。
  3. **跨拍稳定（最高）**：同一具名角色本集内 `voice_identity` **全文同值**（Part1【角色命名】登记一次 → 各 Beat 语气层逐字复用）；禁随情绪改声线身份（情绪走 `tone`/`speed`/`volume`/`rhythm`）。换装/变装/伪装改嗓仅当原文明文「换声/假声/伪装」→可另标并在 Part1 注明触发；否则禁改。
  4. **辨识度**：不同身份角色不得同腔——主要正反派与重要配角的 `voice_identity` 须可区分；继承上游 `#对白声线` 语义（称谓/句式气质）转成声线标签，禁标签化台词口播。
  5. **字段分工**：`voice_identity`=稳定声线｜`tone`=当句情绪（压抑/决绝/随意…）｜`speed/volume/rhythm/stress/pause`=当句节奏重读停顿｜`voice_type`=通道（对白/OS/V.O./旁白/自白…）。❌用 `tone=领导` 代替 `voice_identity`｜❌ `voice_identity=压抑`（情绪误填）。
  6. **语言**：与项目语言一致（中文项目写中文标签；英文项目可写英文标签如 `respectful old man`）；方言台词仍用同一 `voice_identity`，语种只走`用{语种}说道`前缀。
  7. **Part1 登记**：`【角色命名】` 每具名须含 `地位｜voice_identity=…`；成稿抽检任意**有台词**对白行的 `voice_identity` 须≡该表。
- **OS/V.O./旁白/自白闭嘴（强制；须有非空台词）**：仅当本行确有非空 `{台词}` 且 `voice_type∈{画外音,OS,V.O.,旁白,自白,独白,内心}`→建置/入戏逐人写闭嘴。①OS/旁白/画外音→画内全员闭嘴；声源在画外则不写其画内落位。②自白/独白/内心→发言人+他人均闭嘴+方向锚。背对时方向锚仍禁`对镜头`（§12）。有台词的 OS/旁白等通道仍须填 `voice_identity`（禁因闭嘴省略字段；**禁无台词仍写闭嘴语气壳**）。
- **思想转自白**：心知/暗想→自白或短OS（**须写出非空 `{台词}`**）；禁作者旁白；转写后仍须服从上条明文闭嘴。若剧情只需可见表情/动作外化、无内心文案→只写动作微表演，**禁止**空 `voice_type=内心` 壳。
- **情绪外化**：先过剧情必要门——须体现具体情绪才外化；需要时≥2项过程链，**闭集日常常见项**（禁自创稀奇微动作）。悲=低头塌肩｜怒=下颌绷+握拳｜惧=眼骤张+后倾｜紧=手敲/游移｜羞=视线躲开+唇咬｜犹豫=抬手中停｜决心=视线定｜温=轻抬手｜冷=斜睨｜喜=唇角扬｜愧=回避｜杀意=视线定死。背对时五官项改可见面外化（§12）；落在§5②情绪点/高低点附近并尽量与特写·特别描写咬合（对齐§5-0）。
- **强度**：夸张/细腻/标准；文戏局部特写≥3（含情绪咬合与卖点/高低点主动增补）。影视标签仅服务剧情。
## 6. 动作与武戏（§二、§27–§28、§七）
- **动作规格（七项织入流畅句）**：①部位+幅度/速度/力度(止于手级)｜②始→终位；门开向内/外；**禁指节贴触**｜③文戏低缓(武戏例外)；**细微动作仅剧情必要具体情绪+日常常见禁创新**｜④惯性过渡｜⑤操作链禁跳步｜⑥情绪外化(先过必要门)｜⑦因果可感。❌跳结果｜无幅度「抬手」｜无情绪核销硬塞细微动作｜自创稀奇微动作。
- **打斗/斗法招招前后因果连续（最高；连续攻防段强制；不改因果事件）**：继承并强化上游招式链——每一招须可追**前因**（承上招终态：空门/失衡/落空余势/挡格反弹/距离开合/术法余波/护盾裂口等）→**过程**（起势·轨迹·可见介质）→**后果**（命中/落空/挡格/打断+效果）→**铺下一招**（本招终态须能触发下一式动机与可行性）。跨拍强制承接：相对距离｜姿态/重心｜兵器或握持落位｜术法/护盾/域场现态（有则）。攻防须双向咬合（甲招→乙因该招而应→甲因乙之应再出招）。斗法链=`结印/引气可见→介质成形轨迹→对撞/偏转/穿透→余波→下一式从余波态起手`。**视角覆盖另服从「打斗／法攻 OTS 正反覆盖」**——因果双向咬合≠可单侧机位糊弄。❌无因果堆招｜姿态/距离/结印态跳步｜双方平行炫技｜护盾未破无穿透说明却直伤本体｜「激战一番」摘要。扩写只补可拍过程与承接，**禁新增改因果事件**。
- **意图→具体动作（最高；【建置】【入戏】强制）**：禁「试图/想要/打算/企图/准备去/想干/trying to/wants to/attempts to」代替可拍动作——须转译为具体动作链，并闭合朝向/正背面/运动终点/对白向（§1/§12）。
  - **转译要求**：谁｜哪一部位｜幅度/速度｜自何始位→至何终位｜相对镜头与画幅朝向（背对/正面/侧面+面向画左/画右/对{具名}）｜具体终点或交互对象｜结果反馈（若被拦/失手则写可见受阻过程，非「试图失败」四字）。
  - **失败改写例**：❌`试图推开门` → ✅`右手掌心抵住大门门扇中部，向前用力推，门扇向内开至半开`（开向/门轴服从门窗六维；入画径向↔正背面硬锁）｜❌`想要抓住他的手腕` → ✅`右手自腰侧向前伸出，五指扣向画右近前{名}的右腕`（面向与抓取方向同侧闭合）｜❌`打算转身逃走`（且同拍写完转身+背影逃）→ ✅拆两拍：Beat N 建置正面，入戏`以左脚为轴开始转身`（终态仍正面档）｜Beat N+1 建置背对镜头，入戏`沿动线冲向背景大门，经大门出画外`（正背面变=另起拍；终点具体）｜❌`试图扑向王座` → ✅`自前景中央向前扑出，双手前伸，落点扑向后景王座台阶前`。
  - **与「犹豫/决心」微表演区分**：情绪外化可用「抬手中停」「视线定」等**可见停顿/微动作**（§5）；**不得**用「想要/试图」概括未发生的大动作。未执行的意图若剧情只需心理→走思想转自白/OS（须明文闭嘴），**不得**在入戏写空意图句冒充动作。
  - **内部规划词≠成稿**：位移规划中的「意图」节点仅作内部核对；写入【入戏】时必须已换成上列具体动作句。成稿出现意图词=整拍失败，须回改。
- **主节拍/客体**：每拍唯一主动施力方；客体禁独立拍（§26）；施力→命中→反馈同拍。
- **载具独立行**：`{载具名}：…`；人操作与车体分行；追逐=`途经→方向→特殊动作→速度→相对距离`（§31）。载具属§1**可移动主体**——须写入【建置】**可见面档位（车头/车尾/左/右侧身朝镜头）+车头前进向/停靠向**+落位，并入进出场三态与差集（禁只在入戏出现、建置无名、无朝向或跨拍蒸发）。**人上车/下车另服从§12「多门空间进出」**——入：人行`从{车门位}→到{座位}`；出：人行`从{座位}→经{车门位}→到{车外落点}`；载具行写门开合/车体态；禁人行只写「上车/下车」而门位、座位或落点不可检索。
- **快链合并**：同节奏4–15s连续动量可合并；须拆=切ENV/读脸｜Reveal｜域场变｜决战节点｜追杀跨环境/将超15s。

- **打斗／法攻 OTS 正反覆盖（最高；对齐对白 OTS／正反打）**：连续打斗、近身缠斗、斗法、投射法攻、金身／法相借体出手等**对阵段落**，覆盖语法**必须参照对白 Shot-Reverse / OTS**——对参战**各方**的主动作出手与受力／挡格反馈，均须有**可读角（正面／¾ 或该动作所需可读面）**与**反打可读角**体现；**禁止**全程单侧机位只拍甲方出手而乙方仅背影／远景糊弄，**禁止**只写攻不写守的可见面、只写守不写攻的可见面。

## 7. 转场与开场
- **开场**：§16三步+服化道首落；入画经具名口+完整建置。微表演：呼吸/手敲/视线/肩线｜眉眼唇｜喜剧大眉眼(禁脸红)；禁指节贴触。
- **转场总则**：Beat间/场内闪回/场间/首节拍——判定+OT+首节拍**合并写入**【场景切换与首节拍转场】。闪回/回切须带可拍光学手段（色调变化等，见下「闪回禁臆想多久前」），禁仅靠字幕报时。
- **场间四步（禁硬切）**：动机→桥接(≥1可感)→入场现态(+服化道)→情节咬合。
- **立场/进出场因果链加厚（最高；跨 Scene 强制）**：前后两场存在**立场、进场、出场**直接因果时——典型：追杀/追逐转入下一场、前场环境毁灭后逃入异地、溃败溃逃、押送/护送跨场等——成稿须在上场末 Beat + 下场首 Beat（及【场景切换与首节拍转场】）**清晰交代**：
  1. **出场细节**：谁经何出入口/路径离场；离场动作过程；相对对手/压力的终态态势；环境将毁时如何脱出危险区。
  2. **进场细节**：谁经何入口入画；入场动作与落点；追杀链须可感先后/间距（禁下场双方已站定却无进场过程）。
  3. **状态变化细节**：人物衣态/伤态/喘息/持物/人数相对上场终态的可感差（无变化写「态同上场终」）；环境毁灭过程在上场可核销；禁下场完好如初却上场刚经恶战且无换装/疗伤核销。
  - 写入【场景切换与首节拍转场】短标：`因果链=追杀|环境毁灭|溃逃|护送|无｜出场@Beat…｜进场@Beat…｜状态差=…`。❌「追到仓库」摘要跳步｜❌上场轰塌下场无损整装。
- **转场服化道**：切场/换主环境/首节拍首落环境细节、服饰(**换装必交**)、道具。**Scene 内【场景切换与首节拍转场】强制单行**`服化道核销摘要：环境细节=…｜服饰/换装=…｜道具细节=…`（无则对应项写「无」；**三项=原文初始态**）——下游 Stage 2.1 只消费此行。Part1 仅标签`【服化道初始态】通过｜无终态回填` + `【转场首节拍】…｜服化道摘要=Scene内已写`。**换装明文**：`{具名}｜旧装→新装`（或「入场即{新装}」）；建置/入戏须可见新装；禁只写「换好衣服」无具名无新旧差——2.1 据此拆 CHAR。❌摘要缺具名｜Scene 内省略三项只写散文。
- **服化道/环境初始态锁定（最高硬约束；严格按原文）**：
  1. **权威源**：服化道三项与【主环境】固定清单/文学氛围 = 原剧本对该空间的**初始建立描述**（场头、`△`/`【空境/空镜】`、开场首落、入场现态）——**逐字/逐信息单元**摘抄核销；禁概括改写、禁意译美化、禁下游「为好看」增补回填摘要。
  2. **禁剧情发展回填基准**：禁止把**后文剧情推进后的结果态**写入本场服化道摘要、【主环境】基准、【角色设定】初始外形——如打斗后狼藉、爆炸废墟、火烧烟熏、域场改写后陈设、湿透/血污/战损衣态、道具被毁后残片等。此类变化只进：①Beat【入戏】过程链；②跨拍可持续结构/氛围改写→`{主}_{状态}` 状态衍生（§11）；③明文换装→服饰项旧装→新装 + 衍生行。
  3. **剧变分档（视在该环境停留时长）**：情节对环境/服化道改动过大时，**禁止**用改写后的终态覆盖初始基准，须按下表拆：
     | 判定 | 处置 |
     | :--- | :--- |
     | 短时过程（单拍/短链；可读空间仍是原主环境，未形成可持续新基准） | 只写 Beat 入戏过程；必要时瞬态留 Beat，不改建【主环境】 |
     | 跨拍可持续的结构/重大氛围改写，但仍在同一主空间包络内 | 建状态衍生 `{主}_{状态}`；服化道「环境细节」仍写**改写前初始态**；状态差异进衍生/`empty_view_delta` |

- **逻辑链**：①上场承接｜②四项(时空/桥接/轴线/跨幅)｜③附C OT+手段各≥1｜④首节拍吸睛(环境动态+实体动势各≥1；宏观须特写过渡)→建置→入戏｜⑤下场预埋。每场≥1 `borrowed_films` 对标。

## 8. 特效与宏观（六相；库见附录B；宏观§28）
- **驱动力可视化（强制）**：气/灵气/内功/真元/罡气/魔力/念力/力场/剑气等驱动运动时须写可拍介质——禁只写「运功」或只写结果。必写：形态｜轨迹(源→路径→落点)｜作用+反馈｜介质建置承接；小规模可同拍，大规模叠六相。
- **具象化/规格**：大特效优先化龙凤兽/法相（触发→凝形→落点→作用）；禁高潮只写「能量爆发」。启用即写：触发｜因果可感｜具象形态｜范围(锚ENV边界+未覆盖)｜影响(**具名固定实体**逐项；禁「环境震动」无落点)｜六相`起势→显形→扩散→命中→维持→余波`｜时限。跨拍改结构→`{主}_{状态}`（§11）。七-E择1–2+范围/影响各≥1。宏观见§28；群演写簇；小簇≠宏观。
- **人态化特效主体**：凝形成可辨头面/肢体朝向→**§1「金身／法相≡角色」**（九字段+入画当拍建置+分名分写）+ **§1「宿主↔法相／金身动作同步＋因果共写」**（原则与原主同步同相；凝形/出手/同损/收摄须同拍写清宿主驱动与法相对应可见结果；不同步仅失控／反噬等明文例外）；六相过程另写。无定形介质只走六相+实体落点，不替代本体建置。消散→可拍消形后自终态剔除，且宿主侧须有收摄/解印等对应动作（宿主暂不可见则差集标注因果仍成立｜同步挂靠）。
- **宏大特效：变化细节 · 满幅可渲染 · 细节撑时长（最高）**
  > **判定（命中任一）**：域场/结界/天地法阵｜化龙凤兽/法相/巨化｜大范围元素爆发/对撞波前｜云海改写｜宏观灾难/奇观主相位｜标「宏大/全屏/天地/无边际」｜奇观≥8s 或跨≥2 Beat 环境级特效。轻量单点/近身气爆不适用本条硬门槛，仍须六相可核销。
  > **目标**：满幅可渲染 + 六相各有可辨变化细节撑时长；禁一句「能量爆发铺满天空」。
  1. **满幅/全屏可渲染（强制）**：入戏须写清特效在画幅中的**铺满态**——①覆盖层级=`前景介质|中景主体|后景边界/天际/地平` 至少两层同时有可见变化；②边界锚=`ENV 边界/地平线/穹顶/海面/城廓/山脊` 等具名或可核销空间边界（禁无边界「到处都是光」）；③规模词须可拍（无边际满幅｜自锚点向外吞没至边界｜对撞波前横贯画幅），**禁止**只写角色周身光晕却自称宏大。主相位景别意图=Wide/EWS/全景级（本阶段写画面规模，不写下游运镜处方）；可穿插细节特写切口，但**不得用特写替代满幅主相位**。
  2. **分相变化细节（强制；六相各相≥1 可辨增量）**：每一相须写出**相对上一相多了什么可见变化**（形态/尺度/密度/颜色或明度迁移/边界推进/实体受力态），禁六相复读同一句「光芒更盛」：
     | 相 | 须有的变化细节（择写具象，禁空词） |
     | :--- | :--- |
     | 起势 | 源点凝核/纹路初现/气流或尘粒初扰；尺度仍局部 |
     | 显形 | 主体轮廓可读（鳞甲/法相肢体/阵纹几何/元素形体）；材质或层次≥1 |
     | 扩散 | 边界外扩轨迹（沿何结构/向何方/吞没哪些区）；密度或层数变化 |
     | 命中 | 与具名实体/对手/地面的接触瞬间：碎屑/震环/灼裂/倾侧等**逐实体** |
     | 维持 | 稳态动势（旋转/脉动/粒子雨/云海翻涌）+ 未覆盖区仍可见对比 |
     | 余波 | 衰减方向、残留痕迹、烟尘落定、实体终态；禁瞬间清空无过程 |
  3. **细节撑时长（强制）**：宏大特效不得压成「闪一下」——须用可拍细节过程体现时长：
     - **等效下限**：单段宏大主相位奇观耗时规划 **≥8s**（对抗/对撞型 **≥10s**；跨拍可持续域场按「显形+维持」跨 Beat 累计，维持相须持续写动势细节而非静贴图）；写入【Duration Estimate Basis】奇观分项或 Beat 入戏可核销过程链。
     - **过程密度**：六相中至少 **4 相**各含 ≥2 个可检索细节单元（粒子/碎屑/边界涟漪/实体反馈/光影冲击环/鳞甲生长节段等）；细节不足→拆相写细或另起承接拍，**禁止**靠空时长标注凑秒。
     - **景别节奏**：满幅主相位 + ≥1 细节特写/Insert（鳞甲缝、阵纹节点、波前尘墙纹理、巨物眼部等）再回满幅或余波——细节服务宏大可读与时长，不改因果。
  4. **实体落点不豁免**：满幅不等于「环境震动」四字——须逐项写清哪些**具名固定实体**受何种可见作用，未影响者保持原态（与上「具象化/规格」同锁）；跨拍改结构→状态衍生。
  5. **禁**：抽象光球高潮｜六相粘贴无增量｜只写结果无过程｜满幅声称但只拍角色半身光效｜用特写冒充宏大主相位｜无细节却标 ≥8s。

42. **上集紧急回收保真（强制）**：
  - **已解决证明（类型执行摘要）**：输入若含摘要「上集紧急回收核销块」或等价 `#项…状态=已兑现`/`兑现=scene_id@Beat`，扩写后对应 Beat 的动作/对白/剧情**不得删漏、不得默消、不得推迟到集后半**；摘要核销证明须保留可追溯。无上集 → Part1 标 `适用=无上集`。

  - 若输入**缺摘要核销**但正文/场头出现上集危机承接，仍须在成稿 Beat 兑现，并在 Part1 标 `上游缺摘要核销|已补`。**禁止**用 `BRIDGE_BLOCK` 的「回收=」或仅 Part1 标签代替场面兑现。【紧急回收自检】=`摘要已兑现Beat仍在|缺口`＋`文末待核销块保真|缺`。
