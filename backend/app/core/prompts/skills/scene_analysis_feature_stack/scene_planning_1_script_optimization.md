## 核心任务
**【环节】**三阶段中的剧本优化/继承扩写/可拍化生成。  
**【目标】**零遗漏继承 + 结构强化 + 合理改写 + 可视化前置 + **补全微表情与微动作**（让剧本与主动作更有表现力，让对白—反应—动作链更具连贯性）。  
**【覆盖】**剧情结构、站位调度、**微表情/微动作/微反应补全与动态过程链**、**对白—反应—动作连贯衔接**、每场细节特写、对白情绪标点与节奏、题材适配表情（喜剧夸张/情感细腻）、心理外化、风格视觉化、动作细分、**AI视觉特效强化**、对白与 `OS/V.O.`、环境补充、节奏转场、全员反馈闭环。  
**【边界】**不改原剧情事实、核心动作链、对白语义、人物关系；不得新增改变因果的新事件。**禁止**在本阶段输出或使用 `ENV`/`PROP`/`CHAR` 资产分类标签及 `ENV:`/`PROP:`/`CHAR:` 前缀；仅以剧本自然语言具名称呼人物、物件、空间；是否提取为资产、`ENV/PROP` 归属、升格归档与衍生变体均由 **Stage 2-1** 裁定。  
**【允许】**影视化插入：特技呈现、**AI可拍特效奇观**、环境描述、微反应、微表情/微动作、细节特写、动作拆解、对白停顿与颗粒度细分、**按情绪补标点控节奏**（不改对白语义与剧情信息）。  
**【AI优势】**主动运用生成式视觉能力：超大尺度、微观细节、能量物理、时空扭曲、风格化质感、多主体同帧奇观；原文未明示但题材/情绪/信息可视化需要时，可合理增补特效，不得改变因果。  
**【输出】**`Scene切分`、`环境/衍生环境说明`、`[ADAPTED_SCRIPT]`、`project_visual_backfill(JSON, 强制)`。

**每个【动作/视觉节拍】均须按下列逻辑完整执行**；**前置 + 六环节**彼此咬合、缺任一即 Beat 不合格。细则分别见强约束 §5/§6/§11/§12/§13/§24 与 §二/§四。

| **5** | **微动作 + 微表情（动作/对白配套）** | **每个主动作、每句对白、每个听者/触发者反应**均须各含 ≥1 **微动作** + ≥1 **微表情**，按 `部位 → 起始态 → 变化方向/幅度/节奏 → 落点/余韵` 动态过程链书写；视线/头颈/肩线/肢体位移的变化方向须写清立体三轴（§5）。长对白每 2–3 句至少 1 处组合切口；禁止只写对白/动作而无配套表演层。 |

**Beat 成稿前核验（强制）**：**⓪ 是否已读取上一 Beat（或 Scene 首 Beat 之开场建置/上场承接）全体站位终态，且本 Beat 落位/位移有变化依据** → ① 观察视角与环境、三层建置是否同拍咬合，且**当前环境已通过环境—视角匹配自检**（OTS/正反/POV 等已切对衍生环境，非主环境错配） → ② FG/MG/BG 各层内是否**每个实体**均已逐个写清三轴位置 → ③ 每个实体是否均已写**运动方向与朝向**及**动作方式**（含力度/速度等，移动者含轨迹节点），且**每个角色前后位置已标明参照系（相对镜头 / 相对 ENV / 相对实体）** → ④ 有对白时**对白咬合**是否成立 → ⑤ **每个动作与每句对白**是否均有配套微动作+微表情 → ⑥ 表演连贯与全员反馈是否闭环。

## 强约束
1. **零遗漏继承**：逐句核销；动作/暗示/过渡台词/背景设定不得跳过。  
2. **心理可视化**：心理必须转译为微动作、微表情、道具接触、空间反馈。  
3. **创作**：结构、站位、微表情/微动作/微反应、每场细节特写、风格视觉化、**主动作归属主动施力方（被动物件轨迹与纯粹受力位移写入同 Beat，禁止客体/纯粹受力独立成 Beat）**均在本阶段完成；**每个 Beat 须完整执行「Beat 完整逻辑」前置 + 六环节**；Beat 2 起须先完成环节 0「参考前一 Beat 全体站位」，即使原剧本已有场景分镜等的划分，也要遵守以下规则进行创作。  
4. **每场细节特写（强制）**：每个 Scene **至少 1 处**；须写清特写对象、可见部位、**变化过程**、叙事功能、承接 Beat；禁止整场无特写切口。落点优先：情绪转折/信息落点、长对白停顿与听者反应、道具线索/环境纹理、武戏接触受力瞬间。  
5. **微表情+微动作双轨（强制）**：= Beat 完整逻辑环节 5；下列为动态过程链写法与密度补充。每个【动作/视觉节拍】除主节拍外须各含至少一项微表情与微动作；**每个主动作、每句对白、每个听者/触发者反应均须配套**。均按**动态过程链**书写：`部位 → 起始态 → 变化方向/幅度/节奏 → 落点/余韵`；涉及视线/头颈/肩线/肢体位移者，**变化方向须写清立体三轴（横向左中右 + 纵深 FG/MG/BG）**；禁止静态定格式。长对白/停顿处优先插入组合切口；**原文未写但情绪/信息/动作链需要处须主动补全**，不得留表演真空。  
6. **表演连贯性（强制）**：= Beat 完整逻辑环节 6；**空间站位承接**见环节 0。下列为表演层补充：相邻 Beat、台词轮次与主动作须**承接上一表演落点/余韵**；对白后必有听者/触发者动态反应，反应后再入下一台词或主动作，禁止对白—反应—动作链断层。跨 Beat 持续情绪须写渐变或保持态；状态跳变须有触发交代。主动作起势须呼应前一 Beat 身体姿态与视线；武戏形体链与微表情/微动作同链咬合，禁止 Beat 间表演层断裂或情绪复位无依据。  
7. **原文点出表演层（特别提醒）**：原文明确写出或强暗示的表情、神态、视线、呼吸、手部/肩颈/喉结细部、停顿反应，须**逐项核销并可视化动态改写**进【动作/视觉节拍】/【语言】/【全员反馈】；禁止遗漏、合并吞掉、仅留对白删表演层，或压成静态形容词。改编前先建**核销清单**（原文表述 → Beat 落点 → 动态改写）。  
8. **Scene切分**：按连续时空+同叙事目标划分；时间跳跃/空间跨越/**完整闪回/回忆段落**（见§三「闪回三档判定」）/闪回蒙太奇/目标切换/行动线切换即新 Scene；**快速闪回**（短促回忆对话/有情节画面切片，叙事目标仍锚定当下场；**仅当待呈现回忆对白合计 >30 字**，见§三）不新建 Scene，以**转场专拍 Beat** 或同场插入节拍承载；**无情节回忆切片**（仅印象/情绪/物象触发、无具体对白链与动作情节，见§三）不新建 Scene，**并入相邻 Beat 转场链**或短转场专拍，**不受 >30 字门槛约束**；仅视角/构图/特写/正反/节拍变化不新建 Scene。  
9. **环境定义**：环境=可复用拍摄空间，按空镜写：边界、内外/日夜、空间基准点、固定结构、固定家具/基础陈设、光源、声源、阻隔、尺度、景深层次。思考时可先用“主锚点”定空间原点，成稿须写为具体空间结构具名部位（如「会议桌右前角」「文件柜玻璃门」）。人物与可交互物件以剧名/物件名书写，**不预做资产分类**；会被拿起/递交/移出/破坏/独立展示或跨 Beat 承接状态的物件须写清可拍动作证据，归属由 Stage 2-1 裁定。  
10. **主/衍生环境**：每个 Scene 1 个主环境（0度正面建置）。衍生环境分两类，须分别扫描，不得互相替代：  
  - **视角衍生**：主环境顺时针 45 度倍数切换（`OTS`、门窗内外、屏幕内、镜中、遮挡后、画外声源等触发）；命名 `{观察角度}度{主环境名}`，冲突时追加 `_{衍生类型/观察区域/可见方向}`。  
  - **状态/特效衍生**：AI 特效/域场/环境级冲击导致**固定结构、光源、边界或可拍空镜基准**发生**剧烈且可持续**变化，且须**延续至下一 Beat 及后续 Beat**（非纯瞬时光效/粒子/拖尾）时，必须另建状态衍生环境；命名 `{主环境名}_{状态/域场标识}`，如 `侯府正厅_符阵覆盖态`、`实验室_磁暴电离域`。  
  - **扫描默认“有”**：每 Scene 必扫 `0/45/90/135/180/225/270/315` 视角衍生；**凡 Scene 含环境级特效/域场/结构破坏再生且余波或后果跨 Beat**，必扫状态衍生。仅“5秒内、极简单轴、少/无对白、无多角度触发、无跨 Beat 环境态变化、无后续切换需求”可写无，须附 `无：否决证据`。  
11. **站位与空间建置（强制）**：= Beat 完整逻辑环节 2–4 的展开细则；**Beat 2 起动笔前须先完成环节 0**（读取上一 Beat 全体站位终态）。文首总纲表为唯一基准，本节为执行层。  
  - **核心定义（先三层，再层内逐个）**：建置与站位须按**固定书写顺序**展开：**① 先建 FG/MG/BG 三层框架**（每层写清结构/边界/框景阻隔与层间关系；无有效前景须说明原因）；**② 再在每个层位内，对该层出现的每一个人物与物体逐个、具名**写清落位。禁止跳过三层直接按人名罗列；禁止只写环境氛围或「两人在桌边对峙」等笼统句；**画内可见主体清单（§16）中的已入场者，须在本 Beat 三层内全部落位**（**§15 远距离/受限 POV 例外**：`全局建置=延迟` 时，首 Beat 仅落位当前 POV 可见/可读者，其余标注待补全 Beat）。群演簇可按簇描述，但须写清簇内人数、分布区段与**运动方向与朝向**（含视线落点）。
  - **书写顺序（强制）**：`观察视角+环境 → FG（结构+层间关系 → 本层每个主体逐个落位）→ MG（结构+层间关系 → 本层每个主体逐个落位）→ BG（结构+层间关系 → 本层每个主体逐个落位）`。成稿须按 **FG → MG → BG** 分段叙述，不得打乱层序。
  - **层内逐主体七要素（强制，该层内每个人物/物体各写一遍）**：`[具名主体] + [所属层位 FG/MG/BG（=相对镜头纵深，必填）] + [横向序位（左/中/右）] + [距参照物距离（须标明参照系：相对当前环境结构部位 / 相对镜头 / 相对具名实体）] + [运动方向与朝向] + [面部/视线/传感落点] + [动作方式] + [与他者/环境的相对关系（前/后/左右/隔障须写清参照环境结构、镜头纵深或具名实体，禁止裸写「在前/在后」）]`；有对白时另须核验**对白咬合**（环节 4）；层内缺任一要素即该主体建置不完整。
  - **前后位置双轨（强制，逐角色）**：每个角色的纵深/前后序位须**分列写清**两条（可同句，但两类信息不可缺）：  
    - **相对镜头**：所属 FG/MG/BG + 可选距镜头远近（近距/一步/深景等）；  
    - **相对环境或实体**：锚定当前环境具名结构部位（如「办公室会议桌右前角前侧一步」「门内侧后」）或相对另一具名人物/道具（如「陈医生身前半步、桌沿隔障」）。  
    ❌ 「林医生站在前面」｜✅ 「林医生 **MG 层**（相对镜头），**会议桌右前角前侧**一步（相对环境）」｜✅ 「林医生 **FG**（相对镜头），**陈医生身前、桌沿隔障**（相对实体）」
  - **思考模板（内部推演，不得原样输出）**：`[环境/主锚点逻辑] + [视角角度] + [FG/MG/BG 各层结构] + [各层内主体逐个落位] + [空间约束] + [环境切换]`
  - **成稿覆盖项**：当前环境名与观察基点、视角角度、**FG/MG/BG 三层框架（结构+层间关系）**、**每层内每个可见人物/物件的独立落位**、距具体参照物距离、阻隔/高低差/行动余量、**运动方向与朝向（含视线/传感落点）**、相对实体定位、环境切换。全部内容不得留空或"-"等符号替代；**禁止**用「全员/两人/若干道具已就位」概括替代层内逐个主体描述。

      - **说话人**：身体面向与视线/传感落点须指向本 Beat **主听众**（或明确声源对象）；台词含**第二人称/直呼其名/「你」「您」/指向性称谓**时，须与**被点名的具名人物**一致，禁止说话人背对或侧背主听众却标「正在对白」。

20. **资产分类禁令（强制）**：全文禁止 `ENV/PROP/CHAR` 分类术语、`ENV:`/`PROP:`/`CHAR:` 前缀及资产表式枚举；仅以自然语言具名书写，并为 Stage 2-1 保留归类证据（固定陈设 vs 可移动交互、跨 Beat 状态变化、拿起/递交/破坏等）。  
21. **输出边界**：不得输出 `Scenes Table` 或 `Shot List`；“首镜/补镜头”仅指视觉节拍。  
22. **Backfill强制校验**：第三部分只能有一个 JSON 代码块，顶层 `project_visual_backfill`；`Global_Style`、`borrowed_films`、`borrowed_films_note`、`tone`、`lighting`、`plot_summary`、`music_recommendation` 必填非空，`borrowed_films>=1`；`plot_summary` 须为 **80–120 字中文**百字剧情总结（概括核心剧情、人物关系与情感走向，禁止剧透终局细节）；`music_recommendation` 须写明配乐风格、情绪基调、参考曲目/作曲家/影视配乐及主要使用场景（开场/高潮/情感转折等）；禁止 `null`/空串/`[]`/`{}`/`TBD`/`N/A`/`待补`。  
23. **每场对白拆句判定（强制）**：每个 Scene **必须**单独输出【对白拆句判定】，明确本场是否进行了拆句处理；禁止省略、默认不写或仅在 Part 1 汇总而不逐场声明。  
  - **判定值**：`已拆句` | `未拆句` | `无对白`（三选一，不得留空）。  
  - **已拆句**：逐条列出被拆原句/原段（说话人+原文或核销源对应句）→ 拆句后各子句（含情绪标点）→ 落点 Beat → 配套说话动作切口或听者微反应。>20 字单句或同一角色连续说话 >20 字**必须**拆句并标 `已拆句`。  
  - **未拆句**：须写**未拆原因**（如：全场最长台词≤20 字且节奏无需断句；纯 OS/V.O. 画外无口型；武戏无画内对白；单句短促爆发且≤20 字等）。禁止对 >20 字应拆句台词标 `未拆句`。  
  - **无对白**：本场无任何对白/OS/V.O./旁白/独白，写 `无对白：原因`（如纯动作场、纯环境转场、纯特效专拍等）。  
  - **与成稿一致**：【对白拆句判定】须与【语言】各 Beat 成稿台词、拆句结果一一可核销；拆句不改词义与剧情信息，仅断句+标点+节奏。
24. **纯粹受力/客体运动禁止独立 Beat（强制）**：**纯粹受力的动作不得单独建 Beat**，必须与**主动作（发力方）**合成同一 Beat 的因果链延续；被动物件飞行/滚动/落点、受力方纯粹被动位移（被推动、被击倒、被抛出而无格挡/闪避/承接等主动意图）均须写入**施力方 Beat**内连贯描述，**禁止**升格为下一 Beat 的「主节拍」。**唯一例外**：受力方产生**新的主动作**（接球、格挡、闪避、拦截、反击、主动后撤收势等）时，方可新开 Beat，且**主节拍归该新的主动施力方**，不得把「球飞了」「人被推倒」本身当作 Beat 主节拍。写法见§二「主动作主体示例」。

## Scene/环境识别
- **流程**：先判 Scene，再判主环境，再判衍生环境。  
- **Scene四问**：时间连续？空间连续？行动线连续？叙事目标连续？任一断裂即新 Scene。  
- **环境六要素**：环境名、内/外、日/夜、空间基准实体、空间边界、固定结构。  
- **环境描述边界**：仅写影响交互/站位/通行/遮挡/攻防/视线/声音定位的空间约束；不写材质纹理工艺配色等美术细节。  
- **命名**：主环境=“功能/地点+关键特征”（0 度基准，不加角度前缀）。**视角衍生**=`{观察角度}度{主环境名}`，同角度多区域冲突时追加 `_{衍生类型/观察区域/可见方向}`，如 `45度办公室会客区`、`180度办公室会客区_桌后反打`。**状态/特效衍生**=`{主环境名}_{状态/域场标识}`，如 `办公室会客区_符阵覆盖态`、`侯府正厅_墙体崩塌态`；与视角衍生可同时存在、分别切换。  
- **切换句式（强制）**：视角衍生写 `触发 -> 顺时针角度 -> 切至/返回 环境名 -> 空镜差异 -> 下一节拍承接`；状态/特效衍生写 `特效触发/六相链落点 -> 环境剧变完成（通常在维持/余波相）-> 切至/返回 状态衍生环境名 -> 空镜差异（固定结构/光源/边界变化）-> 下一 Beat 起沿用直至恢复触发`。  
- **禁令**：氛围/情绪/景别/特写不是环境；停顿/表情变化/正反打不是新 Scene。

### 一-B、场景切换与首节拍转场（合并说明，强制）
本小节统摄 **Beat 间过渡、Scene 内快速闪回、Scene 间切换、每场首节拍**；与 §二「转场专拍 Beat」「转场手段参考库」配套使用。Part 1 / Part 2 **禁止**将切换判定、首节拍技巧、出场转场拆成三处各写一半，须合并写入 **【场景切换与首节拍转场】**。

- **转场逻辑链（强制顺序，逐 Scene 走完）**：  
  1. **上场承接**：读取上一场【视觉落点】为本场入点锚；写明「上场落点 → 本场如何接住」（动作余势/视线/声音/物体/色调/构图之一或多）；全剧第一场写「无上场：开场特例」。  
  2. **切换判定（四项必填）**：`时空关系`（连续/省略/跳转）｜`桥接依据`（动作/视线/声音/特写/色调/光影/遮挡/图形 Match/运镜/声画对位等，至少一项）｜`轴线状态`（同侧/已交代过轴）｜`跨幅级别`（小跨幅/已说明跨环境）。禁止无依据硬切。  
  3. **手法选定**：从 §二「首节拍 OT 标签」+「转场手段参考库」各选 **≥1 项**；场间切换与每场首节拍**须标 OT 简称** + 自然语言可拍描述；Beat 间小过渡可只写手段名称。  
  4. **首节拍三步咬合**（强约束§15）：**吸睛（前 3 秒）→ 建置（观察视角+环境+先 FG/MG/BG 三层、再每层内逐个实体落位）→ 入戏**；吸睛手段须与 Step2 桥接依据、Step3 OT/转场手法**同链**，局部特写吸睛后须后拉/摇移或紧接全局建置。**远距离/受限 POV 例外**：首 Beat 为瞄准镜/望远镜/远距监控等 POV 时，建置步**仅覆盖 POV 可见范围**，可标注 `全局建置=延迟`，不必同 Beat 后拉全场；补全 Beat **优先 OT-LS/OT-MAP/OT-AE 等航拍/高位俯瞰建置**，再写 `{下一节拍起幅}` 或专拍 Beat。  
  5. **下场预埋**：本场末 Beat 或【视觉落点】须写明可供下一场 Step1 承接的锚点（落点画面/动作态/声源/物件状态）。

- **三层切换粒度**：  
  | 层级 | 典型场景 | 写法要点 |  
  |---|---|---|  
  | **Beat 间** | 正反打、视线 Match、无情节回忆切片 | 同 Scene；无情节切片可并入转场链，不必独立 Beat |  
  | **Scene 内插入** | 快速闪回（回忆对白 >30 字）/ 无情节回忆切片 | 不拆 Scene；快速闪回主节拍=快速闪回桥接；无情节切片主节拍仍归当下场，切片写入转场链（§三） |  
  | **Scene 间** | 时空跳跃、空间跨越、完整闪回 | 新 Scene 首节拍走完全链；上场末+本场首须双端桥接；完整闪回另拆独立 Scene |

- **首节拍技巧 = 场间转场技巧**：每场第一个【动作/视觉节拍】的 OT/转场手法，即本场**入画方式**；须同时回答——**从哪来（上场承接）→ 怎么切进来（桥接+OT）→ 第一眼看什么（吸睛）→ 空间怎么建立（建置）→ 戏从哪入（入戏）**。

- **与转场专拍 Beat 分工**：需独立展开的桥接情节（场间省略、蒙太奇、声画对位、快速闪回等）→ 上场末 Beat 或本场首 Beat 建**转场专拍 Beat**（主节拍=转场/快速闪回桥接），其前后 Beat 仍须写切换判定与承接；简单连续时空且桥接可在首节拍三步内完成 → 不必另建专拍 Beat。

- **远距离 POV 延迟建置示例**：【Scene实体覆盖】`全局建置=延迟`；已入场：狙击手李、目标王、观察员张——Beat 1 仅落位李（POV 观察侧）+ 镜内王剪影压点；张与王全场关系标注「待全局建置 Beat 3，触发：镜筒移开；补全手段：OT-LS Drone 高位俯拍 rooftop 建置航拍景观」。Beat 1 首节拍：瞄准镜十字线压王胸口吸睛 → POV 衍生环境建置镜框/靶区 FG/MG/BG → 李扣机指渐紧入戏；Beat 3 Drone 自 BG 高位俯拍缓缓下降，一次性建置 rooftop 三人 FG/MG/BG 全局落位与相对距离，再切近景入戏。

### 二、空间位移与动作微观化
- **主节拍/主动作（强制）**：每 Beat 标明**唯一**主节拍/主动作，且**必须归属主动施力方**（**例外**：转场专拍 Beat 主节拍=转场桥接，见下条）；被动物件的运动、落点、碰撞及**纯粹受力位移**仅为该 Beat 因果链的延续描述，**不得升格为独立 Beat**（执行见强约束§24）。微动作不得替代主动作，但须在全员反馈与对白停顿中持续落地。  
- **纯粹受力/客体运动禁令（强制，§24 展开）**：  
  - **同 Beat 必写**：施力主动作 → 接触/命中 → 受力反馈 → 客体轨迹或受力方被动位移 → 落点/碰撞/静止，全链写在**发力方同一 Beat**（或发力方动作延续的下一 Beat，主节拍仍归同一施力方）。  
  - **禁止独立 Beat**：以被动物件为主语的单 Beat（「球飞向…」「杯摔碎」「纸张飘落」）、以纯粹受力为主语的单 Beat（「他被推倒」「她被撞飞」且不含主动格挡/闪避/承接）——均须**并入上一施力方 Beat**。  
  - **可新开 Beat 的条件**：仅当**新的主动施力方**接续并承担主节拍——如对方接球、门将扑救、格挡反击、主动闪避后还击、主动后撤收势等；此时主节拍归该人物，不得仅写「受力结果」而无其主动意图。  
  - **链过长拆分**：**施力起势 Beat** → **同一施力方动作延续 Beat**（含客体全程轨迹至静止/命中，或受力方纯粹被动位移至落点）；**禁止**拆出「客体独立 Beat」或「纯粹受力独立 Beat」。  
- **形体动作因果链（强制）**：施力-受力、接触-运动等同链，须先写完整主动作与受力反馈，再写结果轨迹/落点；禁止只写结果而跳过施力主动作。**主节拍必须归属主动施力方**（人物、有自主意识的活物、或术法/机关的明确触发者）；客体轨迹、旋转、飞行、落点、碰撞须写入施力方同一 Beat 的因果链内连贯描述。仅当**新的主动施力方**接续（对方接球、门将扑救、第二人拦截等）时，方可新开 Beat，主节拍归新施力方。  
- **主动作主体示例**：  
  - Beat 1 主角立于球场 **MG 左区**，右脚由 **BG 右下**发力踢球→球沿低平弧线由 **MG 左前** 飞向 **FG 门口**、在门槛 **FG 前侧** 反弹后滚入走廊 **BG 中纵深**（施力主动作与客体轨迹同 Beat）。  
  - Beat 1 甲挥拳击中乙胸口→乙上身受力后倾、脚跟离地半步后坐倒在地（施力、命中、受力反馈、落点全链同 Beat）。  
  - Beat 1 林医生 **MG 左区**推桌→桌上文件夹沿 **MG 桌面**滑向桌沿（施力主动作与客体轨迹同 Beat）。  
  - Beat 1 主角踢球→球飞向 **FG 门口**；Beat 2 门将 **FG 中区**跃起扑救（主节拍归门将，新主动施力方）。  
  - Beat 1 黑色轿车自 **BG 左深区** 沿 **MG 左车道** 加速驶向 **FG 中偏右区**（车头朝右前，途经 **MG 中线** 后变道至 **FG 右车道**），在斑马线 **FG 右前区** 急刹停稳（施力主动作=加速驶近与制动，轨迹与终落同 Beat）。  
- **特效拆 Beat（例外）**：术法/域场/奇观六相链过长时，可 **起势 Beat → 特效专拍 Beat → 落位 Beat**（细则见§三-B）；不得替代形体动作链，不得跳过触发源。  
- **转场/过渡专拍 Beat（例外）**：凡 Beat 间、Scene 间或时空/情绪/信息需桥接的转场，本阶段为连贯性**优化补写的过渡情节**（蒙太奇切片、空镜桥接、声画对位、匹配切、走位穿越、环境异象铺垫、情绪余韵承接、**快速闪回**、**无情节回忆切片**等）**可单独建 Beat**；**主节拍=转场桥接**（**快速闪回**时主节拍=快速闪回桥接，**须满足回忆对白 >30 字**，见§三；**无情节回忆切片**可并入相邻 Beat 转场链而不必独立建 Beat，见§三）；须写清：切换判定（时空关系/桥接依据/轴线状态/跨幅级别）、前后承接落点、OT 或转场手段名称、可视过程链；**快速闪回**另须标明进入锚点、回忆切片内容（对白/动作要点）、回切锚点与质感处理（见§三）；**无情节回忆切片**写清触发→切片画面要点（≤2s）→回切锚点与质感即可，**不要求**完整对白链/动作链/三层建置。此类 Beat 服务于叙事连贯与转场可读，**不**视为客体独立主动作；**禁止**无桥接依据的硬切占位。  
- **转场专拍示例**：Beat 3 对白落点，林医生视线定格门外→ Beat 4【转场桥接】走廊灯光由暖渐冷、脚步声叠化、门缝光带收窄（桥接依据：声画对位+色调渐变；时空关系：连续省略）→ Beat 5 陈医生推门入画。  
- 路径、开关方向、进出径向、绕障路线须写清；凡方向变化须按**立体三轴**落点，且**前/后须标明相对镜头或相对 ENV/实体**（见 §11 前后位置双轨）。

### 三、内容增强与文化纵深
- 改写前先核对项目时代/地理/族群阶层/制度/题材；缺失写“缺失：按原文与题材常识保守处理”。  
- 结构按“建置->发展->转折->高潮->尾钩”推演；明确发展重点段与高潮重点段。  
- 闪回仅可视觉化原文明示/强暗示信息，不得新增因果事件。  
- **闪回三档判定（强制先判）**：  
  - **完整闪回**：时间层切换、人物/环境/道具状态态与当下形成**可识别差异**、或回忆段落须独立承载对白链/动作链/信息 Reveal → **必须拆独立 Scene**（执行见强约束§8）；前后 Scene 间仍须保留桥接关系。  
  - **快速闪回（有情节）**：服务于当下场情绪/信息落点的**短促回忆对话或具名动作情节切片**（通常 1–3 Beat、单段 ≤8s 体感）；**启用门槛（强制）**：待视觉化呈现的**回忆对白原文合计须 >30 字**（含画外/OS/V.O. 闪切台词；不含仅触发回忆的当下台词如「你还记得吗」）；**≤30 字且含具体情节/对白**时**禁止**建快速闪回 Beat，改以当下场微表情/微动作、听者反应、口述转述或 `OS/V.O.` 承接。人物年龄态/妆发/服装、环境状态、道具状态与当下**无实质差异**，或差异仅通过质感处理（去色、虚化、噪点衰减、柔焦、慢速等）即可区分；回忆内容**补充印证**当前对白/反应，不独立承担新叙事目标。**不拆 Scene**，在当前 Scene 内以**转场专拍 Beat**（主节拍=快速闪回桥接）或插入节拍承载；须写清进入锚点（视线/物体/台词关键词/声音桥）与回切锚点（动作余势/声残响/构图呼应），手法优先：感官冲击闪切、定格闪帧、回忆质感衰减、闪回梦境叠化、跳切、声画对位。  
  - **无情节回忆切片（转场式）**：原文或强暗示仅有**印象/情绪/物象触发**，**无具体对白链、无完整动作情节、无独立信息 Reveal**（如「想起父亲的脸」「雨夜的车灯」「爆炸一闪」「童年走廊剪影」）；**不受 >30 字门槛约束**，**禁止**升格为完整闪回 Scene 或扩写为快速闪回 Beat。**处理方式**：按**转场手段**写入相邻 Beat 的转场链——触发（视线/物件/声/触觉）→ **≤2s 单幅或 1–2 帧印象切片**（写清可见物象/人物剪影/环境色块，**不要求**完整 FG/MG/BG 建置与对白咬合）→ 质感处理（去色/虚化/噪点/柔焦/慢速等）→ 回切当下（动作余势/微反应/声残响）；可并入上一 Beat 末、下一 Beat 初或短转场专拍，**主节拍仍归当下场**。**禁止**为无情节切片单独扩写对白链或完整动作链；切片内具名主体须列入【Scene实体覆盖】，但可仅写剪影/局部/impression 级落点。  
  - **回忆对话处理原则**：原文或强暗示的「想起/记得/当年/那时说过」类回忆——**无具体情节**→ **无情节回忆切片（转场式）**；**≤30 字且有具体情节/对白**→ 当下场口述/反应/OS，不闪回；**>30 字且未达完整闪回升格条件**→ **优先快速闪回**；**构成独立戏剧段落**（多轮对话、完整动作链、状态态大变）→ 升格为完整闪回 Scene。  
  - **示例（快速闪回）**：回忆对白「爸，你别走，我会乖乖听话的，以后都听你的话，求你别丢下我一个人，我真的好怕」>30 字 → 转场专拍 Beat：银打火机特写 Match 切至回忆质感画面，幼年林医生对父亲上述对白闪切（≤8s）→ 声残响回切，陈医生面部微反应承接。  
  - **示例（无情节切片）**：林医生视线落向窗外雨痕 → 去色+柔焦 1 帧「童年走廊尽头父亲背影剪影」感官冲击闪切 → 回切当下，林医生喉结滚动、呼吸一滞；不建独立闪回 Beat，不拆 Scene，不写回忆对白链。  
- 古装/豪门必须体现礼法座次与高低站位。  
- `UI`/旁白/对白最终统一到剧本指定语种。

### 三-B、AI视觉特效强化（细则，强约束§19之展开）
- **定位**：本阶段须**前置规划**可拍特效，不得留给下游即兴补。  
- **触发判定（满足任一即须考虑）**：原文明示/强暗示术法异能科技奇观；题材属仙侠/玄幻/科幻/奇幻/恐怖/悬疑超自然/史诗战争；情绪高潮/转折/Reveal 需视觉外化；信息可视化；空间建置需天地异象或环境域场。  
- **Beat 分配**：  
  - **同拍咬合**：特效较短、与单一形体动作强绑定 → 写入同一 Beat，与角色主动作同框。  
  - **特效专拍 Beat**：六相链须分帧、域场/对抗/宏观微观奇观、或单 Beat 塞不下完整链 → 单独 Beat，**主节拍=六相链**；前 Beat 写触发/起势，后 Beat 写命中后果/落位/收势；专拍内锚定角色具名与微动作/微表情。  
- **特效环境衍生（强制，跨 Beat 承接）**：当特效/域场/环境级冲击改写**固定结构、光源、边界或可拍空镜基准**，且变化须**延续至下一 Beat 及后续 Beat**时：  
  - **升格门槛（须同时满足）**：① 六相链「命中/维持/余波」已改写 FG/MG/BG 内空间结构或空镜基准（如墙体崩裂、地面陷落/符纹定帧、寒潮域场、黑雾半室、建筑再生完成态等）；② 已写明变化**至少延续到下一 Beat**；③ 非仅观察角度切换。  
  - **专拍/同拍分工**：环境剧变可在**特效专拍 Beat 的维持/余波相**完成，或**同拍六相链**内完成；**下一 Beat 起 `当前环境` 必须切换为状态衍生环境**（强约束§10 命名），并触发 §14 建置重评估——FG/MG/BG 须按**新空镜约束**重写，不得沿用破坏/域场前的主环境建置。  
  - **返回主环境**：术法消散、域场解除、时间跳转、Scene 切换等恢复基准态时，须写清触发与 `返回 {主环境名}`；纯 Beat 内瞬时光效/粒子/拖尾**不**建状态衍生环境。  
  - **示例**：Beat 5 专拍符阵炸开，地面符纹定帧、文件柜半倾、冷蓝域光压顶（余波相完成）；Beat 6 起切换至「办公室会客区_符阵覆盖态」，建置重建——**MG** 桌面被光幕覆盖、**BG** 文件柜倾斜虚焦，人物落位按新空镜重写。  
- **写法**：自然语言；写清作用范围与 FG/MG/BG 内受影响人物/物件/空间结构；追逐/对抗/载具类须写速度+方向变化（每变向节点须 FG/MG/BG+左中右）并回写新落位。  
- **AI特效方法参考库（按需选用；输出写名称+自然语言展开）**：  
  - **能量/术法类**：能量聚散、法术轨迹、符箓光纹、法阵展开、灵气涡流、剑气刀光、元素吐纳、对撞冲击波、护盾力场、能力觉醒外显、灵力灌注、禁术反噬纹。  
  - **形体/变身类**：形态切换、巨大化缩小化、分身残影、虚化透明、石化冰冻、异化表征、装甲外骨骼展开、血肉再生、兽化半兽化、年龄瞬间变化。  
  - **时空/维度类**：时间冻结变速、空间折叠扭曲、门扉传送、平行叠影、记忆闪回实体化、预知幻象、因果回溯残像、次元裂缝、时空涟漪、画中界出入。

### 四、对白/旁白/心理外化
- **继承边界**：改标点控节奏，不改意图、词义、事实与因果。  
- **每场拆句声明（强制）**：每个 Scene 在【对白拆句判定】中明确 `已拆句|未拆句|无对白`；已拆句须列原句→子句→Beat→切口对照；未拆句/无对白须附原因。Part 1【对白拆句自检】须逐 Scene 复核判定与【语言】成稿一致。  
- **情绪标点（强制）**：先判情绪阶段，再选标点；与 `tone`/`speed`/`volume` 一致；服务口型与微表情切口。可用：`，` `。` `……` `——` `！` `？` `、` `「」/""`；策略类型：压抑型、爆发型、试探型、喜剧型、治愈型、紧张型；>20字拆句时每子句自带标点。  
- **禁止**：滥用标点；标点与 `tone`/`speed` 冲突；改数字/人名/关键事实词。  
- **OS/V.O./旁白**：明确归属与听者；适用情绪标点与同场反馈规则。  
- **主听众（强制）**：每轮标最主要听众及依据（`叙事目标相关度 > 视线直指 > 空间距离 > 因果承接`）；默认禁止并列，证据等强才写“并列：原因”。听众反应含动态微表情+微动作各≥1。  
- **心理外化**：转译为可拍微表情+微动作+道具接触+空间反馈；禁抽象情绪词（执行见强约束§5/§7）。  
- **环境补充**：仅服务剧情与动作逻辑；禁新增改变因果的实体/事件。  
- **输出**：【语言】直接写成稿台词；第一部分写【对白节奏标点】策略与典型落点。

### 五、角色表情与题材适配
- **先判表情强度**：`夸张型`（喜剧/轻喜剧/日常搞笑/闹剧/反差萌）| `细腻型`（情感/爱情/治愈/亲情/现实主义细腻/文艺）| `标准型`（悬疑/剧情/职场/犯罪等）；混合段按节拍切换。  
- **微表情选材**：优先从 §一「微表情常见项」择项组合；喜剧/夸张型场叠加 §一「喜剧类微表情常见项」；须写清部位与动态过程链，禁抽象情绪词。  
- **夸张型**：眉眼幅度大、嘴型明确、多肌肉组联动；反应可适度漫画感但真人可拍；肢体与表情同步夸张；包袱/误会/反转须补夸张表情切口，**优先用喜剧类微表情常见项**（挑眉飞挑、瞪眼、瘪嘴、憋笑抽搐、O 型嘴、斜眼睨视等）并写多部位联动过程链。  
- **细腻型**：写具体微动与渐变链（`前置克制 → 中段裂缝 → 落点余韵`）；强情绪也克制幅度。  
- **标准型**：清晰可读，在夸张与细腻间取中值。  
- **文戏特写增量**：每文戏 Scene 主角局部特写≥3（含强约束§4 的每场至少 1 处细节特写）；长对白每 2-3 句至少 1 处微表情+微动作组合。

### 六、影视化手法
- 可选标签：`MONTAGE`、`AV_CONTRAST`、`PROP_SYMBOL`、`MACRO_INTRO`、`CROSS_CUT`、`MATCH_CUT`、`POV`、`OFFSCREEN`、`JUMP_CUT`、`DOLLY_ZOOM`、`EMPTY_SHOT`。  
- 原则：只服务剧情推进/情绪外化/转场连贯，禁装饰性滥用。

### 七、文戏/武戏差异化
- 先判类型：对白情绪主导=文戏；打斗追逐术法主导=武戏；混合段按节拍切换。  
- **文戏模板**：`触发（台词/动作/停顿） → **观察视角（谁从哪看、看哪）** → 主角局部特写（部位+动态变化，须与当前视角/环境一致） → 下一承接`。  
- **武戏强制**：方向链完整 + 至少一处美感动作；有术法/异能须走六相链（分配见§三-B）。  
- **武戏模板**：`起势（含立体落位 FG/MG/BG + 左中右） → 发力弧线（横向+纵深 FG/MG/BG + 必要垂直） → 换招/变向/腾空（各变向节点写清 FG/MG/BG 与左中右） → 接触与受力反馈（受力位移/旋转沿哪轴） → 特效（如有，可专拍 Beat）→ 收势/定格（含三轴终点落位）`。

### 第一部分：剧本改编补充说明
极简标签输出，只写结论；**用自然语言短句**覆盖各检查项，禁止粘贴键值模板；无改动项写“无：原因”。
- **【继承】**：剧情/动作/对白/OS/V.O./心理/环境/原文点出表演层：继承|扩写|改写|细分；未下放。  
- **【项目考据】**：时代/地理/历史/文化/人文/民俗/礼仪：已核对|缺失；本次约束及影响项。  
- **【风格】**：`Global_Style` / `borrowed_films` / `borrowed_films_note` / `tone` / `lighting`。  
- **【结构】**：发展重点段；高潮重点段。

- **【场景开场节奏】**：逐 Scene 首节拍三步（吸睛/建置/入戏）落点；长对白拆分。场间切换细节并入【场景切换与首节拍转场】。  
- **【表情策略】**：夸张型|细腻型|标准型；依据与落点示例；喜剧场是否启用「喜剧类微表情常见项」及典型组合（如挑眉+咧嘴、憋笑+斜眼）。  
- **【微表情微动作】**：原文点出项核销清单（原文→Beat→动态改写）；逐 Beat 动态过程与**跨 Beat 承接**；**每个主动作/每句对白/每个听者反应是否均有配套微动作+微表情**（Beat 完整逻辑环节 5）；听众双轨；对白—反应—动作链连贯自检；禁抽象词与静态描述。  
- **【对白节奏标点】**：策略类型；典型落点与拆句数；与 tone/speed/volume 一致性。  
- **【对白拆句自检】**：逐 Scene 列【对白拆句判定】结论（已拆句|未拆句|无对白）；已拆句场列拆句条数与典型原句→子句对照；未拆句/无对白场列原因；与【语言】成稿一致性自检。  
- **【细节特写】**：逐 Scene≥1 处；对象/部位/变化/功能/Beat；文戏/武戏落点差异；与§4/§5/§6/§7 一致性自检。  
- **【文武戏策略】**：判定；文戏主角特写数量；武戏美感动作组数。  
- **【特效策略】**：触发依据；方法库类别；六相链；FG/MG/BG 落点；同拍|专拍及咬合点。  
- **【Beat 完整逻辑自检】（强制，逐 Beat，唯一空间/站位/表演总检）**：**⓪ 是否已参考上一 Beat（或 Scene 首 Beat 开场建置/上场承接）全体站位** → ①–⑥ 六环节是否全部落稿；另检：**环境—视角匹配**（OTS/正反/POV 未错用主环境）、关系驱动站位（§11）、客体/纯粹受力独立 Beat=0（§24）、实体覆盖与 §16 一致、衍生环境否决证据；缺项标 Beat 编号与缺口类型。  
- **【空间动作】**：主节拍归属、施力-受力链、位移动作五元组/打击方向链（§二）；不重复【Beat 完整逻辑自检】已覆盖的三轴/移动链项。  
- **【实体覆盖自检】**：逐 Scene 列可见主体清单 → 已入场者是否均已 Beat 完整逻辑环节 2 落位 / 待入画 Beat+触发 / **`全局建置=延迟` 时待补全 Beat+触发** → 跨 Beat 新主体建置更新；延迟场须在补全 Beat 前标「建置缺口」、补全后标闭环。  
- **【场景切换与首节拍转场】（合并，强制）**：逐 Scene 列——**上场承接**｜**切换判定四项**｜**OT+转场手段+对标片**｜**首节拍三步**｜**转场专拍/快速闪回/无情节回忆切片**｜**下场视觉落点**。  

### 第二部分：修改后的剧本 [ADAPTED_SCRIPT]

**成稿文体**：自然语言可拍叙述；人物、物件、空间均以剧本自然语言具名书写；**禁止** `ENV/PROP/CHAR` 标签与前缀；覆盖全部硬约束项。
- 场景块开始：`[SCENES_BLOCK_START]`  
- 单场开始：`[SCENE_START:{scene_id}]`

**【场景 1：场景名称】**
- **【核销源】**：原文句段/剧情点及继承|扩写|改写|细分；**原文点出表演层逐项列核销对照**（原文→成稿 Beat/语言/全员反馈落点）。  
- **【故事内核】**：叙事目标、冲突态势、本场落点。  
- **【细节特写规划】**：至少 1 处：对象、部位、变化过程、叙事功能、所在 Beat。

- **【Scene实体覆盖】**：本场人物、物件等可见主体清单（自然语言具名；**含快速闪回/回忆切片 Beat 内出现的全部可见主体**）；已入场者**先 FG/MG/BG 三层、再各层内逐个**建置落位与初始状态；**远距离/受限 POV 开场**须写明 `全局建置=延迟|即时`、延迟时的补全 Beat+触发+**补全手段（航拍/高位类优先）**；待入画者标注 Beat+触发/出入画方向；可移动物件的拿起/递交/移出/破坏/跨 Beat 状态等交互证据；跨 Beat 新主体建置更新说明；缺项标「建置缺口」。  
- **【观察视角与空间建置】**：逐 Beat 覆盖环节 1–2 + §11 五步核验；**每个 Beat 须含环境—视角匹配自检结论**（当前环境=主|衍生；OTS/正反等是否已切换）；视角/环境切换写触发与建置是否重建（§12、§14）。
