## 一、全局约定

### 1.1 画幅与命名
- 命名锁 / `generation_prompt_en=""` / `subject_no` 透传：见 common §1.1（任意字符级差异=非法）。
- **单人四视图（默认）**：沿用 common §1.1（16:9 横向浅灰、同一横排；第一宫面部特写 35%；正/侧/背 65%，鞋履可见）。**全身格隐脸（最高）**：仅第一宫生成完整面部；第二/三/四宫全身脸部禁止生成，须用浅灰底色完全覆盖面部区域（含五官），发型/颈/衣着/体态/鞋履保留。`generation_prompt_cn` 收尾【其他】必须显式写出该隐脸指令。
- **群演簇例外**：命中 §2.4——**不**走单人四视图/四宫格；按剧情群体建置形式出一张**全身**群体设定图（人数与队形跟上游，不限 4 人/4 格；前排/中景可读个体须头到鞋履完整，有坐骑则人+骑同框全身）。不适用全身格隐脸。衣着与**附属物**（配饰/器械/旗帜/坐骑等）细节下限与单人/道具同级（见 §1.2A / §2.4）。
- 示例仅作格式参考；每次按当前剧本专属设计。

### 1.2A 项目语境注入（角色 delta）
通则见 common §1.2A。角色开篇六维（无日夜气候项）；风格定位跟 2–4 条可视化落点（配色/廓形/材质/妆造/情绪外显）。缺项标 `上游待补`，不得因缺一项省略其余。

**开篇句式**：`项目基础定位为{…}，项目全局风格为{…}，年代/时代为{…}，地域/国家为{…}，语言环境为{…}，风格定位为{…}。`

- **细节下限**：单人定妆面目段 ≥8 锚点；`appearance_cn` ≥6；`clothing` ≥7 且服色散 **3–7 色**（见下条）；三字段合计 >8。**纯换装衍生（相貌未变）豁免面目≥8 / `appearance_cn`≥6**：`appearance_cn` 一句继承即可；`clothing` 下限与服色散**不豁免**。**群演簇**：面目改走 §2.4 面容卡（禁单人 8 锚点平均脸）；**`clothing` 下限与单人相同**（≥7；服色散 3–7；款式/版型/材质/配色/鞋履/配饰可检索；禁「军装/古装/制服/某朝服饰」空壳）。
- 默认宏大美观 + 色调柔和；仅上游明文落魄/战损等才切换。`anchor_description`：3–5 英文短语（禁数组）。
- **服装**：`clothing` 首句「播出安全等级：成人|非成人。」；须匹配时地/身份的具体款式/材质（禁「某某朝服饰」空壳）；含潮流关键词 + 版型/材质/配色/鞋履，并回写 prompt。**配色须响应 `scene_mood_cue`**（与身份/礼制不冲突时优先跟场级光色；**主色锁身份制度**，用辅色/点缀/材质光泽响应情绪）。**阶段变体（回忆/闪回等）与换装衍生服饰须明显差异，禁简单复制基准装；Index 有几条装束行就出几条独立设计。**基础版服装锁定 Index/服化道**入场初装**——禁把剧情战损/湿透/血污终态画进基础版；此类只出在对应装束/状态衍生行。**不可离身升格配饰**（`accessory_props`）：`clothing`/【衣着】须含 Index `accessory_mount` 部位短注（如`胸前佩戴玉牌`），与 `PROP:[…]` 依赖形制一致、部位不漂移。**可离身升格 PROP**：不进 `clothing`/【衣着】、不挂角色依赖。
- **服色散（最高；主色锁制度）**：`clothing` 与【衣着】须显式写出**主色 + 辅色 + 点缀色**，具名到色相（禁「深色/浅色/彩色」空壳），并绑到衣片/鞋履/配饰。
  - **主色 1–2**：须核销 `identity` / 时地礼制 / 制服冠服品秩（警察藏青、军绿或制度规定色、品官补服主色、僧衣灰赭、学生校服等）；**禁止**用番位或场级情绪改主色（情绪只动辅色/点缀/光泽）。
  - **辅色 ≥1、点缀 ≥1**：辅色衬主色、可跟 `scene_mood_cue`；点缀落扣襻/滚边/纹样/鞋履小面积或配饰，面积明显小于主色。
  - **总色数 3–7（强制）**：计可分辨色相（同色深浅算 1）；**少于 3=废弃**（缺辅或缺点缀），**多于 7=废弃**（无据花哨）。黑/白/灰可计入，但不得用「黑白灰三色」冒充已写主辅点缀层级。
  - **色数按年龄×身份×性格裁定（强制）**：logic 写 `服色散：主色={…}｜辅色={…}｜点缀={…}｜色数=N｜档={底|中|高}｜依据=年龄{…}+身份{…}+性格{…}`。
    - **底档 3**：幼童朴素、老年克制、僧侣/苦修/底层、性格内敛沉静——主 1 + 辅 1 + 点缀 1。
    - **中档 4–5**：青年/成年日常、中产职场、性格平和；**制式着装默认本档**（军警/卫兵/仪仗/校服/工装/甲胄同制等——主色锁制度，须有辅色+点缀，色数 4–5）；身份有层次但不越制。
    - **高档 6–7**：盛装/品秩华贵、仪典冠服、少年明快、性格张扬活泼外向；仍须主色不越制。
    - 冲突取**身份制度优先**（制服/礼制锁主色与上限），再按年龄与性格在 3–7 内加减；缺性格则按身份+年龄定档，logic 标上游缺项，禁为凑档臆造张扬。

### 2.0 真人写实光影铁律（权威 · 仅 §1.6 判真人时）
**成图目标**：无感打光 + 色调柔和 + **第一宫**聚焦面目。内部默认 setup=柔和侧逆光 + 正面大面积 Fill（细节只写 `dependency_strategy.logic`；`description_cn` 恒 `""`）。

**显式豁免 common §1.3「禁虚构正面补光」（定妆专用）**：定妆浅灰底四视图允许棚拍式「正面大面积均匀补光」；与 common「Character 真人定妆豁免门」一致。该豁免**仅**适用于 character 真人定妆，不适用于 Environment/Poster/Prop。

1. 光线存在感极低；禁可识别鼻影/颊影/rim 条/阴阳脸/强冷暖戏剧光。
2. 色调低饱和、柔和统一；`generation_prompt_cn` 写「色调柔和统一」即可（项目「冷暖对比」气质与 **`scene_mood_cue` 光色**若有，只进 `dependency_strategy.logic`，**不成图可见色光对冲**；情绪落在【衣着】配色，不落戏剧光）。
3. 面目段篇幅 ≥ 光线段 3 倍；光线 **≤1 句**。
4. **第一宫**面部大面积均匀受光；禁鼻梁/颧骨/额头独立 spotlight。例外：双眼自然 catchlight；鼻尖/耳廓极轻次表面透光（非皮肤发光）。第二/三/四宫无脸，不适用本条。
5. 全脸哑光；禁水光肌/glowing/美颜光晕。

**`【光线】`唯一合法语义（须改写）**：柔和侧逆光 + 正面大面积均匀补光 + 面部受光均匀无局部亮斑 + 肌肤全哑光无发光 + 色调柔和 + 无明显光影感。

**输出校验**：基准版/年龄态/面部受损衍生：面目≥8 锚点 + §2.3 七必锚全量 + 五层可检索项（含拍摄载体）+ 光线 1 句含上述语义。**纯换装衍生（相貌未变）**：豁免面目≥8 与七必锚全量（由参考图承担）；仍须拍摄载体或继承开篇画布、光线 1 句、【衣着】写满。否则废弃重写。本条优先于 common §1.5 大光比（定妆图豁免）。

### 2.2 Prompt 字段模板
- `description_cn`：恒为 `""`（禁任何正文）。
- `dependency_strategy.logic`：身份/叙事功能、择型依据、内部光学 rationale、**`scene_mood_cue` 服化/色彩响应**、变体 Delta；主要角色含「选角参考：」。

- **`role`（强制继承 Index 身份）**：=职业/社会/品秩身份。**权威源**=Index `entity_attributes.identity:`（如`警察`/`皇子`/`公主`/`普通修仙者`/`刑侦警探`）；写入 JSON `role`（可英译或保留项目语言专名，语义须等价）。**禁止**用 `plot_role`（男主/女主等）填 `role`；**禁止** `role` 与 `plot_role` 混写。`clothing`/【衣着】与时地礼制须能核销该身份（制服/冠服/修士层级等）。Index 缺 `identity:` → `role` 可据称呼/服制弱推断并在 logic 标「上游缺 identity」，禁臆造细职衔。
- **`gender`（人态强制继承；神兽/非人豁免）**：读取 Index `entity_attributes.gender`（`男`→`M`，`女`→`F`；群演簇 `混合`→按簇主导或写 `M/F` 并在 logic 注明混合）；**禁止**与 Index 矛盾。**人态角色**：缺 `gender:` 时据 `plot_role`/`identity:` 补写并在 logic 注明「上游缺 gender，已据…补」。**神兽/异兽/魔兽/妖兽/灵兽/坐骑/宠物/非人集群等**：Index 无 `gender:` → **禁止**臆造男/女；JSON `gender` 可省略或写物种中性标注并在 logic 注明「非人/神兽类，上游未明确性别，不强填」；成稿字段**不**强写性别词。
- **年龄（人态强制继承；神兽/非人豁免）**：读取 Index `entity_attributes.age_tier`（及并存的 `约N岁`）；写入 `appearance_cn`/`generation_prompt_cn` 可检索年龄语义——有岁数用岁数；仅有层次无岁数时用层次；**禁止**与 Index 矛盾。**未明确年龄默认 23 岁（仅人态；强制）**：人态角色 Index 既无具体岁数、亦无可用年龄层次/年龄态证据时，按 **23 岁** 写入上述字段，logic 注明「上游未明确年龄，默认23岁」；有 `age_tier` 但无岁数时，层次按 Index，**岁数仍默认 23**（除非层次与 23 明显冲突——如幼童/儿童/少年/中年/老年——则只写层次、不套 23）。**不适用**：群演簇、宠物、神兽/异兽/魔兽/妖兽/灵兽/坐骑/非人集群——Index 无龄态则**不强写**岁数/年龄层次，禁套 23。
- 默认表情中性、静态站姿；上游另有指定时覆盖。

### 2.4 群演簇（Collective）
触发：`crowd_role:群演簇` 或匿名背景集合体（含人态卫兵/路人/宾客，以及异兽/神兽/魔兽/妖兽/灵兽/坐骑群、非人集群等）。替代单人四视图/择型/七必锚全量。

- **画幅与构图（最高；不锁四宫格）**：16:9 横向、浅灰色连续画板；**禁止**强制套用单人「四宫格/四等分横排/第一宫特写」模板；**禁止**为凑 4 格而把群体拆成固定 4 人四格。成稿=**一张全身群体设定图**，构图直接体现上游群体建置形式（见下）。
- **全身像（最高；含坐骑）**：前排/中景可读个体须**头到鞋履完整入画**（发冠/盔巾→躯干四肢→靴履皆可见）；禁胸/腰/半身裁切冒充设定图，禁只画脸墙。默认平视静态站/骑姿，全身轮廓可读。**有坐骑/驮兽/战车**（骑阵、人骑同簇、非人坐骑群）→ **人+骑（或骑具）同框全身**：鞍/辔/蹬/鞦/甲叶/蹄装可见；禁只画人头+马头、禁裁掉蹄腿。远景密度层可缩小但仍须全身剪影（含骑则含马体剪影）。收尾【其他】须可检索「全身」「鞋履完整」；有骑另须「人骑同框全身」。
- **人数不限 4（最高；继承上游）**：可见人数/规模须跟 Index / Stage 1 可核销规模（`约12人`／`两排各6`／`三列纵队`／`百人方阵`／`数十骑` 等）——**可少于、等于或远多于 4**；宏观大军可写满幅阵列+景深层次（前排可读、后排密度延续），禁压成「永远只画 4 个人」。上游缺规模 → logic 标 `upstream_missing_crowd_scale_or_formation`，禁臆造人数；有规模词则画面须可读对应量级。
- **群体建置形式驱动构图（最高；跟剧情）**：`generation_prompt_cn`【建置/站位】须写出与上游一致的**位置排列/队形**，并据此组织画面——例：军队/仪仗→整齐纵队/方阵/横列齐肩；围观→扇形或半环疏密；路人→散点疏密带；跪拜簇→前后梯次跪立；骑阵→横列或楔形。logic 注明 `建置形式={纵队|方阵|横列|扇形围观|散点|…}｜规模={…}`。❌固定四格横排冒充任何剧情队形｜✅构图=剧情群体落位本身。
- **禁止单人平均脸（最高）**：【相貌】**不得**写成一张 8 锚点「标准群演脸」再暗示人人长这样。单人定妆的面目≥8 / 七必锚全量**不套用**于簇；簇只写共性 1 句 + 下面的**逐人面容卡**。
- **可读个体面容卡（最高；反同脸；人态强制）**：前排/中景脸部可辨者必须**每人一张互斥面容卡**，写入 `appearance_cn` 与 `generation_prompt_cn`【相貌】，站位可核销（`前排画左`/`前排中央`/`前排画右`/`中景第二列左` 等）。
  - **张数**：`N = min(可见人数, max(4, 前排可读数))`；可见 <4 则全员各一卡；宏观大军/满幅阵列前排可读 **≥6**。远景密度层可概括，但仍禁整排同模克隆脸，须写「后排延续参差、禁止复制前排脸」。
  - **每卡 8 槽（须可检索、彼此不同构）**：①年龄层次或约岁 ②脸型下颌 ③眼型/眼距/眼睑褶 ④鼻梁鼻尖 ⑤唇形+眉形 ⑥肤色底调（同族群内仍须冷白/暖白/浅麦/健康麦/晒红等可分，禁全员同一「冷白」）⑦发型发量发色（制式可统一盔/巾，仍须发际、鬓角、胡须或露出发差）⑧**唯一微标记**（痣位、浅疤、酒窝、法令纹、眉缺口、胡茬形态、眼镜、单侧耳饰、肤色斑等）——**簇内禁止两卡共用同一微标记**。相邻两张可读卡须在 **≥5** 个槽上不同。
  - **反默认脸 / 反主角套皮**：禁止全员「青年东亚瓜子脸+大眼高鼻薄唇」或同一偶像骨相；禁止把本项目男女主/主要角色的骨相配方复制给群演；禁止只改发型/站姿/表情冒充换脸。
- **随机性与参差（最高；可复现、禁撞车）**：用内部种子 `{Scene ID}|{簇名}` 从下列菜单**组合抽样**，禁止每次从同一默认序列起笔、禁止邻卡顺延只改一字。
  1. **龄档穿插**：无上游锁单一年龄层（如校服/幼童簇）时，可读卡须覆盖 **≥2 个** `age_tier`（青年+中年 为底；规模≥6 再叠少年或老年之一）；禁全员默认 23 岁。
  2. **性别穿插**：Index `gender:混合` 或未锁单性 → 前排可读须男女交错可见；仅上游明文全男/全女才可单性。
  3. **体态穿插**：高矮/胖瘦/肩宽至少 **3 档** 穿插；制式阵列允许身高接近，仍须骨相+年龄+微标记打散。
  4. **五官菜单禁复用**：脸型（国字/鹅蛋/圆脸/长脸/菱形/方下颌）、眼型（细长/圆杏/内双/单眼皮厚睑/眼距宽窄）、鼻（高直/短圆/宽翼/微驼）、唇（薄/厚/唇峰显/唇色深浅）——同一菜单项在可读卡中 **最多出现 1 次**（规模>6 时同一大类最多 2 次且须配不同微标记+龄档）。
  5. **簇间不撞车**：同 Scene 多条群演簇时，各簇前排主导骨相不得雷同（宾客簇 vs 卫兵簇须一眼可分）。
- **衣着与单人同级（最高；人态强制）**：群演簇**不豁免** §1.2A 服装合同。`clothing` 与 `generation_prompt_cn`【衣着】须：首句「播出安全等级：成人|非成人。」；**`clothing` ≥10 且服色散 3–7**（主色锁制度 + 辅色 + 点缀；色数按簇身份/龄档跨度裁定）；匹配时地/身份的**具体**款式/版型/材质/配色/鞋履/配饰（禁「军装/古装/制服/某朝服饰/甲胄」空壳）；配色响应 `scene_mood_cue`（**主色跟制度**，辅色/点缀/材质光泽跟场级情绪）。**【衣着】结构（强制）**：①簇共性装束（写满单人同等槽 + 服色散）→ ②前排可读个体着装差或品秩微差（不得把簇色数打出 3–7）→ ③**附属物**（下条；配饰/器械/旗帜/坐骑等，有则必写满槽）。`clothing_req`/`clothing_env` 与单人同锁。缺槽或空壳=废弃。
- **附属物细节（最高；配饰/道具/坐骑等同锁）**：凡簇成员可见的配饰、随身/制式器械、旗帜仪仗、盾牌号角、包袋灯盏、坐骑及鞍辔甲胄等附属物，**须与衣着同级写细节**，禁「持械/有马/有配饰/骑马」空壳。群体设定图**必须画出**这些附属物（阵势资产，非单人净身定妆）。
  - **每件 6 槽（可检索）**：①名称/类（矛/腰刀/圆盾/军旗/号角/托盘/鞍等，禁只写「武器/马」）②形制（刃长/旗面比例/鞍型/盾面弧度等）③材质 ④主/辅/点缀色（计入簇 3–7，禁另开第八色）⑤挂位或持握手侧/鞍位/旗杆位 ⑥制式统一或个体微差。缺名或缺形制+材质=废弃。
  - **坐骑加重**：物种/毛色斑纹/体型体态 + 鞍/辔/蹬/鞦/蹄铁或甲叶——鞍具各件同样走 6 槽；人+骑同框全身见上条。非人坐骑群本体特征卡仍 ≥4 差，装具不豁免本条。
  - **不抽 PROP（最高）**：簇附属物**只**落本簇 `clothing`/`【衣着】`；**禁止**自造或挂 `PROP:[…]`，**禁止**写 `accessory_props`/`accessory_mount`，`visual_dependencies` **必须为空或仅含非 PROP**（簇无道具依赖）。具名角色自己的升格件与本簇无关，不得因「同类器械」把主角道具画进簇或反向抽簇械为 PROP。
  - **军队/仪仗**：远读识别包须含器械/旗/骑剪影（矛林/盾墙/旗阵/马列）；近读细节包须含刃鞘纹/旗徽/鞍饰/盾面纹。与衣着双尺度一并核销。
  - logic 须可检索 `附属物=…｜不抽PROP=是`（列名+各件形制/材质要点）；上游有骑/械/旗而【衣着】无对应槽=废弃。上游全无附属物证据 → 写 `附属物=无`，禁臆造兵器马匹。
- **先判制式（读 Index `服饰倾向` / 身份 / 时地礼制 / 上游明文）**：
  1. **普通人群（默认）**：无制服/制式/军警僧道仪仗等统一着装要求 → **服饰 + 相貌均须差异**。簇共性仍须写满上条槽位；再在款式/配色/新旧破损/配饰上拉开 **≥2 类**可分差，前排可读者各有可核销着装差，不得像同一套服装复制品。相貌走上面面容卡。
  2. **制服/制式类（军队/仪仗加重）**：上游明文或身份制度要求统一着装（军警/卫兵/僧侣/仪仗/校服/工装/甲胄同制等）→ **服饰统一**（同款制式、同主色与徽章层级；允许品秩微差如袖章/肩章/新旧磨损，但廓形与制式识别须一致）；**面容卡仍强制、不得因制服同脸**。阵列几何仍服从上游整齐队形。**统一≠空壳**：须同时写出**双尺度**，供宏观场面与近景配套——
     - **远读识别包（宏观/EWS/WS 一眼成军）**：剪影廓形（盔/帽/甲/袍轮廓）、主色块分区（上衣/下装/披风/甲叶）、头具形制、阵列重复单元；骑阵另含坐骑体型+鞍辔剪影。禁只写「整齐军装」而无剪影与色块。
     - **近读细节包（与单人衣着同级）**：领襟袖摆/开衩、面料织纹、甲片/扣襻/束带、靴履形制、徽识/肩章/袖章/胸章层级、腰带披挂；配饰/器械挂位只写在【衣着】（不挂 PROP）。军队/甲胄至少再写甲型（札甲/布面甲/现代战术背心等可核销词）+ 头盔/巾帽 + 靴。
     - logic 须可检索 `远读识别包=…｜近读细节包=…`。缺任一包=废弃。
  3. **异兽/神兽/魔兽/妖兽/灵兽/坐骑群等非人集群**：无「衣着」时以皮毛/鳞甲/角冠/体型斑纹/伤痕/光泽/体态落实——同种同系但**禁止**同模复制；每张可读卡 **≥4 处**可核销特征差（体型大小、斑纹位置与形状、角叉数/角向、鳞色深浅、伤疤位点、耳形、瞳色或虹膜纹、姿态气质等），相邻个体禁止同一斑纹模板。须**全身**（含四肢/蹄爪/尾）。若上游要求鞍辔/甲胄/符纹**制式统一**，则装具统一且写满形制/材质/主辅色（同近读细节包），本体特征仍须分异；群体落位仍跟上游建置形式。
- **【相貌】结构（强制）**：①簇共性 1 句（族群/时代气质/是否制式发饰，**不含**一张标准五官）→ ②逐条面容卡（站位+8 槽短句）→ ③远景「参差延续、禁克隆」1 句。缺逐条卡或仅有共性=废弃。
- **`negative_prompt_en`（群演强制置前，可并入既有串）**：`identical faces, cloned extras, duplicate faces, same face repeated, copy-paste crowd, twin extras, uniform beauty-filter faces, identical bone structure, same hairstyle everyone, cropped crowd, bust-only extras, missing shoes, cropped hooves, rider without mount`。人态另保留真人 Tier1 肤质词；三维/二维改用对应假人/同模词，仍须含 identical/cloned/duplicate faces。
- 仍须 §1.2A（面目走面容卡；**衣着走单人下限**）、分段标签、光线 ≤1 句、色调柔和。
- 单条 `characters[]`；logic 须可检索：`群演簇：{制服类|普通人群|非人集群}｜全身像=是｜附属物=…｜不抽PROP=是｜服色散=主色…｜辅色…｜点缀…｜色数=N｜档=…｜建置形式=…｜规模=…｜面容卡数=N｜随机种子={SceneID}|{簇名}｜龄档跨度=…｜性别穿插=…｜与主角骨相碰撞=否｜非四宫格全身群体图；差异：{服饰+相貌|仅相貌/外形|装具统一+本体特征差}`；制服类另加 `远读识别包=…｜近读细节包=…`。

### 2.5 三维动画（仅显式三维制式）
§2.0/§2.3 不生效。子风格择一次世代 PBR 或风格化 toon，写入 logic。四视图骨架同 §1.1；特写改几何体块/材质分区。禁真人毛孔/选角话术。`negative_prompt_en` 追加 photoreal/live-action 类。

### 2.6 二维动画（仅显式二维制式）
§2.0/§2.3 不生效。子风格择一日系/美漫/国风二维等，写入 logic。线稿统一粗细；平涂色块+硬边阴影。禁真人/PBR 话术。`negative_prompt_en` 追加 photoreal/3D render 类。

## 三、输出模板

- 唯一输出：一个 JSON，仅含 `characters`（无则 `[]`）。
- 全量覆盖、类型路由正确；`name/name_en/base_name_en` 与 Index **逐字符完全一致**（任一字不等即废弃重写）。
- **换装核销**：输出前对照 Index 全部 character 行；凡 `base_entity≠None` 的装束/状态衍生均须有独立条目且 `clothing`/`【衣着】` 与基准可区分；缺行或混装=废弃重写。**纯换装衍生另核**：已挂 `CHAR:[@基准名]`；`appearance_cn`/【相貌】无五官身材复述；logic 可检索 `纯换装继承=是｜相貌复述=否`；出现基准骨相/眼型/鼻唇/身高/头身比抄写=废弃。
- 每实体须有 `visual_dependencies` 与 `dependency_strategy {type, logic}`。Index `accessory_props`（不可离身）→ 必挂对应 `PROP:[…]` **且** `clothing`/【衣着】可检索该件名+挂位（见 Node 3/3b）；缺挂或【衣着】漏件=废弃。**可离身 PROP** 出现在**单人**角色 `visual_dependencies` 或角色生图词=废弃。**群演簇**：`visual_dependencies` 含 `PROP:` 或写了 `accessory_props`=废弃；附属物只在 `clothing`/【衣着】。
- 真人：`description_cn=""`；`dependency_strategy.logic` 含内部光学 rationale + **`场级情绪`/`服化响应`** + **`服色散`** + 选角参考；`generation_prompt_cn` 含分段标签 + 七必锚 + 五层可检索 + 光线 1 句；【衣着】配色可核销身份制度主色 + `scene_mood_cue`；单人细节面目≥8。**纯换装衍生豁免七必锚/五层/选角参考/面目≥8**（logic 写继承基准；【相貌】一句继承）；衣着/服色散/光线/隐脸**不豁免**。**单人四视图须核销全身格隐脸**：收尾【其他】可检索「第二/三/四宫」「底色覆盖/无脸」；缺隐脸指令或写成全身露脸=废弃。**服色散**：`clothing`/【衣着】可检索主色+辅色+点缀且色数 ∈[3,7]；缺层、少于 3、多于 7、主色与 identity/制服制度冲突=废弃。**群演簇**：不套七必锚全量/单人 8 锚点；须**全身像**（收尾【其他】可检索全身/鞋履完整；有骑可检索人骑同框；禁半身裁切）；**`clothing`/`【衣着】` 达单人下限**（≥7 且服色散 3–7，禁军装/制服空壳）；附属物 6 槽只进【衣着】且 **`visual_dependencies` 无 `PROP:`**；制服/军队须远读识别包+近读细节包；须面容卡数达标、【相貌】含逐人 8 槽、`negative_prompt_en` 含 identical/cloned faces、logic 含随机种子与龄档跨度；否则废弃。
- 三维/二维：按 §2.5/§2.6；仍须分段标签；不适用七必锚与选角参考；`description_cn=""`。
- 衍生：`description_cn=""`；logic 含 Delta（换装写清旧装→新装可见差异）。**纯换装（相貌未变）**：`generation_prompt_cn` = §A 参考图声明 +【相貌】一句继承 + §C 衣着 Delta（禁 §B 复述面貌身材）；logic 含 `纯换装继承=是｜相貌复述=否`。年龄态/面部受损：含参考图声明与相貌 Delta + 衣着/状态 Delta。§C 衣着 Delta 不得空泛「换装」。
- 群演：按 §2.4（**非四宫格全身群体图**；人数/队形跟上游；前排头到鞋履、有骑则人骑同框；**【相貌】禁止一张平均脸**；前排逐人面容卡 8 槽互斥+随机抽样；衣着与附属物与单人同级且**不抽 PROP**；普通=服饰+相貌差；制式=服饰统一+双尺度细节+面容仍差；非人=全身特征卡 ≥4 差）。
- **剧情依存形制**：有 `clothing_req` 或服装结构依存动作时，`clothing` 与 `【衣着】` 须可检索对应袖/袋/襟/腰带/下摆形制词；否则废弃重写。
- **成人向年轻女性剪裁**：播出=成人且人态年轻成年女性时，`clothing` 与【衣着】须可检索 `露肩|深V领|开叉|短裙|短裤|短靴|露背` 中 ≥2 词；缺词且 logic 无合法豁免=废弃重写。
