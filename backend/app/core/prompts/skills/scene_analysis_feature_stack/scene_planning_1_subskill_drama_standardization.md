## 1. 核销
原文每一信息单元可检索；禁概括吞并。
- **对白/OS/画外音/VO/可见字**：项目语言侧逐字保留；可断句，词序用词不改。>20字拆独立 Beat，拼接=原文全句。无具体台词可省略，禁臆造。有非空台词 → 成稿必须写成 `{原文逐字}`，八键全写，开口行完整可检索。原文标 `画外音`/`VO`/`V.O.`/`旁白`/`NARRATOR` 且有非空正文 → **必须**落入成稿 `{台词}`（§4.2A），禁遗漏。说话人本体本拍不在画面（门外、隔门只闻声、未入画、电话/对讲另一端等）→ 即使原文未标 VO，也必须按 §4.2A 升成画外音行，禁写成画内张嘴对白。
- **商业宣传片花字**：原文 `花字:` / `花字=` 是片内图形叠字，不是对白硬字幕；文案、位置、字级、排向（横/竖）、字体、字形（简/繁）、强调体、`展示=`、`艺术=`、`英=`、`上屏=`、`停留=`、`听=`、`逐字=` 须原样保留进成稿。含「X家」的店号「家」须保留，禁收成漏家或复写邻字。原文 `印=` / `压字=` / `上屏=字卡专镜` / `字卡=` / `手写=` 须原样保留；印章只在句外，禁印面盖字、禁印代字。店号/热线花字须整拍保留为字卡专镜（无旁白，Static Hold，`烧录=libass｜手写=禁`），禁改回视频手写、禁拆进有旁白的动作镜。字层由后期 libass 烧录，成稿须留下引号原文。**旁白优先（最高）**：花字优先级低于旁白。同拍已有旁白/口播（`口播:` 非「无」）→ 成稿该拍 `花字: 无`，禁把花字并进有旁白的开口行以免分心；花字只留在无声拍，必要时拆到下一条无声开镜/段末/黑屏专镜/字卡专镜。**切镜融合**：`上屏=段末切镜|段首开镜` 须留在该段开镜/结束镜，禁并进动作中段抢镜。`上屏=黑屏专镜` 的黑场花字拍须整拍保留且该拍无旁白，禁拆进动作镜、禁因此升场。`停留=长`（含 CTA）禁压成一闪。**禁底部（最高）**：禁改写成画幅底部白字黑边，原文若 `位置=底` → 抬到 `位置=中`，以免与字幕重合。企业素材产品出镜拍的产品名花字须原样保留（画右或画左竖排），禁改成诗眼或口播。禁把画右/画左竖排产品名改成底部横排，禁把繁体/古体/印章体/中屏艺术组合改回当代印刷黑体，禁把中屏字少味厚句扩成说明书或口播整句，禁删或放大英文配套，禁当开口台词。中屏 `艺术=` 组合须保留（不限于印章/古体/英文小字/颜色）。**密度**：一个动作最多一条花字；吸睛/共鸣/价值/收口各段最多一条。末拍有韵味收口句须原样保留，禁改成 CTA 动词；CTA 不是第二条花字。

## 4. 改编 Beat
增改锁见目标。输入已有 Beat 全留（可拆、可插、可改写表现）。禁按镜头术语切拍，禁重切 Scene。

### 4.0 Beat 划分（叙事权威 · 最高；本层规划锁死）
切拍按**时间顺序**，只认两条叙事轴：**故事推进**与**情绪转折**。§4.2 技术必拆叠在本条之后，不得用镜头术语推翻本条。下游分镜 **Pn 与最终 Beat 逐一对应**，本层切错 = 分镜无法补救。现场编排若仍见整机+舱内同拍，**允许补拆**（第二层）。

0. **先规划再写拍（最高；载具/盒匣尤严）**：落笔正文前，据场核【道具身份】列出本场拍序：`空间档=占用|宿主`（内部规划，成稿禁 `ENV:` 标签）。占用拍=舱内/面上角色，正文只写人+舱内锚（驾驶座/控制台），空间词用统筹占用名（`飞行器驾驶舱`），**禁** `PROP:[飞行器]`。宿主拍=整机/大世界，正文只写 `PROP:[整物名]`+宿主空间词（`霓虹摩天楼`），**禁**驾驶座 MCU。两边都有 → 规划里已是**两拍以上**，再写正文。未列入规划的空间档不得在正文里偷写。**每拍再锁 §4.0B【改编指导】与 §6【世界物理】**，未锁四槽或三键禁止写该拍可见正文。

1. **时序**：按发生先后连续编号。禁倒叙重排；禁把后发生的揭示/反应/决定提前成拍。
2. **双轴切口**：故事往前走了一步，或角色情绪发生可见变化 → **必须新起 Beat**。未推进、未转情绪的纯装饰不另起拍（§4b 改拍除外）。
3. **角色独立动作必分拍（最高）**：不同角色各自做事、彼此**无直接因果** → **必须分拍，分开描述**。一拍只写一个独立动作主语。❌甲在窗边写信、乙在门口整衣揉进一拍。**例外**：原文要强调两人**同一时间**并行（对位/同时动作）才可同拍，须写清同时关系。
4. **道具身份 XOR（最高；只执行统筹）**：先抄本场【本场道具身份】与提取块 `道具身份=`，写入场核【道具身份】。该拍只选一档，**禁止本层另判冲突档**。统筹缺行 → 回流。场内换档仅当统筹已写 `兼` 并分段。
   - **`主体`**：观众看的是这件道具本身在动——整车远观驶过/漂移/撞击、离体飞剑、匣盖自行扣上、门闸自行开合。→ 走第 5 条，单独 Beat，正文以统筹 `PROP:[整物名]` 为主语（`黑轿车`，不是车厢名）。
   - **`容器环境`**：观众看的是**里面或面上的角色**（舱内对白/互殴、甲板戏、开盒取物后的人）。载具/匣柜是活动空间，不是本拍动作主语。→ 角色按第 3 条分拍；舱体晃、窗外过幅、匣内暗写进该角色拍的环境随动，**禁止**另起「车在开/匣在那」Beat 顶替角色戏，禁止把整车当本拍主语，禁止 `坐在 PROP:[飞行器] 的主驾驶座`（PROP 不替代空间；空间名=统筹占用名，本层仍禁 `ENV:`）。
   - **`手持`**：CHAR 操作且道具无独立位移（举杯、拔剑在手）→ 跟该角色动作拍。
   同场可换档：外追逐看车=`主体`；切进舱内对白=`容器环境`。**一拍只一档**。**整机与舱内角色禁同 Beat（最高；两套环境，顾此失彼）**：舱内角色拍只写人+占用空间，禁点整机 `PROP:`、禁「作为舱体容器/部分可见舱壁」。整机拍只写 `PROP:[飞行器]`+宿主，禁驾驶座 MCU、禁控制台建置。两边都要 → **拆成两拍**，分挂两套环境。禁止一拍既当主体又当容器。三层交付（车内人与**车外人对戏**）本拍=`主体`（整车作道具，人相对该 PROP，当前环境=宿主），**不是**舱内 MCU 再挂整机容器。
5. **道具主体动作必分拍**：仅当第 4 条判=`主体` 且该道具自带位移/转向/开合/运转/撞击/飞掠 → **必须单独 Beat**。禁压成「CHAR 驾车离去」。驾驶员该拍一手打方向导致车转 = 直接因果，可同拍。`容器环境` 档不套本条。
6. **动作与反应（因果链）**：每个有人拍或道具**主体**拍必须包含**一个**动作**或**一个反应，形成可追因果。该「一个动作」=**1 主动作**，可带同主语同相附属（头/目光/肩或重心，§6）；禁同拍第二独立主动作。例：提问 → 回答 → 情绪变化 = **至少三拍**，禁揉一拍。施动与受者可见反应分拍（反应即卖点/结果时尤严，与 §4.2 同核）。
7. **情绪转折**：怒→静、疑→信、喜→惧等可见情绪变 → 新 Beat。情绪是观众感知节奏的核心，不得用「渐渐冷静」一句吞掉转折。正文须写成可视微动作（§5/§6），禁用「愤怒/悲伤」等抽象词交差。
8. **信息交换**：一次信息传递或揭示（线索/秘密/决定/知情变）只要推动故事 → 独立 Beat。与 §4.2「揭示/知情变」同核。
9. **空镜例外**：真环境文学空镜（无人可写、无道具主体动作）可不含角色/道具动作；其后第一有人拍或道具主体拍仍须动作或反应。

❌一拍里甲问乙答再变脸｜❌无因果的两人各干各的同拍｜❌未判身份就把车内对白写成「车在拐弯」主体拍｜❌整车远观与舱内开口揉一拍｜❌舱内驾驶座 MCU 又写 `PROP:[飞行器] 作为舱体容器`｜❌当前环境=霓虹摩天楼 却打名牌【飞行器驾驶舱】｜❌容器档另起无角色的「车在开」空拍｜❌情绪已变仍粘在上拍

### 4.0A 增拍（何时另起 · 与划分同核）
**另起**（拆或插，计入 `新增`/`拆分`/`衔拍增拍`）当且仅当命中下列；未命中 → **只加厚原拍**，禁灌水空拍。
1. 输入一拍已含 **≥2** 个 §4.0 切口（提问+回答、两名角色独立动作、道具身份未判、主体档与角色戏同拍、占用与宿主同拍、情绪已变仍粘上拍、一次以上信息揭示）→ 必须拆开。
2. 角色独立动作未分开描述；或 `主体` 档载具/有动作道具未单独成拍；或 `容器环境` 与 `主体` 揉在一拍；或舱内角色与整机 PROP 同拍。
3. §4.2 必拆任一项。
4. §4a 可拍通道读不清，须另起 `~` 才能落地（反应特写/空镜/道具特写）。
5. §4b 衔拍增拍：上拍与下拍之间恰好 1 拍，同时转入转出。
6. 受者反应即卖点/峰谷，且原拍读不清该反应。

**增拍写法**：新拍只加表现（一个主动作[+同相附属]或一个反应，或空镜例外），**不增**事件/台词/线索。插在时序正确位置，从 1 重排。`【Beat切分确认】` 的 `新增`/`拆分`/`衔拍增拍` 须与成稿拍数对上。

**禁另起**：无推进且无情绪转折的纯装饰｜因 VO 自身另起｜为凑 `-`/`~` 配额空拍｜把同一因果单元拆成无增量碎拍

### 4.0B 改编指导（每拍强制；先于可见正文）
每拍写可见正文前，必须分析本拍**涉及角色**（主动作主语）或**剧本本拍**（空镜/无人）的四槽，作为改编加厚的叙事指导。只读原文+场核，禁另造事件/台词/线索。未写齐四槽=该拍失败。
恰好一行，写在 `- Beat {n}：` / `~ Beat {n}：` 之后、可见叙述之前（内部台账，**不成画面句**）：
`【改编指导】角色=CHAR:[@甲]|剧本本拍｜目标=…｜障碍=…|无｜策略=…｜潜台词=…|无`
- **角色 XOR**：有人拍=`CHAR:[@主动作主语]`（对位同拍可 `；对=CHAR:[@乙]`，目标/策略仍跟主语，对方进障碍）；空镜/整车无人=`剧本本拍`。
- **目标**=本拍该角色或本拍剧本要推进的可见一步（一句；禁用「愤怒/悲伤」当目标）。
- **障碍**=此刻挡住目标的人/物/信息/处境；无=`无`。
- **策略**=本拍用何可见手段推进（须能落入 §6 一主动作+附属，或空镜落点）；禁写第二独立主动作。
- **潜台词**=未说破的真意；指导行可写明，正文用微动作/语气兑现，**禁说破**（§9）。无则 `无`。
纯反应拍：`目标=消化上拍施力`，策略=可见反应微动作。空镜：`目标=建立空间|空镜任务`，`潜台词=无`。
兑现：可见正文的主动作+附属+对白八键须能核销四槽。禁把 `目标=`/`障碍=`/`策略=`/`潜台词=` 原词写入叙述层。下游【入戏】不抄本行。
✅`【改编指导】角色=CHAR:[@甲]｜目标=把钢管抬到胸口逼同伴看清｜障碍=CHAR:[@乙]对视不退｜策略=慢抬钢管+下颌收紧+目光钉死｜潜台词=再近一步就动手，此刻还在忍`｜❌无本行直接写正文｜❌正文写「他的目标是威胁」

### 4.2A 画外音/VO（单独处理；可同拍；禁遗漏）
下列任一 = **独立语言单元**，须单独写成开口/闭嘴行（`voice_type=VO|旁白`）：①原文标 `画外音`/`VO`/`V.O.`/`V.O`/`旁白`/`NARRATOR`/`NARRATION`，或叙述声叠在画面上；②**说话人本体本拍不可见**（见下条；原文未标也升 `VO`）。
- **可同拍**：允许叠在本拍画面/动作/画内对白上；不因 VO 另起 Beat。另起仅当命中 §4.2 其他项（说话人变、>20字等）。
- **禁遗漏**：有非空正文则成稿必须可检索对应 `{台词}` + 语气八键 + `开口 | 无`；禁吞进动作叙述、禁写入【音效】`{…}`、禁改成画内口型对白、禁当无台词省略。升格的门外/不可见对白同此。
- **同拍两行**：本拍已有画内对白 → **对白行与 VO 行都写**（按原文时序；VO 不占画内说话人名额）。
- **本体不可见升画外音（最高）**：本拍说话人身体不在画面里 → `voice_type=VO`，`开口 | 无`，禁 `开口 | CHAR:[@说话人]`。命中=`门外且本拍不见其人｜隔门/门缝只闻声｜隔壁/屏后/帘后只闻声｜待入画尚未入画就开口｜电话/对讲/广播另一端｜本拍画面无该人本体`。可与画内听者同拍，不因自身另起。该人不进本拍【世界物理】、不计画内角色单位，并服从下条禁表演。门开到能见其人、人已入画落定、人在画内只是背对/远景/口型被挡、蒙在本拍可见被子下（被形在画内）→ **不升**，仍走画内对白或 §5 `口型不可见`/`OS`。
- **不可见禁表演（最高）**：`voice_type=VO|旁白` 的发音人，以及本拍门外、屏后、帘后、未入画等不可见人物，正文、【改编指导】策略、【世界物理】一律不写其动作、表情、姿势、视线、张嘴、点头、抬手、微表演。只保留开口行里的声音与 `{台词}`。声只写从遮挡外侧传来，禁写成此人看向、转向或冲着遮挡做动作。画面与【改编指导】`角色=` 只取画内可见者，禁把不可见人当主动作主语。
- **暂不可见·知情才看遮挡（最高）**：只约束**本拍身体可见**的发话人。听者在门外、蒙在被子里、屏后、帘后，且发话人明确知道其位置 → 可见发话人看向听者所在的那件遮挡。明确知道=`原文已锁定该位置｜刚目睹进入该遮挡｜点名该门/该被｜正在隔该物对谈`。无依据=`不知情`，禁臆造已知落点，不写盯住该遮挡。`身朝`/`眼神`=该遮挡（白名单内的被子/屏/帘写 `PROP:[名]`，门写具名环境主体），禁看向被挡住的脸，禁看向空处。发话人本人已是画外音或本拍不可见 → 不写其看向；画内听者可 `眼神`=声源侧那件遮挡。
- 本空间且身体在画内、仅口型不可见，且原文标 OS（未标画外音/VO）→ 仍走 §5 `voice_type=OS`，可与听者同拍。

### 4.3 禁删
禁删拍、禁并拍。拆段全出。最终 Beat 数 ≥ 输入 Beat 数。禁吞原文画外音/VO。禁把门外或本体不可见的说话人写成画内开口。禁描述画外音发音人或门外等不可见人物的动作、表情、姿势、视线。

### 4.4 符号与类型
`-`=推进；`~`=特写/反应/空镜/余波。标题只写 `- Beat {n}：` 或 `~ Beat {n}：`，其后先写【改编指导】、【世界物理】，再写可见正文。**禁**在标题写 `节拍=`、`表情特写` 或其它可拍通道名（`节拍=` 链与 `表情特写@B` 只进场级，见 §0.1 / §4a）。`~` 优先挂场级类型=`开场画面｜终场画面｜游戏时光｜一无所有｜灵魂黑夜｜主题抛出`；`-` 优先=`催化剂｜进入行动｜坏人逼近｜终章`。有戏场两种都要；`~`约三成；连续 `-`≤4、`~`≤2。
**配乐拍型（只读 `music_recommendation`）**：先读注入的 `Global_Style` 与 `project_visual_backfill.music_recommendation`。有则按 `节奏=` / `拍型指导=` 定本场 `-`/`~` 松紧——慢板/蓄压场 `~` 可贴近上限（仍≤40%、连续`~`≤2）；快板/冲压场 `-` 可贴近配额（连续`-`≤4，砸点锁定`~`不改）；松紧交替则按本场【情绪峰谷综合】在配额内换气。无注入则按本条默认配额。配乐只进【声画综合】/【配乐】行；听感只进【配乐】行 `{…}`，禁写入【音效】行。
**商业宣传片配乐（最高；覆盖默认垫底）**：片种=商业宣传片，或注入 `片种=商业宣传片` / `配乐音量=并重|压过` / `music_recommendation` 含 `音量=并重|压过` / `权重=配乐主轴` → 配乐是成片主轴，须够响可闻。场级【声画综合】`音量=并重|压过`（禁`垫底`）。每拍【配乐】默认 `音量=中`；吸睛起幅、价值高潮、收口/CTA/slogan=`音量=强`。有口播/VO 时配乐仍须并重可闻，禁弱、禁写成垫底几乎不可闻。

### 4.5 通过
覆盖 100%｜每拍可拍｜§4.0 时序+推进/情绪双轴+因果链+角色独立动作已分+道具身份已判（主体/容器/手持）+空间档已规划（占用/宿主不同 B）｜§4.0A 增拍仅命中闸、未灌水｜每拍【改编指导】四槽已锁且正文已兑现｜每拍【世界物理】姿/身朝/眼神已锁｜每拍一主动作+同相附属（空镜/纯反应例外）｜物理锁已响应｜抽象情绪已转克制微动作｜每拍画内角色单位<5（具名/有戏龙套各1，群演簇计1）｜场级 `节拍=` 链与 `承接=` 同号｜`表情特写` 等通道只在场级 `承接=`/`落地=` 挂 B｜无删无并｜三类要点均可拍通道检索｜编号连续｜原文 VO/画外音已成行（可同拍，禁遗漏）｜门外/本体不可见对白已升VO（未写成画内张嘴；画内背对/远景/可见被形仍为口型不可见或OS）｜可见发话人知情已看向听者所在遮挡｜画外音发音人与门外等不可见人未写动作/表情/姿势/视线。

## 4a. 可拍通道落地
`承接=` 与 `指导=` 写入场级综合项并挂对应 B 号，禁场尾补作业，禁写进 Beat 标题。名场面只借机制。`表情特写` 与 `节拍=` 同此：只进【卖点综合】/【情绪峰谷综合】/`落地=`，不进 `- Beat n：`。

- **挂拍**：优先原文锚拍或紧邻拍。写入≠合并。另起 `~`=可拍通道或断句/反应/余波。另起 `-`=原文下一段推进。
- **细节**：文学加厚后落入可拍通道。`美食`=`哪只手取食→咬/吮→汁油道具特写→表情特写→{咔嚓/吸吮}`。`美景`=宏观或空镜+风物动势。`美物`=道具特写。`美人`=表情特写。文字/证据用原文可见内容。**运动舱内**（车厢/驾驶舱/客舱等）开场空镜或对白镜须让观众读出舱位在走，且即使戏在舱内也须写出舱外变化（窗外过幅+景物更替），落入空镜/音效/随动作；细则 §6，禁写成停泊厅堂、禁窗外钉死。**宿主大环境切占用面**（街上→车内、海面→甲板）须先判切法并写出切口，禁宿主与占用同拍混空间。**高科技光电（可拍闸）**：原文有全息/投影/光幕/HUD，或激光/等离子/粒子束/EMP/能量盾等科技光电 → 加厚必须写出**光源**（具名发射源+出光方向）与**占位空间**（展现类=体积锚+边界；束行类=源→空气柱/廊道→落点；波前类=外扩至具名边界），并写环境受光（脸/台面/墙/尘被染）。落入道具特写或空镜。禁「全息亮起/一道激光/护盾张开」无源无体积。奇观/武器过程仍只标名+路由，细槽归武戏增强。
- **反馈**：受者两步可见反应；无在场观察者=`反馈=N/A:无在场受者`。
- **运镜**：一条有动机运动句。禁焦距/机位。**宿主↔封闭舱**须写 §6 运镜档；默认连续推/拉过阈平稳进出，禁只切空间不写镜头怎么过门窗。

## 4b. 场内艺术衔拍（≠场际转出/转入）
用与场际覆写**同族手法**加厚氛围、拍间不断、把卖点/峰谷拍满，给观众可感的情绪落点。只服务本场 Beat 链，**不是**换场。场际 `切法转入`/`切法转出` 与 `艺术转入`/`艺术转出` 只由开场/终场继承衔接字段，本条不得改写或替代那两端。

**两途（可混用）**
- **改拍**：在已有拍正文写入手法过程（同一载体动作上叠介质/覆写/尺度），不另起拍。对白词/因果不改。
- **增拍（同时转入转出）**：在上拍与下拍之间**新增恰好 1 拍**。这一拍前半=转出上拍焦点（未完成），后半=转入下拍焦点（落成），中间不断、同一载体。默认 `~`。禁拆成「只转出」「只转入」两拍，禁写成换场。

**启用闸**
- 有戏场 **1–3** 处（须覆盖至少 1 个已入列卖点或主峰值/主低点）；过场 **0–1**。无卖点无峰谷且无下列强制项可不做，`【艺术衔拍】=无`。
- **回忆/倒叙/多线强制（场内）**：下列任一为真，必须至少 1 处衔拍（优先增拍=同时转入转出），禁止只硬切过拍：
  1. 【闪回分档】=`同场短闪回｜同场闪切｜回忆长对话待下游可视化`：进入回忆拍与回切当下拍各须衔拍（可改拍该锚拍，或在当下↔回忆之间增拍）。
  2. 本场【场景名称】叙事线=`倒叙` 且场内有时间跳步/知情变：跳步两侧用衔拍。
  3. 本场有场内短切线（§4.2）或【多线编排】本场画面在线间对位：对位切口用衔拍（同型物/对位动作当载体）。
  4. 同场闪回/蒙太奇（§4.2 必拆项）：拆开后的切口必须衔拍，禁裸切。
  5. **仓外大背景↔舱内**（§6）：入舱过程切口与过阈切必须衔拍（优先增拍=同时转入转出），禁街上大景硬切进驾驶座对白。场际转入已锁的开场只加厚该端。出舱反向同核。
  - 不新造回忆/倒叙/多线画面；只把原文已有切口用手法接上。独立闪回 Scene 的进出走场际继承，本条只处理场内剩余切口。
- 必须骑上拍已有动作、持物、目光、衣帜、光色、声，或已入列卖点物/人；回忆优先骑触发旧物/目光/同一动作切面。禁臆造事件/台词/线索。
- 手法闭集同场际：`勾勒覆写｜点簇聚形｜行进吞没｜剪影过阈｜层叠吞噬｜尺度反转｜焦点掏空｜介质铺展｜光色浸染｜氛霭开合｜衣帜遮幅｜卷轴开合｜笔势入景｜同型蜕变｜倒映交接｜碎形重组`。一场不重复同一手法。
- 介质跟 `Global_Style`（古典/水墨才锁水墨；当代优先光色/烟霭/织物/倒映）。回忆/梦境偏倒映、光色、氛霭、焦点掏空；倒叙偏卷轴、笔势、光色；多线对位偏同型蜕变、衣帜、尺度、剪影过阈。
- 必须落入可拍通道；`承接=` 方式可写 `艺术衔拍`，仍须挂通道@B。
- 增拍计入 `-`/`~` 配额与连续上限；禁为炫技连插冲掉对白。
- 开场/终场已继承场际转入/转出的拍：只加厚该端，不再套本条另起换场式覆写。

**卖点/峰谷/时空线选法（只选同向，禁硬套）**
美景→勾勒覆写/层叠吞噬/尺度反转｜美物→倒映交接/介质铺展/同型蜕变｜美人→焦点掏空/光色浸染/剪影过阈｜美食→介质铺展/点簇聚形｜仪式感→卷轴开合/笔势入景/衣帜遮幅｜峰值→层叠吞噬/尺度反转/碎形重组｜低点→氛霭开合/光色浸染/焦点掏空｜氛围/反差→光色浸染/氛霭开合/衣帜遮幅｜回忆进入→倒映交接/同型蜕变/焦点掏空/氛霭开合｜回忆回切→碎形重组/光色浸染/焦点掏空｜倒叙跳步→卷轴开合/笔势入景/光色浸染｜多线对位→同型蜕变/衣帜遮幅/尺度反转/剪影过阈｜入舱切入→剪影过阈/衣帜遮幅/行进吞没/倒映交接｜出舱回切→碎形重组/焦点掏空/行进吞没。

- **改拍**：整句写在该拍内，焦点从本拍原态过渡到卖点/情绪可读态。
- **增拍**：同一拍必须两相都在——转出相停在未完成（上拍焦点未退尽）；转入相接到落成（下拍卖点/情绪焦点已可读）。下拍不得重拍转入相，只接落成后的动作/对白。

**成稿**：手法过程写进对应 Beat 正文；场级只留【艺术衔拍】落地行。增拍 `挂=B{a}→B{c}` 表示夹在重排后的 a 与 c 之间（该增拍为中间号）。

## 5. 对白与加密
- **语言**：项目语言原生写。中英同义并列只留项目语言侧；专名/有动机异语不删。方言=`用{语种}说道{}`。
- **卖点/峰谷**：见 §4a。有戏场可拍通道落点≥3，过场≥1|N/A。原文特写不替换。
- **对话击中**：说话人微表情≥1 + 听者复合过程脸≥1。闭集=`欲言又止｜气得说不出话｜话到嘴边又咽回｜强忍不哭｜似笑非笑`（附）。说话人已按 §4.2A 升 VO，或本拍在门外等不可见 → 不写其微表情、动作、姿势、视线与张嘴，听者复合过程脸仍≥1。
- **环境情绪**：落入可拍通道，禁氛围空词。`{…}` 只作伴随。角色情绪走 §5 微动作，不写「愤怒/悲伤」。优先用 §4b 衔拍把情绪写成可见过程。
- **主观听觉**：可选。触发=`恐惧｜紧张｜重大心理变化｜生病｜重伤｜失血｜高烧｜昏迷将醒｜爆炸冲击｜濒死`。效果=`耳鸣｜闷听muffled｜心跳放大`。采用=听者可见反应 + `{听者内听：…+强弱}`。未命中=`主观听觉=无`。
- **声画标签（每拍强制；标准表达；`|` 分隔同台词）**：正文后、对白前写。【配乐】恰好一行；【音效】≥1 行。主体须 `CHAR:[@原样]` / `PROP:[原样]`，禁裸名；**运动舱运动声**可用 `配合=舱体行进`（仍禁 `ENV:`）。标签、`{…}` 描述、各字段一律用 `|` 并排，禁 `【配乐】态=` / `【音效】{` 紧贴；禁尖括号。
  - `【配乐】 | {听感一句} | 态=起|续|变|收 | 乐器=主奏+铺底+点缀 | 音量=弱|中|强 | 质量=干净|温暖|粗糙|空灵|闷浊|清脆 | 混响空间=干·近密|短·室内|中·厅堂|长·殿宇|长·户外 | 锚={主体}{部位+动作}`。`{…}`=本拍听感（继承总谱风格/情绪/节奏，可按空间/峰谷微调；禁乐器清单、禁 dB/Hz）；空`{}`=失败。`起`/`变`/`收` 须与【声画综合】同号；其余拍=`续`。乐器可多样共同合作（本拍可轮入/齐奏/对位，须仍属总谱编制，**本拍具名≤5**）；禁只写一件顶替全组，禁超编。对白拍默认垫底，砸点可中/强。**商业宣传片覆盖本句**：默认中，起幅/收口/CTA 强，禁弱垫底。禁插件名；听感只进本行 `{…}`，禁写入【音效】`{…}`。**仙攻/魔攻拍可叠与施法者身份同核的体系人声/法器为铺底或点缀**（先核剧本宗教/修炼：佛教=梵音/钟磬；道教=步虚/法铃；修仙无宗教明文=琴笛/剑鸣，禁一律梵音；魔道=源体系扭曲）；体系声只进本行，禁写入【音效】。
  - `【音效】 | {可听内容+方位/远近} | 配合={主体}{部位+动作} | 方位=近|中|远 | 音量=弱|中|强 | 质量=干净|温暖|粗糙|空灵|闷浊|清脆 | 混响空间=干·近密|短·室内|中·厅堂|长·殿宇|长·户外`。每拍 ≥1；原文声音须落入。配合=该声由谁的哪一动作触发（推门/落杯/停步/拍桌）。**运动舱行驶段**每拍另须一条舱体运动声（轮轨/引擎/风噪/浪拍/马蹄/轿厢导轨），`配合=舱体行进` 或宿主外部 `PROP:[名]`（禁 `ENV:`）；可与角色动作音并存。停靠段禁飞掠声。音量/质量/混响须与声源材质和所在空间同向（门轴近=干·清脆；殿内脚步=中·长；车厢轮轨=短·闷浊或干·近密）。禁 BGM、空`{}`、用声音冒充切线、dB/Hz。**仙攻/魔攻结印/诵咒拍可另写与身份同核的咒语音效**（佛教真言拖腔/梵呗气声；道教符咒气声；修仙引气低吟；魔道倒诵邪咒；`配合=` 挂施法方开口诵咒/结印）；只写听感，禁臆造可辨经文当对白，禁把配乐人声写成音效，禁无据通场梵音。
- **台词格式**：有非空 `{台词}` 才写八键语气层；无台词禁开口/闭嘴行与 `voice_*`。无具体台词可省略，禁臆造。**花括号强制（最高）**：台词正文必须包在 `{}` 内，与八键用 `|` 隔开；禁把原文直接夹在两个 `|` 之间不包花括号。禁写「语气层+台词」占位。
- **开口｜闭嘴（`|` 并排拉开；先开后闭）**：标明**画面里谁张嘴、谁闭嘴**。两侧都写。开口/闭嘴与对应角色用 `|` 并排，中间夹完整对话，拉开文字距离。禁括号紧贴（❌`开口（CHAR:[@…]）｜闭嘴（CHAR:[@…]）`），禁单侧只挂说话人（❌`开口｜闭嘴（众弟子:[@众弟子]）`），禁闭嘴写在台词前。
  - **骨架**：`开口 | CHAR:[@说话人] |` 八键 + `{台词}` `| 闭嘴 | CHAR:[@听者…]`。先写完开口人与对话，再写闭嘴侧。
  - 对白且口型可见：`开口 | CHAR:[@说话人] |` 八键 + `{台词}` `| 闭嘴 | CHAR:[@听者A], CHAR:[@听者B]`。齐声=开口侧写齐声者；画内未张嘴的具名角色/群演进闭嘴侧。
  - 对白但口型不可见（背对/远景；母版`开口|发声（口型不可见）`）：`开口 | 无·口型不可见 |` 台词仍写 `| 闭嘴 | 画内全员：CHAR:[@…]`。
  - `voice_type=VO|旁白`，或说话人本体本拍不可见（门外/隔门只闻声/未入画/电话另一端等，§4.2A）：`开口 | 无 |` 台词 `| 闭嘴 | 画内全员：CHAR:[@…]`（含群演）；只写画内听者/环境反应；禁写该发音人的动作、表情、姿势、视线，禁画内张嘴对口型，禁把门外的人写成开口侧 CHAR。可与本拍画内动作/画内对白同拍，禁漏行。
  - `voice_type=OS`（身体在本空间画内、仅口型不可见；原文标 OS）：`开口 | 无·口型不可见 |` 台词 `| 闭嘴 | 画内全员：CHAR:[@…]`。门外/本体不在画面 → 不走本条，升 `VO`。
  - `voice_type=自白|内心`：`开口 | 无 |` 台词 `| 闭嘴 | CHAR:[@发言人], CHAR:[@他人…]`；发言人闭口/内心状 + 方向锚（对谁|望天|望远|对空位）。
  - 画内仅说话人：`开口 | CHAR:[@说话人] |` 台词 `| 闭嘴 | 无其他画内角色`。
- **方言**：`用{语种}说道{台词}` 原文保留；禁译成项目主语言或删标签只留译文。
- **语气节奏**：`pause`/`rhythm`/`stress` 须落到可见微表演相位（停顿/换气/重读外化）；禁只写键不写画面。
```
开口 | CHAR:[@众弟子] | voice_type=对白｜voice_identity={具名}·{闭集底盘}·{对白声线要点}音｜tone=…｜speed=…｜volume=…｜rhythm=…｜stress=…｜pause=… | {台词原文逐字} | 闭嘴 | CHAR:[@大长老], CHAR:[@楚玄]
```
`voice_type`=`对白｜OS｜旁白｜VO｜自白｜内心`。画外音/V.O.→`VO`；叙述旁白→`旁白`；说话人本体本拍不可见→`VO`；三者同锁 §4.2A。画内背对/远景口型不可见→`对白`或原文`OS`，不升 `VO`。
- **`voice_identity`（强制参考对白声线）**：先读注入「本场角色道具白名单」【本场对白声线】，再写该说话人的 `voice_identity`。格式=`{具名}·{闭集底盘}·{对白声线要点}音`。闭集=`领导｜御姐｜萝莉｜村妇｜老者｜军人｜书生｜反派｜市井`（可再加年龄/职业）。该人 `对白声线` 非`无` → 声线原词或可检索要点**必须**写进 `voice_identity`（例：`对白声线=江湖黑话夹杂霸气直球` → `voice_identity=沈青·市井·江湖黑话夹杂霸气直球音`）。无声线 → 才只用闭集+身份。同人全稿同值；Part1【角色命名】登记一次并写`依据声线=`。禁只用闭集丢掉已提取声线；禁全员同腔；禁把声线标签写入 `{台词}`。情绪走 `tone` 等，不改 `voice_identity`。
- **身份锁**：言行像身份/地位/明文性格。无明文禁补人设。心知→自白/OS须有 `{台词}`，否则只写可见微表演。
- **情绪外化（强制；抽象→可视微动作）**：`愤怒|悲伤|高兴|恐惧|紧张|羞愧` 等抽象情绪词**禁止写入 Beat 正文**（场核【情绪峰谷综合】可用类型词）。一律转成**可视肢体微动作**，同拍须能检索：①头面克制（下颌收紧、眉骨下压；禁夸张嘶吼/脸崩/号哭）②手或持物受力（有已持 `PROP:`→指节攥紧该件；无持物=握拳/指节发白；禁臆造新物）③胸腔呼吸变沉或肩线紧 ④整体=肢体紧绷、**克制抗拒姿**，禁用砸/摔/扑/狂奔等大幅度爆发冒充外化。原文已写爆发只加厚过程与重力，不删；本层加厚情绪时禁另加爆发。日常闭集只作选槽，须写成部位过程：`悲=低头塌肩+胸腔呼吸变沉｜怒=下颌收紧+眉骨下压+指节攥紧持物+肢体紧绷无爆发｜惧=眼骤张+后倾克制｜紧=手敲/游移+呼吸变沉｜羞=视线躲开+唇咬｜犹豫=抬手中停｜决心=视线定+下颌收｜温=轻抬手｜冷=斜睨+肩线不动｜喜=唇角微扬眼不弯｜愧=回避｜杀意=视线定死+指节攥紧`。须≥2 步可见；复合脸优先（附录）。背对禁写正面才可见内容。仍服从身份锁。✅`下颌收紧，眉骨下压，指节攥紧 PROP:[钢管]，胸腔呼吸变沉，肢体紧绷，克制的抗拒姿态`｜❌`他很愤怒`｜❌嘶吼脸/另砸钢管。

## 6. 动作
写部位+幅度/速度+始末+结果。每动作/姿势先评物理锁；每拍 1 主动作+同相附属，速度合人体；抽象情绪只写可视微动作。禁跳结果、禁意图词、禁瞬间超快、禁「愤怒/悲伤」空词。受者须响应：应答｜可见反应｜明文不响应。无台词拍不硬写“对着谁”。禁镜头向、F°、机位、焦距。空间侧（绕障、门扇、拉推、抽出）须挂具名物件写`画左|画右|近镜头|远镜头`（`大门画右`、`柱画左`），禁无锚「往画右走」。
- **物理锁响应（Physics lock；强制；每物体/每身体）**：≠【世界物理】（只锁姿/身朝/眼神）。画内每个 `CHAR:` 身体与每个 `PROP:`/具名物件都有物理属性。落笔前先认本拍在动的人/件属性，再写动作如何被其带动；可见正文须能核销响应，禁无重漂浮、禁轻若无物、禁到点死停。强制闭集（本拍命中才写可见响应，禁空贴属性名）：`重力｜质量｜惯性｜摩擦｜接触｜重量转移｜地面压力｜碰撞｜跟随动作（follow-through）｜物体落地｜拖动物体`。
  - **重力**：衣物/附着液增重垂坠（雨水附着→布料被雨水增重、自然下垂，禁飘空不沾、禁硬挺不垂）；持物有下坠感；落步/放下有下坠余波；静姿须接地。
  - **质量**：重物=起势慢+施力形变（钢管抬升→手腕/肩受力，禁轻若无物、禁无重瞬举）；轻物可快，禁无接触瞬移。
  - **惯性**：起停有延迟；急停有前冲余势；衣摆/持物滞后于躯干。
  - **摩擦**：鞋底/手掌/物件与接触面有阻力；拖/推须先克服静摩擦才滑动；湿滑/粗糙只抄统筹与原文，禁臆造。
  - **接触**：须写触点（哪只手/脚/物贴何面）；禁隔空施力（与触达同核）。
  - **重量转移**：变姿/迈步/抬物须写重心从哪一脚或哪一侧移到哪一侧。
  - **地面压力**：落步/站定写脚底压地或承托面受压（微陷/微震/积水涟漪）；静立亦评估接地。
  - **碰撞**：人/件相撞=`接触→形变或声响→反弹|止动`；禁穿体重叠。
  - **跟随动作（follow-through）**：主动作停后须写后续惯性动作（挥停后手还在走、衣摆续摆、持物微晃），禁到点即死停。算同相附属，不另计主动作；另起因果仍拆拍。
  - **物体落地**：脱手/抛/放=`下落弧→触地→弹跳|砸实→余振`；禁瞬现已在地上。
  - **拖动物体**：握点+克服摩擦+物体滞后跟随+地面刮痕或承托面阻力；禁人与物同速无滞后。
气候/积水/雨雪只抄统筹与原文。`实体类=虚拟` 无接地实影，不写地面压力；屏上平面像跟会变化的屏，手镜跟该 PROP；穿衣镜等室内固定镜跟环境主体裸名，不另起身体物理。超能/法术明文抗重力才可例外，须写可见介质。✅`CHAR:[@甲] 双手握 PROP:[钢管] 中段抬至胸口，手腕下沉受力，重心压向右脚，钢管停后仍微晃`｜❌钢管轻若无物瞬举到位｜❌放下无下落弧已在地上｜❌动作到点四肢死停。
- **一拍一主动作 + 附属（强制）**：每有人拍或道具主体拍只保留 **1 个主动作** + 该主语**主动做的附属动作**（头/目光/肩或重心/follow-through 等随主动作发生的同相配合，非第二独立事件）。本拍有情绪外化时，§5 四槽微动作整束算同一附属，不另计主动作。物理锁的跟随动作/衣摆余势/持物微晃同此。主动作=本拍叙事推进的主施力/主位移/主持物变化；附属=同主语、同目标、同时相、不另起因果。主动作或目标变 → 新 Beat（与 §4.2 同核）。空镜/纯反应拍以该反应为「一个」，禁再叠主动作。动作须符合人体物理速度：起势→过程→落定，禁瞬间超快、禁姿态硬切、禁无过程已到位。✅`CHAR:[@甲] 将 PROP:[钢管] 抬至胸口高度，头部微微下压，目光直视 CHAR:[@乙]，钢管停后仍微晃`｜❌同拍先抬钢管再转身再递出｜❌钢管已在胸口无抬升过程｜❌头与目光瞬切到位。
- **情绪转微动作（强制；克制）**：抽象情绪不进正文，按 §5 写成可视肢体微动作，挂在本拍主动作的附属位（下颌/眉骨/指节/胸腔呼吸/肢体紧绷）。四槽同相，不另起主动作。禁用大幅度爆发冒充情绪外化；禁夸张嘶吼脸。
- **左右侧**：`左手｜右手｜左脚｜右脚`。
- **特点物取用**（手机/平板/手表/开盖笔记本/对讲机/车载屏）：现位=`哪只手|具名桌面|膝上|已收纳`；桌↔手须拿起/放下；屏面=`朝持有人|朝上|朝桌面|朝向{名}`。亮屏/接听须写界面类型+可读文案+操作前→过程→后界面；禁只写「接电话」。
- **朝向**：对白=`对{具名听众}|内心|画外声源|听者所在遮挡`；一拍画内对白说话人≤1。`voice_type=VO|旁白` 可叠同拍，不占画内说话人名额。画外音发音人与门外等本拍不可见的人不写朝向、视线、动作、表情。听者暂不可见（门外、蒙被、屏后、帘后）时，仅**身体可见**的发话人在明确知道位置后看向听者所在遮挡（§4.2A）；不知情不写盯住该遮挡。说话/递物/推门写面向谁。身体朝向与眼神朝向另走【世界物理】，对象=世界主体，禁画左/面向镜头。
- **世界物理（强制；每角色＋有正反面道具；开拍三键）**：画内每个 `CHAR:` 与每个**有正反面**的 `PROP:`（整车/屏/镜/像/手机屏面/有正面法器）必须锁 `姿`＋`身朝`＋`眼神`。§4.2A 已升 VO 的发音人，以及本拍门外等不可见的人，不写入本拍【世界物理】，正文不写其动作、表情、姿势、视线。听者在遮挡后且发话人身体可见并知情 → 该可见发话人 `身朝`/`眼神`=该遮挡（门/被子/屏/帘）；发话人不可见时无其视线行，画内听者可 `眼神`=同一遮挡。蒙在可见被子下的人仍锁三键，口型不可见。本行只锁朝向三键，**不替代**物理锁响应（质量/重力/惯性等走上一款）。无正反面件（杯盏/无面钢管）不写身朝，或 `身朝=无`。本行=开拍世界锁（内部台账，**不成画面句**），写在【改编指导】后、可见叙述前；可见正文须能核销同核。现场编排原样继承为 `姿态=`/`朝向=`/`眼神=`；建置/入戏才按机位转画布。禁 `ENV:`。
  恰好一行（多人用 `；` 分隔）：
  `【世界物理】CHAR:[@甲]｜姿=站｜身朝=CHAR:[@乙]｜眼神=CHAR:[@乙]；CHAR:[@乙]｜姿=站｜身朝=CHAR:[@甲]｜眼神=PROP:[钢管]`
  - **姿**=【本场姿势】闭集=`站|立|坐|翘脚坐|盘腿坐|平躺|俯卧|向左侧躺|向右侧躺|蹲|跪|半跪|倚|骑|腾空`（道具无姿=`无`）。每拍都写，无变仍写，禁只写说话人。
  - **身朝**=身体正面所对的**世界主体**：`CHAR:[@名]`｜`PROP:[名]`｜具名环境主体（大门/落地窗/控制台/路，裸名）｜`画外声源`。可加 `之左|之右|之上|之下`（所看面，≠站位）。
  - **眼神**=目光落点，对象闭集同身朝；可与身朝不同（身朝门、眼神看人）；同则 `眼神=同身朝`。禁空写「目光定」无对象。
  - **禁**：`面向镜头`｜画左/画右/近镜头｜东南西北当朝向对象｜`面向{N}度`｜臆造未出场主体。无变化须与上拍终态同核。本拍变姿/转身/转视线 → 正文写过渡；开拍行仍=动作前，终态在正文可检索。
  空镜/整车无人=`【世界物理】无`。✅`身朝=落地窗｜眼神=CHAR:[@乙]`｜❌`身朝=画左`｜❌只写「站着」无身朝眼神。
- **门类**：点名哪一口。过程=`开闭态→开(手+接触点+推|拉+开向+人站侧+扇展侧)→通行→带上→关闭`。手=`左手|右手`；接触=`在{门名}{左|右}{上|中|下}部`（抄环境规划把手位；无注入则取门轴对侧中部）；力=`推|拉`；开向=`向里|向外`（抄环境规划）。人站侧=`{门名}画左|画右`。扇展侧=`门扇往画左|画右展开`。须能核销「在门左中部向内打开」。向里拉大门须写清拉向里+人站哪侧+扇往哪侧展开，禁只写「拉开/推开」。**双开**须点 `左扇|右扇|双扇`（抄环境 `通行扇=`；双扇同开写两触点），禁把对开门写成单扇一门轴。禁穿关闭门（双开禁穿仍关的那扇）。禁裸「进门/出门」。抽屉同（手+开向+往画左|画右抽出）。
- **触达**：须走近与接触，禁隔空（物理锁`接触`同核）。
- **操作链**：开合/取出/展读/解锁/递交中间步按时序可检索；禁跳结果态。
- **因果链**：施力/接触/受力/投射须同拍写完。投射=`出手→弹道→命中部位→效果→余势`；闪避/格挡写预期弹道与实际落点。碰撞/落地/拖动余势须同核物理锁。
- **位移**：先原始位置再落点；写运动方向+朝向；禁「走过去/车开过来」。**障物评估**：直线起点→落点扫本场已写固定大件/柱/人/门扇。无挡可直走。有挡须写 `绕={具名}之{画左|画右|近镜头|远镜头}`；直线穿障=失败。曲折绕障装不进一拍→拆拍。载具/坐骑作单独主语时保留路线/开合，禁压成「CHAR 驾车离去」。
- **原文站位（最高）**：原文已写「站/立/坐在{具名}前/旁/后」→ 开场画面拍必须可检索该锚（如「站立在巨幅落地窗前」），禁删、禁改挂到原文未写的桌/椅旁。后拍若要换锚，本拍或上拍必须写出位移始末。运镜句（推进/推近/拉远）≠ 走位，不得暗示人已换位。无位移则后拍人仍在原锚原朝向。
- **入场 XOR（强制；禁鬼魅；执行统筹可见性出场时机）**：【本场角色】/【本场道具】`在场` → 开场画面拍已在空间内（开场姿/手持可检索）。`待入画` → 首次出现拍必须写经具名出入口或具名容器的入画过程（从门口走入/推门入厅/递入/开盒取出等），禁中途凭空已在场开口或动作。人未入画就说话 → 台词按 §4.2A 升画外音，不把说话人写进该拍画面。介质可见≠真人入画。占空间的虚拟 CHAR（全息／幻影）按 `在场`／`待入画` 写本体，禁写成屏上平面人。屏上／镜中平面像只写器件表面，禁再写第二个 `CHAR:[@同名]`。独立道具同核：开场本体已在桌/手/身上 → 开场写；开场在盒/匣/袋内 → 取出当拍才点名，禁写入开场画面。对白提前点名、场头清单已列、全局信物 ≠ 开场建置依据。
- **可见性出场时机（最高；跟统筹槽）**：开场观众能看见本体才写进开场画面。盒/匣/抽屉/口袋/包内须取出才见 → 开场不是出场时机，等具体取出拍再写。开场已佩戴/手持，后拍才抚摸、发亮、使用 → 开场画面必须已写该件，后续只写动作。配饰不跟宿主盲抄：人开场在场、件仍在盒里 → 件不进开场画面。
- **进出场衬托（最高；禁一句交差；禁突兀）**：待入画首次入画、中途出画/离场，禁止只写进出者「走进来/离开」，禁止人已在画中开口/站定而无过渡。须同时写出：①**进出者经口过程**（门类/位移已有；须有可见过渡：口沿/门缝→身形→落定或背影出，禁瞬现半身）②**视线配合三拍**（有在场者强制；无在场者才 `反应=N/A:无在场者`）：**预看**=进出发生前至少一人视线先转向出入口/声源（门响、脚步），人未入画或未出画完；**跟看**=过程中视线跟随进出者路径（转头/目光扫过）；**对视落定**=落定或出画完成后进出者与在场者视线交接（互看或目送落空），再进入下一拍对白。可叠停顿/起身或坐直/表情两步，但**不得用表情顶替视线三拍**。③反应即卖点或峰谷则另起 `~` 或挂 `反应特写`/`反馈特写参考`。景别不锁档，须在场核给出意图（`指导=` 可含 `入场锚`/`转折/离场`）。禁意图词「众人震惊」无可见步骤。落定后下一拍才对白加压。开场已在场建立走入场双义务，不套本条。
- **开场见人（禁空镜起幅后人突现）**：开场已在场者必须写进开场画面拍（可远、可小、可只见轮廓，须可检索在空间里）。禁先写无人空镜 Beat，再在下一拍半身/对白里突然开口或动作。真环境文学空镜仅当该拍无人可写；其后第一拍有人仍须在空间远景或全身可见，禁空镜后直接半身对白。**载具**：内部自成做场写在占用空间（可远、可小）。三层交付/整车作道具写在大世界，可点名整车、允许人相对该 PROP。整车无人建立拍正文无人，可点名 PROP，禁 CHAR。待入画者先写经口入画，落定后再收近。景别与挂 ENV 由现场编排锁。
- **入场双义务（吸睛 + 整体建置）**：有戏场开场画面链必须两闸都兑现。①**吸睛**=可拍通道或艺术转入落成的可见抓眼（道具/表情/动作切口/宏观/关键音画）。②**整体建置**=谁在何空间、相对落点可读（可与吸睛同拍，若远景里已有醒目动作）。**可从特写起幅吸睛**，但进入铺垫/对白加压前必须另写（或衔拍）空间建立拍，禁特写开场后直接半身对白、从未拉开。场际转入落成若是特写，下一拍仍须落到本场空间整体。景别由现场编排锁。
- **运动舱内（强制；车厢/驾驶舱/客舱等）**：本场【主环境】/【场景名称】/活动空间属交通工具内舱（汽车内、客舱、驾驶舱/操纵舱、轿子、马车厢、船舱、火车/地铁车厢、电梯轿厢等）→ 默认 `舱态=行驶`，**必须写出舱位在运动**，且**即使戏在舱内也须写出舱外变化**，禁当停泊厅堂或静止房间。原文/场核明文停靠、停车、到站、熄火、停驶、停泊、停层开门 → `舱态=停靠`：写停稳+窗外静止（有窗则钉死不流），禁仍写飞掠。仓外大背景切入后，**落定舱内拍起**才走本条四槽。
- **露天合建运动态（强制；甲板/敞篷后厢/开顶平台等）**：占用面型=露天合建且载具在走 → 须写大世界过幅（海平线/街景/路树沿前进向流过+换段）+ 面体晃（甲板浪摇/后厢路振）+ 运动音。禁写成无外界的静止平台。明文停靠才钉死远景。
  - **开场画面拍四槽可检索**：①舱体动势=`微颠|纵晃|侧倾|巡航微震|步态颠簸|浪摇|轿厢升降震`（按载具择1；禁空词「车在开」）｜②**舱外变化（强制）**=窗外/舷窗景物或光影沿前进向流过，且须写出变化增量（楼群更替/街景换段/层位升降/云海过幅）；无窗/帘闭仍须经缝隙/反光/仪表外景交代舱外在变（`窗外=缝隙可见`/`反光过幅`），禁钉成静止壁画｜③随动=乘员肩/膝，或已有吊环/扶手带/帘穗/杯水/挂件随晃（禁臆造新物件；**不顶替②**）｜④【音效】一条舱体运动声（见 §5）。禁无据加急刹/车祸/脱轨改因果。
  - **其后行驶拍**：每拍须含 ②舱外变化（可短句）+ 运动音；①③至少保留其一。对白连拍可压缩舱体/随动，**禁压缩掉舱外变化**。禁整场零运动句、禁整场零舱外变化句。
  - **禁**：窗外钉成静止壁画｜只写舱内对白/互殴而无舱外景物更替｜把停靠写成行驶｜用运镜/手持处方冒充舱动｜`ENV:`。
- **宿主大环境切占用面（强制；仅内部剧情才切；本层规划）**：本场含宿主大环境且随后进入**内部自成做场**（内舱或甲板）→ **必须先规划成相邻两拍以上**再写正文：宿主拍与占用拍分号，并写出切口。禁同一拍既写整车无人远观、又写内部剧情。禁宿主上的人瞬移进占用面。**三层交付不切占用**：人在车里与街上/岸上对话、枪战等，正文留在大世界，载具作 PROP。
  - **切法 XOR**：①`入舱过程`（默认；原文有走近/开门/上车/落座/越过护栏上甲板）→ 宿主拍写到门扇/护栏过程（未完成）→ 衔拍或下拍落到占用面（落成）→ 落定舱内后才走运动舱四槽；门开合仍走门类条。②`过阈切`（原文无逐步上车、宿主建立后切入占用面）→ §4b 增拍：转出宿主焦点未尽，转入占用面落成（剪影过阈/衣帜遮幅/行进吞没/倒映交接，骑门/窗/护栏/人走）。③`场际转入`（本场开场即占用面，上场已是宿主；`艺术转入≠无`）→ 开场拍整句继承转入动作落到占用面，禁重拍宿主起势、禁再走一遍上车。④`出舱反向`：占用面→宿主，对称（出舱过程|过阈切|场际转出）。
  - **运镜切法（强制；封闭舱外↔内优先连续推/拉；一条有动机运动句；禁焦距/机位）**：切法须挂运镜档。**平稳进出（最高）**：从外部环境进封闭舱、从封闭舱回外部环境，默认**一镜骑阈连续运动**完成换空间，禁街上大景硬切舱内半身对白。文戏只写运动句（推过门框/拉出舱口），不写 mm/机位。
    - **外→内用推**：默认 `过框推入`（沿已具名门/窗/舱口推进，起幅在外、落幅已在舱）。人走近则 `跟随入舱`（跟人走到口再推过阈）。先隔窗看见舱内再进则 `窗外窥入`（窥清再推入）。侧门/后门则 `绕体外跟` 再推。场际开场已在舱→`落幅在舱`，不重拍外景跟。
    - **内→外用拉**：默认 `过框拉出`（沿同一阈拉出，起幅在舱、落幅在外）。人走出则 `跟随出舱`（跟人过门再拉开见外部）。
    - **灵活**：同一阈可换档，但进出须对称可核（进用哪口、出还从哪口）。急促闯入可缩短推程仍须骑口；从容上下车可跟人走到口再推。禁空推空拉（须骑人走/门窗/舱口/车身）。露天合建无舱门过阈则不套本条。三层交付不切占用、不走本条。
  - **禁**：宿主与占用同拍混空间｜无门无座瞬移入座｜切入占用面仍写宿主海/路当当前主空间｜只切空间不写镜头过阈｜外景硬切舱内半身｜用运镜处方（机位/焦距）冒充运动句｜`ENV:`。
- **全员**：画内主配角写姿态/身朝/眼神（【世界物理】）+倾听/防备；听者/旁人有反应须写出；施力后受力方须滞后反应。未写则明文不响应。
- **身体姿势（强制；继承【本场姿势】）**：每拍画内每人须有闭集词可检索=`站|立|坐|翘脚坐|盘腿坐|平躺|俯卧|向左侧躺|向右侧躺|蹲|跪|半跪|倚|骑|腾空`，并写入【世界物理】`姿=`。先抄该人开场/入画姿；原文无姿按统筹补全。变姿须有过渡链（坐→站先起身）。姿势须过物理锁（衣物垂坠/承重/接地/地面压力）。禁只写说话人有姿、听者「在场」无姿。
- **手持/佩戴开场即写（强制；仅已可见件）**：入画首拍与持物未变拍，画内每人须可检索**开场已露出本体**的手持与佩戴（无则`无`）。开场已在身/在手 → 禁等用时才第一次点名（后拍抚摸/发亮仍须开场已写）。开场在盒/匣/袋内、本体未露出 → **禁**开场点名；取出过程写入该拍，取出后下拍才写手持/佩戴。跨多拍持续的动作主体须已在 `[PROP_EXTRACT]`，叙述层用 `PROP:[名]`。纯外形配饰与已上身绳/铐/镣等束缚件不升格，跟宿主写佩戴，禁 `PROP:[手铐]`。
- **名牌不算动作**：画面打出角色名牌物理文字不是角色行为，禁写成独立动作拍或动作链步骤。
- **力度**：激烈动作写力度、速率、相对距离。
- **上下拍主动补连续（最高）**：动作连续、位置连续不是只核销。同一人、同一件，上拍终态与本拍开拍对不上，就在本拍正文里、对不上的那一动作之前补上。动作不接：补收势、换手、起身、放下、接上未完成的链、受者响应。位置不接：补从上一落点走到本拍落点的移动。只增不删，不改对白。下拍从补完后的终态写起。**故意双生不补**：剧情已写明同一人同时有第二具身体，如灵魂出窍、元神离体、分身、残影，或特效技术造出的另一具。第二具与本体分名分写，可以同时在不同位置、做不同动作。这种差不补走位，也不补成同一人的过渡。
- **禁**：虚空瞬移｜中途鬼魅出现（无开场在场、无经出入口入画却已在场开口/动作）｜开门不写手/接触点/推拉/开向/扇展侧｜手持杯却双手打字｜武器无中生有｜直线穿桌/柱/人/门扇。先放下再做新手部动作。对不上的同一人先按上条补过渡，不把断续留到下游。

## 7. 命名与角色设定
禁番位当姓名；有真名保留。有个体动作须具名。占位补名须用日常人名，**禁止按剧情功能/结局/隐藏身份取名泄密**（❌复仇者｜真凶｜内鬼｜白莲）。【角色设定】只摘原文外形/性情/特定动作及身份/地位/外形评价原词；有 `对白声线` 则转抄，并据它设定该人 `voice_identity`。对白夸赞外形须进设定。已摘性情须在 Beat 言行可核销；`对白声线` 只进 `voice_identity`，**不改台词用词**。

### 7.1 资产标准表达（文戏起；下游原样继承）
白名单=注入「本场角色道具白名单」+ 本场 `[SCENE_CAST]` + 整集提取块 `名称=`。落笔四步同 Stage 2.2：①定位与明文完全相同的名 → ②原样复制 → ③套 `CHAR:[@{原样}]` / `PROP:[{原样}]` → ④不在清单则保持自然语言、禁止套前缀。
- 范围=Beat 叙述层、开口/闭嘴、朝向对象、取用对象、【配乐】`锚=`、【音效】`配合=`。`[SCENE_CAST]` 原位透传。
- 不对白、不对字：花括号/引号内台词、配乐/音效 `{…}`、OS/V.O./旁白/自白、载体上的物理字样保持裸名。
- 禁另起未列出名；禁 `ENV:`；禁拆已有前缀还原裸名。
- 例：✅`CHAR:[@林岳] 把 PROP:[银打火机] 搁上桌，说道 {林岳来了吗}`｜❌叙述层写裸名`林岳`｜❌`{CHAR:[@林岳]来了吗}`。

### 7.2 虚实同核（最高；防镜中／全息双人）
同拍叙述禁止把同一核名人像写成两个身体。视频模型见两个同名 `CHAR:` 会生成两个真人。
- **虚拟 CHAR**（提取块 `实体类=虚拟`）：用分名 `CHAR:[@{宿主}全息]`／`CHAR:[@{宿主}幻影]`，须写虚像辨识 ≥1（半透明／扫描线／体积光／无接地实影）。禁与宿主同名，禁写「全息的他」而不套分名标签。
- **屏上平面像／手镜**：会变化的屏与会被拿起的手镜只写 `PROP:[终端/手镜]` 的屏面成像或镜面反射，可点依赖角色名一次作「其像」；**禁止**再写 `CHAR:[@甲]` 站在屏里／镜里。宿主真人在场 → 肉体 `CHAR:[@甲]` 只出现一次 + 器件表面反射／影像。
- **室内固定镜**：穿衣镜、墙镜、落地镜、固定梳妆镜等环境主体用规划注册裸名，不套 `PROP:`。只写该镜的镜面反射；禁止再写镜中第二 CHAR。
- **角色单位**：屏上／镜中像不计第二 CHAR；虚拟 CHAR 计 1。
- ✅`CHAR:[@林月] 立于穿衣镜前，镜面反射其像`｜❌`CHAR:[@林月] 立于 PROP:[穿衣镜] 前`｜❌`CHAR:[@林月] 与镜中的 CHAR:[@林月] 对视`
- ✅`CHAR:[@林月] 看着 CHAR:[@林月全息]；后者半透明、无接地实影`｜❌`CHAR:[@林月] 与全息林月并立`（同名两个身体）

## 9. 保真
