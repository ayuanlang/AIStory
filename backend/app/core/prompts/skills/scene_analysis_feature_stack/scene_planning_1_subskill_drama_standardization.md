## 目标（最高；本文件工作方式）
本文件的核心交付不是局部润色，而是逐 Scene 产出已经确认、可直接使用的**最终 Beat 列表**。
1. **确认 Beat 切分**：依据原文信息单元、说话轮次、动作/反应链、卖点、高低点、揭示与节奏规则，新增、拆分、合并或修改 Beat；完成后不保留“待拆”“建议另起”等未决状态。
2. **全部内容可拍化**：Scene 内每个原文信息单元必须且只能归入一个明确 Beat，并转成可见动作、可听声音、具体台词或可拍环境变化；禁止作者解释、抽象心理、空泛情绪和无承载信息游离在 Beat 外。
3. **按重点组织 Beat**：继承【场景综合】【卖点综合】【情绪峰谷综合】【叙事综合】，将卖点、情绪峰谷与叙事三类 `指导=` 落实到对应 Beat；不改上游判断，不为加强而新增因果。
4. **文戏标准化**：处理对白拆句与语气、细节/反馈特写、环境情绪、音效`<…>`、身份地位、微表演和非武戏动作；
5. **边界与透传**：禁止重切 Scene、改卖点名或峰谷判定。场号、场级标签。
## 核心任务
逐 Scene 完成“原文信息核销 → Beat 边界判定 → 卖点与规则校正 → 全内容可拍化 → 连续重排 → 最终列表校验”，输出唯一确定的 Beat 列表。多线结论**继承上游 A0**：上游=`多线/双线`则保持可见画面交叉与串接，上游=`单线豁免`则保留豁免依据；本阶段不得改判、不得为凑线新增因果，也不得把已规划多线压回单线。

## 1. 原文核销与对白职责
本文件不写建置几何；输入已有位置/朝向/ENV 空间词原样透传。
本文件执行：对白咬合（语气/身份/受者，不写朝向词）｜微表情｜表演连贯。

- **原文逐字核销（最高硬约束；本文件侧=对白/专名/信息单元）**：原剧本**每一处文字 / 每一信息单元**必须落入优化稿可检索落点；**禁止**概括吞并、跳场省略、只留「大意」。
  - **对白/OS/屏幕可见字**：项目语言侧台词 **逐字保留**（可按自然停顿切开，词序与用词不改；禁意译替换、禁删半句）。>20字拆句落独立 Beat（见 §4）；拆后各拍拼接=原文全句。**无具体台词内容可省略该句对白（强制例外）**：上游仅有说话动作描述、无可核销台词正文 → 可省略该句对白，**禁止**臆造台词；可见说话动作仍按微表演核销。
  - **专有名词/角色名/地名**：与原文 **逐字一致**（§19 仅处理番位占位→具名；已有真名禁改）。
  - **叙述/动作信息单元**：谁做了什么、何结果须可检索；位置/朝向/ENV 空间词不删不改。原文声音→【入戏】尖括号`<…>`（§5）。
  - **增补边界**：微表演可进【入戏】；禁新增改因果事件。
  - **交付**：Part1 `【原文逐字核销】通过｜入戏兜底=已做｜抽检=…`。无具体台词而省略的对白不计核销失败。

## 4. 最终 Beat 切分逻辑（canonical）
**Beat 定义**：一个 Beat 是一个可独立拍摄、内部因果连续的最小叙事动作单元，具有明确的`触发/承接 → 可拍过程 → 信息或状态落点`。Beat 不是一句话、一个镜头术语或任意长度段落；禁由 `Shot/Lens Preference` 单独驱动切分，禁重切 Scene。

### 4.1 切分执行顺序
逐 Scene 严格按下列顺序处理，最终只输出结果：
1. **信息单元编号**：内部逐项列出原文的对白、动作、反应、声音、环境变化、可见文字、揭示、结果及专项过程；每项只分配一次。
2. **建立基础 Beat**：先按“主动作或主信息落点”顺序聚合连续信息，不沿用输入的错误边界。
3. **应用强制切分闸**：命中 §4.2 任一项即切开；一个位置命中多项只切一次。
4. **应用合并闸**：仅同时满足 §4.3 全部条件才可合并相邻 Beat。
5. **卖点与可拍化校正**：按 §4a、§5、§6 增补或修改承载 Beat；必要时新增反应拍、揭示拍、留白拍，不得新增剧情事实。
6. **连续重排**：每 Scene 的 `[BEAT_START:{n}]`、标题 Beat 号、`[BEAT_END:{n}]` 统一从 1 连续编号；所有场级 B 引用同步更新。
7. **最终校验**：通过 §4.5 后才可输出；不得保留候选方案、临时 Beat、旧编号或“待下游决定”。

### 4.2 强制切分闸（命中任一即新 Beat）
1. **说话轮次变化**：说话人改变，或听者开始开口应答；一 Beat 内非群体齐声的具名说话人去重数≤1。
2. **长对白自然分段**：单人连续台词>20字，按句号、分号、转折、信息重音或自然停顿切开；各段各自成 Beat，拼接后必须逐字等于原句。
3. **主动作或目标变化**：角色开始新的独立动作、操作目标改变，或“准备/执行/结果”之间存在明确戏剧停顿；连续操作链未换目标时不得机械拆碎。
4. **受者反应成为信息**：被击中、理解、拒绝、决定、情绪反转等反应本身承担卖点、结果或后续因果时，独立为紧邻反应 Beat。
5. **揭示与知情状态变化**：Reveal、证据读清、身份/答案显露、观众先知、角色从未知到知晓，须在揭示落点切拍；不得把“看见—理解—反应”压成不可读的一句。
6. **时间或叙事形态变化但未达切 Scene**：同场短闪回、想象、屏幕内容、蒙太奇切片、明显时间跳步，分别成 Beat，并保留进入/回切锚。
7. **原文独立视觉信息**：原文单列的近景、特写、空镜、可见文字、关键道具或环境变化必须有独立落点；若其可读性、情绪或卖点需要停留，则另起 `~ Beat`。
8. **卖点/峰谷节点**：卖点的细节、反馈或余波无法在推进拍中清楚读出；高潮/低点或金句击中需要独立承载时，必须另起。
9. **场内叙事线可见切换**：已锁多线在同一 Scene 内从一组可见行动切到另一组，再切回时，各段分别成 Beat；不得用音效冒充画面切线。

### 4.3 相邻 Beat 合并闸（必须全部满足）
- 同一主动作/同一信息目标，时空、叙事线和知情状态连续；
- 合并后仍仅一个具名说话人，且无>20字未拆台词；
- 不吞并独立反应、揭示、原文特写、卖点或高低点节点；
- 合并后仍能清楚写出触发、过程与落点，且没有两个相互竞争的主动作；
- 合并不导致原文信息概括、顺序改变或可拍细节消失。

### 4.4 Beat 类型与节奏
- `- Beat {n}`：主职责是推进原文已有动作、信息或因果。
- `~ Beat {n}`：主职责是让关键细节、反应、揭示、情绪、空镜或余波被读清。
- 有戏场（≥3 Beat）两种都要；`~`约三成、`-`过半；连续 `-`≤4、连续 `~`≤2。高潮/低点效果特写、文戏击中脸、Iconic/金句、空镜情绪砸点已标 `~` 时不得改为 `-`。禁只换符号凑配额。
- **客体禁独立拍**：受力物、被递物等默认与施力/交互者同拍；仅当客体变化本身成为揭示、结果、卖点或后续因果时才可独立。

### 4.5 最终 Beat 列表通过条件
- **覆盖**：原文每个信息单元均有唯一 Beat 落点，零遗漏、零重复、顺序不乱；
- **可拍**：每 Beat 均有可见/可听承载，抽象心理已转为原文允许的动作、表情、OS/自白或环境响应；
- **完整**：每 Beat 有触发/承接、过程和落点，不存在只有标题、说明、镜头术语或空情绪的 Beat；
- **边界**：无可合并的碎 Beat，也无含两个主动作、两个说话轮次或被压扁揭示的过载 Beat；
- **重点**：卖点、高潮/低点、贯穿信息及对应细节/反馈均能以最终 B 号检索；
- **编号**：本场从 1 连续，START/标题/END 逐一相等，场级标签和 Part1 引用均指向最终编号。

Part1 必须输出：
`【Beat切分确认】场=…｜最终Beat数=n｜新增=n｜拆分=n｜合并=n｜修改=n｜信息覆盖=100%｜可拍化=通过｜编号连续=是`
`【对白拆句】结论=已拆句|未拆句|无对白｜长句=B…|无｜拼接=原文全句`
`【快慢节奏】-n/~n｜配额掌控=已调|原样达标`

## 4a. 场级综合指导 → Beat 落地协议（文戏 canonical）
> 目标：把上游【卖点综合】【情绪峰谷综合】【叙事综合】各自的 `指导=` 转成可检索 Beat，而不是照抄指导文本。**本节决定如何修改 Beat**；不得重切 Scene，不得改判看点、峰谷或叙事结论，不得改原文因果。

### 1. 先拆指导，再找原文锚
逐 Scene 建内部映射（不输出分析过程）：
`卖点/情绪/叙事指导项 → 原文锚句 → 承载Beat → 可拍动作/细节/反馈 → 离场状态 → 保护项 → 责任技能`。
- `原文锚句`必须来自该 Scene 。
- 输入已有 Beat：优先挂到含原文锚的 Beat；输入尚无 Beat：先按 §4 对原文正常拆拍，再挂指导。
- 一个指导项可落同一 Beat，也可落锚点前后紧邻 Beat；禁止把指导集中塞到场尾“补作业”。
- `名场面参考`只提取其情绪、叙事、表演、声音、节奏或注意力组织机制，再映射到本场原文对象；禁止复制参考片的剧情、台词、人物关系、标志性动作、招式或专有视觉设计。

### 2. 决定“并入”还是“另起”
- **并入原 Beat**：细节与反馈都能在原动作/对白因果内完成，且不会出现两个说话人、不会压缩原文信息、不会混入位置朝向。
- **另起 `~ Beat`**：关键文字/道具必须让观众读清｜揭示/解谜需要先看细节再看人｜一句对白击中后需要独立反应｜高潮/低潮需要余波停留｜指导明确要求隐藏后揭示或回收对照｜【叙事综合】`关键人物`首次入画或改因果瞬间须被看清。
- **另起 `- Beat`**：指导落点本身承担新一段原文已有的推进动作；禁止为了特写把静态细节伪装成快拍。
- 新增 Beat 只增加**表现细节**，不得增加新事件、新台词、新能力、新线索或改变知情顺序；完成后本场从 1 连续重排。

### 3. 三项落地写法
1. **细节特写参考**：
   - 写进【入戏】，格式语义=`具名对象 + 具体可见细节 + 变化/可读信息`。
   - 文字/信件/证据须保留原文可见内容；禁止自拟新字句。美景/美物/美人/美食须写能被画面辨认的具体质感，不写空泛“很美”。
2. **反馈特写参考**：
   - 同拍或紧邻拍写明确承受者/发现者的复合可见反应；至少两步过程，且符合身份、地位、明文性格。
   - 解谜=`发现细节→理解变化→反应`；悬念=`看见但未完全理解/观众先知→压住反应`；高潮=`效果→人物/群体释放`；低潮=`打击→克制/崩落→余波`。
   - 禁止臆造对白；反馈不能由无关第三人替代。
   - 原文确无在场观察者且指导标 `反馈特写参考=无` 时，可用对象自身变化或环境响应闭合（如火焰映亮文字、风掀起信角），回填 `反馈=N/A:无在场受者`；禁止凭空拉入角色。
3. **运镜参考**：
   - 在对应 Beat【入戏】写**一条短的有动机镜头运动句**，把上游方向转为可执行叙事关系，例如：`镜头沿信纸已写文字缓慢推近，停在被烧焦的署名`。
   - 运镜必须连接 `注意起点→发现对象→信息/反馈落点`；推近=聚焦/压迫，拉开=释放/孤立，跟随=发现/追随，揭示=遮挡后显露，停留=余波/回收。
   - 允许写运动方向与叙事目的；禁止焦距、设备、机位参数、复杂分镜表及无动机炫技。

### 4. 情绪与叙事指导落地
- **情绪指导**：`入场锚`落在本场首个相关 Beat；`峰值放大`、`低点放大`落在对应原文节点或紧邻反应 Beat；`转折/离场`须在转折 Beat 与末个相关 Beat 可检索；`弧线保护`禁止提前爆发、提前释压、删拍或重复兑现。
- **叙事指导**：`关键人物`（对情节改变有重大影响、须放大=是）必须落到出场/抉择/揭示/改因果的原文锚 Beat，可见面可读；首次入画或改因果瞬间优先另起 `~ Beat` 放大，禁止并进过场 `-` 一笔带过。`信息焦点`必须有具体可见/可听承载（焦点即关键人物时与上项同名同拍）。`显隐次序`严格服从原文知情顺序；`两难/选择`只强化原文已有选择行为与代价；`契科夫`只展示/回收原文已有对象；`后果/回指`落在原文结果及其反馈 Beat。禁止把龙套当关键人物放大，禁止指导已列关键人物却无独立可见落点。
- 情绪或叙事指导命中 VFX/XIAN 专项过程时，本文件只落实文戏前置/后续反应与保护项，专项命中过程留给对应技能。

### 5. 贯穿信息保护

- **意图→具体动作（最高；【入戏】强制）**：禁用意图词代替动作；转译为可见动作链。朝向/起终位/方向/距离/运动终点不写入戏。
  - **转译要求**：【入戏】写谁、部位、幅度/速度、连续动作、具名交互节点与结果反馈；若被拦/失手，写可见受阻过程，不写「试图失败」。
  - **失败改写例**：❌`试图推开门` → ✅写部位+开向+门扇运动。
  - **与「犹豫/决心」微表演区分**：情绪外化可用「抬手中停」「视线定」等**可见停顿/微动作**（§5）；**不得**用「想要/试图」概括未发生的大动作。未执行的意图若剧情只需心理→走思想转自白/OS（须明文闭嘴），**不得**在入戏写空意图句冒充动作。
  - **内部规划词≠成稿**：位移规划中的「意图」节点仅作内部核对；写入【入戏】时必须已换成上列具体动作句。成稿出现意图词=整拍失败，须回改。
## 7. 命名与角色设定
- **§19具名**：禁番位当姓名；有真名保留否则合法取名；姓名≠剧情地位。群演簇仅用于无个体剧情动作的匿名氛围集合；凡有独立走位、交互、对白/OS 等个体剧情动作，必须具名为龙套。角色身份/地位写入【角色设定】。Part1 `【角色命名】`对照表含地位闭集（含`龙套`/`群演簇`）。
- **§19a【角色设定】**：Part2首段；只摘原文已写外形/性情/特定动作；**软性外形决定因素（强制保真）**：原文已写的身份、地位、特殊用途，以及明确评价外形的词（高贵/精致/漂亮/性感/绝美/华贵/素净/冷艳/俊美等）须**原词**写入该人外形短注（可作「身份/地位/外形评价：…」），供 Stage 2.1 入 `entity_attributes`/`appearance_cues`；禁当主观形容词删掉或改成「好看/气质好」。对白夸赞外形（「你真漂亮」等）=外形信号，须进角色设定，不得只留对白而设定块蒸发。**性情另锁言行（强制）**：已摘性情须在【入戏】**动作/行为/语言**可核销兑现（豪门/高户内敛、农家直接；明文性格禁抹平）；无则静默。禁发散。语种统一；方言标语种。
## 9. 文戏局部保真
- **潜台词/钩子**：原文已有潜台词与钩子须保持含蓄可读，不得因可拍化改成直白解释或提前解答。
- **受者响应**：细则 canonical 在 §6 / §5；对白和文戏交互的受者响应、跨拍衔接与复合表情须保真或在不改因果前提下加密。
