## 1. 动作规格与招间因果（打斗/法攻/仙攻）
- **动作规格（七项）**：①部位+幅度/速度/力度(止于手级)｜②动作始末与门开向｜③文戏低缓(武戏例外)｜④惯性过渡｜⑤操作链禁跳步｜⑥必要且日常的情绪外化｜⑦因果可感。写动作与经过的具名交互节点。
- **招招前后因果连续（最高）**：每一招须可追**前因**（承上招终态：空门/失衡/落空余势/挡格反弹/距离开合/护盾裂口/术法余波等）→**过程**（起势·轨迹·可见介质）→**后果**（命中/落空/挡格/打断+效果，**且写到效果结束/停驻**）→**铺下一招**。跨拍强制承接：相对距离｜姿态/重心｜兵器或握持落位｜术法/护盾/域场现态（有则）。攻防须双向咬合（甲招→乙因该招而应→甲因乙之应再出招）。
- **斗法链（仙攻段强制）**：`结印/引气可见→介质成形轨迹→对撞/偏转/穿透→余波→下一式从余波态起手`。
- **禁因 AI 规避省略连续攻击**：连招/换招链不得压成「起势—结果」或删中段；规避只砍不必要细节动作，不砍招招过程。❌无因果堆招、混战摘要、或同构再出招。
- **禁重复招式（最高）**：同一连续攻防段内，**同一出手方**不得重复或同构再出招式/法术。判定=招名相同｜部位+轨迹相同｜同一法术介质同路径再放｜空域技法同构连用｜仅同义换词。下一招须至少换部位/左右手/兵器路径/命中面/空域技法/法术介质之一。挡格/闪避可同类但须换方向或部位。明文连击须写出可辨变奏。❌直拳再直拳／火球再火球／俯冲再俯冲。
- **明确动作 + 效果写到终止态（最高）**
  - **禁混战摘要**：❌「混战在一起」/「激战一番」。群战=阵势质块 + 主角切口的明确 1v1/1v2 招式链。
  - **明确动作最低粒度**：每招可检索——谁｜部位/兵器/法器｜对谁｜起势→轨迹→命中面。
  - **效果写到终止**：命中/法攻/仙攻后写受力、连续位移、撞击/落地/被接住和动作停住。轻击写到局部运动停止。介质命中 → 人/物如何被带动 → 撞何物/落何地 → 瘫/跪/贴地/被护盾托住。空中命中仍须写坠落→落地停驻。
- **打击/投射**：近身=`起势→发力→命中→反馈→路径→终点/停驻`；投射=`出手→路径→命中→效果→停驻`；位移类效果须写到撞墙/落地/瘫地。反馈段须含受力方表情或可读局部特写，禁只写位移/光效或“混战”摘要。

## 2. 金身／法相 ≡ 角色（最高；仙攻增量；字段零减免）
输入出现法相／金身／法身／真身／金光法身／万丈金身／化龙凤／龙／巨兽等时启用。凡有正反面且有自身动作 → 须 `CHAR:[@{名}]`（与宿主分名；无专名=`{宿主}法相` 或原文称呼）。字段与句式**与角色同标**；缺任一=失败；与宿主同框须**分名分写**（宿主≠金身）。禁只当特效过程词无名体。

**九字段**：定位 XOR｜正背面｜面向｜姿态｜与他者｜视线(有则)｜动作方式。本文件写可见凝形/同步/消形过程。
- ❌`金身显形`无可见凝形过程。
- 凝形后维持相仍在画→每拍写清宿主驱动与金身对应动作；消散须可拍消形／出画过程。
- **入画／突现**：本拍写凝形动作。
- 金纹/波前等无定形介质→走六相，**不**替代金身本体。
- 须读脸/口型/正面躯干才安排可读面过程；背对禁写须正面才可见内容。

### 宿主↔法相／金身动作同步＋因果共写（最高）
法相／金身与宿主同框维持相期间，**原则上动作与原主同步同相**——宿主抬臂／结印／发力／转向／姿态变／受击反馈时，金身／法相须**同拍**写出对应同向或尺度放大的镜像动作（可巨化／可极短可视延迟，但相位须可检索咬合）。

| 相位 | 宿主侧（须可拍） | 法相／金身侧（须可拍） | 禁 |
| :--- | :--- | :--- | :--- |
| 凝形／显形 | 起势／结印／吐纳／抬臂等驱动过程 | 轮廓凝出／拔地／撑幅落位（当拍九字段） | 金身自现、宿主无动作 |
| 借体出手／对位攻击 | 驱动姿态或**同步**发力（掌势/口令/目光锁；肢体方向与金身出手同向或可核销镜像） | 同拍对应出手／弹道／命中（与宿主发力同相） | 只写金身掌推、宿主旁观空白；宿主抬左金身无据出右且无核销 |
| 维持相同步（原则） | 姿态／朝向／发力变有可拍过程 | 同拍镜像或放大同向动作 | 金身连招而宿主全程静止／另做无关动作 |
| 同损／受击反馈 | 宿主震颤／吐血／跪软等可见反馈（有则） | 金身裂纹／踉跄／光衰等对应反馈 | 金身重创、宿主毫无反应且无核销例外 |
| 收摄／消形 | 收掌／解印／召回动作 | 消形／缩回／离画过程 | 金身蒸发、宿主无收摄动作 |

## 3. 身法：地面与空域

## 6. 特效六相与驱动力
- **驱动力可视化（强制）**：气/内功/魔力/念力/力场/灵气/真元/罡气/剑气等驱动运动时须写可拍介质——禁只写「运功」或只写结果。必写：形态｜轨迹(源→路径→落点)｜作用+反馈｜介质建置承接；形态须落到**粒子**或**流体解算**之一（可叠用）；小规模可同拍，大规模叠六相。通用法攻写其实际介质；仙攻段写灵气/真元/罡气/剑气，禁止把仙攻介质改写成普通光效交差。
- **具象化/规格**：大特效禁高潮只写「能量爆发」。启用即写：触发｜因果可感｜具象形态｜范围(锚ENV边界+未覆盖)｜影响(**具名固定实体**逐项；禁「环境震动」无落点)｜六相`起势→显形→扩散→命中→维持→余波`｜时限。跨拍改结构→`{主}_{状态}`。七-E择1–2+范围/影响各≥1；点状离散介质须含粒子≥1，连续液/气/焰/雾/浆须含流体解算≥1。通用体系优先元素形体/冲击环/波前+粒子或流体；仙攻体系优先化龙凤兽/法相（触发→凝形→落点→作用），介质层仍须粒子或流体可核销。
- **粒子 / 流体解算（强制分型）**：点状离散（火星/尘埃/余烬/灵尘/光点/碎屑）走**粒子**——写出发射源、密度、速度方向、与具名实体碰撞后的碎裂/贴附、沉降消散。连续液/气/焰/雾/浆/能量流体走**流体解算**——写出体积、速度场、与具名实体碰撞后的翻卷/泼溅/浸润/回流、消散。可叠用（火=流体体+粒子火星；剑气=流体刃+拖尾粒子）。禁只写「光芒/气浪」而无粒子或流体形态。
- **人态化特效主体**：凝形成可辨头面/肢体朝向→本节「金身／法相≡角色」+「宿主↔法相同步」。六相过程另写。无定形介质只走六相+实体落点；消散后从终态剔除，并写宿主收摄/解印。通用体系可处理非仙的巨化/机甲展开/能量体，字段与角色同标（定位 XOR｜正背面｜面向｜姿态｜与他者｜视线(有则)｜动作方式），与驱动者同拍写清因果。
- **光效/特效边界**：画外光源可写其在画内的投影/受力/声音；禁写画外本体细节。特效命中陈设须可拍反馈。

### 宏大特效：变化细节 · 满幅可渲染（最高）
> **判定（命中任一）**：域场/结界/天地法阵｜化龙凤兽/法相/巨化｜大范围元素爆发/对撞波前｜云海改写｜宏观灾难/奇观主相位｜标「宏大/全屏/天地/无边际」｜跨≥2 Beat 环境级特效。轻量单点/近身气爆不适用本条硬门槛，仍须六相可核销。
> **目标**：满幅可渲染 + 六相各有可辨变化细节；禁一句「能量爆发铺满天空」。

1. **满幅/全屏可渲染（强制）**：①覆盖层级=`前景介质|中景主体|后景边界/天际/地平` 至少两层同时有可见变化；②边界锚=`ENV 边界/地平线/穹顶/海面/城廓/山脊`（禁无边界「到处都是光」）；③规模词须可拍（无边际满幅｜自锚点向外吞没至边界｜对撞波前横贯画幅），**禁止**只写角色周身光晕却自称宏大。主相位景别意图=Wide/EWS/全景级；可穿插细节特写切口，但**不得用特写替代满幅主相位**。**满幅/快动→局部特写仍须数量速度不塌**（特写可钉一件局部，正文须写同向同质体过幅/前后层密度 + 与满幅同级速率；禁切近后单件慢/停。升格仅 `~`/情节升格）。
2. **分相变化细节（强制；六相各相≥1 可辨增量）**：禁六相复读同一句「光芒更盛」：
   | 相 | 须有的变化细节 |
   | :--- | :--- |
   | 起势 | 源点凝核/纹路或符纹初现/粒子初扰或流体微涌；尺度仍局部 |
   | 显形 | 主体轮廓可读（元素形体/阵纹几何/冲击环/**鳞甲/龙首**/法相肢体）；粒子簇或流体体层次≥1 |
   | 扩散 | 边界外扩轨迹（沿何结构/向何方/吞没哪些区）；粒子密度场或流体速度场变化 |
   | 命中 | 与具名实体/对手/地面的接触瞬间：粒子撞碎/流体泼溅/碎屑/震环/灼裂/倾侧等**逐实体** |
   | 维持 | 稳态动势（旋转/脉动/粒子雨/流体翻涌/云海）+ 未覆盖区仍可见对比 |
   | 余波 | 衰减方向、粒子沉降/流体回落、残留痕迹、实体终态；禁瞬间清空无过程 |
3. **细节密度**：至少 **4 相**各含 ≥2 个可检索细节单元（粒子/流体泼溅/碎屑/边界涟漪/鳞甲生长节段/阵纹节点等）；满幅主相位 + ≥1 细节特写/Insert 再回满幅或余波。细节特写须保级整体数量与速度，禁孤立一件静置。**禁止**空标注凑过程。
4. **实体落点不豁免**：须逐项写清哪些**具名固定实体**受何种可见作用，未影响者保持原态。满幅≠「环境震动」。
5. **禁**：抽象光球高潮｜六相粘贴无增量｜只写结果无过程｜满幅声称但只拍角色半身光效｜用特写冒充宏大主相位｜无细节却标宏大。

## 7. 决战 · 宏观 · 快慢 · 追杀
- **正式决战**：≥10 Beat；对峙→试探→攻防≥4轮→逆转→决胜→收势；阶段内可快链；高成本≥3；**各轮招式须前后因果连续**；**各轮须 OTS／正反覆盖**。术法域场属仙攻则按仙攻增量闭合，本文件仍闭合招间因果与正反覆盖。
- **宏观群体**：`宏观群体=是`→≥6 Beat。三要素：无边际满幅｜阵势威武(前中后满编+真实参差，禁机械同步)｜压迫感。须写可拍规模 + 阵势排布；禁「大军压境」无人数感与队形。结构：全景→阵势→压迫→指挥→对冲→余波。输出【宏观 Beat 规划】。**满幅/快动→局部特写（数量速度不塌）**：宏观整体或快速运动实体（冲锋/齐射/疾驰/穿梭/弹幕）切到盔甲/旌旗/马蹄/箭矢等局部特写时，特写正文仍须写清整体量级（同向同质体过幅/前后层密度）+ 与满幅同级速率；禁切近后变成单件慢/停。❌千骑→一马慢走｜❌万箭→单箭悬浮。
- **打斗快慢**：升格≈30%(25–35%；>40%滥用；<15%且无快连击=失败)；常速≥50%；每场≥1快连击(≥3招具名+攻防，可同拍，禁全升格)；须穿插特写。
  - **§30-A 立体快链**：凡场≥1快连击须≥1 Beat 本模式；动笔前自【主环境】择≥2具名结构。七维最低：①≥2部位+≥3击具名｜②位移≥3次攻守各≥1｜③每招↔挡/闪/拆/反击且招间前因→后果可追｜④≥1上下段｜⑤≥2 ENV结构｜⑥融合≥2层(30-B)｜⑦常速≥50%本链升格≤1。
  - **§30-B 环境融合**（同拍）：起点≥2结构锚+材质/光区一句；每拍≥1 ENV信息；命中有陈设反馈。四层 A结构｜B材质｜C光影｜D动态。禁抠图空白互殴。
- **追杀/穿梭**：连续位移动量（禁结果概括）。节点≥3；≥2 Beat。入缠斗写撞停/下马；须特写。❌一路狂奔/1拍抓到。输出【追杀/穿梭链规划】。命中楼间穿梭/空中追逐/飞行器追逐/车辆追逐时另须该行特征槽全覆盖。
