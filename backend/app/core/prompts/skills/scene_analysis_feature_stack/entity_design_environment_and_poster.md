- **构图与纵深是方法，必须在过程中体现（最高；≠禁写）**：`scene_mood` 的构图倾向（三分/纵深压迫/中心仪式/负空间）与光色纵深（纵深光层、纵深色层、适度景深）**全程要写、全程要看见**，只是**按骨架分层落地**，不得收成一篇单机位作文。落地序：①全局共享先声明全场构图倾向 + 纵深光层/色层（方法总规）；②【四面内容基准】每一向用后景/中景把该方法落到**本向**可见半空间（本向三分落点、本向近中远受光、本向压迫/留白、本向地面与天花/天空入画）；③【四向拼图】每一格继承该向后景/中景，用左右缘 + 上下边界做成**五面围合纵深**（背景+左右+上下均可见；机位后方相对 180° 一面不可见）。缺方法（四面无纵深/构图落点）=失败；有方法但无骨架=同样失败；四宫格只见贴墙背景、地面或天花被裁出=失败。
- **输入内容=正面面对 · 四方基准 · 禁偏斜（最高）**：上游写在某向（0/90/180/270）的内容**即该向镜头所正对、正面面对的背景主景**。主环境设计只以四方正交为基准；禁止 45°/墙角/荷兰角/菱形斜透视等偏斜构图。细则 §2.5.2。**第一刀切割（只切割）**：§B 只截取放大对应宫格并去掉分割线/格标；**禁止**写正对边界、四方正交、适度景深、斜向机位、荷兰角，也禁止写开篇拓扑/门窗柜台楼梯/坡向。衍生的衍生不重切、不复述几何、不画回拼图痕迹。

## 执行顺序
接收上级输出后按序执行；最终只输出模板规定的 JSON。

**最高优先级：`environments` 全量覆盖 IDENT /【主环境】主环境名；禁止为补齐而造衍生行。有「封面海报简报」才写 `posters`。缺主环境即废弃重写。**

- **[Node 1] 项目视觉基线**
  - 读取 `Project Context` / `Global_Style` / 时代地域；统一环境/海报体系，禁止反向题材化。
  - **只读环境规划 IDENT `定位` + `目标` + `情绪表达`**：定位=体量档+气质/类型（番位只进 logic）；目标=本场空镜须达成的叙事/视觉任务（`本场空镜须` + `可见落点`；`服务=`卖点只进 logic）；情绪=主情绪+空镜表达+文学级光色/构图倾向。缺定位标 `upstream_missing_basic_positioning`；缺目标读继承句或标 `upstream_missing_env_goal`；缺情绪读继承句或标 `upstream_missing_scene_mood`。禁止等待或索要场景分析场核。**光学九项（§2.7.0）须先按定位×情绪裁定**，再写光影（§2.7）、色彩（§2.9）、四向构图；**四面须能核销 `env_goal` 可见落点**，不得用 `purpose` 顶替。不得与 `color_spectrum` 主冷暖冲突。**美景×质感同核**：`主情绪=悬疑/压迫/肃杀` 时，空镜须美而不安（过静、负空间、远景不可辨、光色压暗/偏冷），**禁止**无情绪明信片风光或无据满室暖黄喜庆；`主情绪=明媚/温煦` 才可走通透暖调。禁把人名写进空镜。**定位优先尺度、目标优先可见落点、情绪优先光色**：小屋禁扩成豪宅广角；目标点名的半开门/空椅不得蒸发；压迫场禁无据喜庆暖黄——冲突裁决见 §2.7.0。
  - 按 `entity_design_common.md` §1.5 完成色谱推导，再按本文 §2.9 环境化落地（色层须能核销 `scene_mood` 光色倾向 + `basic_positioning` 气质品级）。
  - 先据日夜/内外/气候/季节 + **定位 + `env_goal` 可见落点 + `scene_mood` 光色倾向**按 §2.7.0 定焦段/景深档/三点/光比/色温/柔硬/自然光/实用光，再写光源清单（§2.7）与陈设；这些字段写入**主环境** `generation_prompt_cn`，衍生从截取目标宫格继承，除非 §C 有可见状态 Delta（只写变化；**禁止描述未改实体**；变化实体名须与原名逐字符相同，不得重新取名）。
  - 渲染风格按 `entity_design_common.md` §1.6 三选一：三维→§2.11；二维→§2.12；真人/未声明默认→§2.7–§2.9。
  - `dependency_strategy.logic`「美学参考：」列 2–4 部作品名 + 借用的具体视觉细节；转译后入 `generation_prompt_cn`，禁止作品名原样入生图词；`description_cn` 恒 `""`。
- **[Node 2] 美术深化**：基于上游环境/海报与依赖做空间深化、材质升级、构图/光学转译；按 §2.2.1 **写满四周/地板/天空（或天花）量化细节并预留中区舞台净空**；主/衍生构图须**正对输入该向内容、四方正交、禁偏斜**（§2.5.2）。`scene_mood` 的构图与纵深是**方法**：全局先声明，四面每一向、四宫格每一格都必须写出本向/本格的三分或压迫落点与近中远受光差——**禁止省略**；四宫格每格另须**五面围合**（背景+左右+上下均可见，机位后一面不可见）——**禁止**拍成只见背景墙的扁平贴图；也**禁止**把整份主环境收成一张单镜头 16:9「三分法」空镜来顶替 2×2。不得重定义 Subject 分类或 Clean Plate 归属。**环境 = 纯空镜**：禁写入角色主体、人影、以及「用于某角色做某事」的用途叙事；海报可按依赖整合 CHAR/PROP/ENV。**主环境成稿前先落骨架**：先写出【四面内容基准】四向标题与【四向拼图】四格标题，再往骨架里填构图/纵深/材质；禁止先写一篇电影长镜头再事后补宫格。
- **[Node 3] 数据封装**
  - 清单只读：禁止新增/拆分/合并/重命名；缺口标「上游待补（回流 Stage 2）」。
  - `subject_type = trim + lowercase`；`environment → environments[]`，`cover_poster → posters[]`；单实体单归属。
  - **禁空入库**：每条 `environments[]` / `posters[]` 的 `generation_prompt_cn` 必须非空。主环境族不得整族交空；缺稿须在本份 JSON 重写，禁止用 `""` 占位交差。

## 一、全局约定

### 1.1 命名与底线
- 命名锁 / `subject_no` / Clean Plate / 合规 / 双语字段：见 common。环境名尤须保留 Index 已写定的空格/`_`/角度前缀全串；禁「规范化空格」「补角度后缀」「缩短主环境名」。

### 1.2A 项目语境注入（环境 delta）
通则见 common §1.2A。环境额外强制：⑦日夜/内外/气候/季节须写入**主环境**全局共享段并可画（未明示则合理推断，logic 注明）；**主环境光影规格（§2.7）+ 色彩规格（§2.9）**写在全局共享段（开篇拓扑之后、【四面内容基准】之前）；细节密度：【四面内容基准】每一向的**后景+中景合计 >10**（围合材质主要落在该向后景；地面/天花可写入中景或后景上/下边界，见 §2.2.1）——**四面不写左右缘长文**；**【四向拼图】段禁止重写后景/中景材质明细**，但**必须**为每格写出左右缘查表结果钉句；命中 §2.4.3 顶格场所时围合层取顶格条目且全场色·光·材·细纹超额；衍生只截取已达标的目标宫格，**不另写 >6 条陈设/光色细节**；仅在 §C 写可见状态 Delta。

**开篇句式**：`项目基础定位为{…}，项目全局风格为{…}，年代/时代为{…}，地域/国家为{…}，语言环境为{…}，风格定位为{…}。时段为{…}，内外为{…}，气候为{…}，季节为{…}。` + 风格定位 2–4 条可视化落点。

- `anchor_description`：逗号连接 3–5 个英文短语（空间结构/主舞台/材质/固定光源）；禁 JSON 数组、瞬态光影、人物动作。

### 1.3 字段契约（光学/空间权威见 §2.5 / §2.7）
- Clean Plate / 引擎控制符 / `negative_prompt_en` / 合规：见 common；**环境主/衍生 = 纯空镜（最高）**——见 §2.6。
- **无记忆性**：`generation_prompt_cn` 只写画面最终结果，禁推导过程/公式/「对照/继承/同上」。
- **双字段分工**：

| | `description_cn` | `generation_prompt_cn` / `dependency_strategy.logic` |
| :--- | :--- | :--- |
| 可写 | 恒 `""`（禁任何正文） | **主环境 prompt（两段式折中）**：①全局共享（风格/开篇拓扑/光影/色彩/中区）→②【四面内容基准】每向**只写后景+中景**（含细节·材质）→③【四向拼图】**引用**后景/中景 + **查表出句的左右缘钉**（禁过程词「旋转/对照」）。**衍生 prompt**：仅 §B 截取放大 + 可选 §C；不重写。**logic**：360 拓扑、转角对照、美学参考、光学 rationale；衍生 §A 等可括注「不成稿」 |
| 禁写 | 非空字符串 | prompt：拓扑字段、度数公式、继承锚点、跨格对照；**任何人物/用途句**（§2.6） |

- 转译自检：单独复制 `generation_prompt_cn` 应可直接生图；`description_cn` 必须为 `""`。**主环境另须先过骨架锁**：复制全文后应能搜到骨架字面标记；构图/纵深必须出现在全局规格 **以及** 每一向后景/中景（可检索本向近中远或三分/压迫落点）。【四向拼图】画布与每格须可检索 `五面围合`（背景+左右+上下可见；机位后方一面不可见）。每一向须可检索 `本向光变`；不可见灯具/窗洞不得出现在该向正文。若只有一篇「真人实拍 / 电影级8K / 16:9 / 构图采用三分法 / 这是一个…大堂」单镜头空镜、四面标题缺失 = 失败；若骨架齐全但四面只列家具名、无构图/纵深落点 = 同样失败；若四宫格只见背景墙、地面或天花被裁出画幅 = 同样失败。
- **`generation_prompt_cn` 禁空（最高；防整族落空）**：`""` / 缺键 / `null` / `…` / `待补` / `停止成稿` **只允许**出现在 `description_cn` 与 `generation_prompt_en`。主环境与其全部 `{N}度…` / 状态衍生的 `generation_prompt_cn` **必须每条非空**。同一主环境族主+衍生皆空 = 整份失败，须在**本份 JSON 内当场重写**，禁止交空族。上游缺口、数量未闭合、骨架自检未过、`废弃重写` **都不是**把字段留空——缺口只进 `dependency_strategy.logic`，生图词仍须按合同写出可入库文本。

### 1.4 审美基线（环境 delta；通则见 common §1.4）
- 对标电影级空间/海报；禁舞台剧/样板间/廉价缩小感。
- **可简约、禁破旧倾向（强制）**：`generation_prompt_cn` 可写素净、少陈设、留白净空——简单≠破旧。无上游明文破败/灾后/战损等时，**禁止**主动加破烂、残墙剥落、霉渍油污、裂缝狼藉、破烂家具等破旧描写；张力用光色/秩序/空寂，**禁用脏乱破烂代替戏剧性**。
- **环境增量**：无上游明文限制时优先**整洁可读、开阔层次**（豪宅强调挑高（多层）通透；城市偏繁华；自然偏开阔层次；普通空间可简约有序）；服从 common「非必要不设破烂」。
- **非常规设计思路（强制；破千篇一律）**：每场环境须有**可检索的视觉辨识点**——禁默认「绿树+蓝天」「白墙木地板灰家具」万能模板。自然外景见 §2.4.1（须穿插黄/红等非常规植被色）；室内见 §2.4.2（须有非常规材质/色块/陈设节奏）。辨识点写进主辅点缀与四周量化细节，服从上游清单与活动区净空。
- **色彩美观（强制）**：环境画面须**有层次、有色相呼吸、不单调**——主/辅/点缀/过渡四层落地到具名表面与 FG/MG/BG；禁全场灰褐糊成一团、禁只写「冷调/暖调」无具名色；细则 §2.9。
- **光线美观（强制）**：环境画面须**有光向、有体积、有亮暗呼吸、不平板**——三点布光（Key/Fill/可选轮廓）+ 光比 + 色温 + 柔硬 + FG/MG/BG 受光差 + 半影/投影可感；选型须核销 `basic_positioning` 与 `scene_mood`（§2.7.0）；禁均匀平光、禁整室同亮、禁只写「有光/电影感」、禁无定位无情绪的默认三点暖黄；细则 §2.7。
- **四周·地板·天空细节充足（强制）**：四向围合/地面/天空（或室内天顶）须有**量化可核销**的具体描写，保美观真实不单调；**中区舞台净空保留**——细则 §2.2.1。
- **顶格场所超额（强制）**：豪宅/皇宫/高档酒店/宴席/广场、仙境、帮派练武场等命中 §2.4.3 时，颜色·光学·材质·细纹须按该节**顶格条目数**写满（高于 §2.2.1 / §2.7 / §2.9 常规下限）；不达标 = 廉价缩样失败。

## 二、环境专项

### 2.1 基础原则
- **上游绑定**：`topology_top_down_360` / `zero_degree_axis` / `spatial_anchor_head|tail` / `fixed_architecture_and_finish` / `fixed_furniture_and_set_dressing` **只读继承**——禁删改挪动具名实体与拓扑、禁颠倒头尾锚点、禁省略陈设。
- **长轴物理一致性（条形实体统一合同；最高）**：下列对象**同一套**开篇锁轴 + 四格纵深/横跨成稿，禁止各写各的度数端话术：
  1. **中区长条**：长桌/长案/床/沙发等；
  2. **贴墙长条**：柜台/吧台/案台/服务台/贴墙柜等（另锁 `M=所属墙｜F=正面`）；
  3. **楼梯/台阶/坡道展开轴**（另锁 `U=上行｜下口端｜上口端｜基准格=M`）。
  须先据上游裁定长轴（0°–180° 或 90°–270°）与两端具名锚，再按 §2.5.3 可见面表成稿；**前方配套几/矮几随主件四格守恒**（§2.5.2）；楼梯须同时声明 U；**禁止**默认固化一种走向。权威表与 F/U 见 §2.5.3。
- **中区桌形制锁（最高；防「八仙桌」吃掉长轴）**：开篇必须先写 `形制=正方形八仙桌｜长方桌/条案`。
  - **正方形八仙桌**：四边等长；四格桌面剪影都近似等边；**禁止**写短边/长边/纵深拉长/横穿长边。只写「朝{具名锚}的一边」。
  - **长方桌/条案**：必须写 `长:宽≈{≥1.6}:1`（禁约等于 1:1）；长轴 + 两端具名锚。四格是**同一张长方形**随观察轴**剪影倒置**，不是各画一张不同的桌：
    - **纵深格**（看短边）：桌面=纵向长条，横向窄、深度明显长；短边朝镜；配套长凳分列画面左右。
    - **横跨格**（看长边）：桌面=横向长条，左右跨度明显大于前后厚度；长边横贯中景中带；配套长凳分列近景与远景（桌前/桌后）。**禁止**画成与纵深格同比例的正中小方桌，禁止仍向深处延伸的短边桌。
  - ❌ 坏例（用户案）：名写「八仙桌沿0↔180」+ 90°写「横穿可见长边」，生图 0°/180° 桌面向深处拉长，90°/270° 却收成正中近方桌——长短方向没跟着角度变。
  - ✅ 正例：`形制=长方条案（非正方形八仙），长:宽≈2:1，沿0度↔180度；0度端=大门侧、180度端=楼梯侧`。0°/180°=窄端朝镜、桌身向背景锚拉长；90°/270°=同一张桌左右拉满中景、前后只见一条窄台面。英文钉可写入【四向拼图】画布句：`one rectangular table, not square; 0/180=narrow end toward camera, long axis into depth; 90/270=long edge spanning left-right, shallow depth; same aspect ratio inverted by view`。
- **允许美术增补**：见 §2.5；增补不得改拓扑。**分位**：**四面允许加**围合立面陈设/贴墙件；**靠边常用配置允许**（沙发/屏风等靠边，不占表演中央）；**表演中央按剧情需要**——禁止把无上游清单的家具搬进走位中央。以上仅作内部美术裁决，**不得把“分位从简/四面允许加围合/中间按剧情需要/靠边常用配置允许”等元规则写入 `generation_prompt_cn`、`anchor_description`、环境叙述或logic的实例化结果**；成稿必须改写成最终实际存在的具名实体、具体靠向/扇区与具体净空，没有采用某类配置就完全不提。**场头空间位置关系锁定（对齐 Stage 1 / 上游 1i）**：门/窗/主家具/出入口/活动区相对与四向归属只读继承；禁把单门扩成多门、禁把门桌对调或换向；**表演中央禁增补立体障碍**。
- **固定实体零遗漏**：清单内每一实体须进主环境四向 `generation_prompt_cn`；禁止因「次要」省略。**中区地面家具（茶几/矮几/中央桌等）须进每一格的可见子集**——不是「全文出现一次即可」；90/270 格静默消失 = 失败（完全遮挡须显式写遮挡，见 §2.5.2）。**通高须共享外形**：下层与上层实体须在开篇拓扑及可见格**分别具名**；禁止 `二楼同楼下` / 只画一层而让上层「继承」。**二层内部不共享外形**则为独立主环境行（可 `StyleReference` 挂一层主环境作风格参考），禁止把客房/账房家具画进一层大堂四向拼图当「上层」，也禁止用风格依赖省略本块四向。
- 专属字段 + 日夜/内外/气候/季节须写入**主环境** `generation_prompt_cn`；衍生只继承目标宫格，除非 §C 有可见状态 Delta。

### 2.2 舞台与空间实体化
- 围绕上游 `{Stage}` / `activity_space` / `activity_fit`：**环境描述须服务剧情活动空间**——先锁定表演区/动线/站位承载/出入画口的空镜几何，再落固定实体与边界（**分位从简**：四面可补围合；靠边常用配置可有；表演中央只落上游已列剧情必要件），再分层/光照/Delta。核心舞台在中景可读净空。
- **建置剧情空间分析（最高；设计前强制）**：须据 Index `activity_space`/`activity_fit`/`purpose`/`basic_positioning`/固定清单槽位（及注入中若有的 Stage 1 建置/位置规划）分析本场环境与道具的剧情使用——对峙纵深、逃窜动线、入座/上床可达、桌面操作区、出入画口净空——并在四向拼图**预留**这些空间。只转译无人称几何与家具槽位（主位端椅、床头侧、客位端桌面）。**禁止**把角色名/人称/谁坐谁逃写进 `generation_prompt_cn`/`anchor_description`（空镜逻辑）；注入建置含人名时内部理解后剥名再成稿。缺净空而被家具堆满=失败。
- **基本定位尺度闸（读 Index `basic_positioning:`；最高）**：主环境须先吃叙事定位中的**体量档+气质/类型**（如`女主婚前住房，不大，精致小屋`→空间紧凑、精致小屋完成度，**禁止**扩成豪宅/宫殿四向或堆满大件）。**定位同时驱动 §2.7.0 光学选型**（体量→焦段偏置；气质/类型→光质/实用光/照度档），不只锁空间尺度。番位归属（女主/男主/「谁的住房」）只进 `dependency_strategy.logic` 并标「不成稿」，**禁止**写入 `generation_prompt_cn`。衍生行继承所属主环境本句，不另改尺度档。缺键则 logic 标上游缺口，尺度仍须与固定清单密度自洽。
- **环境目标闸（读 Index `env_goal:`；最高）**：主环境须核销本场空镜任务——`本场空镜须` + `可见落点` 转译为无人称空间语，四面/四格须能看见该落点（半开门、空椅、仪式中轴等），**禁止蒸发**。`服务=`卖点名只进 logic。视角衍生写`继承主环境`则跟主环境落点；状态衍生若有目标 Delta 只写变化。**≠** `purpose`（Master/反打观察用途不得顶替目标）。缺键则 logic 标 `upstream_missing_env_goal`，禁臆造卖点。人名/人称禁进成稿。
- **外形四维（环境设计真源）**：Index `style`/`social_status`/`literary_atmosphere`/`purpose` 及 `fixed_*` 外形定语凡已写须转译——风格与氛围进四向拼图可见材质/完成度；场域地位定陈设品级（小康小屋≠王府正堂）；作用/番位只进 logic。禁丢掉「精致/素净/礼制」只堆家具名。
- **软性外形决定因素（读 Index；最高）**：`appearance_cues`/`social_status`/`style`/`purpose` 凡已写须驱动空镜完成度——`精致`→细节精巧控杂、禁扩豪宅；`高贵/华贵`→材质品级与维护度；`素净`→少陈设留白仍可读；特殊用途（礼制正堂/会客）定陈设档。`appearance_cues` 原词须在主环境 `generation_prompt_cn` 可核销（气质/完成度句），禁弱化为「好看」。无该键禁臆造奢华或性感化空间。
- **剧情活动空间明示（最高；主环境 `generation_prompt_cn` 强制）**：上游 `activity_space`（主舞台/表演区｜动线｜站位承载｜出入画口）须在主环境四向拼图中**可核销可见**——用空镜结构语写清「开阔站立净空区」「门→中区可通行通道」「座次区几何」「具名门洞出入净空」等，保证后续剧情有实际可用的活动与调度空间；**禁止**只列家具堆满画面而无表演净空。衍生侧据 `activity_fit` 保证该角背景半空间与纵深可读，且不堵死该角所需动线/对峙纵深。仍守 §2.6 Clean Plate：禁写人名/站姿/对峙情节句，只写空间几何。
- **交通工具内舱空镜（最高；独立主环境 + 按载具类型惯例）**：汽车内/客舱/**任何驾驶舱或操纵舱**（飞机驾驶舱、轮船驾驶台/舰桥、列车司机室、工程机械/航天器驾驶舱等）/轿子/马车厢/船舱/火车车厢须作为**独立主环境**画四向拼图，**禁止**画进舱外环境同一张拼图。出入封闭同场时仓外与仓内各画各的主环境四向拼图。座椅与操纵台几何必须可视化上游惯例：
  - **前向驾驶舱/操纵舱**：0°格正对前窗/挡风/驾驶台或仪表主视面；前向操纵位落在前端并朝0°；后方观察员/机组槽位若有，须位于操纵位的车尾/机尾/舰尾侧。轴向拓扑固定核销为 `后窗/后舱壁→后方槽位→前向操纵位→前窗/驾驶台主视面`，**禁止**把后方槽位画到操纵位与前窗之间。180°格正对后窗/后舱壁。**90°/270°格须横贯全舱，禁止只画半舱**：近镜头侧=该侧门窗框+该侧全部座位侧面；中景=其余座位侧面（驾驶座/副驾/后排各座有则全画）；后景=对侧窗。近镜头侧不得留空或整排省略。
  - **封闭空间相对槽位是建置接口**：空镜设计须为座位、操纵席、舱门侧、过道侧、床位等给出稳定具名槽位。座排从0°前向端往舱尾计数（最前/操纵排=第1排）；每排按面朝0°时的舱体左→右编号，写`本排共M位、左起第K位`，并附靠左/居中/靠右/靠窗/靠过道及与前排槽位左后/正后/右后关系。成稿与logic均须能核销唯一ID `第N排-左起第K/M位-功能名`；K不得重复、总位数闭合。无排式开放舰桥用控制台/操纵区编号与左起位序，禁伪造座排。禁只输出“后排右座”或“前景/画右”。每个衍生角须明确该角可见槽位、不可见槽位与可见面。
  - **舱型差异**：汽车驾驶座在前排；飞机驾驶舱按飞行员/副驾驶操纵席；轮船驾驶台/舰桥按舵轮、主操纵台、观察窗与真实值守槽位；列车司机室按司机台。开放式舰桥/多控制台若各槽位朝向不同，按上游逐槽位呈现，禁止压成汽车式前后排或无据全员同向。
  - **其他座舱**：同向乘员舱座椅靠背朝舱尾、坐面朝前；相对座两排长凳对向；轿子单座正对轿帘；马车先判车型。禁止把轿车后排画成会议对坐、把飞机驾驶舱与客舱合并、把舰桥画成厅堂围坐。
  仍无人称。上游缺座向/操纵位惯例 → logic 标 `upstream_missing_vehicle_cabin_orientation`；舱内被并进舱外 → `upstream_should_split_vehicle_cabin_main_env`，成稿仍按可核销舱型画独立舱。
- **载具/机甲外部本体作为ENV（最高；仅场景尺度）**：Index 行含`exterior_asset_scope:外部场景空间`时，本环境代表甲板、舰体表面、机甲外壳平台、车顶/翼面等可站立走位或战斗的**外部本体空间**，不是舱内，也不是停放载具的机库/道路。须设计完整可辨的宿主外形包络、可活动表面、进出舱口及与`interior_env_refs`对应的门窗/舱口关系；四向及0°轴须与宿主车头/机头/舰艏/机甲正面方向一致。禁止只画一块无宿主归属的平台，禁止把舱内座椅/仪表搬到外壳，禁止同一外部本体又交 PROP 重复出图。若外部本体只是置于另一环境中的可移动整车/整机/整甲，应回流 Stage 2.1 分类为 PROP，不在本 Skill 越权设计。
- **实体落位、进深与背景强锚定（防发飘；条形统一单层成稿）**：世界度数只用于开篇拓扑一次声明（长轴、两端具名锚、所属墙面 M、F/U、下口/上口）。**每格成稿禁止再写「X度端在画面左/右」与同格左右实体双轨复述。** 凡条形实体（中区长桌 **与** 贴墙柜台/楼梯等边上方向性物体）在各格只用与长桌**同一套**画面语言：
  - **纵深格**=`由画面近端向背景{具名端锚}深度延伸`（见短边/端面/迎面）；
  - **横跨格**=`横穿画面，画面左侧朝向{具名左端锚}、画面右侧朝向{具名右端锚}`（见长边/侧立面；楼梯横跨格可加坡向角点锁，但左右端锚句式不得另起一套）；
  - **邻向贴边**=`画面{左|右}缘（贴边窄条｜绝对非背景｜非主景）：仅见{实体}{哪一端}短端面/侧帮一条斜切窄条；peripheral fringe only`（等同长桌只露出一端，**禁止**无端锚的自由「梯帮斜线/柜台侧切」，**禁止**把贴边写成完整正立面/第二背景）。
  禁只写「可见短边/可见长边」无锚；禁 `270度端在画面左侧` 这类度数端标签。
- **出入口可视化**：上游可通行出入口须具名可见（开闭态、开向、门轴侧、把手位、连通、净空）；禁堵死成实墙；出入画口净空须与 `activity_space` 出入项一致。
- **实体间关系**：前后左右上下 + 每层每实体垂直上/中/下；**同向后景 ≥2 具名实体时必须写清彼此左右或上下（可叠用），禁只并列点名**；门窗须写开闭态、内开|外开、门轴侧与把手位（门左|门右 × 上|中|下，把手侧≠门轴侧）；方向性实体具名+朝向+正反面（成稿锚固定实体或相对镜头表述）。**贴墙定向实体**（柜台、吧台、收银台、服务台、案台、神龛、讲台、贴墙柜等）与长桌同锁长轴+两端具名锚，另写 **M｜F**、背面贴靠；坐标绝不代替 F。四格按长轴表写纵深/横跨/贴边端，再按 F 标正面/背面/左侧面/右侧面；禁随画面左右翻面、镜像、换墙或消失。**楼梯/台阶/坡道/扶梯**与长桌同锁展开轴+两端（下口/上口=两端具名），另写 U 与基准格；贴墙时所属格必须有 `背景正对` 整跑基准，禁只写「有楼梯」。
- **细节质感与真实性补充（提升美感）**：不能仅列出干瘪的家具名，必须为每一个具名构件或家具补充**材质、纹理、光泽度或自然使用痕迹**（例如：带有细碎划痕的黑胡桃木桌面、反光的做旧黄铜边框、边缘泛着冷光的钢化玻璃等），以切实提升画面的电影写实质感与美学底蕴。
- **固定实体数量预检（最高；先于美术设计）**：读取 Index `fixed_entity_inventory` / `homogeneous_layout` / `opening_inventory` / `directional_structure_inventory`。任一清单含 `若干|数把|多张|一些|成排|散座`，或同质多件缺总数/分项和/逐具F/顺序，或门窗缺总数/所属扇区/开闭态/开向/门轴/把手位，或窗棂缺**总扇数+每扇横×纵格阵+同墙顺序**，或楼梯缺 M/U/下口/上口/基准格/坡向 → `dependency_strategy.logic` 写 `upstream_missing_env_inventory_quantification:{缺项}:回流 Stage 2.1/1`，**禁止用默认数、常识数、随机数或“若干”写入 `generation_prompt_cn`**。缺数**不等于**停笔留空：仍须输出完整折中两段式骨架 + 已具名且数量已锁的实体；未闭合件数只写具名、不写猜数、不抄模糊量词。该族全部衍生仍须输出非空 §B 截取句。
- **同质多件分边与冗余重复（防遗漏铁律）**：≥2 具椅凳等须写总个数、分边个数、逐具朝向 F、同侧顺序，且强制验算 `总数=分边/分桌/分组之和`；“散座”不是实体清单项，必须展开为具名桌/椅及明确数量。更重要的是：**在描写四向拼图中每格（0°/90°/180°/270°）的具体画面时，必须【冗余地、无死角地】重复交代场内每一具中区地面固定家具的可见面及相对位置，绝不允许在某一个画格里偷懒省略！** 含：全部椅凳（若场内有3把椅子，每格都须先写共有3把，再写各椅在哪、哪一面可见）；**亦含全场仅 1 具的茶几/矮几/中央桌**——禁止只在 0° 格写矮几、90/270 格蒸发。
- **门窗/窗棂阵列成稿（强制）**：全局共享先锁 `门总数`、`窗总数`；【四面内容基准】所属向再逐扇点名并写 `横N列×纵M行` 格阵、各格等宽与否、棂条材质/截面/间距、开闭态、开向、门轴、把手位、同墙从左到右或从下到上顺序。多扇窗须逐扇区分特征并保持总数；邻向左右缘只引用交角最近一扇的框侧沿，禁止把格阵扩成第二扇完整窗。禁裸写「窗棂/雕花窗格/成排窗」而不给数量与阵列。
- **实体配套性（强制）**：上游已写的成套关系（桌↔椅、床↔被枕、壶↔杯盏、**沙发↔茶几/矮几**等）须在描述层**完整可视化**并写明个数/分边；禁只画主件漏配件、禁隐去数量。**配套只可视化已入 Index 的主件配件**；上游无沙发则禁止自拟茶几凑套。**四向每格**：主件（沙发/桌）在该格可见时，配套几/椅须同格交代（完全遮挡则显式「被{主件}遮挡」）。**边界**：仅同 Subject 描述层补可视化；上游清单漏写配套件 → 标「上游待补（回流 Stage 2）」，**禁止**擅自新增 Index 行或伪造未声明实体凑套；禁增补成无关堆砌。
- **活动区净空（最高；禁止在表演中央堆实体；靠边常用配置允许）**：上游 `activity_space` /【活动空间】划定的**主舞台/表演区、动线、站位承载区**为表演净空——**禁止**把沙发/屏风/箱柜等摆进该**表演中央**（对峙/打斗/走位区）。仅允许地毯等贴地层，或上游已列剧情硬核销表演锚。**靠边常用配置允许**：沙发、屏风、边柜及客厅/会客常用配套须**靠边/贴墙**，前方留净空；无该类型依据不加。氛围细节、控杂增补一律落**四面边缘/背景向**（四面**允许加**），不得挤占动线中央。
- **空间均衡**：防过挤（活动区/动线阻塞）；四面偏空可加围合陈设；表演中央偏空=无剧情锚时的正确默认。偏空优先在四面与墙边增常用配置、偏挤则控杂——**细节堆在四周/地面贴层/天顶天空，中区留舞台**（§2.2.1）。
- 构图简洁有序；控杂但不剥离非动线氛围细节。

### 2.2.1 四周·地板·天空细节量化 + 中区舞台预留（强制，美观真实）

> **口诀**：**四周/地板/天空写满可感细节**；**中间预留舞台净空**。细节不足=棚拍空洞；中区堆物=堵戏失败。

**适用范围**：主环境四向拼图每格 `generation_prompt_cn`（衍生截取继承基准，不另造冲突堆砌；`description_cn` 恒 `""`）。服从上游固定清单与实体唯一性；增补只许边缘/背景/贴地层，**禁入活动区**。

#### A. 量化配额（主环境每格 / 全集基准描述均须可核销）

| 区域 | 最低细节条数（可检索短句/短语） | 每条须覆盖的维度（≥3 维，禁空词） | 落点区 |
|------|--------------------------------|-----------------------------------|--------|
| **四周（四向围合）** | **每个方位扇区 ≥4 条**（0°/90°/180°/270° 各自达标；本格「背景」扇区在该格成稿中须写满） | 材质｜纹理/接缝或分格｜色相或光泽｜与邻面交接或收边｜受光/投影响应（五选≥3） | **背景向 + 画面左右贴边窄条**；禁把四周立体物堆进中景表演净空 |
| **地板/地面** | **≥5 条**（四格共享同一地面体系，各格须写本格可见地面句，不得省略） | 材质｜分格/拼花或纹路走向｜色层｜轻微使用痕迹（有节制；无上游破败明文禁写破烂/霉渍/大片裂损）｜反射/粗糙度｜与墙脚/踢脚收边（六选≥3） | **贴地层全场连续**；中区只写贴地，不竖立体物 |
| **天空（外景可见）** | **≥4 条**（主环境四宫格外景：天空/天际**必须入画**，禁止「本格天空不可见」裁掉上边界） | 时段天色｜云量形态或清透｜大气透视/霾｜与地平或建筑天际线交接｜日光/月光方位染色（五选≥3） | **上半幅远景**；不占中区地面 |
| **天顶/天花（室内或有顶）** | **≥3 条**（无天空句时强制以此替代「上边界」） | 材质｜梁架/灯槽/吊顶分格｜色｜可见灯位与照度关系（四选≥3） | **上方围合**；灯具计入光学清单口径 |

**合计自检（每格）**：四周背景扇区细节 ≥4 ＋ 地面可见句 ≥2（指向共享≥5 条体系中的可见子集）＋（天空≥4 或天花≥3）＝该格「围合充足」；再加中景舞台净空句 ≥1。不达标 → 重写该格。  
**顶格场所**：命中 §2.4.3 时，上表四周/地板/天空或天花条目数改用该节「围合层」顶格配额（常规下限作废）。

#### B. 写法要求（具体、充足、不单调）
1. **禁空壳**：禁止只写「地板是木地板」「四周有墙」「天空很蓝」；须落到可拍质感（例：深胡桃人字拼、缝宽约指尖、哑光漆面局部冷窗反光；远空高云丝、近地平微暖雾带）。
2. **四周≠四面同贴图（继承 Stage 1 五区区分）**：0°/90°/180°/270° 各格背景主锚须与上游俯视360该扇区**可辨对应**——不同立面功能/材质主次/开洞/陈设；**原则上不重复或不能完全重复**同名同功能实体集。中景中央=上游「中心」：表演净空、剧情硬核销锚、或**靠边常用配置**（沙发靠墙缘+前方净空；无上游沙发且无客厅/会客类型则禁自拟中央桌）。**四面允许加**贴墙/立面陈设（含靠边屏风）使该向可辨；有戏表演中央不加件；无戏四面亦须写满可辨立面，**禁敷衍空墙/抄邻向**。仍守对向不串写与邻向贴边窄条规则。
3. **地板服务舞台（地面必写）**：每格须有可见地面句；中区地面写清开阔可贴地区域（材质连续、无障碍）；装饰拼花/地毯边/地灯嵌条优先落**边缘环带**，禁在表演净空中央堆立体陈设。
4. **天空/天顶定气场（空中或屋顶必写；四宫格上边界必须入画）**：外景用天空层次破「棚拍灰顶」；室内用天花/梁架/主灯分格破「白板顶」；与 §2.7/§2.9 光色联动。**主环境四宫格禁止**用「本格天空/天花不可见」把上边界裁出画幅——室内每格天花入画，外景每格天空入画，无顶外廊/檐下以上沿（檐口/梁底/树冠）入画替代天花。衍生截取继承基准格，不另裁。
5. **增补优先序**：四周立面细节与贴墙陈设（四面**允许加**；靠边屏风/边柜允许） → 地面贴层 → 天空/天花 → 边缘点缀；**最后**才考虑中景剧情硬核销家具（仅上游已列）——且不得挤占 `activity_space`。**分位从简**：禁为凑配额把沙发/屏风搬进**表演中央**；靠边常用配置不在此禁。

#### C. 中区舞台预留（与活动区净空同级）
1. **中景中央**：显式写出「主舞台/表演净空」空镜几何（约画面中下部至中景纵深的可站立·可走动开阔区）；**禁**为凑细节配额向该区堆家具/盆景/立柱/箱柜。
2. **配额与净空不冲突**：四周/地板/天空的细节条数靠**围合面与贴地层**完成，不靠中区加立体物凑数。
3. **硬核销家具**（对白桌/座次椅等）仅上游已列者可留中区，须同时写清其周围剩余净空与动线宽度感（空镜几何，不写人物）。
4. **自检**：若去掉中区所有非硬核销立体物后，四周+地板+天空细节仍达标且中区仍显开阔可调度 → 通过；中区一堆杂物才「看起来满」→ 失败。

#### D. 成稿锚点（嵌入四向格）
每格须能检索到类似结构（语序可融叙述，信息不可缺）：  
`背景（输入该向内容=正面面对的四周主立面细节×≥4维落地；四方正交，禁偏斜/墙角）…｜中景-舞台净空={开阔贴地可站区/动线}…｜中景-中央家具（沙发/桌/茶几/矮几，本格可见则全员具名，禁只写主件漏配套几）…｜地面={可见贴层细节；下边界必须入画}…｜天空或天花={上边界细节；必须入画}…｜左右邻向立面仅贴边斜切（左右两面必须可见）…｜五面围合={背景+左+右+上+下均可见；机位后方一面不可见}…｜光照…`

### 2.2.2 环境载体可见文字（强制；牌匾/招牌灯/书/纸等）

> 通则见 common §1.2「载体可见文字」。本节规定 ENV 空镜陈设落地口径。

**适用范围**：留在 ENV 的固定/氛围文字载体——牌匾、匾额、店招、**招牌灯**、门牌、路牌、横幅、霓虹、灯箱、电子屏固定文案、书架上的书册/卷轴、案几告示纸笺、贴墙文书/菜单/铭牌、符箓等（XOR 已升格为 PROP 的可移动书/纸走 prop 文件，规则同四项）。

**成稿四项（缺一失败；须进主环境四向/`generation_prompt_cn` 可见格）**：
1. **文字内容**：逐字写出画面应读到的文案；上游有 `visible_text`→透传；无→剧情补字并标「原文未明示；根据剧情补写」。禁只写「牌匾/古书/纸张」而无字。远景可缩小字号但仍须声明全文或主标题字；特写可读区不得用「模糊字」搪塞（上游明文污损除外）。
2. **排向（横排｜纵排；招牌灯/牌匾最高）**：显式写 `横排` 或 `纵排`（混排须核销）。横匾/横幅灯箱/横招霓虹→横排；竖匾/竖招/对联→纵排；无上游亦须按形制裁定并写出。禁「牌上写着…」不标排向。
3. **字体/书体（含颜色）**：楷/隶/行/魏碑/篆/宋/黑/仿宋/手写/招牌美术字等 + 工艺（阴刻鎏金/墨书/木版印刷/烫金/灯箱贴字/霓虹弯管等）+ **字色** + **底色/匾地/灯箱面板色**。**招牌灯/霓虹/灯箱另须写发光色**（灯管/LED/透光字色相）。匹配时代地域与机构礼仪；禁只写书体无字色，禁只写「红字金字」无书体。
4. **中文繁简体**：显式写 `简体` 或 `繁体`（或有核销的混排），且字形与裁定一致；上游原文繁/简体系不得擅自互转；无原文时按地域/时代默认（古装碑匾书卷常繁体；大陆当代室内标识常简体）。

**落位与 Clean Plate**：文字写在具名载体上（挂哪面墙/哪格背景/案几哪侧）；禁把文字当漂浮字幕；禁为人名/对白服务的用途句（仍守 §2.6）。多册书脊/多页纸若朝向镜头可读→逐具或按「可见主标题+其余同体系书脊」写清排向与字色，不得整排无字色块冒充藏书。

**四向拼图 / 广角空镜可读性门禁（最高；防为字造第二柜面）**：
1. **分层**：`visible_text` 四项仍须写入 Index / `entity_attributes`（及升格 PROP）；**不等于**一律塞进主环境四向拼图 `generation_prompt_cn`。
2. **何时可写逐字**：仅当该文字载体是**本格背景主景或近景特写可读面**（如牌匾挂在本格正对墙、门楣匾、近景摊开书页占画幅主要可读区）。
3. **何时禁写逐字（四向拼图高频）**：载体只是中远景柜面/桌面小物件（账本、算盘旁纸页、柜上菜单条等），约 50mm 眼高广角下本不可辨读 → 生图只写「柜面置摊开账本与算盘轮廓，**字迹不可辨读**」；**禁止**写具体文句、排向细规、繁简字形。
4. **禁果**：为迁就可读字另造前景第二张桌/第二层柜面/镜头前托台 = 失败。❌ 坏例（用户案）：180° 格已写「背景正对红木长柜台」，又写柜面账本逐字「天宝三载…」→ 模型另推一张前景桌面托账本，形成双柜面。
5. **特写出口**：须可读流水账等细字 → 另开 PROP/Insert/`{N}度` 特写衍生或后制裁切近景，勿在四向基准广角格硬塞。

**自检**：任一 ENV 文字载体在 Index 缺内容/排向/字体色（字色+底色；招牌灯缺发光色）/繁简标注，或文案繁简与标注冲突 → 废弃重写该环境条；四向拼图广角格对中远景小物件写了逐字文案或出现双柜面/前景托台 = 失败。

### 2.3 光学与美学（执行入口）
先日夜/内外/气候/季节 + **Index `basic_positioning`（定位）+ `env_goal`（目标/可见落点）+ `scene_mood`（情绪表达）** → 按 §2.7.0 裁定曝光三角 / 景深控制 / 焦段选择 / 三点布光 / 光比 / 色温 / 柔硬 / 自然光 / 实用光 → §2.7 光源清单与光影规格 → 各层受光/投影 → 色彩（§2.9）→ 陈设（须能核销 `env_goal` 可见落点）。默认照度充足、主舞台可读、**光影有层次不平板**；上述光学项**禁止**套默认模板（禁一律 50mm 平光暖黄、禁无定位无情绪的三点布光套路）。城市/自然执行落点服从 §1.4。礼制空间写中轴/座次/门窗尺度。**真人写实门禁**（仅 §1.6 判真人）：真实可拍场地、生活痕迹；三维/二维改 §2.11/§2.12。

### 2.4 仙侠/东方幻想（题材增量）
可用悬空/云上/非现实比例等，主体清楚重心稳。色可用月白-青碧/冷金等；禁无依据退水墨（除非上游明确）。祥瑞异观写景别/尺度/受光，不抢主舞台。光学仍走 §2.7 清单口径。**仙境/仙府/云上宫阙/灵山琼台等**另命中 §2.4.3 顶格超额——禁「月白青碧」标签一句带过而无顶格色/光/材/纹条目。

### 2.4.1 自然风景/山景（题材增量 · 非常规色相强制）
山景/自然空镜须有**鲜明辨识点**：季节与生态层次（植被色相、远近层次、可选水体）+ **非常规色穿插**，避免棚拍单调与「千篇一律绿蓝」。

**禁绿蓝万能模板（最高）**：
1. **禁止**默认成稿 = 满屏翠绿植被 + 纯蓝天空，仅靠明度差凑层次。
2. **禁止**所有自然场共用同一「青翠山林 / 碧空」色卡；每场须写出**本场独有**的植被/地表/天空色组合（可检索具名色，非「绿色树林」）。
3. 绿/蓝可作辅色或远景雾气层，但**不得**同时垄断主色+辅色+天空三层。

**黄/红等非常规穿插（强制；无上游题材硬禁时）**：
1. 在已有植被/地表/岩土/枯枝/花丛等可转译落点上，**至少嵌入 2 处**黄系或红系（及近邻：琥珀/赭石/锈橙/绛紫叶/金黄草甸等）可见色块——例：金黄阔叶或枯枝梢、朱红/琥珀花簇、赭红岩壁、锈褐地表带、夕照染黄远树冠等。
2. 落点须写**物体+部位+面积感+距离层**（如「中景边缘金黄灌丛冠缘」「背景右贴边赭红岩面」）；总提神面积宜约占植被可见面 **15%–30%**，禁零星看不见的「一点红」。
3. **优先转译**上游固定清单/季节已写植被与地表；清单无具体色时，美术层可对已列植被/地表做非常规色相深化（仍同一实体，不新增 Index 行）。禁止无据另造「瀑布/巨型枫林」等清单外主体抢戏；缺口实体回流 Stage 2。
4. 仙侠/东方幻想可叠加冷金/赤霞/朱砂雾带，仍须满足黄红穿插可核销，禁退回一律青绿仙山。

**空间量化**：天空与地表须按 §2.2.1 写满（仙境级自然外景另加 §2.4.3 顶格）；中区仍留可调度开阔地；服从实体唯一性与活动区净空。

### 2.4.2 室内环境非常规设计（强制 · 破样板间）
室内/有顶空间须有**非常规设计思路**，避免「白墙+木地板+灰沙发+一盏顶灯」万能样板间。

**强制辨识点（每场室内主环境至少 2 项可核销，落边缘/背景/贴地层，禁入活动区立体堆物）**：
1. **非常规色块墙面或立面节奏**：非默认全白/全灰——如局部漆色墙段、异色踢脚带、半墙异材、色块壁龛、暖赭/墨绿/靛蓝立面条带等（服从时代地域与 `color_spectrum`）。
2. **非常规材质对撞**：至少一组可辨对撞（例：粗石灰墙×抛光铜、旧红砖×玻璃、深色丝绒帘×冷石地、竹编×金属边框）；禁全场同一哑光木色糊成一片。
3. **非常规陈设/天顶节奏**：非对称挂饰、异形灯槽、可见梁架染色、地面拼花边环、窗纱染色渗光等——写清位置与色，服务 §2.9 点缀，不堵动线。
4. **光色非常规**：Key/Fill 冷暖落在不同具名表面（例：冷窗渗光×暖灯罩芯、琥珀台灯×青灰墙），禁「一律暖黄室内灯」无辅色。

**边界**：不改上游拓扑/具名实体/头尾锚；增补不得扩成多门多窗；辨识点优先挂已有墙/地/天花/清单家具的材质与色，而非凭空新增 Index 道具。礼制/宫廷空间的非常规落在材质层次与冷暖对撞，禁毁中轴秩序。命中 §2.4.3 时辨识点与顶格条目叠加，取更严配额。

### 2.4.3 顶格场所细节超额（豪宅·仙境·练武场等 · 强制）

> **口诀**：命中顶格场所 → 颜色/光学/材质/细纹**全部按顶格条目数写满**；常规 §2.2.1 / §2.7 / §2.9 下限不够。欠条 = 廉价缩小样板失败。

#### A. 触发判定（命中任一即强制顶格；logic 标 `detail_tier=ceiling`）

| 类 | 典型场所（含同义/近义；非穷尽） |
|----|--------------------------------|
| **豪宅礼制与高规格公共** | 皇宫/王宫/殿宇/御花园；高档酒店/酒店大堂/总统套房；宴席/宴会厅/酒宴；广场/仪仗广场/宫前广场；豪宅/别墅大厅/会客厅；礼堂/金厅/大理石厅；赌场贵宾厅等「金碧/挑高/礼仪」空间 |

**边界**：普通民居/街边小店/简陋仓库等**不**触发；不确定但名称或上游氛围含「豪华/金碧/仙府/演武」→ 按顶格执行。衍生截取继承主环境顶格质感，§B 不重写长文；§C 状态 Delta 不得把顶格材质糊成脏乱除非上游状态明文。

相对常规下限的**超额**如下（取顶格列；四向每格围合层各自达标；色彩/光学/材质/细纹为全场共享规格一次声明 + 各格可见落点）：

| **光学·材质响应** | ≥2 具名表面 | **≥5** | 高光/哑光/透射/湿反射/漫反射等具体响应 | 绑具名表面 |

**仙境外加强制**：非人间辨识点 ≥2（悬空结构/云海阶/异相天色/冷金霞雾等）+ 祥瑞异观若有则写尺度与受光，不抢中区舞台。  
**练武场额外强制**：训练功能可读空镜 ≥3（擂台/桩位/兵器架/砂土或青砖场地分界等，上游有则转译）+ 至少 **2** 处使用痕迹细纹（踩踏砂纹、木桩砍痕、兵器架磨亮边——有节制，禁脏乱替戏剧性）。

#### C. 写法与禁项
1. **顶格≠堆中区**：超额条目仍落四周/地面贴层/天顶天空/边缘；活动区净空不豁免（§2.2）。
2. **禁标签凑数**：「金碧辉煌」「仙气飘飘」「杀气腾腾」无具名表面/纹样/光效 = 失败。
3. **禁缩样**：皇宫写成普通客厅白墙、仙境写成普通青山绿水万能模板、练武场写成空院无纹无痕 = 失败。
4. **与 §2.4.1/§2.4.2 叠加**：自然仙境外景仍须黄/红等穿插（若适用）；室内豪宅/仙府仍须 ≥2 非常规辨识点，且条目数取更严的顶格列。
5. **自检**：`detail_tier=ceiling` 时，删「豪华/仙气/霸气」后能否数出上表各维条目？任一维欠条 → 重写。

### 2.5 主环境四向拼图、衍生与正反逻辑（空间权威）

#### 2.5.1 分层与依赖
- **主环境（成稿两段式折中；最高）**：`description_cn=""`；`dependency_strategy.logic` = 俯视 360 + 0 度轴（仰视可选）+ 美学参考；`generation_prompt_cn` **必须**按 §2.5.3：①**全局共享**（风格 + 开篇拓扑 + 光影 + 色彩 + 中区）→②**【四面内容基准】**每向**只写后景+中景**（细节·材质·中区投影——后景/中景文字真源）→③**【四向拼图】**每格 = **引用**该向后景+中景 + **查表出句的左右缘钉**（禁「由邻面旋转/对照」过程词；禁在③重写后景/中景材质长文）；画布=**一张** 16:9 **2×2 四宫格**（左上0/右上90/右下180/左下270；顺时针 0→90→180→270），**不是**一张单镜头 16:9 可拍空镜；各格正对输入该向内容，四方正交，禁偏斜；默认 `visual_dependencies=[]` + `BaselineDefinition`；有 `style_reference_env` 则 `visual_dependencies=["ENV:[风格父主环境名]"]` + `StyleReference`（仍独立写满四向，只对齐风格）；禁作 Beat ENV。
- **单镜头坍塌一票否决（最高；用户案）**：主环境若写成「真人实拍，电影级8K，16:9画幅。这是一个…大堂…构图采用三分法…纵深光层：前景=大门…中景=八仙桌…背景=二楼走廊与承重柱」这类**单机位电影空镜**，即框架破裂——失败点是**用一篇构图/纵深顶替四向拆分**，不是构图/纵深本身。门/窗/桌/柱/楼梯被塞进同一构图 = 把四向压成一镜。正确做法：全局仍写构图倾向+纵深光层/色层；门的三分/纵深落在【0度方向】后景/中景；窗/梯落在所属向；柱/桌按扇区各写本向近中远；【四向拼图】四格引用并靠左右缘+上下边界完成五面围合纵深。衍生若抛开 §B 截取句、另写一篇单镜头空镜，同样失败。
- **第一刀视角衍生（含 `0度` Master）**：`generation_prompt_cn` = **只截取放大**对应宫格（见 §2.5.4–§2.5.5），**不写**正对边界/四方正交/景深/斜向机位/荷兰角，**不重写陈设、不写楼底/坡向**；成稿=单张完整镜头，**禁止保留**四向拼图分割线、格标、宫格边框或拼缝。`visual_dependencies=["ENV:[所属主环境名]"]`。
- **衍生的衍生（同角再衍生）**：在**已切割的同角衍生图**上叠加状态 Delta（光色/氛围，或已有具名实体的形状变化）；`visual_dependencies=["ENV:[同角已切割衍生名]"]`（N 必须与本行一致）。§B 不重切四向拼图宫格。§C **禁止描述未改实体**；变化实体名须与原清单**逐字符相同**，不得重新取名。`description_cn=""`；元数据 + §C → `dependency_strategy.logic`。
- **全局楼底只在主环境写一次**：开篇拓扑 / 门窗柜梯 / 坡向锁只出现在主环境 `generation_prompt_cn`。衍生切割**不再复述、不再核对这些句**——宫格里已有什么就放大什么。

#### 2.5.2 坐标系硬规则
- **方位坐标约定（全链路最高；与 Stage 1 / 2.1 同核）**：一律**俯视鸟瞰顺时针**。主环境 **0°轴** = Stage 1 首个非航拍全局建置视角的背景方位（非真北）。正交四向闭集=`0/90/180/270`；从 0° 起强制：`0° →(+90°)→ 90° →(+90°)→ 180° →(+90°)→ 270° →(+90°)→ 0°`；下一正交角=`(N+90)%360`；对向=`(N+180)%360`。**禁止**逆时针编号、按行优先写成 `0→90→270→180`、第一人称「向左/右转」推角、为「更好看」把上游 90°/270° 对调。四向拼图宫格按**顺时针递增**锁位：`0°=左上`、`90°=右上`、`180°=右下`、`270°=左下`（成稿序=`[0度格-左上]`→`[90度格-右上]`→`[180度格-右下]`→`[270度格-左下]`）。2×2 排版仍不等于俯视平面图位置；扇区内容按顺时针度数锁，不得因宫格排版而改写世界角。
- **0°** = Viewing Direction（该观察轴下背景半空间）；**N 度格** = 摄影机**朝向** N° 方位实体（该实体在背景）；机位在 `(N+180)°` 侧。**禁止**理解为「站在 N° 向外看」。
- **顺时针** = 俯视鸟瞰口径（上条）；禁第一人称「向左/右转」推角。
- **四向正面边界锚定（最高；输入内容=正面面对；四方基准；禁偏斜）**：主环境四向拼图各格一律以**四方（0°/90°/180°/270° 正交四壁/四边界）为设计基准**。
  1. **输入内容即本向正面面对（强制）**：上游（Stage 1 俯视360/四向+中心、Index `topology_top_down_360`、固定清单、头尾锚、衍生 `empty_view_delta`/`activity_fit`）写在某向的内容，**就是该向镜头所正对、正面面对的内容**——须落在该格/该 `{N}度` 衍生的**背景主位**，以**完整正立面**朝向本格 Viewing Direction（门扇正面、窗框正面、柜体正面、街口开口面、主墙立面等居中或居背景主位）。禁止把输入该向内容挪到画面斜侧、墙角，或写成邻向贴边冒充主景。
  2. **正对四周边界**：背景主景须为正对门、正对窗、正对家具主立面/端面、正对街口/巷口/廊口等；立面横平竖直，与画幅上下沿/左右沿正交对齐。
  3. **禁止偏斜设计（最高）**：禁 45°/对角看墙角、禁荷兰角/斜倾地平、禁以房间一角为画面中心的菱形/斜透视构图、禁把本向主锚写成 ¾ 斜对或斜切主景、禁为「透视更好看」把四壁转成菱形。邻向仅许贴边窄条（见下条），**不得**用邻向斜切冒充本格背景主景，亦不得因此把本格写成偏斜机位。
  4. **第一刀只切割**：`{N}度` 截取主环境 N° 宫格放大；§B **禁止**写正对边界、四方正交、适度景深、斜向机位、荷兰角，也禁止写开篇拓扑/门窗柜台楼梯/坡向。宫格陈设已定稿，放大即可。**成稿禁止保留四向拼图分割线、格标、宫格边框或拼缝**。衍生的衍生不重切、不复述本条、不画回拼图痕迹。
  例外仅限上游 Stage 1 明文斜向几何，或开阔无立面时改以道路中轴/地标轴线**正对**（仍禁荷兰角与无据墙角构图）。偏斜导致背景主景面不可读、邻向误成主景、截取放大后主锚丢失。
- **画面左** = `(N+270)%360`；**画面右** = `(N+90)%360`（摄影机自身左右；仍按俯视顺时针推算）。实体自身左/右侧面按正面 F 定义，**不得**直接等同画面左/右。
- **邻缘扇区方向硬锁（禁左右对调；180° 高频钉死）**：画面左缘只能挂 `(N+270)%360` 扇区交角处内容；画面右缘只能挂 `(N+90)%360` 扇区交角处内容——**禁止**把左缘实体画到右缘。成稿前用「四格左右速查表」核对扇区方向。
  - **180° 格强制验算（最高；用户案硬伤）**：`画左=(180+270)%360=90°`，`画右=(180+90)%360=270°`。开篇若楼梯/窗在 90° 侧、散座/酒桌在 270° 侧，则：
    - **左缘**只能挂 90° 交角最近件（窗侧沿，或无窗时的楼梯上口端侧面）；
    - **右缘**只能挂 270° 交角最近件（散座/酒桌短端面）；
    - 柜台横跨两端亦同：`画面左侧朝向{90°侧具名锚}、画面右侧朝向{270°侧具名锚}`。
  - ❌ **一票否决**：180° 写成「左缘=散座/酒桌、右缘=楼梯」（或柜台「左侧朝向散座侧、右侧朝向楼梯侧」）= **扇区对调失败**，整张四向拼图废弃重写。
  - ✅ 正例：180° `画面左缘…窗格/90°侧…；画面右缘…散座短端面…`；柜台 `左侧朝向楼梯/窗格侧、右侧朝向散座侧`。
- **0° 楼梯缘可见面硬锁（最高；缺词即失败；先裁定该端是下口还是上口）**：0° 哪一缘挂楼梯、挂的是哪一端，**必须跟 U 与所属墙 M**，禁止默认「0° 右缘=下口」。
  - **U=180 且梯贴 90°**：0° **右缘**=**下口端**侧面（近背景大门侧=低端，梯帮向近镜头升高）。
  - **U=0 且梯贴 270°（用户客栈案）**：0° **左缘**=**上口端**侧面（近背景柜台侧=高端平台，梯帮向近镜头降低通向门外下口）。**禁止**把柜台交角画成下口/最低踏步；**禁止**因 U=0 在 0° 格画迎面拾级。
  成稿**必须同时出现**下列两类钉（缺任一 = 失败，不得只写「梯帮窄条」）：
  1. **可见面钉**：`可见面=侧边` 或 `{下口|上口}端侧面/短端面`（与上条裁定的那一端一致）；
  2. **禁迎面钉**：`禁止迎面踏步` / `禁止踢面层层` / `forbid frontal stair treads`（至少一句）。
  - 另须带端锚与近远高低（与基准坡向同核）。
  - ❌ 只写「楼梯梯帮一条斜切窄条」无可见面钉+禁迎面钉 → 失败（生图常画成迎面拾级）。
  - ❌ 0° 格任何位置出现迎面踏步/层层踢面楼梯主体 → 失败。
  - ❌ U=0/贴270° 却在 0° 左缘写「下口端」或画出贴地最低踏步 → 走向对倒失败。
  - ✅ U=180/贴90°：`仅见楼梯大门侧（下口端）侧面/短端面一条斜切窄条；可见面=侧边；禁止迎面踏步与踢面；side edge only; forbid frontal stair treads`。
  - ✅ U=0/贴270°：`仅见楼梯柜台侧（上口端）侧面/短端面一条斜切窄条；可见面=侧边；近背景柜台侧=上口高端；梯帮向近镜头降低；禁止迎面踏步与踢面；forbid frontal stair treads`。
- **楼梯单跑跨格同核（最高；禁短 stub、禁双段；用户案硬伤）**：全场声明 `仅1跑` 后，**基准格=M（所属墙那一格，不一定是 90°）**的完整侧立面 = 唯一长度/级数真源；邻向 0°/180° 缘**不是**另一截楼梯，只是同一跑的端头切片。
  1. **下口邻缘**：只露下口端侧面窄条，须写 `同一跑下口端切片｜向上延续出画外与基准格整跑同核｜forbid short stub staircase`。U=180/贴90° → 常在 0° 右缘；U=0/贴270° → 常在 180° 右缘。
  2. **上口邻缘**：只露**一条连续**上口端侧面/梯帮窄条，须写 `同一跑上口端切片｜单条连续梯帮｜forbid double-segment stairs / second flight`。U=180/贴90° → 仅当 180° 左缘交角最近确为上口；U=0/贴270° → 常在 0° 左缘。
  3. **禁止**：邻缘再画完整侧立面、再起一段从地到顶的短梯、把回廊踏步与主跑画成两跑；**禁止**把上口端画成贴地起步的下口。
  4. ✅ U=180/贴90°：0° 下口切片 + 180° 上口单条连续。✅ U=0/贴270°：0° 左缘上口高端切片 + 180° 右缘下口低端切片。
- **条形两端命名须跟长轴（最高；禁错用正交度数）**：实体长轴若为 `90↔270`，两端只能写 `90度端｜270度端`（或具名：楼梯侧｜散座侧）；**禁止**写成 `0度端｜180度端`。长轴若为 `0↔180`，两端只能写 `0度端｜180度端`。❌ 坏例（用户案）：`柜台沿90↔270…，0度端=木墙侧、180度端=楼梯侧`（端锚度数与长轴正交对调）→ 后续各格左右必乱。
- **同场条形左右须共核**：柜台与近门方桌若同为 `90↔270` 长轴，则在同一观察格内「画面左侧朝向 / 右侧朝向」的两端具名锚**必须同向**（180° 格二者皆为左=90°楼梯侧、右=270°木墙侧）。❌ 柜台左楼梯右木墙、方桌却左木墙右楼梯 = 失败。
- **四格可见面必填（最高；楼梯/柜台/门/长条均适用）**：凡方向性实体（楼梯/台阶/坡道、贴墙柜台/吧台、门扇、长桌/床/沙发等），写入任一格（含 `背景正对` 与左右缘）时，**必须显式点名本格看到的是哪一面**——闭集：`正面｜背面｜左侧面｜右侧面｜短端面/端侧面`（楼梯另可用 `侧立面｜下口端侧面｜上口端侧面`）。**禁止**只写实体名不写可见面。查 §2.5.3 F/U 与长轴表后成稿；四面各自不同面时须四格分别写清，不得抄同一句到四格。
  1. **楼梯高频（贴90°墙、U=180、下口=大门侧）**：
     | 格 | 楼梯落位 | 本格可见面（强制写进成稿） |
     | :--- | :--- | :--- |
     | **90°**（基准） | `背景正对` 整跑 | **完整侧立面**（梯帮+踏步侧剖）；禁迎面拾级 |
     | **0°** | 仅右缘交角最近时 | **下口端侧面/短端面**（只见梯帮侧边一条）；**禁止迎面踏步/踢面层层** |
     | **180°** | 仅当交角最近确为上口且无更近窗时 | **上口端侧面/短端面**；禁整跑、禁迎面 |
     | **270°** | 通常不可见（90°=机位后方） | **禁止出现楼梯** |
  2. ❌ 坏例（用户案）：0° 右缘只写「楼梯…梯帮窄条」却未锁「可见面=下口端侧面｜禁迎面」→ 生图常在 0° 画出迎面拾级；或 90° 画布首句写成「背景:右侧楼梯」（把本格主景误标成「右侧」）。
  3. ✅ 正例：0° `画面右缘…仅见楼梯大门侧（下口端）侧面/短端面一条斜切窄条；可见面=侧边；禁止迎面踏步与踢面；side edge only; forbid frontal stair treads`。
  1b. **楼梯高频（贴270°墙、U=0、下口=正门侧、上口=柜台侧）**：
     | 格 | 楼梯落位 | 本格可见面（强制写进成稿） |
     | :--- | :--- | :--- |
     | **270°**（基准） | `背景正对` 整跑 | **完整侧立面**；`/`；左下=正门下口、右上=柜台上口；禁迎面拾级 |
     | **0°** | 仅左缘交角最近时 | **上口端侧面/短端面**（近背景柜台侧=高端）；**禁止迎面踏步**；禁画成下口贴地起步 |
     | **180°** | 仅右缘交角最近时 | **下口端侧面/短端面**（近背景正门侧=低端）；禁整跑、禁迎面 |
     | **90°** | 通常不可见（270°=机位后方） | **禁止出现楼梯** |
  4. **柜台/门同锁**：柜台完整正面只在所属墙那一格；邻向缘上=`柜台短端面`（禁完整正面）；正门完整正面只在 180°（若门贴180°）；邻格缘=`门框侧沿`（禁第二扇完整门）。
- **邻缘只挂交角最近件（最高；禁把邻墙全员塞进左右缘）**：左右缘**不是**「邻向墙上所有实体清单」。非本格正面时，每侧缘最多挂 **1** 个（或同一件的一个短端面）——取「本格背景墙 × 该侧邻墙」**交角处空间上最近、透视最先入画**的那一件；同墙其余实体留在其所属格 `背景正对`，**禁止**为凑齐全员而往非正面格硬塞。
  1. **算法**：①查本格背景墙两端各接哪条邻墙；②在该邻墙上，取靠近本格背景端锚的那一件（或该件朝向交角的端面）；③写入对应左/右缘窄条。远处/墙中段实体不入本格缘。
  2. **同墙多实体（客栈高频）**：90° 墙若 `画面左至中=楼梯、画面右=窗格`（窗靠近柜台/180° 端）——则 **0° 格右缘**只挂楼梯**下口端**（近大门交角）；**180° 格左缘**只挂**窗格侧沿/窗旁墙段**（近柜台交角），**禁止**在 180° 左缘再塞楼梯上口或整跑梯帮。❌「邻向=90° 就把楼梯+窗全写进 180° 左缘」或「凡 M=90 楼梯必出现在所有看见 90° 的缘上」= 失败（用户案）。
  3. **柜台两端同理**：180° 看柜台时，左端锚=靠 90° 交角（近窗侧）、右端锚=靠 270° 交角（近酒桌侧）；左缘优先窗/墙段窄条，右缘优先酒桌短端面——不要把整跑楼梯因「也在 90° 墙」硬挂左缘。
  4. **可省略**：某侧交角无可辨实体或被柱完全挡，可写「邻向墙段贴边斜切」而不点名远墙实体；**禁止**为「左右两侧都要有东西」从邻墙远端拉件。
- **前景/中景/背景**：一律以本格/本镜 Viewing Direction 看——近=前景，远=背景。**扇区≠景深**：仅速查表「背景」列可入本格背景；机位后方禁入背景。
- **严禁对向串写**：0°↔180°、90°↔270° 互不点名对面**扇区立面**实体（门/窗/挂画/贴墙柜/廊口等）；禁「不可见{对向实体}（机位后方）」。**本条不适用于中区地面家具**（茶几/矮几/中央桌/沙发等属【中心】，见下「中区地面固定家具 ≠ 邻向立面」）。
- **可见面→对应衍生环境锚点（最高；生成环境资产强制）**：按 §2.5.3 可见面表判定后——
  1. **可见面必须写入对应衍生锚点**：观察轴=`N` 的 `{N}度…` 衍生（含 `0度` Master）——该视角下**可读**的实体面（正面/背面/左|右侧面/短边|长边可见态、门扇可见面、柜体可见立面等）须落入**该衍生**的 `anchor_description`（英文短语）、§A 参考定位、以及 `dependency_strategy.logic` 中本镜背景/头尾可见锚说明；主环境四向拼图的 `N` 度格成稿只写本格可见面，作为该角衍生截取的唯一画面权威。
  2. **不可见面严禁写入**：机位后方半空间、对向扇区实体、本视角查表为不可读的物体面（如背对镜却写正面铭文/柜门正面细节、对向门完整正面等）——**禁止**写入该衍生的 `anchor_description` / `generation_prompt_cn`（§A§B§C）/ 生图向 logic。禁用「不可见的{名}/机位后方有…」工程句冒充锚点或画面事实。
  3. **一对一映射**：可见面只挂**其可见的那条**衍生行；不得把 0° 格才可见的面抄进 180° 衍生锚点，亦不得在主环境某格写他格才可见的面。邻向仅贴边斜切可见的半截面可写，完整正面仍禁。
  4. **头尾双锚服从可见性**：成稿优先挂本镜**可见**头/尾锚；首选锚本镜不可见→改挂对向可见锚或本镜背景半空间内可核销锚；**禁止**把不可见锚的「应有正面细节」写成当前衍生可见事实。
- **主环境四向拼图纵深与五面围合（最高硬约束；只锁主环境四格成稿）**：
  1. **每格必须有一定空间纵深（四格同核）**：主环境四向拼图**每一格**必须保持约 35mm–50mm 电影级眼高焦段的**同一档适度景深**与开阔视野，呈现真实的三维纵深感——近端地面/贴边碎片 → 中景舞台净空 → 后景主立面三层可读。背景立面/柜后货架/窗格/墙面须**可读清晰**，与中景同属可辨焦段。**禁止**：拍成毫无侧向与上下参照的二维扁平贴墙大特写；**禁止**任一格改用人像浅景深/大光圈虚化背景（尤禁 180° 柜台特写把柜后酒架/墙面糊成焦外）；**禁止**四格景深档不一致（三格深、一格浅 = 失败）。**衍生切割不复述本条**：第一刀 §B 与衍生的衍生都不写景深/五面围合/左右侧向入画。
  2. **机位后方一面不可见（相对 180°）**：本格观察轴为 $N^\circ$ 时，机位在 `(N+180)%360` 侧；该对向立面及其附着物**整面不入画**（与「严禁对向串写」同核）。禁止为「六面都看见」把机位后墙、对向门/柜完整正面画进本格。
  3. **除背景外，左右两面与上下两面均须可见（五面围合；最高）**：每格是「看进盒子」的正交空镜，不是只贴一张背景墙。除本格 $N^\circ$ **背景主立面**外，下列四面也必须入画可读——成稿须可检索 `五面围合`：
     - **左面**：画面左侧 `(N+270)%360` 侧壁/交角墙段或交角最近件贴边（侧向围合可见）；
     - **右面**：画面右侧 `(N+90)%360` 侧壁/交角墙段或交角最近件贴边（侧向围合可见）；
     - **上面**：室内=天花/梁架/灯槽入画；外景=天空/天际入画；无顶外廊/檐下=檐口/梁底/树冠上沿入画（上边界不得被裁出画幅）；
     - **下面**：地板/地面贴层入画（下边界不得被裁出画幅）。
     英文钉可写：`five-face enclosure: floor + ceiling/sky + left wall + right wall + back wall visible; camera-behind wall forbidden`。
  4. **左右仍是侧壁、禁升格为第二背景（≠塞满邻墙全员）**：
     - 在正对本格 $N^\circ$ 背景主壁/主立面（作为画面正中与主背景）的前提下，左右必须**看得见是侧壁**（侧壁厚度、交角墙段或交角最近件的贴边窄条），不得整侧留白到「只有一张背景墙」。
     - **不等于**把邻向扇区上每一个实体都画进左右缘——只表现交角最近可见碎片（见上「邻缘只挂交角最近件」）；远端/墙中段实体不入非正面格。
     - **主次边界与防错**：左右仅为贴边侧壁碎片，背景正中依然严格正对输入 $N^\circ$ 边界主景；严禁因展现左右或上下而将机位歪斜成对角看墙角、菱形斜透视、荷兰角，或改成仰拍只见天花 / 俯拍只见地面。
  5. **上下入画闸（与 §2.2.1 同核、升格为构图硬约束）**：主环境四宫格**禁止**用「本格天空/天花不可见」把上边界裁掉。室内每格天花必须入画；外景每格天空必须入画；无顶则以上沿入画。地面每格必须入画。❌ 只见背景墙、地面或天花被裁出 = 失败。❌ 只见背景+地面、左右与天花全无 = 失败。❌ 为见五面改成墙角/荷兰角/仰俯极端裁切 = 失败。
- **跨衍生环境实体描述（含朝向等）规则化变换与逻辑一致性（最高硬约束；仅主环境四向成稿阶段）**：
  场内所有实体（中心家具、长桌、座椅、楼梯、门窗、柜台、梁柱、壁挂、装饰物等）在主环境【四面内容基准】各向中，其**画面落位与可见面描述必须严格按照几何投影变换规则动态更新**，保证跨视角物理与逻辑绝对一致。**此变换只用于写【四面内容基准】**；【四向拼图】只引用四面；各 `{N}度` 衍生生图**不再做第二次楼底推演**，只截取已画好的对应宫格，**不做调整**。
  1. **画面位置变换（左右与纵深）**：
     - 位于世界扇区 $N^\circ$ 的实体 $\to$ 在当前画面为【背景正中 / 远景主景】；
     - 位于世界扇区 $(N+180)^\circ$ 的实体 $\to$ 在当前画面为【前景近端 / 摄影机下方或后方】；
     - 位于世界扇区 $(N+270)^\circ$ 的实体 $\to$ 在当前画面为【画面左侧 / 中景左侧】（作为左侧壁或左侧陈设透视可见）；
     - 位于世界扇区 $(N+90)^\circ$ 的实体 $\to$ 在当前画面为【画面右侧 / 中景右侧】（作为右侧壁或右侧陈设透视可见）。
  2. **实体朝向与可见面系统变换（查 §2.5.3 F/U 权威表）**：
     - 单体方向性实体（椅、柜台、门、牌匾等，正面朝向 F）：按摄影机朝向分别映射为【正面 / 背面 / 左侧面 / 右侧面】，严禁跨视角朝向混乱；
     - 长条形实体（长桌、长案、床、沙发）：按长轴方向分别映射为【纵深延伸（短边在近）/ 横跨画面（长边横向，注明两端对应扇区）】；
     - 楼梯/台阶/坡道（上行朝向 U ≡ F）：按观察轴分别映射为【正面迎面拾级 / 背面梯底收进 / 侧立面斜坡上升（明确写清由左向右升或由右向左升）】。
     - **柜台/吧台/案台/服务台/贴墙柜等定向固定实体（F 视图记录）**：先锁 `所属墙面=M｜正面/操作面=F｜长轴两端={A,B}｜开口/抽屉/台面/可读文字所在面`，再逐格投影：`N=F` 只能见正面/操作面；`N=F+180°` 只能见背板/背面，禁写正面抽屉、开口或文字；`N=F+90°` 只能见左侧面；`N=F+270°` 只能见右侧面。实体落位仍按所属墙面 M：`M=N`=背景主位，`M=N+270°`=画面左侧缘，`M=N+90°`=画面右侧缘，`M=N+180°`=机位后方不可见。**F 决定看见哪一面，M 决定它在画面哪里；两者不得互相替代。**
  3. **跨衍生实体守恒**：几何可见的实体在各衍生环境中必须持续具名并保持物理属性一致（件数、材质、尺度、配套关系一致），仅可见面、朝向和相对位置按规则变化，禁止某实体在某角度凭空消失或突变。
- **邻向入境与主景边界约束（主环境四向格与全部衍生均适用；防左右抢背景）**：相邻两向（画面左=`(N+270)%360`、画面右=`(N+90)%360`）的**扇区立面/贴墙实体**（门、窗、挂画、贴墙柜、**柜台/吧台**、走廊口、踢脚墙段、**贴墙楼梯/台阶侧缘**）作为透视侧立面基本可见入画，但**禁止**把邻向扇区写成正对平视的背景主景（正对完整立面只属于所属扇区格）。禁搬邻向完整正立面作背景。**门/窗/贴墙梯/柜台邻向格不得复述完整名作第二件**（见下「唯一落位」）。**本格背景主锚仍须正对输入该向内容，四方正交，禁偏斜构图。本条不约束中区地面家具——茶几/矮几不得被当成「0°邻向立面」而省略或缩成贴边斜切。**
  - **五面可读句式（生图强制；原三向+上下）**：每格必须让模型读出互不抢戏的五面——①`背景正对=`本格 N° 具名立面主景（唯一完整正面）②`画面左缘=`邻向窄条 ③`画面右缘=`邻向窄条 ④`上边界=`天花/天空入画 ⑤`下边界=`地面入画；机位后方一面不写。左右句**禁止**以「0度柜台 / 90度侧窗 / 180度楼梯」这类**度数+实体名**起头（模型常把该实体升格为背景，导致 90° 格背景变成柜台而非侧窗）。
  - **同向后景多实体相对位置（最高；左右或上下必写）**：同一格 `背景正对`（或同扇区后景墙面）并列 ≥2 个具名实体时，**禁止**只并列点名而不锁相对关系。成稿必须用画面坐标系写清：
    1. **左右**：`{甲}在画面左半 / {乙}在画面右半`，或 `甲居中、乙贴其右`；同墙横排须写出从左到右顺序。
    2. **上下**：`{甲}在上（门楣/匾/梁上） / {乙}在下（门扇/柜面）`，或 `窗在梯跑中段上方、梯在窗下贴地`。
    3. **可叠用**：左右 + 上下同时写（例：`左下=整跑楼梯侧立面，右上=同墙雕花窗格`）。
    4. ❌ 坏例：`背景正对贴墙木楼梯与雕花窗格`（无左右/上下 → 生图常把窗与梯对调或叠成一团）。
    5. ✅ 正例：`背景正对同墙两件——画面左至中=贴墙整跑木楼梯完整侧立面（贴地上升），画面右=雕花窗格（位于梯跑中上段右侧墙面，残阳透窗）`；或 `背景正对大门居中；匾额「客栈」横挂门楣正上方`。
  - **左右缘抗升格为背景（最高；贴边窄条常被模型当成背景）**：仅写「贴边窄条，非背景」不够——成稿必须用**多重降级**钉死，左右缘实体不得与背景抢戏。
    1. **句序**：先写完 `背景正对=`（并显式收束一句 `本格唯一背景主景={具名}`），**再**写左右缘；禁止左右缘句写在背景句之前或与背景句同等长度堆细节。
    2. **强制句式（左/右同构；缺任一项=失败）**：
       `画面{左|右}缘（仅画幅最外缘透视碎片｜贴边窄条｜绝对非背景｜非中央｜非主景｜禁止完整正立面）：仅见{具名实体}{哪一端}的{短端面|侧帮|门框侧沿}一条斜切窄条；peripheral fringe only; NOT the background; do not center this object; forbid full facade.`
    3. **细节门禁**：左右缘**禁止**写完整材质长描写、可读文字、体积光主戏、整跑楼梯/整扇门/整段柜台正面；只许「端锚名 + 短端面/侧帮 + 窄条」。完整描写只留给该实体所属格的 `背景正对`。
    4. **视觉自检**：任一侧缘物体视觉上像「第二背景立面」或被置于画面中央 = 失败。
    5. ❌ 坏例：`画面右缘（贴边窄条，非背景）：红木长柜台窗格侧短端面`（信息过强、无非主景钉 → 生图常把柜台抬成右半幅背景）。
    6. ✅ 正例：`背景正对=贴墙整跑楼梯…（本格唯一背景主景=楼梯+同墙窗）。画面右缘（仅画幅最外缘透视碎片｜贴边窄条｜绝对非背景｜非中央｜非主景）：仅见柜台窗格侧短端面一条斜切窄条；peripheral fringe only; NOT background; forbid full counter facade.`
  - **左右成稿唯一句式（与长桌露一端同构；必须叠加上条抗升格）**：默认采用上条强制句式；可在句尾括注所属扇区一次，但**度数不得作实体前缀**；**禁止**省略端锚只写「梯帮斜线/柜台侧切」；**禁止**把左右缘写成可独立成画的完整家具。
  - ❌ 坏例（用户案）：90°格写 `背景侧窗墙面` + `中景-左侧：0度柜台边缘侧切` → 生图常把柜台画成背景主景，侧窗被挤到画面左；或仅写「贴边窄条，非背景」仍被升格。
  - ✅ 正例：楼梯/柜台不在本格所属时，90°格先锁 `背景正对`+唯一背景主景，再按抗升格句式写左/右缘窄条。若楼梯**贴本格墙**，则整跑写入本格 `背景正对`，并与同墙窗格写清左右/上下，不得只写右缘窄条。
- **中区地面固定家具 ≠ 邻向立面（最高；防茶几/矮几换角蒸发）**：上两条（对向串写、邻向入境）**只约束贴墙/贴边界的扇区立面**。下列对象**不是**某向「背景立面内容」，禁止套用邻向「只许贴边窄条」或对向串写来删件：
  1. **范围**：茶几、矮几、中央桌、岛台、床尾凳、沙发前方配套几等——位于房间中心、主家具前方、或两边界之间，**不贴单一扇区实墙**。属 Stage 1 五区之【中心】，与 0/90/180/270 立面主锚分簿。
  2. **跨格守恒**：只要本格几何上未被完全遮挡，**0°/90°/180°/270° 四格都必须具名写出**该家具的可见面、以及相对主家具的落位（前方 / 朝门一侧 / 远侧）。禁止因「0度格已写沙发与矮几」就在 90/270 格删除。
  3. **误分类禁令**：禁止把沙发/茶几/矮几写进「背景正对{家具}」来代替四周立面。各格**背景=该向围合立面**（墙/门/窗/廊口）；沙发与矮几一律进「中景-中央家具」。0° 可写背景墙 + 中景正对沙发正面，矮几仍是中区家具，换角必须仍在。
  4. **完全遮挡须显式**：仅当被沙发背/墙体完全挡住时，该格写「{名}被{遮挡体}遮挡」——**禁止静默删除**。
- **实体唯一性**：默认每种功能全场 1 具；**门/窗/楼梯通常唯一**；多件须先写总个数再逐具区分特征；禁美术增补扩成多门多窗或多跑同构楼梯。
- **门/窗/楼梯/柜台唯一落位（最高；防四向重复开件）**：邻向入境**不等于**把同一扇门、同一跑楼梯或同一柜台再写到邻格当第二件/背景主景。
  1. **开篇只声明一次**：全场门数/梯数/柜台数 + 逐具具名 + 所属扇区或中心（例：大门=0°，仅 1 扇；楼梯贴 180°，仅 1 跑；柜台贴 0° 墙、正面朝 180°）。走廊口/卧室门若有，必须另名另扇区。楼梯另须声明上行朝向 U 与下口/上口（见下条）。
  2. **完整主体只在所属格（优先级高于 F/U 可见面表）**：完整门板/门框正面、**贴墙整跑楼梯完整主体（迎面或侧立面，以所属格×U 查表为准）**、**柜台正面/操作面**只许写在其扇区那一格的**背景主景**；F/U 表在邻向格只决定窄侧缘可见面类型，**不得**据此把完整迎面/正面/整跑侧立面搬到非所属格。中庭楼梯才按中心规则四格写可见面。0° 格机位在门侧看沙发时，大门在机位后方——**禁止**在 0° 前景/中景再写一扇门。
  3. **邻向格禁复述主体**：90°/270° 等邻向格即使几何上能见到该门/梯/柜台侧缘，**禁止**再写「大门/防盗门/玄关大门/门扇/楼梯/台阶/柜台正面」作可识别第二件或背景；只写「邻向墙段贴边斜切」或「同一扇门/同一跑梯/同一柜台的侧缘窄条，全场仅此一件，禁止另画」。❌ 90° 写「中景-左侧：0度柜台边缘侧切」导致柜台抢侧窗背景。同理禁 90/270 各画一座楼梯或第二扇门。
  4. **矮几「朝门一侧」≠ 把门搬来**：90/270 格写矮几在沙发朝 180° 的一侧时，只作家具落位，**不授权**在该格画门。
  5. **自检**：同一具名门/梯/柜台在 ≥2 格写成完整/可独立识别主体或背景主景 = 失败；四格完整件数 > 上游声明件数 = 失败；**贴墙楼梯开篇已声明但四格均无「背景正对…整跑楼梯」= 失败（无基准）**。
- **楼梯/台阶/坡道/扶梯朝向（最高；方向性构筑，覆盖同门窗）**：楼梯**有朝向**，禁止当无方向装饰四面都画成迎面拾级。
  1. **开篇一次声明**：具名；贴墙=所属扇区 / 中庭=中心；**上行朝向 U**（走上时面朝的世界度数，**≠**楼梯所在坐标）；**踏步展开轴**（0°↔180° 或 90°↔270°）；下口端、上口端各落哪一端。
  2. **U ≡ F**：查 §2.5.3 方向性实体表——**正面**=迎面踏步+踢面层层（从下口看向上口）；**背面**=梯底板/斜梁腹，或上口收进楼板；**左/右侧面**=该侧梯帮+栏杆，踏步侧面纵深。展开轴再按长条家具可见面表写「向背景延伸」或「横跨画面」。
  3. **坐标 ≠ 上行**：❌「90度有楼梯」（究竟贴 90° 墙，还是往 90° 走上去？）；✅「楼梯贴 90° 墙，上行朝向 180°，下口在 0° 端」。
  4. **贴墙楼梯必须有且仅有一个基准格（最高；防无正面基准）**：所属墙面扇区那一格 = 楼梯基准参考源。该格 **`背景正对` 必须写入整跑楼梯完整主体**（按所属格×U 查表：多为**完整侧立面**，少数为迎面拾级），可与同墙窗/梁柱并列共写，但**禁止**把整跑楼梯降级为仅「中景斜升」或仅「画面左/右缘梯帮窄条」。画布首句该向背景列表须点名楼梯（例：`右上=90度（背景:贴墙楼梯完整侧立面+雕花窗格）`）。邻向格左右缘只挂**交角最近件**的窄条——楼梯仅出现在靠近其下口/上口交角的那一格缘上，**禁止**凡看见邻向扇区就挂楼梯。对向格（机位后方）楼梯不可见，禁臆造。❌ 坏例（用户案）：开篇写「楼梯贴90度墙」，但 90° 格 `背景正对雕花窗格`、仅 `中景-楼梯…斜向上升`，四格均无背景正对整跑 → 无基准。❌ 另坏例：90° 墙左楼梯右窗时，180° 左缘仍硬塞楼梯。✅ 正例：90° 格 `背景正对` 整跑楼梯+同墙窗并写左右相对；0° 右缘须双钉 `下口端侧面｜可见面=侧边｜禁止迎面踏步｜forbid frontal stair treads`；180° 左缘=靠柜台端的窗格侧沿窄条（非楼梯）。
  5. **楼梯坡向绝对锁（最高；挂在长桌式横跨句上，防镜像 + 防 0°/90° 互倒 + 生图抗翻转）**：楼梯展开轴的左右端锚句式**必须先按 §2.5.3 成稿单层句式写完**（与长桌横跨同构），再在同句锁定角点坡向；禁止只用坡向、不用两端具名锚。
     - **开篇强制**：与长桌相同写 `长轴 + 两端具名锚`，另标 `U｜基准格｜坡向锁：基准格{角}下口→{对角}上口｜坡向符号=/或\｜禁止镜像`。**禁止**写无格号的「侧面格画面左低右高」。
     - **生图抗翻转（最高；提示词对≠图对）**：扩散模型常忽略「左下→右上」自然语言，并被**强光窗/体积光构图先验**拉成反斜线。成稿必须用**多重冗余**钉死，不可只写一句禁镜像：
       1. **句序**：基准格正文里，**楼梯坡向句必须紧跟「背景正对…楼梯」之后、写在窗格/残阳/体积光之前**——禁止先写透窗逆光再写楼梯（光先验会翻转坡向）。
       2. **四分位**：显式写 `最低踏步/下口落在画面左下四分之一；最上踏步/上口平台落在画面右上四分之一`（U=180/基准90°时；其他 U 按总锁换角）。
       3. **坡向符号**：`N=U+270`（含 U=180 的 90° 格）强制 `坡向符号=/（左下→右上）`；`N=U+90` 强制 `坡向符号=\（右下→左上）`。成稿写清 `只要出现\（右下低左上高）即失败`（或对调）。
       4. **英文钉（可同句夹写）**：`stairs ascend ONLY from lower-left to upper-right; forbid reverse diagonal`。
       5. **开篇+基准格各写一遍**坡向锁；基准格末可再短收一句 `复核：/ 非 \`。
     - **基准格正文模板（U=180/基准90°）**：`背景正对贴墙整跑楼梯…。楼梯横穿画面可见侧立面，画面左侧朝向大门侧（下口）、右侧朝向柜台侧（上口）；坡向符号=/；左下四分之一=下口最低踏步，右上四分之一=上口最高平台；左下角→右上角；forbid \`。` → **然后才写**同墙窗格与残阳体积光。
     - **U=180 且基准格=90°（高频坏例钉死）**：
       - 90°：上条模板；❌ 图上出现右下→左上（`\`）= 失败（即使用户提示词已写左下→右上）。
       - 0°右缘（仅当下口在大门交角为最近件时）：`仅见楼梯大门侧（下口端）侧面/短端面一条斜切窄条；可见面=侧边；同一跑下口端切片，向上延续出画外与90度基准整跑同核；近背景大门侧=下口低端，梯帮向近镜头升高；禁止迎面踏步/踢面层层；side edge only; forbid frontal stair treads; forbid short stub staircase`；❌ 只写「楼梯梯帮」不锁可见面→生图迎面拾级；❌ 画成到画幅顶收住的短 stub 梯=失败；❌ `梯帮向背景大门升高`= 互倒失败。
       - 180°左缘：若同墙窗靠柜台端 → **挂窗格侧沿，禁止挂楼梯**；仅当交角最近件确为楼梯上口（窗不在该端）时才可写：`上口端侧面/短端面一条连续窄条；可见面=侧边；同一跑上口端切片；禁迎面；forbid double-segment stairs / second flight`；❌ 近镜头当上口；❌ 有窗在柜台端仍写楼梯；❌ 180° 左散座/右楼梯（扇区对调）= 失败；❌ 左缘两段梯/双扶栏= 失败。
     - **U=0 且基准格=270°（客栈高频；用户案硬伤）**：下口=180°门端、上口=0°柜台端。270° 格画左=`(270+270)%360=180°`=下口，画右=`(270+90)%360=0°`=上口 → 仍是 `/`。
       - 270° 基准：`背景正对贴墙整跑楼梯…。楼梯横穿画面可见侧立面，画面左侧朝向正门侧（下口）、右侧朝向柜台侧（上口）；坡向符号=/；左下四分之一=下口最低踏步，右上四分之一=上口最高平台；forbid \`。` 楼梯句先于残阳/体积光。
       - 0° 左缘：`仅见楼梯柜台侧（上口端）侧面/短端面一条斜切窄条；可见面=侧边；同一跑上口端切片；近背景柜台侧=上口高端，梯帮向近镜头降低通向门外；禁止迎面踏步/踢面；forbid frontal stair treads; forbid double-segment`。❌ 左缘画出贴地起步/下口最低踏步=走向对倒；❌ 0° 任何位置迎面拾级=失败。
       - 180° 右缘：`仅见楼梯正门侧（下口端）侧面/短端面一条斜切窄条；可见面=侧边；同一跑下口端切片，向上延续出画外与270度基准整跑同核；近背景大门侧=下口低端，梯帮向近镜头升高；forbid frontal stair treads; forbid short stub`。
       - 90°：**禁止出现楼梯**（270°=机位后方）。
       - ❌ 270° 画成右下→左上（`\`，上口落门侧）= 失败；❌ 0° 左缘当下口、180° 右缘当上口= 互倒失败。
     - **邻向贴边（与长桌露一端同理）**：必须写明是哪一端 + **该端在画面近/远哪一侧的高低**；禁止无端锚、无近远高低的「梯帮斜线窄条」。
     - **跨格同核自检**：90° 若应为 `/`，则 0° 右缘不得「向门升高」、180° 左缘不得「近镜头为上口」；270° 若应为 `/`（U=0），则 0° 左缘不得「柜台侧=下口」、180° 右缘不得「门侧=上口」；任一对倒 = 整张四向拼图失败。
  6. **四格一致性与侧面朝向（最高硬约束）**：先建立不可变的「楼梯视图记录」（**仅开篇用度数**）：`U={上行方向}｜下口=U+180°端｜上口=U端｜N=U:迎面｜N=U+180:背面｜N=U+90:画面右下→左上（符号=\）｜N=U+270:画面左下→右上（符号=/）`。四格服从同一记录；成稿转译为**长桌式**左右端锚+角点+符号，不得并列写「0度下口/180度上口」。**不得**翻转上下口，不得把侧面格改成迎面拾级，**不得**把 N=U+90 与 N=U+270 对调，**不得**让 0° 邻缘与 90° 基准坡向互倒。贴墙梯邻向只保留带端锚+近远高低的窄侧缘。当贴墙楼梯作为背景立面时（如贴 90° 墙）：
     - U=180：90° 基准格用横跨句 + `/` + 四分位；楼梯句先于窗光；0° 右缘下口在近门远景侧；严禁迎面拾级与 `\` 镜像。
     - F/U 表在邻向只授权「哪一端短端面」类型，禁止扩成第二跑完整楼梯。
     - **严禁**侧面格与对向纵深格画成相同迎面拾级。
  7. **落格**：贴墙整跑完整主体只在所属扇区格的 `背景正对`（写法=长桌横跨/纵深句）；中庭大楼梯属中心。邻向只许带端锚的短端面窄条；禁「四格都无背景正对楼梯」。
  8. **同类覆盖**：台阶、坡道、扶梯、室外踏步、旋梯同一套长轴两端 + U/基准格/坡向锁；禁漏写朝向。
- **四向成稿歧义控制（最高）**：成稿任一词若可被理解为「第二件 / 换了位置 / 换了朝向」，即歧义，必须改写。
  1. **一名一物**：开篇锁具名；同物禁换称导致像两件（❌ 大门+玄关大门+防盗门 三称三扇）。
  2. **一物一位**：每实体唯一所属=某一扇区立面 **或** 中心；禁止两格都当背景主景。
  3. **坐标 ≠ 朝向**：所在扇区/端点 ≠ F（家具正面）≠ U（楼梯上行）。位置在 0° 端的椅可以朝向 180°；贴 270° 的梯可以上行朝 0°。
  4. **类名消歧**：大门 ≠ 走廊口 ≠ 卧室门；楼梯 ≠ 台阶 ≠ 踏步平台；须具名+扇区，禁笼统「有门/有楼梯」。
  5. **定位词 ≠ 搬件**：「朝玄关一侧」「180度门端」「梯侧」只定相对位置，不在该格生成门/梯主体。
  6. **先分类再落格**：贴墙立面（门/窗/挂画/贴墙柜/贴墙楼梯）→ 完整主体只在所属格；中区（沙发/茶几/中庭大楼梯）→ 四格写可见面、**件数不增**。
  7. **开篇拓扑一次**：件数、具名、所属、长轴、F/U；各格只写本格可见面，禁止各格重写冲突落位。
  8. **自检**：同一具名在两格都像独立完整件；或「在 N°」未声明朝向而可两解 → 失败。

#### 2.5.3 主环境四向拼图写法（内部推演工具禁入成稿）

**主环境 `generation_prompt_cn` 成稿两段式（最高；先四面后四宫格；不得省略全局）**

成稿**固定三段顺序**（缺段/倒序/把细节堆进四宫格段 = 失败）。**先落骨架再填肉**：未写出下列字面标题前，禁止写任何「这是一个…」单镜头散文。

**骨架必现（按序可检索；缺一=框架破裂）**
```
{全局共享：开篇句式 + 开篇拓扑 + 光影体系 + 色彩体系 + 中区数量总账}
【四面内容基准】
【0度方向】后景：… 中景：… 本向光变：…
【90度方向】后景：… 中景：… 本向光变：…
【180度方向】后景：… 中景：… 本向光变：…
【270度方向】后景：… 中景：… 本向光变：…
【四向拼图】
生成一张四向拼图基准参考图；16:9 横幅，2×2 四宫格…五面围合…
[0度格-左上]：后景=严格按【0度方向】后景… 中景=… 画面左缘=… 画面右缘=… 五面围合=…
[90度格-右上]：…
[180度格-右下]：…
[270度格-左下]：…
```
单镜头坍塌的失败闭集与合法骨架见 §2.5.1；本模板不重复举例。

**① 全局共享（全文一次；原有内容不得少）**
1. **整体定位**：§1.2A 开篇句式（项目基础定位/全局风格/年代/地域/语言/风格定位 + 时段/内外/气候/季节）+ 风格可视化落点。
2. **开篇拓扑**（条形实体统一；此后各向不成稿复述度数端）：凡条形（中区长桌/床/沙发 **与** 贴墙柜台/吧台 **与** 楼梯展开轴）一律写 `长轴=0↔180|90↔270` + `两端具名锚`；贴墙柜台等另加 `M｜F`；楼梯另加 `全场仅1跑｜M|/中心｜U｜下口=端A｜上口=端B｜基准格=M｜坡向锁=角点+符号(/或\)｜禁止镜像`（基准向楼梯句须写在窗光前）。**通高须共享外形（最高）**：开篇须分列 `下层/一层={具名实体+数量+扇区}｜上层/二层/回廊={具名实体+数量+扇区}`；楼梯写清下口层/上口层。禁 `二楼同楼下` / `上层继承一层` / 只锁一层家具。Index `floor_inventory` 有则原样落地；无则 logic 标 `upstream_missing_floor_inventory`，仍须按已锁具名分层写出，禁止把一层陈设复制到二层。**二层内部**（客房等不共享外形）走独立主环境四向拼图（可 StyleReference 挂一层），禁止在一层开篇写 `上层=客房床桌`，禁止用风格依赖省略本块开篇拓扑。
3. **光影体系**（§2.7 + §2.7.0 全规格）：定位目标｜场景情绪｜曝光三角｜景深控制｜焦段选择｜三点布光｜光比｜色温｜柔硬｜自然光｜实用光｜时段/内外/气候/季节核销｜可见动机光｜Key/Fill/轮廓｜纵深光层｜半影｜材质响应——**写在全局作为世界光总规（灯不随换角关闭）**；四面每一向必须写 `本向光变`（可见源换角后的 Key/Fill/Rim 角色 + 入射侧/投影朝向），并把不可见面光源的续效写成**可见表面受光**（§2.7 换角光变）；禁止四面各写一套互相冲突的全局光规，禁止只写全局一句、四面不再体现，禁止在某向点名该向不可见的灯具/窗洞。
4. **色彩体系**（§2.9 全规格）：主冷暖｜色系｜色温｜饱和度｜主/辅/点缀/过渡｜纵深色层｜影调｜分离色调等——**同上，全局一次方法总规，四面写本向色层落点**。
5. **构图倾向 + 环境目标（方法总规；强制）**：一句写清 `scene_mood` 构图如何服务四格（如「每格三分压迫、中景留舞台净空、后景立面压暗」）+ **四格均须五面围合纵深**；紧接一句转译 `env_goal` 的「本场空镜须」+「可见落点」（无人称）。这是方法，不是单张画面说明书。`服务=`只进 logic。
6. **中区共享实体 + 数量总账**（强制）：中央桌/沙发/茶几等中区件数、长轴、配套椅凳总个数与分边、活动净空/动线几何、地面与天花的共享材质骨架；同时抄入门/窗/楼梯总数，窗棂逐扇横×纵格阵。同质多件须写 `总数=分项和`，禁 `若干|数把|多张|一些|成排|散座`。**通高两层须按层分账**（一层中区桌椅 ≠ 二层回廊椅/栏杆桌；跨层同类件标所属楼层）。**件数、阵列与长轴只在此（或开篇拓扑）锁一次**；四面块只写该向投影可见面，不得改数。

**② 【四面内容基准】（每向只写后景+中景；后景/中景文字真源）**
- 标题块：`【四面内容基准】`。
- 按 `【0度方向】` → `【90度方向】` → `【270度方向】` → `【180度方向】`（顺序可调，四块必须齐全）。
- **每向强制两块（禁写左右缘长文；禁写完整前景人物级描写）**：
  1. **后景**：背景正对唯一主景（同向多实体须左右/上下相对）+ 围合立面细节/材质/可见面；贴墙楼梯/柜台若属本向基准，整跑/正面写在此后景。
  2. **中景**：舞台净空 + 中区条形投影（纵深/横跨单层句）+ 各椅/配套几可见面与左右落点 + **本向可见地面（下边界入画）+ 天花或天空（上边界入画）** + **本向光变（强制）**。
- **通高两层（强制）**：本向能看见的下层实体与上层/回廊实体须**分别点名**（可写上下相对）；禁把一层桌椅投影成二层陈设，禁本向只写一层而用「二楼同下」省略上层。无戏上层仍须写可辨结构（栏杆/楼板开口/廊柱），禁敷衍空廊。
- **每向构图/纵深落点（强制；方法必须在此体现）**：每一向后景+中景须可核销——①本向构图（三分/压迫/留白/中心仪式之一如何落在本向主景与净空，禁荷兰角）；②本向纵深（近端地面或投影 / 中景舞台或家具 / 后景立面受光差至少各一句）；③本向上下边界（地面入画 + 天花/天空入画）；④本向光变（可见源换角后的角色 + 画面坐标入射/投影 + 不可见源只写可见面续效、禁源名；身后 Key 须近端→远景且禁左右侧光）。禁止只抄全局「纵深光层」空话；禁止把邻向实体拉进本向充当前中后景。
- **密度**：每一向后景+中景合计 >10 条可核销细节（§2.2.1）；顶格场所按 §2.4.3。
- **禁止**在四面写：`画面左缘`/`画面右缘` 长句（左右缘改由③查表出句）；禁止四面互写「对照/旋转/继承上向」。

**③ 【四向拼图】（组装：引用后景+中景 + 查表左右缘 + 五面围合钉；禁止旋转过程词）**
- 标题块：`【四向拼图】`。
- 先写画布短指令：
  `生成一张四向拼图基准参考图；16:9 横幅，2×2 四宫格，禁止拉成 1:1；【要求在画面的各格上加上明显的角度文字标志（如 0度、90度、180度、270度）】；禁止俯拍/鸟瞰；各格机位正对该向输入内容，四方正交，禁止偏斜/墙角构图/荷兰角；各格保持约 35–50mm 眼高机位的适度景深与空间纵深感（焦段偏 35 或偏 50 服从上文光影体系已裁定值，四格同焦段）；各格须有一定空间纵深；五面围合：除机位后方一面（相对180度）内容不可见外，背景主立面之外左右两面与上下两面均须可见（地+天花/天空+左壁+右壁+后景）；forbid flat backdrop / missing floor / missing ceiling / camera-behind wall；四格共享上文世界光，换角灯不关；各格只点名本格可见灯具/窗洞，不可见源只表现为可见表面受光/勾边/投影，禁止把机位后灯具写进该格；四格共享上文全局光色与开篇拓扑；中区若为长方桌/条案：四格同一张长方形，纵深格短边朝镜、横跨格长边横贯，剪影随角倒置，forbid square table in all four panels；Clean Plate。`
- **每格固定组装句式（四格都要写；缺任一侧缘钉或缺五面围合钉=失败）**：
  `[N度格-宫格位]：后景=严格按【N度方向】后景绘制，禁止改写材质与楼底。中景=严格按【N度方向】中景绘制，禁止改写中区投影。画面左缘=…（查表结果钉句）。画面右缘=…（查表结果钉句）。五面围合：本格背景主立面+左缘侧壁+右缘侧壁+上边界（天花/天空）+下边界（地面）均可见；机位后方一面不可见。`
  - 左上 N=0；右上 N=90；左下 N=270；右下 N=180。
- **左右缘 = 查表出句（内部用速查表；成稿只写结果，禁止过程词）**：
  - 扇区：画左=`(N+270)%360`，画右=`(N+90)%360`；只挂**交角最近件**贴边窄条。
  - 结果句模板（与下文「邻向贴边成稿」同核）：`画面{左|右}缘（贴边窄条｜绝对非背景｜非主景）：仅见{实体}{端锚}的{短端面|端侧面|门框侧沿|侧边}一条斜切窄条；可见面=…；peripheral fringe only; NOT the background; forbid full facade`。
  - 楼梯邻缘另加单跑同核钉（0°下口：`forbid short stub`+禁迎面；180°上口：`forbid double-segment`）。
  - **成稿绝对禁止**：`由【90度方向】旋转得到`｜`对照邻面`｜`将后景转到侧面`｜`按公式映射左右` 等过程词——模型不执行推演，只认结果钉句。
- **每格纵深收束（强制；五面围合）**：四格共享约 35–50mm 适度景深（与全局 `焦段选择` 同核）；左右缘透视围合 + 上下边界入画必须让本格出现近端地面 / 中景舞台 / 后景主立面三层，且左壁、右壁、天花或天空、地面均可见。禁止任一一格拍成无纵深的贴墙扁平特写，禁止裁掉地面或天花，禁止只见背景不见左右。构图方法已在对应【N度方向】写完，本段只引用，不另起一篇整图三分法。
- **禁止**在③：重写后景/中景材质长文、重锁开篇拓扑、省略左右缘、省略五面围合钉、把邻向完整后景搬进左右缘当第二背景。

**§0 内部备忘（不成稿过程词）**：条形实体长轴/两端/F/U **只声明一次**，四向共用；禁向间「较 0 度旋转」链式传递写入成稿。对称长桌与贴墙柜台/楼梯须据上游裁定长轴后按下表转换——**禁照搬示例默认轴**；**边上方向性物体与中区长桌查同一张长轴表**。单体方向性实体（椅等）声明 F（≠放置坐标）。楼梯另声明 U（≡F）+ 下口/上口=长轴两端。**左右缘组装仅内部查表，成稿输出结果句。**

**Step 1 可见面表（内部，逐向独立查表；度数端标签不成稿）**

**适用范围（强制统一）**：中区长桌/床/沙发；贴墙柜台/吧台/案台/长条柜；楼梯/台阶/坡道**展开轴**。下表供内部查端点；**成稿必须转译为「具名锚 + 画面左/右/近/远」单层句，禁止把表中「0°端/180°端」原样写入该格正文**：

| 家具长轴方向 | 0°格(背景=0°) | 90°格(背景=90°) | 180°格(背景=180°) | 270°格(背景=270°) |
| :--- | :--- | :--- | :--- | :--- |
| **0°-180° 轴线** | **纵深**：短边朝镜；近端→背景0°具名锚延伸 | **横跨**：长边横穿；画左=0°具名锚侧、画右=180°具名锚侧 | **纵深**：短边朝镜；近端→背景180°具名锚延伸 | **横跨**：长边横穿；画左=180°具名锚侧、画右=0°具名锚侧 |

**成稿单层句式（强制；长桌 ≡ 贴墙柜台 ≡ 楼梯；每实体每格只写一条）**
1. **开篇拓扑**（全文一次）：长轴=`沿0度↔180度` 或 `沿90度↔270度`；两端用世界度数锁定到具名锚（如 `0度端=大门侧｜180度端=柜台侧`）。贴墙件补 M/F；楼梯补 U（下口/上口=上述两端）与基准格。此后各格不再重复「X度端」。
2. **纵深格成稿**（中区或贴墙整跑在本格呈端面/迎面时）：`{实体}可见短边端面，由画面近端向背景{具名端锚}深度延伸；桌面剪影=纵向长条（横向窄、深度长），forbid square table`。
3. **横跨格成稿**（中区长边，或贴墙楼梯/柜台在基准格呈完整侧立面时）：`{实体}横穿画面可见长边/侧立面，画面左侧朝向{具名左端锚}、画面右侧朝向{具名右端锚}；桌面剪影=横向长条（左右长、前后短），与纵深格为同一张长方形的倒置，forbid centered square table`。楼梯横跨格须同句加角点+四分位+坡向符号（`/` 或 `\`），**写在窗格/体积光描述之前**，**不得**另起与左右端锚冲突的坡向句。
4. **邻向贴边成稿（写入【四向拼图】左右缘；四面基准禁止写）**：`画面{左|右}缘（仅画幅最外缘透视碎片｜贴边窄条｜绝对非背景｜非中央｜非主景｜禁止完整正立面）：仅见{实体}{哪一端具名锚}的{短端面|端侧面|门框侧沿}一条斜切窄条；可见面={短端面|端侧面|侧边}；peripheral fringe only; NOT the background; forbid full facade`。楼梯邻缘另须：`同一跑{下口|上口}端切片｜与基准格整跑同核｜禁止迎面踏步/踢面｜side edge only; forbid frontal stair treads`；**0°下口另加** `向上延续出画外｜forbid short stub staircase`；**180°上口另加** `单条连续梯帮｜forbid double-segment stairs / second flight`；并写该端近/远高低。必须点明端锚+可见面；禁止无端锚；禁止左右缘写完整材质长描写或可读字；**禁止**成稿写「由邻面旋转/对照得到左右缘」。
5. **椅/配套件**：写入【四面】中景，与主件同句或紧接一句，写清画面左/右/近/远 + 可见面；禁另起「2把正面、2把背面」无左右落点的摘要。
6. **禁止**：再用「X度端在画面左」或「中景-左侧：N度{实体}」复述；禁止边上物体另搞一套不写两端锚的描述体系。
7. ❌ 坏例：`中央桌横穿…270度端在画面左侧`（度数端双轨）；`中景-左侧：0度柜台边缘侧切`（度数前缀抬背景）；`画面右缘：楼梯梯帮斜线窄条`（无端锚）；90° 左下→右上却 0° 右缘「梯帮向大门升高」（0°/90° 坡向互倒）；180° 格浅景深虚化柜后货架；**四宫格写「将【90度】后景旋转到左缘」**；**四面写满左右缘、四宫格却省略侧缘钉**。
8. ✅ 正例 A（**近门方桌长轴 90↔270**；柜台贴180、F朝0；楼梯贴90、U=180、下口=大门侧、上口=柜台侧；90°墙左=楼梯、右=窗靠柜台端）——本例桌轴是 90↔270，**不要**抄到 0↔180 中区长桌上：
   - 全局：开篇拓扑 + 光影/色彩/中区一次声明。
   - 【90度方向】**后景**：`背景正对同墙两件——左至中=整跑楼梯完整侧立面、右=雕花窗格（本向唯一背景主景=楼梯+窗）；可见面=侧立面；坡向符号=/；左下四分之一=下口、右上四分之一=上口；forbid \`。` **中景**：残阳落点；近门方桌短端面纵深朝楼梯（纵向长条）；椅位可见面。
   - 【0度方向】**后景**：大门门扇正面+门缝夕光。**中景**：通道净空；近门方桌长边横跨（左=木墙侧、右=楼梯侧；横向长条）。
   - 【180度方向】**后景**：柜台正面+酒架。**中景**：净空；方桌长边横跨（左=窗/楼梯侧、右=酒桌侧，与柜台同核；横向长条）。
   - 【270度方向】**后景**：木墙散座。**中景**：方桌短端面纵深朝散座（纵向长条）。
8b. ✅ 正例 B（**中区长方桌长轴 0↔180**；用户客栈案）：`形制=长方条案（非正方形八仙），长:宽≈2:1，沿0度↔180度；0度端=大门侧、180度端=楼梯侧`。
   - 【0度方向】**中景**：短边朝镜，桌身向大门深处拉长（纵向长条）；长凳分列左右。
   - 【90度方向】**中景**：长边横贯，左=大门侧、右=楼梯侧（横向长条，左右跨度 >> 前后厚度）；长凳分列近远。
   - 【180度方向】**中景**：短边朝镜，桌身向楼梯深处拉长（纵向长条）；长凳分列左右。
   - 【270度方向】**中景**：长边横贯，左=楼梯侧、右=大门侧（横向长条）；长凳分列近远。
   - ❌ 90°/270° 仍画正中近方桌，或 0°/180° 已拉长而横跨格不扁 = 长短方向未随角变，失败。
   - 【四向拼图】**0度格**：后景/中景引用【0度方向】；`画面左缘…酒桌大门侧短端面…`；`画面右缘…楼梯下口端侧面…可见面=侧边；forbid short stub；forbid frontal treads`。**180度格**：引用【180度】后景/中景；`画面左缘…窗格侧沿（交角最近；禁楼梯）…`或上口单条连续；`画面右缘…酒桌短端面…`。❌ 左散座右楼梯=一票否决；❌ 过程词「旋转邻面」=失败。

**前方配套几/矮几跨格落位（强制；随上表主件长轴，禁止蒸发）**

配套几位于主件**正面朝向 F** 的一侧（例：沙发正面朝 180°、矮几在沙发与大门之间）。主件按上表写可见面后，**同一格必须紧接着写配套几**：

| 本格看到主件的哪一面 | 配套几落位（成稿必须具名；用画面左/右，禁度数端标签） |
| :--- | :--- |
| **正面**（如 0° 格看 F=180° 的沙发） | 几在主件**前方**（近镜头、主件与机位之间），完整可见顶面/近端 |
| **侧面/短边纵深**（90° 或 270° 格） | 几在主件长边**朝 F 的那一侧**，落画面左或右（以开篇已锁的 F 侧具名锚为准）；**完整中景可见**，禁止当邻向立面贴边省略。例：沙发长轴 90↔270、F=180 → **90° 格矮几在画面右（朝玄关/大门侧）**；**270° 格矮几在画面左（朝玄关/大门侧）**。此句只定位矮几，**禁止**在 90/270 格再画/再写完整大门（大门只在 180° 格背景） |
| **背面**（如 180° 格看同一沙发） | 几在主件**远侧**朝 F（常=朝大门）；全挡→显式「被沙发背遮挡」；两侧露出则写露出部分。禁止静默删除 |

❌ 0° 写「沙发与矮几」、90/270 只写沙发纵深、矮几消失。

方向性实体（按 F，即物体正面的朝向方位；**楼梯/台阶/坡道/扶梯的上行朝向 U ≡ F**）：
**强防错约束：必须用物体的实际朝向 F/U 查表，绝不能用物体所处的位置坐标查表！** 例如：放在 0° 端的椅子如果“朝向 180°（面朝大门）”，那么 F=180°。查表可得在 0° 格（摄影机在 180° 往 0° 拍）必然看到的是该椅子的【正面】；在 180° 格摄影机在它背后，看到的是【背面】。楼梯同理：贴 270° 墙但上行朝向 0° → U=0°，**270° 基准格见完整侧立面**（`/`，左下=门侧下口、右上=柜台侧上口）；**0° 格只见左缘上口端侧面窄条（禁迎面踏步）**；**180° 格只见右缘下口端侧面窄条**——**严禁**因 U=0 就在 0° 格画迎面拾级，**严禁**把「楼梯在 270°」当成「迎面朝 270°」。严禁将位置 0° 错当成朝向 0°，导致正反面完全写反！

楼梯成稿用词（查**下表** F/U 后转译；开篇用度数锁 U/下口/上口=长轴两端；**各格正文先写长桌式纵深/横跨/贴边端锚，侧面再挂角点坡向**；禁四面迎面拾级）：
- **正面（U 迎面）**：与长桌纵深同构——迎面踏步由近端向背景上口端延伸。
- **背面（U 背面）**：梯底板/斜梁腹，或上口收进（看不到正面踏步）。
- **侧面（U 侧面横看；最易错）**：与长桌横跨同构——`楼梯横穿画面可见侧立面，画面左侧朝向{下口具名侧}、右侧朝向{上口具名侧}`，再钉角点坡向；**禁止**无左右端锚的纯斜线句；**禁止**镜像与迎面层层拾级。

| :--- | :--- | :--- | :--- | :--- |
| **0°**（上行向0°/下口在180°端） | **正面**（迎面踏步向0°背景延伸） | **侧立面**（右下角→左上角升） | **背面**（梯底/上口收进） | **侧立面**（左下角→右上角升） |

**侧面格左右高低总锁（开篇用度数声明一次；各格成稿转译为画面角点+具名侧，并由衍生原样继承）**：任意上行朝向 `U`，`N=U+90°` 格必为**画面右下角=下口、画面左上角=上口（右下→左上）**；`N=U+270°` 格必为**画面左下角=下口、画面右上角=上口（左下→右上）**。不随楼梯贴墙位置或在画面左/中/右落点而翻转。**禁止**开篇只写「侧面格左低右高」而不写格号与对角角点——易与 `N=U+90`/`N=U+270` 对调或被生图镜像。贴墙梯邻向格只写同向**窄侧缘/梯帮斜线**（坡向碎片与基准锁同向），禁重绘完整梯段、镜像坡向或改成迎面踏步；禁在同一格再用「0度下口/180度上口」复述已写的画面角点。

**贴墙楼梯 × F/U 表（强制）**：表中「正面/背面/侧立面」描述的是可见面类型；**完整主体只落所属墙面基准格的 `背景正对`**。邻向格即使表写「正面/背面」，也只许窄端面/梯帮，不得另造整跑。

**四格左右速查表（成稿强制查；写左右缘前对一遍）**

| 格 | 背景 | 画面左 `(N+270)` | 画面右 `(N+90)` | 机位后方（不可见） |
| :--- | :--- | :--- | :--- | :--- |
| 0° | 0° | 270° | 90° | 180° |
| 90° | 90° | 0° | 180° | 270° |
| 180° | 180° | **90°** | **270°** | 0° |
| 270° | 270° | 180° | 0° | 90° |

**客栈拓扑代入（扇区方向 ≠ 邻墙全员入缘）**：左右缘只挂**交角最近件**。90° 墙若左=楼梯、右=窗（窗靠 180°/柜台端）——则 **0°→右缘=楼梯下口端侧面（须双钉：可见面=侧边 + 禁止迎面）**；**180°→左缘=窗格侧沿（禁楼梯）、右缘=酒桌短端面**；270°→左柜台端/右门侧沿，**禁楼梯**。❌ 因「画左扇区=90°」就在 180° 左缘强制挂楼梯 = 失败；❌ 180°「左散座右楼梯」= 一票否决。

对向=`(N+180)%360` 禁入可见清单的是**扇区立面实体**；邻向立面只许**交角最近件的贴边斜切**（见上「邻缘只挂交角最近件」），**禁止**把邻墙远端/全员实体塞进左右缘。**中区地面家具不适用本句省略。** 主环境各格左右缘对条形方向性物体须与长桌露一端同写且带端锚；**禁止**无端锚的「梯帮斜线/柜台侧切」，禁止 `中景-左侧：0度柜台…` 度数前缀句。扇区归属若需消歧，用句尾括注，不要写在实体名前。**禁止**在同格中央家具句再写 `X度端在画面左/右`。**衍生 §B 不重述任何左/右实体；可见锚及其左右落位仅写入 §A logic / `anchor_description`；§C 禁止描述未改实体，变化实体名须与原名逐字符相同、不得重新取名。**

**成稿格式（分工强制）**
- **【四面内容基准】每一向**：`【N度方向】` → **后景（背景正对+材质+可见面）** → **中景（舞台净空→中央条形纵深/横跨→各椅/配套几→地面入画→天花/天空入画→本向光变）**。**禁止**在四面写左右缘。**禁止**在本向点名该向不可见的灯具/窗洞光源。
- **【四向拼图】每一格**：`[N度格]` → **后景=引用【N度方向】后景** → **中景=引用【N度方向】中景** → **画面左缘（查表结果钉）** → **画面右缘（查表结果钉）** → **五面围合钉**。贴墙楼梯/柜台完整主体仍只在所属向**后景**；邻向只在四宫格左右缘出窄条。

**成稿禁词**：`参照速查表`｜`Step 0/1/2`｜`查表`｜`较 0 度格`｜`内部推演`｜`转角对照`（作过程时）｜**`由…旋转得到`｜`对照邻面组装`｜`将后景转到侧面`｜`按公式映射左右`**｜本格角度粘贴实体名前｜跨格摘要行｜**`X度端在画面左/右`**｜**`中景-左侧/右侧：N度{实体}`**｜**无端锚的「梯帮斜线窄条」**｜**【四向拼图】重写【N度方向】后景/中景材质长文**｜**【四面】写满左右缘却【四向拼图】省略侧缘钉**｜**主环境开篇 `这是一个…大堂/房间` 单镜头总述**｜**主环境把画布写成单张 `16:9画幅` 而不写 `2×2 四宫格`**｜**【四向拼图】省略五面围合钉**｜**`机位后方有…灯`｜`身后窗/台灯`｜`不可见的{灯}照来`**。**不禁**「三分法/纵深光层/纵深色层」——这些是方法，必须在全局+每一向出现；禁的是用它们写成无骨架的单机位总述。

**禁写**：向间对照/继承过程句入成稿；把本向 `N` 当实体前缀；用左右句把邻向实体抬成背景主景；楼梯/柜台不用两端具名锚；**跳过【四面内容基准】直接在四宫格堆后景细节**；**四面写完后在四宫格改写楼底或后景材质**；**指望模型自行「旋转」邻面生成左右缘而不给结果钉句**。

#### 2.5.4 衍生三段式与转角（截取放大权威；第一刀只切割，不写几何/楼底）

**衍生同核保障（最高；只约束各衍生环境生成）**

目标：同一主环境族里，每个 `{N}度…` 都是**同一张四向拼图的同一宫格放大**，不是各自文生的另一间房。切到 0°、再切到 180°、再回到 0° 时，0° 背景必须仍是左上格那一套门/左右缘/中区投影。

1. **同角身份 `angle_key`（强制）**：`angle_key={所属主环境名}|N`，`N=view_angle_from_main`∈`0|90|180|270`。凡 `angle_key` 相同的第一刀**只有** `{N}度{主}` 一行，**必须截取同一宫格、挂同一张主环境四宫格参考图**。同角状态行（衍生的衍生）**必须挂该角已切割图**，不另起楼底。❌ 同向再拆 `_桌后反打` / `_乙侧` / `_近景`。❌ `0度客栈_沙尘` 挂 `180度客栈`。
2. **生图门闩（强制）**：主环境四向拼图**图**未就绪 → 禁止开第一刀衍生生图。第一刀同角切割图未就绪 → 禁止开该角衍生的衍生。缺对应参考图=失败，禁改挂他角/他主，禁无参考文生。
3. **主环境骨架未过关 → 衍生不得另起房间（≠留空）**：主环境 `generation_prompt_cn` 缺【四面内容基准】/四格标题，或已坍成单镜头 16:9 空镜 → 先在**本份 JSON 重写主环境骨架**；logic 可标 `upstream_main_env_grid_broken`。第一刀衍生**仍须**输出标准 §B 截取句（点名所属主环境+宫格，非空）。禁止把衍生 `generation_prompt_cn` 写成 `""`，也禁止另起一间房散文顶替截取句。
4. **一图四裁（仅第一刀）**：0/90/180/270 只是同一张四向拼图的四个宫格放大。§B 不重锁拓扑、不重报件数、不重写光色。
5. **§B 必须钉死宫格坐标（第一刀；与 N 同核）**：`N=0→左上0度格`；`N=90→右上90度格`；`N=180→右下180度格`；`N=270→左下270度格`。§B 须可检索该宫格全称；写错格、只写「对应宫格」、或截 0° 却点名 180° 格=失败。
6. **切割去拼图痕迹（强制；第一刀最高）**：成稿须为该宫格放大后的**单张完整镜头**。禁止把四向拼图的宫格分割线、宫格边框、格标/角标（如「0度格」「左上」文字）、十字拼缝、邻格漏边带进成稿。邻格内容不得作为本镜头第二条分界。衍生的衍生参考图已是单镜头，**禁止画回**上述痕迹。
7. **衍生的衍生挂同角已切割（强制；对应准确）**：`{N}度{主}_{状态}` 的 `visual_dependencies`=`ENV:[{N}度{主}]`（或该角上一状态行）。N 必须与被依赖行相同。§B 以该切割图为本镜头，§C 只写真正变化的实体；**禁止描述未改实体**；变化实体名须与原名**逐字符相同**（不得重新取名）。**禁止**再从主环境四向拼图重切，**禁止**挂他角切割图。
8. **禁止角度互挂当参考图**：180° 不得 `visual_dependencies=ENV:[0度…]`；也不得挂 CHAR/PROP/海报/他主。同基准他角互挂=失败。第一刀不得把 `{N}度…` 当四向拼图父。

- **§A 参考定位（仅 `dependency_strategy.logic` + `anchor_description`，不进入 `generation_prompt_cn`）**：写清 `所属主环境=` + `截取宫格=`（第一刀）或 `同角切割父=`（衍生的衍生）。不要在 §A 重写开篇拓扑或楼底。
- **§B（仅 `generation_prompt_cn`）**：第一刀用 §2.5.5 **只切割句**（截宫格 + 去分割线/格标；不写正对/正交/景深，不写开篇拓扑/楼底/坡向）。衍生的衍生只写「以同角已切割图为本镜头」，不重切、不复述几何、不画回拼图痕迹。不重述未改陈设。
- **§C 状态 Delta（衍生的衍生强制有可见 Delta；追加在 `generation_prompt_cn`；最高）**：只写相对同角切割图的**可见差值**。
  1. **禁止描述未改实体（最高）**：未发生形状/结构/可见光色变化的实体**一句都不写、一个名字都不出现**。未改实体由参考图继承，禁止为「画面完整」复述桌椅门窗墙地天花等未改件。
  2. **实体名与原来一样，不得重新取名（最高）**：§C 点名的每一实体必须与 Index 固定清单 / 主环境四面已写名 / 同角切割图已用名 **逐字符完全一致**。禁止润色、规范化、翻译、缩写、同义替换、加前后缀、合并拆分（`石碑` 不得写成 `残碑`/`古碑`/`那块碑`；`百叶窗` 不得写成 `窗叶`/`blinds`）。无名则本条不得写该物。
  3. 可写：①光色/氛围短增量；②**仅上述已更名锁定的已有实体**的形状/结构短差值（倾侧、开裂、塌陷一角、折断、卷曲、积沙改原形轮廓等）。不重写该实体材质长文、不补原清单没有的新陈设、不另起一间房、不把 §C 写成新空镜。无可见 Delta 则本行不应作为衍生的衍生。不改构图、不重切宫格。
- **衍生 `anchor_description`（强制）**：3–5 英文短语只含本宫格可见结构；禁对向实体、禁 invisible/behind camera。

**转角（内部→logic）**：衍生 0° 正面 = 主环境 N°；90/180/270 = `(N+90/180/270)%360`。转角公式只用于主环境四面成稿与 logic 核验；**衍生 §B 不写转角、不写开篇拓扑、不另造楼底**。`lens_profile`：Master/建置=Wide；OTS/反打=Standard（禁广角）。

**四向细节补充**：仅主环境可增；衍生不做独立拆分；logic 标 `supplemental_entities:{…}` 或 `无`；禁新增 Index 行。**分位**：增补**允许落四面**围合立面/贴墙/边缘（含靠边屏风/边柜）；**禁入表演中央**（主舞台走位/对峙区）；靠边常用配置按上游清单可视化；违者废弃重写。

**状态/特效/氛围衍生**：无角状态行→主环境；有角再状态/状态后视角→**同角已切割衍生**（或该角上一状态）。命名含角度（如 `{N}度{主环境}_{状态}`）。特效须写①作用范围②受影响具名实体及可见变化；禁「能量弥漫」无落点；人物/临场道具特效归 CHAR/PROP。
- **衍生的衍生**：`visual_dependencies=["ENV:[同角已切割衍生名]"]`（N 必须与本行一致；禁挂他角、禁在已有同角切割时回挂主环境四向拼图）。`generation_prompt_cn` 可检索 `所属主环境={Index 主环境名}`；§B 以该切割图为本镜头；§C 只写变化（**禁止描述未改实体**；变化实体名与原名逐字符相同，不得重新取名）。Index `reference_env` 与生图依赖同核（同角父）。

#### 2.5.5 字段形态骨架（禁照抄剧情）
- 第一刀衍生 `description_cn=""`；logic：`spatial_axis=…；lens_profile=…；axis_crossing=…。所属主环境={Index 主环境名}。截取宫格={左上0度格|右上90度格|右下180度格|左下270度格}。`

- **特别行例外（Stage 1 `特别表述=`）**：Index/`special_note` 有原文则必须整句注入 `generation_prompt_cn`（可检索`特别表述=`）。以所属宫格为空间基准，按该表述改俯仰或透视；禁止只切割、禁止丢弃该句、禁止给无该字段的普通行补造。`特别表述=变形:` 时允许荷兰角/倾斜地平线。
- 衍生的衍生 logic：`所属主环境={名}。angle_key={名}|{N}。同角切割父={N}度{名}（或该角上一状态名）。状态Delta=仅变化项；形状Delta=仅已变具名实体（原名逐字符）相对原形的短差值（无则省略）。未改实体=不写。`
- 衍生的衍生 `generation_prompt_cn`：`所属主环境={所属主环境名}。angle_key={所属主环境名}|{N}。以已切割的同角衍生「{同角已切割衍生名}」参考图为本镜头最终画面。16:9，高分辨率。不要改构图，不要重切宫格，不要描述未改实体。禁止画回宫格分割线、格标或拼缝。` + §C `在此画面基础上叠加…`（只写变化实体；名称须与原清单逐字符相同，不得重新取名）。

### 2.6 纯空镜去角色化与门禁（最高硬约束）
环境资产的目标画面是**无人空镜**——只画空间、建筑、固定陈设、材质、光色与空气感。

**`generation_prompt_cn`（含主环境【四面内容基准】各向 / 【四向拼图】引用段 / 衍生 §B 与可选 §C；§A 仅在 logic）绝对禁止**：
1. **任何人像实体**：具名角色、匿名群演、路人、手/足/肩/背/剪影、焦外人影、倒影中的人、雕像以外的拟人主体（雕像仅当上游固定清单已列）。
2. **任何人物语义**：人称（他/她/他们/某人）、站位/姿态/视线/对白/口型/持握/交互/走位/跪拜/对峙等动作叙述。

### 2.7 全域光影（光学权威 · 美观不平板；环境与海报均适用）
继承 common §1.5-A；与 §2.9 色谱联动。  
**目标**：环境空镜**好看、有体积、有亮暗呼吸、不平板**——同一时段下仍须见 Key 方向、Fill 托起、FG/MG/BG 受光差、半影/投影与材质光学响应；禁均匀平光、禁整室同亮、禁只写「有光/电影感光影」。

#### 2.7.0 定位 × 目标 × 情绪表达驱动选型（最高；先于开灯；禁默认模板）
光学工具不是通用配方。须先读 Index：
- **定位** = `basic_positioning`（体量档 + 气质/类型；番位只进 logic）+ 已写的 `style` / `social_status` / `literary_atmosphere` / `appearance_cues`。缺 `basic_positioning` → logic 标 `upstream_missing_basic_positioning`，体量仍须与固定清单密度自洽。
- **目标** = `env_goal`（`本场空镜须` + `可见落点`；`服务=`只进 logic）。缺则读`继承主环境`或标 `upstream_missing_env_goal`。目标驱动空镜必须看见什么、达成什么；**≠** `purpose`（观察用途）。光学九项仍由定位×情绪裁定，目标把可见落点钉进构图与陈设。
- **情绪表达** = `scene_mood`（主情绪 + 空镜表达 + 光色倾向 + 构图倾向）。缺则 `upstream_missing_scene_mood`。

下列九项须**同时服务定位与情绪**，写入主环境全局 `光影体系`（成稿写可见结果，**禁 EXIF**：`f/1.8` / `1/48s` / `ISO800`；禁推导过程句）。四向拼图空间合同不豁免：四格仍统一适度景深、背景可读，**禁止**用人像浅景深兑现情绪。衍生 §B 不重述本表；§C 仅写可见光学 Delta。

**logic 不成稿**：可写 `光学选型：定位=…｜情绪=…｜焦段偏=35|50｜光比=…｜柔硬=…｜自然光=…｜实用光=…`；可另写 `换角光变：0=…｜90=…｜180=某源不可见但续效写近端受光、禁写该源名｜270=…`（源名只进 logic，不进该向宫格）。`generation_prompt_cn` 只写上表可见结果。

**成稿可见动机光口径（强制，与 common §1.5 对齐）**：logic 可规划全场动机光；**主环境全局共享写全场世界光规（具名+落位+色温；换角不关灯）**；**【四面内容基准】各向**只列本向画内**可见**动机光落点，1–3 具（上限 3），并强制写 `本向光变`；**【四向拼图】段不重列光源**。衍生从目标宫格继承该可见光秩序，只有 §C 发生可见光学 Delta 时才追加该 Delta，禁在 §B 重列光源。日景默认 ≥1（室内宜 ≥2）可见动机光 + 反射 Fill；覆盖不足时补充反射/渗光效果，**禁臆造机位后新灯凑数**。夜景/气候差见 §2.8。成稿具名可见源 **禁止 >3**。

**换角光变与不可见源续效（最高；只锁主环境四向成稿）**
1. **世界光一次、四格续效**：全局 `光影体系` 锁全场动机光。换角**不关灯、不另起一套光**。四格都是同一套世界光的正交投影——入射侧、Key/Fill/Rim 角色、投影朝向随观察轴变，光源本身不变。
2. **明确本向光变（强制；每向可检索 `本向光变`）**：每一向中景须写本向相对光向——可见源在本向扮演 Key / Fill / Rim 哪一种、**入射用画面坐标**（近端/远景/画左/画右，禁写「朝0度背景」这种世界度数当光向）、投影朝哪、近中远哪层更亮。禁止四向抄同一句「窗冷光+台灯暖」。禁止把邻格的侧光句抄到本格。
3. **不可见面光源继续起作用**：落在机位后方 / 对向扇区的灯、窗、门洞渗光，换到该格后**灯具不可见，照明仍在**——须落成可见表面上的受光、勾边、投影或色温。禁止因「灯看不见」就把该格写成无方向平光或把那盏灯关掉。
4. **绝不可把不可见光源写入该向/该格提示词（最高；防被误解为要画出该灯）**：
   - **禁止**点名本格看不见的灯具/窗洞/门洞光源（`黄铜台灯` `百叶窗` `半开木门渗光` `180度正门` `客栈正门斜阳` 等，只要该源本格不可见）；
   - **禁止**写「机位后方有…灯」「不可见的窗在身后照来」「后方台灯轮廓光」「身后门洞渗光」「180度正门不可见但斜阳…」等工程句或源名——点名不可见门=失败（生图常把门或侧光画进该格）；
   - 只写落在**本格可见表面**上的光效，**不带源名、不写身后/机位后/对向度数门窗**；
   - 不可见源的具名与落位只在全局 `光影体系` + `dependency_strategy.logic`；【四面】该向与【四向拼图】该格禁止出现该源名。
5. **可见源才具名**：本格能看见灯罩/窗洞/灯槽/敞开正门才写源名+效果。中区 Practical 几何可见则四格均可具名；全挡则不点名、只写受光。
6. **身后 Key 必须锁画面入射（最高；用户案：0° 把正门斜阳画成右侧来光）**：全局 Key 若落在本格机位后方（Key 扇区=`(N+180)%360`，如 Key=正门180°、本格=0°），成稿**必须**用画面坐标钉死，缺任一项=失败：
   - **入射**：`主光从画面近端射向远景背景主立面`（光跟着视线往深处走）；
   - **投影**：`地面长投影从近端拉向远景背景，影子落在背景立面/背景家具朝镜头的面上`；
   - **禁侧光**：`禁止画面左或右侧作主光入射`（那是 90°/270° 格的侧 Key，不是本格身后 Key）；
   - **英文钉**：`key from camera-near toward background; long shadows fall into far wall; forbid side key from frame-left or frame-right`。
   - ❌ 只写「斜阳续效、投影朝向0度背景」无近端→远景+禁左右侧光 → 生图常抄 90° 格从画面右打进来的体积光（用户客栈案）。
   - ❌ 写「180度正门不可见但斜阳从某侧来」→ 既泄漏源名，又把身后光扭成侧光。
   - ✅ 0°（Key=正门在机位后）：`本向光变：可见源=顶部天窗漫射作Fill；主光从画面近端射向远景柜台立面，地面长投影从近端拉向远景背景；forbid side key from frame-left or frame-right。`
7. **四格光向速查（Key 扇区一次锁定后，各格只写画面坐标）**：

   | 本格 N | Key 在 N（背景） | Key 在 N+180（机位后） | Key 在 N+90（画右） | Key 在 N+270（画左） |
   | :--- | :--- | :--- | :--- | :--- |
   | 入射 | 从远景背景射向近端（逆光） | 从近端射向远景背景 | 从画面右 | 从画面左 |
   | 投影 | 影子拉向机位/近端 | 影子拉向远景背景 | 投向画面左 | 投向画面右 |

   客栈高频：Key=180° 正门斜阳 → 180° 格=远景逆光、影向近端；0° 格=近端→远景、影向柜台、**禁左右侧光**；90° 格=从画右来、影向画左；270° 格=从画左来、影向画右。四格光向必须互为正交投影，禁止 0° 与 90° 都从画面右来光。
8. ❌ 坏例：180° 格写「机位后方百叶窗6500K」；0° 格写「身后半开木门渗光」或「180度正门不可见但斜阳续效」；0° 格主光从画面右打入（抄 90°）。
9. ✅ 正例：180° `本向光变：可见源=敞开正门斜阳作远景强Key逆光+天窗Fill；近端桌面与椅背受暖红逆光勾边，投影拉向近端/机位。` 0° 用上条第 6 款正例（不写正门）。90° `本向光变：可见源=画面右缘门框侧沿透入的暖红侧Key；投影投向画面左。`（只点名本格可见的门框侧沿，不写完整正门）。

**C 防平板（最高）**：
1. **禁均匀平光 / 整室同亮**：无主方向、无亮暗分区 = 失败。
2. **禁只写标签**：仅「侧光/氛围光/电影感」而无来源·范围·效果 = 失败。
3. **禁无 Fill 托起的死黑窟窿**（恐怖压暗场除外且仍须最小动机光可读）：暗部须有反射或第二 Practical 托起纹理。
4. **禁臆造机位后方新灯凑数**；已声明的不可见源**继续照明**，但**禁止**把该源名或「机位后/身后有灯」写入该向/该格提示词——只写可见表面的受光/勾边/投影/色温（见上「换角光变」）。
5. **禁门外渗光却门紧闭**；半开/全开才可写门洞 Key/渗光。

7. **活动区净空不豁免光层**：表演净空可无立体增补，但地面受光/投影、远景墙渗光、边缘 Practical 仍须承担纵深光层——禁因净空而整场平光。

**E 柔和侧逆光 + 环境反射 Fill**（真人优先；三维/二维改 §2.11/§2.12 语言）：半影自然柔散；禁硬阴影刀切；海报群像同口径。默认照度充足、主舞台可读；大光比见 common §1.5-A（≠无脑压黑）。

### 2.8 夜景与气候差（剧情允许时 · 美观仍须层次）
触发：夜/雨夜/雾雪霾风暴/浓阴等；恐怖刻意压暗除外（须写依据，仍保留最小可读动机光）。

**原则**：≠整室漆黑，亦≠单点昏灯平板；成稿可见动机光仍**上限 3**（与 §2.7 / common §1.5 一致）；靠反射/渗光效果补覆盖与**纵深光层**。三路径择一或组合并显式写出：①强化自然主光（月/城市穹顶/湿玻璃反射等）②暖调 Practical 覆盖（≤3）③多人工可见源≤3 + 反射接力。最低：显式时段/内外/气候/季节；中景主舞台+≥1 动线在作用范围内；**FG/MG/BG 仍须可辨受光差**（可用湿反射、窗渗、灯池接力）；禁单点昏灯无层次、禁 >3 成稿具名源、禁在该格点名机位后方源（续效只写可见面受光）、禁整室死黑无 Fill。

### 2.9 色彩体系（色彩权威 · 美观不单调）
继承 common §1.5；不得与 Stage 1 `color_spectrum` 主冷暖冲突。  
**目标**：环境空镜**好看、有色层、不寡淡**——同一主冷暖下仍须见主辅对比、点缀提神、FG/MG/BG 色相/明度差；禁单色平涂、禁灰褐糊成一片。

**A 规格句式（主环境强制；须写入主环境 `generation_prompt_cn`，紧接开篇时段气候后）**：衍生由对应基准宫格继承本规格，§B 不重述；仅 §C 写可见色彩 Delta。
`色彩体系：场景情绪={Index scene_mood 主情绪}｜主冷暖={四选一}｜色系={具名双主干，如旧木褐+煤灰蓝}｜色温：主光{K}、Fill{K}、阴影{偏色}｜饱和度：主舞台{中高可读}/远景{略降}｜色彩结构：主色{具名表面×≥2}/辅色{具名表面×≥2}/点缀{物体+部位+面积}/过渡{距离层×≥1}｜纵深色层：前景={色+材质}/中景={色+材质}/背景={色+材质}｜影调：{Key:Fill+对比}｜分离色调：高光{…}、阴影{…}｜色彩构图：{视线引导/层次分离/提神点；须响应 scene_mood 构图倾向}。`
**纵深色层与色彩构图同是方法**：全局必须写；每一向后景/中景再落到本向可见表面（近端地面色、中景家具色、后景立面色）。禁止只写全局、四面不再体现；禁止用一篇色彩构图总述顶替四向拆分。

**B 落点（美观强制，缺一失败）**：
| 层 | 最低要求 | 美观意图 |
|----|----------|----------|
| **主色** | ≥2 具名表面（墙/地/主家具等），色相可辨；**顶格（§2.4.3）→ ≥4** | 定场气质，禁「深色/暖色」抽象词 |
| **辅色** | ≥3 具名表面，与主色**可辨色相差**（非同灰不同明）；**顶格 → ≥5** | 破单调；冷暖对比题材须至少一暖一冷落层 |
| **点缀** | ≥1（宜 1–2），写物体+部位+形态+面积+受光；总面积约 **20%**；**顶格 → ≥3** | **提神色**（金属高光、织物、釉面、植物、灯罩暖芯、铭牌等）——禁零点缀导致发灰 |
| **过渡** | ≥1 距离层或材质衔接带 | 主辅之间的桥色，防色块硬切或糊成一团 |
| **纵深色层** | FG / MG / BG **各写一句**具名色+材质 | 近端可略饱和/暖或冷偏移，远端略降饱和或偏雾——形成呼吸感 |

**C 防单调（最高）**：
1. **禁单色平涂**：全场同一色相仅明度变化 = 失败；至少主+辅两套可检索色名。
2. **禁灰褐糊**：无题材硬核销时，禁止整室「脏灰/褐灰/水泥灰」单主干；须用辅色或点缀拉开（木作/织物/金属/釉面/植被/天空渗光等）。
3. **禁只写冷暖标签**：仅「冷调主导」「偏暖」而无具名表面色 = 失败。
4. **材质绑色**：每条主/辅/点缀色须挂**可见材质**（漆面/石材/织物/金属拉丝等），让色有质感而非色卡贴纸。
5. **亮暗分色**：亮区与暗区色谱分写（可同色系不同明度+微偏色）；冷暖对比题材须 Key/Fill 冷暖落在不同距离层或不同具名表面。
6. **活动区净空不豁免色谱**：表演净空无立体增补，但地面贴层、远景墙面、边缘点缀仍须承担辅色/点缀落点——禁因净空而整场无色层。
7. **禁自然场绿蓝垄断**：外景/山景/自然空镜若主色+辅色+天空均为绿/蓝系且无黄/红（或琥珀/赭石/绛紫）可核销穿插 = 失败；须按 §2.4.1 补非常规色。
8. **禁室内样板间色谱**：室内若仅「白墙+木褐+灰软装」三色循环、无非常规立面色块/材质对撞/异色点缀 = 失败；须按 §2.4.2 补辨识点。
9. **与定位目标 + `scene_mood` 同核（强制）**：主辅点缀冷暖须能核销 `basic_positioning` 气质品级与 Index 光色倾向、构图倾向（压迫≠无据满室暖黄喜庆；精致小屋≠宫殿金碧；纵深压迫须近中远色层可辨；负空间远景可降饱和）。缺 `scene_mood` 已标回流后，仍不得与 `color_spectrum` 主冷暖打架。

**D 四向 / 衍生 / 海报**：
- **四向拼图**：全局色彩规格**一次声明**（共享主辅点缀秩序）；各格须写出**本格可见表面**上的色落点（背景墙/地面/主家具受光色），不得只抄全局句而各格无色；邻向窄条可带邻向辅色边缘，仍守邻向贴边窄条规则。
- **衍生**：§B **继承而不重述**基准宫格的主辅点缀；§C 仅写光学/状态导致的色温·饱和·点缀 Delta（如雨湿加深、火光染暖）；禁另起冲突主色谱。
- **海报**：标题区与主视觉须有明度/色相对比；rim/环境色挂靠 ENV 光源；禁灰片糊标题。
- 三维/二维按 §2.11/§2.12 转译语言（二维可用色块分层，仍须主辅点缀可辨）。

**E 自检口诀**：删掉「电影感/高级感」后，能否指出——哪两块是主色、哪两块是辅色、提神点缀在哪、近中远三层色差在哪、**色层如何核销 `scene_mood`**？自然场能否指出黄/红穿插落点？室内能否指出非常规辨识点？顶格场所（§2.4.3）主色≥4 / 辅色≥5 / 点缀≥3 是否可数？任一否 → 重写色彩段。  
`negative_prompt_en` 可追加：`monochrome wash, muddy gray-brown palette, flat single-hue grading, desaturated mush, no accent color, uniform color field, generic all-green forest, default blue sky green trees only, white-box interior, showroom flat palette, cheap miniature palace, generic immortal mountain template`。

### 2.10 对话正反打与 OTS

- 标题：安全区/指定位；低噪声底；明度/色相对比；禁高光/特效压标题；副文案版式稳定。
- 拆解上游 `entity_attributes` 为可见元素；`generation_prompt_en=""`。

### 3.3 画幅与移动端
- 显式 `4:3 poster canvas`（写进提示词，不另设 JSON 键）。
- 标题建议 y=30%–35%、x=20%–80%；保留右侧按键区与底部菜单/字幕净空。
