## 核心任务
**【原文逐字落地（最高；禁虚化）】**环境规划中的环境名、环境文学须原样写入；禁止「同原文／按原文／见原文／如上／略」。**`environments[].name` 必须与上游 IDENT `[ENV] 名称=` / `name`（及【主环境】注册名）逐字符完全一致**；禁止润色、近义改写、补后缀、缩短或另起同义名。
**本轮只设计主环境**。用户侧只读三块：`项目信息` +「封面海报简报」+「环境规划」（`SCENE_ENV_IDENT` +【主环境】/【未落清单】）。**禁止等待、索要或依赖「待分析剧本」/逐场分析/下游编排产出/Subject Index。**禁止输出 `{N}度…` 视角衍生或状态衍生（衍生由后续程序入库）。读注入「封面海报简报」写 `posters[]`；无简报则 `posters=[]`。完成主环境设计稿（开篇世界物理，止于【构图】），并无损封装为 `environments`（及可选 `posters`）。禁止输出【四向拼图】与宫格画面句。四宫格由独立技能根据本设计稿转换。禁止处理剧情切片、动作编排、实体抽取、角色设计或其他实体类型。

**表演区空间锁（最高；禁擅自加主体）**：严格遵守环境规划【主环境】对表演区 / `activity_space` 的空间要求。**主舞台区继承（最高）**：开篇必须逐字抄规划 `主舞台区=` / `舞台范围=` / `舞台大小=纵深=` / `开间=` / `可容=` / `舞台净空=剧情动线可通行` / `动线=` / `挂靠锚点=` / `锚点落=`。禁止另起近义舞台、禁止改范围、禁止改步档。步档译米闭集=`贴身=0.4米｜一臂=0.7米｜两步=1.4米｜三步=2.2米｜五步=3.6米`；开篇另写 `舞台占地=`（纵深米×开间米；纵深沿挂靠轴向，开间沿正交轴）。主舞台不要求整片净空。规划已有的床、窗、桌照画在原位。`动线=` 那段路中间不另加障碍，两端本身留下。禁止为好看、凑套再加规划没有的实体。禁止为了画成空地删掉规划已有的床、窗、桌。**高挑/宏大例外（§2.4.3 E）**：须有成人日常尺度的静态衬托（室内桌椅、室外栏杆/普通树等），只落贴墙/贴缘/回廊，**禁止**塞进表演中央；优先消费已列件，无则最多补 1–2 件围合层贴边件。
**美观化环境细节（本环节）**：材质、纹样、收边、表面装饰和光色细部在这里写，贴在规划已锁的主体和封闭面上。墙、地面、天花和家具各自写可见的材质与表面。不改规划的主体名单、落点、走向和同面序，不另起只为好看的具名主体，不把装饰挡在 `动线=` 中间。
**站位参照物识别（最高；视频模型要在参考图里认准这一具）**：开篇逐字继承规划 `参照物=`、`类=`、`落点=`、`识别=独一轮廓`、`醒目光`。这一具必须画成全场最容易被单独认出来的环境主体：轮廓与相邻件拉开，同一种不另画第二件，醒目光只打在这一具上、不挪到旁边的墙或另一件家具。落点仍是规划的东南西北，开篇把米数补在这一落点上，禁止换边。类=地面标记时，地毯、纹路、灯带、褪色标志保持贴地，不抬成立体障碍，不改舞台净空。规划缺 `参照物=` → logic 标 `upstream_missing_reference_subject:回流环境规划`，本环节不另造一张不该有的桌或一棵不该有的树。
**商业宣传片美化（叠在规划上）**：规划或剧本已写 `美化光=` / `点缀装饰=` 时，光色写入开篇与实用灯，点缀只落贴边/贴墙/台沿；**禁止**改空间身份、禁止改视觉还原/规划已锁外形材质、禁止把点缀挡在 `动线=` 中间。未列点缀不得为「更好看」自增。

**规划与定点分工（最高）**：环境规划只给五区自然语言主体与所属向（哪面有什么、几件、剧情裁定的 `开合态=`/`开闭=`、椅的功能朝向），且规划名单须已覆盖剧本提及的全部非角色、非道具环境主体，以及坐下、躺下、伏案等暗示承托。规划已写明确东南西北（北窗/东门/坐北朝南等）→ **本环节逐字继承所属向**，禁止改挂。规划每一具的 `依据=`、`落点=`、`走向=`、`同面序=`、`壁别名=` 逐字继承：落点仍是东南西北，开篇不改写成前、后、左、右；长边从东到西或从北到南保持原句；长边两端、短边两端和朝墙的朝向保持规划已写的壁别名，不换件、不改名；同面从左到右的顺序不另排。`依据=惯例` 和 `依据=参照锚` 的主体与明文主体一样入画。本环节不另起规划未列的主体。规划 `开合态=` 给出的 `开闭=全关|半开|全开` 是开闭真源：**本环节逐字继承、禁止改档**；禁止为采光、好看或框中画把全关画成半开/全开，禁止把规划的半开/全开收成全关。规划该扇缺 `开闭=` → `dependency_strategy.logic` 标 `upstream_missing_opening_state:{名}:回流环境规划`，成稿该扇只许按 `全关` 落笔。规划【活动空间】`整体环境锚点=`/`主舞台区=`/`舞台范围=`/`舞台大小=`/`舞台净空=`/`挂靠锚点=`/`锚点落=` → **本环节逐字继承主舞台区范围/大小/净空，并锁 `挂靠锚点=` / `锚点落=`**。四宫机位不在本技能。衍生 `anchor_description` 不在本环节另选：现场编排选用的环境参考主体由程序解析为 `简要特征=` 写入实体表，每条只写名称和所在位置（正面／左侧面／右侧面／机位后不可见），须覆盖这些已点名主体。禁止另起近义锚。`扇型=`、`开向=`、`通行扇=` 逐字抄环境规划。`心点=`/`距原点=`/`占地=`/`占场≈`/`场径=`/`共面=`/`宫格=`/`门轴=`/`把手=` 由**本环节**裁定。规划未给家具米数=正常，**禁止**回流要规划补坐标。规划已给 `舞台大小=` 步档 → 本环节按闭集译米写入 `舞台占地=`，**禁止**另改档、禁止用场径/3 改规划已锁大小。规划若误写家具米数，以本环节尺度闭集重锁，logic 标 `规划米数已重锁`。规划缺 `舞台范围=`/`舞台大小=`/`舞台净空=` → 回流规划，禁本环节自拟舞台。规划已列主体**禁止**蒸发；规划因暗示写入的椅、榻、桌视同已列，禁止删掉。规划已列的穿衣镜等室内不移动、不变化的主体必须入画，禁止当成道具裁掉，禁止改套 `PROP:`。规划漏列剧本环境件或漏列坐下所需座具时，不得擅自发明未列件顶替（回流规划）。

### 下游分镜失效（强制 · 工程契约）
- 分镜生成依赖本场景关联衍生 ENV 的【衍生环境信息】（所属主环境 / 背景 / 画左 / 画右）。光线只读该主环境 `generation_prompt_cn` 里、当前衍生度数对应宫格已经写成的 `源体可见=`+`源体画布位=`+`高度带=`+`影子投向`。不从开篇 `Key世界向=` 再算方向，不把开篇四壁抄进视频句。换衍生只换格，禁止另起一日（见 `shot_generation.md`）。
- **重跑/清除 `environments[]`（ENV 设计）时**：流水线**仅清除关联该 ENV（含同主环境族衍生）的场景分镜**，再在 ENV 就绪后重跑那些场的分镜；**禁止**把未关联该 ENV 的场次分镜一并清掉。
- **`posters[]` / 封面海报**重跑或清除**不**使分镜失效；海报不参与分镜 ENV 光学门闩。
- 角色/道具资产重跑**不**使分镜失效（CHAR/PROP 不注入分镜 CN prompt）。

- **复用既有主环境（上集/跨集注入）时**：主环境四向拼图与既有 `generation_prompt_cn`/Index 基准同核的是空间、外形和坐标系；各衍生截取的观察轴 `N` 与背景半空间须与该基准**同角完全一致**——禁止为「更好看」重映射度数、旋转 0° 轴、或按顺序轮写四向。开闭与落点以本场环境规划【主环境】为准：规划已改的门窗开闭、已移位主体的位置，按规划重写，禁止把旧稿里冲突的开闭或旧落点照抄回来。衍生只按 Index 已声明角与 `activity_fit` 截取所属扇区。
- **本技能只写开篇世界物理**。主环境 `generation_prompt_cn` 止于【构图】。禁止输出【四向拼图】、宫格标题和画面左/画面右。外形、大小、材质、纹样、颜色、柱径、占地外形、旗的色相图样形状、牌匾文字只写在【主体外形】。大小用米，无限制的一向写无限制。四宫格只返回【四向拼图】：开头一句共享光比、色温、柔硬、焦段、景深、半影和色板；每一格替换四壁的位置、朝向、走向、长短边，并各写构图和会随望向改变的光。程序写回时从本设计稿原样抄入【定位】、【主体外形】和【色彩说明】，中文提示词留这三节加【四向拼图】。四壁、六面一次、光学说明、构图不整节进入中文提示词，只留作下次旋转的输入。禁止输出视角衍生或状态衍生。
- **主环境骨架锁（最高；缺一即整条失败）**：主环境 `generation_prompt_cn` **不是**单张 16:9 可拍空镜，也不是四宫格。本技能只交开篇世界锁。四宫格由下一技能接在开篇后面。全文必须按序可检索下列字面标记，缺任一标记=框架破裂、废弃重写：`【定位】`、`【主体外形】`、`【六面一次】`、`【北壁】`、`【东壁】`、`【南壁】`、`【西壁】`、`【光学说明】`、`【色彩说明】`、`【构图】`、`六面一次`、`下=`、`上=`、`中=`、`北壁=`、`东壁=`、`南壁=`、`西壁=`、`壁别名=`、`场径=`、`围合=`、`向距上限=`、`面积测算=`、`整体环境锚点=`、`主舞台区=`、`舞台范围=`、`舞台大小=`、`舞台净空=`、`舞台占地=`、`挂靠锚点=`、`锚点落=`、`原点主体=`、`场态=`、`主光=`、`辅光=`、`点缀=`、`源形=`、`Key世界向=`、`物理系闭集`、`主体编号表=`、`主体分组=`。成稿须分点自然语言（`- ` 起行）。开篇锁键不得省（`场径=`/`心点=`/`距原点=`/`号=#N`）。主体编号表每一件都有 `距原点=北` 和 `东` 两轴。四宫画面转译不在本技能。

## 开篇世界锁（本技能成稿止于此）
开篇用东南西北和米锁世界，供四宫格技能旋转。本技能不写画面左、画面右、靠近镜头、远离镜头，不写【四向拼图】。
- **【主体外形】在本技能写完（最高）**：【定位】之后、【六面一次】之前，单开【主体外形】。主体编号表里每一件只一句：`[@短名]（{码}）外形={形体}，大小={高×宽×厚|长×宽|该向无限制}，材质={具体材质}，纹样={纹样|无}，颜色={色}。` 外形、大小、材质、纹样、颜色只写在这里。大小必须是具体米，或该向写无限制。只写高耸、巨大、宽阔、辽远，没有米也没有无限制 = 失败。四壁的占地、高度、进深、路宽与这一句是同一组米，不另起一套。四宫格不回写这一节，只写【四向拼图】。程序从这里抄入，大小米随这一节进入中文提示词。缺这一节，或某一件没有这句，或没有大小 = 失败。
- 每一具名主体写成 `[@短名]（{码}）`，写入 `主体编号表=`。码按物理身份：`F` 地面、`C` 天花或天空、`M` 中区与台面件、`N/E/S/W` 各壁围合及该壁贴附。`[@…]` 内禁止东南西北。
- 可定位件写 `心点=` 或 `台面心点=`、`距原点=`、`占地=`、`四向最远=`。原点是一具主体的中心，写成 `原点=中心｜北0东0｜原点主体={短名}`。只锁一具：舞台区中部有主体，且它的中心确实在中部，优先地上的主体，地面、甬道、地板、地毯可以。中部没有这样的主体，改选舞台边上的一具地上主体；挂靠在边上就用挂靠，否则用离中部最近的那一具。墙皮、立面、天花、天空、远山不当原点。场径从这一中心量。主体编号表里每一件都写 `距原点=北{米}东{米}`。北、东两轴都要有。向北、向东为正，向南、向西为负，落在轴上写 0。原点主体写 `距原点=北0东0`。无限制的那一轴写无限制，另一轴仍写米。`心点=正{向}`、`在桌=`、`落在=`、相对挂靠，都不代替这两轴。缺北或东任一轴 = 失败。
- 非正方件写该件自己的 `竖边=南北走向|东西走向` 和两端。挂桌座具写 `在桌=`。有椅面的写 `椅面朝向=正北|正东|正南|正西`。
- **壁别名（最高；逐字继承规划）**：开篇可检索 `壁别名=北=`、`东=`、`南=`、`西=`（舱轴场为 `前=`、`后=`、`左=`、`右=`）。四个名字逐字抄环境规划，不换件、不改名。每一壁标题下写 `别名={该壁主体名}`，并且该壁正文点名这具。这具只属于这一壁，不写进其余三壁和中区。有长短边的同句写 `长边两端={壁别名}↔{壁别名}`、`短边两端={壁别名}↔{壁别名}`。床的端甲、端乙旁写所贴壁的别名。`椅面朝向=` 朝一面墙时，括号里写该壁别名，例如 `椅面朝向=正南（房门）`。朝桌心仍写桌心。罗盘走向保留，供四宫旋转对账；认长边、短边和朝墙认的是壁别名。缺 `壁别名=`、别名与规划不一致、别名主体画到另一壁或中区=失败。
- **四格同一体量（最高；开篇锁，四宫只译）**：点名立柱、巨柱、石柱、通天柱时，每一根写 `柱径=` 一个数、`柱身=垂直于地面`、`柱顶=接到天花`、`柱径相对=`。同形的柱共用这一个柱径，写成 `柱径相对=与{参照柱}一样粗`。另一形写成 `比{参照柱}细一圈` 或 `比{参照柱}粗一圈`。盘龙、束柱、雕纹只是柱身花纹。哥特式肋线、尖券可以收向藻井，柱身不写成向穹顶中心倾斜。禁止只写「通高贯穿天花」或只写直径。每一座台、每一面门、每一列看台只有一个 `占地=`，外形词（八角、长方、圆、层数）只写一次。`舞台占地=` 是人走的那一块地板，不是这座台的第二个长宽。术语库里的高侧窗、玫瑰窗，只有这一壁开篇写了才落在这一壁，禁止四面都补。缺 `柱径=`、`柱身=垂直于地面` 或 `柱径相对=`，或同一座台写出两套长宽=失败。四宫画面句不在本技能。
- **正面封闭面（最高；高侧窗必须落壁）**：每一壁 `封闭面=` 点名这一面远处那一整面的那具主体。看台、座席、屏风、巨门就是这面墙时，封闭面写这具，不另留一张不点名的墙让它「贴在墙前」。高侧窗、玫瑰窗、尖券窗、天窗写入风格落点或术语落点时，必须同时是某一壁或 `上=` 的具名主体，并写它在哪一壁。只写「大面积高侧窗」却没有壁上主体，四宫会把窗画成望东或望西的正面。天花采光口只写在 `上=`，不写成壁上窗洞。东壁封闭面是看台，就不得再在东壁补一排高侧窗。
- 楼梯、台阶、坡道写 `低端=` 与 `高端=`。底面不贴地的件写 `落在=` 与 `离平地=`。
- 构图倾向、纵深光层、纵深色层只写在【构图】一次。四宫不回写这一节。各格构图只写方法和倾向，不点名主体，不写纵深色层。纵深光层仍按每一格的靠近镜头和远离镜头写入光学段。
禁止为了某一格的画面去改剧情已经要求的位置、朝向、开合和大小。

### 1.2A 项目语境注入（环境 delta）
通则见 common §1.2A。环境额外强制：⑦时段/时辰/内外/气候/气候可见/氛围/空气感/季节须写入**主环境**全局共享段并可画（权威=IDENT `时地=` /【主环境】已锁字段；未明示才合理推断，logic 注明）；**主环境光影规格（§2.7）+ 色彩规格（§2.9）**写在开篇（拓扑之后、【四向拼图】之前）；细节密度：四周/地板/天花量化只写开篇（见 §2.2.1），开篇用世界坐标，禁止把围合量化写成某一格镜头前中后景，禁止用复述心点/材质/光色凑条数——**开篇不写画面左/右**；四宫画面不在本技能。命中 §2.4.3 顶格场所时围合层取顶格条目且全场色·光·材·细纹·纹饰超额（仍只写在开篇；单条须写满表列维）；衍生只截取已达标的目标宫格，**不另写 >6 条陈设/光色细节**；仅在 §C 写可见状态 Delta。禁止另起【四面内容基准】。

**开篇句式**：`项目类型为{Project Context.Type 原词}，项目基础定位为{…}，项目全局风格为{…}，年代/时代为{…}，地域/国家为{…}，语言环境为{…}，风格定位为{本场风格模式+落点}。时段为{清晨|白天|中午|黄昏|上半夜|下半夜}，时辰为{子|丑|寅|卯|辰|巳|午|未|申|酉|戌|亥}，内外为{…}，气候为{晴|阴|雨|雪|雾|风|霾}，气候可见为{湿石|雨丝|雾霭|积雪|扬尘|阴云|无}，氛围为{主情绪}，空气感为{清透|薄雾|烟霭|尘土|雨幕|雪尘|闷湿|干冷}，季节为{…}。` + 类型 1–2 条正向落点 + 风格定位 2–4 条可视化落点。风格定位权威=IDENT `风格=` /【本场风格】，无则项目 剧本模式 / `base_positioning` / `Global_Style`；禁止用项目主风格覆盖本场改选。缺 `项目类型为` = 失败重写。**渲染制式锁（叠 common §1.6）**：`Global_Style` 含实拍/Cinematic/8K 而 §1.6=真人时，风格定位落点必须是可拍材质与光色，禁止开篇写「宣纸底/水墨晕染/皮影/线稿平涂」当画面载体；武侠真人走影游实拍（对标片英雄=色块剪影与压迫，禁灰墙金色小时明信片，禁把关隘画成水墨小品）。禁止开篇只写「日/夜」而不锁时段与时辰；禁止漏气候或氛围。城关/城门/关隘/城楼外景 `内外=` 必须为外，禁止写成内。

  **③认档**：牌坊/跨道坊、旗列、台上盏盘、壁贴案柜（未升格为②的）、有独立占地的角楼/谯楼/敌楼。角楼从女墙**拆出**，自锁心点+占地+四向最远+相对Oh，禁止与女墙共用一个 `心点=`，禁止只当女墙端乙名或「女墙与角楼飞檐」一条。室外独立门楼/殿/亭/塔有占地却不是围墙皮 → 走 Oh 或其余可定位件，不走档①、不走本档（除非挂在另一宿主面上）。
  **代数同核（②③通用）**：`件心 − Oh心点 = 相对Oh`。Oh 北11东0、件心北0东10 → 相对南11东10。写成 `心点=正东`=失败。画面左右米不在本技能。
  **端甲/端乙（②最高）**：`端甲=`=已锁触点那一端的具名主体+部位（宿主侧面、栏转角、梯下口）。`端乙=`=另一端具名或场内端名。禁止写成远山/地平/官道/隘口。禁止用 `东翼`/`西翼` 当端名。四格咬合对象必须与开篇同一对，只改画面读法。
  Oh 是参考角色（规划 `挂靠锚点=`），不是第五档；Oh 自己相对 Oc，见 §0。
- **场态三模（最高；先认模再选四宫句；室内句不得套室外）**：由开篇四向 `围合=` 派生，须可检索 `场态=`。禁止用房间五面句写山野，禁止用远山剪影句写厅堂通铺皮。
  | 场态 | 认模 | 上边界 |
  | :--- | :--- | :--- |
  | 室内封闭 | 四向皆封（门窗是封面上的洞，仍算封） | `上=`天花 |
  | 半封闭 | ≥1封且≥1敞（庭院/关隘/敞廊/瓮城/骑楼） | 无顶=`上=`天空；有顶廊=`上=`天花 |
  | 开阔室外 | 四向皆敞，或三敞+`无限制`（山野/官道/校场/云海/广场） | `上=`天空，禁止天花压顶 |
  各格正面与左右邻槽的画面句不在本技能。
  **档④换角（远山/天际/云海/远路；只换哪一份进正面）**：开篇按向锁 `远景=北={词}｜东={词}｜南={词}｜西={词}`。画面句不在本技能。
  **室外独立建筑（有占地，不是围墙皮）**：不走档①。是 Oh 或其余可定位件。心点必须是占地几何中心，禁止 `心点=正{向}`。非对称则开篇锁朝向；四宫只旋看见哪一面，外形与开篇同核。禁止铺满最远处，禁止邻向改成短头或把正立面宽边横过来。
  90°/270° 对调不在本技能。
  **无边界地被（沙/草/石板延展/官道面）**：只锁 `下=` 一次。四格都是同一地面向镜头下沿铺来。禁止写成 `北壁=草地`。该向 `场径=无限制`。
- **长轴物理一致性（条形实体统一合同；最高）**：下列对象**同一套**开篇锁轴 + 四格纵深/横跨成稿，禁止各写各的度数端话术：
  1. **中区长条**：长桌/长案/床/沙发等；
  2. **贴墙长条**：柜台/吧台/服务台/贴墙柜等（另锁 `M=所属墙`；操作面朝室内，`N=M` 见操作面）；**中区案台/书桌/条案走第1类**，禁止把书房中央案当贴墙柜台；未升格为②的贴墙案走③；
  3. **延续体=档②**：开篇一次锁 `竖边=` + `端甲=` + `端乙=` + `心点=`（几何中心），四宫只换画面读法，禁止改咬合对象。南北走向端甲/端乙=北端+南端；东西走向=东端+西端。贴边者认缘：东缘/西缘=`竖边=南北走向`；南缘/北缘=`竖边=东西走向`。**独立柱列**自己锁 `竖边=` + 两端，禁止只写 `同列=`。中轴路/廊认通达轴。梯另锁 `U=` + `下口=` + `上口=` + `低端=` + `高端=` + 坡向。路另锁 `通达=`+`路宽=`+`两侧边界=`。有法线的②另锁 `墙面朝向=`（与竖边正交）。室内板壁/粉壁/混凝土/舱壁走①，不套本条。④不是本条。**禁止**默认固化一种画面走向。权威表与 F/U 见 §2.5.3 / R17。
- **桌形制锁（有桌才触发；防正方形名吃掉长轴）**：凡开篇点名桌/案，须先写 `形制=正方形｜长方/条案｜圆桌`。无桌则本条不触发。
  - **正方形**：四边等长；四格桌面剪影都近似等边；**禁止**写短边/长边/纵深拉长/横穿长边。只写「朝{具名锚}的一边」。
  - **长方/条案**：必须写 `长:宽≈{≥1.6}:1`（禁约等于 1:1）；长轴 + 两端具名锚。四格是**同一张长方形**随观察轴**剪影倒置**，不是各画一张不同的桌：
    - 四格剪影（纵深格/横跨格）不在本技能。

- **允许美术增补**：见 §2.5；增补不得改拓扑、不得新增未列主体。**分位**：**四面只深化**规划已列围合立面/门窗/贴墙件的材质与细节，禁止自拟新具名主体；**中区不要求整片净空**——规划已有的床、窗、桌照画；`动线=` 中间不另加障碍；禁止为好看、凑套再加实体，禁止为了空地删掉已有的件。**唯一窄例外=§2.4.3 E 高挑/宏大尺度衬托**：无已列人体尺度件时，可在围合/贴缘补 1–2 件成人日常静态参照（室内靠墙桌椅、室外栏杆/普通树），禁入表演中央，须有场所功能借口。以上仅作内部美术裁决，**不得把“分位从简/四面允许加围合/中区默认空区/靠边常用配置”等元规则写入 `generation_prompt_cn`、`anchor_description`、环境叙述或logic的实例化结果**；成稿必须改写成最终实际存在的具名实体、具体靠向/扇区与具体净空，没有采用某类配置就完全不提。**场头空间位置关系锁定（对齐环境规划）**：门/窗/主家具/出入口/活动区相对与四向归属只读继承；禁把单门扩成多门、禁把门桌对调或换向；**表演中央禁增补立体障碍**。
- **固定实体零遗漏**：清单内每一实体须进主环境开篇 `generation_prompt_cn`；禁止因「次要」省略。上游【主环境】已点名 `背景微动件=` 且非`无` → 该细小件须在其落点所属向**可见入镜**（贴墙/窗沿/空中/檐下即可），**禁止**画进中区舞台或挡动线；禁因「次要」省略。**中区/靠边地面家具只在开篇锁一次**（`心点=`/`距原点=`/`占地=` + `锚=`/`宫格=`/`落边=`；非正方件加 `竖边=`；挂桌件加 `在桌=`；有前后向的椅/沙发写 `椅面朝向=`；桌禁写 `椅面朝向=`。成稿禁止写 `F=`）。只写锚/宫格、不写极坐标=失败。各格可见面不在本技能。禁止③与①/②共用一个 `心点=正{向}`。**通高须共享外形**：下层与上层实体须在开篇拓扑及可见格**分别具名**；禁止 `二楼同楼下` / 只画一层而让上层「继承」。**二层内部不共享外形**则为独立主环境行（可 `StyleReference` 挂一层主环境作风格参考），禁止把客房/账房家具画进一层大堂四向拼图当「上层」，也禁止用风格依赖省略本块四向。
- 专属字段 + 时段/时辰/内外/气候/气候可见/氛围/空气感/季节须写入**主环境** `generation_prompt_cn`；衍生只继承目标宫格，除非 §C 有可见状态 Delta。

### 2.2 舞台与空间实体化
- 围绕上游 `{Stage}` / `activity_space` / `activity_fit`：**环境描述须服务剧情活动空间**——先锁定表演区/动线/站位承载/出入画口的空镜几何，再落固定实体与边界（**分位从简**：四面只深化已列围合；中区照画规划已有的床、窗、桌；`动线=` 中间不另加障碍），再分层/光照/Delta。核心舞台保证剧情动线可走。
- **建置剧情空间分析（最高；设计前强制）**：须据环境规划 `activity_space`/`activity_fit`/`purpose`/`basic_positioning`/固定清单槽位分析本场空间使用——对峙纵深、逃窜动线、入座/上床可达、桌面操作区、出入画口净空、**高速穿梭/追逐/飞翔航线净空与过幅参照**——并在四向拼图**预留**这些空间。命中高速场另走 §2.4.5。只转译无人称几何与规划已列家具槽位（座具默认相对桌子：位置+朝向都认桌子、椅面默认朝桌心；主位对门/驾驶座朝挡风仅开篇明文另锁，见 §2.5.3；床头侧）。**禁止**把角色名/人称/谁坐谁逃写进 `generation_prompt_cn`/`anchor_description`（空镜逻辑）。无规划中区件却被家具堆满=失败。
- **基本定位尺度闸（读 Index `basic_positioning:`；最高）**：主环境须先吃叙事定位中的**体量档+气质/类型**（如`女主婚前住房，不大，精致小屋`→空间紧凑、精致小屋完成度，**禁止**扩成豪宅/宫殿四向或堆满大件）。**定位同时驱动 §2.7.0 光学选型**（体量→焦段偏置；气质/类型→光质/实用光/照度档），不只锁空间尺度。番位归属（女主/男主/「谁的住房」）只进 `dependency_strategy.logic` 并标「不成稿」，**禁止**写入 `generation_prompt_cn`。衍生行继承所属主环境本句，不另改尺度档。缺键则 logic 标上游缺口，尺度仍须与固定清单密度自洽。
- **环境目标闸（读 Index `env_goal:`；最高）**：主环境须核销本场空镜任务——`本场空镜须` + `可见落点` 转译为无人称空间语，四面/四格须能看见该落点（半开门、空椅、仪式中轴等），**禁止蒸发**。`服务=`卖点名只进 logic。视角衍生写`继承主环境`则跟主环境落点；状态衍生若有目标 Delta 只写变化。**≠** `purpose`（Master/反打观察用途不得顶替目标）。缺键则 logic 标 `upstream_missing_env_goal`，禁臆造卖点。人名/人称禁进成稿。
- **外形四维（环境设计真源）**：Index `style`/`social_status`/`literary_atmosphere`/`purpose` 及 `fixed_*` 外形定语凡已写须转译——风格与氛围进四向拼图可见材质/完成度；场域地位定陈设品级（小康小屋≠王府正堂）；作用/番位只进 logic。禁丢掉「精致/素净/礼制」只堆家具名。
- **软性外形决定因素（读 Index；最高）**：`appearance_cues`/`social_status`/`style`/`purpose` 凡已写须驱动空镜完成度——`精致`→细节精巧控杂、禁扩豪宅；`高贵/华贵`→材质品级与维护度；`素净`→少陈设留白仍可读；特殊用途（礼制正堂/会客）定陈设档。`appearance_cues` 原词须在主环境 `generation_prompt_cn` 可核销（气质/完成度句），禁弱化为「好看」。无该键禁臆造奢华或性感化空间。
- **剧情活动空间明示（最高；主环境 `generation_prompt_cn` 强制）**：上游 `activity_space`（主舞台/表演区｜动线｜站位承载｜出入画口｜命中时的高速空间项）须在主环境四向拼图中**可核销可见**——用空镜结构语写清「开阔站立净空区」「门→中区可通行通道」「座次区几何」「具名门洞出入净空」等；高速场另须可见「广角远距航道」「穿梭走廊净空」「灯杆列/窗格阵过幅参照」「近中远三处不同距离锚」「檐口/管线借力件」。保证后续剧情有实际可用的活动与调度空间；**禁止**只列家具堆满画面而无表演净空。衍生侧据 `activity_fit` 保证该角背景半空间与纵深可读，且不堵死该角所需动线/对峙纵深/航线。仍守 §2.6 Clean Plate：禁写人名/站姿/对峙情节句，只写空间几何。
- **交通工具内舱空镜（最高；独立主环境 + 按载具类型惯例）**：汽车内/客舱/**任何驾驶舱或操纵舱**（飞机驾驶舱、轮船驾驶台/舰桥、列车司机室、工程机械/航天器驾驶舱等）/轿子/马车厢/船舱/火车车厢须作为**独立主环境**画四向拼图，**禁止**画进舱外环境同一张拼图。出入封闭同场时仓外与仓内各画各的主环境四向拼图。座椅与操纵台几何必须可视化上游惯例：
  - **前向驾驶舱/操纵舱**：0°格正对前窗/挡风/驾驶台或仪表主视面；前向操纵位落在前端。**座椅惯例**：驾驶座/副驾/同向后排 `椅面朝向=正北（挡风）`，靠背朝舱尾；开篇须可检索 `椅面朝向=正北`。**禁止驾驶座背对仪表盘**、禁止椅面朝后舱壁当主位、禁止套厅堂「主位朝门」。成稿禁止写 `F=`。0° 格查座椅表见**椅背**（头枕朝镜、椅面朝仪表背景）；180° 格见**椅面**（椅面仍朝 0°，仪表在镜头后）。后方观察员/机组槽位若有，须位于操纵位的车尾/机尾/舰尾侧。轴向拓扑固定核销为 `后窗/后舱壁→后方槽位→前向操纵位→前窗/驾驶台主视面`，**禁止**把后方槽位画到操纵位与前窗之间。180°格正对后窗/后舱壁。**90°/270°格须横贯全舱，禁止只画半舱**：近镜头侧=该侧门窗框+该侧全部座位侧面；中部=其余座位侧面（驾驶座/副驾/后排各座有则全画）；正面=对侧窗。近镜头侧不得留空或整排省略。
  - **封闭空间相对槽位是建置接口**：空镜设计须为座位、操纵席、舱门侧、过道侧、床位等给出稳定具名槽位。座排从0°前向端往舱尾计数（最前/操纵排=第1排）；每排按面朝0°时的舱体左→右编号，写`本排共M位、左起第K位`，并附靠左/居中/靠右/靠窗/靠过道及与前排槽位左后/正后/右后关系。成稿与logic均须能核销唯一ID `第N排-左起第K/M位-功能名`；K不得重复、总位数闭合。无排式开放舰桥用控制台/操纵区编号与左起位序，禁伪造座排。禁只输出“后排右座”或“前景/画右”。每个衍生角须明确该角可见槽位、不可见槽位与可见面。
  - **舱型继承（最高；只消费规划）**：上游【活动空间】或定位已写 `舱型=` → 开篇与四向拼图逐字继承该种类和座位数，按这个舱画座椅。`7座旅行车驾驶舱，座=7，排=前2（驾驶座+副驾）+中3+后2` 必须画出前排两座、中排三座、后排两座；`单人飞行器驾驶舱，座=1，排=仅一个操纵席` 只画一个操纵席。禁止把已锁舱型改成另一种：7座旅行车不得画成轿车两排，单人飞行器不得加副驾或后排。驾驶舱/操纵舱缺 `舱型=`，或只写「驾驶舱」「飞行器驾驶舱」「汽车内」→ logic 标 `upstream_missing_cabin_type`，回流环境规划，禁止本层自拟成泛称驾驶舱。
  - **舱型差异**：在已锁 `舱型=` 之内落操纵位。汽车驾驶座在前排；飞机驾驶舱按飞行员/副驾驶操纵席；轮船驾驶台/舰桥按舵轮、主操纵台、观察窗与真实值守槽位；列车司机室按司机台。开放式舰桥/多控制台若各槽位朝向不同，按上游逐槽位呈现，禁止压成汽车式前后排或无据全员同向。单人舱不套双人飞机，多座旅行车不套单座飞行器。
  - **其他座舱**：同向乘员舱座椅靠背朝舱尾、坐面朝前；相对座两排长凳对向；轿子单座正对轿帘；马车先判车型。禁止把轿车后排画成会议对坐、把飞机驾驶舱与客舱合并、把舰桥画成厅堂围坐。
  仍无人称。上游缺座向/操纵位惯例 → logic 标 `upstream_missing_vehicle_cabin_orientation`；舱内被并进舱外 → `upstream_should_split_vehicle_cabin_main_env`，成稿仍按可核销舱型画独立舱。

3. **地板服务舞台（地面开篇必写）**：地面的外形、材质、纹样、颜色只写在【主体外形】。地面段只写分格、交接和位置。装饰拼花/地毯边/地灯嵌条优先落**边缘环带**，禁在表演中央堆立体陈设。四宫不重写地面句，也不把「留空以待」写进地面或中部。
4. **天空/天顶定气场（开篇必写；四宫上边界必须入画）**：外景用天空层次破「棚拍灰顶」；室内用天花/梁架/主灯分格破「白板顶」；与 §2.7/§2.9 光色联动。上边界写在开篇 `上=`。各格是否裁天上边界不在本技能。衍生截取继承基准格，不另裁。
5. **增补优先序**：四周已列立面的材质细节 → 地面贴层 → 天空/天花 → 边缘点缀；**最后**才考虑中景规划明文家具——且不得挤占 `activity_space`。**分位从简**：禁为凑配额把沙发/屏风搬进**表演中央**或自拟未列主体。

#### C. 中区舞台预留（与活动区净空同级）
1. **中景中央**：开篇中区须可检索 `舞台范围=` + `舞台大小=` + `舞台净空=` + `舞台占地=`（步档译米）。这些键写完即止，禁止再写成留空以待、给舞台留空间、无任何障碍、完全留空、净空无物、以待列阵。**禁**为凑细节配额向该区堆家具/盆景/立柱/箱柜。**净空≠删落边桌**：已锁 `落边=` 的桌贴所属缘。禁止把规划舞台改到另一侧或另起近义净空。
2. **配额与净空不冲突**：四周/地板/天空的细节条数靠**围合面与贴地层**完成，不靠中区加立体物凑数。
3. **硬核销家具**（对白桌/座次椅等）仅上游已列者可留中区，须同时写清其周围剩余净空与动线宽度感（空镜几何，不写人物）。
4. **自检**：若去掉中区所有非硬核销立体物后，四周+地板+天空细节仍达标且主舞台仍显开阔可调度、可通行 → 通过；中区一堆杂物才「看起来满」→ 失败。开篇缺规划舞台键或改档 = 失败。

#### D. 成稿锚点（世界一次 + 四宫只写画面槽）
开篇须能检索：`六面一次` + `下=`/`上=`/`中=`/`北壁=`/`东壁=`/`南壁=`/`西壁=` + `场径=` + `主光=`/`辅光=`/`点缀=`/`源形=`/`Key世界向=` + `舞台范围=`/`舞台大小=`/`舞台净空=剧情动线可通行`/`舞台占地=`（光源与光照方向属物理世界，先于机位；主舞台区逐字继承规划）。`封` 向须可检索 `封闭面=`，`敞` 向须可检索 `远景=`。四宫画布与各格画面句不在本技能。山景/仙境外景开篇另须可检索 `山水层=`（≥4 层，见 §2.4.1）。宫殿/仙宫/豪宅开篇另须可检索 `纹饰=`（≥8 条五维，见 §2.4.3）。

### 2.2.2 环境载体可见文字（强制；牌匾/招牌灯/书/纸等）

> 通则见 common §1.2「载体可见文字」。本节规定 ENV 空镜陈设落地口径。

**适用范围**：留在 ENV 的固定/氛围文字载体——牌匾、匾额、店招、**招牌灯**、门牌、路牌、横幅、霓虹、灯箱、电子屏固定文案、书架上的书册/卷轴、案几告示纸笺、贴墙文书/菜单/铭牌、符箓等（XOR 已升格为 PROP 的可移动书/纸走 prop 文件，规则同四项）。

**成稿四项（缺一失败；须进主环境四向/`generation_prompt_cn` 可见格）**：
1. **文字内容**：逐字写出画面应读到的文案；上游有 `visible_text`→透传；无→剧情补字并标「原文未明示；根据剧情补写」。禁只写「牌匾/古书/纸张」而无字。远景可缩小字号但仍须声明全文或主标题字；特写可读区不得用「模糊字」搪塞（上游明文污损除外）。
2. **排向（横排｜纵排；招牌灯/牌匾最高）**：显式写 `横排` 或 `纵排`（混排须核销）。横匾/横幅灯箱/横招霓虹→横排；竖匾/竖招/对联→纵排；无上游亦须按形制裁定并写出。禁「牌上写着…」不标排向。
3. **字体/书体（含颜色）**：楷/隶/行/魏碑/篆/宋/黑/仿宋/手写/招牌美术字等 + 工艺（阴刻鎏金/墨书/木版印刷/烫金/灯箱贴字/霓虹弯管等）+ **字色** + **底色/匾地/灯箱面板色**。**招牌灯/霓虹/灯箱另须写发光色**（灯管/LED/透光字色相）。匹配时代地域与机构礼仪；禁只写书体无字色，禁只写「红字金字」无书体。
4. **中文繁简体**：显式写 `简体` 或 `繁体`（或有核销的混排），且字形与裁定一致；上游原文繁/简体系不得擅自互转；无原文时按地域/时代默认（古装碑匾书卷常繁体；大陆当代室内标识常简体）。

**落位与 Clean Plate**：文字写在具名载体上（挂哪面墙/哪格背景/案几哪侧）；禁把文字当漂浮字幕；禁为人名/对白服务的用途句（仍守 §2.6）。多册书脊/多页纸若朝向镜头可读→逐具或按「可见主标题+其余同体系书脊」写清排向与字色，不得整排无字色块冒充藏书。

**四向拼图 / 广角空镜可读性门禁（最高；防为字造第二柜面）**：
1. **分层**：`visible_text` 四项仍须写入 Index / `entity_attributes`（及升格 PROP）；**不等于**一律塞进主环境四向拼图 `generation_prompt_cn`。
2. **何时可写逐字**：仅当该文字载体是**本格背景主景或近景特写可读面**（如牌匾挂在本格正对墙、门楣匾、近景摊开书页占画幅主要可读区）。
3. **何时禁写逐字（四向拼图高频）**：载体只是中远景柜面/桌面小物件（账本、算盘旁纸页、柜上菜单条等），约 50mm 眼高广角下本不可辨读 → 生图只写「柜面置摊开账本与算盘轮廓，**字迹不可辨读**」；**禁止**写具体文句、排向细规、繁简字形。
4. **禁果**：为迁就可读字另造前景第二张桌/第二层柜面/镜头前托台 = 失败。❌ 远锚已是柜面，又写柜面逐字 → 另推一张前景托台，形成双柜面。
5. **特写出口**：须可读流水账等细字 → 另开 PROP/Insert/`{N}度` 特写衍生或后制裁切近景，勿在四向基准广角格硬塞。

**自检**：任一 ENV 文字载体在 Index 缺内容/排向/字体色（字色+底色；招牌灯缺发光色）/繁简标注，或文案繁简与标注冲突 → 废弃重写该环境条；四向拼图广角格对中远景小物件写了逐字文案或出现双柜面/前景托台 = 失败。

### 2.3 光学与美学（执行入口）
先 IDENT `时地=` 时段/时辰/内外/气候/气候可见/氛围/空气感/季节 + **Index `basic_positioning`（定位）+ `env_goal`（目标/可见落点）+ `scene_mood`（须与统筹氛围同核）** → 按 §2.7.0 裁定曝光三角 / 景深控制 / 焦段选择 / 三点布光 / 光比 / 色温 / 柔硬 / 自然光 / 实用光 → §2.7 光源清单与光影规格 → 各层受光/投影 → 色彩（§2.9）→ 陈设（须能核销 `env_goal` 可见落点）。默认照度充足、主舞台可读、**光影有层次不平板**；上述光学项**禁止**套默认模板（禁一律 50mm 平光暖黄、禁无定位无情绪的三点布光套路）。城市/自然执行落点服从 §1.4。礼制空间写中轴/座次/门窗尺度。**真人写实门禁**（仅 §1.6 判真人）：真实可拍场地、生活痕迹；三维/二维改 §2.11/§2.12。

### 2.4 仙侠/东方幻想（题材增量）
可用悬空/云上/非现实比例等，主体清楚重心稳。色可用月白-青碧/冷金等；禁无依据退水墨（除非上游明确）。祥瑞异观写景别/尺度/受光，不抢主舞台。光学仍走 §2.7 清单口径。**仙境/仙府/云上宫阙/灵山琼台等**另命中 §2.4.3 顶格超额 + **宏大体量闸**（仙境外景/美景 16–22mm、广场/野外 18–24mm、室内殿 24–28mm；建筑宏大、内部挑高）——外景须见**云海、流动薄雾、浮空岛屿**（或琼台）中至少两类，并过 §2.4.1 **`山水层=` 纵深分层**（近地被/中景山体或琼台/远峰或云海/天空，云海自身再分远近带）；仙宫内景另过 §2.4.3 `纹饰=`（玉材石纹、异纹母题、鎏金线脚、藻井或穹顶细作）。禁「月白青碧/仙气」标签一句带过而无顶格色/光/材/纹/层条目，亦禁 50mm 拍成精致小屋，禁一层青山+一层蓝天交差。

### 2.4.1 自然风景/山景（题材增量 · 非常规色相强制 · 山水纵深分层最高）
山景/自然空镜须有**鲜明辨识点**：季节与生态 + **可核销的纵深分层** + **非常规色穿插**，避免棚拍单调与「千篇一律绿蓝」。logic 标 `landscape_layers=required`。

**山水/仙境纵深分层（最高；开篇可检索 `山水层=`）**：
1. **层数**：山景/自然外景/仙境外景/灵山/琼台/洞天外景必须锁 **≥4 层**，每层独立可检索短句。层序闭集=近地被或近岩 → 中景山体/林带/琼台 → 远峰或云海剪影 → 天空/霞层。缺任一层=失败。
2. **单层加维（最高）**：每层须五维全写——具名物｜距离层｜特征色｜清晰度或大气透视｜与邻层交接。禁「远山朦胧/层次丰富」空壳。✅`山水层=近=#N苔面岩，冷灰青，纹理可读，接中景林脚；中=#N松带，琥珀金黄冠缘，半清，接远峰雾线；远=#N雪脊剪影，降饱和青灰，边缘虚；天=薄卷云+冷金霞边`。
3. **层差强制**：相邻两层须同时有 **色相差 + 清晰度差 + 交接线**（雾带/脊线/云海沿/林冠线之一）。禁止远近同色同清、禁止一层山贴一层天交差。
4. **仙境外加**：云海自身再分 **≥2** 厚薄或远近带（近海可辨浪纹或絮边，远海只留剪影）；浮空岛屿/琼台**禁止**与远峰画在同一深度；近岛须见材质纹路（云石/玉阶拼缝），远岛只留体量剪影。
5. **成稿落点**：分层只锁开篇 `山水层=`（世界一次）。四宫**禁止**写 `层次=` 槽标签；该向可见层译成正面/远景白话，镜后层进 `不新增清单外主体抢戏；层挂已列山/岩/林/云/岛。
6. **水体若入画**：须写近岸纹理 + 中距反射 + 远岸交接，不得一块死蓝。

**禁绿蓝万能模板（最高）**：
1. **禁止**默认成稿 = 满屏翠绿植被 + 纯蓝天空，仅靠明度差凑层次。
2. **禁止**所有自然场共用同一「青翠山林 / 碧空」色卡；每场须写出**本场独有**的植被/地表/天空色组合（可检索特征色，非「绿色树林」；色名服从 common §1.5-B）。
3. 绿/蓝可作辅色或远景雾气层，但**不得**同时垄断主色+辅色+天空三层。

**黄/红等非常规穿插（强制；无上游题材硬禁时）**：
1. 在已有植被/地表/岩土/枯枝/花丛等可转译落点上，**至少嵌入 2 处**黄系或红系特征色（琥珀金黄/赭石/锈橙/绛紫霜叶/柔和暖粉金等）可见色块——例：琥珀金黄阔叶或枯枝梢、朱红琥珀花簇、赭红岩壁、锈褐地表带、夕照染黄远树冠等。禁只写「黄色/红色」。
2. 落点须写**物体+部位+面积感+距离层**（如「中景边缘金黄灌丛冠缘」「背景右贴边赭红岩面」）；总提神面积宜约占植被可见面 **15%–30%**，禁零星看不见的「一点红」。穿插色须落在不同 `山水层=`，禁两处都挤在近景。
3. **优先转译**上游固定清单/季节已写植被与地表；清单无具体色时，美术层可对已列植被/地表做非常规色相深化（仍同一实体，不新增 Index 行）。禁止无据另造「瀑布/巨型枫林」等清单外主体抢戏；缺口实体回流 Stage 2。
4. 仙侠/东方幻想可叠加冷金/赤霞/朱砂雾带，仍须满足黄红穿插可核销，禁退回一律青绿仙山。

**空间量化**：天空与地表须按 §2.2.1 写满（仙境级自然外景另加 §2.4.3 顶格）；中区仍留可调度开阔地；服从实体唯一性与活动区净空。

### 2.4.2 室内环境非常规设计（强制 · 破样板间）
室内/有顶空间须有**非常规设计思路**，避免「白墙+木地板+灰沙发+一盏顶灯」万能样板间。

**强制辨识点（每场室内主环境至少 2 项可核销，落边缘/背景/贴地层，禁入活动区立体堆物）**：
1. **非常规色块墙面或立面节奏**：非默认全白/全灰——如局部漆色墙段、异色踢脚带、半墙异材、色块壁龛、暖赭/墨绿/靛蓝立面条带等（服从时代地域与 `color_spectrum`）。
2. **非常规材质对撞**：至少一组可辨对撞（例：粗石灰墙×抛光铜、旧红砖×玻璃、深色丝绒帘×冷石地、竹编×金属边框）；禁全场同一哑光木色糊成一片。
3. **非常规陈设/天顶节奏**：非对称挂饰、异形灯槽、可见梁架染色、地面拼花边环、窗纱染色渗光等——写清位置与色，服务 §2.9 点缀，不堵动线。
4. **光色非常规**：Key/Fill 冷暖落在不同具名表面（例：冷窗渗光×暖灯罩芯、琥珀台灯×青灰墙），禁「一律暖黄室内灯」无辅色。

**边界**：不改上游拓扑/具名实体/头尾锚；增补不得扩成多门多窗；辨识点优先挂已有墙/地/天花/清单家具的材质与色，而非凭空新增 Index 道具。礼制/宫廷空间的非常规落在材质层次与冷暖对撞，禁毁中轴秩序。命中 §2.4.3 时辨识点与顶格条目叠加，取更严配额。

### 2.4.3 顶格场所细节超额（豪宅·仙境·武学宗门·皇家等 · 强制）

> **口诀**：命中顶格场所 → 颜色/光学/材质/细纹/纹饰**全部按顶格条目数写满，且每条加维**；常规 §2.2.1 / §2.7 / §2.9 下限不够。欠条或单条空壳 = 廉价缩小样板失败。**仙境 / 武学宗门 / 皇家**另过 §D 宏大体量闸（更大广角 + 建筑宏大 + 内部挑高）。仙境/山水外景另过 §2.4.1 `山水层=`。宫殿/仙宫/豪宅另过 `纹饰=`。高挑/宏大另过 §E 尺度衬托（贴边成人日常件，禁塞活动区）。

3. **空间铺开**：至少 **2 个扇区**可见旗（或 1 向满幅旗阵 + 邻向侧缘旗）。禁四向只在一门洞挂一面旗交差。四宫服从 R17：宿主栏/旗座入画的每一格都必须写旗；禁止只在正对格写旗、邻格蒸发。单扇区东缘旗列 → 0°右边与 180°左边必须见旗，270°镜后不见旗。
4. **落点**：优先挂已有旗纛位 / 辕门 / 营门 / 校场门 / 城垛 / 旗杆台 / 阵列边缘 / 鼓角位；**禁入中区表演净空**；禁另起第二辕门凑旗。上游已列旗名/旗位 → 深化不改名不挪位。未列具名旗但场所有旗纛位/辕门/城垛 → 在上述已列立面边缘深化旗阵（不新增 Index 行）。完全无挂点 → logic 标回流，仍须在已有立面边缘落旗，禁臆造新门。

#### C. 多样设计（最高；色·样式·图样·形状，禁一片红）

旗帜是本场**重点分析对象**，不得只写「红旗/军旗/旌旗」。须同时拉开下列四维；全场若四维都同构 = 失败。

| 维 | 每型须写 | 全场多样下限 | 禁项 |
| :--- | :--- | :--- | :--- |
| **颜色** | 旗面主色 + 镶边/飘带/流苏色（具名色，禁「红色系」） | **旗面主色不得垄断为红**；须另有 **≥2 型非红主色**（玄/皂/白/青/金/靛蓝/苍绿/赭/灰蓝等，服从时代与阵营） | 全场一片朱红；只改明度冒充换色 |
| **样式** | 职能/制式名（帅旗｜牙旗｜纛｜长幡｜竖旗｜横幅｜营旗｜信号旗｜团旗｜舰旗 等） | 型数 M 须覆盖 **≥2** 种样式名（校场/宏观 **≥3**） | 只写「军旗」无职能差 |
| **图样** | 徽/兽/星/条纹/火焰边/几何/文字（有字走 §2.2.2 四项；广角中远景可「字迹不可辨」但仍须声明图样类） | 各型图样**不得全同**；至少 **2** 类可分图样 | 全场同一团龙/同一五星复制 |
| **形状** | 外形轮廓（方｜长方｜三角｜燕尾｜长条幡｜圆形纛） | 全场须 **≥2** 种轮廓 | 全场同一长方红布 |

**每型 7 槽（可检索；缺槽=废弃）**：①名称/类（禁只写「旗」）②件数 ③旗面主色+镶边色 ④样式（上表职能名）⑤图样 ⑥形状轮廓 ⑦材质/杆（绸/锦/麻/帆布 + 杆/戟杆/旗头/缨；现代另写金属杆/滑轮）。挂位写扇区或「辕门左/城垛右」等，不占槽。同型复制须声明「同型×K，微差仅风化/朝向」。

**成稿键值（全局共享一次；四面再写成画面词）**：`旗帜设计=总数=N｜型数=M｜色相={非红主色≥2}｜样式=…｜图样=…｜形状=…｜落点扇区=…｜空镜无持旗人=是`。键值不算落地。各格旗面句不在本技能。

#### D. 写法与禁项

1. **空镜**：只画杆上/门楣/垛上/台座上的旗；**禁止**持旗士兵、旗手剪影、握杆手。持用旗归群演簇衣着（character §2.4），不进本空镜。
2. **点缀色**：旗面提神色可计入 §2.9 点缀，但仍须满足本闸非红多样；不得用一面红旗顶替点缀配额后停笔。
3. **禁标签**：`旌旗猎猎` / `旗海` / `军旗林立` 无色/样/图/形/件数 = 失败。
4. **禁单旗冒充大军**：宏观军阵/战场只画一面帅旗 = 失败。
5. **与 §2.4.1/§2.4.3 叠加**：战场外景仍须非常规地表色；仪仗广场命中顶格时旗阵条目与顶格点缀叠加，取更严。

✅小营：`旗帜设计=总数=4｜型数=2｜色相=皂底金边+苍绿牙旗｜样式=营门纛×1、牙旗×3｜图样=兽徽/斜条｜形状=圆纛+三角｜落点扇区=0度辕门+90度栅｜空镜无持旗人=是`。✅校场：黑帅旗燕尾金纹 + 青长幡纵排字 + 白方营旗几何徽 + 赭三角牙旗火焰边，分落辕门与阵列两侧。❌辕门只挂一面大红方旗｜❌全场朱红同一龙纹长方旗｜❌写「旌旗蔽日」无计数无色差。

### 2.4.5 高速场景空间闸（最高；过幅参照与航线净空）

> **口诀**：命中追逐/穿梭/飞翔/飙车 → 空镜做成**更大、更广角的距离场景**，并锁**过幅参照 + 光带锚 + 航线净空 + 借力结构 + 距离锚**。只画静态成排列件与远距层次，供下游在这些锚之间快速换位，并写 Background Motion Blur / Strong Parallax / Light Streak。禁在四向拼图画运动模糊或景物拉丝。禁用 35–50mm 把高速场压成看不远的厅堂。窄巷侧向不改成广场。

#### A. 触发（命中任一即强制；logic 标 `speed_space=required`）

`activity_space` / `purpose` / `env_goal` / `basic_positioning` / 名称 / 四向文学含：**追逐 / 穿梭 / 飞翔 / 飙车 / 高速路 / 楼间 / 峡谷航线 / 塔群 / 云海航线 / 逃窜高速 / 竞速 / 贴地飞行**（含同义）。规划已写 `高速空间=` 则原样承接深化。普通室内对白厅/职场隔间**不**触发。舱内高速链：本闸只锁窗外可见的街灯列/楼群/云层参照（经窗/舷窗），不把舱内画成拉丝，也不把舱体扩成大厅。衍生截取继承主环境已锁参照，§B 不重写长文。

**广角远距（最高；承接规划 `视距=广角远距`）**：规划已写则原样；缺则本层补并 logic 标 `upstream_missing_speed_vista`。航向 `向距上限=无限制` 的，`场径=` 写 `{向}无限制`，远景推远，禁补近壁把航道收成房间。望向航向的格：街/楼缝/航道/峡谷 **18–24mm**；空域/云海/灵山航线 **16–22mm**。距离锚近/中/远必须是三处不同具名位置，沿航向拉开，空镜只画静态位置。侧向若规划为 `窄`，该向格仍守窄向浅进深，禁止改广角把巷宽拍成厅堂。舱内：舱体焦段不改鱼眼；0° 前窗/舷窗外的远景包络用上述广角距离（近灯、中楼、远天际分层）。

#### B. 四槽（强制；键值不算落地）

全局须可检索 `高速空间=档=中|高|极高｜视距=广角远距｜过幅参照=｜光带锚=｜航线净空=｜借力结构={具名|无}｜距离锚=近…→中…→远…`。过幅参照写结构类型（梁列/窗阵/廊栏），**禁止** `0度{梁}+90度{廊}` 这种按格点名——会把 `上=` 共享件和某壁开口拆成两套立面。四面可见向后景/中景再写成画面词。距离锚三处必须互异。

| 槽 | 空镜须可见 | 禁项 |
| :--- | :--- | :--- |
| **过幅参照** | 近端重复竖向件 ≥1 列（灯杆/柱列/檐口节奏/窗格阵/护栏桩），中景走廊或航道层次，远景天际/楼群/山脊可分层 | 只写「街道很深」无重复单元；四面同构无节奏差 |
| **光带锚** | 灯杆列/霓虹阵/窗格阵/舰灯列（静态点亮或未亮形制均可；同质多件须整数总账，禁写`成排`空数），供下游沿航向拉丝 | 空镜直接画光带拖尾/拉丝；只有一盏孤灯冒充列 |
| **航线净空** | 穿梭/追逐走廊不被家具/盆景堵死；楼缝/桥下/峡谷宽度可读 | 中区堆件挡航线；把走廊写成封闭客厅 |
| **借力结构** | 楼间穿梭须檐口/窗框/管线/广告牌/晾架之一（规划已列则深化不改名；未列不新增门，只在已有立面边缘落件） | 无据新开一门凑借力；把借力件摆进中区舞台 |
| **距离锚** | 近、中、远三处不同具名位置沿航向拉开（近灯杆、中路口、远天际），空镜只画静态位置 | 三锚写成同一件；只写「很深」无三处具名 |

**视差层次（强制）**：近端参照尺度明显大于远景（柱近窗远、灯近楼远），四面至少一向可核销近中远三层尺度差，供 Strong Parallax。禁四向都拍成无重复单元的平整贴墙。

#### C. 写法与禁项

1. **静态空镜**：只画成排列件、檐口、窗阵、走廊几何的**静止形制**。**禁止**写运动模糊、景物沿航向拉丝、风压条带、尘线拖尾、光带甩尾——这些归武戏/分镜。
2. **不加人/载具**：已抽 CHAR/PROP 不入空镜；航线净空是空间几何，不是「供谁飞」。
3. **与 §2.2.1/活动净空叠加**：过幅参照与光带锚落**四面围合或贴边**，禁入中区表演中央；航线净空可与主舞台重叠为同一开阔走廊。
4. **舱内**：0° 前窗/舷窗外须能核销成排街景或云层层次（远景包络），禁窗外只写「天空一块」。

✅楼街`高速空间=档=高｜视距=广角远距｜过幅参照=灯杆列｜光带锚=霓虹店招阵×6｜航线净空=楼缝走廊通到巷口｜借力结构=檐口与广告牌横杆｜距离锚=近灯杆→中霓虹阵→远巷口天际`，望向航向 18–24mm，航向场径无限制。✅云海`高速空间=档=极高｜视距=广角远距｜过幅参照=塔群远近层｜光带锚=塔刹夜灯列｜航线净空=檐上至云腰无顶走廊｜借力结构=塔刹脊｜距离锚=近檐→中云腰→远塔刹`，焦段 16–22mm。❌只写「都市街道很有速度感」无列灯无楼缝｜❌四向拼图画「路灯拉成光带、楼体运动模糊」｜❌用 35–50mm 把楼街拍成短巷厅堂｜❌近中远锚写成同一盏灯｜❌窄巷侧向改广角拍成广场。

### 2.5 四宫成稿不在本技能

本技能只交主环境设计稿。`generation_prompt_cn` 写完【构图】即停。
禁止输出【四向拼图】、`2×2 四宫格`、`四宫度数=`、`[0度格-左上·北]`、`[90度格-右上·东]`、`[180度格-左下·南]`、`[270度格-右下·西]`，禁止把开篇译成画面左或画面右。

### 2.6 纯空镜去角色化与门禁（最高硬约束）
环境资产的目标画面是**无人空镜**——只画空间、建筑、固定陈设、材质、光色与空气感。

### 2.7 全域光影（光学权威 · 美观不平板；环境与海报均适用）

| **纵深光层** | FG / MG / BG **各写一句**受光或投影差 | 近端投影/遮挡、中景主受光、远端略收或渗光——形成呼吸 |
| **半影与投影** | ≥1 条半影柔散 + ≥1 条落地方向可感投影（绑具名实体） | 落地、有重量；禁刀切硬边（恐怖/上游硬核销除外） |
| **材质光学** | ≥2 具名表面写高光/哑光/透射/湿反射等响应；**顶格场所（§2.4.3）→ ≥5** | 光落在材质上才好看；禁抽象「反光好」 |

**顶格场所光学超额**：命中 §2.4.3 时，另须 **≥4 条**独立可见效果句 + 材质响应 ≥5（上表）；可见动机光具数仍 ≤3，靠反射/渗光/材质响应把效果写满，禁靠加灯凑数。

**C 防平板（最高）**：
1. **禁均匀平光 / 整室同亮**：无主方向、无亮暗分区 = 失败。
2. **禁只写标签**：仅「侧光/氛围光/电影感」而无来源·范围·效果 = 失败。
3. **禁无 Fill 托起的死黑窟窿**（恐怖压暗场除外且仍须最小动机光可读）：暗部须有反射或第二 Practical 托起纹理。**宫殿/豪宅/仙境**日景另禁极端逆光死黑——飞檐/拱柱/云海可逆光勾边，但汉白玉、鎏金构件、雕花回廊须仍可读。
4. **禁臆造机位后方新灯凑数**；已声明的世界源换角后仍照明。四宫禁止写「机位后/身后有灯」。
5. **禁门外渗光却门紧闭**；半开/全开才可写门洞渗光。门洞渗光≠另起 Key：仅当 `Key世界向` 正对那扇门时，门洞才是主太阳。
6. **禁 Key 与行星错象限**：时辰/`光变档` 与 `Key世界向` 必须同核（卯东/辰东南/午南/酉西/夜=室内灯）。背日开口不得当斜阳主光。开篇缺 `时辰为` 或只写「日/夜」=失败。
7. **禁每格朝远锚自起一盏太阳**：正对非 Key 的门/窗/天井只吃余晖或 Fill；背对 Key 的格禁止关 Key 改平光。四格四套太阳 = 失败。
8. **位置几何一致**：入射侧、照亮面、半影、投影方向须与光源落位可对上。
9. **活动区净空不豁免光层**：表演净空可无立体增补，但地面受光/投影、远景墙渗光、边缘 Practical 仍须承担纵深光层——禁因净空而整场平光。
10. **与 §2.9 联动**：亮区/暗区色、Key/Fill 冷暖须落在不同距离层或具名表面，不得光色两张皮。

**E 柔和侧逆光 + 环境反射 Fill**（真人优先；三维/二维改 §2.11/§2.12 语言）：半影自然柔散；禁硬阴影刀切；海报群像同口径。默认照度充足、主舞台可读；大光比见 common §1.5-A（≠无脑压黑）。

**F 光写在哪一层**：

### 2.8 夜景、气候与氛围（强制消费上游时地；美观仍须层次）
**气候与氛围是设计依据（最高）**：先读 IDENT `时地=` 的 `气候=`/`气候可见=`/`氛围=`/`空气感=`/`光色倾向=`（与【主环境】同核）。禁止忽略、禁止改档、禁止用默认晴空或默认暖黄顶替。`气候可见` 必须落入开篇空气/地面/受光面（雨→湿石或雨丝；雾→雾霭纵深；雪→积雪或雪尘；风→扬尘或旗角；阴/霾→阴云或灰幕）。`空气感` 须可检索。氛围主情绪驱动 §2.7.0 光色，不得与气候打架（雨夜压迫≠无据明媚晴空）。
触发夜/雨夜/雾雪霾风暴/浓阴等时走本条补层次；恐怖刻意压暗除外（须写依据，仍保留最小可读动机光）。

**原则**：≠整室漆黑，亦≠单点昏灯平板；成稿可见动机光仍**上限 3**（与 §2.7 / common §1.5 一致）；靠反射/渗光效果补覆盖与**纵深光层**。三路径择一或组合并显式写出：①强化自然主光（月/城市穹顶/湿玻璃反射等）②暖调 Practical 覆盖（≤3）③多人工可见源≤3 + 反射接力。最低：显式时段/时辰/内外/气候/气候可见/氛围/空气感/季节；中景主舞台+≥1 动线在作用范围内；**FG/MG/BG 仍须可辨受光差**（可用湿反射、窗渗、灯池接力）；禁单点昏灯无层次、禁 >3 成稿具名源、禁在该格点名机位后方源（续效只写可见面受光）、禁整室死黑无 Fill。开篇缺 `气候为`/`氛围为`/`空气感为` 或 `气候可见` 与气候档不符 = 失败。

### 2.9 色彩体系（环境空间 delta · 色板权威=common §1.5）
**禁止复述** common §1.5-B 的色卡锁 / 6:3:1 / 特征色名 / 强对比 / 材质绑色长文。本场只做环境空间落地：把已锁色板绑到具名表面与 FG/MG/BG；色层须能核销 `scene_mood` 光色倾向 + `basic_positioning` 气质品级。
**目标**：空镜好看、有立体感、有对比度、不寡淡——面积守 **6:3:1**；各层须特征色（如旧木褐/煤灰蓝/柔和暖粉金，禁「红/绿/黑」）；辅/点缀相对主色强烈对比；FG/MG/BG 色相/明度差形成纵深；禁单色平涂、禁灰褐糊。

**A 规格句式（主环境强制；须写入主环境 `generation_prompt_cn`，紧接开篇时段气候后）**：衍生由对应基准宫格继承本规格，§B 不重述；仅 §C 写可见色彩 Delta。
`色彩体系：对标片={全局色卡对标片｜或主动锁的顶级大片名}｜场景情绪={Index scene_mood 主情绪}｜主冷暖={四选一}｜色系={特征双主干，如旧木褐+煤灰蓝}｜比例=6:3:1｜色温：主光{K}、Fill{K}、阴影{偏色}｜饱和度：主舞台{中高可读}/远景{略降}｜色彩结构：主色{特征色@具名表面×≥2；约60%}/辅色{特征色@具名表面×≥2；约30%；须与主色强烈对比}/点缀{特征色@物体+部位+面积；约10%；须与主色强烈对比}/过渡{距离层×≥1}｜纵深色层：前景={色+材质}/中部={色+材质}/背景={色+材质}｜影调：{Key:Fill+对比度}｜分离色调：高光{…}、阴影{…}｜色彩构图：{视线引导/层次分离/提神点/立体感；须响应 scene_mood 构图倾向}。`
**纵深色层与色彩构图同是方法**：全局必须写一次。四面禁止再写本向色层作文。四宫技能不回写这一节。程序从本设计稿原样抄入【色彩说明】，放在【四向拼图】之前。主冷暖、比例、色系仍在四向拼图开头写一次。纵深色层留在【色彩说明】，四宫构图不重写，也不点名主体。禁止用一篇色彩构图总述顶替四壁+四机位。

**B 落点（环境表面数；面积比见 common §1.5-B）**：
| 层 | 最低要求 | 美观意图 |
|----|----------|----------|
| **主色** | ≥2 具名表面（墙/地/主家具等），特征色可辨，合计约 **60%**；**顶格（§2.4.3）→ ≥4** | 定场气质；禁普通单字色相 |
| **辅色** | ≥3 具名表面，特征色，合计约 **30%**，与主色**强烈对比**；**顶格 → ≥5** | 拉开立体感与对比度；冷暖对比题材须至少一暖一冷落层 |
| **点缀** | ≥1（宜 1–2），特征色，合计约 **10%**；写物体+部位+形态+面积+受光；与主色**强烈对比**；**顶格 → ≥3** | **提神色**（柔和暖粉金/浓郁宝石色/冰蓝/釉面/灯罩暖芯等）——须从主色底上「跳出来」 |
| **过渡** | ≥1 距离层或材质衔接带 | 主辅之间的桥色，不占 6:3:1 第四份额 |
| **纵深色层** | FG / MG / BG **各写一句**特征色+材质，且三层须有可辨色相或明度差 | 近端可略饱和/暖或冷偏移，远端略降饱和或偏雾 |

**C 环境防单调（空间专属；通用禁则见 common §1.5-B）**：
1. **禁无立体感**：FG/MG/BG 同色同明、无前后推拉 = 失败；纵深色层须让近中远可辨，配合影调对比度写出体积。
2. **亮暗分色**：亮区与暗区色谱分写（可同色系不同明度+微偏色）；冷暖对比题材须 Key/Fill 冷暖落在不同距离层或不同具名表面。
3. **活动区净空不豁免色谱**：表演净空无立体增补，但地面贴层、远景墙面、边缘点缀仍须承担辅色/点缀落点——禁因净空而整场无色层。
4. **禁自然场绿蓝垄断**：外景/山景/自然空镜若主色+辅色+天空均为绿/蓝系且无琥珀/赭石/绛紫/柔和暖粉金等可核销穿插 = 失败；须按 §2.4.1 补非常规色（穿插色仍须特征色名，禁只写「黄/红」）。山景/仙境外景另须开篇 `山水层=` ≥4 且相邻层有色差+清晰度差，一层山+一层天 = 失败。
5. **禁室内样板间色谱**：室内若仅「白墙+木褐+灰软装」三色循环、无非常规立面色块/材质对撞/异色点缀 = 失败；须按 §2.4.2 补辨识点。
6. **与定位目标 + `scene_mood` 同核（强制）**：主辅点缀冷暖须能核销 `basic_positioning` 气质品级与 Index 光色倾向、构图倾向（压迫≠无据满室暖黄喜庆；精致小屋≠宫殿金碧；纵深压迫须近中远色层可辨；负空间远景可降饱和）。缺 `scene_mood` 已标回流后，仍不得与 `color_spectrum` 主冷暖打架。

**D 色写在哪一层**：
- **本技能**：色彩规格在开篇声明一次（共享 6:3:1）。不写各格色落点。
- **四宫格技能**：各格写出该格可见表面上的色落点。邻向侧壁可带邻向辅色边缘。
- **衍生**：不在本技能写提示词。该格色落点已经在四宫里，不另起一套色谱。
- **海报**：标题区与主视觉须有明度/色相对比；rim/环境色挂靠 ENV 光源；禁灰片糊标题；面积仍守 6:3:1。
- 三维/二维按 §2.11/§2.12 转译语言（二维可用色块分层，仍须主辅点缀可辨、特征色名、6:3:1）。

**E 自检口诀**：删掉「电影感/高级感」后，能否指出——**色卡来自全局 `color_palette` 还是主动锁的哪一部顶级大片**、主/辅/点缀面积是否 **6:3:1**、各层是否特征色（无「红/绿/黑」空壳）、辅色与点缀相对主色的**强烈对比**落在哪、提神点缀在哪、近中远三层色差如何形成**立体感与对比度**、**色层如何核销 `scene_mood`**？自然场能否指出琥珀/赭石/绛紫等穿插落点与 `山水层=` 四层交接？室内能否指出非常规辨识点？宫殿/仙宫/豪宅能否指出 `纹饰=` 母题+工艺？军队/军阵场能否指出 **≥2 型非红旗面主色** 与形状/图样差（§2.4.4）？顶格场所（§2.4.3）主色≥5 / 辅色≥6 / 点缀≥4 是否可数且面积仍 6:3:1？任一否 → 重写色彩段。  
`negative_prompt_en` 可追加：`monochrome wash, muddy gray-brown palette, flat single-hue grading, desaturated mush, no accent color, generic red green blue labels, weak same-family contrast, broken 60-30-10 balance, low-contrast muddy palette, no depth in color layers, uniform color field, generic all-green forest, default blue sky green trees only, white-box interior, showroom flat palette, cheap miniature palace, generic immortal mountain template`。
