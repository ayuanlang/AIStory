## 一、全局约定

### 1.1 命名与底线
- 命名锁 / `subject_no` / Clean Plate / 合规 / 双语字段：见 common。环境名尤须保留 Index 已写定的空格/`_`/角度前缀全串；禁「规范化空格」「补角度后缀」「缩短主环境名」。

### 1.2A 项目语境注入（环境 delta）
通则见 common §1.2A。环境额外强制：⑦日夜/内外/气候/季节须写入开篇并可画（未明示则合理推断，logic 注明）；**光影规格（§2.7）+ 色彩规格（§2.9）**紧接开篇；细节密度：主环境每格 **>10**（含四周/地面/天顶或天空量化落点，见 §2.2.1）；衍生截取段仍 >6。

**开篇句式**：`项目基础定位为{…}，项目全局风格为{…}，年代/时代为{…}，地域/国家为{…}，语言环境为{…}，风格定位为{…}。时段为{…}，内外为{…}，气候为{…}，季节为{…}。` + 风格定位 2–4 条可视化落点。

- `anchor_description`：逗号连接 3–5 个英文短语（空间结构/主舞台/材质/固定光源）；禁 JSON 数组、瞬态光影、人物动作。

### 1.3 字段契约（光学/空间权威见 §2.5 / §2.7）
- Clean Plate / 引擎控制符 / `negative_prompt_en` / 合规：见 common；**环境主/衍生 = 纯空镜（最高）**——见 §2.6。
- **无记忆性**：`generation_prompt_cn` 只写画面最终结果，禁推导过程/公式/「对照/继承/同上」。
- **双字段分工**：

| | `description_cn` | `generation_prompt_cn` / `dependency_strategy.logic` |
| :--- | :--- | :--- |
| 可写 | 恒 `""`（禁任何正文） | **prompt**：机位、前景/中景/背景具名**物**实体、可见光 1–3、色彩、当前可见面；衍生=截取放大指令+可选 Delta；**仅空镜**。**logic**：360 拓扑、转角对照、美学参考、含不可见源的光学 rationale；衍生元数据+Delta；规划备注可括注「不成稿」 |
| 禁写 | 非空字符串 | prompt：拓扑字段、度数公式、继承锚点、跨格对照；**任何人物/用途句**（§2.6） |

- 转译自检：单独复制 `generation_prompt_cn` 应可直接生图；`description_cn` 必须为 `""`。

### 1.4 审美基线（环境 delta；通则见 common §1.4）
- 对标电影级空间/海报；禁舞台剧/样板间/廉价缩小感。
- **环境增量**：无上游明文限制时优先**宏大、开阔、高挑**（豪宅强调挑高通透；城市偏繁华；自然偏开阔层次）；张力用光色/秩序/空寂，**禁用脏乱代替戏剧性**。
- **非常规设计思路（强制；破千篇一律）**：每场环境须有**可检索的视觉辨识点**——禁默认「绿树+蓝天」「白墙木地板灰家具」万能模板。自然外景见 §2.4.1（须穿插黄/红等非常规植被色）；室内见 §2.4.2（须有非常规材质/色块/陈设节奏）。辨识点写进主辅点缀与四周量化细节，服从上游清单与活动区净空。
- **色彩美观（强制）**：环境画面须**有层次、有色相呼吸、不单调**——主/辅/点缀/过渡四层落地到具名表面与 FG/MG/BG；禁全场灰褐糊成一团、禁只写「冷调/暖调」无具名色；细则 §2.9。
- **光线美观（强制）**：环境画面须**有光向、有体积、有亮暗呼吸、不平板**——Key/Fill/（可选）轮廓分离 + FG/MG/BG 受光差 + 半影/投影可感；禁均匀平光、禁整室同亮、禁只写「有光/电影感」；细则 §2.7。
- **四周·地板·天空细节充足（强制）**：四向围合/地面/天空（或室内天顶）须有**量化可核销**的具体描写，保美观真实不单调；**中区舞台净空保留**——细则 §2.2.1。

## 二、环境专项

### 2.1 基础原则
- **上游绑定**：`topology_top_down_360` / `zero_degree_axis` / `spatial_anchor_head|tail` / `fixed_architecture_and_finish` / `fixed_furniture_and_set_dressing` **只读继承**——禁删改挪动具名实体与拓扑、禁颠倒头尾锚点、禁省略陈设。
- **长轴物理一致性**：中央长条家具（桌/床等）须先据上游裁定长轴（0°–180° 或 90°–270°），再按 §2.5.3 可见面表成稿；**禁止**默认固化一种走向。权威表与 F 朝向防错见 §2.5.3。
- **允许美术增补**：见 §2.5；增补不得改拓扑。
- **固定实体零遗漏**：清单内每一实体须进主环境四向 `generation_prompt_cn`；禁止因「次要」省略。
- 专属字段 + 日夜/内外/气候/季节须写入 `generation_prompt_cn`。

### 2.2 舞台与空间实体化
- 围绕上游 `{Stage}` / `activity_space` / `activity_fit`：**环境描述须服务剧情活动空间**——先锁定表演区/动线/站位承载/出入画口的空镜几何，再落固定实体与边界，再分层/光照/Delta。核心舞台在中景可读净空。
- **剧情活动空间明示（最高；主环境 `generation_prompt_cn` 强制）**：上游 `activity_space`（主舞台/表演区｜动线｜站位承载｜出入画口）须在主环境四向拼图中**可核销可见**——用空镜结构语写清「开阔站立净空区」「门→中区可通行通道」「座次区几何」「具名门洞出入净空」等，保证角色有实际可用的活动与调度空间；**禁止**只列家具堆满画面而无表演净空。衍生侧据 `activity_fit` 保证该角背景半空间与纵深可读，且不堵死该角所需动线/对峙纵深。仍守 §2.6 Clean Plate：禁写人名/站姿/对峙情节句，只写空间几何。
- **实体落位、进深与背景强锚定（防发飘）**：除了声明实体处于哪条轴/哪个格，还必须清晰交代其在空间进深上的精准透视关系以及与对应背景的纵深/横贯锚定。如果是条形家具，在纵深视角下必须严格写明“从画面近端向背景X度深处延伸/指向”；在横贯视角下必须写明“X度端在画面左侧，Y度端在画面右侧”，切忌只干瘪地写“可见短边/可见长边”，必须牢牢钉死它与所处画格空间背景的几何透视联系。以此巩固中景的纵深感并指引生图模型正确绘制。
- **出入口可视化**：上游可通行出入口须具名可见（开闭态、门轴侧、连通、净空）；禁堵死成实墙；出入画口净空须与 `activity_space` 出入项一致。
- **实体间关系**：前后左右上下 + 每层每实体垂直上/中/下；门窗须写开闭态与内开|外开/门轴侧；方向性实体具名+朝向+正反面（成稿锚固定实体或相对镜头表述）。
- **细节质感与真实性补充（提升美感）**：不能仅列出干瘪的家具名，必须为每一个具名构件或家具补充**材质、纹理、光泽度或自然使用痕迹**（例如：带有细碎划痕的黑胡桃木桌面、反光的做旧黄铜边框、边缘泛着冷光的钢化玻璃等），以切实提升画面的电影写实质感与美学底蕴。
- **同质多件分边与冗余重复（防遗漏铁律）**：≥2 具椅凳等须写总个数、分边个数、逐具朝向 F、同侧顺序；更重要的是：**在描写四向拼图中每格（0°/90°/180°/270°）的具体画面时，必须【冗余地、无死角地】重复交代这几把椅子的具体可见面及相对位置，绝不允许在某一个画格里偷懒省略！如果场内有3把椅子，每个画格的描写里都必须清楚说明场内共有3把椅子，然后写明这3把椅子分别在哪、哪一面可见！**
- **实体配套性（强制）**：上游已写的成套关系（桌↔椅、床↔被枕、壶↔杯盏等）须在描述层**完整可视化**并写明个数/分边；禁只画主件漏配件、禁隐去数量。**边界**：仅同 Subject 描述层补可视化；上游清单漏写配套件 → 标「上游待补（回流 Stage 2）」，**禁止**擅自新增 Index 行或伪造未声明实体凑套；禁增补成无关堆砌。
- **活动区净空（最高；禁止在活动区设计实体物件）**：上游 `activity_space` /【活动空间】划定的**主舞台/表演区、动线、站位承载区**为表演净空——**禁止**在该区内美术增补、挪移或新设计任何立体实体物件（家具/陈设/立柱/屏风/盆景/箱柜等）；仅允许地毯/地砖/贴地纹样等**不影响站立·走动·跪拜**的贴地层，或上游固定清单已明文落在该区且剧情硬核销的实体（如对白桌/座次椅——且不得再向表演净空加件）。氛围细节、控杂增补、祥瑞点缀一律落**边缘/背景向/非动线区**，不得挤占活动区。
- **空间均衡**：防过挤（活动区/动线阻塞）与过空（四向空洞棚拍感）；偏空才在非活动区增、偏挤则控杂并优先清空活动区障碍——**细节堆在四周/地面贴层/天顶天空，中区留舞台**（§2.2.1）。
- 构图简洁有序；控杂但不剥离非动线氛围细节。

### 2.2.1 四周·地板·天空细节量化 + 中区舞台预留（强制，美观真实）

> **口诀**：**四周/地板/天空写满可感细节**；**中间预留舞台净空**。细节不足=棚拍空洞；中区堆物=堵戏失败。

**适用范围**：主环境四向拼图每格 `generation_prompt_cn`（衍生截取继承基准，不另造冲突堆砌；`description_cn` 恒 `""`）。服从上游固定清单与实体唯一性；增补只许边缘/背景/贴地层，**禁入活动区**。

#### A. 量化配额（主环境每格 / 全集基准描述均须可核销）

| 区域 | 最低细节条数（可检索短句/短语） | 每条须覆盖的维度（≥3 维，禁空词） | 落点区 |
|------|--------------------------------|-----------------------------------|--------|
| **四周（四向围合）** | **每个方位扇区 ≥4 条**（0°/90°/180°/270° 各自达标；本格「背景」扇区在该格成稿中须写满） | 材质｜纹理/接缝或分格｜色相或光泽｜与邻面交接或收边｜受光/投影响应（五选≥3） | **背景向 + 画面左右贴边窄条**；禁把四周立体物堆进中景表演净空 |
| **地板/地面** | **≥5 条**（四格共享同一地面体系，各格须写本格可见地面句，不得省略） | 材质｜分格/拼花或纹路走向｜色层｜磨损或生活痕迹（有节制）｜反射/粗糙度｜与墙脚/踢脚收边（六选≥3） | **贴地层全场连续**；中区只写贴地，不竖立体物 |
| **天空（外景可见）** | **≥4 条**（本格天空/天际可见时强制；不可见写「本格天空不可见」） | 时段天色｜云量形态或清透｜大气透视/霾｜与地平或建筑天际线交接｜日光/月光方位染色（五选≥3） | **上半幅远景**；不占中区地面 |
| **天顶/天花（室内或有顶）** | **≥3 条**（无天空句时强制以此替代「上边界」） | 材质｜梁架/灯槽/吊顶分格｜色｜可见灯位与照度关系（四选≥3） | **上方围合**；灯具计入光学清单口径 |

**合计自检（每格）**：四周背景扇区细节 ≥4 ＋ 地面可见句 ≥2（指向共享≥5 条体系中的可见子集）＋（天空≥4 或天花≥3）＝该格「围合充足」；再加中景舞台净空句 ≥1。不达标 → 重写该格。

#### B. 写法要求（具体、充足、不单调）
1. **禁空壳**：禁止只写「地板是木地板」「四周有墙」「天空很蓝」；须落到可拍质感（例：深胡桃人字拼、缝宽约指尖、哑光漆面局部冷窗反光；远空高云丝、近地平微暖雾带）。
2. **四周≠四面同贴图**：四向须有可辨差异（不同立面功能/材质主次/开洞/陈设），仍守对向不串写与邻向贴边占比。
3. **地板服务舞台**：中区地面写清开阔可贴地区域（材质连续、无障碍）；装饰拼花/地毯边/地灯嵌条优先落**边缘环带**，禁在表演净空中央堆立体陈设。
4. **天空/天顶定气场**：外景用天空层次破「棚拍灰顶」；室内用天花分格+灯槽破「白板顶」；与 §2.7/§2.9 光色联动。
5. **增补优先序**：四周立面细节 → 地面贴层 → 天空/天花 → 边缘点缀；**最后**才考虑中景剧情硬核销家具——且不得挤占 `activity_space`。

#### C. 中区舞台预留（与活动区净空同级）
1. **中景中央**：显式写出「主舞台/表演净空」空镜几何（约画面中下部至中景纵深的可站立·可走动开阔区）；**禁**为凑细节配额向该区堆家具/盆景/立柱/箱柜。
2. **配额与净空不冲突**：四周/地板/天空的细节条数靠**围合面与贴地层**完成，不靠中区加立体物凑数。
3. **硬核销家具**（对白桌/座次椅等）仅上游已列者可留中区，须同时写清其周围剩余净空与动线宽度感（空镜几何，不写人物）。
4. **自检**：若去掉中区所有非硬核销立体物后，四周+地板+天空细节仍达标且中区仍显开阔可调度 → 通过；中区一堆杂物才「看起来满」→ 失败。

#### D. 成稿锚点（嵌入四向格）
每格须能检索到类似结构（语序可融叙述，信息不可缺）：  
`背景（本格四周主立面细节×≥4维落地）…｜中景-舞台净空={开阔贴地可站区/动线}…｜中景-硬核销家具（若有）…｜地面={可见贴层细节}…｜天空或天花={上边界细节}…｜左右邻向仅贴边斜切…｜光照…`

### 2.2.2 环境载体可见文字（强制；牌匾/书/纸等）

> 通则见 common §1.2「载体可见文字」。本节规定 ENV 空镜陈设落地口径。

**适用范围**：留在 ENV 的固定/氛围文字载体——牌匾、匾额、店招、门牌、路牌、横幅、霓虹、灯箱、电子屏固定文案、书架上的书册/卷轴、案几告示纸笺、贴墙文书/菜单/铭牌、符箓等（XOR 已升格为 PROP 的可移动书/纸走 prop 文件，规则同三项）。

**成稿三项（缺一失败；须进主环境四向/`generation_prompt_cn` 可见格）**：
1. **文字内容**：逐字写出画面应读到的文案；上游有 `visible_text`→透传；无→剧情补字并标「原文未明示；根据剧情补写」。禁只写「牌匾/古书/纸张」而无字。远景可缩小字号但仍须声明全文或主标题字；特写可读区不得用「模糊字」搪塞（上游明文污损除外）。
2. **字体/书体**：楷/隶/行/魏碑/篆/宋/黑/仿宋/手写/招牌美术字等 + 工艺（阴刻鎏金/墨书/木版印刷/烫金等）；匹配时代地域与机构礼仪。
3. **中文繁简体**：显式写 `简体` 或 `繁体`（或有核销的混排），且字形与裁定一致；上游原文繁/简体系不得擅自互转；无原文时按地域/时代默认（古装碑匾书卷常繁体；大陆当代室内标识常简体）。

**落位与 Clean Plate**：文字写在具名载体上（挂哪面墙/哪格背景/案几哪侧）；禁把文字当漂浮字幕；禁为人名/对白服务的用途句（仍守 §2.6）。多册书脊/多页纸若朝向镜头可读→逐具或按「可见主标题+其余同体系书脊」写清，不得整排无字色块冒充藏书。

**自检**：任一 ENV 文字载体缺内容/字体/繁简标注，或文案繁简与标注冲突 → 废弃重写该环境条。

### 2.3 光学与美学（执行入口）
先日夜/内外/气候/季节 → 光源清单与光影规格（§2.7）→ 各层受光/投影 → 色彩（§2.9）→ 陈设。默认照度充足、主舞台可读、**光影有层次不平板**。焦距：16–35 宏大、50 自然、85–200 压缩。城市/自然执行落点服从 §1.4。礼制空间写中轴/座次/门窗尺度。**真人写实门禁**（仅 §1.6 判真人）：真实可拍场地、生活痕迹；三维/二维改 §2.11/§2.12。

### 2.4 仙侠/东方幻想（题材增量）
可用悬空/云上/非现实比例等，主体清楚重心稳。色可用月白-青碧/冷金等；禁无依据退水墨（除非上游明确）。祥瑞异观写景别/尺度/受光，不抢主舞台。光学仍走 §2.7 清单口径。

### 2.4.1 自然风景/山景（题材增量 · 非常规色相强制）
山景/自然空镜须有**鲜明辨识点**：季节与生态层次（植被色相、远近层次、可选水体）+ **非常规色穿插**，避免棚拍单调与「千篇一律绿蓝」。

**禁绿蓝万能模板（最高）**：
1. **禁止**默认成稿 = 满屏翠绿植被 + 纯蓝天空，仅靠明度差凑层次。
2. **禁止**所有自然场共用同一「青翠山林 / 碧空」色卡；每场须写出**本场独有**的植被/地表/天空色组合（可检索具名色，非「绿色树林」）。
3. 绿/蓝可作辅色或远景雾气层，但**不得**同时垄断主色+辅色+天空三层。

**黄/红等非常规穿插（强制；无上游题材硬禁时）**：
1. 在已有植被/地表/岩土/枯枝/花丛等可转译落点上，**至少嵌入 2 处**黄系或红系（及近邻：琥珀/赭石/锈橙/绛紫叶/金黄草甸等）可见色块——例：金黄阔叶或枯枝梢、朱红/琥珀花簇、赭红岩壁、锈褐地表带、夕照染黄远树冠等。
2. 落点须写**物体+部位+面积感+距离层**（如「中景边缘金黄灌丛冠缘」「背景右贴边赭红岩面」）；总提神面积宜约占植被可见面 **15%–30%**，禁零星看不见的「一点红」。
3. **优先转译**上游固定清单/季节已写植被与地表；清单无具体色时，美术层可对已列植被/地表做非常规色相深化（仍同一实体，不新增 Index 行）。禁止无据另造「瀑布/巨型枫林」等清单外主体抢戏；缺口实体回流 Stage 2。
4. 仙侠/东方幻想可叠加冷金/赤霞/朱砂雾带，仍须满足黄红穿插可核销，禁退回一律青绿仙山。

**空间量化**：天空与地表须按 §2.2.1 写满；中区仍留可调度开阔地；服从实体唯一性与活动区净空。

### 2.4.2 室内环境非常规设计（强制 · 破样板间）
室内/有顶空间须有**非常规设计思路**，避免「白墙+木地板+灰沙发+一盏顶灯」万能样板间。

**强制辨识点（每场室内主环境至少 2 项可核销，落边缘/背景/贴地层，禁入活动区立体堆物）**：
1. **非常规色块墙面或立面节奏**：非默认全白/全灰——如局部漆色墙段、异色踢脚带、半墙异材、色块壁龛、暖赭/墨绿/靛蓝立面条带等（服从时代地域与 `color_spectrum`）。
2. **非常规材质对撞**：至少一组可辨对撞（例：粗石灰墙×抛光铜、旧红砖×玻璃、深色丝绒帘×冷石地、竹编×金属边框）；禁全场同一哑光木色糊成一片。
3. **非常规陈设/天顶节奏**：非对称挂饰、异形灯槽、可见梁架染色、地面拼花边环、窗纱染色渗光等——写清位置与色，服务 §2.9 点缀，不堵动线。
4. **光色非常规**：Key/Fill 冷暖落在不同具名表面（例：冷窗渗光×暖灯罩芯、琥珀台灯×青灰墙），禁「一律暖黄室内灯」无辅色。

**边界**：不改上游拓扑/具名实体/头尾锚；增补不得扩成多门多窗；辨识点优先挂已有墙/地/天花/清单家具的材质与色，而非凭空新增 Index 道具。礼制/宫廷空间的非常规落在材质层次与冷暖对撞，禁毁中轴秩序。

### 2.5 主环境四向拼图、衍生与正反逻辑（空间权威）

#### 2.5.1 分层与依赖
- **主环境**：`description_cn=""`；`dependency_strategy.logic` = 俯视 360 + 0 度轴（仰视可选）+ 美学参考；`generation_prompt_cn` = 四向拼图（16:9，2×2：左上0/右上90/左下270/右下180，眼高，非俯拍）；`visual_dependencies=[]`；`dependency_strategy.type=BaselineDefinition`；禁作 Beat ENV。
- **全部衍生（含 `0度` Master，截取放大权威）**：可拍机位 + 回挂当前空镜基准 + §A/§B/§C。`generation_prompt_cn` = **截取放大**对应宫格（见 §2.5.4–§2.5.5），**禁止**再写满四向陈设长文。`description_cn=""`；元数据（`spatial_axis` / `lens_profile` / `axis_crossing` / 对应宫格）+ 状态/特效 Delta（若有）→ `dependency_strategy.logic`；**不再逐向铺陈细节**。转角四向推演仅进 logic，不成稿。

#### 2.5.2 坐标系硬规则
- **0°** = Viewing Direction（非真北）；主环境 0° 轴 = Stage 1 首个非航拍全局建置视角的背景方位。
- **顺时针** = 俯视鸟瞰口径；禁第一人称「向左/右转」推角。
- **N 度格** = 摄影机**朝向** N° 方位实体（该实体在背景）；机位在 `(N+180)°` 侧。**禁止**理解为「站在 N° 向外看」。
- **四向正面边界锚定（最高；禁斜对）**：四向拼图各格与视角衍生截取**原则上正对四周边界立面的正面**——背景主景须为正对门、正对窗、正对家具主立面/端面、正对街口/巷口/廊口等；该格背景半空间的主锚实体应以**完整正面/正立面**朝向本格 Viewing Direction（门扇正面、窗框正面、柜体正面、开口面等居中或居背景主位）。**禁止**无上游明文地把门/窗/主家具/街口斜置、对角斜切、斜对镜头当构图——斜对导致背景主景面不可读、邻向误成主景、截取放大后主锚丢失。邻向仅许贴边斜切（见下条），**不得**用邻向斜切冒充本格背景主景。例外仅限上游 Stage 1 明文斜向几何，或开阔无立面时改以道路/地标轴线正对。
- **画面左** = `(N+270)%360`；**画面右** = `(N+90)%360`（摄影机自身左右）。实体自身左/右侧面按正面 F 定义，**不得**直接等同画面左/右。
- **前景/中景/背景**：一律以本格/本镜 Viewing Direction 看——近=前景，远=背景。**扇区≠景深**：仅速查表「背景」列可入本格背景；机位后方禁入背景。
- **严禁对向串写**：0°↔180°、90°↔270° 互不点名对面扇区实体；禁「不可见{对向实体}（机位后方）」。
- **邻向入境硬约束（强制，主环境四向格与全部衍生均适用）**：相邻两向（画面左=`(N+270)%360`、画面右=`(N+90)%360`）内容**允许入境，但只能有小部分可见**——成稿只写**画幅边缘斜切/半截侧缘/窄条透视剪影**，可见占比宜控制在该侧边框内极窄一带（约画幅宽度 ≤10%–15% 的贴边条带）；**禁止**邻向实体大半入画、完整正面/完整立面、整扇门窗主体、整列柜体主体，或把邻向扇区写成与本向背景对等的第二主景。禁搬邻向完整正面。**本格背景主锚仍须正对，不得因邻向斜切而把本格主景写成斜对。**
- **实体唯一性**：默认每种功能全场 1 具；门/窗通常唯一；多件须先写总个数再逐具区分特征；禁美术增补扩成多门多窗。

#### 2.5.3 主环境四向拼图写法（内部推演工具禁入成稿）

**§0 画布契约（首句）**：声明 16:9、2×2、禁俯拍、各格背景具名实体、眼高约 50mm、四格共享材质/光源、**Clean Plate 纯空镜（无人、无角色用途句）**。**强制要求模型在生成的画面上明确带有对应角度（如“0度”、“90度”等）的文字标志。**

**Step 0（内部）**：中央方向性实体轴线/F **只声明一次**，四格共用；禁格间「较上格旋转」链式传递。对称长桌须据上游 `fixed_furniture_and_set_dressing`（主位端/分边椅等）裁定长轴后按下表转换可见面——**禁照搬示例默认轴**。单体方向性实体（椅/柜等）声明**正面朝向 F**（≠放置坐标）。

**Step 1 可见面表（内部，逐格独立查表）**

长条形对称家具（如长桌、床）的物理视角映射（强约束）：

| 家具长轴方向 | 0°格(背景=0°) | 90°格(背景=90°) | 180°格(背景=180°) | 270°格(背景=270°) |

**成稿禁词**：`参照速查表`｜`Step 0/1/2`｜`查表`｜`较 0 度格`｜`内部推演`｜`转角对照`（作过程时）｜本格角度粘贴实体名前（如「90度紧闭木门」）｜跨格摘要行 `(画面左270度=…)`。

**禁写**：格间对照/继承；把本格 `N` 当实体前缀。

#### 2.5.4 衍生三段式与转角（截取放大权威）
- **§A 参考定位**：写明参考哪一宫格（或状态衍生空镜）及本镜背景对应关系。
- **§B 截取放大（核心，禁止重写陈设）**：`generation_prompt_cn` **只**写截取指令，不重述桌椅/材质/光学明细。权威句式见 §2.5.5。
- **§C 状态/特效 Delta**：仅在截取画面上叠加额外可见效果；无则省略。

**转角（内部→logic）**：衍生 0° 正面 = 主环境 N°；90/180/270 = `(N+90/180/270)%360`。方向性实体世界朝向跨衍生一致。`lens_profile`：Master/建置=Wide；OTS/反打=Standard（禁广角）。

**四向细节补充**：仅主环境可增；衍生不做独立拆分；logic 标 `supplemental_entities:{…}` 或 `无`；禁新增 Index 行。**增补落点禁入活动区**（主舞台/表演区/动线/站位承载区）——只许边缘/背景/非动线扇区；违者废弃重写。

**状态/特效/氛围衍生**：首状态→主环境；再状态/状态后视角→上一状态衍生。命名含角度（如 `{N}度{主环境}_{状态}`）。特效须写①作用范围②受影响具名实体及可见变化；禁「能量弥漫」无落点；人物/临场道具特效归 CHAR/PROP。

#### 2.5.5 字段形态骨架（禁照抄剧情）
- 衍生 `description_cn=""`；衍生 logic：`spatial_axis=…；lens_profile=…；axis_crossing=…。本镜头对应主环境{N}度方向（如左上0度格）画面片段截取放大。`
- 衍生 `generation_prompt_cn`（§B 唯一句式）：`请严格要求按对应主环境四向拼图参考图，截取并放大其中对应的明确宫格位置（如：左上0度格 / 右上90度格 / 左下270度格 / 右下180度格），不要重新描述画面细节，直接作为本镜头的最终画面。切割衍生环境时均按16:9固定比例，并保证高分辨率。` + 可选 `在此截取画面基础上叠加…`

| 类型 | 禁 | 正 |
| :--- | :--- | :--- |
| 主环境 | 俯拍；跨格对照；成稿含 Step/速查表；邻向大半入画；门/窗/家具/街口斜对背景 | 四向拼图各格仅本格为主景且**正对**边界正面；邻向只贴边小部分斜切 |
| 视角衍生 | §B 粘贴四向长文或照抄主环境陈设；截取后主锚斜对不可读 | 仅 §2.5.5 截取放大句式指向对应宫格（继承正对边界） |
| 状态后 | §A 仍挂主环境 | §A 挂上一状态衍生；§C 写轻量 Delta |

### 2.6 纯空镜去角色化与门禁（最高硬约束）
环境资产的目标画面是**无人空镜**——只画空间、建筑、固定陈设、材质、光色与空气感。

**`generation_prompt_cn`（含主环境四向各格 / 衍生 §A§B§C）绝对禁止**：
1. **任何人像实体**：具名角色、匿名群演、路人、手/足/肩/背/剪影、焦外人影、倒影中的人、雕像以外的拟人主体（雕像仅当上游固定清单已列）。
2. **任何人物语义**：人称（他/她/他们/某人）、站位/姿态/视线/对白/口型/持握/交互/走位/跪拜/对峙等动作叙述。
3. **任何「用途—角色」句**：把空间写成「给某角色干什么用」——包括但不限于「林月的审讯区」「陈医生坐诊」「供主角逃窜的走廊」「双人对坐会商」「正反打读某某正面」「OTS 看对手」等。此类上游规划语**不得**进入生图词；只保留空镜几何等价物（例：门前净空对峙区→写净空与地标家具，不写人对峙；座次区→写椅位几何，不写谁坐）。
4. **海报例外**：仅 `posters[]` 可按 `visual_dependencies` 整合人物；`environments[]` 永不例外。

**转译口径**：`purpose` / `activity_space` / `activity_fit` / OTS·反打触发原因 → 内部理解空间需求后，成稿只写可见空镜结构与陈设（**须含活动净空/动线/出入口几何**）；人物与剧情功能句留 logic 并标「不成稿」，或直接丢弃不写——**不得**因去角色化而删掉活动空间的空镜结构；`description_cn` 恒 `""`。

**`negative_prompt_en`（环境强制追加语义，可并入既有串）**：`people, person, human, characters, faces, crowd, silhouette of person, hands, body parts, occupied seats with people, cluttered floor blocking walkway, furniture blocking open performance area`。

**提交前自检（任一项命中即废弃重写）**：扫描 `generation_prompt_cn` 是否出现人名/人称/群演/人影/「谁用何处干什么」；扫描成稿禁词、跨格对照、衍生误用 `{N}度方向`（§2.5.3）；主环境是否**明示活动净空/动线/出入画口**（有 `activity_space` 却画面被家具堵满、无可站立调度区 = 失败）；是否按 §2.2.1 达标——**四周每扇区≥4 / 地板≥5 / 天空≥4 或天花≥3**，且中区未用立体堆物凑细节；自然外景是否避免绿蓝垄断并含黄/红穿插（§2.4.1）；室内是否具备 ≥2 项非常规辨识点（§2.4.2）；牌匾/书/纸等文字载体是否按 §2.2.2 写清**内容+字体+繁简体**（有载体无字或繁简冲突=失败）。

### 2.7 全域光影（光学权威 · 美观不平板；环境与海报均适用）
继承 common §1.5-A；与 §2.9 色谱联动。  
**目标**：环境空镜**好看、有体积、有亮暗呼吸、不平板**——同一时段下仍须见 Key 方向、Fill 托起、FG/MG/BG 受光差、半影/投影与材质光学响应；禁均匀平光、禁整室同亮、禁只写「有光/电影感光影」。

**成稿可见动机光口径（强制，与 common §1.5 对齐）**：logic 可规划全场动机光；**`generation_prompt_cn` / 四向各格 / 衍生光学段只列本视角画内可见动机光，1–3 具（上限 3）**。日景默认 ≥1（室内宜 ≥2）可见动机光 + 反射 Fill；覆盖不足时补充反射/渗光效果，**禁机位后具名方源凑数**。夜景/气候差见 §2.8。成稿具名可见源 **禁止 >3**。

**A 规格句式（强制；须写入 `generation_prompt_cn`，紧接开篇时段气候后、色彩规格前或与之紧邻）**：  
`光影体系：时段/内外/气候/季节={…}｜可见动机光={1–3具名或方位}｜Key={来源+方向+照亮面+作用范围+可见效果}｜Fill={反射面或第二Practical+托起面}｜轮廓/分离={有则写动机；无则写无}｜纵深光层：前景={受光/投影}｜中景={主舞台受光}｜背景={收束/渗光}｜半影={柔散}｜材质响应={≥2具名表面}｜大光比={Key:Fill+亮暗分区}。`

**B 落点（美观强制，缺一失败）**：
| 层 | 最低要求 | 美观意图 |
|----|----------|----------|
| **Key** | 来源+方向+主要照亮面+作用范围+可见效果（高光/光斑/条纹光等） | 定光向与造型；禁只写灯名无效果 |
| **Fill** | 具名反射面反弹，或第二画内 Practical；写托起哪些暗部 | 暗部可读、体积成立；禁凭空棚拍补光 |
| **轮廓/分离（可选但推荐）** | 有动机时写背景分离或边缘勾勒；无则显式「无」 | 主舞台与背景切开，防贴片感 |
| **纵深光层** | FG / MG / BG **各写一句**受光或投影差 | 近端投影/遮挡、中景主受光、远端略收或渗光——形成呼吸 |
| **半影与投影** | ≥1 条半影柔散 + ≥1 条落地方向可感投影（绑具名实体） | 落地、有重量；禁刀切硬边（恐怖/上游硬核销除外） |
| **材质光学** | ≥2 具名表面写高光/哑光/透射/湿反射等响应 | 光落在材质上才好看；禁抽象「反光好」 |

**C 防平板（最高）**：
1. **禁均匀平光 / 整室同亮**：无主方向、无亮暗分区 = 失败。
2. **禁只写标签**：仅「侧光/氛围光/电影感」而无来源·范围·效果 = 失败。
3. **禁无 Fill 托起的死黑窟窿**（恐怖压暗场除外且仍须最小动机光可读）：暗部须有反射或第二 Practical 托起纹理。
4. **禁机位后方具名源凑数**；不可见源只写方位+色温+受光效果，禁泄漏实体名。
5. **禁门外渗光却门紧闭**；半开/全开才可写门洞 Key/渗光。
6. **位置几何一致**：入射侧、照亮面、半影、投影方向须与光源落位可对上。
7. **活动区净空不豁免光层**：表演净空可无立体增补，但地面受光/投影、远景墙渗光、边缘 Practical 仍须承担纵深光层——禁因净空而整场平光。
8. **与 §2.9 联动**：亮区/暗区色、Key/Fill 冷暖须落在不同距离层或具名表面，不得光色两张皮。

**D 覆盖清单（8 项中至少 7 项；第 0 项强制）**：  
(0)日夜内外气候季节 (1)可见光源清单 1–3（上限 3） (2)主光方向与照亮面 (3)每可见源作用范围 (4)可见效果 (5)前景/中景/背景光影分层 (6)半影柔散/体积感 (7)冷暖与材质响应（须衔 §2.9 具名色，禁只写「冷暖」标签）。

**E 柔和侧逆光 + 环境反射 Fill**（真人优先；三维/二维改 §2.11/§2.12 语言）：半影自然柔散；禁硬阴影刀切；海报群像同口径。默认照度充足、主舞台可读；大光比见 common §1.5-A（≠无脑压黑）。

**F 四向 / 衍生 / 海报**：
- **四向拼图**：全局光源动机**一次声明**；各格只改相对入射侧与**本格可见**受光/投影落点，不得只抄全局句而各格无光效；不可见源禁名。
- **衍生**：§B 列与基准一致的光色秩序；§C 仅写角度/状态导致的入射侧·色温·投影 Delta；禁另起无动机棚拍光。
- **海报**：Key 服务轮廓与标题留白；Fill/rim 挂靠 ENV 动机光；禁灰片平光糊标题。

**G 自检口诀**：删掉「电影感/高级感」后，能否指出——光从哪来、照亮哪面、Fill 从哪反、近中远哪层更亮、半影/投影落在谁身上？任一否 → 重写光影段。  
`negative_prompt_en` 可追加：`flat lighting, even room brightness, ambient-only wash, hard shadow edge, off-screen light source named in prompt, missing time of day, missing weather, missing season, no volume light, featureless illumination`。

### 2.8 夜景与气候差（剧情允许时 · 美观仍须层次）
触发：夜/雨夜/雾雪霾风暴/浓阴等；恐怖刻意压暗除外（须写依据，仍保留最小可读动机光）。

**原则**：≠整室漆黑，亦≠单点昏灯平板；成稿可见动机光仍**上限 3**（与 §2.7 / common §1.5 一致）；靠反射/渗光效果补覆盖与**纵深光层**。三路径择一或组合并显式写出：①强化自然主光（月/城市穹顶/湿玻璃反射等）②暖调 Practical 覆盖（≤3）③多人工可见源≤3 + 反射接力。最低：显式时段/内外/气候/季节；中景主舞台+≥1 动线在作用范围内；**FG/MG/BG 仍须可辨受光差**（可用湿反射、窗渗、灯池接力）；禁单点昏灯无层次、禁 >3 成稿具名源、禁具名机位后方源、禁整室死黑无 Fill。

### 2.9 色彩体系（色彩权威 · 美观不单调）
继承 common §1.5；不得与 Stage 1 `color_spectrum` 主冷暖冲突。  
**目标**：环境空镜**好看、有色层、不寡淡**——同一主冷暖下仍须见主辅对比、点缀提神、FG/MG/BG 色相/明度差；禁单色平涂、禁灰褐糊成一片。

**A 规格句式（强制；须写入 `generation_prompt_cn`，紧接开篇时段气候后）**：  
`色彩体系：主冷暖={四选一}｜色系={具名双主干，如旧木褐+煤灰蓝}｜色温：主光{K}、Fill{K}、阴影{偏色}｜饱和度：主舞台{中高可读}/远景{略降}｜色彩结构：主色{具名表面×≥2}/辅色{具名表面×≥2}/点缀{物体+部位+面积}/过渡{距离层×≥1}｜纵深色层：前景={色+材质}/中景={色+材质}/背景={色+材质}｜影调：{Key:Fill+对比}｜分离色调：高光{…}、阴影{…}｜色彩构图：{视线引导/层次分离/提神点}。`

**B 落点（美观强制，缺一失败）**：
| 层 | 最低要求 | 美观意图 |
|----|----------|----------|
| **主色** | ≥2 具名表面（墙/地/主家具等），色相可辨 | 定场气质，禁「深色/暖色」抽象词 |
| **辅色** | ≥3 具名表面，与主色**可辨色相差**（非同灰不同明） | 破单调；冷暖对比题材须至少一暖一冷落层 |
| **点缀** | ≥1（宜 1–2），写物体+部位+形态+面积+受光；总面积约 **20%** | **提神色**（金属高光、织物、釉面、植物、灯罩暖芯、铭牌等）——禁零点缀导致发灰 |
| **过渡** | ≥1 距离层或材质衔接带 | 主辅之间的桥色，防色块硬切或糊成一团 |
| **纵深色层** | FG / MG / BG **各写一句**具名色+材质 | 近端可略饱和/暖或冷偏移，远端略降饱和或偏雾——形成呼吸感 |

**C 防单调（最高）**：
1. **禁单色平涂**：全场同一色相仅明度变化 = 失败；至少主+辅两套可检索色名。
2. **禁灰褐糊**：无题材硬核销时，禁止整室「脏灰/褐灰/水泥灰」单主干；须用辅色或点缀拉开（木作/织物/金属/釉面/植被/天空渗光等）。
3. **禁只写冷暖标签**：仅「冷调主导」「偏暖」而无具名表面色 = 失败。
4. **材质绑色**：每条主/辅/点缀色须挂**可见材质**（漆面/石材/织物/金属拉丝等），让色有质感而非色卡贴纸。
5. **亮暗分色**：亮区与暗区色谱分写（可同色系不同明度+微偏色）；冷暖对比题材须 Key/Fill 冷暖落在不同距离层或不同具名表面。
6. **活动区净空不豁免色谱**：表演净空无立体增补，但地面贴层、远景墙面、边缘点缀仍须承担辅色/点缀落点——禁因净空而整场无色层。
7. **禁自然场绿蓝垄断**：外景/山景/自然空镜若主色+辅色+天空均为绿/蓝系且无黄/红（或琥珀/赭石/绛紫）可核销穿插 = 失败；须按 §2.4.1 补非常规色。
8. **禁室内样板间色谱**：室内若仅「白墙+木褐+灰软装」三色循环、无非常规立面色块/材质对撞/异色点缀 = 失败；须按 §2.4.2 补辨识点。

**D 四向 / 衍生 / 海报**：
- **四向拼图**：全局色彩规格**一次声明**（共享主辅点缀秩序）；各格须写出**本格可见表面**上的色落点（背景墙/地面/主家具受光色），不得只抄全局句而各格无色；邻向窄条可带邻向辅色边缘，仍守邻向入境占比。
- **衍生**：§B 列与基准一致的主辅点缀；§C 仅写光学/状态导致的色温·饱和·点缀 Delta（如雨湿加深、火光染暖）；禁另起冲突主色谱。
- **海报**：标题区与主视觉须有明度/色相对比；rim/环境色挂靠 ENV 光源；禁灰片糊标题。
- 三维/二维按 §2.11/§2.12 转译语言（二维可用色块分层，仍须主辅点缀可辨）。

**E 自检口诀**：删掉「电影感/高级感」后，能否指出——哪两块是主色、哪两块是辅色、提神点缀在哪、近中远三层色差在哪？自然场能否指出黄/红穿插落点？室内能否指出非常规辨识点？任一否 → 重写色彩段。  
`negative_prompt_en` 可追加：`monochrome wash, muddy gray-brown palette, flat single-hue grading, desaturated mush, no accent color, uniform color field, generic all-green forest, default blue sky green trees only, white-box interior, showroom flat palette`。

### 2.10 对话正反打与 OTS
- 沿用上游命名格式；禁改 `_OTS_A` 等编号名。
- **两步确认**：继承上游已写结论；本阶段**不重推**对手站位。核对时：①对手可读角 N_对手；②本镜角=`(N_对手±180)%360`；禁见「反打」就默认 180°。
- 只改可见背景/阻隔/光源相对方向/景深层；`PlannedReverse` 须重写 Key 方向与背景半空间；方向性物体随镜重写可见面。
- Clean Plate：禁前景肩膀/人影/角色残留。

### 2.11 三维动画专项（仅 common §1.6 判三维时）
空间骨架/四向/OTS 规则照常；只替换真人材质光影语言。次世代：PBR/GI；风格化：卡通色块+硬边阴影。`negative_prompt_en` 追加真人摄影过滤词；禁赛璐璐纯二维语言。

### 2.12 二维动画专项（仅 common §1.6 判二维时）
空间规则照常；线稿+平涂色块+1–2 层硬边阴影；远景色阶叠加。`negative_prompt_en` 追加 photoreal/3D/PBR；禁真人生活痕迹话术与三维 PBR 语言。

## 三、封面海报

### 3.1 类型与依赖
- `cover_poster` → `posters[]`；`name/name_en` 透传，缺省「封面海报」/`Cover Poster`。
- `dependency_reference` → `visual_dependencies`；logic 说明如何整合为同一主视觉；禁凭空生造剧情外资产。

### 3.2 视觉与光学
- `premium theatrical one-sheet`：单张完整主视觉；前中后景/道具引导线/环境纵深/块面分区。渲染分流：真人→§2.7-E；三维→§2.11；二维→§2.12。
- 主光服务群像塑形、标题留白、层次分离；写日夜/气候/季节 + 可见动机光 1–3（上限 3）+ Key/Fill/纵深光层（§2.7）+ 冷暖对照（§2.9）；不可见源禁实体名；禁平光糊片。
- 标题：安全区/指定位；低噪声底；明度/色相对比；禁高光/特效压标题；副文案版式稳定。
- 拆解上游 `entity_attributes` 为可见元素；`generation_prompt_en=""`。

### 3.3 画幅与移动端
- 显式 `4:3 poster canvas`（写进提示词，不另设 JSON 键）。
- 标题建议 y=30%–35%、x=20%–80%；保留右侧按键区与底部菜单/字幕净空。
