## 核心任务
场景类与封面海报类实体设计。仅处理上游 `Subject Index` 中 `environment/场景` 与 `cover_poster/海报/封面` 类实体，完成美术设计、规范化、镜头转译，并无损封装为 `environments` 与 `posters` 数组。禁止处理剧情切片、动作编排、实体抽取、角色设计或其他实体类型。

**上游空间骨架边界（强制）**：
- Stage 1 **主环境** = 基准定义（俯视 360 + 0 度坐标轴 + 固定实体清单；仰视 360 可选）；**不可作 Beat 当前可拍 ENV**；是未改写氛围下全部视角衍生的默认生图参考源。
- 可拍空镜须为 `{N}度{主环境名}` 或状态后 `{N}度{主环境名}_{状态}` 衍生行。
- **`visual_dependencies`**：无状态 → `ENV:[主环境名]`；状态确立后视角/再状态 → `ENV:[上一状态衍生名]`（禁止跳回主环境）；禁止同基准内角度互挂（如 180°→0°）。
- Stage 1/2.1 对衍生**只提供轻量角度清单**（名、`view_angle_from_main`、触发原因含 OTS/反打两步结论、`spatial_axis`、`lens_profile`、`axis_crossing`、`empty_view_delta` 可选）；**不提供**衍生四向具名实体或前景/中景/背景空镜层次。
- **本 Skill 是衍生四向对位与美术设计的唯一执行方**（见 §2.5）；主环境输出**四向拼图** `generation_prompt_cn`；衍生输出可拍机位且 §A 参考其依赖基准图。

## 一、全局约定

### 1.1 命名与底线
- 原样继承 `subject_no`；`name` / `name_en` / `base_name_en` **逐字符原样透传** Subject Index（含 Index 已写定的空格/`_`/角度前缀等全部字符）；与 common「实体命名绝对锁」一致；**禁止任何形式的修改**（含「规范化空格」「补角度后缀」「缩短主环境名」）。
- 示例仅作格式参考；每次按当前剧本专属设计。

### 1.2A 项目语境注入（Mandatory）
动笔前从 `# Project Context` 与 `entity_attributes` 读取并写入 `generation_prompt_cn`：①基础定位 ②全局风格 ③年代/时代 ④地域/国家 ⑤语言环境 ⑥风格定位（上游未给则据定位+Genre+场域归纳 1 组中文词，logic 注明依据）⑦日夜/内外/气候/季节（未明示则合理推断，logic 注明）。

**开篇句式**：`项目基础定位为{…}，项目全局风格为{…}，年代/时代为{…}，地域/国家为{…}，语言环境为{…}，风格定位为{…}。时段为{…}，内外为{…}，气候为{…}，季节为{…}。` 风格定位跟 2–4 条可视化落点；**色彩规格段（§2.9）**紧接其后。日夜/气候须落到可画光学语义，禁止只贴标签。

- 细节特征 **>6**（主环境**每格** >6；衍生前景/中景/背景合计 >6）。
- 默认「宏大、美观」+ 柔和自然真实（§2.7-E）；仅上游明确破败/恐怖等才切换。
- `_cn` 中文；`_en` 英文；`anchor_description` 英文短语；`generation_prompt_en=""`。
- 环境标识文字：有 `visible_text` 逐字回写；否则据场域/剧情/时地/语言补写完整可读字样入 `description_cn` 与 `generation_prompt_cn`。
- `anchor_description`：3–5 个高密度英文短语（空间结构/主舞台/材质/固定光源）；禁瞬态光影与人物动作。

### 1.3 字段契约（光学/空间权威定义见 §2.5 / §2.7）
- **Clean Plate**：环境只写空间/材质/灯光/空气感；主/衍生禁止具名或匿名人物、人称、站位、交互痕迹；Index 角色不得入 `environments`。海报可按依赖整合。
- **无记忆性**：`generation_prompt_cn` 单独发给无上下文模型；只写画面最终结果，禁推导过程/公式/「对照/继承/同上」。
- **双字段分工**：

| | `description_cn` | `generation_prompt_cn` |
| :--- | :--- | :--- |
| 可写 | 360 拓扑、转角对照（进 logic）、衍生四向【{N}度方向】推导结果、美学参考、含不可见源的光学 rationale | 机位、前景/中景/背景具名实体、可见光作用范围+效果（上限 3）、色彩、当前可见面 |
| 禁写 | 四向成稿回指主环境/映射/「沿观察轴」 | 拓扑字段、度数公式、继承锚点、跨格对照 |

- 转译自检：单独复制 `generation_prompt_cn` 应可直接生图。
- 排除引擎控制符：`--ar` / `--v` / `::` / `<lora:...>` 等。
- `negative_prompt_en` 短而个体化；合规：禁血腥/断肢/涉黄猎奇；战损写非图形化状态。
- 通用光学/色彩/渲染分流细节：权威见 §2.7 / §2.9 / common §1.5–§1.6；本节不重复展开。

### 1.4 审美基线（摘要）
- 对标电影级空间/海报；禁舞台剧/样板间/廉价缩小感/硬光硬影（题材例外注明）。
- 豪宅/高贵室内：高挑、明亮、精致；城市类偏繁华宏大；自然类偏多彩壮观——剧情明确要求萧条/荒凉时方可切换，logic 写依据。
- 贫穷/破旧保留秩序与光影美感；无明确风格时默认优美/大气/现代/摄影机质感。

## 二、环境专项

### 2.1 基础原则
- **上游剧情实体只读**：完整继承固定实体清单、360 拓扑、头尾双锚、主副轴、`empty_view_delta`、`literary_atmosphere`；禁止删改/挪动上游具名实体与拓扑。
- **允许美术增补**：见 §2.5「四向细节补充」；增补不得改拓扑。
- **固定实体零遗漏**：清单内每一实体须逐一进 `description_cn` 与 `generation_prompt_cn`（含四向/衍生核销）；禁止因「次要」省略。
- 专属字段（场所/级别/方向/早晚）+ 日夜/内外/气候/季节须写入 `generation_prompt_cn`。

### 2.2 舞台与空间实体化
- 围绕上游 `{Stage}`：核心舞台在中景；先固定实体与边界，再分层/光照/Delta。
- **出入口可视化**：上游可通行出入口须具名可见（开闭态、门轴侧、连通、净空）；禁堵死成实墙。
- **实体间关系**：前后左右上下 + 每层每实体垂直上/中/下；门窗须写开闭态与内开|外开/门轴侧；方向性实体具名+朝向+正反面（成稿锚固定实体或相对镜头表述）。
- **同质多件分边**（权威）：≥2 具椅凳等须写总个数、分边个数、逐具朝向 F、同侧顺序；衍生完全锁定主环境参考图排布（见 §2.5 §B）。
- **空间均衡**：防过挤/过空；**舞台中区禁增障碍家具**（除非上游已列或剧情必须）；氛围细节落边缘/背景/非动线区。
- 构图简洁有序；控杂但不剥离非动线氛围细节。

### 2.3 光学与美学（执行入口）
先日夜/内外/气候/季节 → 光源清单（§2.7）→ 各层受光/投影 → 色彩（§2.9）→ 陈设。默认照度充足、主舞台可读。焦距：16–35 宏大、50 自然、85–200 压缩。城市/自然执行落点服从 §1.4。礼制空间写中轴/座次/门窗尺度。**真人写实门禁**（仅 §1.6 判真人）：真实可拍场地、生活痕迹；三维/二维改 §2.11/§2.12。

### 2.4 仙侠/东方幻想（题材增量）
可用悬空/云上/非现实比例等，主体清楚重心稳。色可用月白-青碧/冷金等；禁无依据退水墨（除非上游明确）。祥瑞异观写景别/尺度/受光，不抢主舞台。光学仍走 §2.7 清单口径。

### 2.5 主环境四向拼图、衍生与正反逻辑（空间权威）

#### 2.5.1 分层与依赖
- **主环境**：`description_cn` = 俯视 360 + 0 度轴（仰视可选）；`generation_prompt_cn` = 四向拼图（16:9，2×2：左上0/右上90/左下180/右下270，眼高，非俯拍）；`visual_dependencies=[]`；`dependency_strategy.type=BaselineDefinition`；禁作 Beat ENV。
- **全部衍生（含 `0度` Master）**：可拍机位 + 回挂当前空镜基准 + §A/§B/§C；`description_cn` 须独立撰写本衍生 0/90/180/270 四向自然语言（只写推导结果）。

#### 2.5.2 坐标系硬规则
- **0°** = Viewing Direction（非真北）；主环境 0° 轴 = Stage 1 首个非航拍全局建置视角的背景方位。
- **顺时针** = 俯视鸟瞰口径；禁第一人称「向左/右转」推角。
- **N 度格** = 摄影机**朝向** N° 方位实体（该实体在背景）；机位在 `(N+180)°` 侧。**禁止**理解为「站在 N° 向外看」。
- **画面左** = `(N+270)%360`；**画面右** = `(N+90)%360`（摄影机自身左右）。实体自身左/右侧面按正面 F 定义，**不得**直接等同画面左/右。
- **前景/中景/背景**：一律以本格/本镜 Viewing Direction 看——近=前景，远=背景。**扇区≠景深**：仅速查表「背景」列可入本格背景；机位后方禁入背景。
- **严禁对向串写**：0°↔180°、90°↔270° 互不点名对面扇区实体；禁「不可见{对向实体}（机位后方）」。邻向可入中景-左/右，**只写斜切边缘/半截侧缘**，禁搬邻向完整正面。
- **实体唯一性**：默认每种功能全场 1 具；门/窗通常唯一；多件须先写总个数再逐具区分特征；禁美术增补扩成多门多窗。

#### 2.5.3 主环境四向拼图写法（内部推演工具禁入成稿）

**§0 画布契约（首句）**：声明 16:9、2×2、禁俯拍、各格背景具名实体、眼高约 50mm、四格共享材质/光源、Clean Plate。

**Step 0（内部）**：中央方向性实体轴线/F **只声明一次**，四格共用；禁格间「较上格旋转」链式传递。对称桌声明主轴/副轴锚点 + 长边落在哪条轴；椅声明正面朝向 F。

**Step 1 可见面表（内部，逐格独立查表）**

对称长轴（按长边所在轴线）：

| 长边轴线 | 0°格 | 90°格 | 180°格 | 270°格 |
| :--- | :--- | :--- | :--- | :--- |
| 0°–180° | 短边 | 长边 | 短边 | 长边 |
| 90°–270° | 长边 | 短边 | 长边 | 短边 |

方向性实体（按 F）：

| F | 0°格 | 90°格 | 180°格 | 270°格 |
| :--- | :--- | :--- | :--- | :--- |
| 0° | 背面 | 左侧面 | 正面 | 右侧面 |
| 90° | 右侧面 | 背面 | 左侧面 | 正面 |
| 180° | 正面 | 右侧面 | 背面 | 左侧面 |
| 270° | 左侧面 | 正面 | 右侧面 | 背面 |

**四格左右速查表**

| 格 | 背景 | 画面左 | 画面右 | 机位后方（不可见） |
| :--- | :--- | :--- | :--- | :--- |
| 0° | 0° | 270° | 90° | 180° |
| 90° | 90° | 0° | 180° | 270° |
| 180° | 180° | 90° | 270° | 0° |
| 270° | 270° | 180° | 0° | 90° |

对向=`(N+180)%360` 禁入可见清单；邻向只斜切边缘。主环境各格「画面左/右」须带角度（`画面左270度…`）；衍生 §B/§C 改用「中景-左侧/右侧」+ 具名，禁 `{N}度方向` 归属。

**成稿格式（每格）**：`[N度格-位置]` → 背景 → 中景-中央桌 → 中景-各椅【区分特征+锚定地标】→ 其他中景固定物 → 中景-左/右（邻向斜切）→ 前景（若有）→ 天花板 → 地面 → 光照（可见源可具名；不可见源只写方位+效果）。轴向重合成对椅：共线两格写「画面横向居中」+ 远近（地标=本格背景则远，否则近）；另两格才写左/右。

**成稿禁词**：`参照速查表`｜`Step 0/1/2`｜`查表`｜`较 0 度格`｜`内部推演`｜`转角对照`（作过程时）｜本格角度粘贴实体名前（如「90度紧闭木门」）｜跨格摘要行 `(画面左270度=…)`。

**禁写**：格间对照/继承；把本格 `N` 当实体前缀。

#### 2.5.4 衍生三段式与转角
- **§A**：参考主环境四向拼图指定格，或状态衍生已生成空镜；声明本镜背景对应哪一格/半空间。
- **§B**：与参考图一致的具象清单（地面/家具/门窗/色谱/锚点）；每实体前景/中景/背景 + 垂直上/中/下；**椅凳排布完全参考主环境参考图**（分边个数/朝向/顺序具象列出）。
- **§C**：本镜 Delta——机位、前景/中景-左/右/背景重组；机位后方只写「半空间不可见」，禁点名对向墙体/发光实体；方向性物体锚定四向固定实体（头尾双锚优先），头尾均不可见才用相对镜头表述；禁成稿写度数回转公式；禁 `{N}度方向` 作实体归属。

**转角（内部→logic）**：衍生 0° 正面 = 主环境 N° 方位；90/180/270 = `(N+90/180/270)%360`。方向性实体世界朝向跨衍生一致，仅可见面变；例外=状态/特效或明示受力移位。`lens_profile`：Master/建置=Wide；OTS/反打=Standard（禁广角）。`PlannedReverse` 须重映射左右与背景半空间。

**四向细节补充与适度增实体**：可补材质/工艺并适度增陈设（每向通常 0–3）；不得改上游锚点/堵动线；舞台中区禁增障碍家具；增补服从实体唯一性；logic 标 `supplemental_entities:{…}` 或 `无`；禁止新增 Index 行。

**上游空格命名衔接**：最长同名主环境前缀 + 单个空格；找不到则 logic 标上游待补，不擅自补造主环境。

**状态/特效/氛围衍生**：首个状态回挂主环境；再状态或状态后视角回挂上一状态衍生。**特效对实体作用（强制）**：须写①作用范围（相对具名结构的层位/方向）②受影响具名实体及可见变化 ③未受影响实体保持原态；禁只写「能量弥漫」无落点；人物/临场道具特效归 CHAR/PROP。

#### 2.5.5 字段形态骨架（禁照抄剧情）
- 衍生 `description_cn`：`spatial_axis=…；lens_profile=…；axis_crossing=…。【0度方向】…【90度方向】…【180度方向】…【270度方向】…`（每段只写本扇区+中心；禁对向串写/省略号）。
- 衍生 `generation_prompt_cn`：`参考图为…{N}度格…。桌椅排布完全参考该参考图…。{焦距}，机位…。与参考图一致：…。本镜头 Delta：背景…；中景-左侧…；中景-右侧…；机位后方半空间不可见。光学：…。Clean Plate。`

| 类型 | 禁 | 正 |
| :--- | :--- | :--- |
| 主环境 | 俯拍；跨格对照；成稿含 Step/速查表 | 四向拼图各格仅本格可见 |
| 0° Master | §B/§C 粘贴四向段落；反打用广角 | §A+§B+§C 单镜 + Wide |
| 180°/OTS | `{N}度方向`；笼统「有椅子」；照抄 Master | Standard + 参考图分边排布 + 左右翻转 |
| 状态后 | §A 仍挂主环境 | §A 挂上一状态衍生 |

### 2.6 去角色化与门禁
- Index 角色不得入 `environments`；匿名群演仅远景/焦外/不可复用（规模气息），优先非人格痕迹。
- 提交前扫描成稿禁词与跨格对照、衍生 `{N}度方向`（见 §2.5.3）。

### 2.7 全域光影（光学权威；环境与海报均适用）

**成稿可见动机光口径（强制，与 common §1.5 对齐）**：`description_cn`/logic 可规划全场动机光；**`generation_prompt_cn` / 四向各格 / 衍生光学段只列本视角画内可见动机光，默认 1–3、上限 3**。日景默认 ≥1 可见动机光 + 反射 Fill；覆盖不足时优先反射/渗光效果，**不加源突破上限 3，禁具名机位后方源凑数**。夜景/气候差见 §2.8——仍上限 3，用覆盖路径+反射补照度。≥2 可见源须标主光源。

- **位置一致性**：入射/照亮面/半影/投影须与光源落位几何一致。
- **可见/不可见两档**：源画内可见 → 可具名；源不可见 → 成稿只写方位+色温+可见受光效果，**禁泄漏实体名**（优先于配额）。
- **Fill**：只许现有动机光经具名反射面反弹，或已有第二画内可见 Practical；禁凭空棚拍补光灯。
- **门外渗光**：门须已声明半开/全开；紧闭禁当门洞 Key。
- **情境顺序**：时段→内外→气候→季节→再定清单；四项标签+光学语义均须入 `generation_prompt_cn`。
- **8 项中至少 7 项**（第 0 项强制）：(0)日夜内外气候季节 (1)可见光源清单≤3 (2)主光方向与照亮面 (3)每可见源作用范围 (4)可见效果 (5)前景/中景/背景光影分层 (6)半影柔散/体积感 (7)冷暖与材质响应。
- **E. 柔和侧逆光 + 环境反射 Fill**（真人优先；三维/二维改 §2.11/§2.12 语言）：半影自然柔散；禁硬阴影刀切；海报群像同口径。
- 四向拼图：全局光源动机一次声明，各格只改相对入射侧；不可见源禁名。
- `negative_prompt_en` 可追加：`flat lighting, hard shadow edge, off-screen light source named in prompt, missing time of day, missing weather, missing season`。

### 2.8 夜景与气候差（剧情允许时）
触发：夜/雨夜/雾雪霾风暴/浓阴等；恐怖刻意压暗除外（须写依据，仍保留最小可读动机光）。

**原则**：≠整室漆黑；成稿可见动机光仍**上限 3**；靠反射/渗光效果补覆盖。三路径择一或组合并显式写出：①强化自然主光（月/城市穹顶/湿玻璃反射等）②暖调 Practical 覆盖（≤3）③多人工可见源≤3 + 反射接力。最低：显式时段/内外/气候/季节；中景主舞台+≥1 动线在作用范围内；禁单点昏灯、禁 ≥5 成稿具名源、禁具名机位后方源。

### 2.9 色彩体系（色彩权威）
继承 common §1.5；不得与 Stage 1 `color_spectrum` 主冷暖冲突。

**A 规格句式（强制）**：`色彩体系：色系={…}｜色温：主光{K}、Fill{K}、阴影{偏色}｜饱和度：…｜色彩结构：主色{具名表面}/辅色{…}/点缀{物体+部位}/过渡{…}｜影调：{Key:Fill+对比}｜分离色调：高光{…}、阴影{…}｜色彩构图：{视线引导/层次分离}。`

**B 落点**：主色≥2 具名表面；辅色≥2；点缀≥1 且写物体+部位+形态+面积+受光（总面积≤10%）；过渡≥1 距离层。

**C–E**：色彩构图须可镜头执行；四向拼图全局色彩一次声明、各格落点一致；衍生 §B 列色谱一致项，§C 仅光学 Delta；海报写标题区色相对比与 rim 挂靠 ENV 光源。三维/二维按 §2.11/§2.12 转译语言。

### 2.10 对话正反打与 OTS
- 沿用上游命名格式；禁改 `_OTS_A` 等编号名。
- **两步确认**：继承上游已写结论；本阶段**不重推**对手站位。核对时：①对手可读角 N_对手；②本镜角=`(N_对手±180)%360`；禁见「反打」就默认 180°。
- 只改可见背景/阻隔/光源相对方向/景深层；`PlannedReverse` 须重写 Key 方向与背景半空间；方向性物体随镜重写可见面。
- Clean Plate：禁前景肩膀/人影/角色残留。

### 2.11 三维动画专项（仅 common §1.6 判三维时）
空间骨架/四向/OTS 规则照常；只替换真人材质光影语言。次世代：PBR/GI；风格化：卡通色块+硬边阴影。`negative_prompt_en` 追加真人摄影过滤词；禁赛璐璐纯二维语言。

### 2.12 二维动画专项（仅 common §1.6 判二维时）
空间规则照常；线稿+平涂色块+1–2 层硬边阴影；远景色阶叠加。`negative_prompt_en` 追加 photoreal/3D/PBR；禁真人生活痕迹话术与三维 PBR 语言。

## 三、封面海报

### 3.1 类型与依赖
- `cover_poster` → `posters[]`；`name/name_en` 透传，缺省「封面海报」/`Cover Poster`。
- `dependency_reference` → `visual_dependencies`；logic 说明如何整合为同一主视觉；禁凭空生造剧情外资产。

### 3.2 视觉与光学
- `premium theatrical one-sheet`：单张完整主视觉；前中后景/道具引导线/环境纵深/块面分区。渲染分流：真人→§2.7-E；三维→§2.11；二维→§2.12。
- 主光服务群像塑形、标题留白、层次分离；写日夜/气候/季节 + 可见动机光 1–3（上限 3）+ 冷暖对照；不可见源禁实体名。
- 标题：安全区/指定位；低噪声底；明度/色相对比；禁高光/特效压标题；副文案版式稳定。
- 拆解上游 `entity_attributes` 为可见元素；`generation_prompt_en=""`。

### 3.3 画幅与移动端
- 显式 `4:3 poster canvas`（写进提示词，不另设 JSON 键）。
- 标题建议 y=30%–35%、x=20%–80%；保留右侧按键区与底部菜单/字幕净空。
