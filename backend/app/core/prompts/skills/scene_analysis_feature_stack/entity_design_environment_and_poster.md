## 一、全局约定

### 1.1 命名与底线
- 命名锁 / `subject_no` / Clean Plate / 合规 / 双语字段：见 common。环境名尤须保留 Index 已写定的空格/`_`/角度前缀全串；禁「规范化空格」「补角度后缀」「缩短主环境名」。

### 1.2A 项目语境注入（环境 delta）
通则见 common §1.2A。环境额外强制：⑦日夜/内外/气候/季节须写入开篇并可画（未明示则合理推断，logic 注明）；**色彩规格段（§2.9）**紧接开篇；细节 >6（主环境每格 / 衍生段均 >6）。

**开篇句式**：`项目基础定位为{…}，项目全局风格为{…}，年代/时代为{…}，地域/国家为{…}，语言环境为{…}，风格定位为{…}。时段为{…}，内外为{…}，气候为{…}，季节为{…}。` + 风格定位 2–4 条可视化落点。

- `anchor_description`：逗号连接 3–5 个英文短语（空间结构/主舞台/材质/固定光源）；禁 JSON 数组、瞬态光影、人物动作。

### 1.3 字段契约（光学/空间权威见 §2.5 / §2.7）
- Clean Plate / 引擎控制符 / `negative_prompt_en` / 合规：见 common；**环境主/衍生 = 纯空镜（最高）**——见 §2.6。
- **无记忆性**：`generation_prompt_cn` 只写画面最终结果，禁推导过程/公式/「对照/继承/同上」。
- **双字段分工**：

| | `description_cn` | `generation_prompt_cn` |
| :--- | :--- | :--- |
| 可写 | 360 拓扑、转角对照（进 logic）、美学参考、含不可见源的光学 rationale；衍生仅元数据+Delta；规划备注可括注「不成稿」 | 机位、前景/中景/背景具名**物**实体、可见光 1–3、色彩、当前可见面；衍生=截取放大指令+可选 Delta；**仅空镜** |
| 禁写 | 四向成稿回指主环境/映射/「沿观察轴」；成稿句写入人名/人称/站位交互 | 拓扑字段、度数公式、继承锚点、跨格对照；**任何人物/用途句**（§2.6） |

- 转译自检：单独复制 `generation_prompt_cn` 应可直接生图。

### 1.4 审美基线（环境 delta；通则见 common §1.4）
- 对标电影级空间/海报；禁舞台剧/样板间/廉价缩小感。
- **环境增量**：无上游明文限制时优先**宏大、开阔、高挑**（豪宅强调挑高通透；城市偏繁华；自然偏开阔层次）；张力用光色/秩序/空寂，**禁用脏乱代替戏剧性**。
- **色彩美观（强制）**：环境画面须**有层次、有色相呼吸、不单调**——主/辅/点缀/过渡四层落地到具名表面与 FG/MG/BG；禁全场灰褐糊成一团、禁只写「冷调/暖调」无具名色；细则 §2.9。

## 二、环境专项

### 2.1 基础原则
- **上游绑定**：`topology_top_down_360` / `zero_degree_axis` / `spatial_anchor_head|tail` / `fixed_architecture_and_finish` / `fixed_furniture_and_set_dressing` **只读继承**——禁删改挪动具名实体与拓扑、禁颠倒头尾锚点、禁省略陈设。
- **长轴物理一致性**：中央长条家具（桌/床等）须先据上游裁定长轴（0°–180° 或 90°–270°），再按 §2.5.3 可见面表成稿；**禁止**默认固化一种走向。权威表与 F 朝向防错见 §2.5.3。
- **允许美术增补**：见 §2.5；增补不得改拓扑。
- **固定实体零遗漏**：清单内每一实体须进 `description_cn` 与主环境四向 `generation_prompt_cn`；禁止因「次要」省略。
- 专属字段 + 日夜/内外/气候/季节须写入 `generation_prompt_cn`。

### 2.2 舞台与空间实体化
- 围绕上游 `{Stage}`：核心舞台在中景；先固定实体与边界，再分层/光照/Delta。
- **实体落位、进深与背景强锚定（防发飘）**：除了声明实体处于哪条轴/哪个格，还必须清晰交代其在空间进深上的精准透视关系以及与对应背景的纵深/横贯锚定。如果是条形家具，在纵深视角下必须严格写明“从画面近端向背景X度深处延伸/指向”；在横贯视角下必须写明“X度端在画面左侧，Y度端在画面右侧”，切忌只干瘪地写“可见短边/可见长边”，必须牢牢钉死它与所处画格空间背景的几何透视联系。以此巩固中景的纵深感并指引生图模型正确绘制。
- **出入口可视化**：上游可通行出入口须具名可见（开闭态、门轴侧、连通、净空）；禁堵死成实墙。
- **实体间关系**：前后左右上下 + 每层每实体垂直上/中/下；门窗须写开闭态与内开|外开/门轴侧；方向性实体具名+朝向+正反面（成稿锚固定实体或相对镜头表述）。
- **细节质感与真实性补充（提升美感）**：不能仅列出干瘪的家具名，必须为每一个具名构件或家具补充**材质、纹理、光泽度或自然使用痕迹**（例如：带有细碎划痕的黑胡桃木桌面、反光的做旧黄铜边框、边缘泛着冷光的钢化玻璃等），以切实提升画面的电影写实质感与美学底蕴。
- **同质多件分边与冗余重复（防遗漏铁律）**：≥2 具椅凳等须写总个数、分边个数、逐具朝向 F、同侧顺序；更重要的是：**在描写四向拼图中每格（0°/90°/180°/270°）的具体画面时，必须【冗余地、无死角地】重复交代这几把椅子的具体可见面及相对位置，绝不允许在某一个画格里偷懒省略！如果场内有3把椅子，每个画格的描写里都必须清楚说明场内共有3把椅子，然后写明这3把椅子分别在哪、哪一面可见！**
- **实体配套性（强制）**：上游已写的成套关系（桌↔椅、床↔被枕、壶↔杯盏等）须在描述层**完整可视化**并写明个数/分边；禁只画主件漏配件、禁隐去数量。**边界**：仅同 Subject 描述层补可视化；上游清单漏写配套件 → 标「上游待补（回流 Stage 2）」，**禁止**擅自新增 Index 行或伪造未声明实体凑套；禁增补成无关堆砌。
- **活动区净空（最高；禁止在活动区设计实体物件）**：上游 `activity_space` /【活动空间】划定的**主舞台/表演区、动线、站位承载区**为表演净空——**禁止**在该区内美术增补、挪移或新设计任何立体实体物件（家具/陈设/立柱/屏风/盆景/箱柜等）；仅允许地毯/地砖/贴地纹样等**不影响站立·走动·跪拜**的贴地层，或上游固定清单已明文落在该区且剧情硬核销的实体（如对白桌/座次椅——且不得再向表演净空加件）。氛围细节、控杂增补、祥瑞点缀一律落**边缘/背景向/非动线区**，不得挤占活动区。
- **空间均衡**：防过挤（活动区/动线阻塞）与过空（四向空洞棚拍感）；偏空才在非活动区增、偏挤则控杂并优先清空活动区障碍。
- 构图简洁有序；控杂但不剥离非动线氛围细节。

### 2.3 光学与美学（执行入口）
先日夜/内外/气候/季节 → 光源清单（§2.7）→ 各层受光/投影 → 色彩（§2.9）→ 陈设。默认照度充足、主舞台可读。焦距：16–35 宏大、50 自然、85–200 压缩。城市/自然执行落点服从 §1.4。礼制空间写中轴/座次/门窗尺度。**真人写实门禁**（仅 §1.6 判真人）：真实可拍场地、生活痕迹；三维/二维改 §2.11/§2.12。

### 2.4 仙侠/东方幻想（题材增量）
可用悬空/云上/非现实比例等，主体清楚重心稳。色可用月白-青碧/冷金等；禁无依据退水墨（除非上游明确）。祥瑞异观写景别/尺度/受光，不抢主舞台。光学仍走 §2.7 清单口径。

### 2.4.1 自然风景/山景（题材增量）
山景/自然空镜须有季节与生态层次（植被色相、远近层次、可选水体），避免棚拍单调；**服从**上游固定实体清单与实体唯一性——禁止无据强制塞入枫叶/瀑布等清单外主体；季节色与点缀优先转译已有植被/地表，缺口回流而非自创 Index 实体。

### 2.5 主环境四向拼图、衍生与正反逻辑（空间权威）

#### 2.5.1 分层与依赖
- **主环境**：`description_cn` = 俯视 360 + 0 度轴（仰视可选）；`generation_prompt_cn` = 四向拼图（16:9，2×2：左上0/右上90/左下270/右下180，眼高，非俯拍）；`visual_dependencies=[]`；`dependency_strategy.type=BaselineDefinition`；禁作 Beat ENV。
- **全部衍生（含 `0度` Master，截取放大权威）**：可拍机位 + 回挂当前空镜基准 + §A/§B/§C。`generation_prompt_cn` = **截取放大**对应宫格（见 §2.5.4–§2.5.5），**禁止**再写满四向陈设长文。`description_cn` = 元数据（`spatial_axis` / `lens_profile` / `axis_crossing` / 对应宫格）+ 状态/特效 Delta（若有）；**不再逐向铺陈细节**。转角四向推演仅进 logic，不成稿。

#### 2.5.2 坐标系硬规则
- **0°** = Viewing Direction（非真北）；主环境 0° 轴 = Stage 1 首个非航拍全局建置视角的背景方位。
- **顺时针** = 俯视鸟瞰口径；禁第一人称「向左/右转」推角。
- **N 度格** = 摄影机**朝向** N° 方位实体（该实体在背景）；机位在 `(N+180)°` 侧。**禁止**理解为「站在 N° 向外看」。
- **画面左** = `(N+270)%360`；**画面右** = `(N+90)%360`（摄影机自身左右）。实体自身左/右侧面按正面 F 定义，**不得**直接等同画面左/右。
- **前景/中景/背景**：一律以本格/本镜 Viewing Direction 看——近=前景，远=背景。**扇区≠景深**：仅速查表「背景」列可入本格背景；机位后方禁入背景。
- **严禁对向串写**：0°↔180°、90°↔270° 互不点名对面扇区实体；禁「不可见{对向实体}（机位后方）」。
- **邻向入境硬约束（强制，主环境四向格与全部衍生均适用）**：相邻两向（画面左=`(N+270)%360`、画面右=`(N+90)%360`）内容**允许入境，但只能有小部分可见**——成稿只写**画幅边缘斜切/半截侧缘/窄条透视剪影**，可见占比宜控制在该侧边框内极窄一带（约画幅宽度 ≤10%–15% 的贴边条带）；**禁止**邻向实体大半入画、完整正面/完整立面、整扇门窗主体、整列柜体主体，或把邻向扇区写成与本向背景对等的第二主景。禁搬邻向完整正面。
- **实体唯一性**：默认每种功能全场 1 具；门/窗通常唯一；多件须先写总个数再逐具区分特征；禁美术增补扩成多门多窗。

#### 2.5.3 主环境四向拼图写法（内部推演工具禁入成稿）

**§0 画布契约（首句）**：声明 16:9、2×2、禁俯拍、各格背景具名实体、眼高约 50mm、四格共享材质/光源、**Clean Plate 纯空镜（无人、无角色用途句）**。**强制要求模型在生成的画面上明确带有对应角度（如“0度”、“90度”等）的文字标志。**

**Step 0（内部）**：中央方向性实体轴线/F **只声明一次**，四格共用；禁格间「较上格旋转」链式传递。对称长桌须据上游 `fixed_furniture_and_set_dressing`（主位端/分边椅等）裁定长轴后按下表转换可见面——**禁照搬示例默认轴**。单体方向性实体（椅/柜等）声明**正面朝向 F**（≠放置坐标）。

**Step 1 可见面表（内部，逐格独立查表）**

长条形对称家具（如长桌、床）的物理视角映射（强约束）：

| 家具长轴方向 | 0°格(背景=0°) | 90°格(背景=90°) | 180°格(背景=180°) | 270°格(背景=270°) |
| :--- | :--- | :--- | :--- | :--- |
| **0°-180° 轴线** | **纵深**：可见短边，由近景向**0°背景**延伸 | **横跨**：可见长边，**0°端**在画左、**180°端**在画右 | **纵深**：可见短边，由近景向**180°背景**延伸 | **横跨**：可见长边，**180°端**在画左、**0°端**在画右 |
| **90°-270° 轴线** | **横跨**：可见长边，**270°端**在画左、**90°端**在画右 | **纵深**：可见短边，由近景向**90°背景**延伸 | **横跨**：可见长边，**90°端**在画左、**270°端**在画右 | **纵深**：可见短边，由近景向**270°背景**延伸 |

方向性实体（按 F，即物体正面的朝向方位）：
**强防错约束：必须用物体的实际朝向 F 查表，绝不能用物体所处的位置坐标查表！例如：放在 0° 端的椅子如果“朝向 180°（面朝大门）”，那么 F=180°。查表可得在 0° 格（摄影机在 180° 往 0° 拍）必然看到的是该椅子的【正面】；在 180° 格摄影机在它背后，看到的是【背面】。严禁将位置 0° 错当成朝向 0°，导致正反面完全写反！**

| 0° | 背面 | 左侧面 | 正面 | 右侧面 |

对向=`(N+180)%360` 禁入可见清单；邻向只许**小部分可见的贴边斜切**（见上「邻向入境硬约束」）。主环境各格「画面左/右」须带角度（`画面左270度…`）；衍生 §B/§C 改用「中景-左侧/右侧」+ 具名，禁 `{N}度方向` 归属；左右侧句须显式落点为「边缘斜切/半截侧缘/窄条可见」，禁写邻向整景。

**成稿格式（每格）**：`[N度格-位置]` → 背景 → 中景-中央桌 → 中景-各椅【**警告：即使总述中提过，本格也必须先说明共有几把椅子，然后再对该视角下所有椅子的可见面与相对位置进行无死角的冗余重复声明，禁止在这个格子里让任何一把椅子凭空消失！**】→ 其他中景固定物 → 中景-左/右（邻向**仅小部分**斜切入境）→ 前景（若有）→ 天花板 → 地面 → 光照（可见源可具名；不可见源只写方位+效果）。轴向重合成对椅：共线两格写「画面横向居中」+ 远近（地标=本格背景则远，否则近）；另两格才写左/右。

**成稿禁词**：`参照速查表`｜`Step 0/1/2`｜`查表`｜`较 0 度格`｜`内部推演`｜`转角对照`（作过程时）｜本格角度粘贴实体名前（如「90度紧闭木门」）｜跨格摘要行 `(画面左270度=…)`。

**禁写**：格间对照/继承；把本格 `N` 当实体前缀。

#### 2.5.4 衍生三段式与转角（截取放大权威）
- **§A 参考定位**：写明参考哪一宫格（或状态衍生空镜）及本镜背景对应关系。
- **§B 截取放大（核心，禁止重写陈设）**：`generation_prompt_cn` **只**写截取指令，不重述桌椅/材质/光学明细。权威句式见 §2.5.5。
- **§C 状态/特效 Delta**：仅在截取画面上叠加额外可见效果；无则省略。

**转角（内部→logic）**：衍生 0° 正面 = 主环境 N°；90/180/270 = `(N+90/180/270)%360`。方向性实体世界朝向跨衍生一致。`lens_profile`：Master/建置=Wide；OTS/反打=Standard（禁广角）。

**四向细节补充**：仅主环境可增；衍生不做独立拆分；logic 标 `supplemental_entities:{…}` 或 `无`；禁新增 Index 行。**增补落点禁入活动区**（主舞台/表演区/动线/站位承载区）——只许边缘/背景/非动线扇区；违者废弃重写。

**状态/特效/氛围衍生**：首状态→主环境；再状态/状态后视角→上一状态衍生。命名含角度（如 `{N}度{主环境}_{状态}`）。特效须写①作用范围②受影响具名实体及可见变化；禁「能量弥漫」无落点；人物/临场道具特效归 CHAR/PROP。

#### 2.5.5 字段形态骨架（禁照抄剧情）
- 衍生 `description_cn`：`spatial_axis=…；lens_profile=…；axis_crossing=…。本镜头对应主环境{N}度方向（如左上0度格）画面片段截取放大。`
- 衍生 `generation_prompt_cn`（§B 唯一句式）：`请严格要求按对应主环境四向拼图参考图，截取并放大其中对应的明确宫格位置（如：左上0度格 / 右上90度格 / 左下270度格 / 右下180度格），不要重新描述画面细节，直接作为本镜头的最终画面。切割衍生环境时均按16:9固定比例，并保证高分辨率。` + 可选 `在此截取画面基础上叠加…`

| 类型 | 禁 | 正 |
| :--- | :--- | :--- |
| 主环境 | 俯拍；跨格对照；成稿含 Step/速查表；邻向大半入画 | 四向拼图各格仅本格为主景；邻向只贴边小部分斜切 |
| 视角衍生 | §B 粘贴四向长文或照抄主环境陈设 | 仅 §2.5.5 截取放大句式指向对应宫格 |
| 状态后 | §A 仍挂主环境 | §A 挂上一状态衍生；§C 写轻量 Delta |

### 2.6 纯空镜去角色化与门禁（最高硬约束）
环境资产的目标画面是**无人空镜**——只画空间、建筑、固定陈设、材质、光色与空气感。

**`generation_prompt_cn`（含主环境四向各格 / 衍生 §A§B§C）绝对禁止**：
1. **任何人像实体**：具名角色、匿名群演、路人、手/足/肩/背/剪影、焦外人影、倒影中的人、雕像以外的拟人主体（雕像仅当上游固定清单已列）。
2. **任何人物语义**：人称（他/她/他们/某人）、站位/姿态/视线/对白/口型/持握/交互/走位/跪拜/对峙等动作叙述。
3. **任何「用途—角色」句**：把空间写成「给某角色干什么用」——包括但不限于「林月的审讯区」「陈医生坐诊」「供主角逃窜的走廊」「双人对坐会商」「正反打读某某正面」「OTS 看对手」等。此类上游规划语**不得**进入生图词；只保留空镜几何等价物（例：门前净空对峙区→写净空与地标家具，不写人对峙；座次区→写椅位几何，不写谁坐）。
4. **海报例外**：仅 `posters[]` 可按 `visual_dependencies` 整合人物；`environments[]` 永不例外。

**转译口径**：`purpose` / `activity_space` / `activity_fit` / OTS·反打触发原因 → 内部理解空间需求后，成稿只写可见空镜结构与陈设；人物与剧情功能句留 `description_cn`/logic 并标「不成稿」，或直接丢弃不写。

**`negative_prompt_en`（环境强制追加语义，可并入既有串）**：`people, person, human, characters, faces, crowd, silhouette of person, hands, body parts, occupied seats with people`。

**提交前自检（任一项命中即废弃重写）**：扫描 `generation_prompt_cn` 是否出现人名/人称/群演/人影/「谁用何处干什么」；扫描成稿禁词、跨格对照、衍生误用 `{N}度方向`（§2.5.3）。

### 2.7 全域光影（光学权威；环境与海报均适用）

**成稿可见动机光口径（强制，与 common §1.5 对齐）**：`description_cn`/logic 可规划全场动机光；**`generation_prompt_cn` / 四向各格 / 衍生光学段只列本视角画内可见动机光，1–3 具（上限 3）**。日景默认 ≥1（室内宜 ≥2）可见动机光 + 反射 Fill；覆盖不足时补充反射/渗光效果，**禁机位后具名方源凑数**。夜景/气候差见 §2.8。成稿具名可见源 **禁止 >3**。

- **位置一致性**：入射/照亮面/半影/投影须与光源落位几何一致。
- **可见/不可见两档**：源画内可见 → 可具名；源不可见 → 成稿只写方位+色温+可见受光效果，**禁泄漏实体名**（优先于配额）。
- **Fill**：只许现有动机光经具名反射面反弹，或已有第二画内可见 Practical；禁凭空棚拍补光灯。
- **门外渗光**：门须已声明半开/全开；紧闭禁当门洞 Key。
- **情境顺序**：时段→内外→气候→季节→再定清单；四项标签+光学语义均须入 `generation_prompt_cn`。
- **8 项中至少 7 项**（第 0 项强制）：(0)日夜内外气候季节 (1)可见光源清单 1–3（上限 3） (2)主光方向与照亮面 (3)每可见源作用范围 (4)可见效果 (5)前景/中景/背景光影分层 (6)半影柔散/体积感 (7)冷暖与材质响应（须衔 §2.9 具名色，禁只写「冷暖」标签）。
- **E. 柔和侧逆光 + 环境反射 Fill**（真人优先；三维/二维改 §2.11/§2.12 语言）：半影自然柔散；禁硬阴影刀切；海报群像同口径。
- 四向拼图：全局光源动机一次声明，各格只改相对入射侧；不可见源禁名；**色彩**按 §2.9 全局一次声明 + 各格可见表面色落点。
- `negative_prompt_en` 可追加：`flat lighting, hard shadow edge, off-screen light source named in prompt, missing time of day, missing weather, missing season, monochrome wash, muddy gray-brown palette, flat single-hue grading`。

### 2.8 夜景与气候差（剧情允许时）
触发：夜/雨夜/雾雪霾风暴/浓阴等；恐怖刻意压暗除外（须写依据，仍保留最小可读动机光）。

**原则**：≠整室漆黑；成稿可见动机光仍**上限 3**（与 §2.7 / common §1.5 一致）；靠反射/渗光效果补覆盖。三路径择一或组合并显式写出：①强化自然主光（月/城市穹顶/湿玻璃反射等）②暖调 Practical 覆盖（≤3）③多人工可见源≤3 + 反射接力。最低：显式时段/内外/气候/季节；中景主舞台+≥1 动线在作用范围内；禁单点昏灯、禁 >3 成稿具名源、禁具名机位后方源。

### 2.9 色彩体系（色彩权威 · 美观不单调）
继承 common §1.5；不得与 Stage 1 `color_spectrum` 主冷暖冲突。  
**目标**：环境空镜**好看、有色层、不寡淡**——同一主冷暖下仍须见主辅对比、点缀提神、FG/MG/BG 色相/明度差；禁单色平涂、禁灰褐糊成一片。

**A 规格句式（强制；须写入 `generation_prompt_cn`，紧接开篇时段气候后）**：  
`色彩体系：主冷暖={四选一}｜色系={具名双主干，如旧木褐+煤灰蓝}｜色温：主光{K}、Fill{K}、阴影{偏色}｜饱和度：主舞台{中高可读}/远景{略降}｜色彩结构：主色{具名表面×≥2}/辅色{具名表面×≥2}/点缀{物体+部位+面积}/过渡{距离层×≥1}｜纵深色层：前景={色+材质}/中景={色+材质}/背景={色+材质}｜影调：{Key:Fill+对比}｜分离色调：高光{…}、阴影{…}｜色彩构图：{视线引导/层次分离/提神点}。`

**B 落点（美观强制，缺一失败）**：
| 层 | 最低要求 | 美观意图 |
|----|----------|----------|
| **主色** | ≥2 具名表面（墙/地/主家具等），色相可辨 | 定场气质，禁「深色/暖色」抽象词 |
| **辅色** | ≥2 具名表面，与主色**可辨色相差**（非同灰不同明） | 破单调；冷暖对比题材须至少一暖一冷落层 |
| **点缀** | ≥1（宜 1–2），写物体+部位+形态+面积+受光；总面积约 **10%** | **提神色**（金属高光、织物、釉面、植物、灯罩暖芯、铭牌等）——禁零点缀导致发灰 |
| **过渡** | ≥1 距离层或材质衔接带 | 主辅之间的桥色，防色块硬切或糊成一团 |
| **纵深色层** | FG / MG / BG **各写一句**具名色+材质 | 近端可略饱和/暖或冷偏移，远端略降饱和或偏雾——形成呼吸感 |

**C 防单调（最高）**：
1. **禁单色平涂**：全场同一色相仅明度变化 = 失败；至少主+辅两套可检索色名。
2. **禁灰褐糊**：无题材硬核销时，禁止整室「脏灰/褐灰/水泥灰」单主干；须用辅色或点缀拉开（木作/织物/金属/釉面/植被/天空渗光等）。
3. **禁只写冷暖标签**：仅「冷调主导」「偏暖」而无具名表面色 = 失败。
4. **材质绑色**：每条主/辅/点缀色须挂**可见材质**（漆面/石材/织物/金属拉丝等），让色有质感而非色卡贴纸。
5. **亮暗分色**：亮区与暗区色谱分写（可同色系不同明度+微偏色）；冷暖对比题材须 Key/Fill 冷暖落在不同距离层或不同具名表面。
6. **活动区净空不豁免色谱**：表演净空无立体增补，但地面贴层、远景墙面、边缘点缀仍须承担辅色/点缀落点——禁因净空而整场无色层。

**D 四向 / 衍生 / 海报**：
- **四向拼图**：全局色彩规格**一次声明**（共享主辅点缀秩序）；各格须写出**本格可见表面**上的色落点（背景墙/地面/主家具受光色），不得只抄全局句而各格无色；邻向窄条可带邻向辅色边缘，仍守邻向入境占比。
- **衍生**：§B 列与基准一致的主辅点缀；§C 仅写光学/状态导致的色温·饱和·点缀 Delta（如雨湿加深、火光染暖）；禁另起冲突主色谱。
- **海报**：标题区与主视觉须有明度/色相对比；rim/环境色挂靠 ENV 光源；禁灰片糊标题。
- 三维/二维按 §2.11/§2.12 转译语言（二维可用色块分层，仍须主辅点缀可辨）。

**E 自检口诀**：删掉「电影感/高级感」后，能否指出——哪两块是主色、哪两块是辅色、提神点缀在哪、近中远三层色差在哪？任一否 → 重写色彩段。  
`negative_prompt_en` 可追加：`monochrome wash, muddy gray-brown palette, flat single-hue grading, desaturated mush, no accent color, uniform color field`。

### 2.10 对话正反打与 OTS
- 沿用上游命名格式；禁改 `_OTS_A` 等编号名。
- **两步确认**：继承上游已写结论；本阶段**不重推**对手站位。核对时：①对手可读角 N_对手；②本镜角=`(N_对手±180)%360`；禁见「反打」就默认 180°。

- Clean Plate：禁前景肩膀/人影/角色残留。

### 2.11 三维动画专项（仅 common §1.6 判三维时）
空间骨架/四向/OTS 规则照常；只替换真人材质光影语言。次世代：PBR/GI；风格化：卡通色块+硬边阴影。`negative_prompt_en` 追加真人摄影过滤词；禁赛璐璐纯二维语言。

### 2.12 二维动画专项（仅 common §1.6 判二维时）
