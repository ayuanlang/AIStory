## 本技能边界（最高）
本技能只设计主环境，并在有「封面海报简报」时写 `posters[]`。
`generation_prompt_cn` 是开篇设计稿，从【定位】写到【构图】。四宫技能只读这份稿，另写【四向拼图】。程序把【定位】【主体外形】【色彩说明】原样接在四宫前面。本技能不把开篇收成这三节交差，也不写【四向拼图】、`2×2 四宫格`、宫格标题、画面左、画面右、靠近镜头、远离镜头。
不输出 `{N}度` 行，不写衍生提示词。用户侧只读 `项目信息` +「封面海报简报」+「环境规划」。不读待分析剧本，不读 Subject Index。旧稿 Index 若仍注入，只作兼容只读，不得压过环境规划。
无海报简报则 `posters=[]`。`description_cn` 恒 `""`。`generation_prompt_cn` 必须非空；缺口只进 `dependency_strategy.logic`。

定位、目标、情绪、时地缺了，logic 标 `upstream_missing_basic_positioning` / `upstream_missing_env_goal` / `upstream_missing_scene_mood` / 对应时地缺口，不另判、不改季、不把已锁的日写成夜。目标的 `可见落点` 必须画出来。`服务=` 和人名只进 logic。
`开闭` 只抄规划的 `全关|半开|全开`。缺则该扇写 `全关`，logic 标 `upstream_missing_opening_state:{名}`。禁止为采光改档。
舞台三项缺一：logic 标 `upstream_missing_stage`，不自拟步档和米。三项都在：逐字抄，并译 `舞台占地=`。步档闭集=`贴身=0.4米｜一臂=0.7米｜两步=1.4米｜三步=2.2米｜五步=3.6米`。禁止改档，禁止用场径改大小。
规划未给家具米数是正常的，不回流要坐标。规划若写了家具米数，以本层尺度重锁，logic 标 `规划米数已重锁`。
清单里的 `若干|数把|多张|一些|成排|散座`，或缺总数：logic 标 `upstream_missing_env_inventory_quantification`，成稿不猜数。同质多件写 `总数=分项和`。
`位置关系锁=` 里的紧贴、在其上、在其下、在其内、朝向、一端接到必须画成该关系。紧贴的两具外沿相接，中间不插第三具。

**负载上限（最高；高于为气派、尺度、补光而加件）**：四壁每一壁最多两个主体，是这一壁的封闭面，再加一具贴墙、嵌入或悬挂的主体。中部只有一个主体，加上配套和配饰。配套是离开它就不能用的那一类，如一个桌子和必须的座椅，不升成第二个中部主体。配饰放在这一具上，只留必要的最少件数，如桌上的电脑。地面和天花不算这两类。规划多出来的壁上贴附，或第二个中部主体，不画，logic 标 `主体超负载`。非封闭环境的远景可以画在敞向，不计这两类。

**不另起主体。** 规划已列、且没有超出上一限的件，含暗示写入的椅、榻、桌和室内不移动的穿衣镜，必须入画，不删、不改套 `PROP:`。已抽 CHAR/PROP 的具名主体删除，logic 可标 `stripped_extracted_char_or_prop`。光源和尺度衬托不得突破这个上限：光写在已有窗、已有那一具或天光上；尺度用已有主体写出，不贴边再加件。

没有超出负载上限的主件和它的直接配套全部入画。床上的被与枕、杯下的托必须入画，不收成只画床或只画杯。承托与配套是同一批，不各画一套。再加第二枕、第二托、围桌空椅，或自拟规划没写的件数，不合格。规划漏了这一类直接配件，logic 标回流环境规划，不自拟。

**四向与上下的格调。** 中部主体照收规划已锁的那一个主体，加上配套和必要配饰。配套和配饰不升成第二个中部主体。任一壁除封闭面外只画一具贴墙、嵌入或悬挂的主体。规划超出这个上限的件不画，logic 标 `主体超负载`。配套件数不加。登记进图的每一具必须是能画出来的实物。同类多于一具时，只在写了 `戏用标识=` 的那一具上画出这个标识：最中心就放在中心；靠某壁某具下就画在那一具下；面上特别主体只画在这一具面上，其余同类面上不画同样的一件。同类配套多于一件时不画成完全一样。戏用的那一件画出规划写的那一处差别，差别不显眼；主位椅可以高背或更深座面，客椅保持同一套。不为此再加一件。没有规划依据的茶几、矮几、饮水机、第二台、另一张床不进中区。格调逐字用该块 `定位` 的 `气质=`。缺这键，logic 标 `upstream_missing_space_tone`，改用同一条 `风格` 的 `气质=`。两处都空，不另判。场所功能仍按题材的场所风格。`气质=` 只改已有面的材质档、纹样、颜色和收边。奢华=贵重材质、细密纹样、清楚收边。温馨=柔材质、暖色、生活尺度的分格。极简=少纹样、平整收边。精致=细收边、对齐分格。粗粝=粗材质、可见接缝。素净=浅色、平纹。冷峻=硬材质、冷色、直收边。民俗=地方纹样。都市=系统分格、当代收边。`无`=只留场所功能。北壁、东壁、南壁、西壁、地面、天花或天空，各自写到能读出这一格，四面和上下同一格。封向写在封闭面和该壁已有件上。敞向写在该向远景的层次和色上。这些句子进已有面的【主体外形】和对应壁段、地面段、天花段，不新登记中区码。四壁或上下仍是单条白墙、木地板或蓝天，读不出这一格，重写。光比和色温仍按光学节跟情绪。材质和纹样守这格，不改成另一格。

**主环境是基准图。** 不画剧情之后的狼藉、废墟、战损；那些只留给已声明的状态衍生。闪回异地各自一块主环境，衍生只挂所属主环境。
`visual_dependencies`：默认 `[]`，`dependency_strategy.type=BaselineDefinition`。Index 有 `style_reference_env` 时，依赖方 `visual_dependencies=["ENV:[风格父主环境名]"]`，`type=StyleReference`；开篇仍独立写满，只对齐父块年代、材质族、色系、工艺，不抄父块家具和轴线。单向，禁环。
`anchor_description`：主环境用逗号连接 3–5 个英文短语（空间、主舞台、材质、固定光源）。不写人物，不写 JSON 数组。
复用上集主环境时，坐标系与已有开篇同核；本场规划已改的开闭和落点按本场规划重写。

## 开篇句
`【定位】` 首句：`项目类型为{Type 原词}，项目基础定位为{…}，项目全局风格为{…}，年代/时代为{…}，地域/国家为{…}，语言环境为{…}，风格定位为{本场风格模式+落点}。时段为{清晨|白天|中午|黄昏|上半夜|下半夜}，时辰为{子|丑|寅|卯|辰|巳|午|未|申|酉|戌|亥}，内外为{…}，气候为{晴|阴|雨|雪|雾|风|霾}，气候可见为{湿石|雨丝|雾霭|积雪|扬尘|阴云|无}，氛围为{主情绪}，空气感为{清透|薄雾|烟霭|尘土|雨幕|雪尘|闷湿|干冷}，季节为{…}。`
风格定位权威=IDENT `风格=` /【本场风格】。禁止用项目主风格盖过本场改选。缺 `项目类型为`、只写「日/夜」、漏气候或氛围 = 失败。城关外景 `内外=` 必须为外。
真人实拍的风格落点只写可拍材质与光色。末日、废土不写成霓虹或全息，除非项目明文指定赛博朋克。
`场所风格=` 与 `建筑术语系=` 写在本句之后，见题材。键值不算落地，后景还要写成可画的构件词。

## 主体与坐标
【主体外形】在【定位】之后、【六面一次】之前。编号表每一件只此一句：
`[@短名]（{码}）外形={形体}，大小={高×宽×厚|长×宽|该向无限制}，材质={具体材质}，纹样={纹样|无}，颜色={色}。`
大小是具体米，或该向写无限制。只写高耸、巨大、宽阔 = 失败。四壁的占地、高度、进深、路宽抄这一句的米，不另起一套。壁正文、地面段、天花段不重复外形、材质、纹样、颜色。
码：`F` 地面，`C` 天花或天空，`M` 中区与台面件，`N/E/S/W` 各壁及贴附。桌、案、床、榻、沙发、椅、凳、床头柜即使用墙也用 `M`。全息屏、立式全息终端、中继屏、固定显示屏、巨幕、矩阵屏、壁挂屏用所在壁的码。`[@…]` 内不写东南西北。
`面件数=北{n}｜东{n}｜南{n}｜西{n}｜中{n}｜上{n}｜合计{n}`。北只计 N，东 E，南 S，西 W；中计每一个 M 和每一个 F；上计 C。地面进中，不另计在 `下=`。`下=` 点了地面的名字，地面仍计入中。一件只进一面。合计等于编号表件数。合计少一件，或中少了某一个 F、某一个 M = 失败。中区每具单独一码，不并成一组。`背靠=` 不改码。南北墙的开间等于东西场径之和，东西墙的开间等于南北场径之和。把房间的东西长度写成东墙或西墙的开间 = 失败。
`主体分组=核心=[@短名]（码）｜成员=[@短名]（码）边=北|东|南|西|面上｜长边=同向|无｜间距=贴身排布|隔1/4参照宽度|隔1/2参照宽度|隔1参照宽度｜靠参照长边=东端|西端|北端|南端|中段|无`。核心必须是规划的参照主体，这一组最核心、最显目的那一具。边、长边、间距、靠参照长边逐字抄规划的中部相对。地面和天花不是成员。没有配套写 `主体分组=无`。不写第二组。规划写了第二组的，不画，logic 标 `主体超负载`。没有依据却在中区再加一具 = 失败。每个成员仍自写 `距原点`，仍逐码计入面件数。距原点由核心中心沿这一边推出：贴身排布的中心距 = 核心在分开轴上的一半 + 0.4米 + 成员在该轴上的一半，长边同向时分开轴是短边；规划间距=贴着时中心距 = 两边一半相加，外沿相接，不改成贴身排布。舞台占地、舞台纵深的米禁止写入距原点。长边=同向而核心没有 `长边平行=`，logic 标 `upstream_missing_long_edge`，不自拟轴向。隔1/4参照宽度=外沿间距等于核心短边的四分之一，隔1/2、隔1照此乘。正方用边，圆用直径。长边=同向的，长边平行与核心同一条轴。面上的件落在核心面上，不写成离开外沿。同一边多具按靠参照长边的那一端沿长边分开。不另排一套疏密。椅、凳、沙发、杯、盏、碗、托、被、枕的对齐写进距原点。规划 `对齐=沿接触边与参照中心齐` 时，与接触边平行的那一轴，成员的米等于核心在这一轴的米，写 `对齐轴={北|东}与[@核心]相同`。分开轴才用上面的中心距。`对齐=沿接触边整组居中` 时，分开轴的米全部相同，写 `同边齐平={北|东}`；沿接触边整组中心与核心中心相同，各件按序均分。`面上双轴与参照中心齐` 的两轴米都等于核心。`与{具名}中心齐` 的两轴米等于那一具。枕的短边轴与床中心相同，长边轴靠床头。规划 `对齐=无｜态=破坏` 才离开这些米，按掀翻、倾倒、散落画，不拉回中心。缺对齐时按与参照中心齐补上，logic 标 `对齐已按中心补上`，不改成歪斜。规划有中部配套却没有中部相对，logic 标 `upstream_missing_center_relative`，不自拟疏密。驾驶舱主驾与副驾的间距仍是一臂。
`物理系闭集=通铺封闭面｜长轴延续体｜随宿主件｜开阔远景`。每具只落一档。
- 通铺封闭面：盖满该向开间的一层皮。`心点=正{向}` + 场径 + 开间×厚度 + `四向最远=`。不写 `竖边`/`端甲`/`端乙`。
- 长轴延续体：俯视长≠宽，两端咬具名衔接点。栏、梯、路、柱列、城垣、女墙、场内可定位的街巷，以及有两端衔接的贴墙柜走这一档。有墙面法线的仍是这一档。写 `端甲=` `端乙=`、几何心点、`占地=`、`四向最远=`、`相对挂靠=`、`触点=`，竖边按下面边或圆。不写 `心点=正{向}`。端甲、端乙是场内具名端，不写远山、地平、东翼。
- 随宿主件：落在另一具上或横跨其道，自身有占地。从宿主 `封闭面=` 拆出，自锁心点、占地、四向最远、相对挂靠、触点。不与宿主共用 `心点=正{向}`。牌坊、旗列、没有独立长轴的壁贴件、有独立占地的角楼走这一档。
- 开阔远景：只写 `远景=北=｜东=｜南=｜西=`，不写坐标键。
`围合=封` 只表示该向有实体挡住。室内墙皮走通铺封闭面。`封闭面=` 必须是该壁编号表里已有的具。门、巨幕、操控台窄于开间时，墙皮另登记一具，封闭面写这具墙。没有码的副墙 = 失败。看台、座席、屏风、巨门本身就是这面墙时，封闭面写这具。
`轴线=X线=东西轴，过原点主体中点，东为正｜Y线=南北轴，过原点主体中点，北为正｜Z=高度向上`。禁止 `中点线=`，禁止用两具中点连线定位。Z 只写 `离平地=` 或高度，不写入北米、东米。
原点只锁一具：`原点=中心｜北0东0｜原点主体={短名}`。优先舞台中部、中心确实在中部的地上主体，地面、甬道、地板、地毯可以。中部没有，改选舞台边上的地上主体。墙皮、立面、天花、天空、远山不当原点。每一件写 `距原点=北{米}东{米}`，北、东为正，南、西为负，轴上写 0。原点主体写 `北0东0`。无限制的那一轴写无限制。缺北或东 = 失败。
边或圆用于中区里长短边之差达到贴身的每一具，含家具、贴墙柜、机床、滑道、轨道、机组、台架，以及长轴延续体（栏、梯、路、柱列、城垣）。通铺墙皮、通铺地面、嵌在墙里的门窗不写。每具只用一种：
- 长短边之差 ≥0.4 米：`长边平行=X线|Y线` 或相对 X 线的 `夹角=`，再写 `短边垂直于长边` 和 `偏移=`。偏移只锁垂直于长边的那一轴，米等于 `距原点` 在该轴上的米。南北走向等于平行 Y 线，东西走向等于平行 X 线。夹角不是 0 或 90 时不写 `竖边=`。`竖边=` 只写在路、廊、街、巷、城垣上：0° 平行 X 线才写 `竖边=东西走向`，90° 平行 Y 线才写 `竖边=南北走向`。机床、滑道、轨道、机组、桌、案、床、榻、沙发不写 `竖边=`。中区主体长短边之差达到贴身、却没有 `长边平行=`，logic 标 `upstream_missing_long_edge`，不自拟轴向。椅、凳、正方、圆除外。
- 差 <0.4 米：走正方，只写 `距原点` 和 `占地`。不写 `竖边`、`长边平行`、半径，也不写成一头近一头远。
- 圆、方向盘、圆灯：`定位=原点+半径｜圆心=距原点｜半径={米}`。不写长短边。
- 柱：每一根 `柱径=`、`柱身=垂直于地面`、`柱顶=接到天花`、`柱径相对=`。同形写与参照柱一样粗；另一形写细一圈或粗一圈。不另写半径。盘龙、束柱只算纹样。写了 `立柱数=` 就必须有同样多的柱码。只在墙纹样里写立柱却另写立柱数 = 失败。
同一具又写边又写半径 = 失败。每一座台、每一面门、每一列看台只有一个 `占地=`。`舞台占地=` 是人走的地板，不是这座台的第二个长宽。
`壁别名=北=｜东=｜南=｜西=` 逐字抄规划。每一壁标题下写 `别名={该壁主体名}`，且该壁正文点名这具。别名必须是该壁的 N/E/S/W 具。中区的桌、案、床、榻、沙发、椅、凳、地毯不当壁别名；规划若这样写，logic 标回流，禁止照抄。规划的 `长边平行=X线|Y线`、`夹角=`、`长边走向=`、`短边走向=`、`沿边=`、`间距=`、`朝向=` 逐字继承。平行 X线必须是 `长边走向=从东到西`、`短边走向=从南到北`；平行 Y线对调。不改成另一轴，不把走向改成两具名字相连。规划若写了 `长边两端=` 或 `短边两端=`，logic 标回流，禁止照抄成连线。长短边之差小于 0.4 米，或该具是圆、方向盘、圆灯，删掉 `长边平行` 和两个走向，logic 标 `规划长边已按正方去掉`。床的 `床头=` 抄规划的东、西、南或北。椅的 `朝向=` 抄规划；朝墙时括号里写该壁别名，例如 `朝向=正南（房门）`。朝桌心仍写朝桌心。托盘、案面、台面、床面的 `朝向=朝上` 必须留下。规划点了名却没有朝向，logic 标 `upstream_missing_facing`，不自拟朝向。规划的 `落点=` 只提供北或南、东或西，轴上写轴上。米仍按本层 `距原点=` 写一次，不把落点再写成第二套北米东米。沿边和间距换成距原点时，贴身=外沿相距 0.4 米，沿长边向东就是往东移这一档。规划的 `接触边=`、`接触面=` 逐字留下。贴身或贴着缺了这两键，logic 标 `upstream_missing_contact`，不自拟哪一端、哪一面。空档从接触边量到接触面。贴着是外沿相接，外沿差写 0，不拉开到 0.4 米。同一对又写贴身又写紧贴，logic 标 `spacing_conflicts_contact`，按紧贴画外沿相接。朝向写成朝大门、没有具名，logic 标回流，不自拟哪一扇。规划因「在旁」写入的中部主体，logic 标回流，不留在中区。
靠墙的沙发、床、榻、矮几、饮水机、茶几写 `背靠=` 该壁别名，操作面朝进房间的一向。贴墙柜、柜台写 `M=所属墙`、背面贴靠、操作面朝室内，不写 `椅面朝向`。`背靠=` 不改码。
全息屏、立式全息终端、中继屏、固定显示屏、巨幕、矩阵屏、壁挂屏用所在壁的 N、E、S 或 W 码，不进中区。`屏面朝向=北|东|南|西`，朝进房间。贴在该壁墙皮上。窄于开间时封闭面仍是墙皮，屏写在这具墙上。有实墙就贴实墙，不贴通透幕墙。规划把它写进中部、又没有 `剧情明文`，改贴到一壁实墙，logic 标 `screen_moved_to_wall`，不留在中区，不写进主体分组。案边嵌入的接口、窄槽留在案的外形，不另起一具。正文已写明立在房间当中或放在桌面上的，才用 M，并留下那句依据。全息幕墙、落地玻璃幕墙仍是墙。屏风、床头屏不走本条。写成中区码、写在大案旁边、或没有 `屏面朝向=` = 失败。有屏面的具都写 `屏面朝向=北|东|南|西`，含正文写明放在桌面上的那一具。缺这一向 = 失败。
四壁每一具抄规划的 `壁关系=`。缺了 logic 标 `upstream_missing_wall_relation`，不自拟。外形有嵌入、内凹、凹进，必须是嵌入。有齐平、与墙面齐平，必须是齐平。没有这些词的壁上具是贴墙。墙皮的法线米是这张墙的室内面。门洞、窗洞、齐平、嵌入的使用面与这张室内面同一个法线米，厚向墙内。贴墙的背面贴室内面，厚向室内，法线中心离室内面等于厚的一半。悬挂用它所属的嵌入或贴墙算法线，另写 `离地=`，不写底贴地面。背靠的具留在中部，离这张墙的空档等于已锁间距，不改成壁码。一端接到的那一端与被接的具同一个法线米。比该关系允许的更靠近房间中心，logic 标 `wall_relation_pulled_forward`，把法线米拉回，不改沿墙那一轴。壁上的具大小写 `沿墙×高×厚`，不把沿墙长度写成进深。
两具体外相邻写一次 `外沿差={米}`。外沿差 = 沿分开那一轴的中心距 − 甲在该轴上的半宽 − 乙在该轴上的半宽。长边落在该轴用长的一半，短边落在该轴用宽或深的一半，屏面法线落在该轴用厚的一半。外沿差小于 0 是重叠，禁止写成贴着、贴身或离开，把 `距原点` 拉开到外沿差等于规划的间距档，logic 标 `外沿差已按档拉开`，不改档。0 到 0.1 米才是贴着。贴身档的外沿差是 0.4 米。中心到对方外沿已是 0.4 米、自身半宽还没扣，不叫贴身。点缀宿主的位置用该具的 `距原点`，不另写一套侧。
楼梯、台阶、坡道写 `低端=` `高端=` `下口=` `上口=`。点名某一层时写 `从低到高数第{n}层` 或 `从高到低数第{n}层`，同一架只用一个方向。不写 `U=`。底面不贴地的件写 `落在=` 与 `离平地=`。
幕墙、弧形墙、曲面墙、落地弧形玻璃写 `弧向=外弧|内弧` 和 `透=透|不透`。直墙不写 `弧向=`。固定玻璃不写 `开闭=`。`开闭=` 只留给门、可开窗扇、帘、百叶。这面墙是主光时 `源形=幕墙|窗`。高侧窗、玫瑰窗、尖券窗、天窗必须同时是某一壁或 `上=` 的具名主体。天花采光口只写在 `上=`。
`场态=` 由四向 `围合=` 派生。室内封闭：四向皆封，`上=` 天花。半封闭：有封有敞，无顶则 `上=` 天空。开阔室外：四向皆敞或三敞加无限制，`上=` 天空。无边界地被只锁 `下=` 一次，该向 `场径=无限制`，不写成 `北壁=草地`。`封` 向可检索 `封闭面=`，`敞` 向可检索 `远景=`。落地玻璃、幕墙、抗爆玻璃保持 `围合=封`，另写 `透=透`。规划把它写成敞，改回封，logic 标 `glass_wall_kept_closed`。每一壁写 `室内面朝向=北|东|南|西`，朝进房间。封墙的门写 `洞外=室内|室外`，无明文写室内。`向距上限=` 逐字抄规划，值是 `窄|开|无限制`。
桌、案先写 `形制=正方形｜长方/条案｜圆桌`。正方形不写长边短边。长方写 `长:宽≈{≥1.6}:1` 和长轴两端。
椅、凳、沙发写 `椅面朝向=正北|正东|正南|正西`。挂桌的写 `在桌=`。主位朝门，客位朝桌心，驾驶座朝挡风。同一种座位多于一张时点明哪一张。办公或书房的主位只有一把、接触边是短边某一沿时，`靠参照长边=中段`，不写成某一端。`椅面朝向=` 抄规划的北、东、南或西，括号里写这扇门的壁别名。规划把这把放在长边一端，或朝向写成朝大门，logic 标 `chair_seat_unplaced`，回流环境规划，不改到另一侧，不自拟朝向。

## 舞台、量化、门窗
开篇抄 `主舞台区=` `舞台范围=` `舞台大小=` `可容=` `舞台净空=剧情动线可通行` `动线=` `挂靠锚点=` `锚点落=`，并写译好的 `舞台占地=`。规划已有的床、窗、桌留在原位。`动线=` 中间不加障碍，不为空地删件，也不为好看加件。这些键写完即止，不再写留空以待、完全留空。
`参照物=` `类=` `识别=独一轮廓` 逐字继承。这一具的侧用它在四向里的那一次 `落点=`，活动空间不再写第二份。`醒目光` 只打在这一具上。侧不换边。类=地面标记时贴地，不抬成立体障碍。规划缺 `参照物=`：logic 标 `upstream_missing_reference_subject`，不另造。`补光落点=` 只说明灯在舞台哪一侧，不写成这具的 `距原点=`。
`背景微动件=` 非`无`时，这一具必须已经是某一向点名的主体。新补的细小件画在它所属向的贴墙、窗沿或檐下，不进动线。已经是窗、灯、灯笼、火塘、烛或补光源时，画在该具已锁的位置，不另补一具。动态光影画在这一具上。
量化只写开篇一次。常规下限：每壁 ≥5 条，地面 ≥6 条，外景天空 ≥5 条或室内天花 ≥4 条。每条至少覆盖位置、围合或分格、开合、尺度、件数、交接中的四项。单条「木地板 / 蓝天 / 白墙」= 失败。材质、纹样、颜色只在【主体外形】，可计入条数，壁上不重复。顶格场所改用题材表的条数。中区不靠加立体物凑条数。多出来的条写在四壁、地面、天花或天空已有面的分格、交接、收边和纹样上，并读得出定位气质。
北东南西四壁的主锚须能对上规划该扇区，不抄邻壁。
平开写 `门轴=门左|门右` 与 `把手=`，把手与门轴异侧，并写内部核验句 `门窗扇展表：{名}｜M={所属向}｜扇型=｜开向=里|外｜门轴世界=`。双开两行。平移、左滑、右滑、推拉、闸门、液压门、升降门、卷帘门不写门轴、铰链、门栓；滑动写 `停端=北端|南端|东端|西端`，闸类写 `门型=`。窗棂写 `格阵=横N列×纵M行`、等宽、同墙顺序。同一扇的开闭、开向、门轴或停端只锁一份。门、窗总数写明。出入口禁堵成实墙。
文字载体（牌匾、招牌、门牌、横幅、霓虹、固定屏、架上书册）写四项：逐字文案、`横排|纵排`、书体加字色加底色（发光载体加发光色）、`简体|繁体`。上游有 `visible_text` 则透传。中远景小物件只写「字迹不可辨读」，不为此加第二张前景桌。

## 载具
任何驾驶舱、操纵舱、车厢、船舱、轿厢是独立主环境，不画进舱外同一张图。`舱型=` 逐字继承。缺 `舱型=` 或只写「驾驶舱 / 汽车内」：logic 标 `upstream_missing_cabin_type`，不自拟成泛称。座位数与 `座=` 闭合。不改排、不加座。
前向驾驶舱：`主驾朝向=南`，挡风和仪表在南壁，舱尾在北壁。驾驶座在东，副驾在西，同排写东、中、西。`椅面朝向=正南（挡风）`。禁止椅面朝北，禁止挡风画到东壁或北壁，禁止写左起第、后排左、驾驶位左侧。座排从南端操纵排往北数，槽位 ID=`第N排-东|中|西-功能名`。开放舰桥按控制台编号，不伪造座排，也不写左起。
`主副驾距=一臂` 时，两座座心东西相距 0.7 米，南北同深。`主副驾距=无` 的单人舱不另画副驾。
飞行器、飞行驾驶器、单人飞行器、航天器，以及 `舱型=` 含飞行驾驶的封闭舱：`内饰档=豪车｜引用=豪车:真皮座椅缝线、木饰或碳纤维中控、金属出风口、地毯或脚垫、门内饰分块、仪表台一体`。座位数仍按 `舱型=`。禁止布座、灰布、廉价塑料、裸金属工装舱。普通轿车、民航客舱、列车、轮船、舰桥不套本条。古装年代把碳纤维换成已核销的贵重木或金属，品级不降。
舱内光色只跟已锁时段、气候、氛围、该块 `色光规划` 和挡风外天光。白天晴天以挡风天光为主光，仪表灯是点缀。夜、雷暴、明文警报或战损才写暗和警示灯。没有这些依据，禁止幽暗、炭黑、应急红当主光。情绪要压暗时，驾驶舱不套这条。
只服务内部剧情的占用 ENV 才画本条。封闭舱按上条。露天合建（甲板、敞篷、开顶平台）同时画载具局部和大世界。整车 PROP 不画进这张空镜。`载具裁定=无` 的摩托、单兵飞行器、马匹不设计占用。马匹不画成占用 ENV。

## 题材

### 场所风格与建筑术语
先定 `场所风格=` 主行：客栈/酒楼→客栈/市井；宫殿/金殿→宫廷/皇家；王府→王府/府邸；住房→民居/住宅；隔间办公→都市职场；董事会议室→高端会议室；总裁办→总裁办/高管办；教室→学校/教室；诊所→医院/诊所；普通轿车/民航/列车/轮船→舱内/载具；游艇→游艇；豪车→豪车；专机→专机；飞行驾驶舱主行可写舱内，内部必须 `引用=豪车`；山景→自然外景/山野；城关/瓮城→关隘/城门；古营→军队·古营；现代军营→军队·现代；校场/战场/军阵→军阵/校场/战场。未列则 `自拟:{名}`。
主行是功能底色，不是闭集。剧情点名的构件必须写入。可跨行 `引用=`。本场没有的槽不强迫写入。引用豪宅或宫殿槽不得把小屋改成金殿体量。
全局可检索：`场所风格={主行}｜落点={本场入画构件}｜引用={行名:槽｜无}｜表外={≥1条}`，以及 `建筑术语系={名}｜落点={≥3条术语原词}｜表外={≥1条}`。
落点里的石、木、金、砖、混凝土、金属、真皮须在【主体外形】见纹理或收边。宫殿、仙宫、豪宅另写 `纹饰=`。光质不写进本表。

### 辨识、顶格、旗帜、高速
自然外景和仙境外景写 `山水层=`，至少四层：近地被或近岩、中景山体或林带或琼台、远峰或云海、天空。每层写具名物、距离层、特征色、清晰度、与邻层交接。相邻层必须同时有色差和清晰度差。至少两处黄系或红系特征色，分落不同层。禁止满屏翠绿加纯蓝天空。水体入画写近岸纹理、中距反射、远岸交接。仙境云海再分至少两带；浮空岛屿不与远峰同一深度。
室内至少两项辨识，落在已有墙、地、天花或清单家具上，不进动线：非常规色块、一组材质对撞、非常规天顶或地面节奏、Key 与 Fill 冷暖落在不同表面。礼制空间不毁中轴。

## 色彩
【色彩说明】紧接光学。先逐字用该块 `色光规划=`。`对标片=` 用 `本块对标片=`。`主冷暖=`、主色、辅色、点缀、过渡、`调色机制=`、`光质=` 照抄，再把色绑到具名表面。全局色卡只作主干色相族，不另起一张卡。缺 `色光规划`：logic 标 `upstream_missing_env_color_plan`，退回全局 `color_palette`；全局也缺，才按 common 自锁一部院线或经典片。同一行可检索：`色光规划=对标片={本块对标片}｜主冷暖=｜光质=｜主色=｜辅色=｜点缀=｜过渡=｜调色机制=`。这行给分镜抽色温，不把开篇其余光句交给分镜。
