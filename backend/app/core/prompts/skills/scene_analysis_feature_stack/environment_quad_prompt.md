每格五行：`正面：`、`左侧面：`、`右侧面：`、`中部：`、`上：`。一件一行。只写随这一望向变的词。不写画布坐标，不写件数、件数核销、`点名=`、`划出=`，不写构图，不写纵深光层，不写源体画布位，不写墙身与地面垂直，不写镜后整包不入画。位置不写米。平天花可写离地净高。穹顶、穹庐、帐顶不写离地净高。辅光只在出光口入画时另起一行，写从哪一侧来。

## 画布与位置
原点用开篇 `原点主体=` 的中心。墙皮、立面、天花、天空、远山不当原点。成稿点名这一具，不写北0东0。
画布坐标、镜头脚、眼高不进成稿。写稿仍用原点中心判断脚深。高挑改法在挑高节。
原点写了占地、且不是墙皮或天花、并且高挑=否：脚停在这具靠近镜头那一侧外沿之外，不站上台面，不站进设备。脚和这一中心之间有墙、柱、栏时，只改那一格：脚停在那一道近面之前。成稿不写镜头脚，不写离开中心的米。
原点是桌、案、床、榻、沙发时，位置就在成稿那一对里，不另写桌心，不写沿X线。其余原点主体再写：`中心落在X线和Y线的交点上。沿X线在画面左右中线，沿Y线在纵深中线。Z贴地面。`

**脚深（不进成稿）**：与望向平行的那一条取一半，长边落在这一轴用长的一半，短边落在这一轴用宽的一半。脚深 = 这一半 + 0.4 米，从原点中心沿靠近镜头量。先把世界侧旋成这一格的画面侧，再比。不得把望北的米不旋转就拿去核其他格。
两端的靠近镜头米都大于脚深：不点名，划出。只有靠近原点的一端还在脚前：点名，写只见这一端。两端都在脚前，或整具在远离镜头一侧：整具照写。原点主体不划。一具在脚后，不连带删掉邻具。中区每一具单独比。南侧贴身的椅：望北在桌心和画面下沿的地面之间；望南、望东、望西不写成脚后划出。焦段不参加入画。侧面整面只看正面两倍，单件只看脚深。

桌、案、床、榻、沙发用成稿节那一对，不另写沿X线、沿Y线、Z贴地面、中心落在X线。写出这些 = 失败。墙用成稿节墙句。挂桌的椅、凳用家具节那一句，不另写沿X线、沿Y线。其余入画主体才写一句：`[@短名]（{码}）。沿X线{在画面左|在画面右|在画面左右中线}。沿Y线{在靠近镜头|在远离镜头|在纵深中线}。Z贴地面。` 位置不写米。
沿 X 线只写画面左、画面右或中线。沿 Y 线只写靠近镜头、远离镜头或中线。离开原点的那一轴，四格不得落在同一侧。两轴都是零时都写中线。零偏移不写米。只写一条轴 = 失败。沿 X 线写成靠近镜头，或沿 Y 线写成画面左 = 失败。有 `离平地=` 时，Z 贴地面改成 `Z离地{米}`。无限制的那一轴写无限制。窗台离地是高度，不占这两轴。
把任一格旋回北米、东米，必须等于开篇，也必须和其他格相同。对向格：左右对调，近远对调，零偏移的中线不改，正面换成对向壁。两格偏移侧相同，或正面仍是同一壁 = 失败。
靠近镜头那一侧、离开原点不到两步的挂桌椅、凳、沙发：写稿核对沿 Y 线时，用「在画面下沿到桌心的这段地面上」。成稿只留家具节那一句，不另写沿Y线。

**边，三类只走一类。** 走成稿墙句或成稿台句的具，这一句已经是位置加走向，不另起位置句。心点在宿主面上且与中心重合的，只写在面上，不写沿X线，也不写走向。其余有长边的具才先写沿X线、沿Y线，再写走向。位置句只是中心落在哪一侧，不算走向。走向：`长边与X线平行。` 或 `长边与Y线平行。` 夹角不是 0 度或 90 度时写成 `长边与X线成{度}。` 或 `长边与Y线成{度}。` 不写短边与另一条轴平行，不写与另一具平行，不写横在画面里、顺着纵深、与画面底边平行。禁止只写「沿着」。有长边、又不是面上与宿主中心重合的件，却不写平行句 = 失败。桌、案、床、榻、沙发的成稿那一对就是平行句，不另写长边与X线平行、长边与Y线平行。窄头句以朝向镜头的这一头是窄头起句。左右长边句以靠近镜头的这一条是长边起句。
开篇 `长边平行=X线` 是世界东西，`长边平行=Y线` 是世界南北。世界东西落到画面左右时写与 X 线平行，落到纵深时写与 Y 线平行。`长边平行=Y线` 对调。`长边走向=从东到西` 就是世界东西，`从南到北` 对调。只有 `长边两端=`、`短边两端=`、没有走向，这一具不连。同一具只许一对：与 X 线平行配从画面左铺到画面右，或配靠近镜头的是长边；与 Y 线平行配一头近一头远，或配窄头句。轴名和跨度拆开配 = 失败。望东、望西不把开篇 `长边平行=X线` 抄成 `长边与X线平行`。长边平行=X线的台：望北、望南写靠近镜头的是长边那一句；望东、望西写窄头句。两句都不另写长边与X线平行、长边与Y线平行。
跨度只补一种：
1. 墙、路、城垣、长街侧列、弧墙、楼梯，以及盖满所对墙的具。围合=敞的远景不走这一类。与 X 线平行且盖满，用成稿节正面墙那一句。短于所对的墙，在这句后加 `两端不到画面边缘。` 与 Y 线平行，用成稿节侧壁那一句。与 Y 线平行不接两端不到画面边缘，不接两端不到左右墙，也不接从画面左铺到画面右。与 X 线平行不接一头近一头远，也不接窄头。拆开配 = 失败。一侧不可见，收到可见端，不写铺满。不写两端一样远，不写墙身与地面垂直。
2. 正方：没有 `竖边=`，或长短边之差小于 0.4 米。不写走向，不写一样宽。椅、凳、桌、案、床、榻、沙发没有 `长边平行=` 时走这一类，中部只写在画面中部，不套成稿节的长边句和窄头句。
3. 短于所对墙的桌、案、台、床、榻、沙发、地毯不接第 1 类的一头近一头远。心点在宿主占地里、或边=面上且与宿主中心重合的件，不走这一类。长边落到画面左右，只用成稿节里靠近镜头的是长边那一句，不接宽度大约。落到纵深，只用成稿节里窄头那一句。不写沿X线、沿Y线、Z贴地面、中心落在X线。不写「在桌心和镜头之间」。纵深的桌案行不写横在、不写不是长边、不写不要把长边画成、不写两端不到画面左右、不写从画面左伸到画面右、不写从画面左铺到画面右、不写左右大约只有房间。望北与望东不得同一句。四格都写成靠近镜头的是长边 = 失败。桌、案、床、榻、沙发这一行写出沿X线、沿Y线或Z贴地面 = 失败。
柜、机床、滑道、轨道、机组、台架不写桌心，不写靠近镜头的是长边或窄头。与 X 线平行且短于所对墙，写两端不到画面边缘。与 Y 线平行，只写一头近一头远。不接两端不到左右墙。壁架、悬臂架、承重架贴在墙上，走第 1 类，不走台架。望向对着这张墙时写与 X 线平行、两端不到画面边缘。望向顺着这张墙时写与 Y 线平行、一头近一头远。
通铺地坪只写地面通铺写满，不抄长边句或窄头句。中部的机床、滑道、轨道写了 `竖边=` 也忽略，仍走上面的类。`竖边=` 只给路、廊、街、巷、城垣。
圆、环、坑、池、井、弧形台、扇形控制台只转圆心，半径不变，不写与 X 线或 Y 线平行。贴环的成员按环缘哪一侧查旋轴表，接触面朝环心。只写紧贴坑缘 = 失败。柱只读 `柱径相对=`，柱身垂直于地面，柱顶接到天花，同形写一样粗，靠近镜头不改粗细，不写柱径米数。盘龙、束柱只是花纹。门的高和宽四格相同。
`沿边=`、`朝向=` 的东南西北按旋轴表转。`朝向=朝上` 四格都是使用面朝上。间距档四格相同。

缝档换算，米留在开篇：贴着｜贴身 0.4｜一臂 0.7｜两步 1.4｜三步 2.2｜五步 3.6。空当小于等于 3.6 米取最近一档。大于 3.6 米按场径写成一成到九成，分母是场径；该向无限制时改用地面已锁的开间或进深。成数不用于桌面。外沿差为负仍写贴着 = 失败。心点在宿主占地里，或边=面上且与宿主中心重合：只写「在[@短名]（码）的面上」，不写靠近台心，不写离端，不走第3类，不写长边句、窄头句、沿X线。这一句优先于台面件。心点在占地外：小于宿主这一边一半的三分之一写靠近台心；贴着这一端写贴着边；离端约四分之一、一半或过半才写这三档。椅、凳与桌子的外沿另写离开桌沿。其他件不把同一空当再写一遍。禁止只写「宿主」。

## 入画与件数
**正面两倍。** 每侧单独跟本格正面纵深比。正面纵深是原点到正面近面的垂距；正面是具名街端时，取该具近面的远离镜头米数。侧面取原点到该侧墙朝向镜头那一面的垂距，不用这一壁的开间，不用场径里较长的那一条。先把正面纵深乘 2，再和这一侧的垂距比。只有侧面垂距大于这份乘积，才写 `左侧面：不可见。` 或 `右侧面：不可见。`，后面不再写字。小于或等于这份乘积，含正好 2 倍，该侧入画。侧面垂距大于正面纵深、仍不大于这份乘积，该侧入画。两侧垂距相同，各算各的；两份都不大于乘积，两份都入画。望向较短的那一轴时，侧面往往比正面远，不超过 2 倍仍入画。只凭侧面比正面远写成不可见 = 失败。没有米时，已有具名主体就入画。街、路、巷、城垣的无限制街端落在左或右仍写不可见；小于或等于才写在画面端、只见这一端，禁止一头近。围合=敞、向距上限=无限制、并且这一向已有具名主体的，不是街端：落到正面写 `远处只画[@名]（码）。`，落到左右写 `画面{左|右}是[@名]（码）。` 不写贴在画面左、不写一头近一头远、不写长边与Y线平行、不写从画面左铺到画面右。场径无限制时，地面半宽不是这一向的尽头。女墙和雉堞沿地面外沿，栏外仍是远景，不把这一向画成封墙。镜头后的墙、护栏、门不画，不改挂。该侧已写不可见时，壁上的件随该侧划出。中部只看脚深。
顺着长边望去的正面写这一端的具名街端；没有具名端头时写 `远处只画[@远景]（{码}）。` 有具名街端时不写没有实墙，不用天际代替。护栏、门、墙写画面左右和纵深。只写沿边缘 = 失败。两侧都不可见时正面和中部照写。两侧都不可见、中部又没有开篇已写下的地面或中区件 = 失败。
到左、到右，取该侧在镜头前方的最近点。墙取朝向镜头的那一面。不用场径代替最近点。

**长条。** 只用于路、廊、街、巷、城垣。室内地坪不走本节。顺着长边的两格，纵深各是从原点到该端的一段，两段相加等于全长。靠近镜头这一头是短边。正面写这一端的具名端；没有具名端头才写该向远景。两格都写成全长 = 失败。不把全长收进沿短边的两格。

开篇 `面件数=` 与编号表不一致时，n 用编号表。北只计 N，东 E，南 S，西 W，中计每一个 M 和每一个 F，上计 C。地面进中。背靠不把 M 码算进壁。敞向已有码的仍计这些码，没有具名主体才是 0。
本格对上去：望北正面对北、左对西、右对东；望东正面对东、左对北、右对南；望南、望西同理对到对向和左右邻。
写稿用面件数核对看见谁，成稿不写件数、件数核销、`点名=`、`划出=`、`划出名=`。开在、贴在、凹进、悬挂的具写进这一面。一端接到、顶接到、底接到、背靠、接到邻壁不写进这一面。整面不可见的侧面正文只有 `不可见。`。这一壁有码却整面不点名 = 失败。
宿主墙在镜头后、件仍有一端在脚前：墙皮不写，壁码改写入中部。中区原有的 M、F 不改挂。壁上的屏不改入；所在壁在镜头后，整具不写。
四格中部除掉各格脚后划出，是同一批。两端都在脚前必须点名。只有靠近原点的一端在脚前，写只见这一端。邻格写过的，本格看得见仍要再写。
心点重合的地面和台上的台各计一件。四向皆封的地坪写通铺写满，不写路面、路宽、两侧铺面。平台、基座不是桌、案、床、榻、沙发时，短于所对墙写两端不到画面边缘。桌、案、台、床、榻、沙发、地毯的跨度只在第3类，不另接两端不到画面边缘。
屏：壁码写在所在壁；M 码且在桌面上或立在当中的写在中部。先写壁关系或「在哪一具面上」，再写屏面。`屏面朝向=` 与正文里的「显示面朝南」「屏朝南」「显示面朝北」「显示面朝东」「显示面朝西」是同一键，取那一个世界向。这一向是屏面法线的指向。这一具入画的每一格都写屏面句。法线与望向相差 180 度：`屏面朝着镜头。` 与望向相同：`屏面背对镜头。` 落到画面左：`屏面朝画面左，见侧沿。` 落到画面右：`屏面朝画面右，见侧沿。` 朝南的屏，望北朝着镜头，望南背对镜头。朝北的屏对调。朝东的屏，望西朝着镜头，望东背对镜头。朝西的屏对调。没有屏面朝向、也没有显示面朝南这类同键时，不把贴在画面左写成朝画面右。缺这一向 = 失败。背对和见侧沿的格子不抄屏上的字。朝着镜头的格写字在这一面上，不把开篇整串文案再写一遍。点缀不改屏面。点缀在中线，屏面仍按法线写。四格都朝着镜头 = 失败。入画却没有屏面句 = 失败。望向与法线相同却写成朝着镜头 = 失败。朝南的显示面四格必须分别出现：望北 `屏面朝着镜头。`，望东 `屏面朝画面右，见侧沿。`，望南 `屏面背对镜头。`，望西 `屏面朝画面左，见侧沿。` 缺一句 = 失败。格子里写出朝南、朝北、朝东、朝西 = 失败。短于开间的写两端不到画面边缘。

## 墙
成稿不抄本节的整段反引号。正面墙和入画侧壁只用成稿节那两句。墙身与地面垂直、两端一样远、不见墙厚的侧沿不进格。
盖满该壁开间、并且编号表有该壁码的封闭面，正面用成稿节那一句：从画面左铺到画面右。不写墙身与地面垂直、两端一样远、不见墙厚的侧沿。 有一侧不可见，收到可见端，不写铺满。短于开间的门、柜、梯、屏、巨幕、操控台不写远处那一整面，写在墙皮上，两端不到画面边缘。这些短件落到侧面，只写厚或侧沿，不用一头近一头远把这一件拉成整段侧墙。墙皮入画时用下面的室内侧壁句，不走这一句。
闸门、液压门、升降门、卷帘门、巨门盖满该壁、并且该壁没有另登记墙皮时，这一具就是封闭面。正面铺满。侧面写贴在画面左或画面右、一头近一头远，不写远处那一整面，不接到正面那一壁，不写与画面底边平行。豁口留在门扇上，两侧不另补墙皮。没有墙皮码的牌、箱、柜落在地面上，不升成墙，不把地面的码改成女儿墙或机房墙。
有 `竖边=` 的城垣、长墙：竖边与望向垂直才进正面，用成稿节正面墙那一句。与望向平行则用成稿节侧壁那一句。贴左朝右，贴右朝左。女墙、雉堞、栏杆、护栏没有竖边，沿地面外沿，不走这两句，不写贴在画面左、不写一头近一头远、不写长边与Y线平行。写成这些，失败。这一向远景=无，不把另一向的远景写到栏外。四格都写成同一条平行轴 = 失败。不写墙身与地面垂直。
`室内面朝向=` 旋到靠近镜头才正对，写朝着镜头。旋到画面右，墙贴画面左、朝画面右；旋到画面左则相反。旋到远离镜头，这面墙不画。内外=外时不写「室内」。不用「墙厚侧沿」代替这一句。开篇有 `壁别名=` 时，长边两端写 `[@别名]`，不写北壁、东壁。
入画的室内侧壁用成稿节侧壁那一句。贴左朝右，贴右朝左。这张墙上的门、架写在这句之后。门洞贴在画面左或画面右，不写进正面墙句。本格正面先写远处那一整面和正面上的主件。入画侧壁没有一头近一头远 = 失败。短于开间的门、柜、屏本身仍不拉成整段侧墙。
城墙衔接：城门楼、角楼接到城垣：`画面{左|右}端是[@城门楼]（{码}），[@城垣]（{码}）接到这座楼为止，和它一样远。` 这一端不再铺满。这座楼不再写一头近。牌坊写在城垣朝向镜头的一侧，不写贴在正面墙前。
看台、座席、屏风、巨门本身是这面墙、没有顺着望向的长轴、该壁没有另登记墙皮、又不是环段时，正面用正面墙句，侧面改与 Y 线平行、一头近一头远。环形、环状、碗状看台走环段。看台侧视两头一样高。开篇 `上=` 的天窗只写在天花。开篇该壁没有的高侧窗、尖券、玫瑰窗不写。
棚、棚架、挑檐走第 1 类长边。四端都在镜头后的那一格写棚在镜头后，不画。

**挑高。** `高挑=是` 时，略仰和门的比例写在正面那一行，不另起画布坐标，不写平视、眼高 1.6 米、贴桌沿、35mm。正面那一行含 `略仰朝向正面。天花贴着这格画面的上沿。` 门句只属于本格正面墙上有平开人员门的那一格。大档接：`门只占这格画面的下部四分之一。门顶是这一条横线。上面四分之三是空墙，天花贴着这格画面的上沿。` 正面那一行再接 `门顶落在画面下部四分之一的那条线上。` 墙句：`这面墙下面四分之一到门顶。门顶以上是空墙，大约三个门那么高。这段空墙占画面上部四分之三。天花贴着画面上沿。` 平开门再写：`门只占这面墙的下面四分之一，也只占画面下部那一截。` 这三句不写桌、不写椅、不写没有门、不写门楣。格子出现这些词 = 失败。 宏大档把四分之一换成五分之一，四分之三换成五分之四，三个门高换成四个门高，上部四分之三换成上部五分之四。本格正面 `开合=无门窗`：画面分配和墙句只写墙身和天花。写 `略仰朝向正面。墙身从地面铺到天花。天花贴着这格画面的上沿。` 这三句里不出现门、门顶、门扇。开合=无门窗的正面写进了门或门顶 = 失败。侧面入画的人员门写在该侧，门扇只占该侧墙的下面四分之一，上面是空墙。落地玻璃从地面接到天花。正面有人员门时，门顶只到玻璃下面四分之一，门顶以上仍是这面玻璃。开合=无门窗的正面，玻璃从地面接到天花。本格正面有人员门时，灯写在画面下部四分之一、门顶那条线上，不先写悬挂在墙上。开合=无门窗的正面，灯按开篇离地写。普通窗在有人员门的正面，窗顶与门顶齐。窗外只写开篇气候可见。闸门、液压门、升降门、卷帘门升到墙顶，不写这两截。桌、椅、床停在开篇高度，椅背不到门顶。原点是短桌、床时，长边或窄头接画布节那两句，写在略仰之后。不写桌、椅全身都在画面下部。焦段按共享句。缺 `高挑=` 不补画面分配，按高挑=否写平视。只写米、把门画到天花下只留门楣、或把整面写成门 = 失败。不为此放大地面，不删掉上，不把天花写成无限制。

**围合。** `围合结构=四面垂直`：正面与侧面用上面的直墙句，不写中段鼓出，不写圆柱。穹顶只写在上，从墙顶拱起。缺这键、四向皆封、又没有明文圆、环厅、圆柱、筒时，按四面垂直。`围合结构=圆形`：四壁是同一圆上的四段环段。正对：`[@名]（码）是环上的一段，从左角接到右角。两端是和左右邻段相接的角。中段绕着原点。左右邻段仍是各自的一段弧，接到这两个角为止。` 侧面：从靠近镜头的角伸向远离镜头的角，中段绕原点鼓出。不写成与画面底边平行的直墙，不把邻段挤掉。同一块又写直墙铺满又写环段鼓出 = 失败。
**弧墙。** 有 `弧向=` 的幕墙、弧形墙、曲面墙、落地弧形玻璃，弧只属于这一壁。名字写了弧形落地窗、弧形玻璃、落地弧形玻璃、弧形幕墙，没有 `弧向=` 不写弧句，不补外弧。正对：`玻璃从左角铺到右角。两端离镜头一样远，两端是和左右邻壁相接的角。中段比两端更远离镜头。左壁和右壁仍是各自的直墙，接到这两个角为止。` 内弧把更远离改成更靠近。落地的底贴地面、顶接到天花；高位的底离开地面、顶不接到天花。侧面：贴在画面左或右，从靠近镜头的角伸向远离镜头的角，中段鼓出这两个角的连线。这一壁在镜头后不画，不把玻璃挪到邻壁。`透=透` 写透过这面玻璃看见外面。帘全关时弧留在帘上，不写外面。固定玻璃不写开闭、扇停在、铰链、门洞。写成与画面底边平行或从画面左铺到画面右 = 失败。
同壁至少两具、并且其中一具是墙皮、这一面入画，才写「远处那一整面是[@墙]（{码}），[@贴]（{码}）都在这张墙上。」侧面写「画面{左|右}是[@墙]（{码}）的侧沿，[@贴]（{码}）沿着这张墙。」每一具下一句写 `壁关系=`，四格关系词相同，只换正面或侧面。
正对：墙皮用室内面朝着镜头。门洞 `门洞开在[@墙]（码）上`。窗洞 `窗洞开在[@墙]（码）上`。齐平 `与[@墙]（码）墙皮齐平，不凸出墙面`。嵌入 `凹进[@墙]（码）的墙皮，外沿与这张墙齐平`。贴墙 `贴在[@墙]（码）的墙皮上，背面贴着这张墙`。悬挂 `悬挂在[@墙]（码）上，底离开地面`。一端接到 `一端接到[@具]（码），和它一样远`。
侧面：门洞、窗洞 `贴在画面{左|右}，开在这张墙上`。齐平 `与墙皮同一条线`。嵌入 `只见凹进的侧沿`。侧面不写凹进齐平，不写只见向里的厚。贴墙才写 `只见向里的厚`。悬挂底离开地面。本格正面有人员门时，高挑的灯改写在画面下部四分之一、门顶那条线上，不写悬挂在墙的上方。开合=无门窗的正面，灯按开篇离地写。`高挑=否` 的吊挂写「悬挂在这一面墙的上方。」
`出入画口=` 所在壁入画时写出完整门洞或通行口，不改成实墙。短于开间的门写门洞，两端不到画面边缘。这一壁在镜头后不画。口前不另堆件。门、窗、券洞、射孔跟着所在墙。这面墙在正面或左右入画，这一具写在该墙句之后。这面墙在镜头后，不写。入画却漏了这一具，失败。
贴墙的法线从室内面再向房间进该具厚的一半。墙在正面，这一差在远离镜头。墙在画面左，向画面右收，不改纵深。墙在画面右，向画面左收。门洞、窗洞、齐平、嵌入的法线米等于室内面。与墙同一个米，或比这一档更靠近房间中心 = 失败。背靠的具留在中部。壁上的具写了背靠 = 失败。这一壁在镜头后，壁上的具不写；背靠的具仍在中部，写背靠的那一壁在镜头后。只写沿着这张墙、不写壁关系句 = 失败。
同一面墙上的口和贴先排成一列。北壁从西到东，南壁从东到西，东壁从北到南，西壁从南到北。正对写「从左到右分别为[@A]（码）、[@B]（码）。」只写两头、漏掉中间 = 失败。墙在画面右，从远到近仍是这一列。墙在画面左，从另一头读起。桌、案、床、椅、凳不进这一列。门和窗走开合，不另写两端米。有 `窗台离地=` 或 `离平地=` 的，四格写同一个米。两键都没有，高位写底离开地面，落地写落地。不用墙高减窗高自拟窗台。

## 走向与长街
竖边与望向垂直的两格是一类，与望向平行的两格是另一类。0° 与 180° 两端对调，90° 与 270° 两端对调。下表只给墙、路、城垣、长街。成稿不写北端、南端、东端、西端。

| 开篇竖边 | 0望北 | 90望东 | 180望南 | 270望西 |
| :--- | :--- | :--- | :--- | :--- |
| 南北走向 | 从靠近镜头伸向远离镜头 | 从画面左铺到画面右 | 从靠近镜头伸向远离镜头 | 从画面左铺到画面右 |
| 东西走向 | 从画面左铺到画面右 | 从靠近镜头伸向远离镜头 | 从画面左铺到画面右 | 从靠近镜头伸向远离镜头 |

路、廊：有 `竖边=` 和 `路宽=` 就用。没有这两键、并且一条至少是另一条两倍时，长边取较长的，路宽取较短的。室内地坪不走。竖边平行望向：`长边与Y线平行。从靠近镜头伸向远离镜头，一头近、一头远。靠近镜头这一头是短边。` 竖边垂直望向：`长边与X线平行。两端一样远。从画面左铺到画面右。` 进深等于路宽。
长街：地面一条至少是另一条两倍时，长轴两端的坊、门、露台、牌坊是街端，两侧连绵铺面是侧列。东西长街望东、望西顺着长边；南北长街把四格对调。顺着长边：`远处那一整面是[@名]（{码}）。中心在左右中线上。左端和右端离镜头一样远、一样大。从画面左铺到画面右。` 另一端在镜头后，不点名。侧列贴在画面左或右，一头近一头远，靠近镜头这一头是铺面侧沿。沿短边：正面是侧列，从画面左铺到画面右。街端先按正面两倍，小于或等于才写 `在画面{左|右}端，只见这一端。` 禁止一头近。望东或望西不把靠近镜头这一头写成短头或一扇门。成稿不写「短头」「没有实墙」。开篇只登记一根的灯杆，四格只写这一根。
纹路：`纹路走向=正交无主轴` 时四格都不写方向。南北走向：望北、望南写「纹路沿远离镜头」，望东、望西写「纹路沿画面左右」。东西走向对调。有走向时四格同一句 = 失败。写成 `[@地面]（{码}）纹路{沿远离镜头|沿画面左右}。`
方向线：开篇 `方向线=` 转成画布坐标。开篇 `线平行=X线` 是世界东西，不是画面左右。没有这键不自造警示线、防护线或标线。`线走向=正交无主轴` 时四格都不写这条线的方向。`线平行=X线` 且 `线走向=从东到西`：望北、望南写 `[@宿主短名]（码）的{线名}与X线平行。` 望东、望西写 `[@宿主短名]（码）的{线名}与Y线平行。` `线平行=Y线` 且 `线走向=从南到北` 对调。夹角：望北、望南写 `[@宿主短名]（码）的{线名}与X线成{度}。` 望东、望西写 `[@宿主短名]（码）的{线名}与Y线成{度}。` 度数照抄。有走向时四格同一句 = 失败。格子里不写东、南、西、北，不留下 `线平行=`、`线走向=`。宿主是地面：与 X 线平行再写 `铺在这块地面上，从画面左伸到画面右。` 与 Y 线平行再写 `铺在这块地面上，从靠近镜头伸向远离镜头。` 与 X 线平行却接从靠近镜头伸向远离镜头 = 失败。与 Y 线平行却接从画面左伸到画面右 = 失败。轴名按本格望向换，不把开篇 `线平行=X线` 原样抄进望东、望西。 宿主是中部那一具：再写 `线留在这一具面上。` 不拉到墙，不另起一件。通铺地坪仍不抄家具长边句；方向线这句照写。同一宿主的家具长边句和方向线句都留下。中部已有桌、案、床，方向线仍写。漏一格失败。线名逐字等于开篇方向线。家具的长边句和窄头句不代替方向线。
南北场径与东西场径不等时，与望向平行的是纵深，垂直的是左右。较长的轴垂直望向时，这一格更宽、纵深更短。场径不写进成稿。

## 家具与座具
靠墙的沙发、床、榻、矮几、饮水机、茶几，码在中部、`壁关系=背靠`：留在中部。走向按画布节。再写 `短边从这面墙探进房间。` 壁码的柜、屏、门、窗不写这句。
床头写 `床头在画面右。` 或 `床头在远离镜头。` 不写沿X线、沿Y线。床尾不另写。世界向按旋轴表。长边或窄头按画布节，窄头可以是床头或床尾这一头。
挂桌的椅、凳、沙发：`坐在[@桌]（码）的{画面左|画面右|靠近镜头|远离镜头}那一侧，离开桌沿大约{缝档}。` 贴身写成离开桌沿大约一肩，中间有一条缝。靠近镜头那一侧：在画面下沿到桌心的这段地面上，看见椅背，挡在桌子和镜头之间。远离镜头那一侧：桌面挡在椅子和镜头之间，看见椅座，椅背朝着远处。画面左或画面右、并且本格靠近镜头的是窄头：在这一侧外侧，和桌心一样远，椅在画面中部，不挡在窄头和镜头之间，看见朝向镜头的那一侧面。东侧或西侧的椅在望东、望西不写和桌心一样远。四格都写挡在桌子和镜头之间 = 失败。椅面只写朝远离镜头、朝靠近镜头、朝画面左或朝画面右，按旋轴表转。没有 `椅面朝向=` 不自拟，logic 标回流。开篇有椅面朝向，这一具入画的每一格都写朝向旋成的画面侧。在桌的椅同时写坐在哪一侧。漏一格失败。
`对齐=沿长边与桌心齐`、`对齐=沿短边与桌心齐` 与 `对齐=沿接触边与参照中心齐` 同一句：接触边落到画面左右写「沿这条桌沿与桌心左右对齐」；落到纵深写「沿这条桌沿与桌心一样远」。同一侧多把，整组中心与桌心对齐。`态=破坏` 不拉回中线。缺对齐不补。
驾驶座、操纵席、副驾只旋 `椅面朝向=`。主驾朝向南、挡风在南：0 度椅面朝靠近镜头，挡风在镜头后，正面是舱尾；180 度见椅背，椅面朝远离镜头，正面是挡风。不把挡风改挂到别的壁。光色照抄开篇，不另加应急红、幽暗、死黑。有 `舱外依赖=` 且 `依赖因=舱外环境` 时，玻璃外只复述这一块宿主。`主副驾距=一臂`：0 度与 180 度两座左右分开大约一条手臂，落在纵深中线上；90 度与 270 度一近一远大约一条手臂，落在画面左右中线上。
`主体分组=`：核心是桌、案、床、榻、沙发时用成稿那一对，不写沿X线。成员心点在宿主占地里只写在面上。离开宿主中心的成员才写沿 X 线、沿 Y 线。不写「在核心的某一侧」，不写与核心平行。挂桌的椅仍写坐在桌子的哪一画面侧。`边=` 只认北、东、南、西、面上，按旋轴表的北侧、东侧、南侧、西侧。写成 `边=长边北侧` 则回流。没有 `长边平行=` 的「东西向」「南北向」不自拟走向。椅面朝向不改 `边=` 已经转好的那一侧。核心入画却少一个成员 = 失败。
床头柜挨着床头，画面侧与床头相同，单独过脚深。
台面件与宿主中心重合的，只写在这一具的面上，不写沿X线，不写长边，不写窄头。心点离开宿主中心的，每只一句，只写沿 X 线、沿 Y 线，不写长边句。杯与托中心相同就写同一对。枕写在床头所在的那一端。下表的左右、远近按望南、望西再对调。

| 开篇 | 0望北 / 180望南 | 90望东 / 270望西 |
| :--- | :--- | :--- |
| 南北同、东西不同 | 一只在桌心画面左，一只在画面右，和桌心一样远 | 一只靠近，一只远离，左右与桌心对齐 |
| 东西同、南北不同 | 一只靠近，一只远离，左右与桌心对齐 | 一只在桌心画面左，一只在画面右，和桌心一样远 |

东边那只：望北在桌心画面右，望东更远离，望南在画面左，望西更靠近。西边对调。北边那只：望北更远离，望东在画面左，望南更靠近，望西在画面右。南边对调。四格都写成画面左和画面右 = 失败。
旗只写画面左右、纵深和 Z。色相、图样、形状留在【主体外形】。宿主在镜后，旗不点名。

## 开合
看见这扇的每一格都写全关、半开或全开，四格用开篇同一个词。
平开门、平开窗、柜门：铰链是开篇同一个世界端，按旋轴表转成画面左、画面右、靠近镜头或远离镜头。门栓在铰链对端，门把手在门栓这一端。`起侧=` 是东南西北时，铰链端与这一向相同。值是门左或门右时，不把这两个词写成画面侧。
词与 `扇型=` 相同。外形写了另一个词，画面句仍用扇型。单扇正对：`这一扇是单扇。门洞在这面正面墙上，左端是{铰链|门栓}，右端是{门栓|铰链}。两个立边离镜头一样远，这是门扇正对镜头。` 门洞中心离开墙的左右中线时，接位置句里的画面左或画面右，再写 `门洞中心落在沿X线已经写出的那一侧。` 人员门沿墙宽除以所在墙开间，取最近的一档写进正对的门洞句：十六分之一、八分之一、四分之一、一半。写成 `这扇门的宽度大约只有这面墙的{这一档}。` 超过一半不写。不写米。侧面不写这句占墙比例。在画面左或右：`这一扇是单扇。门洞贴在画面{左|右}，靠近镜头的一头是{铰链|门栓}，远离镜头的一头是{门栓|铰链}。` 一端铰链，另一端门栓。双开侧面不写这一扇是单扇。侧面的人员门在高挑房间里再写 `门扇只占这面墙的下面四分之一，上面是空墙。` 侧面半开同样写门板停在半程，里开贴在铰链这一头。
双开：两端各是一扇自己的铰链，中间是对缝。正对：`这一对是双扇。左端是{画面左那一扇}的铰链，右端是{画面右那一扇}的铰链，中间是对缝，两端一样远。` 侧面：靠近镜头的一头是近端那一扇的铰链，远离镜头的一头是远端那一扇的铰链，中间是对缝。不把单扇的门栓句套到双开上，不把两头都写成门轴。侧面门洞写 `贴在画面{左|右}，开在这张墙上`。`只见向里的厚` 只给壁关系=贴墙。
平移、推拉、闸门、液压门、升降门、卷帘门不写铰链、门栓、门轴。停端用开篇 `停端=`，四格旋成同一个世界端的画面侧。禁止四格都写左侧。闸门四格保持同一扇门洞轮廓，顶接到天花，不改成拱门，不另写门框壁。盖满开间且没有另登记墙皮的，正面铺满，侧面只写一头近一头远。平移正对：`扇停在画面{左|右}，两端一样远。` 贴在侧面：`扇停在{靠近镜头|远离镜头}的一头。` 闸门自己是封闭面时，不写门洞在墙上。
平开外开且全开：门栓这一端是空门框，铰链端的门板在墙外。里开且全开：门板折进房间，贴在铰链这一头的内墙。半开必须写门板停在哪。里开：`门板停在半程，向房间折出，贴在铰链这一头，门栓这一头是敞开的口。` 外开：`门板停在半程，向墙外开出，铰链这一头仍连着门轴，门栓这一头是敞开的口。` 框中画只嵌在敞开的那一半。只写半开两个字 = 失败。半开停在贴在铰链这一头、后面没有敞开的口，失败。正面半开没有敞开的那一半框中画，失败。全开才是空门框。全关留在洞口里。整扇在镜头后，侧面不点名。
帘、百叶用同一套开闭词，留在所在壁。全关不写帘外景物。半开只露出半面。全开：单幅收到开向那一侧，双开收到两端。固定玻璃不写开闭。
**框中画。** 先看开闭。`开闭=全关` 且没有 `透=透`：不写框中画，不写门外、窗外、室外、城、天际。只写全关，门扇留在洞口里。全开并且该壁在正面，才写 `[@门]（{码}）框内是框中画：{远景短词}，嵌在这张正面墙的洞里。` 半开不用这一整洞句。半开的正面在门板句之后写 `敞开的那一半框内是框中画：{远景短词}，嵌在门栓这一头。` `洞外=室内` 的远景短词只写室内。`洞外=室外` 才写室外。侧面只有能斜看进洞时才写侧沿框内。`围合=敞` 的整面远景不套框中画。`透=透` 的固定玻璃、弧墙写透过这面玻璃看见外面。纸、纱、绢、裱写透过这面纸、透过这面纱或透过这面绢，不写玻璃。石、砖、夯土、毛毡、皮革、木、铁不写透过。这一壁在镜头后，不把这片外面写进别的门洞。四格远处都出现同一片天际 = 失败。全关仍写框中画 = 失败。半开仍把整洞写成通廊、门板不留在铰链这一头 = 失败。

## 光
开篇【光学说明】不抄进成稿。成稿不写光源、源形、源体画布位、高度带、纵深光层。光比、色温、柔硬、焦段、景深、半影、材质响应只在共享句。辅光出光口在本格正面、画面左或画面右时，该格一行写从哪一侧来。出光口在镜头后，不写辅光名。点缀入画才写在该具那一行。缺的不另起一盏。格子里的光只用本节末尾那几句。
来向、射向里的东南西北各查旋轴表一次。写成 `光线从{来向的画布侧}`，`射向{射向的画布侧}`。影子投向与射向相同。向下只写向下，向上只写从上方。无日且出光口是天空：四格都写从天空漫射下来，不查旋轴。没有世界来向、世界射向，不写光线从和射向，不用 Key世界向或时辰补。吊灯、顶灯已写世界射向=下的，射向是下。把任一格旋回东、南、西、北、上或下，必须等于开篇，也必须和其他格相同。辅光、点缀各用自己的出光口和来向，不抄主光。
成稿不写高度带。没有 `高度=` 不补低、中、高，也不按时辰补。`Key世界向=无日` 不画金盘。

## 自检
只核【四向拼图】是否按上文写成。缺键不补。成稿不抄技能里的禁止、失败、回流、默认、logic。不另加解释句。
每格只有正面、左侧面、右侧面、中部、上。位置不写米。纵深的台用成稿节窄头句。格子不写没有门、不写桌和椅、不写画布坐标、不写件数核销、不写镜后整包。桌案行出现沿X线、沿Y线、Z贴地面或中心落在X线，纵深桌案行出现左右大约只有房间、从画面左伸到画面右或从画面左铺到画面右，面上与宿主中心重合的件另写长边或窄头，敞向远景写成贴在画面左或一头近一头远，同一行既有天花离地又有从天空漫射下来，都失败。没有长边平行却写了长边、窄头或靠近镜头的是长边，短件和铺满或一头近一头远在同一句，出现所在的，屏入画没有屏面句，有出光口而四格都没有光线从或光源不可见，天花离地后面没有净高，上这一面点了两具天花，构图点了主体名，共享句多了七个键以外的话，四宫度数在构图之后再出现一行，窄头句以长边与Y线平行起句，桌案行写出桌心、画面下沿、两端不到左右墙、两端不到画面左右、宽度大约、上下也在中部、不贴画面下沿、看见窄头正对镜头、这条长边比纵深长、长边与X线平行或长边与Y线平行，都失败。另核格标题角、出光口四类、方向线、椅面朝向、扇型、半开的口、透的材料、女墙与敞向远景、嵌入的侧面、穹顶与平天花。漏一项即失败。其余对照上文各节，不在这里再写第二套。
