## 成稿
唯一输出：一个 JSON，仅含 `environments`。每条只写 `name` 与 `generation_prompt_cn`。
用户消息里有几段【主环境设计稿】，`environments` 就有几条，`name` 取该段标题中的主环境名，逐字对应，写在同一份 JSON 里。禁止只写第一条。
`generation_prompt_cn` 只含【四向拼图】，从【四向拼图】起笔，到最后一格为止。
【定位】、【主体外形】、【色彩说明】只作输入，本技能不输出。程序写回时原样抄入，【色彩说明】放在【四向拼图】之前。
禁止输出 `posters`、`{N}度` 衍生、`description_cn`、`dependency_strategy`、`visual_dependencies`。
成稿不出现这些标题：【定位】【主体外形】【六面一次】【北壁】【东壁】【南壁】【西壁】【中区】【光学说明】【色彩说明】【构图】。
开篇缺键不另造主体、米、开闭、材质、纹样、颜色、配套、配饰、光源。只做两处转译：没有 `原点主体=` 时，按「画布」的顺序选一具已有地上主体；没有 `高度=` 时，按「光」里的时辰取高度带。这两处不改已经写明的主体和细节。

共享句在四格标题之前，只写一次：`共享：光比=，色温=，柔硬=，焦段=，景深=，半影=，色板=`。词从开篇【光学说明】【色彩说明】照抄。主冷暖、比例、色系、纵深色层留在【色彩说明】，共享句和四格都不写。
画布只这一行：`16:9，2×2 四宫格；四宫度数=左上0度｜右上90度｜左下180度｜右下270度。四格是同一处的四个方向，材质与开闭相同。` 这一行是四张拼回后的成图。生图按下一节拆四次，不按这一行一次画完四格。
四格按阅读序：`[0度格-左上·北]`、`[90度格-右上·东]`、`[180度格-左下·南]`、`[270度格-右下·西]`。
必须可检索：【四向拼图】、`共享：`、`构图：`、`四宫度数=左上0度｜右上90度｜左下180度｜右下270度`，以及上面四个格标题。不得检索到【定位】、【主体外形】、【六面一次】、【北壁】、【东壁】、【南壁】、【西壁】、【光学说明】。心点和 Key世界向不进入成稿。

每格按这个顺序：`角标=`、`画布坐标：`、`正面：`、`左侧面：`、`右侧面：`、`中部：`、`上：`、`件数核销：`、`构图：`、光学段、`镜后整包不入画。`
角标只许 `0度·望北` / `90度·望东` / `180度·望南` / `270度·望西`。
五面每格都要有。左右侧按「入画」可以写 `不可见`，行仍必须在。镜后不单开第六面，最后只留这一句，不点那一面的主体。
东南西北只许留在格标题和角标。各格先删掉全部 `[@短名]（{码}）`，剩下的句子里出现 `北|东|南|西` = 失败。`[@]` 内的开篇原名照抄。

四格不写外形、大小、材质、纹样、颜色、柱径米数、旗的色相图样形状、牌匾文字、光比、色温、柔硬、焦段、景深、半影、色板、主冷暖、纵深色层。这些都留在环境资产设计里，四格不另写一套，也不改其中任何一件。开篇没有的主体、纹样、配套和配饰，四格不补。
四格不写人，不写已抽角色或道具。不写主舞台、北0东0、横轴、纵轴、上轴、u、v、公式、写稿方法。
禁止这些键：`站在=`、`远锚=`、`机位=`、`画面落位=`、`底面=`、`贴附层=`、`左邻壁=`、`右邻壁=`、`可见=`、`可见面=`、`落点=`、`对面=`、`距对面=`、`负空间=`、`本格朝向=`、`本格可见座具=`、`同排=`、`同列=`、`#N`、`心点=`、`距原点=`、`Key世界向=`、`主光=`、`高度=`、`出光口=`。
光学段用 `光源=`、`源形=`、`源体可见=`、`源体画布位=`、`高度带=`、`辅光=`、`点缀=`。这是成稿键。开篇的 `主光=`、`Key世界向=`、`高度=`、`出光口=` 旋进这些成稿键，不原样留下。

## 出图
文字四格一次从主环境转写。不按已经写成的一格改写下一格。成稿仍是一份【四向拼图】。格子里不写参照，不写出图序。

生图不把四格一次画进同一张。从这份成稿拆四次，每张都是单张 16:9，再按左上 0、右上 90、左下 180、右下 270 拼回。拼回后的一张才是下游裁切用的四宫。

1. 0 度。输入只有主环境的【定位】【主体外形】【色彩说明】、共享句、[0度格]。不附其他格，不附已生成的图。
2. 90 度。输入只有主环境、共享句、[90度格]。可以附上 0 度成图，只用来认同一具的外形和材质。不把 0 度的纵深、主体朝向、长边走向抄过来。这一格长边横在画面里还是顺着纵深，只读本格的画面走向。
3. 180 度。输入是 0 度成图、共享句、[180度格]。镜头转到 0 度的对面。左右对调，近远对调。禁止把 0 度原图左右翻转。0 度里在镜头后面的那一壁，只按本格正文画，不从 0 度图里补。0 度里已经看见的主体保持同一具，只换到对向该在的一侧。
4. 270 度。输入是 90 度成图、共享句、[270度格]。同第 3 步，对向是 90 度。不拿 0 度成图当几何，也不拿 180 度成图当几何。

0 度错了只传给 180 度。90 度错了只传给 270 度。不是对向的两格不互相继承构图。一次把四格画进同一张 = 失败。四张没有拼回就拿单张当四宫 = 失败。180 度不参照 0 度成图，或 270 度不参照 90 度成图 = 失败。对向转写成左右翻转原图 = 失败。90 度把 0 度的纵深构图抄进来 = 失败。

## 画布与位置
四格画面原点是同一个主体的中心。开篇已写 `原点主体=` 就用那一具。没有这键时只选一具：舞台区中部有主体，且它的中心确实在中部，优先地上的；地面、甬道、地板、地毯可以。中部没有，改选舞台边上的一具地上主体；挂靠在边上就用挂靠，否则用离中部最近的那一具。墙皮、立面、天花、天空、远山不当原点。这一中心是北0东0。成稿点名这一具，不写北0东0，不写主舞台。
挂靠被选成原点时，原点就是它的中心。挂靠不是原点时，写相对原点中心的沿本格 X线、Y线，不把脚改站到挂靠外沿。

原点、镜头脚写在角标之后、正面之前。本格 X线、Y线按上一节的四句改，四格不是同一句。

`画布坐标：原点是[@短名]（{码}）的中心，在地面上、画面左右正中。本格X线从{画面左到画面右|靠近镜头到远离镜头|画面右到画面左|远离镜头到靠近镜头}，正方向在{画面右|远离镜头|画面左|靠近镜头}。本格Y线从{靠近镜头到远离镜头|画面右到画面左|远离镜头到靠近镜头|画面左到画面右}，正方向在{远离镜头|画面左|靠近镜头|画面右}。Z向上。镜头脚在这一中心朝向正面的反侧、紧贴这一中心的外侧地面上，眼高 1.6 米，平视朝向正面。主体的米从这一中心量，也沿这三条线量。这句不画成字，不画线。`

原点主体写了占地、且不是墙皮或天花时，把「紧贴这一中心的外侧地面上」改成「停在这具靠近镜头那一侧外沿之外的地面上，不站上台面，不站进设备」。桌、案、床、榻、沙发、地毯、台、平台、卸货台、钢板台、基座、机组同一句。不另写离开中心的米。脚和这一中心之间有墙、柱、栏时，只改那一格：脚停在那一道近面之前。镜头离这一中心不另写米。
原点主体写「中心就在画布原点，落在本格X线和本格Y线的交点上。Z贴地面。」没有原点主体 = 失败。

**脚深（写稿用，不进成稿）**：半幅是开篇大小里、与本格望向平行的那一条的一半。望北、望南取南北，望东、望西取东西。脚深 = 这一半 + 贴身 0.4 米。沿靠近镜头量这一具的两端，米从原点中心量。
两端的靠近镜头米都大于脚深：整具在脚后，这一格不点名，从原面划出，划出名写这一具。禁止写成只见这一端。
只有远离原点的那一端大于脚深、靠近原点的那一端小于或等于脚深：仍点名，写只见靠近原点的这一端。
两端都小于或等于脚深，或整具在远离镜头一侧：整具在脚前，照写。
原点主体本身不拿脚深划掉。脚深只从原点主体量。半幅取与望向平行的那一条：长边落在这一轴用长的一半，短边落在这一轴用宽的一半，不默认取长边。中区每一具单独比，含轨道、机床、滑道、柜和分组里的成员，不限于桌、椅、床。一具在脚后，不连带删掉仍在脚前的邻具，也不因邻具在脚前就把脚后的这具留在画里。两端都大于脚深却写只见这一端 = 失败。只有一端在脚前却整具划出 = 失败。
焦段 k 不参加入画。侧面整面只看正面两倍，单件只看脚深。

入画主体的位置只写一句：`[@短名]（{码}）。沿本格X线{在画面左{米}|在画面右{米}|在靠近镜头{米}|在远离镜头{米}|落在画面左右中线上，与[@原点主体]左右对齐|落在纵深中线上，与[@原点主体]同一纵深}，沿本格Y线{同这一套}。Z贴地面。`
沿本格 X线的那一侧必须是这一格 X线的方向。望北、望南的 X 线只写画面左、画面右，或零偏移的画面左右中线。望东、望西的 X 线只写靠近镜头、远离镜头，或零偏移的纵深中线。Y 线对调：望北、望南的零偏移写纵深中线，望东、望西的零偏移写画面左右中线。零偏移不写米，不写落在线上，不单写中线。只写同一纵深或只写左右对齐、不写是哪一条中线 = 失败。同一对米写两句 = 失败。只写一条轴、只写缝档、或只写贴在画面左 = 失败。四格出现 `大小=` = 失败。成稿出现「原点主体」四个字 = 失败。
有 `离平地=` 时，Z贴地面改成 `Z离地{米}`。无限制的那一轴写无限制。`离平地` 和 `窗台离地` 是高度，不占这两轴。不可见的一侧不写该侧主体的位置。
把任一格的画面位置旋回北米、东米，必须等于开篇这一份，也必须和其他格旋回的结果相同。
对向两格差 180 度。零偏移的那一条中线不改。另一轴、正面和朝向必须对调。望南相对望北：画面左与画面右对调，靠近镜头与远离镜头对调，正面从北壁换成南壁。朝南的面从朝着镜头改成背对镜头，朝北的面对调。纵深中线仍写纵深中线。望西相对望东：靠近镜头与远离镜头对调，画面左与画面右对调，正面从东壁换成西壁。朝东的面从背对镜头改成朝着镜头，朝西的面对调。画面左右中线仍写画面左右中线。两格偏移侧相同，或正面仍是同一壁 = 失败。

**边，三类只走一类。** 每一件先写位置句。边类是位置句的下一句。位置句里的「沿本格X线在画面左」只是中心落在哪一侧，不算第 3 类，也不等于长边与这条轴平行。同一件不叠两类边句。
1. 墙、路、城垣、长街侧列、弧墙、楼梯：用后面各节的画面句，不另写「长边与本格X线平行」。
2. 正方：没有 `竖边=`，或长边与短边之差小于贴身 0.4 米。不写与某线平行，不写一头近。垂直望向：`左右和前后一样宽，偏在画面{左|右}。两端离镜头一样远、一样大。这一段不到画面对侧。` 心在左右对齐：`左右和前后一样宽，落在左右中线两侧。两端离镜头一样远、一样大。两端都不到画面边缘。` 平行望向：`左右和前后一样宽。靠近镜头的一边和远离镜头的一边一样宽。` 禁止「从画面左铺到画面右」。
3. 凡开篇写了 `长边平行=` 或 `长边走向=` 的主体都走第 3 类。含桌、案、台、工作台、凳、椅、沙发、床、榻、地毯、矮几、饮水机、茶几、柜、机床、滑道、轨道、机组、台架，以及放在它们面上的板、屏。不限这份名单里点过的名字。墙皮、通铺地坪、门洞、窗洞不走第 3 类。下一句先写轴句：`长边与本格X线平行。短边与本格Y线平行。` 或两条对调。开篇 `长边平行=X线` 写成与本格 X线平行，`长边平行=Y线` 写成与本格 Y线平行。这句只锁平行的世界轴。不是顺着铺过去，也不是位置句里的「沿本格X线在画面左」。禁止只写「沿着」。夹角不是 0 度或 90 度时，长边与转好的本格 X线仍成开篇那个度数，写成 `长边与本格X线成{度}。短边垂直于长边。` 长边落到左右、并且短于所对的墙：另写 `不到画面对侧` 或 `两端不到画面边缘`。轴句禁止一头近、与画面底边平行、左右一样宽、从画面左铺到画面右、几成、落在左右中线两侧、偏在画面左。缝档仍可写档。既写与本格某线平行，又写一头近、与画面底边平行、左右一样宽、从画面左铺到画面右、落在左右中线两侧或偏在画面左 = 失败。
轴句的下一句写这一格的画面走向，闭集只此两句。长边落到本格的画面左右轴：`长边横在画面里。短边顺着纵深。` 长边落到本格的纵深轴：`长边顺着纵深。短边横在画面里。` `长边平行=X线` 时，望北、望南写横在画面里，望东、望西写顺着纵深。`长边平行=Y线` 对调。望南相对望北、望西相对望东，画面走向不改，位置句的左右和远近仍对调。四格写成同一句画面走向 = 失败。望北与望东写成同一句 = 失败。位置句只钉中心。中心在画面左右中线上，不表示长边横在画面里，也不表示长边顺着纵深。中心在纵深中线上同样不表示走向。滑道、轨道、机床的中心落在中线上，长边仍按这一句。只写位置句、不写画面走向 = 失败。只写轴句、不写横在画面里或顺着纵深 = 失败。画面走向禁止写成从画面左铺到画面右、与画面底边平行、一头近一头远。那些是墙和路。既写画面走向，又写从画面左铺到画面右或一头近一头远 = 失败。
开篇 `长边走向=从东到西` 就是 `长边平行=X线`。四格都写同一句轴句「长边与本格X线平行。短边与本格Y线平行。」本格X在望北、望南是画面左右，在望东、望西是靠近镜头与远离镜头，不另改成与本格Y线平行。画面走向按第 3 类对调，不把轴句改成与另一条线平行。`长边走向=从南到北` 就是平行 Y线，四格都写长边与本格Y线平行、短边与本格X线平行。夹角不是 0 度或 90 度时，四格仍写「长边与本格X线成{度}。短边垂直于长边。」不把 `长边两端=`、`短边两端=` 的两个主体名画成一条连线；开篇若只有这种连线、没有走向，logic 标回流，这一具不连。`沿边=沿长边向东`：望北落到画面右，望南落到画面左，望东落到远离镜头，望西落到靠近镜头；向西相反。`沿短边向北`：望北是远离镜头，望南是靠近镜头，望东是画面左，望西是画面右；向南相反。间距档四格相同，贴身仍是贴身。`朝向=朝上` 四格都是使用面朝上。朝向是北、东、南、西的，望北时朝北是背对镜头、朝南是朝着镜头、朝东是画面右、朝西是画面左；望东时朝东背对镜头、朝西朝着镜头、朝南画面右、朝北画面左；望南、望西按对向再转。床头的东、西、南、北用同一张表，不改成另一端。

圆只转圆心，半径四格相同。禁止把圆写成一头近一头远，禁止把半径拉成长边。柱只读柱径相对，不另画一套半径长边。柱身与地面垂直，柱顶接到天花。同形写「一样粗」。开篇 `柱径相对=` 是细一圈或粗一圈的，四格用同一句。靠近镜头不改成更粗。不写柱径米数。盘龙、束柱只是花纹。柱身不向藻井中心收，不写成一头近一头远。台不重写外形词，长边只换落到的轴。`舞台占地=` 不拿来改这座台的大小。门的高和宽四格相同。

缝档由开篇边到边的米换算，米留在开篇：贴着（不留缝）｜贴身 0.4｜一臂 0.7｜两步 1.4｜三步 2.2｜五步 3.6。空当 ≤3.6 米取最近一档。大于 3.6 米写一成、两成、三成、四成、一半、六成、七成、八成或九成。横的空当用东西场径之和，纵的空当用南北场径之和。台上的件不用步：贴着边、大约四分之一、大约一半、大约过半、靠近台心。四格缝档相同，只有画面侧随望向转。成稿写「在[@参照]（{码}）的画面{左|右|靠近镜头这一侧|远离镜头那一侧}，离开它大约{缝档}。」缝档句不写米。缝档不代替沿本格 X线、Y线。空当是两具四向最远外沿相减。外沿差 = 沿分开那一轴的中心距 − 甲在该轴上的半宽 − 乙在该轴上的半宽。长边落在该轴用长的一半，短边落在该轴用宽或深的一半，屏面法线落在该轴用厚的一半。外沿差小于 0 是重叠，禁止写贴着、贴身或离开。0 到 0.1 米才写贴着（不留缝）。贴身只在外沿差是 0.4 米。中心到对方外沿是 0.4 米、自身半宽还没扣，不写贴身。四格抄开篇这一档。写成贴着而外沿差为负 = 失败。心点落在另一具占地里面的，那一具就是宿主，必须是本格已经点名的 `[@短名]（码）`。成稿写「在[@短名]（码）的面上，离这张{短名}{画面左|画面右|靠近镜头|远离镜头}那一端大约{几成}。」禁止只写「宿主」。禁止不点名。配电板在工作台面上，宿主是这张工作台，不是地面。位置已经写在沿本格 X线、Y线里，面上这句不再写偏在画面左。❌在宿主面上、离宿主画面左那一端大约两成。✅在[@长条形铁质工作台]（M-001）的面上，离这张工作台画面左那一端大约两成。

## 入画与件数
**正面两倍。** 每侧单独跟本格正面纵深比，不跟另一侧比。正面纵深是原点到正面朝向镜头那一面的垂距；正面是具名街端时，取该具近面的远离镜头米数。左右距离大于这份纵深的 2 倍，该侧只写 `左侧面：不可见。` 或 `右侧面：不可见。`，这一句后面不再写字。小于或等于，含正好 2 倍，该侧入画。两侧距离彼此接近，不能因此一起留下。正面纵深越长，这道 2 倍越宽。算式不写入成稿。
无限制长条端，或左右距离大于正面纵深 2 倍的长条端，落在左或右时只写不可见。禁止在这一侧写主体名、大小、没有实墙、远处只画、短头、远天际、开敞、通向外景。街端、门楼、坊落在左或右，小于或等于才写在画面端、只见这一端，禁止一头近；大于则不写入该格。
正面短墙近面在镜头前就写入正面。短墙的竖边与望向垂直才许写成正对。顺着长边望去的正面写这一端的具名街端；没有具名端头时写 `远处只画[@远景]（{码}）。` 长墙自己的墙面不写成这一格的正面。有具名街端时禁止写没有实墙，禁止用天际代替这一具。
`场径=无限制`、这一侧没有长条端、也没有具名主体时，不参与这道比较，按场态写侧天际。入画的平行侧壁才写从靠近镜头伸向远离镜头、一头近、一头远。一侧不可见时，城垣和通铺墙收到可见的那一端为止，不写从画面左铺到画面右。沿短边的侧列仍可从画面左铺到画面右。
左侧面、右侧面、中部至少一处入画。两侧都不可见时，正面和中部照写。两侧都不可见、中部又没有开篇已经写下的地面、长条近端或中区件 = 失败。
到左侧、到右侧，只取该侧主体在镜头前方的最近点。墙取朝向镜头的那一面。长条取伸进远离镜头的近端。中心落在纵深对齐、身体又没有伸进远离镜头的，不参加比较，不写成开敞。有具名主体时，不用场径代替最近点。

**长条同一套。** 只用于路、廊、街、巷、城垣，以及开篇已写 `竖边=` 且本身就是这些长条的主体。室内四向皆封的地坪、地毯、通铺地面不走本节，四格只写通铺写满。中部的机床、滑道、轨道、机组、桌、案、床、榻、沙发不走本节。这些具开篇若写了 `竖边=`，四宫忽略这一键，仍走第 3 类。一条比另一条长，也不改成路面。顺着长边的正反两格，纵深各是从原点中心到该端的一段，两段相加等于全长。靠近镜头这一头是这条长条的短边。这两格的正面写这一端的具名端；没有具名端头时才写该向远景。两格都写成全长 = 失败。禁止把全长收进沿短边那两格的纵深，禁止让长条铺满画面，禁止让长条代替正面。

开篇 `面件数=` 的 n 按主体编号表重数：北只计 N，东只计 E，南只计 S，西只计 W，中计每一个 M 和每一个 F，上计 C。中区有多具时逐码计，不并成一组。背靠某一壁不把 M 码算进那一壁。`下=` 点了地面，地面仍计入中。面件数和编号表对不上时，核销用编号表的个数，禁止抄面件数里那个少计的数。抄了与编号表不合的中件数 = 失败。禁止把开篇 n 改成这一格已经写下的件数。
本格对上去：望北正面对北、左对西、右对东；望东正面对东、左对北、右对南；望南正面对南、左对东、右对西；望西正面对西、左对南、右对北。中部对中，上对上。成稿核销句不写东南西北。

看得见的一面，第一句写 `件数={k}。` k 等于这一面里 `[@]` 的个数，然后逐件写。k 加本面划出等于开篇 n。整面不可见的侧面，正文仍只有 `不可见。`，点名=0，划出=开篇 n，划出名等于该侧开篇每一件。
宿主墙在镜头后、件仍有一端在脚前：墙皮不写，件改写入中部。改入只从原壁划出一次，而且只用于壁码。中区原有的 M 码和 F 码禁止改入。壁上划出=0 却写改入 = 失败。地面计入开篇中。贴墙的全息屏、立式全息终端、中继屏、固定显示屏、巨幕、矩阵屏、壁挂屏不改入中部。所在壁在镜头后，整具不写。
每一面 `点名+划出=开篇`。中部接收改入时，`点名+划出−改入=开篇中`。
划出大于 0 时，同一句写 `划出名=`，逐个列出本面正文没有的 `[@短名]（码）`，个数等于划出。划出为 0 时，划出名写无。划出名里的码不得出现在这一面正文。编号表有码、正文没有、划出=0 = 失败。
五面写完、构图之前：
`件数核销：正面点名={k}开篇={n}划出={m}划出名={码}｜左侧面点名={k}开篇={n}划出={m}划出名={码}｜右侧面点名={k}开篇={n}划出={m}划出名={码}｜中部点名={k}开篇={n}划出={m}改入={p}划出名={码}｜上点名={k}开篇={n}划出={m}划出名={码}。`
四格中部点名的主体，除掉各格自己的脚后划出，是同一批。某一格写远离镜头、该具仍在脚前的，对向格改成靠近镜头，左右格改成画面左或画面右，仍然点名。中部每一具，两端都还在脚前就必须点名，禁止划出。只有靠近原点的一端在脚前，写只见这一端，禁止整具划出。不限于桌、案、椅、凳、床、榻。

正面、左侧面、右侧面、中部、上，看得见的每一件单独一句。少一件 = 失败。邻格写过的，本格看得见仍要再写。心点重合的地面和台上的台各计一件。地面、甬道、地板按通铺写满。四向皆封的地坪禁止写成路面、路宽、两侧铺面、不铺成广场。台、平台、卸货台、钢板台、基座按自己的占地写，短于地面或短于所对墙时两端不到画面边缘，禁止从画面左铺到画面右，禁止与地面合成一块地。墙上短于开间的巨幕、横幅、矩阵屏、操控台：居中写落在左右中线两侧、两端不到画面边缘；偏一侧写不到对侧。禁止铺满这一壁。全息屏、立式全息终端、中继屏、固定显示屏、巨幕、矩阵屏、壁挂屏四格都写在正面、左侧面或右侧面。成稿屏面句不带「正对时」。贴在画面左时屏面朝画面右，贴在画面右时屏面朝画面左。短于开间的写两端不到画面边缘。禁止写在大案旁边，禁止改挂到另一壁。有屏面的具先写壁关系句，再写屏面朝向。

## 墙
没有 `竖边=` 的通铺墙皮，正面第一句是开篇该壁 `封闭面=`。这一具必须在主体编号表里有该壁的码。没有码的副墙不写。门、巨幕、操控台窄于该壁开间时，封闭面用墙皮那一具，门和幕写在这具墙上。中区的案台、椅、地毯、平台不写进正面。望东用东壁那具，望西用西壁，望北用北壁，望南用南壁。四格四个正面主体互不相同。
没有 `弧向=` 的正对墙：`墙身与地面垂直，与画面底边平行。左端和右端离镜头一样远、一样大。室内面朝着镜头。不见墙厚的侧沿。` 远近只写原点到朝向镜头那一面的垂距，一个米数。两侧都入画才接「从画面左铺到画面右」。有一侧不可见，墙收到可见端为止。中心偏左或偏右时，只在落到左右的那条轴上写米，远近仍是这一个垂距。中心的两轴都偏离对齐时，这面不是正对，改贴到侧面。
有 `竖边=` 的城垣、女墙、长墙不走这句。竖边与望向垂直才写进正面，用上一句。竖边与望向平行则贴在侧面：`贴在画面{左|右}，墙身与地面垂直，从靠近镜头伸向远离镜头，一头近、一头远。室内面朝画面{右|左}。` 贴在画面左，室内面朝画面右。贴在画面右，室内面朝画面左。禁止写成远处那一整面，禁止与画面底边平行，禁止两端一样远。本格正面改写该向远端。同一件既写与画面底边平行又写一头近一头远 = 失败。四格都写成同一句伸向 = 失败。只写「靠近镜头的一头是墙厚侧沿」、没有室内面朝向 = 失败。墙厚只在这一壁与镜头后那一壁相接的角上写一次，不代替室内面。
开篇有 `壁别名=` 时，长边两端写 `[@别名]`，不写北壁、东壁、南壁、西壁。
`墙面朝向=` 旋到靠近镜头才许正对。旋到画面右，墙贴画面左；旋到画面左，墙贴画面右；旋到远离镜头，这面墙在镜头后，不画。入画的每一壁都写室内面：正对写 `室内面朝着镜头`，贴在画面左写 `室内面朝画面右`，贴在画面右写 `室内面朝画面左`。室内面是开篇朝进房间的那一向，四格只旋这一向。禁止用「靠近镜头的一头是墙厚侧沿」代替这一句。
城门楼、角楼接到城垣时：`画面{左|右}端是[@城门楼]（{码}），[@城垣]（{码}）接到这座楼为止，和它一样远。` 城垣这一端不再写从画面左铺到画面右。禁止这座楼再写一头近。牌坊、风铃写在城垣朝向镜头的这一侧。禁止「贴在正面墙前」。
棚、棚架、挑檐走第 1 类长边，不收成贴在墙皮上。宿主壁是短边的一端。四端都在镜头后的那一格写「棚在镜头后，不画」。
看台、座席、屏风、巨门本身是这面墙、且没有顺着望向的长轴时，同样写墙身与地面垂直、与画面底边平行、两端一样大。看台侧视写从靠近镜头伸向远离镜头、两头一样高。开篇 `上=` 的天窗只写在天花。开篇该壁没有的高侧窗、尖券、玫瑰窗不写进正面。

**弧墙。** 开篇有 `弧向=` 的幕墙、弧形墙、曲面墙、落地弧形玻璃，弧只属于这一壁。两端停在这一壁和左右邻壁相接的两个角上，角不挪。中段只在这两个角之间鼓出。外弧鼓向房间外面，内弧鼓进房间。邻壁仍是开篇那一具直墙，开间不缩短，不改成玻璃，不跟着鼓。弧不越过角铺进邻壁。正对：`玻璃从左角铺到右角，墙身与地面垂直，底贴地面，顶接到天花。两端离镜头一样远，两端是和左右邻壁相接的角。中段比两端更远离镜头。左壁和右壁仍是各自的直墙，接到这两个角为止。` 内弧把「更远离」改成「更靠近」。禁止写成两端与中段一样远，禁止「只见朝向镜头的这一面」，禁止弧越过角铺到左右壁上，禁止左右壁收成一条缝。贴在侧面：`贴在画面{左|右}。玻璃从靠近镜头的那个角伸向远离镜头的那个角，底贴地面，顶接到天花。中段鼓出这两个角的连线。` 正面那一壁和另一侧仍是直墙，不写中段鼓出。禁止把这道玻璃写到正面或另一侧，禁止写成一根直线、一头近、一头远。这一壁在镜头后：不画这道弧。左右邻壁和正面保持各自的直墙，不把玻璃挪到邻壁上。`透=透` 的写「透过这面玻璃看见外面」。盖住它的帘全关时，弧留在帘上，不写外面。固定玻璃不写开闭、扇停在、铰链、门洞。这面墙是主光时，源形写幕墙或窗。邻壁写成弧、玻璃或幕墙，而开篇这一壁没有 `弧向=` = 失败。弧壁在镜头后，画面里仍有这道玻璃 = 失败。正对时左右邻壁没有各自的直墙句 = 失败。弧越过角铺进邻壁 = 失败。

同壁至少两具名、这一面入画：正面写「远处那一整面是[@墙]（{码}），[@贴]（{码}）都在这张墙上。」侧面入画才写「画面{左|右}是[@墙]（{码}）的侧沿，[@贴]（{码}）沿着这张墙。」这句只点名同壁。每一具自己的下一句必须写开篇 `壁关系=`，四格只换这一壁在正面还是在侧面。
正对：墙皮用室内面朝着镜头。门洞写 `门洞开在[@墙]（码）上`。窗洞写 `窗洞开在[@墙]（码）上`。齐平写 `与[@墙]（码）墙皮齐平，不凸出墙面`。嵌入写 `凹进[@墙]（码）的墙皮，外沿与这张墙齐平`。贴墙写 `贴在[@墙]（码）的墙皮上，背面贴着这张墙`。悬挂写 `悬挂在[@墙]（码）上，底离开地面`。一端接到写 `一端接到[@具]（码），和它一样远`。
侧面：门洞、窗洞写 `贴在画面{左|右}，开在这张墙上`。齐平写 `贴在画面{左|右}，与墙皮同一条线`。嵌入写 `贴在画面{左|右}，凹进这张墙，只见侧沿`。贴墙写 `贴在画面{左|右}，只见向室内的厚`。有长短边的再写长边与本格哪条轴平行，不写背靠。悬挂写 `悬挂在画面{左|右}这张墙上，底离开地面`。一端接到的那一端与被接的具落在同一远近或同一画面侧。
法线沿这张墙的法线，不沿靠近镜头。墙的成稿米是室内面。场径若是墙心，室内面比场径向房间收进墙厚的一半。门洞、窗洞、齐平、嵌入的法线米等于室内面。贴墙的法线米从室内面再向房间进入该具厚的一半。墙在正面时，这一差落在远离镜头那一轴。墙在画面左时，这一差向画面右收，不改纵深。墙在画面右时，向画面左收。与墙写成同一个米 = 失败。比这一档更靠近房间中心 = 失败。悬挂跟它的嵌入或贴墙，另有离地才写离地。背靠的具留在中部，只用背靠那一句。壁上的具写了背靠、短边探进房间 = 失败。同一具四格的壁关系词必须相同。只写沿本格的米、或只写沿着这张墙、不写壁关系句 = 失败。这一壁在镜头后，壁上的具整具不写；背靠的具仍在中部，写背靠的那一壁在镜头后。

同一面墙上落地或贴着墙根的口和贴，先沿这面墙排成一列。北壁从西到东，南壁从东到西，东壁从北到南，西壁从南到北。正对写「从左到右分别为[@A]（{码}）、[@B]（{码}）、[@C]（{码}）。」墙在画面右：从远到近仍是这一列。墙在画面左：从远到近从另一头读起。只写两头、漏掉中间 = 失败。桌、案、床、榻、沙发、椅、凳和床头柜不进这一列。吊挂另写「悬挂在这一面墙的上方。」每一口在同面句之后再写自己的沿本格 X线、Y线。门和窗走开合，不另写两端米。有 `窗台离地=` 或 `离平地=` 的，四格写同一个米。两键都没有，窗的 Z 不写离地米，高位写「高位，底离开地面」，落地写「落地」。禁止用墙高减窗高自拟窗台。

## 走向与长街
同一件：竖边与望向垂直的两格是一类，与望向平行的两格是另一类。0° 与 180° 同一类，两端对调。90° 与 270° 是另一类，两端对调。括号只供对账，成稿不写北端、南端、东端、西端。

| 开篇竖边 | 0望北 | 90望东 | 180望南 | 270望西 |
| :--- | :--- | :--- | :--- | :--- |
| 南北走向 | 从靠近镜头伸向远离镜头（北远南近） | 从画面左铺到画面右（北左南右） | 从靠近镜头伸向远离镜头（南远北近） | 从画面左铺到画面右（南左北右） |
| 东西走向 | 从画面左铺到画面右（西左东右） | 从靠近镜头伸向远离镜头（东远西近） | 从画面左铺到画面右（东左西右） | 从靠近镜头伸向远离镜头（西远东近） |

这张表只给第 1 类：墙、路、城垣、长街。有长边平行的主体走第 3 类，不抄这张表。正方走第 2 类。

**路、廊。** 开篇有 `竖边=` 和 `路宽=` 就用这两键。没有这两键、并且这一具是路、廊、街、巷、地面一条至少是另一条的两倍时，长边取较长的那一条，路宽取较短的那一条。室内四向皆封的地坪、地毯不走这两句。
竖边平行望向：`本格沿长侧看[@名]（{码}），长边从靠近镜头伸向远离镜头，一头近、一头远。靠近镜头这一头是路面的短边，短边与画面底边平行，左右一样宽。两侧铺面从镜头旁伸向远离镜头。` 这一头只写路面的短边。
竖边垂直望向：`本格沿短侧看[@名]（{码}），长边与画面底边平行，从画面左铺到画面右。左端和右端离镜头一样远、一样大。短边从靠近镜头伸向远离镜头，进深等于路宽，不铺成广场。` 左右按正面两倍。已经是路或廊的室内窄向再写：`进深等于这条长条的短边，正面墙就在近处，近端地面和正面几乎同深。` 地坪不写这句。

**长街两端。** 地面一条至少是另一条两倍时，长轴两端的坊、门、露台、牌坊是街端，长轴两侧的连绵铺面是侧列。东西长街：望东、望西顺着长边，望北、望南沿短边。南北长街把这四格对调。
顺着长边：`远处那一整面是[@名]（{码}）。中心在左右中线上。左端和右端离镜头一样远、一样大。从画面左铺到画面右。` 另一端的街端在镜头后方，不点名。侧列：`贴在画面{左|右}，从靠近镜头伸向远离镜头，一头近、一头远。靠近镜头这一头是铺面侧沿。`
沿短边：正面是这一侧的侧列，中心左右对齐，从画面左铺到画面右，左端和右端一样远。街端先按正面两倍。小于或等于才写：`在画面{左|右}端，只见这一端。左端和右端离镜头一样远、一样大。` 禁止一头近。侧面先点开篇已有的名字。
开篇只登记一根的灯杆，四格只写这一根。风格落点里的灯杆列没有对应主体时，四格不加第二根。
望北或望南把街端写成一头近一头远 = 失败。望东或望西把靠近镜头这一头写成短头或一扇门 = 失败。街端正面写成没有实墙 = 失败。连绵铺面在沿短边的格里中心写成画面左或画面右 = 失败。成稿不写「短头」「没有实墙」。

**纹路。** `纹路走向=正交无主轴` 时不旋。南北走向：望北、望南写「纹路沿远离镜头」，望东、望西写「纹路沿画面左右」。东西走向对调。四格同一句纹路 = 失败。写成 `[@地面]（{码}）纹路{沿远离镜头|沿画面左右}。`

开篇南北场径与东西场径不相等时，与望向平行的场径是纵深，与望向垂直的场径是左右。较长的轴垂直望向时，这一格更宽、纵深更短。禁止把较长的轴在垂直望向的格里画成通向远景的纵深。场径不在成稿里再写一遍。

## 家具与座具
靠墙的沙发、床、榻、矮几、饮水机、茶几，并且码在中部、`壁关系=背靠`：`背靠=` 四格是同一壁，件留在中部。壁码的柜、机柜、药柜、屏、门、窗不走这句。侧面：`贴在画面{左|右}。背靠这一侧的墙。` 然后写第 3 类轴句和画面走向，再写 `短边从这面墙探进房间。` 有椅面再写椅面朝画面哪一侧。正面壁：`偏在画面{左|右}，靠近这面正面墙。不到画面对侧。短边从这面墙探向镜头。` 椅面朝靠近镜头。这一壁转到镜头后，按脚深。背仍靠这壁，不改挂到另一壁。

床、榻在第 3 类轴句之外，写哪一头是床头屏、哪一头是床尾档。床头屏只在床头那一头，床尾档只在床尾那一头。偏在画面左时，这一头是其中一头，不到画面右的那一头是另一头。落在左右中线上时，画面左这一头和画面右那一头各是一头，两端不到画面边缘。南北走向、床头在北：望北靠近镜头是床尾档、远离镜头是床头屏；望南对调；望东画面左是床头屏、画面右是床尾档；望西对调。床头在南则这四句对调。东西走向把北南换成东西。不写北端、端甲、椅面朝向、几成。

挂桌的椅、凳、沙发：先写沿本格 X线、Y线，再写 `坐在桌子的画面{左|右|靠近镜头这一侧|远离镜头那一侧}，离开桌沿大约{缝档}，椅面朝画面{右|左|远离镜头|靠近镜头}。` 画面侧查旋轴的参照表。近侧朝远离镜头，远侧朝靠近镜头，左侧朝画面右，右侧朝画面左。边走第 2 类或第 3 类。离开桌沿的缝档用椅沿和桌沿的外沿差。椅的占地在桌的占地之外才写离开桌沿。开篇 `椅面朝向=` 已经另锁的，只旋那个世界向。不从短名推断朝向。
每一把单独一句。开篇 `对齐=沿接触边与参照中心齐`：接触边横在画面里时，写「沿这条桌沿与桌心左右对齐」；接触边顺着纵深时，写「沿这条桌沿与桌心一样远」。缝档仍写离开桌沿。同一 `在桌=` 的多把，四格都留在桌子的同一画面侧，离开桌沿的距离相同，整组中心与桌心对齐。0°/180° 同侧、左右分开。90°/270° 同侧、一近一远。禁止一格近侧、邻格改成左右分贴。各把各过脚深。开篇 `态=破坏` 的不写对齐，按倾倒或散落画。
椅面世界向：正北则望北朝远离、望南朝靠近、望东朝画面左、望西朝画面右。正南把靠近与远离对调、画面左与画面右对调。正东则望东朝远离、望西朝靠近、望北朝画面右、望南朝画面左。正西再对调。

驾驶座、操纵席、副驾默认挡风在南，椅面朝南。0度对向座位正面：椅面朝靠近镜头，挡风在镜头后，正面是舱尾那一壁。180度见椅背：椅面朝远离镜头，正面是挡风。开篇已经锁了 `椅面朝向=`，只旋那个世界向。不把挡风写成东壁或北壁。驾驶舱的光色照抄开篇。开篇没有应急红、幽暗、死黑，四格不另加。挡风外面的天光按开篇时段和气候写。开篇 `主副驾距=一臂` 时，四格都留下这一臂：0度与180度两座左右分开大约一条手臂，落在纵深中线上；90度与270度一近一远大约一条手臂，落在画面左右中线上。

开篇有 `主体分组=` 时，核心和每个成员都先写沿本格 X线、Y线。成员再写相对核心的画面侧、缝档、自己的走向和朝向。成员有自己的竖边时，按自己的边类写，不抄核心。不写主舞台，不写总句。核心入画却少一个成员 = 失败。
开篇有床头柜或床头凳时，它挨着床头，贴着床所在的那面墙，在床头外侧。远近和画面侧与床头相同。床在镜头后，柜也不点名。床入画则柜入画。

台面件每只单独一句。先写沿本格 X线、Y线，再写相对这张桌子的缝档。杯、盏与托写杯心与托心对齐。托在桌面上、开篇是双轴与参照中心齐时，写在桌心上，两轴都与桌心对齐。有对上的座位时，这一套沿桌沿与那把椅对齐。枕写沿床的短边与床心对齐，靠在床头。开篇 `态=破坏` 的不写这些对齐句。

| 开篇 | 0望北 / 180望南 | 90望东 / 270望西 |
| :--- | :--- | :--- |
| 南北分量同、东西不同 | 一只在桌心画面左，一只在桌心画面右，和桌心一样远；望南左右对调 | 一只更靠近，一只更远离，左右与桌心对齐；望西对调 |
| 东西分量同、南北不同 | 一只更靠近，一只更远离，左右与桌心对齐；望南对调 | 一只在桌心画面左，一只在桌心画面右，和桌心一样远；望西对调 |

东边那只：望北在桌心画面右，望东更远离，望南在桌心画面左，望西更靠近。西边那只对调。北边那只：望北更远离，望东在桌心画面左，望南更靠近，望西在桌心画面右。南边那只对调。四格都写成画面左和画面右 = 失败。桌子入画却漏一只 = 失败。

宿主栏或旗座入画的格，每一面具名旗单独一句，只写沿本格 X线、Y线和 Z。色相、图样、形状留在【主体外形】，四格不写。宿主在镜后，旗不点名。

## 开合
看见这扇的每一格都写开还是合，词与开篇相同：全关、半开或全开。四格开闭词相同。
平开门、平开窗、柜门写铰链和门栓，门栓在铰链对端，门把手在门栓这一端。四格铰链是开篇同一个世界端，随望向旋成画面左、画面右、靠近镜头或远离镜头。
平移、左滑、右滑、推拉、闸门、液压门、升降门、卷帘门不写铰链，不写门栓，不写门轴，不写双侧。平移和推拉的停端用开篇 `停端=`，四格把这同一个世界端旋成画面侧。禁止四格都写左侧。停端换了世界端 = 失败。闸门四格保持同一扇门洞轮廓，禁止改成拱门，禁止另长成第二扇口。一面墙只有开篇的那一扇。无口的墙不画门。
窗帘、窗纱、帘、百叶用同一套开闭词，留在所在壁，不进中部。不写铰链、门栓、扇停在、门洞。全关：帘布留在窗洞里，不写帘外景物。半开：帘停在半程，只露出半面。全开：单幅收到开向那一侧；双开的两幅分别收到两端。固定幕墙、落地弧形玻璃不写开闭。

平开才用下面两句。正对：`门洞在这面正面墙上，左端是{铰链|门栓}，右端是{门栓|铰链}，两端一样远。` 在画面左或右：`门洞贴在画面{左|右}，靠近镜头的一头是{铰链|门栓}，远离镜头的一头是{门栓|铰链}。` 东壁和西壁：望北南端靠近、北端远离；望南对调。南壁和北壁：望东西端靠近、东端远离；望西对调。90° 与 270° 左右对调，靠近端和远离端也对调。
平移和推拉：正对时 `门洞在这面正面墙上，扇停在画面{左|右}，两端一样远。` 贴在侧面时 `门洞贴在画面{左|右}，扇停在{靠近镜头|远离镜头}的一头。`
平开外开且全开：房间里看不见门板，门栓这一端是空门框，铰链端的门板在墙外。里开且全开：门板折进房间，贴在铰链这一头的内墙。半开：门板停在半程。全关：门板留在洞口里。整扇在镜头后方时，侧面不点这扇门的名。

**框中画。** 封墙上的门洞、窗洞看出去的远景，写成嵌在这扇框里。`围合=敞` 的整面远景是正面本身，不套框中画。落地玻璃、幕墙是封，不走敞。`开闭=全关` 且不透时不写门外景物。`透=透` 的固定玻璃不是全关，正对或贴在侧面时写透过这面玻璃看见外面。这一壁在镜头后，这一格不写外面，也不把这片外面写进别的门洞。`洞外=室内` 的全开或半开写 `洞外是室内`，不写天际、城市、天空。`洞外=室外` 且该壁在正面：`[@门]（{码}）框内是框中画：{远景短词}，嵌在这张正面墙的洞里。` 窗同理。该壁在侧面：只有能斜看进洞时才写 `侧沿框内是框中画：{远景短词}，嵌在这张侧墙的洞里。` 四格远处都出现同一片天际 = 失败。色彩说明里的背景只在点名的那一壁入画时看见。

## 楼梯
开篇有 `低端=` 和 `高端=` 才写。左右两端按正面两倍。四格写 `低在` 和 `高在`，不回写东南西北。

| 低端=西，高端=东 | 低在画面左，高在画面右 | 低在靠近镜头，高在远离镜头 | 低在画面右，高在画面左 | 低在远离镜头，高在靠近镜头 |

点名某一层必须写「从低到高数第{n}层」或「从高到低数第{n}层」。同一架只用一个方向。从低到高时贴地最低是第1层。从高到低时最高一层是第1层。禁止只写第{n}层、第{n}级。镜头在哪一头不改层号。
贴墙且竖边与望向平行：梯帮贴着宿主墙的画面边内侧。靠近镜头的一头是低端时，写成从低到高数第1层，或从高到低的最后一层。靠近镜头的一头是高端时对调。远离镜头的一头是另一头。0° 与 180° 必须一格变高、一格变低。
贴墙且竖边与望向垂直：`[@梯]（{码}）贴在正面墙上。` 低端和高端各在一个画面角，踏步从这一角逐级升到那一角。右下到左上用 `\`，左下到右上用 `/`。不写两端同深，不写与画面底边平行，不写从画面左铺到画面右。
宿主墙在镜头后的那一格，整跑不入画。贴东墙、低端在南：望西不画。贴西墙、低端在南：望东不画。

## 构图
每一格在上之后、光学段之前写 `构图：方法={对称|中心|纵深|框中|对角线}，倾向={开篇倾向}。`
方法用开篇已经写下的构图方法。开篇只有倾向时，归入这五个词里的一个。倾向照抄开篇。不点名任何主体，不写前景、中景、远景，不写纵深色层，不写米，不写东南西北。四格可以同一句。

## 光
开篇【光学说明】整节不抄进成稿。主光、辅光、点缀每一格都要转写。缺的不另起一盏。光比、色温、柔硬、焦段、景深、半影、色板只在共享句。
`高度=` 已有则四格同一档。未写时按时辰：寅、卯、辰 = 低；巳、未、申 = 中；午 = 高；酉 = 低；戌、亥、子、丑 = 无日盘。高度不随望向改。低 = 见盘格贴远天近地平，影长。中 = 远天中带。高 = 天顶下，影短。无日盘不画金盘。这是日头或光线进入的角度。源是某一扇已登记的窗时，源体画布位的高低用窗位：高位、高侧窗写高，窗台在坐高附近写中，落地窗写低。不用时辰把高窗写成低。光线角度仍用时辰，窗位和光线角度可以不同。
下表的近 = 靠近镜头 = 天体盘在镜头后，画面内不见源体。远 = 画内，金盘在远离镜头那一侧。见盘最多两格，两格的左右偏能回到同一个世界向。90° 与 270° 按本格重算，不对调另一格的光句。与望向相差 180°：源在镜头正后，写对齐。

点缀的宿主入画才写；宿主在镜后，这一格不写点缀。点缀、照亮里点到的具，左右和纵深等于这一格该具位置句。左右轴零偏移写在画面左右中线上，在画面左写画面左，在画面右写画面右。纵深轴零偏移写在纵深中线上，写了靠近镜头才写靠近镜头，写了远离镜头才写远离镜头。位置句是纵深中线，光句写成靠近镜头或远离镜头 = 失败。位置句是画面左右中线，光句写成画面左或画面右 = 失败。照亮只点本格入画的主体，画面侧用这一套，不另写纵深。有 `屏面朝向=` 的，另写屏面朝向的画面侧：朝着镜头、背对镜头、朝画面左或朝画面右。这一句只旋开篇那一向，不跟着点缀改。纵深光层：近层是靠近镜头这一侧已经入画的受光，远层是远离镜头那一侧已经入画的受光。纵深中线上的具不写进近层或远层。望向对调时近层和远层对调。封墙无开口时，不写成从这面墙射入。逆光不改开篇色相。`体积光=有` 时四格同一条光束，只旋轴。`体积光=无` 时四格都不写光柱。

每格光学段都有：`光源=`、`源形=`、`源体可见=`、`源体画布位=`、`高度带=`、`光线从`、`射向`、受光句、`影子投向`、辅光句、`纵深光层：近层=`、`远层=`。

- 镜头正后：`光源={开篇主光名}，源形={开篇源形}。源体可见=镜头后。源体画布位=镜头后、对齐、靠近镜头、高度带={低|中|高}。画面内不见源体。光线从镜头正后、{低|中|高}角度进入画面，射向远离镜头。靠近镜头的地坪全幅亮。正面远景背光。影子投向远离镜头。`
- 画内：`光源={开篇主光名}，源形={开篇源形}。源体可见=画内。源体画布位=画面{左|右|对齐}、远离镜头、高度带={低|中|高}。光线从该画布位射向画面{对向}、靠近镜头。照亮={本格入画的开篇照亮对象及其画面侧}。影子投向画面{对向}、靠近镜头。`
- 同深：`光源={开篇主光名}，源形={开篇源形}。源体可见=画内。源体画布位=画面{左|右}缘、与正面同深、高度带={低|中|高}。光线从该缘射向画面{对向}。照亮={本格入画的开篇照亮对象及其画面侧}。`
- 辅光：`辅光={开篇辅光名}。从{本格旋出的画面来向}托起{本格入画的暗部}。` 点缀宿主入画时：`点缀={开篇点缀名}，在{画面左|画面右|画面左右中线上}、{靠近镜头|远离镜头|纵深中线上}。` 两个词分别抄该具位置句的左右轴和纵深轴。

## 自检
只核【四向拼图】。开篇缺键不在这里补。
- 只有【四向拼图】。共享句是光比、色温、柔硬、焦段、景深、半影、色板，各写一次。四格没有这些词，也没有外形、材质、纹样、颜色、柱径米数、旗色、牌匾文字、主冷暖、纵深色层。四格没有新增主体，没有删掉设计稿里的主体，没有改大小、纹样、配套和配饰。格子里没有参照，没有出图序。文字四格一次写完，没有按上一格改写下一格。
- 四格标题按 0 左上、90 右上、180 左下、270 右下。每格有角标、画布坐标、五面、件数核销、构图、光学段、镜后整包不入画。左右侧写了不可见的，行仍在。
- 四格同一原点。画布坐标的 X线、Y线、正方向与旋轴四句一致，Z向上。入画件的位置只有沿本格 X线、沿本格 Y线和 Z。同一对米写了两句 = 失败。望南相对望北、望西相对望东，偏移侧已对调，正面已换成对向壁。零偏移的中线种类未改。
- 有长边平行的主体走第 3 类，含机床、滑道、轨道、机组，不限桌椅床。正方走第 2 类。墙、路、城垣、长街走第 1 类。室内四向皆封的地坪没有写成路面、路宽、两侧铺面。中部机床、滑道、轨道没有走长条同一套。同一件叠了两类句子 = 失败。第 3 类先写「长边与本格X线平行」或「长边与本格Y线平行」，短边与另一条轴平行，下一句写画面走向。长边落到画面左右轴写「长边横在画面里。短边顺着纵深。」落到纵深轴写「长边顺着纵深。短边横在画面里。」望北与望东的画面走向不同。四格同一句画面走向 = 失败。只写轴句 = 失败。位置中线没有被当成走向。画面走向没有写成从画面左铺到画面右或一头近一头远。只写沿着 = 失败。放在另一具面上的，写出那一具的 `[@名]（码）`。成稿单独出现「宿主」= 失败。
- 脚深：两端都大于脚深的不点名；只有靠近原点的一端在脚前才写只见这一端，含轨道、机床、滑道和成员；两端都在脚前的整具照写。一端在脚前却整具划出 = 失败。四格中部除掉脚后划出的是同一批。
- 看得见的面，`件数=` 等于这一面的 `[@]` 个数。点名+划出=编号表重数；中部再减去改入。开篇 n 没有抄与编号表不合的面件数。划出大于 0 必须有划出名，个数等于划出，这些码不在这一面正文里。中区原有的件没有改入。壁上划出=0 却写了改入 = 失败。
- 大于正面纵深 2 倍的那一侧只有不可见。街端不写一头近，成稿没有「短头」「没有实墙」。一侧不可见时，正面没有从画面左铺到画面右。城垣接到城门楼时写接到这座楼为止，这座楼没有一头近。
