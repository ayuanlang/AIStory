## 1. 只读主环境，按 Beat 挂衍生
空间依据=已注入【主环境】0°轴/四向+中心/活动空间/固定清单 +【未落清单】。逐拍推 `{N}度{主名}`（可多个）；不得先选角再回头补实体。
**方位**：俯视顺时针；`0° → 90° → 180° → 270° → 0°`；对向=`(N+180)%360`；画左=`(N+270)%360`、画右=`(N+90)%360`。禁逆时针或第一人称左右推角。`view_angle_from_main` 的 N 服从本约定。
当前 ENV 必须是已声明 `{N}度{名}` 或状态衍生，不得挂裸主名。

## 2. 衍生环境（按内容建）
> **不变式**：所属主环境固定实体不增/不减/不矛盾；仅可见性可变。白名单只来自主环境登记；主环境有实体≠本角可见。

### 2.1 何时必须声明新角（衍生最小化）
须声明新角=任何真正反打/读对手｜切镜头致正背面档位变化｜背对须读正面内容｜越轴｜>90°｜门窗内外/POV/状态｜**异排且异向**｜§2.8 仰天/屋顶/变形。前向驾驶舱“异排但同向”不属于本项，按驾驶舱槽位可见性声明0°/180°/90°/270°读角。Insert/CU/同侧过肩且档位/扇区不变→沿用父、禁新行。无 Beat 覆盖的冗余角不建。

### 2.2 每行必填
每衍生行必填：名 / `view_angle_from_main` / 触发 / `spatial_axis` / `lens_profile` / `axis_crossing` / `empty_view_delta`，以及 `活动适配` / `可见内容白名单` / `可见边界` / `不可见内容`。头尾双锚已在主环境声明。禁止写前中后景空镜层次、材质光色细参、四向拼图成稿。
- `活动适配=…`：本角后景/表演区可承载什么动作。
- `可见内容白名单=…`：本角允许进入画面描述的**全部具名固定实体/出入口/景外锚及其可见面**（轻量名称+面）。**舱内**：白名单只锁座椅/挡风/方向盘等固定面，**不授权乘员脸**；`0度{舱}`禁写`后排座:正面`或任何人脸（0°望挡风时后排可见面=靠背背面）。**`90/270度{舱}` 须列全部座位**（驾驶座|副驾|后排各座，有则全写）并标近镜头侧/远侧可见面，禁只写半舱。
- `可见边界=…`：画幅边界与禁止越出的对向/机位后方。**`可见边界=全画幅`无效**——必须用具名实体/结构写清左界、右界、上界、下界/近端截断。
- `不可见内容=…`：与本拍易混淆的对向实体/不可见面。
**衍生主名段必须=所属主环境名。**

### 2.3 先做 Beat→衍生覆盖矩阵，再设计衍生（最高）
逐 Beat 盘点本拍必须在画面中成立的全部内容：①角色世界锚/承托面（`柜台后|桌旁|椅上|门内`）；②动作交互固定实体；③手持/桌面/附着道具及须读可见面；④环境特写/Insert对象；⑤出入口与运动终点；⑥特效命中实体；⑦背景叙事锚。为每项写`必须可见=是|仅画外方向D|可暂不可见`，再选择/新建能完整覆盖**同一拍所有必须可见项**的衍生 ENV。禁止先随便选 ENV 再从主环境补剧情实体。
- **必见集**：画面明写的主体/动作/交互/挂靠/位移路径节点/投射弹道与命中面才进 R；纯声音、对白提到、望向画外标 D。成稿 `R={…}` `W={…}` `R−W=∅`。
- **选角序**：`R完整覆盖 > 交互面可读 > 露脸可拍 > 守轴 > 切换成本`。**0 度无优先权**；空镜角只取 0/90/180/270。
- **剧情覆盖衍生允许按需建角**：可建 `{N}度{主环境名}_{剧情覆盖短名}`（N 取 0/90/180/270）。若物理上任何单角无法完整看见，须分别声明两角，并在矩阵标`跨对向=拆拍`。
- **挂靠实体同显**：角色须`站在柜台后/坐在桌旁/坐在椅上`时，对应柜台/桌/椅必须命中该拍选用角白名单；对向不可见则另建可见该锚的衍生。
- **交互链同显**：文戏已写的取用/开门/递接（含左右手、承托面、物件）必须同时命中`执行者+承托/挂靠实体+道具+被读取的面`。仅写`桌区:全部面`不能隐式授权酒盏。触达对象须能在开拍画面为 V。不补写取用过程。
- **同框锚须设计进角（Two-Shot/多人）**：每人世界锚/承托面须同属某一声明角的白名单+活动适配。驾驶舱后排×司机同框只可规划 `90/270`，该角须近镜头侧+全部座位。换角只切换半空间，不创造物理同框。
- **一拍需求跨对向则分角**：必见项分属 N 与 N+180 时，任何单一衍生都不得同时收录；须分别声明两个角。

### 2.4 主环境对向位零可见（最高；固定环境实体）
对当前衍生观察轴 N，主环境四向中精确位于 `(N+180)%360` 的对向边界实体及其附着/承托物全部在机位后方，必须列入`不可见内容`，与白名单交集必须为 ∅。禁止因“写背面/广角/稍带到”把对向位实体塞回画面。
- N=0：180°位柜台/酒架及承托物全不可见。
- N=180：0°位大门及门外本体全不可见。
- N=90：270°位楼梯/回廊全不可见；N=270 反之。相邻 ±90° 仅在`可见边界`明示贴边小部分时可入白名单，不能整面入镜。
- **舱内侧向例外（仅交通工具内舱 90/270）**：机位贴一侧窗看对侧窗时，近镜头侧门框/窗框+该侧全部座位侧面须进白名单；全部座位都要描述。对向零可见只约束舱外对向街景，禁止把近侧半舱座位整排进`不可见内容`。

### 2.5 轴线
先列 R，再为覆盖 R 的真实机位建 `{N}度…`。禁轮角、禁无拍冗余角。定 0° Master 后写本场 `spatial_axis`，后续守轴：

| `axis_crossing` | 何时允许 | 要求 |
| :--- | :--- | :--- |
| `None` | 同侧微调、非反打 Insert/CU、沿用父观察侧 | 不跨 `spatial_axis` |
| `PlannedReverse` | 正反打/读对手（沿轴线对向，典型 ±180°） | 触发须含 `N_对手→(N±180)%360`；左右屏关系与轴线闭合 |
| `MotivatedCross` | 仅剧情明文动机越轴 | 须写动机一句；禁无动机为「换个角好看」而跨轴 |

禁：无动机在轴线两侧来回跳；把越轴标成普通反打；为填满清单而建跨轴角。

### 2.6 反打 ENV / 状态衍生 / 出入舱触发
- **反打 ENV**：先定所需背景/对手可读面，再算 `N_对手→(N±180)%360`；该行白名单须能看见所需内容。`axis_crossing=PlannedReverse`。非反打 Insert 不另建行。
- **状态衍生**：`{主}_{状态}`；`{N}度{主}_{状态}` 每行仍须写 `所属主环境={主}`。
- **出入封闭舱**：仓外/仓内两块主环境已由环境规划声明。本文件须为两族各声明衍生；仓外族白名单含载具外部本体+各具名门扇；仓内族按载具惯例写座舱。声明触发名=`入舱切主环境|出舱切主环境|回切仓外主环境`。换主名≠反打。
- **闪回/蒙太奇切主**：各主环境各挂各衍生族；声明触发名=`闪回切主环境|闪切切主环境|蒙太奇切主环境|回切当下主环境`。

### 2.7 按背景内容选角
依据=后景应见内容 ↔ 候选行`活动适配+白名单+可见边界`。禁无据粘`0度`、机械轮角。

| 画面事实 | 应挂 | 禁挂 |
| :--- | :--- | :--- |
| 背对/面向后景（内侧/王座） | 可见王座/内侧的角（常`180度…`） | 可见大门的`0度…` |
| 正面朝镜、身后/后景应见大门；或自背景门迎入 | 可见大门的角（常`0度…`） | 可见王座的对向角 |
| 背对向内走、门近端/身后 | 可见内侧/王座（常`180度…`） | 可见大门的`0度…` |
| 外景航拍/山巅建立 | 外景族`{N}度…` | 厅内`0度…` |

选 ENV：①定后景内容 → ②定位 N°+守轴 → ③取`活动适配`匹配行 → ④背景锚∈半空间 → ⑤与正背面/反打交叉 → ⑥核同 ENV 连续次数（≤3）。

### 2.8 特别衍生（仰天 / 屋顶 / 变形）
仅当空镜资产本身必须仰看天花/天空，或必须变形透视时另建一行。Beat 只锁`镜头角度=仰拍/虫蚁/航拍`而空镜仍是平视宫格 → **不建**特别行。
名=`{N}度{主}_仰天`｜`{N}度{主}_屋顶`｜`{N}度{主}_变形`。N 仍取所属半空间 0/90/180/270。`类型=特别`。
**`特别表述=`（仅本类必填；普通四方行禁止写）**=`仰天|屋顶|变形:{一句可核销空镜}`。
例：`仰天:满幅夜空与檐口剪影，地面仅近端截断`｜`屋顶:仰看梁架与主灯铺满上半幅，四壁收为画缘`｜`变形:荷兰角地平线左低右高，立柱倾斜压迫`。
❌无据建特别行｜❌普通行写`特别表述=`｜❌把仰拍对白主拍建成仰天空镜。

## 3. 选用节奏与过肩
- **连续≤3**：同一衍生名连续拍不得超过 3（可稍后切回，每段仍≤3）。合理换角=`R−W=∅`+对向零可见+守轴+非无动机越轴。满 3 优先切已声明他角；现有角皆不能覆盖才补侧向。
- **例外（须写依据）**：①本场≤3 拍；②转身且半空间未变（计入连续）；③唯一覆盖角（标`唯一覆盖角`+R−W）；④连续位移切角破动量最多+1。武戏快链豁免。
- **读对手 vs 同侧过肩**（`关系角=过肩|过腰|OPC` 时必须写`OTS类型=`）：

| 类型 | 判定 | ENV |
| :--- | :--- | :--- |
| **读对手 / 反打** | 越过近侧看对方脸；或对白换可读方；背景半空间翻转 | 挂对向 `{N}度…`（`PlannedReverse`）；`OTS类型=读对手`；`ENV变=是` |
| **同侧过肩** | 半空间不变；近侧只作框 | 沿用父 ENV；`OTS类型=同侧过肩`；禁标反打 |

❌读对手却同父 ENV｜❌同侧过肩标反打。

## 4. 景别与构图
每拍须同时锁环境 + 机位 + 景别构图：拍摄键写【取景锁定】，推导键（含`选择证据=`）写【场记分析】。
**选型序**：场核+本拍 → 功能 → ENV → 机位 → 景别 → 构图 → 核跨度 → 写四轴证据。禁通场 `MCU+三分+平拍` 无据交差。对白/交付/动作空间/画幅/`-`/`~`→§4.5；机位→§4.6。

### 4.1 景别（七档完整；必须与剧情匹配）
闭集（成稿只写英文档）=`EWS|WS|FS|MS|MCU|CU|ECU`。原文远近词（大远景/远景/全景/中景/近景/特写/大特写）映射本表并写`原文景别=`。原文`航拍/俯拍/仰拍/平拍`写入`原文角度=`与`镜头角度=`，不占景别档。每拍须能指回本表画幅覆盖。

| 档 | 中文 | 画幅覆盖（可核销） | 典型剧情功能（须命中其一） | 禁用于 |
| :--- | :--- | :--- | :--- | :--- |
| **EWS** | 大远景 | 人极小或不可辨；环境/地貌/城廓/阵势为主 | 开场建立、宏观规模、孤绝渺小、环境文学空镜、满幅特效/战场余波 | 口型对白主拍；贴身交付；读脸反应 |
| **WS** | 远景 | 人可辨轮廓+全身；空间关系/动线可读 | 空间交代、走位入场、群像关系、对峙拉开、空镜主景 | 口型主拍；ECU 级细节冒充远景 |
| **FS** | 全景 | 主体从头到脚完整；可带近距环境 | 全身动作、入座起身、打斗起势、空间交付同框、礼法站位 | 只拍脸的反应；道具文字 Insert |
| **MS** | 中景 | 约腰/桌面以上；手势+半身关系可读 | 关系镜、动作+对白同相、双人/多人同框、听者反应默认 | 须读眼部微表情却裁掉脸；须见全身间距却裁脚 |
| **MCU** | 中近景 | 胸/肩以上；口型+表情可读 | 对白加压主拍、过肩/反打读脸、隐忍审视 | 空间交付主相位；数步对峙同框；群演主拍 |
| **CU** | 特写 | 脸或等大物件为主；肩可入画缘 | 情绪砸点、听者反应链、关键道具首次可读、`~`精髓拍 | 数步同框无交代；只拍施动者丢掉受者；群演脸 |
| **ECU** | 大特写 | 眼/唇/手/伤口/文字/机关局部填幅 | Insert、契科夫枪、屏/信字样、命中局部、细节特写参考 | 口型对白主拍（唇部 ECU 仅停顿/欲言又止）；走位关系 |

- **`剧情匹配=`**（每拍【场记分析】必写）=`建置`｜`走位`｜`对白`｜`交付`｜`反应`｜`特写`｜`空镜`｜`宏观`。建置/空镜→EWS/WS；走位→WS/FS；对白→MS/MCU/CU（口型须面部可读）；交付→FS/MS 同框施受；反应→MCU/CU；特写→CU/ECU；宏观→EWS/WS。
- 贴身→MCU/CU；数步对峙→WS/FS。
- 交付/对白/画幅细则→§4.5。非反打收紧沿用父 ENV；读脸反打切可读角。
- 原文`△近景/特写`须落入对应拍并写`原文景别=`。
- 环境文学空镜：独立拍，WS/EWS，ENV 挂该文学主景。
- **群演**：只进 `EWS|WS|FS`；禁 `MS|MCU|CU|ECU` 群演主拍（宏观满幅例外，仍禁单人格特写）。
- `MCU|CU|ECU` 不得标`纵深层=前中后同时可读`。

### 4.2 构图档（主档+可兼完整；必须与剧情匹配）
主档闭集必选一=`三分`｜`中心`｜`纵深`。可兼闭集可多或无=`对称`｜`框中框`｜`引导线`｜`负空间`。禁止另造主档名（黄金分割/对角/三角等映射回本闭集：偏置→三分；居中仪式→中心；前后层→纵深）。
成稿每拍【取景锁定】写：`构图=三分|中心|纵深｜可兼=对称|框中框|引导线|负空间|无｜主体落点=画左三分|中央|画右三分｜留白=视线前|运动前|无｜纵深层=前中后同时可读|浅层单焦`。

| 类型 | 层级 | 可核销画面结果 | 典型剧情功能 | 禁 |
| :--- | :--- | :--- | :--- | :--- |
| **三分** | 主档 | 主体落画左/画右三分交点；对侧留白 | 对白交流、对峙分列、视线/运动引导、常规叙事 | 标三分却钉中央；无留白的假三分 |
| **中心** | 主档 | 主体或对峙轴钉画面正中 | 仪式/权力/Iconic、对峙轴、揭示砸点、对称殿堂 | 无仪式/权力/砸点依据的闲聊对白通场中心 |
| **纵深** | 主档 | 前/中/后至少两层同时可读 | 空间层次、走位避障、门—桌关系、前后排对戏、建立空镜 | MCU/CU/ECU 假标多层；必读层不可见 |
| **对称** | 可兼 | 左右或轴对称可检索 | 殿堂/礼法/对仗/仪式 | 无对称结构却空标 |
| **框中框** | 可兼 | 门洞/窗/廊/肩/器物形成内框 | 窥视、隔障对话、进出门槛、细节特写收束 | 无可见内框却空标 |
| **引导线** | 可兼 | 道路/廊柱/队列/桌沿把视线导向主体 | 入场动线、队列、通道压迫 | 无线可循却空标 |
| **负空间** | 可兼 | 主体占比小、大块空/暗/远景压人 | 孤绝、被监视、渺小、低点放大 | 热闹群戏无据大留空 |

- 对白/对峙默认三分+视线前留白；仪式/Iconic→中心；走位/前后层→纵深；窥视/门槛→框中框；通道→引导线；孤绝→负空间。可兼须有可见依据。
- `主体落点=`只约束取景，不改角色世界落位。场级【构图规划】主档须被关键拍复现或写例外。
- 有视线/运动→`留白=视线前|运动前`；中心钉死可`无`。`可兼=负空间`时留白字段仍须写方向或无。
- **留白须可核销空边**：`视线前|运动前` = 该方向有 Head Room（头顶）与 Lead Room（视线/运动前）可量空边；`无` = 中心钉死可贴顶但禁裁颅。禁标留白却贴边满幅。

### 4.3 场级【构图规划】
```
【构图规划】主档=三分|中心|纵深｜兼档=…|无｜关键=B…｜空镜=…|无｜道具特写=…|无｜Iconic=…|无
```
主档=本场大多数叙事拍的默认框法；关键/空镜/道具特写/Iconic 拍须写出偏离或强化依据，不得与场级主档无故打架。

### 4.4 跨拍切换
每拍【场记分析】写`上拍景别=`与`跨度=`。`同级`＝同档；`邻档`＝沿 `EWS↔WS↔FS↔MS↔MCU↔CU↔ECU` 移 1 档；`越级`＝跨≥2 档，须写`越级:{依据}`。默认只允许同级/邻档。
**越级闭集**：①原文`△特写`/`细节特写参考`；②卖点/高潮/`~`；③Insert；④空镜/宏观后切特写陪衬（或回切）；⑤交付拉开；⑥反打只为读脸且落幅仍同级/邻档——**反打不是 EWS↔CU 的依据**。
对白链两侧同级或邻档，只翻 ENV/`主体落点`。构图主档随功能变，禁无功能轮跳；反打默认同主档只翻落点。
近景链满 3 且下拍有走位/交付须拉开；远景链满 2 且已入对白须收近（宏观例外+依据）。
关系角≠景别：过肩对白另锁 `MS|MCU|CU`；交付 Two-Shot/过腰另锁 `MS|FS`。

### 4.5 选型专规
#### 4.5.1 对白景别
口型主拍、可见 OS/V.O.、反打/过肩读脸、反应、微表情 → **`MS|MCU|CU`**（过肩对白典型 MCU）。禁 `EWS|WS|FS` 常规口型（宏观/特效满幅例外+依据）。听者与说话拍同级或邻档。
3 人+：具名角色各锁单人/过肩近档。Walk-and-Talk 锁 `MS`（可邻 `FS`）。自白/画中画说话人锁 `MS|MCU|CU`。

#### 4.5.2 画幅
读 `Aspect Ratio` / `aspect_ratio`。未注入按横屏。写入【景别构图综合】`画幅=`。
- **竖屏**（height≥width）：每条口型锁该说话人 `MS|MCU|CU`；多人分拍（可过肩）。建置可 WS/FS，下一对白须收近。Walk-and-Talk 锁 `MS|MCU`。
- **横屏**：允许 Two-Shot / MS；Walk-and-Talk 可 `MS|FS`。仍禁 EWS/WS 口型。
- 交付按 §4.5.3 锁更远档，竖屏不得为「禁 Two-Shot 口型」裁掉间距。

#### 4.5.3 空间交付拉开
须同见施受+轨迹+间距（指鼻/递物/扇耳光/拍肩/抵喉/抓领等）时：禁 `CU|ECU` 单人裁对方；锁 `FS|MS`；`剧情匹配=交付`。竖屏优先 `MS|FS`，禁双人 CU 硬塞横向指鼻。

#### 4.5.3A 动作空间（物理路径可读）
文戏已写的位移/投射/交付须进本拍 R，且 `活动适配` 能承载该路径。
- **走位**：起点锚+路径节点+终点 ∈ 白名单；一拍装不下曲折绕障 → 拆拍或标跨对向。`剧情匹配=走位` 时 `纵深层` 跟路径层。
- **投射**：出手点+弹道经过+命中面须同角可见，否则拆拍。
- **近身接触**（牵手/拥抱/接吻/缠斗）：锁 `过肩|过腰|Two-Shot` + `FS|MS` 或局部特写；禁 EWS 扛复杂缠绕。
- **手部精细**（写字/弹琴/系扣）：锁 `CU|ECU` 手部或切脸，禁远景细描手指。
- **形变/进食**：禁一拍远景走完 A→B 全程；拆 `~` Insert 或邻拍。

#### 4.5.4 特写配额与卖点
常规有戏场（≥3 Beat）：`CU|ECU` 拍约占本场 **15%–25%**（纯过场/宏观满幅场可低于此，须写依据）。卖点/高潮/低谷/【高潮与核心情绪点】/`细节特写参考`/桥段击中·命中·法攻效果/过程穿插表情，须落入已锁 `MCU|CU|ECU` 的拍（主高潮优先「角色近景 + 环境 Insert」分拍或紧邻拍）。**禁止**把卖点/高潮/低谷全程压在 WS/MS。`~` 精髓拍必须锁 `CU|ECU`。写入【景别构图综合】`特写配额=`。

#### 4.5.5 拍型 `-`/`~` 与快节奏
| 上游拍型 | 景别锁档 | 禁 |
| :--- | :--- | :--- |
| **`- Beat`** | 快交代偏 `MCU`（对白快交代）或跟功能（走位/交付仍 WS/FS/MS） | 把交代拍锁成全程 ECU；用 EWS 扛近身快戏 |
| **`~ Beat`** | **必须** `CU|ECU`（Insert→ECU） | 用 WS/FS 冒充砸点；精髓拍锁远景 |
| **快节奏打斗/追杀** | 贴身链偏 `MCU`；命中/效果可邻档 `CU`；宏观满幅跟 §4.5.1 例外 | EWS/WS 扛近身连击无依据 |

#### 4.5.6 局部特写与远近备档
局部特写须服务本拍功能（唇/眼/手/字/伤口）；禁无据孤立凝视。成人向局部仅成人角色，须服装/剪影覆盖，禁裸露与未成年人性化。
关键/卖点/弧光拐点：须有 EWS/WS 或 CU/ECU 至少一档落地（可分拍），禁通场只锁 MS。

### 4.6 机位（俯仰 + 关系角）
成稿每拍【取景锁定】写：`镜头角度=`｜`关系角=`｜`OTS类型=`｜`近侧框主=`｜`主拍对象=`｜`主观角色=`。
【场记分析】写：`角度动机=`｜`原文角度=`｜`上拍镜头角度=`｜`角度跨度=`。原文平视/仰视/俯视/OTS/鸟瞰写入`原文角度=`并映射本闭集（成稿键只写短词）。

#### 4.6.1 俯仰
| 档 | 原文同义 | 可核销 | 跟 `角度动机=` | 禁 |
| :--- | :--- | :--- | :--- | :--- |
| **平拍** | 平视 | 眼高/胸口，镜头水平 | 对白默、常规建置、过肩反打默认 | 压迫/渺小通场平拍无据 |
| **仰拍** | 仰视 | 自下向上；须高度锚（膝/腰/桌沿） | 压迫、崇高、巨物、权威 | 借仰拍改跪姿；口型用虫蚁冒充 |
| **俯拍** | 俯视 | 自上向下；**非航拍** | 压迫、布局、桌面 | 室内桌面升航拍 |
| **微仰** | — | 略低于眼高 | 轻微权威 | 无据通场 |
| **微俯** | — | 略高于眼高 | 桌面、轻度弱势 | 无据通场 |
| **虫蚁** | 贴地仰 | 贴地/桌面仰 | 渺小、倒地、贴地道具 | **口型主拍** |
| **航拍** | 鸟瞰 | 远高于头顶 | 宏观 | **口型主拍**；作 0°轴 |
| **主观** | POV | 机位=某角色眼位；主观者画外 | 窥视、看见 | 无看见依据；该主观者口型 |

- 口型主拍默认`平拍`；禁`航拍`/`虫蚁`/该主观者口型。
- 反打默认同俯仰；反打不是换俯仰的依据。
- **高度锚（须可核销）**：平拍=眼高或胸口；微仰/微俯=略偏眼高；仰拍=膝/腰/桌沿等具名高度；俯拍=相对头顶的高度差（非航拍）；虫蚁=贴地/桌面；航拍=远高于头顶。可写入`角度动机=`句内。
- 主观须点名`主观角色=`。
- 原文「俯拍大远景」→`景别=EWS｜镜头角度=俯拍`（宏观则`航拍`）。
- 峰值/压迫/渺小/崇高须由`镜头角度=`+`角度动机=`核销；口型可写「平拍保口型」且邻拍/构图已加压。禁无据`平拍｜对白默`交差。

#### 4.6.2 关系角
| 档 | 可核销 | 跟 | ENV |
| :--- | :--- | :--- | :--- |
| **干净** | 主拍独自满幅 | 单人/Insert/空镜 | 跟本拍衍生 |
| **过肩** | 越过近侧肩看远侧脸 | 对白反打、读脸 | §3：`读对手`换对向；`同侧过肩`沿用父 |
| **过腰** | 越过近侧腰看远侧 | 交付、桌面递接 | 同过肩 |
| **OPC** | 越过近侧半身取远侧 | 隔人窥视 | 同过肩 |
| **Two-Shot** | 两人同框均可读，无「越过」 | 交付同框 | 两人锚同属该角白名单 |

`关系角=过肩|过腰|OPC` 时写`OTS类型=`（判别只认 §3）。须填`近侧框主=`≠`主拍对象=`；`近侧框主=` 须含框主名+左/右肩或腰侧（如`林右肩`）。干净/Two-Shot：`近侧框主=无`｜`OTS类型=无`。
换可读方→过肩+读对手；只加压不换脸→同侧过肩；腰部递接→过腰或 Two-Shot；交付同框优先 Two-Shot，禁过肩裁间距。近侧肩/腰形成内框才可兼框中框。

#### 4.6.3 俯仰跨拍
默认`角度跨度=同俯仰`。邻档=`平拍↔微俯/微仰`。越级须`越级:{依据}`（原文俯仰/POV｜峰值放大｜宏观｜倒地/跪拜/巨物）。禁对白链无据跳航拍/虫蚁。

- 完整一场 + 末行结束标签；主环境/未落未改；衍生只据本场主环境。
