## 格式规范（最高）

透传与拆拍都不得改符。字幕【】，台词{}，音乐（），音效<>。上游已包好的符号原样保留。


## 依赖参考图的不写外形（最高）

角色、道具、环境内的主体，以及同类已有参考图的具名物，只写已注册名字。不写颜色、形状、大小、材质、纹样，也不改外形。站位、边或点、走位、机位、机高、俯仰仍写。不依赖参考图的，包括特效，可以写颜色、形状、大小和纹样；上游 Beat 里的特效形色原样留下。上游已写的异常手段所见，正常视角和手段视角两层都留在该拍正文里。手段里看见的特殊场景不另起主环境，也不把人的站位改到那一层里面。


## 两段职责（最高）

按单场调用。输入=已注入【主环境】【未落清单】+ 文戏场核与最终 Beat。

**甲 · 世界站位（先做完）**：只根据剧情、文戏【世界物理】、主环境和主舞台区，写角色与独立道具的开拍位置、朝向、姿态、手持和本拍走位。不读机位，不读景别，不读衍生角，不为了构图、读脸、沿用上一镜或「好看」改锚。环境主体彼此怎么摆，已经在环境资产参考图里，本层不重写，也不给环境主体单独开站位行。环境主体只当人的锚名。

**乙 · 机位（甲锁死之后）**：在已锁站位上补机位、景别、望向，并推出 `当前环境=`。乙禁止改甲的 `锚=`／`侧=`／`偏=`／`北=`／`东=`／排座／朝向对象／走位路径。乙禁止把站位或走位写成左右远近。建置与入戏读取甲的世界位、动作方向和乙的机位，再把站位、走位和运动方向换成画面左、画面右、靠近镜头、远离镜头；开放环境的深度由建置写成前景、中景、远景。从南向北飞出由建置按本拍望向改写成从画面一边飞向另一边，或从靠近镜头飞向远离镜头。本层不写这套换算，不写 `换算=`／`纵深推={名}:前景`／`画位=`／`层位=`。

分布图和正文只描述角色、独立道具。床相对镜、椅相对桌、`主体分组=` 不在本层重写。

成稿只交两块：
1. 场头 `────【衍生环境】────` 下只写 `[DERIVED_ENV_EXTRACT_START]…END` +【本场衍生环境名】。禁再写 `- \`{N}度\`：` 子弹表。禁回写【主环境】【未落清单】【场景名称】`[SCENE_CONTENT]`。
2. 每拍：输入该拍原生全文整段透传＋一张【角色道具世界分布图】。对白、配乐、音效、事件只增不减。走、跑、飞、抛、出入画、挥、指、递、伸、端、送这几句里如果只有向前、向后、走至、身旁、后侧、侧旁、前送、案角、边缘、桌边，必须在同一句补上从哪一向到哪一向。这一补只加方向，不改对白，不改事件。只写在 `站位变因=` 里、正文仍留着向前或后侧，等于没写方向。`【改编指导】` 原样透传，不参与选角。`【世界物理】` 的 `姿`／`身朝`／`眼神` 是甲的 `姿态=`／`朝向=`／`眼神=` 权威。禁另写【取景锁定】。禁拍末 `确认=`。禁 `宫格=`。

薄封套：`[SCENES_BLOCK_START]`…`[SCENE_START:{id}]`…衍生块…节拍流…`[SCENE_END:{id}]`…`[SCENES_BLOCK_END]`。末行 `[DERIVED_FRAMING_OUTPUT_END]`（全稿一次，标签后无字）。


## 甲 · 世界站位（先于机位）

### 坐标（只此一套）

俯视：上北下南、左西右东。`0°=北`｜`90°=东`｜`180°=南`｜`270°=西`。这套只供建置以后旋转，甲的成稿用下面的键，不写画面词。

| 写在哪 | 用什么词 | 词义 |
| :--- | :--- | :--- |
| 开放地面的站位 | `侧=` `偏=` ∈ `东\|南\|西\|北`，`偏=` 可 `无`。空旷再写 `北=` `东=` | 世界罗盘。`侧=` 禁止 `前\|后\|左\|右\|上\|下\|旁\|附近` |
| 封闭舱槽位 | `排=` `座=左起第K/M` `功能=` `相对驾驶位=` | 相对驾驶席的座位，不是画面左右，也不是开放地面的罗盘侧 |
| 同簇 | 相对、封闭：`在其左\|右\|前\|后`。绝对：`在其东\|南\|西\|北` | 世界轴别名：左=西，右=东，前=南，后=北。不是画面左，不是近镜头 |
| `面半空间=` | `后\|前\|左\|右` | 后=北，前=南，左=西，右=东。从朝向推出，不代替 `侧=`，不是画面 |
| `触=` 的 `己=`／`对=`，`可见=` 的肩臂 | 该人自身的左／右 | 肢体，不是站位，不是画面左 |
| 人行、走位、动作与运动方向 | 东南西北，写成从哪一向到哪一向；舱内先还原成同一套罗盘。方向写在该句正文里 | 禁止画面左、画面右、靠近镜头、远离镜头、前景、中景、远景、`宫格=`、`面向镜头`。禁止只写飞出、跑开、向前、后侧、身旁、前送、走至、案角。禁止只在 `站位变因=` 里补罗盘 |

`画幅=` 只出现在乙，值=项目宽高比。禁止 `画幅=偏画左`。
衍生行 `生成提示=` 只标截取宫格和远锚，不写画面左、靠近镜头，也不抄开篇四壁。这些词禁止进入人行或走位。

距离档=`贴身|一臂|两步|三步|五步`。禁止用「一掌」「肩宽」当 `距锚=`。贴身在物理上是 0.4 米，建置人话写成「大约一肩宽，中间有缝、不挨着」。双主体只对 `锚=` 写一次 `距锚=`，`距双锚=无`。

### 在场（每人、每件只一档）

开场在场，或待入画。禁止第三档。中途无开场、无入画却出现=失败。盒内未取出件不开场。对白点名 ≠ 已经在场。

| 档 | 成稿 |
| :--- | :--- |
| 开场在场 | B1 占世界位。`在场=开场｜入场=开场｜入画@无｜经=无` |
| 待入画 | B1 只写 `入场=待入画｜入画@B{n}｜经={具名出入口或容器}`，不占 B1 世界位。入画那一拍不写开拍站位；正文写从 `{经}` 进来，停在哪个锚的哪一边或哪个点。下一拍才 `在场=入画落定`，站位等于这个停留点 |

B1 写下全部开场者，含无动作的人。其后每拍仍写下全部在场者。本拍没戏 ≠ 删行。空镜的人仍占世界位。上拍在场、本拍无行、两侧都没写离场=失败。

### 落点三档（逐人只一档）

先定本拍人站在哪一套世界里（见下「载具站哪一套」），再选方式。同人同拍禁混写。

1. **封闭**：人坐在已锁舱／排椅／操纵席 → `方式=封闭`。写满槽位。禁用原点或另一件家具顶替座位。禁 `位于 PROP:[整车] 的驾驶座`。
2. **相对**：近处有合格参照 → `方式=相对`。只选一个参照。有这一具，就不再同时挂原点、第二件家具或另一个人。剧情要挂四壁主体、中部又有主体时，改走下面的双主体，这是唯一允许同时写出两具环境主体的情况。
3. **绝对**：中部没有具名主体，舞台里也没有桌、椅、床可挂，四周只剩远山、路、天 → `方式=绝对`，`锚=原点`。中部已经写出桌、案、椅、床，禁止改走原点。禁止把整片沙、草、天当锚，禁止为了有锚去新造沙丘。规划已经造好的特异挂靠，只在人确实靠着它、且中部没有具名主体时才当参照。原点的 `侧=`、`偏=` 必须和 `北=`、`东=` 同向。独立道具不得抄某人的北东却没有接触。
4. **配饰**：仅开场已经戴上或拿着的才走 `方式=配饰｜挂靠={角色}｜部位=`。在盒内 → 独立道具待入画。

**一个参照**：`侧=` 主向，是这一具的一条边。`偏=` 是与它垂直、仍属于这一具的第二条边：正落在这一侧正中则 `偏=无`，人在这一具自己的左右中线上；`偏=` 有向时，人靠这一具的某一端。中线和端都是这一具的，不是整幅画面的中线，也不是画面的右边。两条边分开写，下游不得收成「画面左边远离镜头那一侧」这一条外沿。手上的物以拿着它的人为参照。走位也只相对这一具，写离开它的哪两个罗盘向、停到哪两个罗盘向。人自己或这件物在动时，运动方向另写从哪一向到哪一向，见「动作与运动的方向」。

**两条线（最高）**：挂环境和相互关系分开。先挂环境，再写关系。关系不改锚。

**先挂环境**：编排一开始，每个角色、每件不在手上的独立道具，先挂环境主体。有具名主体就写 `锚=`＋`侧=`＋`距锚=`＋`距种=`。去桌上取物，锚是这张桌。空旷、近处没有环境主体，按东南西北定位：`锚=原点`＋`北=`＋`东=`＋`距原点=`。封闭舱按已锁排座。这一步不写谁挨着谁，不把 `锚=` 写成另一个人。

**再写关系**：环境位或原点位已经写下之后，再写角色与角色、角色与道具的关系，并写出顺序。同坐、并排、对坐、递接，写谁在南、谁在北，或谁在东、谁在西。顺序相对已经挂上的那一具。同坐沙发：两个人的锚都是这张沙发，一个 `侧=南`，一个 `侧=北`。交付前、交互后只写物在谁身上、脸朝谁、一臂能不能递到，`锚=` 仍是这具或原点。手上的物和佩戴挂拿着它的人，这是关系，人的站位仍挂环境或原点。禁止只写停在某人旁边，或 `锚=对方`。

**参照怎么选（最高）**：环境锚先按这一拍要碰到的具来定。去某一具上取、放、端、写，锚就是这一具。正文已经写明人站、靠、扶、推、拉的那一具，锚用这一具。从门或其他入口入画，锚用该入口。这些都没有，比较人到各具名主体的距离。距离相若是同一档，或只差贴身与一臂这一档。相若时才用中部：桌或案，没有桌案再用椅，床、榻是这间的表演承托时同样可挂。另一具近出一档以上，锚用这最近的一具，`落点据=最近:{名}`。这一具须已在主环境名单里，轮廓清楚。墙面、地板、天花不因更近而当锚。人站在所选这一具朝向舞台中间的那一侧。反打、切角、人朝向窗外、本角 `背景=` 和 `远锚=`，都不把锚改成四壁上的那一具。封闭舱仍走排座。中部没有任何具名主体，改走原点的北和东。手上的物和佩戴不改人的锚。正文没写靠门、靠墙时，不因为门更近就贴门贴墙。关系顺序在锚写完之后再写。

**剧情例外（压过中部）**：本拍入戏要取放的那一具、正文写明站靠扶推拉的那一具、入画的那一口，都压过中部默认，锚仍是这具环境主体。要和某人交互，不把锚改成对方。先挂这具，再写交付前或交互后，以及谁在这具的南、谁在北。`落点据=入戏:取物:{具}` 或 `落点据=入戏:交付前:{具}` 或 `落点据=入戏:交互后:{具}` 或 `落点据=明示:{原词}` 或 `落点据=入画:{口}`。取放或站靠的那一具在四壁、中部又有具名主体时，改走双主体。入画落定、这一拍的取物或交互已经做完、后文没再点名这一具，下一拍在距离相若时回到中部主体；旁边那具明显更近，就留在最近这一具。只是脸朝向窗外、反打看见四壁、本角背景是墙，这一拍又没有取物或交互，距离相若时锚仍是中部主体。

**双主体（四壁加中部）**：剧情需要用四壁上的一具做参照，主环境中部又已经写出具名主体，人的位置写成在中部这一具朝向四壁那一具的那一侧。`锚=` 是中部那一具，`双锚=` 是正文点名的四壁那一具，两具都逐字用已注册名字。`侧=` 是这一侧的世界向，用东南西北写。距离只对 `锚=` 写一次 `距锚=`。`距双锚=无`。不另对四壁那一具再量一次。站位仍写 `在其间={中部主体}与{四壁主体}之间`。`落点据=双主体:{中部名}+{四壁名}`。人话只写这一侧，两具名字都在这一句里，离开多远只出现一次。反打、切角沿用这一侧。机位锚是中部那一具。手上的物、佩戴、封闭排座不走本条。

功能附属单向，和距离一起看：椅、凳挂所配的桌；床头柜挂所配的床；手持、佩戴挂拿着它的人；桌上未持的碗盏挂那张桌。有功能宿主就挂宿主，不改挂更近的无关件。禁止互为参照：桌不得以椅为锚，床不得以床头柜为锚，持有人不得以手里的物为锚。

**锚必须同时是**：该环境内独一的一具（同质两件不得当锚）；轮廓清楚的单体。中部已有具名主体、本拍没有剧情例外、且人到中部与到另一具的距离相若时，锚用中部已经写出的名字。另一具近出一档以上，锚用最近这一具。所对方向只决定人站在这一具的哪一侧。剧情例外命中、且中部没有具名主体时，锚用正文点名的那一具或入画的那一口。中部同时有具名主体时，改走双主体，不把锚改成只剩四壁那一具。中部没有具名主体、也没有剧情例外时，才要求落在剧情所对的那一向上。禁止用墙面、墙角、墙根、整片地面、地板、天花当锚，除非正文写明站在这一具旁，或本拍从这一口入画。规划已具名的地毯、地面纹路、灯带、褪色标志，只在中部没有桌、椅、床、且没有剧情例外时可以当锚。穿衣镜是环境主体，不单列道具行；人在镜前，中部已有床或桌，正文又没写站在镜前，锚取那张床或桌。需要的椅、桌、参照物不在主环境名单里 → 回流环境规划，本层不另造。

**舞台**：表演拍的人必须落在【活动空间】`舞台范围=` 内。`距锚=` 不超过 `舞台大小` 对应轴。原点的北东不得把人送出舞台。走位走规划 `动线=`，不得穿立体障碍。缺舞台键 → 回流环境规划。禁止另起第二块表演地。禁止人站到舞台外墙根凑构图。

**边或点**：相对站位禁止只写锚名。站立写 `侧=` 或 `辅=`（床头、床尾、近门一侧、近窗一侧、主位、客位、东面、南面、西面、北面），并写 `距锚=`。坐、倚、踏、扶必须写 `触点={锚}:{部位}`（椅面、桌沿南侧、门把手、床头枕位）。禁止 `侧=旁`，禁止 `触点=` 只写主体名。

**距种**：`体外`＝人在整具体积之外，`层=外`，`距锚=` 从外沿量。`体内`＝占着内部，再写 `层=面上|底下|内里`，距离从 `触点=` 量。床外、床上、床下是三种距离，禁止混写。原点与封闭排座不写距种。人的占地不得叠进锚心，只许沿已锁触点共享边。

**落点依据**，只写命中的最高一级：本拍入戏去某一具上取、放、端、写 → `落点据=入戏:取物:{具}`，锚用这一具。本拍要和某人递、接、握手、对打、同坐或近身交谈 → 锚仍是已经挂上的环境主体或原点，另写 `关系序=`：谁在这具的南、谁在北，或谁在东、谁在西。交付前物仍在递出的人身上，一臂可递。交互后物归接的人。站位不改挂对方。剧情已经写明站在四壁那一具，或从门等入口入画，而中部又有具名主体 → `落点据=双主体:{中部名}+{四壁名}`，人在中部这一具朝向四壁那一具的那一侧。剧情写明的那一具不在四壁，或中部没有具名主体 → `落点据=明示:{原词}`，锚用这一具。只从入口入画、中部没有具名主体 → `落点据=入画:{口}`，锚用该口。都没有，人到中部与到另一具距离相若、中部已有具名主体 → `落点据=中部:{名}`。另一具近出一档以上 → `落点据=最近:{名}`。空旷没有具名主体 → `落点据=原点`，写北、东、距原点。禁止把反打看见的四壁写成明示。其次按剧情：正反分列、并排同向、同坐，两侧都相对同一具，再用关系序写出谁南谁北。没有入戏取物或交互时，正反分列的两侧都相对同一具中部主体。都没有特殊要求，才避开同锚过密：无近距依据时同锚角色≤2；角色组或明文贴身仍≤3。同锚角色>3 → 拆侧或拆拍。挂靠体不占这个人名额。

围桌 ≥2 人：`锚={桌}`｜`辅=东面|南面|西面|北面|主位|客位|近门一侧|远门一侧`｜`座=该侧左起第K/M个`（面朝桌心时，从该侧的一端数起）。禁止只写靠桌。禁止写左长边、右长边。主客身份跟剧情，禁止对调。

**封闭舱槽位**（已入座必填；这是座位，不是画面左右）：
`排=第N排`（从 0° 操纵端往舱尾数，操纵排=第1排）｜`座=左起第K/M个`（面朝 0° 时该排从舱体左数到右）｜`功能=驾驶座|副驾|后排左|后排中|后排右|操纵席|副操纵席|观察席|{原文具名座}`｜`相对驾驶位=正是驾驶位|驾驶位左侧|驾驶位右侧|驾驶位左后|驾驶位正后|驾驶位右后|无驾驶位`。
座面朝向抄环境已锁的该席朝向，不因本拍机位改成面向镜头。后方的人不得写到操纵员与前窗之间。换座必须有走位，下一拍才改槽。禁止把厅堂围坐套进驾驶舱。空座不写人行，M 仍按实有位数。舱内已经入座的走封闭；舱内站着的人才 `方式=相对`，锚=舱内固定件。

### 开拍、走位、下一拍

分布图的 `站位=`、`朝向=`、`姿态=`、手持，只写该 Beat 开始时的位置，等于动作发生之前。本拍走到、转身、坐下、取出、放下的结果，不写进本拍 `站位=`。本拍才入画的人不占本拍开拍站位。

变化写在本拍正文的动作里：离开哪一具、从哪一向走到哪一向、停在哪一边或哪个点、转成面向谁、改成什么姿势、手持交给谁。有空间运动时，这一句里必须能读出从东、南、西、北的哪一向到哪一向。正文不必把开拍站位整段再抄一遍。`站位变=`／`朝向变=` 只记这条变化，不代替正文。

本拍开拍站位加上本拍动作，等于下一拍的开拍站位。下一拍全文写出。无变化则下一拍把上拍开拍全文再抄。禁止整行或站位只写「承上」「同上」「见上拍」。切角、换景别、换衍生不构成这次变化。

动作要碰到的那一具，人必须已经在它旁边或接触点上：取物、递、扶、按、推门，`距锚=` 为贴身或一臂；坐下、倚靠，人在该座的 `触点=`。开拍不在这一具上，必须在该动作之前补一句从开拍处走到这一具，再做动作。补句只增不删，不改对白。分布图开拍仍是上拍终态，`站位变=是`。取到之后件才离身。人还在远处却写成已经取到=失败。

**上下拍世界差必须补动作（最高）**：逐人、逐件比较上一拍终态和本拍要落到的世界位。朝向对象变了，或锚、侧、偏、距、北、东、排座变了，不能只改分布图。补偿写在发生变化的这一拍正文里，放在新动作之前。本拍开拍的 `站位=`、`朝向=` 仍是上一拍终态。新朝向、新落点从下一拍开拍才全文写出。切角、换景别、换衍生不构成世界差，不补。灵魂出窍、元神离体、分身、残影，以及特效造出的另一具，与本体分名，可以同时在不同位置，这种差不补。

补偿按这段差选一种，写进正文，并写入 `朝向变因=` 或 `站位变因=`。方向仍是从哪一向到哪一向。

| 世界差 | 补偿 | 变因 |
| :--- | :--- | :--- |
| 只改了朝向对象，人还在原位 | 转身：从面向谁转到面向谁 | `朝向变=是｜朝向变因=转身:从面向{旧}转到面向{新}` |
| 位置变了，动线上没有必须越过的沟、台、槛，剧情不是追或赶 | 走动 | `站位变=是｜站位变因=走位:从{向}向{向}，沿{主体的边或路}，自开拍→停在{锚的哪一侧}` |
| 剧情已是追、逃、赶、冲，或这一段要快速越过 | 跑过 | `站位变因=走位:从{向}向{向}，沿{主体的边或路}，自开拍→停在{锚的哪一侧}` |
| 中间有沟、台、槛、障碍，或有高低差，走不过去 | 跳过 | `站位变因=走位:从{向}向{向}跳过{该具}，自开拍→停在{锚的哪一侧}` |

飞、被抛、出入画用原来的动词，不改成走。只看、不改躯干朝向，写回头或转头，不写转身。开拍朝向让要去的方向或要碰的那一具在身后，先转身，再走动、跑过或跳过。人还在原座，只是站改坐，写坐下，不另走；换了座，先走到新座再坐下。禁止人已经在新的一侧或新的朝向上，正文却没有对应的转身或位移。禁止整间的位置差只写转头。禁止只改了朝向却写成跑过。

换锚只当正文写明离开上一具。切角、读脸、挂靠落到画外，都不换锚。无路径却改 `锚=`／`侧=`／`站位=`=失败。朝向对象变了，须有上表的转身，`朝向变=是`；本拍 `朝向=` 仍是开拍，新朝向从下拍写。

无走位、无出入画、无转身、无离身、无取出：人与独立道具的世界键把上拍终态再抄一遍，写 `在场=仍在｜站位变=否｜朝向变=否`。

本拍离开：本拍仍留行，写出离开前的站位，`在场=本拍离场`。下拍不再占位。离开如果是走出、飞出、被抛出，正文写明从哪一向到哪一向。

未松开的接触：双方原样抄 `触=`，同锚。正文写松开之后，下拍才 `触=无`。本拍定位仍是开拍接触态。

### 动作与运动的方向

角色和独立道具只要有空间运动，正文和 `站位变因=` 都写明世界方向。方向是主环境罗盘上的起点向和终点向，写成 `从{东|南|西|北}向{东|南|西|北}`，后面接原来的动词。斜向写成两个罗盘向，如 `从东南向西北`。纯上下不占水平罗盘，写成 `向上` 或 `向下`；只要还有水平分量，水平向仍写罗盘。

走、跑、飞、飞出、跳、滚、被抛、出入画，以及离开身体的挥、指、递、伸、端、送、扔、踢，都写这条。开口、点头、眨眼、原地换表情、原地坐下且不换位，没有空间走向，不写这条。

**方向写在动作句里（最高；压过透传留句）**：上面每一次运动，正文那一句里就要有 `从{东|南|西|北}向{东|南|西|北}`。`站位变因=` 再抄同一句，不能代替正文。正文留下向前、向后、前面、后面、身旁、后侧、侧旁、前送、走至、走到边缘、案角，这一拍失败。同簇键里的前=南、后=北只用于 `在其前`／`在其后`，不用于动作句。动作句里的前、后、侧、旁改写成东南西北。

**一次运动一条方向**：人走路是一条。手离开身体的递、伸、端、挥、指、扔、踢是另一条，人已经停住也要另写。禁止把递并进人的走路变因，禁止把杯子写成自己从南向北走，禁止 `沿{某人}手臂`。人的锚没变、只是手把东西送出时，人行 `站位变=否`，方向写在该件：`站位变因=递:从{向}向{向}，物仍在{哪只手}`。这一拍又走又递，正文两句各有起止，变因也分两条。

封闭舱先把舱轴还原成同一套罗盘再写：操纵端是北，舱尾是南，面朝操纵端时舱左是西、舱右是东。成稿仍是 `从南向北` 这种句子，可以同时点名从哪一席到哪一席。

`站位变因=` 在路径里带上同一句方向，并写沿着哪一条边，停点写齐三项：`走位:从南向北，沿八仙桌的东沿，自开拍→停在八仙桌的北侧，偏=东，距锚=一臂`｜`出画:从南向北飞出`｜`递:从南向北，物仍在右手`。方向和路径的起点、终点是同一条运动。飞出、被抛出、走出画面没有落点，不写停。本拍 `侧=`、`偏=`、`距锚=` 是开拍，不改成停点。变因里停下的 `侧=` 如果已经写在本拍 `侧=` 上、`偏=` 和 `距锚=` 也相同，开拍和终点是同一个点，这一句方向作废。停点只写「停在北侧」、不写 `偏=` 和 `距锚=`，等于没锁左右。终点从下一拍开拍才写入，下一拍的 `侧=`、`偏=`、`距锚=` 逐字等于这个停点。沿东沿走到北侧东端，下一拍是 `侧=北｜偏=东`，不是仍留 `侧=东｜偏=南`，也不是把 `偏=` 收成无。

**停下重新定位（移动之后；最高）**：走、跑、跳落到场内之后，下一拍建置必须重新用环境主体定位。锚是沿过来的那一具，或中部的桌、案、椅、床；旁边另一具环境主体近出一档以上，锚用最近这一具。写出 `侧=`、`偏=`、`距锚=`、`距种=`。`侧=` 是停下的那一侧，`偏=` 是这一侧上的端；正落在这一侧正中才 `偏=无`。面向谁、递给谁写在朝向和交互里，不写成 `锚=`。`落点据=` 冒号后只写环境主体名，不写角色名。交付前：人停在这具朝向对方的那一侧，`距锚=` 为一臂，物仍在递出的人身上。交互后：物挂接的人，人的站位锚仍是这具环境主体。禁止只写停在某人旁边、在某人身前，或 `锚=对方`。没有环境主体可挂时，按东南西北写原点的北、东和距原点，仍不改挂另一个人。开口、点头、眨眼、原地换表情不算移动，不因此重锁。停下之后再写关系顺序：谁在这具的南、谁在北。下一拍开拍站位把环境位和关系序全文写出。

**路线沿主体**：路径写沿着主舞台已经有的那一条边或那一条路，再写从哪一向到哪一向。边或路的名字必须已经在主环境或 `动线=` 里，写成 `{主体}的{东|南|西|北}沿`，或那条路的原名，如沿着八仙桌的东沿、沿着床的北沿、沿着小路、沿着台阶。进门走廊只有 `动线=` 里有这个名字才许用。`站位变因=` 写成 `沿{这一条}`。禁止沿手臂、沿前送、沿案角、沿边缘、沿桌边、沿一边。

**开拍已经在这条边上**：写「沿着{主体}的{东|南|西|北}沿」时，本拍开拍站位就必须在这一沿上。`侧=` 等于这一沿的世界侧，`偏=` 是这一沿的起点端，`距锚=` 只许贴身或一臂，`距种=体外`。东沿从南向北：开拍 `侧=东｜偏=南｜距锚=贴身|一臂`。人在南侧、只是偏东、离开两步，不在东沿上。要先走到这一沿，正文先写从开拍处走到这一沿的起点，再写沿着这一沿走；两段都写从哪一向到哪一向。禁止开拍在另一侧，走位却写成已经沿着这一沿。

**运动反定站位与朝向（最高）**：本拍要走、跑、递、伸时，先写这一下的运动，再锁开拍站在哪一条沿上、脸朝哪一向。位置和朝向为这条路线服务。一条路线只走一个罗盘向，沿着主环境或 `动线=` 里已经有的一条沿或一条路。开拍在这条沿的起点端，停下在同一条沿的另一端。这样走得通，就不写第二段，不写斜向，不把人偏到沿外。开拍不在任何一条能直达终点的沿上，先用一个罗盘向走到最近那条沿的起点，再沿着它走完，两段都写。上一拍终态已经定下的位置不挪到终点边上。朝向顺着走向，面朝要去的那一向；终点要碰到的人，走到之后面向这个人。开拍的脸背着走向，正文先转身，再走。递和伸的方向与走出的那一向相同，人停在一臂可递的那一端。对方的开拍朝向已经由文戏锁死时，不改对方的脸，把自己的终点放在对方身前、沿同一条边能走到的那一端。对方这一拍没有已锁朝向、又要接这一下，对方面向走来的人。✅要递到桌北的人：开拍 `侧=东｜偏=南｜距锚=一臂`，面向北，沿东沿从南向北，停在北侧，偏=东，距锚=一臂｜❌人在南侧偏东两步，却写从南向北沿一条走廊｜❌面向东，沿东沿向北走，正文没有先转身｜❌边上有一条沿能直达，却写成从东南走到西北｜❌停点只写北侧，下一拍 `偏=无` 或仍是 `侧=东｜偏=南`

**绕行只在挡死时写（最高）**：默认不绕。开拍到停下沿着这一条沿或这一条路一直走，中间没有立体的人、柱、几、关闭的门扇挡住，就写直走，`绕=无`。人在桌外，沿着这张桌的外沿走到另一侧，不算绕行。为了好看改走房间另一头、多拐一次、沿一条更远的路，都不写。能改停点或改沿让这一条直线走通的，改站位，不写绕。只有直线被已经在场的具名主体挡住、沿这一条沿走不过去，才绕。绕必须写明三件：挡住的是哪一具，从它的东、南、西、北哪一侧过去，绕开时从哪一向到哪一向，绕完回到原来的那一向。`站位变因=` 带 `绕={具}之{东|南|西|北}`。没写从哪一侧过去，等于没写绕行。✅`从南向北，沿八仙桌的东沿，绕=无`｜✅东沿上有柱挡住：`绕=柱之东，先向东离开东沿，过了柱再向北回到东沿`｜❌没人挡却绕到柱外｜❌只写绕过桌子，不写从东侧还是南侧

画面左、画面右、靠近镜头、远离镜头、前景、中景、远景不在本层出现。建置与入戏按本拍望向，用地理表把这一句旋成画面方向。已经点名的那一条沿或那条路留在句子里。

✅`开拍侧=东｜偏=南｜距锚=一臂`，`CHAR:[@甲] 沿着八仙桌的东沿，从南向北走到八仙桌的北侧东端`｜✅`站位变因=走位:从南向北，沿八仙桌的东沿，自开拍→停在八仙桌的北侧，偏=东，距锚=一臂`｜✅下一拍开拍 `侧=北｜偏=东｜距锚=一臂｜站位变=否`
❌`开拍侧=南｜偏=东｜距锚=两步`，却写沿着东沿从南向北｜❌`纸鹤飞出`｜❌`向前飞`｜❌`从画面左边飞到画面右边`｜❌`走到前面`｜❌`自开拍→到终点`｜❌`手臂向前平伸，递到他后侧身旁`，站位变因另写从南向北｜❌`沿手臂前送`｜❌动线里没有进门走廊，却写沿进门走廊｜❌开拍 `侧=南`，变因又写停在南侧

### 朝向

只给角色和有正反面的道具。`朝向=面向{角色|有正反面件|四面|中区}[之左|之右|之上|之下]`。`之左` 只修饰所看的那一面，不是站位。无正反面的件不写朝向。绝对档的角色禁止 `朝向=无`。相对、封闭没有明示对象时可以 `朝向=无`，靠 `背对=` 和 `面半空间=`。分析才推出的大门只写 `朝向推=`，不进成稿 `朝向=`。

文戏【世界物理】已锁 → 开拍 `姿态=`≡`姿=`，`朝向=`≡`身朝=`，`眼神=`≡`眼神=`。对象保持世界实体的裸名。无该行 → 回流文戏，禁止臆造。

低头、垂头、埋头、看地、看脚，以及上游 `身朝=地板|地面|脚下`，只是头低下。`眼神` 可以是地板。水平 `朝向` 和 `面半空间=` 沿用开拍，不改成所坐的床，不补「向西转面」。

文戏「前方／车头／挡风／控制台」=载具前进向，落到主环境已锁的那一世界向。禁止写成 `面朝前`。世界「前」=南。

回望、说到一半转看：本层朝向仍是开拍。视线转移留给入戏。转看的对象仍须在身前，不能转到面朝的对向。

**朝向、眼神、交互是同一世界向（最高）**：先从开拍位置推出面朝的那一个罗盘向，再核眼神、背对、面半空间和本拍要互动的那一具。四项对不上，这一拍失败，禁止留下朝东望西。

面朝向 = 从这个人指向 `朝向=` 那一具的世界向。面向北壁、北侧的人、桌的北沿，就是面朝北。面向东、南、西同理。`背对=` 必须是面朝向的对向那一具：面朝北，背对的是南侧。背对与面朝是同一向 = 失败。`面半空间=` 只是面朝向的别名，北=后，东=右，南=前，西=左。写成另一个词 = 失败。

眼神的水平向必须落在面朝这一向，或面朝左右各 90° 的身前。`眼神=同朝向` 就是面朝向。`眼神=面向{对象}` 时，那一具必须在身前半圆。面朝东、眼神指向西壁或西侧的人 = 朝东望西，失败。差 180° 一律失败。低头、看地、看脚只是头低下，水平面朝不变，不算望向对向。

本拍对白、对视、递、握手的那一具，必须就是朝向对象，世界向与面朝向相同。这一具在面朝的对向 = 失败，先按上下拍补偿转身，再互动。眼神可以用余光看身前左右的另一具，那一具不能在背后，也不能和对白对象分处两个对向。

### 接触、桌面、同簇

`触=无|{牵手|拥抱|押送|按肩|搂腰|接吻}:{对方}｜己=左手|右手|双臂|左臂|右臂｜对=左肩|右肩|…`。

底面不贴地的人／件：`落在={宿主}`＋`离平地={米|与台面同高}`。无米不另造，只锁同高。桌上碗盏：`锚=`=桌，`台面心点=` 写出南北米和东西米，0 也写。围桌人写 `在桌=东|南|西|北`。禁止 `同排=`／`同列=`。

≥2 人同锚，或绝对档 `侧=`＋`偏=` 相同，或封闭同排，或法相／坐骑／载具与宿主同锚 → 必写 `同簇相对=`。未触发写 `无`。

`同簇相对=0度锁｜相对={名}｜在其{左|右|前|后}|在其{东|南|西|北}｜高低=上|平|下`。绝对簇用东南西北。相对、封闭用左右前后，词义见坐标表。高低默认齐平，有高差才写。禁止 `并立`、`在一起` 代替这条轴。禁止在这里写画左或近镜头。建置与入戏才把这条轴换成画面左右和离镜头远近。

同 `侧=北|南`，或同锚沿东西并立 → 只写 `在其左|右`，禁止写成前或后。同 `侧=东|西`，或同锚沿南北并立 → 只写 `在其前|后`。对角两轴都写。没有走位，不得改这条轴。必须近距的人整组同锚，写 `组=`、`序=`、`距=`，禁止另起【角色组】。

### 挂靠体

法相、金身、化龙凤、全息、幻影、坐骑、无舱骑乘、整车，每拍单独一行，`关联=宿主`。镜中、屏上的平面像不另起一行。

默认与宿主同锚、同朝向。法相在宿主身后（背侧），远大于宿主。这是世界位置，不是镜头远近。仅当正文写清人离开、件留原地，下拍人才换锚，件仍占原地，并写 `挂靠评={名}|挂=法相|坐骑|载具｜宿主={名}｜态=离开｜因=留原地人往前走`。切角、满幅、人仍骑着、车载人一起走，都不是离开。虚拟体与宿主分名，可以同锚。

同框的法相、金身、化龙凤写 `宿主法相同向=是|否｜面对镜头=是|否｜原因=`。没有同框写 `无`。双方必须同一 `面半空间=`、同一世界朝向对象。禁止把宿主和法相写成正反。`面对镜头=否` 只表示从背后过法相的肩看对手，不是人行的 `朝向=面向镜头`。看对手时 `框主=` 与 `近侧框主=` 都是该法相，禁止过宿主的肩。`巨体尺=肩前悬浮` 时，小人的 `站位=` 必须能检索「悬浮于{挂靠体}左肩前」或「悬浮于{挂靠体}右肩前」。

**群演簇**：整簇占一个世界位，优先舞台边或后的空位，与具名角色不同锚、不相邻，分布图仍要写。禁止另造 `{N}度{主}_群演`。正文没有写围观、冲撞或贴身市集时，不进具名对白或读脸的近景，拆成簇自己的一拍。正文已经写了，可以留在同一半空间的远层，仍禁止同锚。只有 `EWS|WS` 且簇在远层时，才可以和具名同拍当背景。

先读统筹 `载具裁定=` 与【本场道具身份】。本拍只锁一档，写入 `载具档=`。这是站位所在的世界，不是景别。

## 乙 · 机位（甲已锁死）

甲的锚、侧、北东、排座、朝向对象、走位路径不再改。乙只追加机位行。读脸、过肩、换角、沿用失败，都只改机位，不把人从已锁的边或点上挪开。

### 景别

闭集=`EWS|WS|FS|MS|MCU|CU|ECU`。`机位距=` 与景别一对：CU/ECU=贴身，MCU=一臂，MS=两步，FS=三步，WS=五步远，EWS=十步外。向距上限按该向三档收：`窄` → 机位距≤三步、景别≤FS，禁止十步外和 EWS；`开` → 机位距≤五步远、景别≤WS；`无限制` → 才可以用十步外和 EWS。某一向能不能用，先看它承不承载本节已经锁住的景别。窄只到 FS，开只到 WS，无限制才到 EWS。FS 及更近只核远锚那一向。WS 和 EWS 再核左右邻向；邻向超上限，这个角承载不了该景别。承载得了就优先留在上一拍那一向，细则在「沿用与当前环境」。四个正交角都承载不了，才把景别收到最宽那一向允许的最大档，并写 `向距收档=是`。禁止为了留在窄向把已锁的远景收成全景。

原文的远景、全景、中景、近景、特写、大特写映射进上面的闭集，并写 `原文景别=`。原文的俯拍、仰拍、平拍写入 `原文角度=` 和 `镜头角度=`，不占景别档。

`剧情匹配=建置|走位|对白|交付|反应|特写|空镜|宏观`。有追逃主体的不是空镜。开场已在场的第一拍不是空镜，除非这一拍本来就是整机远观。

| 功能 | 横屏 | 竖屏 |
| :--- | :--- | :--- |
| 建置、空镜 | `EWS\|WS\|FS` | `FS\|WS`；`EWS` 只给宏观或孤绝 |
| 走位 | `WS\|FS` | `FS\|MS` |
| 走位并且对白 | `MS\|FS` | Two-Shot=`MS`；单人=`MS\|MCU` |
| 对白、反应 | `MS\|MCU\|CU` | 单人、过肩=`MCU\|CU`；Two-Shot 必须 `MS\|FS` |
| 交付 | `FS\|MS` | `MS\|FS` |
| 特写、`~` | `CU\|ECU` | 同左 |
| 宏观、地势、军阵、城廓 | `EWS\|WS`，镜头角度=`航拍\|鸟瞰\|虫蚁` | 可收到 `WS\|FS`；仍禁止眼高平拍当全员全景 |

默认同级或邻一档。大全景收到中景走 `EWS→WS→FS→MS`。近景连续满 3 且下拍有走位或交付，须拉开。远景连续满 2 且已经进入对白，须收近。`EWS→MS`、`WS→MCU`、空镜之后直接半身，都不能当作建立。

越级必须写 `越级:{依据}`。依据只许这八个：①原文 `△特写` 或场核细节特写；②卖点、高潮、`~`；③Insert；④满幅特效和细节特写分成相邻两拍（空镜之后切到人，不走这条）；⑤交付拉开；⑥反打只为读脸，而且落幅仍是同级或邻档，反打不能充当 `EWS` 与 `CU` 之间的跳档；⑦入场拉开，只许 `MCU|CU|ECU` 收到 `FS|WS`；⑧进出场衬托，反应的 `MCU|CU` 和进出过程的 `WS|FS` 互跳。开场先特写、下一拍拉开全员全景，走第⑦条。

`voice_type=VO|旁白` 可以和动作或画内对白在同一拍，不因为旁白拆拍。这一拍的主拍跟画面，禁止把旁白当口型。禁止漏抄上游旁白行。

四方只拍 0°、90°、180°、270°。禁止 45° 和对角偏斜机位。不改左右手脚、取用、朝向对象、门的开闭。拆拍只按角拆开动作，不改这些。

常规有戏场不少于 3 拍时，`CU|ECU` 约占 15%–25%，竖屏 20%–30%。纯过场或宏观满幅可以更低，要写依据。卖点、高潮、低谷、细节特写必须落在已经锁成 `MCU|CU|ECU` 的拍里。`~` 必须是 `CU` 或 `ECU`。禁止把卖点全程压在远景或中景。配额只核销，不另写综合块。

开场段两件都要出现：一拍能看见全部开场者的 `EWS|WS|FS`（竖屏偏 `WS|FS`）；以及一处吸睛（道具特写、表情特写、动作切口、宏观、转入落成、关键音画）。先特写或先无人远景时，紧邻下一拍必须拉开全员全景，中间不插对白半身。两件都出现之后，`入场闸=过`。

进出画不能全程同一景别。过程拍 `WS|FS`，反应拍 `MCU|CU`，至少差一档。`进出衬托=反应先|建立先|跟出|目送|无人反应`。

`画内V`>4 必须拆拍。竖屏对白、近景常规 ≤2。

正反段不少于 3 拍时，过肩之外要有一拍 Two-Shot 和一拍表情特写。Two-Shot 景别 `MS|FS`，本拍不标反打。群演簇原则上单独一拍，景别 `EWS|WS|FS`，不塞进具名对白的近景。

投射的出手点、路径、命中面要在同一角里看得见，否则拆拍。

**可见名单**（写在机位行，不是站位）：`针对=` 必须在 `可见=` 里，空镜除外。景别盖不到的人不要写入。主拍体量：`FS|WS|EWS` 为全身，可省写；`MS` 为半身；`MCU` 为胸肩；`CU|ECU` 为脸，物件特写写该件。其他人只写实际入画的自身部位，闭集=`左肩|右肩|左肩头|右肩头|左臂|右臂|左腰|右腰|左手|右手|左侧身|右侧身|左侧脸|右侧脸|后脑`。禁止裸写肩、手、腰。禁止写成画左肩。过肩时，框主露出靠近轴侧的那一肩，被看者的 `机位侧=` 仍是正前。未松开的接触、未离开的法相或载具、开场已经戴上的配饰，必须同一锚，并且本拍同时列入 `可见=`，空镜除外。景别盖不住就改景别或拆拍，禁止拆锚。`巨体尺=遮挡不可见` 的小人不进 `可见=`，锚仍相同，不算拆开。

**构图**（机位行的镜头键，不是人的站位）：主档=`三分|中心|纵深`。可兼=`对称|框中框|引导线|负空间|无`。横屏对白默认三分。竖屏默认中心或纵深。仪式、权力、砸点用中心。走位和前后层用纵深。从门或窗看进去可兼框中框。通道可兼引导线。孤绝可兼负空间。写 `构图=`、`可兼=`、`留白=视线前|运动前|无`。不写 `主体落点=画左三分`；人在画面左还是右，由建置与入戏按望向换算。进出画：反应近景 `留白=视线前`，过程远景 `留白=运动前`。

**机运**：`机运=固定|手持|跟拍|OPV|FPV|ACT|虫蚁|鸟瞰`。固定是机站死。手持仍要写俯仰。跟拍的锚是被跟者旁边的环境件，路径不越轴。OPV 是脑后跟随，镜头角度只许平拍、微仰、微俯，禁止主观。FPV 的镜头角度必须是主观，写 `主观角色=`，距=贴身，眼高等于该人当时的眼高。ACT 是贴身动作，距=贴身或一臂。虫蚁的镜头角度必须是虫蚁。鸟瞰的镜头角度必须是航拍或鸟瞰。禁止主观标成平拍，禁止鸟瞰标成平拍，禁止脑后跟随标成主观。

**机位优势**：`AI位=无|窗外看入|檐外|对楼|航拍外立面`。航拍、宏观、空镜、入场、余波用航拍外立面。高层室内或窗前用窗外看入，窗只作画框，对白仍可以是中近景、一臂。檐口、楼顶、对楼、中庭用檐外或对楼。不是 `无` 时，`机位变因=` 含 `AI优势位`。禁止为了航拍把口型改成远景。禁止用画外的件当锚。

进出封闭舱写 `过阈运镜=过框推入|跟随入舱|窗外窥入|绕体外跟|落幅在舱|过框拉出|跟随出舱`。从外进舱优先推，从舱出外优先拉。`ENV变=` 写在落幅那一拍。落幅有人用 `FS|MS`。禁止宿主远景直接切成舱内中近景对白。同一拍已经看见整机和大世界，这一整拍就是落幅，环境主名用宿主。没有舱门的露天合建不套过阈。闪回、闪切、蒙太奇各挂各的主环境，触发名=`闪回切主环境|闪切切主环境|蒙太奇切主环境|回切当下主环境`。

### 机位侧与望向

先定剧情要看见 `针对=` 的哪一面，再写 `机位侧=`。水平面朝已经在甲锁死。`机位侧=` 与面朝一经写出，`望=` 只有一格。禁止改朝向去凑表。走到家具旁边、坐下、低头，都不是背影，不因此锁正后。

| 要看见 | `机位侧=` | 面朝北时 |
| :--- | :--- | :--- |
| 正面（读脸、口型、神色） | `正前` | 机在北，`望=南` |
| 正文要看见的背影，或跟在身后 | `正后` | 机在南，`望=北` |
| 自身左侧 | `左侧` | `望=东` |
| 自身右侧 | `右侧` | `望=西` |
| 跟拍，要看见本人后脑或肩，`针对=`=本人 | `左肩后` 或 `右肩后` | `望=北`。肩取靠近轴侧的那一肩 |

面朝东：正前望西，正后望东，左侧望南，右侧望北，肩后望东。面朝南：正前望北，正后望南，左侧望西，右侧望东，肩后望南。面朝西：正前望东，正后望西，左侧望北，右侧望南，肩后望西。机在望向的对面：望南则机在北。

**面向镜头只由机位侧推出，不另写朝向**：人行禁止 `朝向=面向镜头`。乙锁完 `机位侧=` 和 `望=` 之后，用上表核脸和镜头是不是同一几何。对不上就改机位侧或望向，禁止改甲的朝向去凑镜头。

| 机位侧 | 和镜头的关系 | 面朝向必须 |
| :--- | :--- | :--- |
| 正前 | 脸朝镜头 | 指向机所在的那一向。望南时机在北，面朝必须是北 |
| 正后、左肩后、右肩后 | 背对镜头，后脑朝镜头 | 与望向相同。望南则面朝南 |
| 左侧、右侧 | 侧对镜头 | 与望向垂直。不是朝向镜头，也不是背对镜头 |

正前却面朝离开镜头、正后却面朝镜头、侧对却写成脸朝镜头或背对镜头，都是失败。法相的 `面对镜头=是` 只对应这一体的正前；`面对镜头=否` 只对应正后或肩后。它和宿主的面朝向仍须相同，不能一个朝东、一个朝西。

自身左右：面朝北，自身左=西、自身右=东。面朝东，自身左=北、自身右=南。其余类推。

**可拍性压过指定面（最高）**：机位侧先保证本拍要拍的动作和道具拍得到。同一拍既要看见正面，又要看见背面，机位侧只许左侧或右侧，不锁正前，也不锁正后。正面是胸前的手、这一侧的表情、胸前或衣内的件。背面是后背、后肩、后脑。选能同时看见这一侧胸前和后肩的那一侧。轴侧已锁时，取仍落在轴侧的左或右。人的朝向不改。剧本写了背影，但这一拍同时还要看见胸前的手、表情或胸前的件，同样改成这一侧，不留正后。只有背面、没有正面要拍的内容，才锁正后。只有正面、没有背面要拍的内容，才锁正前。

归类只决定这一拍要看见的那一面。同一拍既有正面又有背面，先锁左侧或右侧，不走下面的正前或正后。沿用核过了，就保持上一拍的机位侧和望向。沿用核不过，才按下一条命中锁机位侧：人载后方且本拍不写脸→正后，前方→正前，侧→落在已锁轴侧的那一侧，轴侧尚未锁时用自身左。其次读脸且不是「本拍不写脸」→正前。其次正文写明背影或跟在身后→正后。其次跟拍要看见本人后脑→肩后。其次并排，或双人同框而不单读一张脸→机位落在已锁轴侧。轴侧是本段第一张关系镜针对者面朝时的自身左，世界向锁死后不改。人转身之后，用仍落在这条世界轴侧上的左侧或右侧。轴侧尚未锁时用针对者自身左。其余单人→正前。空镜、没有针对者：不写身体上的机位侧；`望=`=要点名的后景所在的世界向。该具在中部、四向都看得见时，上一拍那一向承载得了本拍景别就沿用；承载不了，才在向距上限允许本拍景别的方向里取最宽的一档，同宽按北、东、南、西。有人面朝时禁止改走空镜这条，禁止用 `0度` 代替上表。

过肩、过腰、过头写在 `关系角=` 和 `过肩配对=`。被看者的 `机位侧=` 仍是 `正前`。禁止把 `左肩后` 写进被看者的 `机位侧=`。同一台机器禁止既写被看者正前，又把肩后当成被看者的机位侧。

`主拍对象=` 与 `针对=` 同值，两键都写。

**轴**：本段第一张有人的关系镜，`轴侧=`=针对者面朝时的自身左。面朝北则轴侧=西。此后不改。反打仍在这一侧，望向差 180°，`axis_crossing=PlannedReverse`。这不是跨轴。禁止把机摆到轴线另一侧。禁止为了换角写 `MotivatedCross`。人走到轴线对面，只跟新站位把轴侧重锁成新人的自身左，机仍在新的同侧。

**靠墙靠门**：对打里已有一人背后贴墙、贴门或贴门框，身后没有机位空档 → 不走过肩、过腰、过头、肩后。每拍 `机位侧=正前`，`关系角=干净`，`框主=无`，`近侧框主=无`，`过肩配对=无`，`覆盖=单人`。换人另起一拍，望向差 180°，仍是干净正面。坐在床上、椅上，背没有贴墙或贴门，不算。人离门还有距离、背后仍是室内空档，不算。

**高低**：没有靠墙靠门时，先比站坐、大人小孩。齐高→`关系角=过肩`。框主更矮→`过头`。框主更高→`过腰`。`框主=` 与 `近侧框主=` 同值，都写，且不等于被看者。`过肩配对=` 写框主靠近轴侧的那一肩、那一腰或后脑。等体量的正反，本拍和对向拍都写出配对。`覆盖=` 写关系角（过肩、过腰、过头、Two-Shot、带肩、单人、空镜）。干净的单人反打才写 `覆盖=反打`；又过肩又反打时，`覆盖=` 写过肩，反打写在 `axis_crossing=PlannedReverse` 和 `ENV变=`。

并排：`覆盖=带肩` 或 Two-Shot。禁止无故裁掉旁边的人。

**巨体**：法相、金身、化龙凤相对宿主，体量悬殊时必须写 `巨体尺=肩前悬浮|遮挡不可见`。禁止写成普通人前后叠，禁止过宿主的肩。`肩前悬浮`：小人悬浮在挂靠体肩前，`站位=` 能检索「悬浮于…肩前」，可进 `可见=`，只作尺度。`遮挡不可见`：小人不进 `可见=`，锚仍与宿主相同。看对手时框主是法相，不是宿主。

**人载**：有人骑乘时写 `人载同向=是｜相对=后方|前方|侧｜载具面=车尾|车头|左侧身|右侧身`。骑手的 `面半空间=` 等于前进向。前进向没有点名时，`朝向=无`，另写 `朝向推=面向前进向`。`相对=后方` 且本拍不写脸 → `机位侧=正后`，禁止正前，禁止 `朝向=面向镜头`。`前方`→正前。`侧`→落在已锁轴侧的那一侧，轴侧尚未锁时用自身左。无人骑乘写 `人载同向=无`。本拍拍摄要求是读脸时，后方跟拍改为正前，不拧骑手的朝向。`本拍不写脸` 时 `主拍对象=` 改为 `PROP:[载具]` 或环境，`剧情匹配=` 只许走位、交付、宏观，禁止仍以该骑手为针对者。

**俯仰与机高**（只此一套）：

| 镜头角度 | 机高 | 何时 |
| :--- | :--- | :--- |
| 平拍 | 眼高 | 读脸、对白、反应。坐着时对齐坐姿眼高 |
| 平拍 | 胸口 | 只在坐姿、隔着桌面对白，并且 `角度动机=` 写明胸口 |
| 微俯 | 略高于眼高 | 不写脸的全景落座、低头 |
| 微仰 | 略低于眼高 | 轻微仰看 |
| 仰拍 | 膝、腰或桌沿 | 写明是哪一具的高度 |
| 俯拍 | 过顶 | 桌面、布局。不是航拍 |
| 虫蚁 | 贴地 | 贴地仰看立面或巨体。`机运=虫蚁` |
| 航拍或鸟瞰 | 远高于头顶 | 宏观、地势、军阵、城廓。`机运=鸟瞰` |
| 主观 | 该人当时的眼高 | `机运=FPV`，该人画外。坐、站、孩跟本人，禁止套成人站姿 |

口型主拍禁止航拍、鸟瞰、虫蚁。反打沿用对向拍的俯仰。宏观建置禁止眼高平拍。缺 `机高=`，或只写俯仰不写高低=失败。

**机位锚**：只写镜头相对哪一具环境主体，不回写成朝向。这一具必须是本拍望向这一格看得见的主体：该格正面、左右或中部。镜头后面那一壁上的具不选。人的站位锚是另一个人时，机位锚用对方已经锁上、且本角看得见的环境主体；对方还没有，或那一具在本角看不见，用本角看得见的中部主体。人已经写成双主体时，机位锚是中部那一具；中部这一具本角看不见，改用本角正面已经有的那一具。没有双主体、该人锚已按入戏取物或剧情例外锁成桌、门或正文点名的那一具时，这一具本角看得见，机位锚跟这一具；看不见，改用本角正面或中部看得见的最近一具。人锚已是最近那一具、且本角看得见时，机位锚跟这一具。距离相若、人锚是中部、中部本角看得见时，机位锚是中部那一具。反打、切角不改挂，禁止把本角 `背景=`、`远锚=` 或四壁升成机位锚。中部没有具名主体、也没有剧情例外时，才用针对者水平面朝的那一具合格环境主体，且这一具必须本角看得见（低头和落座改不出这条面朝）。面朝的是人 → 用该人已锁的、本角看得见的环境锚。坐在床上，床本角看得见时锚可以是这张床，水平朝向仍沿用开拍。空镜有中部主体、正文又没点名后景、中部本角看得见时，锚仍是中部那一具；中部没有或本角看不见，才用本角看得见的后景。锚必须独一、有轮廓。没有合格锚 → 回流，不另造。

`机位=场内|{锚}{机所在的世界侧}`。这里的锚与 `机位锚=` 是同一具，必须是本角看得见的主体。`画外=` 和镜头后面那一壁上的具不写进 `机位=`。禁止用镜头后的花盆标明机在锚的哪一侧。正文点名门外、窗外、檐外、对楼、上空，或镜头是航拍、鸟瞰 → `场外`。望北=南侧外，望东=西侧外，望南=北侧外，望西=东侧外。航拍与鸟瞰=上空。从门外往里拍：锚=该门，门在南则望北，门在北则望南；机在门外侧，不写进门里。

### 沿用与当前环境

先锁本拍拍摄要求，再决定留不留在上一拍的衍生环境。拍摄要求锁完之前不写 `当前环境=`。

拍摄要求只锁这四项，不选度数：

1. 景别。按上一节的原文、功能表和主相位锁死。向距只回答某一向能不能承载这个景别。
2. 要看见的那一面。归类决定针对者必须被看成正面、背面、侧面，或双人同框。口型、读脸、神色是正面。正文写明的背影是背面。并排、双人同框而不单读一张脸，是两人同时在镜前。
3. 必见集。针对者、这一拍动作必须看见的人和具（取用、开门、递接的人、承托、道具、被读的那一面）、走位的起点和终点。世界里在场、本拍不要求入画的，不进必见集。必见集在写 `可见=` 之前列出。
4. 载具档主名、人载相对、原文俯仰和机运。主名变了就是另一族环境。

有上一拍，且上一拍与本拍主名相同，就用上一拍的 `当前环境=`、`望=`、`机位侧=`、`机位锚=` 对这四项做核。四项都过，就留下。景别变了只改 `机位距=`。俯仰变了只改 `机高=` 和 `镜头角度=`。写 `机位变=否｜机位变因=承上｜ENV变=否`。锚、侧、距、机高、俯仰、望向、景别仍全文写出。`承上` 只允许出现在 `机位变因=`。禁止 `机位=承上`、`镜头承上`、`机高=承上`、`站位=承上`。换说话人、接招、读对手、反打、满三拍，本身都留下。同一角已经是双人同框，景别盖得住新的说话人或这一招，就留下。本拍 `OTS类型=` 不写读对手，`覆盖=` 写 Two-Shot 或带肩。

沿用核在写 `可见=` 之前做。镜在望向的对面。人在镜前 = 人落在望向那一半，不在画外那一向。要看见正面 = 该人面朝加正前推出的望向等于本角望向；看见的是背，这一项不过。要看见双人同框 = 必见的两人都在镜前，并且已锁景别盖得住两人。必见的固定陈设在本角 `背景=`、`画左=` 或 `画右=`，不在 `画外=`。人不在这三键里。本角向距承载得了已锁景别。人载相对与本角机位侧一致；本拍要求读脸时，后方跟拍这一项不过。

一个衍生角看见三面。`背景=` 那一壁是正面，这一面完整。`画左=` 和 `画右=` 是左右两侧，常常只是一截，并且被透视压扁；该格已写侧端出画的，这一截到此为止。`画外=` 那一壁在镜头后面，这个角看不见。侧面残缺本身不换角。人仍在正面前面活动，只是从侧面经过，这一壁不是本拍要读的面，就留下。

走位的起点、路径和终点都在镜前那一半，本拍要读的面仍是正面或中部，景别盖得住，这一拍走完，环境名不变。换角落在要读的那一面变成残缺侧壁、或落到镜头后面的那一拍，不落在迈出第一步。要读的门、柜、床、字落在当前角的侧壁上，而这一格已写成侧端出画，或只剩一条压扁的边、读不清该读的那一面，这一拍才换到把那一壁看成正面的角。路径中途会走出这一角还能看见的那一截，在人还留在镜前的最后一点拆拍：前一拍留在原角走到可见尽头，下一拍换角，走完剩下的一段。望北时人从正北走到东壁偏北，人仍在镜前，留在 `0度`。到了才要读东壁上的门、物或字，下一拍换 `90度`。东壁这一格已是侧端出画，就在镜前的最后一点切开。望东时终点已在正面上，起点那一截北壁还在画面里，就留在 `90度`。

四项有一项不过，才离开，按下面重锁。禁止先选度数再倒推机位。侧面残缺而本拍不读那一壁，不算不过。

- 要看见的面在上一角是背：`机位侧=` 改成正前，按面朝表重算望向。反打时望向差 180°，轴侧不变，`axis_crossing=PlannedReverse`，`ENV变=是:反打`，`机位变因=反打`。禁止用差 90° 的角冒充反打。
- 正前那一向承载不了已锁景别：改到仍能看见要求的那一面、并且向距承载得了的正交角。侧面先试落在已锁轴侧的那一侧。`ENV变=是:向距承景别`，`机位变因=切角投影`。四个正交角都承载不了，才把景别收到最宽那一向允许的最大档；上一角就是这一档，就留下。写 `向距收档=是`。
- 必见的人在镜后，或必见的陈设在画外：先试正前。正前仍看不见该具，再试轴侧那一侧、另一侧、正后，取第一个能看见它、且承载得了景别的机位侧。四面都看不见，或必见项分属两个对向角 → 拆拍。`ENV变=是:覆盖不足`。读脸、口型、人载要看的正面，不因为另一件道具在画外而改掉正前望向；该具不进 `可见=`，或另拆一拍。禁止为了看见它而改甲的站位或朝向。
- 人载相对变了：机位侧改到新的相对。本拍拍摄要求是读脸时，后方跟拍改为正前，不拧骑手朝向。
- 载具档主名变了：`ENV变=是:整机换主|出舱切主环境`，度数仍由本拍望向推出。
- 上拍是空镜，本拍第一个人在该角镜后：按这个人的面朝重锁。

沿用成功，要读的脸在本角是正面或侧面：`表情换环境评=保持`。离开的原因是看见背：`表情换环境评=改挂:{正前|左侧|右侧}`，侧写重锁后的机位侧。按正前刚刚算出的望向看见的就是正面，禁止对它再写改挂。不能改挂则 `本拍不写脸`。无神色写 `无`。禁止拧人的朝向凑正面。

场第一拍：`机位变=开场｜机位变因=首拍｜机位切换=无｜ENV变=否`。其后只有环境名变了才 `机位变=是`，并写 `机位切换=到{本拍机位锚}{本拍机位侧}{本拍机位距}`，这三个值与本拍机位行相同。不写上一拍机位在哪。`机位变=否` 时 `机位切换=无`。变因闭集=`反打|切角投影|换主拍|过肩换框|进出衬托|卖点加压|AI优势位`。景别变化留在同一环境时，变因仍是承上。

**望向推出环境名**：望北→`0度{主}`，望东→`90度{主}`，望南→`180度{主}`，望西→`270度{主}`。`{主}`=本拍 `载具档=` 已锁的那一族。望向只换度数，不换主名。`触发=Master` 不是 `0度` 的同义词。开场、第一刀，都不自动粘 `0度`。禁止先选度数再倒推机位。禁止把 `主拍ENV=` 直接写成 `当前环境=`。

一拍只挂一个已声明名。盖不住，或同框有戏的具名超过 4 个 → 拆拍。同主同向只一行，不因为景别、过肩、反打另起后缀。上游写了扭曲、变色、粒子化，或标了环境改观，满幅和维持的拍才挂 `{N}度{主}_{状态}`，状态词跟上游；余波回落后回到没有状态的那一行。只有空镜资产本身必须仰看天花或天空，才另建 `{N}度{主}_仰天`，并写 `特别表述=仰天:{一句可核销空镜}`。普通四方行禁止写 `特别表述=`。仰天行禁止标成衍生的衍生。只是镜头角度为仰拍、航拍，而环境仍是平视四宫的，不建仰天行。

### 衍生环境提取（切环境图，不是给人换算）

普通行名=`{N}度{主名}`，N∈0/90/180/270。主名逐字等于所属主环境。禁止 `Beat:`、`文戏:`、`Ndeg` 当名字。

每行写入提取块：名称、所属主环境、`view_angle_from_main`、类型、触发、`活动适配`、`可见内容白名单`、`可见边界`、`不可见内容`、`背景=`、`画左=`、`画右=`、`画外=`、`生成提示=`、`lens_profile`、`axis_crossing`、`spatial_axis`。

`背景=` 照抄主环境该向已点名的主体。`画左=` 照抄左转 90° 那向，`画右=` 照抄右转 90° 那向，`画外=` 照抄对向并标（不可见）。禁止改写、禁止把角色和可移动道具写进这四键、禁止填无。对应向没有主体 → 回流环境规划。这四键是该角度环境图的固定陈设，不是角色站位。

`生成提示=` 必须能检索到 `截取宫格=`，并与 `view_angle_from_main`、主环境 `四宫度数=` 一致。主环境四宫已经写了度数，就按那一行裁；旧稿若是右下 180、左下 270，按旧行裁。缺行才用 0→左上0度，90→右上90度，180→左下180度，270→右下270度。另须 `远锚=`。远锚照抄 `背景=`，禁止用画外主体。生成提示只标切哪一格。不抄开篇【北壁】【东壁】【南壁】【西壁】【中区】【光学说明】正文，不写路怎么铺、地面纹路、中部逐件、画面左或靠近镜头。开篇世界内容不写入生成提示，也不交给生图模型。重生修正从主环境中文提示词抽取【定位】【色彩说明】整节，【主体外形】只留该格 `[@名]` 点到的行，【四向拼图】只留共享句和该格。光学、结构和摆位用该格已写成的正面、左侧面、右侧面、中部、源体可见、源体画布位、高度带、影子投向。16:9 是切割比例。本拍成片宽高比另写机位行 `画幅=`。生成提示不重写桌椅朝向，也不进人行。

`可见边界=全画幅` 无效。必须用具名实体写清左界、右界、上界、下界。左界、右界和 `画左=`、`画右=` 是同一批件。沿着短的一侧看路时，写出路的左右截断，禁止为了把路的全长收进来而把边界扩到两端。

白名单只写固定陈设及其可见面。禁止写入人名、动作、表情。主环境已经点名 `背景微动件=`，而且本角看得见，就写入白名单，不另造，也不改它的落点。舱内 0 度望向挡风，不写后排座的正面。90 度与 270 度须列出全部座位，并标近侧和远侧的可见面。驾驶舱里后排和司机要同时看见，只允许 90 度或 270 度。对向不可见只约束舱外的街景，禁止把近侧座位整排写进 `不可见内容`。

不在提取行写 `简要特征=`。程序按各拍用到的 `锚=`、`机位锚=` 归入该衍生。

本拍必见的锚、承托、手持可见面、出入口、特效命中面，必须落在这一角的白名单里。取用、开门、递接还要同时看见执行的人、承托、道具和被读的那一面。只写「桌区全部面」不等于看见酒盏。走位里本拍要读的锚、承托和出入口必须在白名单里，并且要读的那一壁是本角正面。人经过的空地不因为不在白名单里换角。侧壁上的件，只在本拍要读它的那一面、而这面已经残缺时，才算没盖住。直线上有障碍，绕开的那一侧也要进必见集，一拍装不下就拆拍。已入场但本拍不必看见的人，仍占世界位，不为他改挂。纯声音不进必见集。一拍的必见项分属两个对向角 → 拆拍。

场核的 `细节特写参考`、`贯穿保护` 必须落在已声明的衍生里。`反馈特写参考` 要在同一拍或紧邻的切角里读得到。`运镜参考` 要有连续可见的空间。

拆拍时，过程和特效句按角分完，禁止吞掉。每拍自备【配乐】【音效】和分布图，从 1 重新编号。场级 `承接=`、`节拍=`、`落地=` 与输入的 B 号对齐。`拆拍依据=ENV覆盖|角色超限|群演疏离|占用换主`。拆开之后每一拍仍是一个动作或一个反应。禁止把没有因果关系的两件事揉回同一拍。不改对白、因果、左右手脚、取用、朝向和门的开闭。

## 自检

- 封套完整，末行是结束标签。每拍原文在分布图之前。没有回写主环境。没有【取景锁定】。没有 `宫格=`。
- 甲先于乙。人行没有画面左、画面右、靠近镜头、远离镜头、前景、中景、远景。人行 `纵深推=无`。走位和动作方向用东南西北，写成从哪一向到哪一向，不用左右远近。方向在该句正文里。飞出、跑开、向前、后侧、身旁、前送、走至、案角，只在 `站位变因=` 里有罗盘 = 失败。走和递各有一条起止。沿的是主环境或动线里已有的东沿、南沿、西沿、北沿或路名，没有沿手臂、沿桌边、沿一边。开拍站位已经在这一条边上：侧等于这一沿，偏是起点端，距离是贴身或一臂。有走或递时，开拍在这一沿的起点，停下在同一沿的另一端，只一个罗盘向，朝向顺着走向或对着要碰的人。斜向、偏到沿外、沿一条不存在的路 = 失败。无挡 `绕=无`。有挡写了绕过哪一具的哪一向，以及绕开时从哪一向到哪一向。没挡却绕、或只写绕过不写从哪一侧 = 失败。本拍侧、偏、距仍是开拍，不写成停点。停点写齐侧、偏、距。下一拍开拍的这三项等于停点。停点只写一侧、下一拍偏收成无、或下一拍仍留着开拍的侧 = 失败。
