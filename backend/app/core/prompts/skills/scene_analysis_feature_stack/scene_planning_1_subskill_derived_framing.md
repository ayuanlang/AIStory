## 成稿只认这一套

后文用来选定望向、景别和距离的词，只留在推理里。写成稿时只认下面这一套。后文与这一套不一致的，按这一套写。

- 人与独立道具的位置只写 `锚=`、`X=`、`Y=`、`Z=`。X 东为正，Y 北为正，Z 向上。档是贴身、一臂、两步、三步、五步，正中写轴上，沿边只偏到一头写端。不写 `侧=`、`偏=`、`距锚=`、`距种=`、`层=`、`触点=`、`落点据=`、`站位=`、`北=`、`东=`、`距原点=`、`在桌=`、`落在=`、`离平地=`、`台面心点=`、`背对=`、`侧序=`、`下一位=`、`距下=`、`同簇相对=`、`在其左=`、`在其右=`、`在其前=`、`在其后=`。同一侧的顺序写进这一轴的档或端。挽着写在 `触=`。
- 在场的每个角色，以及有正反面的每件道具，每拍都写 `朝向=` 和 `罗盘朝向=`。开拍朝向的对象抄文戏身朝。坐着且没有转身，`罗盘朝向=` 抄座朝向，不从对面的人站在哪一侧倒推。走向与开拍朝向相反时，正文先转身，`朝向终=` 写下，下一拍开拍才改。不把本拍开拍朝向改成走向。
- `机位侧=` 只写东、南、西、北，站在望向对面：望北=南，望东=西，望南=北，望西=东。正前、正后、自身左、自身右、左肩后、右肩后只用来推出望向和拍法，不写入 `机位侧=`，也不写入 `机位切换=`。`机位切换=` 写成到哪一具的哪一侧、哪一档。
- 机位行必须写 `镜型=` 和 `拍法=`。拍法只许正面、背面、侧面、过肩、双人同框。人距近时镜型是正反打，人距远时镜型是单人正拍。上游 `追逐覆盖=` 是追击视角、过肩、双人同框或航拍全景时，世界距是远也同框，对方进可见。对白的句眼和关键反应不走这条。关系角不在这一步写死。景别、机位距、机高和背向角色的落点都锁完之后，按「背向与落点定关系角」选定干净、过肩、过头或过腰。俯仰若再改机高，按「机高锁完再核关系角」只改关系角。四步有一步不过，要读的那张脸拍法仍是正面，关系角=干净。四步都过，拍法=过肩，被看者仍按正面核侧脸。两面必须同时看见才留在同一拍，拍法=侧面。已经拆开的各拍只拍该拍那一面。
- 单人表演，含开场、收拍、单人动作和单人走位，景别用中景、近景、特写。全身离开画面才用全景。远景和全景只给空间交代，以及纯无人空镜。追逐覆盖的航拍全景用远景或全景，追击视角和双人同框可以用全景，双方都要在画里。

- 不写 `针对=`、`机位=场内`、`原文景别=`、`原文角度=`。与 `框主=` 相同的 `近侧框主=` 不写。值为无或否的键不写，含 `ENV变=否`、`落幅环境=无`、`载具档=无`、`可兼=无`、`axis_crossing=None`、`机位切换=无`。`门窗态=无` 和 `盒态=无` 是这一行本身，没有这类件时仍写。

## 两段职责（最高）

按单场调用。输入=已注入的全部【主环境】【未落清单】+ 文戏场核与最终 Beat。同一场注入了当下、重生、闪回、回忆、梦境、蒙太奇多块时，每一块都读。拍落到哪一块，站位、锚和 `基准=主环境:` 只用那一块的主体和主舞台区。禁止用当下的桌椅给定重生、闪回或回忆那一拍的站位。本拍主名只取本场已注入的【主环境】注册名，逐字。拍首 `蒙太奇链=…｜地点={名}` 的 `{名}` 与某一块注册名逐字相同。旧稿若写成 `主环境=`，同样只对这个名字，这一拍就落在这一块上，与上一拍是不是同一块无关。链上的字对不上任何注册名，本场又只有一块 `主环境角色=闪回|回忆|重生|梦境|蒙太奇片段`，这一拍改挂这一块的注册名。角色对得上的块多于一块，或注入里没有这一处 → 本拍停写，回流环境规划。不把人钉在当下主环境里。链上的字、拍文里的地名、三年前、当年、旧时、回忆中、闪回里，都不收成 `{N}度{新名}`。提取块写 `{N}度{对上的注册名}`。缺了已对上的那一块，或这一拍仍挂着另一块，都是失败。新造一行所属主环境不在注入里的衍生，同样是失败。

**衍生环境只切自注入的主环境（最高；蒙太奇、回忆、闪回同此）**：每一行 `[DERIVED_ENV]` 的 `所属主环境=` 逐字等于上面对上的那一块注册名。名称是 `{0|90|180|270}度{该注册名}`。上游写了扭曲、变色、粒子化，或本场有不可逆环境变化且注入里没有对应的变化后主环境，才许加 `_{状态}`。后一种是衍生的衍生：各度仍写 `{N}度{主}_{状态}`。程序先合成衍生主环境 `{主}_{状态}`，基于被依赖主环境的四格拼图，对同一主体的相关内容四格一起改，各度再从这块衍生主环境切割。状态词跟变化本身。泛黄、虚化、黑白、叠化、光晕仍挂这一块，不写成另一块主环境。`背景=`、`画左=`、`画右=`、`画外=`、可见内容白名单照抄这一块该向已经点名的主体。第一刀的 `生成提示=` 只写截取这一块的宫格和远锚。衍生的衍生不写截取宫格。各度的参考依赖是这块衍生主环境，不能是原来的主环境，也不能是同角第一刀。回忆、闪回、蒙太奇的正文不另写一套墙、街、桌椅或陈设。❌注入注册名是「前世林宅正厅」，链上写「三年前的旧宅」，提取块写成 `180度三年前的旧宅`，背景按拍文另写老街。✅提取块写 `180度前世林宅正厅`，背景照抄这一块南向已点名的主体。

**衍生度数只许四向（最高）**：每一行衍生的名称度数和 `view_angle_from_main` 只许 `0`、`90`、`180`、`270`。第一刀、仰天、衍生的衍生都用这四个数。禁止 45、135、225、315，禁止小数，禁止「约 90」。仰天不另起第五个水平度数，仍用原来的 0、90、180 或 270。

**全场调度（先于逐拍；最高）**：落笔任何一拍的机位之前，先写一次【全场调度】。只读已注入的主环境，不新造地方。一块场可以有多块主环境，逐块点名。然后写本场每个人、每件独立道具的开场位置：有参照主体就写锚和相对这一具的参考位，空旷才写相对原点的绝对位。再写本场行动：谁从哪一处做到哪一处。最后写行动结束后的落点，同样是参考位或绝对位。位置只用东南西北和 X、Y、Z。这一段不选衍生环境，不写景别，不写画面左右。后面每一拍的开拍位置必须接得上这一份，落点必须落在这一份已经写下的终点上。缺了【全场调度】就写逐拍，不合格。格式写在衍生环境名之后、第一拍之前：`环境=` 逐字列出每一块已注入主环境。每人、每件独立道具各两行：`开场=` 名字、所在环境、锚或原点、X、Y、Z、朝向；`落点=` 同样五项。中间一行 `行动=` 谁从哪一处做到哪一处。不写景别，不写度数。

**动作空档（最高）**：开场位置按这一场要做的动作留出空档。空档写进人的开场 X、Y、Z，是人站的世界位。镜头构图的 `留白=` 仍只写视线前、运动前或无，不代替这一档。人要沿桌、案、台、床的外沿走，或隔着这一具递、伸，开场就在这一沿外侧，贴身或一臂，从开场到落点的这段留在占地外面。递和伸不把身体写成穿过这一具。行动结束后的落点另写一套锚、X、Y、Z。后面每一拍的开拍接开场或上一拍已经更新的落点。

**甲 · 世界站位（全场调度之后，逐拍展开）**：按【全场调度】把每一拍的开拍位置、朝向、姿态、手持和本拍走位写进分布图。每个人、每件的开拍位置只写一次：锚、X、Y、Z。不在正文里再写一套左右远近，也不写桌前、桌后。没有走位，下一拍全文抄这一次，不另起一种说法。不读机位，不读景别，不为了构图、读脸或好看改锚。环境主体彼此怎么摆，已经在环境资产参考图里，本层不重写。环境主体只当人的锚名。

**乙 · 正拍，然后环境，然后机位（甲锁死之后）**：每一拍先定主拍对象，再只按这个主拍对象选出衍生环境，最后才写机位距和俯仰。主拍是这一拍有剧情的主体：行动、说话或反应的角色；必须同框时是这两个人；剧情在群演身上时是这一簇；没有这些、而是特写某一具时，主拍是这一具。没有剧情的主体不进主拍，画外也不因此换度。要正脸取该人背对的那一向，要背面取面朝的那一向。人背对的那一壁当背景看见的是脸；要后脑时这一壁在镜头后。后脑和这一壁都要当背景，拆成相邻两拍。拍法、镜型、人距、景别见「成稿只认这一套」和「拍间按人距衔接」。环境名锁死后，镜头只朝这一度的正面。乙不改甲的锚和走位。

分布图和正文只描述角色、独立道具。床相对镜、椅相对桌、`主体分组=` 不在本层重写。

成稿只交两块：
1. 场头 `────【衍生环境】────` 下只写 `[DERIVED_ENV_EXTRACT_START]…END` +【本场衍生环境名】。紧接着写一次【全场调度】。禁再写 `- \`{N}度\`：` 子弹表。禁回写【主环境】【未落清单】【场景名称】`[SCENE_CONTENT]`。

### 成稿位置：XYZ（最高；类主环境）

只量角色和独立道具相对锚，不重写环境主体彼此的米。分布图头一行写一次：`轴=X线=东西，东为正｜Y线=南北，北为正｜Z=向上｜上=南｜下=北｜左=西｜右=东｜原点=中心｜原点主体={中部具名}`。没有中部具名时，原点主体写本场已经用来当原点的那一具地上主体。全场只这一行，不按望向改轴。

每人、每件独立道具把相对锚的位置收成三键，三键都写：

| 键 | 写法 | 意思 |
| :--- | :--- | :--- |
| `X=` | `轴上`｜`东{档}`｜`西{档}`｜`东端`｜`西端` | 相对锚中心的东西。正中写轴上，不写 0 |
| `Y=` | `轴上`｜`北{档}`｜`南{档}`｜`北端`｜`南端` | 相对锚中心的南北 |
| `Z=` | `贴地`｜`椅面`｜`榻面`｜`床面`｜`台面`｜`底下`｜`离平地{档}` | 脚或件底在哪一层。站、盘腿、俯卧而脚在地上写贴地 |

档只许贴身、一臂、两步、三步、五步。锚是另一个人、并且两人隔着同一件道具时，这一轴不写步档，写 `南隔:{段}`｜`北隔:{段}`｜`东隔:{段}`｜`西隔:{段}`，段等于留在两个接触点之间、体外的那一段。离锚的那一轴写档。沿着这具长边偏到一头、这一头没有另量出一档，写 `东端|西端|北端|南端`，不另造米。两轴都离中心，两轴都写档。坐在已经点名的椅或凳上：锚就是这张座位，`X=轴上｜Y=轴上｜Z=椅面`。躺或靠在床、榻、沙发上：锚是这一张，头所在的一端写进 X 或 Y，`Z=床面|榻面`。件在台面上：`Z=台面`，X 和 Y 都要写，两件不得同一对 X、Y。人在件底下：`Z=底下`。空旷、锚=原点：X 写东或西或轴上，Y 写北或南或轴上，Z=贴地，不再写 `北=` `东=` `距原点=`。封闭舱不另写 X、Y，排是南北，座=东|中|西就是东西，`Z=椅面`。

同一锚上两个人或两件的 X 与 Y 都相同＝失败。沿这一侧把下一位改到下一档或改到另一端。正文没写谁靠东，按本拍点名顺序，先写的靠东端或北端，后写的靠西端或南端。

选定可以想这一具的哪一侧、哪一端。落笔只留上表的 X、Y、Z。

### 在场（每人、每件只一档）

开场在场，或待入画。禁止第三档。中途无开场、无入画却出现=失败。盒内未取出件不开场。对白点名 ≠ 已经在场。

| 档 | 成稿 |
| :--- | :--- |
| 开场在场 | B1 占世界位。只写 `在场=开场`。不写 `入场=`、`入画@无`、`经=无` |
| 待入画 | B1 只写 `入场=待入画｜入画@B{n}｜经={具名出入口或容器}`，不占 B1 世界位。人还在画外、本拍镜头不拍这个人、这个人也不在这一拍画内开口，才继续 `在场=待入画`，不写坐标。入画那一拍人已经在画面里，按「已经在画面里就占位」写开拍坐标，`在场=入画`。走完的停点下一拍写 `在场=入画落定` |

B1 写下全部开场者，含无动作的人。其后每拍仍写下全部在场者。本拍没戏 ≠ 删行。纯无人空镜这一处不收人。窗外特写和本场仍有人的拍，人仍占世界位。上拍在场、本拍无行、两侧都没写离场=失败。

**已经在画面里就占位（最高）**：本拍 `主拍对象=` 是这个人，或 `可见=` 写了这个人，或本拍有画内开口 `开口 | CHAR:[@这个人]`，这个人已经在画面里。这一拍写 `在场=入画` 或 `仍在`，并写 `锚=`、`X=`、`Y=`、`Z=`、`姿态=`、`朝向=`、`罗盘朝向=`。开拍位置是这一拍动作开始的那一点。走完才到的停点不写进这一拍。上一拍已经在场写 `仍在`。禁止这一拍仍写 `在场=待入画`，禁止不写坐标。

场上从一端走到另一端是走位。地面、坪、街的北端或南端是这块场地上的位置，不是画外入口。人已经在这块地上开口、被正拍，开拍锚就是这块地面，位置写在走出的那一端。禁止用 `经=` 这一端把人留在待入画。

✅甲从场地北端向南走向乙，本拍开口，主拍是甲，乙在南。甲 `在场=入画｜锚=这块地面｜X=轴上｜Y=北端｜Z=贴地｜姿态=站｜朝向=面向乙｜罗盘朝向=南`。❌同一拍写成 `在场=待入画｜经=地面北端`，没有坐标，也没有罗盘朝向。这一例只给已经在这块场地上、从一端走到另一端的人。首次入画和离场不套这一例。

**进出场必须经出入口（最高）**：中途才进场、才离场的人，必须有一口。口是主环境已经登记的门、门口、巷口、舱门、梯口。开盒、开匣取人取件，口是那只容器。开场已经在场、已经坐着或躺着的人不是入画，开拍就在那一具上。

首次入画的开拍写在这一口上：门外一侧或门洞。成稿写东南西北，收进 X、Y。走到室内桌边、椅边的停点从下一拍才写成开拍。出画走向同一口。人还在口内，这一拍不写离场，走出之后的下一拍才离场。人在镜前还是镜后由建置按本拍望向评，本层不按镜头后面改停点。

无遮挡的地面正中、原点、舞台正中、锚不是门而 X 与 Y 都是轴上，不是口。从这种空处走进画面，就是突然冒出。禁止把首次入画的开拍写在这里，也禁止人还在这里就消失。锚已经是这扇登记的门，X 与 Y 都是轴上，人就在这扇门的门心，这一句合格，不是地面正中。明文传送、幻影生成仍要落在已登记的那一口或那一具上，不落在无遮挡的地面正中。入画这一拍的 `站位变因=` 只停在门内侧。不得把停点写成桌子、椅子的某一侧。走到那一具旁边从下一拍才写开拍。

✅乙从南门进：入画拍 `经=南门｜锚=南门｜X=轴上｜Y=南贴身｜Z=贴地`，人在门洞。下一拍才到桌北。✅从西墙正中的门进来：`锚=这扇门｜X=轴上｜Y=轴上｜Z=贴地`，人在门心。站位变因只写停在门内侧。下一拍才写桌子西侧。❌同一拍站位变因停在办公桌西侧。❌乙首次出现就 `锚=八仙桌｜X=轴上｜Y=轴上`。❌从厅中空地走进来，面前没有已登记的门。

### 落点三档（逐人只一档）

先定本拍人站在哪一套世界里（见下「载具站哪一套」），再选方式。同人同拍禁混写。

1. **封闭**：人坐在已锁舱／排椅／操纵席 → `方式=封闭`。写满槽位。禁用原点或另一件家具顶替座位。禁 `位于 PROP:[整车] 的驾驶座`。
2. **相对**：近处有合格参照 → `方式=相对`。只选一个参照。有这一具，就不再同时挂原点、第二件家具或另一个人。这件同时连着另一个人时，被连上的人改以拿着的人为锚，见「人位相互参照」。剧情要挂四壁主体、中部又有主体时，改走下面的双主体，这是唯一允许同时写出两具环境主体的情况。
3. **绝对**：中部没有具名主体，舞台里也没有桌、椅、床可挂，四周只剩远山、路、天 → `方式=绝对`，`锚=原点`。中部已经写出桌、案、椅、床，禁止改走原点。禁止把整片沙、草、天当锚，禁止为了有锚去新造沙丘。规划已经造好的特异挂靠，只在人确实靠着它、且中部没有具名主体时才当参照。原点的东西收进 X、南北收进 Y，不另写侧、偏、北、东、距原点。独立道具不得抄某人的北东却没有接触。
4. **配饰**：仅开场已经戴上或拿着的才走 `方式=配饰｜挂靠={角色}｜部位=`。在盒内 → 独立道具待入画。这件同时连着另一个人时，方式仍是配饰，挂靠仍是拿着的人，另写 `共同=`。

**一个参照**：只选一具。正落在这一侧正中，这一轴写轴上；靠这一具的某一端，写东端、西端、北端或南端。中线和端都是这一具的。手上的物以拿着它的人为参照。这件同时连着另一个人时，参照仍是拿着的人，共同关系另写。走位只相对这一具。人自己或这件物在动时，运动方向另写从哪一向到哪一向。

**两条线（最高）**：挂环境和相互关系分开。先挂环境，再写关系。关系不改锚。同一件道具已经连着两个人时，被连上的人改以拿着的人为锚，见「人位相互参照」。高优定位点不走第二条。

**高优定位点（最高）**：有 `戏用标识=` 时，第一个人和独立道具先挂那一具。是椅，锚就是这张椅；是桌，锚就是这张桌。其余人的锚是第一个人，写在他的东、南、西或北。另一张椅不升成锚，椅名写在姿态里。被同一件连着的人改挂拿着的人。没有戏用标识、人已经坐在点名的椅或凳上，锚就是这一张。同一种座位多于一张，必须点明哪一张：已注册的独一名，或这一侧从东到西、从南到北数第几把。顺序写进这一轴的端或档，不写左起第。本场只有一张已注册的椅，写出注册名。只写坐在椅子上，不合格。道具在身上、且没有再连着另一个人，方式走配饰，写 `挂靠=` 和 `部位=`，不再对桌子写距离。连着另一个人时，握持仍挂拿着的人，再写共同。人没坐在座位上，仍挂环境。手上的物不改这个人的环境锚。封闭舱已锁排座，不再对舱内另一具重定。床、榻、沙发不在完成之列：锚是这一张，还要写哪一侧、姿势、头朝哪、面朝哪。侧用床头、床尾或东南西北。姿势用仰卧、侧卧、俯卧、靠。只写躺在床上，不合格。✅坐在主位皮椅上，不再写离桌子一臂。对面的人站在这张座朝向的那一侧。座朝南，对面的人相对桌子写 `Y=南一臂`，罗盘朝北。坐着的人收成轴上，不把对面的人写成北一臂。`站位承载=` 写了南侧，写南侧。✅仰卧，头朝床头，面朝上。❌两把客凳只写坐在椅子上。❌只写躺在单人床上。

**道具共同关系（最高；压过只挂拿着的人）**：每一件独立道具在锁挂靠之前，先问它这一拍是否同时连着两个或更多人。只被一个人拿着、佩着、背着，没有再碰到另一人，仍只挂这个人，不写 `共同=`。刺入、没入、抵住、捆住、套住、勒住、两人同握，或一端在这个人身上、另一端在另一个人身上，握持仍挂拿着或主要负载的那一个人，`挂靠=` 和 `部位=` 不改。还必须把和每一个其他人的关系写全。只写谁握着这件，不合格。

每一段关系写四样：那个人的哪一处，这件的哪一段，怎么连上，连到什么程度。程度只用剧情已经写出的比例或部位，如一半长度、没至柄、抵在喉前。剧情没写深浅，不另造一半或没至柄。不写这件的颜色、形状、材质、纹样。方向用东南西北：从拿着的人伸向被连上的人，写从哪一向到哪一向。不把锚改成这件道具。

**人位相互参照（最高；只在这件同时连着人时）**：连着的两个人，位置互相参照。距离等于这件隔在两个接触点之间、留在体外的那一段。一半长度刺入胸口，体外还留一半，两人接触点相距就是这留在体外的一半。同握、抵住、捆住、套住，距离等于这件在两个接触点之间的那一段。不把这段收成贴身、一臂、两步、三步或五步。

被连上的人这一拍 `锚=` 改成拿着的人。沿这件的走向，写在对方的哪一向；这一轴的距离写这一段，写成 `南隔:{段}`｜`北隔:{段}`｜`东隔:{段}`｜`西隔:{段}`，不写步档。另一轴写 `轴上`。`Z=` 仍按站或坐。拿着的人环境锚留下，用来钉在主环境里，同时写回 `互参=`：对方在自己的哪一向，隔着同一段。被连上的人也写 `互参=`，方向相反，距离相同。只写一方、两边距离不同、或被连上的人仍按桌子另写一套间距，不合格。已经坐在点明的椅、凳上的人，锚仍是这张座位，`互参=` 仍写，这一段必须和这张座位到对方的间隔是同一段。

两人各写：`互参=CHAR:[@对方]｜隔=PROP:[长剑]｜距=留在体外的一半｜向=南`。对方那一行 `向=` 相反，`距=` 相同。

开拍已经是这个状态，写在本拍道具行：`共同=CHAR:[@乙]｜处=胸口｜段=剑身一半长度｜态=刺入｜从=CHAR:[@甲]的右手｜向=南`。连着的人多于一个，用 `；` 再接一段。本拍动作里才连上，开拍行仍只挂拿着的人，不写 `共同=`；这一拍正文的动作句写全四样和从哪一向到哪一向。下一拍道具行才写 `共同=`。递出还没交到对方手上，物仍在递出的人身上，不写 `共同=`。

✅CHAR:[@甲] 右手握着 PROP:[长剑]，剑身一半长度向南刺入 CHAR:[@乙] 的胸口。`挂靠=CHAR:[@甲]｜部位=右手｜共同=CHAR:[@乙]｜处=胸口｜段=剑身一半长度｜态=刺入｜从=CHAR:[@甲]的右手｜向=南`。甲的环境锚留下，`互参=CHAR:[@乙]｜隔=PROP:[长剑]｜距=留在体外的一半｜向=南`。乙 `锚=CHAR:[@甲]｜Y=南隔:PROP:[长剑]留在体外的一半｜X=轴上｜Z=贴地｜互参=CHAR:[@甲]｜隔=PROP:[长剑]｜距=留在体外的一半｜向=北`。❌只写甲右手握着长剑。❌乙仍写在桌子南侧两步，没有写隔着剑身留在体外的一半。

**同侧顺序**：同一参照、同一侧上的人是一组。南侧、北侧从东到西，东侧、西侧从南到北。沙发同一侧按座面长边走。≥2 人必须沿这一侧逐个点名，间隔写在这一轴的档上，挽着写在 `触=`。圆桌不走这一条。这一侧只有一人，这一轴写轴上或该端。

**参照怎么选（最高）**：有戏用标识时，第一个人和独立道具先挂那一具，其余人挂第一个人，不按更近改选别的桌椅。没有戏用标识时，环境锚先按这一拍要碰到的具来定。去某一具上取、放、端、写，锚就是这一具。正文已经写明人站、靠、扶、推、拉的那一具，锚用这一具。从门或其他入口入画，锚用该入口。这些都没有，先按下面「参照先对主环境方向」对上人所在的那一向，再只在这一向已经列出的具里比较距离。距离相若是同一档，或只差贴身与一臂这一档。相若时才用这一向里的中部：桌或案，没有桌案再用椅，床、榻是这间的表演承托时同样可挂。这一向里另一具近出一档以上，锚用这最近的一具。落点不在这一向的具，不进入这次比较。这一具须已在主环境名单里，轮廓清楚。墙面、地板、天花不因更近而当锚。人站在所选这一具朝向舞台中间的那一侧。反打、切角、人朝向窗外、本角 `背景=` 和 `远锚=`，都不把锚改成四壁上的那一具。封闭舱仍走排座。中部没有任何具名主体，`锚=原点`。手上的物和佩戴不改人的锚。正文没写靠门、靠墙时，不因为门更近就贴门贴墙。关系顺序在锚写完之后再写。

**参照先对主环境方向（最高）**：选参照之前，先读注入主环境已经写明的各个方向。北、东、南、西各列了哪些具，中心列了哪些具，每具的 `落点=`、`壁别名=`、`同面序=` 是哪一向。人站在哪，先对上这些方向里的具，再写锚。人在中心这一具和某一壁这一具之间，就用这两具：`锚=` 是中心那一具，`双锚=` 是这一向上的那一具，`在其间=` 是这两具，这一向收进 X 或 Y。落点不在人所在这一向的具，名字再眼熟、看起来再近，也不当这一拍的参照。禁止不看方向，只按「有一件家具」或「更近」挑一件。✅主环境中心是桌子、北壁是电视墙，人站在两者之间：`锚=桌子｜双锚=电视墙｜在其间=桌子与电视墙之间`，北收进 Y。❌不看北壁落点，改挂东壁的沙发。

**关系不跟衍生环境改（最高）**：反打、切角、换衍生环境，只改机位和望向。人相对主体的关系不改。在哪一具的哪一侧，或在哪两具之间，没有走位就逐字留下。人在桌子与电视墙之间，换到另一度仍是桌子与电视墙之间，不改成只靠桌子，也不改挂到落点在另一向的具。这一向落到本拍画外，`锚=`、`双锚=`、`在其间=` 仍留下，不改挂。✅反打后仍是 `锚=桌子｜双锚=电视墙｜在其间=桌子与电视墙之间`。望向变了，世界位不改。❌反打后改挂东壁的沙发。

**剧情例外（压过中部）**：本拍入戏要取放的那一具、正文写明站靠扶推拉的那一具、入画的那一口，都压过中部默认，锚仍是这具环境主体。要和某人交互，不把锚改成对方。已经由同一件连着的两个人除外，走「人位相互参照」。先挂这具，再写谁在这具的南、谁在北。取放或站靠的那一具在四壁、中部又有具名主体时，改走双主体。入画落定、这一拍的取物或交互已经做完、后文没再点名这一具，下一拍在距离相若、且仍对得上主环境这一向时回到中部主体；这一向里旁边那具明显更近，就留在最近这一具。不改挂到落点在另一向的具。只是脸朝向窗外、反打看见四壁、本角背景是墙，这一拍又没有取物或交互，距离相若时锚仍是中部主体。

**双主体（四壁加中部）**：剧情需要用四壁上的一具做参照，主环境中部又已经写出具名主体，人的位置写成在中部这一具朝向四壁那一具的那一侧。`锚=` 是中部那一具，`双锚=` 是正文点名的四壁那一具，两具都逐字用已注册名字。这一侧收进锚的 X 或 Y 一次。写 `在其间={中部主体}与{四壁主体}之间`。不写 `距锚=`、`距双锚=`、`侧=`。反打、切角仍是这两具之间，不收成只靠其中一具。机位锚是中部那一具。手上的物、佩戴、封闭排座不走本条。四壁那一具必须是主环境写在人所在这一向上的那一具。

功能附属单向，和距离一起看：椅、凳挂所配的桌；床头柜挂所配的床；手持、佩戴挂拿着它的人，同时连着另一个人时共同关系另写；桌上未持的碗盏挂那张桌。有功能宿主就挂宿主，不改挂更近的无关件。禁止互为参照：桌不得以椅为锚，床不得以床头柜为锚，持有人不得以手里的物为锚。两人被同一件连着时，人与人按「人位相互参照」，不走这条。

**锚必须独一**：同质两件不得当锚。选哪一具见「参照怎么选」和「剧情例外」。禁止用墙面、墙角、墙根、整片地面、地板、天花当锚，除非正文写明站在这一具旁，或本拍从这一口入画。地毯、地面纹路，只在中部没有桌、椅、床、且没有剧情例外时可以当锚。穿衣镜不单列道具行。人在镜前，中部已有床或桌，正文又没写站在镜前，锚取那张床或桌。需要的具不在名单里 → 回流，本层不另造。

**舞台**：表演拍的人必须落在【活动空间】`舞台范围=` 内。X 或 Y 的档不超过 `舞台大小` 对应轴。原点的 X、Y 不得把人送出舞台。走位走规划 `动线=`，不得穿立体障碍。缺舞台键 → 回流环境规划。禁止另起第二块表演地。禁止人站到舞台外墙根凑构图。

**关系序与同锚**：递、接、握手、对打、同坐、近身交谈，锚不改挂对方，另写 `关系序=`：谁在南、谁在北，或谁在东、谁在西。交付前物仍在递出的人身上，一臂可递。交互后物归接的人。正反分列的两侧都相对同一具。并排同向沿这一侧用 X 或 Y 的端分开。无近距依据时同锚角色≤2；角色组或明文贴身仍≤3。同锚角色>3 → 拆侧或拆拍。挂靠体不占这个人名额。

长桌、方桌围坐 ≥2 人：`锚={桌}`。南侧、北侧把顺序收进 X，从东到西；东侧、西侧把顺序收进 Y，从南到北。不写 `座=`，不写左起第。禁止只写靠桌。禁止写左长边、右长边。主客身份跟剧情。圆桌不走这一句。

**圆桌坐位（最高；压过侧序、四侧分座、其余人改挂第一个人）**：人坐在圆桌旁时，不把这一桌拆成东、南、西、北四侧，不写 `侧序=`，不写左起第几把。每人相对这张圆桌写钟点，再按顺时针逐个排。俯视上南下北、左西右东。12点在北，读图在下；3点在东，6点在南，9点在西。角度是相对正北的顺时针度数，每点 30 度，12点=0。钟点不是衍生环境的度数。禁止为了 1 点去写 30 度环境。衍生度数仍只许 0、90、180、270。

全桌一行：`圆桌序=顺时针｜桌={注册名}｜12点=CHAR:[@名]|空｜1点=…｜2点=…｜3点=…｜4点=…｜5点=…｜6点=…｜7点=…｜8点=…｜9点=…｜10点=…｜11点=…`。有人的点写这个人，空位写空。每人再写：`钟点={n}点｜角度=顺时针{度}｜顺时针序=第{k}`。有下一位再写 `下一位={下一个有人的钟点}`。k 从 12 点起，只数有人的座位，顺时针。全桌只一人不写 `下一位=`。锚是所坐的那张椅，这张椅的钟点与这个人相同。不把锚改成邻座的人。面朝桌心。罗盘朝向取朝向桌心的最近一方：11点、12点、1点面朝南；2点、3点、4点面朝西；5点、6点、7点面朝北；8点、9点、10点面朝东。读这张脸的正前望向与面朝相反：面朝南望北，面朝西望东，面朝北望南，面朝东望西。

**圆桌正反打**：换到同桌另一个人读脸时，望向改成那一个人的正前望。不强制与上一拍差 180°。两人的正前望相同，也就是同在 11点至1点、2点至4点、5点至7点或 8点至10点，留在这一度，不做 180° 反转。正前望差 90° 或 180°，都换到那一个人的脸所在的度。差 180° 仍写 `axis_crossing=PlannedReverse`。差 90° 写 `axis_crossing=圆桌换席`，`ENV变=是:圆桌换席`，`机位变因=圆桌反打`。这一下 90° 看见的是这一张脸。长桌、方桌、对坐、驾驶舱的反打仍必须差 180°。轴、靠墙换人、沿用里「反打必须差 180°」不套到圆桌换席。同桌谁可以挡在镜头前面，见「桌面谁可以当框」。差 6 个钟点但连线不正交的，不因为隔着桌心就写成框主。

**封闭舱槽位**（已入座必填；世界物理只用东南西北，禁止左起第）：
默认 `主驾朝向=南`，与环境规划已锁的朝向相同。操纵端、挡风在南，舱尾在北。面朝南时左是东、右是西。左舵前排两座：驾驶座在东，副驾在西。单人操纵席在中，仍朝南。`排=第N排` 从南往北数，操纵排=第1排。`座=东|中|西`。本排两座只写东和西，三座写东、中、西。`功能=驾驶座|副驾|后排东|后排中|后排西|操纵席|副操纵席|观察席|{原文具名座}`。`相对驾驶位=正是驾驶位|驾驶位东侧|驾驶位西侧|驾驶位东北|驾驶位正北|驾驶位西北|无驾驶位`。0度望北，对向座位正面；180度望南，见椅背和挡风。上游写成左起第K、从左到右、后排左、后排右、驾驶位左侧、驾驶位右侧、驾驶位左后、驾驶位右后，按面朝南译成上面这些词：左侧和后排左是东，右侧和后排右是西，左后是东北，右后是西北，正后是正北。成稿不留左起、左侧、右侧。剧本已经写明车头朝向另一向时，跟环境规划的 `主驾朝向=`，仍译成东南西北。座面朝向抄环境已锁的该席朝向，不因本拍机位改成面向镜头。后方的人在操纵员北侧，不得写到操纵员与前窗之间。换座必须有走位，下一拍才改槽。禁止把厅堂围坐套进驾驶舱。空座不写人行。舱内已经入座的走封闭；舱内站着的人才 `方式=相对`，锚=舱内固定件。同一排有驾驶座和副驾时，两人东西相距一臂，南北同深，抄规划 `主副驾距=一臂`。坐着侧伸手臂能够到对方近侧的手或扶手。递、侧头对视、说话、拍到对方肩，都在座位上完成，不离座走到对方旁边，也不把这段距离写成两步或三步。中控可以在两人之间，不改这一臂。单人舱不写副驾。前后排仍用排距，不用这一臂冒充。✅第1排、座=东、功能=驾驶座、相对驾驶位=正是驾驶位。✅第1排、座=西、功能=副驾、相对驾驶位=驾驶位西侧、距主驾=一臂。❌第1排左起第1个。❌后排左。❌驾驶位左侧。❌0度只见椅背。❌副驾贴西壁、与驾驶座隔两步。❌坐着的副驾先起身走到驾驶座旁再递。

**正反面道具必须写朝向（最高）**：驾驶舱、整车、飞行器、船、机甲，以及屏、镜、像、有正面的法器、有屏面的操纵台，都有正面和背面。在场的每一拍都写开拍 `朝向=` 和 `罗盘朝向=东|南|西|北`。正面是挡风、车头、机头、船头或屏面。背面是舱尾、车尾、机尾或屏背。默认跟环境规划已锁的 `主驾朝向=`。没另锁时挡风、车头朝南，舱尾朝北，`罗盘朝向=南`。剧本或规划已经把车头锁到另一向，跟那一向。不因本拍机位改成面向镜头。

整车、整机在画：道具行写 `朝向=车头朝{东|南|西|北}｜罗盘朝向=` 这同一向。舱内拍没有整车行，分布图头一行仍写 `舱正面=挡风朝{向}｜舱尾朝{对向}｜罗盘朝向=`。坐着的人朝向同一正面：`朝向=面向挡风｜罗盘朝向=` 与舱正面相同。封闭槽位不能代替这三键。没写朝向就排机位 = 失败。

侧面看见这具时，仍写车头的罗盘向，不写侧面朝镜头。车头落在东西轴上就写朝东或朝西。

✅整车 `朝向=车头朝南｜罗盘朝向=南`。✅侧面 `朝向=车头朝东｜罗盘朝向=东`。✅舱内 `舱正面=挡风朝南｜舱尾朝北｜罗盘朝向=南`，驾驶座上的人 `朝向=面向挡风｜罗盘朝向=南`。❌只写排和座，驾驶舱没有朝哪一向。❌车头朝向写成面向镜头。❌侧面写成侧面朝镜头。

### 开拍、走位、下一拍

分布图的 X、Y、Z、`朝向=`、`罗盘朝向=`、`姿态=`、手持，只写该 Beat 开始时的位置，等于动作发生之前。本拍走到、转身、坐下、取出、放下的结果，不写进本拍的 X、Y、Z，也不改写本拍开拍 `朝向=`。人还在画外的才不占本拍开拍站位。已经在画面里的人，开拍占在动作开始的那一点。转身的结果另写在本拍 `朝向终=` 和 `罗盘朝向终=`，下一拍开拍才写成这份终态。

变化写在本拍正文的动作里：离哪一具、从哪一向走到哪一向、停在哪一边或哪个点、转成面向谁、改成什么姿势、手持交给谁。有空间运动时，这一句里必须能读出从东、南、西、北的哪一向到哪一向。正文不必把开拍站位整段再抄一遍。`站位变=`／`朝向变=` 只记这条变化，不代替正文。

本拍开拍的 X、Y、Z 加上本拍动作，等于下一拍的开拍 X、Y、Z。下一拍全文写出。无变化则下一拍把上拍开拍全文再抄。禁止整行只写「承上」「同上」「见上拍」。切角、换景别、换衍生不构成这次变化。

**场记要接的新位置（最高）**：开拍位置里的空档保持到这一拍结束之前。本拍动作把人移到新位置时，停点写进 `站位变因=`，锚、X、Y、Z 写全。下一拍开拍逐字等于这个停点。这一拍的收拍位置就是下一拍开拍，场记按这一套更新。建置抄本拍开拍，入戏抄停点，下一拍建置抄这个新位置。分镜再抄建置和入戏。停点已经换到另一侧时，下一拍开拍写这一侧。开拍的空档留在沿外，不收进桌、案、台的占地里。

动作要碰到的那一具，人必须已经在它旁边或接触点上：取物、递、扶、按、推门，开拍的 X 或 Y 是贴身或一臂；坐下、倚靠，人已经在该座上，X=轴上，Y=轴上，Z=椅面。开拍不在这一具上，必须在该动作之前补一句从开拍处走到这一具，再做动作。补句只增不删，不改对白。分布图开拍仍是上拍终态，`站位变=是`。取到之后件才离身。人还在远处却写成已经取到=失败。

**上下拍世界差必须补动作（最高）**：逐人、逐件比较上一拍终态和本拍要落到的世界位。朝向对象变了，或锚、X、Y、Z、排座变了，不能只改分布图。补偿写在发生变化的这一拍正文里，放在新动作之前。本拍开拍的 X、Y、Z、`朝向=` 仍是上一拍终态。新朝向、新落点从下一拍开拍才全文写出。切角、换景别、换衍生不构成世界差，不补。灵魂出窍、元神离体、分身、残影，以及特效造出的另一具，与本体分名，可以同时在不同位置，这种差不补。

补偿按这段差选一种，写进正文，并写入 `朝向变因=` 或 `站位变因=`。方向仍是从哪一向到哪一向。

| 世界差 | 补偿 | 变因 |
| :--- | :--- | :--- |
| 只改了朝向对象，人还在原位 | 转身：从面向谁转到面向谁 | `朝向变=是｜朝向变因=转身:从面向{旧}转到面向{新}` |
| 位置变了，动线上没有必须越过的沟、台、槛，剧情不是追或赶 | 走动 | `站位变=是｜站位变因=走位:从{向}向{向}，沿{主体的边或路}，自开拍→停在{锚的哪一侧}` |
| 剧情已是追、逃、赶、冲，或这一段要快速越过 | 跑过 | `站位变因=走位:从{向}向{向}，沿{主体的边或路}，自开拍→停在{锚的哪一侧}` |
| 中间有沟、台、槛、障碍，或有高低差，走不过去 | 跳过 | `站位变因=走位:从{向}向{向}跳过{该具}，自开拍→停在{锚的哪一侧}` |

飞、被抛、出入画用原来的动词，不改成走。只看、不改躯干朝向，写回头或转头，不写转身。开拍朝向让要去的方向或要碰的那一具在身后，先转身，再走动、跑过或跳过。人还在原座，只是站改坐，写坐下，不另走；换了座，先走到新座再坐下。禁止人已经在新的一侧或新的朝向上，正文却没有对应的转身或位移。禁止整间的位置差只写转头。禁止只改了朝向却写成跑过。

换锚只当正文写明离开上一具。切角、读脸、挂靠落到画外，都不换锚。无路径却改锚或 X、Y、Z =失败。朝向对象变了，须有上表的转身，`朝向变=是`；本拍 `朝向=` 和 `罗盘朝向=` 仍是开拍，`朝向终=` 写成转完所对的对象，`罗盘朝向终=` 写成转完的东、南、西或北。下一拍的 `朝向=`、`罗盘朝向=` 全文等于这一拍的 `朝向终=`、`罗盘朝向终=`。`朝向变=` 不能代替正文，也不能代替 `朝向终=`。剧情要改朝向、正文没有这段动作，就补在该动作之前。

**开拍与终态一致（最高）**：开拍等于上一拍终态。人的朝向变了，他所依附的那一具朝向一起变。只转眼睛，那一具不转。人已经离开再转向，按起身或换位写。

无走位、无出入画、无转身、无离身、无取出：人与独立道具的世界键把上拍终态再抄一遍，写 `在场=仍在`，不写站位变、朝向变。

本拍离开：本拍仍留行，写出离开前的锚、X、Y、Z，`在场=本拍离场`。下拍不再占位。离如果是走出、飞出、被抛出，正文写明从哪一向到哪一向。

未松开的接触：双方原样抄 `触=`，同锚。正文写松开之后，下拍不写 `触=`。本拍定位仍是开拍接触态。

### 动作与运动的方向

角色和独立道具只要有空间运动，正文和 `站位变因=` 都写明世界方向。方向是主环境罗盘上的起点向和终点向，写成 `从{东|南|西|北}向{东|南|西|北}`，后面接原来的动词。斜向写成两个罗盘向，如 `从东南向西北`。纯上下不占水平罗盘，写成 `向上` 或 `向下`；只要还有水平分量，水平向仍写罗盘。

走、跑、飞、飞出、跳、滚、被抛、出入画，以及离开身体的挥、指、递、伸、端、送、扔、踢，都写这条。开口、点头、眨眼、原地换表情、原地坐下且不换位，没有空间走向，不写这条。

**方向写在动作句里（最高；压过透传留句）**：上面每一次运动，正文那一句里就要有 `从{东|南|西|北}向{东|南|西|北}`。`站位变因=` 再抄同一句，不能代替正文。正文留下向前、向后、前面、后面、身旁、后侧、侧旁、前送、走至、走到边缘、案角，这一拍失败。动作句里的前、后、侧、旁改写成东南西北。桌、案、台、床挡在起点和落点的直线上时，脚不穿过这一具。人已经在这一侧贴身或一臂，这一拍不迈步，停点仍是这一侧，至少一肩留在沿外。递、伸只写手和杯子沿这一具的面上方，从这一侧到对面那一侧上方，人的锚和 X、Y 不变。正文里的「向前迈进半步」「朝镜头迈一步」没有起点和落点，改成留在原侧，不补穿过去的那一步。

**一次运动一条方向**：人走路是一条。手离开身体的递、伸、端、挥、指、扔、踢是另一条，人已经停住也要另写。禁止把递并进人的走路变因，禁止把杯子写成自己从南向北走，禁止 `沿{某人}手臂`。人的锚没变、只是手把东西送出时，人行不写 `站位变=`，方向写在该件：`站位变因=递:从{向}向{向}，物仍在{哪只手}`。这一拍又走又递，正文两句各有起止，变因也分两条。

封闭舱先把舱轴还原成同一套罗盘再写：主驾朝向是南，操纵端是南，舱尾是北，面朝操纵端时舱左是东、舱右是西。成稿仍是 `从南向北` 这种句子，可以同时点名从哪一席到哪一席。禁止写成从左到右，禁止左起第。0度对向座位正面。

`站位变因=` 在路径里带上同一句方向，并写沿着哪一条边，停点写齐 X、Y、Z：`走位:从南向北，沿八仙桌的东沿，自开拍→停点 X=东端｜Y=北一臂｜Z=贴地`｜`出画:从南向北飞出`｜`递:从南向北，物仍在右手`。方向和路径的起点、终点是同一条运动。飞出、被抛出、走出画面没有落点，不写停。本拍 X、Y、Z 是开拍，不改成停点。变因里的停点如果和本拍 X、Y、Z 相同，开拍和终点是同一个点，这一句方向作废。停点必须写齐 X、Y、Z。终点从下一拍开拍才写入，下一拍的 X、Y、Z 逐字等于这个停点。沿东沿走到北侧东端，下一拍是 `X=东端｜Y=北贴身或一臂｜Z=贴地`，不是仍留东侧南端，也不是把偏出的那一轴收成轴上。

**停下重新定位（移动之后；最高）**：走、跑、跳落到场内之后，下一拍重新用环境主体定位，写成 X、Y、Z。锚是沿过来的那一具，或中部的桌、案、椅、床；旁边另一具近出一档以上，锚用最近这一具。面向谁、递给谁写在朝向里，不写成锚。交付前停在这具朝向对方的那一侧，距离一臂，物仍在递出的人身上。交互后物归接的人，人的锚仍是这具。戏用标识下，第一个人仍挂那一具，其余人仍相对第一个人。没有环境主体可挂时，锚=原点。开口、点头、眨眼、原地换表情不算移动。

**路线沿主体**：路径写沿着主舞台已经有的那一条边或那一条路，再写从哪一向到哪一向。边或路的名字必须已经在主环境或 `动线=` 里，写成 `{主体}的{东|南|西|北}沿`，或那条路的原名，如沿着八仙桌的东沿、沿着床的北沿、沿着小路、沿着台阶。进门走廊只有 `动线=` 里有这个名字才许用。`站位变因=` 写成 `沿{这一条}`。禁止沿手臂、沿前送、沿案角、沿边缘、沿桌边、沿一边。

**开拍已经在这条边上**：写「沿着{主体}的{东|南|西|北}沿」时，本拍开拍的 X 或 Y 就必须在这一沿上，档只许贴身或一臂。东沿从南向北：开拍 `X=东贴身或东一臂｜Y=南端｜Z=贴地`。人在南侧、只是偏东、离两步，不在东沿上。要先走到这一沿，正文先写从开拍处走到这一沿的起点，再写沿着这一沿走；两段都写从哪一向到哪一向。禁止开拍在另一侧，走位却写成已经沿着这一沿。

**运动反定站位与朝向（最高）**：本拍要走、跑、递、伸时，先写这一下的运动，再锁开拍站在哪一条沿上、脸朝哪一向。位置和朝向为这条路线服务。一条路线只走一个罗盘向，沿着主环境或 `动线=` 里已经有的一条沿或一条路。开拍在这条沿的起点端，停下在同一条沿的另一端。这样走得通，就不写第二段，不写斜向，不把人偏到沿外。开拍不在任何一条能直达终点的沿上，先用一个罗盘向走到最近那条沿的起点，再沿着它走完，两段都写。上一拍终态已经定下的位置不挪到终点边上。开拍朝向抄文戏身朝，不改成走向。走向与开拍朝向相反时，正文先转身，`朝向终=` 写下，下一拍开拍才改。终点要碰到的人，走到之后面向这个人，这一面向写在终态或下一拍。递和伸的方向与走出的那一向相同，人停在一臂可递的那一端。对方的开拍朝向已经由文戏锁死时，不改对方的脸，把自己的终点放在对方身前、沿同一条边能走到的那一端。对方坐着且座已锁朝向，身前就是座朝向那一侧，罗盘仍抄座朝向。对方这一拍没有已锁朝向、又要接这一下，对方面向走来的人。✅要递到桌北的人：开拍 `X=东一臂｜Y=南端｜Z=贴地`，面向北，沿东沿从南向北，停点 `X=东端｜Y=北一臂｜Z=贴地`｜❌人在南侧偏东两步，却写从南向北沿一条走廊｜❌面向东，沿东沿向北走，正文没有先转身｜❌边上有一条沿能直达，却写成从东南走到西北｜❌停点只写北侧，下一拍把偏出的那一轴收成轴上

**绕行只在挡死时写（最高）**：默认不绕。开拍到停下沿着这一条沿或这一条路一直走，中间没有立体的人、柱、几、关闭的门扇挡住，就写直走，不写 `绕=`。人在桌外，沿着这张桌的外沿走到另一侧，不算绕行。为了好看改走房间另一头、多拐一次、沿一条更远的路，都不写。能改停点或改沿让这一条直线走通的，改站位，不写绕。只有直线被已经在场的具名主体挡住、沿这一条沿走不过去，才绕。绕必须写明三件：挡住的是哪一具，从它的东、南、西、北哪一侧过去，绕开时从哪一向到哪一向，绕完回到原来的那一向。`站位变因=` 带 `绕={具}之{东|南|西|北}`。没写从哪一侧过去，等于没写绕行。✅`从南向北，沿八仙桌的东沿`｜✅东沿上有柱挡住：`绕=柱之东，先向东离东沿，过了柱再向北回到东沿`｜❌没人挡却绕到柱外｜❌只写绕过桌子，不写从东侧还是南侧

✅`X=东一臂｜Y=南端｜Z=贴地`，`CHAR:[@甲] 沿着八仙桌的东沿，从南向北走到八仙桌的北侧东端`｜✅`站位变因=走位:从南向北，沿八仙桌的东沿，自开拍→停点 X=东端｜Y=北一臂｜Z=贴地`｜✅下一拍开拍 `X=东端｜Y=北一臂｜Z=贴地`，不写站位变
❌`开拍 X=东两步｜Y=南端｜Z=贴地`，却写沿着东沿从南向北｜❌`纸鹤飞出`｜❌`向前飞`｜❌`从画面左边飞到画面右边`｜❌`走到前面`｜❌`自开拍→到终点`｜❌`手臂向前平伸，递到他后侧身旁`，站位变因另写从南向北｜❌`沿手臂前送`｜❌动线里没有进门走廊，却写沿进门走廊｜❌开拍在南侧，变因又写停在南侧

### 朝向

只给角色和有正反面的道具。`朝向=面向{角色|有正反面件|四面|中区|窗外|远方}[之东|之南|之西|之北|之上|之下]`。无正反面的件不写 `朝向=`、`罗盘朝向=`、`眼神=`、`背对=`。绝对档的角色禁止缺少 `朝向=`。相对、封闭没有明示对象时，`朝向=` 写 `面朝东|南|西|北`，并写 `罗盘朝向=`。`背对=` 不进成稿。驾驶舱、整车、飞行器、船、机甲、屏、镜、像、有正面的法器和操纵台不走这句豁免，见「正反面道具必须写朝向」。分析才推出的大门只写 `朝向推=`，不进成稿 `朝向=`。窗外、远方是明确落点，可以当朝向对象。左、右、前、后不是朝向对象。

**朝向必须写下，行动后必须更新（最高）**：已入场的每个角色、每个有正反面的道具，每一拍都写开拍朝向，并写这一拍行动之后的朝向。开拍用 `朝向=` 和 `罗盘朝向=东|南|西|北`。`罗盘朝向=` 是从这个人、这件指向 `朝向=` 那一具的世界向：面向北壁、北侧的人、桌的北沿，就是北。坐着且没有转身时，这一向先抄座朝向，再把身朝那一具放到这一向，不从站位倒推。本拍没有转身、没有把这件转面，不写 `朝向终=`、`罗盘朝向终=`，缺省就是同开拍。本拍转身或把有正反面的件转过来，正文先写从面向谁转到面向谁，`朝向变=是`，才写 `朝向终=` 和 `罗盘朝向终=`。本拍开拍两键不改成终态。下一拍开拍的 `朝向=`、`罗盘朝向=`：上一拍写了终态就全文抄终态；上一拍没写终态，就全文抄上一拍的开拍两键。无变化禁止只写承上。新拍确认正面还是双人同框，只读本拍这份开拍朝向，不读本拍还没发生的 `朝向终=`。✅甲开拍 `朝向=面向 CHAR:[@乙]｜罗盘朝向=北`，本拍转身面向窗，`朝向终=面向窗｜罗盘朝向终=东`；下一拍开拍写成面向窗、罗盘朝向=东。❌只改了下一拍朝向，本拍没有 `朝向终=`。❌有正反面的屏没有朝向。❌本拍才转身，选拍法却用转完的东向当开拍。

**左右朝向译成东南西北（最高）**：文戏 `身朝=`／`眼神=`／正文朝向里出现左、右、之左、之右、朝左、向右、向左看，先用这个人开拍已经推出的面朝罗盘向来译，不按画面左，也不另猜一具。面朝北：左=西，右=东。面朝东：左=北，右=南。面朝南：左=东，右=西。面朝西：左=南，右=北。开拍面朝来自这个人的位置和已对上的主体：人在主体南侧、面向该主体，就是面朝北。坐着且没有转身的人，开拍面朝先抄座朝向，左右按这一向译，不从对面站错的那一侧倒推。译完把左右换成这一向：有主体写 `面向{主体}之{东|南|西|北}`，没有主体写 `面朝{东|南|西|北}`。成稿 `朝向=`／`眼神=` 不留左、右。左手、右手、左脚、右脚仍是解剖，不走这条。✅人面朝北、文戏 `眼神=向左` → `眼神=面朝西`。✅人面朝东、`身朝=落地窗之右` → `朝向=面向落地窗之南`。❌面朝北仍写 `朝向=面向之左`。❌把朝左写成画面左。

文戏【世界物理】已锁 → 开拍 `姿态=`≡`姿=`，`朝向=`≡`身朝=`，`眼神=`≡`眼神=`。对象保持世界实体的裸名。左、右先按上一条译成东南西北再写入，不把之左、之右原样留下。`朝向=` 的主体必须与 `身朝=` 是同一具。只许把这一具上的之左、之右译成这一具的东、南、西、北。禁止改挂成另一具。站着的人，`罗盘朝向=` 从这一拍的位置指向身朝这一具。坐在已锁朝向的椅、凳、沙发上、这一拍没有转身，`罗盘朝向=` 抄这张座的 `朝向=`，并写 `座朝向=` 同一向。朝向对象仍是身朝那一具。这一具不在座朝向的那一侧，把这一具挪到座朝向那一侧，不把坐着的人转过去，也不回流文戏。不从对面的人已经站在哪一侧倒推罗盘。不把身朝对象改成门、玻璃或办公桌之西。不抄墙自己的东、西，也不抄下一拍。身朝写成幕墙之东、桌之西，先回流文戏去掉这四个罗盘后缀，不在本层改主体。主位 `沿边=长边北侧｜朝向=南` 时，坐着的人罗盘是南，对面的人相对桌子 `Y=南一臂`、罗盘是北。`站位承载=` 写了南侧，写南侧。`Y=北一臂` 且罗盘朝南只属于南椅、座朝北。东墙玻璃在背后、光从这面玻璃进来，不把朝向改成这面玻璃，也不把已经朝西的脸改成朝东。本拍有人、却没有【世界物理】行 → 回流文戏，禁止臆造。正文点名了整机、整车、屏、镜、像当主体，世界物理却是无 → 回流文戏补这一件的姿、身朝、眼神。禁止把这件收成空镜暂不可见，禁止不写朝向就往下排机位。

低头、垂头、埋头、看地、看脚，以及上游 `身朝=地板|地面|脚下`，只是头低下。`眼神` 可以是地板。水平 `朝向` 和 `罗盘朝向=` 沿用开拍，不改成所坐的床，不补「向西转面」。

文戏「前方／车头／挡风／控制台」=载具前进向，落到主环境已锁的那一世界向。禁止写成 `面朝前`。世界「前」=南，只用于载具和没有座朝向的空旷。坐着的人与对面的人跟座朝向，不跟世界前。

回望、说到一半转看：本层朝向仍是开拍。视线转移留给入戏。转看的对象仍须在身前，不能转到面朝的对向。

**朝向、眼神、交互是同一世界向（最高）**：站着的人先从开拍位置推出面朝的那一个罗盘向。坐着且没有转身的人，面朝向先抄座朝向，再核身朝那一具在不在这一向，不从位置倒推去改座朝向。然后核眼神、背对和本拍要互动的那一具。四项对不上，这一拍失败，禁止留下朝东望西。

面朝向 = 从这个人指向 `朝向=` 那一具的世界向。坐着且没有转身，这一向已经是座朝向，身朝那一具必须落在这一向。面向北壁、北侧的人、桌的北沿，就是面朝北。面向东、南、西同理。背对只用来核对，不进成稿。面朝北时对向是南侧。背对与面朝是同一向 = 失败。

眼神的水平向必须落在面朝这一向，或面朝左右各 90° 的身前。`眼神=同朝向` 就是面朝向。`眼神=面向{对象}` 时，那一具必须在身前半圆。面朝东、眼神指向西壁或西侧的人 = 朝东望西，失败。差 180° 一律失败。低头、看地、看脚只是头低下，水平面朝不变，不算望向对向。

本拍对白、对视、递、握手的那一具，必须就是朝向对象，世界向与面朝向相同。这一具在面朝的对向 = 失败，先按上下拍补偿转身，再互动。眼神可以用余光看身前左右的另一具，那一具不能在背后，也不能和对白对象分处两个对向。

### 接触与桌面

`触=无|{牵手|拥抱|押送|按肩|搂腰|接吻|挽着}:{对方}｜己=左手|右手|双臂|左臂|右臂|无｜对=左肩|右肩|…`。

**接触手只由朝向确认（最高）**：`己=` 和正文里的左手、右手，只由朝向推出，不由画面左、也不由上游用词留下够不着的那只手。被接触者的左手边、右手边是他自己面朝时的左侧、右侧。站在被挽者的左手边：两人面朝同一向，`己=右手`；两人面朝相反，`己=左手`。站在他的右手边，这两只手对调。道具落在自己面朝时的左手边，只用左手碰；落在右手边，只用右手碰。上游写的那只手和这张表不一致，改成这张表的那只手，正文同一句一起改。朝向推不出唯一一只手，`己=无`，正文删掉「左手」「右手」，只留挽着、牵着、按着或递到。面对面、人站在身前够手，仍是自己右手够对方左手，不套身侧这张表。

底面不贴地的人／件：宿主写在 `锚=`，高度写在 `Z=`。桌上碗盏 `锚=`=桌，`Z=台面`，南北东西收进 X、Y。围桌人的一侧收进 X 或 Y。不写 `落在=`、`离平地=`、`台面心点=`、`在桌=`。禁止 `同排=`／`同列=`。

### 挂靠体

法相、金身、化龙凤、全息、幻影、坐骑、无舱骑乘、整车，每拍单独一行，`关联=宿主`。镜中、屏上的平面像不另起一行。

默认与宿主同锚、同朝向。法相在宿主身后（背侧），远大于宿主。这是世界位置，不是镜头远近。仅当正文写清人离开、件留原地，下拍人才换锚，件仍占原地，并写 `挂靠评={名}|挂=法相|坐骑|载具｜宿主={名}｜态=离开｜因=留原地人往前走`。切角、满幅、人仍骑着、车载人一起走，都不是离。虚拟体与宿主分名，可以同锚。

同框的法相、金身、化龙凤写 `宿主法相同向=是|否｜面对镜头=是|否｜原因=`。没有同框不写这两键。双方必须同一世界朝向对象。禁止把宿主和法相写成正反。`面对镜头=否` 只表示从背后过法相的肩看对手，不是人行的 `朝向=面向镜头`。看对手时 `框主=` 是该法相，不写与框主相同的 `近侧框主=`，禁止过宿主的肩。`巨体尺=肩前悬浮` 时，小人的 X、Y、Z 必须能读出悬浮于挂靠体的左肩前或右肩前。不写 `站位=`。

**群演簇**：整簇占一个世界位，优先舞台边或后的空位，与具名角色不同锚、不相邻，分布图仍要写。禁止另造 `{N}度{主}_群演`。正文没有写围观、冲撞或贴身市集时，不进具名对白或读脸的近景，拆成簇自己的一拍。正文已经写了，可以留在同一半空间的远层，仍禁止同锚。只有 `EWS|WS` 且簇在远层时，才可以和具名同拍当背景。

### 载具：人站在哪一套世界

先读统筹 `载具裁定=` 与【本场道具身份】。本拍只锁一档。不是无才写入 `载具档=`。无则不写这个键。这是站位所在的世界，不是景别。

| 档 | 人站在哪 | 禁止 |
| :--- | :--- | :--- |
| `内部ENV` | 舱内。入座走封闭槽位。当前环境主名=占用名 | 整车 PROP 占舱内位；主拍已经是整机却留在本档 |
| `道具沿用宿主` | 宿主大世界。只用于人正在跨开口，或车内人与车外人这一拍对戏。整车是宿主里的 PROP | 当前环境写成驾驶舱；俯冲、刮擦、砸地的驾驶器拍把坪上的人写进来 |
| `整车无人` | 宿主。不写人。整机在画仍写这一件的位置和朝向，不收成空镜暂不可见 | 舱内座位；把在画的整机收成无道具 |
| `无` | 本拍载具不出场。摩托、马、单兵飞行器走普通 PROP，人相对该件 | 另造内舱 |

`载具裁定=无` 的摩托、马、单兵飞行器本拍不写 `载具档=`。马车走已锁裁定。`仅ENV` 的舱内有人拍用 `内部ENV`，除非这一拍已经是整机主拍。`仅PROP` 不切占用。`双出` 按本拍正文只选一档。需要占用而场里没有这块主环境 → 回流环境规划。同一拍既要舱内人，又要整机外形 → 拆成两拍，`拆拍依据=占用换主`。舱内拍只有人和舱；整机拍只有宿主和整车。三层交付（人在车里与车外人对戏，或人正在跨开口）才用 `道具沿用宿主`，不拆成舱内中近景。露天合建挂「局部加大世界」那一块占用，不另挂纯宿主。

**封闭舱三层不混进一张分布图（最高）**：封闭驾驶舱有宿主时，驾驶器、驾驶舱内、驾驶舱外是三套主环境。驾驶器拍 `载具档=整车无人`，分布图只有这具 `PROP:`，当前环境是这一段航迹的宿主。楼缝、峡谷里的掠过不挂停机坪。砸到停机坪的那一段才挂停机坪，这一拍仍然不写站在坪上的人。坪上的人是舱外拍，主环境是停机坪，开拍在整机已经停驻之后；不得在俯冲拍里写成贴地站在原点旁。舱内的人是 `内部ENV`，主环境是驾驶舱，不写整机外形，不写坪上的人。`道具沿用宿主` 不得用来把看坠落的人写进驾驶器拍。❌飞行器自双子大厦峡谷俯冲砸上停机坪，`载具档=道具沿用宿主`，`当前环境=90度停机坪`，分布图同时有飞行器和站在坪上的顾临风、严啸。✅俯冲拍只有飞行器，挂楼缝宿主；砸地犁沟拍只有飞行器，挂停机坪；两人在下一拍的停机坪上，飞行器已经停住。

整机主拍认的是这一拍正文看见了什么。正文已经写出整机在楼群、航道、空域里的外形、航迹、尾焰、对射或刮擦，含两架及以上同框，这一拍就是整机主拍。主拍对象写成操纵台、座椅、舱门，或写成空镜无道具，都不改变这一拍。必须改成 `道具沿用宿主` 或 `整车无人`，当前环境主名=宿主。机位锚用宿主里看得见的楼、塔、广告牌或航道，禁止用舱内操纵台，禁止 `AI位=航拍外立面` 仍挂机舱。上拍是舱、本拍是整机 → `ENV变=是:整机换主|出舱切主环境`。场里没有宿主块 → 回流环境规划。禁止用一块舱内环境当这些全景整机的背景。禁止整拍挂驾驶舱，只把「拉出挡风」当成还在舱里。**出入舱跨口（最高；入和出同一条）**：人跨进或跨出载具开口的那一拍，当前环境都是宿主，`载具档=道具沿用宿主`，写入机位行。整车是【本场道具身份】已注册的 PROP，分布图写这一具。人相对这具跨开口，开口在这具上。当前环境主名=宿主。出舱写 `ENV变=是:出舱切主环境`。禁止这一拍挂驾驶舱，禁止把开口收成镜头后方。人已经在舱内、要拍座椅和舱壁的下一拍，才改 `内部ENV`，那一拍不再挂整机 PROP。`落幅在舱` 是开场已经在舱里，不套这一条。

舱内和舱外看这一拍看见的空间，主名逐字抄环境规划已经注入的那一块。机位锚写成操纵台、前风挡、舷窗，只说明玻璃和台在哪。舱内档同时成立四条：画面主体是座、人、操纵台和这一面玻璃；外面只写在这块玻璃里，一句「前风挡里，前方的楼或云沿航向拉成光带」，轨道只写窗外航向；本机的机腹、喷口、机尾、两侧翼面、全机侧滚、激波尾不出现；两架整机不在楼群、航道、空域里同框。这些外面的句子出现，改成 `道具沿用宿主` 或 `整车无人`，`当前环境` 主名逐字等于注入的宿主注册名，机位锚用宿主里的楼、塔或航道，机高可以远高于头顶。注入里没有这块宿主 → 回流环境规划补宿主，禁止把楼群、航道写进舱块，也禁止仍挂机舱。舱内拍的机高用坐姿眼高或略高于眼高。

### 人行怎么写

已入场的角色、独立道具各一行。必写：`在场=` `方式=` `锚=` `X=` `Y=` `Z=` `姿态=`。有正反面再写 `朝向=` `罗盘朝向=`。坐在已锁朝向的椅上再写 `座朝向=`，没有转身时与 `罗盘朝向=` 相同。眼神和朝向是同一对象时不写 `眼神=`；看向另一具才写那一具。

`方式=配饰` 只写 `在场=` `挂靠=` `部位=`，不写 X、Y、Z。封闭舱写 `排=` `座=` `功能=` `相对驾驶位=` `Z=椅面`，不另写 X、Y。`站位变=是` 才写 `站位变因=`。没走位不写 `站位变=`。`朝向变=是` 才写 `朝向变因=` `朝向终=` `罗盘朝向终=`。没转身不写 `朝向变=`。开场写 `在场=开场`，不写站位变、朝向变。

这些只在命中时写：`双锚=` `在其间=`；`关系序=`；`关联=`；`触=` `己=` `对=`；同时连着另一个人时写 `共同=`，两人各写 `互参=`。

人还在画外才不占位，只写 `入场=待入画｜入画@B{n}｜经={口}`。不写锚、X、Y、Z、朝向。本拍已经在画面里的人不走这一句，按「已经在画面里就占位」写开拍坐标和罗盘朝向。

姿态只写一档；「站」与「立」同义，成稿写 `站`。

机位行的镜型、拍法、空镜、不写的键，见「成稿只认这一套」。本拍有相关的另一个人时再写 `人距=近|远`。人距变了才写 `人距变=近了|远了`。`[DERIVED_ENV:]` 与 `当前环境=` 是同一个名字，两个都留。


## 乙 · 机位（甲已锁死）

甲的锚、X、Y、Z、排座、朝向对象、走位路径不再改。乙只追加机位行。读脸、过肩、换角、沿用失败，都只改机位，不把人从已锁的边或点上挪开。机位改的是站在哪、离多远、仰还是俯。水平朝向改了，就是换到另一个衍生环境的正面，不能在同一度里把镜头拧向侧壁或画外。

**新拍先定正拍，再选环境（最高）**：纯无人空镜和窗外特写不走本段。其余拍先写镜型和拍法，再写望向，最后写当前环境。先读本拍要体现的是谁。要正面，望向等于他背对的那一向；要背面，望向等于他面朝的那一向。禁止先写度数再倒推拍法。禁止用侧面环境充当正反打，也禁止用一个人的正脸环境充当双人侧面同框。

**拍间按人距衔接（最高）**：定镜型之前，先量本拍开拍时主拍对象和这一拍相关的另一个人之间的世界距，写入机位行 `人距=近|远`。相关的另一个人是朝向所对的人、关系序的对方、共同或互参连着的人、对白的听者或说话人。场里没有第二个人，不写 `人距=`，镜型用单人正拍。

近：两人同一锚上分开的那一轴是贴身、一臂或两步；或锚是对方、隔着的那段短于两步；或仍写着共同、互参、触、挽着；或对坐、并排而这一档不到三步。远：分开的那一轴是三步、五步或更远，并且没有仍连着的接触。两人分属两块主环境，这一拍又没有近身，算远。

近的镜型只许 `正反打` 或 `双人同框`。已经拆开的说话、听反应、句眼、关键反应、交互之后要读的那一张脸，用正反打，各用该人自己的正面环境。下一拍就是另一个人的正面时，本拍不改成双人同框。打斗的一次接触、递接必须看见双方、正文 `同拍=`、共同关系这一拍要看见连着的两边，用双人同框。这一段不再给他正反打、他又必须留在这一拍画面里，才用双人同框。禁止 `人距=近` 的对白拍写成 `镜型=单人正拍`、`关系角=干净`、`覆盖=单人`、`框主=无` 并且不写轴线。靠墙靠门时近距离仍是正反打：关系角可以是干净，那是无过肩的正面反打，`覆盖=反打`，轴线仍在。那不是远距离的干净单人，也不是双人同框。

远的镜型只许单人正拍。`关系角=干净`，`覆盖=单人`，不写 `框主=`，不写轴线，对方不进 `可见=`。不因为场里还有这个人就排正反打或双人同框。远去的背影同样是干净单人。远不再改成过肩、过头或过腰。追逐覆盖的追击视角、过肩、双人同框、航拍全景不走这一段，走下条。

**追逐同框（人与驾驶器；最高）**：上游写了 `追逐覆盖=`，或这一拍正文是地面追杀、空中追人、骑马、摩托、驾驶器、飞行器、车辆、舰艇的追逐，并且要看见双方。世界距是三步、五步或更远，仍然同框。`人距=远` 照写。对方进 `可见=`。对白的句眼和关键反应不走这条，仍按远距干净单人。链上要有追击视角、双人同框、航拍全景。缺了就补拍，`拆拍依据=追逐覆盖`。不把舱里的人和整机写进同一拍。`机位变因=追逐同框`。
- **追击视角**，上游 `过肩=是`：`拍法=过肩`，`关系角=过肩`，`覆盖=过肩`，`框主=` 是追方的人，或追方这具 `PROP:`。逃方在框主面朝的前方，进可见。`镜型=双人同框`。`机运=跟拍`。景别用 `FS` 或 `WS`，双方都要进画。驾驶器这一拍 `载具档=整车无人`，敞篷骑乘写 `道具沿用宿主`。`当前环境` 主名是宿主。主拍对象是追方这具。不挂驾驶舱，不写驾驶座。封闭舱里的人不进这一拍。机位行写 `舱外=是`。人已经在这条路上被看清，再写 `场内=是`。
- **双人同框**：`拍法=双人同框`，`覆盖=Two-Shot`，`关系角=干净`，不写框主。人用 `MS` 或 `FS`，要见全身用 `WS`。两具驾驶器用 `WS`，环境是宿主，两具都进可见，不写驾驶座，写 `舱外=是`。同一舱里的两个人只留在场内那一拍。
- **航拍全景**：`镜头角度=航拍`，`机运=鸟瞰`，`机高=远高于头顶`，`景别=WS` 或 `EWS`，`拍法=双人同框`，`覆盖=Two-Shot`，`关系角=干净`，不写框主。双方和这条路、楼缝或航道同框。驾驶器挂宿主，`AI位=航拍外立面`，写 `舱外=是`。不挂驾驶舱。`内部ENV` 不用航拍。
- **场内**：有封闭舱、上游这一拍是 `追逐覆盖=场内`：`载具档=内部ENV`，人在舱里，景别 `MS` 或 `FS`，外面只是前风挡里一条光带。不写整机，不写另一架。没有封闭舱时，不另造这一拍。
- 驾驶器的追击视角、双人同框、航拍全景，主拍对象是追方这具 `PROP:`，不改成舱里的人。

✅追方机体在宿主航道近处、逃方机体在前：`追逐覆盖=追击视角｜拍法=过肩｜框主=PROP:[追方驾驶器]｜可见=` 含两具｜`舱外=是｜当前环境` 主名=宿主。✅高处看见两具和这条航道：`追逐覆盖=航拍全景｜镜头角度=航拍｜景别=EWS｜舱外=是`。✅舱里要看见人：下一拍 `追逐覆盖=场内｜载具档=内部ENV`，前风挡里一条光带。❌两具隔着五步被收成追方单人。❌航拍仍挂驾驶舱。❌舱里的人和两具整机写在同一拍。

近只锁镜型，不在这一步把关系角写成过肩。跨桌坐姿、正对、近距的景别默认见「跨桌坐姿优先过肩」。其余过肩、过头、过腰要等景别、机位距和背向角色的落点都锁完，按「背向与落点定关系角」。贴身、一臂、两步只说明人距近，不单独成立过肩。

交互后锁近：本拍或上一拍有递、接、握手、拥抱、挽、对打的接触、刺入、没入、抵住、捆住、套住、勒住、同握，或正文 `同拍=` 的接触。从这一拍起 `人距=近`，直到某一拍的走位把两人拉开到三步或更远，拉开之后的下一拍才改 `人距=远`。拉开之前的各拍按近距离处理。读脸用正反打。必须同框用双人同框。禁止退回干净单人。

拍与拍要接上：上一拍 `人距` 与本拍不同，镜型跟着换。上一拍远、本拍近，本拍不得沿用干净单人。上一拍近、本拍仍近，不得改成干净单人。上一拍近、本拍远，本拍改成干净单人，对方退出可见。人距变了才写 `人距变=近了|远了`。镜型从单人正拍改成正反打、本拍仍读同一个人的正面时，环境可以留在这一度，但必须写上轴线和对方，下一拍换到对方的正面。人距从远改近并且镜型改成双人同框时，沿用按换拍法重算望向。人距改成远就去掉轴线。

### 景别

闭集=`EWS|WS|FS|MS|MCU|CU|ECU`。`机位距=` 默认与景别一对，任何主拍、任何锚都量镜头到主拍：CU/ECU=贴身，MCU=一臂，MS=两步，FS=三步，WS=五步远，EWS=十步外。这一对是景别给出的默认距离。主拍在机位锚远离镜头的那一侧，镜头留在这具靠近镜头的这一侧，桌、案、台隔在中间：不用这一对里的贴身和一臂。`机位距` 取两步、三步或五步，短于这具进深的档不合格，依据写 `桌面隔在镜头和人之间`。景别仍可以是 `CU` 或 `ECU`，入画只见头，镜头不收到这个人正前一肩。人在这具靠近镜头的这一侧，中间没有这具，才用景别默认的贴身。拍摄对象的体量、要看见的那一面，或原文已经写明的远近，要求另一档时，可以改 `机位距=`，依据写在机位行。改距离不改 `望=`，不换度。机位锚只说明镜头站在哪一具环境主体的哪一侧。角色和手上的道具不升成机位锚。机位只写机位锚、罗盘机位侧和机位距。主拍落到镜头后面，这一拍回流，不改景别去凑。`主拍对象=` 就是这具环境主体时，距离才直接写离这座锚的注册名。平拍的机高等于主拍当时姿态的眼高，不套另一种姿态。向距上限按该向三档收：`窄` → 机位距≤三步、景别≤FS，禁止十步外和 EWS；`开` → 机位距≤五步远、景别≤WS；`无限制` → 才可以用十步外和 EWS。FS 及更近只核远锚那一向。WS 和 EWS 再核左右邻向；邻向超上限，这个角承载不了该景别。承载得了就优先留在上一拍那一向，细则在「沿用与当前环境」。四个正交角都承载不了，才把景别收到最宽那一向允许的最大档，并写 `向距收档=是`。禁止为了留在窄向把已锁的远景收成全景。

原文的远景、全景、中景、近景、特写、大特写映射进上面的闭集，只写 `景别=`，不写 `原文景别=`。原文的俯拍、仰拍、平拍写入 `镜头角度=`，不写 `原文角度=`，不占景别档。

`剧情匹配=建置|走位|对白|交付|反应|特写|空镜|宏观`。`剧情匹配=空镜` 只在文戏该拍写了 `纯无人空镜=是` 时使用。`窗外特写=是` 写 `剧情匹配=特写`，不是纯无人空镜。没有这两个标记，不把这一拍改成空镜，也不另拆无人拍。开场已在场的第一拍，文戏没标纯无人空镜，就不是纯无人空镜。

**纯无人空镜配环境（最高）**：文戏 `纯无人空镜=是` 的拍，原样透传 `模式=`、`地点=`、`状态=`。地点必须是另一块已注入主环境，不得是本场。这一拍、上一拍、下一拍，这一处都没有角色。不把上一处的人抄进本拍分布图。`镜型=空镜`。不写 `拍法=`，不写 `人距=`，不写 `针对=`，不写 `空镜成法=`。不走「先定正拍」。`主拍对象=` 是这一处承载动势的那一具。景别可以用 `WS` 或 `EWS`。`空镜环境=单独主环境`。`当前环境` 的主名逐字等于文戏 `地点=`。`ENV变=是:空镜切主环境`。有状态且注入里没有变化后的另一块：开拍挂 `{N}度{主}`，落幅挂 `{N}度{主}_{状态}`。对不上已注入主环境，或这一处前后已有角色，回流。本场仍有角色却标了纯无人空镜，回流，改走窗外特写。

**窗外特写成法（最高；机位和特写，或运镜推出）**：文戏 `窗外特写=是` 的拍，本场仍有角色。原样透传 `对象=`、`模式=`、`地点=本场`、`状态=`。人留在上一拍世界位，锚、X、Y、Z、朝向全文抄上一拍终态。不因为【世界物理】无就清出分布图。不标 `纯无人空镜=是`。机位行写 `空镜成法=机位避人|运镜推出`。`镜型=空镜`。`覆盖=空镜`。不写 `拍法=`，不写 `人距=`，不写 `针对=`。不走「先定正拍」。`主拍对象=` 等于 `对象=`：窗、幕墙、门外的那一层。景别只许 `CU` 或 `ECU`。身上的件跟人。可见名单只收镜前并且这一档特写盖到的人。当前环境仍是本场 `{N}度{主}`，度数朝向这一具。不切到另一块去冒充纯无人空镜。

- **机位避人**：开拍镜头已经只看见这一层。镜头站在这一具和仍在场的人之间，比人更靠近这一具，望向这一具。用镜前表核每个人。望南时人在机之北，望北时人在机之南，望东时人在机之西，望西时人在机之东，才是镜后。`机位锚=` 是这一具。`机位侧=` 在望向对面。`机位距=` 量到这一具，短于最近的那个人到这一具的距离，默认贴身或一臂，依据写 `人在镜后`。特写只盖这一具外面的那一层。不用 `WS` 或 `EWS`。人坐在桌北、幕墙在南、要只见幕墙外：望南，镜头在桌子南侧更靠近幕墙，`机位距=贴身` 或 `一臂`，`景别=CU`，人在机之北。镜前表核完人仍在镜前并且特写盖到，就再把镜头挪到人与这一具之间。

**关键剧情动作收拍（最高）**：重要剧情动作通常在一个 `救猫咪拍=` 的最后一节。这一节又是场最后一拍，并且主事件是可见的剧情动作、这一下改变了人或物的结果，才算关键剧情动作。出手、命中、交付完成、揭开、摔碎、关门隔断、离去落定、法术结成，都算。纯对白收句、纯反应脸、纯空镜余韵，不算。这一下要读的是细节特征、且这一拍没有角色在做动作、也没有对白时，景别锁 `CU` 或 `ECU`，`机位距=贴身`，机位行写 `收拍=关键动作特写`。细节特征是纹、印、裂、痕、字、刃口、针孔，或这一下只落在一处局部上的结果。从中景或全景收到这两档，写 `越级:关键动作特写`。同拍的道具特写或原理留在这一拍，不挪到内侧。同一拍已有角色动作或对白时，不写 `收拍=关键动作特写` 去把主拍收成道具，景别走角色选镜；这一处细节归分镜运镜。其余关键剧情动作仍用这一拍已经按角色或空间交代锁好的景别，单人表演不改成远景或全景。机位行写 `收拍=关键动作定格`。动作在这一拍里做完，人和物停在结果上。不写拉镜、环绕、推近、微距。大景别由分镜拉镜和环绕配合，特写由分镜用特写运镜配合，落幅仍是这一拍已锁的档。两个键只写一个。未命中不写。✅信上的裂口是这一下的结果，收拍 `景别=ECU｜收拍=关键动作特写`。❌裂口仍锁成全景。❌又写定格又写特写。

**句眼与关键反应**：读 `【对话标注】`。句眼的主拍是说话人，关键反应的主拍是听者。近时各用该人背对的环境，写轴线。远时对方不进可见，不写轴线。关系角不在这里写成干净，也不写成过肩。近侧椅背已经在这一度参考图里的，可以收到 `CU` 或 `ECU`，坐着的人和椅背仍进 `可见=`，见「参考图里的座位带着坐的人」。参考图里没有这张椅、这一拍已按越级收到 `CU` 或 `ECU` 的，不改回 `MCU`。其余按「背向与落点定关系角」。`反应拍=无` 的轮不另造反应拍。这两拍不写 `同拍=`。站位不因为收近而改。❌听反应仍用说话人的正面环境。

**角色动作与对白按角色选镜（最高）**：本拍正文有角色在做动作，或有开口对白，拍法、`主拍对象=`、`望=`、`覆盖=`、景别都按在做这一下的角色来锁。`主拍对象=` 必须是 `CHAR:`。驾驶器追逐的追击视角、双人同框、航拍全景除外：这一拍的主拍对象是追方这具 `PROP:`，人留在场内那一拍。禁止把 `主拍对象=` 写成手里或身上的 `PROP:`。禁止把 `望=` 改成对着这件道具。禁止 `覆盖=单人` 且 `可见=` 只剩这件道具。禁止为了看清这件而反打、换度，把本拍仍在做动作或对白的角色裁出 `可见=`。这一件仍进 `可见=`。有 `【重点运镜】` 仍写 `重点=是`。不在本层写推、拉、摇、移。

**重点运镜用景别突出**：有 `【重点运镜】` 才写 `重点=是`。不写推拉摇移、焦距、光比。朝向不因为收近而改。这一拍不计入近景连续满 3，也不计入 `CU|ECU` 配额。开场拍和收拍不改成远景。同一拍已有角色动作或对白时，道具细节不收成特写。
- `扩写=表情特写`：`景别=CU` 或 `ECU`，`机位距=贴身`，拍法=正面，`主拍对象=` 是这一行的人，读这张脸。不留 `MS`、`MCU`、`FS`。从中景或全景收到这两档，写 `越级:重点运镜`。同时是句眼时，越级依据写句眼，景别仍是这两档，`重点=是` 仍写。
- `扩写=道具特写`：本拍没有角色动作、也没有对白时，`景别=CU` 或 `ECU`，`主拍对象=` 是这一行的 `PROP:`，这一件入 `可见=`。不留中景或更远。本拍已有角色动作或对白时，不走这一条，走「同拍的道具细节归分镜运镜」。
- `扩写=背影`：拍法=背面，机位侧写这一望向对面的东、南、西、北，不写正后。景别默认 `MCU|CU|ECU`，后颈或肩背是主信息。正文写的是离去的全身，才用 `FS`。不用 `WS` 或 `EWS` 把人压成一块。这一拍不改去读脸。
- `扩写=原理`：景别收到能读清这一作用过程的档。小件、咬合、落点走 `CU` 或 `ECU`。`主拍对象=` 是这一件或做这一下的人。
上一角看得见这一对象，就留下，只收 `机位距=`。看不见，才换到看得见的那一度。没有角色的信物拍才可以 `景别=ECU｜主拍对象=PROP:[信]｜重点=是`。✅信物拍没有人在做动作，`景别=ECU｜主拍对象=PROP:[信]｜重点=是`。❌重点仍是 `WS`。❌背影重点改成正前读脸。❌机位行写了 Dolly 或轮廓光。❌有人在刺、有人在看，主拍仍写成这件刃。

**同拍**：正文有 `同拍=` 时，两下必须同时在镜前，镜型才是双人同框。必见集含被同拍的人，以及这一下碰到的具。景别必须盖住两边。上一角看不见这一下接触，才换正交角。这一拍不反打去读另一方的脸。✅甲递信、乙同时接住，留在能看见两只手的 `MS`。❌同拍却收成只剩甲的脸。

`voice_type=VO|旁白` 可以和动作或画内对白在同一拍，不因为旁白拆拍。这一拍的主拍跟画面，禁止把旁白当口型。禁止漏抄上游旁白行。

常规有戏场不少于 3 拍时，普通对白和普通反应里的 `CU|ECU` 约占这些拍的 15%–25%，竖屏 20%–30%。句眼、关键反应、重点运镜、`~`、原文 `△特写` 不计入。纯过场或宏观满幅可以更低，要写依据。卖点、高潮、低谷、细节特写必须落在已经锁成 `MCU|CU|ECU` 的拍里。同一拍有角色动作或对白、并且镜型是双人同框的，景别用 `MS` 或 `FS`，细节归分镜运镜。单人正拍的卖点留在 `MS|MCU|CU|ECU`，不改到下一拍。`收拍=关键动作特写` 的场末留在 `CU` 或 `ECU`。`~` 的单人表演用 `MCU|CU|ECU`。细节特征的关键动作收拍不挪。禁止把单人表演压在远景。配额只核销，不另写综合块。

进出画不能全程同一景别。过程拍 `WS|FS`，反应拍 `MCU|CU`，至少差一档。`进出衬托=反应先|建立先|跟出|目送|无人反应`。

`画内V`>4 必须拆拍。竖屏对白、近景常规 ≤2。

群演簇原则上单独一拍，景别 `EWS|WS|FS`，不塞进具名对白的近景。三人及以上，每人侧脸按自己的罗盘朝向查表。

**可见名单**（写在机位行，不是站位）：`主拍对象=` 必须在 `可见=` 里。景别盖不到的人不要写入。主拍体量：`FS|WS|EWS` 为全身，可省写；`MS` 为半身；`MCU` 为胸肩；`CU|ECU` 为脸，物件特写写该件。其他人只写实际入画的自身部位，闭集=`左肩|右肩|左肩头|右肩头|左臂|右臂|左腰|右腰|左手|右手|左侧身|右侧身|左侧脸|右侧脸|后脑`。禁止裸写肩、手、腰。禁止写成画左肩。关系角=过肩时，框主的 `可见=` 必须有靠近轴侧的左肩或右肩。关系角=过头时必须有后脑。关系角=过腰时必须有左腰或右腰。只写左肩头或右肩头不算充足。被看者按正面核侧脸。未松开的接触、未离开的法相或载具、开场已经戴上的配饰，必须同一锚，并且本拍同时列入 `可见=`。人已经在镜后，身上的件跟人不进 `可见=`。景别盖不住就改景别或拆拍，禁止拆锚。`巨体尺=遮挡不可见` 的小人不进 `可见=`，锚仍相同，不算拆开。

**参照不跟景别改（乙）**：甲的 `锚=` 不读景别。乙不因特写、近景或中景另选一具，也不把这一具标成出画后改挂到脸上。`机位锚=`、望向、当前环境、`机位侧=` 不因景别改。主拍对象就是这具环境主体时，机位距写离这座锚。本角画外才用临时锚。

**构图**（机位行的镜头键，不是人的站位）：主档=`三分|中心|纵深`。可兼=`对称|框中框|引导线|负空间|无`。横屏对白默认三分。竖屏默认中心或纵深。仪式、权力、砸点用中心。走位和前后层用纵深。从门或窗看进去可兼框中框。通道可兼引导线。孤绝可兼负空间。写 `构图=`、`留白=视线前|运动前|无`。`可兼=` 不是无才写。不写 `主体落点=画左三分`；人在画面左还是右，由建置与入戏按望向换算。沿侧偏按「沿侧偏」锁，三分不另把镜头滑开。进出画：反应近景 `留白=视线前`，过程远景 `留白=运动前`。

**机运**：`机运=固定|手持|跟拍|OPV|FPV|ACT|虫蚁|鸟瞰`。固定是机站死。手持仍要写俯仰。跟拍的锚是被跟者旁边的环境件，路径不越轴。OPV 是脑后跟随，镜头角度只许平拍、微仰、微俯，禁止主观。FPV 的镜头角度必须是主观，写 `主观角色=`，距=贴身，眼高等于该人当时的眼高。ACT 是贴身动作，距=贴身或一臂。虫蚁的镜头角度必须是虫蚁。鸟瞰的镜头角度必须是航拍或鸟瞰。禁止主观标成平拍，禁止鸟瞰标成平拍，禁止脑后跟随标成主观。

**机位优势**：`AI位=无|窗外看入|檐外|对楼|航拍外立面`。航拍、宏观、空镜、入场、余波用航拍外立面。高层室内或窗前用窗外看入，窗只作画框，对白仍可以是中近景、一臂。檐口、楼顶、对楼、中庭用檐外或对楼。不是 `无` 时，`机位变因=` 含 `AI优势位`。禁止为了航拍把口型改成远景。禁止用画外的件当锚。

进出封闭舱写 `过阈运镜=过框推入|跟随入舱|窗外窥入|绕体外跟|落幅在舱|过框拉出|跟随出舱`。从外进舱优先推，从舱出外优先拉。跨口这一拍（跟随入舱和跟随出舱）走上面「出入舱跨口」：当前环境是宿主，载具是道具。`ENV变=` 写在落幅那一拍。落幅有人用 `FS|MS`。禁止宿主远景直接切成舱内中近景对白。同一拍已经看见整机和大世界，这一整拍就是落幅，环境主名用宿主。没有舱门的露天合建不套过阈。重生、闪回、回忆、梦境、闪切、蒙太奇各挂注入里对应的那一块主环境，`当前环境` 主名逐字等于这一块注册名。同一句闪回注入了宿主和舱两块时，按这一拍看见的那一套来挂：看见整机外形、侧翼、擦过尖顶、楼缝或空域，挂宿主那一块，载具档走整机；看见座、舱壁、舱内的人，挂舱那一块。禁止整机那一拍仍挂机舱。链上的近义、时间词不另写一块衍生。触发名=`重生切主环境|闪回切主环境|回忆切主环境|闪切切主环境|蒙太奇切主环境|回切当下主环境`。回到当下持续戏，再挂当下那一块。注入里只有机舱、这一拍却是整机擦尖顶 → 回流环境规划，不把尖顶写进舱。

### 机位侧与望向

**机位朝向跟环境正面**：0度望北，90度望东，180度望南，270度望西。`望=`、`当前环境=` 的度数、`[DERIVED_ENV:]` 同向。禁止望向 `画左=`、`画右=`、`画外=`，禁止 45 度。拍法和机位侧先推出望向。衍生的衍生与同度数第一刀是同一个正面。

**沿侧偏**（只此一套；定镜头在这一侧上的哪一点）：沿侧是垂直于 `望=` 的那一轴。望南或望北时沿侧是东、西；望东或望西时沿侧是南、北。镜头仍对着这一度的正面，不拧成斜向。不写米，不给镜头写 X、Y、Z。未写 `沿侧偏=` 等于轴上：镜头在 CHAR:[@名] 身体中线的延长线上。成稿不写主拍。

- 过肩：不写 `沿侧偏=`。这一偏就是越过已锁轴侧的那一肩。圆桌正对而且写了 `沿侧偏=正对椅` 的，这一条不取消那一键。
- 圆桌正对、两张椅不在桌心线上：写 `沿侧偏=正对椅`。望向不变，镜头沿垂直于望向的那一轴移到这两张椅的连线上。见「桌面谁可以当框」。这一键压过「构图=中心不写沿侧偏」和「过肩不写沿侧偏」。
- `构图=中心`：不写 `沿侧偏=`。镜头在 CHAR:[@名] 身体中线的延长线上。成稿不写主拍。已经要写 `沿侧偏=正对椅` 的，仍写那一键。
- `留白=视线前`，并且眼神所对的那一具落在沿侧的一侧：写 `沿侧偏=视线同一侧一肩`。镜头沿这一侧偏到视线所朝的那一方，档只一肩。人落在视线的反侧，留白留在视线前。眼神与望向同一条轴，对着镜头这一方或正后方，没有横向视线，不写这个键。
- 其余：不写 `沿侧偏=`。

画面中心跟着这一条：正前在身体中线，正后在后背中线，左侧或右侧在这一侧中线，俯拍或鸟瞰在主拍这具的中心，颊前在左颊或右颊。有 `沿侧偏=视线同一侧一肩` 时，轴仍对着这条中线，人偏在视线反侧。颊前不再另偏。主观不写这个键，机位在该人眼位。

**距离和仰俯按景别与拍摄对象定（最高）**：朝向锁死之后，远近和高低另定。`机位距=` 先按景别的默认一对，再按拍摄对象要看见的体量改定。`镜头角度=` 和 `机高=` 按拍摄对象要看见的那一面、读脸或背影、原文俯仰、主相位来定，再按本拍剧情因素改定。环境正面不决定贴身还是十步外，也不决定平拍、俯拍还是仰拍。同一度上收近、拉开、微俯、微仰、俯拍、仰拍，望向和环境名都不改。只有要看见的那一面在这一正面上看不见，或这一向承载不了已锁景别，才换度。换完仍朝向新的那一度的正面。✅180度望南，句眼收成贴身平拍，环境仍是 180 度。✅同一 180 度，桌面物件改成过顶俯拍，望向仍是南。✅巨体立面在这一正面里，用贴地仰拍，不换度。❌为了俯拍或仰拍改成另一个度数。❌180度环境里把镜头改望东去读侧壁。

**正拍先分正脸与后背**：要口型、神色、表情，拍法=正面，`表情换环境评=保持`。要后背、后颈、后脑、背影或跟在身后，拍法=背面，`表情换环境评=本拍不写脸`。后颈特写仍是背面。同一拍既要正脸又要后背，拍法=侧面。已经拆开的不并回。低头、坐下、走到家具旁不是背影。

`拍法=侧面` 和 `拍法=双人同框` 不套上面的正背两列，`望=`、度数、`机位侧=` 仍必须是这四组里的一整组：望北 0 度机在南，望东 90 度机在西，望南 180 度机在北，望西 270 度机在东。禁止为了把幕墙、撞击点或窗放进背景而改度。总裁办主位朝向等于门所在壁。门在南、主位朝南，正脸是 0 度。门在西、主位朝西，正脸才是 90 度。坐在已锁朝向的椅、凳、沙发上，开拍 `罗盘朝向=` 等于这张座的朝向，并写 `座朝向=` 同一向。人没有转身，禁止改成另一向去配度数。座朝南，正脸是 0 度。对面的人站在座朝向那一侧，罗盘朝向与座相反。座朝南，对面的人 `Y=南一臂`、罗盘朝北，读她的正脸是 `望=南｜当前环境=180度｜机位侧=北`。已经转身的，正脸跟转完的开拍朝向，座朝向仍抄这张座。❌座朝南，对面的人写成 `Y=北一臂｜罗盘朝向=南`，坐着的人 `罗盘朝向=北`，再按她的脸选 0 度。❌总裁办门在南、`罗盘朝向=南`、`拍法=正面`，却写 `当前环境=90度总裁办公室`。❌座朝南、人没有转身，写成 `座朝向=南｜罗盘朝向=西｜拍法=正面｜当前环境=90度`。❌机头朝南、`拍法=正面`、`望=南`、`当前环境=180度`、`机位侧=北`。这一组看见的是机尾。✅同一人正脸：`罗盘朝向=南｜座朝向=南｜拍法=正面｜望=北｜机位侧=南｜当前环境=0度总裁办公室`。✅门在西：`罗盘朝向=西｜座朝向=西｜拍法=正面｜望=东｜机位侧=西｜当前环境=90度总裁办公室`。✅机头朝南要看机头：`罗盘朝向=南｜拍法=正面｜望=北｜机位侧=南｜当前环境=0度{宿主}`。要看机尾才写 `拍法=背面｜望=南｜机位侧=北｜当前环境=180度{宿主}`。

**双人同框各查自己的侧脸**：不抄邻座。对坐、面朝相反的两人，一个左侧面、一个右侧面。轴侧是被看者面朝时的自身左：面朝北则轴侧=西，`机位侧=西`，`望=东`。

**面向镜头只由要看见的面推出，不另写朝向，也不把正前写进机位侧**：人行禁止 `朝向=面向镜头`。乙锁完 `机位侧=` 和 `望=` 之后，用上表核脸和镜头是不是同一几何。对不上就改机位侧或望向，禁止改甲的朝向去凑镜头。

| 正前 | 脸朝镜头 | 指向机所在的那一向。望南时机在北，面朝必须是北 |

正前却面朝离开镜头、正后却面朝镜头、侧对却写成脸朝镜头或背对镜头，都是失败。法相的 `面对镜头=是` 只对应这一体的正前；`面对镜头=否` 只对应正后或肩后。它和宿主的面朝向仍须相同，不能一个朝东、一个朝西。

**可拍性压过指定面（最高）**：机位侧先保证本拍要拍的动作和道具拍得到。同一拍既要看见正面，又要看见背面，`拍法=侧面`，机位落在这一侧，不锁正前，也不锁正后。正面是胸前的手、这一侧的表情、胸前或衣内的件。背面是后背、后肩、后颈、后脑、脊背。选能同时看见这一侧胸前和后肩的那一侧。文戏已拆成两拍的，不把两面并回这一拍。轴侧已锁时，取仍落在轴侧的左或右。人的朝向不改。剧本写了背影，但这一拍同时还要看见胸前的手、表情或胸前的件，同样改成这一侧，不留正后。只有背面、没有正面要拍的内容，才锁正后。只有正面、没有背面要拍的内容，才锁正前。

沿用核不过，才按这一序锁要看见的面：人载后方且本拍不写脸→背面，前方→正面，侧→轴侧。其次读脸→正面。其次后背、后颈、后脑、背影或跟在身后→背面。其次跟拍要看见本人后脑→过肩。其次并排或双人同框→轴侧。其余单人→正面。轴侧是本段第一张关系镜里被看者面朝时的自身左，此后不改。纯无人空镜和窗外特写不写身体上的机位侧。本拍有角色在行动、说话或反应，望向由这个人的拍法和罗盘朝向锁定，不用后景那一壁。没有这些、景别是特写时，主拍才是被特写的那一具。这一具在该望向里不可见，不得当主拍。

过肩、过腰、过头写在 `关系角=` 和 `过肩配对=`。部位必须是「背向与落点定关系角」已经选定的那一处。被看者按正面核侧脸。肩后不写进被看者的机位侧。

**正拍度数跟这个人的脸（最高）**：走位的终点向不代替面朝。面朝南、要正脸，望北。面朝北、要正脸，望南。禁止因为往南走改挂 180 度。上一拍的轴线是另外两人时，本拍按这个人重算。翻出后背而这一拍要口型，这个反打不成立。没有罗盘朝向，先补朝向，禁止先挑度数。

**过肩的框主在镜头和被看者之间**：这一拍看见的是框主朝向镜头的肩背，被看者在框主面朝的那一侧。框主面朝南、本拍望北，镜头看见的是框主的正脸，不能写越过他的肩。被看者和框主面朝同一向，被看者又在框主北侧，框主不在镜头和她之间。这一拍要被看者的正脸，`关系角=干净`，不写 `框主=`，不写 `过肩配对=`。人距近则 `覆盖=反打`，轴线仍在。人距远才 `覆盖=单人`。望向仍是她的正前。禁止为了留下过肩改挂 180度去拍后背。

✅甲面朝南，从北向南走，正拍要脸：`望=北｜当前环境=0度{主}｜关系角=干净｜框主=无`。丙也面朝南、站在甲南侧，不做丙的过肩。❌同一拍 `望=北` 又写框主=丙、过肩。❌改成 `180度`、望南，去拍甲的后背。

**轴**：本段第一张有人的关系镜，`轴侧=`=针对者面朝时的自身左。面朝北则轴侧=西。此后不改。反打仍在这一侧，望向差 180°，`axis_crossing=PlannedReverse`。这不是跨轴。圆桌换席不走这一条，望向跟被看者的钟点，见「圆桌坐位」。禁止把机摆到轴线另一侧。禁止为了换角写 `MotivatedCross`。人走到轴线对面，只跟新站位把轴侧重锁成新人的自身左，机仍在新的同侧。

**靠墙靠门**：对打里已有一人背后贴墙、贴门或贴门框，身后没有机位空档 → 不走过肩、过腰、过头、肩后。每拍拍法=正面，机位侧写望向对面的罗盘向，`关系角=干净`，不写 `框主=`、`近侧框主=`、`过肩配对=`。人距近则 `覆盖=反打`，轴线仍在。人距远才 `覆盖=单人`。换人另起一拍，望向差 180°，仍是干净正面。坐在床上、椅上，背没有贴墙或贴门，不算。人离门还有距离、背后仍是室内空档，不算。

**桌面谁可以当框（最高；同桌先于四步）**：被看者和另一个人都坐在同一张桌旁时，机位行先写 `桌面关系=正对|斜对|邻座`。这个键相对被看者。对面有好几个人，只取落在被看者面朝延长线上的那一个写正对，其余对面的人各算斜对，不抢框主。不在同一张桌上的，不写这个键。

长桌、方桌：正对是对面那一侧，并且和被看者落在同一条面朝线上。南北对坐时两人的 X 相同，东西对坐时两人的 Y 相同。错开不到一臂仍是正对。对面那一侧沿桌长错开到一臂或更远，是斜对。坐在相邻一侧、面朝差 90°，也是斜对。同一侧是邻座。

圆桌用较短弧。正对只取落在被看者面朝延长线上的那一个，望向仍是正交，不顺着斜线转：12 对 6、6 对 12、3 对 9、9 对 3，连线过桌心。1 对 5、5 对 1、7 对 11、11 对 7、2 对 10、10 对 2、4 对 8、8 对 4，连线平行于南北或东西，不过桌心，仍是正对。差 6 个钟点但连线偏 30° 或 60° 的，1 对 7、2 对 8、4 对 10、5 对 11，隔着桌心，机位对不上，算斜对。较短弧差 3 或 5 也是斜对。较短弧差 1 或 2 是邻座。

正对：镜头才站到这个人的椅背外。望向仍是被看者的正前，度数不改。长桌方桌读南侧面朝北的人，望南，镜头在北侧正对者那张椅的椅背外，机位锚仍是这张桌。圆桌读 12 点，望北，镜头在 6 点那张椅的椅背外。读 3 点，望东，镜头在 9 点椅背外。这两对在桌心线上，不写 `沿侧偏=`。1 对 5 这一类不在桌心线上：望向仍是被看者那一组的正前，写 `沿侧偏=正对椅`，镜头平移到这两张椅的连线上，不改成 30° 或 60°。然后才进下面四步。

斜对：镜头留在被看者面朝的延长线上，不挪到斜对者的椅背外，不用 `沿侧偏=` 去够他。他不是框主。关系角在这一步停，写干净。人距近仍是正反打，`覆盖=反打`。长桌方桌上两人面朝仍差 180°、只是沿桌错开：换人望向仍差 180°，两边都没有框主。相邻侧、面朝差 90°：各用自己的正前，差 90° 不标反打，`机位变因=换主拍`。圆桌差 90° 仍走圆桌换席，斜对者仍不写成框主。

邻座：镜头在被看者正前时，邻座在侧面，不在镜头和被看者之间。关系角=干净。要同时看见邻座，用并排 `覆盖=带肩` 或双人同框，不写成过肩。

**参考图里的座位带着坐的人（最高）**：本拍这一度的环境参考图里已经能看见的椅、凳、沙发，本拍有人坐在上面，这个人就在镜前。背面朝着镜头仍算在画里。`可见=` 写下他的后脑或靠近轴侧的肩，不写 `可见=否`。生成用的是这张没有人的房间参考图。人不进这一拍，模型会把参考图里的空椅原样留下。这张座位整张不在这一度参考图里，人和座位都不进可见。

180 度望南、参考图前景是办公椅椅背、椅在桌子靠近镜头的这一侧。过肩：坐在这张椅上的人在镜头和桌子之间，不在镜头背后。对面的人站在桌子远离镜头的那一侧，或坐在对面。读对面的人时，框主是坐着的这个人。景别可以是 `MCU`、`MS`，也可以收到 `CU` 或 `ECU`。收到特写时，`可见=` 仍写下坐着的这个人和这张椅背。干净角不套这一段，镜头改到这张椅和被看者之间。

**跨桌坐姿优先过肩（最高；先于收成干净特写）**：同一场里隔着同一张桌对白，近侧有人坐在有靠背的椅或沙发上，并且这张椅背在这一度参考图里。办公桌、长桌、方桌、圆桌正对都算，办公桌是这一条的常例。对面的人坐着或站着都算。优先写成过肩，不先收成只剩对面那张脸的干净反打。两人都坐着时，`桌面关系=正对` 才走椅背外；对面站着、近侧椅背已经在参考图里，同样走椅背外。

`人距=近` 时，景别默认 `MCU`。镜头站在正对者的椅背外，不站到椅背和被看者之间。望向仍是被看者的正前，度数不改。机位距量到被看者，取正对者比被看者更靠近镜头的那一档。两人隔着桌面已经是一臂时，椅背外通常是两步，不把机位距缩成一臂，以免镜头挤到椅背前面。`关系角=过肩`，`拍法=过肩`，`框主=` 是坐在这张椅或沙发上的正对者，`过肩配对=` 是靠近轴侧的那一肩。`可见=` 写下这一肩。椅和人同一可见，椅背留在画面里。`覆盖=过肩`，反打仍写在轴线上。换人读另一张脸时，镜头改到另一张椅背外，仍是过肩。没有越级依据的普通对白，不收到 `CU` 或 `ECU`。默认 `MCU` 盖得住这一肩，四步核完不改回干净。

停在干净的只有这几样：`人距=远`，并且这一度参考图里没有这张有人的椅背，`覆盖=单人`。斜对和邻座，椅背不在被看者面朝延长线上，参考图里也看不见这张椅背。靠墙靠门，身后没有机位空档。参考图里没有这张椅、并且这一拍已经按越级锁成 `CU` 或 `ECU` 的，含句眼、关键反应、表情特写、原文特写，不把这一档放宽成 `MCU`；肩不在画内就写干净。镜型已经是双人同框的，保持双人同框。坐在没有靠背的凳上，参考图里这张凳已经有人，人仍和凳一起留在可见里；关系角仍按下面四步，不默认过肩。

**干净角的机位（非过肩）**：`关系角=干净` 时，镜头不站在近侧椅背外面。镜头站在这张椅和被看者之间，比这张椅更靠近被看者。机位句写明：镜头在这张椅和被看者之间，这张椅在镜头后面。近景里会挡住被看者的椅、凳、沙发同样在镜头后面。坐在这张椅上的人不进 `可见=`，不写他的肩、背或椅背。过肩才把这张椅和坐着的人留在镜头前面。

**背向与落点定关系角（最高）**：四步不改已经锁好的景别和机位距。跨桌坐姿优先过肩已经锁成 `MCU` 的，这一档盖得住肩，不改回干净。其余这一档盖不到背向的部位，就写干净，不把 `CU` 或 `ECU` 放宽去迁就过肩。镜型已经是双人同框、并且这一拍不是追逐的追击视角，`覆盖=Two-Shot`，不改成过肩、过头或过腰。追击视角保持 `覆盖=过肩`，框主是追方。跟拍只看见本人后脑、场里没有第二个相关的人，仍按上表拍法=过肩，不写 `关系角=过肩`，不写 `框主=`，不写 `过肩配对=`，不按两人落点改成过头。同桌的斜对和邻座已经在上一条停住。其余要在干净、过肩、过头、过腰里选的，四步按顺序，一步不过就停。不过的拍：拍法=正面，`关系角=干净`，不写 `框主=`，不写 `过肩配对=`。人距近则 `覆盖=反打`，轴线仍在。人距远则 `覆盖=单人`。追逐覆盖的追击视角已经锁成过肩，不按远距改回干净，逃方留在可见里。四步都过才写过肩、过头或过腰，拍法=过肩。`框主=` 是背向的那一个，不等于被看者。与框主相同的 `近侧框主=` 不写。被看者按正面核侧脸。

1. **距离**：`人距=远` 停，关系角=干净。`人距=近` 才往下。贴身、一臂、两步都不单独写成过肩。
2. **背向角色在不在镜头和被看者之间**：同桌时，这一步只查 `桌面关系=正对` 的那一个。斜对和邻座不是框。背向角色是脸朝被看者、背朝镜头的那一个。镜头站在他落点的背后那一侧：坐在椅、凳、沙发上，落点是这一张，座朝南则镜头在这一张的北侧；躺或靠在床、榻上，落点是这一张，镜头在他面朝的反面；站着，落点是他已经锁上的那一具环境主体，镜头同样在面朝的反面。他到镜头的距离必须短于本拍 `机位距=`（机位距量到被看者）。跨桌坐姿优先过肩已经把镜头放在椅背外的，机位距用椅背外那一档，不拿景别默认的一臂把这一步判停。人在被看者身后、和镜头同在落点正面、或到镜头不短于机位距：他不是框，停。禁止为了留下过肩改挂 180 度去拍被看者的后背。禁止把镜头拧到斜对者的连线上。
3. **机位加景别是否真能看见这一部位**：先按下一表从落点选出候选部位，再看本拍景别盖不盖得住，并且 `可见=` 写得充足。充足是能读出这一处，不是只剩一条边。`ECU` 只剩被看者的局部，背向角色不进画，停。肩或后脑：`MCU`、`MS` 可以充足；`CU` 只在这一部位离镜头已经短于一臂时充足，人还坐在椅上、肩或后脑离镜头仍是一臂或更远，`CU` 不充足。`FS` 已经看见背向者全身时，这一拍是双人同框，不写成过肩或过头。腰：只有 `MS` 或 `FS` 充足。`MCU`、`CU`、`ECU` 腰在画外。`WS`、`EWS` 不写过肩、过头、过腰。只写左肩头或右肩头，不算充足，停。
4. **落点主体选定哪一种**：候选部位只从背向角色自己的锚和姿态里取，再跟被看者的眼高比。坐在有靠背的椅或沙发上，腰在靠背后面，过腰不成立，只在肩和后脑里选。坐在没有靠背的凳上，腰可以进候选。

并排：`覆盖=带肩` 或 Two-Shot。禁止无故裁掉旁边的人。

**巨体**：法相、金身、化龙凤相对宿主，体量悬殊时必须写 `巨体尺=肩前悬浮|遮挡不可见`。禁止写成普通人前后叠，禁止过宿主的肩。`肩前悬浮`：小人的 X、Y、Z 能读出悬浮于挂靠体肩前，可进 `可见=`，只作尺度。`遮挡不可见`：小人不进 `可见=`，锚仍与宿主相同。看对手时框主是法相，不是宿主。

**人载**：有人骑乘时写 `人载同向=是｜相对=后方|前方|侧｜载具面=车尾|车头|左侧身|右侧身`。前进向没有点名时，`朝向=` 写面朝前进向，罗盘朝向写这一拍已经能推出的那一向。推不出就不另写朝向推。`相对=后方` 且本拍不写脸 → 拍法=背面，机位侧=望向对面，禁止改成正面。禁止 `朝向=面向镜头`。`前方`→拍法=正面。`侧`→落在已锁轴侧的那一侧，轴侧尚未锁时用自身左。无人骑乘不写 `人载同向=`。本拍拍摄要求是读脸时，后方跟拍改为正前，不拧骑手的朝向。`本拍不写脸` 时 `主拍对象=` 改为 `PROP:[载具]` 或环境，`剧情匹配=` 只许走位、交付、宏观，不把主拍对象留在骑手上。

**剧情因素再定俯仰（最高）**：功能表先选一行，再读本拍【改编指导】的目标、障碍、潜台词，以及正文已经写出的施压或受压。卖点里的强者压制、恐怖压迫、低潮压抑同样算。只看主拍对象是哪一方。

- 主拍是施压、居高、被仰望的一方：`角度动机=压迫`。功能表若是读脸、对白、反应的平拍，改成微仰，机高=略低于眼高。体量已经悬殊，或正文要看见从下往上压来，改成仰拍，机高写膝、腰或桌沿，并写明是哪一具。
- 主拍是被逼、跪、伏、落在下风的一方：`角度动机=被压`。读脸改成微俯，机高=略高于眼高。要看见倒在地上的全身，才用俯拍、过顶。跪着仍要读脸，留微俯。
- 对等，或正文和改编指导都没有这层：不写 `角度动机=`。对白保持平拍。`角度动机=胸口` 仍只给隔着桌面的坐姿对白。

已经锁死、剧情不改的档：原文已经写入的俯、仰、平；桌面和布局的俯拍；宏观的航拍或鸟瞰；主观；贴地看巨体的虫蚁。口型主拍命中压迫或被压，仍只用微仰、仰拍或微俯。双人同框只跟主拍这一档。两边要各一档高低，拆成两拍，各写各的 `角度动机=`。反打：本拍写了压迫或被压，俯仰按本拍，不抄对向拍；两边都没有，才沿用对向拍的俯仰。望向、度数、景别都不改。

**机高锁完再核关系角（最高）**：落点表先按平拍、机高等于被看者眼高来选肩、后脑或腰。俯仰按上面锁完之后，用最终 `机高=` 再核一次，只改关系角，不改俯仰，不改景别，不改望向。平拍在胸口，坐着的两人仍按肩。微仰或仰拍不把过肩改成过头；这一档里肩和后脑都不在画内，改成干净。微俯且机高已经高于框主的后脑、后脑仍在画内，关系角改成过头，即使落点表原先是过肩。俯拍、航拍、鸟瞰、主观、虫蚁：背向的人不再当框，关系角=干净，不写框主。主观角色在画外，没有框主。

口型主拍禁止航拍、鸟瞰、虫蚁。宏观建置禁止眼高平拍。缺 `机高=`，或只写俯仰不写高低=失败。载具档仍是 `内部ENV` 时，不用航拍、鸟瞰、远高于头顶；外面在玻璃里，机高仍是坐姿眼高或略高于眼高。这一拍已经看见本机外形或两架整机，先按上面改成宿主，再许用航拍。

**机位锚**：只写镜头相对哪一具环境主体，不回写成朝向。这一具必须是本拍望向这一格看得见的主体：该格正面、左右或中部。镜头后面那一壁上的具不选。人的站位锚是另一个人时，机位锚用对方已经锁上、且本角看得见的环境主体；对方还没有，或那一具在本角看不见，用本角看得见的中部主体。人已经写成双主体时，机位锚是中部那一具；中部这一具本角看不见，改用本角正面已经有的那一具。没有双主体、该人锚已按入戏取物或剧情例外锁成桌、门或正文点名的那一具时，这一具本角看得见，机位锚跟这一具；看不见，改用本角正面或中部看得见的最近一具。人锚已是最近那一具、且本角看得见时，机位锚跟这一具。距离相若、人锚是中部、中部本角看得见时，机位锚是中部那一具。反打、切角不改挂，禁止把本角 `背景=`、`远锚=` 或四壁升成机位锚。中部没有具名主体、也没有剧情例外时，才用针对者水平面朝的那一具合格环境主体，且这一具必须本角看得见（低头和落座改不出这条面朝）。面朝的是人 → 用该人已锁的、本角看得见的环境锚。坐在床上，床本角看得见时锚可以是这张床，水平朝向仍沿用开拍。空镜有中部主体、正文又没点名后景、中部本角看得见时，锚仍是中部那一具；中部没有或本角看不见，才用本角看得见的后景。锚必须独一、有轮廓。没有合格锚 → 回流，不另造。

门外、窗外、檐外、对楼、上空、航拍：望北时机在南侧外，望东在西侧外，望南在北侧外，望西在东侧外；航拍在上空。从门外往里拍：锚=该门，门在南则望北，门在北则望南。

### 沿用与当前环境

**新拍先定拍法，再定衍生**：拍法还没写成正面、背面、侧面、过肩、双人同框之一，禁止写 `当前环境=`，禁止先挑度数。拍法锁完，才推出机位侧和望向。候选名先走下一条点名。主拍要看见的那一面在这同一个望向里成立，才写下 `当前环境=`。其余主体落在画外，不挡这次确认。只核环境主体、主拍的正反面仍按正文后脑来写，不算成立。

**确认衍生环境前先点名本拍主体（最高）**：候选是 `{N}度{主}`。`当前环境=` 和 `[DERIVED_ENV:]` 先不写。先把这一拍出现过的主体列成名单，再逐一点名，再核这一度里每一具是否可见，含有正反面的那一具的正面和背面。

名单是两批，合在一起，不并成全员、四壁或若干。第一批是本拍正文、动作、锚、双锚、手持、朝向对象里出现过的角色、独立道具和环境主体。第二批是候选这一度里面已经有的环境主体：`背景=`、`画左=`、`画右=`、`画外=`，再加上这一块主环境中部已经点名的主体。同一注册名只留一行。

每一具单独一行，写在分布图里、`当前环境=` 之前：

`本拍主体={注册名}｜类=角色|道具|环境｜正面=可见|不可见|无｜背面=可见|不可见|无｜可见=是|否｜落位=背景|画左|画右|中部|画外`

有正反面才写正面和背面：人，以及驾驶舱、整车、飞行器、船、机甲、屏、镜、像、有正面的法器、有屏面的操纵台，门再写朝向室内的那一面和门外的那一面。没有正反面的写 `正面=无｜背面=无`，只答整具 `可见=`。

名字在这一度的 `背景=`、`画左=`、`画右=` 或中部，`可见=是`。名字在 `画外=` 或 `不可见内容`，`可见=否`，`落位=画外`。没有正反面的环境主体只答整具 `可见=`。人，以及驾驶舱、整车、飞行器、船、机甲、屏、镜、像、有正面的法器、有屏面的操纵台，正面和背面只查侧脸表：这一具的 `罗盘朝向=` 乘本拍 `望=`。每人、每件用自己的罗盘朝向。表上是正面，写 `正面=可见｜背面=不可见`。表上是背面，写 `正面=不可见｜背面=可见`。表上是左侧面或右侧面，看见的那一侧写可见，另一面写不可见。不跟正文里的后脑、背影、正脸改写。不跟已经写下的 `机位侧=` 改写。表和拍法对不上，这一度不确认。

**衍生环境只跟主拍**：主拍是谁见乙。没有剧情的人、道具、门、窗、壁不进主拍，不参与选度。同一拍既有角色动作或对白又有道具细节，主拍仍是这个角色或这两个人。

望向和 `当前环境=` 只保这个主拍对象要看见的那一面。人：拍法=正面，表上必须是正面。拍法=背面，表上必须是背面。拍法=侧面，表上必须是这一侧。拍法=过肩，被看者的表必须是正面，框主的表是朝向镜头的肩所在的那一面。表上这一面成立，就写下 `当前环境=`。有正反面的特写实体：本拍要看见的屏面、车头、挡风或像的那一面，必须就是表上的那一面。禁止改主拍的罗盘朝向去凑这一度。

其余在场的人、其余道具、锚、双锚、承托、门和壁，不参与选度。它们落在这一度的 `画外=` 或 `不可见内容`，写 `可见=否｜落位=画外`，不因此换度，也不升成 `主拍对象=`。机位锚改到这一度看得见的主体上。

双人同框的望向取能同时看见两边要看的那一面的那一度。每人用自己的罗盘朝向查表。对不上就改拍法或拆拍。群演簇作主拍时，望向取看得见这一簇的那一向。簇外没有剧情的具名角色不并进这一簇。

人背对的那一壁跟主拍这个人的拍法绑在一起。拍法=正面，这一壁在 `背景=`，看见的是脸。拍法=背面，这一壁在镜头后面，`可见=否｜落位=画外`，不得写成 `主拍对象=`，不得写成 `落位=背景`。特效、落幅、监控屏落在这一壁上，不把望向改成这一壁所在的那一向，也不把这一壁写成主拍。背面拍留下由拍法推出的望向，这一壁写不可见。这一拍的任务是把这一壁看成背景，拍法改成表上那一面，人的正反面改成表上的词。后脑和这一壁当背景要同时成立，拆成相邻两拍：一拍望向等于面朝，主拍是这个人，只写后脑，这一壁在画外；相邻一拍望向等于背对，这一壁在背景，人写正面。禁止留在同一度里两行互相矛盾。

换度只在主拍对象的要求面在这一度对不上时发生。换完再查这张表，主拍要看见的那一面仍是表上的那一面。非主拍在画外，不换度。读脸的正前和主拍必须看见的那一具分属对向两壁，拆拍。候选这一度自己的画外主体仍逐行点名，`可见=否`。确认之后，机位锚不得改挂到这些画外的环境主体上。换度之后主拍的正反面按新望向重写。不许只改环境主体那一行、把主拍的正反面留在上一度。

❌陆沉 `罗盘朝向=北`，这一拍是他坐着，要后脑，却写 `望=南｜当前环境=180度顶层办公室｜主拍对象=南侧整面通高落地窗｜正面=不可见｜背面=可见`。望南、面朝北，表上是正面。南窗在他背后，放进背景看见的是脸。✅同一人要后脑，主拍是这个人：`望=北｜当前环境=0度顶层办公室｜机位侧=南｜主拍对象=CHAR:[@陆沉_重生后]`，南窗 `可见=否｜落位=画外`，人 `正面=不可见｜背面=可见`。北门若落在背景，名单写可见；景别盖不到时由建置不写。✅同一人要正脸：`望=南｜当前环境=180度顶层办公室｜拍法=正面｜主拍对象=CHAR:[@陆沉_重生后]`，人 `正面=可见｜背面=不可见`，南窗 `落位=背景`。北门在这一度镜后，`可见=否`，不改望，建置不写这扇门。❌主拍是这个人、要正脸，北壁窗在望南的画外，于是改成望北把窗放进背景，脸改成后脑。❌本拍没有人在行动，特写这面南窗，却仍把主拍写成坐着的人。✅特写这面南窗：`主拍对象=` 是这面窗，望向取这面窗朝向镜头的那一度。❌名单写成环境主体若干。✅八仙桌、南椅、北壁窗各一行。这一份不是拍末 `确认=`。

先锁本拍景别和其余拍摄要求，再决定留不留在上一拍的衍生环境。拍摄要求含已经写下的拍法。拍摄要求锁完之前不写 `当前环境=`。

**沿用默认留下**：四项和拍法都过就留下。景别变只改机位距。俯仰变只改机高和镜头角度。换说话人、接招、读对手、满三拍，本身不换角。只有上一角看不见要读的那一面，或承载不了已锁景别，或拍法从单人改成双人同框、或从双人同框改回单人读脸，才换度。禁止用拉远把双人同框留在单人那一张图上。反打必须差 180°。差 90° 看见的是侧壁，禁止拿来冒充反打。圆桌换人读脸除外，写 `圆桌换席`。蒙太奇换块时，当前环境必须已经是对上的注册名。

拍摄要求只锁这四项，不选度数：

1. 景别。按上一节的原文、功能表和主相位锁死。向距只回答某一向能不能承载这个景别。
2. 要看见的那一面。归类决定针对者必须被看成正面、背面、侧面，或双人同框。口型、读脸、神色是正面。正文写明的背影是背面。并排、双人同框而不单读一张脸，是两人同时在镜前。
3. 必见集。只收主拍对象要看见的那一面，以及必须和主拍同一面入画的人和具（取用、开门、递接的人、承托、道具、被读的那一面）、走位的起点和终点。世界里在场、本拍不要求入画的，不进必见集。人背对的那一壁、这一度镜后的具不进必见集，不因此换度。景别盖不到的具也不进必见集。必见集在写 `可见=` 之前列出。
4. 载具档主名、人载相对、原文俯仰和机运。主名变了就是另一族环境。

有上一拍且主名相同，用上一拍的 `当前环境=`、`望=`、`机位侧=`、`机位锚=` 核这四项，并先核拍法。拍法还没写下，不得沿用，也不得换角。上一角的拍法就是本拍拍法，这一项才过。单人与双人同框对不上，拍法不过，按下面重锁，禁止 `ENV变=否`，禁止仍写 `机位变因=承上`。轴侧重算后望向与上一拍相同，才留在这一度。✅上拍 `拍法=正面｜望=南｜当前环境=180度`；本拍双人同框、被看者面朝北：`机位侧=西｜望=东｜当前环境=90度{主}｜ENV变=是:双人同框｜机位变=是｜机位变因=换主拍`。❌仍沿用 180 度，只用拉开把特写收成全景。拍首蒙太奇对上的注册名与上一拍主名不同，必须换块，`ENV变=是:蒙太奇切主环境`。`【世界物理】无`、`【改编指导】` 不取消这次换主，也不改望向和度数。四项和拍法都过就留下。留下而本拍画面已是不可逆变化之后、这一行仍是第一刀：改挂同度 `{N}度{主}_{状态}`，不写 `落幅环境=`。变化在本拍才落到画面上：当前环境留第一刀，`落幅环境=` 写同度状态行，`ENV变=是:环境状态`，`机位变=否｜机位变因=承上`，不写 `机位切换=`。没有景别、俯仰或状态变化：`机位变=否｜机位变因=承上`，不写 `ENV变=`。锚、X、Y、Z、机高、俯仰、望向、景别、拍法仍全文写出。`承上` 只许出现在 `机位变因=`。禁止 `机位=承上`、`镜头承上`、`机高=承上`、`站位=承上`。同一角已经是双人同框、景别盖得住、拍法仍是双人同框，就留下。

沿用核在写 `可见=` 之前做，并且在 `拍法=` 已经写下之后做。镜在望向的对面。人在镜前 = 人落在望向那一半，不在画外那一向。拍法=正面：该人面朝加正前推出的望向等于本角望向；看见的是背，这一项不过。拍法=双人同框：必见的两人都在镜前，并且已锁景别盖得住两人。拍法=过肩：被看者按正面核，框主在近侧。拍法=背面：四向表上这一人是背面，看见的是后背。表上是正面，这一项不过。拍法=侧面：看见的是左侧或右侧，并且等于表上的那一侧。必见集里的具在本角 `背景=`、`画左=` 或 `画右=`。不在必见集里的具落在 `画外=`，不因此换度。人不在这三键里。本角向距承载得了已锁景别。人载相对与本角机位侧一致；本拍要求读脸时，后方跟拍这一项不过。

一个衍生角看见三面。`背景=` 是正面。`画左=`、`画右=` 是两侧；该格已写侧端出画的，这一截到此为止。`画外=` 在镜头后。侧面残缺本身不换角。要读的面仍在正面，人只是从侧面经过，就留下。

走位的起点、路径和终点都在镜前那一半，本拍要读的面仍是正面或中部，景别盖得住，这一拍走完，环境名不变。换角落在要读的那一面变成残缺侧壁、或落到镜头后面的那一拍，不落在迈出第一步。要读的门、柜、床、字落在当前角的侧壁上，而这一格已写成侧端出画，或只剩一条压扁的边、读不清该读的那一面，这一拍才换到把那一壁看成正面的角。路径中途会走出这一角还能看见的那一截，在人还留在镜前的最后一点拆拍：前一拍留在原角走到可见尽头，下一拍换角，走完剩下的一段。望北时人从正北走到东壁偏北，人仍在镜前，留在 `0度`。到了才要读东壁上的门、物或字，下一拍换 `90度`。东壁这一格已是侧端出画，就在镜前的最后一点切开。望东时终点已在正面上，起点那一截北壁还在画面里，就留在 `90度`。

四项有一项不过，或拍法对不上，才离开，按下面重锁。拍法没写下不得重锁。禁止先选度数再倒推拍法或机位。侧面残缺而本拍不读那一壁，不算不过。入场拉开、越级、上一角拉远也能看见两人，都不取消拍法不过。

- 拍法从单人正面、背面、侧面或过肩改成双人同框：机位落在已锁轴侧，重算望向。新望向与上一拍不同就换度，`ENV变=是:双人同框`，`机位变=是`，`机位变因=换主拍`。禁止留在单人那一度上拉远。从双人同框改回单人读一张脸：按正前重算望向，`ENV变=是:换拍法`。新望向与上一拍相同才留下。
- 要看见的面在上一角是背：按这个人的正前重算望向，机位侧改成该望向的对侧罗盘向，不写正前。反打时望向差 180°，轴侧不变，`axis_crossing=PlannedReverse`，`ENV变=是:反打`，`机位变因=反打`。翻出来看见的是后背，而这一拍要口型，这个反打不成立，改回这个人的正前，不写反打。禁止用差 90° 的角冒充反打。圆桌换席按被看者钟点的正前望，差 90° 写 `机位变因=圆桌反打`，不按这一句判成冒充。禁止把另外两人的轴线翻 180° 当成这个人的正前。
- 正前那一向承载不了已锁景别：改到仍能看见要求的那一面、并且向距承载得了的正交角。侧面先试落在已锁轴侧的那一侧。`ENV变=是:向距承景别`，`机位变因=切角投影`。四个正交角都承载不了，才把景别收到最宽那一向允许的最大档；上一角就是这一档，就留下。写 `向距收档=是`。
- 必见的人在镜后，或必见的陈设在画外：先试正前。正前仍看不见该具，再试轴侧那一侧、另一侧、正后，取第一个能看见它、且承载得了景别的机位侧。四面都看不见，或必见项分属两个对向角 → 拆拍。`ENV变=是:覆盖不足`。读脸、口型、人载要看的正面，不因为另一件道具在画外而改掉正前望向；该具不进 `可见=`，或另拆一拍。禁止为了看见它而改甲的站位或朝向。
- 人载相对变了：机位侧改到新的相对。本拍拍摄要求是读脸时，后方跟拍改为正前，不拧骑手朝向。
- 载具档主名变了：`ENV变=是:整机换主|出舱切主环境`，度数仍由本拍望向推出。
- 上拍是空镜，本拍第一个人在该角镜后：按这个人的面朝重锁。

沿用成功，要读的脸在本角是正面或侧面：`表情换环境评=保持`。离开的原因是看见背：`表情换环境评=改挂`，重锁后的望向和机位侧按罗盘写下，不把正前、左侧、右侧写进机位侧。按正前刚刚算出的望向看见的就是正面，禁止对它再写改挂。不能改挂则 `本拍不写脸`。无神色写 `无`。禁止拧人的朝向凑正面。

场第一拍：`机位变=开场｜机位变因=首拍`。不写 `机位切换=`，不写 `ENV变=`。其后只有环境名变了才 `机位变=是`，并写 `机位切换=到{本拍机位锚}{本拍机位侧}{本拍机位距}`，这三个值与本拍机位行相同。不写上一拍机位在哪。例外：环境名只是同一度的 `{N}度{主}` 与 `{N}度{主}_{状态}` 之间更换，望向、机位锚、机位侧、机位距都相同，则 `机位变=否｜机位变因=承上｜ENV变=是:环境状态`。`机位变=否` 时不写 `机位切换=`。景别变化留在同一环境时，变因仍是承上。

**望向推出环境名**：望北→`0度{主}`，望东→`90度{主}`，望南→`180度{主}`，望西→`270度{主}`。度数只此四个，含衍生的衍生。`{主}` 逐字等于本拍已经对上的注入注册名。有 `蒙太奇链`、或这一拍是回忆、闪回、梦境、重生时，先按「两段职责」对上那一块，再取这一块的注册名。没有这条、也不是这些拍时，`{主}`=本拍 `载具档=` 已锁的那一族，这一族也必须已在注入里。望向只换度数，不换主名。对上的名字写入提取块，至少一行 `{N}度{该注册名}`。这一拍要挂的是衍生的衍生时，名字是同度数的 `{N}度{该注册名}_{状态}`，拍法、机位侧、望向与这一度的第一刀相同，不另算一个角。闪回、回忆、蒙太奇、重生切到另一块时，触发=`闪回切主环境|回忆切主环境|蒙太奇切主环境|重生切主环境` 中对上的那一个。没有人的空镜仍写这一行，机位锚用这一块里已点名的楼、塔、尖顶或航道。对不上 → 回流环境规划，不新造衍生行，不改挂到别的主环境。`触发=Master` 不是 `0度` 的同义词。开场、第一刀，都不自动粘 `0度`。禁止先选度数再倒推拍法或机位。禁止把 `主拍ENV=` 直接写成 `当前环境=`。禁止写出 0、90、180、270 以外的度数。

一拍只挂一个已声明名。例外只有同度不可逆变化：这一拍开拍挂第一刀，落幅再挂同度状态行，两个都写。盖不住，或同框有戏的具名超过 4 个 → 拆拍。同主同向的无状态第一刀只一行，不因为景别、过肩、反打另起后缀。上游写了扭曲、变色、粒子化，或标了环境改观，满幅和维持的拍才挂 `{N}度{主}_{状态}`，状态词跟上游；余波回落后回到没有状态的那一行。不可逆变化的 `_{状态}` 另走下条，同一度的无状态第一刀和状态行并存。只有空镜资产本身必须仰看天花或天空，才另建 `{N}度{主}_仰天`，并写 `特别表述=仰天:{一句可核销空镜}`。普通四方行禁止写 `特别表述=`。仰天行禁止标成衍生的衍生。只是镜头角度为仰拍、航拍，而环境仍是平视四宫的，不建仰天行。

**不可逆变化走衍生的衍生（最高）**：天象改了，桌子或架子被掀翻，墙、玻璃、门扇破了，地面或梁留下断口。这一处变化留在环境里，本场内不复原。先看注入的【主环境】。已经有一块就是这次变化之后的同一空间，那些拍挂 `{N}度{该注册名}`，按第一刀只切割。没有这样一块，不回流环境规划，不把破损、掀翻或天象写进无状态第一刀，也不要另起一个废墟之类的新主名。无状态第一刀仍是 `{N}度{主}`，`类型=第一刀`，`状态Delta=无`，生成提示只切割不改画。变化能被这一角看见的每一度，另起一行 `{N}度{主}_{状态}`，`类型=衍生的衍生`，`触发=状态`，`同角切割父=` 同一度的第一刀。N 只许 0、90、180、270，与父行的 `view_angle_from_main` 相同。`背景=`、`画左=`、`画右=`、`画外=` 照抄该第一刀。选拍法、沿用、反打、双人同框、机位侧和望向时，这一行与同度数的第一刀一样处理，不另起一套选角。

**破损按剧情写清（最高）**：写这一行之前，按本场剧情把这一处评成一档，写进 `状态Delta`。墙、玻璃、门扇、梁、地面、天花的破法先分两档，不能混。`范围=一个洞`：只破开一处。点名哪一具的哪一面，洞或裂口在哪。原文写了大小、形状，原样留下。其余墙、梁、天花、地面和家具保持完好。状态词用破洞或裂口。`范围=整体崩碎`：这一面或这一间一起塌、碎或焚毁。点名哪些具一起没了，哪些还立着。状态词用崩碎、坍塌或焚毁。掀翻、天象不套成洞或崩碎，`范围=掀翻|天象`，状态词用掀案、血月这类剧情词。原文写了破损，`依据=` 带上那一句原文；没写则 `依据=无`，仍按动作写出是一个洞还是整体崩碎。禁止只写「破损」「毁了」「狼藉」。同一处不能既是一个洞又是整体崩碎。天象和特效可以写颜色、形状、纹样。已注册的桌、墙、玻璃不改颜色、材质、纹样。不新造陈设，不重摆四壁。`状态Delta=` 写这一处：哪一具、范围、具体样子，并带上 `依据=`。`生成提示=` 只写这一句状态Delta。同一主、同一度、同一组变化只一行。后文又添一处不可逆变化，另起一个状态词。`状态Delta` 写成相对原主环境已经留下的全部变化，每一处仍写明自己的范围。父仍是该度第一刀，不把父写成上一层状态行。这一角的背景、画左、画右或中部看不见该变化，不给这一角建状态行。没人再用的度不建。状态行只要存在，提取块里必须有它的同角第一刀，即使没有拍再挂那一刀。程序不按度分别改画面。同一所属主环境、同一状态词合成一块衍生主环境，名字是 `{主}_{状态}`，参考图是被依赖主环境的四格拼图，同一主体的相关内容四格一起改。一个洞只改点名的那一具，整体崩碎才让点名的那些具一起碎。各度 `{N}度{主}_{状态}` 只切割这块衍生主环境。

**对应拍切换两套衍生（最高）**：变化还没发生的拍，`当前环境=` 挂无状态第一刀，不写 `落幅环境=`。变化在本拍才落到画面上，开拍仍是变化前：这一拍 `当前环境=` 挂同度第一刀，`落幅环境=` 挂同度 `{N}度{主}_{状态}`。两个名字都写入这一拍，各有一条 `[DERIVED_ENV:]`。`ENV变=是:环境状态`。望向、机位锚、机位侧、机位距不变。禁止这一拍只挂其中一套。禁止把破损写进第一刀。禁止落到下一拍才第一次挂状态行，而这一拍的落幅已经是破后。下一拍起，只要还停在这块主环境、变化还在，`当前环境=` 和 `[DERIVED_ENV:]` 只挂 `{N}度{主}_{状态}`，不写 `落幅环境=`。场开场已经是变化之后，各拍直接挂状态行，不写 `落幅环境=`，第一刀只留在提取块里当父，不在开场拍再切一次完好图。换到另一度，那一度也挂同一个状态词，不在换角那一拍再从完好图切一次。粒子、沙尘、光晕会散掉的，仍只在满幅和维持的拍挂状态，余波回落回到无状态行，不写 `落幅环境=`。不可逆变化不因余波结束回到无状态行。门窗开合、盒盖开合、挪开椅子、端走杯子、人走开，不建这一行。门写在该拍 `门窗态=`。盒、匣、箱、盖、抽屉写在该拍 `盒态=`。景别、过肩、反打不另起状态词。

### 衍生环境提取（切环境图，不是给人换算）

普通行名=`{N}度{主名}`，N 只许 0、90、180、270。不可逆变化的状态行名=`{N}度{主名}_{状态}`，N 与同角第一刀相同，也只许这四个数。主名段仍是该注册名。主名逐字等于所属主环境，并且逐字等于本场已注入的某一块【主环境】注册名。禁止 `Beat:`、`文戏:`、`Ndeg` 当名字。禁止用链上未注入的字、拍文地名、三年前、当年、旧时、回忆中、闪回里当主名。禁止 45 和其他水平角。衍生的衍生不因为加了状态就换成另一个 N。

每行写入提取块：名称、所属主环境、`view_angle_from_main`、类型、触发、`活动适配`、`可见内容白名单`、`可见边界`、`不可见内容`、`背景=`、`画左=`、`画右=`、`画外=`、`生成提示=`、`lens_profile`、`axis_crossing`、`spatial_axis`。

`背景=` 照抄主环境该向已点名的主体。`画左=` 照抄左转 90° 那向，`画右=` 照抄右转 90° 那向，`画外=` 照抄对向并标（不可见）。禁止改写、禁止把角色和可移动道具写进这四键、禁止填无。对应向没有主体 → 回流环境规划。这四键是该角度环境图的固定陈设，不是角色站位。

`生成提示=` 必须能检索到 `截取宫格=`，并与 `view_angle_from_main`、主环境 `四宫度数=` 一致。主环境四宫已经写了度数，就按那一行裁；旧稿若是右下 180、左下 270，按旧行裁。缺行才用 0→左上0度，90→右上90度，180→左下180度，270→右下270度。另须 `远锚=`。远锚照抄 `背景=`，禁止用画外主体。不抄开篇四壁、中区、光学说明、【定位】【色彩说明】【主体外形】【四向拼图】，不写路怎么铺、地面纹路、中部逐件、画面左或靠近镜头。核对时只读已经对上的那一块里该格已经写成的句子。光学、结构和摆位用该格已写成的正面、左侧面、右侧面、中部、源体可见、源体画布位、高度带、影子投向。16:9 是切割比例。成片宽高比写在机位行 `画幅=`。以上只约束第一刀。衍生的衍生不写 `截取宫格=`，生成提示只写 `状态Delta`。

`可见边界=全画幅` 无效。必须用具名实体写清左界、右界、上界、下界。左界、右界和 `画左=`、`画右=` 是同一批件。沿着短的一侧看路时，写出路的左右截断，禁止为了把路的全长收进来而把边界扩到两端。

白名单只写固定陈设及其可见面。禁止写入人名、动作、表情。本角背景微动件必须是这一行里明确可见的主体：名字逐字出现在 `背景=`、`画左=`、`画右=` 或白名单可见面里。`画外=` 与 `不可见内容` 里的具不能当本角背景微动件。主环境已经点名 `背景微动件=`，而且它就在这三键或白名单里，就写入白名单，不另造，也不改它的落点。它不在这三键里，本角不写它。可见主体包括光源：窗、灯、灯笼、火塘、烛、补光源。本角看得见这一具时，微动可以是它的动态光影。写到影子时，必须点名投下这道影的那一具光源，而且这一具就在本角 `背景=`、`画左=` 或 `画右=` 里。看不见的光源不写它的光，也不写它的影子。舱内 0 度望向挡风，不写后排座的正面。90 度与 270 度须列出全部座位，并标近侧和远侧的可见面。驾驶舱里后排和司机要同时看见，只允许 90 度或 270 度。对向不可见只约束舱外的街景，禁止把近侧座位整排写进 `不可见内容`。

不在提取行写 `简要特征=`。程序按各拍用到的 `锚=`、`机位锚=` 归入该衍生，只留下本角看得见的面：正面、左侧面、右侧面。画外那一壁、机位后面的主体不写入。180度望南时，北壁在镜头后面，北向落地窗不进简要特征。

本拍必见的锚、承托、手持可见面、出入口、特效命中面，必须落在这一角的白名单里。取用、开门、递接还要同时看见执行的人、承托、道具和被读的那一面。只写「桌区全部面」不等于看见酒盏。走位里本拍要读的锚、承托和出入口必须在白名单里，并且要读的那一壁是本角正面。人经过的空地不因为不在白名单里换角。侧壁上的件，只在本拍要读它的那一面、而这面已经残缺时，才算没盖住。直线上有障碍，绕开的那一侧也要进必见集，一拍装不下就拆拍。已入场但本拍不必看见的人，仍占世界位，不为他改挂。纯声音不进必见集。一拍的必见项分属两个对向角 → 拆拍。

场核的 `细节特写参考`、`贯穿保护` 必须落在已声明的衍生里。`反馈特写参考` 要在同一拍或紧邻的切角里读得到。`运镜参考` 要有连续可见的空间。

拆拍时，过程和特效句按角分完，禁止吞掉。每拍自备【配乐】【音效】和分布图，从 1 重新编号。场级 `承接=`、`节拍=`、`落地=` 与输入的 B 号对齐。`拆拍依据=ENV覆盖|角色超限|群演疏离|占用换主`。拆开之后每一拍仍是一个动作或一个反应。禁止把没有因果关系的两件事揉回同一拍。不改对白、因果、左右手脚、取用、朝向，也不改正文已经写明的开或关。开或关落在哪一拍，那一拍的 `门窗态` 或 `盒态` 写成 `本拍=开` 或 `本拍=关`。

`开口朝向=` 是口朝哪一向，只用东、南、西、北、上。口是朝哪一向看进去的那一面。顶开的盒、匣、箱、盖，口在顶面，没有明文就朝上。明文写了口朝东、南、西、北，或把口转向某人，跟那一向：转向某人时，从这件指向这个人。抽屉的口朝抽出的那一向；`门窗态` 的 `往向=` 是东、南、西、北时，开口朝向等于往向。柜门的口朝该具使用面，抄环境规划这一具的 `朝向=`。盖掀去的那一侧仍由 `门窗态` 的 `往向=` 管，口不改成盖掀去的那一侧。

同一件已经有 `门窗态=`：这一行的 `开拍=`、`本拍=`、`终态=` 与那一行相同。这一行补 `开口朝向=`。

本拍正文没有开、关、掀、抽、拉这一件：`本拍=保持`，`终态=` 等于开拍。本拍才打开：`本拍=开`。写到敞开、或没写留缝，终态=全开。写半掩、留缝、虚掩，终态=半开。本拍才关上：`本拍=关`。关严是全关。停在半掩是半开。

本拍把口转到另一向：开拍的 `开口朝向=` 仍是转之前，`开口终=` 是转完的那一向。下一拍的 `开口朝向=` 全文等于这一拍的 `开口终=`。没转时，下一拍全文抄上一拍的 `开口朝向=`。

这一件在本拍镜头后面，这一行仍写。已抽成道具的具名与 `PROP:[名]` 同名。环境里的柜门、箱盖、抽屉与 `门窗态` 同一名字。

✅`盒态=木盒｜开拍=全关｜开口朝向=上｜本拍=开｜终态=全开`。盖往北掀，口仍朝上。
✅抽屉的 `门窗态` 往向=南：`盒态=抽屉｜开拍=全关｜开口朝向=南｜本拍=保持｜终态=全关`。两行的开拍、本拍、终态相同。
❌顶开的盒因为盖往北掀，写成 `开口朝向=北`。
❌`开口朝向=画面左`。
❌有木盒却写 `盒态=无`。

## 自检

各节已写的失败条件仍有效。这里只核落笔：

- 封套从 `[SCENES_BLOCK_START]` 起。提取块、【全场调度】、至少一拍都在结束标签前。没有【取景锁定】，没有 `宫格=`，没有回写主环境。主名逐字等于注入注册名。
- 人行的位置只有锚、X、Y、Z。坐着的人保留 `座朝向=`。没有侧、偏、距锚、落点据、辅、背对、侧序、同簇、针对、机位=场内、原文景别、站位变=否、绕=无。`ENV变=否`、`落幅环境=无`、`载具档=无`、`机位切换=无`、`axis_crossing=None` 不写。`门窗态=无`、`盒态=无`、`动扇=无`、`状态Delta=无` 仍写。
- 机位侧是东、南、西、北，站在望向对面。近是正反打，远是单人正拍。追逐覆盖的追击视角、双人同框、航拍全景，远距也同框，对方在可见里。同桌先写桌面关系。只有正对者可以当框，斜对和邻座是干净。同一场近距、近侧有人坐在有靠背的椅或沙发上、这一度参考图已经看见椅背，对面坐着或站着，景别可以是 MCU、MS，也可以是 CU 或 ECU。人和椅背一起进可见。特写不把坐着的人写成不可见。人距远且参考图里没有这张椅背，才是干净单人。圆桌 1 对 5 这一类写 `沿侧偏=正对椅`，望向不改成斜线。1 对 7 这一类不是框。关系角按背向四步：远、不在镜头和被看者之间、景别盖不到、或和这张椅的可见高度不合，都是干净。坐在有靠背的椅或沙发上没有写成过腰。四步都过才是过肩、过头或过腰，被看者仍是正面。单人表演是中景、近景、特写。
- 开拍是动作前。走和递的方向在正文里。停点的 X、Y、Z 从下一拍才写入。走向与开拍朝向相反时，正文先转身。坐着且没有转身，罗盘朝向等于座朝向。对面的人在座朝向那一侧。主位朝南时对面是南侧，不写北一臂朝南。
- 纯无人空镜这一处没有角色。窗外特写人仍占世界位，景别是特写。
- 同时连着两个人的道具写全四处、哪一段、怎么连、什么程度。被连上的人锚是拿着的人。
- 不可逆变化落到画面上的那一拍，当前环境是同度第一刀，落幅环境是同度状态行。破损写了一个洞或整体崩碎。起侧、往向、开口朝向用东南西北或上。
