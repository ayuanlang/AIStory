## 目标（最高；本子技能工作方式）
本技能按**单场**调用。程序输入=已注入【主环境】【未落清单】的该场 + 文戏标准化（及按评估后的特效/仙攻增强）的最终 Beat。
**本环节只依据已注入【主环境】**（及【未落清单】）：根据该主环境的 0°轴/四向/固定清单/活动空间，为**每个 Beat** 明确衍生环境。环境复用已在环境规划阶段解决，本环节不考虑复用、不沿用场外/项目库衍生名。
职责四项，缺一失败：
**A. 按本场主环境声明衍生族**：只根据已注入【主环境】，为每个最终 Beat 的必见内容建立够用的 `{N}度…` 衍生行（可多个），写入 ENV_BLOCK 的【衍生环境】。
**B. 为每个 Beat 锁定完整景别（七档）与构图方案（主档+可兼），且必须与该拍剧情功能匹配、与上拍切换合理；对白/交付/画幅/特写配额/`-`/`~` 按 §4.5 一次锁死，禁止留给下游分镜改档**。
**C. 为每个 Beat 选定对应衍生名**，输出覆盖矩阵；同一衍生连续≤3。
**D. 每个 Beat 正文必须直接写入该拍的环境选择、景别、构图、剧情匹配、跨度**（与场头方案同核）；缺任一拍=失败。
不写【建置】落位句、不写入戏位移、不改对白/特效/仙攻过程、不改主环境四向/0°轴/固定清单/注册名。
1. **当前可拍 ENV 只能是本文件按本场主环境声明的 `{N}度{主名}`**（Master=`0度{主}`）；禁裸主环境名。空间依据=本场【主环境】；每个 Beat 的衍生环境必须能由该主环境推得。不考虑环境复用；输入若另有复用衍生清单/项目库衍生名，忽略不沿用。坐标系服从本场主环境，禁止重映射角度或另起近义主名。
2. **不改主环境骨架**：【主环境】【未落清单】原文透传。只允许在 `[ENV_BLOCK_END]` 前追加或补全 `────【衍生环境】────` 行。
3. **过程正文原样透传，取景必须写入该拍**：文戏/特效/仙攻过程句不改写；不写三段式建置/入戏。场头仍写覆盖矩阵与【Beat景别构图方案】。**每个 `[BEAT_START]` 在标题行后、过程正文前必须另起一行【取景锁定】**，写入该拍 `当前环境` + `景别` + `构图`（含主体落点/留白/纵深层）+ `剧情匹配` + `跨度` + `[DERIVED_ENV:{完整名}]`。只写场头方案、Beat 内无【取景锁定】=失败。场头 B{n} 与该拍【取景锁定】必须逐字同核。
3b. **衍生提取标签（最高；供程序入库，不经 LLM）**：每个 Beat 的【取景锁定】与【Beat景别构图方案】每一拍的 ENV 后必须紧跟 `[DERIVED_ENV:{完整名}]`。场头必须另写 `[DERIVED_ENV_EXTRACT_START]…[DERIVED_ENV_EXTRACT_END]`，对本场方案实际用到的每个衍生名各写一行 `[DERIVED_ENV] 名称=…｜所属主环境=…｜view_angle_from_main=…｜类型=第一刀|衍生的衍生｜…`。缺标签或提取块=失败。程序按主环境把这些行拼成切割生图 JSON 入资产库。
4. **场级指导强制承载**：`细节特写参考`/`贯穿保护` 涉及的环境、道具、文字载体必须进入至少一个合法衍生白名单；`反馈特写参考` 须有同显或紧邻切角可读方案；`运镜参考` 须有连续可见空间。`指导=` 不写焦距/机位处方。
5. **输出=完整一场戏**：从 `[SCENES_BLOCK_START]` 起笔，保留场号、【场景名称】、主环境块（已补衍生）、`SCENE_CONTENT`、场级综合与全部 Beat 过程正文，最后 `[SCENE_END]`、`[SCENES_BLOCK_END]`、`[DERIVED_FRAMING_OUTPUT_END]`。
6. **结束标签硬闸**：缺 `[DERIVED_FRAMING_OUTPUT_END]`=失败。写完 `[SCENES_BLOCK_END]` 立刻换行打该标签作为全文最后一行。

## 通用硬约束（各子技能同锁；最高）
1. **忠于上游 + 未命中原样输出**：不改事实/因果；禁新增改因果事件。未命中段落禁止改写。
2. **原文信息零丢失 + 禁虚化（最高）**：禁止用「同原文／按原文／见原文／如上／略」代替原文。
3. **专名逐字**：环境注册名与上游逐字一致；衍生主名段必须=所属主环境名。
4. **对白保真**：本文件不改台词。
5. **逻辑合理可拍**：活动空间可站可动；四方正交；禁 45°/对角偏斜空镜角。
6. **禁实拍执行语**。
7. **下游边界**：景别与构图由本文件锁定；禁代写分镜处方（焦距/运镜处方归 `shot_generation`，分镜只继承本文件锁档）。
8. **只锁衍生与取景**：不得借「设计衍生」改写对白/特效/主环境几何/建置落位。

## 1. 只读主环境，按主环境定每个 Beat 的衍生
- **只注入/只依据主环境**：空间依据仅为已注入【主环境】的 0°轴、四向+中心、活动空间、固定清单，以及【未落清单】。禁止改这些字段。
- **按 Beat 明确衍生**：逐 Beat 用该主环境推 `{N}度{主名}`（可多个），写入【衍生环境】并挂到该拍。不得先选角再回头补实体。
- **不考虑环境复用**：复用已在环境规划阶段解决；本场【主环境】即权威骨架。禁止再判复用/新建，禁止沿用场外或项目库衍生名。
- **方位坐标（全链路最高）**：俯视鸟瞰顺时针。以主环境 0°轴为原点：`0° → +90° → 90° → 180° → 270° → 0°`；对向=`(N+180)%360`；画左=`(N+270)%360`、画右=`(N+90)%360`。禁止逆时针或第一人称左右推角。`view_angle_from_main` 与 `{N}度…` 的 N 必须服从本约定。
- **主环境永不作当前环境**：每个 Beat 的 ENV 必须是 `{N}度{名}`（或已声明状态衍生）。

## 2. 衍生环境（按内容建；从原环境规划完整迁入）
> **不变式**：衍生对**所属**主环境固定实体不增/不减/不矛盾；仅可见性与方向性朝向可变。白名单候选必须来自主环境登记，衍生不得自创资产；主环境有实体≠本角可见。

### 2.1 何时必须声明新角（衍生最小化）
须声明新角=任何真正反打/OTS读相向对手｜切镜头致正背面档位变化｜背对须读正面内容｜越轴｜>90°｜门窗内外/POV/状态｜**异排且异向**。前向驾驶舱“异排但同向”不属于本项，按驾驶舱槽位可见性声明0°/180°/90°/270°读角。Insert/CU/同侧过肩且档位/扇区不变→沿用父、禁新行。无 Beat 覆盖的冗余角不建。

### 2.2 每行必填
每衍生行必填：名 / `view_angle_from_main` / 触发 / `spatial_axis` / `lens_profile` / `axis_crossing` / `empty_view_delta`，以及 `活动适配` / `可见内容白名单` / `可见边界` / `不可见内容`。头尾双锚已在主环境声明。禁止写前中后景空镜层次、材质光色细参、四向拼图成稿。
- `活动适配=…`：本角后景/表演区可承载什么动作。
- `可见内容白名单=…`：本角允许进入画面描述的**全部具名固定实体/出入口/景外锚及其可见面**（轻量名称+面）。**舱内**：白名单只锁座椅/挡风/方向盘等固定面，**不授权乘员脸**；`0度{舱}`禁写`后排座:正面`或任何人脸（0°望挡风时后排可见面=靠背背面）。**`90/270度{舱}` 须列全部座位**（驾驶座|副驾|后排各座，有则全写）并标近镜头侧/远侧可见面，禁只写半舱。
- `可见边界=…`：画幅边界与禁止越出的对向/机位后方。**`可见边界=全画幅`无效**——必须用具名实体/结构写清左界、右界、上界、下界/近端截断。
- `不可见内容=…`：与本拍易混淆的对向实体/不可见面。
**衍生主名段必须=所属主环境名。**

### 2.3 先做 Beat→衍生覆盖矩阵，再设计衍生（最高）
逐 Beat 盘点本拍必须在画面中成立的全部内容：①角色世界锚/承托面（`柜台后|桌旁|椅上|门内`）；②动作交互固定实体；③手持/桌面/附着道具及须读可见面；④环境特写/Insert对象；⑤出入口与运动终点；⑥特效命中实体；⑦背景叙事锚。为每项写`必须可见=是|仅画外方向D|可暂不可见`，再选择/新建能完整覆盖**同一拍所有必须可见项**的衍生 ENV。禁止先随便选 ENV 再从主环境补剧情实体。
- **先判“必须可见”**：只有画面明写主体/动作/反应/交互/挂靠/可见细节的实体才进必见集；纯声音、对白提到、角色望向画外、因果来源可标 D 态。例：马蹄声由门外传来→`大门/门外=D`，除非本拍另写看见大门。
- **实体标准化展开后做真集合差**：`柜台后站位`→`木质柜台:角色挂靠/可见交互面`；`右手压算盘`→`算盘:顶面/手部交互面`；`拿起桌面酒盏`→`桌面+精致酒盏顶面/内壁`。成稿须输出 `R={…}`、`W={…}`、`R−W={…}`；只有差集显式为 ∅ 才可通过。
- **合理选角，不得默认 0 度/Master（最高）**：按 `R完整覆盖 > 关键交互面可读 > 角色关系/露脸可拍 > 守轴 > 切换成本` 选最佳角；**0 度没有优先权**。空镜角以四方 0/90/180/270 为基准，禁止 45°/对角偏斜。
- **剧情覆盖衍生允许按需建角**：可建 `{N}度{主环境名}_{剧情覆盖短名}`（N 取 0/90/180/270）。若物理上任何单角无法完整看见，须分别声明两角，并在矩阵标`跨对向=拆拍`（拆拍执行归站位）。
- **挂靠实体同显**：角色须`站在柜台后/坐在桌旁/坐在椅上`时，对应柜台/桌/椅必须命中该拍选用角白名单；对向不可见则另建可见该锚的衍生。
- **交互链同显**：`拿起桌面酒盏/拨算盘/翻账册`必须同时命中`执行者+承托/挂靠实体+道具+被读取的面`。仅写`桌区:全部面`不能隐式授权酒盏。触达对象须能在开拍画面为 V。
- **同框锚须设计进角（Two-Shot/多人）**：每人世界锚/承托面须同属某一声明角的白名单+活动适配。驾驶舱后排×司机同框只可规划 `90/270`，该角须近镜头侧+全部座位。换角只切换半空间，不创造物理同框。
- **一拍需求跨对向则分角**：必见项分属 N 与 N+180 时，任何单一衍生都不得同时收录；须分别声明两个角。

### 2.4 主环境对向位零可见（最高；固定环境实体）
对当前衍生观察轴 N，主环境四向中精确位于 `(N+180)%360` 的对向边界实体及其附着/承托物全部在机位后方，必须列入`不可见内容`，与白名单交集必须为 ∅。禁止因“写背面/广角/稍带到”把对向位实体塞回画面。
- N=0：180°位柜台/酒架及承托物全不可见。
- N=180：0°位大门及门外本体全不可见。
- N=90：270°位楼梯/回廊全不可见；N=270 反之。相邻 ±90° 仅在`可见边界`明示贴边小部分时可入白名单，不能整面入镜。
- **舱内侧向例外（仅交通工具内舱 90/270）**：机位贴一侧窗看对侧窗时，近镜头侧门框/窗框+该侧全部座位侧面须进白名单；全部座位都要描述。对向零可见只约束舱外对向街景，禁止把近侧半舱座位整排进`不可见内容`。

### 2.5 内容驱动建角 + 轴线
先列每个 Beat 的 R，再为能完整覆盖 R 的真实机位建立 `{N}度…`。禁止默认 0 度、按 0→90→180→270 轮角、或习惯先写 180 反打。无 Beat 使用的冗余角不建。本场主环境只锁坐标系；按每个 Beat 的 R 在同坐标系内声明合法剧情覆盖衍生或分角供站位拆拍；禁改主环境骨架。
定 0° Master 后声明本场 `spatial_axis`（对戏/站位动作轴线）。后续衍生须守轴：

| `axis_crossing` | 何时允许 | 要求 |
| :--- | :--- | :--- |
| `None` | 同侧微调、非反打 Insert/CU、沿用父观察侧 | 不跨 `spatial_axis` |
| `PlannedReverse` | 正反打/OTS 读对手（沿轴线对向，典型 ±180°） | 触发须含 `N_对手→(N±180)%360`；左右屏关系与轴线闭合 |
| `MotivatedCross` | 仅剧情明文动机越轴 | 须写动机一句；禁无动机为「换个角好看」而跨轴 |

禁：无动机在轴线两侧来回跳；把越轴标成普通反打；为填满清单而建跨轴角。

### 2.6 反打 ENV / 状态衍生 / 出入舱触发
- **反打 ENV**：先定所需背景/对手可读面，再算 `N_对手→(N±180)%360`；该行白名单须能看见所需内容。`axis_crossing=PlannedReverse`。非反打 Insert 不另建行。
- **状态衍生**：`{主}_{状态}`；`{N}度{主}_{状态}` 每行仍须写 `所属主环境={主}`。
- **出入封闭舱**：仓外/仓内两块主环境已由环境规划声明。本文件须为两族各声明衍生；仓外族白名单含载具外部本体+各具名门扇；仓内族按载具惯例写座舱。声明触发名=`入舱切主环境|出舱切主环境|回切仓外主环境`。换主名≠反打。建置落点归站位。
- **闪回/蒙太奇切主**：各主环境各挂各衍生族；声明触发名=`闪回切主环境|闪切切主环境|蒙太奇切主环境|回切当下主环境`。

### 2.7 按背景内容选角（从原站位迁入；本文件执行规划）
唯一直接依据=后景应见内容 ↔ 候选衍生行自身的`活动适配+可见内容白名单+可见边界`。禁无据粘`0度`、机械轮角。

| 画面事实 | 应挂 | 禁挂 |
| :--- | :--- | :--- |
| 背对/面向后景（内侧/王座） | 可见王座/内侧的角（常`180度…`） | 可见大门的`0度…` |
| 正面朝镜、身后/后景应见大门；或自背景门迎入 | 可见大门的角（常`0度…`） | 可见王座的对向角 |
| 背对向内走、门近端/身后 | 可见内侧/王座（常`180度…`） | 可见大门的`0度…` |
| 外景航拍/山巅建立 | 外景族`{N}度…` | 厅内`0度…` |

选 ENV：①定后景内容 → ②定位 N°+守轴 → ③取`活动适配`匹配行 → ④背景锚∈半空间 → ⑤与正背面/反打交叉 → ⑥核同 ENV 连续次数（≤3）。

## 3. 选用节奏与 OTS（从原站位完整迁入；本文件规划）
- **同场积极换角（强制）**：切换合理时须积极改挂已声明的不同 `{N}度…`。同一衍生环境名连续使用不得超过 3 个 Beat（计连续拍；可稍后切回，每次连续段仍≤3）。第 4 拍起须换已声明合法角；满 3 且下一拍切换合理却仍同挂=失败。**合理=**候选角 `R−W=∅` + 对向零可见 + 守轴 + 逻辑可拍，且非无动机越轴、非机械轮角。满 3 后优先切已声明他角；现有角皆不能覆盖则补合法侧向，不得为凑换角另建无 Beat 覆盖的冗余行。
- **例外（须写依据，否则连续>3=失败）**：①本场总拍数≤3；②转身过程拍且轴/背景半空间未变（可同父，计入连续次数）；③物理上仅一合法覆盖角（标`唯一覆盖角`+R−W）；④文戏连续载具/同行位移无停顿且切角破动量——最多再+1拍。武戏快链豁免连续≤3。❌连续4+同挂且下一拍切换合理。
- **OTS读对手 vs 同侧过肩（强制判别）**：

| 类型 | 判定 | ENV |
| :--- | :--- | :--- |
| **OTS读对手 / 反打** | 镜头越过近侧肩去看对方脸/对手可读面；或对白轮次需换可读方；背景半空间相对上拍翻转/对向 | 必须挂已声明新 `{N}度…`（常±180°；`PlannedReverse`）；矩阵标`ENV变=是` |

## 4. 景别与构图（从原站位完整迁入；本文件规划）
每个最终 Beat 必须同时给出**完整**景别 + 构图档 + 对应衍生 ENV，并**写入该拍【取景锁定】**。站位建置首句只抄该拍已写入的锁定行，不得另起方案。
**选型总闸（最高）**：先定本拍**剧情功能** → 再选景别七档之一 → 再选构图主档（+可兼）→ 再核与上拍跨度。对白/交付/特写配额/画幅/`-`/`~` 另受 §4.5（从分镜迁入）约束。禁止先贴常用档再找剧情；禁止通场只写 MCU+三分交差。缺类型定义核销、缺剧情匹配、无动机越级=失败。本文件只锁取景意图，不写焦距/运镜处方；下游分镜只继承本文件锁档。

### 4.1 景别（七档完整；必须与剧情匹配）
闭集（成稿只写英文档）=`EWS|WS|FS|MS|MCU|CU|ECU`。原文`航拍/俯拍/大远景/远景/全景/中景/近景/特写/大特写`按其意图映射到下表，并写`原文景别=`。每拍必须能指回本表「画幅覆盖 + 剧情功能」。

| 档 | 中文 | 画幅覆盖（可核销） | 典型剧情功能（须命中其一） | 禁用于 |
| :--- | :--- | :--- | :--- | :--- |
| **EWS** | 大远景 | 人极小或不可辨；环境/地貌/城廓/阵势为主 | 开场建立、宏观规模、孤绝渺小、环境文学空镜、满幅特效/战场余波 | 口型对白主拍；贴身交付；读脸反应 |

- **剧情匹配（强制；每拍写`剧情匹配=`）**：闭集=`建置`｜`走位`｜`对白`｜`交付`｜`反应`｜`特写`｜`空镜`｜`宏观`。档位必须服务该功能——建置/空镜→EWS/WS；走位/全身动作→WS/FS；对白→MS/MCU（口型须 MCU/CU）；交付→FS/MS（须同框施受）；反应→MCU/CU；特写/Insert→CU/ECU；宏观/满幅→EWS/WS。功能与档错位=失败。
- **景别与距离同向匹配**：贴身→MCU/CU；数步对峙→WS/FS；禁 Wide 写贴身无依据、ECU 写数步同框无交代。
- **空间交付动作**（指对方鼻子/脸、递物到手、扇耳光、拍肩、抵胸口/喉、抓住衣领等须见两点间距者）→ 本层必须锁能看见施受双方+动作向量的档（§4.5.3）；禁止只规划施动者 CU 丢掉受者，禁止把拉开留给下游分镜。
- **对白链**：口型可读主拍须锁 MS/MCU/CU（细则 §4.5.1–4.5.2）；禁用 EWS/WS/FS 承载常规口型主拍（宏观/特效满幅相位例外，须写依据）。听者反应与说话镜同级或邻档。
- **非反打**景别收紧沿用父 ENV；须读脸/OTS 反打仍切可读角 ENV。
- **原文景别/特写提示必须核销**：`△近景/特写/中景`、`【特写/近景】` 各须落入对应 Beat 的景别方案；轴未变且非反打、正背面档不变时沿用父观察侧衍生。
- **环境文学空镜**：原文可感环境文学须独立空镜 Beat，景别偏 WS/EWS，ENV 挂能看见该文学主景的衍生；【建置】句由站位写`空镜／无角色`。
- **群演/背景簇**：只进 WS/FS/EWS 氛围层；禁 MCU/CU/ECU 群演主拍（宏观群体满幅例外，仍禁单人格特写）。
- **景别↔纵深**：`MCU|CU|ECU` 不得标`纵深层=前中后同时可读`；近景只锁`浅层单焦`，或改 MS/FS/WS 再标多层。

### 4.2 构图档（主档+可兼完整；必须与剧情匹配）
主档闭集必选一=`三分`｜`中心`｜`纵深`。可兼闭集可多或无=`对称`｜`框中框`｜`引导线`｜`负空间`。禁止另造主档名（黄金分割/对角/三角等映射回本闭集：偏置→三分；居中仪式→中心；前后层→纵深）。
成稿每拍：`构图=三分|中心|纵深｜可兼=对称|框中框|引导线|负空间|无｜主体落点=画左三分|中央|画右三分｜留白=视线前|运动前|无｜纵深层=前中后同时可读|浅层单焦`。

| 类型 | 层级 | 可核销画面结果 | 典型剧情功能 | 禁 |
| :--- | :--- | :--- | :--- | :--- |
| **三分** | 主档 | 主体落画左/画右三分交点；对侧留白 | 对白交流、对峙分列、视线/运动引导、常规叙事 | 标三分却钉中央；无留白的假三分 |
| **中心** | 主档 | 主体或对峙轴钉画面正中 | 仪式/权力/Iconic、对峙轴、揭示砸点、对称殿堂 | 无仪式/权力/砸点依据的闲聊对白通场中心 |
| **纵深** | 主档 | 前/中/后至少两层同时可读 | 空间层次、走位避障、门—桌关系、前后排对戏、建立空镜 | MCU/CU/ECU 假标多层；必读层不可见 |
| **对称** | 可兼 | 左右或轴对称可检索 | 殿堂/礼法/对仗/仪式 | 无对称结构却空标 |
| **框中框** | 可兼 | 门洞/窗/廊/肩/器物形成内框 | 窥视、隔障对话、进出门槛、细节特写收束 | 无可见内框却空标 |
| **引导线** | 可兼 | 道路/廊柱/队列/桌沿把视线导向主体 | 入场动线、队列、通道压迫 | 无线可循却空标 |
| **负空间** | 可兼 | 主体占比小、大块空/暗/远景压人 | 孤绝、被监视、渺小、低点放大 | 热闹群戏无据大留空 |

- **标档须可核销**：三分=主体偏置+留白；中心=钉中央；纵深=至少两层同时可读。可兼须有可见依据，禁空标。
- **构图须跟剧情功能**：对白/对峙默认三分+视线前留白；仪式/权力/Iconic→中心（可兼对称）；空间建立/走位/前后层对戏→纵深+前中后同时可读；窥视/门槛→可兼框中框；通道/队列→可兼引导线；孤绝/压迫/低点→可兼负空间。场级【构图规划】主档须能被关键拍复现。
- **构图≠角色定位**：`主体落点=`只约束取景，不规定角色世界落位。上游 `#构图规划` / 场级主档 → 本拍同核或写例外依据。禁为凑档要求站位挪世界落位或改朝向。
- **留白**：有视线/运动→`视线前|运动前`；压迫贴边或中心钉死可`无`（须功能匹配）。负空间≠无留白——负空间是可兼档，留白字段仍须写方向或无。

### 4.3 场级【构图规划】
```
【构图规划】主档=三分|中心|纵深｜兼档=…|无｜关键=B…｜空镜=…|无｜道具特写=…|无｜Iconic=…|无
```
主档=本场大多数叙事拍的默认框法；关键/空镜/道具特写/Iconic 拍须写出偏离或强化依据，不得与场级主档无故打架。

### 4.4 景别/构图切换必须合理（跨拍最高）
相邻 Beat 的景别、构图是**切点**，不是每拍重开。须在方案写`上拍景别=`与`跨度=`。
- **景别跨度闭集**：`同级`＝与上拍同一档；`邻档`＝沿 `EWS↔WS↔FS↔MS↔MCU↔CU↔ECU` 只移 1 档；`越级`＝跨 ≥2 档（须写`越级:{剧情依据}`）。默认只允许同级或邻档。
- **允许越级的闭集依据**（须可回指本拍过程/原文/场级指导，否则失败）：①原文独立`△特写/【特写】`或`细节特写参考`；②卖点/高潮/低点砸点或`~`精髓拍；③契科夫枪/文字/伤口 Insert；④独立空镜/宏观建立后切特写陪衬（或特写后回建立）；⑤空间交付必须拉开（CU链→FS/MS 同框）；⑥反打/OTS 只为读脸，且落幅仍与对白链同级或邻档——**反打本身不是 EWS↔CU 的依据**。
- **硬禁无动机跳切**：EWS/WS↔CU/ECU 无上列依据；对白链中突然 EWS；空镜后无过渡直切 ECU 却无特写陪衬依据；正反打把上拍 MCU 无故拉成 EWS。
- **正反打/对白链**：两侧保持同级或邻档（典型 MCU↔MCU 或 MS↔MCU）；只翻 ENV/主体落点（画左↔画右），不借反打改剧情功能档。
- **构图切换**：主档随**剧情功能**变，不随拍号轮换。对白链保持同一主档；功能从交流→仪式/揭示→中心，从对白→空间走位→纵深，从建立→孤绝→可兼负空间。禁止无功能变化时三分/中心/纵深每拍轮跳。反打允许只翻`主体落点`（画左三分↔画右三分），主档默认不变。
- **连续过近/过远**：MCU/CU/ECU 连续段须服务对白/反应/特写链；满 3 拍近景且下一拍有空间/走位/交付却不拉开=失败。EWS/WS 连续段须服务建立/宏观/空镜；满 2 拍远景且已入对白/读脸却不收近=失败（宏观满幅相位例外+依据）。
- **关系形态≠景别档**：Two-Shot / OTS / Dirty Single 只描述谁同框，景别仍须落七档之一（OTS 对白典型 MCU；交付 Two-Shot 典型 MS/FS）。

### 4.5 从分镜迁入的选型专规（本文件锁定；下游只继承）
下列原在 `shot_generation` 的景别/构图具体要求，**改由本环节一次锁死**。分镜不得再选档、不得按画幅/配额/拍型改远近。

#### 4.5.1 对话景别切分（强制）
口型可读对白、画内听者可见的 OS/V.O.、正反打 / OTS、反应拍、以及须读的微表情/微动作 → **锁 `MS|MCU|CU`**（OTS 对白典型 MCU）。**禁止**用 `EWS|WS|FS` 承载常规口型主拍。听者反应、微表情链须与说话拍**同级或邻档**。
- **例外**：特效相位、宏观群体主节拍须锁 EWS/WS/FS 体现规模；对白以宏观/特效动势为主，说话人可为远景群像或画外，须写依据。
- **3 人+**：Index 内具名角色各锁单人/OTS 近档，禁群体广角口型主拍。
- **自白/内心**：锁该角色 `MS|MCU|CU`。
- **Screen View / 画中画**：屏内说话人锁 `MS|MCU|CU`。
- **Walk-and-Talk**：锁 `MS`（可邻 `FS` 跟走位）；禁长时间 EWS/WS 口型主拍。

#### 4.5.2 画幅比驱动的对话景别（强制；读输入 Project Context / 项目信息）
读 `Aspect Ratio` / `aspect_ratio` / 画幅比。未注入或无从判竖屏 → 按横屏灵活。须在【景别构图综合】写`画幅=`。
- **竖屏**（`9:16`、`3:4` 等 height≥width）：每条口型可读对白原则上单独锁该**说话人** `MS|MCU|CU`；禁 `EWS|WS|FS` 作说话人主拍。多人按说话人分拍（可 OTS，落幅仍须说话人面部/口部可读）。建置拍可锁 WS/FS，**下一对白拍须收近**（邻档或越级写依据）。Walk-and-Talk 竖屏锁 `MS|MCU`。
- **横屏**（`16:9` 或未声明）：允许 Two-Shot / MS 关系镜、Walk-and-Talk `MS|FS`、建置 WS；仍禁 EWS/WS 口型主拍。不必每句都锁 MCU/CU，但说话人面部/口部须可读。
- **其他**（`4:3`、`2.35:1`、`1:1`）：竖向窄画幅倾向说话人 `MS|MCU|CU`；横向宽画幅可按剧情灵活，仍守口型通则。
- **交付压过本条**：空间交付相位按 §4.5.3 锁更远档，不因竖屏「禁 Two-Shot 口型」而裁掉间距。

#### 4.5.3 空间交付必须拉开（最高；本层锁档）
入戏含须空间向量可读的交付/接触（指对方鼻子/脸、递物到手、扇耳光、拍肩、抵胸口/喉、抓住衣领、点穴等——须同见施动部位、轨迹、受者触达点、二人间距）时：
1. **该拍禁止锁 `CU|ECU` 单人裁掉对方与间距**（禁只锁伸出的手指或只锁被指的鼻子）。
2. **必须拉开**：锁 `FS|MS`（Two-Shot / 侧向全/中景）。对白可在邻拍 MCU，**交付拍本身须更远**；或该拍 `剧情匹配=交付`。
3. **竖屏加严**：优先 `MS|FS`；禁双人 CU 硬塞横向指鼻。可一人上半、一人下半的竖向叠层，间距仍须可见。
`剧情匹配=交付`。❌交付锁施动者 CU 丢掉受者｜❌指望下游分镜 Pull Out 改档。

#### 4.5.4 全景 / 中景 / 特写用途（强制；跨拍路径）
| 档组 | 锁给 | 禁 |
| :--- | :--- | :--- |
| **EWS/WS/FS** | 新场建立、空间关系首次交代、走位/调度、Walk-and-Talk、宏观/特效、群像 | 常规口型主拍 |
| **MS/MCU** | 对话默认、双人/多人关系、动作+对白同相、听者反应 | 须读眼部微表情却裁脸；须见全身间距却裁脚 |
| **CU/ECU** | 情绪高点、`细节特写`/高潮点、道具特别描述、微表情链、口型/眼部精确读、`~`精髓 | 群演主拍；交付单人裁间距 |

跨拍默认路径=`建立远 → 叙事中 → 砸点近`（EWS/WS/FS → MS/MCU → CU/ECU），须写`跨度=`；禁止无动机从全景直锁极特写（越级只允许 §4.4 闭集依据）。

#### 4.5.5 场级特写配额与卖点近景（强制）
常规有戏场（≥3 Beat）：`CU|ECU` 拍约占本场 **15%–25%**（纯过场/宏观满幅场可低于此，须写依据）。卖点/高潮/低谷/【高潮与核心情绪点】/`细节特写参考`/桥段击中·命中·法攻效果/过程穿插表情，须落入已锁 `MCU|CU|ECU` 的拍（主高潮优先「角色近景 + 环境 Insert」分拍或紧邻拍）。**禁止**把卖点/高潮/低谷全程压在 WS/MS。`~` 精髓拍必须锁 `CU|ECU`。写入【景别构图综合】`特写配额=`。

#### 4.5.6 拍型 `-`/`~` 与快节奏（强制）
| 上游拍型 | 景别锁档 | 禁 |
| :--- | :--- | :--- |
| **`- Beat`** | 快交代偏 `MCU`（对白快交代）或跟功能（走位/交付仍 WS/FS/MS） | 把交代拍锁成全程 ECU；用 EWS 扛近身快戏 |
| **`~ Beat`** | **必须** `CU|ECU`（Insert→ECU） | 用 WS/FS 冒充砸点；精髓拍锁远景 |
| **快节奏打斗/追杀** | 贴身链偏 `MCU`；命中/效果可邻档 `CU`；宏观满幅跟 §4.5.1 例外 | EWS/WS 扛近身连击无依据 |

#### 4.5.7 群演 / 局部特写功能
- **群演/背景簇**：只进 `EWS|WS|FS` 氛围层；禁 `MS|MCU|CU|ECU` 群演主拍（宏观群体满幅例外，仍禁单人格特写）。
- **局部特写功能**：唇→口型/呼吸/欲言又止；眼→视线/泪光/警觉；胸肩→呼吸/权力姿态；腿→步伐/距离；腰臀线条→转身/落座/走位或遮挡转场。禁止脱离剧情的孤立凝视。成人向局部仅成人角色，须服装覆盖/剪影/光影轮廓，禁裸露与未成年人性化。

#### 4.5.8 重要场景远近备档
关键/情绪爆发/卖点兑现/人物弧光拐点：须有 **EWS/WS（环境压迫/规模）** 或 **CU/ECU（微表情/核心道具）** 至少一档落地（可分拍），不得通场只锁 MS 交差。

## 成稿自检（本子技能）
- 已输出完整一场戏 + `[DERIVED_FRAMING_OUTPUT_END]`。
- 【主环境】【未落清单】未改；【衍生环境】已按本场主环境写入 ENV_BLOCK；未处理复用、未沿用场外衍生名。
- 每个最终 Beat 均有【取景锁定】（当前环境 + 景别 + 构图 + 剧情匹配 + 跨度 + `[DERIVED_ENV:{完整名}]`），且该拍衍生可由本场主环境推得，并与场头【Beat景别构图方案】同核；`R−W=∅`；同衍生连续≤3（例外已写依据）。缺拍内锁定或只写场头方案=失败。
- 景别七档与构图主档/可兼均取自闭集且可按 §4 / §4.5 定义核销；每拍`剧情匹配=`与档位同向；相邻拍`跨度=`为同级或邻档，越级已写闭集依据；无动机 EWS/WS↔CU/ECU=0；构图主档未无功能轮跳。
- 对白口型主拍未锁 EWS/WS/FS（宏观例外已写依据）；交付拍已锁 FS/MS 同框施受；竖屏对白已锁说话人近景；`~` 已锁 CU/ECU；有戏场特写配额 15–25% 或已写例外；卖点/高潮未全程压在 WS/MS。
- 本场选用过的每个衍生名均已写入 `[DERIVED_ENV_EXTRACT_START]…[DERIVED_ENV_EXTRACT_END]`，字段齐全；程序只认该块与 `[DERIVED_ENV:…]` 标签入库。
- OTS读对手已挂对向衍生；同侧过肩未标反打。
- 未写【建置】【入戏】【位置规划】，未改对白/特效/场核。
- 主环境永不作可拍当前环境。

- 顺序：`[BEAT_STREAM_END]` → `[SCENE_END:{scene_id}]` → `[SCENES_BLOCK_END]` → `[DERIVED_FRAMING_OUTPUT_END]`。
