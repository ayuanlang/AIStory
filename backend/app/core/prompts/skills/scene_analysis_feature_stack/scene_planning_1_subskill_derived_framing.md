## 决策链（最高；逐步锁。后步只继承前步，禁为镜头拧人、禁先选角后摆机）

### 步0 · 这场谁在（§0.0）
逐 CHAR／可移动 PROP 只选一档：开场在场（B1 占格）**或**待入画（`入画@B`+`经=`出入口或容器，入画前不占格）。中途无开场、无入画却入格 = 鬼魅，整场失败。盒／匣内待取件不开场。B1 覆盖开场全景（含无动作），禁只锁有戏者。本层不标进画档。

### 步1 · 建立／继承宫格站位图（物理世界；最高；§0.1→§0.2）
先立本拍开拍图，**不选角、不摆机、不考虑衍生与本拍视角**。定位只凭参照物＋视野方向＋东南西北。有上拍 → **只能继承**上拍终态：`锚=`／`宫格=`／`四侧=`／`辅=`／`朝向=` 对象／`面半空间=`／`背对=`／`载具档=`／`人载同向.相对=`／未松开的 `触=`。切角／收放景别／换主拍／换衍生／镜头推进 ≠ 换站、≠ 换看谁。
- **时序**：上拍过程已走到邻格／已转身／已入画 → **本拍**图才写终点格／新朝向／入格。本拍过程才开始走／转／入 → 本拍图仍=开拍（=上拍终态），新态留给步8预锁、下拍图落地。
- **在场集合**：本拍开拍在场 ≡ 上拍收拍在场。仅出画／离场减员。上拍入画过程 → 本拍才入格。
- **落点（B1 或本拍须新锁时）**：先锁 `载具档=`（无出入舱／无换主 → 抄上拍；§0.3-0）。室内有主体 → `方式=相对` 或封闭，`锚=`=该人实际站靠的固定环境主体（原文「站在{窗/门/桌}前」必须是该件）。仅空旷才绝对。围桌／舱位锁到第几座。近距才同格；一格>3 拆格或拆拍。
- **挂靠体必评**（§0.2H）：法相／坐骑／载具默认与宿主同格同朝向。仅正文写清「人离开、件留原地」才分格。
- **开拍分布图必含**：已入场全员＋挂靠体各一行（`宫格=`中心交叉位＋`方式=`＋`站位=`＋`朝向=`）。本步**不摆机**。无人走位／出入画 → 步8 人／件抄上拍，只改本拍机位行。
- **世界键变化须有路径**：相对上拍改了 `宫格=`／`站位=` 锚侧 → 须有 `自{开拍}→经{路径}→到{终}`，并写 `站位变=是｜站位变因=走位:…`。无路径却换锚 = 失败。朝向对象变 → `朝向变=是｜朝向变因=转身:…`。切角不得写站位变／朝向变。

### 步2 · 朝向世界锁（只对主体；§0.3 1–7）
先继承上拍看谁。无转身 → `朝向=` 对象／`面半空间=`／`背对=` 不改。切角／换 ENV／收放景别 **不改** 朝向对象。对象=物理世界环境实体或其他角色／道具，**和镜头无关**。
- 成稿只给**角色**或**有正反面道具**：`朝向=面向{角色|有正反面件|四面|中区}[之左|之右|之上|之下]`。例：`面向 CHAR:[@乙]`｜`面向门`｜`面向杯子的左边`。`之左` 只修饰所看面，站位仍走 `锚=`／`四侧=`／`辅=`。无正反面件不写朝向。禁 `面向镜头`／`面向画左`／`面向画右`／`面向{N}度{主}`。
- 无明示对象：相对／封闭 `朝向=无`（靠 `背对=`／`面半空间=`）；绝对角色禁 `无`。分析才推出的大门／对向墙 → 只写 `朝向推=`，不成稿。
- 骑乘前进向：文戏已点名路／航道 → `面向{该名}`；未点名 → `朝向=无`+`朝向推=面向前进向`。无改航向 → 抄上拍。
- 由「本人格→对象格」锁 `面半空间=`（切角不改）。`背对=`=背后具名件。`主拍ENV`=拍他脸时机位应望哪一侧（§0.3 4），供步6–7推导，还不是 `当前环境=`。
- 回望／说到一半转看：本层定位仍写开拍朝向；视线转移留给入戏。

### 步3 · 本拍拍什么（剧本要求＋上下拍衔接）
读本拍正文，先锁功能再锁人际，**仍不选角**。记下拍对照用的上拍镜头键（N／景别／机位／对打／主拍／入场闸），本步不改世界朝向。
- 功能 → `剧情匹配=`：有人建空间=`建置`；R 无人=`空镜`（追逐有追逃主体禁空镜，改 `走位|交付`）；位移=`走位`；口型／换说话人=`对白`；须同框施受=`交付`；神色=`反应`；物件／`~`=`特写`；满幅阵势=`宏观`。
- **衔接**：上拍空镜／无人 → 本拍第一张有人不得直接 `对白` 半身（须先 `WS|FS`）。上拍建置未完成 → 本拍优先认人／收近。上拍正反换说话人未切脸 → 本拍应走反打，不得同向假切。上拍交付未完成 → 本拍继续同框。上拍近景链满 3 且本拍有走位／交付 → 须能拉开。上拍远景链满 2 且已入对白 → 本拍应收近。
- 人际 → `对打=`：相向=`正反`；同向并肩=`并排`；单人／空镜／Insert=`无`。宿主↔法相禁正反。
- 附问（步4落锁）：有人骑／立法相／正文有神色？无剧情改跟拍 → 人载 `相对=` 抄上拍。

### 步4 · 交叉闸（人载 > 正拍禁背面 > 表情；§0.3 ⑧⑨⑩）
约束**机位望向**（与步5景别同锁），不先选角。名牌不进。无剧情改跟拍／改法相 → 承上拍。**读脸／神色／口型能否见正面或侧面，本层一次评完**；下游建置只投影，不重评、不改挂、不拧人。
1. **人载**：先锁 `相对=后方|前方|侧`（无改向抄上拍）。查 §0.3 ⑩。无人=`无`。
2. **法相**：查 §0.3 ⑨。未离开 → 与宿主同格同朝向；看对手过法相肩。
3. **表情**：查 §0.3 ⑧。拟望向只能见背面 → `改挂:`（改机位望向）或 `本拍不写脸:`。禁止拧人的 `朝向=` 凑正面。读脸功能不得锁在背面机上后丢给下游圆。

- 建置：横 `EWS|WS`，竖 `FS|WS`。走位：横 `WS|FS`，竖 `FS|MS`。对白：横 `MS|MCU|CU`；竖单人／过肩 `MCU|CU`。交付：`FS|MS` 同框。反应：`MCU|CU`。特写／`~`：`CU|ECU`。宏观：`EWS|WS`。
- 贴身／桌面对白 → `MCU|CU`；数步对峙 → `FS|MS`。竖屏 Two-Shot 必须 `MS|FS`。
- **跨度**：默认同级或邻档。越级须闭集依据。禁空镜→半身；禁 `EWS→MS`／`WS→MCU` 当建立收近。大全景收中景须 `EWS→WS→FS→MS`。
- **链**：近景连续满 3 且下拍有走位／交付 → 须拉开。远景连续满 2 且已入对白 → 须收近。
- **读脸景别**：本拍须写神色／口型且 `表情换环境评=保持` → 景别须盖到该人脸（对白／反应默认 `MS|MCU|CU`）。拟望向只能见背 → 回步4，禁把读脸锁在背面机上。
- **开场／进出场**：开场优先 `EWS|WS|FS` 交代全部 `入场=开场` 者站位（待入画不进）。特写／无人远景吸睛后，**紧邻下一拍**必须拉开该全景，禁先对白半身。`入场闸` 吸睛+有人建置都出现后才 `过`。进出过程 `WS|FS` 与反应 `MCU|CU` 至少跨一档。

### 步6 · 机站哪（与景别同锁；可在九宫内或九宫外；剧本＋衔接；§4.0／§4.6／§0.2C）
未写 `机位锚=`（环境主体）／`机位距=`／`镜头角度=`／`机运=`／`机位侧=` **且未预落分布图 `机位=`** 不得进步7。机位成稿=**环境主体＋距离**（可核销），再写机运与镜头角度。距≡景别：CU/ECU=`贴身`，MCU=`一臂`，MS=`两步`，FS=`三步|五步远`，WS/EWS=`五步远|十步外`。写 `上机位=`+`机位变因=`+`上拍镜头角度=`+`角度跨度=`＋`关系角=`。
- **同轴原则（最高；机位禁跨轴）**：先锁本段 `轴线=`（对戏=`{甲}↔{乙}`；单人=`{人}↔{锚}`），再锁 `轴侧=`（轴线哪一工作半空间）。此后所有机位必须落在该半空间。反打／读对手=沿轴线走到对向端、望向差 180°，**仍在同一轴侧**（`axis_crossing=PlannedReverse`），左右屏对调合法，**不是跨轴**。禁把机摆到轴线另一侧；禁无据 ±90° 跳到对面；禁「换个角好看」越轴。`轴侧=` 无走位／无明文越轴不得改。
  - 过肩配对（同轴）：过甲**右**肩看乙 ↔ 过乙**左**肩看甲（同一轴侧）。写成过甲左肩看乙 = 跨轴，失败。等体量正反须**同时写出**本拍框主部位与对向 `过肩配对=`（值=肩／腰／后脑，跟关系角）。
  - **OTS高低（最高；过肩／过腰／过头／OPC／主观角色先评）**：框主与被看（或 `主观角色=` 与看见对象）须比**站／坐、大人／小孩、立／跪**等高差，再选越过哪一层，**禁默认过肩**。齐高站或齐坐→`过肩`（`左肩后|右肩后`）。框主明显更矮（坐看站、小孩看大人）→`过头`（`脑后`）。框主明显更高（站看坐、大人看小孩）→`过腰`（`左腰后|右腰后`）。高差配对：矮后脑↔高腰。`主观角色=`／FPV 机高=该人眼高（坐／站／孩），禁套成人站姿眼高。
  - **并排对手戏露肩（最高）**：`对打=并排` 时除 Two-Shot、同侧 OTS 外，须评**露肩拍**：发声者 `MS|MCU`（`:半身|:胸肩`）＋并排邻人入画（`:半身|:胸肩|:左肩|:右肩`），`覆盖=带肩`。禁无据 `覆盖=单人` 裁掉并排者。邻人可写半身，不限一条肩。
  - **反打遮挡／体量（最高；同时盖两体先评）**：一拍或一对正反要同时覆盖两个角色（含宿主+挂靠体）时，先判近层是否挡住远层。近层远大于远层（法相／金身／化龙凤相对宿主、巨物相对人）→ **不适合从巨体后方反打两体**（巨背挡光轴，小人不可读）。改**另一侧／面侧**（小人在近、巨体在其后作背景，两体都可读），或本拍**忽略被挡者**（`可见=` 不列，或只作尺，禁升可读半身／框主）。小物体在前、巨体在后而机仍在巨体背后 = 失败。等体量普通人 → 可前后叠（近者肩／半身，远者脸仍可读），或走上方 OTS 配对。换侧=沿轴对向，不是跨轴。
  - 穿插 Two-Shot／侧角：只能落在已锁轴侧；可 90/270，但机仍在工作半空间，本拍不标反打。
  - 单人／空镜／Insert：机仍在该段 `轴侧=`；禁为特写绕到轴线对面。
- 步4人载 `相对=` → 锚／侧跟该表（后方=`正后`）。无改向 → 抄上拍。
- 正反读脸 → `关系角=` 按 OTS 高低锁 `过肩|过腰|过头` +`OTS类型=读对手`（对向由步7从望向推出）。同侧 OTS 望向不变。并排对白优先评露肩拍／Two-Shot。交付同框优先 `Two-Shot`。框主须比被看对象更近。法相类看对手 → `近侧框主=法相`。
- 俯仰跟动机：口型默认 `平拍`。反打默认同俯仰。宏观优先 `航拍`。
- **同环境机位变**须有因（`反打|切角投影|换主拍|景别档|过肩换框|进出衬托|卖点加压|对角穿插|AI优势位`）。未变=`承上`（人站承上，机位／望／景别亦抄上拍）。因=`对角穿插` 仍须同轴侧。
- **预落机位**：不强制入格。九宫外写 `九宫外:西侧外|东侧外|北侧外|南侧外|上空|门外侧|窗外侧|檐外|对楼`。从门外／窗外往里拍用 `门外侧|窗外侧`，锚=该门／窗，望向场内。机不占人名额。禁只写拍摄键不写分布图机位行。九宫外机同样不得落到轴线对面。

### 步7 · 由机位望向推导背景衍生（不是分析；§0.4／§2）
**先有步6机位，再推导 `当前环境=`。** 禁止先挑 `{N}度{主}` 再倒推机位。
- **望向**：机位镜头对着主环境哪一侧 → `望=北|东|南|西`（≡主环境该向）。映射：望北→`0度{主}`；望东→`90度{主}`；望南→`180度{主}`；望西→`270度{主}`。写入分布图 `当前环境=ENV:[{该N}度{主名}]`。望向必须≡本拍镜头方向。
- 只挂步1已锁族内**恰好一个**已声明名。`R−W=∅`；盖不住或预估同框>4 → 拆拍（回步5–6 改机／景别），禁双挂。
- **衔接推导**：换说话人／读脸／接招 → 机位翻到对向，望向差 180°，`ENV变=是:{反打|读对手|…}`。并排 → 望向能同框双方的一侧。空镜 → 望向=要交代的那面后景。步4 `改挂:` → 改机位望向，不拧人。
- **同名连续**：该衍生名已连续满 3 → 本拍必须换望向（唯一覆盖除外）。无剧情动机禁两侧来回跳、禁无据粘 0°。
- `朝向=` 世界对象**不改**。`ENV变=否` = 望向未变。人格名不改。九宫内机须落在望向的对向半空间；九宫外机须在所望侧的外侧（望北→南侧外或南3行以南）。不标 `背景衍生=`。

### 步8 · 重评走位／出入画，落本拍【角色道具宫格分布图】
按本拍剧情再评一次走位与出入画，写入该拍分布图——**该拍权威站位、朝向、机站、覆盖可见与衍生**。已入场全员仍全部入表（含将落镜后者，不删行）。空镜全员仍占格，`可见=无`。
- **无走位／无出入画／无转身** → 人／件世界键一字不改，`站位变=否｜朝向变=否`。切角 ≠ 出画、≠ 改人格。机位／景别／望向／可见／衍生必须本拍写。
- **有走位／出入画**：本拍人行仍记**开拍**中心格（=上拍终态）；写 `站位变=是｜站位变因=走位:{路径}`；终点格从**下拍**分布图落地。入画@B 本拍只预锁经口，下拍才入格。无路径却换格 = 失败。
- 上拍 `触≠无` 且本拍未松开 → 双方原样抄 `触=`，且必须同格、同入 `可见=`。本拍收拍在场 = 下拍开拍在场。
- 禁拍末 `确认=`。禁【取景锁定】。`当前环境=`／`望=`／`景别=` 只写在分布图，并与提取块同名。预估同框>4 → 回步5–7。

**机位与景别可见必须匹配（最高）**
- `针对=` 必须列入 `可见=`（空镜除外）。
- `覆盖=Two-Shot` → 双方都在 `可见=`，景别须 `MS|FS`（竖屏同核）。
- `覆盖=过肩|过腰|过头` → `框主=`＋`看=` 都在 `可见=`；框主须写局部（过肩=`左肩|右肩`，过腰=`左腰|右腰`，过头=`后脑`）；框主中心须比被看更近机位。关系角须与 OTS 高低同核。等体量正反须写 `过肩配对=`（甲右肩↔乙左肩；高差则矮后脑↔高腰）。法相类看对手 → 框主=法相；同时读宿主+法相正面 → 走面侧，禁巨体后方硬盖两体。
- `覆盖=带肩` → 主拍 `:半身|:胸肩` 与并排邻人 `:半身|:胸肩|:左肩|:右肩` 都在 `可见=`；`针对=`=发声者。禁升邻人为唯一主拍、禁裁掉邻人。
- `覆盖=反打` → 望向相对上拍差 180°，`当前环境=` 对向，读脸对象在 `可见=`。同时盖两体须先过步6遮挡／体量闸。
- 景别盖不到的人不得写入 `可见=`；写入 `可见=` 的人须能被该档盖到（CU/ECU 仅针对＋必须同框的接触肢／配饰）。
- **近景别可见可写局部（最高；`MS|MCU|CU|ECU`）**：`可见=` 不是只报人名。主拍写该档盖住的体量；其他人只写实际入画的**自身左右局部**。例：`景别=MS｜针对=CHAR:[@甲]｜可见=CHAR:[@甲]:半身, CHAR:[@乙]:右肩`（甲的中景，画里带着乙的右肩）。
  - 主拍体量：`FS|WS|EWS`=`全身`（可省 `:全身`）；`MS`=`半身`；`MCU`=`胸肩`；`CU|ECU`=`脸`（物件特写写该件）。
  - 其他人部位闭集=`左肩|右肩|左肩头|右肩头|左臂|右臂|左腰|右腰|左手|右手|左侧身|右侧身|左侧脸|右侧脸|后脑`。禁裸写 `肩`／`手`／`腰`。禁 `画左肩`／`近镜头肩`（那是建置投影）。
  - **左右=该人自身左／右，按 `朝向=` 锁身轴，再看机／主拍在其哪一侧**：面朝谁之后，其左肩／右肩已定。过肩：机在其**左后**→`左肩`（`机位侧=左肩后`）；**右后**→`右肩`。并排贴边：邻人露出**朝向主拍的那一侧**——主拍在邻人自身之左→邻人 `左肩`；主拍在邻人自身之右→邻人 `右肩`。无转身不得把上拍左肩改成右肩。
  - `覆盖=单人` 且景别盖不到旁人 → 旁人不要写入 `可见=`。旁人只露肩／臂仍须写入并标部位，不得无据升 `:半身`／`:全身`。**并排露肩例外**：`覆盖=带肩` 时邻人允许 `:半身|:胸肩`。
- **密切关联同格且同可见（最高）**：直接接触未松开、真身↔法相／金身／化龙凤未离开、人↔载具／坐骑未离开、开场已佩戴配饰 → 必须同一 `宫格=`（中心），且本拍同时列入 `可见=`（空镜除外）。近景别关联体可写局部（按肩的手、法相肩），不得蒸发。景别盖不住关联体 → 改景别或拆拍，禁拆格凑构图。**巨体挡光轴例外**：近层远大于远层且机在巨体背后 → 被挡者可不进 `可见=`（或只作尺），格仍同，不算拆关联；禁把被挡者写成可读半身／框主。要两体都可读 → 改另一侧。

## 0. 宫格 → 主拍ENV → 对打取景

### 0.0 入场核销（最高；逐 CHAR/PROP；禁鬼魅）

### 0.1 开拍 XOR 落点
B1 开场者写满 XOR；待入画只三键+预锁、不占格。其后每拍覆盖仍在场者（含无动作、将落镜后者）+该拍待入画。走位改侧/细节/锚／宫格（终点从下拍写）；改方式仅当出入封闭或离开锚。
档已由步2锁。再按**落点三级**定格与朝向，再写 XOR。宫格基准=`0度{已锁族主名}`。相对锚：档=`内部ENV` → ∈占用面固定件；档=`道具沿用宿主` → **允许** `PROP:[整车]`。❌先挤中格再找理由。❌内部剧情却挂宿主+整车。❌三层交付却切占用 ENV。

**落点三级（最高）**
1. **剧情明示（最高；覆盖构图）**：原文 / 文戏 /【未落清单】已写「站/立/坐在{具名}前/旁/后」、锚、侧、座位、门侧、柜台后、第 N 桌等 → **原样落入**，`锚=`=该具名件，`落点据=明示:{原词}`。禁为 180° 全景、框中框、桌案层次、正反打预留或避难点改挂到另一件。❌原文「站立在巨幅落地窗前」却 `锚=大理石办公桌`。切角 / 收景别 / 换主拍 / `镜头推进` ≠ 改明示锚。
2. **剧情分析**：明示未锁的空位，按下表统筹，让后文拍得成、卖点读得清。

2. **围桌/围案**（≥2 人同桌）→ `方式=相对`：`锚={桌}` + §0.1A（`辅=`哪一侧 + `座=`该侧第K/M）。禁只写靠桌。
3. **室内/房间（最高；中区有主体必须相对）**：厅堂/舱内/甲板等有固定主体 → 全员 `方式=相对`（座位走封闭）。`锚=`=该人实际站靠的固定件（明示窗前/门旁必须是该件；不是全场默认中区桌）。同人同拍一个锚。`侧=`=`前|后|上|下|东|南|西|北`（主环境向；`北≡后`／`东≡右`／`南≡前`／`西≡左`；禁画左/近镜头）。三维：`四侧=`+`锚纵深=近|远`+高低。辅=`主位|客位|左长边|右长边|近门一侧|远门一侧|床头|床尾|东面|南面|西面|北面`（可加 `偏=东|南|西|北`，如西面边偏靠南）。`距锚=`相对该锚，不是镜头前中后。
4. **仅完全空旷 → 才绝对**：中区无稳定主体的广场、空大厅、旷野 → `方式=绝对`。室内有主体却写绝对 = 失败。有锚却称「无明确相对锚」= 失败。绝对成稿须同时过 **对照表入格 + `宫格=` + 朝向**（§0.1B）。本层不写 `层位=`／`画位=`。
5. **配饰**：仅开场已佩戴/手持可见才走本档：`挂靠={角色}`｜`部位=`。开场在盒/匣/袋内 → 按独立道具 `待入画`（`经=`=该容器）。独立道具走 1–4。
6. **逐人禁混写 + 画位分流（最高）**：同一角色只用一套方式。该人 `方式=绝对` → 本层只写 `宫格=`（后/中/前 × 左/中/右），不写 `层位=`／`画位=`。该人 `方式=相对|封闭` → 定位行/宫格键/`侧=`/`细节=` **禁止**出现 `画左|画右|画中|中央|前景|中景|后景`（构图 `纵深层=`/`主体落点=` 不回填到该人位置句）。相对只写锚+侧+四侧+辅+距锚；封闭只写排座。❌`锚=八仙桌｜侧=画左`｜❌相对行再填 `画位=画右`｜❌绝对人行写本拍画面 `前景|画左`。
7. **角色组**：必须近距者整组同格；`组=`/`序=`/`朝向=`/`距=`写在定位行。禁另起【角色组】。无近距依据禁标组。
8. **同锚 / 同绝对格（最高；§0.2A）**：≥2 人 `锚=` 同一具名参照，或 `方式=绝对` 且 `宫格=` 相同，或封闭同排 → **必须**写 `同簇相对=`。`序=`/`距=` 不能代替三维。禁只写「并立 / 在一起 / 同在柜台前」。

### 0.1A 槽位锁（围桌 / 封闭舱强制）

多人围桌、排椅、车/机舱/机甲/轿子等封闭座位，**必须锁到唯一槽位**。`同簇相对=` 不替代本条。K 同侧/同排不重复，`1≤K≤M`，M=该侧或该排总位数。切角不改世界槽位（`排=`/`辅=`/`功能=`/`K` 守恒）。本层不写画幅词。

**围桌 / 围案（`方式=相对`）**
每人必填：`锚={具名桌/案}`｜`辅=主位|客位|左长边|右长边|近门一侧|远门一侧|东面|南面|西面|北面`｜`座=该侧左起第K/M个`（0° 面朝桌心或面朝 0° 后景时，该边从左数）。可兼 `功能=主位|客位`、`偏=东|南|西|北`。
❌`靠桌`｜`围坐`｜`桌边`｜`主位旁`无 K/M｜两人同侧同 K。
✅`锚=八仙桌｜辅=左长边｜座=该侧左起第2/3个｜功能=客位`
✅`锚=八仙桌｜辅=西面｜偏=南｜座=该侧左起第1/2个`

**封闭舱 / 排座（`方式=封闭`；车、机甲、机舱、舰桥、轿子、剧场排椅）**
每人必填：`排=第N排`（从 0° 前向/操纵端往舱尾数，操纵排=第1排）｜`座=左起第K/M个`（面朝 0° 时该排舱体左→右）｜`功能=`闭集或载具惯例名=`驾驶座|副驾|后排左|后排中|后排右|操纵席|副操纵席|观察席|{原文具名座}`。
可核销 ID=`第N排-左起第K/M位-{功能}`。汽车司机=`第1排-驾驶座`；机甲驾驶员=`第1排-操纵席`；后方人员不得写到操纵员与前窗之间。禁套厅堂围坐进驾驶舱。
❌`在车上`｜`后排`｜`副驾旁`无排无 K｜只写`前景画右`。
✅`排=第2排｜座=左起第1/3个｜功能=后排左`

空座不写人行，但 M 仍按实有位数。入座/换座写过程；本拍定位=开拍槽位。

### 0.1B 绝对定位对照表 + 朝向（最高；仅 `方式=绝对`）

相对/封闭不走本条。绝对必须**查表入格**，禁止凭直觉写画左。对照表里的「后／中／前 × 左／中／右」是**主环境 0° 世界格别名**，不是本拍画面前景／画左。

**1. 落格对照表（强制；世界格 → `宫格=`）**

| 世界纵深＼左右 | **左** | **中** | **右** |
| :--- | :---: | :---: | :---: |
| **后**（主环境 0° 侧） | 后左 | 后中 | 后右 |
| **中** | 中左 | 中 | 中右 |
| **前**（主环境 180° 侧） | 前左 | 前中 | 前右 |

本层每人只写 `宫格=`（西列×北行交叉位＝中心归属），且 ≡该拍分布图该人行。不写 `画位=`。缺 `宫格=` = 失败。切角不改格名。成稿禁写 `后左`／`前中`。

**2. 超过两人锁世界序（最高；本拍绝对已入场＞2）**
`方式=绝对` 且已入场人数 **＞2** → 写世界相对：`同簇相对=` 或互为左／右／前／后（§0.2A／§0.2G）。**禁**本层写本拍画面 `左起`／`近起`／`前景|画左`。
本拍绝对人数 ≤2 → 仍须写互为左/右或前/后；同格走 §0.2A。

**3. 朝向必须落到世界主体（最高；绝对每人）**
绝对角色 `朝向=` 不得 `无`（闭集见步2）。`面半空间=` 必填。无转身不改。无正反面件不写朝向。

### 0.2 3×3 主环境九宫（每拍；与衍生无关）

把所属**主环境**俯视场地虚拟成九宫。**不随本拍切角／衍生改人格名**——切到 180° 只改分布图机位行与 `当前环境=`，人的 `宫格=` 与 `朝向=` 不改（无走位／无转身）。宫格本身不做转换。

```
        西1列          中2列          东3列
北1行   西1列×北1行    中2列×北1行    东3列×北1行     （北=0°）
中2行   西1列×中2行    中2列×中2行    东3列×中2行
南3行   西1列×南3行    中2列×南3行    东3列×南3行     （南=180°）
```

**落入规则**
| 方式 | 入格 |
| :--- | :--- |
| **绝对** | **只查 §0.1B 对照表**：世界后/中/前 × 左/中/右 → `宫格=`。人行不写 `层位=`／`画位=`。 |
| **相对** | 先把 `锚=` 落到该锚在主环境场地上的格，再按锚侧微移：`侧=前`→前一档，`侧=后`→后一档；`四侧=左端`→左邻格，`右端`→右邻格（不出场）。**禁止**用角色 `画左/画右`／`近镜头侧` 入格。同锚且距=贴身/一臂 → **必须同格**。 |
| **封闭** | 第1排（操纵端）落入载具所朝世界半空间的近端格；尾排落入对向；`座=` 左起第K决定左/中/右。缺 `辅=`/`排=`/`座=K/M`/`功能=` → 未入格，回改 §0.1A。禁用近镜头入格。 |

**近者同格仅限剧情近距（最高）**：普通人角色组 / 明示贴身 / 一臂交付才同格。无近距依据 → **分格**（避难点：单视角不密）。一格角色>3 → 按 `侧=`/`辅=` 拆到邻格；邻格仍超 → **拆拍**（各组挂不同后景）。无近距依据时一格角色≤2。**挂靠体例外（§0.2H）**：法相／坐骑／载具默认随宿主**同格同朝向**，不占人名额、不触发本条分格。无宿主的独立道具单独占格但不占人名额。群演簇整簇占一格、不计单个名额；落点与拆拍见 §0.2B。

成稿每拍**只写一张 §0.2C【角色道具宫格分布图】**（人／件中心格＋站位／朝向＋变否变因；机位可九宫外；覆盖可见；`当前环境=`）。其后无人走位则人行抄上拍。❌另起三表｜❌成稿写后左／前中｜❌用本拍衍生画左重写格名｜❌切角改人格｜❌拍末 `确认=`

### 0.2A 同簇三维相对（同锚 / 同绝对格强制；切角不改世界轴）

宫格只锁「落在哪一格」。同锚／同格须再锁三维相对（谁在谁之左、谁近谁远、谁高谁低）。

**触发（命中任一即强制；每人一行）**
1. **同参照**：`方式=相对` 且 `锚=` 同一具名件（含同质多件已锁到同一具）。
2. **同绝对格**：`方式=绝对` 且 `宫格=` 相同（高低可不同，仍算同簇）。
3. **封闭同排**：`方式=封闭` 且同一 `排=`（`座=` 第 K 只锁左右序，仍须补纵深/高低）。
4. 角色组 / 明示贴身 / 一臂交付同格 → 必写（`组=`/`序=`/`距=` 不替代本键）。
5. **挂靠同格**（§0.2H）：法相／坐骑／载具与宿主同格 → 必写（法相：在其后／高低上；坐骑／载具：宿主 `在其上`）。

未触发 → `同簇相对=无`。挂靠体随宿主同格时必须触发 5。独立可移动道具与人同锚/同格时同样写。

**0° 世界锁（写入该拍合一行 `同簇相对=0度锁`；无走位继承上拍）**
三轴必填。`高低=`/`纵深=` 两种方式同锁。左右轴按该人 XOR **分流**（最高）：
- **绝对／相对／封闭同簇**：一律写人际世界轴 `在其{左|右|前|后}`（或抄已锁 `四侧=`/`辅=`）。**禁止** `画幅=偏画左|居中|偏画右`、**禁止** `近镜头侧|远镜头侧`。
- `高低=`=`上`｜`平`｜`下`（谁更高：站凳/踩踏/俯身/躺卧；`平`=**齐站**；切角**不改**此轴）。齐站默认不写高低，有高差才写 `站凳偏高`/`俯身偏低`。

2 人：互写 `相对={对方}`。3 人同簇：每人 `相对={其余}`，并加左右序／高低序（只写有差的轴；`在其左→右`）。
❌`并立`｜`在一起`｜`柜台前两人`｜只用 `序=1/2` 不写轴｜用宫格名冒充格内相对（`宫格=前中` ≠ 谁在谁之左）｜本层写 `画幅=`／`近镜头侧`。

成稿=`同簇相对=0度锁｜相对={名}｜在其{左|右|前|后}｜高低=上|平|下`（3 人加序）。禁 `画幅=`／`换算=`／`近镜头侧`。`辅=`／`近门一侧`／`座=` 是世界槽，切角不改，≠永远靠近镜头。图上同行 → 只写 `在其左|右`，无走位禁改前后。贴身另锁 `触=`。

### 0.2F 同格挤身（拥抱/押送/牵手；只锁世界）

一格 2–3 人且 `距=贴身`（拥抱/押送/挟持/牵手/按肩/搂腰）→ 本层只锁世界：同格 + `触=` + `在其{左|右}`。本层不写谁在画幅哪一侧、不写 `露=`、不按景别评进画。收紧景别不得从宫格删接触者。

**世界左右（本层）**：写 `在其{左|右}`。切角不改口。禁造 `画幅=`。肢体左右=角色**自身**左/右（写入 `触=` 的 `己=`／`对=`）。

**触= 跨拍守恒（最高；未结束则每拍必抄）**：接触一旦成立，双方合一行写 `触={式}:{对方}｜己=…｜对=…`。此后每拍**原样抄**（切角/收景别/换主拍 ≠ 松开）。仅本拍正文写松开/挣脱/放开/放下手臂/结束拥抱 → **下拍**才 `触=无`。本拍定位行仍=开拍接触态。❌上拍牵手、下拍两人独立站位无 `触=`｜❌只改 `距=一臂` 暗示已放开。

成稿：`触=押送:唐柔｜己=右手｜对=右肩｜同簇相对=0度锁｜在其右`。
❌同格不写 `在其左/右`｜❌造 `画幅=`｜❌拥抱未结束却漏 `触=`。

### 0.2B 群演簇（原则上独立拍 + 空格疏离）

剧情允许时，群演簇**原则上不跟具名挤同一主拍**。先落空格，再拆独立拍作簇主拍。

**落点（先于选角）**
1. 整簇独占一格；优先**边/后空格**（`后左|后右|中左|中右`），禁占 `中`/`前中` 抢具名。
2. 与最近具名 **隔≥1 空格**（不相邻）。禁同格、禁贴邻格并肩。
3. `落点据=`=`分析:群演疏离`（原文未写围观/冲撞/贴身市集）或 `避难点:群演让位`。
4. **明示例外**：原文/文戏已写围观、冲进、市集贴身、簇为交付/走位障 → 可邻格或同半空间远层；仍禁与具名同格叠身。`落点据=明示:{短语}`。

**取景（原则上独立衍生拍）**
- 拆成独立 Beat：`主拍对象=群演簇`｜`对打=无`｜景别 `EWS|WS|FS`｜挂**能看见该空格**的已声明 `{N}度{主}`（常 0° 建立或 90/270 侧角）。该拍具名非 R → 仍占格，不为簇改挂具名对白角。
- 同向不另起行：禁 `{N}度{主}_群演` / `_人群`。独立=**独立拍 + 簇作主拍**，不是新造环境名。
- 具名对白/读脸/MCU+ 拍：簇仍占格，不升为主拍。仅 EWS/WS 建立且簇在远层可读时，才可同拍作背景层——仍守空格、不抢「聚」。
- 须拆未拆 → §2.3A，`拆拍依据=群演疏离`。

❌无据把簇塞进具名 MCU/过肩同框｜❌簇与具名同格或贴邻｜❌为簇新造衍生短名。

### 0.2C 【角色道具宫格分布图】（强制；每拍一张；落位真源）

每拍只出一块。基准=所属主环境俯视九宫，**与衍生无关**。`宫格=`=主体最中心交叉位，可跨格可见。禁重排左右为前后（§0.2G）。禁另起三表／ASCII 九宫成稿。

**1. 九宫只对位主环境（最高）**
列=西1→中2→东3；行=北1→中2→南3。北1行三格对主环境 0°=北；南3行对 180°=南；西1列对 270°=西；东3列对 90°=东；中2列×中2行对中心。禁另造格主体，禁用衍生画左重写格名。

**2. 人／件行**
已入场全员＋挂靠体各一行。`方式=`＋`站位=`（参照物＋东南西北／固着侧／排座）。`朝向=`只写世界对象。相对上拍必须写 `站位变=`／`朝向变=`＋变因。切角不得写变。无正反面件 `朝向=无`。

**3. 机位行（不强制入九宫；与景别同锁）**
九宫只给人／件用。机位**默认可在宫格外**，写 `机位=九宫外:西侧外|东侧外|北侧外|南侧外|上空|门外侧|窗外侧|檐外|对楼`。仅机中心确实落在某交叉位才写格名。禁为「填满九宫」把门外／窗外／檐外／对楼／上空机硬塞进格内。`望=`≡北东南西。`景别=`≡`机位距=`。缺 `机位=`／`望=`／`景别=`／`当前环境=` =失败。

**场外往内拍（最高；门外／窗外）**：机站在开口**外侧**，镜头穿过门／窗看场内。人仍在九宫内，机不入格。
- `机位=九宫外:门外侧` 或 `九宫外:窗外侧`（可叠方位：`门外侧·北`＝门外且在北侧外）。
- `机位锚=`=该具名门／窗（环境主体，逐字），`机位距=`=贴框外多远（窥视常 `贴身|一臂`，交代常 `两步|三步`）。
- `望=`=朝**场内**（对着开口所在向的对向：门在北→望南；窗在东→望西）。`当前环境=`=该望向的 `{N}度{主}`（看进去的室内面）。
- `机位侧=窗外贴玻璃`（窗外）或开口外侧。`构图` 可兼 `框中框`。`AI位=窗外看入`（窗外）或 `无`（门外）。`镜头角度=` 仍必写（默认平拍；俯看室内桌面=`俯拍`）。

### 2.3A 一拍一衍生（最高；覆盖不足可改 Beat）

- **盖不住才改 Beat**：该角白名单+活动适配+边界无法完整覆盖 R（含跨对向、交互链不同显、同框锚分属对向、走位/投射一角装不下）→ **拆拍改写**：将一拍拆成多拍，各拍只写能被**该角**看见的角色动作/过程，再各挂对应 `{N}度{主名}`（或合法状态/仰天行）。禁为凑覆盖改对白词、因果、左右手脚/取用/朝向/门开闭合同。
- **画内>4 必拆**：本拍 `画内V`（具名/有戏，角色组按组内计）>4 必须拆。拆后每拍 ≤4，各组挂不同后景。各拍只写该组在该角可见的动作。
- **群演疏离可拆**：剧情未写围观/冲撞/贴身市集，却把簇与具名对白/读脸同拍近框 → 按 §0.2B 拆出簇主拍，挂看见其空格的已声明角。`拆拍依据=群演疏离`。禁为簇新造 `{N}度{主}_群演`。
- **占用换主须拆（最高；§4.3C）**：同一拍既要 `内部ENV`（舱内自成做场）又要 `整车无人`/`道具沿用宿主` 的大世界远观 → 必须拆。`拆拍依据=占用换主`。三层交付是一拍、一档=`道具沿用宿主`，**不拆**。内部剧情过阈：前拍可挂宿主无人，过框后拍挂占用。禁把内部剧情与整车无人合成一拍。
- **拆拍合同**：过程/特效句按角分配且全出（禁吞并）；每拍自备【配乐】【音效】与分布图；从 1 重排；场级 `承接=`/`节拍=`/`落地=` 与输入【Beat切分确认】的 B 号/拍数同步；该拍分布图 `跨对向=否`，写 `拆拍依据=ENV覆盖|角色超限|群演疏离|占用换主`。❌一拍挂两 ENV｜❌`画内V>4` 不拆｜❌拆拍后丢过程或改台词。

### 2.4 主环境对向位零可见（最高；固定环境实体）
对当前观察轴 N，主环境四向中位于 `(N+180)%360` 的对向边界实体及其附着/承托物写入 **`画外={照抄该向}（不可见）`**，并列入`不可见内容`（与 `画外=` 同核），与白名单交集=∅。选本角 ENV、写分布图/朝向/Beat 可见叙述时**禁止点名**这些主体。禁因“写背面/广角/稍带到”塞回。相邻 ±90° 仅`可见边界`明示贴边小部分可入白名单，不能整面入镜。
- **舱内 90/270**：近镜头侧门框/窗框+全部座位侧面进白名单。对向零可见只约束舱外街景，禁把近侧半舱座位整排进`不可见内容`。

### 2.5 轴线（机位同轴；禁跨轴）
先列 R，再为覆盖 R 的真实机位建 `{N}度…`。禁轮角、禁无拍冗余角。定 0° Master 后写本场 `spatial_axis`（≡分布图 `轴线=`）。**机位选择遵守同轴原则，不能跨轴。**

轴线=对戏两人中心格连线，或单人↔其锚。工作侧=`轴侧=`，开场／本段第一张有人关系镜锁死，后续机位只许落在该半空间。

| `axis_crossing` | 何时允许 | 机位 |
| :--- | :--- | :--- |
| `None` | 同侧微调、同侧过肩、非反打 Insert/CU | 仍在 `轴侧=`；不跨 `spatial_axis` |
| `PlannedReverse` | 正反打/读对手（沿轴线对向，典型 ±180°） | **同轴对向**：机走到轴另一端，仍同 `轴侧=`。左右屏对调。触发须含 `N_对手→(N±180)%360` |
| `MotivatedCross` | **本层机位不用** | 禁为换角／好看／补清单把机摆到轴线对面。原文若写人走到轴线对面，只改人的走位，机仍跟新站位重锁同侧，不先跨轴摆机 |

禁：机位跨到轴线另一侧；无据 ±90° 跳对面；把跨轴标成普通反打；过甲右肩后下一拍无据改过甲左肩；为填满清单建跨轴角。

### 2.6 反打 ENV / 状态衍生 / 出入舱触发
- **反打 ENV**：先定所需背景/对手可读面，再算 `N_对手→(N±180)%360`；该行白名单须能看见所需内容。`axis_crossing=PlannedReverse`。非反打 Insert 不另建行。同时盖两体先过步6遮挡／体量闸：巨体后方看不见小人 → 改面侧行或本拍忽略被挡者。
- **状态衍生**：仅跨拍可持续的结构/重大氛围改写才建 `{主}_{状态}`；`{N}度{主}_{状态}` 每行仍须写 `所属主环境={主}`。禁止把景别/反打用法写成状态后缀。**仙攻大招环境改观**（上游写了扭曲/变色/粒子化，或标`环境改观={主}_{状态}`）→ 该满幅拍及维持相须挂 `{N}度{主}_{状态}`（状态词=扭曲｜变色｜粒子化｜域场等，跟上游）；`特别表述=` 写可见改观（哪面弯/何色迁/何处粒子化），禁另造主环境、禁把改观看成换地。余波回落后才回挂无状态行。
- **出入封闭舱 / 宿主↔占用过阈**：仓外宿主与封闭舱占用是不同主环境族，各声明衍生。仓外族白名单含整车（已抽则 `PROP:[整车名]`）+各具名门扇/窗/舱口；占用族按舱内写活动空间。本拍挂哪一族服从 §0.3-0 `载具档=`。声明触发名=`入舱切主环境|出舱切主环境|回切仓外主环境`。换主名≠反打。过框后若是**内部剧情** → 落幅挂占用族。若是**三层交付** → 仍挂宿主、整车保持 PROP。缺过阈锚则先挂可见该口的宿主侧向角，禁从看不见口的宿主远角直接切进占用面。
  - **推拉平稳进出（最高；执行文戏运镜档）**：分布图写 `过阈运镜=过框推入|跟随入舱|窗外窥入|绕体外跟|落幅在舱|过框拉出|跟随出舱`。外→封闭舱优先连续**推**过阈；封闭舱→外优先连续**拉**过同一阈。起幅拍须看见该口；`ENV变=` 写在**落幅拍**（推入落幅=`入舱切主环境`，拉出落幅=`出舱切主环境|回切仓外主环境`）。连续运动可跨两拍（前拍未完成、后拍落成），禁中段硬切。落幅有人须 `FS|MS`，禁宿主 `EWS|WS` 硬切舱内 `MCU|CU` 对白。露天合建无舱门过阈不套本条。
- **闪回/蒙太奇切主**：各主环境各挂各衍生族；声明触发名=`闪回切主环境|闪切切主环境|蒙太奇切主环境|回切当下主环境`。

### 2.8 特别衍生（仰视）
仅当空镜资产本身必须仰看天花/天空时另建一行。Beat 只锁`镜头角度=仰拍/虫蚁/航拍`而空镜仍是平视宫格 → **不建**特别行。屋顶并入仰天，不另起 `{N}度{主}_屋顶`。荷兰角/变形透视写拍摄键，不另建衍生行。

## 3. 选用节奏与过肩
- **连续≤3**：同一衍生名连续拍不得超过 3（可稍后切回，每段仍≤3）。满 3 优先切已声明他角；现有角皆不能覆盖才补侧向。合理换角=`R−W=∅`+对向零可见+守轴。
- **例外（须写依据）**：①本场≤3 拍；②转身且半空间未变（计入连续）；③唯一覆盖角（标`唯一覆盖角`+R−W）；④连续位移切角破动量最多+1。武戏快链豁免。
- **读对手 vs 同侧 OTS**、正反穿插、禁入戏假切、正拍禁背面：见步7／§0.4。`关系角=过肩|过腰|过头|OPC` 必须写 `OTS类型=`。档位跟 OTS 高低，禁逢对白就过肩。

| **CU** | 特写 | 脸或等大物件为主；肩可入画缘 | 情绪砸点、听者反应链、关键道具首次可读、`~`精髓拍 | 数步同框无交代；只拍施动者丢掉受者；群演脸 |
| **ECU** | 大特写 | 眼/唇/手/伤口/文字/机关局部填幅 | Insert、契科夫枪、屏/信字样、命中局部、细节特写参考 | 口型对白主拍（唇部 ECU 仅停顿/欲言又止）；走位关系 |

- **`剧情匹配=`**（每拍必写）=`建置`｜`走位`｜`对白`｜`交付`｜`反应`｜`特写`｜`空镜`｜`宏观`。建置=有人空间建立（已在场者须在画）；空镜=本拍 R 无人。追逐／飙车／楼间穿梭有追逃主体在画 → `走位|交付`，禁 `空镜`（窗外流景并进追逐拍；宏观机群满幅才可 `宏观`）。真·空镜仅无人环境文学／地貌／全员待入画；整车无人远观可 `空镜`。功能→档见步5；画幅见 §4.5.2；收中景见 §4.3A。
- 贴身→MCU/CU；数步对峙→`FS|MS`（拉开可 `WS|FS`；禁 MCU 同框）。
- 原文`△近景/特写`须落入对应拍并写`原文景别=`。非反打收紧沿用父 ENV。
- **空镜拍**：只锁 ENV+拍摄键；`主拍对象=环境`；`画内V=0`（预估）。已在场者仍占格，本层不写进画档。整车无人全景：挂宿主、可点名 `PROP:[整车]`，禁 CHAR。道具特写/Insert 不是空镜。开场已在场第一拍禁标空镜（§4.3A）。
- **群演**：只进 `EWS|WS|FS`；禁近档群演主拍（宏观满幅例外，仍禁单人格特写）。簇主拍见 §0.2B。
- `MCU|CU|ECU` 不得标`纵深层=前中后同时可读`。

### 4.2 构图档（主档+可兼完整；必须与剧情匹配）
主档闭集必选一=`三分`｜`中心`｜`纵深`。可兼闭集可多或无=`对称`｜`框中框`｜`引导线`｜`负空间`。禁止另造主档名（黄金分割/对角/三角等映射回本闭集：偏置→三分；居中仪式→中心；前后层→纵深）。
成稿每拍分布图写：`构图=三分|中心|纵深｜可兼=对称|框中框|引导线|负空间|无｜主体落点=画左三分|中央|画右三分｜留白=视线前|运动前|无｜纵深层=前中后同时可读|浅层单焦`。

| 类型 | 层级 | 可核销画面结果 | 典型剧情功能 | 禁 |
| :--- | :--- | :--- | :--- | :--- |
| **三分** | 主档 | 主体落画左/画右三分交点；对侧留白 | 对白交流、对峙分列、视线/运动引导、常规叙事 | 标三分却钉中央；无留白的假三分 |
| **中心** | 主档 | 主体或对峙轴钉画面正中 | 仪式/权力/Iconic、对峙轴、揭示砸点、对称殿堂 | 无仪式/权力/砸点依据的闲聊对白通场中心 |
| **纵深** | 主档 | 前/中/后至少两层同时可读 | 空间层次、走位避障、门—桌关系、前后排对戏、建立空镜 | MCU/CU/ECU 假标多层；必读层不可见 |
| **对称** | 可兼 | 左右或轴对称可检索 | 殿堂/礼法/对仗/仪式 | 无对称结构却空标 |
| **框中框** | 可兼 | 门洞/窗/廊/肩/器物形成内框 | 窥视、隔障对话、进出门槛、细节特写收束 | 无可见内框却空标 |
| **引导线** | 可兼 | 道路/廊柱/队列/桌沿把视线导向主体 | 入场动线、队列、通道压迫 | 无线可循却空标 |
| **负空间** | 可兼 | 主体占比小、大块空/暗/远景压人 | 孤绝、被监视、渺小、低点放大 | 热闹群戏无据大留空 |

- 对白/对峙：横屏默认三分+视线前留白；竖屏默认中心或纵深叠层（横向不够钉宽三分）。仪式/Iconic→中心；走位/前后层→纵深；窥视/门槛→框中框；通道→引导线；孤绝→负空间。可兼须有可见依据。**仙攻大招/法相巨化满幅**：主档优先`纵深`（近大远小），可兼`负空间`压对比物（被施法者或具名建筑/山）；禁`MCU`假标多层。
- `主体落点=`：相对/封闭不改锚位；绝对须与构图落点同向。关键/空镜/道具特写/Iconic 拍的构图须有剧情依据，禁无故通场同档。
- 有视线/运动→`留白=视线前|运动前`；中心钉死可`无`。`可兼=负空间`时留白字段仍须写方向或无。
- **留白须可核销空边**：`视线前|运动前` = 该方向有 Head Room（头顶）与 Lead Room（视线/运动前）可量空边；`无` = 中心钉死可贴顶但禁裁颅。禁标留白却贴边满幅。

### 4.3 跨拍切换
每拍分布图写`上拍景别=`与`跨度=`。`同级`＝同档；`邻档`＝沿 `EWS↔WS↔FS↔MS↔MCU↔CU↔ECU` 移 1 档；`越级`＝跨≥2 档，须写`越级:{依据}`。默认只允许同级/邻档。
**越级闭集**：①原文`△特写`/`细节特写参考`；②卖点/高潮/`~`；③Insert；④宏观/满幅特效后切特写陪衬（或回切；**空镜后切人戏不在此条，走 §4.3A**）；⑤交付拉开；⑥反打只为读脸且落幅仍同级/邻档——**反打不是 EWS↔CU 的依据**；⑦开场段特写吸睛后拉开整体建置（`越级:入场拉开建置`，仅 `MCU|CU|ECU`→`FS|WS`，禁再跳对白）；⑧进出场衬托（`越级:进出场衬托`）：反应 `MCU|CU` ↔ 入画/出画 `WS|FS`，仅紧邻进出场拍（§4.3D）。满幅↔细节特写须分拍或紧邻，依据写`越级:满幅特效↔细节`。
对白链两侧同级或邻档，只翻 ENV/`主体落点`。构图主档随功能变，禁无功能轮跳；反打默认同主档只翻落点。
近景链满 3 且下拍有走位/交付须拉开；远景链满 2 且已入对白须收近（宏观例外+依据；收近走 §4.3A，禁空镜硬切 MS）。
关系角≠景别：过肩对白另锁 `MS|MCU|CU`；交付 Two-Shot/过腰另锁 `MS|FS`。

### 4.3A 大全景收中景（最高；先见人，禁空镜起幅后半身突现）
与 §4.3B 并用。从 `EWS|WS` 收到 `MS`（对白/关系/手势）必须让观众**先在空间里看见人**，再认出身形，再读半身。禁「无人空镜 → 中景里人已坐/已站开口」。
**阶梯（默认邻档）**：`EWS→WS→FS→MS`。`EWS→MS` / `WS→MCU` 为越级，不在 §4.3 越级闭集，禁止当建立收近。横屏建立可 `EWS|WS`；竖屏建立偏 `WS|FS`（`EWS` 仅宏观/孤绝）。收到对白/关系前，链上须有一拍 `FS`（或竖屏建立已是 `FS`）让人从头到脚可辨，再邻档进 `MS`。
**开场已在场（最高；待入画除外）**：全部 `入场=开场` 者须在开场建置拍可核销占格（人可极小/轮廓）。该拍 `剧情匹配=建置`（不是`空镜`），景别 `EWS|WS|FS`（竖屏偏 `WS|FS`）。待入画不进本拍画面义务。`主拍对象=` 跟将承接的人/簇，禁 `主拍对象=环境` 却把已在场者标非 R。❌只锁有戏者、闲人后拍才占格｜❌B1 空镜无人 + B2 `MS` 半身开口。
**真·空镜**定义见 §4.1。空镜之后**第一拍有人**必须 `WS|FS`，**禁空镜硬切 `MS|MCU|CU`**。
**待入画**：入画过程拍锁 `WS|FS` 经上游 `经=` 出入口入画；**进出场衬托走 §4.3D**（须另有反应近档或落定后收近，禁过程拍与邻拍同档交差）。落定后再邻档收 `MS`。禁仓外/门外空镜后室内中景已落座开口（入舱过阈仍走文戏切口，落幅见人须 `FS|MS`，不得空镜落半身）。
**取景核销**：建立有人→`剧情匹配=建置`；建立无人→`空镜`。从大全景收到中景的各拍 `跨度=` 须逐步 `邻档`（中间可插 `FS`）。选择证据景别锚须能指回「见人/认人/读半身」哪一阶。

### 4.3B 入场双义务（最高；全员全景优先 + 吸睛）
每场开场段（进入铺垫/对白加压之前）必须**两闸都兑现**，缺一失败。
1. **全员全景位置（优先；待入画除外）**：至少一拍 `EWS|WS|FS`（竖屏偏 `WS|FS`），`剧情匹配=建置`，把全部 `入场=开场` 者收入画／宫格（谁在哪格可核销；人可极小）。待入画不进。禁只交代主拍、禁只靠对白 MS 暗示「在某房间」。
2. **吸睛**：观众第一眼有抓眼落点。闭集=`道具特写`｜`表情特写`｜`动作切口`｜`宏观规模`｜`艺术转入落成`｜`关键音画`。可与全员全景同拍（远景里已有醒目动作/阵势 → `入场闸=双`）。

**合法序**
- **默认先全景**：开场第一有人拍 = 全员全景位置 → 再邻档收近吸睛/对白。
- **先吸睛**：`MCU|CU|ECU` 特写，或无人 `EWS|WS` 远景／宏观 → **该拍一结束，紧邻下一拍必须拉开全员全景**（可 `跨度=越级:入场拉开建置`，仅 `MCU|CU|ECU`→`FS|WS`）。中间禁插对白／半身／另一特写。❌特写或空镜远景后直接 `MS` 开口、从未见全员站位。

**同拍双闸**：一拍 `WS|FS`（横屏亦可 `EWS`）里开场全员可读，且有醒目动作/阵势/转入落成 → `入场闸=双`。`CU|ECU` **不能**单独算建置。无人空镜 **不能**单独算吸睛（除非 `宏观` 本身即抓眼，其后仍须紧邻全员全景）。
**取景核销**：开场段每拍写 `入场闸=吸睛|建置|双`；全员全景出现后该拍记 `建置` 或 `双`。两闸都出现后其后拍 `入场闸=过`。进入对白前两闸均须已出现。场际转入落成是特写 → 下一拍必须全员全景。

### 4.3C 载具档（只执行 §0.3-0）
四档与挂族只认 §0.3-0。本层只补：B1 不得用 `整车无人`／`空镜` 顶替已在场者建置（人在场+车先过 → `拆拍依据=占用换主`）；内部ENV 与整车无人同拍 → §2.3A 拆。三层交付不拆。`载具档=无` 的骑乘须写 `人载同向=`。

### 4.3D 进出场衬托景别链（最高；禁同档一句进出）
待入画入画拍、中途出画/离场拍，不得只锁一档扛完全过程。须用**景别变化**衬托进出，并让在场者反应可读（文戏已写则本层锁档兑现；未写标 `upstream_missing_entry_reaction`，禁自造反应）。

**入画链（择一；写入 `进出衬托=`）**
| 档 | 过程拍 | 反应/落定拍 |
| :--- | :--- | :--- |
| **反应先** | 紧邻上拍或本拍起：在场者 `MCU\|CU`，`剧情匹配=反应` | 再邻档或 `越级:进出场衬托` 拉开 `WS\|FS` 见经口入画，`剧情匹配=走位` |
| **建立先** | 入画过程 `WS\|FS` 见口+人，`剧情匹配=走位` | 落定后邻档收 `MCU\|CU` 入画者或反应者，`剧情匹配=反应`（随后对白才 `对白`） |

**出画链（择一）**
| 档 | 过程拍 | 反应拍 |
| :--- | :--- | :--- |
| **跟出** | 跟人到口 `FS\|WS`，`剧情匹配=走位` | 可切 `MCU\|CU` 在场者目送，`剧情匹配=反应` |
| **目送** | 先 `MCU\|CU` 在场者视线，`剧情匹配=反应` | 再拉开 `WS\|FS` 见空门口或背影出，`剧情匹配=走位` |

- 入画过程拍本身仍锁 `WS|FS`（§4.3A 见人）；**反应拍**才锁近档。
- 过程拍+反应拍景别须**至少跨一档**。全程同档=失败（原文明文同档须写依据）。
- **视线×景别（强制；与运镜成对）**：反应近档 `MCU|CU` → `留白=视线前`，主体落点对侧留给出入口方向，主拍=预看/对视的人，禁钉进出者脸而丢掉看的方向。过程远档 `WS|FS` → `留白=运动前`，可兼引导线/框中框骑出入口，人从留白侧入/出，禁贴边满幅突然占画。反应先=近档先锁预看视线再拉开见口；建立先=远档见口+跟看再收近对视落定。运镜落地归下游，本层只锁档+留白方向，使 Push 收近 / Pull 拉开 / Follow 见口有据。
- `选择证据` 景别锚=`文戏:进出场衬托:{反应先|建立先|跟出|目送}`。
- 无在场者（全员待入画/已离场）→ 只走建立先/跟出，`进出衬托=无人反应`。
- 开场已在场建立仍走 §4.3A/4.3B，不套本条。

### 4.5 选型专规
#### 4.5.1 对白景别
口型主拍、可见 OS/V.O.、反打/过肩读脸、反应、微表情 → **`MS|MCU|CU`**（过肩对白典型 MCU；竖屏单人口型默认 MCU|CU）。禁 `EWS|WS` 常规口型（宏观/特效满幅例外+依据）。听者与说话拍同级或邻档。正反穿插景别见 §0.4。锁景别须同锁 §4.6.4 落点。
文戏 `voice_type=VO|旁白` **可与动作/画内对白同拍**，不因 VO 拆拍；该拍主拍跟画面功能（听者脸/空镜/Insert），**禁把 VO 当口型主拍**，禁漏抄上游 VO 行。
竖屏 Two-Shot 对白合法，**景别必须匹配**：双方同框可读 → 锁 `MS|FS`（优先纵深叠层）；禁 `MCU|CU` Two-Shot。3 人+：具名各锁单人/过肩近档。Walk-and-Talk：横屏 `MS`（可邻 `FS`）；竖屏 Two-Shot=`MS`，单人=`MS|MCU`。自白/画中画说话人锁 `MS|MCU|CU`。

#### 4.5.2 画幅 → 景别侧重（读项目信息；最高）
先读注入 `────【项目画幅】────` / `# Project Context` / `Aspect Ratio` / `aspect_ratio`。未注入按**横屏**。每拍分布图写 `画幅=`。
- **竖屏**＝height≥width：`9:16`｜`3:4`｜`4:5`；`1:1` 跟竖屏策略（Two-Shot 须景别匹配，优先纵深叠层）。
- **横屏**＝width>height：`16:9`｜`4:3`；`21:9` 横屏再偏远/左右分列一档。
功能闭集不改（口型仍禁远景；`~`/原文特写仍跟专规）。画幅只**收档、拆拍、换构图**，不另造景别名。
**画幅闸优先于距离闸**：贴身对白默认 `MCU|CU`；竖屏 Two-Shot 仍必须 `MS|FS`（交付=`FS|MS`）。`MCU|CU` 只给单人或过肩。

| 功能 | **竖屏侧重** | **横屏侧重** |
| :--- | :--- | :--- |
| **对白/反应** | 单人/过肩=`MCU\|CU`；**Two-Shot=`MS\|FS`**（优先纵深叠层）；正反穿插表情=`CU\|ECU`（听众同） | `MS\|MCU`；Two-Shot 可 MS；正反穿插表情=`MCU\|CU`；3 人+分拍 |
| **建置/空镜** | `FS\|WS`；`EWS` 仅宏观/孤绝；有人建置后经 FS 再进对白 MS（Two-Shot 可停 MS）；禁空镜硬切 MS | `EWS\|WS\|FS`；有人建置后经 FS 再进 MS；远景链满 2 仍须收近，禁空镜硬切 MS |
| **走位** | `FS\|MS`；Walk-and-Talk Two-Shot=`MS` | `WS\|FS`；Walk-and-Talk 可 `MS\|FS` |
| **交付** | `MS\|FS` Two-Shot 合法；禁双人 CU 硬塞横向指鼻 | `FS\|MS` Two-Shot 优先 |
| **并排** | Two-Shot 合法，**景别匹配**（`MS\|FS`）；或 `MS\|MCU` 露肩（发声者＋邻人半身／肩）；优先纵深叠层，慎 MCU 左右并坐却裁邻人 | Two-Shot、带肩露肩、或同侧 OTS；左右分列合法 |
| **构图** | 中心 / 纵深；`主体落点` 偏中央；慎宽三分左右钉 | 三分+视线前；对峙左右分列 |
| **画内** | 对白/近档 `画内V` 常规 **≤2** 具名（近侧框主可+1） | ≤4 |

#### 4.5.3A 动作空间（物理路径可读）

**OTS 纵深／高低闸（最高；框主比被看对象近）**：过肩／过腰／过头／OPC = 镜头在框主对应部位后，越过其身看远侧**主拍对象**。`近侧` 只对主拍而言。先评高低再定档，禁局限过肩。
- 框主必须比 `主拍对象` 更近镜头（对手在更远格／更远层）。
- **普通人同排跟分布图**（§0.2G）：同行锁左右并列 → 双方保持同层左右，禁无走位改前景／后景。构图肩入近缘 ≠ 世界换格。并排对手戏：`覆盖=带肩` 时邻人写半身或肩。等体量正反：可前后叠，或 `框主=`+`过肩配对=` 同时写出（甲右肩↔乙左肩；高差则矮后脑↔高腰）。
- **法相／金身／化龙凤看对手**：`近侧框主=`=该挂靠体（§0.3 ⑨）。未离开则与宿主**同格**。机在背侧：只过挂靠体看对手；宿主若入画只作尺，**禁**当第二框主。同时读两体 → 改面侧。`面对镜头=否` 合法。世界身后 ≠ 镜头后景／远镜头侧。
- **主观角色**：`主观角色=`／FPV 机高=该人眼高（站／坐／孩），禁默认成人站姿。
- 框主写成比被看对象更远（后景／远镜头侧）= 失败。
- `机位锚=`=框主 + `机位侧=`（过肩=`左肩后|右肩后`；过腰=`左腰后|右腰后`；过头=`脑后`）。
❌齐高差却写过肩｜❌坐看站仍过肩不过头｜❌站看坐仍过肩不过腰｜❌并排对白干净单人裁邻人｜❌机在背侧把挂靠体写成后景／远镜头侧、宿主写成前景｜❌过宿主肩／后脑顶替挂靠体｜❌巨体后方同时反打两体｜❌等体量正反只写一侧、对向无 `过肩配对=`｜❌机位在更远的人肩后、更近的人挡光轴

#### 4.6.3 俯仰跨拍
默认`角度跨度=同俯仰`。邻档=`平拍↔微俯/微仰`。越级须`越级:{依据}`（原文俯仰/POV｜峰值放大｜宏观｜倒地/跪拜/巨物）。禁对白链无据跳航拍/虫蚁。

#### 4.6.4 机位落点（最高；环境主体＋距离；与景别同锁）
锁 `景别=` 的同一拍必须锁：相对**哪一环境主体**、**多远**、`镜头角度=`、`机运=`。机位**不强制入九宫**；宫外写 `九宫外:{侧}`，仅机中心确在某格才写交叉位。禁只锁 MCU 不写主体＋距离。禁无锚「随便摆机」。禁锚本角 `画外=`。禁为填格把场外机写入格内。
- 空镜：`机位锚={本拍背景或场地具名件}`｜`机位距=五步远|十步外`｜`镜头角度=` 必写｜`机运=固定|鸟瞰`。
- FPV：`机位锚={主观角色}眼位`｜`机位距=贴身`｜`镜头角度=主观`｜`机运=FPV`。眼高跟该人站／坐／孩，禁默认成人站姿。
- OTS：`机位锚={可见环境件}+CHAR:[@框主]`｜`机位侧=`跟关系角（肩后／腰后／脑后）｜`机位距=`≡景别｜`镜头角度=` 必写｜`机运=固定|手持|OPV`。
- 带肩：`机位锚={可见环境件}+CHAR:[@发声者]`｜`机位侧=左颊前|右颊前|正侧`｜邻人须在 `可见=`。

**锚优先（环境主体优先）**：本拍可见三键／白名单固定件（门/窗/柜/桌/柱/檐）是主锚。已锁 `人载同向=是` → 兼锚 `PROP:[载具]`。过肩兼锚框主，**环境件仍要写**。`AI位≠无` 时锚可为窗外/檐口/对楼（须是可见结构名）。禁只锚人名不写环境件（FPV 除外）。

## 成稿自检
- **闭包**：薄封套 + 末行结束标签。只交衍生环境块 + 每拍原文＋分布图。未回写主环境／未落／SCENE_CONTENT。无【取景锁定】、无建置句、无三表、无拍内场记。
- **衍生（程序裁出）**：提取块全列。【本场衍生环境名】=提取块全列。第一刀有画幅锚＋`生成提示=`。特别行有 `特别表述=`＋`生成提示=`（禁空壳）。衍生的衍生有 `同角切割父=`＋`状态Delta=`＋`生成提示=`。画幅锚照抄主环境对应向；未点名本角 `画外=`；白名单无 CHAR/PROP。
- **Beat 原文**：输入该拍全文在分布图之前整段可检索；开口行整行在；配乐音效在。只增不减。
- **分布图**：每拍一块，在该拍原文后。九宫=主环境，只锁人／件中心格。机位不强制入格，宫外写 `九宫外:`。`望=`／`景别=`／`当前环境=`／`[DERIVED_ENV:]` 同核。`可见=` 与 `覆盖=`／`针对=`／景别匹配；近景别写主拍体量＋他人自身左右局部。密切关联同格同可见。切角只改机位行。
- **交叉闸**：`表情换环境评=`／`人载同向=` 写在分布图。宿主↔法相同格；巨体挡光轴可忽略被挡者出 `可见=`。
- **触=**：未结束双方原样抄、同格同可见。
- **机／景**：档自闭集；距≡档。机位=环境主体＋距离＋`机运=`＋`镜头角度=`（四者必写）。同轴；反打仍同侧。同时盖两体先评遮挡／体量。OTS 先评高低（过肩／过腰／过头）；等体量正反写 `过肩配对=`。并排对手戏评带肩，禁无据裁邻人。竖屏 Two-Shot=`MS|FS`。FPV≡主观且眼高跟该人姿态；鸟瞰≡航拍；OPV 禁主观。
