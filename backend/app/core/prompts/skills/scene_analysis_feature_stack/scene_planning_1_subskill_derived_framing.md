## 依赖参考图的不写外形（最高）

角色、道具、环境内的主体，以及同类已有参考图的具名物，只写已注册名字。不写颜色、形状、大小、材质、纹样，也不改外形。站位、边或点、走位、机位、机高、俯仰仍写。不依赖参考图的，包括特效，可以写颜色、形状、大小和纹样；上游 Beat 里的特效形色原样留下。上游已写的异常手段所见，正常视角和手段视角两层都留在该拍正文里。手段里看见的特殊场景不另起主环境，也不把人的站位改到那一层里面。


## 两段职责（最高）

按单场调用。输入=已注入的全部【主环境】【未落清单】+ 文戏场核与最终 Beat。同一场注入了当下、重生、闪回、回忆、梦境、蒙太奇多块时，每一块都读。拍落到哪一块，站位、锚和 `基准=主环境:` 只用那一块的主体和主舞台区。禁止用当下的桌椅给定重生、闪回或回忆那一拍的站位。本拍主名只取本场已注入的【主环境】注册名，逐字。拍首 `蒙太奇链=…｜地点={名}` 的 `{名}` 与某一块注册名逐字相同。旧稿若写成 `主环境=`，同样只对这个名字，这一拍就落在这一块上，与上一拍是不是同一块无关。链上的字对不上任何注册名，本场又只有一块 `主环境角色=闪回|回忆|重生|梦境|蒙太奇片段`，这一拍改挂这一块的注册名。角色对得上的块多于一块，或注入里没有这一处 → 本拍停写，回流环境规划。不把人钉在当下主环境里。链上的字、拍文里的地名、三年前、当年、旧时、回忆中、闪回里，都不收成 `{N}度{新名}`。提取块写 `{N}度{对上的注册名}`。缺了已对上的那一块，或这一拍仍挂着另一块，都是失败。新造一行所属主环境不在注入里的衍生，同样是失败。

**衍生环境只切自注入的主环境（最高；蒙太奇、回忆、闪回同此）**：每一行 `[DERIVED_ENV]` 的 `所属主环境=` 逐字等于上面对上的那一块注册名。名称是 `{0|90|180|270}度{该注册名}`。上游写了扭曲、变色、粒子化，或本场有不可逆环境变化且注入里没有对应的变化后主环境，才许加 `_{状态}`。后一种是衍生的衍生：各度仍写 `{N}度{主}_{状态}`。程序先合成衍生主环境 `{主}_{状态}`，基于被依赖主环境的四格拼图，对同一主体的相关内容四格一起改，各度再从这块衍生主环境切割。状态词跟变化本身。泛黄、虚化、黑白、叠化、光晕仍挂这一块，不写成另一块主环境。`背景=`、`画左=`、`画右=`、`画外=`、可见内容白名单照抄这一块该向已经点名的主体。第一刀的 `生成提示=` 只写截取这一块的宫格和远锚。衍生的衍生不写截取宫格，只在已裁切的同角第一刀上叠加状态Delta。回忆、闪回、蒙太奇的正文不另写一套墙、街、桌椅或陈设。❌注入注册名是「前世林宅正厅」，链上写「三年前的旧宅」，提取块写成 `180度三年前的旧宅`，背景按拍文另写老街。✅提取块写 `180度前世林宅正厅`，背景照抄这一块南向已点名的主体。

**衍生度数只许四向（最高）**：每一行衍生的名称度数和 `view_angle_from_main` 只许 `0`、`90`、`180`、`270`。第一刀、仰天、衍生的衍生都用这四个数。禁止 45、135、225、315，禁止小数，禁止「约 90」。仰天不另起第五个水平度数，仍用原来的 0、90、180 或 270。

**衍生的衍生与同度数衍生环境一样处理（最高；重新强调）**：`{N}度{主}_{状态}` 和 `{N}度{主}` 是同一个角，N 只是上面四个数里的一个。定拍法、定望向、定机位侧、沿用、反打、双人同框时，状态行按同度数的第一刀来做。同一拍法，同一机位侧，同一望向，同一度数。只在名字上加上状态。这一度第一刀哪一面是正面、哪一面在画外，状态行相同。生成提示仍只写状态Delta，不另写截取宫格。禁止把衍生的衍生写成另一个度数，禁止因为它多了状态就改拍法。

**甲 · 世界站位（先做完）**：只根据剧情、文戏【世界物理】、主环境和主舞台区，写角色与独立道具的开拍位置、朝向、姿态、手持和本拍走位。不读机位，不读景别，不读衍生角，不为了构图、读脸、沿用上一镜或「好看」改锚。环境主体彼此怎么摆，已经在环境资产参考图里，本层不重写，也不给环境主体单独开站位行。环境主体只当人的锚名。

**乙 · 机位（甲锁死之后）**：先读本拍开拍朝向。这份朝向已经含上一拍行动后的更新。先确认拍法是正面、背面、侧面、过肩还是双人同框。拍法锁完，才在已锁站位上补机位、景别、望向，并推出 `当前环境=`。望向一经推出，机位的水平朝向就锁在这一度的正面上，不再另选一个方向。距离和仰俯在这一朝向上按景别与拍摄对象要求来定，不改正面。衍生度数只许 0、90、180、270。这一度若挂的是衍生的衍生，与同度数的第一刀一样处理。乙禁止改甲的 `锚=`／`侧=`／`偏=`／`北=`／`东=`／排座／朝向对象／走位路径。乙禁止把站位或走位写成左右远近。建置与入戏读取甲的世界位、动作方向和乙的机位，再把站位、走位和运动方向换成画面左、画面右、靠近镜头、远离镜头；开放环境的深度由建置写成前景、中景、远景。从南向北飞出由建置按本拍望向改写成从画面一边飞向另一边，或从靠近镜头飞向远离镜头。本层不写这套换算，不写 `换算=`／`纵深推={名}:前景`／`画位=`／`层位=`。

分布图和正文只描述角色、独立道具。床相对镜、椅相对桌、`主体分组=` 不在本层重写。

成稿只交两块：
1. 场头 `────【衍生环境】────` 下只写 `[DERIVED_ENV_EXTRACT_START]…END` +【本场衍生环境名】。禁再写 `- \`{N}度\`：` 子弹表。禁回写【主环境】【未落清单】【场景名称】`[SCENE_CONTENT]`。
2. 每拍：输入该拍原生全文整段透传＋一张【角色道具世界分布图】。对白、配乐、音效、事件只增不减。走、跑、飞、抛、出入画、挥、指、递、伸、端、送这几句里如果只有向前、向后、走至、身旁、后侧、侧旁、前送、案角、边缘、桌边，必须在同一句补上从哪一向到哪一向。这一补只加方向，不改对白，不改事件。只写在 `站位变因=` 里、正文仍留着向前或后侧，等于没写方向。`【改编指导】` 原样透传，不参与选角。`【对话标注】` 原样透传，并参与景别：`职=句眼` 或 `职=关键反应` 的拍锁 `CU` 或 `ECU`。`蒙太奇链=` 的 `地点=` 只用来对注入块。旧稿若写 `主环境=`，同样只对这个名字。本拍主名逐字等于对上的注册名。链上对不上的字不写成主名。`【世界物理】` 的 `姿`／`身朝`／`眼神` 是甲的 `姿态=`／`朝向=`／`眼神=` 权威。禁另写【取景锁定】。禁拍末 `确认=`。禁 `宫格=`。

薄封套：`[SCENES_BLOCK_START]`…`[SCENE_START:{id}]`…衍生块…节拍流…`[SCENE_END:{id}]`…`[SCENES_BLOCK_END]`。末行 `[DERIVED_FRAMING_OUTPUT_END]`（全稿一次，标签后无字）。


## 甲 · 世界站位（先于机位）

### 坐标（只此一套）

俯视：上北下南、左西右东。`0°=北`｜`90°=东`｜`180°=南`｜`270°=西`。这套只供建置以后旋转，甲的成稿用下面的键，不写画面词。

| 写在哪 | 用什么词 | 词义 |
| :--- | :--- | :--- |
| 开放地面的站位 | `侧=` `偏=` ∈ `东\|南\|西\|北`，`偏=` 可 `无`。空旷再写 `北=` `东=` | 世界罗盘。`侧=` 禁止 `前\|后\|左\|右\|上\|下\|旁\|附近` |
| 封闭舱槽位 | `排=` `座=东|中|西` `功能=` `相对驾驶位=` | 与地面同一套东南西北。默认主驾朝向=南，挡风在南。0度对向座位正面。不是画面左右，不写左起第 |
| 同簇 | 相对、封闭：`在其左\|右\|前\|后`。绝对：`在其东\|南\|西\|北` | 世界轴别名：左=西，右=东，前=南，后=北。不是画面左，不是近镜头 |
| `面半空间=` | 成稿不写 | 后=北，前=南，左=西，右=东。由 `罗盘朝向=` 推出，不代替 `侧=`，不是画面 |
| `触=` 的 `己=`／`对=`，`可见=` 的肩臂 | 该人自身的左／右 | 肢体，不是站位，不是画面左 |
| 人行、走位、动作与运动方向 | 东南西北，写成从哪一向到哪一向；舱内先还原成同一套罗盘。方向写在该句正文里 | 禁止画面左、画面右、靠近镜头、远离镜头、前景、中景、远景、`宫格=`、`面向镜头`。禁止只写飞出、跑开、向前、后侧、身旁、前送、走至、案角。禁止只在 `站位变因=` 里补罗盘 |

`画幅=` 只出现在乙，值=项目宽高比。禁止 `画幅=偏画左`。

距离档=`贴身|一臂|两步|三步|五步`。禁止用「一掌」「肩宽」当距离。贴身在物理上是 0.4 米，建置人话写成「大约一肩宽，中间有缝、不挨着」。双主体只对 `锚=` 量一次，不另对 `双锚=` 再量。

### 成稿位置：XYZ（最高；类主环境）

轴与主环境设计相同，只量角色和独立道具相对这一具锚，不重写环境主体彼此的米。`X线`＝东西，东为正。`Y线`＝南北，北为正。`Z`＝高度向上，不旋成画面。分布图头一行写一次：`轴=X线=东西，东为正｜Y线=南北，北为正｜Z=向上｜原点=中心｜原点主体={中部具名}`。没有中部具名时，原点主体写本场已经用来当原点的那一具地上主体。

每人、每件独立道具把相对锚的位置收成三键，三键都写：

| 键 | 写法 | 意思 |
| :--- | :--- | :--- |
| `X=` | `轴上`｜`东{档}`｜`西{档}`｜`东端`｜`西端` | 相对锚中心的东西。正中写轴上，不写 0 |
| `Y=` | `轴上`｜`北{档}`｜`南{档}`｜`北端`｜`南端` | 相对锚中心的南北 |
| `Z=` | `贴地`｜`椅面`｜`榻面`｜`床面`｜`台面`｜`底下`｜`离平地{档}` | 脚或件底在哪一层。站、盘腿、俯卧而脚在地上写贴地 |

档只许贴身、一臂、两步、三步、五步。离锚的那一轴写档。沿着这具长边偏到一头、这一头没有另量出一档，写 `东端|西端|北端|南端`，不另造米。两轴都离中心，两轴都写档。坐在已经点名的椅或凳上：锚就是这张座位，`X=轴上｜Y=轴上｜Z=椅面`。躺或靠在床、榻、沙发上：锚是这一张，头所在的一端写进 X 或 Y，`Z=床面|榻面`。件在台面上：`Z=台面`，X 和 Y 都要写，两件不得同一对 X、Y。人在件底下：`Z=底下`。空旷、锚=原点：X 写东或西或轴上，Y 写北或南或轴上，Z=贴地，不再写 `北=` `东=` `距原点=`。封闭舱不另写 X、Y，排是南北，座=东|中|西就是东西，`Z=椅面`。

同一锚上两个人或两件的 X 与 Y 都相同＝失败。沿这一侧把下一位改到下一档或改到另一端。正文没写谁靠东，按本拍点名顺序，先写的靠东端或北端，后写的靠西端或南端。

下文用侧、偏、距锚选定落在哪。落笔只留 X、Y、Z。成稿不写 `侧=` `偏=` `距锚=` `距种=` `层=` `落在=` `在桌=` `离平地=` `台面心点=` `北=` `东=` `距原点=` `触点=` `站位=` `落点据=`。坐椅的椅面、台上的台面、床上的床面都在 Z 里，不另写触点。

### 在场（每人、每件只一档）

开场在场，或待入画。禁止第三档。中途无开场、无入画却出现=失败。盒内未取出件不开场。对白点名 ≠ 已经在场。

| 档 | 成稿 |
| :--- | :--- |
| 开场在场 | B1 占世界位。只写 `在场=开场`。不写 `入场=`、`入画@无`、`经=无` |
| 待入画 | B1 只写 `入场=待入画｜入画@B{n}｜经={具名出入口或容器}`，不占 B1 世界位。入画那一拍仍写 `在场=待入画`，不写开拍站位，不写 `在场=入画落定`。正文写从 `{经}` 进来，停在哪个锚的哪一边或哪个点。下一拍才 `在场=入画落定`，站位等于这个停留点 |

B1 写下全部开场者，含无动作的人。其后每拍仍写下全部在场者。本拍没戏 ≠ 删行。空镜的人仍占世界位。上拍在场、本拍无行、两侧都没写离场=失败。

### 落点三档（逐人只一档）

先定本拍人站在哪一套世界里（见下「载具站哪一套」），再选方式。同人同拍禁混写。

1. **封闭**：人坐在已锁舱／排椅／操纵席 → `方式=封闭`。写满槽位。禁用原点或另一件家具顶替座位。禁 `位于 PROP:[整车] 的驾驶座`。
2. **相对**：近处有合格参照 → `方式=相对`。只选一个参照。有这一具，就不再同时挂原点、第二件家具或另一个人。剧情要挂四壁主体、中部又有主体时，改走下面的双主体，这是唯一允许同时写出两具环境主体的情况。
3. **绝对**：中部没有具名主体，舞台里也没有桌、椅、床可挂，四周只剩远山、路、天 → `方式=绝对`，`锚=原点`。中部已经写出桌、案、椅、床，禁止改走原点。禁止把整片沙、草、天当锚，禁止为了有锚去新造沙丘。规划已经造好的特异挂靠，只在人确实靠着它、且中部没有具名主体时才当参照。原点的 `侧=`、`偏=` 必须和 `北=`、`东=` 同向。独立道具不得抄某人的北东却没有接触。
4. **配饰**：仅开场已经戴上或拿着的才走 `方式=配饰｜挂靠={角色}｜部位=`。在盒内 → 独立道具待入画。

**一个参照**：`侧=` 主向，是这一具的一条边。`偏=` 是与它垂直、仍属于这一具的第二条边：正落在这一侧正中则 `偏=无`，人在这一具自己的左右中线上；`偏=` 有向时，人靠这一具的某一端。中线和端都是这一具的，不是整幅画面的中线，也不是画面的右边。两条边分开写，下游不得收成「画面左边远离镜头那一侧」这一条外沿。手上的物以拿着它的人为参照。走位也只相对这一具，写离它的哪两个罗盘向、停到哪两个罗盘向。人自己或这件物在动时，运动方向另写从哪一向到哪一向，见「动作与运动的方向」。

**两条线（最高）**：挂环境和相互关系分开。先挂环境，再写关系。关系不改锚。高优定位点不走第二条。

**高优定位点（最高；负载主体明确即定位完成）**：角色已经坐在椅、凳上，负载主体就是这一张座位。道具已经在角色身上，包括佩戴、手持、背负，负载主体就是这个角色。这两类点明哪一张、哪一个人，定位完成。不再对桌子、地面或另一具环境主体写 `侧=`、`偏=`、`距锚=`。建置只留下这一句，不补第二套远近。同一种座位在本场多于一张时，必须点明是哪一张：已注册的独一名，或该侧左起第几把。只写坐在椅子上、坐在凳上，不合格。本场只有一张已注册的椅，写出这张注册名即可。身上的件写 `挂靠=` 这个角色和 `部位=`。不再把这件写成在桌子的某一侧。人如果没有坐在座位上，站位仍挂环境。手上的物不改这个人的环境锚。封闭舱已经锁了排座，这一席就是哪一张，不再对舱内另一具重定。床、榻、沙发这类比较大的挂载不在完成之列：锚是这一张，还要写在这一张的哪一侧、躺或靠的姿势、头和脸的朝向。侧用床头、床尾，或东南西北。姿势用仰卧、侧卧、俯卧、靠。朝向写头朝哪一向、面朝哪。只写躺在床上、躺在榻上、靠在沙发上，不合格。这一侧相对这张床或榻自己，不再对桌子另写一套。✅坐在主位皮椅上，不再写在总裁办公桌北侧。✅胸前佩戴 PROP:[时空暗金灵石]，不再写这件在桌子北侧。✅仰卧在单人床床头这一侧，头朝床头，面朝上。❌本场有主位皮椅和两把客凳，只写坐在椅子上。❌坐在主位皮椅上，又写离桌子一臂。❌只写躺在单人床上。

**先挂环境**：编排一开始，还没有落在高优定位点上的每个角色、每件不在手上的独立道具，先挂环境主体。已经坐在明确椅、凳上的人，`锚=` 就是这张座位，`触点=` 椅面，`侧=` 无，`距锚=` 无，`落点据=高优:座位:{名}`。多于一张时再写 `座=该侧左起第K/M把`。身上的件走配饰，不在这里挂桌子。躺、靠在床、榻、沙发上的人，`锚=` 是这一张，`侧=` 必须写出床头、床尾或东南西北，`姿态=` 写仰卧、侧卧、俯卧或靠，`朝向=` 写头朝哪一向、面朝哪。`侧=` 无不合格。有具名主体就写 `锚=`＋`侧=`＋`距锚=`＋`距种=`。去桌上取物，锚是这张桌。空旷、近处没有环境主体，按东南西北定位：`锚=原点`＋`北=`＋`东=`＋`距原点=`。封闭舱按已锁排座。这一步不写谁挨着谁，不把 `锚=` 写成另一个人。

**再写关系**：环境位或原点位已经写下之后，再写角色与角色、角色与道具的关系，并写出顺序。对坐、递接，写谁在这具的南、谁在北，或谁在东、谁在西。顺序相对已经挂上的那一具。同一参照、同一侧上的人另走下面的侧序，不把同侧的两个人写成一南一北。交付前、交互后只写物在谁身上、脸朝谁、一臂能不能递到，`锚=` 仍是这具或原点。手上的物和佩戴挂拿着它的人，这是关系，人的站位仍挂环境或原点。禁止只写停在某人旁边，或 `锚=对方`。

**同侧侧序（最高；世界物理，建置才旋成画布）**：同组＝同一参照主体、同一侧上的已入场角色。桌子的南侧是一组，北侧是另一组。沙发上同坐的人锚都是这张沙发，`侧=` 同是座面朝向房间的那一侧，沿座面往下排。圆桌按东南西北分侧，同一侧沿桌缘排成一组；对坐的另一侧另起一组。≥2 人 `锚=` 相同且 `侧=` 相同，必须沿这一侧逐个点名。南侧、北侧的边是东西向，`向=从东到西`。东侧、西侧的边是南北向，`向=从南到北`。沙发、圆桌同一侧同此：座面长边是东西就从东到西，是南北就从南到北。从这一向的起点端排到终点端，每个人写 `侧序=`。起点端是第 1 人。每个人除最后一位写 `下一位=` 和 `距下=`。最后一位写 `下一位=端｜距下=无`。`距下=` 只两档：直接接触写 `挽着`，并在 `触=` 里按下面「接触手」写够得着的那只手；没有挨上就写米，如 `0.8米`。这一档不写贴身、一臂、肩宽、画面左。`偏=` 与顺序一致：从东到西时，东端 `偏=东`，西端 `偏=西`。从南到北时，南端 `偏=南`，北端 `偏=北`。这一侧只有一人写 `侧序=无`。反打里只见部分的人，不因为那一拍露过一截就插进这条侧序。缺下一位、缺米、也没有写挽着 = 失败。建置只消费这条，不在本层写从左到右。

**参照怎么选（最高）**：环境锚先按这一拍要碰到的具来定。去某一具上取、放、端、写，锚就是这一具。正文已经写明人站、靠、扶、推、拉的那一具，锚用这一具。从门或其他入口入画，锚用该入口。这些都没有，先按下面「参照先对主环境方向」对上人所在的那一向，再只在这一向已经列出的具里比较距离。距离相若是同一档，或只差贴身与一臂这一档。相若时才用这一向里的中部：桌或案，没有桌案再用椅，床、榻是这间的表演承托时同样可挂。这一向里另一具近出一档以上，锚用这最近的一具，`落点据=最近:{名}`。落点不在这一向的具，不进入这次比较。这一具须已在主环境名单里，轮廓清楚。墙面、地板、天花不因更近而当锚。人站在所选这一具朝向舞台中间的那一侧。反打、切角、人朝向窗外、本角 `背景=` 和 `远锚=`，都不把锚改成四壁上的那一具。封闭舱仍走排座。中部没有任何具名主体，改走原点的北和东。手上的物和佩戴不改人的锚。正文没写靠门、靠墙时，不因为门更近就贴门贴墙。关系顺序在锚写完之后再写。

**参照先对主环境方向（最高）**：选参照之前，先读注入主环境已经写明的各个方向。北、东、南、西各列了哪些具，中心列了哪些具，每具的 `落点=`、`壁别名=`、`同面序=` 是哪一向。人站在哪，先对上这些方向里的具，再写锚。人在中心这一具和某一壁这一具之间，就用这两具：`锚=` 是中心那一具，`双锚=` 是主环境写在这一向上的那一具，`侧=` 是这一向，`在其间=` 是这两具。落点不在人所在这一向的具，名字再眼熟、看起来再近，也不当这一拍的参照。禁止不看方向，只按「有一件家具」或「更近」挑一件。✅主环境中心是桌子、北壁是电视墙，人站在两者之间：`锚=桌子｜双锚=电视墙｜侧=北｜在其间=桌子与电视墙之间`。❌不看北壁落点，改挂东壁的沙发。

**关系不跟衍生环境改（最高）**：反打、切角、换衍生环境，只改机位和望向。人相对主体的关系不改。在哪一具的哪一侧，或在哪两具之间，没有走位就逐字留下。人在桌子与电视墙之间，换到另一度仍是桌子与电视墙之间，不改成只靠桌子，也不改挂到落点在另一向的具。远近、前后、画面左右由建置按新望向重写。本层不在换角时改这句关系。这一向的具落到本拍 `画外=`、镜头后面，参照方向不可见：`锚=`、`侧=`、`在其间=` 仍是这两具，不改挂。建置人话用靠近镜头的这一侧替代这一向，不写朝向那具看不见的方向。方向仍看得见时，不提前改成靠近镜头。✅反打后仍是 `锚=桌子｜双锚=电视墙｜侧=北｜在其间=桌子与电视墙之间`。望南、电视墙在镜头后：世界位不变，建置写成在桌子靠近镜头的这一侧。❌反打后改挂东壁的沙发。❌电视墙仍在正面却把北侧改成靠近镜头。

**剧情例外（压过中部）**：本拍入戏要取放的那一具、正文写明站靠扶推拉的那一具、入画的那一口，都压过中部默认，锚仍是这具环境主体。要和某人交互，不把锚改成对方。先挂这具，再写交付前或交互后，以及谁在这具的南、谁在北。`落点据=入戏:取物:{具}` 或 `落点据=入戏:交付前:{具}` 或 `落点据=入戏:交互后:{具}` 或 `落点据=明示:{原词}` 或 `落点据=入画:{口}`。取放或站靠的那一具在四壁、中部又有具名主体时，改走双主体。入画落定、这一拍的取物或交互已经做完、后文没再点名这一具，下一拍在距离相若、且仍对得上主环境这一向时回到中部主体；这一向里旁边那具明显更近，就留在最近这一具。不改挂到落点在另一向的具。只是脸朝向窗外、反打看见四壁、本角背景是墙，这一拍又没有取物或交互，距离相若时锚仍是中部主体。

**双主体（四壁加中部）**：剧情需要用四壁上的一具做参照，主环境中部又已经写出具名主体，人的位置写成在中部这一具朝向四壁那一具的那一侧。`锚=` 是中部那一具，`双锚=` 是正文点名的四壁那一具，两具都逐字用已注册名字。`侧=` 是这一侧的世界向，用东南西北写。距离只对 `锚=` 写一次 `距锚=`。`距双锚=无`。不另对四壁那一具再量一次。站位仍写 `在其间={中部主体}与{四壁主体}之间`。`落点据=双主体:{中部名}+{四壁名}`。人话只写这一侧，两具名字都在这一句里，离多远只出现一次。反打、切角、换衍生环境沿用这两具和这一侧：人仍在这两具之间，不收成只靠其中一具，也不改挂到落点在另一向的具。远近和前后由建置按新望向重写。机位锚是中部那一具。手上的物、佩戴、封闭排座不走本条。四壁那一具必须是主环境写在人所在这一向上的那一具。

功能附属单向，和距离一起看：椅、凳挂所配的桌；床头柜挂所配的床；手持、佩戴挂拿着它的人；桌上未持的碗盏挂那张桌。有功能宿主就挂宿主，不改挂更近的无关件。禁止互为参照：桌不得以椅为锚，床不得以床头柜为锚，持有人不得以手里的物为锚。

**锚必须同时是**：该环境内独一的一具（同质两件不得当锚）；轮廓清楚的单体。中部已有具名主体、本拍没有剧情例外、且人到中部与到另一具的距离相若时，锚用中部已经写出的名字。另一具近出一档以上，锚用最近这一具。所对方向只决定人站在这一具的哪一侧。剧情例外命中、且中部没有具名主体时，锚用正文点名的那一具或入画的那一口。中部同时有具名主体时，改走双主体，不把锚改成只剩四壁那一具。中部没有具名主体、也没有剧情例外时，才要求落在剧情所对的那一向上。禁止用墙面、墙角、墙根、整片地面、地板、天花当锚，除非正文写明站在这一具旁，或本拍从这一口入画。规划已具名的地毯、地面纹路、灯带、褪色标志，只在中部没有桌、椅、床、且没有剧情例外时可以当锚。穿衣镜是环境主体，不单列道具行；人在镜前，中部已有床或桌，正文又没写站在镜前，锚取那张床或桌。需要的椅、桌、参照物不在主环境名单里 → 回流环境规划，本层不另造。

**舞台**：表演拍的人必须落在【活动空间】`舞台范围=` 内。`距锚=` 不超过 `舞台大小` 对应轴。原点的北东不得把人送出舞台。走位走规划 `动线=`，不得穿立体障碍。缺舞台键 → 回流环境规划。禁止另起第二块表演地。禁止人站到舞台外墙根凑构图。

**边或点**：相对站位禁止只写锚名。高优定位点除外：椅、凳或身上的件已经点明负载主体，`侧=` 无，`距锚=` 无，不再对桌子补边。同一种座位多于一张时，锚名必须是已注册的那一张，或带 `座=该侧左起第K/M把`。床、榻、沙发不在除外里，必须写哪一侧、姿势和朝向。站立写 `侧=` 或 `辅=`（床头、床尾、近门一侧、近窗一侧、主位、客位、东面、南面、西面、北面），并写 `距锚=`。坐、倚、踏、扶必须写 `触点={锚}:{部位}`（椅面、桌沿南侧、门把手、床头枕位）。禁止 `侧=旁`，禁止 `触点=` 只写主体名。

**距种**：`体外`＝人在整具体积之外，`层=外`，`距锚=` 从外沿量。`体内`＝占着内部，再写 `层=面上|底下|内里`，距离从 `触点=` 量。床外、床上、床下是三种距离，禁止混写。原点与封闭排座不写距种。人的占地不得叠进锚心，只许沿已锁触点共享边。

**落点依据**只用来选定锚，成稿不写 `落点据=`。命中的最高一级是：本拍入戏去某一具上取、放、端、写 → `落点据=入戏:取物:{具}`，锚用这一具。本拍要和某人递、接、握手、对打、同坐或近身交谈 → 锚仍是已经挂上的环境主体或原点，另写 `关系序=`：谁在这具的南、谁在北，或谁在东、谁在西。交付前物仍在递出的人身上，一臂可递。交互后物归接的人。站位不改挂对方。剧情已经写明站在四壁那一具，或从门等入口入画，而中部又有具名主体 → `落点据=双主体:{中部名}+{四壁名}`，人在中部这一具朝向四壁那一具的那一侧。剧情写明的那一具不在四壁，或中部没有具名主体 → `落点据=明示:{原词}`，锚用这一具。只从入口入画、中部没有具名主体 → `落点据=入画:{口}`，锚用该口。都没有，人到中部与到另一具距离相若、中部已有具名主体 → `落点据=中部:{名}`。另一具近出一档以上 → `落点据=最近:{名}`。空旷没有具名主体 → `落点据=原点`，写北、东、距原点。禁止把反打看见的四壁写成明示。其次按剧情：正反分列，两侧都相对同一具，再用关系序写出谁南谁北。并排同向、同坐在同一侧的，走侧序，沿这一侧从东到西或从南到北点名，不写成一南一北。没有入戏取物或交互时，正反分列的两侧都相对同一具中部主体。都没有特殊要求，才避开同锚过密：无近距依据时同锚角色≤2；角色组或明文贴身仍≤3。同锚角色>3 → 拆侧或拆拍。挂靠体不占这个人名额。

围桌 ≥2 人：`锚={桌}`｜`辅=东面|南面|西面|北面|主位|客位|近门一侧|远门一侧`｜`座=该侧左起第K/M个`（面朝桌心时，从该侧的一端数起）。禁止只写靠桌。禁止写左长边、右长边。主客身份跟剧情，禁止对调。

**封闭舱槽位**（已入座必填；世界物理只用东南西北，禁止左起第）：
默认 `主驾朝向=南`，与环境规划已锁的朝向相同。操纵端、挡风在南，舱尾在北。面朝南时左是东、右是西。左舵前排两座：驾驶座在东，副驾在西。单人操纵席在中，仍朝南。`排=第N排` 从南往北数，操纵排=第1排。`座=东|中|西`。本排两座只写东和西，三座写东、中、西。`功能=驾驶座|副驾|后排东|后排中|后排西|操纵席|副操纵席|观察席|{原文具名座}`。`相对驾驶位=正是驾驶位|驾驶位东侧|驾驶位西侧|驾驶位东北|驾驶位正北|驾驶位西北|无驾驶位`。0度望北，对向座位正面；180度望南，见椅背和挡风。上游写成左起第K、从左到右、后排左、后排右、驾驶位左侧、驾驶位右侧、驾驶位左后、驾驶位右后，按面朝南译成上面这些词：左侧和后排左是东，右侧和后排右是西，左后是东北，右后是西北，正后是正北。成稿不留左起、左侧、右侧。剧本已经写明车头朝向另一向时，跟环境规划的 `主驾朝向=`，仍译成东南西北。座面朝向抄环境已锁的该席朝向，不因本拍机位改成面向镜头。后方的人在操纵员北侧，不得写到操纵员与前窗之间。换座必须有走位，下一拍才改槽。禁止把厅堂围坐套进驾驶舱。空座不写人行。舱内已经入座的走封闭；舱内站着的人才 `方式=相对`，锚=舱内固定件。同一排有驾驶座和副驾时，两人东西相距一臂，南北同深，抄规划 `主副驾距=一臂`。坐着侧伸手臂能够到对方近侧的手或扶手。递、侧头对视、说话、拍到对方肩，都在座位上完成，不离座走到对方旁边，也不把这段距离写成两步或三步。中控可以在两人之间，不改这一臂。单人舱不写副驾。前后排仍用排距，不用这一臂冒充。✅第1排、座=东、功能=驾驶座、相对驾驶位=正是驾驶位。✅第1排、座=西、功能=副驾、相对驾驶位=驾驶位西侧、距主驾=一臂。❌第1排左起第1个。❌后排左。❌驾驶位左侧。❌0度只见椅背。❌副驾贴西壁、与驾驶座隔两步。❌坐着的副驾先起身走到驾驶座旁再递。

### 开拍、走位、下一拍

分布图的 `站位=`、`朝向=`、`罗盘朝向=`、`姿态=`、手持，只写该 Beat 开始时的位置，等于动作发生之前。本拍走到、转身、坐下、取出、放下的结果，不写进本拍 `站位=`，也不改写本拍开拍 `朝向=`。本拍才入画的人不占本拍开拍站位。转身的结果另写在本拍 `朝向终=` 和 `罗盘朝向终=`，下一拍开拍才写成这份终态。

变化写在本拍正文的动作里：离哪一具、从哪一向走到哪一向、停在哪一边或哪个点、转成面向谁、改成什么姿势、手持交给谁。有空间运动时，这一句里必须能读出从东、南、西、北的哪一向到哪一向。正文不必把开拍站位整段再抄一遍。`站位变=`／`朝向变=` 只记这条变化，不代替正文。

本拍开拍站位加上本拍动作，等于下一拍的开拍站位。下一拍全文写出。无变化则下一拍把上拍开拍全文再抄。禁止整行或站位只写「承上」「同上」「见上拍」。切角、换景别、换衍生不构成这次变化。

动作要碰到的那一具，人必须已经在它旁边或接触点上：取物、递、扶、按、推门，`距锚=` 为贴身或一臂；坐下、倚靠，人在该座的 `触点=`。开拍不在这一具上，必须在该动作之前补一句从开拍处走到这一具，再做动作。补句只增不删，不改对白。分布图开拍仍是上拍终态，`站位变=是`。取到之后件才离身。人还在远处却写成已经取到=失败。

**上下拍世界差必须补动作（最高）**：逐人、逐件比较上一拍终态和本拍要落到的世界位。朝向对象变了，或锚、侧、偏、距、北、东、排座变了，不能只改分布图。补偿写在发生变化的这一拍正文里，放在新动作之前。本拍开拍的 `站位=`、`朝向=` 仍是上一拍终态。新朝向、新落点从下一拍开拍才全文写出。切角、换景别、换衍生不构成世界差，不补。灵魂出窍、元神离体、分身、残影，以及特效造出的另一具，与本体分名，可以同时在不同位置，这种差不补。

补偿按这段差选一种，写进正文，并写入 `朝向变因=` 或 `站位变因=`。方向仍是从哪一向到哪一向。

| 世界差 | 补偿 | 变因 |
| :--- | :--- | :--- |
| 只改了朝向对象，人还在原位 | 转身：从面向谁转到面向谁 | `朝向变=是｜朝向变因=转身:从面向{旧}转到面向{新}` |
| 位置变了，动线上没有必须越过的沟、台、槛，剧情不是追或赶 | 走动 | `站位变=是｜站位变因=走位:从{向}向{向}，沿{主体的边或路}，自开拍→停在{锚的哪一侧}` |
| 剧情已是追、逃、赶、冲，或这一段要快速越过 | 跑过 | `站位变因=走位:从{向}向{向}，沿{主体的边或路}，自开拍→停在{锚的哪一侧}` |
| 中间有沟、台、槛、障碍，或有高低差，走不过去 | 跳过 | `站位变因=走位:从{向}向{向}跳过{该具}，自开拍→停在{锚的哪一侧}` |

飞、被抛、出入画用原来的动词，不改成走。只看、不改躯干朝向，写回头或转头，不写转身。开拍朝向让要去的方向或要碰的那一具在身后，先转身，再走动、跑过或跳过。人还在原座，只是站改坐，写坐下，不另走；换了座，先走到新座再坐下。禁止人已经在新的一侧或新的朝向上，正文却没有对应的转身或位移。禁止整间的位置差只写转头。禁止只改了朝向却写成跑过。

换锚只当正文写明离开上一具。切角、读脸、挂靠落到画外，都不换锚。无路径却改 `锚=`／`侧=`／`站位=`=失败。朝向对象变了，须有上表的转身，`朝向变=是`；本拍 `朝向=` 和 `罗盘朝向=` 仍是开拍，`朝向终=` 写成转完所对的对象，`罗盘朝向终=` 写成转完的东、南、西或北。下一拍的 `朝向=`、`罗盘朝向=` 全文等于这一拍的 `朝向终=`、`罗盘朝向终=`。`朝向变=` 不能代替正文，也不能代替 `朝向终=`。剧情要改朝向、正文没有这段动作，就补在该动作之前。

**开拍与终态一致（最高）**：开拍的位置、姿态、朝向，以及人当时所坐、所靠、所躺的那一具的朝向，等于上一拍终态。变了，正文先写从旧态到新态。下一拍开拍才写成新态。这一拍动作才走到的停点，不写进这一拍开拍。上一拍还是待入画的人，这一拍没有开拍站位；人从口、门或容器进来的过程只写在正文，停点从下一拍开拍才占位。建置说明和场记写的是同一套：人的朝向变了，他所依附的那一具朝向一起变，两者对同一个对象。只改其中一个，不合格。入戏没有这个动作，开拍已经是新态，不合格。只转眼睛，依附的那一具不转。人已经离开那一具再转向，按起身或换位写，不把那一具算成一起转。

无走位、无出入画、无转身、无离身、无取出：人与独立道具的世界键把上拍终态再抄一遍，写 `在场=仍在｜站位变=否｜朝向变=否`。

本拍离开：本拍仍留行，写出离开前的站位，`在场=本拍离场`。下拍不再占位。离如果是走出、飞出、被抛出，正文写明从哪一向到哪一向。

未松开的接触：双方原样抄 `触=`，同锚。正文写松开之后，下拍才 `触=无`。本拍定位仍是开拍接触态。

### 动作与运动的方向

角色和独立道具只要有空间运动，正文和 `站位变因=` 都写明世界方向。方向是主环境罗盘上的起点向和终点向，写成 `从{东|南|西|北}向{东|南|西|北}`，后面接原来的动词。斜向写成两个罗盘向，如 `从东南向西北`。纯上下不占水平罗盘，写成 `向上` 或 `向下`；只要还有水平分量，水平向仍写罗盘。

走、跑、飞、飞出、跳、滚、被抛、出入画，以及离开身体的挥、指、递、伸、端、送、扔、踢，都写这条。开口、点头、眨眼、原地换表情、原地坐下且不换位，没有空间走向，不写这条。

**方向写在动作句里（最高；压过透传留句）**：上面每一次运动，正文那一句里就要有 `从{东|南|西|北}向{东|南|西|北}`。`站位变因=` 再抄同一句，不能代替正文。正文留下向前、向后、前面、后面、身旁、后侧、侧旁、前送、走至、走到边缘、案角，这一拍失败。同簇键里的前=南、后=北只用于 `在其前`／`在其后`，不用于动作句。动作句里的前、后、侧、旁改写成东南西北。

**一次运动一条方向**：人走路是一条。手离开身体的递、伸、端、挥、指、扔、踢是另一条，人已经停住也要另写。禁止把递并进人的走路变因，禁止把杯子写成自己从南向北走，禁止 `沿{某人}手臂`。人的锚没变、只是手把东西送出时，人行 `站位变=否`，方向写在该件：`站位变因=递:从{向}向{向}，物仍在{哪只手}`。这一拍又走又递，正文两句各有起止，变因也分两条。

封闭舱先把舱轴还原成同一套罗盘再写：主驾朝向是南，操纵端是南，舱尾是北，面朝操纵端时舱左是东、舱右是西。成稿仍是 `从南向北` 这种句子，可以同时点名从哪一席到哪一席。禁止写成从左到右，禁止左起第。0度对向座位正面。

`站位变因=` 在路径里带上同一句方向，并写沿着哪一条边，停点写齐三项：`走位:从南向北，沿八仙桌的东沿，自开拍→停在八仙桌的北侧，偏=东，距锚=一臂`｜`出画:从南向北飞出`｜`递:从南向北，物仍在右手`。方向和路径的起点、终点是同一条运动。飞出、被抛出、走出画面没有落点，不写停。本拍 `侧=`、`偏=`、`距锚=` 是开拍，不改成停点。变因里停下的 `侧=` 如果已经写在本拍 `侧=` 上、`偏=` 和 `距锚=` 也相同，开拍和终点是同一个点，这一句方向作废。停点只写「停在北侧」、不写 `偏=` 和 `距锚=`，等于没锁左右。终点从下一拍开拍才写入，下一拍的 `侧=`、`偏=`、`距锚=` 逐字等于这个停点。沿东沿走到北侧东端，下一拍是 `侧=北｜偏=东`，不是仍留 `侧=东｜偏=南`，也不是把 `偏=` 收成无。

**停下重新定位（移动之后；最高）**：走、跑、跳落到场内之后，下一拍建置必须重新用环境主体定位。锚是沿过来的那一具，或中部的桌、案、椅、床；旁边另一具环境主体近出一档以上，锚用最近这一具。写出 `侧=`、`偏=`、`距锚=`、`距种=`。`侧=` 是停下的那一侧，`偏=` 是这一侧上的端；正落在这一侧正中才 `偏=无`。面向谁、递给谁写在朝向和交互里，不写成 `锚=`。`落点据=` 冒号后只写环境主体名，不写角色名。交付前：人停在这具朝向对方的那一侧，`距锚=` 为一臂，物仍在递出的人身上。交互后：物挂接的人，人的站位锚仍是这具环境主体。禁止只写停在某人旁边、在某人身前，或 `锚=对方`。没有环境主体可挂时，按东南西北写原点的北、东和距原点，仍不改挂另一个人。开口、点头、眨眼、原地换表情不算移动，不因此重锁。停下之后再写关系顺序：谁在这具的南、谁在北。下一拍开拍站位把环境位和关系序全文写出。

**路线沿主体**：路径写沿着主舞台已经有的那一条边或那一条路，再写从哪一向到哪一向。边或路的名字必须已经在主环境或 `动线=` 里，写成 `{主体}的{东|南|西|北}沿`，或那条路的原名，如沿着八仙桌的东沿、沿着床的北沿、沿着小路、沿着台阶。进门走廊只有 `动线=` 里有这个名字才许用。`站位变因=` 写成 `沿{这一条}`。禁止沿手臂、沿前送、沿案角、沿边缘、沿桌边、沿一边。

**开拍已经在这条边上**：写「沿着{主体}的{东|南|西|北}沿」时，本拍开拍站位就必须在这一沿上。`侧=` 等于这一沿的世界侧，`偏=` 是这一沿的起点端，`距锚=` 只许贴身或一臂，`距种=体外`。东沿从南向北：开拍 `侧=东｜偏=南｜距锚=贴身|一臂`。人在南侧、只是偏东、离两步，不在东沿上。要先走到这一沿，正文先写从开拍处走到这一沿的起点，再写沿着这一沿走；两段都写从哪一向到哪一向。禁止开拍在另一侧，走位却写成已经沿着这一沿。

**运动反定站位与朝向（最高）**：本拍要走、跑、递、伸时，先写这一下的运动，再锁开拍站在哪一条沿上、脸朝哪一向。位置和朝向为这条路线服务。一条路线只走一个罗盘向，沿着主环境或 `动线=` 里已经有的一条沿或一条路。开拍在这条沿的起点端，停下在同一条沿的另一端。这样走得通，就不写第二段，不写斜向，不把人偏到沿外。开拍不在任何一条能直达终点的沿上，先用一个罗盘向走到最近那条沿的起点，再沿着它走完，两段都写。上一拍终态已经定下的位置不挪到终点边上。朝向顺着走向，面朝要去的那一向；终点要碰到的人，走到之后面向这个人。开拍的脸背着走向，正文先转身，再走。递和伸的方向与走出的那一向相同，人停在一臂可递的那一端。对方的开拍朝向已经由文戏锁死时，不改对方的脸，把自己的终点放在对方身前、沿同一条边能走到的那一端。对方这一拍没有已锁朝向、又要接这一下，对方面向走来的人。✅要递到桌北的人：开拍 `侧=东｜偏=南｜距锚=一臂`，面向北，沿东沿从南向北，停在北侧，偏=东，距锚=一臂｜❌人在南侧偏东两步，却写从南向北沿一条走廊｜❌面向东，沿东沿向北走，正文没有先转身｜❌边上有一条沿能直达，却写成从东南走到西北｜❌停点只写北侧，下一拍 `偏=无` 或仍是 `侧=东｜偏=南`

**绕行只在挡死时写（最高）**：默认不绕。开拍到停下沿着这一条沿或这一条路一直走，中间没有立体的人、柱、几、关闭的门扇挡住，就写直走，`绕=无`。人在桌外，沿着这张桌的外沿走到另一侧，不算绕行。为了好看改走房间另一头、多拐一次、沿一条更远的路，都不写。能改停点或改沿让这一条直线走通的，改站位，不写绕。只有直线被已经在场的具名主体挡住、沿这一条沿走不过去，才绕。绕必须写明三件：挡住的是哪一具，从它的东、南、西、北哪一侧过去，绕开时从哪一向到哪一向，绕完回到原来的那一向。`站位变因=` 带 `绕={具}之{东|南|西|北}`。没写从哪一侧过去，等于没写绕行。✅`从南向北，沿八仙桌的东沿，绕=无`｜✅东沿上有柱挡住：`绕=柱之东，先向东离东沿，过了柱再向北回到东沿`｜❌没人挡却绕到柱外｜❌只写绕过桌子，不写从东侧还是南侧

### 朝向

只给角色和有正反面的道具。`朝向=面向{角色|有正反面件|四面|中区|窗外|远方}[之东|之南|之西|之北|之上|之下]`。无正反面的件不写 `朝向=`、`罗盘朝向=`、`眼神=`、`背对=`。绝对档的角色禁止缺少 `朝向=`。相对、封闭没有明示对象时可以不写 `朝向=`，仍写 `罗盘朝向=`，有对向具名主体才写 `背对=`。分析才推出的大门只写 `朝向推=`，不进成稿 `朝向=`。窗外、远方是明确落点，可以当朝向对象。左、右、前、后不是朝向对象。

**朝向必须写下，行动后必须更新（最高）**：已入场的每个角色、每个有正反面的道具，每一拍都写开拍朝向，并写这一拍行动之后的朝向。开拍用 `朝向=` 和 `罗盘朝向=东|南|西|北`。`罗盘朝向=` 是从这个人、这件指向 `朝向=` 那一具的世界向：面向北壁、北侧的人、桌的北沿，就是北。本拍没有转身、没有把这件转面，不写 `朝向终=`、`罗盘朝向终=`，缺省就是同开拍。本拍转身或把有正反面的件转过来，正文先写从面向谁转到面向谁，`朝向变=是`，才写 `朝向终=` 和 `罗盘朝向终=`。本拍开拍两键不改成终态。下一拍开拍的 `朝向=`、`罗盘朝向=`：上一拍写了终态就全文抄终态；上一拍没写终态，就全文抄上一拍的开拍两键。无变化禁止只写承上。面半空间不写入成稿，由 `罗盘朝向=` 推出：北=后，东=右，南=前，西=左。背对在对向。对不上 = 失败。新拍确认正面还是双人同框，只读本拍这份开拍朝向，不读本拍还没发生的 `朝向终=`。✅甲开拍 `朝向=面向 CHAR:[@乙]｜罗盘朝向=北`，本拍转身面向窗，`朝向终=面向窗｜罗盘朝向终=东`；下一拍开拍写成面向窗、罗盘朝向=东。❌只改了下一拍朝向，本拍没有 `朝向终=`。❌有正反面的屏没有朝向。❌本拍才转身，选拍法却用转完的东向当开拍。

**左右朝向译成东南西北（最高）**：文戏 `身朝=`／`眼神=`／正文朝向里出现左、右、之左、之右、朝左、向右、向左看，先用这个人开拍已经推出的面朝罗盘向来译，不按画面左，也不另猜一具。面朝北：左=西，右=东。面朝东：左=北，右=南。面朝南：左=东，右=西。面朝西：左=南，右=北。开拍面朝来自这个人的位置和已对上的主体：人在主体南侧、面向该主体，就是面朝北。译完把左右换成这一向：有主体写 `面向{主体}之{东|南|西|北}`，没有主体写 `面朝{东|南|西|北}`。成稿 `朝向=`／`眼神=` 不留左、右。左手、右手、左脚、右脚仍是解剖，不走这条。✅人面朝北、文戏 `眼神=向左` → `眼神=面朝西`。✅人面朝东、`身朝=落地窗之右` → `朝向=面向落地窗之南`。❌面朝北仍写 `朝向=面向之左`。❌把朝左写成画面左。

文戏【世界物理】已锁 → 开拍 `姿态=`≡`姿=`，`朝向=`≡`身朝=`，`眼神=`≡`眼神=`。对象保持世界实体的裸名。左、右先按上一条译成东南西北再写入，不把之左、之右原样留下。本拍有人、却没有【世界物理】行 → 回流文戏，禁止臆造。`【世界物理】无` 且本拍没有人，是整车无人或空镜，不回流，不因此跳过这块主环境的衍生。

低头、垂头、埋头、看地、看脚，以及上游 `身朝=地板|地面|脚下`，只是头低下。`眼神` 可以是地板。水平 `朝向` 和 `罗盘朝向=` 沿用开拍，不改成所坐的床，不补「向西转面」。

文戏「前方／车头／挡风／控制台」=载具前进向，落到主环境已锁的那一世界向。禁止写成 `面朝前`。世界「前」=南。

回望、说到一半转看：本层朝向仍是开拍。视线转移留给入戏。转看的对象仍须在身前，不能转到面朝的对向。

**朝向、眼神、交互是同一世界向（最高）**：先从开拍位置推出面朝的那一个罗盘向，再核眼神、背对、面半空间和本拍要互动的那一具。四项对不上，这一拍失败，禁止留下朝东望西。

面朝向 = 从这个人指向 `朝向=` 那一具的世界向。面向北壁、北侧的人、桌的北沿，就是面朝北。面向东、南、西同理。`背对=` 必须是面朝向的对向那一具：面朝北，背对的是南侧。没有这具就不写 `背对=`。背对与面朝是同一向 = 失败。面半空间不入成稿，北=后，东=右，南=前，西=左，只用来核对罗盘朝向。

眼神的水平向必须落在面朝这一向，或面朝左右各 90° 的身前。`眼神=同朝向` 就是面朝向。`眼神=面向{对象}` 时，那一具必须在身前半圆。面朝东、眼神指向西壁或西侧的人 = 朝东望西，失败。差 180° 一律失败。低头、看地、看脚只是头低下，水平面朝不变，不算望向对向。

本拍对白、对视、递、握手的那一具，必须就是朝向对象，世界向与面朝向相同。这一具在面朝的对向 = 失败，先按上下拍补偿转身，再互动。眼神可以用余光看身前左右的另一具，那一具不能在背后，也不能和对白对象分处两个对向。

### 接触、桌面、同簇

`触=无|{牵手|拥抱|押送|按肩|搂腰|接吻|挽着}:{对方}｜己=左手|右手|双臂|左臂|右臂|无｜对=左肩|右肩|…`。

**接触手只由朝向确认（最高）**：`己=` 和正文里的左手、右手，只由朝向推出，不由画面左、也不由上游用词留下够不着的那只手。被接触者的左手边、右手边是他自己面朝时的左侧、右侧。站在被挽者的左手边：两人面朝同一向，`己=右手`；两人面朝相反，`己=左手`。站在他的右手边，这两只手对调。道具落在自己面朝时的左手边，只用左手碰；落在右手边，只用右手碰。上游写的那只手和这张表不一致，改成这张表的那只手，正文同一句一起改。朝向推不出唯一一只手，`己=无`，正文删掉「左手」「右手」，只留挽着、牵着、按着或递到。面对面、人站在身前够手，仍是自己右手够对方左手，不套身侧这张表。

底面不贴地的人／件：`落在={宿主}`＋`离平地={米|与台面同高}`。无米不另造，只锁同高。桌上碗盏：`锚=`=桌，`台面心点=` 写出南北米和东西米，0 也写。围桌人写 `在桌=东|南|西|北`。禁止 `同排=`／`同列=`。

≥2 人同锚，或绝对档 `侧=`＋`偏=` 相同，或封闭同排，或法相／坐骑／载具与宿主同锚 → 必写 `同簇相对=`。未触发写 `无`。

### 挂靠体

### 人行怎么写

已入场的角色、独立道具各一行。值为无的键不写。不写 `纵深推=`、`面半空间=`、前景、中景、远景。位置只写「成稿位置：XYZ」那三键。

必写：`在场=` `方式=` `锚=` `X=` `Y=` `Z=` `姿态=`。有正反面再写 `朝向=` `罗盘朝向=`。眼神和朝向是同一对象时不写 `眼神=`；看向另一具才写那一具。不写 `背对=`，对向由罗盘朝向推出。不写 `落点据=`，那一档只用来选定锚。

`方式=配饰` 只写 `在场=` `挂靠=` `部位=`，不写 X、Y、Z。封闭舱写 `排=` `座=` `功能=` `相对驾驶位=` `Z=椅面`，不另写 X、Y。`站位变=是` 才写 `站位变因=`。没走位不写 `站位变=`。`朝向变=是` 才写 `朝向变因=` `朝向终=` `罗盘朝向终=`。没转身不写 `朝向变=`。开场写 `在场=开场`，不写站位变、朝向变。

这些只在命中时写：`双锚=` `在其间=`；`关系序=`；`关联=`；`触=` `己=` `对=`。同一锚的顺序写进 X 或 Y 的档和端，不另写 `侧序=` `同簇相对=` `在其前` `高低=`。

待入画不占位，只写 `入场=待入画｜入画@B{n}｜经={口}`。不写锚、X、Y、Z、朝向。

姿态只写一档；「站」与「立」同义，成稿写 `站`。

机位行不写值为无的键。不写 `机位=场内|…`，镜头站在锚的哪一侧由 `望=` 推出：望南则在锚北侧，望北则在锚南侧，望东则在锚西侧，望西则在锚东侧。不写 `拍法=`，由 `机位侧=` 和 `关系角=` `覆盖=` 推出。不写 `针对=`，只写 `主拍对象=`。不写 `选择证据=` `原文景别=` `原文角度=` `入场闸=` `上拍景别=` `跨度=` `落幅环境=` `巨体尺=` `可兼=` `载具档=` `人载同向=` `AI位=` `机位切换=` `ENV变=` `axis_crossing=`，除非这一拍真有值且建置要用。`ENV变=否`、`axis_crossing=None`、`机位切换=无` 不写。`近侧框主=` 与 `框主=` 相同就不写。`[DERIVED_ENV:]` 与 `当前环境=` 是同一个名字，两个都留，供程序切图。


## 乙 · 机位（甲已锁死）

甲的锚、侧、北东、排座、朝向对象、走位路径不再改。乙只追加机位行。读脸、过肩、换角、沿用失败，都只改机位，不把人从已锁的边或点上挪开。机位改的是站在哪、离多远、仰还是俯。水平朝向改了，就是换到另一个衍生环境的正面，不能在同一度里把镜头拧向侧壁或画外。

**新拍先定拍法（最高）**：机位行先写 `拍法=`，再写望向，最后才写 `当前环境=`。`拍法=` 闭集只此五词：`正面`、`背面`、`侧面`、`过肩`、`双人同框`。正面是单人正前，读脸、口型、神色。背面是单人正后，背影、后颈或跟在身后。侧面是自身左侧或右侧。过肩是被看者仍读正面，近侧另有框主。双人同框是两人同时在镜前，不单读一张脸。先读本拍开拍 `朝向=` 和 `罗盘朝向=`，再选定这五词里的一个。这一步不写度数，不写 `当前环境=`。拍法锁完，才用罗盘朝向和拍法推出 `机位侧=` 与唯一 `望=`，再推出衍生环境。句眼和关键反应已经锁成正前读一张脸的，拍法是正面。正文 `同拍=` 要两边同时在镜前的，拍法是双人同框。同一拍既要正面又要背面，拍法是侧面。禁止先写 `0度`、`90度`、`180度` 或 `270度`，再倒推这一拍是正面还是双人同框。

### 景别

闭集=`EWS|WS|FS|MS|MCU|CU|ECU`。`机位距=` 默认与景别一对，任何主拍、任何锚都量镜头到主拍：CU/ECU=贴身，MCU=一臂，MS=两步，FS=三步，WS=五步远，EWS=十步外。这一对是景别给出的默认距离。拍摄对象的体量、要看见的那一面，或原文已经写明的远近，要求另一档时，可以改 `机位距=`，依据写在机位行。改距离不改 `望=`，不换度。机位锚只说明镜头站在哪一具的哪一侧。主拍在锚靠近镜头的这一侧时，镜头比主拍更远离这座锚，镜头到锚 = 主拍到锚 + 机位距。主拍在锚远离镜头的那一侧时，镜头留在靠近镜头的这一侧，锚在镜头和主拍之间，不穿到主拍背后。把机位距直接量到锚面上、主拍却比镜头更远离锚，主拍就在镜头后面，这一拍回流，不改景别去凑。平拍的机高等于主拍当时姿态的眼高，不套另一种姿态。向距上限按该向三档收：`窄` → 机位距≤三步、景别≤FS，禁止十步外和 EWS；`开` → 机位距≤五步远、景别≤WS；`无限制` → 才可以用十步外和 EWS。某一向能不能用，先看它承不承载本节已经锁住的景别。窄只到 FS，开只到 WS，无限制才到 EWS。FS 及更近只核远锚那一向。WS 和 EWS 再核左右邻向；邻向超上限，这个角承载不了该景别。承载得了就优先留在上一拍那一向，细则在「沿用与当前环境」。四个正交角都承载不了，才把景别收到最宽那一向允许的最大档，并写 `向距收档=是`。禁止为了留在窄向把已锁的远景收成全景。

原文的远景、全景、中景、近景、特写、大特写映射进上面的闭集，并写 `原文景别=`。原文的俯拍、仰拍、平拍写入 `原文角度=` 和 `镜头角度=`，不占景别档。

`剧情匹配=建置|走位|对白|交付|反应|特写|空镜|宏观`。有追逃主体的不是空镜。开场已在场的第一拍不是空镜，除非这一拍本来就是整机远观。

| :--- | :--- | :--- |
| 建置、空镜 | `EWS\|WS\|FS` | `FS\|WS`；`EWS` 只给宏观或孤绝 |
| 走位 | `WS\|FS` | `FS\|MS` |
| 走位并且对白 | `MS\|FS` | Two-Shot=`MS`；单人=`MS\|MCU` |

默认同级或邻一档。大全景收到中景走 `EWS→WS→FS→MS`。近景连续满 3 且下拍有走位或交付，须拉开。远景连续满 2 且已经进入对白，须收近。`EWS→MS`、`WS→MCU`、空镜之后直接半身，都不能当作建立。

越级必须写 `越级:{依据}`。依据只许这九个：①原文 `△特写` 或场核细节特写；②卖点、高潮、`~`；③Insert；④满幅特效和细节特写分成相邻两拍（空镜之后切到人，不走这条）；⑤交付拉开；⑥反打只为读脸，而且落幅仍是同级或邻档，反打不能充当 `EWS` 与 `CU` 之间的跳档；⑦入场拉开，只许 `MCU|CU|ECU` 收到 `FS|WS`；⑧进出场衬托，反应的 `MCU|CU` 和进出过程的 `WS|FS` 互跳；⑨文戏 `【对话标注】` 的句眼或关键反应，收到 `CU` 或 `ECU`。开场先特写、下一拍拉开全员全景，走第⑦条。

**句眼与关键反应用特写加强（最高）**：读文戏 `【对话标注】`。`职=句眼` 的拍，`景别=CU` 或 `ECU`，`机位距=贴身`，`针对=` 是说出这句的人，读这张脸和口型。`职=关键反应` 的拍同样只锁 `CU` 或 `ECU`，`针对=` 是接住这句的听者，读这张脸上的表情和微动作。这两拍不留 `MS`、`MCU`、`FS`，也不用双人同框把脸盖小。`反应拍=无` 的轮不另造反应拍。从上一拍的中景或全景收到这两档，写 `越级:句眼` 或 `越级:关键反应`。站位和朝向不因为收近而改。上一角看得见这张脸，就留下，只收 `机位距=`。上一角看不见这张脸，才换到正前。这两拍各锁一张脸，正文的 `同拍=` 不落在这两拍上。✅句眼拍 `景别=CU｜针对=CHAR:[@甲]`，下一拍关键反应 `景别=ECU｜针对=CHAR:[@乙]`。❌句眼仍是 `MS` 双人。❌关键反应只给 `MCU`。❌把听者的脸写进句眼拍再当成同拍。

**同拍这一拍怎么选角（最高）**：正文有 `同拍=` 时，这一拍的两下必须同时在镜前。`针对=` 仍是本拍主动作主语。必见集含被同拍的那个人，以及这一下碰到的具。`覆盖=` 写成双人同框，或写成这一下接触。景别必须同时盖住两边的这一下，不用 `CU` 或 `ECU` 把对方裁出。机位侧取能同时看见接触的那一侧。上一角已经同时看见这两下，就留下，只改 `机位距=`。上一角看不见这一下接触，才换到看得见的正交角。这一拍禁止为了读同拍另一方的脸而反打。要读那张脸，是下一拍；下一拍再按句眼或关键反应收近，看不见脸才反打。✅甲递信、乙同时接住，留在能看见两只手的 `MS`，`ENV变=否`。❌同拍却收成只剩甲的脸。❌同拍这一拍反打去看乙的表情。

`voice_type=VO|旁白` 可以和动作或画内对白在同一拍，不因为旁白拆拍。这一拍的主拍跟画面，禁止把旁白当口型。禁止漏抄上游旁白行。

四方只拍 0、90、180、270。衍生环境的度数，含第一刀、仰天和衍生的衍生，只许这四个。禁止 45° 和对角偏斜机位，禁止其他水平角。不改左右手脚、取用、朝向对象、门的开闭。拆拍只按角拆开动作，不改这些。

常规有戏场不少于 3 拍时，`CU|ECU` 约占 15%–25%，竖屏 20%–30%。纯过场或宏观满幅可以更低，要写依据。卖点、高潮、低谷、细节特写必须落在已经锁成 `MCU|CU|ECU` 的拍里。`~` 必须是 `CU` 或 `ECU`。禁止把卖点全程压在远景或中景。配额只核销，不另写综合块。

开场段两件都要出现：一拍能看见全部开场者的 `EWS|WS|FS`（竖屏偏 `WS|FS`）；以及一处吸睛（道具特写、表情特写、动作切口、宏观、转入落成、关键音画）。先特写或先无人远景时，紧邻下一拍必须拉开全员全景，中间不插对白半身。两件都出现之后，`入场闸=过`。

进出画不能全程同一景别。过程拍 `WS|FS`，反应拍 `MCU|CU`，至少差一档。`进出衬托=反应先|建立先|跟出|目送|无人反应`。

`画内V`>4 必须拆拍。竖屏对白、近景常规 ≤2。

正反段不少于 3 拍时，过肩之外要有一拍 Two-Shot 和一拍表情特写。Two-Shot 景别 `MS|FS`，本拍不标反打。群演簇原则上单独一拍，景别 `EWS|WS|FS`，不塞进具名对白的近景。

主相位按这一拍在做什么再收一档，不改上面的功能表：

投射的出手点、路径、命中面要在同一角里看得见，否则拆拍。

**可见名单**（写在机位行，不是站位）：`针对=` 必须在 `可见=` 里，空镜除外。景别盖不到的人不要写入。主拍体量：`FS|WS|EWS` 为全身，可省写；`MS` 为半身；`MCU` 为胸肩；`CU|ECU` 为脸，物件特写写该件。其他人只写实际入画的自身部位，闭集=`左肩|右肩|左肩头|右肩头|左臂|右臂|左腰|右腰|左手|右手|左侧身|右侧身|左侧脸|右侧脸|后脑`。禁止裸写肩、手、腰。禁止写成画左肩。过肩时，框主露出靠近轴侧的那一肩，被看者的 `机位侧=` 仍是正前。未松开的接触、未离开的法相或载具、开场已经戴上的配饰，必须同一锚，并且本拍同时列入 `可见=`，空镜除外。景别盖不住就改景别或拆拍，禁止拆锚。`巨体尺=遮挡不可见` 的小人不进 `可见=`，锚仍相同，不算拆开。

**参照不跟景别改（乙）**：甲的 `锚=` 不读景别。乙不因特写、近景或中景另选一具，也不把这一具标成出画后改挂到脸上。站位仍写成在这一具哪一侧离哪个方向大约多远的位置。`机位锚=`、望向、当前环境、`机位侧=` 同样不因景别改。镜头句写成镜头在这一具朝向或远离另一具的那一边离这一具更近或更远的位置，距离用本拍 `机位距=`。不写「的外面」。没有第二具则写成镜头在这一具画面左边或画面右边离画面左或离画面右大约多远的位置。人在远离镜头的那一侧，这一具在镜头和人之间；人在靠近镜头的那一侧，这一具在人后。本角画外才用临时锚。

**构图**（机位行的镜头键，不是人的站位）：主档=`三分|中心|纵深`。可兼=`对称|框中框|引导线|负空间|无`。横屏对白默认三分。竖屏默认中心或纵深。仪式、权力、砸点用中心。走位和前后层用纵深。从门或窗看进去可兼框中框。通道可兼引导线。孤绝可兼负空间。写 `构图=`、`可兼=`、`留白=视线前|运动前|无`。不写 `主体落点=画左三分`；人在画面左还是右，由建置与入戏按望向换算。进出画：反应近景 `留白=视线前`，过程远景 `留白=运动前`。

**机运**：`机运=固定|手持|跟拍|OPV|FPV|ACT|虫蚁|鸟瞰`。固定是机站死。手持仍要写俯仰。跟拍的锚是被跟者旁边的环境件，路径不越轴。OPV 是脑后跟随，镜头角度只许平拍、微仰、微俯，禁止主观。FPV 的镜头角度必须是主观，写 `主观角色=`，距=贴身，眼高等于该人当时的眼高。ACT 是贴身动作，距=贴身或一臂。虫蚁的镜头角度必须是虫蚁。鸟瞰的镜头角度必须是航拍或鸟瞰。禁止主观标成平拍，禁止鸟瞰标成平拍，禁止脑后跟随标成主观。

**机位优势**：`AI位=无|窗外看入|檐外|对楼|航拍外立面`。航拍、宏观、空镜、入场、余波用航拍外立面。高层室内或窗前用窗外看入，窗只作画框，对白仍可以是中近景、一臂。檐口、楼顶、对楼、中庭用檐外或对楼。不是 `无` 时，`机位变因=` 含 `AI优势位`。禁止为了航拍把口型改成远景。禁止用画外的件当锚。

进出封闭舱写 `过阈运镜=过框推入|跟随入舱|窗外窥入|绕体外跟|落幅在舱|过框拉出|跟随出舱`。从外进舱优先推，从舱出外优先拉。`ENV变=` 写在落幅那一拍。落幅有人用 `FS|MS`。禁止宿主远景直接切成舱内中近景对白。同一拍已经看见整机和大世界，这一整拍就是落幅，环境主名用宿主。没有舱门的露天合建不套过阈。重生、闪回、回忆、梦境、闪切、蒙太奇各挂注入里对应的那一块主环境，`当前环境` 主名逐字等于这一块注册名。同一句闪回注入了宿主和舱两块时，按这一拍看见的那一套来挂：看见整机外形、侧翼、擦过尖顶、楼缝或空域，挂宿主那一块，载具档走整机；看见座、舱壁、舱内的人，挂舱那一块。禁止整机那一拍仍挂机舱。链上的近义、时间词不另写一块衍生。触发名=`重生切主环境|闪回切主环境|回忆切主环境|闪切切主环境|蒙太奇切主环境|回切当下主环境`。回到当下持续戏，再挂当下那一块。注入里只有机舱、这一拍却是整机擦尖顶 → 回流环境规划，不把尖顶写进舱。

### 机位侧与望向

**机位朝向跟环境正面（最高）**：机位的水平朝向和本拍衍生环境是同一向，朝向这一度的正面。正面就是这一度 `背景=` 所在的世界向，也是 `望=`。0度正面在北，望北。90度正面在东，望东。180度正面在南，望南。270度正面在西，望西。`望=`、`当前环境=` 的度数、`[DERIVED_ENV:]` 三者同向。镜头站在正面的对侧，轴线对着这一面。可以偏在这一侧的左或右，仍对着正面，不拧成斜向。禁止望向 `画左=`、`画右=` 的侧壁，禁止望向 `画外=`。禁止用 45 度或别的水平角去凑拍摄对象。拍法和机位侧先推出望向，望向推出环境。环境一定下来，朝向就锁在这一正面，不再另选一个方向。衍生的衍生与同度数第一刀是同一个正面，不另起朝向。

**距离和仰俯按景别与拍摄对象定（最高）**：朝向锁死之后，远近和高低另定。`机位距=` 先按景别的默认一对，再按拍摄对象要看见的体量改定。`镜头角度=` 和 `机高=` 按拍摄对象要看见的那一面、读脸或背影、原文俯仰、主相位来定。环境正面不决定贴身还是十步外，也不决定平拍、俯拍还是仰拍。同一度上收近、拉开、微俯、微仰、俯拍、仰拍，望向和环境名都不改。只有要看见的那一面在这一正面上看不见，或这一向承载不了已锁景别，才换度。换完仍朝向新的那一度的正面。✅180度望南，句眼收成贴身平拍，环境仍是 180 度。✅同一 180 度，桌面物件改成过顶俯拍，望向仍是南。✅巨体立面在这一正面里，用贴地仰拍，不换度。❌为了俯拍或仰拍改成另一个度数。❌180度环境里把镜头改望东去读侧壁。

先定剧情要看见 `针对=` 的哪一面，再写 `机位侧=`。水平面朝已经在甲锁死。`机位侧=` 与面朝一经写出，`望=` 只有一格，这一格就是该衍生环境的正面。禁止改朝向去凑表。走到家具旁边、坐下、低头，都不是背影，不因此锁正后。

**正拍先分正脸与后背（最高）**：正拍是镜头正对这个人的身体中线。落笔前先看剧情这一拍要的是正脸，还是后背、后颈。要口型、神色、表情、正脸：`机位侧=正前`，可见面是脸，`表情换环境评=保持`。要后背、后颈、后脑、背影，或镜头跟在身后：`机位侧=正后`，可见面是后背和后颈，`表情换环境评=本拍不写脸`，不写眉、眼、嘴。两种望向差 180°，都不是侧面。后颈的特写仍是 `正后`，不收成正脸。正脸的特写仍是 `正前`，不写成后颈。同一拍既要正脸又要后背，改成左侧或右侧。下一拍才要另一面，另起拍再反打，不在这一拍里从后颈转到脸上。正文只写低头、坐下、走到家具旁，仍按剧情要的那一面锁，不因此改成后背。

| :--- | :--- | :--- |
| 正面（读脸、口型、神色） | `正前` | 机在北，`望=南` |
| 正文要看见的背影，或跟在身后 | `正后` | 机在南，`望=北` |
| 自身左侧 | `左侧` | `望=东` |

面朝东：正前望西，正后望东，左侧望南，右侧望北，肩后望东。面朝南：正前望北，正后望南，左侧望西，右侧望东，肩后望南。面朝西：正前望东，正后望西，左侧望北，右侧望南，肩后望西。机在望向的对面：望南则机在北。

**面向镜头只由机位侧推出，不另写朝向**：人行禁止 `朝向=面向镜头`。乙锁完 `机位侧=` 和 `望=` 之后，用上表核脸和镜头是不是同一几何。对不上就改机位侧或望向，禁止改甲的朝向去凑镜头。

| 机位侧 | 和镜头的关系 | 面朝向必须 |
| :--- | :--- | :--- |
| 正前 | 脸朝镜头 | 指向机所在的那一向。望南时机在北，面朝必须是北 |
| 正后、左肩后、右肩后 | 背对镜头，后脑朝镜头 | 与望向相同。望南则面朝南 |
| 左侧、右侧 | 侧对镜头 | 与望向垂直。不是朝向镜头，也不是背对镜头 |

正前却面朝离开镜头、正后却面朝镜头、侧对却写成脸朝镜头或背对镜头，都是失败。法相的 `面对镜头=是` 只对应这一体的正前；`面对镜头=否` 只对应正后或肩后。它和宿主的面朝向仍须相同，不能一个朝东、一个朝西。

自身左右：面朝北，自身左=西、自身右=东。面朝东，自身左=北、自身右=南。其余类推。

**可拍性压过指定面（最高）**：机位侧先保证本拍要拍的动作和道具拍得到。同一拍既要看见正面，又要看见背面，机位侧只许左侧或右侧，不锁正前，也不锁正后。正面是胸前的手、这一侧的表情、胸前或衣内的件。背面是后背、后肩、后脑。选能同时看见这一侧胸前和后肩的那一侧。轴侧已锁时，取仍落在轴侧的左或右。人的朝向不改。剧本写了背影，但这一拍同时还要看见胸前的手、表情或胸前的件，同样改成这一侧，不留正后。只有背面、没有正面要拍的内容，才锁正后。只有正面、没有背面要拍的内容，才锁正前。

归类只决定这一拍要看见的那一面。同一拍既有正面又有背面，先锁左侧或右侧，不走下面的正前或正后。沿用核过了，就保持上一拍的机位侧和望向。沿用核不过，才按下一条命中锁机位侧：人载后方且本拍不写脸→正后，前方→正前，侧→落在已锁轴侧的那一侧，轴侧尚未锁时用自身左。其次读脸且不是「本拍不写脸」→正前。其次剧情要的是后背、后颈、后脑、背影或跟在身后→正后，不因为「其余单人」改成正前。其次跟拍要看见本人后脑→肩后。其次并排，或双人同框而不单读一张脸→机位落在已锁轴侧。轴侧是本段第一张关系镜针对者面朝时的自身左，世界向锁死后不改。人转身之后，用仍落在这条世界轴侧上的左侧或右侧。轴侧尚未锁时用针对者自身左。其余单人→正前。空镜、没有针对者：不写身体上的机位侧；`望=`=要点名的后景所在的世界向。该具在中部、四向都看得见时，上一拍那一向承载得了本拍景别就沿用；承载不了，才在向距上限允许本拍景别的方向里取最宽的一档，同宽按北、东、南、西。有人面朝时禁止改走空镜这条，禁止用 `0度` 代替上表。

过肩、过腰、过头写在 `关系角=` 和 `过肩配对=`。被看者的 `机位侧=` 仍是 `正前`。禁止把 `左肩后` 写进被看者的 `机位侧=`。同一台机器禁止既写被看者正前，又把肩后当成被看者的机位侧。

`主拍对象=` 与 `针对=` 同值，两键都写。

**轴**：本段第一张有人的关系镜，`轴侧=`=针对者面朝时的自身左。面朝北则轴侧=西。此后不改。反打仍在这一侧，望向差 180°，`axis_crossing=PlannedReverse`。这不是跨轴。禁止把机摆到轴线另一侧。禁止为了换角写 `MotivatedCross`。人走到轴线对面，只跟新站位把轴侧重锁成新人的自身左，机仍在新的同侧。

**靠墙靠门**：对打里已有一人背后贴墙、贴门或贴门框，身后没有机位空档 → 不走过肩、过腰、过头、肩后。每拍 `机位侧=正前`，`关系角=干净`，`框主=无`，`近侧框主=无`，`过肩配对=无`，`覆盖=单人`。换人另起一拍，望向差 180°，仍是干净正面。坐在床上、椅上，背没有贴墙或贴门，不算。人离门还有距离、背后仍是室内空档，不算。

**高低**：没有靠墙靠门时，先比站坐、大人小孩。齐高→`关系角=过肩`。框主更矮→`过头`。框主更高→`过腰`。`框主=` 与 `近侧框主=` 同值，都写，且不等于被看者。`过肩配对=` 写框主靠近轴侧的那一肩、那一腰或后脑。等体量的正反，本拍和对向拍都写出配对。`覆盖=` 写关系角（过肩、过腰、过头、Two-Shot、带肩、单人、空镜）。干净的单人反打才写 `覆盖=反打`；又过肩又反打时，`覆盖=` 写过肩，反打写在 `axis_crossing=PlannedReverse` 和 `ENV变=`。

并排：`覆盖=带肩` 或 Two-Shot。禁止无故裁掉旁边的人。

**巨体**：法相、金身、化龙凤相对宿主，体量悬殊时必须写 `巨体尺=肩前悬浮|遮挡不可见`。禁止写成普通人前后叠，禁止过宿主的肩。`肩前悬浮`：小人悬浮在挂靠体肩前，`站位=` 能检索「悬浮于…肩前」，可进 `可见=`，只作尺度。`遮挡不可见`：小人不进 `可见=`，锚仍与宿主相同。看对手时框主是法相，不是宿主。

**人载**：有人骑乘时写 `人载同向=是｜相对=后方|前方|侧｜载具面=车尾|车头|左侧身|右侧身`。骑手的 `面半空间=` 等于前进向。前进向没有点名时，`朝向=无`，另写 `朝向推=面向前进向`。`相对=后方` 且本拍不写脸 → `机位侧=正后`，禁止正前，禁止 `朝向=面向镜头`。`前方`→正前。`侧`→落在已锁轴侧的那一侧，轴侧尚未锁时用自身左。无人骑乘不写 `人载同向=`。本拍拍摄要求是读脸时，后方跟拍改为正前，不拧骑手的朝向。`本拍不写脸` 时 `主拍对象=` 改为 `PROP:[载具]` 或环境，`剧情匹配=` 只许走位、交付、宏观，禁止仍以该骑手为针对者。

**俯仰与机高**（只此一套；朝向已锁在环境正面，这里只定高低）：按本拍景别和拍摄对象选一行。不因为选了俯或仰去改 `望=` 或换度。

| :--- | :--- | :--- |
| 平拍 | 主拍当时姿态的眼高 | 读脸、对白、反应。站、坐、蹲、跪、躺各用自己的眼高，不套另一种姿态 |
| 平拍 | 胸口 | 只在坐姿、隔着桌面对白，并且 `角度动机=` 写明胸口 |
| 微俯 | 略高于眼高 | 不写脸的全景落座、低头 |
| 微仰 | 略低于眼高 | 轻微仰看 |
| 仰拍 | 膝、腰或桌沿 | 写明是哪一具的高度 |
| 俯拍 | 过顶 | 桌面、布局。不是航拍 |
| 虫蚁 | 贴地 | 贴地仰看立面或巨体。`机运=虫蚁` |

口型主拍禁止航拍、鸟瞰、虫蚁。反打沿用对向拍的俯仰。宏观建置禁止眼高平拍。缺 `机高=`，或只写俯仰不写高低=失败。载具档仍是 `内部ENV` 时，不用航拍、鸟瞰、远高于头顶；外面在玻璃里，机高仍是坐姿眼高或略高于眼高。这一拍已经看见本机外形或两架整机，先按上面改成宿主，再许用航拍。

**机位锚**：只写镜头相对哪一具环境主体，不回写成朝向。这一具必须是本拍望向这一格看得见的主体：该格正面、左右或中部。镜头后面那一壁上的具不选。人的站位锚是另一个人时，机位锚用对方已经锁上、且本角看得见的环境主体；对方还没有，或那一具在本角看不见，用本角看得见的中部主体。人已经写成双主体时，机位锚是中部那一具；中部这一具本角看不见，改用本角正面已经有的那一具。没有双主体、该人锚已按入戏取物或剧情例外锁成桌、门或正文点名的那一具时，这一具本角看得见，机位锚跟这一具；看不见，改用本角正面或中部看得见的最近一具。人锚已是最近那一具、且本角看得见时，机位锚跟这一具。距离相若、人锚是中部、中部本角看得见时，机位锚是中部那一具。反打、切角不改挂，禁止把本角 `背景=`、`远锚=` 或四壁升成机位锚。中部没有具名主体、也没有剧情例外时，才用针对者水平面朝的那一具合格环境主体，且这一具必须本角看得见（低头和落座改不出这条面朝）。面朝的是人 → 用该人已锁的、本角看得见的环境锚。坐在床上，床本角看得见时锚可以是这张床，水平朝向仍沿用开拍。空镜有中部主体、正文又没点名后景、中部本角看得见时，锚仍是中部那一具；中部没有或本角看不见，才用本角看得见的后景。锚必须独一、有轮廓。没有合格锚 → 回流，不另造。

`机位=场内|{锚}{机所在的世界侧}`。这里的锚与 `机位锚=` 是同一具，必须是本角看得见的主体。`画外=` 和镜头后面那一壁上的具不写进 `机位=`。禁止用镜头后的花盆标明机在锚的哪一侧。正文点名门外、窗外、檐外、对楼、上空，或镜头是航拍、鸟瞰 → `场外`。望北=南侧外，望东=西侧外，望南=北侧外，望西=东侧外。航拍与鸟瞰=上空。从门外往里拍：锚=该门，门在南则望北，门在北则望南；机在门外侧，不写进门里。

### 沿用与当前环境

**新拍先定拍法，再定衍生（最高）**：先读本拍开拍 `朝向=` 和 `罗盘朝向=`。这份朝向已经含上一拍行动后的更新。`拍法=` 必须已经写成正面、背面、侧面、过肩、双人同框之一。拍法还没写下时，禁止写 `当前环境=`，禁止先挑 0、90、180、270。拍法锁完，才用罗盘朝向和拍法推出 `机位侧=` 和唯一 `望=`。望向才推出衍生环境名。

**衍生的衍生与同度数衍生环境一样处理（最高；重新强调）**：望向推出的 N 只许 0、90、180、270。这一度若要挂 `{N}度{主}_{状态}`，选角与挂名都按同度数的 `{N}度{主}` 来做。同一拍法，同一机位侧，同一机位锚，同一机位距，同一望向。状态行只换名字。这一度第一刀哪一面是正面、哪一面在画外，状态行相同。不因为是衍生的衍生就改拍法，也不另给一个度数。生成提示仍只写状态Delta。

先锁本拍景别和其余拍摄要求，再决定留不留在上一拍的衍生环境。拍摄要求含已经写下的拍法。拍摄要求锁完之前不写 `当前环境=`。

**按合镜能拍成的效果选角（最高）**：默认短镜头。沿用成功、`当前环境=` 逐字不变，这些拍会并进一镜，画面锁在这一张参考图上，后面只在这张图上推近或拉开。所以四项都过就留下。景别变、或拍摄对象要求另一档远近，只改 `机位距=`。俯仰变、或拍摄对象要求另一档高低，只改 `机高=` 和 `镜头角度=`。这两项都不改望向，朝向仍是这一度的正面。换说话人、接招、读对手、满三拍不换角，就是为了让这一段停在同一张图上。同一主环境只是度数不同（反打、切角），短镜头会另起一镜，效果是切到对面那一壁的另一张参考图，镜内不转过去。只有上一角看不见要读的那一面，或承载不了已锁景别，才换这一个度数。拍法从单人正面、背面、侧面或过肩改成双人同框，或从双人同框改回单人读一张脸，本身就要换背景：按新拍法重算望向，新望向与上一拍不同就必须换度。禁止用入场拉开、越级、或上一角拉远也能看见两人，把双人同框留在单人那一张图上。反打必须差 180°。差 90° 切过去看见的是侧壁，不是这张脸，禁止拿来冒充反打。主名不同的蒙太奇链会整链并进一镜，效果是按链序换参考图。每一拍的 `当前环境=` 必须已经是对上的那一块注册名。禁止留在上一块房间里，用推近或拉开假装到了另一处。

拍摄要求只锁这四项，不选度数：

1. 景别。按上一节的原文、功能表和主相位锁死。向距只回答某一向能不能承载这个景别。
2. 要看见的那一面。归类决定针对者必须被看成正面、背面、侧面，或双人同框。口型、读脸、神色是正面。正文写明的背影是背面。并排、双人同框而不单读一张脸，是两人同时在镜前。

**不可逆变化走衍生的衍生（最高）**：天象改了，桌子或架子被掀翻，墙、玻璃、门扇破了，地面或梁留下断口。这一处变化留在环境里，本场内不复原。先看注入的【主环境】。已经有一块就是这次变化之后的同一空间，那些拍挂 `{N}度{该注册名}`，按第一刀只切割。没有这样一块，不回流环境规划，不把破损、掀翻或天象写进无状态第一刀，也不要另起一个废墟之类的新主名。无状态第一刀仍是 `{N}度{主}`，`类型=第一刀`，`状态Delta=无`，生成提示只切割不改画。变化能被这一角看见的每一度，另起一行 `{N}度{主}_{状态}`，`类型=衍生的衍生`，`触发=状态`，`同角切割父=` 同一度的第一刀。N 只许 0、90、180、270，与父行的 `view_angle_from_main` 相同。`背景=`、`画左=`、`画右=`、`画外=` 照抄该第一刀。选拍法、沿用、反打、双人同框、机位侧和望向时，这一行与同度数的第一刀一样处理，不另起一套选角。

**破损按剧情写清（最高）**：写这一行之前，按本场剧情把这一处评成一档，写进 `状态Delta`。墙、玻璃、门扇、梁、地面、天花的破法先分两档，不能混。`范围=一个洞`：只破开一处。点名哪一具的哪一面，洞或裂口在哪。原文写了大小、形状，原样留下。其余墙、梁、天花、地面和家具保持完好。状态词用破洞或裂口。`范围=整体崩碎`：这一面或这一间一起塌、碎或焚毁。点名哪些具一起没了，哪些还立着。状态词用崩碎、坍塌或焚毁。掀翻、天象不套成洞或崩碎，`范围=掀翻|天象`，状态词用掀案、血月这类剧情词。原文写了破损，`依据=` 带上那一句原文；没写则 `依据=无`，仍按动作写出是一个洞还是整体崩碎。禁止只写「破损」「毁了」「狼藉」。同一处不能既是一个洞又是整体崩碎。天象和特效可以写颜色、形状、纹样。已注册的桌、墙、玻璃不改颜色、材质、纹样。不新造陈设，不重摆四壁。`状态Delta=` 写这一处：哪一具、范围、具体样子，并带上 `依据=`。`生成提示=` 只写这一句状态Delta。同一主、同一度、同一组变化只一行。后文又添一处不可逆变化，另起一个状态词。`状态Delta` 写成相对原主环境已经留下的全部变化，每一处仍写明自己的范围。父仍是该度第一刀，不把父写成上一层状态行。这一角的背景、画左、画右或中部看不见该变化，不给这一角建状态行。没人再用的度不建。状态行只要存在，提取块里必须有它的同角第一刀，即使没有拍再挂那一刀。程序不按度分别改画面。同一所属主环境、同一状态词合成一块衍生主环境，名字是 `{主}_{状态}`，参考图是被依赖主环境的四格拼图，同一主体的相关内容四格一起改。一个洞只改点名的那一具，整体崩碎才让点名的那些具一起碎。各度 `{N}度{主}_{状态}` 只切割这块衍生主环境。

**对应拍切换两套衍生（最高）**：变化还没发生的拍，`当前环境=` 挂无状态第一刀，`落幅环境=无`。变化在本拍才落到画面上，开拍仍是变化前：这一拍 `当前环境=` 挂同度第一刀，`落幅环境=` 挂同度 `{N}度{主}_{状态}`。两个名字都写入这一拍，各有一条 `[DERIVED_ENV:]`。`ENV变=是:环境状态`。望向、机位锚、机位侧、机位距不变。禁止这一拍只挂其中一套。禁止把破损写进第一刀。禁止落到下一拍才第一次挂状态行，而这一拍的落幅已经是破后。下一拍起，只要还停在这块主环境、变化还在，`当前环境=` 和 `[DERIVED_ENV:]` 只挂 `{N}度{主}_{状态}`，`落幅环境=无`。场开场已经是变化之后，各拍直接挂状态行，`落幅环境=无`，第一刀只留在提取块里当父，不在开场拍再切一次完好图。换到另一度，那一度也挂同一个状态词，不在换角那一拍再从完好图切一次。粒子、沙尘、光晕会散掉的，仍只在满幅和维持的拍挂状态，余波回落回到无状态行，不写 `落幅环境=`。不可逆变化不因余波结束回到无状态行。门窗开合、挪开椅子、端走杯子、人走开，不建这一行。景别、过肩、反打不另起状态词。

✅注入只有「林宅正厅」，原文「一掌把案掀翻」。掀案这一拍 `当前环境=180度林宅正厅`，`落幅环境=180度林宅正厅_掀案`，两条 `[DERIVED_ENV:]` 都在。父=`180度林宅正厅`。状态Delta=案面掀翻。范围=掀翻。依据=原文：“一掌把案掀翻”。第一刀仍只切割。下一拍只挂 `180度林宅正厅_掀案`。✅原文「窗上炸开一个脸盆大的洞」：状态词用破洞，范围=一个洞，Delta 写南壁窗一个洞、约脸盆大，其余墙梁天花保持完好，依据带上这句原文。炸开的这一拍从 `180度林宅正厅` 切到 `180度林宅正厅_破洞`。✅原文「整面墙崩碎，梁一起塌下来」：范围=整体崩碎，状态词用崩碎，Delta 点名这面墙和梁一起没了，没写塌的家具留下。✅后文窗玻璃也碎了，再起 `180度林宅正厅_掀案破窗`，Delta 同时写案面掀翻和窗玻璃碎裂，各自带范围，父仍是 `180度林宅正厅`。✅血月留在天上，用到的 0 度和 180 度各一行 `_血月`，父各是该度第一刀。❌只写「破损」，不写是一个洞还是整体崩碎。❌把一个洞画成整间崩碎，或把整体崩碎写成一条缝。❌把掀翻写进第一刀的生成提示。❌炸开的这一拍只挂完好图，或只挂破洞图。❌没有变化后的主环境，却新造 `180度林宅正厅废墟`。❌父写成 `180度林宅正厅_掀案`。❌掀翻之后的拍仍挂无状态的 `180度林宅正厅`。

### 衍生环境提取（切环境图，不是给人换算）

普通行名=`{N}度{主名}`，N 只许 0、90、180、270。不可逆变化的状态行名=`{N}度{主名}_{状态}`，N 与同角第一刀相同，也只许这四个数。主名段仍是该注册名。主名逐字等于所属主环境，并且逐字等于本场已注入的某一块【主环境】注册名。禁止 `Beat:`、`文戏:`、`Ndeg` 当名字。禁止用链上未注入的字、拍文地名、三年前、当年、旧时、回忆中、闪回里当主名。禁止 45 和其他水平角。衍生的衍生不因为加了状态就换成另一个 N。

每行写入提取块：名称、所属主环境、`view_angle_from_main`、类型、触发、`活动适配`、`可见内容白名单`、`可见边界`、`不可见内容`、`背景=`、`画左=`、`画右=`、`画外=`、`生成提示=`、`lens_profile`、`axis_crossing`、`spatial_axis`。

`背景=` 照抄主环境该向已点名的主体。`画左=` 照抄左转 90° 那向，`画右=` 照抄右转 90° 那向，`画外=` 照抄对向并标（不可见）。禁止改写、禁止把角色和可移动道具写进这四键、禁止填无。对应向没有主体 → 回流环境规划。这四键是该角度环境图的固定陈设，不是角色站位。

`生成提示=` 必须能检索到 `截取宫格=`，并与 `view_angle_from_main`、主环境 `四宫度数=` 一致。主环境四宫已经写了度数，就按那一行裁；旧稿若是右下 180、左下 270，按旧行裁。缺行才用 0→左上0度，90→右上90度，180→左下180度，270→右下270度。另须 `远锚=`。远锚照抄 `背景=`，禁止用画外主体。生成提示只标切哪一格。不抄开篇【北壁】【东壁】【南壁】【西壁】【中区】【光学说明】正文，不写路怎么铺、地面纹路、中部逐件、画面左或靠近镜头。开篇世界内容不写入生成提示，也不交给生图模型。重生修正从已经对上的那一块主环境中文提示词抽取【定位】【色彩说明】整节，【主体外形】只留该格 `[@名]` 点到的行，【四向拼图】只留共享句和该格。叙事里的重生、回忆、闪回、蒙太奇不另写一块空间，仍只切这一块。光学、结构和摆位用该格已写成的正面、左侧面、右侧面、中部、源体可见、源体画布位、高度带、影子投向。16:9 是切割比例。本拍成片宽高比另写机位行 `画幅=`。生成提示不重写桌椅朝向，也不进人行。蒙太奇、回忆、闪回的正文不改写这一处的墙、街、桌椅或陈设。以上只约束第一刀。衍生的衍生不写 `截取宫格=`，生成提示只写 `状态Delta`。画面改动由衍生主环境在四格里一起完成。

`可见边界=全画幅` 无效。必须用具名实体写清左界、右界、上界、下界。左界、右界和 `画左=`、`画右=` 是同一批件。沿着短的一侧看路时，写出路的左右截断，禁止为了把路的全长收进来而把边界扩到两端。

白名单只写固定陈设及其可见面。禁止写入人名、动作、表情。本角背景微动件必须是这一行里明确可见的主体：名字逐字出现在 `背景=`、`画左=`、`画右=` 或白名单可见面里。`画外=` 与 `不可见内容` 里的具不能当本角背景微动件。主环境已经点名 `背景微动件=`，而且它就在这三键或白名单里，就写入白名单，不另造，也不改它的落点。它不在这三键里，本角不写它。可见主体包括光源：窗、灯、灯笼、火塘、烛、补光源。本角看得见这一具时，微动可以是它的动态光影。写到影子时，必须点名投下这道影的那一具光源，而且这一具就在本角 `背景=`、`画左=` 或 `画右=` 里。看不见的光源不写它的光，也不写它的影子。舱内 0 度望向挡风，不写后排座的正面。90 度与 270 度须列出全部座位，并标近侧和远侧的可见面。驾驶舱里后排和司机要同时看见，只允许 90 度或 270 度。对向不可见只约束舱外的街景，禁止把近侧座位整排写进 `不可见内容`。

不在提取行写 `简要特征=`。程序按各拍用到的 `锚=`、`机位锚=` 归入该衍生，只留下本角看得见的面：正面、左侧面、右侧面。画外那一壁、机位后面的主体不写入。180度望南时，北壁在镜头后面，北向落地窗不进简要特征。

本拍必见的锚、承托、手持可见面、出入口、特效命中面，必须落在这一角的白名单里。取用、开门、递接还要同时看见执行的人、承托、道具和被读的那一面。只写「桌区全部面」不等于看见酒盏。走位里本拍要读的锚、承托和出入口必须在白名单里，并且要读的那一壁是本角正面。人经过的空地不因为不在白名单里换角。侧壁上的件，只在本拍要读它的那一面、而这面已经残缺时，才算没盖住。直线上有障碍，绕开的那一侧也要进必见集，一拍装不下就拆拍。已入场但本拍不必看见的人，仍占世界位，不为他改挂。纯声音不进必见集。一拍的必见项分属两个对向角 → 拆拍。

场核的 `细节特写参考`、`贯穿保护` 必须落在已声明的衍生里。`反馈特写参考` 要在同一拍或紧邻的切角里读得到。`运镜参考` 要有连续可见的空间。

拆拍时，过程和特效句按角分完，禁止吞掉。每拍自备【配乐】【音效】和分布图，从 1 重新编号。场级 `承接=`、`节拍=`、`落地=` 与输入的 B 号对齐。`拆拍依据=ENV覆盖|角色超限|群演疏离|占用换主`。拆开之后每一拍仍是一个动作或一个反应。禁止把没有因果关系的两件事揉回同一拍。不改对白、因果、左右手脚、取用、朝向和门的开闭。

## 自检

- 封套完整，末行是结束标签。每拍原文在分布图之前。没有回写主环境。没有【取景锁定】。没有 `宫格=`。同一场注入的当下、重生、闪回、回忆、梦境、蒙太奇各块都读过。落到那一块的拍，`基准=主环境:` 和 `当前环境` 主名逐字等于那一块注册名，锚取那一块的主体。每一行衍生的所属主环境都在本场注入里。蒙太奇、回忆、闪回没有把链上的字、拍文地名或三年前、当年、旧时写成新的 `{N}度{名}`。四向和生成提示切的是对上的那一块，没有按拍文另写墙、街、桌椅。链上的名字对不上、且不能唯一改挂时，已经回流，没有为了填满提取块新造一行。没有用当下桌椅给定另一时空的站位。缺块已回流环境规划。
- 甲先于乙。人行没有画面左、画面右、靠近镜头、远离镜头、前景、中景、远景，也不写 `纵深推=`。值为无的键没有留下。没有 `侧=` `偏=` `距锚=` `落点据=` `背对=` `触点=` `站位=` `眼神=同朝向`。位置是 `X=` `Y=` `Z=`。走位和动作方向用东南西北，写成从哪一向到哪一向，不用左右远近。方向在该句正文里。飞出、跑开、向前、后侧、身旁、前送、走至、案角，只在 `站位变因=` 里有罗盘 = 失败。走和递各有一条起止。沿的是主环境或动线里已有的东沿、南沿、西沿、北沿或路名，没有沿手臂、沿桌边、沿一边。开拍的 X 或 Y 已经在这一条边上，档是贴身或一臂。有走或递时，开拍在这一沿的起点，停下在同一沿的另一端，只一个罗盘向，朝向顺着走向或对着要碰的人。斜向、偏到沿外、沿一条不存在的路 = 失败。无挡不写绕。有挡写了绕过哪一具的哪一向，以及绕开时从哪一向到哪一向。没挡却绕、或只写绕过不写从哪一侧 = 失败。本拍 X、Y、Z 仍是开拍，不写成停点。停点写齐 X、Y、Z。下一拍开拍的这三项等于停点。停点只写一轴、下一拍把另一轴收成轴上、或下一拍仍留着开拍那一轴 = 失败。
- 每人 `方式=` 只一档。相对位置有锚，有 X、Y、Z。坐在点明的椅上是 X=轴上、Y=轴上、Z=椅面。本拍入戏是取物，锚是那张桌。每个人先有环境锚的 X、Y、Z，或原点的 X、Y，再写关系序。对坐、递接能读出谁在南、谁在北，或谁在东、谁在西。同一锚的两个人 X 与 Y 不全相同，沿边的间距写在那一条轴的档或端上。挽着的那只手只由朝向确认：站在被挽者左手边，同朝向是右手，相反朝向是左手；右手边对调。对不上已改手，推不出已去掉左右手。交付前或交互后只说明物在谁身上、脸朝谁，不把 `锚=` 写成对方。剧情要挂四壁那一具、中部又有主体时，站位写了 `双锚=` 和 `在其间=`，距离只写在锚的 X、Y 上。人话能读出在中部这一具朝向四壁那一具的那一侧，机位锚是中部那一具。参照已对上主环境北、东、南、西、中心的落点；落点不在这一向的具没有当锚。人在两具之间时，反打和换衍生环境后锚、双锚、X、Y、在其间仍是这两具。这一向落到画外时，世界位不改，建置用靠近镜头的这一侧替代这一向。方向仍看得见，没有改成靠近镜头。中部没有主体时，正文点名或从门入画，锚才是这一具或这一口。没有取物或交互的拍，人到中部与到另一具距离相若时，人锚和机位锚才是中部那一具。另一具近出一档以上，锚是最近这一具。反打没有把四壁升成锚。中部没有具名主体、正文也没写靠门靠墙的人在舞台中间，锚才是桌、椅或作为表演承托的床榻。封闭舱写的是排、东或西或中、功能和相对驾驶位，Z=椅面，同一排主副驾距是一臂，没有左起第。原点的 X、Y 都写了。
- 开拍站位是动作之前。终点在下一拍。无路径不换锚，也不改 X、Y、Z。有空间运动的正文和 `站位变因=` 都写了从哪一向到哪一向，两处是同一句，变因不能单独顶替正文。上下拍朝向或位置变了，正文在新动作前有匹配的补偿：只改朝向是转身，近处换位是走动，追赶是跑过，有沟台或高低差是跳过。每个在场角色、每个有正反面的道具都写了开拍 `朝向=`、`罗盘朝向=`。没有转身时不写 `朝向终=`、`罗盘朝向终=`，也不写 `朝向变=`。转了身才写终态两键，下一拍开拍朝向全文等于它们。无正反面的件不写这四键。无变化的键全文再抄，人行不写承上。上拍在场者没有无故消失。没有 `选择证据=`、`原文景别=`、`原文角度=`、`入场闸=`、`拍法=`、`针对=`、`机位=场内`。
- 乙没有改甲的锚、侧、朝向对象。新拍先写了 `拍法=`，再写 `当前环境=`。拍法只是正面、背面、侧面、过肩、双人同框。被看者要读脸时机位侧=正前，拍法是正面或过肩。双人同框不收成只剩一张脸。过肩的肩后写在框主的配对里，不写进被看者的机位侧。`主拍对象=` 与 `针对=` 同值。`框主=` 与 `近侧框主=` 同值。
- 朝向、眼神、面半空间、罗盘朝向是同一个面朝向。成稿不写 `背对=`。面朝的对向有具名主体时，只用来核对罗盘朝向，不另写一行。面半空间用北=后、东=右、南=前、西=左。眼神在身前，差 180° 的朝东望西 = 失败。对白、对视、递、握手的对象就是朝向对象。朝向对上具体主体，或明确是窗外、远方。文戏留下的左、右已按开拍面朝译成东南西北：面朝北则左=西、右=东，面朝东则左=北、右=南，面朝南则左=东、右=西，面朝西则左=南、右=北。成稿朝向不留左、右。正前脸朝镜头，正后背对镜头，左右侧对镜头；对不上不改朝向。人行没有 `面向镜头`。选拍法用的是本拍开拍朝向，不是本拍 `朝向终=`。
- `机位变因=` 只使用首拍、承上、反打、切角投影、换主拍、过肩换框、进出衬托、卖点加压、AI优势位。承上时机位锚、侧、距、机高、俯仰、望向、景别仍然全文在，`机位切换=无`。机位变=是时 `机位切换=` 到本拍机位锚、侧、距，不写上一拍机位。同一环境名之下景别变了，`机位变=否`，`机位变因=承上`，`ENV变=否`。上拍是单人正面、背面、侧面或过肩，本拍是双人同框，望向已按轴侧重算；新望向与上拍不同时度数变了，`ENV变=是:双人同框`，`机位变因=换主拍`。仍写上一拍的度数和 `ENV变=否` = 失败。从双人同框改回单人读脸，按正前重算，不留在双人同框那一度。同度只换 `_{状态}`、望向和机位锚侧距未变时，`机位变=否`，`机位切换=无`，`ENV变=是:环境状态`。换说话人、接招没有单独把环境名改掉。反打的望向与上拍差 180°。人在不在镜前按望向那一半核。侧面残缺而本拍不读那一壁，环境名不变。走位换角落在要读的那一面变成残缺侧壁或落到镜头后的那一拍。
- `当前环境=`、`望=`、`拍法=`、`[DERIVED_ENV:]` 同核。机位水平朝向等于这一度的正面：0度望北，90度望东，180度望南，270度望西。没有望向侧壁或画外。度数来自望向，只是 0、90、180、270。同一度上改了距离或仰俯，望向和环境名没变。衍生的衍生与同度数第一刀的拍法、望向、机位侧、机位锚、机位距相同，只多状态名。主名等于本拍载具档那一族，并逐字等于注入的舱内块或宿主块。没有把 Master 写成 0 度。整机主拍的主名是宿主。正文已是楼群或空域里的整机时，主拍对象未改成操纵台，机位锚不是舱内件，机高可以是远高于头顶。舱内拍没有本机机腹、机尾、两侧翼面、全机侧滚，没有两架整机，没有沿楼缝贴檐，机高不是远高于头顶。缺宿主块时已经回流环境规划。
- 景别与机位距默认一致。拍摄对象要求另一档距离时，机位行写了依据，没有为此改望向或换度。仰俯按景别和拍摄对象选定，有 `机高=`，没有为了俯或仰换度。靠墙靠门没有写过肩。竖屏 Two-Shot 是 MS 或 FS。
- 封闭舱入座写了排、东或西或中、功能和相对驾驶位。同一排驾驶座与副驾相距一臂，没有写成两步，也没有先离座走过去。没有左起第、后排左、驾驶位左侧。后排没有写到挡风之前。空地没有用整片沙或新造的沙丘当锚。同南北并立只写左右，同东西并立只写前后。
- 法相同框写了宿主法相同向和面对镜头。肩前悬浮的站位能检索到「悬浮于…肩前」。人载写了相对和载具面。不写脸时主拍不是骑手。
- 越级写了九类依据之一。已标 `职=句眼` 或 `职=关键反应` 的拍是 `CU` 或 `ECU`，针对者是说话人或接住这句的听者，不是 `MS` 或 `MCU`。可见名单的体量跟景别一致，盖不到的人不在名单里。接触、法相、载具同锚并且同在可见里。构图和留白已写，人行没有主体落点。机运和镜头角度配对。向距没有把窄向拍成大厅。
- 提取块的可见边界是具名实体，不是全画幅。第一刀的生成提示含截取宫格，不抄开篇四壁，不写路、纹路、中部和画面左右。衍生的衍生不写截取宫格，生成提示只写状态Delta。取用和递接的人和件在同一角。拆拍没有丢过程，依据在四类之内。场核的特写和运镜参考有对应衍生。本角背景微动件在 `背景=`、`画左=`、`画右=` 或白名单里。画外和不可见内容里的具没有当成微动件。光源的动态光影只写本角看得见的那一具。影子点名的光源也在这三键里。
- 天象、掀翻、墙与玻璃破损这类本场内不复原的变化：注入里已有变化后的那一块主环境，就挂那一块的第一刀。没有这块时，无状态第一刀仍只切割。变化留在画面里的度另有 `{N}度{主}_{状态}`，类型是衍生的衍生，父是同度第一刀，N 只是 0、90、180、270。状态行与同度数第一刀一样处理：拍法、望向、机位侧不另算。状态Delta写明哪一具、范围和具体样子。墙和玻璃的破法写了 `范围=一个洞` 或 `范围=整体崩碎`，没有只写破损。原文有破损句就写在 `依据=`。一个洞没有写成整间崩碎，整体崩碎没有写成一条缝。变化落到画面上的那一拍，`当前环境=` 是同度第一刀，`落幅环境=` 是同度状态行，两条 `[DERIVED_ENV:]` 都在。下一拍只挂状态行。场开场已经是变化之后的拍没有再切完好图。变化之后仍停在这块主环境的拍没有挂回无状态第一刀，也没有新造主环境名。后一处变化的父仍是第一刀，Delta含已经留下的全部变化，每一处仍有自己的范围。看不见该变化的度没有状态行。门窗开合、挪椅子、端走杯子没有状态行。出现 0、90、180、270 以外的度数 = 失败。
