## 通用硬约束（最高）
1. 不改事实/因果；未命中段落不改写。
2. 禁「同原文／见原文／如上／略」代替原文。
3. 环境注册名逐字；衍生主名段=所属主环境名。
4. 不改台词、左右手脚、取用、朝向对象、门开闭。过程句默认原样；仅 §2.3A 拆拍时按角拆写角色动作。场级 `节拍=` 链仅在拆拍后同步 B 号。非剧情明示的衍生环境朝向主体不成稿（§0.3）。
5. 四方正交可拍；常规禁 45°/对角偏斜。仅 §2.8 特别行可仰看天花/天空或变形。
6. 禁实拍执行语。
7. **可见性按 §0.5 裁定**：须先有宫格与 `主拍ENV=`。已入场禁标 `X`。锚/层位不在本拍 ENV，或特写非主拍 → `暂不可见`（带 `因=`）。主拍对象不得标暂不可见。禁通场全员 `V`。一格>3人必须拆格或拆拍。

## 0. 宫格 → 主拍ENV → 对打取景 → 可见性

每拍按 0.1→0.5 顺序写，禁先选角再补人。开拍位=上拍终态（无走位抄锚/侧/层位/宫格/`朝向=`/`朝向推=`/`背对=`/`体侧=`/`主拍ENV=`/`同簇相对=`的 0° 锁）。本拍过程含转身 → 本拍定位行仍写**开拍朝向**；新朝向从**下拍**定位行起写。同 ENV 只换主拍或收放景别 ≠ 改朝向/体侧。切角只改 `同簇相对=` 的本拍投影，不改 0° 锁。定位只写开拍落点，禁把过程写进 `细节=`（❌擦桌子/拍击/腾空/跃起）。

### 0.1 开拍 XOR 落点
【主体定位方案】覆盖开场已入场全员+可移动道具（禁只锁主拍）。【Beat主体定位】覆盖仍在场者（含暂不可见）+该拍待入画。走位改侧/细节/锚/宫格；改方式仅当出入封闭或离开锚。
先按**落点三级**定格与朝向，再写 XOR。❌先挤中格再找理由。

**落点三级（最高）**
1. **剧情明示**：原文 / 文戏 /【未落清单】已写锚、侧、座位、门侧、柜台后、第 N 桌等 → **原样落入**。禁为构图、正反打预留或避难点挪明示位。
2. **剧情分析**：明示未锁的空位，按下表统筹，让后文拍得成、卖点读得清。
3. **避难点**：1–2 皆无特殊要求时，按下表降低单视角生成难度。❌用避难点覆盖明示或分析。

| 级 | 因素 | 落点要求 |
| :--- | :--- | :--- |
| **分析** | 正反对白/对峙（本场将发生） | 双方分列、相向；**不同格**；预留 `主拍ENV` 相差 180°；旁观者离开对打轴（后文可标暂不可见） |
| **分析** | 并排对白/同行 | 同格或邻格同半空间；同向 |
| **分析** | 卖点/高潮读脸 | 主卖点角色独占可读格；`背对=` 具名后景；勿埋进群/后排 |
| **分析** | 入画/离场 | 落在将用出入口的邻格 |
| **分析** | 交付/触达 | 施受邻格或同格，一臂可达 |
| **分析** | 走位发展 | 起点不堵路径；终点格预留净空 |
| **分析** | 主客/座位 | 围桌锁 `辅=`哪一侧+`座=`该侧第K/M；舱锁 `排=`第N排+`座=`左起第K/M+`功能=`。身份跟剧情，禁对调、禁只写靠桌/后排 |
| **分析** | 群演疏离 | 原文未写围观/冲撞/贴身市集 → 簇不进具名对白/读脸拍；拆独立拍作簇主拍；落相对空格、与具名隔≥1 空格（§0.2B） |
| **避难点** | 单视角不密 | 无近距依据时，预计同框具名**分格**；一格角色≤2（角色组/明示贴身除外，仍≤3） |
| **避难点** | 身份可辨 | 同框人错开格或朝向；禁无据肩并肩贴脸 |
| **避难点** | 不挡脸/口型 | 后景人勿正对前景后脑；道具不挡主拍脸 |
| **避难点** | 留动作空隙 | 人与人、人与大件至少一臂；禁叠身叠脚 |
| **避难点** | 群演让位 | 簇占边/后空格，不占中/前中抢具名；禁与具名同格或贴邻格 |

成稿每行写 `落点据=`（只写命中的最高一级）：`明示:{锚或原文短语}`｜`分析:{正反|并排|卖点|入画口|交付|走位净空|主客位|群演疏离}`｜`避难点:{单视角疏离|错格可辨|不挡脸|留臂|群演让位}`。

**XOR 选序**
1. **座位为主**（舱/排椅/机甲操纵席）→ `方式=封闭`：须写满 §0.1A（`排=`第N排 + `座=`左起第K/M + `功能=`）。
2. **围桌/围案**（≥2 人同桌）→ `方式=相对`：`锚={桌}` + §0.1A（`辅=`哪一侧 + `座=`该侧第K/M）。禁只写靠桌。
3. 否则近身固定大件 → `方式=相对`：一锚。选锚优先唯一件；唯一锚只写锚名。同质多件先锁该参照物靠哪一端第几。`侧=`只供切角算法=`画左|画右|上|下|近镜头|远镜头`。**人在该锚哪一侧，锁这一侧的三维**：`四侧=`（可区分的面）+ `锚纵深=近|远` + 画左/画右 + 高低。三维挂在侧上，不标人。锚=本拍背景件 → 朝镜头面=`近`，背面=`远`；对向切角后按新机位重判。辅=`主位|客位|左长边|右长边|近门一侧|远门一侧|床头|床尾`。
4. 无明确相对锚 → `方式=绝对`：`前景|中景|后景` + `画左|中央|画右` + `高|平|低`。
5. **配饰**：`挂靠={角色}`｜`部位=`｜`体侧=`。独立道具走 1–4。
6. **角色组**：必须近距者整组同格；`组=`/`序=`/`朝向=`/`距=`写在定位行。禁另起【角色组】。无近距依据禁标组。
7. **同锚 / 同绝对格（最高；§0.2A）**：≥2 人 `锚=` 同一具名参照，或 `方式=绝对` 且 `层位×画位` 落入同一宫格，或封闭同排 → **必须**写 `同簇相对=`。`序=`/`距=` 不能代替三维。禁只写「并立 / 在一起 / 同在柜台前」。

### 0.1A 槽位锁（围桌 / 封闭舱强制）

多人围桌、排椅、车/机舱/机甲/轿子等封闭座位，**必须锁到唯一槽位**。`同簇相对=` 不替代本条。K 同侧/同排不重复，`1≤K≤M`，M=该侧或该排总位数。切角不改世界槽位（`排=`/`辅=`/`功能=`/`K` 守恒）；只改本拍投影与画幅词。

**围桌 / 围案（`方式=相对`）**
每人必填：`锚={具名桌/案}`｜`辅=主位|客位|左长边|右长边|近门一侧|远门一侧`｜`座=该侧左起第K/M个`（0° 面朝桌心或面朝 0° 后景时，该边从左数）。可兼 `功能=主位|客位`。
❌`靠桌`｜`围坐`｜`桌边`｜`主位旁`无 K/M｜两人同侧同 K。
✅`锚=八仙桌｜辅=左长边｜座=该侧左起第2/3个｜功能=客位`

**封闭舱 / 排座（`方式=封闭`；车、机甲、机舱、舰桥、轿子、剧场排椅）**
每人必填：`排=第N排`（从 0° 前向/操纵端往舱尾数，操纵排=第1排）｜`座=左起第K/M个`（面朝 0° 时该排舱体左→右）｜`功能=`闭集或载具惯例名=`驾驶座|副驾|后排左|后排中|后排右|操纵席|副操纵席|观察席|{原文具名座}`。
可核销 ID=`第N排-左起第K/M位-{功能}`。汽车司机=`第1排-驾驶座`；机甲驾驶员=`第1排-操纵席`；后方人员不得写到操纵员与前窗之间。禁套厅堂围坐进驾驶舱。
❌`在车上`｜`后排`｜`副驾旁`无排无 K｜只写`前景画右`。
✅`排=第2排｜座=左起第1/3个｜功能=后排左`

空座不写人行，但 M 仍按实有位数。入座/换座写入戏；本拍定位=开拍槽位。

### 0.2 3×3 宫格草稿（每拍；以 `0度{主}` 为唯一基准）

把 `0度{主}` 俯视场地虚拟成九宫。**不随本拍切角改格名**——切到 180° 只改可见性与本拍 ENV，宫格仍用 0° 世界坐标。

```
后景/远（0°背景向）   后左    后中    后右
中景                 中左     中     中右
前景/近（靠近0°机位） 前左    前中    前右
                     画左    中央    画右
```

**落入规则**
| 方式 | 入格 |
| :--- | :--- |
| **绝对** | `层位×画位` 直接入格：后景+画左=`后左`；中景+中央=`中`；前景+画右=`前右`；其余同理。 |
| **相对** | 先把 `锚=` 落到该锚在 0° 场地上的格，再按 `侧=` 微移：近镜头→前一档，远镜头→后一档，画左/画右→左/右邻格（不出场）。同锚且距=贴身/一臂 → **必须同格**。 |
| **封闭** | 排近镜头→前/中；排远→后；`座=` 左起第K决定左/中/右。围桌/舱位缺 `辅=`/`排=`/`座=K/M`/`功能=` → 未入格，回改 §0.1A。 |

**近者同格仅限剧情近距（最高）**：角色组 / 明示贴身 / 一臂交付才同格。无近距依据 → **分格**（避难点：单视角不密）。一格角色>3 → 按 `侧=`/`辅=` 拆到邻格；邻格仍超 → **拆拍**（各组挂不同后景）。无近距依据时一格角色≤2。道具随宿主格；无宿主的独立道具单独占格但不占人名额。群演簇整簇占一格、不计单个名额；落点与拆拍见 §0.2B。

成稿【宫格草稿】只写占用格：`B{n}=后中:{金镶玉+算盘}｜前中:{李玄}｜中左:{顺子}`。每人定位行写 `宫格=`。❌空格全列｜❌用本拍 180° 画左重写格名。

### 0.2A 同簇三维相对（同锚 / 同绝对格强制；切角须投影）

宫格只告诉「落在哪一格」。**格内 / 同锚仍是三维体积**——两人可以同在 `前中`、同站柜台画左，却一个偏画左近镜头、一个偏画右远一层。不写三维 → 生图叠身、左右对调、切角后站反。

**触发（命中任一即强制；每人一行）**
1. **同参照**：`方式=相对` 且 `锚=` 同一具名件（含同质多件已锁到同一具）。
2. **同绝对格**：`方式=绝对` 且 `层位×画位` 落入同一 `宫格=`（高低可不同，仍算同簇）。
3. **封闭同排**：`方式=封闭` 且同一 `排=`（`座=` 第 K 只锁左右序，仍须补纵深/高低）。
4. 角色组 / 明示贴身 / 一臂交付同格 → 必写（`组=`/`序=`/`距=` 不替代本键）。

未触发 → `同簇相对=无`。道具随宿主；独立可移动道具与人同锚/同格时同样写。

**0° 世界锁（只写【主体定位方案】与无走位继承）**
三轴必填，词闭集，坐标系=**`0度{主}` 画幅**（与宫格同基准；不随本拍切角改锁）：
- `画幅=`=`偏画左`｜`居中`｜`偏画右`（谁更靠 0° 画左 / 钉中央 / 靠 0° 画右）
- `高低=`=`上`｜`平`｜`下`（谁更高：站凳/踩踏/俯身/躺卧；四向切角**不改**此轴）
- `纵深=`=`近镜头侧`｜`同层`｜`远镜头侧`（谁更靠近 0° 机位 / 同层 / 更靠 0° 后景）

2 人：互写 `相对={对方}`。3 人同簇：每人 `相对={其余}`，并加 `画幅序=`/`纵深序=`/`高低序=`（只写有差的轴；左→右、近→远、上→下）。
❌`并立`｜`在一起`｜`柜台前两人`｜只用 `序=1/2` 不写轴｜用宫格名冒充格内相对（`宫格=前中` ≠ 谁偏画左）。

**本拍投影（【Beat主体定位】必写；ENV 变必须换算）**
先抄 0° 三轴，再按本拍 `ENV` 的 N 查下表，把分量写入**本拍画面词**。`宫格=` 仍是 0° 世界名，**禁止**用本拍画左重写格名。走位改格内相对 → 先改 0° 锁，再投影本拍。

| 0° 分量 | →0° | →90° | →180° | →270° | 落入本拍哪轴 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 偏画左 | 偏画左 | 近镜头侧 | 偏画右 | 远镜头侧 | 0/180=`画幅`；90/270=`纵深` |
| 居中 | 居中 | 同层 | 居中 | 同层 | 同上 |
| 偏画右 | 偏画右 | 远镜头侧 | 偏画左 | 近镜头侧 | 同上 |
| 近镜头侧 | 近镜头侧 | 偏画右 | 远镜头侧 | 偏画左 | 0/180=`纵深`；90/270=`画幅` |
| 同层 | 同层 | 居中 | 同层 | 居中 | 同上 |
| 远镜头侧 | 远镜头侧 | 偏画左 | 近镜头侧 | 偏画右 | 同上 |
| 上\|平\|下 | 原样 | 原样 | 原样 | 原样 | 四向皆 `高低` |

例：0° 锁 `甲偏画左+近镜头侧`、`乙偏画右+远镜头侧`。
- 挂 `180度{主}` → 甲=`偏画右+远镜头侧`，乙=`偏画左+近镜头侧`（左右对调、近远对调）。
- 挂 `90度{主}` → 甲=`纵深=近镜头侧`+`画幅=偏画右`，乙=`纵深=远镜头侧`+`画幅=偏画左`（原左右变成近远，原近远变成左右）。
- 高低原样。无走位不得改 0° 锁，只改投影。

成稿：【主体定位方案】`同簇相对=0度锁｜相对={名}｜画幅=偏画左|居中|偏画右｜高低=上|平|下｜纵深=近镜头侧|同层|远镜头侧`（3 人加序）。【Beat主体定位】`同簇相对=本拍投影｜相对={名}｜画幅=…｜高低=…｜纵深=…｜换算=0→{N}`。单人/分格无同锚 → `同簇相对=无`。
❌切到 180° 仍抄「甲偏画左」｜❌90° 仍把 0° 画左写成画左（应落入纵深）｜❌只改 ENV 名不改投影。

### 0.2B 群演簇（原则上独立拍 + 空格疏离）

剧情允许时，群演簇**原则上不跟具名挤同一主拍**。先落空格，再拆独立拍作簇主拍。

**落点（先于选角）**
1. 整簇独占一格；优先**边/后空格**（`后左|后右|中左|中右`），禁占 `中`/`前中` 抢具名。
2. 与最近具名 **隔≥1 空格**（不相邻）。禁同格、禁贴邻格并肩。
3. `落点据=`=`分析:群演疏离`（原文未写围观/冲撞/贴身市集）或 `避难点:群演让位`。
4. **明示例外**：原文/文戏已写围观、冲进、市集贴身、簇为交付/走位障 → 可邻格或同半空间远层；仍禁与具名同格叠身。`落点据=明示:{短语}`。

**取景（原则上独立衍生拍）**
- 拆成独立 Beat：`主拍对象=群演簇`｜`对打=无`｜景别 `EWS|WS|FS`｜挂**能看见该空格**的已声明 `{N}度{主}`（常 0° 建立或 90/270 侧角）。该拍具名非 R → `暂不可见`，不为簇改挂具名对白角。
- 同向不另起行：禁 `{N}度{主}_群演` / `_人群`。独立=**独立拍 + 簇作主拍**，不是新造环境名。
- 具名对白/读脸/MCU+ 拍：簇默认 `暂不可见｜因=景别不及`（或特写非主拍）。仅 EWS/WS 建立且簇在远层可读时，才可同拍作背景层——仍守空格、不抢「聚」。
- 须拆未拆 → §2.3A，`拆拍依据=群演疏离`。

❌无据把簇塞进具名 MCU/过肩同框｜❌簇与具名同格或贴邻｜❌为簇新造衍生短名。

### 0.3 背对 → 角色主拍ENV（每人）

1. **朝向成稿 vs 过程（最高）**：`朝向=` 只写**剧情明示**对象（人对人，或原文/文戏已点名的锚/出入口）。分析才推出的衍生环境主体（大门、对向墙、机位后半空间件等）**不成稿**，只写 `朝向推=面向{该件}`（定位行 + 该拍【取景锁定】）。正对镜头已锁定朝向 → 成稿 `朝向=面向镜头`，**禁再写「对着大门」**——该件此时在机位后、本角不可见，点名会让视频模型把对向件画进脸前。
2. 成稿 `朝向=` 闭集=`面向{明示具名}`｜`面向镜头`｜`无`。禁 `面向中心`。禁把 `朝向推=` 的环境名抄进 `朝向=`。无明示且非正对 → `朝向=无`，靠 `体侧=`/`背对=` 锁半空间。
3. `背对=`=其背后所对的具名固定实体或 0° 半空间（后中/门/内侧墙等）。背对物=本角可见后景，≠朝向成稿；锁 `主拍ENV` 用 `背对=` +（过程）`朝向推=`，不靠成稿点名机位后件。
4. `主拍ENV={N}度{主}`=**镜头正对该人脸、背景恰好是其背对物** 的那一行。该角专用于此人作主拍（读脸/对白主相位）。
   - 背对 0° 后景锚 → 主拍挂 `0度{主}`（脸朝镜头，背入后景）。
   - 背对 0° 前景/大门 → 主拍挂 `180度{主}`。
   - 背对画右半空间 → 主拍挂 `90度{主}`；背对画左 → `270度{主}`。
5. **转身不改本拍定位朝向**：本拍过程含转身 → 本行 `朝向=`/`朝向推=`/`背对=`/`体侧=`/`主拍ENV=` 仍=开拍（上拍终态）。新朝向只从下拍定位行写。❌本拍定位写成转后面向。
6. **同角朝向守恒**：同 ENV、本拍无转身 → `朝向=`/`朝向推=`/`背对=`/`体侧=` 抄上拍终态。❌因改挂主拍或 WS→MS 改 `体侧`。`体侧` 由开拍面向半空间 × 本拍 ENV 四向推出：面向远/近→偏正背；面向画左/画右锚→侧面。
7. 配饰不写主拍ENV。❌无背对却写主拍ENV｜❌把主环境名当主拍ENV｜❌`朝向=面向中心`｜❌成稿 `朝向=面向大门` 而剧情未写看门/对门（正对镜头时大门应在镜头后）。

### 0.4 对打 + 景别 → 本拍衍生

先判本拍人际，再锁 `主拍对象` + 本拍 `ENV` + `景别`。机位/构图随 §4。

| `对打=` | 剧情 | 本拍 ENV | 关系角 |
| :--- | :--- | :--- | :--- |
| **正反** | 相向说话/对峙；双方宫格分列、`主拍ENV` 相差 180° | 挂**主拍对象**的 `主拍ENV`；反打拍换挂对手 `主拍ENV` | `过肩`+`OTS类型=读对手`；`axis_crossing=PlannedReverse` |
| **并排** | 同向并肩/并坐/同行说话；同格或邻格同半空间 | 双方共用一个角（优先主拍者 `主拍ENV`，或 `90/270` 能同框的侧角） | `Two-Shot` 或 `同侧过肩`。竖屏 Two-Shot **须景别匹配**（对白/关系=`MS|FS`，禁 `MCU|CU` 双人满幅；§4.5.2）。禁标反打 |
| **无** | 单人/空镜/Insert/走位建立 | 跟主拍对象 `主拍ENV`，或建立用 `0度` | `干净` |

**景别跟距离（剧情）**：贴身/桌面对白→`MCU|CU`；数步对峙→`FS|MS`；走位/建立→`WS|FS`；卖点/Insert→`CU|ECU`。再按 §4.5.2 用项目横/竖屏收一档或拆拍。宫格相隔≥2 格（如后左 vs 前右）禁锁口型 `CU` 却标双方都 `V`——须拆拍或改 `FS|WS`。
画内 `V`≤4（竖屏对白常规≤2，§4.5.2）；一格>3 已在 0.2 拆完。未锁主拍+ENV+景别+`对打=` 不得写 §4；机位/构图未写入【取景锁定】不得进入 0.5。

### 0.5 可见性判定（每拍每人）

先读本拍 `ENV=` + `景别=` + `主拍对象=` + `对打=` + 宫格。已入场全员都要出结论。

```
入场态 → 主拍短路 → 相对/绝对分叉 → 成稿
```

| 步 | 问 | 是 | 否 |
| :--- | :--- | :--- | :--- |
| 1 | 已离场？ | 不入表 | 下一步 |
| 2 | 尚未入场？ | `待入画` | 下一步 |
| 3 | 纯画外声、本体不在本空间？ | `D` | 下一步 |
| 4 | =主拍对象（或其配饰/手持，或特写仍须同框的角色组）？ | `V` | 分叉 |

**特写总闸（`CU|ECU`）**：仅主拍（+配饰/手持；贴身组仅必须同框时）=`V`。其余一律 `暂不可见｜因=特写非主拍`。

**相对（人跟锚走）**：锚 ∉ 本拍白名单/画幅三锚 → `暂不可见｜因=锚不在本角`。锚在则看景别：`MCU` 仅主拍同锚+同格近身组=`V`，其他锚=`因=景别不及`；`MS` 同半空间且锚仍可读=`V`，远格/被裁=`因=锚不在本角`；`FS|WS|EWS` 锚在白名单且未被裁=`V`。

**绝对（人跟层位走）**：切角后重投影（前景↔后景）。层位落对向/机位后方 → `因=层位出画`。`MCU` 后景出画；`MS` 前中景=`V`；`FS|WS|EWS` 画幅内各层=`V`。正反打时非主拍若宫格仍在本角远层，`MCU` 及更近按景别裁，勿一律 `V`。

**封闭**当相对锚。**配饰**抄宿主。

**成稿**：`V` 写 `因=无`，计入画内人数。`暂不可见` 必写 `因=锚不在本角|特写非主拍|景别不及|层位出画`，`宫格=`/`锚=`/`层位=`不删。切角≠出画。回切能读到其格/锚 → 改回 `V`。

## 1. 只读主环境，按 Beat 挂衍生

## 2. 衍生环境（按内容建）
> **不变式**：所属主环境固定实体不增/不减/不矛盾；仅可见性可变。白名单只来自主环境登记；主环境有实体≠本角可见。已点名 `背景微动件` 且本角落点可见 → 入白名单，不另造、不改落点。

### 2.1 何时必须声明新角（衍生最小化 + 同向合并）
普通衍生闭集=`{N}度{所属主环境名}`，N∈`0|90|180|270`。**同一主环境同一方向只一行**，名必须逐字=`{N}度{主名}`。禁止因景别/构图/过肩/Insert/CU/反打用法/剧情覆盖短名另起 `{N}度{主}_{后缀}`（如`_近景` `_桌后反打` `_乙侧` `_柜台区`）。禁止用节拍短句/选择证据锚当环境名（`Beat:金镶玉拨算盘`、`0deg Beat:…再收紧些`、`文戏:拨算盘`）。景别与用法只写拍摄键，挂已声明该向。
须声明新角=任何真正反打/读对手｜切镜头致正背面档位变化｜背对须读正面内容｜越轴｜>90°｜门窗内外/POV/状态｜**异排且异向**｜§2.8 仰视。前向驾驶舱“异排但同向”不属于本项，按驾驶舱槽位可见性声明0°/180°/90°/270°读角。Insert/CU/同侧过肩且档位/扇区不变→沿用父、禁新行。无 Beat 覆盖的冗余角不建。❌同向因 WS/MCU/CU 拆多行。

### 2.2 每行必填
每衍生行必填：名 / `view_angle_from_main` / 触发 / `spatial_axis` / `lens_profile` / `axis_crossing` / `empty_view_delta`，以及 `活动适配` / `可见内容白名单` / `可见边界` / `不可见内容` / **`背景=` / `画左=` / `画右=`**。头尾双锚已在主环境声明。禁止写前中后景空镜层次、材质光色细参、四向拼图成稿。
- `活动适配=…`：本角后景/表演区可承载什么动作。
- `可见内容白名单=…`：本角允许进入画面描述的**全部具名固定陈设/出入口/结构及其可见面**（轻量名称+面）。所属主环境已点名 `背景微动件=` 且本角落点可见 → **须入本行白名单**（不强制作 `背景=` 主锚；细小件可挂后景/贴边）。**舱内**：白名单只锁座椅/挡风/方向盘等固定面，**不授权乘员脸**；`0度{舱}`禁写`后排座:正面`或任何人脸（0°望挡风时后排可见面=靠背背面）。**`90/270度{舱}` 须列全部座位**（驾驶座|副驾|后排各座，有则全写）并标近镜头侧/远侧可见面，禁只写半舱。**禁** `CHAR:`/`PROP:`/人名/动作/持握/表情/特效过程。
- `可见边界=…`：画幅边界与禁止越出的对向/机位后方。**`可见边界=全画幅`无效**——必须用具名实体/结构写清左界、右界、上界、下界/近端截断。左界/右界须与 `画左=`/`画右=` 同名件。
- `不可见内容=…`：与本拍易混淆的对向**固定陈设** / 不可见面。禁角色/道具动作。
- **画幅三锚（强制；提取块同核；空镜锚）**：`背景=`/`画左=`/`画右=` **只写本角可见的主环境固定陈设/出入口/结构**。`背景=`＝镜头正对、落后景主位的具名固定件（∈白名单；对向件禁入）。`画左=`＝画幅左侧缘具名件（∈白名单；`(N+270)%360` 贴边可见）。`画右=`＝画幅右侧缘具名件（∈白名单；`(N+90)%360` 贴边可见）。三键必填；该侧确无具名件才写`无`。禁只写方位不写实体。仰天特别行背景可写天花/天空具名结构。**禁**把角色、可移动道具、动作、表情、特效写进三锚或自造 `参照物=`。❌`背景=CHAR:[@金镶玉]冷冷逼视`｜❌`参照物=…、CHAR:[@李玄]后背撞上木门、PROP:[玉佩]脱落`。✅`背景=二楼雕花栏杆｜画左=客栈大门｜画右=柜台`。
**衍生主名段必须=所属主环境名。**

### 2.3 先核本拍必见项与单角覆盖，再设计衍生（最高；只核，不成稿矩阵）
先锁 §0.4 本拍 ENV+主拍+对打，再逐 Beat 盘点 **R（必见集）**——不是已入场全员。
R 只含：①主拍对象锚/承托面/排座；②本拍动作交互固定实体；③手持/桌面/配饰可见面；④Insert；⑤本拍走位的出入口与终点；⑥特效命中；⑦本拍必须读到的背景叙事锚。画面明写的主体/动作/交互/挂靠/路径节点/弹道命中面进 R；纯声音、对白提到、望向画外标 D。
**已入场但非 R**：不进 R。锚不在本角或特写非主拍 → §0.5 标 `暂不可见`（带 `因=`），**不为他改挂或拆拍**。❌已入场禁「可暂不可见」。
每项 R `必须可见=是|仅画外方向D`。再核该 ENV 能否覆盖**同一拍全部 R**。R 的锚不在本角 → 改挂可见该锚的四方角或拆拍，**禁改 `X`**，禁换远锚凑覆盖。禁先选角再补实体。核销结果写入该拍【取景锁定】`跨对向=`/`拆拍依据=`/`画内V=` 与【Beat主体定位】，禁另起覆盖矩阵。
- **必见集成稿**：`R={…}` `W={…}` `R−W=∅`（只核 R，不把非 R 的已入场者塞进 R）。
- **选角序**：`已锁定位锚可见 > R完整覆盖 > 交互面可读 > 露脸可拍 > 守轴 > 切换成本`。**0 度无优先权**；空镜角只取 0/90/180/270。
- **剧情覆盖只选/补四方角，禁短名拆行**：覆盖不足时声明或改挂 `{N}度{主名}`（N∈0/90/180/270）。禁止 `{N}度{主}_{短名|景别|桌后反打}`。同向白名单取该向半空间并集（守对向零可见）。单角无法完整看见→**拆成多拍**，每拍只挂一角（§2.3A）；禁一拍挂两角。
- **交互链同显**：文戏已写的取用/开门/递接须同时命中`执行者+承托/挂靠实体+道具+被读取的面`。`桌区:全部面`不授权酒盏。触达对象开拍为 V。
- **同框锚**：R 内主体的锚/承托面须同属某一声明角白名单+活动适配。非 R 者不要求同框。驾驶舱后排×司机同框只可 `90/270`，该角须近镜头侧+全部座位。
- **一拍跨对向则拆拍**：R 分属 N 与 N+180 时不得同收一角，须按 §2.3A 拆成多拍、一拍一 ENV。

### 2.3A 一拍一衍生（最高；覆盖不足可改 Beat）
每个 Beat **只能对应一个**已声明衍生环境。`当前环境=` / `[DERIVED_ENV:]` 恰好一个完整名。禁一拍并列两角。
- **选角仍先于改拍**：先锁 §0.4，再选能覆盖本拍全部 R 的单角。盖得住且画内具名/有戏≤4 → 正文零改写（只套 `ENV:` + CHAR/PROP 复查）。
- **盖不住才改 Beat**：该角白名单+活动适配+边界无法完整覆盖 R（含跨对向、交互链不同显、同框锚分属对向、走位/投射一角装不下）→ **拆拍改写**：将一拍拆成多拍，各拍只写能被**该角**看见的角色动作/过程，再各挂对应 `{N}度{主名}`（或合法状态/仰天行）。禁为凑覆盖改对白词、因果、左右手脚/取用/朝向/门开闭合同。
- **画内>4 必拆**：本拍 `可见性=V` 的具名/有戏人数（角色组按组内计）>4 必须拆。拆后每拍 ≤4，各组挂不同后景 ENV。可按组/按角：各拍只写该组在该角可见的动作。
- **群演疏离可拆**：剧情未写围观/冲撞/贴身市集，却把簇与具名对白/读脸同拍近框 → 按 §0.2B 拆出簇主拍，挂看见其空格的已声明角。`拆拍依据=群演疏离`。禁为簇新造 `{N}度{主}_群演`。
- **拆拍合同**：过程/特效句按角分配且全出（禁吞并）；每拍自备【配乐】【音效】与【取景锁定】；从 1 重排；场级 `承接=`/`节拍=`/`落地=` 与输入【Beat切分确认】的 B 号/拍数同步；该拍锁定行 `跨对向=否`，写 `拆拍依据=ENV覆盖|角色超限|群演疏离`。❌一拍挂两 ENV｜❌画内 V>4 不拆｜❌拆拍后丢过程或改台词。

### 2.4 主环境对向位零可见（最高；固定环境实体）
对当前观察轴 N，主环境四向中位于 `(N+180)%360` 的对向边界实体及其附着/承托物列入`不可见内容`，与白名单交集=∅。禁因“写背面/广角/稍带到”塞回。相邻 ±90° 仅`可见边界`明示贴边小部分可入白名单，不能整面入镜。
- **舱内 90/270**：近镜头侧门框/窗框+全部座位侧面进白名单。对向零可见只约束舱外街景，禁把近侧半舱座位整排进`不可见内容`。

### 2.5 轴线
先列 R，再为覆盖 R 的真实机位建 `{N}度…`。禁轮角、禁无拍冗余角。定 0° Master 后写本场 `spatial_axis`，后续守轴：

| `axis_crossing` | 何时允许 | 要求 |
| :--- | :--- | :--- |
| `None` | 同侧微调、非反打 Insert/CU、沿用父观察侧 | 不跨 `spatial_axis` |
| `PlannedReverse` | 正反打/读对手（沿轴线对向，典型 ±180°） | 触发须含 `N_对手→(N±180)%360`；左右屏关系与轴线闭合 |
| `MotivatedCross` | 仅剧情明文动机越轴 | 须写动机一句；禁无动机为「换个角好看」而跨轴 |

禁：无动机在轴线两侧来回跳；把越轴标成普通反打；为填满清单而建跨轴角。

### 2.6 反打 ENV / 状态衍生 / 出入舱触发
- **反打 ENV**：先定所需背景/对手可读面，再算 `N_对手→(N±180)%360`；该行白名单须能看见所需内容。`axis_crossing=PlannedReverse`。非反打 Insert 不另建行。
- **状态衍生**：仅跨拍可持续的结构/重大氛围改写才建 `{主}_{状态}`；`{N}度{主}_{状态}` 每行仍须写 `所属主环境={主}`。禁止把景别/反打用法写成状态后缀。
- **出入封闭舱**：仓外/仓内两块主环境已由环境规划声明。本文件须为两族各声明衍生；仓外族白名单含载具外部本体+各具名门扇；仓内族按载具惯例写座舱。声明触发名=`入舱切主环境|出舱切主环境|回切仓外主环境`。换主名≠反打。
- **闪回/蒙太奇切主**：各主环境各挂各衍生族；声明触发名=`闪回切主环境|闪切切主环境|蒙太奇切主环境|回切当下主环境`。

### 2.7 按主拍ENV核后景（选角已由 §0.3–0.4 锁）
本拍 ENV **先跟 §0.4**：正反=主拍对象的 `主拍ENV`；并排=共用一角；无=主拍对象 `主拍ENV` 或建立用 `0度`。本节只核后景是否等于其 `背对=`，不另起选角。禁无据粘`0度`、机械轮角。

| 画面事实 | 应挂 | 禁挂 |
| :--- | :--- | :--- |
| 主拍对象 `背对=` 具名后景锚 | 其 `主拍ENV`（该角 `背景=`=该背对物） | 对向角（背对物落到机位后方） |
| 空镜/建立，后景须见大门 | 可见大门的角（常`0度…`） | 可见对向王座的角 |
| 空镜/建立，后景须见内侧/王座 | 可见王座的角（常`180度…`） | 可见大门的`0度…` |
| 外景航拍/山巅建立 | 外景族`{N}度…` | 厅内`0度…` |

❌把「面向王座」写成「背对王座」再翻 180°。❌按「背对王座」却挂可见大门的角。
选 ENV：①§0.4 已锁主拍+对打 → ②取主拍对象 `主拍ENV`（空镜才按后景内容） → ③核 `背景=`≡`背对=` → ④守轴+活动适配 → ⑤核同 ENV 连续次数（≤3）。

### 2.8 特别衍生（仰视）
仅当空镜资产本身必须仰看天花/天空时另建一行。Beat 只锁`镜头角度=仰拍/虫蚁/航拍`而空镜仍是平视宫格 → **不建**特别行。屋顶并入仰天，不另起 `{N}度{主}_屋顶`。荷兰角/变形透视写拍摄键，不另建衍生行。
名=`{N}度{主}_仰天`。N 仍取所属半空间 0/90/180/270。`类型=特别`。
**`特别表述=`（仅本类必填；普通四方行禁止写）**=`仰天:{一句可核销空镜}`。
例：`仰天:满幅夜空与檐口剪影，地面仅近端截断`。
❌无据建特别行｜❌普通行写`特别表述=`｜❌把仰拍对白主拍建成仰天空镜｜❌按景别为同一方向另起行。

## 3. 选用节奏与过肩
- **连续≤3**：同一衍生名连续拍不得超过 3（可稍后切回，每段仍≤3）。合理换角=`R−W=∅`+对向零可见+守轴+非无动机越轴。满 3 优先切已声明他角；现有角皆不能覆盖才补侧向。
- **例外（须写依据）**：①本场≤3 拍；②转身且半空间未变（计入连续）；③唯一覆盖角（标`唯一覆盖角`+R−W）；④连续位移切角破动量最多+1。武戏快链豁免。
- **读对手 vs 同侧过肩**（`关系角=过肩|过腰|OPC` 时必须写`OTS类型=`）：

| 类型 | 判定 | ENV |
| :--- | :--- | :--- |
| **读对手 / 反打** | 越过近侧看对方脸；或对白换可读方；背景半空间翻转 | 挂对向 `{N}度…`（`PlannedReverse`）；`OTS类型=读对手`；`ENV变=是` |
| **同侧过肩** | 半空间不变；近侧只作框 | 沿用父 ENV；`OTS类型=同侧过肩`；禁标反打 |

❌读对手却同父 ENV｜❌同侧过肩标反打。

## 4. 景别与构图
每拍须同时锁环境 + 机位 + 景别构图：拍摄键与推导键（含`选择证据=`/`朝向推=`/`跨度=`/`剧情匹配=`/`[DERIVED_ENV:]`）都写在该拍【取景锁定】，禁另起拍内【场记分析】或场头【Beat景别构图方案】。
**选型序（接总序 ④b）**：§0.1–0.3 宫格与主拍ENV → §0.4 对打+景别+本拍 ENV → 本节补机位/构图写入【取景锁定】 → §0.5 可见性 → 核跨度 → 四轴证据。禁通场 `MCU+三分+平拍` 无据交差。对白/交付/动作空间/画幅/`-`/`~`→§4.5；机位→§4.6。

### 4.1 景别（七档完整；必须与剧情匹配）
闭集（成稿只写英文档）=`EWS|WS|FS|MS|MCU|CU|ECU`。原文远近词（大远景/远景/全景/中景/近景/特写/大特写）映射本表并写`原文景别=`。原文`航拍/俯拍/仰拍/平拍`写入`原文角度=`与`镜头角度=`，不占景别档。每拍须能指回本表画幅覆盖。

| 档 | 中文 | 画幅覆盖（可核销） | 典型剧情功能（须命中其一） | 禁用于 |
| :--- | :--- | :--- | :--- | :--- |
| **EWS** | 大远景 | 人极小或不可辨；环境/地貌/城廓/阵势为主 | 开场建立、宏观规模、孤绝渺小、环境文学空镜、满幅特效/战场余波 | 口型对白主拍；贴身交付；读脸反应 |
| **WS** | 远景 | 人可辨轮廓+全身；空间关系/动线可读 | 空间交代、走位入场、群像关系、对峙拉开、空镜主景 | 口型主拍；ECU 级细节冒充远景 |
| **FS** | 全景 | 主体从头到脚完整；可带近距环境 | 全身动作、入座起身、打斗起势、空间交付同框、礼法站位 | 只拍脸的反应；道具文字 Insert |
| **MS** | 中景 | 约腰/桌面以上；手势+半身关系可读 | 关系镜、动作+对白同相、双人/多人同框、听者反应默认 | 须读眼部微表情却裁掉脸；须见全身间距却裁脚 |
| **MCU** | 中近景 | 胸/肩以上；口型+表情可读 | 对白加压主拍、过肩/反打读脸、隐忍审视 | 空间交付主相位；数步对峙同框；群演主拍 |
| **CU** | 特写 | 脸或等大物件为主；肩可入画缘 | 情绪砸点、听者反应链、关键道具首次可读、`~`精髓拍 | 数步同框无交代；只拍施动者丢掉受者；群演脸 |
| **ECU** | 大特写 | 眼/唇/手/伤口/文字/机关局部填幅 | Insert、契科夫枪、屏/信字样、命中局部、细节特写参考 | 口型对白主拍（唇部 ECU 仅停顿/欲言又止）；走位关系 |

- **`剧情匹配=`**（每拍【取景锁定】必写）=`建置`｜`走位`｜`对白`｜`交付`｜`反应`｜`特写`｜`空镜`｜`宏观`。建置/空镜→横屏 EWS/WS，竖屏 FS/WS（EWS 仅宏观/孤绝）；走位→横屏 WS/FS，竖屏 FS/MS；对白→横屏 MS/MCU/CU，竖屏单人/过肩 MCU/CU、**Two-Shot 须 MS|FS**（口型须面部可读）；交付→FS/MS 同框施受；反应→MCU/CU；特写→CU/ECU；宏观→EWS/WS。细则§4.5.2。
- 贴身→MCU/CU；数步对峙→WS/FS。
- 交付/对白/画幅细则→§4.5。非反打收紧沿用父 ENV；读脸反打切可读角。
- 原文`△近景/特写`须落入对应拍并写`原文景别=`。
- 环境文学空镜：独立拍，WS/EWS，ENV 挂该文学主景。
- **群演**：只进 `EWS|WS|FS`；禁 `MS|MCU|CU|ECU` 群演主拍（宏观满幅例外，仍禁单人格特写）。剧情允许时簇主拍走独立 Beat（§0.2B），不与具名对白同框。
- `MCU|CU|ECU` 不得标`纵深层=前中后同时可读`。

### 4.2 构图档（主档+可兼完整；必须与剧情匹配）
主档闭集必选一=`三分`｜`中心`｜`纵深`。可兼闭集可多或无=`对称`｜`框中框`｜`引导线`｜`负空间`。禁止另造主档名（黄金分割/对角/三角等映射回本闭集：偏置→三分；居中仪式→中心；前后层→纵深）。
成稿每拍【取景锁定】写：`构图=三分|中心|纵深｜可兼=对称|框中框|引导线|负空间|无｜主体落点=画左三分|中央|画右三分｜留白=视线前|运动前|无｜纵深层=前中后同时可读|浅层单焦`。

| 类型 | 层级 | 可核销画面结果 | 典型剧情功能 | 禁 |
| :--- | :--- | :--- | :--- | :--- |
| **三分** | 主档 | 主体落画左/画右三分交点；对侧留白 | 对白交流、对峙分列、视线/运动引导、常规叙事 | 标三分却钉中央；无留白的假三分 |
| **中心** | 主档 | 主体或对峙轴钉画面正中 | 仪式/权力/Iconic、对峙轴、揭示砸点、对称殿堂 | 无仪式/权力/砸点依据的闲聊对白通场中心 |
| **纵深** | 主档 | 前/中/后至少两层同时可读 | 空间层次、走位避障、门—桌关系、前后排对戏、建立空镜 | MCU/CU/ECU 假标多层；必读层不可见 |
| **对称** | 可兼 | 左右或轴对称可检索 | 殿堂/礼法/对仗/仪式 | 无对称结构却空标 |
| **框中框** | 可兼 | 门洞/窗/廊/肩/器物形成内框 | 窥视、隔障对话、进出门槛、细节特写收束 | 无可见内框却空标 |
| **引导线** | 可兼 | 道路/廊柱/队列/桌沿把视线导向主体 | 入场动线、队列、通道压迫 | 无线可循却空标 |
| **负空间** | 可兼 | 主体占比小、大块空/暗/远景压人 | 孤绝、被监视、渺小、低点放大 | 热闹群戏无据大留空 |

- 对白/对峙：横屏默认三分+视线前留白；竖屏默认中心或纵深叠层（横向不够钉宽三分）。仪式/Iconic→中心；走位/前后层→纵深；窥视/门槛→框中框；通道→引导线；孤绝→负空间。可兼须有可见依据。
- `主体落点=`：相对/封闭不改锚位；绝对须与构图落点同向。关键/空镜/道具特写/Iconic 拍的构图须有剧情依据，禁无故通场同档。
- 有视线/运动→`留白=视线前|运动前`；中心钉死可`无`。`可兼=负空间`时留白字段仍须写方向或无。
- **留白须可核销空边**：`视线前|运动前` = 该方向有 Head Room（头顶）与 Lead Room（视线/运动前）可量空边；`无` = 中心钉死可贴顶但禁裁颅。禁标留白却贴边满幅。

### 4.3 跨拍切换
每拍【取景锁定】写`上拍景别=`与`跨度=`。`同级`＝同档；`邻档`＝沿 `EWS↔WS↔FS↔MS↔MCU↔CU↔ECU` 移 1 档；`越级`＝跨≥2 档，须写`越级:{依据}`。默认只允许同级/邻档。
**越级闭集**：①原文`△特写`/`细节特写参考`；②卖点/高潮/`~`；③Insert；④空镜/宏观后切特写陪衬（或回切）；⑤交付拉开；⑥反打只为读脸且落幅仍同级/邻档——**反打不是 EWS↔CU 的依据**。
对白链两侧同级或邻档，只翻 ENV/`主体落点`。构图主档随功能变，禁无功能轮跳；反打默认同主档只翻落点。
近景链满 3 且下拍有走位/交付须拉开；远景链满 2 且已入对白须收近（宏观例外+依据）。
关系角≠景别：过肩对白另锁 `MS|MCU|CU`；交付 Two-Shot/过腰另锁 `MS|FS`。

### 4.5 选型专规
#### 4.5.1 对白景别
口型主拍、可见 OS/V.O.、反打/过肩读脸、反应、微表情 → **`MS|MCU|CU`**（过肩对白典型 MCU；竖屏单人口型默认 MCU|CU）。禁 `EWS|WS` 常规口型（宏观/特效满幅例外+依据）。听者与说话拍同级或邻档。
文戏 `voice_type=VO|旁白` **可与动作/画内对白同拍**，不因 VO 拆拍；该拍主拍跟画面功能（听者脸/空镜/Insert），**禁把 VO 当口型主拍**，禁漏抄上游 VO 行。
竖屏 Two-Shot 对白合法，**景别必须匹配**：双方同框可读 → 锁 `MS|FS`（优先纵深叠层）；禁 `MCU|CU` Two-Shot。3 人+：具名各锁单人/过肩近档。Walk-and-Talk：横屏 `MS`（可邻 `FS`）；竖屏 Two-Shot=`MS`，单人=`MS|MCU`。自白/画中画说话人锁 `MS|MCU|CU`。

#### 4.5.2 画幅 → 景别侧重（读项目信息；最高）
先读注入 `────【项目画幅】────` / `# Project Context` / `Aspect Ratio` / `aspect_ratio`。未注入按**横屏**。每拍【取景锁定】写 `画幅=`。
- **竖屏**＝height≥width：`9:16`｜`3:4`｜`4:5`；`1:1` 跟竖屏策略（Two-Shot 须景别匹配，优先纵深叠层）。
- **横屏**＝width>height：`16:9`｜`4:3`；`21:9` 横屏再偏远/左右分列一档。
功能闭集不改（口型仍禁远景；`~`/原文特写仍跟专规）。画幅只**收档、拆拍、换构图**，不另造景别名。

**为何分策**：竖屏纵向长、横向窄——单人上下身与前后纵深好读，左右并排若景别过近会挤半身。横屏横向宽——左右分列、群像关系好读，单人 MCU 两侧易空。竖屏**允许 Two-Shot**，但景别须能同时读两人（对白/关系=`MS|FS`；交付=`FS|MS`）；`MCU|CU` 只给单人或过肩。

| 功能 | **竖屏侧重** | **横屏侧重** |
| :--- | :--- | :--- |
| **对白/反应** | 单人/过肩=`MCU\|CU`；**Two-Shot=`MS\|FS`**（优先纵深叠层） | `MS\|MCU`；Two-Shot 可 MS；3 人+分拍 |
| **建置/空镜** | `FS\|WS`；`EWS` 仅宏观/孤绝；下一对白须收近（Two-Shot 对白可停 MS） | `EWS\|WS\|FS`；远景链满 2 仍须收近 |
| **走位** | `FS\|MS`；Walk-and-Talk Two-Shot=`MS` | `WS\|FS`；Walk-and-Talk 可 `MS\|FS` |
| **交付** | `MS\|FS` Two-Shot 合法；禁双人 CU 硬塞横向指鼻 | `FS\|MS` Two-Shot 优先 |
| **并排** | Two-Shot 合法，**景别匹配**（`MS\|FS`）；优先纵深叠层，慎 MCU 左右并坐 | Two-Shot 或同侧过肩；左右分列合法 |
| **构图** | 中心 / 纵深；`主体落点` 偏中央；慎宽三分左右钉 | 三分+视线前；对峙左右分列 |
| **画内 V** | 对白/近档常规 **≤2** 具名（近侧框主可+1） | ≤4（原闸） |
| **CU 配额** | 本场可 **20%–30%**（手机观看偏近） | **15%–25%** |
| **群演** | 更须独立拍（§0.2B）；禁塞进竖屏对白近框 | 独立拍原则同 §0.2B；WS 远层可作背景 |

❌竖屏 `关系角=Two-Shot` 却锁 `MCU|CU`｜❌竖屏建置后对白仍 WS｜❌横屏通场 MCU 把空间挤没｜❌用画幅当借口改口型远景或丢掉交付间距。
交付拉开见下条。竖屏 Two-Shot 交付仍锁 `MS|FS`，不得为收近裁掉施受间距。

#### 4.5.3 空间交付拉开
须同见施受+轨迹+间距（指鼻/递物/扇耳光/拍肩/抵喉/抓领等）时：禁 `CU|ECU` 单人裁对方；锁 `FS|MS`；`剧情匹配=交付`。竖屏优先 `MS|FS`，禁双人 CU 硬塞横向指鼻。

#### 4.5.3A 动作空间（物理路径可读）
文戏已写的位移/投射/交付须进本拍 R，且 `活动适配` 能承载该路径。
- **走位**：起点锚+路径节点+终点 ∈ 白名单。直线开拍→终点有障（家具/柱/人/门扇）→绕障节点（`{具名}之画左|画右|近镜头|远镜头`）须进 R；一拍装不下曲折绕障 → 按 §2.3A 拆拍（一拍一 ENV）。门开合的人站侧与扇展侧同核。`剧情匹配=走位` 时 `纵深层` 跟路径层。
- **投射**：出手点+弹道经过+命中面须同角可见，否则拆拍。
- **近身接触**（牵手/拥抱/接吻/缠斗）：锁 `过肩|过腰|Two-Shot` + `FS|MS` 或局部特写；禁 EWS 扛复杂缠绕。
- **手部精细**（写字/弹琴/系扣）：锁 `CU|ECU` 手部或切脸，禁远景细描手指。
- **形变/进食**：禁一拍远景走完 A→B 全程；拆 `~` Insert 或邻拍。

#### 4.5.4 特写配额与卖点
常规有戏场（≥3 Beat）：`CU|ECU` 拍约占本场 **15%–25%**（竖屏可 **20%–30%**，§4.5.2；纯过场/宏观满幅场可低于此，须写依据）。卖点/高潮/低谷/【高潮与核心情绪点】/`细节特写参考`/桥段击中·命中·法攻效果/过程穿插表情，须落入已锁 `MCU|CU|ECU` 的拍（主高潮优先「角色近景 + 环境 Insert」分拍或紧邻拍）。**禁止**把卖点/高潮/低谷全程压在 WS/MS。`~` 精髓拍必须锁 `CU|ECU`。配额只核销，不成稿综合块。

#### 4.5.5 拍型 `-`/`~` 与快节奏
| 上游拍型 | 景别锁档 | 禁 |
| :--- | :--- | :--- |
| **`- Beat`** | 快交代偏 `MCU`（对白快交代）或跟功能（走位/交付仍 WS/FS/MS） | 把交代拍锁成全程 ECU；用 EWS 扛近身快戏 |
| **`~ Beat`** | **必须** `CU|ECU`（Insert→ECU） | 用 WS/FS 冒充砸点；精髓拍锁远景 |
| **快节奏打斗/追杀** | 贴身链偏 `MCU`；命中/效果可邻档 `CU`；宏观满幅跟 §4.5.1 例外 | EWS/WS 扛近身连击无依据 |

#### 4.5.6 局部特写与远近备档
局部特写须服务本拍功能（唇/眼/手/字/伤口）；禁无据孤立凝视。成人向局部仅成人角色，须服装/剪影覆盖，禁裸露与未成年人性化。
关键/卖点/弧光拐点：须有 EWS/WS 或 CU/ECU 至少一档落地（可分拍），禁通场只锁 MS。

### 4.6 机位（俯仰 + 关系角）
成稿每拍【取景锁定】写：`镜头角度=`｜`关系角=`｜`OTS类型=`｜`近侧框主=`｜`主拍对象=`｜`主观角色=`｜`角度动机=`｜`原文角度=`｜`上拍镜头角度=`｜`角度跨度=`。原文平视/仰视/俯视/OTS/鸟瞰写入`原文角度=`并映射本闭集（成稿键只写短词）。

#### 4.6.1 俯仰
| 档 | 原文同义 | 可核销 | 跟 `角度动机=` | 禁 |
| :--- | :--- | :--- | :--- | :--- |
| **平拍** | 平视 | 眼高/胸口，镜头水平 | 对白默、常规建置、过肩反打默认 | 压迫/渺小通场平拍无据 |
| **仰拍** | 仰视 | 自下向上；须高度锚（膝/腰/桌沿） | 压迫、崇高、巨物、权威 | 借仰拍改跪姿；口型用虫蚁冒充 |
| **俯拍** | 俯视 | 自上向下；**非航拍** | 压迫、布局、桌面 | 室内桌面升航拍 |
| **微仰** | — | 略低于眼高 | 轻微权威 | 无据通场 |
| **微俯** | — | 略高于眼高 | 桌面、轻度弱势 | 无据通场 |
| **虫蚁** | 贴地仰 | 贴地/桌面仰 | 渺小、倒地、贴地道具 | **口型主拍** |
| **航拍** | 鸟瞰 | 远高于头顶 | 宏观 | **口型主拍**；作 0°轴 |
| **主观** | POV | 机位=某角色眼位；主观者画外 | 窥视、看见 | 无看见依据；该主观者口型 |

- 口型主拍默认`平拍`；禁`航拍`/`虫蚁`/该主观者口型。
- 反打默认同俯仰；反打不是换俯仰的依据。
- **高度锚（须可核销）**：平拍=眼高或胸口；微仰/微俯=略偏眼高；仰拍=膝/腰/桌沿等具名高度；俯拍=相对头顶的高度差（非航拍）；虫蚁=贴地/桌面；航拍=远高于头顶。可写入`角度动机=`句内。
- 主观须点名`主观角色=`。
- 原文「俯拍大远景」→`景别=EWS｜镜头角度=俯拍`（宏观则`航拍`）。
- 峰值/压迫/渺小/崇高须由`镜头角度=`+`角度动机=`核销；口型可写「平拍保口型」且邻拍/构图已加压。禁无据`平拍｜对白默`交差。

#### 4.6.2 关系角
| 档 | 可核销 | 跟 | ENV |
| :--- | :--- | :--- | :--- |
| **干净** | 主拍独自满幅 | 单人/Insert/空镜 | 跟本拍衍生 |
| **过肩** | 越过近侧肩看远侧脸 | 对白反打、读脸 | §3：`读对手`换对向；`同侧过肩`沿用父 |
| **过腰** | 越过近侧腰看远侧 | 交付、桌面递接 | 同过肩 |
| **OPC** | 越过近侧半身取远侧 | 隔人窥视 | 同过肩 |
| **Two-Shot** | 两人同框均可读，无「越过」 | 交付同框；竖屏对白/并排亦可 | 两人锚同属该角白名单。竖屏须 `景别=MS\|FS`（双方半身/全身可读）；禁竖屏 MCU/CU Two-Shot |

`关系角=过肩|过腰|OPC` 时写`OTS类型=`（判别只认 §3）。须填`近侧框主=`≠`主拍对象=`；`近侧框主=` 须含框主名+左/右肩或腰侧（如`林右肩`）。干净/Two-Shot：`近侧框主=无`｜`OTS类型=无`。
换可读方→过肩+读对手；只加压不换脸→同侧过肩；腰部递接→过腰或 Two-Shot；交付同框优先 Two-Shot，禁过肩裁间距。近侧肩/腰形成内框才可兼框中框。

#### 4.6.3 俯仰跨拍
默认`角度跨度=同俯仰`。邻档=`平拍↔微俯/微仰`。越级须`越级:{依据}`（原文俯仰/POV｜峰值放大｜宏观｜倒地/跪拜/巨物）。禁对白链无据跳航拍/虫蚁。
