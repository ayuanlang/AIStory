## 目标（最高；本子技能工作方式）
对**输入剧本**做打斗/法攻/宏观/宏大特效的可拍过程加密。
1. **只改命中段**：近身打斗、通用法攻/术法、打击投射、宏观群体、宏大特效、打斗快慢——且场核已标或原文确有落点。
2. **服从场核**：加密须兑现本场卖点/高潮（如打斗美学），不得把文戏场写成无据决战，不得改谁胜谁负。
3. **其余原样输出**：对白、文戏特写、场核标签、场号、建置几何、仙攻段、未涉打斗的叙述。
4. **无命中则整份原样**：不得为填规则造招、造特效。
5. **输出=完整一场戏**：无论是否改写，都必须输出 `[SCENES_BLOCK_START]`、`[SCENE_START:{scene_id}]`、【场景名称】、环境块/`SCENE_CONTENT`（输入有则原样）、全部 Beat、`[SCENE_END:{scene_id}]`、`[SCENES_BLOCK_END]`。禁止只交命中段或结束标签。

## 场景提取入口（最高；按切分标签）
1. 先扫描每个 `[SCENE_START:{scene_id}]`…`[SCENE_END:{scene_id}]` 内的：
   `[SPECIAL_SCENE_ANALYSIS_START:{scene_id}]`…`[SPECIAL_SCENE_ANALYSIS_END:{scene_id}]`。
2. **仅提取并优化**其中 `[VFX] 命中=是` 的完整 Scene；允许类型仅为 `近身打斗｜宏观群体｜通用法攻｜宏大特效｜追杀/穿梭`。同场以该行 `证据=原文：“……”` 指向的原文段为入口，再处理其必要连续攻防链；不得要求上游已有 Beat。
   - 上游采用**宽松判定、宁多勿缺**；`边界待专项复核` 仍视为合法命中。本文件先提取，再在场内复核实际适用段；若证据最终只构成蓄势/前置线索，则只对该线索作必要承接或原样保留，禁止因命中偏宽而凭空造战斗/特效。
3. `[VFX] 命中=否` 的 Scene 必须逐字原样透传；不得因 `[XIAN] 命中=是`、题材像动作片或角色有战力而启用本文件。
4. `[VFX] 命中=是` 但 `证据=` 无本场原文短引、无动作/能力/场面落点，或包裹 ID 与 Scene ID 不一致 → **路由失败，不得猜测补写**。
5. 同场 `[VFX]` 与 `[XIAN]` 均命中时，VFX 只处理自身证据指向的信息单元；禁止改写或重复扩写 XIAN 证据段。专用包裹及两条路由行须原样保留，供后续继续提取。
6. 输入没有任何合法特殊情景包裹时，整份原样输出并报告 `VFX路由=缺失`，禁止自行全稿扫描后越权启用。
7. `[COMPREHENSIVE_INFO_START]`…`[COMPREHENSIVE_INFO_END]` 是与 Scene 同级的只读全局资料：可用于理解人物能力与整体背景，但不得当作本场命中证据，不得改写、移动、拆散或复制进 Scene；连同全部 `INFO_ITEM` 子包裹逐字保留，供后续提取。
8. **场级指导强制落地**：读取【场景综合】全集作用，以及【卖点综合】【情绪峰谷综合】【叙事综合】各自的 `指导=`。对本文件命中的每个重点，按卖点指导至少加入 `特效/动作细节特写≥1 + 受击方/目击者反馈特写≥1 + 符合运镜参考的有动机运镜≥1`；按情绪指导保持入场锚、峰值/低点承载、转折/离场与弧线保护；按叙事指导保持**关键人物可见放大**、信息焦点、显隐次序、选择代价、契科夫、后果/回指及贯穿保护。`名场面参考`只借鉴视听、节奏、反馈和注意力组织机制并映射到本场原文，禁止复制参考片剧情、台词、人物关系、标志性动作、招式或专有视觉设计。不得用纯光效替代人物反馈；贯穿道具、情报、伤态、持物、关键人物和能力状态须从输入态连续到输出态，禁止提前揭示或无因消失。

## 通用硬约束（各子技能同锁；最高）
> 抽自父提示词文首总闸 / 【边界】 / §1 原文核销 / 成稿口径。本子技能写特效时**不得**借「加密过程」违反下列任一条。

1. **忠于上游原文 + 未命中原样输出**：不改事实/因果/胜负/伤亡/角色关系；**禁新增改因果事件**；扩写只补**命中本规则段落**的可拍过程与可见反馈。上游已写则**保真不得压扁**；上游空泛则仅对该段加密（不改谁胜谁负）。**未命中段落禁止改写。**
2. **原文信息零丢失**：原剧本**每一处文字 / 每一信息单元**必须落入成稿可检索落点；**禁删/漏**原剧本任一文字单元；禁止概括吞并、跳场省略、只留「大意」、因「不知归哪类」而静默丢弃。未优化段须能与输入逐字对上。
3. **专名逐字**：角色名/地名/招名/法器名与原文**逐字一致**；已有真名禁改。
4. **对白保真**：项目语言侧台词逐字保留（可按自然停顿拆句，词序与用词不改）；**禁止臆造台词填洞**。无具体台词内容可省略该句对白，可见说话动作转动作/微表演。
5. **逻辑合理可拍**：凡建置/朝向/层位/运动/ENV 选择——第一原则=物理世界 + 镜头投影下可成立、可拍摄。公式/硬锁/模板与可拍冲突时**以逻辑合理为准重写**。
6. **三段职责**：【建置】=开口前画面初始态；【入戏】=纯过程（动作/对白/表情/交互/特效过程/音效`<…>`）；【Beat切换说明】=变化过程 + 终态。**位置与朝向只写建置及切换说明终态**；入戏禁止描述角色/道具的位置、朝向、层位、左右、距离、起终点或槽位。
7. **禁实拍执行语**：威亚/钢丝/替身/绿幕等；腾空/轻功/飞跃只写可见运动（本文件若出现位移类效果，同锁）。
8. **禁意图词**：试图/想要/打算 → 具体动作链；失败也写可见受阻，不写「试图失败」。
9. **下游边界**：本阶段定「拍什么」；禁代写分镜处方（焦距/运镜处方归 `shot_generation`）。
10. **只执行已注入规约**：不得自行加入未注入的题材/地点/武器体系专规；仙攻专规未注入本文件时不得把近身/法攻改写成仙侠空战。

## 术语
| 术语 | 定义 |
| :--- | :--- |
| **法攻** | 非仙攻的术法/能量/元素/力场/科技投射攻击（火球/冰锥/雷击/气盾/气爆/激光/EMP 等）。本文件不写结印/灵气/御剑/法相。 |
| **六相** | `起势→显形→扩散→命中→维持→余波`；每相相对上一相须有可辨增量。 |
| **驱动力可视化** | 气/内功/魔力/念力/力场等不可见力实际施力时，须写形态｜轨迹(源→路径→落点)｜作用+反馈。 |
| **效果终止态** | 命中后受力运动写到撞墙/落地/被接住/瘫地或局部运动停止；禁停在「被打飞/中招」。 |
| **招间因果** | `前因→过程→后果→铺下一招`；上招终态=下招前因。 |
| **禁重复招式** | 同一连续攻防段同一出手方不得同名/同部位同轨迹/同介质同路径再出。 |
| **OTS 正反覆盖** | 出手方可读角 + 受力方挡格/中招可读角；禁全程单侧。 |
| **宏大特效** | 非仙体系域场/结界、大范围元素爆发/对撞波前/宏观灾难/标「宏大/全屏/无边际」/跨≥2 Beat 环境级特效；仙侠灵气域场/法阵归 XIAN。 |
| **满幅** | 前景介质\|中景主体\|后景边界至少两层同时有可见变化，并锚具名空间边界。 |
| **宏观群体** | 大军/对冲/兽潮/机群/舰队/人海（≠2–3人簇）；`宏观群体=是`→≥6 Beat。 |
| **快链** | 同节奏单元、连续动量、无停顿的无对白/武戏链。 |
| **升格配额** | 打斗升格≈30%(25–35%)；常速≥50%；>40%滥用。 |
| **核销** | 原文信息单元在成稿有且仅有可检索落点。 |
| **原样输出** | 未命中本规则的输入文本逐字透传，禁止润色/重排/顺带改写。 |
| **XOR** | 同一主体定位只选绝对或相对一种；入戏不写定位。 |
| **受者响应** | 对白主听众或交互被作用对象须应答/可见反应/明文不响应。 |

## 1. 动作规格与招间因果（打斗/法攻）
- **动作规格（七项；内部规划后按三段归属）**：①部位+幅度/速度/力度(止于手级)｜②动作始末与门开向｜③文戏低缓(武戏例外)｜④惯性过渡｜⑤操作链禁跳步｜⑥必要且日常的情绪外化｜⑦因果可感。**入戏只写动作与经过的具名交互节点；起终位、方向、层位、距离、停驻点写切换说明。**
- **招招前后因果连续（最高）**：每一招须可追**前因**（承上招终态：空门/失衡/落空余势/挡格反弹/距离开合/护盾裂口等）→**过程**（起势·轨迹·可见介质）→**后果**（命中/落空/挡格/打断+效果，**且写到效果结束/停驻**）→**铺下一招**。跨拍强制承接：相对距离｜姿态/重心｜兵器或握持落位｜术法/护盾现态（有则）。攻防须双向咬合（甲招→乙因该招而应→甲因乙之应再出招）。
- **禁因 AI 规避省略连续攻击**：连招/换招链不得压成「起势—结果」或删中段；规避只砍不必要细节动作，不砍招招过程。❌无因果堆招、混战摘要、或同构再出招。
- **禁重复招式（最高）**：同一连续攻防段内，**同一出手方**不得重复或同构再出招式/法术。判定=招名相同｜部位+轨迹相同｜同一法术介质同路径再放｜仅同义换词。下一招须至少换部位/左右手/兵器路径/命中面/法术介质之一。挡格/闪避可同类但须换方向或部位。明文连击须写出可辨变奏。❌直拳再直拳／火球再火球。
- **明确动作 + 效果写到终止态（最高；打斗/法攻尤严）**
  - **禁混战摘要**：❌「混战在一起」/「激战一番」。群战=阵势质块 + 主角切口的明确 1v1/1v2 招式链。
  - **明确动作最低粒度**：每招可检索——谁｜部位/兵器/法器｜对谁｜起势→轨迹→命中面。
  - **效果写到终止**：命中/法攻后不得停在「被打飞/被震开/中招」。【入戏】写受力、连续位移、撞击/落地/被接住和动作停住的可见过程，但不写空间方向、落点位置或距离；【Beat切换说明】写具名落点、停驻姿态与相对关系。轻击写到局部运动停止；下一拍【建置】承接终态。
- **打击/投射**：近身=`起势→发力→命中→反馈→路径→终点/停驻`；投射=`出手→路径→命中→效果→停驻`；位移类效果须写到撞墙/落地/瘫地。反馈段须含受力方表情或可读局部特写，禁只写位移/光效或“混战”摘要。
- **地面身法（无超能题材）**：都市/现实无超能 → 不强制腾空，仍须地面身法轨迹（闪绕/低扫/借墙）并穿插过程表情。本文件不写空域轻功/御剑。

## 2. 法攻命中与过程特写
对话击中、近身/法攻命中与挡格须以角色表情+特写级局部呈现；打斗/法攻过程亦须穿插可读表情。

| 节点 | 特写最低要求（同拍或紧邻特写切口） |
| :--- | :--- |
| **对话击中** | 说话人开口≥1 面部微表情；**听者/被击中方**怼脸或局部反应过程链≥1 |
| **打斗命中/挡格** | **受力方**可读面表情或痛感/惊变微表演≥1 + 姿态/握持局部；关键招宜叠出手方眼神/咬牙 |
| **法攻命中·对撞·挡格** | **目标方**中招/承压表情或可见面外化≥1 + 余波落在人/物上的局部；禁只写介质/爆炸无人脸上变化 |
| **过程穿插** | 每个过程位或每招中段：出手方**或**对手一方五官/可见面表情≥1。连续段技法≥2 时，过程表情切口原则上 ≥ 技法数。**与命中效果脸并存，不得互相替代** |

武戏快链可同拍压缩「技法过程→表情切口→命中→表情骤变」，**不得**豁免无人脸效果。❌揭破/命中后无人脸，或过程无表情切口。背对禁写须正面才可见的受击表情或胸腹。

## 3. 打斗／法攻 OTS 正反覆盖（最高）
连续打斗、近身缠斗、投射法攻等**对阵段落**，覆盖语法必须参照对白 Shot-Reverse / OTS——对参战**各方**的主动作出手与受力／挡格反馈，均须有**可读角**与**反打可读角**；**禁止**全程单侧只拍甲方出手而乙方仅背影／远景糊弄。

| 相位 | 正侧（出手方） | 反侧（受力方） | ENV |
| :--- | :--- | :--- | :--- |
| 出手／起势 | 出手方可读角（可 OTS 过对手肩） | 同拍可挂肩背／侧面作关系，但不得替代反侧专拍 | 切出手方可读 `{N}度…` |
| 命中／挡格／闪拆／受力 | — | **必须**切受力方可读角 | `ENV变=是`；反打不换主环境名 |
| 反击／换手 | 新出手方可读角 | 原出手方转受力可读角 | 换手=新一轮正反 |
| 法攻投射链 | 施法／击发方可读（出手+介质离体） | 目标方可读（迎弹／偏转／中招／余波） | 出手拍与命中拍原则上分属互补可读角 |

**硬门槛**：①正式决战／连续攻防≥4 轮 → **每轮**至少 1 次正↔反 ENV 切换；②凡场有打斗／法攻对阵 → 各方至少各有 **≥1** 可读角主拍；③快链可同拍合并动量，**不得**用快链豁免「缺反侧可读角」。❌全程单侧只拍一方出手。本文件不写金身／法相借体出手。

## 4. 特效六相与驱动力（排除仙攻介质）
- **驱动力可视化（强制）**：气/内功/魔力/念力/力场等驱动运动时须写可拍介质——禁只写「运功」或只写结果。必写：形态｜轨迹(源→路径→落点)｜作用+反馈｜介质建置承接；小规模可同拍，大规模叠六相。**本文件不写灵气/真元/罡气/剑气。**
- **具象化/规格**：大特效禁高潮只写「能量爆发」。启用即写：触发｜因果可感｜具象形态｜范围(锚ENV边界+未覆盖)｜影响(**具名固定实体**逐项；禁「环境震动」无落点)｜六相`起势→显形→扩散→命中→维持→余波`｜时限。跨拍改结构→`{主}_{状态}`。七-E择1–2+范围/影响各≥1。本文件不写化龙凤兽/法相；优先元素形体/冲击环/波前。
- **无定形介质**：只走六相+实体落点；消散后从终态剔除。凝形成可辨头面/肢体朝向的**法相/金身**本文件不写；本文件可处理非仙体系的巨化/机甲展开/能量体，字段与角色同标（定位 XOR｜正背面｜面向｜姿态｜与他者｜视线(有则)｜动作方式），与驱动者同拍写清因果。
- **光效/特效边界**：画外光源可写其在画内的投影/受力/声音；禁写画外本体细节。特效命中陈设须可拍反馈。

### 宏大特效：变化细节 · 满幅可渲染（最高）
> **判定（命中任一；本文件）**：大范围元素爆发/对撞波前｜宏观灾难/奇观主相位｜标「宏大/全屏/无边际」｜跨≥2 Beat 环境级特效。本文件不写域场/结界/天地法阵/化龙凤兽/法相/云海改写；六相+满幅语法同锁。轻量单点/近身气爆不适用本条硬门槛，仍须六相可核销。
> **目标**：满幅可渲染 + 六相各有可辨变化细节；禁一句「能量爆发铺满天空」。

- 原文打斗/法攻/特效信息单元均有落点；无新增胜负/能力；未改情绪弧。

- 宏大则满幅+分相增量+细节密度够。
- 入戏无位置/朝向/落点；终态在切换说明。

- 未命中段无润色/重排/顺带改写。
