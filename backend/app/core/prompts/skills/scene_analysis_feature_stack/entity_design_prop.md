## 一、道具专属硬约束

### 1.1 画幅与命名
- 16:9 横向、均匀浅灰连续画板、同一横排四视图；第一宫占横向 35% 纵向居中，第二/三/四宫共享 65%；禁 2×2、换行、错层。`generation_prompt_en` 固定 `""`；`description_cn` 恒 `""`。
- **第一/第二宫=尺度对照合成格（最高；覆盖旧「特写格/正面格」）**：这两格**各**为同一合成格合同——格内必须**同时**画出本道具 + **一个**标准化尺度参照主体（**承接**提取块 `参照主体=名=` + `长=`/`高=`/`宽=` 与 `尺度=`；有则原样，空才自拟，须为线性图），二者同框、按三轴比例对照，**禁止**把参照另开一格、禁止只写文字尺度不画参照。**隔离（最高）**：道具与参照是完全隔离的两个主体——中间须留可见浅灰空隙；禁止接触、叠压、穿插、粘连、持握、佩戴、靠在参照上或被参照握住。第一宫=近距对照（道具材质/形制仍须可读 + 参照同框隔离）；第二宫=完整正面对照（道具全轮廓 + **同一**参照，同样隔离）。第三宫侧面、第四宫背面为**道具单体**（不画参照、不画人）。

### 1.1A 标准化尺度参照（强制；第一/第二宫）
- **承接（最高；空才自拟）**：提取块 `参照主体=名=` + `长=`/`高=`/`宽=` 与 `尺度=` 为参照比例权威。①名与三轴已写且非空泛 → **原样承接**（可检索全名与 `长=3/4掌长` 一类对参照轴的比例）；`高=无｜刃薄不计` 等「无+因」算已写，禁止改参照、改档、改三轴。②仅缺名、或缺任一轴（空、裸`无`无因、或仅「小/大/适中」）→ 已写项原样留下，只补缺口，logic 标 `upstream_missing_scale_reference`（缺名）和/或 `upstream_missing_relative_scale`（缺轴）。自拟时仍须写出对参照的长/高/宽（参照轴须点名：掌长/掌宽/身高/肩宽/球径等），禁只写「约一掌大小」。`依据=` 只进 logic，禁把宿主角色名画进画面。
- **隔离（最高）**：道具与参照主体**不得直接接触**；两主体完全分开，浅灰底从二者之间穿过；禁手握道具、禁佩在耳/颈/腕上、禁刀尖抵人、禁车轮压人线。参照=标准线性图（灰黑线稿/极简轮廓），无时装、无五官写真、无剧情姿态。
- **选型（仅②空缺时启用；参照与道具主尺寸比须约 1:4～4:1，禁止跨档）**：自拟时须同时写出 `长=`/`高=`/`宽=`（相对下表参照特征轴；不适用轴写`无`+因），禁只补一个「大小」句。

### 1.3 道具四视图光影（真人/默认）
- **目标**：光从哪来 → 照哪一面/棱 → 高光/半影/接触影 → 冷暖落在各材质；浅灰底≠无光。
- **默认 setup**：侧向柔 Key（窗光/反光动机）+ 相机侧前方反射 Fill（白卡/墙/窗延续）+ 轻柔轮廓分离；半影柔散。Fill **须**经具名反射面，禁无锚点虚构正面灯（对齐 common §1.3）。
- **须写入 prompt（精简）**：光源类型与方位、主照亮面、≥1 条冷暖或同温层次（**须响应 `scene_mood_cue`**）、≥1 条材质光学响应、四面板同一光源体系；第一/第二合成格须见道具受光结果（划痕/纤维/厚度等），参照为线性图浅灰描线、不抢光、无独立高光体系，图上标注字须可读。压迫/肃杀偏冷 Key、温煦/明媚偏暖 Fill；仍禁 ≥8:1。
- **投影例外**：均匀浅灰底；允许 Key 对侧**轻软接触影**以保体积；禁纯白底、渐变、环境反色、脏污投影。
- **单状态**：一 Subject 一物理态；多态需求上游未拆则回流全局统筹提取。耗时渐变前后态：写清 Delta 可见变化 + 其余与基准一致。
- **衍生**：`visual_dependencies` 用逐字实体名（如 `PROP:[...]`）；光照体系与紧邻基准一致，仅状态改变局部高光/污迹。
- `negative_prompt_en` 短而个体化；优先滤塑料/玩具/微缩/尺度失真（过小玩具感或夸张放大）/photoreal holding hands/gripping pose/prop touching reference/overlapping scale figure/extra people/missing scale reference in first two panels/unlabeled scale line drawing/blank silhouette reference/missing reference-name text/错字/时代错置；真人可追加 `flat lighting, ring light, harsh flash, hard shadow edge`。禁止用 `hands, no text` 一类词误杀线性参照、线性图上的参照名/比例字或 `L=`/`V=` 标注。

## 四、渲染分支

### 4.1 真人实拍 / 未声明默认
执行 §1.1–§1.3。`description_cn=""`；简要 Key/Fill/轮廓方位与色温 + **`场级情绪`/`材质响应`** 进 `dependency_strategy.logic`；`generation_prompt_cn` 写可见受光结果，勿堆摄影教材。

### 4.2 三维动画（仅 common §1.6 显式命中三维/3D/CG/风格化三维等）
- §1.3 柔光静物 setup **不生效**；改用几何体块 + PBR 或 Toon 语言；画幅仍 §1.1。
- 次世代：Metallic/Roughness/IBL/倒角；风格化：色块 + 硬边阴影/描边。择一写入 `dependency_strategy.logic`。
- `generation_prompt_cn` ≥6 项几何/材质锚点；`negative_prompt_en` 追加 `photorealistic material photography, real object photo`（风格化再加 `photorealistic PBR material`；次世代再加 `flat toon shading`，**勿**加 `2D line art`——第一/第二宫参照仍须线性图）。
- 禁真人手作工艺话术与纯二维赛璐璐语言。画幅与合成格仍 §1.1/§1.1A。

### 4.3 二维动画（仅 common §1.6 显式命中二维/赛璐璐/二次元等）
- §1.3 柔光静物 setup **不生效**；赛璐璐线稿 + 平涂色块 + 1–2 层硬边阴影；画幅仍 §1.1。
- `generation_prompt_cn` ≥6 项线稿/上色/高光块锚点；`negative_prompt_en` 追加 `photorealistic material, 3D render, PBR shading, realistic lighting gradient`。
- 禁真实材质纹理话术与三维 PBR/体块语言。画幅与合成格仍 §1.1/§1.1A（参照用同风线稿轮廓）。

## 六、输出模板（严格）
唯一输出：一个 JSON 对象，根键仅 `props`（无实体则 `[]`）。全量覆盖「全局统筹道具提取」中的 `[PROP]`；名称与提取块 `名称`/`名称_en` **逐字符完全一致**（任一字不等即废弃）；每条含 `visual_dependencies` 与 `dependency_strategy {type, logic}`（logic 须含 `场级情绪`/`材质响应` 或已标 `upstream_missing_scene_mood`）；命中重型器类时 logic 另须 `器类对标：档=｜器类=`，`generation_prompt_cn` 可检索 `器类=`+全槽`落点=`+`表外=` 且结构/工艺句（非仅键值）含各槽实质词，只写「一台机甲/一架战机」=废弃；`generation_prompt_cn` 须可检索第一/第二宫合成格 + 隔离空隙 + 线性图文字（参照全名+三轴比例）+ `L=`/`H=`/`V=`；提取块已写 `参照主体`/`尺度` 则须可检索原名与 `长=`/`高=`/`宽=` 三轴比例（另选参照或改轴=废弃），仅空缺时才自拟并 logic 标缺口；`anchor_description` 第一条须可检索参照物全名 + 对参照的长/高/宽比例（如 `成人女性手掌线性图｜长=1/2掌长｜高=2/3掌宽｜宽≈1/6掌厚`）+ 数字英文单位；缺任一或写成持握/佩戴接触或无字线性剪影=废弃；`generation_prompt_en` 恒为 `""`。材质冷暖须可核销提取块 `情绪`。字段禁角色壳；输出中禁写本文章节号（如「§4.1」）。
