# SKILL: promo_generation

## Name
Promo Planner（商业宣传片策划）

## Purpose
独立 skill：用户选定企业 / 品牌 / 产品（产品可无）、锁定核心诉求并提交介绍信息后，分析主体特性，对标至少 3 部行业经典商业宣传片，按统一节奏 **吸睛 → 共鸣 → 价值 → 收口** 输出可回写页面的策划案。

## Prompt Source
- 主提示词：`skills/promo_generation/promo_planner_scheme.md`
- 视觉解析（可选前置）：`skills/promo_generation/promo_planner_image_analysis.md`
- 成片剧本：`skills/promo_generation/promo_planner_script.md`
- 技巧联想词库：`skills/promo_generation/promo_technique_lexicon.md`（策划与编剧共用）
- 执行器：`app.services.promo_planner.generate_promo_planner_scheme` / `generate_promo_script`
- 注册入口：`skills/skills_registry.json` 中 `id = promo_generation`

## Runtime
1. 建立项目时填写与剧本项目同核的项目信息：类型必须选择制作类型（实拍真人 / 二维 / 三维等），**不要用「商业宣传片」顶替类型**；画幅必填；语言、国家地域、剧本模式、时代、季节、光线、基调等一并锁定。片种由系统标为商业宣传片。规划与编剧技能的**系统提示词**注入 `[项目信息]`，禁止另起冲突设定。
2. 用户选定企业、品牌、产品（产品可无）。
3. 用户锁定核心诉求（五选一，必填）与预期时长（必填）。
4. 用户提供介绍信息：基本介绍、目标客群、CTA、竞品与市场。
5. 宣传主体素材库（企业/品牌/产品）存**全部**素材。项目素材库只勾选本片要用的子集。注入策划/编剧/统筹的素材信息**只准「已有素材资源描述」**（本项目已选项，一条一次），禁止把主体全库、台账或解析原文另注入。用户也可在项目内新上传，新上传同时写入主体库，供之后项目再选。有选中素材则解析后回填已有素材资源描述。**禁止解析水印**。**场景图只重生环境**。已有素材资源描述只作家形参考，**不作场面约束**。无选中素材或场面不够壮观时，按效果优先**新构思**宏观大场面与精密拍摄。
6. 本 skill 一次提交 1–3（有资产则作视觉上下文）：先锁本次宣传要点与主要卖点，再分析特性、对标 ≥3 部经典片、写四段策划并充分展现卖点。规划与编剧必须继承建项时锁定的项目信息。
7. 输出回写：对标片名与内容、各阶段规划、`project_visual_backfill` 基调与风格、建议补充内容（事实缺口 vs 画面后续补充/AI 生成）。
8. 四段规划锁定后可再生成正式成片剧本（**全剧一场**）。策划不写、不展示、不传镜头表。编剧按四段 `content` **逐字核销**并拆成可拍节拍，保证策划信息全部可视化；**旁白/口播/动作必须分行**（动作只写看见的原位→动作→落位，口播只写听见的短句，禁止混成一段风景散文）。在此前提下**认真分析全部对标**（每片 techniques/content_borrow），结合本案例综合实现各 Beat，禁止只点一部片。场景可在上游基础上用灯光与简单贴边装饰美化。写入同账户剧本项目分集 `script_content`。进入全局统筹时注入策划信息；统筹禁止再拆场。CHAR/PROP/ENV 外形须抄已有素材资源描述后重生。

## Notes
- 核心诉求闭集：企业品牌宣传（情绪种草）／即时转化（引流获客）／建立信任（权威，客户证言）／产品使用与原理（产品测评，技术科普，使用指南）／招商合作（招商，招聘，年会，加盟）。
- 种草片前三段禁止口播式介绍企业、品牌、产品；花字可以点产品、Logo、slogan。口播自我介绍放收口。
- 节奏不可另起：吸睛 → 共鸣 → 价值 → 收口。
- 共鸣可适当融合「救猫咪」式节拍：看见一次小而可亲的主动作，让观众站到人这边；不是第五段、不是长剧全表、不拆场。短片只落一个微动作，长片才可叠主题点题或微暗夜。
- 成片剧本与全局统筹都是全剧一场；四段只作场内节拍，不因换空间或时长档拆场。
- 预期时长由用户锁定；四段规划的秒数、口播与花字密度必须合档。镜头由编剧按四段内容拆镜并逐字核销。
- 须规划片内图形花字：`flower_text_spec` 全片统一字体/字色/字重。**旁白优先（最高）**：花字优先级低于旁白；有旁白/口播的拍不出花字，禁止同一时间轴同步上屏，以免转移注意力。花字只挂无声拍（开镜/段末切镜/黑屏专镜/字卡专镜，`听=无`）。**禁底部**，以免与字幕重合；只落中/画右/画左。吸睛、共鸣、价值、收口**各段最多一条**，一个动作最多一条。花字与切镜融合：优先段首开镜或段末切镜，不与动作抢镜；也可单独一拍黑屏专镜或字卡专镜只上花字（场内，不拆场）。**店号/品牌/热线走字卡专镜**：场景底只出画面，字层由后期 libass 按引号逐字烧录（`烧录=libass｜手写=禁`），禁止视频模型描字；印章另层不进字盒；字卡不是 CHAR/PROP/ENV。CTA 可较长停留。片尾必须有一句有韵味的收口花字（CTA 不是第二条）。中部花字须字数简洁、文化味强、内涵深，并**特别做艺术化组合设计**（可选并不限于印章、古体字、英文小字、颜色）。不是对白硬字幕。古风／文化／文旅可适当用繁体、古体字体、印章体；品牌名、店号（含「X家」）与 CTA 数字保持原形可扫读，须写 `逐字=`，禁漏家、禁复写邻字。**印章不压字**：印只在句外，`压字=禁｜替字=禁`，禁止印面盖住花字。企业素材产品出镜时，该拍花字必须是产品名，画右或画左竖排，仍算该段唯一一条。
- 先完整针对基本介绍里的本次宣传要点；无要点则按核心诉求从企业/品牌/产品信息抽取。总结主要卖点（美食、美景、美物、美人、工艺、文化、高科技、历史沉淀等）并充分展现。画面核跟主卖点同核。
- 先锁画面核再写入各段 `content` / `sensory`：美食/美人/产品充分特写，美景观宏观特效，科技见技术特效。有产品必须写特别描述（形制/材质/标识/高光）并给专拍特写，不能只点品名。有 Logo / slogan 等企业元素必须给标识特写，禁止远处小标一闪而过。主核在吸睛与价值必须专拍突出，禁止路过远景一带而过。镜头不在策划展示或下传。
- 配乐是宣传片主轴：`music_recommendation` 锁 `音量=并重`（收口可压过），禁止垫底几乎听不见。
- 效果第一：已有素材不作场面约束。发挥 AI 视频优势，无传统预算与拍摄风险限制；须联想宏观大场面与精密拍摄，新场面标 AI 生成。
- 不编造用户未提供的企业/产品事实；缺口写入 `supplement_suggestions`。无上传素材时必须新构思可拍剧情，`content` / `sensory` 不得空；画面标「后续补充」或「AI生成」。
- 对标可借鉴情节、配色、拍摄与剪辑技巧；禁止照搬仅限对方商标 / Logo / 吉祥物 / 注册口号等易混淆标识。
