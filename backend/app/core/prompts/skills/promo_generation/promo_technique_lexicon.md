# 商业宣传片技巧联想词库（策划 + 编剧共用）

本词库是**内容 / 感官**两必须角，以及节奏、声音、光色、转场、记忆点的联想闭集。策划按四段选出 `technique_assoc`；编剧按上游规划细化落地，禁止另起故事。

硬闸：
- 先锁上游 `stage_plan` 的 `content` / `sensory` / `copy` / `flower_text`（策划不传 `shots`）。编剧对四段 `content` 逐字核销后再从本表联想技法。先对上 `promo_focus` / `selling_points` / `visual_core`：已锁卖点必须充分展现；美食/美人/产品用充分特写，美景用宏观特效，科技用技术特效，主核必须专拍突出。有产品必须特别描述形制材质标识，并给特写，禁止只点品名。有 Logo / slogan 等企业元素必须给标识特写。种草片前三段禁止口播式介绍，花字可以点产品/Logo/slogan。花字跟 `flower_text_spec` 全片统一；**旁白优先**：有旁白/口播的拍不出花字，禁止同步上屏以免分心，花字只挂无声拍；禁底部避字幕；各段最多一条、一个动作最多一条；优先段末切镜或段首开镜，不与动作抢镜，也可黑屏专镜；默认中部中号，收口中部大号，CTA 可较长停留，末句须有韵味。中部花字须字少味厚，并艺术化组合设计（不限于印章/古体/英文小字/颜色）。产品名通常画右或画左竖排，仍算该段唯一一条。
- 对标片必须**全表**分析：每条 `techniques` / `content_borrow` 都转译到本案例现场，并综合进各 Beat；禁止只借一部、其余空转。`do_not_copy` 只避商标/Logo/吉祥物/注册口号。对标服务于策划内容落地，不另起故事。
- 效果第一：已有素材不作场面约束。发挥 AI 视频优势，无传统预算与拍摄风险；全片至少一段宏观大场面、一段精密拍摄。
- 编剧落地用**文学可见结果**，禁止机位/焦距/推拉摇移术语。旁白/口播/动作必须分行：`动作:` 写看见，`口播:` 写听见，禁止【旁白】后接风景散文再夹口播。
- 每段至少：1 个内容核 + 1 个感官核；各拍写 `对标综合=`（多部片名+手法→本案可见结果）。可选 1 条创新变体。写清 `技法: 内容核=…｜感官核=…｜对标综合=…｜创新=…｜落地=…`。共鸣可适当用内容核=救猫咪，加强代入，不另起第五段。

## 1. 内容核（必须）

| 内容核 | 惯用（国际顶级宣传片常见） | 创新变体 | 文学落地（编剧） |
| :--- | :--- | :--- | :--- |
| 向往 | 黎明窗光里的日常仪式；对向行走汇合；手触水/织物/热气 | 先给结果余温，再回落到此刻手部 | 人迎着透光站定，手拂过可见质感，空气里有温度 |
| 解决问题 | 痛点特写打断→解除特写；前后对照；产品入画压住混乱 | 同一只手从慌乱到稳住，中间只换一件物 | 先看见卡住的细节，再看见同一位置被理顺 |
| 改变的希望 | 灰调日常被一束暖光切开；旧物翻新；孩子/学徒抬头 | 希望只落在一件被照亮的旧物上，不喊口号 | 暗处里一处表面突然可读，人的肩线松开 |
| 成果展现 | 完工特写接广场景观；成品被双手托住；人群停步看 | 成果先以倒影/蒸汽出现，再露出本体 | 先见光斑或倒影，再看见完成的物或场面 |
| 人物证言 | 说话人近身，证据在身后或手边同时可见 | 证言中途把视线交给证据，口播不停 | 人开口时，手边或身后有可核销的结果物 |
| 企业人文 | 工位/车间里的重复手势；师徒递物；灯光一盏盏亮起 | 只跟一双经过训练的手走完整段流程 | 可见的熟练动作连续发生，空间里有人气 |
| 独特功能 | 功能点被手完成一次；前后状态对照；材质/结构特写 | 功能只用一个「不可能轻易做到」的小动作证明 | 手做完一件事，物的状态明显改变 |
| 技术突破 | 剖面/透明壳/光点在结构里走；实验室克制光 | 突破不写参数，只写一次可见的稳定 | 内部结构被光走一遍，落点稳定可读 |
| 历史沉淀 | 旧物包浆、年代层、手掌覆上铭痕 | 今手与旧痕叠在同一触点 | 新旧两层同时在一个表面可读 |
| 悬念 | 先给局部与声，再给全貌；问题句压在画面前 | 悬念用一件未揭开的遮挡物，不用字幕问号 | 先只见局部或遮挡，动作停在揭开前 |
| 客户代入 | 目标客群的早晨/通勤/工作台；第一人称手部 | 代入只换一双与客群同身份的手，不换世界观 | 观众能对上那双手在做什么 |
| 救猫咪 | 共鸣段一次小而可亲的主动作：扶、让、递、停下来帮，观众因此站队 | 可亲动作不给旁人、只给自己身边一件乱物理顺，痛点仍同核 | 手做完一件对人/对弱者/对乱局的好事，结果立刻可读；禁止真救猫当主线 |
| 解决方案 | 企业/产品进入刚才的困境位置；效果立刻可见 | 解决方案以「拿走痛点物」完成，不演讲 | 困境位置上的物被替换或被手理顺 |
| 记忆强化 | 标与 slogan 同框；主色回扣开篇第一眼；中屏花字字少味厚并艺术化组合 | 收口把开篇第一件物以完成态再举一次 | 开篇出现过的物/光再次完整出现；中屏记忆句宜≤15字、有余味，须写艺术=组合 |
| 行动召唤 | 清晰动作：打开、预约、到店、扫；收口段最多一条花字 | CTA 落在人的手刚刚做完的动作之后的段末切镜或黑屏专镜 | 手停在可执行的下一步；收口花字不抢动作；CTA 可较长停留，不是第二条花字；禁止用动词句冒充收口花字 |

## 2. 感官核（必须）

| 感官核 | 惯用 | 创新变体 | 文学落地 |
| :--- | :--- | :--- | :--- |
| 航拍气势 | 厂区几何、海岸线、车队轨迹、城市脉络；AI 无预算可铺山海城脉 | 航拍只借一条会动的线（车灯/河道/传送带） | 地面纹理成网，一条亮线在其中走动，禁止因无实拍航拍而删 |
| 精细特写 | 手部工艺、材质纹理、水珠、蒸汽、眼神；精密到可见纤维与切口 | 特写停在「将触未触」 | 表面纹理、温度或水汽可读，禁止因「拍不清」而改远景 |
| 虫视微观 | 桌面帝国、食材森林、零件峡谷 | 微观里出现一只属于本品牌的手/工具 | 日常物被放大成可走的地形 |
| 人美 | 充分特写：皮肤反光、发丝轮廓光、眼神唇齿、姿态停稳 | 美不靠摆拍，靠做事时的侧光贴脸 | 脸与肩线的光可读，禁止只给全身远站 |
| 景美 | 宏观铺开 + 可见特效：云气、光带、雨幕、日照扫地貌 | 景美只加一层会动的空气或光 | 整片地貌被光或云气走一遍，禁止只给走廊一角 |
| 物美 | 产品充分特写：形制、材质、主辅色、标识/文字、英雄光、倒影 | 物美用环境实用光，不另起影棚；手触或开合停在可读细节 | 产品外形与标识同时可读，禁止只写品名或远景小点 |
| 美食 | 充分特写：热气、切开、汁水、纹理、器皿 | 食物美只给一次切开或一次盛起，特写停够 | 热气与切口占满眼前，禁止餐桌全景当主菜 |
| 技术特效 | 剖面、光走结构、能量流、界面与机芯同显 | 特效只证明一次稳定，不堆参数 | 内部被光走一遍，外壳与机芯同时可读 |
| 多镜情绪 | 景别从远到近或从近拉开放松；表情微变 | 情绪变只换光质，不换人 | 同一人身上的光或肩线发生变化 |
| 震撼体量 | 大场面人潮/机群/建筑体量对比；AI 可铺宏大结构 | 震撼用一个小人站在大结构脚下 | 人体相对结构显得小，结构完整可读，禁止因预算删大场面 |

## 3. 节奏 / 声音 / 光色 / 转场 / 记忆点（辅助必选其一服务内容+感官）

| 角度 | 惯用 | 创新 | 文学落地 |
| :--- | :--- | :--- | :--- |
| 节奏-短片 | 一段一主画面；口播一句；硬切干净 | 用一次延长的呼吸声代替第二句口播 | 画面停稳的瞬间才出字 |
| 节奏-中长 | 价值段可分层，仍四段；重复手势作节拍器 | 同一手势在四段各出现一次，完成度递增 | 能数出同一动作的三次变体 |
| 声音-先声 | 环境声先入，再给画面；配乐同时够响 | 先给一个品牌材质声（金属扣/蒸汽/刀砧），配乐不消 | 耳先于眼，配乐并重可闻 |
| 声音-静后击 | 片刻静音再给冲击声或口号 | 静音落在手即将触物前 | 触物瞬间才出声 |
| 光色-窗纱暖 | 窗纱/百叶把日光切成条 | 暖光只打在产品或证言脸上 | 条状暖光落在主体表面 |
| 光色-实用灯 | 台灯、吊灯、橱窗灯在画内 | 一盏灯被手打开，空间才亮 | 人开灯，陈设被照亮 |
| 光色-冷暖对 | 前景暖、远处冷，或反过来 | 痛点冷、解决暖，同机位不换景 | 同一空间里冷暖分层 |
| 转场-物接物 | 圆对圆、手接手、门对门 | 蒸汽/布匹过幅代替硬切 | 上一件的形状接到下一件 |
| 转场-声桥 | 一句口播跨两段画面 | 同一句被两张嘴接力 | 声音不断，画面已换 |
| 转场-花字卡 | 无声的段末/段首切镜叠一句花字，不压动作、不同步旁白 | 满幅黑屏专镜只上这一句花字，该拍无旁白 | 字在无声开镜或结束镜停稳；有旁白则不出花字；黑屏卡仍同场；CTA 可多停一会儿 |
| 记忆-回扣 | 收口重复吸睛第一眼的物/光 | 第一眼的残缺在收口补全 | 观众能指认「这是开头那件」 |
| 记忆-锁标 | 标与主色最后定格；有 Logo/slogan 必须特写停留 | 标出现前先给材质，再给图形 | 先认材质，再认标识；Logo/slogan 须可读，禁止远处小标一闪而过 |

## 4. 国际顶级宣传片惯用（转译用，不抄商标）

可借鉴结构与技法，须换成用户企业/品牌/产品名称与现场：
- 日常英雄：把普通人一件小事拍成仪式（窗光、手部、完成）。
- 问题—打断—解决：混乱被一只手/一件物打断。
- 证据同框：说话时证据已在画面里。
- 桌面编排：产品与工具在桌面被手移动，像短舞。
- 一镜走过：人穿过工位/厨房/展厅，沿途点亮功能。
- 色彩揭示：先近乎单色，品牌主色后至。
- 结尾锁画：标 + 短 CTA + 开篇回扣。

创新只允许在上述骨架上改**一个**变量（光、手、物、声），禁止另起第五段故事。

## 5. 场景美化（灯光 + 简单装饰；叠在上游上）

允许（在视觉还原 / 策划环境之上）：
- **美化光**：窗纱透光、条状百叶光、一盏暖实用灯、桌面反光、蒸汽/尘中的可见光柱。不改围合，不改时段档。
- **点缀装饰**：一束鲜切花、小瓶、亚麻桌旗、靠墙灯、浅色织物垂坠、玻璃水杯。必须贴边/贴墙/台沿。

禁止：
- 改空间身份、改视觉还原核心外形/材质/尺度。
- 往主舞台净空加立体障碍或第二套家具。
- 点缀升成有戏份的独立 PROP（除非人手持或有个体动作）。
- 未见的奢华装修、未提供的奖墙/Logo 墙。

写法：`美化光=…｜点缀装饰=…（贴边，不占舞台净空）`
