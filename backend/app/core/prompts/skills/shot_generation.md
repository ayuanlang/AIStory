   - **`# Scene Subject Image Prompts (CN)`（ENV 光学锚定，强制）**：管道**仅注入本场景关联的 ENV** `generation_prompt_cn`；**不注入** CHAR/PROP。拆镜时**只读 ENV CN prompt 提取光学体系**（§0.06）；CHAR/PROP 设定图由下游生视频环节随附绑定，**禁止**在 `Video Content (CN)` 中复述外形/材质/身份锚点或整段粘贴 CN prompt；无对应参考图者**不得自拟外观**。不得自造 Subject Index 外的新实体名。

### 二、镜头规划与计算 (Shot Planning & Timing)
1. **拆镜推演**：明确场次 -> 切分分镜 -> **逐镜建立实体出入画物理闭环**（上一镜 `本镜出场实体` → 本镜 `上镜出场实体复核` 逐资产 → 复核后才列 `本镜新入镜资产` → **有出画时写 `出画运镜` 并用 Video 呈现** → 本镜末写 `本镜出场实体`）；**具名角色画内可见性或面部可读性变化**须对应上游 Beat 过渡动作与**出画方式**，一 Beat 拆多镜时出画/入画/转身/反打过程不得删略。
1.5 **ENV 驱动的 Beat-Shot 拆分与合并（强制）**：拆镜粒度以 Beat 的 **ENV** 与 **主环境** 为双轴判据。主环境 = `ENV:[...]` 去除 `{N}度`/状态/正反打等衍生前缀后的登记主体（如 `Office` 之于 `0度Office`/`180度Office_桌后反打`）。**同一主环境内**观察侧/正反打/360 度转角产生的**衍生 ENV 切换**（OTS、反打、换手等）**不属于**「主环境不一致」。

   **同角度环境桶（强制定义，归镜判据）**：对 `ENV:[...]` 名称取**首个** `-`、空格或 `_` 之前的子串为**同角度环境桶键**（无上述分隔符则整名为桶键）。桶键 = **同一主环境 + 同一观察角度**（如 `180度办公室会客区` = 180° + 主环境「办公室会客区」）。例：`ENV:[180度办公室会客区_桌后反打]` 与 `ENV:[180度办公室会客区_乙侧反打]` 桶键均为 `180度办公室会客区` → **视为同一环境**；`ENV:[0度办公室会客区]` 桶键为 `0度办公室会客区`，与 `180度…` **不同桶**；`ENV:[办公室会客区_火灾]`（状态衍生，无 `{N}度` 前缀）桶键为 `办公室会客区`。

   **核心归并原则（强制，优先级自上而下）**：
   1. **同一主环境内合并优先（强制）**：同一主环境内（及不同环境均依赖同一主环境的衍生环境），相邻 Beat 的 `ENV:[...]` **逐字完全相同**，或**同角度环境桶键相同**（同一主环境同一角度，仅 `-`/空格/`_` 后缀差异），或者**属于同一主环境的不同衍生环境** → **均以合并为优先原则，默认归入同一 Shot**。
      - 当归入同一Shot的不同Beat使用了不同的衍生环境时，**必须在视频生成提示词 (`Video Content (CN)`) 中明确通过运镜方式（如摇镜头、Pan、推拉等）来展现环境的切换。**
      - **禁止**仅因 Beat 边界或衍生后缀差异机械拆镜。
   2. **同主环境对戏归镜（强制）**：同一**主环境**内、构成连续**对白往返/打斗/近身攻防/术法对撞**等对戏过程的相邻 Beat，即便衍生 ENV 因 OTS/反打/换手而切换 → **默认归入同一 Shot**，在 P 段内用 §5.5 G 运镜切换视角（Arc Orbit / Reverse Shot / OTS Switch / Pan to New Axis / Whip Pan 等，禁硬切）；**禁止**合镜内每个后续 Beat 都另起一段全景 Wide **打断对戏**式重复建置。**澄清（与「每镜必建置」不冲突）**：本条只约束**同一 Shot 内**中途勿机械复写全景；**每一个独立 Shot 的 P1 仍须完整角色建置**（§八.2「每镜必建置」）；若「同上/同时」Beat 因超时拆分等落成**新 Shot**，新镜 P1 **仍须**据上一 Beat/上镜终态主动写全员落位，**不得**以归镜规则为由省略建置。
   3. **唯一拆分触发 = 超时长或跨主环境**：完成 ①② 归并后，**合镜Duration > 15s（若超出时间在2秒内，则强制压缩成最高分镜时间15秒而不进行拆分）** → 若仍超容差，按「超时拆分建置桥接」拆为多 Shot；**相邻 Beat 主环境不同（且无上下级依赖关系）** → 边界拆 Shot（§二.1.5 跨主环境拆分）。**除此以外禁止拆镜**。

   **归并前置核验（①② 均须满足，缺任一则不得归镜）**：
   - **信息点零丢失**（= §一.2 Beat 绝对覆盖）：各 Beat `{行为过程}`/`{结果落位}`/道具/环境交互/位移/微动作/微表情/对白/反馈须**全部**在对应 P 段可检索。

   **合镜时长合并计算（强制，与 ①② 配套）**：
   - 完成 ①② 归并分组后，**须将同组内全部 Beat 的时长合并累计**，再判是否 >15s；**禁止**只对单个 Beat 单独计时而忽略同组其他 Beat 的叙事耗时。
   - **计算步骤（逐项相加，强制）**：① 组内**逐 Beat** 按 §二.4 分别写出完整 `时间预估` 分项——**建置 / 语言 / 动作 / 微表情 / 特效 / 反馈 / 转场·停顿**（该 Beat 凡有对白、动作、微表演、反馈、建置更新、视角切换等**须逐项估时**，无该项写 `0s`，**禁止**整 Beat 只写一个总数或只写「并行核」）；② 各 Beat 内按 §二.4 计算顺序得出 **Beat 小计**（`Beat小计 = 建置 + 语言 + 动作 + 微表情 + 特效 + 反馈 + 转场/停顿`，同相位并行仍取 Max 后计入对应类，但**七类分项须齐**）；③ **合镜累计**：`合镜Duration = Σ（组内各 Beat 小计）+ Beat衔接补偿`，**组内 Beat 按叙事先后逐项串行相加**——**每个 Beat 的建置/语言/动作/微表情/特效/反馈/转场均须计入**，**禁止**以 ENV 未变、对戏归镜、建置更新=否 等为由省略后续 Beat 任一分项；④ **Beat衔接补偿（强制）**：合镜组内 **Beat 数 N ≥ 2** 时，`Beat衔接补偿 = (N − 1) × 1s`（每多合并 1 个 Beat **+1s**，补偿 Beat 间节奏留白/切换/承接）；单 Beat 未成组时 **Beat衔接补偿 = 0s**；⑤ 四舍五入得 **合镜Duration**。
   - **`时间预估:` 合镜写法（必填）**：`Beat3(建置1s+语言3s+动作2s+微表情1s+反馈1s=9s)+Beat4(建置2s+语言2s+动作1s+微表情1s=6s)+Beat衔接补偿1s=合镜Duration=15s`（七类分项须写全，0s 亦标明；**N 个 Beat 合镜须显式写 `Beat衔接补偿(N-1)s`**）。
   - **`Beat-Shot映射:` 必填（合镜时）**：`合镜Beat=Beat3+Beat4`｜`合镜Duration=…s`｜`分项=Beat3=…s+Beat4=…s`（分项须对应上式逐项相加）；单 Beat 未成组时写 `单BeatDuration=…s` + 完整七类分项。
   - **反例**：❌ Beat3(8s)+Beat4(7s) 同 ENV 归镜却写 `Duration=7s` 仅取末 Beat｜❌ Beat5–Beat8 各 Beat 单独均 ≤15s 但合镜累计 18s 仍强行 1 Shot｜❌ 合镜组 Beat2 有对白/动作却整 Beat 计 0s 或只写并行核｜❌ Beat4 建置更新=是 却少计建置/语言/动作任一项。

   **未继续合并说明（强制，合镜Duration 或 单BeatDuration <= 15s 时必填）**：
   - 本镜 **Duration <= 15s** 且 **存在可与之归镜的相邻 Beat 未并入本镜** 时，`Shot Logic (CN)` **须写** `未继续合并说明:`，阐明**为何未与前一/后一 Beat 继续归镜**；**无相邻可归 Beat**（Scene 末 Beat、已与前镜合至上限等）亦须写明。
   - **合法原因（择实填写）**：`合镜累计>15s`（若与下一 Beat 合并将超时，**预估须含 Beat衔接补偿**）｜`跨主环境`｜`ENV角度桶不同`（写明桶键）｜`不满足同主环境对戏归镜`（写明与下一 Beat 非对戏链）｜`Scene首Beat无前一Beat` / `Scene末Beat无后续Beat`｜`已与前镜/后镜合至 §二.1.5 上限`。
   - **反例**：❌ 合镜Duration=8s 且 Beat2 同 ENV 桶可归却未写 `未继续合并说明`｜❌ 写「时间跳跃」等非 §二.1.5 合法项作未合并理由。
   - **正例**：✅ `未继续合并说明: 未与Beat2归镜，原因=ENV角度桶不同（0度农家院子 vs 90度农家院子_侧面近景）；若合并合镜Duration=14s≤15s 仍不归，因不满足原则1/2`｜✅ `未继续合并说明: 无后续Beat（Scene末Beat）`｜✅ `未继续合并说明: 未与Beat5归镜，原因=与Beat5合镜累计将达18s>15s`。

   **超时拆分建置桥接（强制，触发 = ①② 归并后 合镜Duration > 15s）**：
   - **前镜末段（服从 §三.1 Pull Back 双前提，禁止借桥接破例）**：超时拆分**不**豁免 Pull Back。前镜末是否 Pull Back / 回 Two Shot·Wide **一律**按 §三.1 双前提判定——**前提②不满足**（后镜出场具名 CHAR 数 ≤ 前镜末可见数，如 2→2 同场继承）→ **禁止** Pull Back / Dolly Out / Arc Orbit Return 等回建置后拉；镜末**保持**本镜实际景别（CU/MCU/OTS 等），`收束落幅判定` 写 `Pull Back前提=不满足｜缺项=下镜出场人物未多于本镜｜超时拆分=是｜落幅档位=保持本镜末景别`。**禁止**写 `Pull Back前提=满足` 却依据=超时拆分建置桥接、同时 `下镜人物多于本镜=否`。
   - **仅当双前提均满足时**：前镜末可用 Pull Back 等回建置（§5.5 G），**2–3s**，计入 `转场/停顿Xs`；后镜 P1 自扩框后的建置幅继承。
   - **后镜 P1（强制）**：以**继承前镜末帧**为准做**重新建置说明**——读取前镜 `本镜出场实体` + 终态落位/持握/朝向/关系站位/ENV；前镜末若保持近景则后镜 P1 **可自该近景/中近景起幅继续**（或同轴 Reframe/Push，**禁**为「补建置」无人数增量而另做 Pull Back）；仅当前镜末已合法回全景/Two Shot 时，后镜才在 Wide/Two Shot 建置段逐实体写清 FG/MG/BG 与七要素。角色/道具状态须与前镜结束画面**一致继承**，仅允许本镜内已写明的位移/交互继续演化。
   - **组内拆分**：按 Beat 顺序或自然叙事断点切分，各子 Shot 仍须 §一.2 信息点零丢失；相邻子 Shot 之间执行「前镜按双前提落幅 → 后镜继承该末帧」桥接，**非**强制「前镜必回建置」。
   - **`Shot Logic (CN)` 必填** `超时拆分建置桥接:`（前镜末落幅=保持近景|合法Pull Back｜继承出场实体=…｜后镜 P1 起幅摘要=…｜Pull Back前提=满足|不满足+缺项）；**禁止**把超时拆分写成 Pull Back 的满足依据。

   **反例**：❌ 同 ENV 连续 Beat 机械拆镜重复建置｜❌ 合镜 >15s 仍 1 Shot 删内容｜❌ `Pull Back前提=满足` 依据=超时拆分建置桥接，但 `下镜人物多于本镜=否`（如 2→2）仍回 Two Shot

   **跨主环境拆分（强制，独立于超时长）**：相邻 Beat **主环境不同**（如 `Office`→`Corridor`）→ **默认拆成不同 Shot**，在主环境边界切镜；**禁止**跨主环境 Beat 塞入同一 Shot 内部硬切（连续跟拍穿越两主环境走 §5.5 G「门槛/通道穿越」，仍计独立切换耗时）。

   **判定顺序（强制）**：① 扫描相邻 Beat → 原则 1 归镜 → ② 原则 2 归镜 → ③ **各归镜组内逐 Beat 七类分项估算 + 逐项相加得合镜Duration** → ④ **合镜Duration ≤15s → 该组 1 Shot** + **`未继续合并说明:`**（<=15s 时必填）→ ⑤ **合镜Duration >15s** 超时拆分 → ⑥ 跨主环境边界拆 Shot。`Beat-Shot映射:` 须含合镜累计 Duration、分项、**`未继续合并说明:`**（适用时）。

1.6 **单 Beat / 合镜组归镜（强制）**：§二.1.5 归并后 **合镜Duration ≤15s → 1 Shot**；**唯一拆分** = 合镜 >15s｜跨主环境。`Beat-Shot映射:` + `<=15s 时 `未继续合并说明:`** 必填。

   - **首场首镜抓力**：全剧首镜用压迫/冲击构图承接抓力结构，并在 `Shot Logic (CN)` 写明抓取逻辑。  
   - **重要场景表现**：当为重点场景或是情绪爆发的关键节点时，**必须**使用远景/全景镜头（Extreme Wide / Wide/ Pull Back 航拍后拉），通过广阔的环境氛围、天地比例等元素，来展现事态的严重性、角色的渺小、以及整体的情感冲击力；或者也可以通过拉近焦点，给予某个核心道具、微表情或细节动作的特写（Close-Up / ECU / Insert），以微观视角透视整体的关键结果。
3. **每个新 Scene 首镜摄影（内容序=Stage 1；本层写运镜）**：上游首 Beat 已定「吸睛→建置→入戏」；本镜用运镜实现——吸睛 P 段继承上游 **≥1 环境物理动势 + ≥1 实体动势**（§七.7；Logic：`吸睛动势:`）；宏观/EWS 吸睛后须 **≥1 特写陪衬 P 段** 再入戏（Logic：`宏观→入戏过渡:`）；远距/延迟全局建置优先 Drone/Crane/Bird's-Eye 补全（Logic：`全局建置补全:`）。禁静态空 Establishing。**禁止另起独立 Shot 只写开场/OT-/吸睛**——`开场转场技巧说明` / OT- / 吸睛动势 **必须**落在覆盖 **Beat 1** 的那一镜的 **P 段内**（通常为该镜 P1），并写入该行 `Beat-Shot映射`；**禁止**在 Beat 1 映射镜之前多输出一行无 Beat 映射的「首镜/Establishing」。
4. **时长推演公式 (强制 4s-15s)**：
   - **基础计时单位**：所有时间预估必须拆成可核对类型，写入 `Shot Logic (CN)`：`时间预估: 建置Xs + 语言Xs + 动作Xs + 微表情Xs + 特效Xs + 反馈Xs + 转场/停顿Xs = 串行Ys；并行核=Max(...)Xs；Duration=Zs。` 无该类型写 `0s`，不得只写总秒数。
   - **计算顺序（强制，防重复计时）**：① 先按下列规则分别估算各类型耗时，写出分项；② 同相位并行的对白/动作/微表情/特效/运镜，只取 `Max(语言, 动作, 微表情, 特效, 运镜)` 作为**并行核**，**禁止**把已并行项再次全额串行相加；③ 仅对**必须串行**的段落追加：建置（首段或建置更新=是）、转场桥接、结果落位定格、强悬念插帧、独占反应镜/插帧；④ 四舍五入得 Duration。
   - **语言耗时（分语种估算，强制）**：先读本句台词正文与上游「用{语种|方言}说道」标签（若有），再据 `# Project Context` 的 `Language`/`project_language` 判定估时公式；**禁止**把英文台词按中文字数公式估算（亦禁反向）；**禁止**先把小语种/方言译成中文/英文再估时。`时间预估:` 语言分项须标注语种/方言与算式（如 `语言3s(中文15字/5)` / `语言4s(英文10词/2.5)` / `语言2s(粤语4字/5)` / `语言2s(日语6字/5)`）。
     - **中文**（含标准普通话旁白/OS/V.O./自白；**无**方言标签时）：`中文字数 / 5` 秒；短句保底 1.5s；**≥20 字**长句先拆短句，各短句分别计时并加 0.3–0.8s 呼吸停顿。
     - **英文**（含 English narration/OS/V.O./monologue）：`英文单词数 / 2.5` 秒；短句保底 1.5s；**≥10 词**长句先拆短句/从句，各段分别计时并加 0.3–0.8s 呼吸停顿；缩写/连写（I'm、don't、gonna）按 **1 词**计。
     - **方言**（粤语/四川话/东北话/闽南语/上海话等，上游已标「用{方言}说道」）：书面以汉字为主时按 **汉字字数 / 5**；须在分项写明方言名；**禁止**按普通话语感改写后再估时。
     - **其他小语种**（日语/韩语/法语/西班牙语等非中非英）：按原文**书写单元**估时——汉字/假名/谚文音节块等合计字符近似 `/ 5`，拉丁字母小语种近似按 **词数 / 2.5**；短句保底 1.5s；分项须写明语种名。
     - **多语种/方言混句**：按各片段分别估时后相加（中文/方言汉字走字数/5，英文/拉丁小语种走词数/2.5，其他小语种走上条），再加句内呼吸停顿。
     - **须读上游 `rhythm`/`stress`/`pause` 微调**——`pause` 显式长停/换气/破折号或省略号截断 +0.5–2s；`rhythm=一字一顿/一字慢读/staccato/slow burn` 等须相应拉长或压缩语言段；`stress` 重读词处可 +0.2–0.5s 微表演相位；口型可见的对白不得压缩到低于语言耗时。
   - **音效耗时（强制，有则计）**：上游尖括号 `<…>` 可听音效——短促一声（门轴/撞击/狗吠切入）**0.5–1.5s**；持续环境声桥/雨打窗/远处犬吠铺垫 **1–3s**；与对白/动作同相位时并入并行核取 Max，独占声先入/声桥相位才全额计入 `转场/停顿Xs` 或并入动作核；`时间预估:` 有音效时须写 `音效Xs` 或并入已标明的并行核（如 `并行核=Max(语言3s,音效1s)=3s`）。**禁止**因「品质收束含无背景音乐」而删上游剧情音效（「无背景音乐」≠无画内/画外剧情音效）。
   - **建置/运镜耗时**：新场景空间建置1-3s；关键角色/道具首次落位每组0.5-1s；焦点转移/Rack Focus 0.5-1.5s；短程推拉摇移1-2s；复杂关系重建或OTS反打建轴2-3s；**视角/反打切换过程**（§5.5 G）**1.5–3s**，计入对应 P 段或 `转场/停顿Xs`；**§二.1.5 超时拆分**仅当 §三.1 双前提满足时前镜回建置才计 2–3s，否则镜末保持近景不计 Pull Back；后镜 P1 继承末帧 1–2s；高速追逐/打斗/景别切换运镜与动作同相位并入并行核取 Max。运镜与对白/动作同相位时并入并行核取 Max，不得全额另计。
   - **动作耗时**：常态短发力1-2s；递交/转身/落座/起身/后退等单步动作1.5-3s；复杂交互、拉扯、攻击、防御、避障3-5s；长距离或多障碍动作用同镜 P 段简化落点呈现，**Duration > 15s 时**按 §二.1.5 超时拆分。
   - **追杀/穿梭节点耗时（强制，§5.5 D / Stage 1 §31）**：凡本镜含追杀/追逐/追逃/走廊·巷道·楼宇穿梭/门槛连续奔逃/载具追逐等连续位移动量，须按**路径节点**估时——绕障/跃槛/急转/抓扶 **2–3s**；长直段加速跟跑 **3–4s**；门槛/通道穿越 **2–4s**；载具超车/变道 **3–4s**；多节点同镜内**串行累加**计入 `动作Xs`（**禁止**用单次 Max 抹掉节点时长）。同链跨多 Shot 时各镜动作分项之和须覆盖上游整链等效（**≥20s**）。Video 明示秒数须与本分项一致（§5.5 D）。
   - **微表情耗时标准化**：微表情必须按 `前置反应 -> 中段变化 -> 落点结景` 计时；单点微表情0.5-1s；完整三段链1.5-3s；落泪/强忍/心虚/怒意升级等渐变链2-4s；与对白/动作同相位时并入并行核取 Max，独占画面相位才单独计时。
   - **听者反馈耗时**：单个听者即时反应0.5-1s；两人以上反应镜1-2s；群演统一反馈1s；群演随机反馈或空间避让1.5-2.5s。反应已写入 `(Pn)` 听者段且与对白同相位时，并入并行核，不另计；Beat 强制要求独立反应镜或插帧时才全额计入。
   - **特效耗时标准化**：特效按 `触发源 -> 显形/扩散 -> 命中/作用 -> 维持/碰撞 -> 余波/残留` 分相计时；轻量视觉反馈1-2s；单段法术/能量/技术效果3-5s；对抗型特效5-8s；大范围环境影响8-12s；与动作咬合取 `Max(动作相位, 特效相位)+余波`，不得把特效折叠成一个泛化动作。
   - **升格/慢镜耗时**：Slow Motion / Bullet Time / Speed Ramp 等升格相位单独计入 `特效Xs` 或 `运镜Xs`（按主导项）；单段 Bullet Time 或环绕定格 2-4s；局部慢动作 1-3s；Speed Ramp 含入出常速各 0.3-0.5s；与击打/爆炸/法术命中同相位时并入并行核取 Max，独占升格镜全额计入。
   - **打斗/特效快慢节奏计时（强制，§5.4.1）**：含打斗或特效攻击的镜，`时间预估` 须另写 `快慢节奏:` 分项——**常速快相位**、**升格慢相位**、**Speed Ramp 出入**分别估算后串行计入总时长，不得只写单一并行核抹平快慢差异。常速快攻/Whip Pan/Handheld/弹道常速跟拍 2–4s；升格短插 1–4s（Bullet Time 2–4s、Hyper Slow-Mo 1–3s、Time Slice 1–3s）；每次常速↔升格切换 Speed Ramp 入+出各 0.3–0.5s。特效六相链中**命中/对撞/爆炸/作用**相须单独计入升格慢相位；多 P 段快慢交替时各 P 段并行核**相加**（快相位与慢相位不得合并为一次 Max）；整镜仅常速或仅升格均视为节奏失败，须**补写 P 段**。**升格占比核验（Mandatory）**：`快慢节奏:` 末尾须写 `升格占比≈Xs/Ys=Z%`（升格慢相位秒数/打斗过程总秒数）；**目标 Z≈30%**（建议 **25%–35%**），**>40% 须削减升格**；快连击常速相位合计须 **≥50%** 打斗总时长。
   - **情绪停顿/插帧耗时**：道具特写、人物局部特写、环境细节插帧1-2s；强悬念停顿或信息落点1.5-3s；**无情节回忆切片** 0.5–2s，计入 `转场/停顿Xs`（§三.6），与触发/回切同相位并入并行核；只服务节奏，不得无因延时；嵌入主节拍间隙的插帧不重复全额计时。
   - **总耗时计算**：`T = 建置串行 + Σ各段并行核 + 独占反馈 + 独占插帧/停顿 + 转场桥接`；单段并行核 = `Max(语言, 动作, 微表情, 特效, 运镜)`；多 P 段同镜内各段并行核**相加**（段间切换即节奏，不每段重复全额建置）；多主体同时动作用主动作计时，辅助反应按0.3-1.5s补足（已与对白并行则并入 Max）。
   - **合镜多 Beat 累计（强制，§二.1.5 配套）**：同一 Shot 承担 **≥2 Beat** 时，**组内每个 Beat 均须写出完整七类分项**（建置/语言/动作/微表情/特效/反馈/转场·停顿），再 **逐项串行相加**，并加 **Beat衔接补偿**：`合镜Duration = Σ 各 Beat 小计 + (N−1)×1s`（N=合镜 Beat 数）；**禁止**只取其中一个 Beat 的时长；**禁止**省略 `Beat衔接补偿`；**禁止**后续 Beat 省略语言/动作/建置等任一类。`时间预估:` 须写：`Beat3(…=Xs)+Beat4(…=Ys)+Beat衔接补偿1s=合镜Duration=Zs`。
   - **调平硬规则**：预期总时长T -> 四舍五入为整数秒；低于4s补足建置/反应/落点停顿，高于15s按 §二.1.5/§二.1.6 超时拆分；**禁止**通过删除/概括上游内容来降时长（§一.2）。
5. **切镜客观连续性（Video 写法）**：`Video Content (CN)` **只写本镜画面内可见的最终状态与变化**，禁写“承接上一镜/上镜/前镜/上一 Beat/previous shot”及“同上一镜/延续上一镜/承接 Beat”等代指或承接说明；Beat 衔接、前接判定、变更依据、可剪辑合镜推演**只写** `Shot Logic (CN)`，画面以内化描写直接呈现当前实体落位与空间关系（字段见下条）。
6. **分镜间衔接逻辑 · 可剪辑合镜（最高硬约束）**：相邻 Shot 须设计为**可在剪辑台上直接合镜**——上镜末帧与本镜起幅在时空、轴线、视线、动作相位、实体态上**可咬合**；`Shot Logic (CN)` **每镜必填**衔接推演；**禁止**出现合不上、跳接穿帮、轴线/朝向矛盾、动作相位错位等**不合合镜逻辑**的设计。

   **目标**：剪辑师（或下游自动合镜）仅凭相邻两镜即可完成连续叙事切点，无需补拍、无需改戏、无需假设中间缺镜。

   **字段（`Shot Logic (CN)` 强制）**：
   - **`前接说明:`**（SH02+ 必填；Scene 首镜写 `前接说明: Scene首镜无上一镜`）——上镜 `Shot ID`｜上镜末景别/机位能量｜上镜末主拍实体与终态（落位/朝向/姿态/持握）｜本镜 P1 起幅如何咬合该终态。
   - **`分镜衔接:`**（每镜必填，含 Scene 首镜对下一镜的预留）——`衔接类型=`（下表择 1–2）｜`切点相位=`（上镜末动作/对白/视线落在哪一瞬）｜`本镜起幅咬合=`（Match 锚点 / 同轴续拍 / 反打起幅 / 环境切换起幅等）｜`轴线=`（保持｜合法过轴+依据｜新场重建）｜`银幕方向=`（保持｜动机改向+依据）｜`下镜预留=`（本镜末为下镜准备的落幅/锚点，Scene 末镜写无）。
   - **`可剪辑合镜核销:`**（SH02+ 必填）——`时空连续=是|否`｜`实体态连续=是|否`｜`轴线/银幕方向=是|否`｜`动作相位可咬=是|否`｜`不合逻辑项=无|…`；任一项为否且无合法例外依据 → **须改设计后再输出**。
   - 另须保留：时空关系摘要、桥接依据、跨幅级别（景别跨度）；含对白收束时另写 `收束落幅判定`（§三.1）；**每个新 Scene 的首镜**必写 `开场转场技巧说明`（见 §二.3、§十一候选库），禁“无过渡/None”。

   **合法衔接类型（择实，禁空写）**：
   | 类型 | 何时用 | 咬合硬门槛 |
   | :--- | :--- | :--- |
   | **同轴续拍 / Reframe** | 同主环境、同观察侧、人数/景别微调 | 本镜 P1 起幅 = 上镜末同轴画面的合法延续或相邻一档景别；实体态零跳变 |
   | **Match on Action（动作 Match）** | 跨镜拆开同一连续动作 | 上镜末停在动作**未完成中段**；本镜起幅自**同一动作后续相位**续写；禁上镜已落定再本镜重演起手 |
   | **Eyeline Match（视线 Match）** | 看→被看 / 反应镜 | 上镜末视线方向与本镜被看对象/空间方位**可核销**；禁视线落空或反向无动机 |
   | **Shot-Reverse / OTS 切换** | 对白往返、对戏反打 | 轴线声明清晰；OTS 四要素齐（§七.6）；禁无过轴声明的越轴跳切 |
   | **Graphic Match（图形 Match）** | 构图/形状/色块桥接 | Logic 写明上下镜图形锚点；Video 各自写清可见锚点画面 |
   | **Insert ↔ 主镜回切** | 道具/局部特写插入后回主 | 回切后主镜实体态 = Insert 前终态 + Insert 已交代的合法变化 |
   | **环境/门槛切换** | 跨主环境或 §5.5 G 切换 | 服从 §二.7；有过程运镜；禁硬切换场 |
   | **Motive Cut / 声桥 / 遮挡交接** | 情绪或信息动机切 | 须写动机锚点（遮挡物/声源/光变）；禁无锚点硬跳 |

   **可剪辑合镜硬门槛（相邻 SH 均须满足）**：
   1. **时空连续**：同 Scene 内默认连续时空；时间跳跃/闪回须走 §三.6 并在 Logic 标明，**禁止**无声明时空跳切。
   2. **实体态连续**：上镜 `本镜出场实体` → 本镜 `上镜出场实体复核` 逐项咬合；持握/穿戴/开合态/门窗态/座姿承托面与上镜末一致，直至本镜明文演化；**禁止**上镜已放下的道具本镜无过程又在手、上镜已出画角色本镜无入画运镜突然在场。
   3. **轴线与银幕方向**：对戏/走位保持 180° 轴线；银幕左右运动方向跨镜一致；越轴须 §5.5 G 过轴过程或 `MotivatedCross` 依据；**禁止**无声明左右对调、走位方向对倒。
   4. **动作相位可咬**：跨镜动作须 Match on Action 或上镜完整闭环后再切静态结果；**禁止**上镜动作已完成落定、下镜又从同一起手重演（除非上游明文重复动作）；**禁止**因果链（施力→命中→反馈）被无桥接地拆到无法合镜的两镜。
   5. **景别/能量可切**：相邻镜景别与运镜能量跨度服从 §三.1 / §三.4（同级或相邻一档；跨 ≥2 档须剧本动机 + Logic 桥接）；**禁止**无动机 Wide↔ECU 硬跳、Static 建置↔Bullet Time 无 Ramp。
   6. **落幅为下镜服务**：本镜末按 `收束落幅判定` / `下镜预留` 留给下镜可接切点（近景续对白链、动作中段、视线锚、门槛起幅等）；**禁止**镜末停在无法被下镜 P1 合法咬合的悬空态（动作半截无 Match、全员已出画却下镜仍同场无入画等——有明文例外须写依据）。

   **不合合镜逻辑的设计（禁止，检出即改）**：
   - ❌ 上镜末 MCU 对白未完结落幅，下镜无桥接却 Wide 全场重铺且角色姿态/持握与上镜矛盾
   - ❌ 正反打越轴且无过轴声明/无 OTS 四要素，左右站位对调无法合镜
   - ❌ 上镜拳已命中并反馈完，下镜又从挥拳起手重演同一击
   - ❌ 上镜角色出画完成，下镜无入画运镜却已在场交谈
   - ❌ 上镜视线看画右门，下镜被看对象却在银幕逻辑上的画左且无转场说明
   - ❌ 跨主环境硬切无门槛/Match/声桥过程
   - ❌ 仅写「切下一镜」而无 `分镜衔接` 类型与咬合锚点

   **正例摘要**：✅ `前接说明: SH01末=MCU Lin口型落点+持文件｜分镜衔接: 类型=Eyeline Match+OTS Switch｜切点=Lin视线落向Chen｜本镜起幅=过Lin右肩OTS看Chen｜轴线=保持｜可剪辑合镜核销: 全是`｜✅ `分镜衔接: 类型=Match on Action｜切点=SH02末右直拳出至半途｜本镜起幅=同拳后半程命中+Chen架肘｜银幕方向=保持`

   **与 Video 分工**：衔接类型、咬合判定、轴线/核销**只写 Logic**；Video 把咬合结果写成**本镜可见起幅画面**（禁写「承接 SH01」字样）。
7. **跨环境声明（强制）**：环境切换时 `Shot Logic (CN)` 与 `Video Content (CN)` 均须写“切换到 ENV:[...]”、物理桥接与**空间重建**；并须**显式写出环境切换运镜手法**（从 §5.5 G 择 1–2 项），禁无运镜硬切。`Shot Logic (CN)` 必填 `环境切换运镜:`（触发类型+选用项+桥接依据）+ **`360度转角继承:`**（§七.6，衍生 ENV 时）；`Video Content (CN)` P 段须写出机位运动过程（含**顺时针回转角度或 Reverse/OTS 等效**与 BG 更替），与 ENV 切换同相位，**禁**把 `empty_view_delta`/`angle_mapping` 等上游字段粘贴进正文。**环境切换建置可执行性（强制）**：重建 FG/MG/BG 后须对照当前 `ENV:[...]` 固定结构/家具布局与空镜差异，核验实体落位与本镜动作/走位/接触/视线是否可拍可行；与 ENV 实体安排冲突时 **禁止**改写 Beat 动作/落位/朝向/姿势——`Shot Logic` 标 `建置冲突:` + `{覆盖核销}` 上游缺口回流，Video 仍按 Beat 明文转写可见面；禁止为「可执行」擅自挪人改戏。
8. **分镜序号三层编码（强制）**：输出表格每一行须同时正确填写 `Shot ID` 与 `Scene ID`，严格区分并完整继承上游 **分集 → 场景 → 分镜** 层级，禁止省略任一层级或混用非规范编号。
   - **权威来源**：`Episode ID`、`Scene ID` **唯一**取自上游 `# Core Scene Info` / 输入 Scene 表对应行的 `Episode ID`、`Scene ID` 列；**禁止**自造集号/场号、禁止与上游不一致的 EP/SC 前缀。
   - **字母后缀子场（强制原样）**：上游 `Scene ID` 若含字母后缀（如 `EP01_SC01B`、`EP01_SC02A`），`Scene ID` 与 `Shot ID` 的场景段**必须逐字原样输出**，**禁止**剥除字母写成 `EP01_SC01` / `EP01_SC01_SH01`，**禁止**改大小写、重排或自造后缀。
   - **规范格式（零填充，强制）**：
     - **分集**：`EPxx`（如 `EP01`、`EP12`）
     - **场景**：`EPxx_SCyy` 或 `EPxx_SCyy`+字母后缀（如 `EP01_SC01`、`EP01_SC01B`、`EP01_SC02A`；`yy` 为场内序号，**2 位**零填充；字母后缀原样继承上游）
     - **分镜**：`{Scene ID}_SHzz`（如 `EP01_SC02_SH01`、`EP01_SC01B_SH01`、`EP01_SC02_SH12`；`zz` 为场内镜序号，**2 位**零填充）
   - **层级包含关系（强制）**：`Shot ID` **必须**完整包含三级路径；同行 `Scene ID` **必须**等于 `Shot ID` 去掉 `_SHzz`（及可选补镜 `_n`）后的前缀，**逐字一致**（含字母后缀）。❌ `Shot ID=EP01_SC01B_SH01` 但 `Scene ID=EP01_SC01`｜❌ `Shot ID=EP01_SC02_SH01` 但 `Scene ID=EP01_SC01`｜❌ `Shot ID=SH01`｜❌ `Shot ID=SC02_SH01`｜❌ `Shot ID=EP1_SC2_SH3`（未零填充）
   - **场内连续编号（强制）**：同一 `Scene ID`（含字母后缀，整串相等才算同场）下，`SH` 从 `01` 起按**叙事/拆镜顺序**连续递增（`SH01→SH02→…`），**禁止**跳号、重号、倒序、同场重启 `SH01`；一 Beat 拆多镜须占用连续 `SH` 号段。`EP01_SC01` 与 `EP01_SC01B` 为**不同场**，各自从 `SH01` 起编。
   - **表格行序（强制）**：整张 Shot List 行序须按 **分集升序 → 同集内场景升序（含字母后缀按上游场序）→ 同场内分镜升序** 排列；完成当前 `Scene ID` 全部镜头后再进入下一场；**禁止**同表内乱序穿插不同 Scene 的行（除非上游明确要求分场分批输出且每批仍自洽）。
   - **跨场/跨集切换（强制）**：进入新 Scene 时 `Scene ID` 与 `Shot ID` 的场景段**同步切换**（含字母后缀）；`SH` **每场重置**为 `01`，**不得**跨 Scene 延续 `SH` 序号。
   - **补镜/插镜后缀（例外）**：事后插入的分镜可在基础 `{Scene ID}_SHzz` 后追加 `_1`、`_2`…（如 `EP01_SC02_SH03_1`、`EP01_SC01B_SH02_1`）；常规批量生成仍用标准 `SHzz`，**禁止**用 `_1` 替代正常递增编号。
   - **输出前核验（强制）**：逐行检查——① `Shot ID` 匹配正则 `^EP\d{2}_SC\d{2}[A-Za-z]*_SH\d{2}(_\d+)?$`（字母后缀可选；补镜后缀可选）② 同行 `Scene ID`= `Shot ID` 去掉 `_SHzz(_n)?` 后的前缀且与上游逐字一致 ③ 同场 `SH` 连续无重复 ④ 行序符合 EP→SC→SH 叙事序；任一失败须重排或重写 ID 后再输出。

### 三、摄影与镜头语言 (Cinematography)

**本章 = 摄影技法实现**（不改上游叙事）；景别/运镜/景深/转场细则见各专节与 §5.5。
1. **景别/角度专规**
   - **角色局部特写比例（强制）**：每场须有足够 **P 段**特写/局部特写（Close-up / ECU / Insert），常规场景建议同 Scene 内约 15%-25% 相位为特写级。
   - **成人向局部特写边界（强制）**：仅当画面角色明确为成人时，成人向/成熟向场景可安排嘴唇、眼部、胸部、腿部、臀部等局部特写；所有胸部/臀部/腿部特写必须以服装覆盖、姿态线条、剪影、光影轮廓、镜面/遮挡构图等影视化方式表达，禁止裸露、露骨性行为、低俗挑逗、未成年人或年龄不明角色的性化局部镜头。
   - **局部特写功能约束**：嘴唇特写用于口型、呼吸、停顿、欲言又止；眼部特写用于视线、泪光、瞳孔、警觉；胸部/肩颈特写用于呼吸起伏、服装材质、心跳紧张、权力姿态；腿部特写用于步伐、站姿、距离变化；臀部/腰臀线条特写只用于服装轮廓、转身、落座、走位节奏或遮挡转场。禁止把局部特写写成脱离剧情的孤立凝视。**群演/匿名背景人群例外（强制）**：局部特写/中景/中近景**原则上不分配给群演/背景人群**；群演仅作远景/全景/虚化 BG 层出现，见 §七.7-b。
   - **对话景别切分（强制）**：口型可读的对白、画内听者可见的 OS/V.O.、Shot-Reverse-Shot / OTS、反应镜、以及 `(Pn)` 段内须可读的微表情与微动作，**原则上**采用 **Medium Shot / Medium Close-up / Close-up / OTS**（中景、中近景、特写、过肩）；禁止在常规对话段落用 Wide / Full / Master / Two Shot 全景承载口型可读对白。听者反应、微表情链、微动作须与说话镜处于**同级或相邻一级**景别，保证面部与口部/眼部可读。**画幅比例外与强化**见下条「画幅比驱动的对话景别」。**例外**：特效相位、宏观群体主节拍（Stage 1 §28 + §5.5 E）须远景/全景主拍。
   - **画幅比驱动的对话景别（强制，读 Project Context `Aspect Ratio`）**：
     - **竖屏画幅（Mandatory 强化）**：当 Project Context **明确**为竖屏比例（如 **`9:16`**、`3:4` 等 height ≥ width 的声明）时，**原则上**每条口型可读对白须为该**说话人**单独分配 **中景或特写** P 段——**Medium Shot / Medium Close-up / Close-up / OTS / Dirty Single**；竖屏画幅窄、双人同框信息密度低，**禁**用 Wide / Full / Master / Two Shot / Establishing 承载说话人主拍落幅。多人对话须**按说话人逐句/逐组切换**至该人物中景或特写主拍（可 OTS 但落幅仍须说话人面部/口部可读）；Scene 建置 P1 若用全景/中全景，须在本镜内**尽快 Push In / Reframe** 至说话人近景。**Walk-and-Talk** 竖屏时仍优先 **Medium Shot / Medium Close-up** 跟拍，禁长时间 Wide 跟拍承载口型对白。
     - **横屏画幅（灵活安排）**：当 Project Context **明确**为 **`16:9`** 或未声明画幅比、且无从推断为竖屏时，对话景别**可根据剧情合适安排**——允许 Two Shot / 中全景关系镜、Walk-and-Talk 中全景跟拍、Scene 建置 Wide、以及 **§三.1 双前提满足时**的收束 Pull Back 回全景等，但仍须遵守本条「对话景别切分」口型可读禁 Wide 主拍之通则，以及 §三.1 景别递进、收束落幅、动作主体运镜等专规；不必机械要求每句对白都切至 MCU/CU，但说话人须保证面部/口部可读。
     - **其他画幅**（如 `4:3`、`2.35:1`、`1:1`）：`画幅比继承:` 注明比例与竖|横判定；对话景别在遵守口型可读通则前提下，**竖向窄画幅倾向说话人中景/特写**，**横向宽画幅可按剧情灵活调度**。
   - **近景对话背景虚化（允许，推荐）**：**Medium Shot / Medium Close-up / Close-up / OTS / Dirty Single** 等近景对话 P 段，**可以**采用 **浅景深（Shallow Depth of Field）虚化背景**（Bokeh / Defocus / Selective Focus / Rack Focus 落至说话人），突出说话人面部/口型与微表情；听者过肩时听者肩部/后脑、同框非主拍角色**可虚焦**。**须仍保留** `ENV:[...]` 标签，并在虚化背景中写出**白名单内已有实体**的可感知轮廓/动势线索（如失焦文件柜/门框轮廓、虚化窗外树冠轻晃、远距车流缓移——**实体须剧本/Beat/Index/ENV 已出现**），**禁止**近景对白写成纯白底或无环境信息的抠图悬浮感。**Pn 段禁写光影**：虚化背景中的光斑/冷蓝 bokeh/Practical 暖光散景/条纹光漂移等**一律不写在本 P/`(Pn)` 段**，统一写入「动态连续光影/焦点」「光线连动弧光」。**与 §七.7 关系**：P1 全景/深焦建置仍须写清晰环境实体**物理**微动；近景对白 P 段可简化为**虚化背景中已有实体的物理微动**（如「背景虚化失焦，窗外树冠轮廓轻晃、远距车流缓移」），不必重复 P1 全量三层建置。**例外**：剧情须强调空间关系/走位/多人同框调度时，近景对白可维持深焦或半深焦，须在 `Shot Logic (CN)` `收束落幅判定` 或 `P段时序链` 注明依据。
   - **景别递进与防越级（强制）**：同镜内相邻 **P 段**景别变化原则上**逐级**递进或回退；禁止无动机地从全景直切极特写。情绪高点、上游 `细节特写`、转场 Match 可例外，须在 `Shot Logic (CN)` 写明桥接依据。
   - **特写/中景/全景切换规则（强制）**：
     - **全景（Wide / Full / Master / Two Shot / Establishing）**：新 Scene 建置、空间关系首次交代、走位/调度展示、Walk-and-Talk、宏观/特效场面、群像关系；**禁止**作为常规口型可读对白的主拍落幅。
     - **中景（Medium Shot / Medium Full / Medium Close-up / OTS）**：对话主拍默认档、双人/多人关系镜、动作+对白同相位、听者反应镜；口型可读对白、OS/V.O. 听者、微表情/微动作须在 **中景或更近** 可读。
     - **特写（Close-up / Extreme Close-up / Insert）**：情绪高点、上游 `细节特写`、**剧本/Beat 对道具的特别描述**（§三.1「道具特别描述特写运镜」）、微表情链落点、关键道具线索、口型/眼部精确读；每场须保留 §三.1 规定比例的局部特写。**群演/背景人群禁 CU/ECU/Insert 主拍**（§七.7-b）。
     - **群演/背景人群景别（强制，§七.7-b）**：匿名群演/背景人群簇**原则上不得**分配 **Medium Shot / Medium Close-up / Close-up / OTS / Dirty Single** 等中景或更近主拍；须写为 **Wide / Full / Master / Extreme Wide / Long Shot** 内的 **BG/MG 虚化层**（失焦群众、远景路人剪影、背景办公人员簇等），禁 Push In / Rack Focus 对准群演个体、禁群演面部/口部可读特写。**例外**：宏观群体主节拍（Stage 1 §28 + §5.5 E）允许远景/全景群像主拍，仍**禁止**群演 CU/中景单人主拍。
     - **切换路径（强制）**：`全景 → 中景 → 特写` 为默认同镜 **P 段**递进，用 Push In / Pull Back / Track / Rack Focus 等写清过渡。
     - **同镜收束落幅（强制 · Pull Back 有前提）**：`收束落幅判定` 只决定**本镜末 P 段**落幅；**禁止**因收束判定另起 Shot。**已按 §二.1.5 超时拆分**时，后镜 P1 继承前镜 `本镜出场实体` 重新建置。
       - **Pull Back / 回全景前提（强制，双条件同时满足才执行）**：镜末 **Pull Back / Slow Dolly Back / Dolly Out to Master / Arc Orbit Return / Crane Up to Master** 等回全景运镜**仅当**下列二者**同时**成立时才进行——① **本镜已做特写等收紧运镜**：本镜内至少一 P 段到达 **CU / ECU / Insert / MCU**，或执行了 Push In / Crash Zoom / Macro 等将景别自建置幅**收紧至近景/特写**的运镜；② **下镜出场人物多于本镜（硬门槛）**：下一 Shot 须让**比当前分镜更多**的具名 `CHAR:[@…]` 入画/同框可见（含新入镜角色，或本镜特写只拍了子集、下镜须扩至更多仍留场角色同框）。人数比较以具名角色计：`下镜本镜出场实体具名CHAR数 > 本镜末段主拍可见具名CHAR数`（或下镜明确新增 ≥1 具名角色入画）。**仅「恢复原全景」而人数不增 → 不满足前提②，禁止 Pull Back**。**缺任一条件 → 禁止**无因 Pull Back；维持本镜末实际景别即可。
       - **不满足前提时的落幅（强制）**：本镜全程未收紧至特写/近景 → 镜末**保持**本镜实际落幅，**禁**机械后拉；本镜虽有特写但下镜出场人数≤本镜、或继续 CU/MCU/OTS/Insert 对白链 → 镜末**保持近景/中近景**，**禁**为「默认收束」或「超时拆分建置桥接」强行回全景/Two Shot。`收束落幅判定` 须写 `Pull Back前提=不满足` + 缺哪条（本镜无特写收紧｜下镜出场人物未多于本镜）。**硬禁**：`下镜人物多于本镜=否` 时不得写 `Pull Back前提=满足`，不得以超时拆分/继承同场实体/回建置桥接为满足依据。
       - **满足前提时的执行**：优先 `0度{主环境名}` 或本镜对戏沿用的 Master/Wide/Full/Two Shot（人数≥3 用 Wide/Full/Master，双人可用 Two Shot 中全景），运镜用 Pull Back 等（§5.5 G），通常 **2–3s**，计入 `转场/停顿Xs`；写 `Pull Back前提=满足`（本镜收紧=…｜下镜出场CHAR数=…＞本镜末可见CHAR数=…｜新增/扩框角色=…）。**满足依据只能是双前提本身**，禁止填「超时拆分建置桥接」。
       - **全员同框（强制，仅回全景时）**：一旦执行回全景落幅，须使下镜将呈现的、本镜仍留场及即将同框的具名 `CHAR:[@…]` **同框可见**；已按 `出画运镜` 完成出画者可不入框。群演/匿名簇按 §七.7-b 虚化 BG/MG，**不要求**个体清晰，但须可感知在场。落幅写清各具名角色相对 ENV 的落位关系（不必复写 P1 全量七要素）。
       - **例外 = 下镜换环境**：下一 Shot 将**跨主环境**或须执行 §二.7 / §5.5 G **环境切换运镜**进入不同主环境 → 本镜末**不**做回当前环境全景全员，改为环境切换起幅/门槛桥接/Match Cut 锚点等；`收束落幅判定` 须写 `例外=下镜换环境` + 下镜目标 ENV/主环境（**不要求**满足 Pull Back 双前提）。**同主环境内**衍生 ENV 切换（OTS/反打/同角度桶）**不算**换环境，仍按上述双前提判定。
       - **其他例外（从严，须写依据）**：上游明确要求止于特写/Insert 作悬念挂点、或本镜末即出画离开且出画运镜已完成全员离场 → 可保持近景/出画落幅，须在 `收束落幅判定` 写明；**禁止**仅因「对白未完」或「情绪紧」强行 Pull Back（对白未完则同镜内继续 P 段；是否回全景仍看双前提）。
       - **档位**：**回全景 Pull Back（全员同框）**—仅双前提满足｜**保持本镜末景别（前提不满足）**｜**环境切换起幅**｜**保持特写/Insert（须依据）**｜**出画落幅（全员已出画）**。旧档「维持中景关系镜」**仅**作过渡中段。
       - `Shot Logic (CN)` 必含 `收束落幅判定:`（对白组是否完结｜Pull Back前提=满足|不满足+缺项｜落幅档位=回全景全员|保持本镜末景别|环境切换起幅|…｜执行方式=Pull Back/Dolly Out/保持CU/…｜本镜末可见CHAR数=…｜下镜出场CHAR数=…｜下镜人物多于本镜=是|否｜下镜换环境=是|否｜桥接依据）。
     - **同镜内 P 段**：P1 建置可用全景或中全景；对白 P 段落中景/特写；**终段仅在双前提满足时回全景同框**，**不强制**每段对白后复写 P1 同级全景三层建置。
2. **构图**：服从主体视线与运动方向留白（§七条目7 Head Room / Lead Room）。
3. **焦段/透视**：随景别与空间意图选用；禁无动机极端畸变。
4. **摄影机运动**：推/拉/摇/跟；每场至少1个高级运镜；**OTS 四要素**见 §七.6「正反/OTS 专规」（缺任一=不合格）；不可越轴。
   - **运镜选用（强制）**：每场≥1镜；打斗/追逐/法术/轻功/宏观Beat全覆盖。**选用流程**：先读本 Beat 空间/人数/节奏/题材/ENV/情绪落点 → §5.5 按相位择 1–2 项 → **核验 §三.4「运镜递进合理性」+「运镜组合合理性」** → `运镜选用依据:` 写明剧本要素与选用理由 → 写入 `打斗运镜技法`/`特效攻击运镜`/`快慢节奏`/`高速跟拍技法`/`AI高成本奇观`/`升格技法`。禁套用预设片名/名场面，须与本场剧本可核对。
   - **运镜递进合理性（强制，与 §三.1 景别递进同级）**：同镜相邻 **P 段**、同 Scene 相邻镜的机位能量须**可解释递进或回退**，禁止无动机跳级。
     - **能量档位（自低→高）**：① Static Hold / 微呼吸｜② Slow Push / Slow Pull / Soft Pan / Rack Focus｜③ Track / Follow / Lead / Arc Orbit｜④ Handheld / Whip Pan / Crash Zoom / Speed Ramp｜⑤ Bullet Time / 多轴复合奇观。相邻相位原则上**同档或相邻一档**；跨 ≥2 档须有剧本触发（情绪高点、命中、惊吓、追逐加速、Reveal）并在 `Shot Logic` 写桥接依据。
     - **叙事弧对齐（强制）**：建置/入戏偏 **①–②**；对白加压/对峙升级可升至 **②–③**；打斗/追逐/惊吓主相位可达 **③–④**；命中/奇观短插才用 **⑤**；收束/余波须**回落**至 ①–②；**仅当 §三.1 Pull Back 双前提满足**时才用 Pull Back / Crane Up / Soft Dolly Out 回当前环境全景全员同框，禁高潮档硬切收场、禁无前提机械后拉。
     - **与景别同向（强制）**：景别收紧（Wide→MS→CU）优先配 Push In / Track In / Soft Pan；景别打开优先配 Pull Back / Dolly Out / Arc Return；**禁止**景别在收紧却机位在剧烈后拉、或景别在打开却持续 Crash Zoom（Reveal 例外须注明）。
     - **跨 P / 跨镜链**：写出 `运镜递进链:`（P1档→P2档→…→终段档，或 SH01→SH02…）；终段相对高潮须有回落说明。
     - **反例**：❌ P1 Static Wide 建置后 P2 无桥接直上 Whip Pan+Crash Zoom｜❌ 对白加压全程 Static，情绪高点却突然 Bullet Time｜❌ 打斗高潮后硬切 Static CU 无回落运镜。
     - **正例**：✅ Wide Soft Push → MS Track → MCU Push In → CU 微表情 →（下镜出场CHAR多于本镜末可见）Pull Back 扩框同框｜✅ 常速 Handheld 快连击 → Speed Ramp → Bullet Time 命中短插 → Soft Orbit/Pull Back 余波（余波须容纳更多角色同框）｜✅ CU 对白链跨镜延续且下镜人数不增 → 镜末保持 MCU、**不做** Pull Back。
   - **运镜组合合理性（强制）**：同相位叠用 ≥2 种运镜时，须**同轴/同目的/可物理执行**；禁止技法堆砌与相互抵消。
     - **单相位主导（强制）**：每一 P 段**仅 1 个主导运镜**（决定起幅→落幅主轨迹）；可附 **≤1 个辅助**（如 Track 主导 + Soft Pan 微调框景，或 Push In + Rack Focus）。**禁止**同相位并列 ≥3 个高级运镜名，亦禁止只列技法名而无主次。
     - **合法复合（优先择此类）**：Track+Pan（跟移中微调框）｜Push In+Rack Focus｜Dolly+Pan｜Follow+Soft Pan｜Arc Orbit+轻微 Tilt｜Handheld+短程 Track｜Pull Back+Crane Up（回建置）｜Whip Pan 单独作切换桥（前后相位各有落幅）。
     - **非法/高冲突组合（禁，除非上游明确奇观并写依据）**：同相位 **Crash Zoom ∩ Dolly Zoom**｜**Push In ∩ Pull Back**（对冲）｜**Whip Pan ∩ Slow Push**（节奏互斥）｜**Bullet Time ∩ 常速 Handheld 缠斗**（须 Speed Ramp 分相，不得同相位叠写）｜**Drone/Bird's-Eye ∩ 口型可读 CU**（鸟瞰禁口型主拍）｜**Static Hold ∩ 高速追逐主相位**｜一 P 段内 **Orbit+Crane+Whip+Crash** 堆砌。
     - **节奏桥接（强制）**：常速↔升格、舒缓↔剧烈之间须用 **Speed Ramp / 短停顿落幅 / Soft 过渡运镜** 分相，**禁止**无桥接硬跳档。
     - **轴线与空间**：复合运镜不得无过轴声明越轴；环境切换复合须服从 §5.5 G（有过程、禁硬切）。
     - **`Shot Logic` 必填** `运镜递进与组合:`（递进链=…｜主导运镜=…｜辅助=无|…｜合法复合依据=…｜跨档桥接=无|…）；无复合写「单运镜主导」。
     - **反例**：❌「Handheld+Whip Pan+Crash Zoom+Orbit 同时」｜❌ 对白镜 Push In 同时 Pull Back｜❌ 升格与常速快攻写在同一 P 段无 Speed Ramp｜❌ 本镜无特写收紧却机械 Pull Back｜❌ 下镜出场人数≤本镜却强行 Pull Back｜❌ 仅「恢复原全景」人数不增却回全景。
     - **正例**：✅ `运镜递进与组合: 递进链=②Soft Push→③Track→④Handheld→⑤Bullet Time短插→②Pull Back｜主导=P2 Track / P3 Handheld｜辅助=P2 Soft Pan｜跨档桥接=P3→P4 Speed Ramp｜Pull Back前提=满足`。
   - **高速追逐/穿梭**：追逐·穿梭主相位须跟拍，禁Static+Wide；**继承 Stage 1 §31**——路径节点连续呈现、链累计时长覆盖上游 ≥20s 保底；Video 对应 P 段须**连续动作过程**并**明示占用秒数**，计入本镜 Duration（§5.5 D）。
   - **打斗/术法近身**：须打斗运镜+轴线同步+**快慢结合+轨迹绑定**(§5.4.1)，禁Static+Wide、禁全程常速或全程升格、禁机位不跟攻防轨迹；**升格整场占比≈30%**、**须含快连击 P 段**；`正式决战=是` 时须 §5.5 A/B/C + 动作联想。详见 §5.5「武打/术法」。
   - **轻功/御剑/空域**：须 §5.5「轻功/飞翔」+ `AI高成本奇观:`；正式决战≥3 Beat。
   - **宏观群体**：须 §5.5「宏观」+ `宏观群体规模/三要素`。

   - **对白运镜与说话人景别（强制）**：口型可读对白须 MS/MCU/CU/OTS 落幅 + 显式运镜（§上文对话景别/画幅比专规）；竖屏 9:16 逐说话人切近景；16:9 灵活但口型仍可读。近景可浅景深虚化 BG（保留 ENV 气质线索）。多人按说话人分 P 段；细节见 §六.1。
   - **对白运镜例外（强制判定）**：
     - **无画内说话人**（NARRATOR、真画外 V.O./旁白、隔门/对讲/声源不可见）：**画内全员 明确 闭嘴**（§六.4）；拍听者/环境/声源方向，禁对不存在主体 Push In；禁任何画内角色张嘴对口型。
     - **自白/内心**：给予自白角色中景或特写，明确闭嘴（闭口/内心状），不按 lip-sync。
     - **Walk-and-Talk / 对白+位移**：Tracking / Follow / Lead，中景~中全景；禁硬推特写。
     - **背对/遮脸/大侧脸**：OTS / Reframe / 绕位至可读角度。
     - **Screen View / 画中画**：屏幕内说话人单独中景/特写主拍（§七.5）。
     - **句间 Insert**：可插，不得替代该句说话人主拍。
     - **抢话/单镜多句**：Whip Pan、反打或**同镜拆 P 段**；每句仍须主拍。
     - **3 人+**：Index 内具名角色单人/OTS 主拍，禁群体广角承载口型对白。
     - **特效/宏观场面**：Beat 含特效相位或全体宏观场面（大军、灾难、仪式、环境级事件等）须 **Extreme Wide / Wide / Full** 体现规模；对白以特效/宏观动势为主拍，说话人可为远景/全景群像或画外，口型非必读；可 intercut 说话人 MCU 但不得压过宏观/特效可读性。`Shot Logic (CN)` 标注例外依据。
     - **宏观群体**（Stage 1 §28，`宏观群体=是`）：`宏观群体规模/三要素` + §5.5 E + EWS/Drone 满幅动势；稀疏 BG 小簇见 §七.7-b，≠ 宏观主节拍。
   - **对白收束与景别落幅（强制）**：**对白结束判定** = 本组全部 `(Pn)` 语言读完且微表演落点完成；组内须逐 `(Pn)` 落点后再切下一 P 段或切换景别。对白全部读完后，本镜末按 §三.1 **Pull Back 双前提**落幅——满足则回全景全员同框，不满足则**保持**本镜末景别（可止于 CU/MCU/OTS），下镜换环境走例外；`收束落幅判定` 只写本镜末 P 段落幅，**禁止**据此拆镜，**禁止**无双前提却机械 Pull Back。
   - **主要动作角色运镜与景别（强制，与对白运镜同级）**：凡本镜 P 段内**正在执行本 Beat 核心动作/主节拍动作**（§五.0）的角色——含发力/接触/受力、道具拾取交递穿戴放下、位移落位、开合动作、打斗/术法/投射攻击、环境结构交互等——须与对白说话人**同等强制**分配镜头，三项俱全、缺一不可：
     1. **显式分配景别**：依动作幅度与关键部位可读性择 Medium Shot / Medium Close-up / Close-up / Two Shot / OTS / Insert 等（遵守 §三.1 景别递进与越级禁令；打斗/追逐/宏观/特效相位按 §5.4.1、§5.5、§三.1 宏观/特效例外执行），**禁止**用 Static Hold + Wide/Full/Master 承载需要看清发力部位、接触细节或命中效果的核心动作。
     2. **显式写出运镜**：从 §5.5、§5.4.1 对应技法库择 1 项以上（Push In / Track / Follow / Pan / Handheld / Arc Orbit / Crane / Whip Pan 等），**禁止**只写"运镜跟随/镜头运动"等泛化词而不落到具体技法名。
     3. **明确运镜运动过程**：须写清**起幅（机位/景别）→ 过程（运动方式+方向+轨迹节点）→ 落幅（机位/景别）**三段，**禁止**只写落幅终态而略过运镜过程，亦禁止动作已发生但机位与动作/轨迹脱节（同 §5.4.1 轨迹绑定）。
     一 P 段内**同时**存在主要动作角色与说话角色时，二者须共享同一焦点主拍（§八.2 按角色组织）或按时序拆分为相邻 P 段分别落实，**不得**二者皆无明确景别/运镜；多角色同时动作（群体混战、多人协作等）按主拍/辅助分层，主动作者优先获得对应景别与运镜，辅助者可同框但不得反客为主。`Shot Logic (CN)` 须写 `动作主体运镜与景别:`（见 §十一模板）。
   - **道具特别描述特写运镜（强制）**：上游对 `PROP:` 的特别描述须在同镜 **Insert P 段**（Push In / Rack Focus / Macro CU 等）可读呈现；拆镜前扫描 Beat，未映射=失败须补 P 段。
   - **发光电子设备亮屏内容（强制，= Stage 1 正方向物件·亮屏内容）**：凡手机、平板、笔记本电脑、智能手表、车载/对讲屏、监视器、电视、全息/HUD 等 `PROP:` 在上游 Beat 写成**亮屏/来电/通知点亮/通话中**，且本镜画内屏幕面朝镜头或 POV/Screen View **可读**时，`Video Content (CN)` **必须写出屏幕上此刻可见的具体内容**——界面类型（来电/通话中/锁屏/通知/聊天/导航/监控等）+ 可读文案/号码/联系人名/图标态；**禁止**只写「屏幕亮起/蓝光映脸/看手机」而无屏面内容。屏面内容属 **Beat 态信息**（§0.05 允许），须逐字继承上游，**禁止**自造 UI/文案/联系人；上游仅「亮屏」无具体界面内容 → `Shot Logic` 标 `upstream_missing_screen_content` 回流，Video 只写「屏面亮起但界面文案不可核销/不可读」，**禁止**补最小界面。**接听/挂断/拒接后变化（强制）**：上游有接听、接通、拒接、挂断、切免提/视频等时，对应 P 段须写清**操作前界面 → 操作过程 → 操作后界面**（如来电「张三 来电」→ 点接听 → 通话中「通话中 00:03」）；**禁止**只写角色「接了/挂了」而屏面仍停在来电态或完全不交代变化。背板朝镜头/息屏/景别不可读时须明示**屏面不可读**；上游已有界面内容时，在可读 Insert/POV/Screen View P 段**转写**该内容（禁自造）。须可读的亮屏内容优先 **Insert / Macro CU / Screen View POV**。`Shot Logic (CN)` 写 `亮屏内容继承:`（PROP｜界面态｜可读性=是|否｜接听前后Δ｜特写P段=…）。
5. **转场**：上游过渡 -> 具体运镜/光影/色调演进；可用视线、动作轴线、遮挡、图形 Match、Rack Focus、色调渐变/去色/冷暖切换、Defocus、自然推拉、声桥。禁止生硬切镜。  
6. **闪回/回忆（强制继承 Stage 1 闪回三档，禁止升格）**：  
   - **完整闪回 Scene**：独立 Scene，首镜走完整开场转场链；须完整 ENV 建置与实体落位，按常规拆镜。  
   - **快速闪回（有情节）**：上游回忆对白 **>30 字** 或具名动作情节；主节拍=快速闪回桥接；须写进入锚点→回忆内容→回切锚点；质感优先 OT-TX/OT-DF/OT-CG/OT-FD/OT-SP；**可**独立 Shot 或短专拍组，Duration 通常 3–8s；须完整继承上游对白与微表演。  
   - **无情节回忆切片（转场式）**：上游仅印象/情绪/物象触发，**无对白链、无完整动作情节**；**按转场处理**，**禁止**升格为独立闪回 Scene 或扩写对白/动作链。**拆镜**：**并入相邻 Shot 转场链**（P 段内闪切或镜末桥接），**不必**单独建闪回 Shot；写法：触发→**≤2s 单幅/1–2 帧印象切片**（剪影/局部/色块/物象，**不要求**完整 FG/MG/BG 建置与口型）→ 去色/虚化/噪点/柔焦/慢速（OT-TX、Defocus、Color Grading 等）→ 回切当下微反应/声残响；**主节拍仍归当下场**；`Shot Logic (CN)` 须写 `无情节回忆切片:`（触发/切片要点/回切/转场手段/是否并入本镜）。**计时**：计入 `转场/停顿Xs`，通常 **0.5–2s**，与触发/回切同相位时并入并行核，**禁止**为无情节切片单独全额建置计时。  
   - **≤30 字且有具体情节**：不闪回，当下反应/OS，本阶段不出回忆镜。  
7. **特殊时空（蒙太奇等）**：除上条闪回三档外，蒙太奇/梦境/意识流等用声画过渡；可用 Defocus、Color Grading、亮度压低、慢速运镜、纹理/噪点衰减、声效淡入淡出。  
8. **镜头三段式（Shot Mode）**：每镜 `Video Content` 须覆盖起镜建置、运镜过程、落镜定格（机位/景别/运镜/焦点/落位），优先摄影机视角；禁主观情绪句，改写可视细节。与 §八.2 的 P1/过程/终段对应。  
9. **多人同框压降**：两人以上对话/互动 -> **同镜 P 段 + 运镜串联**（单人主拍、OTS、反应镜、Insert、短程运镜）；降动作复杂度、标明主拍/辅助。  
10. **摄影术语库**：选用库见 **§5.5 A–H**；每场择 1–3 项服务本镜者写入 Video/Logic，禁堆砌；叠用须服从 §三.4 组合合理性（1 主导≤1 辅助）。

### 四、灯光设计 (Lighting Design)

**摄影技法**：ENV/资产 CN + 上游光学 → Key/Fill/Rim、FG/MG/BG 分层、冷暖对照、运镜光向连续；**禁**借光影改站位/动作/对白。提取与防悬浮 **§0.06**；光动**只写**「动态连续光影/焦点」「光线连动弧光」，与 §七.7 **物理**微动分写、禁止混入 Pn/BG。

5. **全域光影执行规范（Mandatory · 每镜 Video Content）**
   - **§0.06 联动（Mandatory）**：动笔前提取 `光影锚定:`；Video 以 ENV CN 为主权威，CHAR/PROP 写接地影/色溢出/环境 Fill；衍生 ENV 切换重建光学链；**Video 光源/光线/色彩只写具名实体，禁位置前缀**（§0.06）；**只写画内可见发光实体；不可见光源绝对禁实体名，只写方位+可见光学效果**（§0.06）。
   - **与 §一.3A 联动**：光源动机、Practical、色温、照度**以本镜 ENV CN + Beat 明文为准**；Project Context 年代/地域仅用于核销已有光学语义是否同体系，**禁止**据此新建未出现的灯具/材质/陈设；低照度例外须有上游依据；不得与 §0.06 ENV CN 光学锚定冲突。
   - **E. 「柔和侧逆光 + 正面补光」标准（Mandatory，真人/写实优先；服从 ENV CN，禁另起棚拍光）**：
     - **侧逆光 / Rim**：窗光、天光、Practical 或顶侧光作**柔和**侧逆光，塑形人物轮廓、空间边缘、道具棱线；禁止硬 rim、刀切轮廓。
     - **Key**：侧向柔光/窗光/Practical 塑形 MG 主舞台与 `CHAR:` 可见面；半影**自然柔散、渐变绵长**。
     - **Fill（正面补光）**：白墙/地面/桌面/环境反射/柔光延续作 **大面积均匀 Fill**，**包裹面部**压平局部亮斑，保证**面部、口型、微表情**可读；反弹源**画内可见**时写「反弹自{ENV 具名光源}、经{具名反射面}」；反弹源**不可见**时只写「经{画内可见反射面}反弹的{色温}Fill」，**禁止**写出不可见发光实体名（§0.06）；**禁止**鼻梁/颧骨/额头/唇峰独立 spotlight、**禁止面部光斑不均**；**禁止为补光而补光**（禁无 ENV 锚点的棚拍柔光箱/美颜补光灯）。
     - **光影过渡（Mandatory）**：FG/MG/BG 各层投影须**软过渡、无硬阴影边界**；暗部保留肤质/材质纹理；**禁止刀切式阴阳脸、高反差硬投影、纯黑死影块、面部斑驳受光/某部位突然过亮**（恐怖/剪影/上游压暗例外）；投影方向须与 ENV Key 落位一致。
     - **整体氛围**：**柔和、自然、真实**——对标电影级自然光实拍；禁止硬闪、环形美颜顶光、广告硬光。
   - **光源角色一致性（强制）**：标注为 `Key` 的光源效果须体现"照亮/受光面提亮"；标注为 `Fill` 的光源效果须体现"托起暗部/暗部仍可读"，禁止 Fill 效果写成"加深阴影/沉入暗部/绵长深邃阴影"；非补光作用的光源改标"环境冷光/氛围光"。**Key/Fill/Rim 入射方位与受光面须与 ENV 光学几何一致**；源画内可见时可具名，源不可见时只写方位+效果（§0.06），不得为构图美观改写光向，也不得为「具名核销」泄漏不可见实体名。
   - **光线—光源位置一致性（强制）**：动笔前核对 `光影锚定:`；Video 每句光效须可回答——**源可见时**：「光从哪个具名光源来、为何照到该面」；**源不可见时**：「光从哪个**入射方位/色温**来、照到哪块画内可见受光面」（**禁止**为答「哪个具名光源」而写出机位后方/画外实体名）。**禁止**入射在一侧却写对侧主亮、可见台灯在左后却写右颊 Key、无反射依据却写正面 Fill。
   - **门外作光源须先确认门开启（强制）**：凡写「门外/门廊/走廊渗入」「门洞来光」「门外街光/走廊灯作 Key/Fill/Rim」等以**门外空间为动机光**时，须**先**核对本镜建置/ENV/Beat 中该门（或门洞）为**开启态**（半开/全开/门扇已拉开，门洞通路可读）；`Shot Logic (CN)` `光影锚定:` 须写 `门外光源门态=半开|全开｜核销依据=…`。**门紧闭/关合时禁止**把门外光写成室内主动机入射；紧闭门最多门缝微渗或门外不可见效果，不得当门洞 Key。门在本镜内由行动打开后才可启用门外光，须写开合行动与光效接通过程。**门外灯具本身不可见时**：可写「门洞渗入{色温}光」等效果，**禁止**写出门外灯具/霓虹实体名（§0.06）。
   - **禁数值化光比（强制）**：正文禁止出现测光数值光比（如 `>8:1`）；反差一律转译为渐变式半影描述，暗部须保留材质纹理可读，恐怖/惊悚/上游明确压暗题材除外（须在 Shot Logic 标依据）。
   - **核心目标**：`Video Content (CN)` 须让 AI 视频模型明确「**光从哪来（可见则具名，不可见则方位） → 作用范围照到哪里 → 产生什么可见效果 → 冷暖如何分层**」，不仅是“有电影感/自然光”，而是**可执行的光学链条**；涉及 `ENV:[...]` 的环境须**光源清晰、照度充足**（除非悬疑/恐怖/上游明确压暗）。
   - **最低输出量（「动态连续光影/焦点」+「光线连动弧光」两段合计）**：须覆盖下列 **10 项中的 8 项**——
     **(1) 光源清单与动机（画内可见 1–3，上限 3）**：只列本镜**画内可见**动机发光实体（可见台灯/吊灯/门洞渗光可读面/霓虹牌/屏幕/烛焰/窗格——**窗体仅当本镜画内可见**；§0.06）及**实体锚点**（如「黄铜台灯」「门框侧壁灯」；禁位置前缀）；不可见但影响照度的光源**不计入清单、全文不得出现其实体名**，只写可见效果（顶光提亮桌面、条纹冷光落地面、墙面反弹 Fill 等）；画内不足 3 时用反射 Fill 补足照度描述，**禁止**用机位后方窗/灯凑数；禁止只写“自然光/明亮”。
     **(2) Key 方向与照亮面**：Key 从哪一侧/哪高度来（源可见可具名，不可见写方位），主要照亮哪些 `CHAR:`/`PROP:`/`ENV:` 实体的哪一面（左颊/右颊/桌面/椅背/墙面/地面）。
     **(3) 光源作用范围（Mandatory）**：**每个画内可见动机光源须写清作用范围**——哪些具名 `CHAR:`/`PROP:`/`ENV:` 表面进入亮区/半影、光能到达的纵深边界、**未照亮暗口袋**挂靠哪件具名实体；不可见动机光只写受光面效果句；禁止只写「有窗光/有台灯」而不写照到哪里；**禁止**用「前景/中景/背景」「FG/MG/BG」区段替代实体指称（§0.06）。
     **(4) 光源可见效果（Mandatory）**：**须写光线作用产生的具体可见效果**——条纹光、桌下椭圆影、门边斜投影、湿地面/金属冷高光条、体积光束、人物轮廓分离、椅脚短影、屏幕反光等；禁止只写「有光影/电影感」而不写效果形态；**效果句不得夹带不可见发光实体名**。
     **(5) 多实体光影分层**：按**画内可见**具名实体写**受光面、半影、投影、明暗对比**——如门框框景明暗、会议桌/旧木地板受光与桌下/脚下投影、文件柜列退暗退冷与门洞渗光；**半影须自然柔散、投影边缘无硬切线**；**禁止**把机位后方窗墙写入分层具名；**禁止**用「前景/中景/背景」「FG/MG/BG」层位前缀替代实体名（§0.06）。
     **(6) Fill/Back/Rim 与暗部可读**：补光来源（白墙反弹/环境反射/第二画内可见 Practical）；轮廓/分离光如何切开人物与背景；暗部是否保留肤质/材质纹理可读；Rim 源不可见时只写轮廓效果。
     **(7) 冷暖色温**：主光/Fil/阴影区色温（5500K 日光/3200K 钨丝/6500K 阴天/混合色温分区域）；至少 1 组**冷暖对照**或明确同温层次。
     **(8) 光学响应（非外形）**：写 Key/Fill 下**受光面/半影/反射/高光形态**——如金属棱线冷高光条、玻璃反射、织物边缘 ENV 色溢出、面部**大面积均匀 Fill** 与**无局部亮斑**（§四.5-E）；**须与 §0.06 一致**——主体须带 ENV 环境色溢出，接触面须写接地/接触阴影。**禁止**写脸型/五官/妆发/肤质/服装版型等设定图级描写；**禁止**写「左颊与鼻梁受光/鼻梁高光形状/颧骨亮块」等鼓励局部过亮的句式。
     **(9) 运镜中的光影连续**：Push In/OTS 切换/环境切换时，**光源方向、作用范围、投影、焦点与色温须连续或写清变化过程**；禁运镜后光影方向无理由跳变；切 ENV 时按新 ENV CN 重建光学链，CHAR/PROP 融入同步更新；切角后原可见发光实体若出画，**立即去名改效果**。
     **(10) 资产场景融入（Mandatory，§0.06）**：画内每个主要 `CHAR:`/`PROP:` 须在同段或相邻句写清**至少一项**——环境色溢出（面颊/衣料/棱线受 ENV 冷暖染色）｜接地/接触阴影（鞋跟/椅脚/桌沿/手持物与接触面短影，方向与 ENV Key 入射同向）｜环境反射 Fill（地面/桌面/白墙反弹至暗部）；**禁止**主体光向/色温与 ENV 脱节的无根悬浮感。
   - **光源充足硬约束（环境相关）**：`ENV:[...]` 为室内/办公室/厅堂/豪宅/商业/户外日景等时，默认须**照度充足、主舞台与动线可读**——须写 **画内可见动机光源 1–3（上限 3）** + **≥1 环境反射/补光**；禁止整镜只有 vague atmosphere、单点昏暗光或无动机黑场（悬疑/惊悚/恐怖低照度例外须 `Shot Logic` 注明依据）。**夜景 ENV（剧情允许时）**：强化自然主光效果 / 暖调覆盖 / 可见 Practical（**画内可见动机光仍上限 3**，不足用反射与渗光效果补覆盖），写清各**可见**光源作用范围与覆盖效果；**禁止**为凑数写入机位后方窗/灯实体名；禁止整室仅一盏灯或主舞台无动机黑区。
   - **真人/写实类额外强制**：优先 **§四.5-E 柔和侧逆光 + 正面 Fill**；对话镜须保证**面部、口型、微表情受光可读**（§六.3）；禁止环形美颜顶光、无方向平光、硬闪直打、**硬阴影边界/刀切投影**；动态真实感（自然眨眼/眼球微动/运动中纹理保真）另见 **§六.5**。
   - **即贴写法结构（可改写）**：`光源清单：{1–3 个画内可见动机光源及实体锚点，上限3，禁位置前缀，禁不可见实体}。{可见光源A}作用范围覆盖{具名 CHAR/PROP/ENV 表面}，在{具名实体/受光面}形成{可见效果}；{可见光源B若有}…。Key 从{方位}以{色温}照{受光面}（源可见可具名，不可见禁名）；Fill 来自{画内可见反射面}托起{暗部}；{具名远层可见实体}退冷/门洞渗光/霓虹点缀（仅可见者）；冷暖对照为{具体描述}；运镜中{焦点/光向/作用范围}随{Push/OTS/切 ENV}如何变化。`
   - **Shot Logic 配套**：每镜 `Shot Logic (CN)` 须写 `光影锚定:`（§0.06：本镜 **ENV** CN prompt 光学要点摘要 + **可见/不可见光源分流** + 本镜适配/连续方式 + 防悬浮落点）+ `光影继承:`（来源 Beat/上镜光向、本镜 Key/Fil/冷暖 rationale、**各光源作用范围摘要**、跨镜连续风险）+ `光源充足性:`（画内可见动机光个数≤3 是否满足照度/低照度例外依据｜不可见源仅 Logic 具名）。
   - **输出前光影自检**：单独阅读「动态连续光影/焦点」段，是否仍能回答——光从哪来（可见具名 / 不可见仅方位）？**是否与 ENV 光学几何一致**？**Fill 是否有反射面依据（非为补光而补光）**？**若用门外作光源，门是否已确认为开启态**（§四.5）？**每个可见光源作用范围照到哪些具名实体、哪里未照到**？产生什么投影/反射/条纹/体积光等**可见效果**？CHAR/PROP 是否有**接地影/环境色溢出/环境 Fill**、无悬浮抠图感？是否**无前景/中景/背景等位置前缀**（§0.06）？是否**全文零出现不可见发光实体名称**（含检索本镜 `(N+180)%360` 扇区窗/灯名）？可见动机光是否 **≤3**？冷暖如何分层？若不能，须重写。（对话镜面部受光细则见 §六.3）

#### 5.4.1 打斗·特效·运动轨迹快慢镜协调（强制）

**定位**：打斗、特效攻击、投射弹道、轻功/空战/追逐等**高动态相位**，须同时协调 **实体运动轨迹**、**摄影机运镜速率**、**画面播放速率（常速/升格/Speed Ramp）** 三者；**快镜（常速快连击）建立动势与空间读解，占打斗主体约 70%**；**慢镜定格关键节点**（命中/对撞/受力/轨迹转折），**整场升格占比控制在 ≈30%**，二者须成对出现并写清切换点。

**整场升格占比控制（Mandatory，打斗专规）**
- **统计范围**：同一打斗链内全部 P 段——单镜内完整打斗，或 §二.1.5 合镜后连续承担打斗的 Beat 组；**分子**=升格慢相位秒数（Bullet Time/Hyper Slow-Mo/Time Slice/Freeze 等，**不含** Speed Ramp 入出）；**分母**=该打斗链 `Duration` 或各 P 段串行合计。
- **目标占比**：**≈30%**（建议 **25%–35%**）；`快慢节奏:` 末尾必填 **`升格占比≈Xs/Ys=Z%`**。
- **硬门槛**：**Z > 40%** → 升格滥用，须删减升格 P 或改常速快连；**Z < 15% 且无 ≥2s 快连击 P 段** → 节奏失败，须补快相位。
- **快连击配额**：常速快相位（含快攻连击/Whip Pan 多击衔接）合计须 **≥50%–70%** 打斗总时长；升格**只**插在关键节点，**禁止**连续多段升格堆叠拖镜。

**三速同步原则（强制）**
| 维度 | 常速快相位 | 升格慢相位 | 协调要求 |
| :--- | :--- | :--- | :--- |
| **实体运动** | 快攻/连击/常速位移/弹道飞行 | 命中瞬间/格挡受力/腾空顶点/对撞接触 | 升格相位须锁定**已写明的 FG/MG/BG+左中右 轨迹节点**，禁慢镜里实体仍在高速位移 |
| **摄影机运镜** | Handheld/Whip Pan/Tracking/Follow/Orbit 常速跟轨迹 | Bullet Time/Orbit 定格/Static Hold CU/Time Slice 绕节点 | **快相位机位须跟实体或弹道同向同速**；慢相位机位须**对准关键节点**（命中点/接触面/轨迹弧顶） |
| **画面播放** | 常速 100% | Slow Mo / Hyper Slow-Mo / Bullet Time / Time Slice | 每次常速↔升格须写 **Speed Ramp 入/出**（各 0.3–0.5s），禁硬切无过渡 |

**快镜规则（常速快相位，强制）**
- **适用相位**：起势后发力、**快攻连击/连招/组合技前段**、闪避位移、弹道/能量**出手→扩散→逼近**、追逐跟拍、群殴 Master 动势、域场规模建立。
- **运镜选用**：Handheld Combat｜Whip Pan / Swish Pan｜Tracking / Follow / Lead 常速跟拍｜Lateral / Arc at Speed｜Crash Zoom 逼近（仍属常速）｜Drone/Crane 常速读规模。
- **快连击设计（Mandatory）**：每段打斗链须 **≥1 个快连击 P 段**——**可同 Beat 同 P** 写 **≥2 击/≥2 招** 常速衔接；**每一击/每一防须写具体招式或动作名称**（继承 Beat，禁泛化）；**双人对战须攻防匹配**——攻方招名↔守方格挡/闪避/拆招/反击，或命中/破防/擦过/打空（§4.1）；单段快连击 **≥2s**；**禁止**把多击全拆成升格慢镜、**禁止**单方无反应堆招。
- **轨迹绑定（强制）**：`Video Content (CN)` 须写清**机位与实体/弹道/特效同相位运动**——如「镜头 Handheld 贴战圈随 CHAR 右移」「Follow 沿画面中线跟子弹自镜头前方右侧射向画面左侧」；禁 Static Hold + Wide 承载高速攻防、禁弹道飞出而镜头不动。
- **时长参考**：单段快相位 2–4s；连击须用 Whip Pan / Swish Pan **同镜 P 段**衔接下一段快相位，快相位总时长须 **≥ 升格总时长 × 2**（即升格占比天然 ≤33%）。

**慢镜规则（升格慢相位，强制）**
- **适用相位（每场打斗链择 1–2 处升格，禁整镜/整段慢镜）**：**命中/对撞/爆炸/格挡受力/偏转碎裂**｜弹道/法术**轨迹可读节点**（Time Slice 读 FG→MG→BG 路径）｜腾空/落地**弧顶/触地**｜关键一击**接触瞬间**｜域场**波前/法阵展开锋面**｜组合技**终结技/破防**（**仅 1 处**，前段须已用常速快连击建立）。
- **运镜选用**：Bullet Time / Hyper Slow-Mo｜Time Slice 沿轨迹切片｜Orbit 短绕命中点｜Static Hold CU/ECU 读受力反馈｜Freeze Frame 可选（≤0.5s）。
- **轨迹绑定（强制）**：升格段须**钉住**上游 Beat 已写轨迹节点——如「升格 Bullet Time 绕命中点（对方左肩）Orbit 半圈，读肩线后挫与半旋」；投射须读**命中部位+效果**，禁升格只拍空镜慢飞。
- **时长参考**：单段升格 1–3s 为主（Bullet Time 2–3s，Hyper Slow-Mo 1–2s，Time Slice 1–2s）；**整场升格累计 ≤ 打斗总时长 × 35%**；单段升格 >4s 须拆出或改常速快连。

**Speed Ramp 与切换规则（强制）**
- **入慢**：快相位末帧 → Speed Ramp 入（0.3–0.5s）→ 升格慢相位；触发点=**接触前最后一帧**或**轨迹节点进入可读区**。
- **出常**：升格读毕命中/效果 → Speed Ramp 出（0.3–0.5s）→ 常速读受力反馈/余波/群体反应。
- **跨 P 段**：同镜内 `P2 常速 → P3 升格 → P4 出常+反馈` 为默认链；**已按 §二.1.5 超时拆分**时，后镜 P1 用 Match on Action / Whip Pan 衔接。
- **失败判定**：整镜仅常速｜整镜仅升格｜**升格占比 >40%**｜**无 ≥2s 快连击 P 段**｜有升格无 Speed Ramp 出入｜快相位机位不跟轨迹｜慢相位未钉轨迹节点 → 须**补写 P 段**。

**分类型协调速查（强制参考）**

| 类型 | 快镜（常速） | 慢镜（升格） | 切换 |
| :--- | :--- | :--- | :--- |
| **近身打斗** | Handheld/Whip Pan 跟攻防 | Bullet Time/Hyper Slow-Mo 读命中/格挡 | 连击末帧入慢，受力后出常 |
| **投射/弹道** | Follow/Tracking 跟 FG→MG→BG 弹道 | Time Slice 读节点；Bullet Time 读命中部位 | 常速跟弹道→入慢读命中→出常反馈 |
| **法术/能量** | Orbit/Push In 常速跟出手与扩散 | Slow Mo 读对撞/护盾碎裂/波前 | 逼近最后一帧入慢，余波出常 |
| **闪避/腾空** | Tracking 常速跟位移 | Speed Ramp 弧顶短慢读姿态 | 入慢+出常，落地回常速跟拍 |
| **组合技/连击** | **多段快连击**+Whip Pan **P 段**切换（常速 **≥50%**） | **1 处**升格短插读终结技/破防（**≈30% 整场**） | 快连击末帧入慢，受力后出常 |
| **域场/宏观特效** | Drone/Crane 常速读规模 | Slow Mo 读波前/法阵锋面 | 波前入慢，群体反应出常 |
| **追逐/载具** | Follow/Lead/Car Mount 常速 | 撞击/跃障/碰撞 Bullet Time | 撞击前常速，接触瞬间短插 |

**P 段写法模板（`Video Content (CN)` 强制）**
- **快相位 P 段**：写明**机位运动名+跟拍对象+轨迹方向**（自然语言表达层位与方向）+ **常速** + **逐招具名快链** + **双方攻防匹配**；例：「P2 镜头 Whip Pan 随 CHAR:[@甲] **右直拳→左勾→侧踢** 自画面左侧横扫至中线，CHAR:[@乙] **架肘格挡→侧身闪避→反刺** 对应拆解，Handheld 贴战圈常速跟拍」。
- **慢相位 P 段**：写明**升格技法+锁定节点+可读信息**；例：「P3 Speed Ramp 入慢后 Bullet Time，镜头 Orbit 绕画面中线的命中点，读**侧踢**接触 CHAR:[@乙] 左肩与受力后挫」。
- **变速 P 段**：写明**Speed Ramp 方向+时长感+落幅**；例：「P4 Speed Ramp 出常，镜头 Pull Back 至 MCU 读乙后退半步与甲收势」。
- **禁写**：「快速打斗」「慢动作效果」「镜头跟随」等泛化句；须落到运镜名、速率、轨迹节点。

**Shot Logic 必填（打斗/特效/投射/追逐镜）**
- `快慢节奏:` 各 P 段=常速|升格|变速 + 运镜名 + 特效相/攻防相 + **轨迹节点** + 预估秒数 + **`升格占比≈Xs/Ys=Z%`**（目标 Z≈30%）。
- `快连击链:`（打斗/快链 P 段**必填**）= **逐招具名序列** + **双方攻防对应**（攻方招名↔守方防招/拆招/反击或命中效果）+ 轨迹节点摘要。
- `升格技法:` 选用项 + 触发相位（命中/对撞/轨迹节点/弧顶等）+ **本打斗链第几处升格**（建议 1–2 处）。
- 打斗镜另填 `打斗运镜技法:`；特效/投射镜另填 `特效攻击运镜:`（§5.5 A/A-2）。

**反例（强制禁止）**
- ❌ 全程 Handheld 常速打完整段格斗，无升格读命中。
- ❌ 整镜 Bullet Time 慢镜拖过 5s，无快相位建立动势。
- ❌ **升格占比 >40%**——多段连续 Bullet Time 拖镜，快连击不足。
- ❌ **无快连击设计**——每击皆升格，或只有单击慢镜无 Whip Pan/Handheld 连招段。
- ❌ **快链缺招名/缺攻防匹配**——只写「快速连击」、单方连招而对手无格挡/闪避/反击。
- ❌ 子弹/法术飞出，镜头 Static Wide 不跟弹道。
- ❌ 升格段实体仍在高速位移，未钉住命中/接触节点。
- ❌ 有 Slow Mo 无 Speed Ramp 出入，硬切速率。
- ✅ P2 常速 Handheld **快连击** 3.5s（**甲：右直拳→左勾→侧踢；乙：架肘格挡→侧身闪避→反刺**，Whip Pan 衔接）→ P3 Speed Ramp 入慢 + Bullet Time 读**侧踢**命中 1.5s（**升格占比≈1.5/7.5=20%**）→ P4 Speed Ramp 出常 + 受力反馈 2.5s。

### 六、对话的镜头实现（内容=Stage 1；本层只写景别/运镜/口型可读）

**语气层 / 对谁说 / 称呼锁定 / 情绪标点 / 小语种·方言标签 / 音效尖括号 → 唯一权威 Stage 1**（本层**不展开字段定义**）。本分镜只做：逐字写入 Video + 为说话人分配景别/运镜（§三.1）+ 音效落位可听。

#### 六.0 语气层写入（强制，零删改）
- Beat 每条对白/OS/V.O./自白 → Video 对应 `(Pn)` **完整携带**上游语气层括号（含 `对{听众/方向}` + 八字段）；缺任一项=继承失败。
- 禁改对象/方向/重读词/标点；`rhythm`/`stress`/`pause` 须落到可拍微表演相位（服务口型与 §二.4 语言耗时）。
- 画内可对口型说话人：`(Pn)` **须 ≥1 项面部微表情**（与 tone 咬合）；听者写上游已有微表演，**禁补创**。
- Logic：`语气层继承:`（N 条｜对谁列表｜特殊 pause/rhythm｜无则写无）。

#### 六.0A 小语种 / 方言台词承接（强制，零译抹）
- **识别**：上游入戏对白含「用{语种|方言}说道」或等价明文（如 `用日语说道` / `用粤语说道` / `用四川话说道`）时，本镜 **必须**在对应 `(Pn)` **原样保留**该语种/方言标签 + **原文台词**（Stage 1 花括号 `{…}` 内全文；写入 Video 时可用 `"…"` 外壳，但**正文逐字不变**）。
- **禁止**：译成项目主语言/普通话/英文后冒充原台词；删掉语种/方言标签只留译文；用同义改写、繁简转换、罗马化转写替代原文；把方言「规范化」成普通话。
- **标准普通话 / 英文**：上游未标语种/方言时不必加标签；仍须逐字继承台词正文。
- **Logic**：有则写 `语种方言继承:`（语种|方言列表 + 对应说话人 + 原文可检索=是）；无则写 `语种方言继承: 无`。
- **与项目 Language 关系**：`# Project Context` 的 `Language` 只约束主体语种与全局风格注入；**不得**据此覆盖本条已标注的小语种/方言原文。

#### 六.1 对白写入格式（Video）
`(Pn) {说话人面部微表情+状态} — Dialogue (CHAR:[@名]) (对{听众/方向}, voice_type: …, voice_identity: …, tone: …, speed: …, volume: …, rhythm: …, stress: …, pause: …): [用{语种|方言}说道]"{逐字原文}" — {听者微表演}`

- 有小语种/方言时 **必须**保留 `用{语种|方言}说道` 前缀（方括号仅示意可选，成稿写明文不写方括号）。
- 示例（普通话）：`(P2) CHAR:[@林医生] 唇角微绷、吸气半拍后开口 — Dialogue (CHAR:[@林医生]) (对陈医生, voice_type: 对白, voice_identity: 林医生·领导型主治医师音, tone: 压抑, speed: 中速, volume: 正常, rhythm: 先缓后催, stress: 重读「确定、签字」, pause: 报告—略停—你确定): "报告——你确定要签字？" — CHAR:[@陈医生] 眉弓微抬、下颌收紧`
- 示例（方言/小语种）：`(P2) CHAR:[@阿强] 侧头、嘴角一扯后开口 — Dialogue (CHAR:[@阿强]) (对陈医生, voice_type: 对白, voice_identity: 阿强·市井青年音, tone: 随意, speed: 中速, volume: 正常, rhythm: 短促, stress: 重读「唔该」, pause: 无): 用粤语说道"唔该" — CHAR:[@陈医生] 眉心微蹙`；`(P3) …: 用日语说道"こんにちは" — …`

#### 六.2 音效承接（强制，零删略）
- **识别**：上游 Beat 入戏段尖括号音效 `<{音效描述}>`（如 `<远处传来狗叫声>` / `<门轴吱呀一声>`）为本镜**可听剧情音效权威**；经 Stage 2-2 落表后格式不变。
- **写入**：在「运镜与动作流」对应时序 P 段（或声先入/声桥所在段）**原样写入**尖括号全文，或紧邻写等义可听描述且 **尖括号原文仍须可检索**；须保留声源方位/远近/介质等上游已写信息。
- **禁止**：因品质收束句含「无背景音乐」而删除剧情音效（该句禁的是 **BGM/配乐**，**不**禁画内/画外剧情音效）；禁升级为混响/频段/分贝等 Stage 3 声场细参；禁无上游依据堆砌装饰性音效；禁把音效改写成无来源的抽象「气氛声」。
- **与转场**：上游/Logic 已用声桥、J-Cut、L-Cut、OT-AS、OT-SB 等时，Video 须在对应相位写出可听内容（继承 `<…>`），不得只写转场标签名而无声音落点。
- **Logic**：有则写 `音效继承:`（N 条｜尖括号原文列表｜落点 P 段）；无则写 `音效继承: 无`。

#### 六.3 对话镜布光运用
§四.5-E + §0.06：面部/口型/微表情在 ENV 动机光下可读；禁无方向平光/硬阴影切脸。

#### 六.4 OS/V.O./旁白运用
真画外/旁白相位：**画内全员明确闭嘴**（含群演）；声源标 `NARRATOR` 或对应 `CHAR:[@…]`（画外）；拍听者/环境/声源方向，禁对不存在主体 Push In 对口型。**语气层**：OS/V.O./旁白/自白/独白仍须 **§六.0 全字段 inline 继承**（含 `对{听众/方向}` + `voice_identity`）；画内闭嘴≠省略语气层。自白/内心：须保留方向锚（对镜头｜望天｜望远｜对空位等）；画内发言人可写口型时仍带完整语气层；OS/V.O. 不按 lip-sync 但 `(Pn)` 段须保留 Beat 原文语气层块供 TTS/后期。**小语种/方言 OS/V.O.** 同 §六.0A，标签与原文不得译抹。

#### 六.5 自然生理微动作与运动纹理保真（摄影真实感，禁表演二创）
补充 §四.5-E / §六.3：**只写**动态真实感提示（非外形；§0.05）——自然眨眼/眼球微动/发丝随动清晰；禁整镜瞪眼定格、禁「柔化/磨皮」、禁借此写骨相/肤质。有对白或 >3s 静态特写时 Logic 可标 `自然眨眼:已写`。**禁止**据此补创 Beat 未写的情绪微表演。

#### 7.6 360 度拓扑 → 镜头语言转译（本分镜专责）

**读上游**（Stage 1 §11 `{主环境}`/`{衍生环境}`）：0 度轴、顺时针递增、可见/不可见 Delta、OTS 反打角 `(N_对手+180)%360`。**只在 `Shot Logic` 推演**。

**`Shot Logic (CN)` 必填（衍生 ENV 或视角切换镜）**
- `360度转角继承:` 主环境 0 度观察基点=…；本镜 ENV=…；相对主 0 度**顺时针转角 N**=…；**OTS/反打时另写** `对手可读角 N_对手=…` → `目标ENV角=(N_对手+180)%360=…`（禁盲套 180）；转角对照=衍生正面↔主环境 N 度；**新可见**=…；**退出可见**=…；方向性物体重判=…（椅背/门扇/桌头等逐项）。
- 与 `观察视角继承:`、`环境切换运镜:` 配套；主环境（0 度）镜可简写 `360度转角继承: 主环境基准，N=0，无转角`。

**`Video Content (CN)` 转译规则（强制，禁遗留推导信息）**
- 上游拓扑/转角/可见性 Delta **须在写作前消化**，正文**只输出镜头语言**，不得把 Stage 1/2 的推导字段、度数坐标、拓扑公式粘贴进视频提示词。
- **必写要素（衍生 ENV 或正反/OTS/POV 切换时，POV 镜头以主观角色视角建置、不包含主观角色自身）**：
  1. **机位落点**：站在/位于哪一结构侧（如「会议桌长边侧面、胸口高度 Eye-level」——**仅当该侧发光墙体本镜画内可见时**才可点名窗/灯实体）。
  2. **观察朝向 / 回转**：相对主视角 Master 轴的**顺时针回转 N 度**，或等效运镜名（Reverse Shot、Left-Shoulder OTS、POV Handoff、Pan to New Axis、Motivated Reframe 等）；可写「沿桌轴线/门槛轴线顺时针回转 180 度」。
  3. **背景更替**：用自然语言写 BG **看见什么**；机位后方半空间只写「不可见」一句，**禁止**点名已退出可见的发光/墙体实体（❌「主视角时的百叶窗墙位于机位后方」——百叶窗名泄漏；✅「背景为半开木门与门外冷蓝走廊；机位后方半空间不可见」）。
  4. **方向性物体可见面**：椅背/椅面、门扇开向、桌头/桌尾、床头/床尾、主客位等按当前机位写**可见面与画面左右**，禁沿用主视角朝向。
- **`ENV:[...]` 标签**：Index 原名（含 `{N}度` 前缀）**保留**作环境标识；正文空间描述须用镜头语言，**不得**把 ENV 名中的角度数字当画面说明复读。

**正反/OTS 专规**
- **OTS 四要素（强制，`Shot Logic` + `Video Content` 均须可检索；缺任一=不合格）**：凡标 OTS / 过肩 / Left-Shoulder / Right-Shoulder，须同时写清——
  1. **过谁的肩（肩主）**：前景虚焦肩框归属人，须写 `CHAR:[@…]`；禁止只写「过肩」不写肩主。
  2. **肩主可见面**：机位相对肩主从哪一面取过肩框——**左侧面 / 右侧面 / 正面 / 背面**（可写四分之三背、后脑勺侧等，但须落四选一主类）；经典 OTS 多为**背面**或**侧面**见肩线/后脑；禁止只写肩侧不问可见面。
  3. **左肩或右肩**：Left-Shoulder（过肩主左肩）| Right-Shoulder（过肩主右肩）；须与画面左右、轴线留白一致（左肩常占画左/右缘须自洽）。
  4. **过肩后看谁（主拍）**：主焦点对象 `CHAR:[@…]` + 其相对镜头的**正/侧/背面及口型/表情可读性**。
  - **推荐句式**：`过 CHAR:[@甲] {可见面}{左|右}肩 → 看 CHAR:[@乙] {正/侧/背面}{景别}`；例：`过 Lin 背面右肩 → 看 Chen 正面中近景`；`过 Chen 左侧面左肩 → 看 Lin 四分之三面 MCU`。
  - **Shot Logic 摘要字段**：`OTS四要素: 肩主=…｜可见面=左侧面|右侧面|正面|背面｜肩侧=左肩|右肩｜主拍=…+可读面=…`
  - **反例**：❌ `Left-Shoulder OTS，Chen 中近景`（缺肩主与可见面）｜❌ `过肩看 Lin`（缺左/右肩与肩主可见面）｜❌ `OTS 反打`（四要素全缺）。
- **OTS/反打 ENV 角判定（强制，禁止盲套主环境+180°）**：切 OTS/反打衍生 ENV 前，须据上游 Beat 判定**被拍对象/对手**在主环境 360 度拓扑中的可读观察角 **N_对手**（落位+面向+轴线）；本镜 ENV 角 = **`(N_对手 + 180) % 360`**，**不得**不经判定一律用主环境 0 度 + 180 度。例：对手可读角 90° → ENV 270°；对手可读角 0° → ENV 180°。上一镜已在衍生角 M 时，仍须以对手可读角推导，而非「M+180」或盲套 180 度 ENV。
- 正反/OTS 须写同一空间锚点（桌中线/门框/门槛）+ **连续运镜过程**切换至对侧（**禁 Static 硬切**）；Shot Logic 写 **N_对手**、**`(N_对手+180)%360` 目标 ENV 角**、**OTS 四要素**及可见 Delta（禁只写「180 度互补」而不列对手角）；Video Content 写 **Arc Orbit / Pan / Track + Reverse/OTS** + **四要素落幅句** + 相对**上一观察角/主 Master 轴**的实际顺时针回转**过程**（回转度数须与判定的目标 ENV 角一致，禁一律写 180 度）+ BG **渐进**更替 + 椅背/门扇等重判 + **三分构图自然留白**（§七条目7 构图留白）。

**转译对照（Shot Logic → Video Content）**（拓扑前提：主环境 `0°=百叶窗墙段｜90°=白板墙段｜180°=半开木门｜270°=文件柜列`；`0度` 后景=百叶窗、前景近木门侧、横轴左=文件柜、右=白板——**须与主环境一致**）

| `view_angle_from_main:180` | 沿桌轴线/空间锚点**顺时针回转 180 度**，Reverse Shot / 过 Lin 背面右肩 Left-Shoulder OTS 看 Chen 正面 |

| `empty_view_delta: 0°后景百叶窗→机位后方不可见；后景换为180°木门` | 背景为半开实木门与门外通道；机位后方半空间不可见（**禁写**不可见发光/墙体实体名）；画面一侧可见白板、对侧可见文件柜边缘 |

**Video Content 禁写示例**

#### 7.7 环境背景微动态（强制）

**定位**：AI 视频须有**活的环境**；除角色/群演/主节拍动作外，每镜 `Video Content (CN)` 须在 BG 或可见 ENV 结构中写入 **≥1 项**轻量、**全镜持续**的环境**实体物理微动**，**禁止**背景完全静止如静态生图空镜。**近景对话 P 段**（§三.1「近景对话背景虚化」）可写**虚化背景中已有实体的物理微动**（如失焦树冠轻晃、虚化车流缓移、窗帘轮廓轻摆）替代清晰 BG 全量描述，仍须 ≥1 项可读环境动势线索——**禁**用光斑/bokeh/光晕/条纹光等光学描写顶替（光学一律进「动态连续光影/焦点」「光线连动弧光」）。

**实体白名单（最高硬约束 · 如无必要勿增实体）**
- 环境微动、背景信息、以及「运镜与动作流」内 **P1/P2…Pn/`(Pn)`** 凡点名的环境/道具/陈设实体，**必须**已在上游输入剧本内容中出现——白名单来源为：**本 Scene 剧本原文** ∪ **Stage 1/Beat 已写明文** ∪ **Subject Index 已登记行** ∪ **本镜 `ENV:[...]` 固定实体清单/CN prompt 已列结构**。
- **禁止**为凑微动、填背景或丰富 Pn 描写而新增剧本未提及的具名实体（❌ 剧本未写「挂钟」却写「挂钟秒针」；❌ 未写「霓虹招牌」却写「霓虹频闪」；❌ 未写「蒸汽」却写「咖啡热气升腾」）。
- **无可用微动锚点时**：只对**已出现**的结构写极轻物理动势（如已有窗帘→轻摆；已有窗外树→树冠轻晃；已有车流/街景→远距缓移）；若本场剧本/ENV **确实无可动元素**，写 **1 句**已有实体的极轻态（如「门扇停在半开位微不可察」）并标依赖已有门扇，**仍禁止**凭空造实体。
- 匿名 BG 人群簇（§七.7-b）仅当上游已暗示人群/职场背景等时可写自然语言簇，**禁止**具名新角色。

**光影分工（最高硬约束 · 微动/BG/Pn 禁光）**
- **§七.7 环境微动、背景信息段、P1 建置、P2…Pn/`(Pn)` 对白动作段**：**只写物理空间与实体动势**（晃/摆/移/升腾/雨丝/车流/人群等），**禁止**描写光线、光影、色温、投影、半影、高光、条纹光、光斑、bokeh、光晕、Practical 闪烁/脉动、霓虹频闪、屏光呼吸、烛焰光跳、体积光、明暗分区等光学内容。
- **光线/光影/光源微动一律统一写入**「**动态连续光影/焦点**」与「**光线连动弧光**」两段（§八.3–§八.4 + §0.06/§四.5）——含灯闪、霓虹脉动、烛焰跳动、屏光呼吸、条纹光漂移、池化光斑、墙面反弹明暗微变等；**禁止**在运镜与动作流/微动/BG 段提前写或重复写光影。
- **不可见发光实体**：即便在光影段亦绝对禁实体名（§0.06）；微动/Pn 段更不得借「看不见的光」点名画外灯/窗。

**双层背景动势（强制）**
- **第一层·环境实体微动（§七.7，每镜必填）**：须锚定白名单内、本镜**画内可见**的具体元素并写清**物理动势**——如**树枝/树冠随风轻晃**、**窗外/远距车流缓移**、百叶/窗帘轻摆、水面涟漪、雨丝下滑、旗帜/布幔飘动、挂钟秒针、蒸汽升腾、纸张被气流轻掀等（**仅当该实体已在剧本/Beat/Index/ENV 中出现**）；**无人群镜亦必填**。
- **第二层·背景人群随机动势（§七.7-b，有簇时追加）**：BG 可见群演/匿名人群簇时，**在 §七.7 环境实体微动之外另写**，**禁止**用人群描述替代环境实体微动；**禁止**只写「办公人员簇在动」而漏写已有百叶/窗外树/车流等 ENV 元素动势。
- **写法顺序（P1 BG 段建议）**：先写 **ENV 实体物理微动** → 再写 **人群簇随机动势**（若有）→ 再接主配角落位；**全程不写光影**。

- **写法位置**：P1 建置 BG 段**必写**环境实体物理微动；P2…Pn/终段若 BG 仍可见须**延续或更新**同类型物理微动（运镜导致 BG 更替时改写与新 BG 匹配的白名单项）；灯闪/霓虹/烛焰/屏光/条纹光/光斑等**只写在**「动态连续光影/焦点」「光线连动弧光」。
- **选型原则**：须匹配当前 `ENV:[...]` 类型、内外/日夜、题材基调与 Project Context；**只从白名单**选上游剧本/Beat/环境已暗示或 Index/ENV 固定清单中**可见的自然/人造元素**写动势；无明确户外元素时，仅对已有室内元素写物理微动（百叶/窗帘轻摆、空调气流扰动**已有**纸张/尘粒、**窗外已写明的**远距车流/树冠等）；**如无必要勿增实体**——禁臆造未出现元素。
- **幅度与优先级**：微动须 **subtle**、连续、不抢主拍；Static Hold / 特写仍须保留可感 BG 生命感（虚焦处**已有**叶影/窗帘轮廓轻晃、雾粒漂移等——**禁** Practical 光晕微颤入本段）；宏观/特效主相位写**场域级真实物理动势**（旌旗猎猎、尘浪推进、金属撞击、术法粒子场漂移等；**宏观阵势禁整齐划一机械同步**，须保留 terrain/参差/自然节奏）；光学动势仍归光影两段。
- **分类速查（择 1–2 项，勿堆砌；各项实体须已在白名单）**：
  - **户外自然**：树冠/**树枝**轻晃、草叶起伏、云层缓移、水面/雨洼涟漪、旗帜/布幔随风（**禁**「光尘在光束中漂移」——光学归光影段）。
  - **室内日常**：百叶/窗帘随气流轻摆、蒸汽/咖啡热气升腾、挂钟秒针、**窗外远距车流/树冠/街景虚化流动**（**禁**台灯/荧光灯闪烁入本段）。
  - **都市/赛博**：LED **屏面内容**微滚（屏为已有 PROP/ENV 时）、雨丝下滑、**后景车流/行人剪影缓行**（**禁**霓虹频闪/湿地面反光——反光归光影段）。
  - **悬疑/惊悚**：窗玻璃雨痕下滑、树影轮廓轻移、门扇微不可察颤动（**禁**烛焰光跳/走廊顶灯微闪入本段——光动归光影段；烛焰物理焰形跳动若剧本已有烛，可写「焰形轻颤」一句物理态，其照亮效果仍归光影段）。
  - **仙侠/奇幻/科幻**：法阵纹理微流转、能量粒子场漂移、全息界面内容微变、灵雾/离子雾缓流（**禁**把上述写成「发光脉动/光柱」光学句——光学归光影段）。
#### 7.7-b 背景人群（有簇时追加，与 §七.7 双层并列）

### 八、视频提示词要求 (Video Content Prompting)

只写入 `Video Content (CN)`：`Shot Logic (CN)` 写结构化推演与规则执行逻辑，本字段**只写发给 AI 视频模型的纯画面最终结果**，用自然语言叙述。维度间用 `<br>`，共五段 + 固定收束句：**全局动态风格 / 运镜与动作流 / 动态连续光影·焦点 / 光线连动弧光 / 物理文字生成 / 品质收束**。

**写法要点**
- 叙述体优先；禁 `结构=…｜`、`FG/MG/BG=` 键值体。
- **层位自然语言化（强制，见文首「Beat 自然语言 → 镜头坐标转译」）**：正文默认用连贯自然语言表达层位与方位（如「近处」「纵深处」「画面左侧」「身后」），**禁止**把 `FG/MG/BG` 缩写或「左区/右区/中线」等坐标词直接拼贴进叙述句（如「MG 左区」「BG 左区入画」）；确需点明景深层次时用完整中文词「前景/中景/背景」写成流畅句子，不得以缩写代码或字段体形式出现。
- **只写画面最终结果（最高硬约束）**：正文只描述镜头里**实际看见**的机位、景别、运镜、实体落位、动作、表情、及其变化；上游 Beat 与分镜规则须在写作前消化，**以画面内化呈现，不得在正文解释如何承接 Beat、如何执行规则**。❌ `承接上一 Beat 站位后，按环节 2 建置三层`｜❌ `因对白组未完结故保持中近景`｜❌ `按 §三.1 收束落幅判定本镜末 Pull Back`｜✅ `Eye-level Two Shot 中全景，CHAR:[@Lin] 距桌右前角一步、朝右前倾压桌…`。**光影例外**：光线/光影/色温/投影等**只**写在「动态连续光影/焦点」「光线连动弧光」，**禁止**混入「运镜与动作流」P 段。
- **追杀/穿梭时长明示例外（允许，§5.5 D）**：追杀/追逐/穿梭连续跟拍 P 段**允许且强制**在动作过程句内写入「持续约 Xs / 约占 Xs」等**可执行时长提示**（服务生视频模型按时长生成）；该秒数须计入本镜 `Duration (s)`。此为例外，**不视为**规则推演入正文；仍禁止写 Beat 承接、§ 引用、Logic 字段名。
- **Beat 实体/ENV 零缺失**（§一.2）：正文可检索每一个 `CHAR:`/`PROP:`/`ENV:`；≥1 个 `ENV:[...]`，切换按次数写出+运镜。
- **实体白名单 · 如无必要勿增实体（强制，§七.7）**：环境微动、背景信息、P1/P2…Pn/`(Pn)` 点名的环境/道具/陈设，**必须**来自剧本原文 ∪ Beat 明文 ∪ Index ∪ 本镜 ENV 固定清单；**禁止**为丰富描写新增未提及实体。
- **光影统一归段（强制）**：「运镜与动作流」（含环境微动、BG、P1–Pn、`(Pn)`）**禁止**写光线/光影/色温/投影/光斑/灯闪等；上述内容**只**写入「动态连续光影/焦点」与「光线连动弧光」。
- 运镜与动作流按 `P1/P2/P3…`；**呈现序=上游建置→入戏**（内容规则不在此重述）：P1 先把上游**建置段**拍成可读起幅，再进入 P2…Pn 拍**入戏段**；每 P 显式景别 + 显式运镜；对白 `(Pn)` 带完整语气层（§六）。
- 保留 `CHAR/PROP/ENV` 方括号标签；凡 Index 与 Core Scene Info 双源均出现的实体**必须**使用标准表达（§一.0.1），名称逐字取自 Scene Subject Index。已入 Index 的**群演簇**须写 `CHAR:[@簇名]` 并补充随机差异化动势描述；未入 Index 的匿名背景人群用自然语言，**禁止** `EXTRA:`。段首可用中文维度引导。
- **禁分镜推演与规则逻辑入正文（硬约束）**：`Video Content (CN)` **禁止**写入——Beat/上镜承接说明；`收束落幅判定`/`下一镜`/`路径 A/B`/调度预留/桥接动机/执行优先级；环节编号（环节 0–6）、章节引用（§x.x）、上游工程字段（`{对白组边界}`/`{下一节拍起幅}`/`建置更新=`/`Beat完整逻辑继承` 等）；规则判定句式（「按…判定」「因上游…故…」「须…故本镜…」）；以及任何仅属 `Shot Logic (CN)` 的解释性、推演性文字。
- **禁上游空间推导术语入 Video Content（硬约束，§七.6）**：正文**禁止**出现——`0度/90度/180度/270度` 作工程坐标、`360度拓扑`、`转角对照`、`衍生0度=主环境N度`、`(N+90)%360`、`view_angle_from_main`、`empty_view_delta`、`angle_mapping`、`topology_360`、`zero_degree_anchor` 等 Index/Stage 推导字段或公式。**须转译为镜头语言**：机位落点（如「会议桌长边侧面、胸口高度 Eye-level」）、相对主视角的**顺时针回转 N 度**（如「沿桌轴线顺时针回转 180 度至桌内侧」——**禁**写「至百叶窗侧」若该窗已不可见）、Reverse Shot / OTS / POV 等运镜名、**背景更替**（如「背景为半开木门与门外走廊；机位后方半空间不可见」——**禁**「取代主视角时的百叶窗墙」这类点名不可见实体）、方向性物体**可见面变化**（如「椅背朝向镜头、门扇向室内开启停在画面右侧」）。`ENV:[180度办公室会客区_桌后反打]` 等 Index 原名**保留**作环境标签，但正文描述须用上述镜头语言，不得复读 ENV 名中的角度前缀当空间说明。
- **黑名单自检**：禁工程坐标与推导字段（上条列举）；**允许**镜头运动语义（沿轴线回转、Reverse/OTS、BG 更替）；禁 `N度` 作人物朝向/光源的工程描述。

1. **全局动态风格（Mandatory，§一.3A）**：1–2 句重申项目基调；首句含**上游已有**的项目类型+语境+风格定位转译（句式见 §一.3A）；类型跟 1–2 条正向视听落点；风格定位**仅上游已给时**跟可视化落点；光学氛围服从 §四.5-E；有 `Global_Style` 须合并且不得与 `Type` 冲突；**禁止**自拟题材标签或借风格段补写未出现陈设。
2. **运镜与动作流**（正文**只输出画面**；内容=上游 Beat；本层叠加景别/运镜/构图）：

   **P 段摄影骨架（强制）**
