3. **内容继承**：用 **P1…Pn 区分本镜覆盖的不同 Beat**（**一般一 P 对应一 Beat**；合镜 N Beat → 恰好 P1…PN 一一对应；**时序=播放序，不可变**，细则 §二.3A）。**P1 有人/有独立道具**=整句抄该拍【建置】入画角色/道具（含已锁落位/可见面/面向/距）→ 背景参考图为 `ENV:[…]` → 再写入戏。**P1 纯无人空镜**=不抄 CHAR/PROP 落位，只写运镜/环境动势 + 背景参考图为 `ENV:[…]`（建置原文为 `空镜／无角色／无道具` 则照此，禁补人补件）。**同 ENV 的 P2…Pn 只写背景参考图为 `ENV:[…]` 与该拍【入戏】/运镜/配音/音效**。**相邻拍 `ENV:[…]` 名变时**：有人拍该 Pn 含该拍【建置】整句并写「背景切换到参考图 `ENV:[新]`」再写入戏（§二.7A）；空镜拍只写切换参考图。**禁止**把【入戏】动作链并进建置句。名单只抄该拍建置主体 ∪ 入戏主语（空镜可仅 ENV）。运镜不改站位与锁档。背对则忽略面部表情（§二.9）。脑内核销；Logic 只落 `实体:` + `P链:`（§一）。

   #### 3A. Pn 时序与实体优先（最高 · 时序不可变）
   **主序=时间 · 一般一 P 对应一 Beat**：P1…Pn 必须等于本镜覆盖 Beat 的叙事/播放先后，一一对应（合镜 N Beat → 恰好 N 个 P）。禁止因卖点/高潮/情绪/要点把后拍提前或前拍后置；禁止把尚未发生的高潮实体提前到更早 Pn；禁止把多 Beat 揉进同一 P；禁止同一 Shot 内把一 Beat 拆成多个 P。一 Beat 因时长门槛拆到不同 Shot 时，各镜只写本镜承担的那一拍（一镜一 P），不得倒叙。
   **同拍二次优先（只排 CHAR/PROP；不改 Pn 号、不删其余）**：该拍读上游【卖点综合】【情绪峰谷综合】【叙事综合】的 `承接=` / `指导=` / `落地=` / `重点对象` / `关键人物` / `信息焦点` / `契科夫` 及峰谷挂靠，识别本拍要点对应的 `CHAR:` / `PROP:`。同拍内把这些实体放到建置句序、主拍/焦平面、Logic `实体:`、`Associated Entities` 的前列；其余在场者仍须全覆盖，排在其后。各实体【建置】整句原文不改，只调句序。
   **同拍优先档（高→低）**：卖点 `重点对象` → 情绪峰谷承载（峰值/低点/入场锚/转折）→ 叙事 `关键人物` / `信息焦点` / `契科夫` 道具 → 本拍入戏主语/主动作者 → 其余建置在场。同档并列保持该拍【建置】原文相对序。P2+ 动作链仍按时序；同相位多主体时要点实体获主拍（辅者同框不得反客为主）。

8. **对白只继承（最高 · 八键全文）**

台词 / 八键语气 / 方言标签 / 闭嘴名单 / 微表演 = 入戏开口行原文。本层写入 `(Pn)` Dialogue/Voiceover 壳，**不释义、不重列字段、不补表演、不另定口型规则**。缺闭嘴、缺 `{台词}`、缺任一八键、或写成「语气层+台词」/「语气层:」占位 → `upstream_missing_dialogue` 回流。

**八键=语气层正文（禁写标签词）**：`voice_type`｜`voice_identity`｜`tone`｜`speed`｜`volume`｜`rhythm`｜`stress`｜`pause`。壳里的语气位**就是这八键原文逐字**（用上游全角 `｜`），**禁止**把占位名抄成「语气层」/「语气层:」/「语气层+台词」。有非空台词 → 八键全文必须在该 Pn **可检索**（缺任一键=失败）。无具体台词 → 省略该句 Dialogue，不臆造。禁把 `开口 |` 骨架的 ASCII `|` 裸写进单元格（裂列）。
- **画外音/VO 禁遗漏**：上游 `voice_type=VO|旁白|OS` 或 `开口 | 无` 的非空 `{台词}` 必须写入**同一 Pn**（可与画内 Dialogue / 动作同拍）；禁漏抄、禁并入口型对白、禁改写成音效/`{…}`。缺 VO 行 → `upstream_missing_dialogue`。

8A. **配乐与音效同拍同频（强制 · 只抄上游）**
该拍【配乐】`{听感}`/`态=`/`乐器=`/`音量=`/`质量=`/`混响空间=`/`锚=` 与【音效】`{…}`/`配合=`/`方位=`/`音量=`/`质量=`/`混响空间=` **只抄不改**，写入「运镜与动作流」对应 Pn，**嵌在 `锚=` / `配合=` 指向的同一动作或同一运镜起/落幅同句（或紧邻后半句）**，使声画出现时机一致、节奏同拍同频。
- **配乐**：`起`=锚动作出手/起幅瞬间写「{乐器组}配乐起，{【配乐】`{…}`听感}，{音量}，{质量}，{混响空间}」｜`变`=锚动作变奏瞬间写「配乐变／加压」+听感增量｜`续`=本拍入戏起幅可短挂「配乐续」+乐器组与听感，不另起冲突织体｜`收`=锚动作收势/落幅写「配乐收」。`乐器=` 可多件共同合作（**≤5**），抄上游编制与听感原样，禁压成单件，禁另加超编件，禁改音量/质量/混响。配乐听感只抄【配乐】行 `{…}`，禁写入【音效】行。
- **音效**：写在 `配合=` 动作发生的同一瞬间（推门↔门轴吱呀；拳中胸↔闷响；迈出右脚停步↔皮鞋笃笃；运镜落幅↔配合落点声）；保留 `{可听内容}` + 方位 + 音量 + 质量 + 混响空间。入戏已写这些键 → Video 该动作句必须可检索，**禁止**只写 Dialogue 而丢掉音效行。
- **禁**：堆到 Pn 段末或两光影段；声先于/后于配合动作一个相位；另造未写入的 BGM；因品质收束「无背景音乐」而删已写入的配乐/音效（「无背景音乐」=禁另起未写入的 BGM，≠无本层已抄配乐/剧情音效）。入戏已有【配乐】【音效】或 `{…}` 却未嵌到对应动作/运镜句=失败；上游整段无标签 → 脑内标 `upstream_missing_audio`，禁补造。

8B. **角色介绍物理文字标签（只抄上游 · 不算动作 · 只跟该人主动作后）**
**打出角色名牌物理文字不算动作**：不占动作链、不计动作耗时、不写成角色行为。上游【入戏】（优先）或旧稿【建置】若写 `画面打出物理文字标签：【{裸名}】{标签}】｜字体=…｜字色=…`（兼容旧稿 `画面打出字幕：【{裸名}】{标签}】`），须在**该人主要动作句后立刻**写「同拍打出物理文字标签」+ 字样（与该人正面/¾ 同相位出现）。P1 / ENV 名变 Pn：抄建置（**建置句内若含名牌须抽出，不原位留在建置**）→ 背景参考图 `ENV:` → 写入戏；该人主动作写完 → 紧跟该人名牌 → 再写下一人动作。入戏原文已在该人主动作后含名牌 → **原位保留**，禁再抄一遍到 §七.5。旧稿名牌只在建置 → **提到该人主动作后**。中途入画则挂该人入画落定句后。本拍该人无主动作仅对白 → 跟开口句后。**禁止**挂建置、禁止把打出名牌写成独立动作、禁止先写完全员建置/动作再把多名牌攒到 Pn 段末或 §七.5 物理文字段。**此为片内图形名牌，不是对白硬字幕、不是画幅底部白字黑边。** 字样/字体/字色已由上游按剧本明文或项目语言写定，**禁改译、禁换书体、禁换字色、禁中英并列、禁另造另一语种**。字样保持裸名，禁套 `TYPE:`。上游已写**客观身份**标签（如`千金`/`第一家族继承人`/`智能AI宠物猫`）**原样抄**。上游若仍写`落魄千金`/`复仇女皇`等处境或剧情词 → 只抄剥后的客观词（`千金`），禁把落魄/复仇上屏。上游标签为`无`或只打了裸名 → 原样只上裸名，**禁**另造职业/角色定位/剧情词。蒙面/易容/真脸不可读或上游未写该行 → **禁自造名牌**（连裸名也不打）。仅上游缺字体/字色才跟 `Global_Style` 补一书体+具名色。无该行 → 禁自造名牌。品质收束「无字幕」=禁对白硬字幕，**不删**本条物理文字标签。

9. **穿帮对照（只调明显矛盾）**
只核本层 Video 里一眼可见的占位/朝向矛盾，**可优化调整**，不扩检、不改戏、不改锁档。**收短建置、改层位词、改面向、漏已锁落位 = 擅自变化，不是本条。**

- 穿帮只在 Video 里改画面结果，不写入 Logic。

   **合镜时长合并计算（强制，与原则 1 配套）**：
   - 完成原则 1 归并后，**须将同组内全部 Beat 的时长合并累计**，再对照 `MergeFillThreshold = MaxShotSeconds−6` 决定是否继续并入 / 封口；**禁止**只对单个 Beat 单独计时而忽略同组其他 Beat 的叙事耗时。
   - **计算步骤（分项对账 + 并行核，强制）**：① 组内**逐 Beat** 按 §三.5 写出完整 `时间预估` 分项——**建置 / 语言 / 动作 / 微表情 / 特效 / 反馈 / 转场·停顿**（无该项写 `0s`，七类须列齐供对账）；② **Beat 小计禁止七类全额相加**。公式：`Beat小计 = 建置串行 + 并行核 + 独占项`。**建置串行**仅本拍需要新起幅时计入（本镜首拍 / ENV名变 / `建置更新=是`）；**同ENV且 P2+ 不重复落位 → 建置=0s**（仍须写出 `建置0s`）。**并行核** = `Max(语言, 动作, 微表情, 特效, 运镜, 音效)`（同相位只取最大一项，**禁止**把已并行的转头+表情+慢推+雨声+配乐再全额相加）。**独占项**仅强悬念插帧 / 独占反应 / 必须串行的结果定格。③ **合镜累计**：`基准合镜Duration = Σ（组内各 Beat 小计）+ Beat衔接补偿`。组内 Beat **小计**按叙事先后相加。**禁止漏计**后续 Beat 的语言/动作/微表情/特效（ENV未变、对戏归镜不是删戏借口）；**必须**把同ENV后续拍建置写成 `0s`。跨P同一连续运镜（Slow Push/Dolly/Track 贯穿）只在起始P计入全程，后续P `运镜=0s` 或只计档变增量。④ **Beat衔接补偿**：有切角/换主/对白轮次/站位跳变时 `=(N−1)×0.9s`；**同一连续运镜贯穿且无切角、无站位跳变 → `Beat衔接补偿=0s`（已含在该运镜全程）**；单 Beat 未成组 = `0s`。⑤ **封口判定用基准累计 T0**对照 `MaxShotSeconds−6`（见原则 3；**T0 不含镜末语言延续**，禁止用 +1s 提前封口）；⑥ **填表 Duration**：先由 T0 得 Duration0——若 **T0 > MaxShotSeconds** → Duration0 **强制 = MaxShotSeconds**（禁止浮动下调冒充未超、禁止拆镜）；否则按 §三.5 **±20% 浮动**取整，钳制 **[4, MaxShotSeconds]**；⑦ **镜末语言延续（强制）**：本镜**最后一个 Beat** 为语言类 → `Duration = min(MaxShotSeconds, Duration0 + 1)`；末 Beat 非语言类 → `Duration = Duration0`。`时间预估:` 须写 `镜末语言延续=1.0s|无`。
   - **`时间预估:` 合镜写法（必填）**：七类分项须写全（0s 亦标明），**小计必须写出并行核**，禁止把分项用 `+` 串成小计。对白例：`Beat3(建置0.9s｜语言2.7s｜动作1.8s｜微表情0.9s｜特效0s｜反馈0s｜转场0s｜并行核=Max(2.7,1.8,0.9)=2.7｜小计=0.9+2.7=3.6s)+Beat4(建置0s同ENV｜语言1.8s｜动作0.9s｜微表情0.9s｜并行核=1.8｜小计=1.8s)+Beat衔接补偿0.9s(对白轮次)=T0=6.3s｜门槛=MaxShotSeconds-6｜浮动±20%→[5,8]｜Duration0=6｜镜末语言延续=1.0s｜Duration=7`。氛围建立例（无对白、同ENV、同轴慢推）：`Beat1(建置1.8s新场EWS｜语言0s｜动作转头1.4s｜微表情0.9s｜特效0s窗雨≠宏大特效｜音效雨雷并行｜运镜SlowPush1.8s｜并行核=1.8｜小计=1.8+1.8=3.6s)+Beat2(建置0s同ENV｜语言0s｜动作俯瞰持0s｜微表情0.9s｜特效0s｜运镜续推0s已计P1｜并行核=0.9｜小计=0.9s)+Beat衔接补偿=0s(同轴续推已含)=T0=4.5s｜~放→Duration=5或6｜禁灌满MaxShotSeconds`。超上限例：`基准合镜Duration=16.8s｜超上限钳制｜Duration0=MaxShotSeconds｜镜末语言延续=压缩进末秒｜Duration=MaxShotSeconds`（仅对白/动作/特效分项确实撑满时）。

5. **时长推演公式 (强制 4s–MaxShotSeconds)**：
   - **基础计时单位**：脑内按类型拆秒（建置/语言/动作/微表情/特效/反馈/转场）；**Logic 只落** `Beat-Shot映射:` 的 `Duration=` 整数，不写分项公式。
   - **计算顺序（强制，防重复计时）**：① 先完成 §三.4 `节奏需求`（含拍型 `-`/`~` 与 `计时适应=压|放`）；② 再按下列规则分别估算各类型耗时，写出分项，**并按拍型取档**（见下「拍型计时适应性调节」）；③ 同相位并行的对白/动作/微表情/特效/运镜，只取 `Max(语言, 动作, 微表情, 特效, 运镜)` 作为**并行核**，**禁止**把已并行项再次全额串行相加；④ 仅对**必须串行**的段落追加：建置（首段或建置更新=是）、转场桥接、结果落位定格、强悬念插帧、独占反应镜/插帧；⑤ 得**基准 T0** 后按 **±20% 浮动**取整得 Duration0，浮动偏向须回扣拍型（`-` 偏压、`~` 偏放）；⑥ **镜末语言延续**（见下条）：末 Beat 语言类 → `Duration = min(MaxShotSeconds, Duration0 + 1)`，否则 `Duration = Duration0`。
   - **拍型计时适应性调节（强制；对齐 §三.4）**：覆盖 Beat 的 `-`/`~` **必须**改变分项取档与 Duration 偏向；合镜**逐 Beat** 各自取档后再相加，禁止用主导档抹平组内 `~`。`时间预估:` 须含 `计时适应:拍型=-／~｜分项取档=下沿／上沿｜浮动偏向=压／放`（合镜写 `Beat3=-下沿压+Beat4=~上沿放`）。

     | :--- | :--- | :--- | :--- |
     | **`-`** | 建置/动作/微表情/停顿/短程运镜取各区间**下沿**（建置偏 0.9s、单点微表情 0.5–0.9s、短程运镜 0.9–1.4s、停顿偏 0.9s）；语言保口型下限不压穿 | 优先 `[round(T×0.8), T]`；基准T=4 **禁下浮**（可保持 4） | 用升格/三段微表情/强悬念停顿灌交代秒；下浮删对白或跳步骤 |

     - **须读上游 `rhythm`/`stress`/`pause` 微调**——`pause` 显式长停/换气/破折号或省略号截断 +0.5–1.8s；`rhythm=一字一顿/一字慢读/staccato/slow burn` 等须相应拉长或压缩语言段；`stress` 重读词处可 +0.2–0.45s 微表演相位；口型可见的对白不得压缩到低于语言耗时。
     - **镜末语言延续（强制 · 固定 +1.0s）**：本镜覆盖的**最后一个 Beat** 若为**语言类**——该 Beat **语言载荷>0**（有非空台词的对白 / OS / V.O. / 旁白 / 自白 / 独白 / 内心；无具体台词而省略的说话动作行**不算**）→ 在 Duration0（含单Beat锚定 4s、合镜累计、±20% 浮动、上限钳制）之后 **固定再 +1.0s**：`Duration = min(MaxShotSeconds, Duration0 + 1)`。该 1s **串行接在末句说完之后**，**禁止**并入口型并行核，**禁止**被 `-` 拍下浮吃掉，**禁止**用这 1s 追加台词。合镜**封口/门槛判定只用 T0**（不含这 1s），禁止用 +1s 提前封口。`时间预估:` 须写 `镜末语言延续=1.0s｜末Beat=语言类` 或 `镜末语言延续=无｜末Beat=非语言`。**Video**：末 P 收尾须写出说完后约 1s 余韵定格（口型闭合/余韵微表情/听者余波；OS/旁白则画内保持闭嘴余韵），**禁止**卡在最后一个音节切断。Duration0 已=MaxShotSeconds → Duration 保持上限，余韵**压缩进末秒**，仍须写出、不删台词。末 Beat 语言=0（纯动作/空镜/转身过程拍等）→ 不加。
   - **音效耗时（强制，有则计）**：上游花括号 `{…}` 可听音效——短促一声（门轴/撞击/狗吠切入）**0.5–1.4s**；持续环境声桥/雨打窗/远处犬吠铺垫 **0.9–2.7s**；与对白/动作同相位时并入并行核取 Max，独占声先入/声桥相位才全额计入 `转场/停顿Xs` 或并入动作核；`时间预估:` 有音效时须写 `音效Xs` 或并入已标明的并行核（如 `并行核=Max(语言2.7s,音效0.9s)=2.7s`）。**配乐与持续环境声（雨打窗/闷雷/都市底噪）不另加串行秒**，并入并行核；**禁止**把每条 `{…}` 音效逐条相加。Video 落点见 §二.8A（嵌动作/运镜句，禁堆段末）。**禁止**因「品质收束含无背景音乐」而删上游【配乐】或剧情音效（「无背景音乐」=禁另起未写入的 BGM）。
   - **建置/运镜耗时**：新场景空间建置0.9–2.7s（**合镜 Pn 换主须计入该档，禁 0s**，§二.7A）；同主切角/状态变 ENV 名变须计入关系重建或反打建轴 0.9–2.7s（禁 `建置更新=否` / `0s`）；**同ENV且未写建置更新=是的后续拍：建置=0s**（P2+不重复落位，计时同样不重收建置秒）。关键角色/道具首次落位每组0.5–0.9s；焦点转移/Rack Focus 0.5–1.4s；短程推拉摇移0.9–1.8s；复杂关系重建或OTS反打建轴1.8–2.7s；**视角/反打切换过程**（§四.9 G）**1.4–2.7s**，计入对应 P 段或 `转场/停顿Xs`；**跨P连续同一运镜**：Slow Push/Dolly/Track 贯穿多P时，只在起始P计入全程秒，后续P `运镜=0s` 或只计档变增量（EWS→WS 微调≠再收 1.8s）。**§三.3 合镜封口另起后镜**仅当 §四.1 三前提满足时前镜回建置才计 1.8–2.7s，否则镜末保持近景不计 Pull Back；后镜 P1 继承末帧 0.9–1.8s；高速追逐/打斗/景别切换运镜与动作同相位并入并行核取 Max。运镜与对白/动作同相位时并入并行核取 Max，不得全额另计。
   - **动作耗时**：常态短发力0.9–1.8s；递交/转身/落座/起身/后退等单步动作1.4–2.7s；复杂交互、拉扯、攻击、防御、避障2.7–4.5s；长距离或多障碍动作用同镜 P 段简化落点呈现；**打出角色名牌物理文字不算动作，不计本分项**；**基准 T > MaxShotSeconds 时不拆镜**，表列 Duration 强制=MaxShotSeconds（§三.3）。
   - **追杀/穿梭节点耗时（§四.9 D）**：连续位移动量按**路径节点**估时——绕障/跃槛/急转/抓扶 **1.8–2.7s**；长直段加速跟跑 **2.7–3.6s**；门槛/通道穿越 **1.8–3.6s**；封闭舱推/拉过阈 **1.8–3.6s**（须覆盖起幅外或内→过框→落幅换 ENV，禁 0s）；载具超车/变道 **2.7–3.6s**；多节点同镜内**串行累加**计入 `动作Xs`（禁用单次 Max 抹掉节点）。同链跨多 Shot 时各镜动作分项之和须覆盖上游整链等效（**≥18s**）。Video 明示秒数须与本分项一致。
   - **微表情耗时标准化**：微表情必须按 `前置反应 -> 中段变化 -> 落点结景` 计时；单点微表情0.5–0.9s；完整三段链1.4–2.7s；落泪/强忍/心虚/怒意升级等渐变链1.8–3.6s；与对白/动作同相位时并入并行核取 Max，独占画面相位才单独计时。
   - **听者反馈耗时**：单个听者即时反应0.5–0.9s；两人以上反应镜0.9–1.8s；群演统一反馈0.9s；群演随机反馈或空间避让1.4–2.3s。反应已写入 `(Pn)` 听者段且与对白同相位时，并入并行核，不另计；Beat 强制要求独立反应镜或插帧时才全额计入。
   - **特效耗时标准化**：特效按 `触发源 -> 显形/扩散 -> 命中/作用 -> 维持/碰撞 -> 余波/残留` 分相计时；轻量视觉反馈0.9–1.8s；单段法术/能量/技术效果2.7–4.5s；对抗型特效4.5–7.2s；大范围环境影响7.2–10.8s；**宏大特效主相位 ≥7.2s、对抗/对撞 ≥9s**，须按六相**分项**写出可核销秒数（禁单行「特效7s」无分相）；与动作咬合取 `Max(动作相位, 特效相位)+余波`，不得把特效折叠成一个泛化动作。分相秒数须有对应 Video **变化细节**支撑，禁空标时长。**禁把氛围衬托当宏大特效**：`ENV背景微动`（窗雨/帘/烟气）、持续环境声、配乐、霓虹雨丝粒子衬托 **特效=0s**，只并入并行核（通常被运镜/动作盖住）。**大范围环境影响 7.2–10.8s 仅**上游明文的法术/爆炸/灾变改观整场，禁用于开场站窗看雨。上游打斗/法攻/仙攻/宏大特效 Video 须抄**粒子级衬托**（基本格斗=尘土/碎屑；武侠叠气劲/剑光微粒；仙侠再叠灵尘/光电；上层含下层）且法攻/仙攻/宏大落地 **≥5 条**互不复读的效果细节（粒子/流体 + 实体动作可混计；抄上游已写单元，禁干打、禁压成「金光爆发」）。**仙攻须抄上游粒子阵形秩序**（八卦/符阵/凶兽/武器/法相轮廓等可读几何，禁 random 无序光点）。
   - **升格/慢镜耗时**：是否升格认上游节奏/情节（§三.1），本层只测算秒数。Slow Motion / Bullet Time / Speed Ramp 等升格相位单独计入 `特效Xs` 或 `运镜Xs`（按主导项）；单段 Bullet Time 或环绕定格 1.8–3.6s；局部慢动作 0.9–2.7s；Speed Ramp 含入出常速各 0.3–0.45s；与击打/爆炸/法术命中同相位时并入并行核取 Max，独占升格镜全额计入。`~`/情节砸点取上沿；`-` 不得用升格灌交代秒。
   - **打斗/特效快慢节奏计时（强制）**：硬口径与分项秒数见 **§四.8**（升格≈30%/25–35%，>40% 砍；常速≥50%；`升格占比≈Xs/Ys=Z%`）。`时间预估` 须另写 `快慢节奏:`——常速/升格/Speed Ramp **分项串行**，禁用单次 Max 抹平快慢；多 P 段快慢交替各段并行核**相加**。
   - **情绪停顿/插帧耗时**：道具特写、人物局部特写、环境细节插帧0.9–1.8s；强悬念停顿或信息落点1.4–2.7s；**无情节回忆切片** 0.5–1.8s，计入 `转场/停顿Xs`（§四.6），与触发/回切同相位并入并行核；只服务节奏，不得无因延时；嵌入主节拍间隙的插帧不重复全额计时。
   - **总耗时计算**：`T = 建置串行 + Σ各段并行核 + 独占反馈 + 独占插帧/停顿 + 转场桥接`；单段并行核 = `Max(语言, 动作, 微表情, 特效, 运镜, 音效)`；多 P 段同镜内各段并行核**相加**（段间切换即节奏，不每段重复全额建置；跨P同一连续运镜不在后续P再计入并行核）。多主体同时动作用主动作计时，辅助反应按0.3–1.4s补足（已与对白并行则并入 Max）。
   - **氛围/建立镜封顶（强制）**：无对白（语言=0）且无复杂动作（无打斗/追杀/过阈/多步交互）且无宏大特效的建立/凝视/空镜合镜：两Beat 合镜 T0 典型 **4.5–8s**，Duration 落 **5–8**（`~` 可到 9）。**禁止**为凑满 MaxShotSeconds 拉长 Slow Push、重计建置、把窗雨当特效。Duration=MaxShotSeconds 仅当对白/动作/特效分项确实撑满（或 T0>Max 钳制）。
   - **合镜多 Beat 累计（强制）**：公式与写法**仅见 §三.3**（小计=建置串行+并行核，**不是**七类相加）；此处估时后回填同一套 `时间预估:` / `Beat-Shot映射:`。
   - **单Beat默认锚定（强制）**：单 Beat 未成组成镜时，`基准T` 默认锚定 **4s**，先得 Duration0 默认 **4**（`Beat-Shot映射:单Beat=…｜基准T=4｜Duration0=4`）。分项公式若 **<4s** → 先补足建置/反应/落点停顿至 **基准T=4**；分项若 **>4s** → 以分项结果为基准T（可再 ±20%；若已 >MaxShotSeconds 则 Duration0 强制=MaxShotSeconds）。**基准T=4 时禁止再下浮**——Duration0 只能保持 4 或上浮（慢节奏留白），不得低于 4。**然后**若该单 Beat 为语言类 → `Duration = min(MaxShotSeconds, Duration0 + 1)`（默认即 5）；非语言类 → `Duration = Duration0`。合镜多 Beat **不适用**本条默认 4s，仍按 §三.3 累计。若单 Beat 基准仍 ≤MaxShotSeconds−6 且有下一 Beat → **必须合镜**（原则 3），不得以单 Beat 默认 4s 为由拆开。
   - **时长 ±20% 浮动（强制允许）**：分项公式得出 **基准 T0**（单Beat先经上条锚定；合镜=基准合镜Duration；**均不含镜末语言延续**）后：若 **T0 > MaxShotSeconds** → **禁止浮动**，Duration0 **强制 = MaxShotSeconds**；否则 Duration0 可在区间 `[round(T0×0.8), round(T0×1.2)]` 内取**正整数**，并钳制在 **[4, MaxShotSeconds]**；**若基准T=4，下沿锁定为 4（禁止再下浮）**，上沿仍可按 +20%（可选 `[4, round(T0×1.2)]`）。浮动**须回扣拍型**：`-` 优先落在下半带（压密度），`~` 优先落在上半带（留白）。**浮动只作用于 Duration0**；语言末 Beat 的 +1s 在浮动之后硬加，不得被下浮吃掉。公式只在脑内；**Logic 只写** `Beat-Shot映射:…｜Duration=整数`。
     - **浮动服务节奏，不改内容**：上浮≠灌水空镜；下浮≠删对白/动作/步骤（§二.4）；口型可见对白的语言耗时为硬下限，下浮不得使其不可读；**基准T=4 不得以 `-` 为由再压秒**；`~` 上浮须有已锁近景/停顿/Slow Push 可核销，禁只加秒无画面、禁为上浮另切 CU。
     - **合镜/封口判据用基准**：是否继续并入对照 **基准累计 vs MaxShotSeconds−6**；是否超上限钳制对照 **基准 T vs MaxShotSeconds**。**禁止**用浮动把 ≤MaxShotSeconds−6「算成」已过门槛而拒并；**禁止**因基准 >MaxShotSeconds 而拆镜。
     - **正例**：✅ `单Beat｜拍型=-｜语言类｜基准T=4s｜Duration0=4｜镜末语言延续=1.0s｜Duration=5｜计时适应=压｜禁下浮吃延续`｜✅ `单Beat｜拍型=-｜非语言｜基准T=4s｜镜末语言延续=无｜Duration=4`｜✅ `单Beat｜拍型=~｜语言类｜基准T=4s｜Duration0=5｜镜末语言延续=1.0s｜Duration=6｜浮动=~落泪留白`｜✅ `拍型=-｜基准T=10s｜门槛=9｜Duration0=9｜末Beat语言类｜Duration=10`｜✅ `合镜两Beat站窗凝视｜语言0｜同ENV｜同轴SlowPush｜T0=4.5～6.3｜Duration=6或7｜禁15`｜✅ `基准T=16.8s｜超上限钳制｜Duration0=MaxShotSeconds｜镜末语言延续=压缩进末秒｜Duration=MaxShotSeconds`。
     - **反例**：❌ 单Beat 语言类 Duration0=4 却写 Duration=4（须 +1→5）｜❌ 语言末Beat 把 +1s 并入口型并行核或拿去加台词｜❌ Video 卡在末音节切断、无约 1s 余韵定格｜❌ 用 +1s 把未过门槛的 T0「算成」已封口｜❌ `-` 拍下浮把延续吃掉｜❌ 末Beat 纯动作却加 +1s｜❌ 单Beat 基准T=4 却写 Duration=3｜❌ 基准 >MaxShotSeconds 却拆镜｜❌ 下浮删半句对白｜❌ 用浮动把基准 8s 写成 10s 声称已过门槛｜❌ 七类分项 `2.7+2.7+2.7+2.7` 串成小计｜❌ 开场站窗+转头+俯瞰两Beat无对白却 Duration=MaxShotSeconds｜❌ 把窗雨/雨丝粒子写成特效7.2s｜❌ 合镜小计照抄旧例 14.4→15。
   - **调平硬规则**：先得基准 T0（**单Beat 默认锚定 4s**）→ 若 **>MaxShotSeconds** 则 Duration0 **强制=MaxShotSeconds**（不拆、不删内容）；否则在 ±20% 浮动带内取整数秒得 Duration0，钳制 [4, MaxShotSeconds]；**基准T=4 禁止再下浮**；单Beat 分项低于 4s 先补足至 4；合镜/其他镜基准低于 4s 先补足建置/反应/落点停顿再浮动；**然后**语言末 Beat 硬加 +1s（已钳 Max 则压缩进末秒）；**禁止**通过删除/概括上游内容来降时长（§二.4）。
6. **切镜客观连续性（Video 写法）**：`Video Content (CN)` **只写本镜画面内可见的最终状态与变化**，禁写“承接上一镜/上镜/前镜/上一 Beat/previous shot”及“同上一镜/延续上一镜/承接 Beat”等代指或承接说明；Beat 衔接、前接判定、变更依据、可剪辑合镜推演**只写** `Shot Logic (CN)`，画面以内化描写直接呈现当前实体落位与空间关系（字段见下条）。
6A. **分镜间衔接逻辑 · 可剪辑合镜（最高硬约束）**：相邻 Shot 须可剪辑合镜（时空/轴线/视线/动作相位/实体态咬合）。**写出口径只见 §三.3B**：合镜后先评估，再把转镜运镜与转镜其他要求分写入上镜末 / 下镜 P1；核销在脑内完成；**Logic 只写** `衔接:` 本镜那一端（§一；例 `衔接:Eyeline+OTS｜转入运镜=过肩起｜转入其他=视线落Chen｜转出运镜=SoftPan落肩｜转出其他=MCU+持文件`），**禁**核销清单与解释段。

   **运镜技巧 × 稳定 × 剧情（强制 · 分镜间）**：①技巧（Match/Eyeline/OTS/同轴/门槛等，禁空标签）②稳定（能量同档或邻档，§四.5）③剧情锚（动作/对白/视线/ENV/情绪）。高压档仅剧情明文+桥接。

   **上镜末 → 本镜起 双向咬合（强制 · SH02+；执行 §三.3B）**：衔接不能只写 Logic——**上镜末帧**与**本镜 P1 首帧**须在剪辑点对得上。动笔每镜（含回改上镜末段）时强制：
   1. **先读上镜转出**：从上镜末 P 已写入的转出运镜 + 转出其他要求提取切点快照——景别档｜机位能量｜主拍 CHAR｜全员终态（落位/朝向/姿态/持握/**与周边相对：具名锚+尺度距离+哪一侧**）｜视线或动作相位｜ENV｜轴线与银幕方向。终态落位须清晰可辨，禁「在那边」式糊落点。
   2. **再写本镜转入**：P1 起幅须是该快照的**合法下一帧**（同轴续拍 / Match 续相位 / 反打起幅 / 门槛切换起幅等），并写入转入运镜 + 转入其他要求；实体态与上镜末**零跳变**（直至本镜明文演化）；本镜景别=覆盖 Beat 的已锁档；与上镜锁档跨度以相邻拍【建置】`景别=`推算为准，禁止本层另选邻档/越级。
   3. **回写上镜转出**：写本镜前确认上镜末已为本镜起幅留好转出运镜与转出其他要求；若本镜起幅变更，**必须同步改上镜末段**使两端仍咬合——禁止只改一侧。
   4. **Video 内化呈现**：P1 **直接写出**转入运镜与转入其他要求的画面结果（禁「承接上镜」字样）；读者仅看本镜 P1 也应感到从上一切点自然接上，而非每镜重启 Wide Establishing（除非 Scene 首镜或封口后镜按上镜终态重建）。

   **Logic 只落本镜那一端（§一 `衔接:`）**：按 §三.3B 写转入/转出短词。可剪辑核销只在脑内用于改 Video；**禁止**把核销表抄进 Logic。Scene 首镜开场转场写进 Video P1，不另开 Logic 专签。

   **合法衔接类型（择实，禁空写）**：
   | 类型 | 何时用 | 咬合硬门槛 |
   | :--- | :--- | :--- |
   | **同轴续拍 / Reframe** | 同观察侧、人数/景别微调 | 本镜 P1 起幅 = 上镜末同轴画面的合法延续或相邻一档景别；实体态零跳变 |
   | **Match on Action（动作 Match）** | 跨镜拆开同一连续动作 | 上镜末停在动作**未完成中段**；本镜起幅自**同一动作后续相位**续写；禁上镜已落定再本镜重演起手 |
   | **Eyeline Match（视线 Match）** | 看→被看 / 反应镜 | 上镜末视线方向与本镜被看对象/空间方位**可核销**；禁视线落空或反向无动机 |
   | **Shot-Reverse / OTS 切换** | 对白往返、对戏反打 | 抄建置过肩句 + 运镜过程；禁无过轴声明的越轴跳切 |
   | **Graphic Match（图形 Match）** | 构图/形状/色块桥接 | Logic 写明上下镜图形锚点；Video 各自写清可见锚点画面 |
   | **Insert ↔ 主镜回切** | 道具/局部特写插入后回主 | 回切后主镜实体态 = Insert 前终态 + Insert 已交代的合法变化 |
   | **环境/门槛切换** | 衍生 ENV 名变（§三.3 表） | 服从 §三.8 / §四.9 G；有过程运镜；禁硬切躲 ENV |
   | **Motive Cut / 声桥 / 遮挡交接** | 情绪或信息动机切 | 须写动机锚点（遮挡物/声源/光变）；禁无锚点硬跳 |

   **可剪辑合镜硬门槛（相邻 SH 均须满足）**：
   1. **时空连续**：同 Scene 内默认连续时空；时间跳跃/闪回/蒙太奇怎么拍见 §四.6。
   2. **实体态连续**：本镜画内名单 ≡ 覆盖 Beat 的【建置】开拍集 ∪【入戏】过程主语；持握/穿戴/开合态/门窗态/座姿承托面与上游建置/入戏一致，直至本拍明文演化；**禁止**上游已放下的道具本镜无过程又在手、禁把建置未列主体写成开拍在场。
   3. **轴线与银幕方向**：对戏/走位保持 180° 轴线；银幕左右运动方向跨镜一致；越轴须 §四.9 G 过轴过程或 `MotivatedCross` 依据；**禁止**无声明左右对调、走位方向对倒。
   4. **动作相位可咬**：跨镜动作须 Match on Action 或上镜完整闭环后再切静态结果；**禁止**上镜动作已完成落定、下镜又从同一起手重演（除非上游明文重复动作）；**禁止**因果链（施力→命中→反馈）被无桥接地拆到无法合镜的两镜。
   5. **景别/能量可切**：相邻镜景别各用其覆盖 Beat 的已锁档（跨度以上游 `跨度=` 为准）；运镜能量服从 §四.5（同级或相邻一档；跨 ≥2 档须剧本动机 + Logic 桥接）；**禁止**本层自拟 Wide↔ECU 硬跳、Static 建置↔Bullet Time 无 Ramp。
   6. **落幅为下镜服务**：本镜末按 §三.3B 转出运镜 + 转出其他要求留给下镜可接切点；若下镜多人同框且本镜特写收尾 → 须按 §四.1 三前提 Pull Back **刚好扩到下镜已锁起幅档**（禁无因拉远景）；**正反打链禁止借此回拉**。**禁止**镜末停在无法被下镜 P1 合法咬合的悬空态。
   7. **上镜末↔本镜 P1 画面可切（强制）**：假想把上镜最后 0.5s 与本镜 P1 首 0.5s 首尾相接——景别跨度合法、主拍/焦点可解释、实体态无瞬移、视线/动作相位可续；不合则改本镜 P1 或回改上镜末，**禁止**每镜 P1 无桥接重铺全场 Establishing。

   **禁（检出即改）**：每镜重开 Wide｜P1 与上镜末对不上｜越轴无声明｜动作重演｜ENV 名变无运镜桥｜合镜后未做 §三.3B 分写｜上镜末无转出运镜/转出其他｜下镜 P1 无转入运镜/转入其他｜无锚跨档升 Whip/Crash。Logic 写本镜那一端；Video 只写本镜可切起落幅（禁「承接 SH」字样）。
   - ✅ 上镜末 Video 写出 Soft Pan 落肩 + MCU 持文件；下镜 P1 Video 写出过肩起 + 视线落 Chen；Logic `衔接:Eyeline+OTS｜转入运镜=过肩起｜转入其他=视线落Chen`

7. **运镜过渡选型（强制）**：按服务建置/剧情/情绪择主导过渡，**并回扣覆盖 Beat 的 `-`/`~` 拍型**（§三.4）。`运镜过渡选型:` 必填。`-` 优先短促过程桥或剪辑硬切轮次；`~` 优先 Slow/Soft Push 钉点，禁用 Whip/Crash 当过渡扫脸。
   - **过程运镜桥**：Push/Pull/Pan/Track/Follow/Arc/OTS 过程等——合镜 Beat 边界、ENV 名变、镜内加压**优先**
   - **剪辑硬切**：Shot 边界直接切——须§三.6（Match/Eyeline/OTS 起幅/Motive）；**≠**无锚点跳切；**≠**合镜内 ENV Static 硬切

   | 情境 | 优先 | 禁 |
   | :--- | :--- | :--- |
   | 合镜切角/ENV 名变 | 同主=变化角度+自然过程桥（§四.9 G） | 合镜内 Static 硬切；同主写成换场景 |
   | 跟位移 / 上游已写进出过程 | Follow / 门槛过程落地 | Static 瞬移、删略入戏原文 |
   | 镜内情绪加压 | Soft/Slow Push | 无锚 Crash/Whip |
   | 收束适配下镜 | Pull Back（§四.1 三前提） | 无前提拉远景 |
   | Shot 边界对白轮次/露出幅 | 剪辑硬切 Eyeline/OTS | 每句镜内慢推拖沓 |
   | 动作拆镜中段 | Match on Action | 落定后重演起手 |
   | 情绪砸点/惊吓 | 剪辑硬切（高压须剧情锚+桥） | 合镜内冒充硬切躲 ENV |
   | `-` 交代拍 | 短促 Track/Follow/OTS 硬切轮次 | 全程 Slow Push/升格拖交代 |
   | `~` 精髓拍 | Soft/Slow Push 钉点（景别=已锁档） | Whip/Crash/Handheld 扫脸；另切 CU |
   | 衍生 ENV 名变 | 按 §三.3 表（同主切角=变化角度+自然过渡+该拍建置 / 换主=环境切换+该拍建置 / 闪回胶片 / 门槛） | 合镜内硬切躲 ENV；闪回硬切；同主切角只写「环境切换到」；ENV 名变无该拍【建置】 |

   **平衡（最高）**：服务>花哨；丰富≠炫技（禁全 Static，亦禁每镜高压）；对白默认稳机+剪辑硬切轮次。字段：`主导=过程运镜桥／剪辑硬切／混合｜对上｜对下预留｜Beat内桥｜炫技风险=无`。

8. **跨环境声明（强制）**：合镜内 ENV 名变**同等强制**（§三.3）。Logic：`环境切换运镜:`（须含 `变化性质=`）+ `360度转角继承:`（§六.2；度数/不可见只进 Logic）。Video 口径分叉：ENV 名变一律先写「背景切换到参考图 ENV:[新]」；同主切角另加「同一空间变化观察角度」+自然过渡运镜+ **该 Pn 含该拍【建置】**（§二.7A）；换主/门槛/闪回另加 §四.9 G + **该 Pn 含该拍【建置】**（§二.7A）；仅状态衍生=「背景切换到参考图」+状态过程+ **该 Pn 含该拍【建置】**。Video：运镜名+参考图点名；**禁止**再写画内环境陈设导游。ENV 名变还须该拍【建置】角色/道具落位可检索。**建置可执行性**：对照 ENV 布局核可拍性；冲突→`建置冲突:`+回流，**禁改戏**。
9. **Shot ID 三层编码（强制）**：输出表格每一行须同时正确填写 `Shot ID` 与 `Scene ID`，严格区分并完整继承上游 **分集 → 场景 → 分镜** 层级，禁止省略任一层级或混用非规范编号。
   - **权威来源**：`Episode ID`、`Scene ID` **唯一**取自上游 `# Core Scene Info` / 输入 Scene 表对应行的 `Episode ID`、`Scene ID` 列；**禁止**自造集号/场号、禁止与上游不一致的 EP/SC 前缀。
   - **字母后缀子场（强制原样）**：上游 `Scene ID` 若含字母后缀（如 `EP01_SC01B`、`EP01_SC02A`），`Scene ID` 与 `Shot ID` 的场景段**必须逐字原样输出**，**禁止**剥除字母写成 `EP01_SC01` / `EP01_SC01_SH01`，**禁止**改大小写、重排或自造后缀。
   - **规范格式（零填充，强制）**：
     - **分集**：`EPxx`（如 `EP01`、`EP12`）
     - **场景**：`EPxx_SCyy` 或 `EPxx_SCyy`+字母后缀（如 `EP01_SC01`、`EP01_SC01B`、`EP01_SC02A`；`yy` 为场内序号，**2 位**零填充；字母后缀原样继承上游）
     - **分镜**：`{Scene ID}_SHzz`（如 `EP01_SC02_SH01`、`EP01_SC01B_SH01`、`EP01_SC02_SH12`；`zz` 为场内镜序号，**2 位**零填充）
   - **层级包含关系（强制）**：`Shot ID` **必须**完整包含三级路径；同行 `Scene ID` **必须**等于 `Shot ID` 去掉 `_SHzz`（及可选补镜 `_n`）后的前缀，**逐字一致**（含字母后缀）。❌ `Shot ID=EP01_SC01B_SH01` 但 `Scene ID=EP01_SC01`｜❌ `Shot ID=EP01_SC02_SH01` 但 `Scene ID=EP01_SC01`｜❌ `Shot ID=SH01`｜❌ `Shot ID=SC02_SH01`｜❌ `Shot ID=EP1_SC2_SH3`（未零填充）
   - **场内连续编号（强制）**：同一 `Scene ID`（含字母后缀，整串相等才算同场）下，`SH` 从 `01` 起按**叙事/拆镜顺序**连续递增（`SH01→SH02→…`），**禁止**跳号、重号、倒序、同场重启 `SH01`；一 Beat 拆多镜须占用连续 `SH` 号段。`EP01_SC01` 与 `EP01_SC01B` 为**不同场**，各自从 `SH01` 起编。
   - **表格行序（强制）**：整张 Shot List 行序须按 **分集升序 → 同集内场景升序（含字母后缀按上游场序）→ 同场内分镜升序** 排列；完成当前 `Scene ID` 全部镜头后再进入下一场；**禁止**同表内乱序穿插不同 Scene 的行（除非上游明确要求分场分批输出且每批仍自洽）。
   - **跨场/跨集切换（强制）**：进入新 Scene 时 `Scene ID` 与 `Shot ID` 的场景段**同步切换**（含字母后缀）；`SH` **每场重置**为 `01`，**不得**跨 Scene 延续 `SH` 序号。
   - **补镜/插镜后缀（例外）**：事后插入的分镜可在基础 `{Scene ID}_SHzz` 后追加 `_1`、`_2`…（如 `EP01_SC02_SH03_1`、`EP01_SC01B_SH02_1`）；常规批量生成仍用标准 `SHzz`，**禁止**用 `_1` 替代正常递增编号。
   - **输出前核验（强制）**：逐行检查——① `Shot ID` 匹配正则 `^EP\d{2}_SC\d{2}[A-Za-z]*_SH\d{2}(_\d+)?$`（字母后缀可选；补镜后缀可选）② 同行 `Scene ID`= `Shot ID` 去掉 `_SHzz(_n)?` 后的前缀且与上游逐字一致 ③ 同场 `SH` 连续无重复 ④ 行序符合 EP→SC→SH 叙事序；任一失败须重排或重写 ID 后再输出。

### 四、影视语言

本章 = 怎么拍（不改上游叙事）。锁档只抄；焦距/景深/跟焦/帧率/曝光/灯光须服务本拍剧情与 `scene_mood`。转场/闪回/蒙太奇 = §四.6；词库 = §四.9。

1. **锁档落地**：`景别=` / `镜头角度=` / `关系角=` / `构图=` ≡【建置】/【取景锁定】原文。Logic `取景:` 抄锁档并写 **机位锚**（下条）。Video 用 §七.0 专业词点名锁档，不重列闭集、不另选档、不改落点。缺锁定→`upstream_missing_framing`。合镜逐 Beat 各自锁档写入对应 P；Push/Pull 落幅须回指该拍已锁档。
   - **机位锚（最高；景别+构图 → 镜头站哪）**：每 P 须据该拍已锁 `景别=` + `构图=`/`主体落点=`/`留白=`/`关系角=`/`近侧框主=`/`主拍对象=` 裁定镜头相对**哪一具名实体**、在哪一侧、多远。锚优先=`主拍对象` CHAR｜`近侧框主`｜该拍【建置】可见结构（桌/窗/门，只作站位，不扩写环境）。禁无锚「随便摆机」、禁锚镜后对向件。**AI 优势位例外**：窗外/檐外/对楼可作机位站处（画面仍读 ENV 内主体），须 `变因=` 含 `AI优势位`。
     | 已锁景别 | 机位距锚 |
     | :--- | :--- |
     | `CU`/`ECU` | 贴身（脸/局部/道具） |
     | `MCU` | 一臂（胸肩） |
     | `MS` | 两步（腰/桌面） |
     | `FS` | 三步–五步（全身） |
     | `WS`/`EWS` | 五步远–十步外（空间/群） |

     | 已锁构图 / 关系 | 机位相对锚 |
     | :--- | :--- |
     | `构图=中心` + 落点中央 | 对轴，镜头在主体正前/正侧可读面 |
     | `构图=三分` + 落点画左/画右三分 | 镜头偏落点对侧，主体落该三分 |
     | `留白=视线前` | 镜头在视线反侧，Lead Room 在视线前 |
     | `构图=纵深` | 镜头沿人↔可见锚轴线 |
     | `关系角=过肩` + `近侧框主` | 镜头在框主左或右肩后，距=该景别档 |
     | `关系角=干净` | 镜头对主拍，无框主遮挡 |
     **Logic**：`取景:` 须含 `机位={CHAR:[@…]｜PROP:[…]｜可见结构}{侧}{距}`（合镜有变则 `P1…→Pn`）。**Video**：运镜与动作流须可检索同义句（如「镜头贴 CHAR:[@陆廷泽] 左颊前方」「镜头过 CHAR:[@甲] 右肩后一臂看 CHAR:[@乙]」「镜头在 CHAR:[@林] 右前方两步，主体落画左三分」）。两端须同锚同侧同距。❌只写 MCU 不写镜头相对谁｜❌机位锚与主拍/框主矛盾｜❌为摆机改景别或把窗写进镜后。
     **机位不影响运镜（最高）**：`机位=` 只锁**空间关系**（相对谁、哪一侧、多远），**不锁死镜头、不改运镜选型**。跟拍 / Track / Follow、手持 Handheld、推拉 Push/Pull、环绕 Arc/Orbit、Steadicam 等仍按 §三.1 / §三.4 / §四.5 与节奏档落地。跟拍=机位关系**随主体保持**（仍是「左颊前方贴身」一边跟走）；手持=质感叠在该机位上（微抖/呼吸），不取消锚。❌因写了机位把跟拍/手持改成 Static／Locked Off｜❌因跟拍/手持就不写 `机位=`｜❌机位句写成「钉死不动」除非本拍运镜本就是 Static/Hold。
     **同环境机位变须有因（最高；写入 Logic）**：所属主环境相同（含同主切角 `0度`↔`180度`、同角桶）时，相邻镜或同镜相邻 P 的 `机位=` 锚/侧/距任一变 → Logic `取景:` **必须**写 `变因=` + `上机位=`。因闭集=`反打`｜`切角投影`｜`换主拍`｜`景别档`｜`过肩换框`｜`跟拍走位`｜`进出衬托`｜`卖点加压`｜`AI优势位`（可叠，如 `反打+AI窗外`）。首镜=`变因=首镜`；未变=`变因=承上`。分析只落本条短词，不写「因为所以」散文。❌同环境无因从左颊贴身跳到房间另一侧／窗外｜❌机位变了 `变因=承上` 或缺条｜❌用切角当借口乱换距（无景别档变却 MCU↔EWS 机距）。

**视频帧率节奏（强制 · 按场面抬；高帧率 ≠ 升格）**：打斗/追杀/极限动作镜须在 Logic `节奏需求:帧率=` + `快慢节奏:帧率=` 与 Video **点名 fps**。项目默认 Frame Rate（多为 24）只约束**非打斗**与**升格/对峙**；常速快相可高于项目默认，作为生成端「动作采样更密、运动更利落」的提示，**不**因此提高升格占比、**不**改 Duration 公式。
     | 场面情况 | 帧率 | Video 落点 | 禁 |
     | :--- | :--- | :--- | :--- |
     | 近身连击/缠斗/闪避/弹道快逼近/走廊追逐等**常速快相位**（`-`、档=快） | **60fps**（一般动作可 48；正式决战/暴力美学高压优先 60） | 写 `60fps`/`high frame rate`；动作边缘锐、少拖影；招间更密、手持跟得上 | 快打全程 24fps 发糊发慢；用升格冒充高帧率 |
     | 命中/破防/`~` 砸点/Bullet Time/Time Slice | **24fps 电影帧 + 升格慢放** | 写升格/慢放 + Ramp 入出；可写高拍摄采样但播放变慢 | 升格段写成 60fps 常速快放冲掉砸点 |
     | 对峙起势/夹层对白/收势 | **24fps** | 跟项目默认；不抬帧率 | 对白口型主拍套 60fps 体育转播感 |
     | 打斗美学·飘逸的盘旋/对峙升格感 | **24fps**（可短升格） | 用 Arc/Crane/升格感，不靠高帧率 | 飘逸对峙套 60fps |
     - ✅ 快连击 P：`60fps 高帧率常速，贴身手持跟 CHAR:[@…] 连击，动作边缘锐利无拖影` → 命中 P：`Speed Ramp 入慢，24fps 电影帧升格钉踢中胸` 
     - ❌ `快速打斗` 无 fps｜❌ 命中升格写 `60fps 快放`｜❌ 对峙 OTS 对白也写 60fps

**快相位**：起势连招、闪避、弹道出手→逼近、追逐、域场建规模。运镜：Handheld｜Whip｜Track/Follow｜Crash Zoom（常速）｜Drone 读规模。每链 ≥1 快连击 P（≥2 击具名+攻防匹配，≥1.8s）；禁多击全拆升格、禁单方无反应堆招；**具名连击须继承上游差异化招式，禁同构复制**。机位须跟实体/弹道；禁 Static+Wide 扛高速。单段 1.8–3.6s；快总时长 ≥ 升格×2。**常速快相须抬帧率（上表）**，招间节奏随场面加密，不得用 24fps 电影慢底吃掉连击密度。

**慢相位**（每链 1–2 处）：命中/对撞/爆炸/格挡｜弹道可读节点｜弧顶/触地｜终结技破防（仅 1 处）。运镜：Bullet Time｜Time Slice｜Orbit 绕命中｜CU 读受力。钉住 Beat 轨迹节点；禁空镜慢飞。单段 0.9–2.7s；累计 ≤35%；>3.6s 须拆。

**叙事升格（叠加 · 非打斗亦可）**：认上游节奏/情节；帧率 + 计时差异化见 **§三.1 / §三.5**。打斗链内计入本链占比（仍 ≤40%）；非打斗场不套 30% 配额。

**Speed Ramp**：入慢=接触前末帧/节点可读；出常=读毕→反馈/余波。默认 `常速→升格→出常`；合镜封口后镜用 Match/Whip 衔接。失败：整镜单速｜Z>40%｜无 ≥1.8s 快连击｜无 Ramp｜机位不跟｜慢未钉节点 → 补写 P。

**类型速查**：近身 Handheld/Whip↔Bullet 命中｜弹道 Follow↔Time Slice｜法术 Orbit↔对撞慢｜腾空 Track↔弧顶短慢｜连击多段快+1 处终结升格｜域场 Drone↔波前慢｜载具 Follow↔撞击 Bullet。

**P 段**：快=运镜名+跟拍对象+轨迹向+常速+逐招具名+攻防匹配；慢=升格技法+锁定节点+可读信息；变速=Ramp 方向+落幅。禁「快速打斗/慢动作效果」泛化句。

**Logic 必填**：`快慢节奏:`（各 P=常速|升格|变速+运镜+节点+秒+`帧率=60|48|24`+`升格占比`）｜`快连击链:`（逐招+攻防）｜`升格技法:`（选用+触发+第几处）｜打斗另 `打斗运镜技法:` + `打斗正反覆盖:`；特效另 `特效攻击运镜:`（§四.9 A；法攻须正反两端）。

**反例**：❌ 全程常速无升格｜❌ 整镜 Bullet 拖镜｜❌ Z>40%｜❌ 无快连击/缺招名攻防｜❌ 弹道飞出镜头不动｜❌ 打斗快相不写 48/60fps｜❌ 升格砸点写成 60fps 常速。
- ❌ 升格段实体仍在高速位移，未钉住命中/接触节点。
- ❌ 有 Slow Mo 无 Speed Ramp 出入，硬切速率。
- ✅ P2 **60fps** 常速 Handheld **快连击** 3.2s（**甲：右直拳→左勾→侧踢；乙：架肘格挡→侧身闪避→反刺**，Whip Pan 衔接）→ P3 Speed Ramp 入慢 + **24fps** Bullet Time 读**侧踢**命中 1.4s（**升格占比≈1.4/6.8≈21%**）→ P4 Speed Ramp 出常 **60fps** + 受力反馈 2.2s。

### 五、灯光

1. **场景光影锚定（本层光学唯一口径）**
光色 = 当前衍生 ENV 所对主环境四宫格**同方向格** + `scene_mood`。CHAR/PROP 同场同光，不另起人物专用光。ENV CN `光影体系` 已按定位目标×情绪表达裁定曝光/景深/焦段/三点/光比/色温/柔硬/自然光/实用光——本层**继承实现**，禁另起无锚默认三点暖黄。执行见 §五。
   - **`光影锚定:`**：`方向格=…｜当前衍生ENV=…｜情绪={scene_mood}｜Key/Fill/Rim=方向+色温｜光比=高/中/低｜色温=冷/中/暖/混合｜柔硬=柔/硬/混合｜动机光=1–3`。
   - Video 光向=ENV 几何；Fill=画内反射/Practical；可见动机光 1–3；防悬浮写清色溢出｜接地影｜反射 Fill｜轮廓分离之 3/4。光影只进两光影段。

2. **灯光执行**

**权威 = §五.1**（提取、可见/不可见分流、配额≤3、防悬浮 3/4、实体指称）。本节补**执行清单**：灯光方向 + **光比/色温/柔硬** + 与曝光/跟焦同核。光动**只写**「动态连续光影/焦点」「光线连动弧光」；与建置已写物理微动分写。**禁**借光影改站位/动作/对白。美术锚=本场 ENV CN 四宫格同方向格，不另起无锚光。灯光须**服务剧情节点 + `scene_mood`**（压迫压暗仍保主舞台可读；温煦暖 Fill 托起；悬疑冷 Key + 局部 Practical），并与焦距/曝光同核（硬约束 9）。

1. **动笔顺序**：读 Index `scene_mood` → 读 ENV CN `光影体系`/`色彩体系`（同方向格）→ Logic `光影锚定:` + `摄影综合表达:` + `曝光三角:` → Video 两光影段按 §七.2–§七.3 输出。
2. **面部可读 Fill（真人优先，服从 ENV CN；≠压扁大光比）**：侧向 Key + 半影柔散｜Fill **仅** ENV 已声明反射面反弹或第二画内 Practical，保面部/口型**关键信息可读**（禁无 ENV 锚点美颜补光、禁面部局部 spotlight、禁整室同亮/均匀平光抹平 ENV 大光比）｜Rim 须有 ENV 入射动机（禁硬 rim）｜投影软过渡（禁刀切阴阳脸；恐怖/上游压暗例外）。只写自然眨眼/发丝随动，禁磨皮、禁补 Beat 未写的微表演。
2A. **光比／色温／柔硬（本层实现；锚=ENV CN，写观感不抄比值）**  
从该方向格转译，写入 `光影锚定:` 与两光影段；禁无锚另起灯。**禁**写 `Key:Fill≥8:1` 等数值。
   - **光比**（高/中/低）：高=侧光、亮暗分层深、暗部沉（ENV 大光比/压迫）；中=Key 明确、Fill 托起仍见层次；低=平柔、层次浅（仅 ENV 已写均匀/阴天/散射）。禁无锚平光抹平 ENV 高光比；禁无上游压暗自造剪影。
   - **色温**（冷/中/暖/混合）：写可见冷暖（窗冷/灯暖对照等），须≡该格光线颜色 + `scene_mood`。混合须有两源依据。
   - **柔硬**（柔/硬/混合）：柔=半影软、投影过渡；硬=边缘清晰、小光源直射。须跟 ENV 材质/天气/Practical；禁棚拍硬光无锚。
   - Video 须点名 `Key`/`Fill`/`Rim` + `High/Medium/Low Contrast` + `Cool/Neutral/Warm` + `Soft Light`/`Hard Light` 并接亮暗分层（如 `窗侧 Key, Cool, Hard Light, High Contrast，暗部深；桌面反射 Fill, Soft Light, Medium Contrast`）；禁只写「有光/光很柔」。
3. **独特硬约束**
   - **门外作光源**：须先核销门为开启态；`光影锚定:` 写 `门外光源门态=半开|全开｜核销依据=…`；门紧闭禁门外主动机；门外灯具不可见时只写渗光效果、禁实体名（§五.1）。

   - **照度**：室内/日景默认充足（可见动机光 1–3 + ≥1 反射 Fill）；低照度须上游依据。
