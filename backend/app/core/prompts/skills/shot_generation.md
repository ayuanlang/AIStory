### 二、镜头规划与计算 (Shot Planning & Timing)
1. **拆镜推演**：明确场次 -> 切分分镜 -> **逐镜建立实体出入画物理闭环**（上一镜 `本镜出场实体` → 本镜 `上镜出场实体复核` 逐资产 → 复核后才列 `本镜新入镜资产` → **有出画时写 `出画运镜` 并用 Video 呈现** → 本镜末写 `本镜出场实体`）；**具名角色画内可见性或面部可读性变化**须对应上游 Beat 过渡动作与**出画方式**，一 Beat 拆多镜时出画/入画/转身/反打过程不得删略。
1.5 **ENV 驱动的 Beat-Shot 拆分与合并（强制）**：拆镜粒度以 Beat 的 **ENV** 与 **主环境** 为双轴判据。主环境 = `ENV:[...]` 去除 `{N}度`/状态/正反打等衍生前缀后的登记主体（如 `Office` 之于 `0度Office`/`180度Office_桌后反打`）。**同一主环境内**观察侧/正反打/360 度转角产生的**衍生 ENV 切换**（OTS、反打、换手等）**不属于**「主环境不一致」。

   **同角度环境桶（命名辅助，非拆镜判据）**：对 `ENV:[...]` 名称取**首个** `-`、空格或 `_` 之前的子串为**同角度环境桶键**（无上述分隔符则整名为桶键）。桶键用于识别「同一观察角下的后缀变体」（如 `_桌后反打` / `_乙侧反打`）。例：`ENV:[180度办公室会客区_桌后反打]` 与 `ENV:[180度办公室会客区_乙侧反打]` 桶键均为 `180度办公室会客区`；`ENV:[0度办公室会客区]` 与 `ENV:[180度办公室会客区]` **桶键不同**，但仍属**同一主环境**。**硬约束**：角度桶不同**绝不**构成拆镜或拒并理由——同主环境内 0°/90°/180°/270° 及状态衍生 **一律默认合镜**（见原则 1）。

   **核心归并原则（强制，优先级自上而下）**：
   1. **同一主环境内合并优先（强制 · 不同角度默认合）**：相邻 Beat 只要归属**同一主环境**（含：ENV 逐字相同｜同角度桶仅后缀差异｜**不同观察角度衍生**如 `0度X`↔`90度X`↔`180度X`｜OTS/反打/换手衍生｜状态衍生仍挂同一主环境｜依赖同一主环境的衍生行）→ **默认归入同一 Shot**。
      - 合镜内衍生 ENV / 角度切换时，`Video Content (CN)` **必须**用 §5.5 G 运镜（Pan / Arc Orbit / Reverse Shot / OTS Switch / Whip Pan 等）写出切换过程，**禁止**硬切。
      - **禁止**仅因 Beat 边界、角度桶不同、衍生后缀差异或「非对戏」机械拆镜。
   2. **同主环境对戏呈现（强制，合镜后怎么拍）**：同一主环境内连续**对白往返/打斗/近身攻防/术法对撞**等对戏 → 已按原则 1 合镜后，须在 P 段内用 §5.5 G 运镜切换视角；**禁止**合镜内每个后续 Beat 都另起一段全景 Wide **打断对戏**式重复建置。**澄清（与「每镜必建置」不冲突）**：本条只约束**同一 Shot 内**中途勿机械复写全景；**每一个独立 Shot 的 P1 仍须完整角色建置**（§八.2「每镜必建置」）；若因超时拆分落成**新 Shot**，新镜 P1 **仍须**据上镜终态写全员落位，**不得**以归镜规则为由省略建置。
   2.5 **合镜 Beat 衔接运镜逻辑（强制 · 合镜 N≥2 必填）**：多 Beat 归入同一 Shot 时，`Shot Logic (CN)` **必须**写明相邻 Beat 之间如何用**合理运镜**连贯衔接——不是只写「合镜」，而是写出**可执行的摄影桥**。
      - **`Beat衔接运镜:`（合镜必填）**：按叙事序逐段写出 `Beat{i}→Beat{i+1}: 衔接动机=…｜运镜=…｜景别/能量跨度=…｜ENV/观察侧=保持|切换+手法｜站位底座=承接终态｜剧情依据=…`；N 个 Beat → 写满 **(N−1)** 段桥。
      - **合理运镜优先序**：同轴续推 / Soft Pan / OTS Switch / Reverse Shot / Arc Orbit / Match on Action 相位续写 → 仅当剧情明文需要（惊吓、Reveal、追逐加速、情绪断点）才升 Whip Pan / Crash Zoom 等高压档；**禁止**无剧情动机在 Beat 边界堆高级运镜。
      - **稳定与剧情双约束**：合镜内机位能量服从 §三.4（同档或相邻一档；跨 ≥2 档须剧本触发）；对白加压链优先稳定近景往返（OTS/Reverse），禁为「显得花」在每 Beat 边界无故重开 Wide 或乱甩机；切角/反打须有过程运镜（§5.5 G），禁硬切。
      - **Video 落地**：Logic 写出的每段桥须在对应 P 段可见（运镜名 + 起幅→落幅）；**禁止** Logic 写了衔接、Video 却在 Beat 边界无过程跳切。
      - **单 Beat 未合镜**：写 `Beat衔接运镜: 单Beat无需组内衔接`。
      - **反例**：❌ 合镜 Beat1+2+3 却无 `Beat衔接运镜:`｜❌ 只写「自然过渡」无运镜名与动机｜❌ Beat 边界无动机 Whip+Crash 连甩｜❌ 对白链中途每 Beat 重开 Wide Establishing。
      - **正例**：✅ `Beat衔接运镜: Beat1→Beat2: 动机=对白轮到Chen｜运镜=OTS Switch+Soft Push｜跨度=MCU→MCU｜ENV=0度→180度反打｜站位=承接Beat1终态｜依据=对戏反打｜Beat2→Beat3: 动机=Chen视线落向门｜运镜=Eyeline Pan｜跨度=MCU→MS｜ENV=保持｜站位=承接｜依据=视线引导入画`
   3. **唯一拆分触发 = 超时长或跨主环境**：完成原则 1 归并后，**合镜Duration > 15s（若超出时间在2秒内，则强制压缩成最高分镜时间15秒而不进行拆分）** → 若仍超容差，按「超时拆分建置桥接」拆为多 Shot；**相邻 Beat 主环境不同（且无上下级依赖关系）** → 边界拆 Shot（§二.1.5 跨主环境拆分）。**除此以外禁止拆镜**（含：禁止以角度桶不同拒并）。

   **归并前置核验（原则 1 命中即可归镜；缺信息点则不得归镜）**：
   - **信息点零丢失**（= §一.2 Beat 绝对覆盖）：各 Beat `{行为过程}`/`{结果落位}`/道具/环境交互/位移/微动作/微表情/对白/反馈须**全部**在对应 P 段可检索。

   **合镜时长合并计算（强制，与原则 1 配套）**：
   - 完成原则 1 归并分组后，**须将同组内全部 Beat 的时长合并累计**，再判是否 >15s；**禁止**只对单个 Beat 单独计时而忽略同组其他 Beat 的叙事耗时。
   - **计算步骤（逐项相加，强制）**：① 组内**逐 Beat** 按 §二.4 分别写出完整 `时间预估` 分项——**建置 / 语言 / 动作 / 微表情 / 特效 / 反馈 / 转场·停顿**（该 Beat 凡有对白、动作、微表演、反馈、建置更新、视角切换等**须逐项估时**，无该项写 `0s`，**禁止**整 Beat 只写一个总数或只写「并行核」）；② 各 Beat 内按 §二.4 计算顺序得出 **Beat 小计**（`Beat小计 = 建置 + 语言 + 动作 + 微表情 + 特效 + 反馈 + 转场/停顿`，同相位并行仍取 Max 后计入对应类，但**七类分项须齐**）；③ **合镜累计**：`基准合镜Duration = Σ（组内各 Beat 小计）+ Beat衔接补偿`，**组内 Beat 按叙事先后逐项串行相加**——**每个 Beat 的建置/语言/动作/微表情/特效/反馈/转场均须计入**，**禁止**以 ENV 未变、对戏归镜、建置更新=否 等为由省略后续 Beat 任一分项；④ **Beat衔接补偿（强制）**：合镜组内 **Beat 数 N ≥ 2** 时，`Beat衔接补偿 = (N − 1) × 1s`（每多合并 1 个 Beat **+1s**，补偿 Beat 间节奏留白/切换/承接）；单 Beat 未成组时 **Beat衔接补偿 = 0s**；⑤ 得**基准合镜Duration** 后按 §二.4 **±20% 浮动**取整填表列 Duration（拆分判据仍看基准）。
   - **`时间预估:` 合镜写法（必填）**：`Beat3(建置1s+语言3s+动作2s+微表情1s+反馈1s=9s)+Beat4(建置2s+语言2s+动作1s+微表情1s=6s)+Beat衔接补偿1s=基准合镜Duration=15s｜时长浮动=±20%→可选[12,15]s｜Duration=15`（七类分项须写全，0s 亦标明；**N 个 Beat 合镜须显式写 `Beat衔接补偿(N-1)s`**；浮动钳制 [4,15]）。
   - **`Beat-Shot映射:` 必填（合镜时）**：`合镜Beat=Beat3+Beat4`｜`基准合镜Duration=…s`｜`Duration=…s`｜`分项=Beat3=…s+Beat4=…s`（分项须对应上式逐项相加）；合镜另须填 **`节奏需求:`**（§二.3A）+ **`Beat衔接运镜:`**（原则 2.5）；单 Beat 未成组时写 `单Beat基准T=…s` + `Duration=…s` + 完整七类分项 + `节奏需求:` + `Beat衔接运镜: 单Beat无需组内衔接`。
   - **反例**：❌ Beat3(8s)+Beat4(7s) 同 ENV 归镜却写 `Duration=7s` 仅取末 Beat｜❌ Beat5–Beat8 各 Beat 单独均 ≤15s 但合镜累计 18s 仍强行 1 Shot｜❌ 合镜组 Beat2 有对白/动作却整 Beat 计 0s 或只写并行核｜❌ Beat4 建置更新=是 却少计建置/语言/动作任一项｜❌ 合镜有 Duration 分项却缺 `Beat衔接运镜:` 或只写「连贯」。

   **未继续合并说明（强制，合镜Duration 或 单BeatDuration <= 15s 时必填）**：
   - 本镜 **Duration <= 15s** 且 **存在可与之归镜的相邻 Beat 未并入本镜** 时，`Shot Logic (CN)` **须写** `未继续合并说明:`，阐明**为何未与前一/后一 Beat 继续归镜**；**无相邻可归 Beat**（Scene 末 Beat、已与前镜合至上限等）亦须写明。
   - **合法原因（仅下列；择实填写）**：`合镜累计>15s`（若与下一 Beat 合并将超时，**预估须含 Beat衔接补偿**）｜`跨主环境`｜`Scene首Beat无前一Beat` / `Scene末Beat无后续Beat`｜`已与前镜/后镜合至 §二.1.5 上限`。
   - **非法拒并理由（禁止写入，检出即改归并）**：`ENV角度桶不同`｜`观察角不同`｜`非对戏链`｜`OTS/反打切换`｜`衍生后缀不同`｜「时间跳跃」等非上表项。同主环境内 0°↔90° 等**必须**合镜（合镜 Duration≤15s 时），用运镜表现切角。
   - **反例**：❌ 合镜Duration=8s 且 Beat2 同主环境（即便 0° vs 90°）可归却未并入／或以角度桶不同拒并｜❌ 写「非对戏 / 角度不同」作未合并理由。
   - **正例**：✅ `Beat-Shot映射: 合镜Beat=Beat1+Beat2｜主环境=农家院子｜ENV=0度农家院子→90度农家院子_侧面近景｜合镜Duration=14s` + `Beat衔接运镜: Beat1→Beat2: 动机=侧面关系揭示｜运镜=Pan to New Axis｜跨度=MS→MS｜ENV=0度→90度｜站位=承接｜依据=同场切角`｜✅ `未继续合并说明: 无后续Beat（Scene末Beat）`｜✅ `未继续合并说明: 未与Beat5归镜，原因=与Beat5合镜累计将达18s>15s`｜✅ `未继续合并说明: 未与Beat3归镜，原因=跨主环境（农家院子→厢房内）`。

   **超时拆分建置桥接（强制，触发 = 原则 1 归并后 合镜Duration > 15s）**：
   - **前镜末**：Pull Back **不豁免**，**一律**按 §三.1 三前提（超时拆分**不是**满足依据）；不满足则保持本镜末景别。
   - **后镜 P1**：继承前镜末帧/`本镜出场实体` 重新建置；前镜末若保持近景则可自近景续拍（禁为正反打「补建置」另做 Pull Back）；落幅景别以前镜末实际档为准，**非**默认 Wide。
   - **组内拆分**：按 Beat/叙事断点切分，信息点零丢失；相邻子 Shot「前镜按三前提落幅 → 后镜继承该末帧」。
   - **Logic 必填** `超时拆分建置桥接:`（前镜末落幅｜继承出场实体｜后镜 P1 起幅｜Pull Back前提=满足|不满足+缺项）。

   **反例**：❌ 同主环境连续 Beat（含不同角度衍生）机械拆镜重复建置｜❌ 以 `ENV角度桶不同` 拒并同主环境相邻 Beat｜❌ 合镜 >15s 仍 1 Shot 删内容｜❌ `Pull Back前提=满足` 依据=超时拆分建置桥接，但 `下镜多人出镜=否` 或属正反打仍回 Two Shot

   **跨主环境拆分（强制，独立于超时长）**：相邻 Beat **主环境不同**（如 `Office`→`Corridor`）→ **默认拆成不同 Shot**，在主环境边界切镜；**禁止**跨主环境 Beat 塞入同一 Shot 内部硬切（连续跟拍穿越两主环境走 §5.5 G「门槛/通道穿越」，仍计独立切换耗时）。

   **判定顺序（强制）**：① 扫描相邻 Beat → **原则 1 按主环境归镜**（不同角度默认合）→ ② 原则 2 约束对戏合镜内的运镜呈现（非拒并门闩）→ ③ **各归镜组内逐 Beat 七类分项估算 + 逐项相加得合镜Duration** → ④ **合镜Duration ≤15s → 该组 1 Shot** + **`未继续合并说明:`**（<=15s 时必填；禁角度桶拒并）→ ⑤ **合镜Duration >15s** 超时拆分 → ⑥ 跨主环境边界拆 Shot。`Beat-Shot映射:` 须含合镜累计 Duration、分项、**`未继续合并说明:`**（适用时）。

1.6 **单 Beat / 合镜组归镜（强制）**：§二.1.5 归并后 **合镜Duration ≤15s → 1 Shot**；**唯一拆分** = 合镜 >15s｜跨主环境。`Beat-Shot映射:` + `<=15s 时 `未继续合并说明:`** 必填。

2. **场景抓力与重点表现**：
   - **首场首镜抓力**：全剧首镜用压迫/冲击构图承接抓力结构，并在 `Shot Logic (CN)` 写明抓取逻辑。  
   - **重要场景表现**：关键/情绪爆发节点须二选一（或同镜 P 段对照）——**EWS/Wide**（环境压迫感）｜**CU/ECU/Insert**（核心道具/微表情）；镜末扩框仍服从 §三.1 三前提。
3. **每个新 Scene 首镜摄影（内容序=Stage 1；本层写运镜）**：上游首 Beat 已定「吸睛→建置→入戏」；本镜用运镜实现——吸睛 P 段继承上游 **≥1 环境物理动势 + ≥1 实体动势**（§七.7；Logic：`吸睛动势:`）；宏观/EWS 吸睛后须 **≥1 特写陪衬 P 段** 再入戏（Logic：`宏观→入戏过渡:`）；远距/延迟全局建置优先 Drone/Crane/Bird's-Eye 补全（Logic：`全局建置补全:`）。禁静态空 Establishing。**禁止另起独立 Shot 只写开场/OT-/吸睛**——`开场转场技巧说明` / OT- / 吸睛动势 **必须**落在覆盖 **Beat 1** 的那一镜的 **P 段内**（通常为该镜 P1），并写入该行 `Beat-Shot映射`；**禁止**在 Beat 1 映射镜之前多输出一行无 Beat 映射的「首镜/Establishing」。
3A. **节奏需求分析（每镜强制 · 先于估时与运镜选型）**：动笔每镜前须据上游 Beat 剧情判定本镜**快/中/慢**节奏档，写入 `Shot Logic (CN)`，并落到运镜能量与 Video P 段机位质感——**禁止**全场默认中速稳机、也禁止慢戏乱甩高压运镜。
   - **`节奏需求:`（每镜必填）**：`档位=快|中|慢｜依据=上游Beat要素（打斗/追杀/对峙静默/常规对白等）｜运镜策略=…｜手持感=强化|轻|无｜与上下镜能量跨度=…`。合镜多 Beat 时按**主导节奏**定档（打斗/追杀等高压优先于对白中速），并注明组内节奏起伏（如 `主导=快｜组内=中→快`）。
   - **档位判据（择实，须能指回上游）**：
     | 档位 | 典型上游触发 | 运镜/机位质感（本层落地） |
     | :--- | :--- | :--- |
     | **快** | 打斗/缠斗/连击、追杀/追逐/穿梭、惊逃、爆炸冲击、紧急夺物/夺路、高压动作链 | 主相位**加强手持感**——`Handheld` 贴身跟、微抖/跟身呼吸、短促 Whip/Track/Follow/Crash；景别偏 MCU→CU；禁 Static+Wide 扛快戏；快慢交替仍服从 §5.4.1（升格钉命中，非常速全程） |
     | **中** | 常规对白往返、走位交接、信息传递、轻度冲突 | 稳机为主（Steadicam/Soft Push/OTS/Reverse）；能量档②–③；手持感=无或轻（仅走位跟拍时轻 Handheld） |
     | **慢** | 对峙静默、情绪沉淀、空镜氛围、仪式/凝视、悲伤停顿、信息落点插帧 | Soft Push / Slow Dolly / Static Hold / 微呼吸；拉长落点停顿；禁无因 Whip/Crash/Bullet；手持感=无（除非上游明文惊醒切入） |
   - **快节奏手持强化（强制）**：档位=快 时，常速主相位 Video **须显式写出** Handheld 手持质感（如「贴身手持跟拍、轻微呼吸式晃动、镜头贴攻击轴」）；Logic `手持感=强化`；升格命中相位可暂稳钉点，出常后恢复手持跟。**禁止**快戏只用稳轨/航拍/Static 冒充紧张感。
   - **节奏→能量档咬合**：快→优先能量④（Handheld/Whip/Crash/Speed Ramp），命中短插可⑤；中→②–③；慢→①–②。跨档仍服从 §三.4；`运镜递进与组合` / `运镜选用依据` 须能回扣本镜 `节奏需求`。
   - **反例**：❌ 打斗镜无 `节奏需求` 或档位写中却 Static+Wide｜❌ 快节奏无 Handheld/手持感描述｜❌ 情绪慢镜无因连甩 Whip+Crash｜❌ 全场抄同一节奏句不据 Beat 判别。
   - **正例**：✅ `节奏需求: 档位=快｜依据=Beat3近身连击+Beat4追杀起跑｜运镜策略=常速Handheld快连击→Speed Ramp→Bullet命中→出常Handheld跟逃｜手持感=强化｜能量跨度=上镜③→本镜④`｜✅ `节奏需求: 档位=慢｜依据=对峙静默落泪｜运镜策略=MCU Static微呼吸+Slow Push｜手持感=无`。
4. **时长推演公式 (强制 4s-15s)**：
   - **基础计时单位**：所有时间预估必须拆成可核对类型，写入 `Shot Logic (CN)`：`时间预估: 建置Xs + 语言Xs + 动作Xs + 微表情Xs + 特效Xs + 反馈Xs + 转场/停顿Xs = 串行Ys；并行核=Max(...)Xs；基准T=Ts；时长浮动=±20%→可选[A,B]s｜Duration=Zs｜浮动理由=…。` 无该类型写 `0s`，不得只写总秒数。
   - **计算顺序（强制，防重复计时）**：① 先完成 §二.3A `节奏需求`；② 再按下列规则分别估算各类型耗时，写出分项；③ 同相位并行的对白/动作/微表情/特效/运镜，只取 `Max(语言, 动作, 微表情, 特效, 运镜)` 作为**并行核**，**禁止**把已并行项再次全额串行相加；④ 仅对**必须串行**的段落追加：建置（首段或建置更新=是）、转场桥接、结果落位定格、强悬念插帧、独占反应镜/插帧；⑤ 得**基准 T** 后按 **±20% 浮动**取整填 `Duration`（见下条「时长 ±20% 浮动」）。
   - **语言耗时（分语种估算，强制）**：先读本句台词正文与上游「用{语种|方言}说道」标签（若有），再据 `# Project Context` 的 `Language`/`project_language` 判定估时公式；**禁止**把英文台词按中文字数公式估算（亦禁反向）；**禁止**先把小语种/方言译成中文/英文再估时。`时间预估:` 语言分项须标注语种/方言与算式（如 `语言3s(中文15字/5)` / `语言4s(英文10词/2.5)` / `语言2s(粤语4字/5)` / `语言2s(日语6字/5)`）。
     - **中文**（含标准普通话旁白/OS/V.O./自白；**无**方言标签时）：`中文字数 / 5` 秒；短句保底 1.5s；**≥20 字**长句先拆短句，各短句分别计时并加 0.3–0.8s 呼吸停顿。
     - **英文**（含 English narration/OS/V.O./monologue）：`英文单词数 / 2.5` 秒；短句保底 1.5s；**≥10 词**长句先拆短句/从句，各段分别计时并加 0.3–0.8s 呼吸停顿；缩写/连写（I'm、don't、gonna）按 **1 词**计。
     - **方言**（粤语/四川话/东北话/闽南语/上海话等，上游已标「用{方言}说道」）：书面以汉字为主时按 **汉字字数 / 5**；须在分项写明方言名；**禁止**按普通话语感改写后再估时。
     - **其他小语种**（日语/韩语/法语/西班牙语等非中非英）：按原文**书写单元**估时——汉字/假名/谚文音节块等合计字符近似 `/ 5`，拉丁字母小语种近似按 **词数 / 2.5**；短句保底 1.5s；分项须写明语种名。
     - **多语种/方言混句**：按各片段分别估时后相加（中文/方言汉字走字数/5，英文/拉丁小语种走词数/2.5，其他小语种走上条），再加句内呼吸停顿。
     - **须读上游 `rhythm`/`stress`/`pause` 微调**——`pause` 显式长停/换气/破折号或省略号截断 +0.5–2s；`rhythm=一字一顿/一字慢读/staccato/slow burn` 等须相应拉长或压缩语言段；`stress` 重读词处可 +0.2–0.5s 微表演相位；口型可见的对白不得压缩到低于语言耗时。
   - **音效耗时（强制，有则计）**：上游尖括号 `<…>` 可听音效——短促一声（门轴/撞击/狗吠切入）**0.5–1.5s**；持续环境声桥/雨打窗/远处犬吠铺垫 **1–3s**；与对白/动作同相位时并入并行核取 Max，独占声先入/声桥相位才全额计入 `转场/停顿Xs` 或并入动作核；`时间预估:` 有音效时须写 `音效Xs` 或并入已标明的并行核（如 `并行核=Max(语言3s,音效1s)=3s`）。**禁止**因「品质收束含无背景音乐」而删上游剧情音效（「无背景音乐」≠无画内/画外剧情音效）。
   - **建置/运镜耗时**：新场景空间建置1-3s；关键角色/道具首次落位每组0.5-1s；焦点转移/Rack Focus 0.5-1.5s；短程推拉摇移1-2s；复杂关系重建或OTS反打建轴2-3s；**视角/反打切换过程**（§5.5 G）**1.5–3s**，计入对应 P 段或 `转场/停顿Xs`；**§二.1.5 超时拆分**仅当 §三.1 三前提满足时前镜回建置才计 2–3s，否则镜末保持近景不计 Pull Back；后镜 P1 继承末帧 1–2s；高速追逐/打斗/景别切换运镜与动作同相位并入并行核取 Max。运镜与对白/动作同相位时并入并行核取 Max，不得全额另计。
   - **动作耗时**：常态短发力1-2s；递交/转身/落座/起身/后退等单步动作1.5-3s；复杂交互、拉扯、攻击、防御、避障3-5s；长距离或多障碍动作用同镜 P 段简化落点呈现，**Duration > 15s 时**按 §二.1.5 超时拆分。
   - **追杀/穿梭节点耗时（强制，§5.5 D / Stage 1 §31）**：凡本镜含追杀/追逐/追逃/走廊·巷道·楼宇穿梭/门槛连续奔逃/载具追逐等连续位移动量，须按**路径节点**估时——绕障/跃槛/急转/抓扶 **2–3s**；长直段加速跟跑 **3–4s**；门槛/通道穿越 **2–4s**；载具超车/变道 **3–4s**；多节点同镜内**串行累加**计入 `动作Xs`（**禁止**用单次 Max 抹掉节点时长）。同链跨多 Shot 时各镜动作分项之和须覆盖上游整链等效（**≥20s**）。Video 明示秒数须与本分项一致（§5.5 D）。
   - **微表情耗时标准化**：微表情必须按 `前置反应 -> 中段变化 -> 落点结景` 计时；单点微表情0.5-1s；完整三段链1.5-3s；落泪/强忍/心虚/怒意升级等渐变链2-4s；与对白/动作同相位时并入并行核取 Max，独占画面相位才单独计时。
   - **听者反馈耗时**：单个听者即时反应0.5-1s；两人以上反应镜1-2s；群演统一反馈1s；群演随机反馈或空间避让1.5-2.5s。反应已写入 `(Pn)` 听者段且与对白同相位时，并入并行核，不另计；Beat 强制要求独立反应镜或插帧时才全额计入。
   - **特效耗时标准化**：特效按 `触发源 -> 显形/扩散 -> 命中/作用 -> 维持/碰撞 -> 余波/残留` 分相计时；轻量视觉反馈1-2s；单段法术/能量/技术效果3-5s；对抗型特效5-8s；大范围环境影响8-12s；**宏大特效（Stage 1 §8）主相位 ≥8s、对抗/对撞 ≥10s**，须按六相**分项**写出可核销秒数（禁单行「特效8s」无分相）；与动作咬合取 `Max(动作相位, 特效相位)+余波`，不得把特效折叠成一个泛化动作。分相秒数须有对应 Video **变化细节**支撑，禁空标时长。
   - **升格/慢镜耗时**：Slow Motion / Bullet Time / Speed Ramp 等升格相位单独计入 `特效Xs` 或 `运镜Xs`（按主导项）；单段 Bullet Time 或环绕定格 2-4s；局部慢动作 1-3s；Speed Ramp 含入出常速各 0.3-0.5s；与击打/爆炸/法术命中同相位时并入并行核取 Max，独占升格镜全额计入。
   - **打斗/特效快慢节奏计时（强制）**：硬口径与分项秒数见 **§5.4.1**（升格≈30%/25–35%，>40% 砍；常速≥50%；`升格占比≈Xs/Ys=Z%`）。`时间预估` 须另写 `快慢节奏:`——常速/升格/Speed Ramp **分项串行**，禁用单次 Max 抹平快慢；多 P 段快慢交替各段并行核**相加**。
   - **情绪停顿/插帧耗时**：道具特写、人物局部特写、环境细节插帧1-2s；强悬念停顿或信息落点1.5-3s；**无情节回忆切片** 0.5–2s，计入 `转场/停顿Xs`（§三.6），与触发/回切同相位并入并行核；只服务节奏，不得无因延时；嵌入主节拍间隙的插帧不重复全额计时。
   - **总耗时计算**：`T = 建置串行 + Σ各段并行核 + 独占反馈 + 独占插帧/停顿 + 转场桥接`；单段并行核 = `Max(语言, 动作, 微表情, 特效, 运镜)`；多 P 段同镜内各段并行核**相加**（段间切换即节奏，不每段重复全额建置）；多主体同时动作用主动作计时，辅助反应按0.3-1.5s补足（已与对白并行则并入 Max）。
   - **合镜多 Beat 累计（强制）**：公式与写法**仅见 §二.1.5**（七类分项逐 Beat 相加 + `(N−1)×1s`）；此处估时后须回填同一套 `时间预估:` / `Beat-Shot映射:`；合镜同样先得**基准合镜Duration**，再允许 ±20% 浮动填表。
   - **时长 ±20% 浮动（强制允许）**：分项公式得出**基准 T**（合镜=基准合镜Duration）后，表列 `Duration (s)` 可在区间 `[round(T×0.8), round(T×1.2)]` 内取**正整数**，并钳制在 **[4, 15]**。`Shot Logic` 须写清：`基准T=…s｜时长浮动=±20%→可选[A,B]s｜Duration=Zs｜浮动理由=…`（理由须扣节奏——快节奏可略压秒强化密度；慢节奏可略放秒留白/呼吸；口型可读不得压穿语言耗时下限）。
     - **浮动服务节奏，不改内容**：上浮≠灌水空镜；下浮≠删对白/动作/步骤（§一.2 / §0.2A）；口型可见对白的语言耗时为硬下限，下浮不得使其不可读。
     - **拆分/合镜判据用基准**：`基准 T > 15`（或超出后仍无法压入 15 的 §二.1.5 容差）→ **仍须超时拆分**；**禁止**用「浮动后 ≤15」回避拆分。合镜是否继续归并，亦以**基准累计**对照 15s，不以浮动后数字拒并/强并。
     - **正例**：✅ `基准T=10s｜时长浮动=±20%→可选[8,12]s｜Duration=9｜浮动理由=快节奏略压密度`｜✅ `基准T=12s｜可选[10,14]s｜Duration=14｜浮动理由=慢节奏落泪留白`。
     - **反例**：❌ 基准 17s 写 Duration=14 并声称浮动合规｜❌ 下浮删半句对白或跳过操作链｜❌ 只写 Duration 无基准T/浮动区间。
   - **调平硬规则**：先得基准 T → 再在 ±20% 浮动带内取整数秒填 Duration；浮动后仍须落在 [4, 15]；基准低于 4s 先补足建置/反应/落点停顿再浮动；**基准**高于 15s 按 §二.1.5/§二.1.6 超时拆分；**禁止**通过删除/概括上游内容来降时长（§一.2）。
5. **切镜客观连续性（Video 写法）**：`Video Content (CN)` **只写本镜画面内可见的最终状态与变化**，禁写“承接上一镜/上镜/前镜/上一 Beat/previous shot”及“同上一镜/延续上一镜/承接 Beat”等代指或承接说明；Beat 衔接、前接判定、变更依据、可剪辑合镜推演**只写** `Shot Logic (CN)`，画面以内化描写直接呈现当前实体落位与空间关系（字段见下条）。
6. **分镜间衔接逻辑 · 可剪辑合镜（最高硬约束）**：相邻 Shot 须设计为**可在剪辑台上直接合镜**——上镜末帧与本镜起幅在时空、轴线、视线、动作相位、实体态上**可咬合**；`Shot Logic (CN)` **每镜必填**衔接推演，且须写清**运镜衔接逻辑**（用什么技巧接、为何稳定、如何服务剧情）；**禁止**出现合不上、跳接穿帮、轴线/朝向矛盾、动作相位错位、无动机乱甩机等**不合合镜逻辑**的设计。

   **运镜技巧 × 稳定 × 剧情（强制 · 分镜间）**：分镜衔接须同时满足三点——① **合理使用运镜技巧**（Match / Eyeline / OTS / 同轴续拍 / 门槛切换等，择实填写，禁空标签）；② **保持运镜稳定**（相邻镜能量同档或相邻一档，§三.4；对白/关系戏默认稳机近景往返，禁为花哨跨镜乱升档）；③ **符合剧情需要**（切点动机须能指回上游动作/对白/视线/ENV 切换/情绪落点，禁无剧情锚的炫技切）。高压运镜（Whip / Crash / Bullet Time 等）仅当剧情明文触发，且须有 Speed Ramp / Soft 过渡桥接上下镜。

   **上镜末 → 本镜起 双向咬合（强制 · SH02+）**：因各镜视频**独立生成、无跨镜记忆**，衔接不能只写 Logic 标签——须让**上镜末帧画面**与**本镜 P1 首帧画面**在剪辑点上对得上。动笔每镜（含写完上镜后再回改上镜末段）时强制：
   1. **先读上镜结尾**：从上镜 `收束落幅判定` / `下镜预留` / 终段 P / `本镜出场实体` 提取切点快照——景别档｜机位能量｜主拍 CHAR｜全员终态（落位/朝向/姿态/持握）｜视线或动作相位｜ENV｜轴线与银幕方向。
   2. **再写本镜 P1**：起幅须是该快照的**合法下一帧**（同轴续拍 / Match 续相位 / 反打起幅 / 门槛切换起幅等），实体态与上镜末**零跳变**（直至本镜明文演化）；景别优先同级或相邻一档，跨 ≥2 档须有剧本动机 + Logic 桥接。
   3. **回写上镜预留**：写本镜前确认上镜 `下镜预留` / `收束落幅判定` 已为本镜起幅留好切点；若本镜起幅变更，**必须同步改上镜末段**使两端仍咬合——禁止只改一侧。
   4. **Video 内化呈现**：P1 **直接写出**与上镜末可切的画面结果（禁「承接上镜」字样）；读者仅看本镜 P1 也应感到从上一切点自然接上，而非每镜重启 Wide Establishing（除非 Scene 首镜或跨主环境合法重建）。

   **字段（`Shot Logic (CN)` 强制）**：
   - **`前接说明:`**（SH02+ 必填；Scene 首镜写 `前接说明: Scene首镜无上一镜`）——上镜 `Shot ID`｜上镜末景别/机位能量｜上镜末主拍实体与终态（落位/朝向/姿态/持握/视线或动作相位）｜本镜 P1 起幅如何咬合该终态（须具体到景别档+主拍+实体态，禁空写「承接」）。
   - **`分镜衔接:`**（每镜必填，含 Scene 首镜对下一镜的预留）——`衔接类型=`（下表择 1–2）｜`切点相位=`（上镜末动作/对白/视线落在哪一瞬）｜`本镜起幅咬合=`（Match 锚点 / 同轴续拍 / 反打起幅 / 环境切换起幅等）｜`运镜逻辑=`（本镜相对上镜用何运镜/景别策略完成衔接 + **为何稳定** + **剧情依据**；禁只写类型名）｜`轴线=`（保持｜合法过轴+依据｜新场重建）｜`银幕方向=`（保持｜动机改向+依据）｜`能量跨度=`（上镜末档→本镜起档；跨 ≥2 档须写剧本触发）｜`下镜预留=`（本镜末为下镜准备的落幅/锚点：**景别档+主拍实体+切点相位+建议衔接运镜**，Scene 末镜写无）。
   - **`可剪辑合镜核销:`**（SH02+ 必填）——`时空连续=是|否`｜`实体态连续=是|否`｜`轴线/银幕方向=是|否`｜`动作相位可咬=是|否`｜`上镜末↔本镜P1画面可切=是|否`｜`运镜稳定合规=是|否`｜`剧情动机可核销=是|否`｜`不合逻辑项=无|…`；任一项为否且无合法例外依据 → **须改设计后再输出**（含回改上镜末段）。
   - 另须保留：时空关系摘要、桥接依据、跨幅级别（景别跨度）；含对白收束时另写 `收束落幅判定`（§三.1）；**每个新 Scene 的首镜**必写 `开场转场技巧说明`（见 §二.3、§十一候选库），禁“无过渡/None”。

   **合法衔接类型（择实，禁空写）**：
   | 类型 | 何时用 | 咬合硬门槛 |
   | :--- | :--- | :--- |
   | **同轴续拍 / Reframe** | 同主环境、同观察侧、人数/景别微调 | 本镜 P1 起幅 = 上镜末同轴画面的合法延续或相邻一档景别；实体态零跳变 |
   | **Match on Action（动作 Match）** | 跨镜拆开同一连续动作 | 上镜末停在动作**未完成中段**；本镜起幅自**同一动作后续相位**续写；禁上镜已落定再本镜重演起手 |
   | **Eyeline Match（视线 Match）** | 看→被看 / 反应镜 | 上镜末视线方向与本镜被看对象/空间方位**可核销**；禁视线落空或反向无动机 |
   | **Shot-Reverse / OTS 切换** | 对白往返、对戏反打 | 轴线声明清晰；OTS 四要素齐（§七.6）；禁无过轴声明的越轴跳切 |
   | **Graphic Match（图形 Match）** | 构图/形状/色块桥接 | Logic 写明上下镜图形锚点；Video 各自写清可见锚点画面 |
   | **Insert ↔ 主镜回切** | 道具/局部特写插入后回主 | 回切后主镜实体态 = Insert 前终态 + Insert 已交代的合法变化 |
   | **环境/门槛切换** | 跨主环境或 §5.5 G 切换 | 服从 §二.7；有过程运镜；禁硬切换场 |
   | **Motive Cut / 声桥 / 遮挡交接** | 情绪或信息动机切 | 须写动机锚点（遮挡物/声源/光变）；禁无锚点硬跳 |

   **可剪辑合镜硬门槛（相邻 SH 均须满足）**：
   1. **时空连续**：同 Scene 内默认连续时空；时间跳跃/闪回须走 §三.6 并在 Logic 标明，**禁止**无声明时空跳切。
   2. **实体态连续**：上镜 `本镜出场实体` → 本镜 `上镜出场实体复核` 逐项咬合；持握/穿戴/开合态/门窗态/座姿承托面与上镜末一致，直至本镜明文演化；**禁止**上镜已放下的道具本镜无过程又在手、上镜已出画角色本镜无入画运镜突然在场。
   3. **轴线与银幕方向**：对戏/走位保持 180° 轴线；银幕左右运动方向跨镜一致；越轴须 §5.5 G 过轴过程或 `MotivatedCross` 依据；**禁止**无声明左右对调、走位方向对倒。
   4. **动作相位可咬**：跨镜动作须 Match on Action 或上镜完整闭环后再切静态结果；**禁止**上镜动作已完成落定、下镜又从同一起手重演（除非上游明文重复动作）；**禁止**因果链（施力→命中→反馈）被无桥接地拆到无法合镜的两镜。
   5. **景别/能量可切**：相邻镜景别与运镜能量跨度服从 §三.1 / §三.4（同级或相邻一档；跨 ≥2 档须剧本动机 + Logic 桥接）；**禁止**无动机 Wide↔ECU 硬跳、Static 建置↔Bullet Time 无 Ramp。
   6. **落幅为下镜服务（含无跨镜记忆）**：本镜末按 `收束落幅判定` / `下镜预留` 留给下镜可接切点（近景续对白链、动作中段、视线锚、门槛起幅等）；因各镜视频独立生成无记忆，若下镜同主环境多人同框且本镜特写收尾 → 须按 §三.1 三前提 Pull Back **刚好扩到下镜起幅景别**（禁无因拉远景/全景）；**正反打链禁止借此回拉**。**禁止**镜末停在无法被下镜 P1 合法咬合的悬空态（动作半截无 Match、全员已出画却下镜仍同场无入画、特写收尾却切到同场多人关系镜而无本镜适度扩框等——有明文例外须写依据）。
   7. **上镜末↔本镜 P1 画面可切（强制）**：假想把上镜最后 0.5s 与本镜 P1 首 0.5s 首尾相接——景别跨度合法、主拍/焦点可解释、实体态无瞬移、视线/动作相位可续；不合则改本镜 P1 或回改上镜末，**禁止**每镜 P1 无桥接重铺全场 Establishing。

   **不合合镜逻辑的设计（禁止，检出即改）**：
   - ❌ 上镜末 MCU 对白未完结落幅，下镜无桥接却 Wide 全场重铺且角色姿态/持握与上镜矛盾
   - ❌ SH02+ 的 P1 无视上镜 `下镜预留`，每镜重新 Wide 建置「开场」
   - ❌ 上镜末已预留 MCU 续对白，本镜 P1 却从无关 Insert/另一边全景起，无 Match/声桥
   - ❌ 正反打越轴且无过轴声明/无 OTS 四要素，左右站位对调无法合镜
   - ❌ 上镜拳已命中并反馈完，下镜又从挥拳起手重演同一击
   - ❌ 上镜角色出画完成，下镜无入画运镜却已在场交谈
   - ❌ 上镜视线看画右门，下镜被看对象却在银幕逻辑上的画左且无转场说明
   - ❌ 跨主环境硬切无门槛/Match/声桥过程
   - ❌ 仅写「切下一镜」而无 `分镜衔接` 类型与咬合锚点
   - ❌ Logic 写了衔接类型，但 Video P1 画面与上镜末终态对不上（只核销不落地）
   - ❌ `分镜衔接` 缺 `运镜逻辑=`，或只写「技巧切换」无稳定说明/剧情依据
   - ❌ 对白稳镜链中途无剧情触发跨镜跳升 Whip/Crash/Bullet Time
   - ❌ 为炫技每镜重开 Establishing 或无动机跨 ≥2 能量档

   **正例摘要**：✅ `前接说明: SH01末=MCU Lin口型落点+持文件｜分镜衔接: 类型=Eyeline Match+OTS Switch｜切点=Lin视线落向Chen｜本镜起幅=过Lin右肩OTS看Chen｜运镜逻辑=稳机OTS反打续对白加压、能量②→②、依据=对戏轮次｜轴线=保持｜能量跨度=②→②｜可剪辑合镜核销: 全是｜上镜末↔本镜P1画面可切=是｜运镜稳定合规=是｜剧情动机可核销=是`｜✅ `分镜衔接: 类型=Match on Action｜切点=SH02末右直拳出至半途｜本镜起幅=同拳后半程命中+Chen架肘｜运镜逻辑=动作相位续拍跟拳轨迹、能量③→③、依据=命中反馈｜银幕方向=保持`｜✅ `分镜衔接: 类型=同轴续拍｜切点=SH03末MCU对白句末｜本镜起幅=同MCU档续听者反应｜运镜逻辑=同轴稳机续听、禁重开Wide｜下镜预留=保持MCU+OTS给SH05正反打`

   **与 Video 分工**：衔接类型、咬合判定、轴线/核销**只写 Logic**；Video 把咬合结果写成**本镜可见起幅画面**（禁写「承接 SH01」字样）——P1 首句即落在可切景别与实体态上。
7. **跨环境声明（强制）**：环境切换时 `Shot Logic (CN)` 与 `Video Content (CN)` 均须写“切换到 ENV:[...]”、物理桥接与**空间重建**；并须**显式写出环境切换运镜手法**（从 §5.5 G 择 1–2 项），禁无运镜硬切。`Shot Logic (CN)` 必填 `环境切换运镜:`（触发类型+选用项+桥接依据）+ **`360度转角继承:`**（§七.6，衍生 ENV 时；度数/不可见 Delta **只写 Logic**）；`Video Content (CN)` P 段须写出机位运动过程（**运镜名**如 Arc Orbit / Reverse / OTS + **画内可见** BG 更替），与 ENV 切换同相位；**禁**粘贴 `empty_view_delta`/`angle_mapping`/【Beat切换说明】字段，**禁**写回转度数（如「顺时针回转 180 度」）、**禁**写「不可见/机位后方…」类句。**环境切换建置可执行性（强制）**：重建 FG/MG/BG 后须对照当前 `ENV:[...]` 固定结构/家具布局与空镜差异，核验实体落位与本镜动作/走位/接触/视线是否可拍可行；与 ENV 实体安排冲突时 **禁止**改写 Beat 动作/落位/朝向/姿势——`Shot Logic` 标 `建置冲突:` + `{覆盖核销}` 上游缺口回流，Video 仍按 Beat 明文转写可见面；禁止为「可执行」擅自挪人改戏。
8. **分镜序号三层编码（强制）**：输出表格每一行须同时正确填写 `Shot ID` 与 `Scene ID`，严格区分并完整继承上游 **分集 → 场景 → 分镜** 层级，禁止省略任一层级或混用非规范编号。
   - **权威来源**：`Episode ID`、`Scene ID` **唯一**取自上游 `# Core Scene Info` / 输入 Scene 表对应行的 `Episode ID`、`Scene ID` 列；**禁止**自造集号/场号、禁止与上游不一致的 EP/SC 前缀。
   - **字母后缀子场（强制原样）**：上游 `Scene ID` 若含字母后缀（如 `EP01_SC01B`、`EP01_SC02A`），`Scene ID` 与 `Shot ID` 的场景段**必须逐字原样输出**，**禁止**剥除字母写成 `EP01_SC01` / `EP01_SC01_SH01`，**禁止**改大小写、重排或自造后缀。
   - **规范格式（零填充，强制）**：
     - **分集**：`EPxx`（如 `EP01`、`EP12`）
     - **场景**：`EPxx_SCyy` 或 `EPxx_SCyy`+字母后缀（如 `EP01_SC01`、`EP01_SC01B`、`EP01_SC02A`；`yy` 为场内序号，**2 位**零填充；字母后缀原样继承上游）
     - **分镜**：`{Scene ID}_SHzz`（如 `EP01_SC02_SH01`、`EP01_SC01B_SH01`、`EP01_SC02_SH12`；`zz` 为场内镜序号，**2 位**零填充）
   - **层级包含关系（强制）**：`Shot ID` **必须**完整包含三级路径；同行 `Scene ID` **必须**等于 `Shot ID` 去掉 `_SHzz`（及可选补镜 `_n`）后的前缀，**逐字一致**（含字母后缀）。❌ `Shot ID=EP01_SC01B_SH01` 但 `Scene ID=EP01_SC01`｜❌ `Shot ID=EP01_SC02_SH01` 但 `Scene ID=EP01_SC01`｜❌ `Shot ID=SH01`｜❌ `Shot ID=SC02_SH01`｜❌ `Shot ID=EP1_SC2_SH3`（未零填充）
   - **场内连续编号（强制）**：同一 `Scene ID`（含字母后缀，整串相等才算同场）下，`SH` 从 `01` 起按**叙事/拆镜顺序**连续递增（`SH01→SH02→…`），**禁止**跳号、重号、倒序、同场重启 `SH01`；一 Beat 拆多镜须占用连续 `SH` 号段。`EP01_SC01` 与 `EP01_SC01B` 为**不同场**，各自从 `SH01` 起编。
   - **表格行序（强制）**：整张 Shot List 行序须按 **分集升序 → 同集内场景升序（含字母后缀按上游场序）→ 同场内分镜升序** 排列；完成当前 `Scene ID` 全部镜头后再进入下一场；**禁止**同表内乱序穿插不同 Scene 的行（除非上游明确要求分场分批输出且每批仍自洽）。
   - **跨场/跨集切换（强制）**：进入新 Scene 时 `Scene ID` 与 `Shot ID` 的场景段**同步切换**（含字母后缀）；`SH` **每场重置**为 `01`，**不得**跨 Scene 延续 `SH` 序号。
   - **补镜/插镜后缀（例外）**：事后插入的分镜可在基础 `{Scene ID}_SHzz` 后追加 `_1`、`_2`…（如 `EP01_SC02_SH03_1`、`EP01_SC01B_SH02_1`）；常规批量生成仍用标准 `SHzz`，**禁止**用 `_1` 替代正常递增编号。
   - **输出前核验（强制）**：逐行检查——① `Shot ID` 匹配正则 `^EP\d{2}_SC\d{2}[A-Za-z]*_SH\d{2}(_\d+)?$`（字母后缀可选；补镜后缀可选）② 同行 `Scene ID`= `Shot ID` 去掉 `_SHzz(_n)?` 后的前缀且与上游逐字一致 ③ 同场 `SH` 连续无重复 ④ 行序符合 EP→SC→SH 叙事序；任一失败须重排或重写 ID 后再输出。

### 三、摄影与镜头语言 (Cinematography)

**本章 = 摄影技法实现**（不改上游叙事）；景别/运镜/景深/转场细则见各专节与 §5.5。
1. **景别/角度专规**
   - **角色局部特写比例（强制）**：每场须有足够 **P 段**特写/局部特写（Close-up / ECU / Insert），常规场景建议同 Scene 内约 15%-25% 相位为特写级。
   - **上游高潮/核心情绪点特写（强制继承 Stage 1 §5）**：若上游 Scene 含【高潮与核心情绪点】/情绪特写切口，拆镜前须逐点映射为 **P 段** CU/ECU/Insert——角色情绪点→脸/眼/手等角色特写；环境情绪点→空镜/象征陈设 Insert；主高潮标「双特写」则同镜或紧邻镜须同时落地角色 CU **与** 环境 Insert。Logic 写`情绪点特写映射:`（点名｜Beat｜P段｜角色CU|环境Insert｜缺口=无|upstream_missing）。**禁止**把情绪高点全程压在 Wide/MS 而不切近；本层只写运镜实现，**不改**上游建置/因果；上游已写特写切口却未映射=失败须补 P 段。
   - **成人向局部特写边界（强制）**：仅当画面角色明确为成人时，成人向/成熟向场景可安排嘴唇、眼部、胸部、腿部、臀部等局部特写；所有胸部/臀部/腿部特写必须以服装覆盖、姿态线条、剪影、光影轮廓、镜面/遮挡构图等影视化方式表达，禁止裸露、露骨性行为、低俗挑逗、未成年人或年龄不明角色的性化局部镜头。
   - **局部特写功能约束**：嘴唇特写用于口型、呼吸、停顿、欲言又止；眼部特写用于视线、泪光、瞳孔、警觉；胸部/肩颈特写用于呼吸起伏、服装材质、心跳紧张、权力姿态；腿部特写用于步伐、站姿、距离变化；臀部/腰臀线条特写只用于服装轮廓、转身、落座、走位节奏或遮挡转场。禁止把局部特写写成脱离剧情的孤立凝视。**群演/匿名背景人群例外（强制）**：局部特写/中景/中近景**原则上不分配给群演/背景人群**；群演仅作远景/全景/虚化 BG 层出现，见 §七.7-b。
   - **对话景别切分（强制）**：口型可读的对白、画内听者可见的 OS/V.O.、Shot-Reverse-Shot / OTS、反应镜、以及 `(Pn)` 段内须可读的微表情与微动作，**原则上**采用 **Medium Shot / Medium Close-up / Close-up / OTS**（中景、中近景、特写、过肩）；禁止在常规对话段落用 Wide / Full / Master / Two Shot 全景承载口型可读对白。听者反应、微表情链、微动作须与说话镜处于**同级或相邻一级**景别，保证面部与口部/眼部可读。**画幅比例外与强化**见下条「画幅比驱动的对话景别」。**例外**：特效相位、宏观群体主节拍（Stage 1 §28 + §5.5 E）须远景/全景主拍。
   - **画幅比驱动的对话景别（强制，读 Project Context `Aspect Ratio`）**：
     - **竖屏画幅（Mandatory 强化）**：当 Project Context **明确**为竖屏比例（如 **`9:16`**、`3:4` 等 height ≥ width 的声明）时，**原则上**每条口型可读对白须为该**说话人**单独分配 **中景或特写** P 段——**Medium Shot / Medium Close-up / Close-up / OTS / Dirty Single**；竖屏画幅窄、双人同框信息密度低，**禁**用 Wide / Full / Master / Two Shot / Establishing 承载说话人主拍落幅。多人对话须**按说话人逐句/逐组切换**至该人物中景或特写主拍（可 OTS 但落幅仍须说话人面部/口部可读）；Scene 建置 P1 若用全景/中全景，须在本镜内**尽快 Push In / Reframe** 至说话人近景。**Walk-and-Talk** 竖屏时仍优先 **Medium Shot / Medium Close-up** 跟拍，禁长时间 Wide 跟拍承载口型对白。
     - **横屏画幅（灵活安排）**：当 Project Context **明确**为 **`16:9`** 或未声明画幅比、且无从推断为竖屏时，对话景别**可根据剧情合适安排**——允许 Two Shot / 中全景关系镜、Walk-and-Talk 中全景跟拍、Scene 建置 Wide、以及 **§三.1 三前提满足时**的收束 Pull Back（落幅刚好适配下镜起幅，禁无因远景/全景）等，但仍须遵守本条「对话景别切分」口型可读禁 Wide 主拍之通则，以及 §三.1 景别递进、收束落幅、动作主体运镜等专规；不必机械要求每句对白都切至 MCU/CU，但说话人须保证面部/口部可读；**正反打链仍禁无因 Pull Back**。
     - **其他画幅**（如 `4:3`、`2.35:1`、`1:1`）：`画幅比继承:` 注明比例与竖|横判定；对话景别在遵守口型可读通则前提下，**竖向窄画幅倾向说话人中景/特写**，**横向宽画幅可按剧情灵活调度**。
   - **近景对话背景虚化（允许，推荐）**：**Medium Shot / Medium Close-up / Close-up / OTS / Dirty Single** 等近景对话 P 段，**可以**采用 **浅景深（Shallow Depth of Field）虚化背景**（Bokeh / Defocus / Selective Focus / Rack Focus 落至说话人），突出说话人面部/口型与微表情；听者过肩时听者肩部/后脑、同框非主拍角色**可虚焦**。**须仍保留** `ENV:[...]` 标签，并在虚化背景中写出**白名单内已有实体**的可感知轮廓/动势线索（如失焦文件柜/门框轮廓、虚化窗外树冠轻晃、远距车流缓移——**实体须剧本/Beat/Index/ENV 已出现**），**禁止**近景对白写成纯白底或无环境信息的抠图悬浮感。**Pn 段禁写光影**：虚化背景中的光斑/冷蓝 bokeh/Practical 暖光散景/条纹光漂移等**一律不写在本 P/`(Pn)` 段**，统一写入「动态连续光影/焦点」「光线连动弧光」。**与 §七.7 关系**：P1 全景/深焦建置仍须写清晰环境实体**物理**微动；近景对白 P 段可简化为**虚化背景中已有实体的物理微动**（如「背景虚化失焦，窗外树冠轮廓轻晃、远距车流缓移」），不必重复 P1 全量三层建置。**例外**：剧情须强调空间关系/走位/多人同框调度时，近景对白可维持深焦或半深焦，须在 `Shot Logic (CN)` `收束落幅判定` 或 `P段时序链` 注明依据。
   - **景别递进与防越级（强制）**：同镜内相邻 **P 段**景别变化原则上**逐级**递进或回退；禁止无动机地从全景直切极特写。情绪高点、上游 `细节特写`/【高潮与核心情绪点】、转场 Match 可例外，须在 `Shot Logic (CN)` 写明桥接依据。
   - **特写/中景/全景切换规则（强制）**：
     - **全景（Wide / Full / Master / Two Shot / Establishing）**：新 Scene 建置、空间关系首次交代、走位/调度展示、Walk-and-Talk、宏观/特效场面、群像关系；**禁止**作为常规口型可读对白的主拍落幅。
     - **中景（Medium Shot / Medium Full / Medium Close-up / OTS）**：对话主拍默认档、双人/多人关系镜、动作+对白同相位、听者反应镜；口型可读对白、OS/V.O. 听者、微表情/微动作须在 **中景或更近** 可读。
     - **特写（Close-up / Extreme Close-up / Insert）**：情绪高点、上游 `细节特写`/【高潮与核心情绪点】、**剧本/Beat 对道具的特别描述**（§三.1「道具特别描述特写运镜」）、微表情链落点、关键道具线索、口型/眼部精确读；每场须保留 §三.1 规定比例的局部特写。**群演/背景人群禁 CU/ECU/Insert 主拍**（§七.7-b）。
     - **群演/背景人群景别（强制，§七.7-b）**：匿名群演/背景人群簇**原则上不得**分配 **Medium Shot / Medium Close-up / Close-up / OTS / Dirty Single** 等中景或更近主拍；须写为 **Wide / Full / Master / Extreme Wide / Long Shot** 内的 **BG/MG 虚化层**（失焦群众、远景路人剪影、背景办公人员簇等），禁 Push In / Rack Focus 对准群演个体、禁群演面部/口部可读特写。**例外**：宏观群体主节拍（Stage 1 §28 + §5.5 E）允许远景/全景群像主拍，仍**禁止**群演 CU/中景单人主拍。
     - **切换路径（强制）**：`全景 → 中景 → 特写` 为默认同镜 **P 段**递进，用 Push In / Pull Back / Track / Rack Focus 等写清过渡。
     - **同镜收束落幅（强制 · Pull Back 三前提单权威）**：§5.5 的 Pull Back Reveal = **镜中过程**（可叙事用）；**本条只约束镜末收束扩框**（服务无跨镜记忆的下镜起幅）。`收束落幅判定` 只定本镜末 P；禁因收束另起 Shot。超时拆分后镜 P1 继承前镜出场实体。
       - **三前提（须同时满足才镜末扩框）**：①本镜末落在 CU/ECU/Insert/MCU（近景收尾）｜②下镜同主环境且 ≥2 具名 CHAR 同框可见｜③下镜**非**正反打/OTS/Dirty Single 对打链。**正反打绝不回拉**（肩背虚焦/双方合计≥2 亦不算前提②）。缺任一 → 保持本镜末景别；禁以「超时拆分/回建置/恢复全景」伪满足。
       - **满足时**：只拉到下镜起幅所需最小同框档（优先 MS/Two Shot/MFS）；写清相对 ENV 落位；**禁**无下镜宽景需求拉到 Wide/EWS/航拍。运镜 1.5–3s（§5.5 G）。Logic：`Pull Back前提=满足` + 目标/下镜起幅景别 + 幅度依据=刚好适配。
       - **不满足**：保持实际落幅；`Pull Back前提=不满足` + 缺项。硬禁：`下镜多人出镜=否` 或 `正反打排除=是` 却写满足。
       - **例外**：下镜跨主环境 → `例外=下镜换环境`（门槛/Match，不做回拉）；上游明文悬念停特写/全员已出画 → 写依据可保持。禁因「对白未完/情绪紧」强行回拉。
       - **档位**：扩框适配下镜｜保持本镜末｜环境切换起幅｜保持特写（须依据）｜出画落幅。Logic 必含 `收束落幅判定:`（前提=满足|不满足+缺项｜档位｜目标/下镜起幅景别｜特写收尾｜同主环境｜多人出镜｜正反打排除｜换环境｜幅度依据）。
     - **同镜内 P 段**：P1 可 Wide/MFS；对白中景/特写；终段仅三前提满足时扩框；正反打终段保持近景。
2. **构图**：服从主体视线与运动方向留白（§七条目7 Head Room / Lead Room）。
3. **焦段/透视**：随景别与空间意图选用；禁无动机极端畸变。
4. **摄影机运动**：推/拉/摇/跟；每场至少1个高级运镜（不可凭空随机使用，须通读整个场景，寻找经典影视作品场面，整体规划在哪个分镜使用，和其他分镜怎么衔接，并在使用高级运镜的分镜中要在Shot Logic中概要说明）；**OTS 四要素**见 §七.6「正反/OTS 专规」（缺任一=不合格）；不可越轴。
   - **运镜选用（强制）**：每场≥1镜高级运镜；打斗/追逐/法术/轻功/宏观Beat全覆盖。**选用流程**：①先读本 Beat **建置站位**（谁在哪侧/朝向/姿态/主锚）并锁定 P1 底座 → ②完成 §二.3A `节奏需求`（快/中/慢）→ ③再读人数/题材/ENV/情绪落点，在**不改站位**前提下按节奏档规划运镜（快→加强 Handheld 手持感；慢→稳/慢推；中→稳机对白）与前后衔接 → ④§5.5 按相位择 1–2 项（动机=服务已锁站位的可读面/位移/对白向）→ ⑤**核验 §三.4「运镜递进合理性」+「运镜组合合理性」+ §一.1A「运镜服从站位」+ §二.3A 节奏档** → `运镜选用依据:` 写明节奏档、站位底座摘要、剧本要素、经典影视参考与选用理由；若使用高级运镜，须并入整体规划及与其他分镜衔接概要 → 写入 `打斗运镜技法`/`特效攻击运镜`/`快慢节奏`/`高速跟拍技法`/`AI高成本奇观`/`升格技法`。须与本场剧本可核对；**禁止**先定炫技运镜再倒推改位。
   - **运镜递进合理性（强制，与 §三.1 景别递进同级）**：同镜相邻 **P 段**、同 Scene 相邻镜的机位能量须**可解释递进或回退**，禁止无动机跳级。
     - **能量档位（自低→高）**：① Static Hold / 微呼吸｜② Slow Push / Slow Pull / Soft Pan / Rack Focus｜③ Track / Follow / Lead / Arc Orbit｜④ Handheld / Whip Pan / Crash Zoom / Speed Ramp｜⑤ Bullet Time / 多轴复合奇观。相邻相位原则上**同档或相邻一档**；跨 ≥2 档须有剧本触发（情绪高点、命中、惊吓、追逐加速、Reveal）并在 `Shot Logic` 写桥接依据。
     - **叙事弧对齐（强制）**：建置/入戏偏 **①–②**；对白加压/对峙升级可升至 **②–③**；打斗/追逐/惊吓主相位可达 **③–④**；命中/奇观短插才用 **⑤**；收束/余波须**回落**至 ①–②；**仅当 §三.1 Pull Back 三前提满足**时才用 Pull Back / Soft Dolly Out 扩框至**刚好适配下镜起幅**的同框景别（正反打除外；禁无因拉到远景/全景），禁高潮档硬切收场、禁无前提机械后拉。
     - **与景别同向（强制）**：景别收紧（Wide→MS→CU）优先配 Push In / Track In / Soft Pan；景别打开优先配 Pull Back / Dolly Out / Arc Return；**禁止**景别在收紧却机位在剧烈后拉、或景别在打开却持续 Crash Zoom（Reveal 例外须注明）。
     - **跨 P / 跨镜链**：写出 `运镜递进链:`（P1档→P2档→…→终段档，或 SH01→SH02…）；终段相对高潮须有回落说明。
     - **反例**：❌ P1 Static Wide 建置后 P2 无桥接直上 Whip Pan+Crash Zoom｜❌ 对白加压全程 Static，情绪高点却突然 Bullet Time｜❌ 打斗高潮后硬切 Static CU 无回落运镜。
     - **正例**：✅ Wide Soft Push → MS Track → MCU Push In → CU 微表情 →（下镜起幅=Two Shot）Pull Back **只到** Two Shot｜✅ CU →（下镜起幅=三人 Medium Full）Pull Back 到 MFS、**不**拉到 EWS｜✅ 常速 Handheld 快连击 → Speed Ramp → Bullet Time 命中短插 → Soft Orbit/Pull Back 余波（落幅=下镜所需同框景别）｜✅ CU→正反打/OTS 对白链 → 镜末保持 MCU、**不做** Pull Back｜✅ CU 对白链跨镜延续且下镜非多人同框 → 镜末保持 MCU、**不做** Pull Back。
   - **运镜组合合理性（强制）**：同相位叠用 ≥2 种运镜时，须**同轴/同目的/可物理执行**；禁止技法堆砌与相互抵消。
     - **单相位主导（强制）**：每一 P 段**仅 1 个主导运镜**（决定起幅→落幅主轨迹）；可附 **≤1 个辅助**（如 Track 主导 + Soft Pan 微调框景，或 Push In + Rack Focus）。**禁止**同相位并列 ≥3 个高级运镜名，亦禁止只列技法名而无主次。
     - **合法复合（优先择此类）**：Track+Pan（跟移中微调框）｜Push In+Rack Focus｜Dolly+Pan｜Follow+Soft Pan｜Arc Orbit+轻微 Tilt｜Handheld+短程 Track｜Pull Back+Crane Up（回建置）｜Whip Pan 单独作切换桥（前后相位各有落幅）。
     - **非法/高冲突组合（禁，除非上游明确奇观并写依据）**：同相位 **Crash Zoom ∩ Dolly Zoom**｜**Push In ∩ Pull Back**（对冲）｜**Whip Pan ∩ Slow Push**（节奏互斥）｜**Bullet Time ∩ 常速 Handheld 缠斗**（须 Speed Ramp 分相，不得同相位叠写）｜**Drone/Bird's-Eye ∩ 口型可读 CU**（鸟瞰禁口型主拍）｜**Static Hold ∩ 高速追逐主相位**｜一 P 段内 **Orbit+Crane+Whip+Crash** 堆砌。
     - **节奏桥接（强制）**：常速↔升格、舒缓↔剧烈之间须用 **Speed Ramp / 短停顿落幅 / Soft 过渡运镜** 分相，**禁止**无桥接硬跳档。
     - **轴线与空间**：复合运镜不得无过轴声明越轴；环境切换复合须服从 §5.5 G（有过程、禁硬切）。
     - **`Shot Logic` 必填** `运镜递进与组合:`（递进链=…｜主导运镜=…｜辅助=无|…｜合法复合依据=…｜跨档桥接=无|…）；无复合写「单运镜主导」。
     - **反例**：❌「Handheld+Whip Pan+Crash Zoom+Orbit 同时」｜❌ 对白镜 Push In 同时 Pull Back｜❌ 升格与常速快攻写在同一 P 段无 Speed Ramp｜❌ 本镜非特写收尾却机械 Pull Back｜❌ 正反打/OTS 链却强行 Pull Back｜❌ 下镜非同环境多人同框却强行 Pull Back｜❌ 下镜只需 Two Shot 却拉到 Wide/EWS｜❌ 仅「恢复原全景」而无下镜宽景需求却回远景。
     - **正例**：✅ `运镜递进与组合: 递进链=②Soft Push→③Track→④Handheld→⑤Bullet Time短插→②Pull Back｜主导=P2 Track / P3 Handheld｜辅助=P2 Soft Pan｜跨档桥接=P3→P4 Speed Ramp｜Pull Back前提=满足`。
   - **高速追逐/穿梭**：追逐·穿梭主相位须跟拍，禁Static+Wide；**继承 Stage 1 §31**——路径节点连续呈现、链累计时长覆盖上游 ≥20s 保底；Video 对应 P 段须**连续动作过程**并**明示占用秒数**，计入本镜 Duration（§5.5 D）。

   - **快速闪回（有情节；同 Scene）**：上游留在当下场的短暂回忆（对白 **>30 字** 或具名动作）；主节拍=快速闪回桥接；须写**进入运镜锚点→回忆内容→回切运镜锚点**；质感 OT-TX/OT-DF/OT-CG/OT-FD/OT-SP **叠加** §5.5 J 运镜（典型：Push Into Eyes→Dissolve｜Whip Pan 入出｜Match on Object｜Soft Dolly）；**可**独立 Shot 或短专拍组，Duration 通常 3–8s；须完整继承上游对白与微表演。回忆镜 ENV 挂上游闪回【主环境】族衍生（禁仍用当下主环境）；回切=跨主环境拆镜（§二.1.5）且须有回切运镜过程。**禁止**本阶段另拆闪回 Scene。  
   - **无情节回忆切片（转场式；同 Scene）**：上游仅印象/情绪/物象触发，**无对白链、无完整动作情节**；**按转场处理**，**禁止**升格为独立闪回 Scene 或扩写对白/动作链。**拆镜**：**并入相邻 Shot 转场链**（P 段内闪切或镜末桥接），**不必**单独建闪回 Shot；写法：触发→**短运镜桥**（Push Into Eyes / Whip / Match / Soft Push / Defocus Pull，择 1）→**≤2s 单幅/1–2 帧印象切片**（剪影/局部/色块/物象，**不要求**完整 FG/MG/BG 建置与口型）→ 去色/虚化/噪点/柔焦（OT-TX、Defocus、Color Grading 等）→ **短运镜回切**当下微反应/声残响；**主节拍仍归当下场**；`Shot Logic (CN)` 须写 `无情节回忆切片:`（触发/切片要点/回切/`闪回运镜`进入+回切/光学/是否并入本镜）。**计时**：计入 `转场/停顿Xs`，通常 **0.5–2s**，与触发/回切同相位时并入并行核，**禁止**为无情节切片单独全额建置计时。上游已立闪回主环境时，切片画面仍须可识别挂该 ENV 名（可不完整建置）。  
   - **≤30 字且有具体情节**：不闪回，当下反应/OS，本阶段不出回忆镜。  
7. **特殊时空（蒙太奇等）**：除上条外，蒙太奇/梦境/意识流等用**运镜+声画**过渡；可用 Defocus、Color Grading、亮度压低、慢速运镜（Soft Dolly / Slow Push）、Whip / Match 切点、纹理/噪点衰减、声效淡入淡出——**禁**无运镜硬切堆片段。**蒙太奇多主环境（同 Scene）**：上游同场多【主环境】时，相邻 Beat 主环境不同 → **按 §二.1.5 跨主环境拆 Shot**；各镜 ENV 挂对应主环境族衍生，禁混挂；点间切换须有 §5.5 J 或 G 过程运镜；**禁止**本阶段把蒙太奇拆成多 Scene。  
8. **镜头三段式（Shot Mode）**：每镜 `Video Content` 须覆盖起镜建置、运镜过程、落镜定格（机位/景别/运镜/焦点/落位），优先摄影机视角；禁主观情绪句，改写可视细节。与 §八.2 的 P1/过程/终段对应。

### 四、灯光设计 (Lighting Design)

**权威 = §0.06**（提取、可见/不可见分流、配额≤3、防悬浮 3/4、实体指称）。本节只补**执行清单与独特硬约束**；光动**只写**「动态连续光影/焦点」「光线连动弧光」；与 §七.7 物理微动分写。**禁**借光影改站位/动作/对白。

1. **动笔顺序**：读 ENV CN → Logic `光影锚定:` → Video 两光影段按 §八.3–§八.4 书写顺序输出。
2. **§四.5-E 面部可读 Fill（真人优先，服从 ENV CN；≠压扁大光比）**：侧向 Key + 半影柔散｜Fill **仅** ENV 已声明反射面反弹或第二画内 Practical，保面部/口型**关键信息可读**（禁无 ENV 锚点美颜补光、禁面部局部 spotlight、禁整室同亮/均匀平光抹平 ENV 大光比）｜Rim 须有 ENV 入射动机（禁硬 rim）｜投影软过渡（禁刀切阴阳脸；恐怖/上游压暗例外）。**继承效果、不抄数字**：Stage 3 ENV 大光比以亮暗分层/冷暖对照落入 Video，**禁**写 `Key:Fill≥8:1` 等数值。
3. **独特硬约束**
   - **门外作光源**：须先核销门为开启态；`光影锚定:` 写 `门外光源门态=半开|全开｜核销依据=…`；门紧闭禁门外主动机；门外灯具不可见时只写渗光效果、禁实体名（§0.06）。
   - **Key/Fill 角色名实一致**：Key=照亮；Fill=托起暗部（禁把 Fill 写成加深阴影）；入射须与 ENV 几何一致。
   - **照度**：室内/日景默认充足（可见动机光 1–3 + ≥1 反射 Fill）；低照度须上游依据。
4. **两光影段覆盖（10 取 8，细则定义见 §0.06）**：(1)可见光源清单1–3 (2)Key方向与照亮面 (3)各可见光源作用范围 (4)可见效果 (5)多实体受光/投影分层 (6)Fill/Rim/暗部可读 (7)冷暖对照 (8)光学响应非外形+接地影/色溢出 (9)运镜中光向连续 (10)CHAR/PROP 融入防悬浮。
5. **Logic 必填**：`光影锚定:`｜`光影继承:`｜`光源充足性:`（可见动机光个数≤3｜低照度例外）。输出前自检：可见具名/不可见仅方位｜与 ENV 一致｜Fill 有反射依据｜门外光源门态｜无位置前缀｜无不可见实体名｜≤3｜冷暖分层。

| 实体 | 快攻/连击/弹道 | 命中/格挡/弧顶/对撞 | 慢相位锁已写轨迹节点；禁慢镜里实体仍高速位移 |
| 机位 | Handheld/Whip/Track/Follow 跟轨迹 | Bullet Time/Orbit/CU 钉节点 | 快跟同向同速；慢对准命中点/接触面 |
| 播放 | 100% | Slow/Hyper/Bullet/Time Slice | 每次切换 Speed Ramp 入/出各 0.3–0.5s |

**快相位**：起势连招、闪避、弹道出手→逼近、追逐、域场建规模。运镜：Handheld｜Whip｜Track/Follow｜Crash Zoom（常速）｜Drone 读规模。每链 ≥1 快连击 P（≥2 击具名+攻防匹配，≥2s）；禁多击全拆升格、禁单方无反应堆招。机位须跟实体/弹道；禁 Static+Wide 扛高速。单段 2–4s；快总时长 ≥ 升格×2。

**慢相位**（每链 1–2 处）：命中/对撞/爆炸/格挡｜弹道可读节点｜弧顶/触地｜终结技破防（仅 1 处）。运镜：Bullet Time｜Time Slice｜Orbit 绕命中｜CU 读受力。钉住 Beat 轨迹节点；禁空镜慢飞。单段 1–3s；累计 ≤35%；>4s 须拆。

**Speed Ramp**：入慢=接触前末帧/节点可读；出常=读毕→反馈/余波。默认 `常速→升格→出常`；超时拆分后镜用 Match/Whip 衔接。失败：整镜单速｜Z>40%｜无 ≥2s 快连击｜无 Ramp｜机位不跟｜慢未钉节点 → 补写 P。

**类型速查**：近身 Handheld/Whip↔Bullet 命中｜弹道 Follow↔Time Slice｜法术 Orbit↔对撞慢｜腾空 Track↔弧顶短慢｜连击多段快+1 处终结升格｜域场 Drone↔波前慢｜载具 Follow↔撞击 Bullet。

**P 段**：快=运镜名+跟拍对象+轨迹向+常速+逐招具名+攻防匹配；慢=升格技法+锁定节点+可读信息；变速=Ramp 方向+落幅。禁「快速打斗/慢动作效果」泛化句。

**Logic 必填**：`快慢节奏:`（各 P=常速|升格|变速+运镜+节点+秒+`升格占比`）｜`快连击链:`（逐招+攻防）｜`升格技法:`（选用+触发+第几处）｜打斗另 `打斗运镜技法:`；特效另 `特效攻击运镜:`（§5.5 A）。

**反例**：❌ 全程常速无升格｜❌ 整镜 Bullet 拖镜｜❌ Z>40%｜❌ 无快连击/缺招名攻防｜❌ 弹道飞出镜头不动。
- ❌ 升格段实体仍在高速位移，未钉住命中/接触节点。
- ❌ 有 Slow Mo 无 Speed Ramp 出入，硬切速率。
- ✅ P2 常速 Handheld **快连击** 3.5s（**甲：右直拳→左勾→侧踢；乙：架肘格挡→侧身闪避→反刺**，Whip Pan 衔接）→ P3 Speed Ramp 入慢 + Bullet Time 读**侧踢**命中 1.5s（**升格占比≈1.5/7.5=20%**）→ P4 Speed Ramp 出常 + 受力反馈 2.5s。

- 禁改对象/方向/重读词/标点；`rhythm`/`stress`/`pause` 须落到可拍微表演相位（服务口型与 §二.4 语言耗时）。
- 画内可对口型说话人：`(Pn)` **须 ≥1 项面部微表情**（与 tone 咬合）；听者写上游已有微表演，**禁补创**。
- Logic：`语气层继承:`（N 条｜对谁列表｜特殊 pause/rhythm｜无则写无）。

#### 六.0A 小语种 / 方言台词承接（强制，零译抹）
- **识别**：上游入戏对白含「用{语种|方言}说道」或等价明文（如 `用日语说道` / `用粤语说道` / `用四川话说道`）时，本镜 **必须**在对应 `(Pn)` **原样保留**该语种/方言标签 + **原文台词**（Stage 1 花括号 `{…}` 内全文；写入 Video 时可用 `"…"` 外壳，但**正文逐字不变**）。
- **禁止**：译成项目主语言/普通话/英文后冒充原台词；删掉语种/方言标签只留译文；用同义改写、繁简转换、罗马化转写替代原文；把方言「规范化」成普通话。
- **标准普通话 / 英文**：上游未标语种/方言时不必加标签；仍须逐字继承台词正文。
- **Logic**：有则写 `语种方言继承:`（语种|方言列表 + 对应说话人 + 原文可检索=是）；无则写 `语种方言继承: 无`。
- **与项目 Language 关系**：`# Project Context` 的 `Language` 只约束主体语种与全局风格注入；**不得**据此覆盖本条已标注的小语种/方言原文。

#### 六.1 对白写入格式（Video）
`(Pn) {说话人面部微表情+状态} — Dialogue (CHAR:[@名]) (对{听众/方向}, voice_type: …, voice_identity: …, tone: …, speed: …, volume: …, rhythm: …, stress: …, pause: …): [用{语种|方言}说道]"{逐字原文}" — {听者微表演}`

- 有小语种/方言时 **必须**保留 `用{语种|方言}说道` 前缀（方括号仅示意可选，成稿写明文不写方括号）。
- 示例（普通话）：`(P2) CHAR:[@林医生] 唇角微绷、吸气半拍后开口 — Dialogue (CHAR:[@林医生]) (对陈医生, voice_type: 对白, voice_identity: 林医生·领导型主治医师音, tone: 压抑, speed: 中速, volume: 正常, rhythm: 先缓后催, stress: 重读「确定、签字」, pause: 报告—略停—你确定): "报告——你确定要签字？" — CHAR:[@陈医生] 眉弓微抬、下颌收紧`
- 示例（方言/小语种）：`(P2) CHAR:[@阿强] 侧头、嘴角一扯后开口 — Dialogue (CHAR:[@阿强]) (对陈医生, voice_type: 对白, voice_identity: 阿强·市井青年音, tone: 随意, speed: 中速, volume: 正常, rhythm: 短促, stress: 重读「唔该」, pause: 无): 用粤语说道"唔该" — CHAR:[@陈医生] 眉心微蹙`；`(P3) …: 用日语说道"こんにちは" — …`

#### 六.2 音效承接（强制，零删略）
- **识别**：上游 Beat 入戏段尖括号音效 `<{音效描述}>`（如 `<远处传来狗叫声>` / `<门轴吱呀一声>`）为本镜**可听剧情音效权威**；经 Stage 2-2 落表后格式不变。
- **写入**：在「运镜与动作流」对应时序 P 段（或声先入/声桥所在段）**原样写入**尖括号全文，或紧邻写等义可听描述且 **尖括号原文仍须可检索**；须保留声源方位/远近/介质等上游已写信息。
- **禁止**：因品质收束句含「无背景音乐」而删除剧情音效（该句禁的是 **BGM/配乐**，**不**禁画内/画外剧情音效）；禁升级为混响/频段/分贝等 Stage 3 声场细参；禁无上游依据堆砌装饰性音效；禁把音效改写成无来源的抽象「气氛声」。
- **与转场**：上游/Logic 已用声桥、J-Cut、L-Cut、OT-AS、OT-SB 等时，Video 须在对应相位写出可听内容（继承 `<…>`），不得只写转场标签名而无声音落点。
- **Logic**：有则写 `音效继承:`（N 条｜尖括号原文列表｜落点 P 段）；无则写 `音效继承: 无`。

#### 六.3 对话镜布光运用
§四.5-E + §0.06：面部/口型/微表情在 ENV 动机光下可读；禁无方向平光/硬阴影切脸。

#### 六.4 OS/V.O./旁白/自白运用
凡上游 `voice_type∈{画外音,OS,V.O.,旁白,自白,独白,内心}` 或真画外/旁白相位：`(Pn)` **须明文写闭嘴/闭口**（禁只挂声却写张嘴对口型）。①OS/V.O./旁白/画外音→**画内全员明确闭嘴**（含群演）；声源标 `NARRATOR` 或对应 `CHAR:[@…]`（画外）；拍听者/环境/声源方向，禁对不存在主体 Push In 对口型。②自白/独白/内心→发言人**闭口/内心状**（不按 lip-sync）+画内他人闭嘴；须保留方向锚（对镜头｜望天｜望远｜对空位等）。**语气层**：OS/V.O./旁白/自白/独白仍须 **§六.0 全字段 inline 继承**（含 `对{听众/方向}` + `voice_identity`）；画内闭嘴≠省略语气层；不按 lip-sync 但 `(Pn)` 段须保留 Beat 原文语气层块供 TTS/后期。**小语种/方言 OS/V.O.** 同 §六.0A，标签与原文不得译抹。

#### 六.5 自然生理微动作与运动纹理保真（摄影真实感，禁表演二创）
补充 §四.5-E / §六.3：**只写**动态真实感提示（非外形；§0.05）——自然眨眼/眼球微动/发丝随动清晰；禁整镜瞪眼定格、禁「柔化/磨皮」、禁借此写骨相/肤质。有对白或 >3s 静态特写时 Logic 可标 `自然眨眼:已写`。**禁止**据此补创 Beat 未写的情绪微表演。

### 七、空间 → 镜头语言（构图/转角/微动；建置内容规则见 Stage 1）

**本章只管摄影转译**：如何框、如何转角、如何留白、如何写活 BG。落位/朝向/姿态/七要素**写什么** → Stage 1；本层只把 Beat 已写内容拍成立体可读画面。

1. **P1 空间起幅**：每镜仅 P1 一次完整呈现上游建置落点；过程段只写行动（§八.2）。
2. **单画布**：统一透视地平面；禁拼贴纸板感；动作优先单人主拍。
3. **层位自然语言**：Logic 可用 FG/MG/BG 推演；Video 用「近处/纵深/画面左」等自然语言（禁 `MG 左区` 拼贴）。冲突 → `建置冲突:` + 保留 Beat 明文（禁改位修补）。
4. **ENV 锚点**：每镜 ≥1 `ENV:[...]`；切换 = 「切换到 ENV:[…]」+ §5.5 G 运镜过程（禁硬切）。
5. **Screen View**：框景边界 + 上游亮屏 UI 内容（禁自造）；接听后同步后态界面。
6. **360° → 镜头语言**：§七.6（本分镜专责）。
7. **构图留白（强制）**：运动/视线/对白方向前方留 **Head Room + Lead Room**（约 1/3）；转角运镜全程留白，禁贴边满幅。
8. **环境物理微动**：§七.7；每镜 ≥1；禁光影混入微动/Pn。

#### 7.6 360 度拓扑 → 镜头语言转译（本分镜专责）

**读上游**（Stage 1 §11 `{主环境}`/`{衍生环境}`）：0 度轴、顺时针递增、可见/不可见 Delta、OTS 反打角 `(N_对手+180)%360`。**只在 `Shot Logic` 推演**。

**`Shot Logic (CN)` 必填（衍生 ENV 或视角切换镜）**
- `360度转角继承:` 主环境 0 度观察基点=…；本镜 ENV=…；相对主 0 度**顺时针转角 N**=…；**OTS/反打时另写** `对手可读角 N_对手=…` → `目标ENV角=(N_对手+180)%360=…`（禁盲套 180）；转角对照=衍生正面↔主环境 N 度；**新可见**=…；**退出可见**=…；方向性物体重判=…（椅背/门扇/桌头等逐项）。
- 与 `观察视角继承:`、`环境切换运镜:` 配套；主环境（0 度）镜可简写 `360度转角继承: 主环境基准，N=0，无转角`。

**`Video Content (CN)` 转译规则（强制，禁遗留推导信息；禁照抄【Beat切换说明】）**
- 【Beat切换说明】与上游拓扑/转角/可见性 Delta / 180° 判定 **须在写作前消化进 `Shot Logic`**，正文**只输出镜头里实际看见的画面**；**禁止**把切换说明原文、推导字段、度数坐标、拓扑公式、不可见半空间说明粘贴进视频提示词。
- **只写可见（最高）**：Video **只描述画内可见**的机位、运镜、实体与背景；**禁止**写「不可见」「不再看见」「机位后方半空间」「画外某某」「退出可见」等——画外/后方内容**沉默省略**，不得点名也不得用「不可见」占位。
- **禁度数入 Video（最高）**：正文**禁止**出现 `0度/90度/180度/270度`、`顺时针回转 N 度`、`回转 180 度`、`N_对手`、`(N+180)%360` 等角度工程表述（含阿拉伯数字+度作拓扑坐标）；切角用 **运镜名**（Reverse Shot / Arc Orbit / OTS / Pan to New Axis 等）表达过程。度数推演**只留 Logic**。
- **必写要素（衍生 ENV 或正反/OTS/POV 切换时）**：POV/FPV **以主观角色视角建置、默认不包含主观角色自身**（细则 §5.5 H-POV：不可见则零描述；局部入镜须部位+入镜方式）。
  1. **机位落点**：站在/位于哪一结构侧（如「会议桌长边侧面、胸口高度 Eye-level」——**仅当该侧发光墙体本镜画内可见时**才可点名窗/灯实体）。POV 贴地/倒地主观 → 写物理高度与朝向（Ground-Level / 贴地仰看天花板）。
  2. **观察朝向 / 运镜过程**：用运镜名写切换（Reverse Shot、Left-Shoulder OTS、POV Handoff、Pan to New Axis、Motivated Reframe、Arc Orbit 等）+ 空间锚点（沿桌轴线/门槛轴线等）；**禁**写回转度数。
  3. **背景更替**：用自然语言只写 BG **看见什么**（✅「背景为半开木门与门外冷蓝走廊」）；**禁**补写机位后方/已退出可见实体，**禁**「…不可见」句（❌「百叶窗位于机位后方」｜❌「机位后方半空间不可见」）。
  4. **方向性物体可见面**：椅背/椅面、门扇开向、桌头/桌尾、床头/床尾、主客位等按当前机位写**可见面与画面左右**，禁沿用主视角朝向。
- **`ENV:[...]` 标签**：Index 原名（含 `{N}度` 前缀）**保留**作环境标识；正文空间描述须用镜头语言，**不得**把 ENV 名中的角度数字当画面说明复读。

**正反/OTS 专规**
- **OTS 四要素（强制，`Shot Logic` + `Video Content` 均须可检索；缺任一=不合格）**：凡标 OTS / 过肩 / Left-Shoulder / Right-Shoulder，须同时写清——
  1. **过谁的肩（肩主）**：前景虚焦肩框归属人，须写 `CHAR:[@…]`；禁止只写「过肩」不写肩主。
  2. **肩主可见面**：机位相对肩主从哪一面取过肩框——**左侧面 / 右侧面 / 正面 / 背面**（可写四分之三背、后脑勺侧等，但须落四选一主类）；经典 OTS 多为**背面**或**侧面**见肩线/后脑；禁止只写肩侧不问可见面。
  3. **左肩或右肩**：Left-Shoulder（过肩主左肩）| Right-Shoulder（过肩主右肩）；须与画面左右、轴线留白一致（左肩常占画左/右缘须自洽）。
  4. **过肩后看谁（主拍）**：主焦点对象 `CHAR:[@…]` + 其相对镜头的**正/侧/背面及口型/表情可读性**。
  - **推荐句式**：`过 CHAR:[@甲] {可见面}{左|右}肩 → 看 CHAR:[@乙] {正/侧/背面}{景别}`；例：`过 Lin 背面右肩 → 看 Chen 正面中近景`；`过 Chen 左侧面左肩 → 看 Lin 四分之三面 MCU`。
  - **Shot Logic 摘要字段**：`OTS四要素: 肩主=…｜可见面=左侧面|右侧面|正面|背面｜肩侧=左肩|右肩｜主拍=…+可读面=…`
  - **反例**：❌ `Left-Shoulder OTS，Chen 中近景`（缺肩主与可见面）｜❌ `过肩看 Lin`（缺左/右肩与肩主可见面）｜❌ `OTS 反打`（四要素全缺）。
- **OTS/反打 ENV 角判定（强制，禁止盲套主环境+180°）**：切 OTS/反打衍生 ENV 前，须据上游 Beat 判定**被拍对象/对手**在主环境 360 度拓扑中的可读观察角 **N_对手**（落位+面向+轴线）；本镜 ENV 角 = **`(N_对手 + 180) % 360`**，**不得**不经判定一律用主环境 0 度 + 180 度。例：对手可读角 90° → ENV 270°；对手可读角 0° → ENV 180°。上一镜已在衍生角 M 时，仍须以对手可读角推导，而非「M+180」或盲套 180 度 ENV。
- 正反/OTS 须写同一空间锚点（桌中线/门框/门槛）+ **连续运镜过程**切换至对侧（**禁 Static 硬切**）；Shot Logic 写 **N_对手**、**`(N_对手+180)%360` 目标 ENV 角**、**OTS 四要素**及可见 Delta（禁只写「180 度互补」而不列对手角；上述**只进 Logic**）；Video Content 写 **Arc Orbit / Pan / Track + Reverse/OTS** + **四要素落幅句** + **画内可见** BG **渐进**更替 + 椅背/门扇等可见面重判 + **三分构图自然留白**（§七条目7）；**禁**回转度数、**禁**「不可见/机位后方」句。

#### 7.7 环境背景微动态（强制）

**定位**：AI 视频须有**活的环境**；除角色/群演/主节拍动作外，每镜 `Video Content (CN)` 须在 BG 或可见 ENV 结构中写入 **≥1 项**轻量、**全镜持续**的环境**实体物理微动**，**禁止**背景完全静止如静态生图空镜。**近景对话 P 段**（§三.1「近景对话背景虚化」）可写**虚化背景中已有实体的物理微动**（如失焦树冠轻晃、虚化车流缓移、窗帘轮廓轻摆）替代清晰 BG 全量描述，仍须 ≥1 项可读环境动势线索——**禁**用光斑/bokeh/光晕/条纹光等光学描写顶替（光学一律进「动态连续光影/焦点」「光线连动弧光」）。

**实体白名单（最高硬约束 · 如无必要勿增实体）**

- **禁止**为凑微动、填背景或丰富 Pn 描写而新增剧本未提及的具名实体（❌ 剧本未写「挂钟」却写「挂钟秒针」；❌ 未写「霓虹招牌」却写「霓虹频闪」；❌ 未写「蒸汽」却写「咖啡热气升腾」）。
- **无可用微动锚点时**：只对**已出现**的结构写极轻物理动势（如已有窗帘→轻摆；已有窗外树→树冠轻晃；已有车流/街景→远距缓移）；若本场剧本/ENV **确实无可动元素**，写 **1 句**已有实体的极轻态（如「门扇停在半开位微不可察」）并标依赖已有门扇，**仍禁止**凭空造实体。
- 匿名 BG 人群簇（§七.7-b）仅当上游已暗示人群/职场背景等时可写自然语言簇，**禁止**具名新角色。

**光影分工**：§七.7 / BG / P1 / Pn **只写物理动势**；一切光学（含灯闪/霓虹/条纹光/bokeh）**只进**光影两段（§0.06 / §八.3–§八.4）。不可见发光实体名禁则见 §0.06（微动/Pn 亦不得借「看不见的光」点名画外源）。

**双层背景动势（强制）**
- **第一层·环境实体微动（§七.7，每镜必填）**：须锚定白名单内、本镜**画内可见**的具体元素并写清**物理动势**——如**树枝/树冠随风轻晃**、**窗外/远距车流缓移**、百叶/窗帘轻摆、水面涟漪、雨丝下滑、旗帜/布幔飘动、挂钟秒针、蒸汽升腾、纸张被气流轻掀等（**仅当该实体已在剧本/Beat/Index/ENV 中出现**）；**无人群镜亦必填**。
- **第二层·背景人群随机动势（§七.7-b，有簇时追加）**：BG 可见群演/匿名人群簇时，**在 §七.7 环境实体微动之外另写**，**禁止**用人群描述替代环境实体微动；**禁止**只写「办公人员簇在动」而漏写已有百叶/窗外树/车流等 ENV 元素动势。
- **写法顺序（P1 BG 段建议）**：先写 **ENV 实体物理微动** → 再写 **人群簇随机动势**（若有）→ 再接主配角落位；**全程不写光影**。

- **写法位置**：P1 建置 BG 段**必写**环境实体物理微动；P2…Pn/终段若 BG 仍可见须**延续或更新**同类型物理微动（运镜导致 BG 更替时改写与新 BG 匹配的白名单项）；灯闪/霓虹/烛焰/屏光/条纹光/光斑等**只写在**「动态连续光影/焦点」「光线连动弧光」。
- **选型原则**：须匹配当前 `ENV:[...]` 类型、内外/日夜、题材基调与 Project Context；**只从白名单**选上游剧本/Beat/环境已暗示或 Index/ENV 固定清单中**可见的自然/人造元素**写动势；无明确户外元素时，仅对已有室内元素写物理微动（百叶/窗帘轻摆、空调气流扰动**已有**纸张/尘粒、**窗外已写明的**远距车流/树冠等）；**如无必要勿增实体**——禁臆造未出现元素。
- **幅度与优先级**：微动须 **subtle**、连续、不抢主拍；Static Hold / 特写仍须保留可感 BG 生命感（虚焦处**已有**叶影/窗帘轮廓轻晃、雾粒漂移等——**禁** Practical 光晕微颤入本段）；宏观/特效主相位写**场域级真实物理动势**（旌旗猎猎、尘浪推进、金属撞击、术法粒子场漂移等；**宏观阵势禁整齐划一机械同步**，须保留 terrain/参差/自然节奏）；光学动势仍归光影两段。
- **分类速查（择 1–2 项，勿堆砌；各项实体须已在白名单）**：
  - **户外自然**：树冠/**树枝**轻晃、草叶起伏、云层缓移、水面/雨洼涟漪、旗帜/布幔随风（**禁**「光尘在光束中漂移」——光学归光影段）。
  - **室内日常**：百叶/窗帘随气流轻摆、蒸汽/咖啡热气升腾、挂钟秒针、**窗外远距车流/树冠/街景虚化流动**（**禁**台灯/荧光灯闪烁入本段）。
  - **都市/赛博**：LED **屏面内容**微滚（屏为已有 PROP/ENV 时）、雨丝下滑、**后景车流/行人剪影缓行**（**禁**霓虹频闪/湿地面反光——反光归光影段）。
  - **悬疑/惊悚**：窗玻璃雨痕下滑、树影轮廓轻移、门扇微不可察颤动（**禁**烛焰光跳/走廊顶灯微闪入本段——光动归光影段；烛焰物理焰形跳动若剧本已有烛，可写「焰形轻颤」一句物理态，其照亮效果仍归光影段）。
  - **仙侠/奇幻/科幻**：法阵纹理微流转、能量粒子场漂移、全息界面内容微变、灵雾/离子雾缓流（**禁**把上述写成「发光脉动/光柱」光学句——光学归光影段）。
#### 7.7-b 背景人群（有簇时追加，与 §七.7 双层并列）

### 八、视频提示词要求 (Video Content Prompting)

只写入 `Video Content (CN)`：`Shot Logic (CN)` 写结构化推演与规则执行逻辑，本字段**只写发给 AI 视频模型的纯画面最终结果**，用自然语言叙述。维度间用 `<br>`，共五段 + 固定收束句：**全局动态风格 / 运镜与动作流 / 动态连续光影·焦点 / 光线连动弧光 / 物理文字生成 / 品质收束**。

**写法要点**
- 叙述体优先；禁 `结构=…｜`、`FG/MG/BG=` 键值体。
- **层位自然语言化（强制，推演坐标见 §五.2；Video 转译见 §七.3）**：正文默认用连贯自然语言表达层位与方位（如「近处」「纵深处」「画面左侧」「身后」），**禁止**把 `FG/MG/BG` 缩写或「左区/右区/中线」等坐标词直接拼贴进叙述句（如「MG 左区」「BG 左区入画」）；确需点明景深层次时用完整中文词「前景/中景/背景」写成流畅句子，不得以缩写代码或字段体形式出现。
- **只写画面最终结果（最高硬约束）**：正文只描述镜头里**实际看见**的机位、景别、运镜、实体落位、动作、表情、及其变化；上游 Beat 与分镜规则须在写作前消化，**以画面内化呈现，不得在正文解释如何承接 Beat、如何执行规则**。❌ `承接上一 Beat 站位后，按环节 2 建置三层`｜❌ `因对白组未完结故保持中近景`｜❌ `按 §三.1 收束落幅判定本镜末 Pull Back`｜✅ `Eye-level Two Shot 中全景，CHAR:[@Lin] 距桌右前角一步、朝右前倾压桌…`。**光影例外**：光线/光影/色温/投影等**只**写在「动态连续光影/焦点」「光线连动弧光」，**禁止**混入「运镜与动作流」P 段。
- **追杀/穿梭时长明示例外（允许，§5.5 D）**：追杀/追逐/穿梭连续跟拍 P 段**允许且强制**在动作过程句内写入「持续约 Xs / 约占 Xs」等**可执行时长提示**（服务生视频模型按时长生成）；该秒数须计入本镜 `Duration (s)`。此为例外，**不视为**规则推演入正文；仍禁止写 Beat 承接、§ 引用、Logic 字段名。
- **Beat 实体/ENV 零缺失**（§一.2）：正文可检索每一个 `CHAR:`/`PROP:`/`ENV:`；≥1 个 `ENV:[...]`，切换按次数写出+运镜。**建置角色优先**：对本镜映射各 Beat 的【建置】角色清单，须**先识别、后落词**——P1 起幅逐人可检索 `CHAR:[@…]` + 落位/朝向/姿态；禁只写主拍漏配角/听者/群演簇（§一.1「建置角色全覆盖」）。
- **实体白名单 · 如无必要勿增实体（强制，§七.7）**：环境微动、背景信息、P1/P2…Pn/`(Pn)` 点名的环境/道具/陈设，**必须**来自剧本原文 ∪ Beat 明文 ∪ Index ∪ 本镜 ENV 固定清单；**禁止**为丰富描写新增未提及实体。
- **光影统一归段（强制）**：「运镜与动作流」（含环境微动、BG、P1–Pn、`(Pn)`）**禁止**写光线/光影/色温/投影/光斑/灯闪等；上述内容**只**写入「动态连续光影/焦点」与「光线连动弧光」。
- 运镜与动作流按 `P1/P2/P3…`；**呈现序=上游建置→入戏**（内容规则不在此重述）：P1 先把上游**建置段**拍成可读起幅，再进入 P2…Pn 拍**入戏段**；每 P 显式景别 + 显式运镜；对白 `(Pn)` 带完整语气层（§六）。
- 保留 `CHAR/PROP/ENV` 方括号标签；凡 Index 与 Core Scene Info 双源均出现的实体**必须**使用标准表达（§一.0.1），名称逐字取自 Scene Subject Index。已入 Index 的**群演簇**须写 `CHAR:[@簇名]` 并补充随机差异化动势描述；未入 Index 的匿名背景人群用自然语言，**禁止** `EXTRA:`。段首可用中文维度引导。
- **禁分镜推演与规则逻辑入正文（硬约束）**：`Video Content (CN)` **禁止**写入——Beat/上镜承接说明；**`────【Beat切换说明】────` 整块及其字段**（`建置更新=`/`ENV变=`/`{Beat终态画内实体}`/`速查更新`/`视角换算台账`/`建置·朝向·视角自检`/`建置逻辑核销`/`差集处置` 等——**仅参考，只进 Logic**）；`收束落幅判定`/`下一镜`/`路径 A/B`/调度预留/桥接动机/执行优先级；环节编号（环节 0–6）、章节引用（§x.x）、上游工程字段（`{对白组边界}`/`{下一节拍起幅}`/`Beat完整逻辑继承` 等）；规则判定句式（「按…判定」「因上游…故…」「须…故本镜…」）；以及任何仅属 `Shot Logic (CN)` 的解释性、推演性文字。
- **禁上游空间推导术语与不可见说明入 Video Content（硬约束，§七.6）**：正文**禁止**出现——`0度/90度/180度/270度` 作工程坐标、`顺时针回转 N 度`/`回转 180 度`、`360度拓扑`、`转角对照`、`衍生0度=主环境N度`、`(N+90)%360`/`(N_对手+180)%360`、`view_angle_from_main`、`empty_view_delta`、`angle_mapping`、`topology_360`、`zero_degree_anchor`；以及**任何「不可见/不再看见/机位后方半空间/画外某某」类句**（画外内容沉默省略）。**须转译为镜头语言**：机位落点（如「会议桌长边侧面、胸口高度 Eye-level」）、**运镜名**（Reverse Shot / Arc Orbit / OTS / POV 等，**不写度数**）、**画内可见**背景（如「背景为半开木门与门外走廊」）、方向性物体**可见面变化**（如「椅背朝向镜头、门扇向室内开启停在画面右侧」）。`ENV:[180度办公室会客区_桌后反打]` 等 Index 原名**保留**作环境标签，但正文描述不得复读 ENV 名中的角度前缀当空间说明。
- **黑名单自检**：禁【Beat切换说明】原文/字段；禁工程坐标与度数回转；禁「不可见/机位后方」说明；**允许**运镜名 + 画内可见 BG 更替；禁 `N度` 作人物朝向/光源的工程描述。

   - **时序与主拍**：P 段按叙事时间推进；每段点名主拍角色及其相对落位；对白落在说话人主拍段；长运镜 ≥4s 须拆 P 段。

   - **正例骨架**：P1 起幅锁定全员站位（接上镜切点或本 Beat 建置；ENV 微动）→ P2 在该站位上 MCU+Push 入戏对白（听者空间可检索）→ P3 按站位关系 Arc/OTS 切可读面+落幅 → 终段 `下镜预留` 收束 → 光影两段另写。
   - **反例**：❌ 跳过 P1 建置直接「跟拍追逐+特写怒脸」｜❌ P1 写了站位，P2 起只堆动作/表情、角色左右前后消失｜❌ 为 Orbit/Whip 好看把建置里画左的人拍成画右。

3. **动态连续光影/焦点（Mandatory · 与下段独占全部光学；规则权威 §0.06 / §四）**：本镜全部光线/色温/投影/光斑/灯闪等**只写本段+下段**，禁入运镜与动作流/§七.7。**书写顺序**：可见光源清单(1–3) → 各源作用范围+可见效果 → Rim/Key 方位与具名受光面 → Fill/反射 → 投影半影（柔散） → CHAR/PROP 接地影+色溢出 → 冷暖 → 运镜中光向/焦点连续。不可见源零实体名；禁位置前缀；受光实体白名单；须覆盖 ≥3 具名 ENV/PROP 受光面 + 每主要 CHAR ≥1 句受光/色溢出。
4. **光线连动弧光（Mandatory · 与上段共同独占光影）**：写光色如何服务情绪阶段，及**作用范围/强度随运镜的变化**（须同写物理动机：机位相对光源、遮挡、主体进出光区）；可与 §七.7 物理微动对照联动，但光学句不得写回动作流。禁氛围空话、禁位置前缀、禁不可见实体名、禁无依据新建灯具。

5. **物理文字生成**：上游有文字类内容须写可见关系；仅新生成字案时交代文本、时机、位置与外形。无则写“无”。
6. **品质收束（Mandatory，每镜末尾固定句）**：五段写完后，**必须以独立收束句**结尾，原文逐字为：`人物面部稳定不变形，动作自然流畅，无卡顿无闪烁，无背景音乐，无字幕，视频全程禁止出现外形、着装、配饰完全一致的人物，禁止生成同款分身、双胞胎效果，同一画面中仅保留单个对应人物，不出现人物重复复刻，高清，细节丰富，电影质感，色彩自然，光影层次清晰可读`。用 `<br>` 与上段分隔；**禁止**改写、删减、拆分、翻译或移到段中；**禁止**漏写。输出前自检：`Video Content (CN)` 单元格**末尾**须等于该原文。（「光影层次清晰可读」≠均匀平光；须服从本镜 ENV 光学与 §0.06 / §四.5-E。）

### 九、兼容列留空规则 (Empty Compatibility Columns)
1. 保留原表头与列顺序（**固定 14 列，顺序不可增删/调换**）；除 `Video Content (CN)` 外，Start/End/Keyframes 及其中文列均留空。
2. **留空列写法（强制，防列错位）**：须留空的列写为**空单元格** `| |`（两竖线之间可有 0–1 个空格），**禁止**：
   - 多写或少写 `|`（每行 `|` 分隔后的单元格数必须 = 14）；
   - 在空列位置插入占位符（如 `-`、`N/A`、`无`、`空`、`(留空)`）；
   - 在 `Duration (s)` 与 `Video Content (CN)` 之间、或 `Video Content (CN)` 与 `Associated Entities` 之间**额外插入空 `|`**（这是最常见错位源：多一个空列会把 `Duration` 挤进 `Video Content`，导致 apply 失败）。
3. **列位对照（强制，输出前默数）**：

| # | 列名 | 本分镜填什么 |
| :--- | :--- | :--- |
| 1 | `Shot ID` | `{Scene ID}_SHzz`（§二.8；含字母后缀如 `EP01_SC01B_SH01`） |
| 2 | `Shot Name` | 核心动作简述 |
| 3 | `Scene ID` | 上游原样（如 `EP01_SC01` / `EP01_SC01B`） |
| 4 | `Shot Logic (CN)` | 推演全文；单元格内换行只用 `<br>`，**禁裸换行、禁未转义的 `\|`** |
| 5 | `Start Frame` | **空** |
| 6 | `Video Content` | **空**（英文视频列不写；内容只进第 11 列） |
| 7 | `Duration (s)` | **正整数秒**（如 `11`）；由基准 T 经 §二.4 **±20% 浮动**取整，钳制 [4,15]；禁空、禁单位后缀、禁小数（除非上游明确要求） |
| 8 | `Keyframes` | **空** |
| 9 | `End Frame` | **空** |

4. **正确空列骨架（复制对照）**：`Shot Logic` 之后到 `Associated Entities` 之前，空列模式必须是：

```text
| <Shot Logic> |  |  | <Duration> |  |  |  | <Video Content (CN)> |  |  | <Associated Entities> |
```

即：Logic 后 **2** 个空列 → Duration → **3** 个空列 → Video CN → **2** 个空列 → Entities。  
**错误示例（多一个空 `|`，禁止）**：`| <Logic> | | | 11 | | | | | <Video CN> | | | <Entities> |`（Duration 与 Video CN 之间多了一格，解析后 Duration 错位）。

5. 完整性校验 `Shot ID`、`Scene ID`、`Shot Logic (CN)`、`Video Content (CN)`、`Duration (s)`、`Associated Entities`：**`Shot ID`/`Scene ID` 须满足 §二.8 三层编码与连续编号**；实体列与正文须满足 §一.0.1 标准实体表达双源交集规则；**`Video Content (CN)` 须逐镜核验 Beat 实体零缺失**——本镜承担 Beat 中每一个 `CHAR:`/`PROP:`/`ENV:` 须在正文可检索，`Associated Entities` 不得多于正文引用、正文不得少于 Beat 实体清单；**须逐镜核验建置角色全覆盖**——对照本镜映射各 Beat【建置】角色清单（合镜取并集），P1/`Associated Entities`/正文三者交集须含全部建置角色，`Shot Logic` 的 `建置角色覆盖:` 漏项须为无；**须逐镜核验环境标签**——最少含 1 个 `ENV:[...]`，本镜有明确环境切换要求时须按切换次数写出对应数量的 `ENV:[...]`，缺失或数量不足须补写后再输出（§一.1、§一.2、§一.3、§七.4、§八）。
