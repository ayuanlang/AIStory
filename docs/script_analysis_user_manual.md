# 📗 AI 剧本分析操作手册

把当前分集剧本拆解为场景、角色、道具、环境和后续制作可用的资产资料。

> 适用场景：你已经有某一集的剧本文本，需要把它分析成可制作的结构化内容。  
> 如果还没有分集剧本，请先阅读 [生成剧本操作手册](script_generation_user_manual.md)。

## 🚀 快速路径

| 步骤 | 页面位置 | 要做什么 | 完成标志 |
|---|---|---|---|
| 1 | 分集页面 | 打开目标分集 | 顶部显示正确分集名称 |
| 2 | 原始编辑器 | 粘贴或检查剧本文本 | 剧本内容完整清楚 |
| 3 | 页面右上 | 点击 **AI 剧本分析与生成** | 出现场景拆解进度 |
| 4 | 进度诊断面板 | 等待四个阶段完成 | 阶段显示“已完成” |
| 5 | 总结报告 | 查看资产、场景、告警 | 结果可人工复核 |
| 6 | 三阶段面板 | 检查剧本优化、资产清单、资产设计 | 错漏项明确 |
| 7 | 修正/重跑 | 按问题范围修正、重排或重跑 | 结果符合制作要求 |

## 🎯 功能说明

**AI 剧本分析与生成** 位于某一集的剧本编辑页。它会读取当前分集剧本，并生成：

| 输出内容 | 用途 |
|---|---|
| 剧本优化结果 | 帮你理解 AI 如何整理、继承和优化原剧本 |
| 场景分析结果 | 把文本拆成可制作的场景结构 |
| 资产清单 | 提取角色、道具、环境、海报等主体 |
| 资产设计 | 为后续图片、视频、镜头生成提供资料 |
| 总结报告 | 显示新增资产、场景数量、运行时长和告警 |

## ✅ 使用前检查

| 检查项 | 为什么重要 |
|---|---|
| 是否选对项目和分集 | 避免分析错误内容 |
| 剧本文本是否完整 | 文本缺失会导致场景和资产漏提取 |
| 人物/地点/道具名称是否统一 | 减少重复资产和命名混乱 |
| 关键动作是否写清方向和落点 | 避免空间关系误判 |
| 剧本分析接口是否可用 | 分析任务依赖可用 AI 接口 |

## 📝 准备原始剧本

在原始编辑器中粘贴或输入当前分集剧本。

推荐写法：

- 按场次或剧情段落分开。
- 人物对白单独成行。
- 重要道具、环境、动作不要省略。
- 进出门、拿放物体、站位移动，要写清动作发生前的位置和动作后的落点。

示例：

> 阿杰原本站在门外，把门向里推开后进入客厅，停在茶几左前方半步处，面向坐在沙发中段的母亲。

这种写法能帮助系统判断人物位置、门的开关方向、进入路径和最终落位。

## ▶️ 开始分析

1. 确认当前分集和剧本文本无误。
2. 点击 **AI 剧本分析与生成**。
3. 等待按钮变为“AI正在为您深度拆解剧本...”。
4. 观察 **场景拆解进度** 和 **进度诊断面板**。

如需中断，点击 **停止分析** 或进度区域里的 **停止任务**。

> 停止后的结果不一定完整。是否可用，以最终完成提示和总结报告为准。

## 📊 看懂进度诊断面板

| 阶段 | 页面显示 | 说明 | 常见操作 |
|---|---|---|---|
| 1 | **剧本优化** | 理解原文，整理剧情、动作、对白和风格 | 检查是否误解剧情 |
| 2 | **资产提取** | 提取角色、道具、环境、海报等主体 | 不满意可点 **重跑** |
| 3 | **场景编排** | 生成场景/分镜规划表 | 不满意可点 **重排** |
| 4 | **资产生成** | 生成更完整的资产设计资料 | 可全部、分类或单实体重跑 |

如果某阶段显示“缺前置”，说明前面的阶段还没有成功完成，不能直接跳到当前阶段。

## 🔍 分析完成后先看什么

完成后，页面会显示“解析大功告成”或“分析管线已完成”等提示，并展示总结报告。

优先检查：

| 区域 | 重点看什么 |
|---|---|
| **资产入库统计** | 本次新增了多少角色、空镜、道具；当前总量是多少 |
| **场景画面搭建** | 本次新增了多少场景；当前分集总量是否合理 |
| **运行时长** | 是否异常过长，是否可能卡顿或重试过 |
| **提示/告警** | 是否需要人工复核 |
| **剧本角色与场景盘点单** | 是否漏角色、漏道具、漏环境，或名称不一致 |

## 🧪 三阶段结果怎么检查

### ① 第一阶段：剧本修改说明 / 优化后剧本 / 全局风格

检查重点：

- 是否误解剧情。
- 是否改动了不该改的设定。
- 是否保留关键对白和动作。
- 风格是否和项目一致。

### ② 第二阶段：场景分析结果 / 资产清单

检查重点：

- 场景是否拆得合理。
- 角色、道具、环境是否漏掉。
- 场景入口状态、出口状态是否清楚。
- 动作方向、站位、空间关系是否准确。

常用处理：

| 问题 | 推荐操作 |
|---|---|
| 资产漏提取 | 对资产提取阶段点 **重跑** |
| 场景拆分不理想 | 对场景编排阶段点 **重排** |
| 少量名称不统一 | 写入补充说明后点 **修正生成结果** |

### ③ 第三阶段：资产设计

检查重点：

- 角色设计是否符合剧本身份。
- 道具是否有明确用途。
- 环境是否和场景空间一致。
- 海报/封面是否符合项目气质。

重跑方式：

| 方式 | 适合情况 |
|---|---|
| **全部重跑** | 多类资产都明显跑偏 |
| **分类重跑** | 只是一类资产有问题，例如环境或道具 |
| **单实体重跑** | 只有某一个角色、道具或环境不满意 |

## 🧰 修正生成结果

如果系统提示“首轮检测到问题，已写入补充说明。请点击‘修正生成结果’”，说明第一次分析已完成，但有可改进项。

建议流程：

1. 先阅读盘点单、告警和三阶段结果。
2. 在补充说明中写清问题。
3. 点击 **修正生成结果**。
4. 等待系统基于已有结果二次修正。

补充说明示例：

| 问题 | 可写成 |
|---|---|
| 漏道具 | 第 4 场漏掉母亲手里的旧照片，请补为关键道具。 |
| 门方向错 | 男主进入房间前在走廊，推门向里进入卧室，门不要写成向外开。 |
| 服装不连续 | 女主第 2 场已经换成黑色外套，后续场景保持一致。 |

## 🛠️ 异常速查

| 问题 | 常见原因 | 处理方式 |
|---|---|---|
| 分析失败 | 接口不可用、超时、文本过长、返回格式不完整 | 查看失败提示；确认接口；缩短文本；点击 **重试分析** |
| 分析被停止 | 手动点击停止，或任务被中断 | 如需继续，重新点击 **AI 剧本分析与生成** |
| 剧本分析返回告警 | 系统加载了可用内容，但结构需要复核 | 先看三阶段面板和盘点单；少量问题用 **修正生成结果** |
| 盘点单提示缺失 | 场景提到的角色/道具/环境未被完整收录 | 统一名称，补充说明后修正；严重时重试分析 |
| 资产生成有失败子任务 | 某类资产返回不完整或导入失败 | 优先点 **重跑失败路由**；再考虑分类或单实体重跑 |
| 角色/道具/环境重复 | 同一对象多个叫法混用 | 统一命名，对资产提取阶段 **重跑** |
| 场景拆分太碎 | 同一连续时空被拆成太多段 | 补充说明“同一地点连续对话不要拆太碎”，再点 **重排** |
| 场景拆分太粗 | 转场、时间跳跃或行动线切换未拆开 | 补充分场标记或说明“转场后必须拆新场景”，再重排 |
| 保存后没看到更新 | 页面缓存、刚完成任务还未刷新 | 点击 **保存修改**，切换分集再回来，或刷新项目数据 |

## 🧩 推荐工作流

1. 打开目标分集。
2. 检查剧本文本是否完整。
3. 补清人物、地点、道具和关键动作。
4. 点击 **AI 剧本分析与生成**。
5. 等待四个阶段完成。
6. 查看总结报告和盘点单。
7. 检查三阶段结果。
8. 小问题用 **修正生成结果**。
9. 阶段性问题用 **重跑** 或 **重排**。
10. 确认结果无误后，再进入镜头、图片、视频等后续制作环节。

## 💡 使用建议

- 剧本越清楚，分析越稳定。
- 人物、地点、道具不要频繁换叫法。
- 动作要写清起点、方向、路径和落点。
- 小范围问题优先单实体重跑或分类重跑。
- 遇到告警先复核，不要急着删除结果。
- 长剧本按分集处理，不要把多集内容一次性放进当前分集。
