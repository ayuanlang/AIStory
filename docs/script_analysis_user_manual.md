# 📗 AI 剧本分析操作手册

把本集剧本拆清楚、管起来，方便后面按场次做场景、认资产、出分镜。

> 适合：本集剧本已写好，要拆成可制作内容。  
> 还没有剧本？先看 [生成剧本操作手册](script_generation_user_manual.md)。

**正常情况**：点一次 **AI 剧本分析**，系统会按五个步骤尽量把本集工作做完（编排、设计、导入、分镜按场推进）。  
**也可能中断**：大模型分心漏项、超时、网络异常、接口抖动等，会让某一步或某一场没做完。这时不必整集推倒重来——用 **重跑 / 重排 / 再导入** 只补缺的部分，效率更高、也更省调用成本；只有上游大改或结果整体不可用时，才从头再跑。

---

## 🚀 快速上手

1. 打开目标分集，检查剧本完整、名称统一；确认 **剧本分析 API** 已按下方建议选好。  
2. 点 **AI 剧本分析**，等进度五个步骤完成。  
3. 看 **本集齐套**（应有 / 已齐）；缺项再局部补，不必整集重做。  
4. 需要时用 **编辑 / 导入 / 重跑·重排**；再进工作区继续做。  
5. 卡住了：点进度里的 **失败节点** 看原因与处理建议，或点右上角 **AI 诊断**（Agent 多轮对话）。

> **两条铁律**  
> ① 上环节改了 → 下环节要重跑才生效。  
> ② 重跑 / 重排 / 再导入前，先删旧内容——系统不会自动覆盖已生成、已导入的内容。

---

## 🔌 剧本分析 API 怎么选

分析前在页面上的 **剧本分析 API** 下拉框选好模型。不同模型在稳定度、细节与合规拦截上差别明显，建议按下面优先级选：

| 选择 | 说明 |
|---|---|
| **优先：G1 组 Gemini 系列** | 日常首选。其中 **Gemini 2.5** 性价比最高，输出结果也最稳定，适合整集主流程。 |
| **备选：GPT 5.5** | 生成细节更细，但价格较高；偶发「放飞自我」（扩写过猛、结构跑偏），结果不一定更好，适合对细节要求高且愿意复核时用。 |
| **合规拦截过严时：DeepSeek** | 部分境外模型内容审查有时偏严，正常剧本也被拒或中断时，可改用 **DeepSeek** 继续分析。 |

简记：**先 G1 Gemini（尤其 2.5）→ 要更细再用 GPT 5.5 并多检查 → 被境外模型拦了就换 DeepSeek。**

### 价格说明

剧情复杂度（场次多少、角色/道具/环境量、篇幅长短等）对最终花费影响很大，系统难以事先给出固定报价。请：

1. **先选合适单价的 API**（日常优先 G1 Gemini 2.5 等性价比更高的选项）。  
2. **分析结束后到消费记录核对实际扣费**。  

经验区间：单集完整剧本分析大约 **500–2000 积分**（随剧情与所选模型浮动；局部重跑会额外计费）。

## 🎯 当前分析流程做什么

| 步骤 | 作用 |
|---|---|
| **分场与环境规划** | 先拆 Scene；环境规划只返回逐场主环境，由程序拼回对应 Scene 再交给场景现场编排 |
| **逐场优化 ∥ 资产清单** | 各 Scene 执行文戏、按需特效/仙攻、场景现场编排、建置入戏；同时提取角色、道具、环境、封面清单 |
| **场景编排 ∥ 资产设计** | 两个上游分支汇合后按场落表；资产设计同步生成角色 / 道具 / 环境 / 封面设计 |
| **分镜生成** | 当前 Scene 编排完成且关联环境资产设计就绪后，按场出分镜 |

拓扑为：**分场 → 环境规划 →（资产清单 ∥ 逐场优化）→（场景编排 ∥ 资产设计）→ 分镜**。进度一律以**本集**为准。

## 🔘 导入、编辑、重排 / 重跑——区别

正常跑通时很少用；中断或局部不对时，用它们**只补缺、不重做整集**，省时间也省成本。记「动作对象不同」：

| 按钮 | 在干什么 | 改的是哪里 | 典型什么时候用 |
|---|---|---|---|
| **编辑** | 打开当前步骤已有结果，人工查看或改字段后保存 | **分析页里的草稿结果**（还没进工作区，或与工作区不同步） | 改场名、补漏字、对齐资产名；小改、能手改时 |
| **导入** | 把当前步骤的分析结果**写入工作区**，供后面制作使用 | **工作区**（场景 / 资产 / 分镜） | 结果检查 OK，要去场景页、资产页、分镜页继续做 |
| **重排** | **场景编排**专用：让 AI **重新生成**场景编排表 | **分析页的场景编排结果**（生成新草稿） | 场拆太碎/太粗、场次结构不对，手改划不来 |
| **重跑** | 其他步骤的「重新生成」（资产清单 / 资产设计 / 分镜等） | **分析页对应步骤的结果** | 整类结果不对，要 AI 再算一遍 |

对照记：

- **编辑** = 人改草稿  
- **导入** = 草稿进工作区（才能接着做）  
- **重排 / 重跑** = AI 重算草稿（不是导入，也不等于进工作区）

> **常见误区**  
> - 只 **编辑** 不 **导入** → 工作区还是旧的，后面制作看不到你的修改。  
> - 只 **重排 / 重跑** 不删旧、不 **导入** → 可能新旧混在一起，或工作区仍是上一版。  
> - **重排** 只出现在场景编排；资产清单、资产设计、分镜用的是 **重跑**。

建议顺序（要替换旧结果时）：

1. 先删工作区 / 分析页里受影响的旧内容  
2. **重排** 或 **重跑**（需要 AI 重算时）或 **编辑**（能手改时）  
3. 确认无误后 **导入** 工作区  
4. 看「本集齐套」是否对齐

## 🗂️ 工作区是什么

**工作区** = 点 **导入** 之后，真正用来继续制作的地方。

| 工作区 | 放什么 |
|---|---|
| 场景工作区 | 一场一场的场景 |
| 资产工作区 | 角色、道具、环境、封面 |
| 分镜工作区 | 每场下的镜头 |

分析页是「算出来」；工作区是「接着做」。没导入，后面页面往往用不了。  
「本集齐套」里的 **已齐**，也是对照工作区统计的。

## 🩺 AI 诊断（Agent）

右上角、操作手册旁的听诊器图标。

- **做什么**：以 **Agent 多轮对话** 方式协助排查——自动带上操作手册、系统日志、本集工作区概况；可追问细化建议，也可把整段对话发给运营人员。  
- **怎么用**：点开 → 在对话框描述问题 → 按回复继续追问；需要时可点 **发送对话给运营**。可加载上次诊断对话。进度里标红的失败节点也可点开，先看原因与处理建议，再从那里直接开 **AI 诊断**（会带上该节点上下文）。  
- **注意**：只给建议，不会自动改内容或覆盖工作区；**每一轮对话**按剧本分析接口计费（余额不足会提示充值）。仅「发送对话给运营」且已有回复时不计费。

适合：进度卡住、齐套缺项、不知该重跑谁、需要来回确认细节。自己很清楚怎么改时，不必用。

---

## 📌 场景编排（一句话 + 要点）

不是改故事，而是把剧本**按场工程化**：拆场、对齐资产清单名称，方便后面分场管理和自动认资产。

检查时看：场次是否合理、名字是否对齐清单、每场人/物/环境是否标清。

---

## 📊 进度与本集齐套

**进度状态**：已完成 / 处理中 / 等待中 / 失败。失败节点可点击，查看错误原因、处理建议，并衔接 AI 诊断。

**本集齐套**：`应有` = 本集清单要求数量；`已齐` = 工作区已对上数量。  
缺了可点「重新生成未齐套的类型」，或开 AI 诊断。

---

## ⚠️ 上改下要重跑

| 你改了 | 后面一般要重做 |
|---|---|
| 分场、环境规划、逐场优化 / 原文 | 资产清单 → 场景编排 → 资产设计 → 分镜 |
| 资产清单 | 场景编排、资产设计（及依赖的分镜） |
| 场景编排 | 场景导入、相关分镜 |
| 资产设计 | 相关分镜 / 工作区对应资产 |

顺序：**改好 → 删旧 → 重排或重跑或编辑 → 导入 → 看齐套**。

---

## 🛠️ 常见问题

| 现象 | 怎么办 |
|---|---|
| 分析失败 / 中途停住 | 点进度里的失败节点看原因与建议；只对缺的步骤 **重跑 / 重排 / 再导入**，不必整集重开；或从节点里开 **AI 诊断** |
| 提示违规 / 内容被拒 | 境外模型审查过严时，把 **剧本分析 API** 换成 **DeepSeek** 再跑 |
| 结果细节乱 / 扩写过猛 | 若用的是 GPT 5.5，可改回 **G1 Gemini 2.5** 后局部 **重跑 / 重排** |
| 工作区还是旧的 | 是否只编辑没导入？导入前是否先删了旧内容？ |
| 分镜不出 | 场景是否已导入？环境资产是否已齐？ |
| 场拆不对 | 先删旧 → **重排** → 确认后 **导入** |
| 清单/设计不对 | 先删旧 → **重跑** → 确认后 **导入** |
| 小改名字/字段 | **编辑** 保存 → 再 **导入**（必要时先删旧） |

---

## 💡 记住这些就够

- 正常一次分析应尽量做完；中断了优先**局部重跑 / 重排 / 再导入**，别一上来整集重开。  
- 剧本清楚、叫法统一，后面最省事。  
- API 优先 **G1 Gemini（尤其 2.5）**；要更细可用 GPT 5.5（需多复核）；被境外审查拦了换 DeepSeek。  
- 费用随剧情波动大：选好单价，事后在**消费记录**核对；经验约 **500–2000 积分**/集。  
- **编辑**改草稿，**导入**进工作区，**重排/重跑**让 AI 重算。  
- 上环节改了，下环节要重做；重做前先删旧。  
- 场景编排管分场与认资产，不改故事。  
- 不确定就点 **AI 诊断**，用 Agent 对话追问到弄清为止。
