# AI 剧本分析操作手册

本文面向日常使用者，说明如何把当前分集剧本分析成场景、角色、道具、环境和后续制作可用的资料。

如果你还没有分集剧本，需要先生成全局框架和分集文本，请阅读 [生成剧本操作手册](script_generation_user_manual.md)。

## 一、功能说明

**AI 剧本分析与生成** 位于某一集的剧本编辑页。它的作用是分析当前分集剧本，把文字剧本拆成场景，并提取角色、道具、环境、海报等资产资料。

简单理解：

1. **生成剧本**：从创意和大纲写出分集剧本。
2. **剧本分析**：把已有分集剧本拆成可制作的场景和资产。

## 二、使用前准备

开始前建议确认以下内容：

1. 已进入正确的项目。
2. 项目概览中的基础信息尽量补完整，例如剧名、类型、规格、语言、受众等。
3. 已经有可分析的分集剧本文本。
4. 已打开目标分集，并把剧本文本放到当前分集的原始编辑器中。
5. 选择合适的剧本分析接口配置。如果页面上有“剧本分析”的接口选择器，请确认使用的是可用的供应商和模型。

## 三、分析当前分集剧本

### 1. 打开目标分集

在项目中选择要分析的分集。进入分集后，页面顶部会显示当前分集名称和段落数量。

如果没有选择分集，页面会提示“请选择或创建一个分集开始写作”。这时需要先创建或选择一个分集。

### 2. 准备原始剧本

在原始编辑器中粘贴或输入剧本文本。

建议格式尽量清楚：

- 按场次或剧情段落分开。
- 人物对白单独成行。
- 重要动作、场景、道具不要省略。
- 如果人物进出、物体移动、门窗开关等动作很关键，请写清动作发生前的位置和动作后的落点。例如：“阿杰原本站在门外，把门向里推开后进入客厅”。

这样做可以减少 AI 对空间关系和动作方向的误判。

### 3. 点击 AI 剧本分析与生成

确认剧本内容无误后，点击 **AI 剧本分析与生成**。

分析开始后，按钮会变成“AI正在为您深度拆解剧本...”，页面会出现进度信息。复杂剧本可能耗时较长，请耐心等待。

如果需要中断任务，可以点击 **停止分析** 或进度区域里的 **停止任务**。停止后，本次分析不会继续完成，页面会显示任务已停止。

### 4. 看懂进度诊断面板

页面上方的 **进度诊断面板** 会显示四个主要阶段：

1. **剧本优化**：系统先理解并整理原始剧本。
2. **资产提取**：提取角色、道具、环境、海报等主体资料。
3. **场景编排**：把剧本拆成场景或分镜规划表。
4. **资产生成**：为提取出的主体生成更完整的设计资料。

每个阶段完成后会显示“已完成”。如果某一阶段提示“缺前置”，说明前面的阶段还没有成功完成，不能直接跳到当前阶段。

### 5. 查看分析状态

分析时，页面会显示 **场景拆解进度**，常见步骤包括：

- 剧本统筹
- 美术提取
- 分镜规划
- 资产生成
- AI 总结报告

下方还会显示最近的处理记录。它可以帮助判断当前卡在理解剧本、导入场景，还是生成资产。

### 6. 分析完成后看什么

完成后，页面会显示类似“解析大功告成”或“分析管线已完成”的提示，并出现总结报告。

建议按顺序检查：

1. **资产入库统计**：本次新增了多少角色、空镜、道具，以及当前总量。
2. **场景画面搭建**：本次新增了多少场景，当前分集总量是多少。
3. **运行时长**：用于判断任务是否异常耗时。
4. **提示或告警**：如果有告警，说明结果可以继续使用，但需要人工复核。
5. **剧本角色与场景盘点单**：核对是否有缺失角色、道具、场景，或命名不一致的问题。

## 四、分析结果面板怎么用

分析页下方有三个阶段结果面板。

### 第一阶段：剧本修改说明 / 优化后剧本 / 全局风格

这里主要看 AI 如何理解和优化原剧本。适合检查：

- 是否误解剧情。
- 是否改动了不该改的设定。
- 风格是否和项目一致。

### 第二阶段：场景分析结果 / 资产清单

这里是后续制作最关键的部分。适合检查：

- 场景是否拆得合理。
- 角色、道具、环境是否漏掉。
- 场景入口状态、出口状态是否清楚。
- 动作方向和空间关系是否准确。

如果资产提取不理想，可以在进度诊断面板中对资产提取阶段点击 **重跑**。

如果场景编排不理想，可以点击 **重排**，让系统重新生成场景规划。

### 第三阶段：资产设计

这里会展示角色、道具、环境、封面/海报等资产设计结果。

如果某类资产不满意，可以使用 **资产生成重跑选择**：

- **全部重跑**：重新生成所有资产类型。
- **分类重跑**：只重跑角色、道具、环境或海报等某一类。
- **单实体重跑**：只重跑某一个角色、道具或环境。

重跑前建议先确认问题范围，能单实体重跑时不要全量重跑，以免覆盖较多已经满意的结果。

## 五、修正和二次处理

如果系统提示“首轮检测到问题，已写入补充说明。请点击‘修正生成结果’”，说明第一次分析已经完成，但存在可改进项。

处理方式：

1. 先阅读提示、盘点单和阶段结果。
2. 在补充说明中写清楚要修正的问题。
3. 点击 **修正生成结果**。
4. 等待系统基于已有结果进行二次修正。

补充说明建议写得具体，例如：

- “第 4 场漏掉了母亲手里的旧照片，请补为关键道具。”
- “男主进入房间前在走廊，推门向里进入卧室，门不要写成向外开。”
- “女主第 2 场已经换成黑色外套，后续场景保持一致。”

## 六、常见异常处理

### 1. 点击 AI 剧本分析与生成后提示分析失败

原因可能是接口配置不可用、模型超时、剧本文本过长、返回格式不完整，或供应商拒绝处理部分内容。

处理：

1. 查看红色失败提示中的具体原因。
2. 确认剧本分析接口配置可用。
3. 如果剧本很长，先拆短或只分析当前分集。
4. 如果提示返回格式不完整，点击 **重试分析**。
5. 如果多次失败，检查剧本中是否有供应商不允许处理的内容，并适当改写。

### 2. 分析被手动停止

页面会提示“分析任务已停止”。

处理：如果只是误点停止，点击 **重试分析** 或重新点击 **AI 剧本分析与生成**。如果停止前已经生成了部分结果，也要以最终完成提示为准，未完成的结果不要直接用于后续制作。

### 3. 出现“剧本分析返回告警”

这类告警通常表示系统已经尽量加载了可用内容，但有一部分结构需要人工复核。

处理：

1. 不要立刻删除结果。
2. 先检查第一、第二、第三阶段面板。
3. 重点核对资产清单、场景表和盘点单。
4. 如果只缺少少量内容，可以补充说明后执行 **修正生成结果**。
5. 如果结构大面积错乱，建议点击 **重试分析**。

### 4. 盘点单提示有缺失

原因：场景里提到的人物、道具或环境没有被资产清单完整收录，或命名前后不一致。

处理：

1. 查看缺失项名称。
2. 判断是系统漏提取，还是原剧本命名不统一。
3. 如果是漏提取，写入补充说明并执行 **修正生成结果**。
4. 如果是命名不统一，先统一剧本文本或阶段结果中的名称，再重试分析。

### 5. 资产生成有失败子任务

总结报告中可能显示“并发子任务导入明细”，其中某些项为导入失败、返回不完整或 LLM 失败。

处理：

1. 查看失败项的类型和错误说明。
2. 如果页面提供 **重跑失败路由**，优先点击它，只重跑失败的部分。
3. 如果失败集中在某一类资产，可以使用 **分类重跑**。
4. 如果只有某一个实体失败，可以使用 **单实体重跑**。

### 6. 结果里角色、道具或环境重复

原因通常是原剧本中同一对象有多个叫法，例如“阿杰”“杰哥”“男主”混用。

处理：

1. 在原剧本或补充说明中写明统一名称。
2. 对资产提取阶段执行 **重跑**。
3. 必要时对第三阶段资产设计执行分类或单实体重跑。

### 7. 场景拆分太碎或太粗

处理：

1. 在补充说明中写明期望拆分方式，例如“同一地点连续对话不要拆太碎”或“转场后必须拆新场景”。
2. 点击场景编排阶段的 **重排**。
3. 如果原剧本文本结构本身不清楚，先手动补充分场标记，再重新分析。

### 8. 保存修改后没有看到更新

处理：

1. 确认已经点击 **保存修改**。
2. 切换到其他分集再切回来，或刷新当前项目数据。
3. 如果是刚刚完成生成或分析，等待几秒后再刷新。

## 七、推荐工作流程

推荐按下面顺序使用：

1. 在项目概览补齐基础信息。
2. 打开目标分集，检查剧本文本。
3. 在原始编辑器中补清人物、地点、道具和关键动作。
4. 点击 **AI 剧本分析与生成**。
5. 等待场景、资产和总结报告完成。
6. 查看盘点单和三阶段结果。
7. 对缺失、错漏或不满意部分执行修正、重排或重跑。
8. 确认结果无误后，再进入镜头、图片、视频等后续制作环节。

## 八、使用小建议

- 剧本越清楚，分析越稳定。人物、地点、道具不要频繁换叫法。
- 重要动作要写清起点、终点和方向，尤其是进出门、拿放物体、站位移动。
- 不满意时先判断问题在哪一层：剧本理解、资产提取、场景编排，还是资产设计。
- 小范围问题优先用单实体重跑或分类重跑，不要一上来全量重跑。
- 遇到告警不要慌，先看盘点单和阶段结果；告警不一定代表全部失败。
- 长剧本建议按分集处理，不要把多集内容一次性塞进当前分集分析。
