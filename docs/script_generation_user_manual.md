# 生成剧本操作手册

本文面向日常使用者，说明如何在项目中生成全局故事框架，并批量或单独生成分集剧本。

## 一、功能说明

**剧本生成** 位于项目编辑器右上角。它的作用是先生成项目级的故事框架，再根据框架生成每一集的剧本文本。

生成完成后，剧本会写入对应分集。之后可以进入分集页面，继续使用 **AI 剧本分析与生成** 把这一集拆成场景、角色、道具、环境和后续制作资料。

简单理解：

1. **生成剧本**：从创意和大纲写出分集剧本。
2. **剧本分析**：把已有分集剧本拆成可制作的场景和资产。

## 二、使用前准备

开始生成前，建议先确认：

1. 已进入正确的项目。
2. 项目概览中的基础信息尽量补完整，例如剧名、类型、规格、语言、受众等。
3. 已确认本项目是故事类项目，还是宣传片/广告片/文旅片项目。
4. 剧本分析接口配置可用。分集生成会使用同一类 AI 接口能力。
5. 如果项目已有分集剧本，请确认是否允许覆盖。全量生成和单集生成都可能覆盖目标范围内已有剧本。

## 三、进入剧本生成页

在项目编辑器右上角点击 **剧本生成**，进入生成器页面。

页面中可能会看到不同生成器：

- **故事生成器（全局 / 项目）**：适合连续剧、短剧、电影等故事类项目。
- **宣传片生成器（企业 / 产品 / 文旅）**：适合宣传片、广告片、文旅片等项目。

请选择和项目类型匹配的生成器。

## 四、填写基础生成信息

以故事生成器为例，常用字段包括：

- **载体规格 / 集数**：填写要生成的总集数，例如 12、20、24。
- **产品规格与节奏**：选择短剧快节奏、电影、通用连续剧等。
- **受众定位**：选择男频、女频或全受众。
- **天马行空的想法**：写下核心创意、人物关系、关键场面、必须出现的台词或结局方向。

写法不用太专业，能说明白即可。

示例：

> 女主被家族误解，三年后带着新身份回归。第 3 集安排一次公开反击，第 8 集揭露男主一直暗中保护她，结尾要有雨夜对峙。

如果是宣传片生成器，请重点补齐宣传类型、产品/企业/景区信息、目标受众、核心卖点和片长节奏。

## 五、生成全局框架

点击 **生成全局框架**。

生成完成后，页面下方会出现 **已生成全局框架（Markdown）**。你可以先预览，也可以切到编辑模式手动修改，然后保存。

全局框架相当于整部作品的大纲。分集剧本会根据它继续展开，所以建议先检查：

1. 集数是否正确。
2. 主线是否符合预期。
3. 主要人物关系是否正确。
4. 每集推进是否清楚。
5. 风格、受众、节奏是否跑偏。

如果全局框架不满意，建议先修改框架，再继续生成分集剧本。

## 六、生成分集剧本

全局框架确认后，可以选择两种方式。

### 1. 全量生成分集

点击 **全量生成分集**，系统会按照集数范围生成所有分集剧本。

适合以下情况：

- 新项目第一次生成。
- 全局框架已经调整完成，需要重新生成整批分集。
- 当前已有内容可以被覆盖。

系统会提示是否覆盖目标范围内已有分集剧本。确认后，任务开始执行。

### 2. 单集生成

在“单集”输入框填入集数，再点击 **单集生成**。

适合以下情况：

- 只想重写某一集。
- 某一集生成失败，需要单独补生成。
- 某一集剧情调整后，需要重新生成。

注意：单集生成会覆盖该集已有剧本，请先确认当前内容是否还需要保留。

## 七、查看生成进度

生成过程中，页面会显示 **分集剧本进度快照**，包括：

- **状态**：运行中或空闲。
- **已处理**：当前处理到第几集。
- **已生成**：成功生成的集数。
- **失败**：生成失败的集数。
- **跳过**：被跳过的集数。

你可以使用这些按钮：

- **查看详情**：查看每集生成结果和失败信息。
- **刷新**：手动更新当前进度。
- **强制停止**：停止当前批量分集剧本任务。

复杂项目可能需要几分钟甚至更久，建议先观察进度是否持续变化，再决定是否停止。

## 八、检查生成结果

分集生成完成后，打开对应分集，检查剧本文本是否已经写入。

重点看：

1. 标题和集数是否正确。
2. 内容是否完整，有没有中途截断。
3. 是否符合项目全局框架和人物设定。
4. 人物名称、地点名称、关键道具名称是否前后一致。
5. 重要动作是否写清楚起点、终点和方向。

如果需要后续进入剧本分析，建议在生成结果中补清空间和动作信息。例如：“阿杰原本站在门外，把门向里推开后进入客厅”，比“阿杰开门进来”更利于后续分析。

## 九、常见异常处理

### 1. 提示 Episodes Count 无效

原因：没有填写有效集数，或集数不是正整数。

处理：回到剧本生成页，在 **载体规格 / 集数** 中填写正确数字，例如 12、20、24，然后重新生成。

### 2. 提示全局框架为空

原因：还没有生成或保存全局框架。

处理：先点击 **生成全局框架**，确认下方 Markdown 内容已经出现并保存，再执行 **全量生成分集** 或 **单集生成**。

### 3. 确认覆盖后生成了新内容，旧内容不见了

原因：全量生成或单集生成会覆盖目标范围内已有分集剧本。

处理：生成前请确认是否需要保留旧内容。如果需要对比旧版，建议先在外部或项目备注中备份关键内容，再执行覆盖生成。

### 4. 分集生成完成，但某几集失败

原因可能是模型返回异常、内容被供应商拦截、单集标题或集数解析失败、网络中断等。

处理：

1. 点击 **查看详情**，查看失败的是哪一集。
2. 打开失败分集，检查已有内容是否为空或不完整。
3. 对失败集数使用 **单集生成**。
4. 如果多次失败，简化全局框架中该集要求，避免一次性要求过多。

### 5. 分集生成一直显示运行中

原因可能是任务还在排队、模型响应较慢、网络请求未及时刷新，或后端任务卡住。

处理：

1. 先点击 **刷新** 查看最新状态。
2. 如果仍然长时间无变化，点击 **查看详情** 看是否有最新处理记录。
3. 确认不再需要等待后，点击 **强制停止**。
4. 停止后可以重新执行单集生成或全量生成。

### 6. 单集生成后没有跳到目标分集

处理：

1. 先点击 **刷新** 更新分集列表。
2. 手动打开目标集数。
3. 检查该集剧本文本是否已写入。
4. 如果没有写入，查看生成详情中是否有失败记录。

### 7. 生成内容跑偏

原因通常是全局框架不够清楚，或创意说明过于笼统。

处理：

1. 回到 **已生成全局框架（Markdown）**，修改跑偏的设定。
2. 在创意说明中补充更明确的限制条件。
3. 对目标集数使用 **单集生成**。
4. 如果全局方向都不对，再考虑重新生成全局框架和全量分集。

### 8. 生成内容中人物或地点名称混乱

处理：

1. 在全局框架中统一人物和地点名称。
2. 避免同一角色同时使用多个称呼，例如“阿杰”“杰哥”“男主”混用。
3. 重新生成受影响的单集。

## 十、推荐工作流程

推荐按下面顺序使用：

1. 在项目概览补齐基础信息。
2. 进入 **剧本生成**。
3. 填写集数、规格、受众和创意说明。
4. 点击 **生成全局框架**。
5. 检查并保存全局框架。
6. 点击 **全量生成分集**，或使用 **单集生成**。
7. 打开目标分集，检查剧本文本。
8. 对不满意的集数修改框架或说明后重新单集生成。
9. 确认分集剧本可用后，再进入剧本分析流程。

## 十一、使用小建议

- 先把全局框架调顺，再生成分集，整体效率更高。
- 小范围问题优先单集生成，不要一上来全量重跑。
- 生成前留意覆盖提示，避免误覆盖已经修改好的剧本。
- 想让后续剧本分析更稳定，生成剧本时就尽量保持人物、地点、道具命名统一。
- 重要动作要写清起点、终点和方向，尤其是进出门、拿放物体、站位移动。
