# 生成剧本操作手册

把项目创意、全局框架和人物设定，生成可编辑的分集剧本文本。

> 适用场景：你还没有完整分集剧本，或想按全局框架批量/单独重写某一集。  
> 后续步骤：分集剧本确认后，再进入 [AI 剧本分析操作手册](script_analysis_user_manual.md)。

## 快速路径

| 步骤 | 页面位置 | 要做什么 | 完成标志 |
|---|---|---|---|
| 1 | 项目概览 | 补齐剧名、类型、语言、受众等基础信息 | 项目信息不再明显缺项 |
| 2 | 剧本生成 | 填写集数、规格、受众和创意说明 | 生成参数清楚可读 |
| 3 | 剧本生成 | 点击 **生成全局框架** | 下方出现全局框架 Markdown |
| 4 | 剧本生成 | 检查并保存全局框架 | 主线、人物、集数正确 |
| 5 | 剧本生成 | 点击 **全量生成分集** 或 **单集生成** | 进度快照开始变化 |
| 6 | 分集页面 | 打开目标分集检查剧本文本 | 标题、集数、内容完整 |

## 功能说明

**剧本生成** 位于项目编辑器右上角。它用于先生成项目级故事框架，再把框架展开为每一集的剧本文本。

生成完成后，系统会把剧本写入对应分集。你可以直接编辑这些文本，也可以继续使用 **AI 剧本分析与生成** 把分集拆成场景、角色、道具、环境等制作资料。

## 使用前检查

| 检查项 | 为什么重要 |
|---|---|
| 项目是否选对 | 避免把剧本写入错误项目 |
| 项目基础信息是否完整 | 影响风格、类型、语言和受众判断 |
| 集数是否正确 | 影响全量生成范围 |
| 是否允许覆盖旧剧本 | 全量生成和单集生成都可能覆盖已有内容 |
| AI 接口是否可用 | 分集生成需要可用的剧本分析/生成接口 |

## 进入剧本生成页

在项目编辑器右上角点击 **剧本生成**。

常见生成器：

| 生成器 | 适合项目 |
|---|---|
| **故事生成器（全局 / 项目）** | 短剧、连续剧、电影、剧情片 |
| **宣传片生成器（企业 / 产品 / 文旅）** | 企业宣传、产品广告、文旅宣传 |

请选择和项目类型匹配的生成器。

## 填写生成信息

故事生成器常用字段：

| 字段 | 填写建议 |
|---|---|
| **载体规格 / 集数** | 填正整数，例如 `12`、`20`、`24` |
| **产品规格与节奏** | 选择短剧快节奏、电影、通用连续剧等 |
| **受众定位** | 选择男频、女频或全受众 |
| **天马行空的想法** | 写人物关系、关键冲突、必备场面、结局方向 |

示例：

> 女主被家族误解，三年后带着新身份回归。第 3 集安排一次公开反击，第 8 集揭露男主一直暗中保护她，结尾要有雨夜对峙。

宣传片生成器建议重点补齐：宣传类型、企业/产品/景区信息、目标受众、核心卖点、可信背书、片长和渠道。

## 生成全局框架

1. 点击 **生成全局框架**。
2. 等待页面下方出现 **已生成全局框架（Markdown）**。
3. 先用预览模式通读，再切到编辑模式修改。
4. 修改后点击 **保存修改**。

全局框架建议重点检查：

| 检查点 | 判断标准 |
|---|---|
| 集数 | 总集数与项目计划一致 |
| 主线 | 每集推进方向清楚，不跳跃 |
| 人物关系 | 主角、反派、盟友关系没有错位 |
| 风格 | 节奏、受众、类型符合项目定位 |
| 关键场面 | 你要求的桥段没有丢失 |

## 生成分集剧本

### 全量生成分集

点击 **全量生成分集**，系统会按集数范围生成所有分集。

适合：

- 新项目第一次生成。
- 全局框架已经调顺，需要整批生成。
- 目标范围内旧内容可以被覆盖。

系统会弹出覆盖确认。确认后，任务开始执行。

### 单集生成

在“单集”输入框填入集数，再点击 **单集生成**。

适合：

- 只重写某一集。
- 某一集生成失败，需要补生成。
- 某一集剧情调整后，需要重新生成。

> 注意：单集生成会覆盖该集已有剧本。执行前请确认旧内容是否还需要保留。

## 查看生成进度

生成过程中会出现 **分集剧本进度快照**。

| 指标 | 含义 |
|---|---|
| **状态** | 当前任务运行中或空闲 |
| **已处理** | 已处理到的集数进度 |
| **已生成** | 成功生成的集数 |
| **失败** | 生成失败的集数 |
| **跳过** | 被系统跳过的集数 |

常用按钮：

| 按钮 | 用途 |
|---|---|
| **查看详情** | 查看每集生成结果和失败原因 |
| **刷新** | 手动更新进度 |
| **强制停止** | 停止当前批量任务 |

复杂项目可能需要几分钟甚至更久。只要进度还在变化，建议继续等待。

## 检查生成结果

打开生成后的分集，按下面清单检查：

- 标题和集数是否正确。
- 内容是否完整，有没有中途截断。
- 人物关系是否符合全局框架。
- 人物、地点、道具名称是否前后一致。
- 重要动作是否写清起点、终点和方向。

更利于后续剧本分析的写法：

> 阿杰原本站在门外，把门向里推开后进入客厅，停在茶几左前方半步处，面向坐在沙发中段的母亲。

不推荐过于省略的写法：

> 阿杰开门进来。

## 异常速查

| 问题 | 常见原因 | 处理方式 |
|---|---|---|
| Episodes Count 无效 | 未填集数，或不是正整数 | 在 **载体规格 / 集数** 填入 `12`、`20` 等正整数 |
| 全局框架为空 | 尚未生成或保存全局框架 | 先点击 **生成全局框架**，确认 Markdown 出现并保存 |
| 旧内容被覆盖 | 生成时确认了覆盖 | 生成前确认是否需要保留旧版；之后可用单集重新调整 |
| 某几集失败 | 模型异常、网络中断、内容被拦截、标题解析失败 | 点 **查看详情** 找到失败集，再用 **单集生成** 补生成 |
| 一直运行中 | 任务排队、模型较慢、状态未刷新或任务卡住 | 先 **刷新**，再看 **查看详情**；确认卡住后点 **强制停止** |
| 单集生成后没跳转 | 页面状态未刷新或目标分集未自动打开 | 点 **刷新**，手动打开目标集数检查 |
| 内容跑偏 | 全局框架不够明确，创意说明太笼统 | 修改全局框架或创意说明，再单集生成 |
| 人物/地点名称混乱 | 同一对象多个叫法混用 | 在全局框架统一命名，再重生成受影响集数 |

## 推荐工作流

1. 补齐项目概览。
2. 进入 **剧本生成**。
3. 填写集数、规格、受众和创意说明。
4. 生成全局框架。
5. 检查并保存全局框架。
6. 全量生成分集，或只生成指定单集。
7. 打开分集检查剧本文本。
8. 对不满意的集数单独重生成。
9. 确认剧本可用后，进入剧本分析流程。

## 使用建议

- 先把全局框架调顺，再生成分集。
- 小范围问题优先用 **单集生成**。
- 生成前认真看覆盖提示。
- 人物、地点、道具命名尽量统一。
- 门窗开关、人物移动、道具拿放等动作，要写清原始位置、方向、路径和落点。
