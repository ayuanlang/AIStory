# 资产页面操作手册

管理角色、环境、道具、海报等主体资产，并为后续分镜、图片和视频生成准备可复用素材。

> 适用场景：剧本分析后需要检查、补齐、生成或替换主体资产。  
> 建议顺序：先确认资产清单，再生成图片；先小范围修正，再批量处理。

## 快速路径

| 步骤 | 页面位置 | 要做什么 | 完成标志 |
|---|---|---|---|
| 1 | 资产页顶部 | 选择 **角色 / 环境 / 道具 / 海报** | 列表只显示目标类型 |
| 2 | 资产卡片 | 检查名称、描述、依赖和参考图 | 信息没有明显缺漏 |
| 3 | 单个资产 | 点击 **设计资产** 或 **修改资产** | 当前资产生成完成 |
| 4 | 顶部按钮 | 点击 **批量生图** | 批量进度开始变化 |
| 5 | 素材/上传入口 | 更换图片或复用素材库图片 | 卡片预览图更新 |
| 6 | 资产参考 | 设置参考图和依赖关系 | 生成结果更稳定 |

## 页面元素说明

| 区域 | 用途 |
|---|---|
| **合计** | 显示当前范围内已生成图片的资产数量 |
| **角色 / 环境 / 道具 / 海报** | 按资产类型筛选列表 |
| **文生图 / 图生图接口** | 选择当前资产生成使用的 AI 接口 |
| **当前分集 / 整个项目** | 切换资产查看范围 |
| **批量生图** | 为当前范围内的资产批量生成图片 |
| **停止** | 停止当前批量任务 |
| **新增资产** | 从 subjects index 和 entity_design 自动新增资产 |
| **删除全部主体资产** | 删除当前范围内主体资产，操作前务必确认 |

## 使用前检查

| 检查项 | 为什么重要 |
|---|---|
| 是否选对分集/项目范围 | 避免误操作其他分集资产 |
| 资产名称是否统一 | 避免同一角色或道具重复生成 |
| 资产描述是否清楚 | 描述越清楚，生成结果越稳定 |
| 是否有依赖关系 | 衍生角色、服装、道具可能需要参考源实体 |
| AI 接口是否可用 | 批量生图和单个生图都依赖接口配置 |

## 筛选资产类型

顶部可以切换：

| 类型 | 常见内容 | 检查重点 |
|---|---|---|
| **角色** | 主角、配角、群演簇、衍生角色 | 身份、年龄、服装、气质、与其他角色关系 |
| **环境** | 室内外空间、场景空间、衍生环境 | 空间边界、入口出口、主锚点、关键陈设 |
| **道具** | 剧情道具、交互道具、关键物件 | 用途、尺寸、材质、持有者、出现位置 |
| **海报** | 封面、宣传图、视觉主图 | 主题、人物关系、项目气质 |

## 生成单个资产

在资产卡片中点击 **设计资产**。

适合：

- 新资产第一次生成。
- 只想处理某一个角色、道具或环境。
- 批量生成前先试一两个关键资产效果。

生成前建议确认：

- 名称是否准确。
- 属性描述是否足够具体。
- 是否已经绑定合适的参考图。
- 如果是衍生资产，源实体或依赖关系是否正确。

## 批量生图

点击顶部 **批量生图**，系统会按当前范围批量生成资产图片。

适合：

- 剧本分析后资产清单已经基本确认。
- 需要一次性补齐当前分集资产图片。
- 资产描述质量较稳定。

批量过程中会显示任务状态和进度。若发现选错范围、接口异常或结果明显跑偏，可以点击 **停止**。

> 建议：第一次不要直接全项目批量。先在当前分集生成一小批，确认风格稳定后再扩大范围。

## 新增资产

点击 **新增资产**，可按 subjects index 和 entity_design 自动新增实体。

适合：

- 剧本分析漏掉少量角色、道具或环境。
- 需要从现有设计文本里补录资产。
- 想让系统按类型自动识别并创建资产。

新增后建议立即检查：

- 类型是否正确。
- 名称是否和剧本一致。
- 是否和已有资产重复。
- 描述是否足够生成图片。

## 更换图片与复用素材

资产卡片中可通过素材库或上传方式更换图片。

| 操作 | 适合情况 |
|---|---|
| **从素材库选择** | 已有素材图比当前图更准确 |
| **上传图片** | 手上已有外部参考图或定稿图 |
| **复用资产** | 想沿用已有图片和锚点描述 |
| **仅设为参考图** | 只想让它参与生成，不想覆盖当前锚点 |

如果图片任务正在运行，部分更换操作可能会被锁定。请等待任务完成或停止后再操作。

## 修改资产

当已有图片不满意时，可以在 **修改资产** 中输入具体指令。

写法建议：

| 不够清楚 | 更推荐 |
|---|---|
| 改好看一点 | 保留人物五官和黑色外套，把表情改得更冷静，背景维持办公室，不要换成街景 |
| 道具更旧 | 保留铜镜形状，增加边缘磨损和暗色氧化痕迹，不要改变尺寸 |
| 环境更压抑 | 保持医院走廊空间，降低整体亮度，保留护士站和远处病房门 |

修改资产会触发重新生成图片。重要资产建议一次只改一两个点，方便判断效果。

## 资产依赖与参考

部分资产会依赖其他资产，例如：

- 角色换装依赖基础角色。
- 道具持有状态依赖角色或场景。
- 衍生环境依赖主环境。
- 海报依赖角色和项目风格。

使用建议：

1. 先生成基础角色和主环境。
2. 再生成衍生角色、道具和环境。
3. 最后生成海报或封面。
4. 如果依赖资产不满意，先修依赖源，再修衍生资产。

## 异常速查

| 问题 | 常见原因 | 处理方式 |
|---|---|---|
| 批量生图一直运行 | 任务排队、接口较慢或任务卡住 | 先观察进度；长时间不动可点 **停止** 后重试 |
| 生成失败 | 接口不可用、提示词异常、参考图不可访问 | 换接口、检查描述和参考图，再单个重试 |
| 图片没有同步回来 | 结果仍在回写或临时链接未稳定 | 等待片刻刷新；必要时重新生成当前资产 |
| 资产重复 | 剧本中同一对象多种叫法 | 统一命名，删除或合并重复项 |
| 类型分错 | 资产名称或描述不清 | 手动调整类型或重新新增 |
| 更换图片失败 | 图片任务运行中、素材链接失效或上传失败 | 等任务结束；换素材；重新上传 |
| 修改后跑偏 | 指令太笼统或一次改动太多 | 写清保留项和禁止项，小步修改 |
| 删除错资产 | 误点删除或范围选错 | 删除前确认当前分集/整个项目范围；必要时重新新增 |

## 推荐工作流

1. 剧本分析完成后进入资产页。
2. 切到 **当前分集**，先检查角色、环境、道具、海报数量。
3. 修正重复、漏项和类型错误。
4. 先生成关键角色和主环境。
5. 再批量生成其余资产。
6. 对不满意资产使用 **修改资产** 或更换参考图。
7. 确认资产图片稳定后，再进入分镜、图片或视频制作。

## 使用建议

- 批量前先小范围试生成。
- 关键角色优先单独生成和确认。
- 描述里写清必须保留的特征和禁止变化的内容。
- 参考图越准确，图生图和修改资产越稳定。
- 删除和全量操作前，先确认当前范围是“当前分集”还是“整个项目”。
