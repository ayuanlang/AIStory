# 📙 资产页面操作手册

管理本集角色、环境、道具、海报的主体图片，供后续分镜、生图、视频复用。

> 适合：剧本分析已跑完（或局部重跑后），要检查、补齐、生成或替换主体图。  
> 剧本 / 清单 / 设计还没齐？先回 [剧本分析操作手册](script_analysis_user_manual.md)。

**资产页管的是「图」；清单与设计文案管的是「有没有这个主体」。**  
列表里缺名字、缺设计描述 → 去 **剧本分析** 重跑资产；有名字没图 → 在本页 **设计资产 / 批量生图**，或从旧集 **复用资产**。

卡住了点顶部 **信息图标（本手册）** 旁的 **听诊器图标（AI 诊断）**。

---

## 🚀 快速上手

1. 顶部范围选 **当前分集**（日常不要直接用「整个项目」批量）。  
2. 按 **角色 / 环境 / 道具 / 海报** 核对数量与名字是否和剧本一致。  
3. 文生图接口按下方建议选好（优先 **gpt-Image-2**）。  
4. 关键角色、主环境先 **设计资产** 试一两张；满意后再 **批量生图**。  
5. 缺主体（连卡片都没有）→ 回剧本分析做 **资产生成重跑**；有卡片没图 → 本页生图或复用旧集图。

---

## 🔌 生图 API 怎么选

资产页顶部有 **文生图** / **图生图** 下拉（以及 **分析** 接口，用于提示词反推等）。日常生图按下面优先级选：

| 选择 | 说明 |
|---|---|
| **优先：gpt-Image-2** | 主体生图首选，质量与可控性更稳，适合角色、道具、环境主流程。 |
| **候补：banana 系列** | gpt-Image-2 排队慢、失败或效果不理想时换用；作为常规备选通道。 |
| **受限内容：Flux / Doubao 等** | 遇 **血腥、暴力、儿童相关** 等合规拦截，或主接口反复拒生时，改试 **Flux、Doubao** 等更宽松或本地/国内通道，再个别重试该资产。 |

简记：**日常 gpt-Image-2 → 不稳换 banana → 血腥 / 儿童等被拦再用 Flux、Doubao 等尝试。**

> 不同供应商名称在下拉框里可能略有前后缀，按关键字认准即可。换接口后，对失败那几条单独 **设计资产** 重试，不必整集重批量。

## 📦 分集资产怎么继承

### 先弄清一件事

资产是 **按分集存的**：同一角色在第 1 集和第 2 集是两条记录，不是全项目共用一行。  
顶部 **当前分集 / 整个项目** 只改变「看见谁、批量谁」，不会把多集合并成一条。

跨集「继承」= **新集里再有一条同名主体**，并可挂上旧集参考；**不会自动把旧集图片拷过去**，需要你生图或点 **复用资产**。

### 正常流水线（最常见）

1. 上一集资产图已经定稿。  
2. 对本集跑完剧本分析的 **资产设计**（或做 **资产生成重跑**）并入库。  
3. 系统在本集 **新建** 同名主体；若其他集已有同名，会挂上对旧实体的参考关系（依赖里的源实体），**本集卡片默认仍是未生图**。  
4. 打开 **资产** → **当前分集**：  
   - 要和旧集长得一样 → 打开卡片，用 **复用资产** / **从素材库选择** 挂上旧图；或  
   - 要本集新画一张 → **设计资产** / **批量生图**（有依赖时按依赖顺序，缺依赖图会跳过并提示）。  
5. 若卡片上有 **从源实体同步**：只同步名称、描述等文字字段，**不同步图片**；图仍要复用或重画。

### 想主动从某集「派生」一条

1. 资产页点 **新增资产** → **AI 新增实体** → **派生实体**。  
2. **参考实体所属分集** 选旧集 / 全部分集 / 项目级。  
3. **选择参考实体**，可填 **追加描述**（换装、伤势、本集特有状态等），点 **开始生成**。  
4. 新实体落在 **当前分集**，并以参考实体为视觉依赖。

### 继承时注意

| 要点 | 说明 |
|---|---|
| 同名不同集 | 是两份资产；改本集不会改旧集 |
| 本集已有同名 | 再导入时通常跳过，不会覆盖已有卡片 |
| 先基础后衍生 | 基础角色 / 主环境先有图，再画换装、衍生环境、依赖道具 |
| 范围别选错 | 删除、批量前确认是 **当前分集** 还是 **整个项目** |

## 🆘 缺了资产怎么办

先分清缺的是哪一种：

| 你看到的情况 | 缺的是什么 | 去哪处理 |
|---|---|---|
| **当前分集**下列表根本没有这个角色/道具/环境 | 缺清单或缺资产设计入库 | **剧本分析** → 资产重跑（见下） |
| 有卡片，但没图 / 生图失败 | 缺图片 | **资产页** 生图、换接口重试，或 **复用资产** |
| 场景页提示「缺失 N 个 subjects」 | 场次认不到主体 | 点该提示 → 跳到剧本分析 **资产生成重跑** |

### 正解：回剧本分析做「资产生成重跑」

资产页的 **新增资产** 只适合补个别手工实体，**不能代替** 整类/整集的资产设计。缺了一批主体时：

1. 打开 **剧本分析** 页（同一分集）。  
2. 看 **进度诊断面板** 里的步骤：**剧本统筹 → 资产清单 → 场景编排 → 资产设计 → 分镜生成**。  
3. 按缺口选择：  
   - **资产清单** 本身不对 / 没有 → 在 **资产清单** 上点 **重跑**（会再带动后续编排与设计，详见剧本分析手册）。  
   - 清单有了，但角色/道具/环境/海报设计或入库缺了 → 在 **资产设计** 上点 **重跑** / **重跑失败项** / **选择重跑**。  
4. 弹出 **资产生成重跑选择**：  
   - **全部重跑** / **分类重跑**（角色、道具、环境、封面/海报）/ **单实体重跑**  
   - 可 **新增条目** 后 **保存新增**，再 **确认重跑**  
5. 重跑并导入完成后，回到 **资产** 页 → **当前分集**，对新建卡片做 **设计资产** 或 **批量生图**。

> 场景页出现 **「缺失 N 个 subjects，点击前往资产生成重跑」** 时，直接点它即可进入同一套重跑流程。

### 资产页能补、不能替的事

| 可以 | 不可以指望它 |
|---|---|
| 个别漏加： **新增资产**（文生 / 图生 / 派生） | 代替剧本分析把一整类资产设计跑完 |
| 有卡片没图： **设计资产**、**批量生图**、**复用资产** | 自动从旧集把图灌进所有新卡片 |
| 文案跟源实体不一致： **从源实体同步** | 同步图片 |

两条铁律（与剧本分析一致）：

1. **上游改了（清单/设计）→ 下游要重跑或再导入才生效。**  
2. **重跑前先弄清旧内容**：系统不会自动覆盖已入库主体；重复同名通常跳过。

## 🧭 页面上有什么

| 区域 | 用途 |
|---|---|
| **合计** | 当前范围内「已有图 / 总资产」 |
| **角色 / 环境 / 道具 / 海报** | 按类型筛选 |
| **文生图 / 图生图 / 分析** | 选生图与分析用的接口 |
| **当前分集 / 整个项目** | 查看与批量范围 |
| **信息图标** | 打开本手册 |
| **听诊器图标** | **AI 诊断**（多轮对话排查） |
| **批量生图** | 按依赖顺序给未出图主体批量生图 |
| **停止** | 停下当前批量任务 |
| **素材库回填** | 给当前分集空链接挂上素材库里最新匹配素材 |
| **新增资产** | 打开 **AI 新增实体** |
| **删除全部主体资产** | 危险操作；先确认范围 |

卡片常用：**设计资产**、**修改资产**、**更换图片**、**复用资产**、**仅参考**、**从素材库选择**、**从源实体同步**。

## 🎨 生图与改图

### 单个：设计资产

适合第一次出图、关键角色试风格、批量前抽样。  
生成前确认：名字对、描述够具体、依赖源已有图、接口已按上文选好。

### 批量生图

适合清单已齐、描述稳定、要一次补齐本集未出图主体。  
队列按场景顺序再按依赖顺序；**依赖还没图的会跳过并提示**——先补依赖再重批量。  
跑偏或接口异常点 **停止**，换接口后只重试失败项。

> 第一次不要用「整个项目」大批量；先在本集小范围确认风格。

### 修改资产

已有图不满意时写清：**保留什么、改什么、禁止改成什么**。一次只改一两个点。

### 换图与复用

| 操作 | 适合 |
|---|---|
| **从素材库选择** | 库里已有更准的图 |
| **上传图片** | 外部定稿 / 参考 |
| **复用资产** | 把已有图（及可选锚点）绑到当前主体——跨集继承外观常用 |
| **仅参考** | 只当生图参考，不覆盖当前图 |

任务进行中部分操作会锁定，等完成或 **停止** 后再改。

---

## 🔗 依赖怎么排

常见：换装依赖基础角色；衍生环境依赖主环境；道具/海报依赖角色或风格源。

建议顺序：

1. 基础角色、主环境  
2. 衍生角色、状态环境、依赖道具  
3. 海报 / 封面  

依赖源图不对时，先修源再修衍生。

---

## 🩺 AI 诊断

顶部听诊器图标。系统会带上本手册、日志、当前资产概况（范围、生图进度、未出图与依赖缺口等），可多轮追问，也可把对话发给运营。  
每轮对话按剧本分析接口计费；只发送已有对话给运营不计费。

## 🛠️ 异常速查

| 问题 | 常见原因 | 处理 |
|---|---|---|
| 本集没有某角色/道具/环境 | 清单或资产设计未入库 | 剧本分析 → **资产设计** → **资产生成重跑选择** → **确认重跑** |
| 场景提示缺失 subjects | 场次与主体对不上 | 点提示进 **资产生成重跑** |
| 有卡片没图 | 未生图或失败 | **设计资产**；换 **gpt-Image-2 / banana**；被拦试 **Flux / Doubao** |
| 血腥 / 儿童等内容被拒 | 主接口合规拦截 | 换 Flux、Doubao 等再试该条 |
| 批量一直转 | 排队、卡住 | 观察进度；不动则 **停止** 后小范围重试 |
| 依赖被跳过 | 源实体无图 | 先给依赖源出图，再批量 |
| 和上集长得不一样 | 继承只建了新卡，没复用图 | **复用资产** 或挂素材库旧图 |
| **从源实体同步** 后图没变 | 设计如此（不同步图） | 再 **复用资产** / 重画 |
| 删错 / 批量错集 | 范围选成整个项目 | 操作前确认 **当前分集** |
| 不知下一步 | — | 顶部 **AI 诊断** |

## 🧩 推荐工作流

1. 本集剧本分析齐套（至少 **资产清单 + 资产设计** 已入库）。  
2. 资产页 → **当前分集**，核对四类数量与命名。  
3. 接口：**gpt-Image-2**（候补 banana；受限内容再换 Flux / Doubao）。  
4. 需要跨集统一外观：对关键卡 **复用资产**；其余再 **批量生图**。  
5. 缺卡片 → 剧本分析 **资产生成重跑**；回来再出图。  
6. 图稳定后再做分镜 / 镜头图 / 视频。

---

## 💡 使用建议

- 日常范围用 **当前分集**；删和全量操作前再看一眼范围。  
- 关键角色单独出图确认，再批量。  
- 跨集要「长得像」：复用或挂旧图，别假设系统会自动拷图。  
- 缺名字回剧本分析重跑；缺图留在资产页解决。  
- 不确定就点 **AI 诊断**。
