# 分组的特殊性及价格差异

# 特殊性具体体现

## 渠道来源差异

- GPT、Claude 等模型在不同的分组中所对应的渠道来源是不同的，因而同一个模型在各分组中的价格是不同的

- 我们采取明码实价策略，确保透明度

- 用户可根据自身需求选择最适合的分组，更具灵活性

## 官方费率说明

为了更好地理解价格关系，我们引入了 “官方费率” 概念：

1. 当分组的费率是 1 时：
  假如官方价格是 1 刀，我们平台也只扣 1 刀
2. 当分组的费率是 1.65 时：
  假如官方价格是 1 刀，我们平台将会扣 1.65 刀
  
通过这种方式，我们为用户提供了更加灵活和透明的定价机制，使其能够根据自己的需求和预算做出最佳选择。
